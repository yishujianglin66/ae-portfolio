### 3.3 适配器统一接口模式

所有适配器遵循统一接口：
```python
class XxxAdapter:
    TOOL_NAME: str                    # 工具标识
    SUPPORTED_OPERATIONS: Dict        # 操作注册表
    def check_available(self) -> bool # 可用性检测（fail-closed）
    def list_operations(self) -> list # 操作列表
    def execute(self, op, params)     # 统一执行
```

### 3.4 降级策略

- **adobe-mcp**: COM 自动化 → ExtendScript → 错误提示（三级）
- **firecrawl**: Cloud API → 本地缓存 → 空结果（三级）
- **BlenderProc**: subprocess CLI → Python API → 空结果（两级）
- **MediaCrawler**: subprocess CLI → Python import → 空结果（两级）
- **所有适配器**: 外部服务不可用时返回 degraded/failed 状态，不崩溃
