## Phase 2: 智能剪辑编排集成

**优先级: P0 | 预计工作量: 3 天**

### 2.1 集成转场规则引擎 (transition_selector)
- **文件**: `puppet-automation/src/engines/premiere/engine.py`
- **新增方法**: `smart_transition(clip_a_info, clip_b_info, content_relation)`
- **逻辑**:
  1. 调用 `transition_selector.select_transition(style, content_relation)` 获取推荐转场
  2. 自动在剪辑间应用转场
  3. 支持风格参数：fast_cut / music_video / cinematic / documentary / vlog / tutorial / gaming
- **API 端点**: `POST /api/v1/premiere/transitions/smart`

### 2.2 集成字幕产品化 (subtitle_product)
- **新增方法**: `add_subtitle_track(subtitles, style_preset, sequence_name)`
- **逻辑**:
  1. 创建字幕轨道（或使用已有轨道）
  2. 调用 `subtitle_product.generate_captions(subtitles, style_preset)` 获取样式化字幕数据
  3. 在 PR 中创建字幕剪辑（支持 PR 原生字幕或图形剪辑）
  4. 支持 6 种预设风格：抖音风 / B站风 / 电影风 / 极简风 / 游戏风 / 新闻风
- **API 端点**: `POST /api/v1/premiere/subtitles`

### 2.3 集成创意模式库 (creative_patterns)
- **新增方法**: `apply_creative_pattern(pattern_name, sequence_name, params)`
- **逻辑**:
  1. 从 `creative_patterns` 获取模式定义
  2. 在 PR 中创建对应的轨道结构和剪辑布局
  3. 支持模式：卡点快剪 / 分屏 / 画中画 / 文字叠加 / 节奏蒙太奇
- **API 端点**: `POST /api/v1/premiere/patterns`

### 2.4 智能自动粗剪增强
- **新增方法**: `smart_auto_edit(clips, music_bpm, beats, creative_style)`
- **逻辑**:
  1. 调用 `ai_creative_planner` 获取创意规划
  2. 调用 `timeline_composer` 获取时间线布局
  3. 在 PR 中执行完整编排
- **API 端点**: `POST /api/v1/premiere/smart-edit`

## Phase 3: Timeline IR 标准化

**优先级: P1 | 预计工作量: 3 天**

### 3.1 创建 IR 模块
- **路径**: `puppet-automation/src/engines/premiere/ir/`
- **文件**:
  - `__init__.py` — 导出公开接口
  - `schema.py` — IR 数据结构定义
  - `builder.py` — 从编排数据构建 IR
  - `pr_exporter.py` — IR → PR ExtendScript 转换
  - `validator.py` — IR 校验规则

### 3.2 IR 数据结构

```python
@dataclass
class IRClip:
    source_path: Path
    name: str
    in_point: float  # 秒
    out_point: float
    track_index: int
    track_type: str  # "video" | "audio" | "subtitle"
    start_time: float  # 在时间轴上的位置
    speed: float = 1.0
    opacity: float = 1.0
    volume: float = 1.0
    effects: List[IREffect] = field(default_factory=list)
    transition_in: Optional[IRTransition] = None
    transition_out: Optional[IRTransition] = None

@dataclass
class IRTrack:
    index: int
    type: str  # "video" | "audio" | "subtitle"
    name: str
    clips: List[IRClip] = field(default_factory=list)
    mute: bool = False
    solo: bool = False

@dataclass
class IRSequence:
    name: str
    width: int = 1920
    height: int = 1080
    fps: float = 30.0
    tracks: List[IRTrack] = field(default_factory=list)
    markers: List[IRMarker] = field(default_factory=list)
```

### 3.3 IR → PR ExtendScript 转换
- `pr_exporter.py` 实现 IR → PR 原生 API 调用序列
- 支持批量操作（减少 Bridge 往返次数）
- 支持增量更新（增量 IR → 只修改变化的剪辑）

### 3.4 IR 校验
- 40+ 规则覆盖：时间合法性、轨道索引冲突、参数范围、素材存在性
- 参考 `validate_ir()` 现有实现

## 开发原则

1. **先原子操作，后高级工作流** — 每个高级功能都建立在原子操作之上
2. **Bridge 在线优先，JSX 降级兜底** — 所有功能在 Bridge 离线时仍可生成 JSX 文件
3. **JSX 注入防御** — 所有用户可控字符串参数必须经过 `_jsx_escape()`
4. **批量操作合并** — 多条相近操作合并为单条 JSX 减少 Bridge 往返
5. **测试先行** — 每个新功能先写测试再实现
6. **渐进式 IR 集成** — IR 标准化不阻塞其他阶段，可并行开发
