## 三、进行中任务 — 木偶动画（最新主线 🔴）

### 3.1 背景与根因（为什么之前 100+ 版本不达标）

**核心诊断**：木偶动画链路薄弱，3渲2 渲染反复调参达不到目标。
- `cel_shading.py` v10 已记录死结：**FBX 静态网格无骨骼，程序化骨骼+auto-weight 蒙皮致网格变形 → 回滚移除骨骼系统**
- 现状 = 静态网格整体位移/缩放模拟"木偶" → 没有真正关节转动
- **结论**：不是渲染参数问题，是动画机制错了。改"部件木偶 + 刚性关节"（Live2D 式）——已完整调研确认（`09-计划文件/2026-08-16_木偶骨骼操纵升级方案.md`，commit `e1e59fa`）

### 3.2 UE 是否接入？ — 明确不接

- UE 解决不了"无骨骼"根因（UE 自动绑骨最弱）
- UE 三渲二需自建 Unlit 管线 + 无矢量描边
- Blender bpy 是"单镜头脚本化批量"主场
- **结论**：不接 UE，打磨 Blender（详见方案文档）

### 3.4 最新突破（本会话最后状态 🔴 接手者从这里继续）

**问题**：v11 模型正立但相机视角不对（从下往上看脚底 / 上下颠倒）。

**决定性修复（已验证成功）**：**look_at 矩阵直接设置相机**（数学确定，不依赖欧拉角）
- 参考脚本：`tmp/test_lookat.py`（项目根 tmp 目录）
- 核心代码：
```python
cam_pos = Vector((center.x, center.y - size*0.9, center.z))  # 从 -Y 方向看
target = center
forward = (target - cam_pos).normalized()
up = Vector((0, 0, 1))
right = forward.cross(up).normalized()
true_up = right.cross(forward).normalized()
m = Matrix((
    (right.x, true_up.x, -forward.x, cam_pos.x),
    (right.y, true_up.y, -forward.y, cam_pos.y),
    (right.z, true_up.z, -forward.z, cam_pos.z),
    (0, 0, 0, 1),
))
cam.matrix_world = m  # Blender 相机朝 -Z
```

**验证结果**（`tmp/lookat/lookat.png`）：
- 模型 114x599px 正立（宽高比 0.19）
- 头在上（顶部窄 48px）脚在下（底部宽 112px）— **方向正确的人形**
- 模型区饱和度 55.4（贴图颜色显示正常）

**当前已完成**：完整模型（不分离）+ 贴图 + 正立 + look_at 相机 → 单帧渲染成功
**未完成**：把 look_at 方案固化进引擎 + 跑完整挥剑动画 MP4
