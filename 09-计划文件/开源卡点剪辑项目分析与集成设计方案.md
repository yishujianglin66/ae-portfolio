## 二、ai-montage-agent 深度分析（最相关 ★★★★★）

### 2.1 项目定位
AI 自动影视混剪 Agent — 输入视频 + BGM，自动生成卡点混剪。

### 2.2 架构设计（模块化，高度可借鉴）
```
ai-montage-agent/
├── packages/
│   ├── video_understanding/   # 镜头检测 + 高光评分
│   ├── beat_engine/           # 节拍检测 + 卡点同步
│   ├── timeline_engine/       # 情绪曲线/节奏/镜头分配  ← 核心！
│   ├── montage_engine/        # 10+ 种转场
│   ├── render_engine/         # FFmpeg 执行器
│   ├── video_enhancement/     # 防抖/降噪/调色/风格模板
│   ├── ai_director/           # LLM 自然语言控制
│   └── timeline_export/       # EDL/CSV/JSON/XML/OTIO
```

### 2.3 关键能力对比

| 能力 | ai-montage-agent | 当前项目(v20e) | 差距 |
|------|-----------------|----------------|------|
| **高光评分** | 5维评分(运动/镜头多样性/表情/运镜/音频) | 无，随机/轮询分配 | **致命缺失** |
| **节拍分级** | 强拍/弱拍分级，不同镜头类型对应 | 仅onset强度+能量百分位 | 缺少节拍强弱语义 |
| **风格预设** | 11种预设(action/vlog/cinematic等) | 手动bar模式，无预设系统 | 缺少标准化风格 |
| **LLM控制** | 自然语言→剪辑指令 | 无 | 缺少智能导演层 |
| **转场系统** | 10+种(dissolve/zoom/shake/wipe) | 仅cut/fade两种 | 转场太单一 |
| **素材理解** | 镜头检测+高光评分驱动选段 | 无视频内容理解 | 素材选择盲目 |
| **时间轴导出** | EDL/OTIO可导入PR/DaVinci | 无 | 无法进入专业工作流 |

### 2.4 最值得借鉴的3个设计

#### ① 5维高光评分系统
```python
# ai-montage-agent 的高光评分维度
highlight_score = {
    "motion":      motion_intensity,      # 画面运动强度
    "shot_variety": shot_diversity_score,  # 镜头多样性
    "expression":  face_expression_score,  # 表情丰富度
    "camera":      camera_movement_score,  # 运镜质量
    "audio":       audio_energy_score,     # 音频能量
}
total_score = weighted_sum(highlight_score)
```
**对你的价值**: 当前素材分配是"随机取段"或"按情绪选源"，完全没有评估素材本身的质量。引入高光评分后，系统能自动选择最精彩的画面片段。

####  节拍强弱分级 + 镜头类型映射
```python
# 强拍 → 重要镜头（高评分素材）
# 弱拍 → 过渡镜头（低评分素材）
if beat_strength > threshold:
    shot_type = "key_shot"    # 关键镜头，用高光素材
else:
    shot_type = "transition"  # 过渡镜头，用普通素材
```
**对你的价值**: 当前所有切点一视同仁，不区分强弱拍。实际上强拍应该配高冲击力的画面和技巧，弱拍配过渡性画面。

#### ③ 风格预设系统
```python
style_presets = {
    "action":    {"cut_rate": "high", "transitions": "zoom/shake", "speed_range": (1.0, 2.0)},
    "cinematic": {"cut_rate": "medium", "transitions": "dissolve", "speed_range": (0.8, 1.2)},
    "vlog":      {"cut_rate": "low", "transitions": "fade", "speed_range": (0.9, 1.1)},
    "mtv":       {"cut_rate": "very_high", "transitions": "flash", "speed_range": (0.5, 2.0)},
}
```
**对你的价值**: 当前每个bar手动配置技巧模式，换一首BGM就要重新调。风格预设可以让系统一键切换"漫剪风格"、"电影风格"、"MV风格"。

### 3.3 最值得借鉴的设计

#### ① 模板节奏复刻（最核心）
```
参考视频 → detect_cuts.py → 提取切点时间轴 → splice_video_rhythm.py → 用素材复刻节奏
```

**对你的价值**: 这是当前项目最大的缺失！你一直在手动设计bar模式、onset映射，但专业漫剪的做法是：**找一段优秀的参考AMV，分析它的剪辑节奏（哪里快切、哪里慢放、哪里定格），然后复刻这个节奏到你的素材上。**

```python
# packages/beat_engine.py
class BeatStrengthEngine:
    """节拍强弱分级引擎"""
    
    def classify_beats(self, beats_sec, downbeats_sec, onset_env):
        """将每个节拍分类为 strong/medium/weak"""
        classifications = []
        for beat in beats_sec:
            # 1. 是否是downbeat（重拍）
            is_downbeat = any(abs(beat - db) < 0.05 for db in downbeats_sec)
            
            # 2. onset能量强度
            onset_strength = onset_env_at(beat)
            
            # 3. 综合分级
            if is_downbeat and onset_strength > threshold_high:
                level = "strong"    # 强拍 → 配关键画面+强冲击技巧
            elif onset_strength > threshold_mid:
                level = "medium"    # 中拍 → 配过渡画面
            else:
                level = "weak"      # 弱拍 → 配普通画面
            
            classifications.append({
                "time": beat,
                "level": level,
                "is_downbeat": is_downbeat,
                "onset_strength": onset_strength,
            })
        return classifications
    
    def get_shot_type(self, beat_level, energy_percentile):
        """根据节拍强度决定镜头类型"""
        if beat_level == "strong":
            return "key_shot"      # 关键镜头：高评分素材 + 强冲击技巧
        elif beat_level == "medium":
            return "normal_shot"   # 普通镜头：中等素材
        else:
            return "transition"    # 过渡镜头：低要求素材
```

### 6.3 P1 实现方案：模板节奏复刻

```python
# packages/template_rhythm.py
import cv2
import numpy as np

class TemplateRhythmAnalyzer:
    """分析参考视频的剪辑节奏，生成可复用的节奏模板"""
    
    def analyze(self, template_video_path):
        """分析模板视频的切点时间轴"""
        cap = cv2.VideoCapture(template_video_path)
        fps = cap.get(cv2.CAP_PROP_FPS)
        
        cut_times = []
        prev_frame = None
        frame_idx = 0
        
        while True:
            ret, frame = cap.read()
            if not ret:
                break
            
            if prev_frame is not None:
                # 计算帧间亮度差
                diff = np.mean(np.abs(
                    cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY).astype(float) - 
                    cv2.cvtColor(prev_frame, cv2.COLOR_BGR2GRAY).astype(float)
                ))
                
                if diff > CUT_THRESHOLD:
                    cut_times.append(frame_idx / fps)
            
            prev_frame = frame
            frame_idx += 1
        
        return cut_times
    
    def generate_rhythm_profile(self, cut_times, bgm_duration):
        """生成节奏画像（可复用的节奏模板）"""
        intervals = np.diff(cut_times)
        profile = {
            "cut_times": cut_times,
            "avg_interval": np.mean(intervals),
            "min_interval": np.min(intervals),
            "max_interval": np.max(intervals),
            "density_curve": self._compute_density(cut_times, bgm_duration),
            "rhythm_pattern": self._classify_pattern(intervals),
        }
        return profile
    
    def apply_to_new_bgm(self, rhythm_profile, new_bgm_duration):
        """将节奏模板适配到新的BGM时长"""
        scale = new_bgm_duration / rhythm_profile["bgm_duration"]
        new_cut_times = [t * scale for t in rhythm_profile["cut_times"]]
        return new_cut_times
```

**使用流程**:
```
1. 找一段优秀的漫剪AMV作为参考
2. TemplateRhythmAnalyzer.analyze() 提取切点时间轴
3. generate_rhythm_profile() 生成节奏画像
4. apply_to_new_bgm() 适配到你的BGM
5. 用这个节奏模板驱动你的素材剪辑
```

## 七、结论与建议

### 7.1 核心结论

1. **当前项目的根本问题不是节拍对齐精度**（v20e已达10.7ms平均偏差），而是**缺少素材内容理解和节拍语义分级**。

2. **ai-montage-agent 是最值得借鉴的项目**，其5维高光评分系统和节拍强弱分级直接解决了"素材选择盲目"和"强拍弱拍无区别"两个P0问题。

3. **hookcut 的模板节奏复刻能力**是当前项目完全缺失的维度。专业漫剪的核心技法就是分析参考片节奏并复刻，而不是从零设计。

4. **不建议直接集成这些项目的代码**（架构差异大、依赖复杂），而是**借鉴其设计思想**，在自己的 `production_director.py` 中实现对应模块。
