# 文字高级化推进方案：描边体系与三维层（2026-09-11）

> 前置：v11 已通过 Boss 验收（字体分区轮换 + 对比度感知样式 + 彩色光晕）。
> 本文回答「描边与三维层怎么推进、需要更高级的设计」。
> 全部能力结论来自 2026-09-11 的 AE 实机探针（`.ae-mcp-bridge/probe_*.jsx`），非文档转述。
> 铁律沿用：**先探针后编码**（A1）· **字体真身必须渲染差分验证**（v6.1 事故）· 每版渲染前基底重置。

## 一、能力可用性矩阵（实机探针实证）

| 能力 | 脚本可用性 | 证据 |
|------|-----------|------|
| 基础描边（TextDocument applyStroke/strokeWidth/strokeOverFill） | ✅ 已用 | 现网代码 |
| 描边随能量脉动（strokeWidth 关键帧） | ✅ | 同上，属性可关键帧 |
| **文字动画器补描边**（ADBE Text Stroke Color / Stroke Width / Stroke Opacity） | ✅ 可添加 | probe_stroke_routes: 5 属性全 OK |
| 多动画器叠加第二描边 | ⚠️ 待解 | 第二动画器 addProperty 报"对象无效"——需换顺序/先加选择器 |
| 文字动画器补填充（Fill Color / Fill Opacity） | ✅ 可添加 | 同上（可实现渐变/变色字） |
| **图层样式**（描边 frameFX / 外发光 / 内发光 / 斜面和浮雕 / 光泽 / 三种叠加） | ❌ **无法脚本启用** | `fr.enabled=true` → "canSetEnabled 为 false"；子属性全被隐藏 |
| 图层样式绕行：`.ffx` 动画预设 + `layer.applyPreset()` | ✅ applyPreset 存在 | probe_stroke_routes: applyPreset=FUNCTION；仓库暂无 .ffx（需产出预设资产） |
| 3D 文字层 / 摄像机 / 灯光 | ✅ | 手册 §八/§十五 已实证（camera push/orbit/Z 视差） |
| 高级 3D 渲染器（真实 3D 模型/环境光/阴影/反射） | ✅ 默认启用 | probe: comp.renderer="ADBE Advanced 3d"（设值无效=已是该模式） |
| **文字挤压/倒角**（几何选项：凸出深度/斜面样式/斜面深度） | ❌ 属性被隐藏 | setValue 报"属性或父级属性被隐藏"；受渲染器/上下文门控，待 UI 验证 |
| 材质参数（反射/高光/金属感/菲涅尔/折射） | ⚠️ 可读，写似同受门控 | probe_ls2: 17 项材质参数可枚举 |
| 假挤压替代（多层 Z 偏移堆叠） | ✅ 纯图层操作 | 无需新 API，风险最低 |

**结论**：描边可做成"体系"（多层叠加 + 脉动 + 色彩），三维层可做"摄像机三维空间"（已实证）；
**真实挤压/倒角与图层样式受 AE 脚本门控**，需要绕行方案（.ffx 预设 / 假挤压 / UI 一次性配置）。

## 二、推进波次

### W1 · 描边体系（1-2 天，低风险，直接扩展已验收成果）

| # | 任务 | 手段 | 验收 |
|---|------|------|------|
| W1-1 | 双描边"贴纸感" | 底层文字（略大）+ 粗描边深色，上层白字 + 细描边 → 双层轮廓 | 渲染帧 VLM：外描边/内描边可分辨 |
| W1-2 | 动画器补描边 | 静态选择器 + `ADBE Text Stroke Width/Color`（**必须先过字体真身验证**，因 RS 动画器有字体回退前科） | 渲染差分探针：字形=目标字体真身，非替换体 |
| W1-3 | 描边脉动 | strokeWidth 关键帧随 onset 能量（复用 energy 字段） | 帧序列：脉动可见、无跳变 |
| W1-4 | 对比度感知整合 | 亮底：外描边 14 + 内描边 4 + 青色光晕；暗底：外描边 6 + 白辉光 | 复用 v11 的 ΔYAVG 与光晕色指标 |

### W2 · 三维层基础（2-3 天，手册配方迁移）

| # | 任务 | 手段 | 验收 |
|---|------|------|------|
| W2-1 | 3D 文字层 + 摄像机推进 | 手册 §八 Camera Push In（threeDLayer + camera Z 关键帧） | 渲染帧：透视变化可见、文字不糊 |
| W2-2 | 摄像机环绕（sin 弧线） | 手册 §八 Camera Orbit | 运动平滑、无穿帮（文字不出画） |
| W2-3 | Z 轴纵深分层 | 主词 z=0 / 辅助元素 z=±200 → 视差 | 视差可见且幅度不夸张 |
| W2-4 | 与现有事件系统融合 | 仅 drop 区（能量最高的 12 事件）启用 3D；intro/outro 保持 2D | 720 帧渲染耗时 ≤ 3 分钟；门禁不回归 |

### W3 · 高级 3D 文字（3-5 天，需要解门控）

| # | 任务 | 手段 | 验收 |
|---|------|------|------|
| W3-1 | 解"几何选项被隐藏" | ① UI 确认高级 3D 设置下几何选项是否可编辑；② 尝试 .ffx 预设携带挤压；③ 尝试 `comp.renderer` 正确赋值序列 | 挤压深度可编程写入（探针记录） |
| W3-2 | 真实挤压 + 倒角 | W3-1 通则用真挤压；不通则**多层 Z 偏移假挤压**（8-12 层，间距 2px） | 渲染帧：立体厚度 + 倒角高光可见 |
| W3-3 | 材质 + 灯光 | 金属感/高光/环境光（手册 V4 Phase1 点光 + 高级 3D 环境光） | 光照方向一致、无明显塑料感 |
| W3-4 | 景深 | 摄像机 DOF（手册 V4 Phase2 已实证） | 前后景虚实分层可见 |
| W3-5 | 渲染预算 | 挤压+灯光+DOF 的 720 帧耗时 | 实测落盘；>10 分钟则限定仅主标题 4-6 事件用真 3D |

### W4 · 叙事化高级设计（1 周）

- 内容分级：主标题（intro/drop 首词）走 3D 挤压+光照；辅词走描边体系；避免全片同款（v4 疲劳教训）
- 3D 空间分层布局：前景字（z 近、模糊）/ 中景字（主）/ 背景字（z 远、低饱和）三层字幕空间
- 与 12 号库大师运镜技法联动（Donya 三维空间 / Xenoz 推拉）——文字随镜头运动同向/反向，强化纵深
- 节拍驱动：挤压深度/景深/描边宽度随 beat 强度脉动
- 沉淀为规则：进 ruleset.jsonl（沿用 R8 生命周期）

## 三、风险与纪律

1. **字体回退铁律**：任何新动画器/选择器上线前必须过"渲染差分探针"（同词不同字体应字形不同）；v6.1 事故证明 RS 动态选择器会静默替换字体。
2. **渲染耗时预算**：当前 720 帧 ≈ 1 分钟；W2 预计 2-3 分钟，W3 可能 10 分钟+ → 必须先测基线再全量启用。
3. **样式一致性与疲劳的平衡**：v4 教训（同款连打疲劳）——高级效果必须按内容分级、轮换变款。
4. **图层样式走 .ffx**：需一次性产出预设资产（可程序化生成 .ffx 或 UI 手工一次），入库后 `applyPreset` 复用，保证可复现。
5. **不要回退已验收项**：对比度感知样式（bg_class）、彩色光晕、字体分区轮换、HKLM 真 PS 名池、无 Bloom 单发光——全部保留为回归基线。
