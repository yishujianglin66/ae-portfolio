## 0. 核心问题拆解（根因级）

**运动镜头抠像的3大失败模式，与现有链路的对应缺口**：

| 失败模式 | 现象 | 根因（对应现有链路的哪块缺失） |
|---------|------|--------------------------------|
| **F1：传播崩溃** | 快速运动/遮挡时，mask面积从N%骤降到0%，整段人物丢失 | SAM2 video memory attention 跨大位移丢失目标；现有fallback触发阈值只有面积<30%，未对「运动强度」加权 |
| **F2：边缘抖动(沸腾)** | 逐帧看边缘位置左右跳；播放时像"水沸腾" | auto_frame逐帧独立、无帧间一致性约束；现有Tier2只做空间域（单帧）平滑，完全没做时间域（跨帧）平滑 |
| **F3：运动模糊区被抠掉** | 快速甩动的衣物/武器边缘，抠出来缺一块（半透明模糊被当背景） | 现有连通域清理+形态学Close/Open用的是固定阈值，对"高运动能量+低梯度=模糊区域"无区分 |

**为什么必须分层解决（而不是改一个参数）**：这3类失败模式，**根因分别在3个不同的抽象层**（检测层→分割层→后处理层），改单参数只能修其中一个，另外两个仍然会漏。

## 2. Layer 0：运动镜头自动检测分级（路由前置）

### 2.1 目标

输入一段视频（或段），输出逐帧标签 `motion_level ∈ {static, mid, fast}` 和运动标量 `motion_energy_per_frame[N]`（单位：像素/帧位移的中值）。

标签驱动后续Layer1分割策略路由 + Layer2时序强度 + Layer3自适应参数。

### 2.2 复用资产（全部现成，无需装新依赖）

| 资产 | 路径 | 用法 |
|------|------|------|
| OpenCV Farneback 光流（快速、CPU即可） | OpenCV `cv2.calcOpticalFlowFarneback`（`scripts/infer_segment_video_enhanced.py` 已 import cv2） | 计算每帧 pixel displacement → 中值 = motion_energy |
| RIFE warplayer 双线性warp（CUDA加速） | [external/rife/model/warplayer.py](file:///C:/Users/Administrator/Desktop/AE-Knowledge-Vault/external/rife/model/warplayer.py#L1-L22) `def warp(tenInput, tenFlow)` | Layer2A 做 mask warp；也可先拿 RIFE 输出的 flow 做 motion_energy（更准但慢） |
| FFmpeg minterpolate（已验证） | [unified_video_pipeline.py](file:///C:/Users/Administrator/Desktop/AE-Knowledge-Vault/integrations/unified_video_pipeline.py)（30→60fps补帧已验证） | 备选：光流通过FFmpeg输出帧间运动矢量 |

### 2.3 技术路线（推荐：Farneback，快+准）

```
视频段(500帧, 1920×1080)
  ├─ 1/4 缩放 → 480×270（光流计算在1/4分辨率够了，速度 ×4）
  ├─ cv2.calcOpticalFlowFarneback(prev_gray, curr_gray, flow=None,
  │      pyr_scale=0.5, levels=3, winsize=15, iterations=3,
  │      poly_n=5, poly_sigma=1.2, flags=0)  → flow.shape=(H, W, 2)
  ├─ magnitude = sqrt(flow[...,0]^2 + flow[...,1]^2) → (H, W)
  ├─ motion_energy[f] = np.median(magnitude) （像素位移中值，抗离群）
  └─ 3级阈值（可被QC回调校准）：
        < 5.0 → "static"
      5~20.0 → "mid"
       >20.0 → "fast"
```

**输出文件**：`{mask_dir}/motion_levels.json`
```json
{
  "source_video": "C:/.../DL_黑岩射手_r924_BV1NL4y1H7u7.mp4",
  "start_frame": 2000,
  "expected_frames": 500,
  "motion_energy": [1.2, 1.4, ..., 25.6, ...],        // length=500
  "motion_level":   ["static","static",...,"fast",...], // length=500
  "level_counts": {"static": 281, "mid": 173, "fast": 46},
  "window_sz_farneback": 15,
  "scale_factor": 0.25
}
```

## 4. Layer 2：时序稳定（★ 最大提升点、补项目明确缺口）

**整个方案中，这一层是"提升一个级别"的关键。** 项目里光流仅用于补帧，**未用于mask稳定**（代码资产全库扫描结论：mask稳定只有Silhouette文档层面，代码未落地）。

### 4A. 光流 warp 融合（P0 · 提升最大 · 半天实现量）

#### 4A.1 原理

```
帧 N-1 的 mask (uint8, 0~255)
       ├─ 帧 N-1 → N 的光流 flow_{N-1→N}  (Farneback 或 RIFE)
       └─ warplayer.warp(Mask_{N-1}, flow) → 预测的 帧N mask
                                                    ↓
帧 N 的 原生 mask (来自 Tier1 输出) ─────► 加权融合:
     Mask_N_stabilized = 0.60 * Mask_N_raw + 0.40 * Warp(Mask_{N-1})
```

**为什么能消除抖动**：`Warp(Mask_{N-1})` 对"帧N的边缘应该在哪里"提供了**强先验**。即使 SAM2 本帧检测偏了1-2个像素，上一帧的warp会把它"拉回"平滑轨迹。权重 0.6/0.4 保证不被旧帧过度拖影。

#### 4A.2 复用资产

| 资产 | 路径 | 用途 |
|------|------|------|
| RIFE warplayer（已import torch，与sam2 venv兼容） | [external/rife/model/warplayer.py::warp](file:///C:/Users/Administrator/Desktop/AE-Knowledge-Vault/external/rife/model/warplayer.py#L8-L22) | 做 mask warp（grid_sample双线性插值，CUDA） |
| Farneback flow（L0 已计算） | L0 输出 `motion_levels.json` 同级，新增 `flow_cache/{fi}.npy` | 每帧 flow 可缓存复用（L0+Layer2A 共享，不重复计算） |

#### 4A.3 代码入口 & 插入位置

**插入位置**：`infer_segment_video_enhanced.py` — Tier1 输出单帧mask之后、进入 `refine_mask_edge()` 之前（在 Tier2 之前做时序稳定，避免 Tier2 空间平滑把时序信息糊掉）

```
新函数位置: refine_mask_edge() 之前，新增 stabilize_temporal()
def stabilize_temporal(mask_raw_np, prev_mask_np, prev_flow_np_to_curr, level):
    if prev_mask_np is None:  # 段首帧
        return mask_raw_np
    # 1. Farneback flow (H,W,2) → torch [1,2,H,W]
    flow_t = torch.from_numpy(prev_flow_np_to_curr).permute(2,0,1).unsqueeze(0).float().cuda()
    prev_t = torch.from_numpy(prev_mask_np).unsqueeze(0).unsqueeze(0).float().cuda()  # [1,1,H,W]
    warped_prev = warp(prev_t, flow_t).squeeze().cpu().numpy().astype(np.uint8)
    # 2. 按 level 调权重：static 更偏时序平滑，fast 更偏本帧
    WEIGHTS = {"static": (0.5, 0.5), "mid": (0.6, 0.4), "fast": (0.75, 0.25)}
    w_raw, w_prev = WEIGHTS[level]
    return np.clip(w_raw * mask_raw_np + w_prev * warped_prev, 0, 255).astype(np.uint8)
```

### 4B. Savitzky-Golay 时域滤波（P3 · 锦上添花 · 1天实现量）

### 4C. 运动模糊区自适应扩张（P3 · 极端运动修正 · 1天实现量）

#### 4C.1 原理

快速运动中，人物边缘是**半透明运动模糊**。现有 SAM2 把模糊部分当背景（像素值介于前景色和背景色之间，特征不强），导致 mask 比真实人物小一圈。

**解决**：识别「运动模糊区域 = 高motion_energy × 低图像梯度」，在这些区域把 mask **扩张 2-3 像素**（而不是收缩）。

```
运动模糊区 mask:
  blur_region = (motion_energy[f] > 15.0)   # 高运动能量
              & (gradient_magnitude < 15)    # 低图像梯度（模糊=无细节）
  mask_final = mask | dilate(mask & blur_region, kernel=ellipse(5×5), iter=1)
```
