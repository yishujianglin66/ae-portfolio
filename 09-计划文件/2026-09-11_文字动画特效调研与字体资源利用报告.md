## 〇、结论摘要（先看这五条）

1. **字体资源可大范围进 AE，但要分级**：用户目录 3476 文件 / 3479 face；49 个与系统重名；
   **68 个带 trial/demo/personal 授权标记（交付禁用）**；≈3430 个可新增安装；已实测"系统级安装后
   AE 可解析"27/27 `已实证`。结论：**建注册表 + 分级白名单 + 逐批渲染差分验证**，不做无脑全装。
2. **学术侧给出了两套可直接用的分类学**：
   - **艺术排版双轴**（2407.14774）：`艺术化样式`（阴影/描边/颜色/发光/纹理）vs `语义排版`（字形变形传达语义）。
     我们目前 100% 落在第一轴，第二轴为零。
   - **逐字效应族**（2407.10476，基于 **584 个专业模板**）：位置/字形/大小的逐字变化，
     明列效应族 **flying / glitches / chromatic aberration / reflecting**，并提出三条验收要求：
     **审美、动效、可读性**。
3. **最可迁移的论文机制是"动作迁移"**（2308.00224）：把参考 GIF 刚体运动的**关键点轨迹**经**局部仿射变换**
   映射到文字控制点，并优化时序以**保持文字拓扑**。→ 我们可用**镜头运动/节拍数据**驱动文字位移，
   做"文字随镜头运动"的高级感，且完全可脚本实现。
4. **"情绪 → 动画"有两个全局旋钮**（2306.07560）：**随机性(entropy) + 速度(speed)**，
   用一个预设动画方案 + 两个标量微调情绪强度。→ 直接对应我们"变款过多/过少"的调参困局，
   可把"变款选择"改成"选情绪族 + 两个旋钮"。
5. **工程侧三条硬规则与一个许可雷区**：`menus-not-defaults + 不重复`（bang-motion）、
   **确定性时间线（每帧是时间的纯函数）**（bang-motion / HyperFrames）、`house-style.md` 风格契约（AE-MCP）；
   **pv-tool 已改 Non-Commercial，只能借鉴概念不可复制代码**。

| 约束 | 强度 | 解法 |

### 1.3 落地（今天可做）

`font_registry.json` 字段建议：`ps_name, file, location, license, license_risk, cov_jp, cov_cn, cov_latin,
pool_role, verified_by, verified_at`。理由：本会话反复证明 **PS 名存在 ≠ 可解析 ≠ 有字形 ≠ 可商用**，
四维必须分开记。

## 四、缺口清单与四条可落地路径（按性价比排序）

### 4.1 缺口（对标 §二/§三 合成）

| 缺口 | 外部依据 | 可行性 |
|---|---|---|
| **mask/clip 揭示** | iart skill："最 robust / industry-standard" | **高**：图层遮罩+关键帧，**不碰文字动画器 → 字体安全** |
| **文字布局族**（散落/条/卡/竖排/文字雨） | pv-tool Text 类 | **高**：多文字层+编排，复用现有事件表 |
| **后处理族**（glitch 条/扫描线/颗粒/半调/hue） | pv-tool Overlay 类 | **中高**：需先探针（Turbulent/Tint/FindEdges 已证可用） |
| **逐字形变形/反射效果** | 2407.10476 | **低**：AE 无逐字形位移 API；可用"文字转形状层"人工步骤兜底 `待验证` |
| **随镜头运动的文字** | 2308.00224 | **高**：用 EDL/节拍数据生成位移关键帧（见 4.2） |
| **情绪化调参** | 2306.07560 | **高**：纯策略层（见 4.3） |

### 4.2 动作迁移（Wakey-Wakey 思路的本项目化）

论文做法 `论文理论`：关键点轨迹 → 局部仿射 → 拓扑保持。
**我们的确定化实现**（`待验证`，可先小样本）：
- 输入：EDL 已知的**镜头运动量**（推/拉/横移）与**节拍强度**（`true_onsets` / `music_envelope`）；
- 映射：把"镜头运动矢量"按**同一仿射**应用到文字位移/缩放/旋转（文字与画面同向运动 → 强化纵深）；
- 拓扑保护：限制位移幅度与旋转角（我们已有"越框/倾斜"负结果教训）；
- 验收：位移幅度上限门禁 + 无事件帧零污染 + 目视可读。

### 4.3 情绪两旋钮（Emordle 思路的本项目化）

把"变款轮换"升级为 **`mood/energy → 动画族` + `entropy/speed` 两旋钮**：
- 动画族：`impact`（punch/radial/glitch）｜`elegant`（mask 揭示/blur-in）｜`kinetic`（elastic/逐字替代方案）；
- `entropy`：族内变款随机度（0=同款到底，1=每词换款）——用**确定性 PRNG + 固定 seed**（对齐 bang-motion 的确定性要求）；
- `speed`：入场时长/衰减常数统一缩放；
- 验收：同族不同词无重复（可脚本断言）+ 全片变款分布统计。

### 4.4 mask 揭示替代被禁用的逐字技法

逐字技法（RS 动画器）因**字体被静默替换**已禁用（本会话 `已实证` 负结果）。
mask/clip 揭示是**层级实现**，天然字体安全，且外部评价为"最稳"：
- 行级上升揭示（`translateY` 等价：位置关键帧 + 遮罩/裁剪）；
- 方向擦除（线性擦除/遮罩路径关键帧）；
- 与现有"对比度感知样式"叠加即得高级标题感。

## 五、与本项目数据契约的关系（本地事实，供集成方引用）

- `schemas/visual_effect_schema.json`：`effect_type` 枚举为**视频特效**
  （twixtor / zoom_pan / bloom / sapphire_glow / optical_flares / bokeh / badtv …），**无文字特效类型**；
  已含按类型分参数定义的范式（如 `SapphireGlowParams` 的 glow_amount/size/color）；
- `scripts/build_master_polish.py` 已有 **`schema_effects_to_plan()`** —— **schema→plan→注入** 通路；
- 文字线自成一套：`scripts/build_text_overlay.py` → `text_overlay/events.json` → JSX 注入。
- **接口建议（最小改动）**：新增 `text_overlay` effect_type，参数对齐 events.json 的
  `word/font/size/bg_class/glow/stroke/shadow/enter/…`；这样文字线即可复用既有校验与版本机制。
  （是否采用由管线/Schema 并行调研定案，此处只记事实与接口形态。）
