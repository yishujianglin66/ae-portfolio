# FATE 抠像验收 — 最终定稿报告（v14，用户已接受）

> 素材：`data/real_amv_test/DL_FATE_r978_BV1qb411C79B_p1.mp4`（392 帧 / 1280×720 / 24fps）
> 定稿预览：`output/one_pipeline/FATE_matanyone验证/FATE_Owlv2锚定_橙底预览_v14.mp4`
> 交付 MOV：同目录 `DL_DL_FATE_r978_BV1qb411C79B_p1_alpha.mov`（qtrle argb，AE 直接用）

## 最终链路（v14）

```
MatAnyone 512 分段独立抠像（48帧/段，CVPR 2025）
  └─ 三级锚定链：YOLOv8x → Owlv2 开放词汇("anime character"/"person")
                → SAM2 全图自动分割（16点/边 IoU≥0.7）
  └─ 锚定面积约束 [1%,40%] + 滑帧找好锚点
→ alpha 曲线增强（半透明→实心）
→ guided filter 边缘精修（贴合动漫线条）
→ 光流 warp 空洞填充
→ BiRefNet 缺失帧补抠（最大连通域裁剪 + 面积约束）
→ MED5 时域平滑
→ MOV 合成 + QC + 橙底预览
```
