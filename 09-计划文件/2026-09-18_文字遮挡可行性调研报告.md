# 文字遮挡（文字从人物后面穿过）可行性调研报告

**日期**：2026-09-18
**动机**：文字线四轮审美迭代后确认"高级感"最缺的一块是**文字与画面的融合**——
其中最有效单项是**文字被前景人物遮挡**。本报告按"完美调研、闭环后再执行"的要求，
完成选型比对与本机实证，给出 go/no-go 与执行计划。

## 二、网络根因与解法（重要，普适）

**症状**：代理退出后"全网不可达"（连 modelscope/清华源都失败），但 ping/TCP 直连全通。

**根因**：本机开过代理（注册表 `ProxyServer=127.0.0.1:7897`）。代理进程退出后
`ProxyEnable` 仍=1 → Python urllib 按系统代理把所有请求塞进**死端口**。

**解法**：`urllib.request.ProxyHandler({})` 显式空代理=直连，不读注册表。
实测直连可达：`dl.fbaipublicfiles.com`（SAM2 官方 CDN）、GitHub（codeload/raw/clone）、
`hf-mirror.com`、`modelscope.cn`。**SAM2 权重根本不需要代理。**

**git clone 会中途断**（`early EOF`，网络 0.3MB/s 且不稳）→ 改用 **codeload tarball + Range 断点续传**（实测 53MB/114s 成功）。

### SAM 2.1 tiny 在我们素材上的实证（三轮，全部落空）

对 3 帧真实成片帧（8.5s 清晰人物 / 25.5s 火焰场景 / 14.5s 特效场景）：

| 策略 | 覆盖率（3 帧） | score | 目视判读 |
|---|---|---|---|
| 自动方框（中央 60%） | 10.9%/17.0%/18.8% | 0.62–0.79 | **圈到背景/火焰，未贴角色** |
| 单正点（画面中部） | 1.7%/1.1%/5.7% | 0.77–0.92 | 抓到点附近**局部碎片** |
| 多正点+负点（手工选点） | 61.7%/3.4%/5.9% | **0.13**/0.67/0.57 | 最好一帧**过分割糊进背景**，其余仍碎片 |

**结论**：SAM 2.1 tiny 对本片素材（动漫线稿 + 重度模糊/特效 + 高饱和）**不能可靠产出可用的角色 mask**。与"SAM 2 训练于自然视频"的已知限制一致；我们的素材又特别难（细节在剪辑阶段已损失 10 倍，见前一附录）。

## 五、Go / No-Go 与执行计划

**总判定：基建 ✅ / 当前选型质量 ❌ —— 暂缓执行，先换选型。**

执行计划（按序，每步有验收口径）：

| # | 步骤 | 验收 | 预估 |
|---|---|---|---|
| 0 | AE track matte API 探针 | 属性真值可读写 | 10 分钟 |
| 1 | **找到 ISNet 正确下载源**（hf-mirror 正确 repo id / modelscope / GitHub release） | 模型文件落盘 | 30 分钟 |
| 2 | ISNet 单帧质量实证（同一组 3 帧） | 角色 mask 覆盖主体 ≥70%、误伤背景 ≤20% | 20 分钟 |
| 3 | 若 ② 过 → ISNet 首帧 mask 作为 SAM2 的 **mask prompt** 做视频传播（解决时序闪烁） | 连续 30 帧 mask 闪烁可见度低 | 1–2 小时 |
| 4 | 事件窗内全链路：分割 → PNG 序列 → AE 遮罩 → 渲染 | 1:1 目视：文字确实被人物挡住 | 半天 |
| 5 | 若 ② 不过 → 试 SAM 2.1 base+（下载 322MB，同法），仍不过则**关闭此方向**，转"文字与画面融合"的其他手段（Screen/Overlay 混合模式已实证可脚本设置） | — | — |

## 六、结论

1. **基建全部闭环**：GPU/依赖/下载通道/推理/导出全通，且发现并解决了"系统代理残留导致全网假性不可达"这个会反复坑人的环境问题。
2. **质量不闭环**：SAM 2.1 tiny 三种提示策略在我们的素材上全部失败——这是有数据的否定结论，不是猜测。
3. **下一步的最短路径**是拿到动漫专用的 ISNet（ Apache-2.0，专为动漫角色训练），它若单帧质量过关，再与 SAM2 的视频传播组合解决时序。
