## 二、关键新发现：本机已有真实 AE MCP，且是"竞争者"而非"替代者"

### 2.1 实况

`C:/Users/Administrator/Desktop/after-effects-mcp-main/`（v1.0.0，社区项目）：

- 工具面：`create-composition` / `run-script` / `get-results` / `setLayerKeyframe` / `setLayerExpression` / `setLayerProperties` / `batchSetLayerProperties` / `getLayerInfo` / `createCamera` / `createNullObject` / `duplicateLayer` / `deleteLayer` / `setLayerMask`（13 个）
- 通信：**文件桥**（与项目 Protocol A 的轮询机制同类）
- 附带高质量 AE 创作知识体系（5000 预设索引、动画十二法则、Particular 有机粒子黄金参数）——项目 `01-项目概览/after-effects-mcp-CLAUDE.md` 已全文收录

### 2.2 对本项目的正确关系

| 原计划主张 | 实况修正 |
|-----------|---------|
| "用 adobe-mcp **替换**现有 Bridge" | 二者同构（都是 ExtendScript 执行通道），无能力增量，**替换论不成立** |
| 未提及的风险 | TASK_STATUS P0-C 已备案：其 node 进程曾被列为**干扰源**（与 Protocol A 抢占 AE 脚本引擎） |
| 正确姿势 | 作为**工具层互备**观察项：若其 `setLayerKeyframe/Expression` 细粒度工具有借鉴价值，以**知识蒸馏**方式吸收进项目桥（沿用"接入即蒸馏"铁律），而非引入第二套常驻通道 |

## 三、真缺口确认：AE 2026 新特性（原计划 §2.2 方向正确、依据需换）

### 3.1 特性核实（均为真）

| 特性 | 内容 | 对本项目的价值 |
|------|------|---------------|
| **原生 Unmult** | 32bit 硬件加速，一键去纯黑/纯白底，保留烟/火/透明细节 | 替代抠像链的第三方依赖路径；素材预处理（去黑底叠层）零成本化 |
| **Substance 3D 材质** | PBR 材质直接应用于 3D 图层/模型 | 3D 空间拉镜（Donya 流派）的质感升级路径 |
| **3D 参数化网格/原生创建** | 原生 3D 形状创建，减少 C4D 往返 | 木偶/静止系 2.5D 管线的轻量 3D 元素 |

### 3.2 项目知识库现状

`10-风格化剪辑知识库/AE2026版本适配脚本与新功能.md`（4.9KB）已覆盖：新特性概览、脚本适配、Null Controller、一拳超人效果、MCP Bridge 路径。
**未覆盖**：Unmult、Substance、原生 3D 创建（grep 零命中）。

### 3.3 修正后的任务定义（替换原 §2.2）

1. **Unmult 素材预处理脚本**：`layer.applyEffect` 挂 Unmult → 验证：黑底叠层素材（烟/火/光斑）抠像质量 vs 现有 BiRefNet 链的 IoU 对比 + 耗时对比（预期：规则底色场景 Unmult 秒级完胜，复杂边缘仍走 BiRefNet——分流而非替换）
2. **Substance/3D 调研笔记**：先核实 ExtendScript 暴露的 API 面（`applyEffect` 能否带参数配置 PBR 路径），写入 AE2026 知识库
3. **验收线**：脚本进测试套件；知识库条目落盘；不设"减少 C4D 依赖 50%"这类无基线的口号指标
