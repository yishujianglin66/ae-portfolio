## 七、MCP 端 applyPreset 调用规范

### 7.1 applyPreset 命令格式

通过 MCP 桥向 AE 发送的 JSON 命令格式:

```json
{
  "command": "applyPreset",
  "params": {
    "layerName": "{{targetLayerName}}",
    "presetPath": "C:\\Program Files\\Adobe\\Adobe After Effects 2026\\Support Files\\Presets\\Text\\Animate In\\Typewriter.ffx"
  }
}
```

### 7.2 applyPreset IIFE 自动化模板(MCP 兼容)

```jsx
(function(){var _r={};try{
var c=app.project.activeItem;
if(!c||!(c instanceof CompItem)){
_r={status:'error',
  message:'No active comp'};
return JSON.stringify(_r);}
var n='{{layerName}}';var L=null;
for(var i=1;i<=c.numLayers;i++){
if(c.layer(i).name==n){L=c.layer(i);break;}}
if(!L){
_r={status:'error',
  message:'Layer not found'};
return JSON.stringify(_r);}
var p='{{presetPath}}';
app.beginUndoGroup('Apply Preset');
L.applyPreset(new File(p));
app.endUndoGroup();
_r={status:'success',layer:n,
  preset:p.split('\\').pop()};
}catch(e){
_r={status:'error',message:e.toString()};
}
return JSON.stringify(_r);})();
```

**占位符说明**:
- `{{layerName}}` — 字符串,目标图层名
- `{{presetPath}}` — 字符串,FFX 文件完整路径(反斜杠需转义为 `\\`)

### 7.3 批量应用预设 IIFE 模板

一次向多个图层应用同一预设(常用于批量套用调色或转场):

```jsx
(function(){var _r={};try{
var c=app.project.activeItem;
if(!c||!(c instanceof CompItem)){
_r={status:'error',
  message:'No active comp'};
return JSON.stringify(_r);}
var names='{{layerNames}}'.split('|');
var p='{{presetPath}}';
var ok=[];var miss=[];
app.beginUndoGroup('Batch Apply');
for(var j=0;j<names.length;j++){
var nm=names[j];var L=null;
for(var i=1;i<=c.numLayers;i++){
if(c.layer(i).name==nm){L=c.layer(i);break;}}
if(L){L.applyPreset(new File(p));
ok.push(nm);}else{miss.push(nm);}}
app.endUndoGroup();
_r={status:'success',applied:ok,
  missing:miss,count:ok.length};
}catch(e){
_r={status:'error',message:e.toString()};
}
return JSON.stringify(_r);})();
```

**占位符说明**:
- `{{layerNames}}` — 管道分隔的图层名,例如 `标题1|标题2|标题3`
- `{{presetPath}}` — FFX 文件完整路径

### 7.5 按名称模糊查找 FFX IIFE 模板

在指定根目录下递归查找匹配关键字的 FFX:

```jsx
(function(){var _r={};try{
var root='{{rootPath}}';
var kw='{{keyword}}'.toLowerCase();
var rootFolder=new Folder(root);
if(!rootFolder.exists){
_r={status:'error',
  message:'Root not found'};
return JSON.stringify(_r);}
var hits=[];
function scan(folder){
var items=folder.getFiles();
for(var i=0;i<items.length;i++){
var it=items[i];
if(it instanceof Folder){scan(it);}
else if(it.name.toLowerCase().
indexOf(kw)>=0&&
it.name.toLowerCase().
indexOf('.ffx')>=0){
hits.push(it.fsName);}}}
scan(rootFolder);
_r={status:'success',
  keyword:kw,
  count:hits.length,
  files:hits};
}catch(e){
_r={status:'error',message:e.toString()};
}
return JSON.stringify(_r);})();
```

**占位符说明**:
- `{{rootPath}}` — 搜索根目录
- `{{keyword}}` — 文件名关键字(不区分大小写)

## 九、预设与 .ffx 解析参考

### 9.1 .ffx 文件本质

每个 `.ffx` 文件本质是 XML 文本,记录一个或多个效果插件的参数快照,可包含关键帧与表达式。可通过文本编辑器直接查看其内部参数结构。

### 9.2 .ffx 基本结构

```xml
<?xml version="1.0" encoding="UTF-8"?>
<AfterEffectsResource>
  <PresetData>
    <Effect matchName="ADBE ...">
      <Param id="1"><Value>...</Value></Param>
      <Param id="2"><Value>...</Value></Param>
    </Effect>
  </PresetData>
</AfterEffectsResource>
```

### 9.3 通过脚本读取 .ffx 元数据 IIFE 模板

不应用预设,仅读取其 XML 内容用于分析:

```jsx
(function(){var _r={};try{
var p='{{presetPath}}';
var f=new File(p);
if(!f.exists){
_r={status:'error',
  message:'File not found'};
return JSON.stringify(_r);}
f.encoding='UTF-8';
f.open('r');
var content=f.read();
f.close();
_r={status:'success',
  path:p,
  size:content.length,
  head:content.substring(0,500)};
}catch(e){
_r={status:'error',message:e.toString()};
}
return JSON.stringify(_r);})();
```

**占位符说明**:
- `{{presetPath}}` — FFX 文件完整路径

完整的 .ffx 参数解析、表达式提取、关键帧逆向工程等内容,参考:
