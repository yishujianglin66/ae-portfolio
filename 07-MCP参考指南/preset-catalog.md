## 🤖 MCP 端自动化预设系统

### MCP 自动化预设调用入口

本仓库提供两种 MCP 端预设调用方式,无需手动运行脚本:

#### 方式 1:executeAtomScript 直接执行 JSX 字符串
通过 MCP 网关的 `executeAtomScript` 命令,直接执行 IIFE 包装的 JSX 字符串。预设参数通过 `{{param_name}}` 占位符由网关运行时替换。

**调用示例**:
```json
{
  "command": "executeAtomScript",
  "params": {
    "scriptContent": "(function(){var _r={};try{var c=app.project.activeItem;if(!c||!(c instanceof CompItem)){_r={status:'error',message:'No active comp'};return JSON.stringify(_r);}var n='{{textLayerName}}';var L=null;for(var i=1;i<=c.numLayers;i++){if(c.layer(i).name==n){L=c.layer(i);break;}}if(!L||!(L instanceof TextLayer)){_r={status:'error',message:'Text layer not found'};return JSON.stringify(_r);}var tp=L.property('ADBE Text Properties');var a=tp.property('ADBE Text Animators').addProperty('ADBE Text Animator');a.name='KT_Waterfall';a.addProperty('ADBE Text Opacity').setValue(0);a.addProperty('ADBE Text Position').setValue([0,80]);var s=a.property('ADBE Text Selectors').property(1);s.property('ADBE Text Selector Offset').setValueAtTime(0,-100);s.property('ADBE Text Selector Offset').setValueAtTime({{duration}},100);_r={status:'success',preset:'kt_char_waterfall',layer:n};}catch(e){_r={status:'error',message:e.toString()};}return JSON.stringify(_r);})();"
  }
}
```

**期望响应**:
```json
{"status":"success","preset":"kt_char_waterfall","layer":"标题文字"}
```

#### 方式 2:applyPreset 加载本地 .ffx 文件
通过 `applyPreset` 命令,加载 AE 系统预设或用户下载的 .ffx 文件。

**调用示例**:
```json
{
  "command": "applyPreset",
  "params": {
    "layerName": "标题文字",
    "presetPath": "C:\\Program Files\\Adobe\\Adobe After Effects 2026\\Support Files\\Presets\\Text\\Animate In\\Typewriter.ffx"
  }
}
```

**期望响应**:
```json
{"status":"success","layer":"标题文字","preset":"Typewriter.ffx"}
```

### MCP 端调用 3 步工作流

1. **查询预设**:从 `config/text_animation_presets.json` 中按预设 ID 查询,读取 `jsx_template` 字符串
2. **替换占位符**:用实际参数值替换 `{{param_name}}`(字符串用单引号包裹,数字直接写入,颜色数组用 `[r,g,b]` 浮点格式)
3. **执行命令**:通过 `executeAtomScript` 命令发送给 AE 端,AE 执行后返回 JSON 结果

### 占位符替换规则

| 参数类型 | 占位符示例 | 替换结果 | 说明 |
|---------|----------|---------|------|
| 字符串 | `'{{textLayerName}}'` | `'标题文字'` | 用单引号包裹 |
| 数字 | `{{duration}}` | `1.2` | 直接写入 |
| 颜色数组 | `[{{fillColorR}},{{fillColorG}},{{fillColorB}}]` | `[1,0.5,0.2]` | 浮点 0-1 |
| 整数 | `{{overshoot}}` | `130` | 直接写入 |
