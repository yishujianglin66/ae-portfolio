## 四、素材管理

### 4.1 文件组织

```
素材目录结构:
├── 01_Footage (实拍素材)
│   ├── 01_Video (视频)
│   ├── 02_Audio (音频)
│   └── 03_Image (图片)
├── 02_Elements (特效元素)
│   ├── 01_Overlay (覆盖)
│   ├── 02_Particle (粒子)
│   └── 03_Light (光效)
├── 03_Graphics (图形)
│   ├── 01_Logo (Logo)
│   ├── 02_Icon (图标)
│   └── 03_Texture (纹理)
└── 04_Archive (归档)
```

### 4.2 命名规范

```
命名规范:
- 项目名_类型_描述_版本
- 示例:
  - Project01_Footage_Interview_v01
  - Project01_Music_BGM_Happy_v01
  - Project01_SFX_Explosion_v01

避免:
- 使用中文(可能编码问题)
- 使用特殊字符
- 过长文件名
- 无意义命名
```

## 五、版权管理

### 5.1 版权类型

| 类型 | 说明 | 使用 |
|------|------|------|
| 公共领域 | 无版权 | 自由使用 |
| CC0 | 放弃版权 | 自由使用 |
| CC-BY | 署名 | 需署名 |
| CC-BY-SA | 署名-相同方式 | 需署名+相同授权 |
| CC-BY-NC | 署名-非商业 | 非商业使用 |
| 商业授权 | 付费授权 | 按授权范围 |

### 5.2 版权检查

```
版权检查清单:
- [ ] 确认版权类型

- [ ] 确认是否可商用

```
