# Round 19 — 素材重复 + 音频杂音 修复 (用户验收反馈)

> 日期: 2026-08-15 | 分支: feat/project-consolidation-v1

用户反馈: "卡点踩节拍非常准确、鼓点对应剪辑技巧应用合理 → 已达验收级别",
但 (1) 素材很多地方重复; (2) 音频有杂乱杂音、听感不好。

## 问题定位

### 1. 素材重复 (v6 实测)

| 素材 | v6 使用次数 | 原因 |
|---|---|---|
| 独自升级5.mp4 | **101x (44%)** | 爆发段池坍缩 |
| 独自升级2.mp4 | 39x | 蓄力段轮转 |
| 猫1 / 初音 | 40x / 37x | 蓄力段轮转 |
| 猫2 / alya / 五条悟 | 各 4x | 几乎未用 |

根因: `_pick_by_narrative_role` 用"主导 scene 标签"门控素材 → 爆发段池
= {battle 主导} = 仅独自升级5 一个素材 (独自升级2 battle 窗口 44% 被
closeup 主导标签遮蔽, 五条悟 indoor 主导)。101 个爆发镜全取同一素材,
近重复窗口 81 对 → 视觉疲劳。

### 2. 音频杂音

体检脚本 `scripts/audio_health_check.py` (每1s RMS/峰值/频谱平坦度):

- BGM 峰值 0 dB 砖墙削波 (17/20/22/25s 等 0~+0.5dBFS 采样间过载);
- **尾部 163.0-168.5s 为 5.5s 数字静音** → 成片尾段 5.5s 无声死气;
- 管线音频 = BGM 纯拷贝 (无任何合成音效) → 杂音 = 削波过载 +
  mp3→AAC 重编码恶化的采样间削波。

## 修复 (25193a9)

1. **素材均衡轮转** `_balanced_pick`: 池内最少使用优先 + 平手 seg_idx 错开;
   角色匹配放宽: 主导命中 OR 偏好场景窗口 ≥20% 均入选
   (爆发段池 1 素材 → 3 素材);
2. **窗口间距收紧**: 已用窗口邻域排斥 0.3-1.0s → 1.5-2.5s (素材内部取点
   更分散, 视觉重复进一步降低);
3. **尾部静音裁剪** `_music_effective_end`: silencedetect 检测尾部静音 →
   成片时长 168.5s → 164.2s (音乐结束即收片);
4. **音频削波余量**: 混音 volume=0.98 (-0.2dB) 防止 AAC 重编码采样间削波。

## 验证

- 快测: 尾部静音 164.2s 检出 ✅; 均衡轮转 12 次 = 4/4/4 完全平均 ✅;
- 回归: 52 项导演相关测试全过 ✅;
- v7 渲染中 (`v23_final_full_v7.mp4`), 渲染后审计素材分布 + 时长 + 评估。
