## 二、粒子质感迭代全记录（本轮核心）

| 迭代 | 效果 | 画面占比 | 关键动作 |
|---|---|---|---|
| v1 | 白色小点 | 0.5-1.3% | Particular 默认渲染 |
| v2 | 金色贴图 | 2.7-2.9% | 贴图染色（修正 RGB 顺序坑） |
| v3 | + 光晕 | 金 3.0+光 2.5% | 外部 Glow |
| v4 | 更大更亮 | 3.6-3.8% | 尺寸 22px + Glow 4.0 |
| v5 | + 拖尾 | 同 v4 | 条纹→Echo 残影（真机探测参数） |
| **v6** | **全屏爆发** | **10.1%** | **发射器 700×10→1920×1080（根治看不见的根因）** |

**关键洞察**：连续几轮"不够"的根因不是参数不够猛，而是 **spark 发射器是底部窄条**——粒子只从画面底部一小条喷出，全屏素材上天然不可见。改为全屏发射器后占比 3.8%→10.1%（近 3 倍），肉眼必见。

**过程中真机排掉的坑**：
- AE 精灵默认白染 → 原生 Tint 染色
- **Tint 颜色是 RGB 顺序**（第一版按 BGR 写成蓝黑）→ 修正后金色验证通过
- 小条纹拖尾盲设无效 → 改 Echo 残影（参数全探明：时间/数量/强度/衰减）
- JSX 中文路径转义 → ASCII 临时路径 + jsx 文件通道绕开
