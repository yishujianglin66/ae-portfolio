# 2026-08-14 推进报告（第 14 轮）—— 用户反馈修正：编排感与效果分配

> 用户反馈: "每个镜头都是晃动、推拉、闪回，应该有自己的判断和编排剧本，
> 那只是那一个段落适合这个效果，为什么要应用到每一个镜头"。
> 本轮核心: 把"全片均匀撒效果"改为"剧本驱动、按段分配、留呼吸"。

## 一、反馈根因分析

1. **每个镜头都运镜**：风格卡 forbidden 无 static + 决策层无"呼吸镜头"
   概念 → 229 段全部被塞推拉摇移（实测 static=0%）。
2. **闪回泛滥**：drop 段默认 flash + build 段每 6 镜一次 flash →
   165s 成片 flash 17 次（每 9.7s 一次），冲击符号失效。
3. **编排剧本未驱动效果分配**：转场/运镜按 mood 均匀分配，而非按
   叙事角色+节拍强弱集中分配。

## 二、修复实施 ✅

### 1. 运镜稀疏化（T4.5 层）
- **规则**: 运镜落强拍/下拍；弱拍镜头按确定性伪随机分布保持固定
  （build 30% / drop 20% / intro/outro 50% 呼吸率）。
- **实测**: static 呼吸镜头 **0% → 19%**（43/229），运镜分布
  8 类均衡（pan 26-28 / zoom 26-27 / orbit 26 / push 28 / static 43）。

### 2. 闪白门控
- drop 默认转场 flash → **cut**；闪白只在强拍/下拍触发；
  非 hard_stop 的 flash **≥20s 间距**。
- **实测**: 165s 成片 flash **17 → 5**（每 33s 一次），转场
  fade 42 / cut 182 / flash 5。

### 3. 渲染截断 bug 修复（组间拼接流拷贝）
- **根因**: 最终 229 组拼接用 libx264 preset slow **重编码整片**，
  600s 超时（机器负载高时）→ 回退首片段 → v2 成片 13.5s 截断。
- **修复**: 优先 `-c:v copy` 流拷贝（同参数片段秒级拼接），
  失败回退重编码（1800s）。
- **实测**: v3 完整成品 **164.9s** 渲染成功（1223MB 高码率全保真）。
