## 三、总体愿景与 KPI（v2.1 升级）

### 3.1 愿景

构建一条"**输入原始素材 → 一键产出成品视频**"的全自动流水线：

```
素材入库 → PS 预处理 → 视频分析 → 风格决策 → 参数映射 → JSX 生成
   → AE 渲染（含 BorisFX 插件）→ DaVinci 调色 → PR 自动剪辑
   → [可选] Topaz AI 增强 → [可选] Silhouette 抠像 → [可选] Blender/C4D 3D 元素
   → FFmpeg 拼接输出（替代 AME）
```

- 全程无人值守，仅最终审核由人工把关
- PS 跟 PR 桌面已安装，**必须真正调用、真正产出**（不只是生成 jsx 文件让用户手动执行）
- **9 引擎全部真实可用**，无需"自动降级"假象
- **用户明确排除 AME**，输出环节由 FFmpeg 主导（PR 不依赖 app.encoder）

## 八、智能体编排层（v2.0 基于 LLM 网关）

### 8.1 5 个智能体

| 智能体 | 职责 | 输入 | 输出 | 模型路由 |
|--------|------|------|------|----------|
| 风格分析 Agent | 综合 视频/音频/参考 → 风格标签 + 参数空间 | features.json, music_bpm, references | style_label, param_space | TIER_2_MIDTIER (PRO) |
| 代码生成 Agent | 根据 参数空间 → JSX 代码 | param_space, template | jsx_code | TIER_3_FLAGSHIP (THINKING) + 垂直小模型 |
| 调色 Agent | 根据 风格 → LUT + DaVinci 节点 | style_label, reference_image | lut.cube, davinci_nodes | TIER_2_MIDTIER (PRO) |
| 质量审核 Agent | 审核 每个节点产物 → 通过/打回 | node_output, expected_schema | verdict, issues | TIER_2_MIDTIER (VISION) |
| 安全审计 Agent | 扫描 所有 JSX/Shell/路径 → 阻断危险 | jsx_code, cmd, path | verdict, blocked_patterns | TIER_1_LOCAL (FLASH) |

### 8.2 协作模式

#### 串行模式（主链路）
```
风格 Agent → 代码 Agent → 调色 Agent → (后续节点)
```

#### 并行模式（PS 预处理与视频分析）
```
material_ingest ──┬─> PS Agent
                  └─> Video Analysis Agent
```

#### 混合模式（质审+安全并行）
```
节点完成 ──┬─> 质审 Agent (异步)
          └─> 安全 Agent (异步，CRITICAL 级阻断)
```

### 8.3 仲裁机制

- 智能体决策冲突时，由方向机（Director）基于优先级裁决
- 优先级：安全 > 质审 > 调色 > 代码 > 风格
- CRITICAL 级安全问题立即阻断流水线
