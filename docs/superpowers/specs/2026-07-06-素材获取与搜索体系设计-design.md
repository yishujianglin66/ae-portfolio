# 素材获取与搜索体系设计

> 设计日期：2026-07-06
> 项目：AE-Knowledge-Vault 素材获取能力体系化建设
> 状态：待用户审查

## 一、背景与目标

### 1.1 背景
基于2026-07-06 BGM实战演练（提取抖音"思响的作品-世上无难事"BGM并导入AE），暴露现有素材获取体系的多项缺陷：
- importFootage MCP工具超时（Bridge返回"Unknown command"）
- download_video 文件检测逻辑错误（遍历整个目录）
- Cookie 路径配置不一致（config指向D盘，文件在桌面）
- search_online 仅YouTube有效（dysearch/bsearch/ksearch前缀yt-dlp不支持）
- generate_ae_script_from_analysis 引用未声明layer变量
- FFmpeg -ss 在 -i 之前导致seek不精确
- 两套并行实现（Python/Node.js）默认目录不一致

### 1.2 目标
构建**模块化、可扩展、原子级精度**的素材获取与搜索体系，使AE-Knowledge-Vault具备：
1. 抖音/B站/YouTube专业级下载能力（替换简陋的douyin-downloader.py）
2. 免费素材API集成（Pixabay/Pexels/Jamendo，按关键词搜索）
3. AI语义素材搜索（基于CLIP，"找段夕阳海滩视频"这类自然语言查询）
4. 完整实战演练经验库（实验报告、日志、训练产出）

### 1.3 硬约束
- 知识库**只存放知识/代码/脚本/配置**，不存放视频/音频等生产物料
- 生产物料存放在 `D:\AE-Work\` 下对应子目录
- 遵循现有 `config/media-config.json` 配置规范
- 所有模块通过 `--json-input` 协议统一调度
- 协议合规：GPL-3.0项目仅作为独立服务调用

### 3.2 子项目2：抖音/B站下载能力强化

#### 3.2.1 抖音专业下载器（`douyin_downloader_pro.py`）
- **整合思路**：参考TikTokDownloader（13.4k star）的Web API模式
- **核心功能**：
  - 短链接解析（重定向跟踪）
  - 无水印视频下载（直接获取video.play_addr.url_list）
  - 音频提取（FFmpeg分离音轨）
  - 视频元数据获取（标题/作者/时长/统计）
  - Cookie自动管理（验证+刷新）
- **技术栈**：httpx（异步HTTP）+ FFmpeg（音频提取）
- **接口**：`--json-input` 协议，支持download_video/download_bgm/get_info/parse_url

#### 3.2.2 B站下载器（`bilibili_downloader.py`）
- **整合思路**：基于bilix（Apache-2.0，异步高并发）
- **核心功能**：
  - 视频下载（支持画质选择）
  - 音频提取（单独下载音频流）
  - 番剧/电视剧下载
  - 收藏夹批量下载
- **技术栈**：bilix（`pip install bilix`）
- **接口**：`--json-input` 协议

#### 3.2.3 YouTube下载器（`youtube_downloader.py`）
- **整合思路**：基于yt-dlp（100k star，社区标准）
- **核心功能**：
  - 视频下载（画质选择）
  - 音频提取
  - 字幕下载
  - 搜索（`ytsearch{N}:query`）
- **技术栈**：yt-dlp（`pip install yt-dlp`）

#### 3.2.4 统一下载入口（`unified_downloader.py`）
- 自动识别平台（抖音/B站/YouTube/快手/TikTok）
- 路由到对应下载器
- 统一输出目录管理

### 3.3 子项目3：免费素材API集成

#### 3.3.1 Pixabay API客户端（`pixabay_client.py`）
- **API文档**：https://pixabay.com/api/docs/
- **功能**：
  - 搜索视频（`/videos/`）
  - 搜索图片（`/`）
  - 搜索音乐（`/music/`）⭐ 新增
- **参数**：q（关键词）、lang、image_type、video_type、orientation、category、per_page
- **限制**：100 req/hour，需API Key
- **接口**：`--json-input` 协议，支持search_videos/search_images/search_music

#### 3.3.2 Pexels API客户端（`pexels_client.py`）
- **API文档**：https://www.pexels.com/api/
- **功能**：
  - 搜索视频（`/videos/search`）
  - 搜索图片（`/search`）
  - 获取热门/精选
- **限制**：200 req/hour，需API Key
- **接口**：`--json-input` 协议

#### 3.3.3 Jamendo音乐API客户端（`jamendo_client.py`）
- **API文档**：https://developer.jamendo.com/v3.0
- **功能**：
  - 搜索音乐（`/tracks`）
  - 按情绪/曲风筛选
  - 获取音乐流URL
- **限制**：需Client ID（免费）
- **接口**：`--json-input` 协议

#### 3.3.4 统一搜索入口（`unified_search.py`）
- 跨平台搜索（Pixabay+Pexels+Jamendo）
- 结果去重与排序
- 统一返回格式

### 3.4 子项目4：AI语义素材搜索

#### 3.4.1 视频帧抽取器（`frame_extractor.py`）
- **功能**：从视频中等间隔抽取关键帧
- **技术**：OpenCV（`cv2.VideoCapture`）
- **参数**：interval（间隔秒数）、max_frames（最大帧数）
- **输出**：帧图片列表 + 时间戳

#### 3.4.2 向量索引构建器（`clip_indexer.py`）
- **功能**：为素材库所有视频/图片建立CLIP向量索引
- **技术**：sentence-transformers（`clip-ViT-L-14`模型）
- **输出**：`vector_index.json`（文件路径+向量+元数据）
- **接口**：`--json-input` 协议，支持build_index/update_index

#### 3.4.3 语义搜索引擎（`clip_searcher.py`）
- **功能**：根据自然语言查询搜索素材
- **示例**：
  - "夕阳下的海滩" → 返回相关视频片段
  - "激烈的战斗场景" → 返回高燃片段
  - "温暖的笑脸" → 返回人物特写
- **技术**：CLIP文本编码 + 余弦相似度
- **接口**：`--json-input` 协议，支持search/update_index

#### 3.4.4 向量存储管理（`vector_store.py`）
- 向量索引文件的读写
- 增量更新（新增素材时只计算新文件）
- 缓存管理
