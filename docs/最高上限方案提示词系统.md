### 六、陷阱清单 (关键教训，勿踩)

- **T1 中文 mojibake**: Windows GBK 下子进程 print 崩溃 → 入口 reconfigure UTF-8 + 测试 subprocess encoding="utf-8" + 断言用 ASCII 标记
- **T2 "save failed unknown"误报**: 先 Read/git 核验实际落盘，勿盲目重试
- **T3 ruff CJK 噪音**: RUF001/002/003 对中文项目是纯误报 (核心库 12,207 条), 必须 ignore
- **T4 B023 良性误报**: 23 处闭包不绑定循环变量经核查全是同迭代内立即调用/await，勿 churn
- **T5 安全发现低风险**: S324 md5×35(均 path/内容指纹)/S301 pickle×6(加载自产可信模型头)/S314 xml×3(本地 FCP 文件)——本地管线威胁模型下无关键可利用漏洞
- **T6 god 文件 0% 覆盖→分解被阻断**: 在 0% 覆盖文件上重构=盲飞，必须先补 characterization/golden-master 测试建安全网
- **T7 ZCode 隔离**: 热文件 build_text_overlay.py (ZCode v47-v50 连续提交) 勿碰；永远勿 git add -A/commit -am
- **T8 全量测试慢**: 5593 测试收集 71s、全量+coverage 跑 18 分钟;7 个失败是预存的 (非我引入，我只改配置), CI 只跑~9 文件从未暴露
- **T9 PowerShell**: 用`;` 不用`&&`; Get-Content 读 UTF-8 文件显示乱码是显示假象 (用 Read 工具核验真实内容); 引号路径前加`&` 调用符
