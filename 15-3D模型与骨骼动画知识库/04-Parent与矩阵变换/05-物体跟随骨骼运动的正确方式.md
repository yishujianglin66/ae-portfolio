# 物体跟随骨骼运动的正确方式

## 问题场景

让物体（如发冠、武器）跟随骨骼运动有多种方式：parent_type='BONE'、Bone约束、Armature Modifier。选择错误会导致物体不跟随、跟随延迟或变换异常。

## 核心原理

### 方案对比

| 方案 | 跟随骨骼旋转 | 跟随骨骼位移 | 适用场景 |
|------|:---:|:---:|------|
| parent_type='BONE' | ✅ | ✅ | 单个附件跟随单根骨骼 |
| Bone Constraint (Child Of) | ✅ | ✅ | 需要动态切换parent |
| Armature Modifier + 权重 | ✅ | ✅ | 网格变形（多骨骼影响） |
| Copy Transforms Constraint | ✅ | ✅ | 精确复制骨骼变换 |
| parent_type='OBJECT' | ❌ | ✅(仅armature) | 跟随armature整体 |

### 方案1：parent_type='BONE'（本项目使用）

```python
def follow_bone_via_parent(child_obj, armature_obj, bone_name):
    """通过parent跟随骨骼（推荐用于刚体附件）"""
    bpy.context.view_layer.update()
    
    pb = armature_obj.pose.bones[bone_name]
    bone_world = armature_obj.matrix_world @ pb.matrix
    tail_mat = bone_world @ Matrix.Translation(Vector((0, pb.bone.length, 0)))
    
    # 记录当前世界位置
    child_world = child_obj.matrix_world.copy()
    
    child_obj.parent = armature_obj
    child_obj.parent_type = 'BONE'
    child_obj.parent_bone = bone_name
    child_obj.matrix_parent_inverse = tail_mat.inverted() @ child_world
    
    # 验证
    bpy.context.view_layer.update()
    # 此后骨骼移动/旋转时，child自动跟随
```

### 方案2：Child Of约束

```python
def follow_bone_via_constraint(child_obj, armature_obj, bone_name):
    """通过Child Of约束跟随骨骼（可动态切换）"""
    constraint = child_obj.constraints.new(type='CHILD_OF')
    constraint.target = armature_obj
    constraint.subtarget = bone_name
    constraint.use_location_x = True
    constraint.use_location_y = True
    constraint.use_location_z = True
    constraint.use_rotation_x = True
    constraint.use_rotation_y = True
    constraint.use_rotation_z = True
    constraint.use_scale_x = True
    constraint.use_scale_y = True
    constraint.use_scale_z = True
    
    # 设置inverse（保持当前位置）
    bpy.context.view_layer.objects.active = child_obj
    bpy.ops.constraint.childof_set_inverse(constraint="Child Of", owner='OBJECT')
```

### 方案3：Copy Transforms约束

```python
def follow_bone_copy_transforms(child_obj, armature_obj, bone_name):
    """完全复制骨骼的世界变换"""
    constraint = child_obj.constraints.new(type='COPY_TRANSFORMS')
    constraint.target = armature_obj
    constraint.subtarget = bone_name
    constraint.target_space = 'WORLD'
    constraint.owner_space = 'WORLD'
    # 注意：这会完全覆盖物体的变换！
```

### 验证跟随效果

```python
def test_bone_follow(child_obj, armature_obj, bone_name):
    """测试物体是否正确跟随骨骼"""
    bpy.context.view_layer.update()
    
    # 记录初始相对位置
    pb = armature_obj.pose.bones[bone_name]
    bone_world = armature_obj.matrix_world @ pb.matrix
    initial_offset = child_obj.matrix_world.translation - bone_world.translation
    
    # 旋转骨骼
    original_rot = pb.rotation_euler.copy()
    pb.rotation_euler.z += math.radians(30)
    bpy.context.view_layer.update()
    
    # 检查物体是否跟随
    new_bone_world = armature_obj.matrix_world @ pb.matrix
    new_offset = child_obj.matrix_world.translation - new_bone_world.translation
    
    # 如果正确跟随，offset应该旋转了相同角度
    offset_diff = (new_offset - initial_offset).length
    print(f"Follow test: offset changed by {offset_diff:.4f}")
    print(f"  (Should be >0 if bone rotated and child followed)")
    
    # 恢复
    pb.rotation_euler = original_rot
    bpy.context.view_layer.update()
```

## 常见陷阱

### 陷阱1：parent后物体不跟随pose变化
```python
# 如果armature的pose改变了（如播放动画）
# parent_type='BONE'的物体会自动跟随
# 但需要确保depsgraph更新
bpy.context.view_layer.update()
```

### 陷阱2：约束的inverse未设置
```python
# Child Of约束默认inverse=Identity
# 物体会跳到骨骼位置
# 必须调用 childof_set_inverse
```
