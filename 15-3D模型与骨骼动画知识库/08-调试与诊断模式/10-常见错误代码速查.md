# 常见错误代码速查

## 问题场景

Blender脚本开发中会遇到各种错误：RuntimeError、TypeError、AttributeError、NameError等。本文汇总常见错误及其原因和解决方案，作为快速排查手册。

## 核心原理

### RuntimeError

```python
# 错误1：Operator需要特定context
# RuntimeError: Operator bpy.ops.object.mode_set.poll() failed, 
#               context is incorrect

# 原因：没有活动对象或对象类型不匹配
# 解决：
bpy.context.view_layer.objects.active = obj
bpy.ops.object.mode_set(mode='EDIT')

# 错误2：编辑模式ops在对象模式调用
# RuntimeError: Operator bpy.ops.mesh.select_all.poll() failed

# 原因：mesh ops需要EDIT模式
# 解决：
bpy.ops.object.mode_set(mode='EDIT')
bpy.ops.mesh.select_all(action='SELECT')
bpy.ops.object.mode_set(mode='OBJECT')

# 错误3：渲染时相机未设置
# RuntimeError: Error: No camera

# 解决：
scene.camera = cam_obj
```

### TypeError

```python
# 错误1：参数类型错误
# TypeError: bpy_struct: item.attr = val: 
#            Object.location expected a Vector, got int

# 原因：location需要Vector或tuple
# 解决：
obj.location = (1, 2, 3)  # tuple
obj.location = Vector((1, 2, 3))  # Vector
# obj.location = 1  # 错误！

# 错误2：颜色参数格式
# TypeError: expected a sequence of size 4

# 原因：颜色需要RGBA四元组
# 解决：
color = (1.0, 0.0, 0.0, 1.0)  # RGBA
# color = (1.0, 0.0, 0.0)  # 错误！缺少Alpha

# 错误3：矩阵运算类型
# TypeError: unsupported operand type(s) for @: 'float' and 'Vector'

# 解决：确保顺序正确
result = matrix @ vector  # 矩阵 @ 向量
# result = vector @ matrix  # 错误！
```

### AttributeError

```python
# 错误1：访问不存在的属性
# AttributeError: 'Object' object has no attribute 'mesh'

# 原因：属性名错误
# 解决：
obj.data  # 不是obj.mesh

# 错误2：None对象访问属性
# AttributeError: 'NoneType' object has no attribute 'name'

# 原因：对象查找失败返回None
# 解决：
obj = bpy.data.objects.get("NonExistent")
if obj:
    print(obj.name)

# 错误3：版本API差异
# AttributeError: 'Scene' object has no attribute 'eevee'

# 原因：某些版本EEVEE设置位置不同
# 解决：检查Blender版本
```

### NameError

```python
# 错误1：变量未定义
# NameError: name '_bc' is not defined

# 原因：变量在条件块内定义，条件不满足时未定义
# 解决：提前定义默认值
_bc = Vector((0, 0, 0))  # 默认值
if condition:
    _bc = calculate()

# 错误2：作用域问题
# NameError: name 'result' is not defined

# 原因：变量在函数/循环内定义
# 解决：在外层定义
result = None
for item in items:
    result = process(item)
```

### KeyError / IndexError

```python
# 错误1：顶点组不存在
# KeyError: 'bpy_prop_collection[key]: key "Hand_L" not found'

# 原因：顶点组名称不匹配
# 解决：
vg = obj.vertex_groups.get("Hand_L")  # 安全访问
if vg:
    # 使用vg

# 错误2：骨骼不存在
# KeyError: 'bpy_prop_collection[key]: key "Hips" not found'

# 解决：
bone = armature.bones.get("Hips")
if bone:
    # 使用bone

# 错误3：索引越界
# IndexError: bpy_prop_collection[index]: index 100 out of range

# 解决：检查长度
if index < len(mesh.vertices):
    v = mesh.vertices[index]
```

### ValueError

```python
# 错误1：枚举值无效
# ValueError: error setting value 'INVALID' for 'Object.rotation_mode'

# 原因：枚举值拼写错误
# 解决：使用有效值
obj.rotation_mode = 'XYZ'  # 有效
obj.rotation_mode = 'QUATERNION'  # 有效
# obj.rotation_mode = 'ABC'  # 无效

# 错误2：数值超出范围
# ValueError: value outside range

# 解决：检查范围
scene.render.resolution_percentage = 100  # 1-10000
```

### MemoryError

```python
# 错误：内存不足
# MemoryError

# 原因：场景太大或内存泄漏
# 解决：
# 1. 清理未使用数据
for mesh in list(bpy.data.meshes):
    if mesh.users == 0:
        bpy.data.meshes.remove(mesh)

# 2. 降低纹理分辨率
for img in bpy.data.images:
    if img.size[0] > 2048:
        img.scale(2048, 2048)

# 3. 减少细分
for obj in bpy.data.objects:
    if obj.type == 'MESH':
        for mod in obj.modifiers:
            if mod.type == 'SUBSURF':
                mod.levels = 1
```

### 错误处理模板

```python
import traceback

def safe_execute(description, func, *args, **kwargs):
    """安全执行包装器"""
    try:
        result = func(*args, **kwargs)
        print(f"[OK] {description}")
        return result
    except RuntimeError as e:
        print(f"[ERROR] {description}: RuntimeError - {e}")
        if "poll() failed" in str(e):
            print("  [HINT] Check context: active object, mode")
    except TypeError as e:
        print(f"[ERROR] {description}: TypeError - {e}")
        print("  [HINT] Check parameter types")
    except AttributeError as e:
        print(f"[ERROR] {description}: AttributeError - {e}")
        print("  [HINT] Check API version compatibility")
    except NameError as e:
        print(f"[ERROR] {description}: NameError - {e}")
        print("  [HINT] Check variable definition scope")
    except KeyError as e:
        print(f"[ERROR] {description}: KeyError - {e}")
        print("  [HINT] Check collection key exists")
    except Exception as e:
        print(f"[ERROR] {description}: {type(e).__name__} - {e}")
    
    traceback.print_exc()
    return None
```

## 常见陷阱

### 陷阱1：错误信息被截断
```python
# subprocess输出可能截断长错误
# 解决：完整捕获stderr
result = subprocess.run(cmd, capture_output=True, text=True)
print(result.stderr)  # 完整错误
```

