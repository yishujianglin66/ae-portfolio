# 网格顶点检测手部位置

## 问题场景

骨骼位置因auto-weight失败而不可靠时，需要用网格顶点直接检测手部位置。上官婉儿模型中Hand_R骨骼在(1.2, 0, 2.5)但实际手部网格在(-0.6, 0.7, -2.72)，偏差达4个单位。

## 核心原理

### 检测策略：最左侧顶点聚类

```python
import bpy
from mathutils import Vector

def detect_hand_from_mesh(body_parts, side='right'):
    """
    从主体网格检测手部位置
    原理：A-pose人形模型中，右手在X最小侧（左手在X最大侧）
    side: 'right'=X最小, 'left'=X最大
    """
    # 1. 找最大的body mesh（顶点数最多）
    main_mesh = max(body_parts, key=lambda o: len(o.data.vertices))
    
    # 2. 获取所有顶点世界坐标
    world_matrix = main_mesh.matrix_world
    vertices = [(world_matrix @ v.co) for v in main_mesh.data.vertices]
    
    # 3. 按X排序，取最左/最右5%
    vertices.sort(key=lambda v: v.x)
    count = max(int(len(vertices) * 0.05), 10)  # 至少10个顶点
    
    if side == 'right':
        hand_verts = vertices[:count]  # X最小的5%
    else:
        hand_verts = vertices[-count:]  # X最大的5%
    
    # 4. 计算聚类中心
    center = sum(hand_verts, Vector()) / len(hand_verts)
    
    print(f"[Hand Detection] {side} hand: {len(hand_verts)} vertices")
    print(f"  Center: ({center.x:.2f}, {center.y:.2f}, {center.z:.2f})")
    print(f"  X range: [{hand_verts[0].x:.2f}, {hand_verts[-1].x:.2f}]")
    
    return center, hand_verts
```

### 上官婉儿的实际检测

```
检测结果（v12第3次运行）：
- 主体mesh: body_main (约5000顶点)
- 取X最小5% = 28个顶点
- 聚类中心: (-0.6, 0.7, -2.72)
- 这就是右手世界坐标

对比骨骼位置：
- Hand_R bone: (1.2, 0.0, 2.5)  ← 完全错误！
- 网格检测: (-0.6, 0.7, -2.72) ← 正确

根因：骨骼位置用百分比计算，假设标准人形比例
      上官婉儿是宽袍A-pose，手臂位置与假设不符
```

### 改进：Z-slice过滤

```python
def detect_hand_with_z_filter(body_parts, z_range_pct=(0.3, 0.6)):
    """
    增加Z高度过滤，排除脚部/头部顶点
    z_range_pct: 手部应在模型高度的30%-60%区域
    """
    main_mesh = max(body_parts, key=lambda o: len(o.data.vertices))
    world_matrix = main_mesh.matrix_world
    vertices = [(world_matrix @ v.co) for v in main_mesh.data.vertices]
    
    # Z范围
    z_values = [v.z for v in vertices]
    z_min, z_max = min(z_values), max(z_values)
    height = z_max - z_min
    z_low = z_min + height * z_range_pct[0]
    z_high = z_min + height * z_range_pct[1]
    
    # 过滤：只保留手部Z范围内的顶点
    filtered = [v for v in vertices if z_low <= v.z <= z_high]
    
    # 再取X最小5%
    filtered.sort(key=lambda v: v.x)
    count = max(int(len(filtered) * 0.05), 5)
    hand_verts = filtered[:count]
    
    center = sum(hand_verts, Vector()) / len(hand_verts)
    return center
```
