# 武器部件识别与分类

## 问题场景

FBX导入后场景中有多个mesh，需要自动识别哪些是武器部件（扇子、剑、枪等），哪些是身体部件。识别错误会导致武器被蒙皮变形或身体部件被当作武器归位。

## 核心原理

### 名称关键词匹配

```python
# 本项目的识别规则（cel_shading.py L1471-1481）
_WEAPON_KEYWORDS = ['weapon']
_WEAPON_PROTECTED = ['face', 'leg', 'baosha', 'op']

def identify_weapon_parts(mesh_objects):
    """识别武器部件"""
    weapon_parts = []
    protected_parts = []
    body_parts = []
    
    for obj in mesh_objects:
        name_lower = obj.name.lower()
        
        # 检查是否受保护
        is_protected = any(kw in name_lower for kw in _WEAPON_PROTECTED)
        if is_protected:
            protected_parts.append(obj)
            continue
        
        # 检查是否是武器
        is_weapon = any(kw in name_lower for kw in _WEAPON_KEYWORDS)
        if is_weapon:
            weapon_parts.append(obj)
        else:
            body_parts.append(obj)
    
    return weapon_parts, body_parts, protected_parts
```

### 体积辅助判断

```python
def classify_by_volume(weapon_parts):
    """
    通过体积区分武器子部件
    上官婉儿：扇柄(小) vs 扇面(大)
    """
    volumes = []
    for obj in weapon_parts:
        # 计算包围盒体积
        bbox = [obj.matrix_world @ Vector(v) for v in obj.bound_box]
        x_size = max(v.x for v in bbox) - min(v.x for v in bbox)
        y_size = max(v.y for v in bbox) - min(v.y for v in bbox)
        z_size = max(v.z for v in bbox) - min(v.z for v in bbox)
        volume = x_size * y_size * z_size
        volumes.append((obj, volume))
    
    volumes.sort(key=lambda x: x[1])
    
    # 最小体积 = 扇柄（handle）
    # 最大体积 = 扇面（blade）
    handle = volumes[0][0] if len(volumes) >= 2 else None
    blade = volumes[-1][0] if len(volumes) >= 2 else None
    
    return handle, blade
```

### 上官婉儿的武器识别

```
FBX导入后的mesh列表：
1. body_main → body（主体）
2. Object001 → crown（发冠，名称含'op'→受保护）
3. 5133_ShuSheng_Weapon_High → weapon（名称含'weapon'）
4. 5133_ShuSheng_Weapon_High002 → weapon（名称含'weapon'）
5. face_mesh → protected（名称含'face'）

武器子分类（体积）：
- 5133_Weapon_High: 体积=0.02 → 扇柄（handle）
- 5133_Weapon_High002: 体积=0.15 → 扇面（blade）
```

## 常见陷阱

### 陷阱1：武器名称不含'weapon'
```python
# 某些模型的武器命名为"sword_01"、"fan_L"等
# 解决：扩展关键词列表
_WEAPON_KEYWORDS = ['weapon', 'sword', 'fan', 'gun', 'staff', 'blade']
```

### 陷阱2：身体部件误判为武器
```python
# "baosha"（宝纱/飘带）可能被误判
```
