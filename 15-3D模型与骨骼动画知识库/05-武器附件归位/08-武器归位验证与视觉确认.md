# 武器归位验证与视觉确认

## 问题场景

武器归位后需要验证：(1)位置是否正确（贴合手部）(2)角度是否自然（握持姿态）(3)渲染结果是否视觉正确。background模式下无法直接查看viewport，需要程序化验证+渲染确认。

## 核心原理

### 程序化验证

```python
import bpy
from mathutils import Vector

def validate_weapon_position(weapon_handle, hand_pos, tolerance=0.5):
    """验证武器握点是否贴合手部"""
    bpy.context.view_layer.update()
    
    # 计算握点世界坐标
    local_bbox = [Vector(v) for v in weapon_handle.bound_box]
    grip_local = Vector((
        min(v.x for v in local_bbox),
        sum(v.y for v in local_bbox) / 8,
        sum(v.z for v in local_bbox) / 8
    ))
    grip_world = weapon_handle.matrix_world @ grip_local
    
    # 计算距离
    distance = (grip_world - hand_pos).length
    
    if distance < tolerance:
        print(f"[OK] Weapon grip is {distance:.3f} from hand (< {tolerance})")
        return True
    else:
        print(f"[FAIL] Weapon grip is {distance:.3f} from hand (> {tolerance})")
        print(f"  Grip: {grip_world.to_tuple()}")
        print(f"  Hand: {hand_pos.to_tuple()}")
        return False

def validate_weapon_orientation(weapon_handle):
    """验证武器朝向是否合理"""
    bpy.context.view_layer.update()
    
    # 检查武器是否大致朝上（扇面朝上）
    world_bbox = [weapon_handle.matrix_world @ Vector(v) for v in weapon_handle.bound_box]
    z_size = max(v.z for v in world_bbox) - min(v.z for v in world_bbox)
    x_size = max(v.x for v in world_bbox) - min(v.x for v in world_bbox)
    
    # 扇子应该Z方向较长（扇面朝上）
    if z_size > x_size * 0.5:
        print(f"[OK] Weapon orientation looks correct (Z={z_size:.2f}, X={x_size:.2f})")
        return True
    else:
        print(f"[WARN] Weapon may be flat (Z={z_size:.2f}, X={x_size:.2f})")
        return False
```

### 渲染验证

```python
def render_validation_frame(output_path, frame=1):
    """渲染单帧用于视觉验证"""
    bpy.context.scene.frame_set(frame)
    bpy.context.scene.render.filepath = output_path
    bpy.ops.render.render(write_still=True)
    print(f"[Render] Validation frame saved: {output_path}")
```

### 验证清单

| 检查项 | 方法 | 通过标准 |
|--------|------|----------|
| 握点距离 | 程序化 | < 0.5单位 |
| 武器朝向 | 程序化 | Z > X*0.5 |
| 视觉贴合 | 渲染图 | 无悬浮/穿模 |
| 扇面展开 | 渲染图 | 扇面朝上可见 |
| 无Z-fighting | 渲染图 | 无闪烁条纹 |

## 常见陷阱

### 陷阱1：只看日志不看渲染
```python
# 程序化验证通过 ≠ 视觉正确
# 必须渲染确认！
# 本项目的教训：日志显示success=True但图像中扇子在地面
```

### 陷阱2：旧帧文件误导
```python
# 如果渲染失败（success=False），旧帧文件仍存在
# 必须检查文件时间戳或大小
import os
stat = os.stat(output_path)
print(f"File modified: {stat.st_mtime}")
```
