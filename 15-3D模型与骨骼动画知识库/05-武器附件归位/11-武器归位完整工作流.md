# 武器归位完整工作流（本项目实战）

## 问题场景

综合前述所有知识，描述上官婉儿扇子归位的完整工作流，包括v8-v12的策略演进和最终方案。

## 策略演进历史

```
v8:  直接parent到Hand_R骨骼 → 失败（骨骼位置错误）
v9:  用骨骼位置计算偏移 → 失败（骨骼位置≠网格位置）
v10: 用模型中心+百分比估算手部 → 部分成功（Y/Z偏差大）
v11: Z-slice宽度曲线分析 → 改善但不够精确
v12: 网格顶点手部检测 + rotate-first → 成功！

关键突破：
- 放弃骨骼位置，改用网格顶点直接检测
- rotate-first避免旋转后握点偏移
```

## 最终工作流（v12）

```python
def full_weapon_pipeline_v12(weapon_parts, body_parts, armature_obj):
    """v12完整武器归位管线"""
    
    # Step 1: 识别武器部件
    handle, blade = classify_by_volume(weapon_parts)
    print(f"[v12] Handle: {handle.name}, Blade: {blade.name}")
    
    # Step 2: 网格顶点检测手部
    hand_pos, hand_verts = detect_hand_from_mesh(body_parts, side='right')
    print(f"[v12] Hand detected: {hand_pos.to_tuple()} ({len(hand_verts)} verts)")
    
    # Step 3: 清除原有parent
    handle.parent = None
    blade.parent = None
    bpy.context.view_layer.update()
    
    # Step 4: Rotate-First归位扇柄
    handle.rotation_euler = Euler((radians(70), 0, radians(-45)), 'XYZ')
    bpy.context.view_layer.update()
    
    # Step 5: 握点对齐
    grip_local = get_grip_point_local(handle)
    grip_world = handle.matrix_world @ grip_local
    shift = hand_pos - grip_world
    handle.location += shift
    bpy.context.view_layer.update()
    
    # Step 6: 扇面跟随旋转
    blade.rotation_euler = handle.rotation_euler.copy()
    bpy.context.view_layer.update()
    
    # Step 7: 扇面连接点对齐扇柄tip
    connect_world = blade.matrix_world @ get_connect_point_local(blade)
    tip_world = get_tip_point_world(handle)
    blade.location += (tip_world - connect_world)
    bpy.context.view_layer.update()
    
    # Step 8: Parent组装
    blade_world = blade.matrix_world.copy()
    blade.parent = handle
    blade.matrix_parent_inverse = handle.matrix_world.inverted() @ blade_world
    
    handle_world = handle.matrix_world.copy()
    handle.parent = armature_obj
    handle.parent_type = 'OBJECT'
    handle.matrix_parent_inverse = armature_obj.matrix_world.inverted() @ handle_world
    
    bpy.context.view_layer.update()
    
    # Step 9: 验证
    validate_weapon_position(handle, hand_pos)
    
    print("[v12] Weapon pipeline complete!")
```

## 常见问题速查

| 问题 | 原因 | 解决 |
|------|------|------|
| 扇子在地面 | _v12_no_reposition=True | 改为False |
| NameError: _bc | 条件分支跳过变量定义 | 添加守卫条件 |
| 握点偏移 | translate-first | 改为rotate-first |
| 扇面方向错 | 未复制扇柄旋转 | rotation_euler.copy() |
| parent后跳跃 | matrix_parent_inverse错误 | 正确计算inverse |
