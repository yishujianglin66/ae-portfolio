# 通用附件归位框架

## 问题场景

不同模型的附件类型各异（扇子、剑、盾、翅膀、尾巴等），需要建立通用归位框架，支持新模型快速适配。

## 核心原理

### 附件类型分类

```python
ATTACHMENT_TYPES = {
    'hand_weapon': {
        'target_bone': 'Hand_R',
        'reposition': True,
        'rotation': (70, 0, -45),  # 握持角度
        'examples': ['fan', 'sword', 'staff']
    },
    'head_accessory': {
        'target_bone': 'Head',
        'reposition': False,  # 保持FBX位置
        'rotation': None,
        'examples': ['crown', 'hat', 'hairpin']
    },
    'back_accessory': {
        'target_bone': 'Chest',
        'reposition': False,
        'rotation': None,
        'examples': ['wings', 'cape', 'backpack']
    },
    'waist_accessory': {
        'target_bone': 'Hips',
        'reposition': False,
        'rotation': None,
        'examples': ['belt', 'skirt', 'tail']
    }
}
```

### 通用归位函数

```python
import bpy
from mathutils import Matrix, Vector, Euler
import math

def attach_accessory(acc_obj, armature_obj, config):
    """
    通用附件归位
    config: ATTACHMENT_TYPES中的配置
    """
    bpy.context.view_layer.update()
    
    target_bone = config['target_bone']
    pb = armature_obj.pose.bones[target_bone]
    bone_world = armature_obj.matrix_world @ pb.matrix
    tail_mat = bone_world @ Matrix.Translation(Vector((0, pb.bone.length, 0)))
    
    # 可选：旋转
    if config.get('rotation'):
        rx, ry, rz = config['rotation']
        acc_obj.rotation_euler = Euler((
            math.radians(rx), math.radians(ry), math.radians(rz)
        ), 'XYZ')
        bpy.context.view_layer.update()
    
    # 可选：重新定位
    if config.get('reposition'):
        # 需要外部提供目标位置
        pass
    
    # Parent
    acc_world = acc_obj.matrix_world.copy()
    acc_obj.parent = armature_obj
    acc_obj.parent_type = 'BONE'
    acc_obj.parent_bone = target_bone
    acc_obj.matrix_parent_inverse = tail_mat.inverted() @ acc_world
    
    bpy.context.view_layer.update()
    return acc_obj
```
