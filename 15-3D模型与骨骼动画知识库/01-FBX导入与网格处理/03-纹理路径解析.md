# 纹理路径解析（3dsMax导出的贴图#N问题）

## 问题场景

3dsMax导出的FBX文件中，纹理节点名称为"贴图 #1"~"贴图 #5"（中文），但 `FileName` 和 `RelativeFilename` 字段均为空。Blender导入后材质无纹理，渲染为纯灰色/粉色。

## 核心原理

### 3dsMax的纹理命名机制

3dsMax内部使用 `BitmapTexture` 对象，导出FBX时：
- `TextureName` = 材质编辑器中的显示名（如"贴图 #5"）
- `FileName` = 实际磁盘路径（**导出时可能不嵌入**）
- 如果勾选了"Embed Media"则纹理嵌入FBX；否则路径为空

### Blender导入后的材质状态

```python
# 导入后检查材质
for mat in bpy.data.materials:
    tree = mat.node_tree
    for node in tree.nodes:
        if node.type == 'TEX_IMAGE':
            # node.image 可能为 None 或 filepath 为空
            print(f"  Image: {node.image}")
            if node.image:
                print(f"  Path: '{node.image.filepath}'")  # 通常为 ""
```

### 粉色材质（Missing Texture）

Blender中纹理缺失时：
- Viewport：显示粉色/紫色
- Cycles渲染：使用默认白色或节点默认颜色
- EEVEE：可能显示黑色

## 代码示例

### 方案1：按名称模式匹配本地纹理文件

```python
import os
from pathlib import Path

def remap_textures(texture_dir):
    """将空路径纹理重映射到本地目录"""
    texture_dir = Path(texture_dir)
    available = {f.stem.lower(): f for f in texture_dir.iterdir() 
                 if f.suffix.lower() in ('.png', '.jpg', '.tga', '.bmp')}
    
    remapped = 0
    for img in bpy.data.images:
        if img.filepath == "" or not Path(img.filepath).exists():
            # 尝试按名称匹配
            name_lower = img.name.lower()
            for key, path in available.items():
                if key in name_lower or name_lower in key:
                    img.filepath = str(path)
                    remapped += 1
                    print(f"[REMAP] {img.name} → {path}")
                    break
    return remapped
```

### 方案2：使用赛璐璐风格忽略原始纹理

```python
# 三渲二风格不依赖原始纹理，使用纯色+Toon shader
# 这是本项目的实际策略：
def apply_cel_material(mesh_obj, base_color=(0.8, 0.85, 0.9, 1.0)):
    """覆盖原始材质为赛璐璐风格"""
    mat = bpy.data.materials.new(name=f"Cel_{mesh_obj.name}")
    mat.use_nodes = True
    tree = mat.node_tree
    # 清除原有节点
    for n in list(tree.nodes):
        tree.nodes.remove(n)
    # 创建Toon BSDF
    toon = tree.nodes.new('ShaderNodeBsdfToon')
    toon.inputs['Base Color'].default_value = base_color
    output = tree.nodes.new('ShaderNodeOutputMaterial')
    tree.links.new(toon.outputs['BSDF'], output.inputs['Surface'])
    # 应用
    mesh_obj.data.materials.clear()
    mesh_obj.data.materials.append(mat)
```

## 常见陷阱

| 陷阱 | 原因 | 解决 |
|------|------|------|
| 纹理全灰 | FileName为空，无嵌入 | 使用纯色材质或手动指定 |
| 中文纹理名匹配失败 | 编码问题(GBK vs UTF-8) | 使用bytes比较或lower() |
| 导入后image为None | 节点创建但无image datablock | 检查node.image而非node本身 |
| 粉色仅在viewport | 渲染时Cycles用默认值 | 不能仅看viewport判断 |

## 版本兼容

- Blender 5.1.0：`Material.use_nodes` 将在6.0移除（当前仍可用）
- 纹理路径错误输出到stderr，不影响Python脚本执行
- 错误信息为C层 `printf`，非Python异常，不会中断脚本
