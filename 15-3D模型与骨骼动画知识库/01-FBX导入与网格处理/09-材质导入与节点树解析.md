# 材质导入与节点树解析

## 问题场景

FBX导入后材质为Principled BSDF默认设置，原始3dsMax材质信息（如Standard Material的Diffuse/Specular）被转换为节点树。需要理解转换规则以决定是保留还是覆盖为赛璐璐风格。

## 核心原理

### 3dsMax → Blender 材质映射

| 3dsMax属性 | Blender节点 | 说明 |
|-----------|-------------|------|
| Diffuse Color | Principled BSDF → Base Color | 基础颜色 |
| Specular Level | Principled BSDF → Specular | 高光强度 |
| Glossiness | Principled BSDF → Roughness | 粗糙度(反转) |
| Opacity | Principled BSDF → Alpha | 透明度 |
| Self-Illumination | Emission | 自发光 |
| Bitmap Texture | Image Texture节点 | 纹理贴图 |

### 检查导入材质状态

```python
import bpy

def inspect_materials():
    for mat in bpy.data.materials:
        print(f"\n=== {mat.name} ===")
        if not mat.node_tree:
            print("  No node tree")
            continue
        for node in mat.node_tree.nodes:
            print(f"  Node: {node.type} ({node.name})")
            if node.type == 'BSDF_PRINCIPLED':
                bc = node.inputs['Base Color'].default_value
                print(f"    Base Color: {bc[:3]}")
                print(f"    Roughness: {node.inputs['Roughness'].default_value}")
            elif node.type == 'TEX_IMAGE':
                print(f"    Image: {node.image}")
```

### 覆盖为赛璐璐材质

```python
def override_to_cel(obj, base_color, outline_width=0.002):
    """覆盖原始材质为Toon shader"""
    mat = bpy.data.materials.new(f"Cel_{obj.name}")
    mat.use_nodes = True
    tree = mat.node_tree
    for n in list(tree.nodes):
        tree.nodes.remove(n)
    
    # Toon BSDF
    toon = tree.nodes.new('ShaderNodeBsdfToon')
    toon.inputs['Base Color'].default_value = base_color
    toon.inputs['Size'].default_value = 0.5  # 明暗分界锐度
    
    # Output
    out = tree.nodes.new('ShaderNodeOutputMaterial')
    tree.links.new(toon.outputs['BSDF'], out.inputs['Surface'])
    
    obj.data.materials.clear()
    obj.data.materials.append(mat)
```

## 常见陷阱

| 陷阱 | 原因 | 解决 |
|------|------|------|
| Material.use_nodes DeprecationWarning | Blender 5.x废弃旧API | 6.0前仍可用，忽略警告 |
| 材质全灰 | 纹理路径为空 | 用纯色Toon覆盖 |
| 多材质slot | 一个mesh多个材质 | 遍历material_slots全部覆盖 |
| blend_method不兼容 | EEVEE的BLEND模式 | Cycles无需设置blend_method |
