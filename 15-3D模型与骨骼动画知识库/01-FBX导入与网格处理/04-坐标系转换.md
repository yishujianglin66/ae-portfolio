# 坐标系转换（Y-up vs Z-up）

## 问题场景

3dsMax使用Z-up坐标系（Z轴朝上），Blender使用Z-up但FBX导入时可能应用Y-up转换。模型导入后可能"躺倒"（面朝上或面朝下），或朝向错误（面向X而非Y）。

## 核心原理

### 各软件坐标系约定

| 软件 | Up轴 | 前方轴 |  handedness |
|------|------|--------|------------|
| 3dsMax | Z | Y (或-X) | 右手 |
| Blender | Z | -Y (面向摄像机) | 右手 |
| Maya | Y | Z | 右手 |
| Unity | Y | Z | 左手 |
| FBX默认 | Y | Z | 右手 |

### Blender FBX导入的坐标处理

```python
bpy.ops.import_scene.fbx(
    filepath="model.fbx",
    use_manual_orientation=False,  # 使用FBX文件内的GlobalSettings
    axis_forward='-Z',            # 导入后的前方
    axis_up='Y',                  # 导入后的上方
)
```

**关键**：Blender的FBX导入器会读取FBX的 `GlobalSettings` 中的 `UpAxis` 和 `FrontAxis`，自动应用旋转矩阵使模型符合Blender的Z-up约定。

### 判断模型朝向

```python
import bpy
from mathutils import Vector

def check_orientation(obj):
    """检查模型是否正确站立"""
    # 获取bounding box
    bbox = [obj.matrix_world @ Vector(v) for v in obj.bound_box]
    zs = [v.z for v in bbox]
    xs = [v.x for v in bbox]
    ys = [v.y for v in bbox]
    
    height_z = max(zs) - min(zs)
    width_x = max(xs) - min(xs)
    depth_y = max(ys) - min(ys)
    
    # 正确站立：Z方向最高
    if height_z > width_x and height_z > depth_y:
        print("✓ 模型正确站立 (Z-up)")
    elif width_x > height_z:
        print("✗ 模型侧躺 (需绕Y旋转90°)")
    elif depth_y > height_z:
        print("✗ 模型前后倒 (需绕X旋转90°)")
    
    return {'z': height_z, 'x': width_x, 'y': depth_y}
```

## 代码示例

### 自动修正朝向

```python
import math

def auto_fix_orientation(obj):
    """自动检测并修正模型朝向"""
    dims = check_orientation(obj)
    
    if dims['x'] > dims['z']:  # 侧躺
        obj.rotation_euler.y = math.radians(90)
    elif dims['y'] > dims['z']:  # 前后倒
        obj.rotation_euler.x = math.radians(-90)
    
    bpy.context.view_layer.update()
    # 应用旋转
    bpy.ops.object.select_all(action='DESELECT')
    obj.select_set(True)
    bpy.context.view_layer.objects.active = obj
    bpy.ops.object.transform_apply(rotation=True)
```

## 常见陷阱

| 陷阱 | 表现 | 解决 |
|------|------|------|
| 模型躺倒 | 高度方向为X或Y | 检查FBX的UpAxis设置 |
| 面向错误 | 渲染看到背面 | 绕Z旋转180° |
| 缩放异常 | 模型极大/极小 | 3dsMax单位(厘米) vs Blender(米) |
| 法线翻转 | 面片透明/黑色 | `bpy.ops.mesh.normals_make_consistent()` |

## 版本兼容

- Blender 5.1.0：FBX导入的 `axis_forward`/`axis_up` 参数行为与4.x一致
- 注意：Blender 4.0+ 改变了FBX导入器的部分默认值
