# 导入后验证清单

## 问题场景

FBX导入后需要系统性验证模型状态，避免后续管线（骨骼/权重/渲染）因导入问题而失败。本清单基于上官婉儿模型调试经验总结。

## 验证清单

### 1. 基础检查

```python
import bpy
from mathutils import Vector

def post_import_validation():
    """FBX导入后完整验证"""
    results = {'pass': [], 'warn': [], 'fail': []}
    
    meshes = [o for o in bpy.data.objects if o.type == 'MESH']
    armatures = [o for o in bpy.data.objects if o.type == 'ARMATURE']
    
    # 1. 对象数量
    if len(meshes) == 0:
        results['fail'].append("无mesh对象")
    else:
        results['pass'].append(f"Mesh数量: {len(meshes)}")
    
    # 2. 模型尺寸
    all_coords = []
    for obj in meshes:
        for v in obj.bound_box:
            all_coords.append(obj.matrix_world @ Vector(v))
    
    if all_coords:
        min_z = min(c.z for c in all_coords)
        max_z = max(c.z for c in all_coords)
        height = max_z - min_z
        if height < 0.1:
            results['fail'].append(f"模型高度异常: {height:.4f}")
        elif height > 100:
            results['warn'].append(f"模型未归一化: height={height:.1f}")
        else:
            results['pass'].append(f"模型高度: {height:.2f}")
    
    # 3. 顶点数
    total_verts = sum(len(o.data.vertices) for o in meshes)
    if total_verts == 0:
        results['fail'].append("无顶点数据")
    else:
        results['pass'].append(f"总顶点数: {total_verts}")
    
    # 4. 材质
    mats = [m for m in bpy.data.materials if m.users > 0]
    results['pass'].append(f"材质数: {len(mats)}")
    
    # 5. 纹理状态
    missing_tex = 0
    for img in bpy.data.images:
        if img.filepath == "" and not img.packed_file:
            missing_tex += 1
    if missing_tex > 0:
        results['warn'].append(f"{missing_tex}个纹理路径为空")
    
    # 6. 骨骼状态
    if armatures:
        results['pass'].append(f"已有Armature: {armatures[0].name}")
    else:
        results['warn'].append("无Armature（需程序化创建）")
    
    # 7. 部件名称
    for obj in meshes:
        results['pass'].append(f"  Part: '{obj.name}' verts={len(obj.data.vertices)}")
    
    return results

# 执行验证
results = post_import_validation()
print("=== 导入验证 ===")
for status, items in results.items():
    for item in items:
        print(f"  [{status.upper()}] {item}")
```

## 常见陷阱

| 检查项 | 失败后果 | 预防措施 |
|--------|----------|----------|
| 模型高度 | 相机/骨骼长度不匹配 | 归一化到6单位 |
| 顶点数为0 | 权重分配崩溃 | 导入后立即检查 |
| 无材质 | 渲染全黑 | 创建默认材质 |
| 部件名称 | 分类逻辑失败 | 打印所有名称确认 |
| 法线方向 | Toon明暗异常 | `normals_make_consistent()` |
