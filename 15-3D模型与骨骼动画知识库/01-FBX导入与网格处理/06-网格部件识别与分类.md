# 网格部件识别与分类

## 问题场景

FBX导入后场景中有多个mesh对象（如body_main、Object001、5133_ShuSheng_Weapon_High等），需要自动识别每个部件的类型（主体/发冠/面部/武器），以决定后续处理策略（蒙皮/归位/保护）。

## 核心原理

### 分类策略：名称匹配 + 空间位置

```python
# 本项目使用的分类规则
CROWN_KEYWORDS = ['_op_', 'object001']  # 发冠/头饰
FACE_KEYWORDS = ['face']                 # 面部
WEAPON_KEYWORDS = ['weapon']             # 武器
PROTECTED_KEYWORDS = ['face', 'leg', 'baosha', 'op']  # 受保护部件

def classify_parts(mesh_objects):
    body_parts = []
    crown_part = None
    face_part = None
    weapon_parts = []
    
    for obj in mesh_objects:
        name_lower = obj.name.lower()
        
        # 发冠识别：名称匹配 或 头部区域小体积物体
        is_crown = any(kw in name_lower for kw in CROWN_KEYWORDS)
        is_face = any(kw in name_lower for kw in FACE_KEYWORDS)
        is_weapon = any(kw in name_lower for kw in WEAPON_KEYWORDS)
        
        if is_crown and crown_part is None:
            crown_part = obj
        elif is_face:
            face_part = obj
        elif is_weapon:
            weapon_parts.append(obj)
        else:
            body_parts.append(obj)
    
    return body_parts, crown_part, face_part, weapon_parts
```

### 空间位置辅助判断

当名称无法识别时，用bounding box位置判断：

```python
def identify_by_position(obj, model_height, model_top_z):
    """通过空间位置识别部件类型"""
    bbox = [obj.matrix_world @ Vector(v) for v in obj.bound_box]
    center_z = sum(v.z for v in bbox) / 8
    volume = (max(v.x for v in bbox) - min(v.x for v in bbox)) * \
             (max(v.y for v in bbox) - min(v.y for v in bbox)) * \
             (max(v.z for v in bbox) - min(v.z for v in bbox))
    
    head_zone_z = model_top_z - model_height * 0.25
    
    if center_z >= head_zone_z and volume < model_height * 0.1:
        return 'crown'  # 头部区域的小体积物体
    return 'body'
```

## 常见陷阱

| 陷阱 | 原因 | 解决 |
|------|------|------|
| Object001被当作body | 名称不含任何关键词 | 添加'object001'到CROWN_KEYWORDS |
| 武器被误判为发冠 | 武器在头部区域（如头簪） | 结合体积判断：大体积=武器 |
| 多body mesh | 角色分件（上衣/裙子/靴子） | 全部归入body_parts统一蒙皮 |
| 名称大小写不一致 | 3dsMax导出保留原始大小写 | 统一用`.lower()`比较 |
