# 多部件网格合并与分离策略

## 问题场景

FBX模型可能由多个分离mesh组成（上官婉儿有6个mesh：body、发冠、2个武器部件、面部、装饰）。需要决定哪些合并（统一蒙皮）、哪些保持独立（单独归位）。

## 核心原理

### 合并条件
- 属于同一骨骼影响区域的body部件
- 需要统一权重分配的主体网格
- 合并后减少draw call提升渲染性能

### 保持分离条件
- 需要独立运动的部件（发冠跟随头部、武器跟随手部）
- 不同材质/shader的部件
- 需要独立parent到不同骨骼的部件

## 代码示例

```python
import bpy

def merge_body_parts(body_parts):
    """合并主体部件为单一mesh（可选）"""
    if len(body_parts) <= 1:
        return body_parts[0] if body_parts else None
    
    bpy.ops.object.select_all(action='DESELECT')
    for obj in body_parts:
        obj.select_set(True)
    bpy.context.view_layer.objects.active = body_parts[0]
    bpy.ops.object.join()  # 合并
    
    merged = bpy.context.active_object
    merged.name = "BodyMerged"
    return merged

def keep_separate(mesh_objects, classification):
```

## 常见陷阱

| 陷阱 | 原因 | 解决 |
|------|------|------|
| join后材质丢失 | 材质slot未正确合并 | join前确认材质兼容 |
| join后UV错乱 | 不同mesh的UV channel冲突 | 检查UV layer数量一致 |
| 分离部件间有缝隙 | 原始建模就是分离的 | 不合并，用相同材质遮盖 |
| parent后部件消失 | matrix_parent_inverse未正确设置 | 设置inverse为单位矩阵或正确逆矩阵 |
