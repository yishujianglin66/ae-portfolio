# 法线处理与面朝向

## 问题场景

FBX导入后部分面片渲染为黑色或透明，viewport中可见"破面"。原因是法线方向不一致（3dsMax导出时部分面法线翻转）。三渲二渲染中法线影响Toon shader的明暗分界。

## 核心原理

### 法线方向规则
- Blender正面：法线朝外（朝向摄像机可见）
- 背面剔除：`material.use_backface_culling = True` 时背面不渲染
- 双面材质：`material.blend_method = 'CLIP'` + 关闭backface culling

### 法线修复方法

```python
import bpy
import bmesh

def fix_normals(obj):
    """重新计算法线方向（全部朝外）"""
    bpy.ops.object.select_all(action='DESELECT')
    obj.select_set(True)
    bpy.context.view_layer.objects.active = obj
    bpy.ops.object.mode_set(mode='EDIT')
    bpy.ops.mesh.select_all(action='SELECT')
    bpy.ops.mesh.normals_make_consistent(inside=False)  # 朝外
    bpy.ops.object.mode_set(mode='OBJECT')

def check_inverted_faces(obj, camera_pos):
    """检测背对摄像机的面（可能是翻转面）"""
    from mathutils import Vector
    mw = obj.matrix_world
    cam_dir = (camera_pos - mw.translation).normalized()
    
    inverted = 0
    for poly in obj.data.polygons:
        world_normal = (mw.to_3x3() @ poly.normal).normalized()
        if world_normal.dot(cam_dir) < 0:  # 法线背对摄像机
            inverted += 1
    
    total = len(obj.data.polygons)
    print(f"  {obj.name}: {inverted}/{total} faces inverted ({inverted/total*100:.1f}%)")
    return inverted / total if total > 0 else 0
```

## 常见陷阱

| 陷阱 | 原因 | 解决 |
|------|------|------|
| 部分面黑色 | 法线翻转+backface culling | `normals_make_consistent()` |
| 头发/裙子透明 | 薄壳模型需要双面渲染 | 关闭backface culling或用Solidify |
| Toon shader明暗异常 | 法线不平滑 | `shade_smooth()` + auto smooth |
| 自定义法线数据丢失 | FBX导入覆盖了原始法线 | 导入时设`use_custom_normals=True` |
