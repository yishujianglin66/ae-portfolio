# UV数据检查与处理

## 问题场景

FBX导入后UV坐标可能缺失、翻转或缩放异常。虽然三渲二风格主要使用纯色Toon shader不依赖UV贴图，但LineArt修改器和某些程序化纹理仍需有效UV。

## 核心原理

### UV Layer结构

```python
import bpy

def check_uv_data(obj):
    """检查mesh的UV数据状态"""
    mesh = obj.data
    uv_layers = mesh.uv_layers
    
    print(f"{obj.name}: {len(uv_layers)} UV layers")
    for i, uv_layer in enumerate(uv_layers):
        print(f"  Layer {i}: '{uv_layer.name}', active={uv_layer.active}")
        # 检查UV范围
        uvs = [uv.uv for uv in uv_layer.data]
        if uvs:
            u_min = min(uv.x for uv in uvs)
            u_max = max(uv.x for uv in uvs)
            v_min = min(uv.y for uv in uvs)
            v_max = max(uv.y for uv in uvs)
            print(f"    Range: U[{u_min:.2f}, {u_max:.2f}] V[{v_min:.2f}, {v_max:.2f}]")
            
            # 检查是否全部为0（UV缺失）
            if u_max - u_min < 0.001 and v_max - v_min < 0.001:
                print(f"    [WARN] UV数据无效（全为常数）")
```

### 3dsMax UV导出特点

- 3dsMax的UV V轴方向与Blender相反（V翻转）
- 多个UV channel可能导出为多个uv_layer
- 未展开UV的mesh导出后UV全为(0,0)

## 代码示例

### 自动创建UV（如果缺失）

```python
def ensure_uv(obj):
    """确保mesh有有效UV layer"""
    mesh = obj.data
    if not mesh.uv_layers:
        mesh.uv_layers.new(name="UVMap")
        # 自动展开
        bpy.ops.object.select_all(action='DESELECT')
        obj.select_set(True)
        bpy.context.view_layer.objects.active = obj
        bpy.ops.object.mode_set(mode='EDIT')
        bpy.ops.mesh.select_all(action='SELECT')
        bpy.ops.uv.smart_project(angle_limit=1.15)
        bpy.ops.object.mode_set(mode='OBJECT')
```

## 常见陷阱

| 陷阱 | 原因 | 解决 |
|------|------|------|
| UV V轴翻转 | 3dsMax V=0在顶部 | `uv.y = 1.0 - uv.y` |
| 无UV layer | 3dsMax未展开UV | `smart_project()`自动展开 |
| 多UV channel冲突 | FBX导出多个channel | 仅保留active layer |
| LineArt需要UV | 某些边缘检测依赖UV | 确保至少一个有效UV layer |

## 关联代码

- 本项目三渲二使用纯色Toon，UV非关键路径
- LineArt修改器（`cel_shading.py` L1250+）不依赖UV，使用几何边缘检测
