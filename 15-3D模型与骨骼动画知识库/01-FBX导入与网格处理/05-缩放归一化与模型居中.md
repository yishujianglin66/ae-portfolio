# 缩放归一化与模型居中

## 问题场景

3dsMax使用厘米为单位，Blender使用米。FBX导入后模型可能高达170单位（170cm人形），导致相机/灯光/骨骼长度全部不匹配。需要将模型归一化到标准高度（本项目目标6单位），并将几何中心对齐世界原点。

## 核心原理

### 单位换算链

```
3dsMax (厘米) → FBX (UnitScaleFactor) → Blender (米)
例: 170cm角色 → FBX UnitScale=1.0 → Blender中170单位
需要缩放: 6.0 / 170 ≈ 0.0353
```

### 归一化公式

```python
target_height = 6.0  # 目标高度（Blender单位）
current_height = bounds_size[2]  # 当前Z方向高度
scale_factor = target_height / current_height

# 应用缩放到所有mesh
for obj in mesh_objects:
    obj.scale *= scale_factor
bpy.context.view_layer.update()

# 应用变换（使scale回归1.0）
bpy.ops.object.select_all(action='SELECT')
bpy.ops.object.transform_apply(scale=True)
```

### 居中策略

```python
# 计算所有mesh的整体bounding box
all_coords = []
for obj in mesh_objects:
    for v in obj.bound_box:
        all_coords.append(obj.matrix_world @ Vector(v))

min_co = Vector((min(c.x for c in all_coords),
                 min(c.y for c in all_coords),
                 min(c.z for c in all_coords)))
max_co = Vector((max(c.x for c in all_coords),
                 max(c.y for c in all_coords),
                 max(c.z for c in all_coords)))

bounds_center = (min_co + max_co) / 2
bounds_size = max_co - min_co

# 居中：XY居中，Z保持底部在地面
offset = Vector((-bounds_center.x, -bounds_center.y, -min_co.z))
for obj in mesh_objects:
    obj.location += offset
```

## 代码示例

### 完整的归一化流程（cel_shading.py实际代码）

```python
import bpy
from mathutils import Vector

def normalize_model(mesh_objects, target_height=6.0):
    """缩放归一化 + 居中"""
    # 1. 计算当前bounds
    all_coords = []
    for obj in mesh_objects:
        for v in obj.bound_box:
            all_coords.append(obj.matrix_world @ Vector(v))
    
    min_co = Vector((min(c[0] for c in all_coords),
                     min(c[1] for c in all_coords),
                     min(c[2] for c in all_coords)))
    max_co = Vector((max(c[0] for c in all_coords),
                     max(c[1] for c in all_coords),
                     max(c[2] for c in all_coords)))
    
    size = max_co - min_co
    current_h = size.z if size.z > 0 else 1.0
    
    # 2. 缩放
    scale = target_height / current_h
    for obj in mesh_objects:
        obj.scale *= scale
    bpy.context.view_layer.update()
    
    # 3. 重新计算bounds（缩放后）
    all_coords = []
    for obj in mesh_objects:
        for v in obj.bound_box:
            all_coords.append(obj.matrix_world @ Vector(v))
    
    min_co = Vector((min(c[0] for c in all_coords),
                     min(c[1] for c in all_coords),
                     min(c[2] for c in all_coords)))
    max_co = Vector((max(c[0] for c in all_coords),
                     max(c[1] for c in all_coords),
                     max(c[2] for c in all_coords)))
    
    center = (min_co + max_co) / 2
    
    # 4. 居中（XY居中，Z底部归零）
    offset = Vector((-center.x, -center.y, -min_co.z))
    for obj in mesh_objects:
        obj.location += offset
    bpy.context.view_layer.update()
    
    return {
        'scale': scale,
        'bounds_center': Vector((0, 0, target_height/2)),
        'bounds_size': Vector((size.x*scale, size.y*scale, target_height)),
    }
```

## 常见陷阱

| 陷阱 | 原因 | 解决 |
|------|------|------|
| bound_box不更新 | 修改scale后未update | 每次变换后`view_layer.update()` |
| 多部件偏移 | 仅居中主mesh忘记附件 | 对所有mesh_objects统一操作 |
| 缩放后骨骼不匹配 | 先创建骨骼后缩放 | 归一化必须在骨骼创建之前 |
| Z底部非零 | 脚底不在z=0 | 用`-min_co.z`而非`-center.z` |

## 版本兼容

- `bpy.ops.object.transform_apply()` 在Blender 5.x中行为不变
- `bound_box` 返回局部空间8个角点，需乘 `matrix_world` 转世界坐标
