# 静态网格vs骨骼网格导入

## 问题场景

FBX文件分为两类：自带Armature+Action的"骨骼网格"和仅含Mesh的"静态网格"。上官婉儿模型属于后者（3dsMax导出时未包含骨骼），需要程序化创建骨骼系统。导入前必须判断类型以选择正确的处理策略。

## 核心原理

### 骨骼网格（Skeletal Mesh）
```
FBX
├── Armature (Model: LimbNode)
│   ├── Bone: Hips
│   │   ├── Bone: Spine
│   │   └── Bone: UpperLeg_L
│   └── ...
├── Mesh (已绑定权重)
│   └── vertex_groups: [Hips, Spine, ...]
└── AnimationStack
    └── AnimationLayer (关键帧数据)
```

### 静态网格（Static Mesh）
```
FBX
├── Model: Mesh (纯几何体)
│   ├── Object001 (发冠)
│   ├── 5133_ShuSheng_Weapon_High (武器)
│   └── body_main (主体)
└── Material/Texture (材质)
# 无Armature、无Animation、无vertex_groups
```

### 判断逻辑

```python
import bpy

bpy.ops.import_scene.fbx(filepath="model.fbx")

# 检查是否有Armature
armatures = [o for o in bpy.data.objects if o.type == 'ARMATURE']
has_skeleton = len(armatures) > 0

# 检查是否有动画
has_animation = any(o.animation_data and o.animation_data.action 
                    for o in bpy.data.objects)

# 检查网格是否有vertex_groups
meshes = [o for o in bpy.data.objects if o.type == 'MESH']
has_weights = any(len(m.vertex_groups) > 0 for m in meshes)

print(f"Skeleton: {has_skeleton}, Animation: {has_animation}, Weights: {has_weights}")

if not has_skeleton:
    print("→ 静态网格，需要程序化骨骼创建")
```

## 代码示例

### 完整的导入+类型判断+策略分发

```python
import bpy

def import_and_classify(fbx_path):
    """导入FBX并分类处理策略"""
    # 清空场景
    bpy.ops.object.select_all(action='SELECT')
    bpy.ops.object.delete()
    
    # 导入
    bpy.ops.import_scene.fbx(
        filepath=fbx_path,
        use_anim=False,           # 静态网格不需要动画
        ignore_leaf_bones=True,   # 忽略叶骨骼（3dsMax兼容）
        automatic_bone_orientation=True,
    )
    
    meshes = [o for o in bpy.data.objects if o.type == 'MESH']
    armatures = [o for o in bpy.data.objects if o.type == 'ARMATURE']
    
    if armatures:
        return 'skeletal', meshes, armatures[0]
    else:
        return 'static', meshes, None

strategy, meshes, armature = import_and_classify("shangguan_er.fbx")

if strategy == 'static':
```

## 常见陷阱

| 陷阱 | 表现 | 解决 |
|------|------|------|
| 误判为骨骼网格 | FBX有Pose节点但无Armature | 检查type=='ARMATURE'而非Pose |
| 多Armature | 导入后存在多个骨架 | 取顶点数最多的或按名称匹配 |
| 网格已parent到空物体 | 3dsMax的Point helper导出为Empty | 检查parent类型 |
| use_anim=True导致卡顿 | 大文件动画数据解析慢 | 静态网格设use_anim=False |

## 版本兼容

- Blender 5.1.0：`bpy.ops.import_scene.fbx()` 参数与4.x一致
- `ignore_leaf_bones=True` 对3dsMax导出特别重要（避免多余骨骼）
- Blender 5.x的FBX导入器性能改善，大文件(>100MB)导入速度提升
