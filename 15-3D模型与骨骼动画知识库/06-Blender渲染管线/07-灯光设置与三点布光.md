# 灯光设置与三点布光

## 问题场景

三渲二渲染需要简洁的灯光设置，避免复杂阴影破坏赛璐璐风格。通常使用三点布光（主光+补光+轮廓光）或简化的单光源。

## 核心原理

### 三点布光

```python
import bpy
import math

def setup_three_point_lighting(target_pos, intensity=5.0):
    """三点布光设置"""
    
    # 1. 主光（Key Light）- 最强，45°侧上方
    key = bpy.data.lights.new("KeyLight", 'AREA')
    key.energy = intensity * 100
    key.size = 3.0
    key.color = (1.0, 0.95, 0.9)  # 暖白
    key_obj = bpy.data.objects.new("KeyLight", key)
    bpy.context.collection.objects.link(key_obj)
    key_obj.location = (
        target_pos[0] + 5,
        target_pos[1] - 3,
        target_pos[2] + 5
    )
    # 指向目标
    key_obj.rotation_euler = (math.radians(45), 0, math.radians(45))
    
    # 2. 补光（Fill Light）- 较弱，对侧
    fill = bpy.data.lights.new("FillLight", 'AREA')
    fill.energy = intensity * 30
    fill.size = 5.0
    fill.color = (0.9, 0.95, 1.0)  # 冷白
    fill_obj = bpy.data.objects.new("FillLight", fill)
    bpy.context.collection.objects.link(fill_obj)
    fill_obj.location = (
        target_pos[0] - 4,
        target_pos[1] - 2,
        target_pos[2] + 2
    )
    
    # 3. 轮廓光（Rim Light）- 背后上方
    rim = bpy.data.lights.new("RimLight", 'AREA')
    rim.energy = intensity * 50
    rim.size = 2.0
    rim.color = (1.0, 1.0, 1.0)
    rim_obj = bpy.data.objects.new("RimLight", rim)
    bpy.context.collection.objects.link(rim_obj)
    rim_obj.location = (
        target_pos[0],
        target_pos[1] + 5,
        target_pos[2] + 6
    )
    
    return key_obj, fill_obj, rim_obj
```

### 简化单光源（三渲二推荐）

```python
def setup_simple_light(target_pos):
    """简化灯光（适合赛璐璐风格）"""
    # 单个大面积Area Light
    light = bpy.data.lights.new("MainLight", 'AREA')
    light.energy = 300
    light.size = 10.0  # 大面积 = 柔和阴影
    light.color = (1.0, 1.0, 1.0)
    
    light_obj = bpy.data.objects.new("MainLight", light)
    bpy.context.collection.objects.link(light_obj)
    light_obj.location = (
        target_pos[0] + 3,
        target_pos[1] - 5,
        target_pos[2] + 8
    )
    
    # 环境光（World背景）
    world = bpy.context.scene.world
    world.use_nodes = True
    bg = world.node_tree.nodes['Background']
    bg.inputs['Color'].default_value = (0.5, 0.5, 0.5, 1.0)
    bg.inputs['Strength'].default_value = 0.3
    
    return light_obj
```

### 灯光与Toon Shader的配合

```python
# Toon BSDF的明暗分界由灯光方向决定
# 单光源 → 清晰的明暗分界（赛璐璐效果）
# 多光源 → 多个分界（可能混乱）

# 推荐：
# - 主光决定明暗分界
# - 环境光提供基础亮度（避免纯黑阴影）
# - 避免多个强光源
```
