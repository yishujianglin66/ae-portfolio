# 骨骼创建完整工作流（本项目实战）

## 问题场景

综合前述所有知识，描述本项目中为上官婉儿FBX模型程序化创建骨骼的完整工作流，包括决策过程、遇到的问题和最终方案。

## 完整工作流

### Step 1: 模型分析

```python
# 导入后分析模型尺寸
import bpy
from mathutils import Vector

meshes = [o for o in bpy.data.objects if o.type == 'MESH']
all_coords = []
for obj in meshes:
    for v in obj.bound_box:
        all_coords.append(obj.matrix_world @ Vector(v))

z_min = min(c.z for c in all_coords)
z_max = max(c.z for c in all_coords)
model_height = z_max - z_min
model_center_z = (z_min + z_max) / 2

print(f"Model height: {model_height:.2f}")
print(f"Z range: [{z_min:.2f}, {z_max:.2f}]")
# 上官婉儿: height=6.0, Z range=[-6.2, -0.2]
```

### Step 2: 骨骼位置计算

```python
# 基于模型高度的百分比定位
h = model_height  # 6.0
base_z = z_min    # -6.2

bone_positions = {
    'Root':      (0, 0, base_z),
    'Hips':      (0, 0, base_z + h * 0.50),   # 50%
    'Spine':     (0, 0, base_z + h * 0.60),   # 60%
    'Chest':     (0, 0, base_z + h * 0.70),   # 70%
    'Neck':      (0, 0, base_z + h * 0.80),   # 80%
    'Head':      (0, 0, base_z + h * 0.88),   # 88%
    
    # 手臂（A-pose，向下30°）
    'UpperArm_L': (-h*0.12, 0, base_z + h*0.72),
    'ForeArm_L':  (-h*0.20, 0, base_z + h*0.62),
    'Hand_L':     (-h*0.26, 0, base_z + h*0.55),
    # 右侧镜像X
    'UpperArm_R': (h*0.12, 0, base_z + h*0.72),
    'ForeArm_R':  (h*0.20, 0, base_z + h*0.62),
    'Hand_R':     (h*0.26, 0, base_z + h*0.55),
    
    # 腿
    'UpperLeg_L': (-h*0.06, 0, base_z + h*0.48),
    'LowerLeg_L': (-h*0.06, 0, base_z + h*0.25),
    'Foot_L':     (-h*0.06, 0, base_z + h*0.02),
    'UpperLeg_R': (h*0.06, 0, base_z + h*0.48),
    'LowerLeg_R': (h*0.06, 0, base_z + h*0.25),
    'Foot_R':     (h*0.06, 0, base_z + h*0.02),
}
```

### Step 3: 创建Armature + 骨骼

```python
# 创建armature
arm_data = bpy.data.armatures.new("Armature")
arm_obj = bpy.data.objects.new("Armature", arm_data)
bpy.context.collection.objects.link(arm_obj)
bpy.context.view_layer.objects.active = arm_obj

bpy.ops.object.mode_set(mode='EDIT')

# 骨骼定义（name, head, tail, parent）
bone_defs = [
    ('Root', bone_positions['Root'], (0,0,base_z+0.3), None),
    ('Hips', bone_positions['Hips'], (0,0,base_z+h*0.53), 'Root'),
    # ... 完整16根骨骼
]

for name, head, tail, parent_name in bone_defs:
    eb = arm_data.edit_bones.new(name)
    eb.head = Vector(head)
    eb.tail = Vector(tail)
    if parent_name:
        eb.parent = arm_data.edit_bones[parent_name]

bpy.ops.object.mode_set(mode='OBJECT')
```

### Step 4: 网格绑定（Parent to Armature）

```python
# 将所有body mesh parent到armature
for obj in body_parts:
    obj.parent = arm_obj
    obj.modifiers.new(name="Armature", type='ARMATURE')
    obj.modifiers["Armature"].object = arm_obj
```

### Step 5: 权重分配

```python
# 方法1：自动权重（简单但不精确）
```

## 决策记录

### 为什么选择程序化骨骼而非导入骨骼？

| 方案 | 优点 | 缺点 | 结论 |
|------|------|------|------|
| 从其他模型导入骨骼 | 精确 | 需要匹配模型 | ❌ 不通用 |
| 程序化创建 | 通用、可参数化 | 位置可能不精确 | ✅ 选择 |
| 使用Mixamo自动绑定 | 高质量 | 需要网络、格式限制 | ❌ 不适合自动化 |

### 为什么保持A-pose而非转换为T-pose？

```
决策过程：
1. 初始尝试：创建T-pose骨骼 → 权重分配后手臂顶点被分到Spine
2. 根因：heat diffusion算法在A-pose网格+T-pose骨骼时失效
3. 第二尝试：旋转网格到T-pose → 破坏原始UV和法线
4. 最终方案：保持A-pose，动画用相机环绕代替骨骼旋转
```

## 常见问题速查

| 问题 | 原因 | 解决 |
|------|------|------|
| 骨骼创建后消失 | tail==head（零长度） | 确保tail≠head |
| 权重分配后网格不动 | 未添加Armature修改器 | 检查modifier |
| 手臂不变形 | 顶点被分到Spine | 用距离反比权重 |
| 发冠位置偏移 | parent到BONE的TAIL | 计算matrix_parent_inverse |
