# 骨骼命名规范与自动镜像

## 问题场景

程序化创建骨骼时，命名不规范会导致：(1)镜像操作失败 (2)权重自动分配时左右混淆 (3)动画重定向时无法匹配。需要建立统一的命名约定。

## 核心原理

### Blender的左右识别规则

Blender通过名称后缀识别左右：
```
支持的格式：
- Bone.L / Bone.R        ← 推荐（点号分隔）
- Bone_L / Bone_R        ← 下划线分隔
- BoneLeft / BoneRight   ← 全拼
- Bone.L.001             ← 带编号（仍识别为左）

不支持：
- BoneLeft / BoneR       ← 不对称缩写
- L_Bone / R_Bone        ← 前缀（Blender不识别）
```

### 自动镜像骨骼

```python
import bpy
from mathutils import Vector

def mirror_bones(armature_obj, source_names):
    """
    将左侧骨骼镜像为右侧
    source_names: ['UpperArm_L', 'ForeArm_L', 'Hand_L']
    """
    bpy.context.view_layer.objects.active = armature_obj
    bpy.ops.object.mode_set(mode='EDIT')
    
    edit_bones = armature_obj.data.edit_bones
    
    for name in source_names:
        src = edit_bones.get(name)
        if not src:
            continue
        
        # 生成镜像名称
        mirror_name = name.replace('_L', '_R').replace('.L', '.R')
        
        # 创建镜像骨骼
        dst = edit_bones.new(mirror_name)
        dst.head = Vector((-src.head.x, src.head.y, src.head.z))  # X取反
        dst.tail = Vector((-src.tail.x, src.tail.y, src.tail.z))
        dst.roll = -src.roll  # Roll取反
        
        # 镜像parent
        if src.parent:
            parent_mirror = src.parent.name.replace('_L', '_R').replace('.L', '.R')
            dst.parent = edit_bones.get(parent_mirror)
    
    bpy.ops.object.mode_set(mode='OBJECT')
```

### 使用Blender内置镜像

```python
def blender_symmetrize(armature_obj):
    """使用Blender的Symmetrize功能（需要.L/.R命名）"""
    bpy.context.view_layer.objects.active = armature_obj
    bpy.ops.object.mode_set(mode='EDIT')
    
    # 选择所有左侧骨骼
    for eb in armature_obj.data.edit_bones:
        eb.select = eb.name.endswith('_L') or eb.name.endswith('.L')
    
    # 执行镜像（从负X到正X）
    bpy.ops.armature.symmetrize(direction='NEGATIVE_X')
    
    bpy.ops.object.mode_set(mode='OBJECT')
```

## 常见陷阱

### 陷阱1：使用下划线但Blender期望点号
```python
# Blender的symmetrize要求.L/.R格式
# 如果用_L/_R，symmetrize不工作
# 解决：使用自定义镜像函数（如上）
```

### 陷阱2：中文骨骼名
```python
# 错误：中文名称在某些操作中会出问题
eb = edit_bones.new("左手")  # ← 不推荐

# 正确：英文命名 + 中文注释
eb = edit_bones.new("Hand_L")  # 左手
```
