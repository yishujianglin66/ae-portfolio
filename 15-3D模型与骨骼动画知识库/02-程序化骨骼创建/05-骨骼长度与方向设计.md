# 骨骼长度与方向设计

## 问题场景

骨骼长度影响：(1)发冠parent时的TAIL偏移量 (2)权重分配的距离计算 (3)动画旋转时的变形范围。过长或过短都会导致视觉异常。

## 核心原理

### 长度设计原则

```python
# 基于模型高度(6.0)的推荐骨骼长度
BONE_LENGTHS = {
    'Root': 0.3,       # 短，仅作参考点
    'Hips': 0.3,       # 骨盆区域
    'Spine': 0.6,      # 脊柱中段
    'Chest': 0.6,      # 胸腔
    'Neck': 0.3,       # 颈部（短）
    'Head': 0.9,       # 头部（长！发冠parent需要）
    'UpperArm': 0.78,  # 上臂
    'ForeArm': 0.72,   # 前臂
    'Hand': 0.42,      # 手掌
    'UpperLeg': 1.5,   # 大腿
    'LowerLeg': 1.38,  # 小腿
    'Foot': 0.48,      # 脚掌
}

# 关键：Head骨骼长度决定了发冠parent的TAIL偏移
# 如果Head太短(如0.3)，发冠会下沉到头发内部
# 推荐：Head length ≥ 模型高度 × 0.15
```

### 方向向量与变形轴

```python
# 骨骼的Y轴 = head→tail方向 = 主要变形轴
# 旋转骨骼时，子骨骼绕父骨骼的tail点旋转

# 脊柱：Y轴朝上 (0,0,1)
# 手臂R：Y轴朝右下 (-cos30°, 0, -sin30°)
# 腿部：Y轴朝下 (0,0,-1)

# 验证方向
bone = arm.data.bones['Head']
direction = (bone.tail - bone.head).normalized()
print(f"Head方向: {direction}")  # 应接近 (0, 0, 1)
```

## 常见陷阱

| 陷阱 | 后果 | 解决 |
|------|------|------|
| Head骨骼太短 | 发冠下沉到头发内 | Head length ≥ 0.9 (6单位模型) |
| 所有骨骼等长 | 权重距离计算失真 | 按解剖比例设计 |
| 方向不一致 | 旋转动画方向错误 | 统一Y轴为骨骼延伸方向 |
| Root骨骼过长 | 整体缩放异常 | Root仅作参考，长度0.3即可 |
