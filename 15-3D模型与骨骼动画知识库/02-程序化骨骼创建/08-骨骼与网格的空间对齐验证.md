# 骨骼与网格的空间对齐验证

## 问题场景

程序化创建的骨骼位置可能与实际网格几何不匹配（如Hand_R骨骼在(1.2, 0, 2.5)但网格手部实际在(0.8, -0.3, 2.7)）。这导致权重分配错误、附件归位偏移。需要系统性验证骨骼-网格对齐度。

## 核心原理

### 对齐验证方法

```python
import bpy
from mathutils import Vector
import numpy as np

def validate_bone_mesh_alignment(armature_obj, mesh_obj, tolerance=0.5):
    """
    验证骨骼位置是否在对应网格区域内
    tolerance: 允许的最大偏差（Blender单位）
    """
    bpy.context.view_layer.update()
    
    # 获取网格世界坐标顶点
    world_matrix = mesh_obj.matrix_world
    vertices = [world_matrix @ v.co for v in mesh_obj.data.vertices]
    
    results = []
    for bone in armature_obj.data.bones:
        # 骨骼head的世界坐标
        bone_head_world = armature_obj.matrix_world @ bone.head_local
        bone_tail_world = armature_obj.matrix_world @ bone.tail_local
        bone_center = (bone_head_world + bone_tail_world) / 2
        
        # 找最近的网格顶点
        distances = [(v - bone_center).length for v in vertices]
        min_dist = min(distances)
        nearest_idx = distances.index(min_dist)
        nearest_v = vertices[nearest_idx]
        
        status = "OK" if min_dist < tolerance else "MISALIGNED"
        results.append({
            'bone': bone.name,
            'bone_pos': bone_center.to_tuple(),
            'nearest_vertex': nearest_v.to_tuple(),
            'distance': min_dist,
            'status': status
        })
        
        if status == "MISALIGNED":
            print(f"  [WARN] {bone.name}: dist={min_dist:.3f} > {tolerance}")
    
    return results
```

### 基于网格统计的骨骼位置校正

```python
def correct_bone_positions_from_mesh(armature_obj, mesh_obj):
    """
    用网格顶点聚类校正骨骼位置
    适用于：FBX导入后骨骼位置不准确的情况
    """
    import bmesh
    
    # 获取世界坐标顶点
    world_matrix = mesh_obj.matrix_world
    verts = [world_matrix @ v.co for v in mesh_obj.data.vertices]
    
    # 按Z高度分层
    z_values = sorted(set(round(v.z, 1) for v in verts))
    z_min, z_max = min(z_values), max(z_values)
    height = z_max - z_min
    
    # 定义骨骼应该在的高度百分比
    bone_heights = {
        'Hips': 0.50,
        'Spine': 0.60,
        'Chest': 0.70,
        'Neck': 0.80,
        'Head': 0.88,
    }
    
    # 对每层，计算X/Y中心
    corrections = {}
    for bone_name, pct in bone_heights.items():
        target_z = z_min + height * pct
        # 找该高度附近的顶点
        layer_verts = [v for v in verts if abs(v.z - target_z) < height * 0.05]
        if layer_verts:
            center_x = sum(v.x for v in layer_verts) / len(layer_verts)
            center_y = sum(v.y for v in layer_verts) / len(layer_verts)
            corrections[bone_name] = Vector((center_x, center_y, target_z))
    
    return corrections
```

### 上官婉儿模型的对齐问题

```
实际发现的问题：
- Hand_R骨骼位置: (1.2, 0.0, 2.5)  ← 基于百分比计算
- 网格右手实际位置: (-0.6, 0.7, -2.72)  ← 顶点检测
- 偏差: 约4个单位！

根因：
1. 骨骼位置用模型高度百分比计算（假设标准人形比例）
2. 上官婉儿模型比例非标准（宽袍大袖，手臂位置偏低）
3. A-pose手臂下垂角度大于假设的30°

解决方案：
→ 用网格顶点检测代替骨骼位置（v12策略）
→ 找主体mesh最左侧5%顶点 = 右手区域
```

## 常见陷阱

### 陷阱1：使用局部坐标而非世界坐标
```python
# 错误：bone.head_local是armature局部空间
bone_pos = bone.head_local  # ← 如果armature有偏移则错误

# 正确：转换为世界坐标
bone_pos_world = armature_obj.matrix_world @ bone.head_local
```

### 陷阱2：未更新view_layer
```python
# 错误：修改后未更新，matrix_world是旧值
obj.location = new_pos
dist = (obj.matrix_world.translation - target).length  # ← 旧值！

# 正确：
obj.location = new_pos
bpy.context.view_layer.update()
dist = (obj.matrix_world.translation - target).length
```
