# 蒙皮工作流总结与决策树

## 问题场景

面对一个新的FBX模型，如何快速决定蒙皮策略？本文提供决策树和完整工作流，避免重复试错。

## 决策树

```
新FBX模型导入
│
├─ 有Armature+权重？
│  ├─ YES → 直接使用（验证权重质量）
│  └─ NO ↓
│
├─ 模型用途？
│  ├─ 静态渲染（无动画）→ 不需要蒙皮！只需parent附件
│  ├─ 简单动画（相机环绕）→ 不需要蒙皮
│  └─ 骨骼动画（角色运动）↓
│
├─ 模型拓扑？
│  ├─ 标准人形（T/A-pose）→ ARMATURE_AUTO
│  ├─ 非标准（宽袍/翅膀/尾巴）→ IDW
│  └─ 机械/硬表面 → 刚体parent（不用权重）
│
├─ ARMATURE_AUTO结果？
│  ├─ 良好 → 微调边界
│  └─ 失败（空骨骼/全身联动）→ IDW top_k=3
│
└─ IDW结果？
   ├─ 良好 → 完成
   └─ 关节断裂 → 增加top_k或手动修正
```

## 完整工作流

```python
import bpy

def full_skinning_pipeline(mesh_objects, armature_obj, model_type='humanoid'):
    """完整蒙皮管线"""
    
    # Step 1: 分类部件
    body_parts = []
    rigid_parts = []  # 刚体（武器/发冠）
    
    for obj in mesh_objects:
        if is_rigid_part(obj):  # 武器/发冠
            rigid_parts.append(obj)
        else:
            body_parts.append(obj)
    
    # Step 2: Body蒙皮
    if model_type == 'standard_humanoid':
        # 尝试自动权重
        try_auto_weight(body_parts, armature_obj)
        if not validate_auto_weight(body_parts, armature_obj):
            # 失败则用IDW
            apply_idw_weights(body_parts, armature_obj, top_k=3)
    else:
        # 非标准模型直接用IDW
        apply_idw_weights(body_parts, armature_obj, top_k=3)
    
    # Step 3: 刚体部件parent
    for obj in rigid_parts:
        target_bone = find_nearest_bone(obj, armature_obj)
        parent_to_bone(obj, armature_obj, target_bone)
    
    # Step 4: 验证
    for obj in body_parts:
        issues = validate_weights(obj, armature_obj)
        if issues:
            print(f"[WARN] {obj.name}: {issues}")
    
    # Step 5: 测试变形
    test_deformation(body_parts[0], armature_obj, 'Hand_R')

def is_rigid_part(obj):
    """判断是否为刚体部件"""
    name_lower = obj.name.lower()
    rigid_keywords = ['weapon', 'object001', 'crown', 'hat']
    return any(kw in name_lower for kw in rigid_keywords)
```

## 本项目最终方案

```
上官婉儿（v12最终方案）：
- 放弃骨骼动画（宽袍模型蒙皮质量不够）
- 保持A-pose静态渲染
- 动画 = 相机360°环绕 + 微幅摆动
- 发冠 = parent到Head TAIL
- 扇子 = 网格顶点检测手部 + rotate-first归位 + parent

结论：三渲二渲染不一定需要完美蒙皮
      选择最简单的可行方案
```
