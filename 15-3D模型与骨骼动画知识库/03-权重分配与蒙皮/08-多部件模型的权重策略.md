# 多部件模型的权重策略

## 问题场景

上官婉儿模型由6个独立mesh组成（body、发冠、2个武器部件、面部、装饰）。不同部件需要不同的权重策略：body需要完整蒙皮，发冠只需跟随Head，武器跟随Hand。

## 核心原理

### 部件分类与策略

```python
PART_WEIGHT_STRATEGY = {
    'body': 'full_skin',       # 完整IDW权重
    'face': 'full_skin',       # 跟随body一起蒙皮
    'crown': 'single_bone',    # 100%权重给Head
    'weapon_handle': 'parent', # 不用权重，直接parent到Hand
```

### 单骨骼绑定（发冠/头饰）

```python
def bind_to_single_bone(mesh_obj, armature_obj, bone_name):
    """将mesh 100%绑定到单根骨骼"""
    # 创建vertex_group
    vg = mesh_obj.vertex_groups.get(bone_name)
    if not vg:
        vg = mesh_obj.vertex_groups.new(name=bone_name)
    
    # 所有顶点权重=1.0
    all_verts = list(range(len(mesh_obj.data.vertices)))
    vg.add(all_verts, 1.0, 'REPLACE')
    
    # 添加Armature modifier
    mesh_obj.parent = armature_obj
    mod = mesh_obj.modifiers.new("Armature", 'ARMATURE')
    mod.object = armature_obj
```

## 本项目的部件处理

```
上官婉儿6个mesh的处理：
1. body_main (主体) → IDW top_k=3 完整蒙皮
2. Object001 (发冠) → parent到Head TAIL（不用权重）
3. 5133_Weapon_High (扇柄) → parent到Hand_R区域
4. 5133_Weapon_High002 (扇面) → parent到扇柄
5. face (面部) → 与body一起蒙皮
6. 装饰件 → 跟随最近骨骼

关键决策：
- 发冠不用权重而用parent → 避免权重计算误差
- 武器不用权重而用parent → 保持刚体（不变形）
```

## 常见陷阱

### 陷阱1：对刚体部件使用权重
```python
# 错误：武器用权重 → 旋转时武器弯曲变形
# 正确：武器用parent（刚体跟随）
```

### 陷阱2：多mesh的vertex_group冲突
```python
# 每个mesh有独立的vertex_groups
# 合并mesh时，同名group会自动合并
# 不同名group会保留 → 可能导致权重混乱
```
