# 常见蒙皮失败原因与修复

## 问题场景

蒙皮（Skinning）失败的表现形式多样：网格不动、局部塌陷、关节断裂、全身联动等。本文汇总常见失败模式及其根因和修复方法。

## 失败模式分类

### 1. 网格完全不动

| 原因 | 诊断方法 | 修复 |
|------|----------|------|
| 无Armature Modifier | `obj.modifiers`为空 | 添加modifier |
| Modifier的object未设置 | `mod.object is None` | 设置armature引用 |
| 未parent到armature | `obj.parent != armature` | `obj.parent = armature` |
| vertex_groups为空 | `len(obj.vertex_groups)==0` | 重新分配权重 |
| 骨骼名≠组名 | 名称不匹配 | 统一命名 |

```python
def diagnose_no_deformation(mesh_obj, armature_obj):
    """诊断网格不变形的原因"""
    checks = []
    
    # 1. Parent关系
    if mesh_obj.parent != armature_obj:
        checks.append("FAIL: mesh未parent到armature")
    else:
        checks.append("OK: parent关系正确")
    
    # 2. Armature Modifier
    arm_mods = [m for m in mesh_obj.modifiers if m.type == 'ARMATURE']
    if not arm_mods:
        checks.append("FAIL: 无Armature Modifier")
    elif arm_mods[0].object != armature_obj:
        checks.append("FAIL: Modifier指向错误的armature")
    else:
        checks.append("OK: Armature Modifier正确")
    
    # 3. Vertex Groups
    if len(mesh_obj.vertex_groups) == 0:
        checks.append("FAIL: 无vertex_groups")
    else:
        checks.append(f"OK: {len(mesh_obj.vertex_groups)} vertex_groups")
    
    # 4. 权重数据
    has_weights = any(len(v.groups) > 0 for v in mesh_obj.data.vertices)
    if not has_weights:
        checks.append("FAIL: 所有顶点权重为0")
    else:
        checks.append("OK: 存在非零权重")
    
    # 5. 名称匹配
    bone_names = set(b.name for b in armature_obj.data.bones)
    group_names = set(vg.name for vg in mesh_obj.vertex_groups)
    matched = bone_names & group_names
    if not matched:
        checks.append(f"FAIL: 骨骼名与组名无交集! bones={bone_names}, groups={group_names}")
    else:
        checks.append(f"OK: {len(matched)}个名称匹配")
    
    return checks
```

### 2. 局部塌陷/糖果纸效应

```
原因：Linear Blend Skinning在多骨骼影响区域的体积损失
表现：关节旋转时，关节处网格向内收缩

修复方案：
1. 启用Dual Quaternion: mod.use_deform_preserve_volume = True
2. 减少关节处top_k（从3降为2）
3. 添加Corrective Smooth Modifier
```

```python
def fix_candy_wrapper(mesh_obj):
    """修复糖果纸效应"""
    # 方法1：DQ
    for mod in mesh_obj.modifiers:
        if mod.type == 'ARMATURE':
            mod.use_deform_preserve_volume = True
    
    # 方法2：Corrective Smooth
    smooth = mesh_obj.modifiers.new("CorrectiveSmooth", 'CORRECTIVE_SMOOTH')
    smooth.factor = 0.5
    smooth.iterations = 5
    smooth.use_only_smooth = False
```

### 3. 全身联动（无局部变形）

```
原因：所有顶点权重集中在1-2根骨骼（如Spine）
诊断：检查每根骨骼的顶点数
修复：重新用IDW分配权重，增加top_k
```

### 4. 部件分离（间隙出现）

```
原因：相邻部件的边界顶点权重不连续
修复：
1. 合并部件为单一mesh
2. 或手动设置边界顶点权重为0.5/0.5
```

### 5. 权重镜像错误

```python
def mirror_weights(mesh_obj):
    """将左侧权重镜像到右侧"""
    bpy.context.view_layer.objects.active = mesh_obj
    bpy.ops.object.mode_set(mode='EDIT')
    bpy.ops.mesh.select_all(action='SELECT')
    bpy.ops.object.mode_set(mode='WEIGHT_PAINT')
    
    # 镜像权重（需要.L/.R命名）
    bpy.ops.object.vertex_group_mirror(use_topology=False)
```
