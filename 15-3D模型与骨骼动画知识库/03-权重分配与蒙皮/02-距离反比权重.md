# 距离反比权重（Inverse Distance Weighting）

## 问题场景

ARMATURE_AUTO对宽袍模型失效后，需要自定义权重分配算法。距离反比权重（IDW）基于"顶点离哪根骨骼近就受哪根骨骼影响大"的直觉，对非标准拓扑更鲁棒。

## 核心原理

### IDW公式

```
对每个顶点v，对每根骨骼b：
  d(v, b) = 顶点到骨骼线段的最短距离
  w(v, b) = 1 / d(v, b)^p    (p=2为常用指数)

归一化：
  W(v, b) = w(v, b) / Σ w(v, b_j)

仅保留top-K骨骼（稀疏化）：
  只保留权重最大的K根骨骼，重新归一化
```

### 完整实现

```python
import bpy
from mathutils import Vector
import math

def point_to_segment_distance(point, seg_start, seg_end):
    """计算点到线段的最短距离"""
    seg_vec = seg_end - seg_start
    seg_len_sq = seg_vec.length_squared
    
    if seg_len_sq == 0:
        return (point - seg_start).length
    
    # 投影参数t (0~1)
    t = max(0, min(1, (point - seg_start).dot(seg_vec) / seg_len_sq))
    projection = seg_start + seg_vec * t
    
    return (point - projection).length

def assign_idw_weights(mesh_obj, armature_obj, top_k=3, power=2.0):
    """
    距离反比权重分配
    top_k: 每个顶点最多受K根骨骼影响
    power: 距离衰减指数（越大越局部化）
    """
    bpy.context.view_layer.update()
    
    mesh = mesh_obj.data
    world_matrix = mesh_obj.matrix_world
    arm_world = armature_obj.matrix_world
    
    # 获取骨骼世界坐标（head/tail线段）
    bone_segments = []
    for bone in armature_obj.data.bones:
        head_world = arm_world @ bone.head_local
        tail_world = arm_world @ bone.tail_local
        bone_segments.append((bone.name, head_world, tail_world))
    
    # 确保vertex_groups存在
    for bone_name, _, _ in bone_segments:
        if bone_name not in mesh_obj.vertex_groups:
            mesh_obj.vertex_groups.new(name=bone_name)
    
    # 清除现有权重
    for vg in mesh_obj.vertex_groups:
        vg.remove(list(range(len(mesh.vertices))))
    
    # 对每个顶点计算权重
    for vert in mesh.vertices:
        v_world = world_matrix @ vert.co
        
        # 计算到每根骨骼的距离
        distances = []
        for bone_name, head, tail in bone_segments:
            d = point_to_segment_distance(v_world, head, tail)
            d = max(d, 0.001)  # 避免除零
            distances.append((bone_name, d))
        
        # 按距离排序，取top_k
        distances.sort(key=lambda x: x[1])
        top_bones = distances[:top_k]
        
        # 计算反比权重
        raw_weights = [(name, 1.0 / (d ** power)) for name, d in top_bones]
        total = sum(w for _, w in raw_weights)
        
        # 归一化并赋值
        for bone_name, raw_w in raw_weights:
            normalized_w = raw_w / total
            if normalized_w > 0.01:  # 忽略极小权重
                vg = mesh_obj.vertex_groups[bone_name]
                vg.add([vert.index], normalized_w, 'REPLACE')
    
    print(f"[IDW] Assigned weights to {len(mesh.vertices)} vertices, top_k={top_k}")
```

### 参数调优

| 参数 | 推荐值 | 效果 |
|------|--------|------|
| top_k=1 | 硬绑定 | 无平滑过渡，关节处断裂 |
| top_k=2 | 适中 | 关节有基本过渡 |
| top_k=3 | 推荐 | 平滑且性能可接受 |
| top_k=5+ | 过度平滑 | 全身联动，失去局部性 |
| power=1 | 线性衰减 | 影响范围大 |
| power=2 | 平方衰减 | 推荐，局部性好 |
| power=4 | 急剧衰减 | 非常局部，过渡硬 |

## 常见陷阱

### 陷阱1：未考虑armature的世界变换
```python
# 错误：使用局部坐标
head = bone.head_local  # ← armature有位移时错误

# 正确：转世界坐标
head_world = armature_obj.matrix_world @ bone.head_local
```

### 陷阱2：权重未归一化
```python
# 错误：直接赋值（总和≠1）
vg.add([idx], 1.0/d, 'REPLACE')

# 正确：先归一化
total = sum(1.0/d for _, d in top_bones)
vg.add([idx], (1.0/d)/total, 'REPLACE')
```
