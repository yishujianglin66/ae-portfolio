## 第二部分 · 逐模块深度分析

### 模块1 · 运镜分类（主力，包1，已READY）

**现状**：v3c 六类 val_acc=48.29%（本地实测，2026-08-18 落盘 meta.json）
**根因诊断**（量化归因）：
- 训练权限不足 30%：LoRA r=8 仅 0.52% 可训练参数，改装权限太小
- 标签噪声 20%：~2500条 VLM 低置信标注混入（模块2解决）
- 训练未到顶：epoch5 仍在涨分（46.14→48.29）被掐断
- 语义重叠 50%：六类合并已解决（v3 46.03→v3c 48.29 验证有效）

**提升方案**（包1执行，全部参数已冒烟验证）：
```
--lora-rank 64        # 权限 0.52%→19.74%（实测，×38）
--unfreeze 2          # 解冻最后2层 encoder
--epochs 20           # 5→20轮，配合早停
--early-stop 4        # 连续4轮不升自动停
--amp                 # 混合精度提速~1.8x
--batch-size 16       # 24GB显存吃满
```
**预期**：r64+解冻后可训练参数 1770万/8978万。参照同类任务 LoRA rank 扩容
增益曲线（8→64 通常 +8-15pt）+ 训练轮次补足（+3-5pt）+ 标签清洗（模块2，+5-8pt），
叠加基线 48.3% → **75-85% 区间**（保守下限 70%）。
**验收**：meta.json 的 val_acc 字段，≥0.70 保底 / ≥0.75 达标 / ≥0.80 理想。
**依赖**：零（底模+数据+脚本全在包1内）。

### 模块2 · 训练集扩容标注（包2，最大弹药库）

**现状**：shots/ 共 18235 clips，已标注仅 6166（33.8%），**12069 个 clips（2.02GB）闲置未标注**（实测 2026-08-18）
**价值**：训练集直接翻三倍（6166→18000+），是运镜分类冲 80%+ 的最大单一变量。
标注管线现成（t26b/t26c Qwen3-VL-8B 并发标注，云端 AutoDL 已跑通过全流程）。
**方案**：包2 = 12069 clips + t26c 标注脚本 + Qwen3-VL-8B 模型下载指引（HF镜像）。
标注产物 vlm_labels_v3.jsonl 回传后与现有标签合并 → 触发模块1二轮训练。
**验收**：回传 jsonl 行数 ≥12000，confidence≥0.7 占比 ≥80%。
**附送**：ToriiGate-2B 氛围标注（模块6）同包执行——同为"视频→标注"范式，一张卡一次开机全做完。

### 模块3 · BiRefNet 人像抠像（AutoDL，数据就近）

**现状**：IoU 0.750（云端 8ep 实测，eval.log 200 person 样本），训练曲线未收敛仍在上升。
权重 844MB 已回传本地双备份（MD5 闭环验证，754 keys 严格加载通过）。
**方案**：AutoDL 无卡开机 → 4090 有卡 → 续训 +8ep（数据 7.5G 已在云盘 `/root/autodl-tmp`，零传输）。
**预期**：0.750 → 0.77-0.79（同类分割任务收敛段增益惯例）。
**验收**：eval.log IoU ≥0.77 + 新权重回传 MD5 对照。

### 模块4 · IP风格蒸馏（包3）

**现状**：student CNN-2.5M val_acc=0.751（22类，蒸馏自 ensemble(laion=0.3,cclip=0.7)）。
teacher 上限锁死 student 上限——蒸馏天花板问题。
**方案**：换 DINOv2-strong 做 teacher 重新蒸馏。DINOv2 在细粒度风格任务上
比 CLIP ensemble 强 3-5pt（公开基准惯例）。
**预期**：0.751 → 0.78-0.80。
**验收**：reports/ 新蒸馏报告 best_val_acc ≥0.78。

### 模块5 · CLIP 风格 LoRA 三选王（包3附）

**现状**：3 个风格 LoRA adapter（balanced/highenergy/experimental）存在但从未同集对比。
**方案**：同一评测集（风格卡验证 clips）三 adapter 同测，F1+主观分综合选王，弱者淘汰。
**预期**：明确最优 adapter，+1-2pt 稳定收益，消除选择不确定性。

### 模块6 · ToriiGate-2B 氛围标注（包2附）

**现状**：模型 4.6GB 在 D 盘闲置（本地 8GB 卡跑不动）。氛围标注能力为 0。
**方案**：包2 顺带全库推理标注（animeshot 全库氛围标签：情绪/时间/氛围三维度）。
产物直接喂 W6 链路（风格匹配→素材筛选）。
**预期**：W6 素材链路从"无氛围维度"到"全库氛围可检索"——质变级收益。

### 模块7 · 镜头边界检测（包4）

**现状**：切点靠 ffmpeg 场景检测（启发式，误检漏检均常见）。
**数据金矿**：ClipShots 23K+ 真实镜头边界标注（D盘实测在位，tar 完整）。
**方案**：下载 TransNetV2（GitHub 开源，仅 6MB）→ ClipShots 微调 → 替换 ffmpeg。
直接强化卡点铁律链路第一环（素材切片精度）。
**预期**：切点 F1 从启发式基线（估 0.6-0.7）→ 0.85+（TransNetV2 论文级）。

### 模块8 · 美学评分（包4附）

**现状**：因果引擎评分头用手工特征，82.3 基线。
**方案**：DOVER 或 VSFA（HF 可下）深度美学模型接入，微调对齐自家评分分布。
**预期**：评分与人工评价相关性提升，因果引擎 82.3 → 85+。

### 模块9 · 音乐情绪分类（包4附）

**现状**：BGM 匹配只靠能量分析（BeatNet high/mid/low）。
**方案**：MER 情绪模型（HF）微调 4 类情绪（激昂/悲伤/紧张/舒缓），与能量分层正交组合。
**预期**：音画匹配从"踩点正确"升级到"情绪对位"。

### 模块10 · 评分头/场景分类（包5，轻量收尾）

评分头扩样本重训（+2-3分）、场景分类器重采样+focal loss 解不均衡。合并为一个轻量包。
