## 第二部分 · 深度推理：为什么卡在 48.3%

完整归因链（按 08-18 根因分析报告）：

```
v3b 10类 46.03%
 ├── 语义重叠 ~50% ──→ 六类合并 ──→ v3c 48.29% ✔（+2.3pt，方向验证有效）
 ├── VLM标签噪声 ~20% ──→ ✘ 未修（zoom_in 2125条中混杂推/拉歧义样本）
 └── 训练配置 ~30% ──→ ✘ 未修（LoRA r=8 仅0.52%参数，5 epochs 曲线未到顶）
```

**关键洞察（顺序不可颠倒）**：
- 若直接大权限训练（不清洗标签）：20% 噪声把天花板锁死在 ≈75%
- 若先清洗标签（噪声→8%）再大权限训练：天花板抬到 ≈85%
- 证据：epoch3→5 仍在涨（46.14→48.29），说明欠拟合未饱和，训练权限是当前第一瓶颈；
  但涨速趋缓，说明标签噪声是紧随其后的第二瓶颈。**两者都要修，且先A后B。**

## 第三部分 · 三阶段执行方案

### 阶段A · 标签质量革命（前置，~3h）
**工具**：Qwen3-VL-8B（复用 t26d 已验证云端管线，4090 约2帧/s）
**动作**：
1. 抽帧上传（~2GB，只传帧不传视频）
2. 重标 6166 条中置信度<0.7 的约 2500 条（运镜六类，含置信度输出）
3. 交叉校验：新旧标签不一致的样本进入人工复核清单
4. **顺带任务**：ToriiGate-2B 批量氛围标注（W6 链路素材库，一次上卡双收益）

**产出**：`vlm_labels_clean.jsonl`（置信度分层）+ 重标报告
**验收**：随机抽 200 条人工复核，新旧一致率≥85% 或新标签复核正确率≥90%

### 阶段B · 大权限训练（核心，~8h）
**改动**（我负责改脚本，冒烟通过才算 READY）：
1. `--lora-rank` 参数：r=8→64，alpha=128（改装权限×8）
2. `--unfreeze N` 参数：解冻最后 N 层 encoder（默认2）
3. `--amp` 混合精度（4090 上 batch 8→16）
4. epochs 5→20 + cosine 衰减 + 早停(patience=4)
5. 加权采样默认开启

**执行**：清洗后标签 + 云端 shots clips（已在数据盘）
**验收**：val_acc ≥ 0.70（保底）/ 0.75（达标）/ 0.80（理想）；按类 F1 无跛脚类

### 阶段C · 全模型飞轮（顺带收益，~6h）
同机顺序执行（数据/底模大半已在云端）：
1. IP 风格 CLIP LoRA 重训（t32，balanced 数据在云端）
2. 评分头：color_cnn / param_head / scene_classifier（t27b）
3. 回传本地 → 因果引擎自进化评分预期 +5（当前基线 82.3，v23 链路）
