### 任务 2：解决 scheduleTask 在 Startup 上下文不工作 ✅

**问题**：`app.scheduleTask()` 在 AE 2025 Startup 加载的脚本中不可靠（已验证）
- `recurring=true` 不触发
- `recurring=false` 自调度不触发
- 原因：Startup 脚本运行在受限上下文，定时器无法维持

**解决方案**：使用 ScriptUI Palette 面板
- 面板通过 `panel.show()` 创建持久 UI 上下文
- `panel.onShow` 中启动 `scheduleTask(recurring=true)` 可靠工作
- 面板内 eval listener 代码后，函数在面板作用域可访问

**关键代码**：
```javascript
panel.onShow = function() {
    $.global.__mcpPoll = function() { pollForCommands(); };
    app.scheduleTask("$.global.__mcpPoll()", 500, true);
};
```

**文件**：`.ae-mcp-bridge/2_mcp_bridge_loader.jsx`

---

### 任务 3：独立面板命令处理实现 ✅

**问题**：eval 加载的 listener 代码中函数闭包变量（`isRunning`, `lastCmdTime`, `CMD_FILE`）在面板外部不可访问

**解决方案**：在 loader 内独立实现完整命令处理
- JSON 序列化/反序列化（ExtendScript 兼容）
- 命令路由：ping / getProjectInfo / createComp / runScript
- 日志记录到 `ae_auto_listener.log`
- 使用 `processed` 标志 + 命令 ID 防止重复处理

**关键修复**：
- `Date.toISOString()` 在 ExtendScript 中不存在 → 自定义 `isoTimestamp()` 函数
- `JSON.stringify` 不可用 → 实现简单序列化器

**文件**：`.ae-mcp-bridge/2_mcp_bridge_loader.jsx`
