## 4. 关键经验总结

1. **占位符模板生成 JSON 时数值类型丢失**：字符串替换会把 `42` 变成 `"42"`，提交给严格 API（ComfyUI prompt）前必须强转回数值。
2. **后台克隆竞争陷阱**：上一个超时克隆进程未死（持有 `.git` 文件锁），新克隆的 `Remove-Item` 失败 → 二者竞争导致目录反复清空。清理残留目录前必须先确认无存活 git 进程。
3. **Windows npm 子进程**：`subprocess.run("npm run build", shell=True)` 才能找到 `npm.cmd`（与既有集成经验一致）。
4. **离线环境下的适配器双模设计**：服务端/依赖不可用时输出"可提交的中间产物"（工作流 JSON / 项目脚手架）而非报错，使管线不被环境阻塞——本方案两个新适配器均按此实现。
5. **Gitee 镜像名不可猜**：`mirrors/SCAIL-2` 不存在，错误表现为要求输入用户名；克隆前先确认镜像真实存在。
