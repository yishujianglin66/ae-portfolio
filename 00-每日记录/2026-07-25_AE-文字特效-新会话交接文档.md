## 一、项目总览

### 1.1 项目定位

这是一个 **AE（After Effects）文字特效自动化开发项目**，核心目标是：
通过 Python 脚本生成 AE JSX（ExtendScript）代码，经 **Bridge 通信** 写入 AE 工程，再用 **aerender 命令行渲染**，批量产出带高级动画的文字特效视频，并以 **渲染文件大小 > 100KB** 作为"画面非近黑/特效真实可见"的硬性验收标准。

### 1.2 技术链路

```
Python 生成器（生成 JSX 字符串）
   ↓ send_bridge() 写入 .ae-mcp-bridge/ae_command.json
AE Bridge 面板轮询执行 JSX（建合成/建层/加特效/打关键帧）
   ↓ 轮询 .ae-mcp-bridge/ae_result.json 取结果
aerender.exe 命令行渲染（-project -comp -output）
   ↓
MP4 输出 → 文件大小 > 100KB 验证 → FFmpeg 拼接 Showreel
```

## 四、已验证工作流（强制遵守）

**任何新特效/新手法开发，必须完整走以下流程，不得跳步：**

```
设计 → 可行性实测 → 集成 → 批量渲染 → 文件大小验证 → Showreel 生成 → 经验沉淀
```

| 步骤 | 要求 |
|------|------|
| 1. 设计 | 明确特效的动画手法、配色、构图、时长 |
| 2. 可行性实测 | **每个新手法必须先独立测试**：Bridge 建最小合成 → aerender 渲染 → 文件 **>100KB** 才算 PASS，否则不得集成 |
| 3. 集成 | 仅将实测 PASS 的手法写入生成器 |
| 4. 批量渲染 | 逐个合成 aerender 渲染 |
| 5. 文件大小验证 | 每个输出 **>100KB**，否则判定为近黑/失败 |
| 6. Showreel 生成 | FFmpeg 拼接全部片段 |
| 7. 经验沉淀 | 更新 JSX 参数手册 + 警醒文档 + 记忆 |

**分批推进原则**：手法多时按批次拆分（如 V4 分两批：摄像机/视差/粒子 为第一批，路径/景深/运动模糊 为第二批），每批独立完成"实测→集成→渲染→沉淀"闭环。

## 五、硬性约束（违反必出问题）

| # | 约束 | 说明 |
|---|------|------|
| 1 | **opacity 单位是 0-100** | 不是 0-1！写小数会导致近黑（<40KB） |
| 2 | **ADBE Text Position 在 AE2025 不存在** | 逐字位移动画不可用 |
| 3 | **逐字动画只用 ADBE Text Opacity + Range Selector** | 唯一可靠的逐字方案 |
| 4 | **JSX 必须兼容 ES3** | 禁 `let`/`const`/箭头函数/模板字符串；`int` 是 ES3 保留字（不能作变量名） |
| 5 | **禁止假设可行性** | 任何新手法必须先独立实测 >100KB 再集成 |
| 6 | **禁止 try/catch 降级策略** | 用户明确拒绝"失败就降级"，要求实测证明 100% 可靠 |
| 7 | **渲染文件必须 >100KB** | 近黑/无效画面的硬性验收线 |
| 8 | **摄像机/灯光只影响 3D 层** | 图层须 `threeDLayer=true`，position 为三维 `[x,y,z]` |
| 9 | **3D 层 scale 需三元素数组** `[v,v,100]` | 2D 层才用 `[v,v]` |
| 10 | **aerender 不支持 -rjsx（AE2025）** | 只能用 `-project -comp -output` |
| 11 | **Python 用 `py -3.12` 执行** | PowerShell 不支持 `&&`，用 `;` 分隔 |

## 六、经验知识库（已实测可靠参数）

### 6.1 Bridge 通信协议

- 写命令：`.ae-mcp-bridge\ae_command.json`，格式 `{"command":"runScript","args":{"code": <JSX字符串>}}`
- 读结果：轮询 `.ae-mcp-bridge\ae_result.json`
- 封装函数：`send_bridge()`（见 `batch_render_expand_v4.py`）

### 6.2 基础动画辅助函数（V3.1 验证，V4 复用）

| 函数 | 作用 | 关键参数 |
|------|------|---------|
| `_glow` | 发光特效 | blendMode=5（相加）增强亮度 |
| `_txt` | 建文字层 | 指定字体/字号/颜色/对齐 |
| `_brighter` / `_dim` | 调色增亮/压暗 | — |
| `_fade` | 透明度淡入 | opacity 0→100 |
| `_slideBack` | easeOutBack 滑入 | 过冲公式见 6.3 |
| `_maskCircle` | 圆形遮罩揭示 | 贝塞尔近似 k=0.5523 |
| `_staggerOpacity` | 逐字错峰透明度 | ADBE Text Opacity + Range Selector |

### 6.3 easeOutBack 过冲公式（可靠）

```
s = 1.70158
p = progress - 1
value = 1 + ((s+1)*p*p*p + s*p*p)
```

### 6.4 V4 高级手法（Phase1，实测 >100KB）

| 函数 | 手法 | 关键点 |
|------|------|--------|
| `_txt3d` / `_make3d` | 建 3D 文字层 | `threeDLayer=true` + position `[x,y,z]` |
| `_cameraPush` | 摄像机推进 | `addCamera` + pointOfInterest + position z 关键帧 |
| `_cameraOrbit` | 摄像机环绕 | position 表达式 `Math.sin` 环绕 |
| `_cameraDrift` | 摄像机横漂 | 横向缓慢位移 |
| `_particleWorld` | CC 粒子世界 | 属性索引需实测：Birth Rate=**-0050**（非 -0001）、Longevity=-0002、Producer=-0008；默认参数即大量可见粒子 |
| `_pointLight` | 动态点光 | `addLight` + ADBE Light Options Group（Intensity/Color/Falloff Type=1） |
| `_slideBack3d` | 3D 滑入 | easeOutBack + `[x,y,z]` |

### 6.5 V4 高级手法（Phase2，实测 >100KB）

| 函数 | 手法 | 关键点 |
|------|------|--------|
| `_pathRefLayer` | 路径参考层 | 隐藏 Solid（opacity=0）+ mask 贝塞尔路径；closed=false |
| `_pathMove` | 路径动画 | `ref.mask('Mask 1').maskPath.pointOnPath(t01)`，**必须 `ref.toComp(p)` 换算坐标空间**（pointOnPath 返回图层坐标） |
| `_pathPingPong` | 路径往返 | `ph=(time/period)%2; t01=ph<1?ph:2-ph` |
| `_dof` | 景深 | ADBE Camera Options Group → Depth of Field=1 + Focus Distance 关键帧 + Aperture 8-12；**焦距 = \|主体z - 相机z\|**（不是 z 坐标本身） |
| `_motionBlur` | 运动模糊 | **comp.motionBlur + layer.motionBlur 双开关缺一不可** + 0.4s 半屏快速位移 |

### 6.6 摄像机/景深属性名（实测确认）

```
ADBE Camera Zoom, ADBE Camera Depth of Field, ADBE Camera Focus Distance,
ADBE Camera Aperture, ADBE Camera Blur Level, ADBE Iris Shape, ...
```

## 七、报错与修复记录

| # | 错误现象 | 可能原因 | 实际修复 | 预防措施 |
|---|---------|---------|---------|---------|
| 1 | PowerShell 报 `InvalidEndOfLine` | PowerShell 不支持 `&&` | 改用 `;` 分隔命令 | 所有 shell 命令用 `;` |
| 2 | 内联 Python 命令 SyntaxError | 中文 + 嵌套引号 + 复杂列表推导被 PowerShell 错误解析 | 改为创建临时 `.py` 脚本文件再执行 | 复杂逻辑写成文件 |
| 3 | Python 输出中文乱码 | 控制台默认 GBK 编码 | 脚本头部 `sys.stdout.reconfigure(encoding='utf-8')` | 所有脚本固定加该行 |
| 4 | CC Particle World 属性索引 -0001 报错 | 属性索引靠猜测，实际 Birth Rate=-0050 | 用 propList 遍历探测真实索引；非核心参数 try/catch 保护 | 新特效属性先探测再写死 |
| 5 | 渲染文件过小（<40KB 近黑） | opacity 误用 0-1 小数 | 统一改为 0-100 整数 | 牢记约束 #1 |
| 6 | JSX 语法报错 | 误用 let/const/箭头函数/模板字符串 | 全部改为 ES3 语法（var/字符串拼接） | 生成器输出前做 ES3 检查 |
| 7 | 路径动画坐标错位 | pointOnPath 返回图层坐标未换算 | 加 `ref.toComp(p)` | 路径动画必 toComp |
| 8 | 景深无虚化效果 | 焦距误用 z 坐标 | 焦距 = \|主体z - 相机z\| | 见约束 6.5 |
| 9 | 运动模糊不生效 | 只开了图层开关 | comp + layer 双开关 | 见约束 6.5 |

## 八、后续开发建议

### 8.1 可继续的方向（按优先级）

1. **新增特效风格**：在 V4 基线上继续扩充（如故障艺术进阶、全息投影变体、赛博 HUD 动态仪表盘、流体模拟进阶）
2. **优化视觉层次**：强化前/中/背景三层分离、动态光影、色彩分级过渡
3. **效果库模板化**：将已验证的生成器抽象为可配置模板（参数化文字/配色/时长），走向"一键生成"产品化
4. **迁移复用**：将 V4 手法迁移到其他项目或合成类型（竖屏/方形/多分辨率）
5. **V5 迭代**：引入表达式驱动动画、音频联动、3D 模型/粒子进阶（Particular 等插件）

### 8.2 启动新批次开发的标准动作

1. 先读本文档 + JSX 参数手册 + 警醒文档
2. 确认 Bridge 可用（`quick_ping.py` 或发一个最小 runScript）
