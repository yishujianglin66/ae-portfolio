### 3.1 Python包版本变更

| 包名 | 变更前 | 变更后 | 原因 |
|---|---|---|---|
| torch | 2.5.1+cu121 | **2.6.0+cu124** | BGE-M3需要torch≥2.6 |
| transformers | 4.48.0 | **5.14.1** | 4.48.0与tokenizers 0.22.2不兼容 |
| tokenizers | 0.21.4 | **0.23.0** | transformers 5.14.1需要≥0.22.0,≤0.23.0 |
| huggingface_hub | 旧版 | **升级版** | transformers 5.14.1需要新API |
| peft | - | 0.20.0 | LoRA微调需要 |
| sentence-transformers | - | 5.7 | BGE-M3需要 |

### 3.2 环境修复过程（重要踩坑）

```
问题链:
1. torch 2.5.1 metadata损坏 → importlib.metadata.version("torch")返回None
2. 升级torch 2.6.0后, transformers 4.48.0报tokenizers版本不匹配
3. 删除旧transformers目录后重装5.14.1, 但huggingface_hub版本过旧
4. 升级huggingface_hub后, tokenizers被降级到0.21.4
5. 最终: transformers 5.14.1 + tokenizers 0.23.0 + huggingface_hub新版

修复命令:
pip install torch==2.6.0+cu124 --extra-index-url https://download.pytorch.org/whl/cu124
pip install "transformers>=4.51" --force-reinstall --no-deps
pip install --upgrade huggingface_hub
pip install "tokenizers>=0.22.0,<0.23.1"
```

## 十、经验与踩坑

### 10.1 环境相关

1. **torch metadata损坏**: 升级torch后metadata可能不更新, 需force-reinstall
2. **transformers版本链**: transformers 5.14.1需要tokenizers 0.22-0.23, huggingface_hub新版
3. **Windows pickle问题**: DataLoader的Dataset类必须模块级, 不能嵌套在函数内
4. **GPU显存竞争**: T21+T7同时训练会抢占8GB显存, 建议串行

### 10.2 训练相关

1. **LoRA target_modules**: CLIP ViT用`["out_proj", "c_fc", "c_proj"]`, 不是"qkv"
2. **LoRA参数冻结**: 冻结base model后要重新启用lora_前缀参数
3. **学生模型太小**: 0.10M CNN对22类不够, 建议≥1M参数
4. **伪标签噪声**: 平均置信0.77, 高置信99.88%但可能有系统性偏差

### 10.3 工程相关

1. **stdout缓冲**: 后台进程输出可能缓冲, 用`flush=True`或`PYTHONUNBUFFERED=1`
2. **进程监控**: 用`Get-Process -Id <PID>`监控, 不要依赖文件存在判断
3. **断点续传**: T19/T20都实现了, 新任务也要加
