### 关键发现：execute-atom-script 架构缺口

- Bridge (94609 bytes) 的 switch 语句中**没有** `case "executeAtomScript"`
- MCP 服务器 `execute-atom-script` 工具发送 `executeAtomScript` 命令 → Bridge 返回 `Unknown command`
- `executeAtomScript.jsx` 处理脚本存在于 `build/scripts/` 但 Bridge 不知道加载它
- **根因**：开源项目 MCP 服务器端有工具定义，但 Bridge 端无对应处理器（架构缺口）
- **影响**：`run_additive_jsx.py` 组装正常（19583 字符），但执行通道被 Bridge 阻断

### 替代执行路径（已验证可用）

- `applyEffect` + `effectMatchName` + `effectSettings` → 可应用任意效果（等效 applyColorCorrection 核心功能）
- `applyEffectTemplate` → 预定义效果组合
- `setLayerKeyframe` / `setLayerExpression` → 动画与表达式

## 九、关键经验

- `eval()` 不解析 ExtendScript `#include`，必须手动内联依赖
- PowerShell 经 Node fallback shell 执行时 `$` 变量被吞，需写 ASCII-only .ps1 文件
- Write 工具会追加而非覆盖，重写文件需先 DeleteFile
- `from __future__ import annotations` 必须在所有其他语句之前（docstring 之后）
- 开源 `execute-atom-script` 对 scriptContent 执行 `eval()`，结果不捕获内层返回值，需存 `$.global`
- **Bridge 不支持 `executeAtomScript` 命令**（switch 无此 case），需通过 `applyEffect` 等原生命令替代
- `applyEffect` 参数用 `compIndex`（项目索引）而非 `compName`；`effectSettings` 而非 `settings`
- `setLayerKeyframe` 参数为扁平结构：`compIndex, layerIndex, propertyName, timeInSeconds, value`
- **`apply-preset` 支持 `presetPath` 全路径**，可直接应用 4998 个本地 .ffx 预设
- **`setLayerExpression` 参数名为 `expressionString`**（非 `expression`）
- AE Text Animator matchName：`ADBE Text Position 3D` / `ADBE Text Scale 3D` / `ADBE Text Opacity` / `ADBE Text Blur` / `ADBE Text Rotation`
- Range Selector matchName：`ADBE Text Percent Start/End/Offset`，Shape: `ADBE Text Range Type2`(1-6)
