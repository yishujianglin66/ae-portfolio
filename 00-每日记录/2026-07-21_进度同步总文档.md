## 一、项目概况

**核心目标**：通过 DaVinci Resolve 实现视频自动化调色，从项目创建到渲染输出全链路自动化。

**唯一有效路径**：`fuscript.exe + Lua`（V12/V15 时代验证成功）

**当前版本**：ResolveColorEngine v4.0

**架构**：
```
[调用方] pipeline / puppet-automation / MCP / 直接调用
    ↓
[统一入口] integrations/davinci_fuscript.py (ResolveColorEngine v4.0)
    ↓         - 12 个 Resolve 预设 + 7 个 FFmpeg 预设
    ↓         - ColorGradeArtifact 跨软件互通
    ↓         - quick_grade / ffmpeg_grade 便捷方法
[执行核心] fuscript.exe -lua script.lua
    ↓
[DaVinci Resolve]
```

| 渲染输出 | `render_project()` | MP4/MOV/EXR + 进度回调 |

## 四、数据模型

```python
@dataclass class FuscriptResult:
    success, stdout, stderr, return_code, duration,
    project_name, timeline_name, clips_graded, clips_imported,
    render_complete, output_path, errors, metadata

@dataclass class ColorGradeConfig:
    preset, lut_path, lut_intensity,
    brightness, contrast, saturation,
    lift, gamma, gain, offset (ColorWheelParams),
    pivot, blend_opacity,
    custom_curve, hue_vs_hue, hue_vs_sat, ... (曲线),
    qualifier (QualifierParams),
    segment_presets, scene_type

@dataclass class ColorGradeArtifact:
    version, preset_name, source, created_at,
    nodes, ffmpeg_filter, metadata
    # to_json() / from_dict() / save() / load()

@dataclass class ColorWheelParams:
    red, green, blue, master

@dataclass class QualifierParams:
    hue_min, hue_max, sat_min, sat_max, lum_min, lum_max, invert

@dataclass class RenderConfig:
    format, codec, resolution, frame_rate, quality, timeout
```

## 七、关键 API 规范

### Fusion 属性设置（必须遵循）
```lua
bc.Brightness = 0.05    -- 正确
bc.Contrast = 1.1       -- 正确
cg.Saturation = 1.05    -- 正确
-- bc:SetAttr("Brightness", 0.05)  -- 错误！SetAttr 不存在
-- item:SetSaturation(value, 0)    -- 错误！TimelineItem 无此方法
```

### SetLUT 调用
```lua
item:SetLUT(lutPath)     -- 正确（单参数）
-- item:SetLUT(1, lutPath)  -- 错误（双参数）
```

### Resolve API 必须 pcall 包裹
```lua
local ok, resolve = pcall(Resolve)
local pmOk, pm = pcall(function() return resolve:GetProjectManager() end)
```

### 时间线检查（GetTimelineByName 不存在）
```lua
-- 正确：遍历检查
for i = 1, project:GetTimelineCount() do
    local tl = project:GetTimelineByIndex(i)
    if tl and tl:GetName() == "MainTimeline" then ... end
end
-- 错误：project:GetTimelineByName("MainTimeline")  -- 不存在
```

### Python f-string 中嵌入 Lua 代码
```python
# 必须双花括号转义
lua_script = f'''
local values = {{
    Red = {params.red},
    Green = {params.green},
}}
'''
```
