## 4. 关键经验总结

- **GitHub 封锁环境下载矩阵**：`codeload.github.com` ZIP 可达（注意先查 GitHub API 拿默认分支名！）；`objects.githubusercontent.com`（Release 资产）挂起 → 走 `ghproxy.net` 代理；`huggingface.co/hf-mirror/gitee-hf` 全不可达 → ModelScope 是权重唯一可靠线路
- **Invoke-WebRequest 慢且易僵死**：大文件一律用 `curl.exe -L --retry`
- **uv 管理的 venv 没有 pip**：`python -m pip` 报 No module named pip，必须 `uv pip install`
- **Motion Canvas 类型陷阱**：`?scene` 模块导出 `FullSceneDescription`（非 `Scene`），官方声明用 `export =`
- **编辑工具"保存失败"可能已落盘**：重试前必须回读，否则注册表条目翻倍（本轮已遇）
