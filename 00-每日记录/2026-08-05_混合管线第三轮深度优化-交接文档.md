## 一、项目全景

### 1.1 项目概述

本项目是一个 **Resolve → AE → Resolve 三段式混合视频制作管线**，核心目标是自动化生产专业级 AMV/MAD 混剪视频。

**三段式铁律（不可颠倒）**：
1. **Stage A**（引擎侧）：踩拍剪辑 + 变速 + 转场 → 中间文件
2. **Stage B**（AE 侧）：导入中间文件 → 文字动画/标题 → 渲染
3. **Stage C**（引擎侧）：全片 LUT+调色 → BGM 混音淡出 → 成片

## 二、第三轮优化完成内容

### 2.1 调色修复（饱和度降低）

**问题**：Stage C 调色饱和度注入过强（1.8x），画面色彩严重失真。

**修复**：
- `hue=s=1.8` → `hue=s=1.5`
- `eq=saturation=1.8` → `eq=saturation=1.5`
- `colorbalance` 参数全部减半（rs:-0.08→-0.05, bs:0.12→0.08 等）

**实测数据**：
| 饱和度倍数 | SATAVG | 效果 |
|-----------|--------|------|
| 1.8x | ~50 | 色彩失真，"变成纯色块" |
| 1.5x | ~28 | **平衡点**，保留原始色彩+适度风格化 |
| 1.3x | ~22 | 低于 evaluator 阈值 28，平淡 |

**修改位置**：`resolve_ae_resolve_pipeline.py` → `_grade_and_mix()` 方法

### 2.2 文字动画重构（核心痛点）

**问题**：
1. 主标题从出现后一直停留到视频结束（无出场动画）
2. 所有文字都是居中淡入淡出，形式单调

**修复**：
1. **消除常驻**：主标题增加出场 opacity 100→0，副标题同样
2. **多样化**：新建 `integrations/smart_director.py`（429 行），实现 6 种动画预设

**6 种动画预设**：
| 预设名 | 动画类型 | 位置 | 灵感来源 |
|--------|---------|------|---------|
| scale_bounce | 缩放弹跳入场+缩小出场 | 居中 | ae/presets/text_animation.json → douyin_bounce_title |
| slide_left | 左侧滑入+右侧滑出 | 左28% | mg_animation slide |
| slide_right | 右侧滑入+左侧滑出 | 右72% | mg_animation slide |
| rotate_3d | Y轴3D旋转进出 | 居中 | ae/presets/3d_effect.json → text_rotation |
| drop_top | 顶部下落+底部下落 | 顶30% | 12-漫剪拉镜大师 |
| fade_scale | 渐显放大+渐隐缩小 | 底65% | 11-大师知识库慢节奏技法 |

**每个文字动画都有完整的"入场→展示→出场"生命周期**，通过 `setValuesAtTimes` 实现贝塞尔平滑过渡。

### 2.3 智能导演系统

**新建文件**：`integrations/smart_director.py`

**闭环链路**：感知→分析→决策→执行

1. **感知**：ffmpeg `tblend difference` 测量运动强度 + `edgedetect` 测量场景复杂度
2. **分析**：根据特征划分 intensity_level（gentle / moderate / intense）
3. **决策**：选择动画预设、位置、字号、时长分配
4. **执行**：生成多样化 JSX 文字动画代码

**知识库消费**：
- ae/presets/text_animation.json → 20 个文字动画预设名称/标签
- ae/presets/3d_effect.json → 10 个 3D 效果参考
- 10-风格化剪辑知识库 → 256 个风格化方案文件

**实测结果**：9 个镜头全部分析为 intense（运动强度 4.0~9.3），6 种预设循环使用。

### 2.4 ExtendScript 关键帧自动化深度研究

**结论：完全可行。** 详见 `docs/ae_bridge_lessons.md` 第 9 节。

**API 能力边界**：
- `setInterpolationTypeAtKey(k, BEZIER/LINEAR/HOLD)` — 插值类型
- `setSpatialTangentAtKey(k, [dx,dy,dz])` — 贝塞尔空间切线（仅空间属性）
- `setTemporalEaseAtKey(k, [inEase, outEase])` — 时间缓动值
- `setTemporalAutoBezierAtKey(k, true)` — 自动贝塞尔
- 表达式函数：`ease()` / `easeIn()` / `easeOut()` / `loopOut()`

**限制**：
- 表达式与手动关键帧互斥（同一属性不能同时有两者）
- 空间切线仅适用于 Position/Anchor Point 等空间属性
- 枚举值不可用裸数字（`KeyframeInterpolationType.BEZIER` 不能写 `2`）
