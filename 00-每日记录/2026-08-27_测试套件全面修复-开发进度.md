## 四、关键经验总结

### 1. sys.modules 快照-恢复模式（通用防御范式）

```python
# 注入前保存
_prior_modules = {k: sys.modules[k] for k in INJECTION_KEYS if k in sys.modules}
_prior_attrs = {}
for parent, attr in PARENT_ATTR_PAIRS:
    pm = sys.modules.get(parent)
    if pm and hasattr(pm, attr):
        _prior_attrs[(parent, attr)] = getattr(pm, attr)

# ... 注入 mock 并执行目标代码 ...

# finally 恢复
try:
    ...
finally:
    for k in INJECTION_KEYS:
        sys.modules.pop(k, None)
    sys.modules.update(_prior_modules)
    for (parent, attr), val in _prior_attrs.items():
        pm = sys.modules.get(parent)
        if pm:
            setattr(pm, attr, val)
```

### 2. 合成包陷阱

`type(sys)("pkg.sub")` 创建的空壳包无 `__init__.py` 执行。后续 `from pkg.sub import RealClass` 命中缓存的空壳包 → `ImportError`。解决：加载完成后删除合成子包，保留必要的父包。

### 3. builtins.__import__ 延迟导入防御

即使 `with patch("builtins.__import__")` 正确恢复，全量运行时因执行顺序/异常路径等原因仍可能导致延迟 import 失败。生产代码中非关键 import 应做 try/except 防御：

```python
try:
    import aiohttp as _aiohttp
    client_timeout = _aiohttp.ClientTimeout(total=timeout)
except Exception:
    client_timeout = None  # mock 环境退化
```

### 4. collect_ignore 路径解析规则

`collect_ignore` 条目相对 `conftest.py` 所在目录解析。在 `tests/conftest.py` 中写 `"tests/xxx.py"` 前缀会导致整个忽略列表静默失效。正确做法：直接用文件名 `"xxx.py"`。
