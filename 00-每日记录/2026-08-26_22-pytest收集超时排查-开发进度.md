## 四、关键经验总结

1. **pytest collect_ignore 条目相对 conftest.py 所在目录**——在 `tests/conftest.py` 里写 `tests/xxx.py` 前缀会使整个列表静默失效，且无任何警告
2. **import 重定向表禁止收录 `test_*` 模块名**——pytest 以裸模块名收集测试文件，重定向器会抢先加载同名文件造成 mismatch
3. **测试文件中 mock 包的 `__path__` 不能为空**——空 `__path__` 会经 sys.modules 缓存污染所有后续 `pkg.*` 子模块解析
4. **诊断挂起的三板斧**：faulthandler 定时栈转储 → 管道缓冲会吞输出需重定向文件；py-spy dump --pid 直接看挂死栈；二分法组合复现跨文件污染

## 追加：topaz 运行期错误修复（同日闭环）

**结果：`test_topaz_engine.py` 1 passed + 4 errors → 5 passed**

### 根因（引擎与新基类契约脱节，两处）

1. **抽象方法未实现（4 errors 直接原因）**：`BaseEngine` 已升级为模板方法模式——`execute()` 是 final 模板（available 短路/异常包裹/时长统计），子类须实现抽象方法 `_execute_impl()`。`TopazEngine` 仍直接覆盖 `execute()`、未实现 `_execute_impl` → `TypeError: Can't instantiate abstract class`，fixture 实例化失败。
2. **`_run_subprocess` 返回值契约变更未跟进**：基类已改返回 4 元组 `(code, stdout, stderr, error_code)`，但 topaz `enhance()` 仍按 3 元组解包 → 即使能实例化，真实执行也会 `ValueError: too many values to unpack`。

### 修复（仅改 `puppet-automation/src/engines/topaz/engine.py`）

- `execute()` → `_execute_impl()`：保留 action 调度；短路/异常/时长统计交还基类模板；对外 `execute()` 接口由基类保留，调用方零改动。
- 3 元组解包 → 4 元组：`code, _stdout, stderr, _err_code`。

### 验证
- `test_topaz_engine.py` 5 passed
- 组合冒烟 `topaz + roto + layer_render` = 104 passed（确认与 roto 的 `src.engines` mock 同跑无类身份冲突）
- 全量收集健康保持（4599 测试 / 0 错误）
- 调用方：`beat_video_service.py` 直调 `enhance()`（仅内部解包变化）；`registry.py`/`api/main.py` 经公共接口不受影响

## 追加：引擎契约批量对齐（同日闭环）

**结果：继承 `BaseEngine` 的全部引擎子类对齐，21 个引擎类 `__abstractmethods__` 清零、可实例化、`execute()` 路径均返回 `EngineResult`**

### 处置（含一次误改回滚）
- **改名 `execute()`→`_execute_impl()`（12 个，均确认继承 `BaseEngine`）**：audition / davinci / media_encoder / moviepy / openmontage / photoshop / premiere / rife / sam2 / silhouette / whisper；`pr` 为 `PremiereEngine` 别名随继承生效。
- **`_run_subprocess` 3→4 元组解包（同批 9 处）**：davinci / media_encoder / moviepy / openmontage×2 / rife / sam2 / silhouette×5。
- **⚠️ 误改回滚（2 个）**：`comfyui`、`flux3` 是**独立类**（不继承 `BaseEngine`），本就不受抽象方法约束；首轮按"覆盖 execute()"粗扫描误改名导致 `no attribute 'execute'`，已回滚保留自有 `execute()`。

### 关键教训
批量修复前**必须逐个确认 `class XxxEngine(BaseEngine)`**——仅凭"覆盖了 execute()"扫描会把独立引擎误纳入，改名反而删掉其对外接口（独立类无基类模板可调 `_execute_impl`）。
