# VFX合成理论与数字特效完全指南

> 版本: 2025-v1 | 适用: AE/Nuke/Silhouette + 影视特效合成

## 一、VFX合成基础理论

### 1.1 什么是数字合成

数字合成(Compositing)是将多个独立拍摄的图像/CG元素组合成单一画面的技术。核心目标: **让观众无法区分真实拍摄与人工添加的元素**。

### 1.2 合成核心原理

| 原理 | 公式/概念 | 应用 |
|------|----------|------|
| Alpha通道 | 透明度信息(0-1) | 遮罩、抠像 |
| 加色混合 | R+G+B=白 | 光效叠加 |
| 减色混合 | 颜料/滤镜 | 色彩校正 |
| Over操作 | A over B = A + B*(1-α) | 图层合成基础 |
| 预乘Alpha | RGB已乘以Alpha | 避免边缘光晕 |
| 通道操作 | 分通道处理 | 高级遮罩 |

### 1.3 Porter-Duff 合成操作

| 操作 | 含义 | AE对应 |
|------|------|--------|
| Over | A在B上方 | 默认图层叠加 |
| In | A被B裁剪 | 蒙版 |
| Atop | A在B范围内显示 | 图层蒙版 |
| Out | A在B范围外显示 | 反相蒙版 |
| Plus | 加色混合(不截断) | 添加模式 |
| Xor | 对称差集 | 排除模式 |

## 二、抠像技术

### 2.1 色度抠像(Chroma Key)

#### 绿幕 vs 蓝幕

| 特性 | 绿幕 | 蓝幕 |
|------|------|------|
| 亮度 | 更亮(传感器绿通道多) | 较暗 |
| 噪点 | 较少 | 较多 |
| 适合肤色 | 所有人 | 所有人 |
| 适合场景 |  daylight/外景 | 暗调/夜景 |
| 溢色问题 | 绿色溢出明显 | 蓝色溢出较自然 |
| 常用工具 | Keylight, Primatte | Keylight, Ultimatte |

#### Keylight 抠像流程

```
1. 屏幕颜色选择: 选取绿幕/蓝幕纯色区域
2. 屏幕预乘: Screen Pre-blur (0.5-1.0)
3. 裁剪黑白: Clip Black/White (精细边缘)
4. 屏幕收缩: Screen Shrink/Grow (-2~-5 去绿边)
5. 屏幕柔化: Screen Soften (0.5-1.0)
6. 溢出抑制: 去溢色(Desaturate/Neutral)
7. 边缘修正: 光包裹+色彩匹配
```

#### 常见问题解决

| 问题 | 原因 | 解决 |
|------|------|------|
| 绿边/蓝边 | 溢色 | Screen Shrink + 去溢色 |
| 边缘闪烁 | 噪点/压缩 | Screen Pre-blur + 去噪 |
| 半透明丢失 | 薄纱/毛发 | 使用RGB差值遮罩 |
| 阴影丢失 | 过度裁剪 | 降低Clip Black |

### 2.2 亮度抠像(Luma Key)

- 基于亮度值创建遮罩
- 适合: 火焰、烟雾、光效等自发光元素
- AE: 提取(Extract)效果 或 设置遮罩(Set Matte)+亮度

### 2.3 Roto(转描/描摹)

#### Roto 工作流

```
1. 分析运动: 观察主体运动轨迹和形变
2. 创建形状: 贝塞尔/B-Spline勾勒主体
3. 设置关键帧: 逐帧或跟踪+手动修正
4. 边缘处理: 羽化/运动模糊
5. 质量检查: 边缘闪烁/丢失检测
```

#### Roto 工具选择

| 工具 | 适用场景 | 精度 |
|------|---------|------|
| AE Roto Brush 3.0 | AI辅助自动抠像 | 中-高 |
| AE Mask/Shape | 硬边物体 | 高 |
| Silhouette Roto | 专业级手动Roto | 极高 |
| Mocha Pro Planar Track | 平面跟踪+Roto | 高 |
| Nuke RotoPaint | 节点式Roto | 极高 |

### 2.4 差异遮罩(Difference Matte)

- 原理: 比较前景/背景帧差异
- 适合: 固定机位中运动物体提取
- AE: 差异遮罩(Difference Matte)效果

## 三、跟踪技术

### 3.1 2D 跟踪

| 技术 | 原理 | 适用 |
|------|------|------|
| 点跟踪 | 追踪单个像素块运动 | 稳定化/简单附着 |
| 平面跟踪 | 追踪平面区域运动 | 屏幕替换/文字附着 |
| 边角钉跟踪 | 四角定位 | 透视变换 |

#### Mocha Pro 平面跟踪流程

```
1. 创建Spline层框选跟踪区域
2. 选择跟踪算法(Perspective/Shear/Translate)
3. 跟踪正向(Forward) + 反向(Backward)
4. 检查跟踪精度(X-Score > 0.8)
5. 输出跟踪数据:
   - AE: Corner Pin / Transform
   - Nuke: CornerPin2D
   - 通用: Matchmove数据
```

### 3.2 3D 摄像机跟踪

| 工具 | 类型 | 精度 |
|------|------|------|
| AE 3D Camera Tracker | 自动点云 | 中 |
| SynthEyes | 专业级 | 高 |
| PFTrack | 工业级 | 极高 |
| Nuke CameraTracker | 节点式 | 高 |

#### 摄像机反求流程

```
1. 分析素材: 镜头畸变、滚动快门
2. 跟踪点检测: 自动/手动添加特征点
3. 解算: 计算摄像机运动+场景点云
4. 验证: 检查滑动/漂移
5. 设定比例/原点/地面
6. 导出: 3D摄像机 + 零平面
7. 匹配: 在3D空间中放置CG元素
```

### 3.3 运动匹配(Matchmove)

核心目标: CG元素与实拍画面的**透视、运动、光照完全一致**

| 要素 | 检查项 |
|------|--------|
| 运动 | 速度曲线、加速度匹配 |
| 透视 | 消失点、镜头畸变 |
| 焦距 | 广角/长焦透视感 |
| 滚动快门 | 果冻效应补偿 |
| 镜头呼吸 | 对焦时焦距微变 |

## 四、合成技法

### 4.1 光效合成

| 效果 | 实现方法 |
|------|---------|
| 镜头光晕 | Optical Flares / 手动光层 |
| 体积光 | 雾+光源 / Deep数据 |
| 光包裹 | 边缘光照匹配(亮边) |
| 反射 | 环境贴图 / 镜面反射层 |
| 散射 | 柔光层 + 色彩溢出 |

### 4.2 环境匹配

| 要素 | 方法 |
|------|------|
| 光照方向 | 分析实拍阴影方向 |
| 色温 | 匹配环境色温 |
| 对比度 | 匹配实拍黑白场 |
| 颗粒 | 添加匹配颗粒感 |
| 模糊 | 匹配镜头景深 |
| 畸变 | 匹配镜头畸变特征 |

### 4.3 数字绘景(Matte Painting)

```
传统: 手绘玻璃画 → 现代: 数字绘景(DMP)
工具: Photoshop + AE/Nuke
流程:
1. 分析场景透视和光照
2. 拍摄参考照片
3. 绘制/合成扩展场景
4. 投影到3D几何体(Projection)
5. 与实拍合成(匹配颗粒/模糊/色彩)
```

## 五、AE 合成实战技法

### 5.1 预合成与合成架构

```
推荐合成架构:
Main Comp
├── BG_Comp (背景层)
├── Character_Comp (角色+Roto)
├── VFX_Comp (特效元素)
│   ├── Particles
│   ├── Light_Rays
│   └── CG_Elements
├── Grade_Comp (调色调整层)
└── Output_Comp (输出处理)
    ├── Grain
    ├── Lens_Distortion
    └── Final_LUT
```

### 5.2 混合模式详解

| 模式 | 公式 | 应用 |
|------|------|------|
| 正常(Normal) | A | 默认 |
| 相加(Add/Plus) | A+B | 光效/发光 |
| 相乘(Multiply) | A×B | 阴影/暗化 |
| 滤色(Screen) | 1-(1-A)(1-B) | 柔光/亮化 |
| 叠加(Overlay) | 条件乘/除 | 增强对比 |
| 柔光(Soft Light) | 柔和叠加 | 微调 |
| 差值(Difference) | |A-B| | 对比/遮罩 |

### 5.3 抠像+合成完整流程

```
1. 素材分析 → 确定抠像方法
2. 初始抠像 → Keylight/Roto
3. 遮罩精修 → 边缘处理/去溢色
4. 运动跟踪 → 将CG元素匹配到场景
5. 光照匹配 → 方向/色温/强度
6. 色彩匹配 → 黑白场/饱和度/色偏
7. 环境融合 → 颗粒/模糊/光包裹
8. 最终调色 → 统一整体色彩
9. 输出处理 → 锐化/颗粒/LUT
```

## 六、质量控制与交付

### 6.1 合成质量检查清单

```
□ 边缘质量: 无闪烁/锯齿/光晕
□ 色彩匹配: CG与实拍色温/对比度一致
□ 光照匹配: 阴影方向/强度正确
□ 运动匹配: 无滑动/漂移
□ 颗粒匹配: CG颗粒与实拍一致
□ 焦点匹配: 景深/模糊一致
□ 镜头畸变: CG跟随镜头畸变
□ Alpha质量: 半透明区域干净
□ 时间一致性: 无闪烁/跳变
□ 分辨率: 符合交付标准
```

### 6.2 输出规范

| 用途 | 格式 | 编码 | 色深 |
|------|------|------|------|
| 合成母版 | EXR序列 | ZIP/PXR24压缩 | 16bit半浮点 |
| 内部审核 | ProRes 4444 | ProRes | 16bit |
| 交付客户 | ProRes 422HQ | ProRes | 10bit |
| 网络发布 | H.265/H.264 | 高码率 | 8bit |
