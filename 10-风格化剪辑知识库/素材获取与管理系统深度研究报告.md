## 第1章 素材资源分类体系

### 1.1 分类体系总览

素材资源分类是数字资产管理（DAM）系统的核心基础。科学的分类体系能够显著提升素材检索效率、降低管理成本、保障版权合规。本章建立了一套覆盖视频、音频、图片、3D、字体、模板、LUT预设、粒子特效八大类的完整分类标准。

```

├── 视频素材 (Video Assets)
│   ├── 实拍素材
│   ├── CG素材
│   ├── 动画素材
│   ├── 绿幕素材
│   ├── 空镜素材
│   ├── 转场素材
```

### 1.2 视频素材详解

#### 1.2.1 实拍素材 (Live-Action Footage)

实拍素材是通过摄像机真实拍摄的视频内容，是影视制作中最基础的素材类型。

**子类划分：**
- **按题材分**：人物、风景、城市、自然、科技、商业、生活、美食、运动、医疗
- **按视角分**：平视、俯视、仰视、航拍、水下、微距、延时、慢动作
- **按风格分**：电影感、纪录片、Vlog、广告、宣传片、MV
- **按格式分**：RAW、ProRes、DNxHR、H.264、H.265、AV1

**技术参数标准：**
| 参数 | 入门级 | 专业级 | 电影级 |
|------|--------|--------|--------|
| 分辨率 | 1920×1080 | 3840×2160 | 4096×2160 / 8K |
| 帧率 | 24/30fps | 60fps | 120/240fps |
| 码率 | 10-50 Mbps | 100-500 Mbps | 500-2000 Mbps |
| 编码 | H.264 | ProRes 422 | ProRes 4444 / RAW |
| 位深 | 8bit | 10bit | 12-16bit |
| 色彩空间 | Rec.709 | Rec.2020 / DCI-P3 | ACES / Log |

#### 1.2.2 CG素材 (Computer Graphics)

CG素材是通过计算机图形技术生成的视频内容，包括3D渲染、2D动画、特效合成等。

**子类划分：**
- **3D渲染**：建筑可视化、产品展示、角色动画、场景漫游
- **2D动效**：MG动画、信息图表、图标动画、文字动画
- **特效元素**：爆炸、火焰、烟雾、粒子、光效、能量波
- **抽象视觉**：渐变流动、几何变换、数据可视化

**常用格式：**
- 带Alpha通道：ProRes 4444, DNxHR 444, CineForm, WebM
- 序列帧：PNG序列、TIFF序列、EXR序列
- 矢量动画：Lottie, SVG动画, SWF (已淘汰)

#### 1.2.3 动画素材 (Animation)

动画素材是具有叙事性或表现性的连续画面，区别于单纯的特效元素。

**子类划分：**
- **2D动画**：逐帧动画、补间动画、骨骼动画、剪纸动画
- **3D动画**：角色动画、机械动画、流体动画、布料模拟
- **定格动画**：实物定格、黏土动画、剪纸定格
- **MG动画**：Motion Graphics，图形动态设计

#### 1.2.4 绿幕素材 (Green Screen / Chroma Key)

绿幕素材是在绿色（或蓝色）背景前拍摄的素材，用于后期抠像合成。

**技术标准：**
- 背景颜色：绿幕（RGB 0, 177, 64）、蓝幕（RGB 0, 71, 187）
- 光照要求：均匀布光，亮度差<10%，无明显阴影
- 拍摄距离：主体与绿幕间距≥2米，减少绿色反光
- 采样要求：4:2:2以上色度采样，10bit位深

**应用场景：**
- 虚拟演播室
- 电影特效合成
- 产品展示视频
- 教育课程录制
- 短视频创作

#### 1.2.5 空镜素材 (B-Roll / Cutaway)

空镜素材是不包含主要人物、用于补充叙事或转场过渡的画面素材。

**常见类型：**
- 自然景观：日出日落、云流动、海浪、森林
- 城市风光：车流延时、建筑特写、夜景灯光
- 细节特写：手部动作、物体细节、文字图案
- 氛围营造：光影变化、雨滴、烟雾、火焰

#### 1.2.6 转场素材 (Transition Assets)

转场素材是用于两个镜头之间过渡效果的视频素材。

**分类：**
- **遮罩转场**：光线擦除、水墨晕染、故障干扰、毛刺转场
- **元素转场**：镜头冲击、变焦推拉、旋转切换
- **特效转场**：粒子爆发、能量传送、空间扭曲
- **预合成转场**：带Alpha通道的完整转场动画

#### 1.2.7 VFX元素 (Visual Effects Elements)

VFX元素是可直接用于合成的特效素材，通常带有Alpha通道。

**主要类型：**
- 光效素材：镜头光晕、光斑、光线扫描、发光线条
- 粒子素材：粉尘、火花、雨点、雪花、魔法粒子
- 环境元素：雾、烟、云、火焰、爆炸、碎片
- 特效叠加：胶片颗粒、划痕、漏光、色散

### 1.3 音频素材详解

#### 1.3.1 背景音乐BGM (Background Music)

背景音乐是用于营造情绪氛围、支撑叙事节奏的音乐素材。

**情绪分类：**
| 情绪类型 | 典型特征 | 适用场景 |
|----------|----------|----------|
| 激昂振奋 | 快节奏、强鼓点、管弦乐 | 宣传片、运动、产品发布 |
| 温馨治愈 | 慢节奏、钢琴/吉他、柔和 | Vlog、生活记录、美食 |
| 悬疑紧张 | 低频音效、不协和音、渐强 | 纪录片、悬疑片、游戏 |
| 史诗大气 | 合唱、管弦、打击乐 | 电影预告、游戏CG |
| 科技未来 | 电子音色、合成器、节奏 | 科技产品、未来概念 |
| 欢快活泼 | 明快旋律、轻快节奏 | 卡通、儿童内容、广告 |

#### 1.3.2 音效SFX (Sound Effects)

音效是用于增强画面真实感或艺术表现力的声音素材。

**分类体系：**
- **环境音效**：城市、自然、室内、交通、人群
- **动作音效**：打斗、爆炸、碰撞、开关门、脚步
- **电子音效**：UI交互、科技感、警报、数据声
- **拟音音效**：衣物摩擦、道具碰撞、身体动作
- **转场音效**：嗖声、冲击声、上升音、下降音
- **动物音效**：各类动物叫声

#### 1.3.3 人声配音 (Voiceover / Narration)

人声配音包括旁白、解说、角色配音等语音素材。

**分类：**
- **按语种分**：中文（普通话/方言）、英语、日语、多语种
- **按性别年龄分**：男声、女声、童声、老年声
- **按风格分**：正式、亲切、活力、沉稳、磁性、可爱
- **按用途分**：广告配音、纪录片解说、课程讲解、游戏角色

#### 1.3.4 环境音 (Ambience / Atmosphere)

环境音是用于营造场景空间感的背景声音。

**常见类型：**
- 室内环境：办公室、咖啡馆、家庭、教室、体育馆
- 室外环境：城市街道、公园、森林、海边、山顶
- 天气环境：雨声、雷声、风声、下雪
- 交通环境：地铁、飞机、汽车、轮船

#### 1.3.5 白噪音 (White Noise)

白噪音是具有均匀频谱密度分布的随机声音信号。

**类型：**
- 白噪音（White Noise）：全频段均匀
- 粉噪音（Pink Noise）：低频更强，更自然
- 棕噪音（Brown Noise）：低频更强，深沉
- 自然白噪音：雨声、海浪声、风扇声、虫鸣

#### 1.3.6 配乐分段 (Stems / Segments)

配乐分段是将完整音乐拆分为多个独立音轨或段落，方便灵活编辑。

**分段形式：**
- **分轨Stems**：鼓组、贝斯、和弦、旋律、人声分别独立
- **段落结构**：Intro、Verse、Chorus、Bridge、Outro
- **时长版本**：完整版、60s版、30s版、15s版、循环版

### 1.4 图片素材详解

#### 1.4.1 照片素材 (Photography)

**分类维度：**
- 题材：人像、风光、建筑、美食、产品、动物、植物
- 风格：写实、复古、日系、赛博朋克、电影感、极简
- 构图：横构图、竖构图、方构图、全景
- 授权：版权免费、商用授权、编辑使用

#### 1.4.2 插画素材 (Illustration)

**风格分类：**
- 扁平插画（Flat Design）
- 渐变插画（Gradient Illustration）
- 手绘插画（Hand-drawn）
- 3D插画（3D Illustration）
- 线条插画（Line Art）
- 水彩插画（Watercolor）
- 国风插画（Chinese Style）
- 赛博朋克（Cyberpunk）

#### 1.4.3 图标素材 (Icons)

**设计风格：**
- 线性图标（Outline）
- 填充图标（Filled / Glyph）
- 双色图标（Duo-tone）
- 渐变图标（Gradient）
- 3D图标（3D Style）

**常用格式：**
- SVG：矢量格式，可无限缩放
- PNG：位图格式，支持透明背景
- ICO：Windows图标格式
- ICNS：macOS图标格式

#### 1.4.4 纹理素材 (Textures)

**常见类型：**
- 材质纹理：木纹、石纹、金属、布料、皮革、纸张
- 自然纹理：木纹、大理石、水流、火焰、云层
- 人工纹理：划痕、噪点、颗粒、做旧、故障艺术
- 抽象纹理：渐变、几何、流体、噪波

#### 1.4.5 背景素材 (Backgrounds)

**分类：**
- 纯色背景
- 渐变背景
- 图案背景
- 模糊背景（虚化）
- 场景背景

#### 1.4.6 PNG素材

PNG素材是带有透明通道的图片素材，可直接用于合成。

**常见类型：**
- 人物PNG：各类人物形象
- 物品PNG：产品、道具、装饰元素
- 装饰PNG：边框、花纹、点缀元素
- 文字PNG：艺术字、标题设计

### 1.5 3D素材详解

#### 1.5.1 模型 (3D Models)

**分类：**
- 角色模型：人物、动物、生物
- 场景模型：建筑、自然、室内
- 道具模型：家具、工具、武器、车辆
- 基础模型：几何体、预设体

**格式：**
- 通用格式：FBX, OBJ, GLB/GLTF, 3DS
- 软件原生：Blend (Blender), Max (3ds Max), C4D (Cinema 4D), Ma (Maya)

#### 1.5.2 材质 (Materials / Textures)

**材质类型：**
- PBR材质：Base Color, Normal, Roughness, Metallic, AO
- 传统材质：Diffuse, Specular, Bump, Displacement
- 程序材质：程序化生成的材质节点

**纹理分辨率：** 1K, 2K, 4K, 8K

#### 1.5.3 HDRI (High Dynamic Range Imaging)

HDRI是高动态范围环境贴图，用于3D场景的环境光照和反射。

**分类：**
- 室内HDRI：工作室、展厅、家居
- 室外HDRI：城市、自然、日出日落、阴天
- 工作室HDRI：影棚、产品展示环境
- 抽象HDRI：渐变、纯色、科技感

#### 1.5.4 粒子预设 (Particle Presets)

粒子预设是粒子系统的参数配置文件，可直接调用生成粒子效果。

**软件支持：**
- After Effects：Trapcode Particular, Form, Stardust
- Cinema 4D：Thinking Particles, X-Particles
- Blender：粒子系统, MantaFlow, Flip Fluids
- Houdini：VEX粒子系统

### 1.6 模板素材详解

#### 1.6.1 AE模板 (After Effects Templates)

**分类：**
- 开场片头：Logo动画、文字标题、电影片头
- 展示模板：产品展示、图片轮播、数据图表
- 特效模板：粒子特效、光效预设、场景合成
- 社交媒体：竖屏短视频、Instagram故事、YouTube片头

#### 1.6.2 PR模板 (Premiere Pro Templates)

- MOGRT模板：可在PR中直接修改的动态图形模板
- 工程文件：完整的PR项目文件
- 转场预设：PR原生转场扩展

#### 1.6.3 PS模板 (Photoshop Templates)

- 海报模板、Banner模板、社交媒体模板
-  mockup模板：产品样机、展示样机
- 修片预设：动作、LUT、样式

#### 1.6.4 DaVinci模板

- 调色预设：Power Grade, LUT
- 转场模板：Fusion转场
- 标题模板：Fusion标题生成器

### 1.7 LUT与预设详解

#### 1.7.1 调色LUT (Look-Up Table)

**LUT类型：**
- **1D LUT**：单通道映射，用于曝光/对比度调整
- **3D LUT**：三维色彩映射，用于整体风格化调色
- **技术LUT**：Log转Rec.709、色彩空间转换
- **创意LUT**：电影感、复古、赛博朋克、日系小清新

**常见格式：** .cube, .3dl, .look, .mga, .csp

#### 1.7.2 效果预设 (Effects Presets)

- AE效果预设：.ffx格式
- PR效果预设：.prfpset格式
- DaVinci Power Grade：.drx格式
- 节点树预设：组合效果链

#### 1.7.3 转场预设 (Transition Presets)

- 软件原生转场预设
- 第三方转场插件预设
- 自定义转场动画预设

#### 1.8.2 光效素材

### 3.1 关键词搜索技巧

#### 3.1.1 布尔运算搜索

布尔运算是最基础也是最强大的搜索技巧，几乎所有搜索引擎都支持。

**基本运算符：**

| 运算符 | 语法 | 说明 | 示例 |
|--------|------|------|------|
| AND | A AND B | 同时包含A和B | city AND night |
| OR | A OR B | 包含A或B | drone OR aerial |
| NOT | NOT A | 不包含A | landscape NOT people |
| 引号 | "A B" | 精确匹配短语 | "time lapse" |
| 星号 | A* | 通配符匹配 | back* (匹配background, backlight等) |

**高级组合示例：**
```
("4k" OR "ultra hd") AND (nature AND landscape) NOT people AND (drone OR aerial)
```

#### 3.1.3 相似度检索

相似度检索是基于内容特征的搜索技术，能够找到视觉上相似的素材。

**技术原理：**
1. 提取素材的特征向量（Feature Vector）
2. 计算向量间的距离（余弦相似度、欧氏距离）
3. 按相似度排序返回结果

**常用特征提取方法：**
- **颜色特征**：颜色直方图、颜色矩、颜色相关图
- **纹理特征**：LBP、GLCM、Gabor小波
- **形状特征**：SIFT、SURF、HOG
- **深度特征**：CNN特征（VGG、ResNet、CLIP）

**CLIP语义相似度：**
CLIP (Contrastive Language-Image Pre-training) 是OpenAI提出的多模态模型，能够将文字和图片映射到同一特征空间，实现真正的"语义搜索"。

```python
# 伪代码：CLIP相似度搜索
import clip
import torch

model, preprocess = clip.load("ViT-B/32")

# 编码文本
text = clip.tokenize(["a cat sitting on a chair"]).to(device)
with torch.no_grad():
    text_features = model.encode_text(text)

# 编码图片库
image_features_list = []
for image_path in image_paths:
    image = preprocess(Image.open(image_path)).unsqueeze(0).to(device)
    with torch.no_grad():
        image_features = model.encode_image(image)
    image_features_list.append(image_features)

# 计算相似度
similarities = []
for img_feat in image_features_list:
    sim = torch.cosine_similarity(text_features, img_feat)
    similarities.append(sim.item())
```

```bash
ffmpeg -framerate 24 -i frame_%04d.png -c:v libx264 -crf 18 -pix_fmt yuv420p output.mp4
```

```python
import cv2
import numpy as np

def remove_watermark_inpaint(image_path, mask_path, output_path):
    img = cv2.imread(image_path)

    # INPAINT_TELEA 或 INPAINT_NS
    result = cv2.inpaint(img, mask, 3, cv2.INPAINT_TELEA)
    
    cv2.imwrite(output_path, result)
```

### 5.3 缩略图系统

**策略：**

2. 多帧缩略图：3x3 / 4x4 网格预览
3. 动态预览：GIF/WebM短视频预览
4. 关键帧序列：场景变化帧

**FFmpeg生成缩略图命令：**

```bash
# 生成单帧缩略图（第10秒）
ffmpeg -i input.mp4 -ss 00:00:10 -vframes 1 -vf scale=320:-1 thumb.jpg

# 生成多帧网格（9帧）
ffmpeg -i input.mp4 -vf "select='eq(n,0)+eq(n,100)+eq(n,200)+eq(n,300)+eq(n,400)+eq(n,500)+eq(n,600)+eq(n,700)+eq(n,800)',scale=160:90,tile=3x3" -frames:v 1 grid.jpg

# 生成GIF预览
ffmpeg -i input.mp4 -ss 5 -t 3 -vf "scale=320:-1,fps=10" preview.gif

# 生成WebM预览（更小体积）
ffmpeg -i input.mp4 -ss 5 -t 5 -vf "scale=320:-1" -c:v libvpx-vp9 -crf 40 -b:v 0 -an preview.webm
```

#### 5.3.2 关键帧提取技术

**关键帧提取方法：**
1. **固定间隔采样**：每秒/每N帧取一帧
2. **场景变化检测**：帧差超过阈值时取帧
3. **内容感知**：基于画面信息量选择

```python
import cv2

def calculate_sharpness(image_path):
```

### 7.1 素材元数据提取器

**功能说明：** 提取视频、音频、图片文件的技术参数和元数据信息。

**依赖安装：**
```bash
pip install ffmpeg-python pillow exifread
# 需要系统安装 FFmpeg
```

**完整代码：**

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
素材元数据提取器 - Metadata Extractor
支持视频、音频、图片文件的元数据提取
"""

import os
import json
import subprocess
from pathlib import Path
from dataclasses import dataclass, asdict
from typing import Optional, Dict, Any
import re


@dataclass
class VideoMetadata:
    filename: str
    file_path: str
    file_size: int
    duration: float
    width: int
    height: int
    codec: str
    bitrate: int
    fps: float
    pixel_format: str
    color_space: str
    audio_codec: str
    audio_sample_rate: int
    audio_channels: int
    audio_bitrate: int


@dataclass
class AudioMetadata:
    filename: str
    file_path: str
    file_size: int
    duration: float
    codec: str
    sample_rate: int
    channels: int
    bitrate: int
    bit_depth: int


@dataclass
class ImageMetadata:
    filename: str
    file_path: str
    file_size: int
    width: int
    height: int
    format: str
    mode: str
    dpi: tuple
    exif: Dict[str, str]


class MetadataExtractor:
    """元数据提取器"""
    
    VIDEO_EXTENSIONS = {'.mp4', '.mov', '.avi', '.mkv', '.webm', '.flv', 
                        '.wmv', '.m4v', '.mpeg', '.mpg', '.ts', '.mxf'}
    AUDIO_EXTENSIONS = {'.mp3', '.wav', '.flac', '.aac', '.ogg', '.m4a', 
                        '.wma', '.aiff', '.opus', '.mid'}
    IMAGE_EXTENSIONS = {'.jpg', '.jpeg', '.png', '.gif', '.bmp', '.tiff', 
                        '.tif', '.webp', '.svg', '.raw', '.exr'}
    
    def __init__(self):
        self._check_ffmpeg()
    
    def _check_ffmpeg(self):
        """检查FFmpeg是否可用"""
        try:
            subprocess.run(['ffprobe', '-version'], 
                         capture_output=True, check=True)
        except (FileNotFoundError, subprocess.CalledProcessError):
            print("警告: 未找到 ffprobe，视频/音频元数据提取将受限")
            self._has_ffmpeg = False
        else:
            self._has_ffmpeg = True
    
    def extract(self, file_path: str) -> Optional[Dict[str, Any]]:
        """提取文件元数据"""
        path = Path(file_path)
        if not path.exists():
            raise FileNotFoundError(f"文件不存在: {file_path}")
        
        ext = path.suffix.lower()
        
        if ext in self.VIDEO_EXTENSIONS:
            return self._extract_video(file_path)
        elif ext in self.AUDIO_EXTENSIONS:
            return self._extract_audio(file_path)
        elif ext in self.IMAGE_EXTENSIONS:
            return self._extract_image(file_path)
        else:
            return {
                'type': 'unknown',
                'filename': path.name,
                'file_path': str(path),
                'file_size': path.stat().st_size,
                'extension': ext
            }
    
    def _extract_video(self, file_path: str) -> Dict[str, Any]:
        """提取视频元数据"""
        path = Path(file_path)
        
        if not self._has_ffmpeg:
            return {
                'type': 'video',
                'filename': path.name,
                'file_path': str(path),
                'file_size': path.stat().st_size,
                'note': '未安装FFmpeg，数据不完整'
            }
        
        try:
            result = subprocess.run(
                ['ffprobe', '-v', 'quiet', '-print_format', 'json',
                 '-show_format', '-show_streams', str(path)],
                capture_output=True, text=True, check=True
            )
            data = json.loads(result.stdout)
            
            video_stream = None
            audio_stream = None
            
            for stream in data.get('streams', []):
                if stream.get('codec_type') == 'video' and video_stream is None:
                    video_stream = stream
                elif stream.get('codec_type') == 'audio' and audio_stream is None:
                    audio_stream = stream
            
            if video_stream is None:
                return {'type': 'video', 'error': '未找到视频流'}
            
            fps = 30.0
            if 'r_frame_rate' in video_stream:
                rate_str = video_stream['r_frame_rate']
                if '/' in rate_str:
                    num, den = map(float, rate_str.split('/'))
                    if den > 0:
                        fps = round(num / den, 2)
            
            meta = VideoMetadata(
                filename=path.name,
                file_path=str(path),
                file_size=path.stat().st_size,
                duration=float(data.get('format', {}).get('duration', 0)),
                width=int(video_stream.get('width', 0)),
                height=int(video_stream.get('height', 0)),
                codec=video_stream.get('codec_name', ''),
                bitrate=int(data.get('format', {}).get('bit_rate', 0)),
                fps=fps,
                pixel_format=video_stream.get('pix_fmt', ''),
                color_space=video_stream.get('color_space', ''),
                audio_codec=audio_stream.get('codec_name', '') if audio_stream else '',
                audio_sample_rate=int(audio_stream.get('sample_rate', 0)) if audio_stream else 0,
                audio_channels=int(audio_stream.get('channels', 0)) if audio_stream else 0,
                audio_bitrate=int(audio_stream.get('bit_rate', 0)) if audio_stream else 0,
            )
            
            result_dict = asdict(meta)
            result_dict['type'] = 'video'
            result_dict['resolution'] = f"{meta.width}x{meta.height}"
            result_dict['aspect_ratio'] = round(meta.width / meta.height, 2) if meta.height > 0 else 0
            result_dict['file_size_mb'] = round(meta.file_size / (1024 * 1024), 2)
            result_dict['duration_formatted'] = self._format_duration(meta.duration)
            result_dict['bitrate_mbps'] = round(meta.bitrate / (1024 * 1024), 2) if meta.bitrate > 0 else 0
            
            return result_dict
            
        except Exception as e:
            return {'type': 'video', 'error': str(e)}
    
    def _extract_audio(self, file_path: str) -> Dict[str, Any]:
        """提取音频元数据"""
        path = Path(file_path)
        
        if not self._has_ffmpeg:
            return {
                'type': 'audio',
                'filename': path.name,
                'file_path': str(path),
                'file_size': path.stat().st_size,
                'note': '未安装FFmpeg，数据不完整'
            }
        
        try:
            result = subprocess.run(
                ['ffprobe', '-v', 'quiet', '-print_format', 'json',
                 '-show_format', '-show_streams', str(path)],
                capture_output=True, text=True, check=True
            )
            data = json.loads(result.stdout)
            
            audio_stream = None
            for stream in data.get('streams', []):
                if stream.get('codec_type') == 'audio':
                    audio_stream = stream
                    break
            
            if audio_stream is None:
                return {'type': 'audio', 'error': '未找到音频流'}
            
            meta = AudioMetadata(
                filename=path.name,
                file_path=str(path),
                file_size=path.stat().st_size,
                duration=float(data.get('format', {}).get('duration', 0)),
                codec=audio_stream.get('codec_name', ''),
                sample_rate=int(audio_stream.get('sample_rate', 0)),
                channels=int(audio_stream.get('channels', 0)),
                bitrate=int(data.get('format', {}).get('bit_rate', 0)),
                bit_depth=int(audio_stream.get('bits_per_sample', 0)),
            )
            
            result_dict = asdict(meta)
            result_dict['type'] = 'audio'
            result_dict['file_size_mb'] = round(meta.file_size / (1024 * 1024), 2)
            result_dict['duration_formatted'] = self._format_duration(meta.duration)
            result_dict['bitrate_kbps'] = round(meta.bitrate / 1024, 1) if meta.bitrate > 0 else 0
            
            return result_dict
            
        except Exception as e:
            return {'type': 'audio', 'error': str(e)}
    
    def _extract_image(self, file_path: str) -> Dict[str, Any]:
        """提取图片元数据"""
        path = Path(file_path)
        
        try:
            from PIL import Image, ExifTags
            
            with Image.open(str(path)) as img:
                exif_data = {}
                try:
                    raw_exif = img._getexif()
                    if raw_exif:
                        exif_data = {
                            ExifTags.TAGS.get(k, str(k)): str(v) 
                            for k, v in raw_exif.items()
                            if k in ExifTags.TAGS
                        }
                except Exception:
                    pass
                
                meta = ImageMetadata(
                    filename=path.name,
                    file_path=str(path),
                    file_size=path.stat().st_size,
                    width=img.width,
                    height=img.height,
                    format=img.format,
                    mode=img.mode,
                    dpi=img.info.get('dpi', (0, 0)),
                    exif=exif_data,
                )
                
                result_dict = asdict(meta)
                result_dict['type'] = 'image'
                result_dict['resolution'] = f"{meta.width}x{meta.height}"
                result_dict['aspect_ratio'] = round(meta.width / meta.height, 2) if meta.height > 0 else 0
                result_dict['file_size_mb'] = round(meta.file_size / (1024 * 1024), 2)
                result_dict['megapixels'] = round((meta.width * meta.height) / 1_000_000, 2)
                
                return result_dict
                
        except ImportError:
            return {
                'type': 'image',
                'filename': path.name,
                'file_path': str(path),
                'file_size': path.stat().st_size,
                'note': '未安装Pillow，数据不完整'
            }
        except Exception as e:
            return {'type': 'image', 'error': str(e)}
    
    def extract_batch(self, directory: str, recursive: bool = True) -> list:
        """批量提取目录下所有文件的元数据"""
        results = []
        path = Path(directory)
        
        if not path.is_dir():
            raise ValueError(f"不是有效目录: {directory}")
        
        pattern = '**/*' if recursive else '*'
        
        for file_path in path.glob(pattern):
            if file_path.is_file():
                ext = file_path.suffix.lower()
                if ext in (self.VIDEO_EXTENSIONS | self.AUDIO_EXTENSIONS | self.IMAGE_EXTENSIONS):
                    try:
                        meta = self.extract(str(file_path))
                        results.append(meta)
                    except Exception as e:
                        results.append({
                            'file_path': str(file_path),
                            'error': str(e)
                        })
        
        return results
    
    def _format_duration(self, seconds: float) -> str:
        """格式化时长"""
        if seconds <= 0:
            return "00:00:00"
        hours = int(seconds // 3600)
        minutes = int((seconds % 3600) // 60)
        secs = int(seconds % 60)
        return f"{hours:02d}:{minutes:02d}:{secs:02d}"
    
    def export_json(self, metadata_list: list, output_path: str):
        """导出为JSON文件"""
        with open(output_path, 'w', encoding='utf-8') as f:
            json.dump(metadata_list, f, ensure_ascii=False, indent=2)


def main():
    """命令行入口"""
    import argparse
    
    parser = argparse.ArgumentParser(description='素材元数据提取器')
    parser.add_argument('path', help='文件或目录路径')
    parser.add_argument('-r', '--recursive', action='store_true', 
                       help='递归处理子目录')
    parser.add_argument('-o', '--output', help='输出JSON文件路径')
    parser.add_argument('-t', '--type', 
                       choices=['video', 'audio', 'image', 'all'],
                       default='all', help='指定处理类型')
    
    args = parser.parse_args()
    
    extractor = MetadataExtractor()
    path = Path(args.path)
    
    if path.is_file():
        result = extractor.extract(str(path))
        print(json.dumps(result, ensure_ascii=False, indent=2))
    elif path.is_dir():
        results = extractor.extract_batch(str(path), args.recursive)
        print(f"共处理 {len(results)} 个文件")
        
        if args.output:
            extractor.export_json(results, args.output)
            print(f"结果已导出到: {args.output}")
        else:
            for r in results[:10]:
                print(f"\n{r.get('filename', '')} - {r.get('type', '')}")
            if len(results) > 10:
                print(f"\n... 还有 {len(results)-10} 个文件")


if __name__ == '__main__':
    main()
```

**功能说明：** 按自定义规则批量重命名素材文件，支持多种命名模板。

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
批量重命名工具 - Batch Rename Tool
支持多种命名规则和模板
"""

import os
import re
import shutil
from pathlib import Path
from dataclasses import dataclass
from typing import List, Callable, Optional
import hashlib


@dataclass
class RenameRule:
    """重命名规则"""
    name: str
    description: str
    function: Callable


class BatchRenamer:
    """批量重命名工具"""
    
    def __init__(self, dry_run: bool = False):
        self.dry_run = dry_run
        self.operations = []  # 记录所有操作
    
    def add_prefix(self, files: List[str], prefix: str) -> List[tuple]:
        """添加前缀"""
        ops = []
        for file_path in files:
            path = Path(file_path)
            new_name = f"{prefix}{path.name}"
            new_path = path.parent / new_name
            ops.append((str(path), str(new_path)))
        return ops
    
    def add_suffix(self, files: List[str], suffix: str, 
                   before_ext: bool = True) -> List[tuple]:
        """添加后缀"""
        ops = []
        for file_path in files:
            path = Path(file_path)
            if before_ext:
                new_name = f"{path.stem}{suffix}{path.suffix}"
            else:
                new_name = f"{path.name}{suffix}"
            new_path = path.parent / new_name
            ops.append((str(path), str(new_path)))
        return ops
    
    def replace_text(self, files: List[str], old_text: str, 
                     new_text: str) -> List[tuple]:
        """替换文件名中的文字"""
        ops = []
        for file_path in files:
            path = Path(file_path)
            new_name = path.name.replace(old_text, new_text)
            new_path = path.parent / new_name
            ops.append((str(path), str(new_path)))
        return ops
    
    def regex_replace(self, files: List[str], pattern: str, 
                      replacement: str) -> List[tuple]:
        """正则表达式替换"""
        ops = []
        for file_path in files:
            path = Path(file_path)
            new_name = re.sub(pattern, replacement, path.name)
            new_path = path.parent / new_name
            ops.append((str(path), str(new_path)))
        return ops
    
    def sequential_numbering(self, files: List[str], prefix: str = "file_",
                            start: int = 1, padding: int = 4,
                            keep_ext: bool = True) -> List[tuple]:
        """序列编号重命名"""
        ops = []
        for i, file_path in enumerate(files):
            path = Path(file_path)
            num = str(start + i).zfill(padding)
            if keep_ext:
                new_name = f"{prefix}{num}{path.suffix}"
            else:
                new_name = f"{prefix}{num}"
            new_path = path.parent / new_name
            ops.append((str(path), str(new_path)))
        return ops
    
    def to_lowercase(self, files: List[str]) -> List[tuple]:
        """转为小写"""
        ops = []
        for file_path in files:
            path = Path(file_path)
            new_name = path.name.lower()
            new_path = path.parent / new_name
            ops.append((str(path), str(new_path)))
        return ops
    
    def to_uppercase(self, files: List[str]) -> List[tuple]:
        """转为大写"""
        ops = []
        for file_path in files:
            path = Path(file_path)
            new_name = path.name.upper()
            new_path = path.parent / new_name
            ops.append((str(path), str(new_path)))
        return ops
    
    def remove_spaces(self, files: List[str], 
                     replacement: str = "_") -> List[tuple]:
        """移除空格"""
        ops = []
        for file_path in files:
            path = Path(file_path)
            new_name = path.name.replace(" ", replacement)
            new_path = path.parent / new_name
            ops.append((str(path), str(new_path)))
        return ops
    
    def template_rename(self, files: List[str], template: str,
                       metadata_extractor=None) -> List[tuple]:
        """
        使用模板重命名
        
        模板变量：
        {index} - 序号
        {name} - 原始文件名（不含扩展）
        {ext} - 扩展名（不含点）
        {date} - 文件修改日期 YYYYMMDD
        {hash} - 文件MD5哈希（前8位）
        {width} - 宽度（需要metadata）
        {height} - 高度（需要metadata）
        {type} - 类型（video/audio/image）
        """
        ops = []
        
        for i, file_path in enumerate(files):
            path = Path(file_path)
            stat = path.stat()
            
            replacements = {
                'index': str(i + 1).zfill(4),
                'name': path.stem,
                'ext': path.suffix.lstrip('.'),
                'date': Path(file_path).stat().st_mtime,
            }
            
            if '{date}' in template:
                from datetime import datetime
                date_str = datetime.fromtimestamp(stat.st_mtime).strftime('%Y%m%d')
                replacements['date'] = date_str
            
            if '{hash}' in template:
                file_hash = self._get_file_hash(str(path))
                replacements['hash'] = file_hash[:8]
            
            if metadata_extractor and ('{width}' in template or 
                                      '{height}' in template or 
                                      '{type}' in template):
                try:
                    meta = metadata_extractor(str(path))
                    replacements['width'] = str(meta.get('width', ''))
                    replacements['height'] = str(meta.get('height', ''))
                    replacements['type'] = meta.get('type', '')
                except Exception:
                    replacements['width'] = ''
                    replacements['height'] = ''
                    replacements['type'] = 'unknown'
            
            new_name = template
            for key, value in replacements.items():
                new_name = new_name.replace('{' + key + '}', str(value))
            
            new_path = path.parent / new_name
            ops.append((str(path), str(new_path)))
        
        return ops
    
    def _get_file_hash(self, file_path: str) -> str:
        """获取文件MD5哈希"""
        md5 = hashlib.md5()
        with open(file_path, 'rb') as f:
            for chunk in iter(lambda: f.read(8192), b''):
                md5.update(chunk)
        return md5.hexdigest()
    
    def execute(self, operations: List[tuple]) -> dict:
        """执行重命名操作"""
        results = {
            'success': [],
            'failed': [],
            'skipped': []
        }
        
        for old_path, new_path in operations:
            try:
                if old_path == new_path:
                    results['skipped'].append((old_path, '名称未变'))
                    continue
                
                if Path(new_path).exists():
                    results['skipped'].append((old_path, '目标文件已存在'))
                    continue
                
                if self.dry_run:
                    results['success'].append((old_path, new_path))
                else:
                    shutil.move(old_path, new_path)
                    results['success'].append((old_path, new_path))
                    
            except Exception as e:
                results['failed'].append((old_path, new_path, str(e)))
        
        self.operations.extend(operations)
        return results
    
    def preview(self, operations: List[tuple]) -> str:
        """预览重命名结果"""
        lines = []
        lines.append(f"{'原文件名':<50} -> {'新文件名':<50}")
        lines.append("-" * 100)
        
        for old_path, new_path in operations:
            old_name = Path(old_path).name
            new_name = Path(new_path).name
            lines.append(f"{old_name:<50} -> {new_name:<50}")
        
        return "\n".join(lines)
    
    def undo(self):
        """撤销上一批操作（反向执行）"""
        if not self.operations:
            return {'success': [], 'failed': []}
        
        reversed_ops = [(new, old) for old, new in reversed(self.operations)]
        results = {'success': [], 'failed': []}
        
        for old_path, new_path in reversed_ops:
            try:
                if not self.dry_run:
                    shutil.move(old_path, new_path)
                results['success'].append((old_path, new_path))
            except Exception as e:
                results['failed'].append((old_path, new_path, str(e)))
        
        return results


def scan_files(directory: str, extensions: Optional[List[str]] = None,
               recursive: bool = True) -> List[str]:
    """扫描目录中的文件"""
    files = []
    path = Path(directory)
    
    if not path.is_dir():
        return files
    
    pattern = '**/*' if recursive else '*'
    
    for file_path in path.glob(pattern):
        if file_path.is_file():
            if extensions:
                if file_path.suffix.lower() in [e.lower() for e in extensions]:
                    files.append(str(file_path))
            else:
                files.append(str(file_path))
    
    return sorted(files)


def main():
    """命令行入口"""
    import argparse
    
    parser = argparse.ArgumentParser(description='批量重命名工具')
    parser.add_argument('directory', help='目标目录')
    parser.add_argument('--prefix', help='添加前缀')
    parser.add_argument('--suffix', help='添加后缀')
    parser.add_argument('--replace', nargs=2, metavar=('OLD', 'NEW'),
                       help='替换文字')
    parser.add_argument('--regex', nargs=2, metavar=('PATTERN', 'REPL'),
                       help='正则替换')
    parser.add_argument('--sequential', action='store_true',
                       help='序列编号')
    parser.add_argument('--seq-prefix', default='file_',
                       help='序列编号前缀')
    parser.add_argument('--seq-start', type=int, default=1,
                       help='序列起始编号')
    parser.add_argument('--seq-padding', type=int, default=4,
                       help='编号填充位数')
    parser.add_argument('--lower', action='store_true', help='转小写')
    parser.add_argument('--upper', action='store_true', help='转大写')
    parser.add_argument('--remove-spaces', action='store_true',
                       help='移除空格')
    parser.add_argument('--template', help='命名模板')
    parser.add_argument('-e', '--ext', help='指定文件扩展名（逗号分隔）')
    parser.add_argument('-r', '--recursive', action='store_true',
                       help='递归子目录')
    parser.add_argument('--dry-run', action='store_true',
                       help='仅预览，不实际执行')
    parser.add_argument('--preview', action='store_true',
                       help='预览重命名结果')
    
    args = parser.parse_args()
    
    extensions = None
    if args.ext:
        extensions = [e.strip() for e in args.ext.split(',')]
    
    files = scan_files(args.directory, extensions, args.recursive)
    print(f"找到 {len(files)} 个文件")
    
    if not files:
        return
    
    renamer = BatchRenamer(dry_run=args.dry_run)
    ops = []
    
    if args.prefix:
        ops = renamer.add_prefix(files, args.prefix)
    elif args.suffix:
        ops = renamer.add_suffix(files, args.suffix)
    elif args.replace:
        ops = renamer.replace_text(files, args.replace[0], args.replace[1])
    elif args.regex:
        ops = renamer.regex_replace(files, args.regex[0], args.regex[1])
    elif args.sequential:
        ops = renamer.sequential_numbering(
            files, args.seq_prefix, args.seq_start, args.seq_padding
        )
    elif args.lower:
        ops = renamer.to_lowercase(files)
    elif args.upper:
        ops = renamer.to_uppercase(files)
    elif args.remove_spaces:
        ops = renamer.remove_spaces(files)
    elif args.template:
        ops = renamer.template_rename(files, args.template)
    else:
        print("请指定重命名规则")
        return
    
    if args.preview or args.dry_run:
        print(renamer.preview(ops))
    
    if not args.preview:
        results = renamer.execute(ops)
        print(f"\n执行完成: 成功 {len(results['success'])} 个, "
              f"跳过 {len(results['skipped'])} 个, "
              f"失败 {len(results['failed'])} 个")


if __name__ == '__main__':
    main()
```

### 7.3 缩略图生成器

**功能说明：** 自动生成视频关键帧缩略图，支持单帧、网格、GIF预览。

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
缩略图生成器 - Thumbnail Generator
视频关键帧提取、缩略图生成、网格预览、GIF预览
"""

import os
import subprocess
import json
from pathlib import Path
from dataclasses import dataclass
from typing import List, Optional, Tuple
import hashlib


@dataclass
class ThumbnailConfig:
    """缩略图配置"""
    width: int = 320
    quality: int = 85
    format: str = 'jpg'
    grid_cols: int = 3
    grid_rows: int = 3
    gif_duration: int = 3
    gif_fps: int = 10


class VideoThumbnailGenerator:
    """视频缩略图生成器"""
    
    SUPPORTED_FORMATS = {'.mp4', '.mov', '.avi', '.mkv', '.webm', 
                         '.flv', '.m4v', '.mpeg', '.ts'}
    
    def __init__(self, config: Optional[ThumbnailConfig] = None):
        self.config = config or ThumbnailConfig()
        self._check_ffmpeg()
    
    def _check_ffmpeg(self):
        """检查FFmpeg"""
        try:
            subprocess.run(['ffmpeg', '-version'], capture_output=True, check=True)
            self._has_ffmpeg = True
        except (FileNotFoundError, subprocess.CalledProcessError):
            self._has_ffmpeg = False
            raise RuntimeError("未找到FFmpeg，请先安装")
    
    def get_duration(self, video_path: str) -> float:
        """获取视频时长"""
        try:
            result = subprocess.run(
                ['ffprobe', '-v', 'quiet', '-print_format', 'json',
                 '-show_format', video_path],
                capture_output=True, text=True, check=True
            )
            data = json.loads(result.stdout)
            return float(data.get('format', {}).get('duration', 0))
        except Exception:
            return 0
    
    def generate_single(self, video_path: str, output_path: str,
                       time_point: Optional[float] = None) -> bool:
        """
        生成单帧缩略图
        
        Args:
            video_path: 视频文件路径
            output_path: 输出图片路径
            time_point: 时间点（秒），默认中间帧
        """
        path = Path(video_path)
        if not path.exists():
            raise FileNotFoundError(f"视频文件不存在: {video_path}")
        
        if time_point is None:
            duration = self.get_duration(video_path)
            time_point = duration / 2 if duration > 0 else 5
        
        try:
            cmd = [
                'ffmpeg', '-y',
                '-ss', str(time_point),
                '-i', video_path,
                '-vframes', '1',
                '-vf', f'scale={self.config.width}:-1',
                '-q:v', str(self.config.quality),
                output_path
            ]
            subprocess.run(cmd, capture_output=True, check=True)
            return Path(output_path).exists()
        except Exception as e:
            print(f"生成缩略图失败: {e}")
            return False
    
    def generate_keyframes(self, video_path: str, output_dir: str,
                          num_frames: int = 9) -> List[str]:
        """
        生成关键帧缩略图（均匀采样）
        
        Args:
            video_path: 视频文件路径
            output_dir: 输出目录
            num_frames: 关键帧数量
        
        Returns:
            生成的图片路径列表
        """
        path = Path(video_path)
        if not path.exists():
            raise FileNotFoundError(f"视频文件不存在: {video_path}")
        
        output_path = Path(output_dir)
        output_path.mkdir(parents=True, exist_ok=True)
        
        duration = self.get_duration(video_path)
        if duration <= 0:
            return []
        
        generated = []
        interval = duration / (num_frames + 1)
        
        for i in range(num_frames):
            time_point = interval * (i + 1)
            output_file = output_path / f"keyframe_{i+1:03d}.{self.config.format}"
            
            if self.generate_single(video_path, str(output_file), time_point):
                generated.append(str(output_file))
        
        return generated
    
    def generate_grid(self, video_path: str, output_path: str,
                     cols: Optional[int] = None, 
                     rows: Optional[int] = None) -> bool:
        """
        生成网格缩略图
        
        Args:
            video_path: 视频文件路径
            output_path: 输出图片路径
            cols: 列数
            rows: 行数
        """
        cols = cols or self.config.grid_cols
        rows = rows or self.config.grid_rows
        num_frames = cols * rows
        
        path = Path(video_path)
        if not path.exists():
            raise FileNotFoundError(f"视频文件不存在: {video_path}")
        
        import tempfile
        with tempfile.TemporaryDirectory() as tmpdir:
            frames = self.generate_keyframes(video_path, tmpdir, num_frames)
            
            if len(frames) < num_frames:
                print(f"警告: 只生成了 {len(frames)} 帧，需要 {num_frames} 帧")
            
            if not frames:
                return False
            
            try:
                inputs = []
                for f in frames:
                    inputs.extend(['-i', f])
                
                filter_str = f"tile={cols}x{rows}"
                
                cmd = [
                    'ffmpeg', '-y',
                    *inputs,
                    '-filter_complex', filter_str,
                    '-q:v', str(self.config.quality),
                    output_path
                ]
                subprocess.run(cmd, capture_output=True, check=True)
                return Path(output_path).exists()
            except Exception as e:
                print(f"生成网格缩略图失败: {e}")
                return False
    
    def generate_gif(self, video_path: str, output_path: str,
                     start_time: Optional[float] = None,
                     duration: Optional[int] = None) -> bool:
        """
        生成GIF预览
        
        Args:
            video_path: 视频文件路径
            output_path: 输出GIF路径
            start_time: 开始时间（秒）
            duration: 持续时间（秒）
        """
        path = Path(video_path)
        if not path.exists():
            raise FileNotFoundError(f"视频文件不存在: {video_path}")
        
        duration = duration or self.config.gif_duration
        
        if start_time is None:
            vid_duration = self.get_duration(video_path)
            start_time = max(0, (vid_duration - duration) / 2)
        
        try:
            palette_path = str(Path(output_path).parent / 'palette.png')
            
            cmd1 = [
                'ffmpeg', '-y',
                '-ss', str(start_time),
                '-t', str(duration),
                '-i', video_path,
                '-vf', f'fps={self.config.gif_fps},scale={self.config.width}:-1:flags=lanczos,palettegen',
                palette_path
            ]
            subprocess.run(cmd1, capture_output=True, check=True)
            
            cmd2 = [
                'ffmpeg', '-y',
                '-ss', str(start_time),
                '-t', str(duration),
                '-i', video_path,
                '-i', palette_path,
                '-filter_complex', 
                f'fps={self.config.gif_fps},scale={self.config.width}:-1:flags=lanczos[x];[x][1:v]paletteuse',
                output_path
            ]
            subprocess.run(cmd2, capture_output=True, check=True)
            
            if Path(palette_path).exists():
                Path(palette_path).unlink()
            
            return Path(output_path).exists()
        except Exception as e:
            print(f"生成GIF失败: {e}")
            return False
    
    def generate_webm_preview(self, video_path: str, output_path: str,
                              start_time: Optional[float] = None,
                              duration: Optional[int] = None) -> bool:
        """生成WebM预览（比GIF更小更清晰）"""
        path = Path(video_path)
        if not path.exists():
            raise FileNotFoundError(f"视频文件不存在: {video_path}")
        
        duration = duration or self.config.gif_duration
        
        if start_time is None:
            vid_duration = self.get_duration(video_path)
            start_time = max(0, (vid_duration - duration) / 2)
        
        try:
            cmd = [
                'ffmpeg', '-y',
                '-ss', str(start_time),
                '-t', str(duration),
                '-i', video_path,
                '-vf', f'scale={self.config.width}:-1',
                '-c:v', 'libvpx-vp9',
                '-crf', '40',
                '-b:v', '0',
                '-an',
                output_path
            ]
            subprocess.run(cmd, capture_output=True, check=True)
            return Path(output_path).exists()
        except Exception as e:
            print(f"生成WebM预览失败: {e}")
            return False
    
    def generate_all(self, video_path: str, output_dir: str) -> dict:
        """
        生成所有类型的缩略图
        
        Returns:
            各类型缩略图路径
        """
        path = Path(video_path)
        out_path = Path(output_dir)
        out_path.mkdir(parents=True, exist_ok=True)
        
        base_name = path.stem
        results = {
            'video': str(path),
            'single': None,
            'grid': None,
            'gif': None,
            'webm': None,
            'keyframes': []
        }
        
        single_path = out_path / f"{base_name}_thumb.{self.config.format}"
        if self.generate_single(video_path, str(single_path)):
            results['single'] = str(single_path)
        
        grid_path = out_path / f"{base_name}_grid.{self.config.format}"
        if self.generate_grid(video_path, str(grid_path)):
            results['grid'] = str(grid_path)
        
        keyframes_dir = out_path / f"{base_name}_keyframes"
        if keyframes_dir.exists() or True:
            keyframes = self.generate_keyframes(
                video_path, str(keyframes_dir), 9
            )
            results['keyframes'] = keyframes
        
        gif_path = out_path / f"{base_name}_preview.gif"
        if self.generate_gif(video_path, str(gif_path)):
            results['gif'] = str(gif_path)
        
        webm_path = out_path / f"{base_name}_preview.webm"
        if self.generate_webm_preview(video_path, str(webm_path)):
            results['webm'] = str(webm_path)
        
        return results
    
    def batch_generate(self, input_dir: str, output_dir: str,
                       types: List[str] = None,
                       recursive: bool = True) -> List[dict]:
        """
        批量生成缩略图
        
        Args:
            input_dir: 输入目录
            output_dir: 输出目录
            types: 生成类型 ['single', 'grid', 'gif', 'webm', 'all']
        """
        types = types or ['single']
        results = []
        
        input_path = Path(input_dir)
        output_path = Path(output_dir)
        
        pattern = '**/*' if recursive else '*'
        
        for video_file in input_path.glob(pattern):
            if (video_file.is_file() and 
                video_file.suffix.lower() in self.SUPPORTED_FORMATS):
                
                rel_path = video_file.relative_to(input_path)
                out_dir = output_path / rel_path.parent / video_file.stem
                
                try:
                    if 'all' in types:
                        result = self.generate_all(
                            str(video_file), str(out_dir)
                        )
                    else:
                        result = {'video': str(video_file)}
                        out_dir.mkdir(parents=True, exist_ok=True)
                        
                        if 'single' in types:
                            single_path = out_dir / f"{video_file.stem}_thumb.{self.config.format}"
                            if self.generate_single(str(video_file), str(single_path)):
                                result['single'] = str(single_path)
                        
                        if 'grid' in types:
                            grid_path = out_dir / f"{video_file.stem}_grid.{self.config.format}"
                            if self.generate_grid(str(video_file), str(grid_path)):
                                result['grid'] = str(grid_path)
                        
                        if 'gif' in types:
                            gif_path = out_dir / f"{video_file.stem}_preview.gif"
                            if self.generate_gif(str(video_file), str(gif_path)):
                                result['gif'] = str(gif_path)
                    
                    results.append(result)
                    print(f"处理完成: {video_file.name}")
                except Exception as e:
                    results.append({
                        'video': str(video_file),
                        'error': str(e)
                    })
                    print(f"处理失败: {video_file.name} - {e}")
        
        return results


class ImageThumbnailGenerator:
    """图片缩略图生成器"""
    
    SUPPORTED_FORMATS = {'.jpg', '.jpeg', '.png', '.gif', '.bmp', 
                         '.tiff', '.tif', '.webp'}
    
    def __init__(self, width: int = 320, height: int = None,
                 quality: int = 85):
        self.width = width
        self.height = height
        self.quality = quality
    
    def generate(self, image_path: str, output_path: str,
                fit: str = 'cover') -> bool:
        """
        生成图片缩略图
        
        Args:
            fit: 适配方式 - cover/contain/fill
        """
        try:
            from PIL import Image
            
            img = Image.open(image_path)
            
            if self.height is None:
                ratio = self.width / img.width
                new_height = int(img.height * ratio)
                new_size = (self.width, new_height)
            else:
                if fit == 'cover':
                    img_ratio = img.width / img.height
                    target_ratio = self.width / self.height
                    
                    if img_ratio > target_ratio:
                        new_height = self.height
                        new_width = int(img.width * (self.height / img.height))
                    else:
                        new_width = self.width
                        new_height = int(img.height * (self.width / img.width))
                    
                    img = img.resize((new_width, new_height), Image.LANCZOS)
                    
                    left = (new_width - self.width) / 2
                    top = (new_height - self.height) / 2
                    right = left + self.width
                    bottom = top + self.height
                    img = img.crop((left, top, right, bottom))
                    new_size = None
                elif fit == 'contain':
                    img.thumbnail((self.width, self.height), Image.LANCZOS)
                    new_size = None
                else:
                    new_size = (self.width, self.height)
            
            if new_size:
                img = img.resize(new_size, Image.LANCZOS)
            
            if output_path.lower().endswith(('.jpg', '.jpeg')):
                if img.mode in ('RGBA', 'P'):
                    img = img.convert('RGB')
                img.save(output_path, 'JPEG', quality=self.quality)
            else:
                img.save(output_path)
            
            return Path(output_path).exists()
        except ImportError:
            print("需要安装Pillow: pip install pillow")
            return False
        except Exception as e:
            print(f"生成缩略图失败: {e}")
            return False
    
    def batch_generate(self, input_dir: str, output_dir: str,
                       recursive: bool = True) -> List[dict]:
        """批量生成"""
        results = []
```

```python
        """检测文件类型"""
        ext = Path(file_path).suffix.lower()

            if ext in extensions:
                return type_name
        
        return 'unknown'
    
    def classify(self, file_path: str, 
                extra_text: Optional[str] = None) -> ClassificationResult:
        """
        分类单个文件
        
        Args:
            file_path: 文件路径
            extra_text: 额外的文本信息用于分类（如描述、标签）
        """
        path = Path(file_path)
        file_type = self.detect_type(file_path)
        
        if file_type == 'unknown':
            return ClassificationResult(
                file_path=str(path),
                type='unknown',
                category='uncategorized',
                subcategory='unknown',
                confidence=0.0
            )
        
        # 组合所有可用于分类的文本
        text_parts = [path.stem.lower()]
        
        # 添加路径中的目录名
        for part in path.parts[-4:-1]:  # 取最近4级目录
            text_parts.append(part.lower())
        
        if extra_text:
            text_parts.append(extra_text.lower())
        
        full_text = ' '.join(text_parts)
        
        # 匹配规则
        best_rule = None
        best_match_count = 0
        
        rules = self.rules.get(file_type, [])
        
        for rule in rules:
            match_count = 0
            for pattern in rule.patterns:
                if re.search(pattern, full_text, re.IGNORECASE):
                    match_count += 1
            
            if match_count > best_match_count:
                best_match_count = match_count
                best_rule = rule
        
        # 提取标签
        tags = self._extract_tags(full_text, file_type)
        
        # 计算置信度
        total_patterns = len(best_rule.patterns) if best_rule else 1
        confidence = min(best_match_count / total_patterns, 1.0) if best_rule else 0.0
        
        # 基于文件类型的基础置信度
        if file_type != 'unknown':
            confidence = max(confidence, 0.3)
        
        if best_rule:
            return ClassificationResult(
                file_path=str(path),
                type=file_type,
                category=best_rule.category,
                subcategory=best_rule.subcategory,
                tags=tags,
                confidence=round(confidence, 2)
            )
        else:
            return ClassificationResult(
                file_path=str(path),
                type=file_type,
                category='uncategorized',
                subcategory='misc',
                tags=tags,
                confidence=round(confidence, 2)

        Args:
            results: 分类结果列表

            move: True移动，False复制
            dry_run: 仅预览，不实际操作
        """
        target_path = Path(target_dir)
        stats = {
            'total': len(results),
            'moved': 0,
            'skipped': 0,
            'errors': [],
            'operations': []
        }

            if result.type == 'unknown' or result.type == 'error':
                stats['skipped'] += 1

            dest_dir = target_path / result.type / result.category
            if result.subcategory:
                dest_dir = dest_dir / result.subcategory
            
            dest_path = dest_dir / src_path.name

                            new_name = f"{src_path.stem}_{counter}{src_path.suffix}"
                            dest_path = dest_dir / new_name
                            counter += 1
                    
                    if move:
                        shutil.move(str(src_path), str(dest_path))
                    else:
                        shutil.copy2(str(src_path), str(dest_path))
                    
                    stats['moved'] += 1
                except Exception as e:
                    stats['errors'].append((str(src_path), str(e)))
            else:
                stats['moved'] += 1
        
        return stats
    
    def export_report(self, results: List[ClassificationResult],
```

```python
                ['yt-dlp', '--version'], capture_output=True, text=True
            )
            self._yt_dlp_version = result.stdout.strip()
            self._has_yt_dlp = True
        except FileNotFoundError:
            self._has_yt_dlp = False
            raise RuntimeError(
                "未找到yt-dlp，请先安装: pip install yt-dlp"
            )
    
    def add_task(self, url: str, output_dir: Optional[str] = None,
                 quality: str = "1080p", format_type: str = "video",
                 options: Optional[Dict] = None) -> DownloadTask:
        """
        添加下载任务
        
        Args:
            url: 下载链接
            output_dir: 输出目录
            quality: 质量 (best/1080p/720p/480p/audio)
            format_type: 类型 (video/audio)
            options: 额外选项
        """
        out_dir = Path(output_dir) if output_dir else self.download_dir
        out_dir.mkdir(parents=True, exist_ok=True)
        
        task = DownloadTask(
            url=url,
            output_dir=str(out_dir),
            quality=quality,
            format=format_type,
            options=options or {}
        )
        
        with self._lock:
            self.tasks[task.task_id] = task
        
        return task
    
    def add_batch_tasks(self, urls: List[str], 
                       output_dir: Optional[str] = None,
                       **kwargs) -> List[DownloadTask]:
        """批量添加任务"""
        tasks = []
        for url in urls:
            task = self.add_task(url, output_dir, **kwargs)
            tasks.append(task)
        return tasks
    
    def add_tasks_from_file(self, file_path: str,
                           output_dir: Optional[str] = None,
                           **kwargs) -> List[DownloadTask]:
        """从文件读取URL列表添加任务"""
        path = Path(file_path)
        if not path.exists():
            raise FileNotFoundError(f"文件不存在: {file_path}")
        
        urls = []
        with open(path, 'r', encoding='utf-8') as f:
            for line in f:
                line = line.strip()
                if line and not line.startswith('#'):
                    urls.append(line)
        
        return self.add_batch_tasks(urls, output_dir, **kwargs)
    
    def _build_command(self, task: DownloadTask) -> List[str]:
        """构建yt-dlp命令"""
        cmd = ['yt-dlp']
        
        # 输出模板
        output_template = str(Path(task.output_dir) / 
                             "%(title)s_%(height)s_%(id)s.%(ext)s")
        cmd.extend(['-o', output_template])
        
        # 格式选择
        if task.quality == 'audio':
            cmd.extend(['-x', '--audio-format', 'mp3', '--audio-quality', '0'])
        elif task.quality == 'best':
            cmd.extend(['-f', 'bestvideo+bestaudio/best'])
        else:
            height = task.quality.replace('p', '')
            fmt = (f'bestvideo[height<={height}]+bestaudio/'
                   f'best[height<={height}]')
            cmd.extend(['-f', fmt])
        
        # 输出进度信息（可解析）
        cmd.extend(['--newline', '--progress'])
        
        # 额外选项
        if task.options.get('proxy'):
            cmd.extend(['--proxy', task.options['proxy']])
        
        if task.options.get('limit_rate'):
            cmd.extend(['--limit-rate', task.options['limit_rate']])
        
        if task.options.get('subtitles'):
            cmd.extend(['--write-subs', '--sub-lang', 
                       task.options.get('sub_lang', 'en,zh-CN')])
        
        if task.options.get('thumbnail'):
            cmd.append('--write-thumbnail')
        
        if task.options.get('playlist'):
            cmd.append('--yes-playlist')
        else:
            cmd.append('--no-playlist')
        
        # URL
        cmd.append(task.url)
        
        return cmd
    
    def _parse_progress(self, line: str, task: DownloadTask):
        """解析进度行"""
        line = line.strip()
        
        # 匹配 "[download]  50.0% of ~10 MiB at 1.0 MiB/s ETA 00:00:10"
        if '[download]' in line and '%' in line:
            try:
                # 提取百分比
                percent_match = line.split('[download]')[1].strip()
                if '%' in percent_match:
                    percent_str = percent_match.split('%')[0].strip()
                    task.progress = float(percent_str)
                
                # 提取速度
                if 'at ' in line:
                    speed_part = line.split('at ')[1].split(' ')[0]
                    task.speed = speed_part
                
                # 提取ETA
                if 'ETA ' in line:
                    eta_part = line.split('ETA ')[1].strip()
                    task.eta = eta_part
                
            except (ValueError, IndexError):
                pass
        
        # 文件名
        if '[download] Destination:' in line:
            task.file_name = line.split('Destination:')[1].strip()
        
        # 文件大小
        if '[download]' in line and 'MiB' in line and 'at' in line:
            try:
                size_part = line.split('of')[1].strip().split('at')[0].strip()
                task.file_size = self._parse_size(size_part)
            except (IndexError, ValueError):
                pass
    
    def _parse_size(self, size_str: str) -> int:
        """解析大小字符串为字节数"""
        size_str = size_str.strip().upper()
        units = {'B': 1, 'KIB': 1024, 'MIB': 1024**2, 'GIB': 1024**3,
                 'KB': 1000, 'MB': 1000**2, 'GB': 1000**3}
        
        for unit, multiplier in units.items():
            if unit in size_str:
                try:
                    num = float(size_str.replace(unit, '').strip())
                    return int(num * multiplier)
                except ValueError:
                    pass
        
        return 0
    
    def download(self, task_id: str, 
                progress_callback: Optional[Callable] = None) -> bool:
        """执行下载任务"""
        with self._lock:
            task = self.tasks.get(task_id)
            if not task:
                raise ValueError(f"任务不存在: {task_id}")
            
            if task.status in (DownloadStatus.DOWNLOADING, DownloadStatus.COMPLETED):
                return False
            
            task.status = DownloadStatus.DOWNLOADING
            task.progress = 0.0
        
        cmd = self._build_command(task)
        
        try:
            process = subprocess.Popen(
                cmd,
                stdout=subprocess.PIPE,
                stderr=subprocess.STDOUT,
                text=True,
                bufsize=1,
                universal_newlines=True
            )
            
            self._processes[task_id] = process
            
            for line in process.stdout:
                self._parse_progress(line, task)
                
                if progress_callback:
                    progress_callback(task)
            
            process.wait()
            
            with self._lock:
                if process.returncode == 0:
                    task.status = DownloadStatus.COMPLETED
                    task.progress = 100.0
                    task.completed_at = time.time()
                    result = True
                else:
                    task.status = DownloadStatus.FAILED
                    task.error = f"返回码: {process.returncode}"
                    result = False
            
            if progress_callback:
                progress_callback(task)
            
            return result
            
        except Exception as e:
            with self._lock:
                task.status = DownloadStatus.FAILED
                task.error = str(e)
            
            if progress_callback:
                progress_callback(task)
            
            return False
        finally:
            if task_id in self._processes:
                del self._processes[task_id]
    
    def start_download(self, task_id: str,
                      progress_callback: Optional[Callable] = None):
        """在后台线程中开始下载"""
        thread = threading.Thread(
            target=self.download,
            args=(task_id, progress_callback),
            daemon=True
        )
        thread.start()
        return thread
    
    def download_all(self, progress_callback: Optional[Callable] = None) -> dict:
        """
        下载所有待处理任务
        
        按max_concurrent限制并发数
        """
        pending_tasks = [
            task for task in self.tasks.values()
            if task.status == DownloadStatus.PENDING
        ]
        
        results = {
            'total': len(pending_tasks),
            'completed': 0,
            'failed': 0,
        }
        
        active_threads = []
        
        def task_callback(task):
            if progress_callback:
                progress_callback(task)
        
        # 简单的并发控制
        import concurrent.futures
            
        with concurrent.futures.ThreadPoolExecutor(
            max_workers=self.max_concurrent
        ) as executor:
            futures = {
                executor.submit(self.download, task.task_id, task_callback): 
                task.task_id
                for task in pending_tasks
            }
            
            for future in concurrent.futures.as_completed(futures):
                task_id = futures[future]
                try:
                    success = future.result()
                    if success:
                        results['completed'] += 1
                    else:
                        results['failed'] += 1
                except Exception:
                    results['failed'] += 1
        
        return results
    
    def cancel_download(self, task_id: str):
        """取消下载"""
        with self._lock:
            task = self.tasks.get(task_id)
            if not task:
                return False
            
            process = self._processes.get(task_id)
            if process and process.poll() is None:
                process.terminate()
                task.status = DownloadStatus.CANCELLED
                return True
            
            return False
    
    def get_task(self, task_id: str) -> Optional[DownloadTask]:
        """获取任务信息"""
        with self._lock:
            return self.tasks.get(task_id)
    
    def get_all_tasks(self) -> List[DownloadTask]:
        """获取所有任务"""
        with self._lock:
            return list(self.tasks.values())
    
    def get_tasks_by_status(self, status: DownloadStatus) -> List[DownloadTask]:
        """按状态获取任务"""
        with self._lock:
            return [t for t in self.tasks.values() if t.status == status]
    
    def list_formats(self, url: str) -> list:
        """列出可用格式"""
        try:
            result = subprocess.run(
                ['yt-dlp', '-F', url, '--no-playlist'],
                capture_output=True, text=True, check=True
            )
            return result.stdout
        except subprocess.CalledProcessError as e:
            return f"错误: {e.stderr}"
    
    def export_task_list(self, output_path: str):
        """导出任务列表"""
        with self._lock:
            data = []
            for task in self.tasks.values():
                task_dict = asdict(task)
                task_dict['status'] = task.status.value
                data.append(task_dict)
        
        with open(output_path, 'w', encoding='utf-8') as f:
            json.dump(data, f, ensure_ascii=False, indent=2)
```

### 7.6 素材去重工具

**功能说明：** 使用感知哈希（pHash）技术检测重复/相似素材。

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
素材去重工具 - Asset Deduplication Tool
基于感知哈希(pHash)检测重复/相似图片和视频
"""

import os
import json
import hashlib
from pathlib import Path
from dataclasses import dataclass, field
from typing import List, Dict, Tuple, Optional
import subprocess
import numpy as np


@dataclass
class DuplicateGroup:
    """重复组"""
    files: List[str]
    similarity: float
    group_id: str


@dataclass
class DeduplicationResult:
    """去重结果"""
    total_files: int
    duplicate_groups: List[DuplicateGroup]
    unique_files: int
    duplicates_count: int


class ImagePHash:
    """图片感知哈希"""
    
    def __init__(self, hash_size: int = 8, highfreq_factor: int = 4):
        self.hash_size = hash_size
        self.highfreq_factor = highfreq_factor
        self.img_size = hash_size * highfreq_factor
    
    def compute(self, image_path: str) -> Optional[str]:
        """
        计算图片的感知哈希值
        
        Returns:
            64位十六进制哈希字符串
        """
        try:
            from PIL import Image
            import imagehash
            
            img = Image.open(image_path)
            phash = imagehash.phash(img, hash_size=self.hash_size)
            return str(phash)
        except ImportError:
            return self._compute_opencv(image_path)
        except Exception as e:
            return None
    
    def _compute_opencv(self, image_path: str) -> Optional[str]:
        """使用OpenCV计算pHash（备选方案）"""
        try:
            import cv2
            
            img = cv2.imread(image_path, cv2.IMREAD_GRAYSCALE)
            if img is None:
                return None
            
            # 缩放到 32x32
            img = cv2.resize(img, (self.img_size, self.img_size),
                           interpolation=cv2.INTER_AREA)
            
            # 转换为float
            img = np.float32(img)
            
            # DCT变换
            dct = cv2.dct(img)
            
            # 取左上角 8x8
            dct_low = dct[:self.hash_size, :self.hash_size]
            
            # 计算平均值（排除DC分量）
            avg = dct_low[1:].mean()
            
            # 生成哈希
            hash_bits = (dct_low > avg).flatten()
            
            # 转为十六进制
            hash_int = 0
            for bit in hash_bits:
                hash_int = (hash_int << 1) | (1 if bit else 0)
            
            return f"{hash_int:016x}"
            
        except ImportError:
            print("需要安装 Pillow+imagehash 或 opencv-python")
            return None
        except Exception:
            return None
    
    def hamming_distance(self, hash1: str, hash2: str) -> int:
        """计算两个哈希的汉明距离"""
        if len(hash1) != len(hash2):
            return -1
        
        # 转为整数后异或，统计1的位数
        x = int(hash1, 16)
        y = int(hash2, 16)
        return bin(x ^ y).count('1')
    
    def similarity(self, hash1: str, hash2: str) -> float:
        """计算相似度 (0-1)"""
        if not hash1 or not hash2:
            return 0.0
        
        distance = self.hamming_distance(hash1, hash2)
        if distance < 0:
            return 0.0
        
        max_bits = len(hash1) * 4  # 每个十六进制位4位二进制
        return 1.0 - (distance / max_bits)


class VideoPHash:
    """视频感知哈希（基于关键帧）"""
    
    def __init__(self, hash_size: int = 8, num_keyframes: int = 5):
        self.image_phash = ImagePHash(hash_size)
        self.num_keyframes = num_keyframes
        self.hash_size = hash_size
    
    def _extract_keyframes(self, video_path: str, 
                          output_dir: str) -> List[str]:
        """提取关键帧"""
        path = Path(video_path)
        out_path = Path(output_dir)
        out_path.mkdir(parents=True, exist_ok=True)
        
        try:
            # 获取时长
            result = subprocess.run(
                ['ffprobe', '-v', 'quiet', '-print_format', 'json',
                 '-show_format', str(path)],
                capture_output=True, text=True
            )
            data = json.loads(result.stdout)
            duration = float(data.get('format', {}).get('duration', 0))
        except Exception:
            duration = 0
        
        if duration <= 0:
            return []
        
        frames = []
        interval = duration / (self.num_keyframes + 1)
        
        for i in range(self.num_keyframes):
            time_point = interval * (i + 1)
            output_file = out_path / f"frame_{i+1:02d}.jpg"
            
            try:
                cmd = [
                    'ffmpeg', '-y',
                    '-ss', str(time_point),
                    '-i', str(path),
                    '-vframes', '1',
                    '-vf', 'scale=160:90',
                    str(output_file)
                ]
                subprocess.run(cmd, capture_output=True, check=True)
                
                if output_file.exists():
                    frames.append(str(output_file))
            except Exception:
                continue
        
        return frames
    
    def compute(self, video_path: str) -> Optional[str]:
        """
        计算视频哈希
        
        方法：提取多个关键帧的pHash，拼接成一个长哈希
        """
        import tempfile
        
        with tempfile.TemporaryDirectory() as tmpdir:
            frames = self._extract_keyframes(video_path, tmpdir)
            
            if not frames:
                return None
            
            frame_hashes = []
            for frame_path in frames:
                h = self.image_phash.compute(frame_path)
                if h:
                    frame_hashes.append(h)
            
            if not frame_hashes:
                return None
            
            # 拼接所有帧哈希
            combined = ''.join(frame_hashes)
            return combined
    
    def similarity(self, hash1: str, hash2: str) -> float:
        """计算视频相似度"""
        if not hash1 or not hash2:
            return 0.0
        
        # 按帧哈希分割
        hash_len = len(hash1) // self.num_keyframes
        if hash_len == 0:
            return 0.0
        
        frame_hashes_1 = [hash1[i:i+hash_len] 
                         for i in range(0, len(hash1), hash_len)]
        frame_hashes_2 = [hash2[i:i+hash_len] 
                         for i in range(0, len(hash2), hash_len)]
        
        if not frame_hashes_1 or not frame_hashes_2:
            return 0.0
        
        # 计算平均帧相似度
        similarities = []
        for h1, h2 in zip(frame_hashes_1, frame_hashes_2):
            sim = self.image_phash.similarity(h1, h2)
            similarities.append(sim)
        
        if not similarities:
            return 0.0
        
        return sum(similarities) / len(similarities)


class FileMD5:
    """文件MD5哈希（精确去重）"""
    
    @staticmethod
    def compute(file_path: str, chunk_size: int = 8192) -> Optional[str]:
        """计算文件MD5"""
        try:
            md5 = hashlib.md5()
            with open(file_path, 'rb') as f:
                for chunk in iter(lambda: f.read(chunk_size), b''):
                    md5.update(chunk)
            return md5.hexdigest()
        except Exception:
            return None


class Deduplicator:
    """去重工具"""
    
    IMAGE_EXTENSIONS = {'.jpg', '.jpeg', '.png', '.bmp', '.gif', 
                        '.tiff', '.tif', '.webp'}
    VIDEO_EXTENSIONS = {'.mp4', '.mov', '.avi', '.mkv', '.webm',
                        '.flv', '.m4v', '.mpeg'}
    
    def __init__(self, threshold: float = 0.85, 
                 use_phash: bool = True,
                 use_md5: bool = True):
        self.threshold = threshold
        self.use_phash = use_phash
        self.use_md5 = use_md5
        self.image_phash = ImagePHash()
        self.video_phash = VideoPHash()
    
    def scan_directory(self, directory: str, 
                      file_types: List[str] = None,
                      recursive: bool = True) -> List[str]:
        """扫描目录中的文件"""
        files = []
        path = Path(directory)
        
        if not path.is_dir():
            return files
        
        extensions = set()
        if not file_types or 'image' in file_types:
            extensions.update(self.IMAGE_EXTENSIONS)
        if not file_types or 'video' in file_types:
            extensions.update(self.VIDEO_EXTENSIONS)
        
        pattern = '**/*' if recursive else '*'
        
        for file_path in path.glob(pattern):
            if file_path.is_file() and file_path.suffix.lower() in extensions:
                files.append(str(file_path))
        
        return sorted(files)
    
    def deduplicate_images(self, image_paths: List[str],
                          progress_callback=None) -> DeduplicationResult:
        """图片去重"""
        # 第一步：MD5精确去重
        md5_groups = {}
        if self.use_md5:
            for i, path in enumerate(image_paths):
                md5 = FileMD5.compute(path)
                if md5:
                    if md5 not in md5_groups:
                        md5_groups[md5] = []
                    md5_groups[md5].append(path)
                
                if progress_callback and i % 10 == 0:
                    progress_callback('md5', i, len(image_paths))
        
        # 分离精确重复和唯一文件
        exact_duplicates = []
        unique_by_md5 = []
        
        for md5, files in md5_groups.items():
            if len(files) > 1:
                exact_duplicates.append(DuplicateGroup(
                    files=files,
                    similarity=1.0,
                    group_id=f"md5_{md5[:12]}"
                ))
            else:
                unique_by_md5.append(files[0])
        
        # 如果不使用pHash，直接返回MD5结果
        if not self.use_phash:
            total_duplicates = sum(
                len(g.files) - 1 for g in exact_duplicates
            )
            return DeduplicationResult(
                total_files=len(image_paths),
                duplicate_groups=exact_duplicates,
                unique_files=len(image_paths) - total_duplicates,
                duplicates_count=total_duplicates
            )
        
        # 第二步：pHash相似去重（仅对MD5唯一的文件）
        hash_list = []  # [(path, phash)]
        
        for i, path in enumerate(unique_by_md5):
            phash = self.image_phash.compute(path)
            if phash:
                hash_list.append((path, phash))
            
            if progress_callback and i % 10 == 0:
                progress_callback('phash', i, len(unique_by_md5))
        
        # 查找相似组
        similar_groups = self._find_similar_groups(
            hash_list, self.image_phash
        )
        
        all_groups = exact_duplicates + similar_groups
        
        # 计算统计
        dup_file_count = sum(len(g.files) - 1 for g in all_groups)
        unique_count = len(image_paths) - dup_file_count
        
        return DeduplicationResult(
            total_files=len(image_paths),
            duplicate_groups=all_groups,
            unique_files=unique_count,
            duplicates_count=dup_file_count
        )
    
    def deduplicate_videos(self, video_paths: List[str],
                          progress_callback=None) -> DeduplicationResult:
        """视频去重"""
        # 第一步：MD5精确去重
        md5_groups = {}
        if self.use_md5:
            for i, path in enumerate(video_paths):
                md5 = FileMD5.compute(path)
                if md5:
                    if md5 not in md5_groups:
                        md5_groups[md5] = []
                    md5_groups[md5].append(path)
                
                if progress_callback and i % 5 == 0:
                    progress_callback('md5', i, len(video_paths))
        
        exact_duplicates = []
        unique_by_md5 = []
        
        for md5, files in md5_groups.items():
            if len(files) > 1:
                exact_duplicates.append(DuplicateGroup(
                    files=files,
                    similarity=1.0,
                    group_id=f"md5_{md5[:12]}"
                ))
            else:
                unique_by_md5.append(files[0])
        
        if not self.use_phash:
            total_duplicates = sum(
                len(g.files) - 1 for g in exact_duplicates
            )
            return DeduplicationResult(
                total_files=len(video_paths),
                duplicate_groups=exact_duplicates,
                unique_files=len(video_paths) - total_duplicates,
                duplicates_count=total_duplicates
            )
        
        # 第二步：视频pHash
        hash_list = []
        
        for i, path in enumerate(unique_by_md5):
            vhash = self.video_phash.compute(path)
            if vhash:
                hash_list.append((path, vhash))
            
            if progress_callback:
                progress_callback('phash', i, len(unique_by_md5))
        
        similar_groups = self._find_similar_groups(
            hash_list, self.video_phash
        )
        
        all_groups = exact_duplicates + similar_groups
        dup_file_count = sum(len(g.files) - 1 for g in all_groups)
        unique_count = len(video_paths) - dup_file_count
        
        return DeduplicationResult(
            total_files=len(video_paths),
            duplicate_groups=all_groups,
            unique_files=unique_count,
            duplicates_count=dup_file_count
        )
    
    def _find_similar_groups(self, hash_list: List[Tuple[str, str]],
                            hasher) -> List[DuplicateGroup]:
        """查找相似组"""
        groups = []
        assigned = set()
        
        for i in range(len(hash_list)):
            path_i, hash_i = hash_list[i]
            
            if path_i in assigned:
                continue
            
            current_group = [path_i]
            assigned.add(path_i)
            
            for j in range(i + 1, len(hash_list)):
                path_j, hash_j = hash_list[j]
                
                if path_j in assigned:
                    continue
                
                sim = hasher.similarity(hash_i, hash_j)
                
                if sim >= self.threshold:
                    current_group.append(path_j)
                    assigned.add(path_j)
            
            if len(current_group) > 1:
                group_id = f"similar_{hashlib.md5(path_i.encode()).hexdigest()[:8]}"
                avg_sim = self.threshold + (1 - self.threshold) / 2  # 估算
                groups.append(DuplicateGroup(
                    files=current_group,
                    similarity=round(sim, 3),
                    group_id=group_id
                ))
        
        return groups
    
    def deduplicate_directory(self, directory: str,
                             file_types: List[str] = None,
                             recursive: bool = True,
                             progress_callback=None) -> dict:
        """目录去重"""
        results = {}
        
        file_types = file_types or ['image', 'video']
        
        if 'image' in file_types:
            image_files = self.scan_directory(
                directory, ['image'], recursive
            )
            if image_files:
                print(f"找到 {len(image_files)} 张图片")
                img_result = self.deduplicate_images(
                    image_files, progress_callback
                )
                results['images'] = img_result
        
        if 'video' in file_types:
            video_files = self.scan_directory(
                directory, ['video'], recursive
            )
            if video_files:
                print(f"找到 {len(video_files)} 个视频")
                vid_result = self.deduplicate_videos(
                    video_files, progress_callback
                )
                results['videos'] = vid_result
        
        return results
    
    def get_deletion_candidates(self, result: DeduplicationResult,
                               keep_strategy: str = 'largest') -> List[str]:
        """
        获取建议删除的文件列表
        
        Args:
            keep_strategy: 保留策略
                - 'largest': 保留最大的文件
                - 'smallest': 保留最小的文件
                - 'first': 保留第一个
                - 'newest': 保留最新的
                - 'oldest': 保留最旧的
        """
        candidates = []
        
        for group in result.duplicate_groups:
            files = group.files.copy()
            
            if keep_strategy == 'largest':
                files.sort(key=lambda f: Path(f).stat().st_size, reverse=True)
            elif keep_strategy == 'smallest':
                files.sort(key=lambda f: Path(f).stat().st_size)
            elif keep_strategy == 'newest':
                files.sort(key=lambda f: Path(f).stat().st_mtime, reverse=True)
            elif keep_strategy == 'oldest':
                files.sort(key=lambda f: Path(f).stat().st_mtime)
            # 'first' 保持原顺序
            
            # 保留第一个，其余加入删除候选
            candidates.extend(files[1:])
        
        return candidates
    
    def export_report(self, results: dict, output_path: str):
        """导出去重报告"""
        report = {
            'summary': {},
            'details': {}
        }
        
        for file_type, result in results.items():
            report['summary'][file_type] = {
                'total_files': result.total_files,
                'unique_files': result.unique_files,
                'duplicates_count': result.duplicates_count,
                'duplicate_groups': len(result.duplicate_groups),
            }
            
            report['details'][file_type] = [
                {
                    'group_id': g.group_id,
                    'similarity': g.similarity,
                    'file_count': len(g.files),
                    'files': g.files
                }
                for g in result.duplicate_groups
            ]
        
        with open(output_path, 'w', encoding='utf-8') as f:
            json.dump(report, f, ensure_ascii=False, indent=2)


def main():
    """命令行入口"""
    import argparse
    
    parser = argparse.ArgumentParser(description='素材去重工具')

        all_candidates.extend(candidates)

        with open(args.delete_list, 'w', encoding='utf-8') as f:
            for path in all_candidates:
                f.write(path + '\n')
        print(f"删除列表已导出: {args.delete_list}")
    
    if all_candidates:
        print(f"\n建议删除 {len(all_candidates)} 个重复文件")
        
        # 计算节省空间
        total_size = 0
        for path in all_candidates:
            try:
                total_size += Path(path).stat().st_size
            except Exception:
                pass
        
        print(f"预计释放空间: {total_size / (1024*1024):.2f} MB")
    
    if args.delete and all_candidates:
        confirm = input("\n确认删除？此操作不可撤销！(yes/no): ")
        if confirm.lower() == 'yes':
            deleted = 0
            for path in all_candidates:
                try:
                    Path(path).unlink()
                    deleted += 1
                except Exception as e:
                    print(f"删除失败: {path} - {e}")
            print(f"已删除 {deleted} 个文件")
        else:
            print("已取消删除")


if __name__ == '__main__':
    main()
```

### 7.7 DAM系统原型

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
DAM系统原型 - Digital Asset Management Prototype
基于文件系统+SQLite的轻量级素材管理系统
"""

import os
import json
import sqlite3
import time
import hashlib
from pathlib import Path
from datetime import datetime
from dataclasses import dataclass, field, asdict
from typing import List, Optional, Dict, Tuple


@dataclass
class Asset:
    """素材实体"""
    id: int = 0
    file_path: str = ""
    file_name: str = ""
    file_size: int = 0
    file_type: str = ""  # video/audio/image/3d/template
    category: str = ""
    subcategory: str = ""
    duration: float = 0.0
    width: int = 0
    height: int = 0
    codec: str = ""
    thumbnail_path: str = ""
    preview_path: str = ""
    md5_hash: str = ""
    tags: List[str] = field(default_factory=list)
    description: str = ""
    author: str = ""
    source: str = ""
    license_type: str = ""
    rating: int = 0
    created_at: float = 0.0
    updated_at: float = 0.0
    metadata: Dict = field(default_factory=dict)


class DAMDatabase:
    """DAM数据库管理"""
    
    def __init__(self, db_path: str = "dam.db"):
        self.db_path = db_path
        self._init_db()
    
    def _init_db(self):
        """初始化数据库表"""
        conn = sqlite3.connect(self.db_path)
        cursor = conn.cursor()
        
        # 素材主表
        cursor.execute('''
            CREATE TABLE IF NOT EXISTS assets (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                file_path TEXT UNIQUE,
                file_name TEXT,
                file_size INTEGER,
                file_type TEXT,
                category TEXT,
                subcategory TEXT,
                duration REAL DEFAULT 0,
                width INTEGER DEFAULT 0,
                height INTEGER DEFAULT 0,
                codec TEXT,
                thumbnail_path TEXT,
                preview_path TEXT,
                md5_hash TEXT,
                description TEXT,
                author TEXT,
                source TEXT,
                license_type TEXT,
                rating INTEGER DEFAULT 0,
                created_at REAL,
                updated_at REAL,
                metadata_json TEXT
            )
        ''')
        
        # 标签表
        cursor.execute('''
            CREATE TABLE IF NOT EXISTS tags (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                name TEXT UNIQUE,
                type TEXT,
                description TEXT,
                usage_count INTEGER DEFAULT 0
            )
        ''')
        
        # 素材-标签关联表
        cursor.execute('''
            CREATE TABLE IF NOT EXISTS asset_tags (
                asset_id INTEGER,
                tag_id INTEGER,
                PRIMARY KEY (asset_id, tag_id),
                FOREIGN KEY (asset_id) REFERENCES assets(id) ON DELETE CASCADE,
                FOREIGN KEY (tag_id) REFERENCES tags(id) ON DELETE CASCADE
            )
        ''')
        
        # 收藏表
        cursor.execute('''
            CREATE TABLE IF NOT EXISTS favorites (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                asset_id INTEGER,
                folder_name TEXT DEFAULT 'default',
                created_at REAL,
                FOREIGN KEY (asset_id) REFERENCES assets(id) ON DELETE CASCADE
            )
        ''')
        
        # 下载/使用记录表
        cursor.execute('''
            CREATE TABLE IF NOT EXISTS usage_logs (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                asset_id INTEGER,
                action TEXT,
                project TEXT,
                timestamp REAL,
                FOREIGN KEY (asset_id) REFERENCES assets(id) ON DELETE CASCADE
            )
        ''')
        
        # 索引
        cursor.execute(
            'CREATE INDEX IF NOT EXISTS idx_assets_type ON assets(file_type)'
        )
        cursor.execute(
            'CREATE INDEX IF NOT EXISTS idx_assets_category ON assets(category)'
        )
        cursor.execute(
            'CREATE INDEX IF NOT EXISTS idx_assets_path ON assets(file_path)'
        )
        cursor.execute(
            'CREATE INDEX IF NOT EXISTS idx_assets_md5 ON assets(md5_hash)'
        )
        
        conn.commit()
        conn.close()
    
    def _get_connection(self):
        conn = sqlite3.connect(self.db_path)
        conn.row_factory = sqlite3.Row
        conn.execute('PRAGMA journal_mode=WAL')
        conn.execute('PRAGMA foreign_keys=ON')
        return conn
    
    def add_asset(self, asset: Asset) -> int:
        """添加素材"""
        now = time.time()
        asset.created_at = now
        asset.updated_at = now
        
        conn = self._get_connection()
        cursor = conn.cursor()
        
        try:
            cursor.execute('''
                INSERT INTO assets (
                    file_path, file_name, file_size, file_type,
                    category, subcategory, duration, width, height, codec,
                    thumbnail_path, preview_path, md5_hash,
                    description, author, source, license_type, rating,
                    created_at, updated_at, metadata_json
                ) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
            ''', (
                asset.file_path, asset.file_name, asset.file_size,
                asset.file_type, asset.category, asset.subcategory,
                asset.duration, asset.width, asset.height, asset.codec,
                asset.thumbnail_path, asset.preview_path, asset.md5_hash,
                asset.description, asset.author, asset.source,
                asset.license_type, asset.rating,
                asset.created_at, asset.updated_at,
                json.dumps(asset.metadata, ensure_ascii=False)
            ))
            
            asset.id = cursor.lastrowid
            
            # 添加标签
            if asset.tags:
                for tag_name in asset.tags:
                    self._add_tag_to_asset(cursor, asset.id, tag_name)
            
            conn.commit()
            return asset.id
            
        except sqlite3.IntegrityError:
            conn.rollback()
            # 已存在，更新
            return self._update_asset_by_path(asset)
        finally:
            conn.close()
    
    def _add_tag_to_asset(self, cursor, asset_id: int, tag_name: str):
        """给素材添加标签"""
        tag_name = tag_name.strip().lower()
        if not tag_name:
            return
        
        # 获取或创建标签
        cursor.execute('SELECT id FROM tags WHERE name = ?', (tag_name,))
        row = cursor.fetchone()
        
        if row:
            tag_id = row[0]
        else:
            cursor.execute(
                'INSERT INTO tags (name, usage_count) VALUES (?, 1)',
                (tag_name,)
            )
            tag_id = cursor.lastrowid
        
        # 关联
        try:
            cursor.execute(
                'INSERT INTO asset_tags (asset_id, tag_id) VALUES (?, ?)',
                (asset_id, tag_id)
            )
            # 更新使用计数
            cursor.execute(
                'UPDATE tags SET usage_count = usage_count + 1 WHERE id = ?',
                (tag_id,)
            )
        except sqlite3.IntegrityError:
            pass  # 已存在
    
    def _update_asset_by_path(self, asset: Asset) -> int:
        """根据路径更新素材"""
        conn = self._get_connection()
        cursor = conn.cursor()
        
        try:
            cursor.execute(
                'SELECT id FROM assets WHERE file_path = ?',
                (asset.file_path,)
            )
            row = cursor.fetchone()
            
            if not row:
                conn.close()
                return 0
            
            asset_id = row[0]
            asset.updated_at = time.time()
            
            cursor.execute('''
                UPDATE assets SET
                    file_name = ?, file_size = ?, file_type = ?,
                    category = ?, subcategory = ?, duration = ?,
                    width = ?, height = ?, codec = ?,
                    thumbnail_path = ?, preview_path = ?, md5_hash = ?,
                    description = ?, author = ?, source = ?,
                    license_type = ?, rating = ?,
                    updated_at = ?, metadata_json = ?
                WHERE id = ?
            ''', (
                asset.file_name, asset.file_size, asset.file_type,
                asset.category, asset.subcategory, asset.duration,
                asset.width, asset.height, asset.codec,
                asset.thumbnail_path, asset.preview_path, asset.md5_hash,
                asset.description, asset.author, asset.source,
                asset.license_type, asset.rating,
                asset.updated_at,
                json.dumps(asset.metadata, ensure_ascii=False),
                asset_id
            ))
            
            conn.commit()
            return asset_id
        finally:
            conn.close()
    
    def get_asset(self, asset_id: int) -> Optional[Asset]:
        """获取素材"""
        conn = self._get_connection()
        cursor = conn.cursor()
        
        cursor.execute('SELECT * FROM assets WHERE id = ?', (asset_id,))
        row = cursor.fetchone()
        
        if not row:
            conn.close()
            return None
        
        asset = self._row_to_asset(row)
        
        # 获取标签
        cursor.execute('''
            SELECT t.name FROM tags t
            JOIN asset_tags at ON t.id = at.tag_id
            WHERE at.asset_id = ?
        ''', (asset_id,))
        asset.tags = [row[0] for row in cursor.fetchall()]
        
        conn.close()
        return asset
    
    def _row_to_asset(self, row) -> Asset:
        """行转对象"""
        asset = Asset(
            id=row['id'],
            file_path=row['file_path'],
            file_name=row['file_name'],
            file_size=row['file_size'] or 0,
            file_type=row['file_type'] or '',
            category=row['category'] or '',
            subcategory=row['subcategory'] or '',
            duration=row['duration'] or 0,
            width=row['width'] or 0,
            height=row['height'] or 0,
            codec=row['codec'] or '',
            thumbnail_path=row['thumbnail_path'] or '',
            preview_path=row['preview_path'] or '',
            md5_hash=row['md5_hash'] or '',
            description=row['description'] or '',
            author=row['author'] or '',
            source=row['source'] or '',
            license_type=row['license_type'] or '',
            rating=row['rating'] or 0,
            created_at=row['created_at'] or 0,
            updated_at=row['updated_at'] or 0,
        )
        
        if row['metadata_json']:
            try:
                asset.metadata = json.loads(row['metadata_json'])
            except json.JSONDecodeError:
                asset.metadata = {}
        
        return asset
    
    def search_assets(self, keyword: str = "",
                     file_type: str = "",
                     category: str = "",
                     tags: List[str] = None,
                     min_rating: int = 0,
                     limit: int = 100,
                     offset: int = 0) -> Tuple[List[Asset], int]:
        """
        搜索素材
        
        Returns:
            (素材列表, 总数)
        """
        conn = self._get_connection()
        cursor = conn.cursor()
        
        conditions = []
        params = []
        
        if keyword:
            conditions.append(
                '(file_name LIKE ? OR description LIKE ?)'
            )
            params.extend([f'%{keyword}%', f'%{keyword}%'])
        
        if file_type:
            conditions.append('file_type = ?')
            params.append(file_type)
        
        if category:
            conditions.append('category = ?')
            params.append(category)
        
        if min_rating > 0:
            conditions.append('rating >= ?')
            params.append(min_rating)
        
        where_clause = ' AND '.join(conditions) if conditions else '1=1'
        
        # 标签筛选
        tag_join = ""
        if tags:
            placeholders = ','.join(['?' for _ in tags])
            tag_join = f'''
            INNER JOIN asset_tags at ON a.id = at.asset_id
            INNER JOIN tags t ON at.tag_id = t.id
            '''
            where_clause += f' AND t.name IN ({placeholders})'
            params.extend(tags)
        
        # 计数
        count_sql = f'''
            SELECT COUNT(DISTINCT a.id) FROM assets a
            {tag_join}
            WHERE {where_clause}
        '''
        cursor.execute(count_sql, params)
        total = cursor.fetchone()[0]
        
        # 查询
        sql = f'''
            SELECT DISTINCT a.* FROM assets a
            {tag_join}
            WHERE {where_clause}
            ORDER BY a.updated_at DESC
            LIMIT ? OFFSET ?
        '''
        params.extend([limit, offset])
        cursor.execute(sql, params)
        
        assets = [self._row_to_asset(row) for row in cursor.fetchall()]
        
        conn.close()
        return assets, total
    
    def delete_asset(self, asset_id: int) -> bool:
        """删除素材"""
        conn = self._get_connection()
        cursor = conn.cursor()
        
        cursor.execute('DELETE FROM assets WHERE id = ?', (asset_id,))
        deleted = cursor.rowcount > 0
        
        conn.commit()
        conn.close()
        return deleted
    
    def get_all_tags(self) -> List[Dict]:
        """获取所有标签"""
        conn = self._get_connection()
        cursor = conn.cursor()
        
        cursor.execute(
            'SELECT name, type, usage_count FROM tags ORDER BY usage_count DESC'
        )
        
        tags = [
            {'name': row[0], 'type': row[1], 'count': row[2]}
            for row in cursor.fetchall()
        ]

class DAMSystem:
    """DAM系统门面类"""
    
    def __init__(self, library_dir: str = "./media_library",
                 db_path: str = "dam.db"):
        self.library_dir = Path(library_dir)
        self.library_dir.mkdir(parents=True, exist_ok=True)
        self.db = DAMDatabase(db_path)
        
        # 子目录
        self.thumbs_dir = self.library_dir / '_thumbnails'
        self.previews_dir = self.library_dir / '_previews'
        self.thumbs_dir.mkdir(exist_ok=True)
        self.previews_dir.mkdir(exist_ok=True)
    
    def import_file(self, file_path: str, 
                    category: str = "",
                    tags: List[str] = None,
                    move_file: bool = False) -> Optional[int]:
        """
        导入素材文件
        
        Args:
            file_path: 源文件路径
            category: 分类
            tags: 标签列表
            move_file: 是否移动文件（默认复制）
        
        Returns:
            素材ID
        """
        src_path = Path(file_path)
        if not src_path.exists():
            raise FileNotFoundError(f"文件不存在: {file_path}")
        
        # 检测类型
        file_type = self._detect_type(src_path.suffix.lower())
        if file_type == 'unknown':
            return None
        
        # 目标路径
        dest_dir = self.library_dir / file_type
        if category:
            dest_dir = dest_dir / category
        dest_dir.mkdir(parents=True, exist_ok=True)
        
        dest_path = dest_dir / src_path.name
        
        # 处理重名
        if dest_path.exists():
            stem = src_path.stem
            suffix = src_path.suffix
            counter = 1
            while dest_path.exists():
                dest_path = dest_dir / f"{stem}_{counter}{suffix}"
                counter += 1
        
        # 复制或移动
        import shutil
        if move_file:
            shutil.move(str(src_path), str(dest_path))
        else:
            shutil.copy2(str(src_path), str(dest_path))
        
        # 计算MD5
        md5 = self._compute_md5(str(dest_path))
        
        # 提取元数据
        metadata = self._extract_metadata(str(dest_path), file_type)
        
        # 创建素材对象
        asset = Asset(
            file_path=str(dest_path),
            file_name=dest_path.name,
            file_size=dest_path.stat().st_size,
            file_type=file_type,
            category=category,
            md5_hash=md5,
            tags=tags or [],
            **metadata
        )
        
        # 生成缩略图
        thumbnail = self._generate_thumbnail(str(dest_path), file_type)
        if thumbnail:
            asset.thumbnail_path = thumbnail
        
        # 存入数据库
        asset_id = self.db.add_asset(asset)
        return asset_id
    
    def import_directory(self, directory: str,
                        category: str = "",
                        recursive: bool = True,
                        move_file: bool = False) -> dict:
        """批量导入目录"""
        path = Path(directory)
        results = {
            'total': 0,
            'success': 0,
            'failed': [],
            'skipped': []
        }
        
        pattern = '**/*' if recursive else '*'
        
        for file_path in path.glob(pattern):
            if not file_path.is_file():
                continue
            
            results['total'] += 1
            
            try:
                asset_id = self.import_file(
                    str(file_path), category=category, move_file=move_file
                )
                if asset_id:
                    results['success'] += 1
                else:
                    results['skipped'].append(str(file_path))
            except Exception as e:
                results['failed'].append((str(file_path), str(e)))
        
        return results
    
    def _detect_type(self, ext: str) -> str:
        """检测文件类型"""
        ext = ext.lower()
        
        video_exts = {'.mp4', '.mov', '.avi', '.mkv', '.webm', '.flv',
                      '.m4v', '.mpeg', '.mpg', '.ts'}
        audio_exts = {'.mp3', '.wav', '.flac', '.aac', '.ogg', '.m4a',
                      '.wma', '.opus'}
        image_exts = {'.jpg', '.jpeg', '.png', '.gif', '.bmp', '.tiff',
                      '.tif', '.webp'}
        
        if ext in video_exts:
            return 'video'
        elif ext in audio_exts:
            return 'audio'
        elif ext in image_exts:
            return 'image'
        else:
            return 'unknown'
    
    def _compute_md5(self, file_path: str) -> str:
        """计算MD5"""
        try:
            md5 = hashlib.md5()
            with open(file_path, 'rb') as f:
                for chunk in iter(lambda: f.read(8192), b''):
                    md5.update(chunk)
            return md5.hexdigest()
        except Exception:
            return ""
    
    def _extract_metadata(self, file_path: str, 
                         file_type: str) -> dict:
        """提取元数据"""
        metadata = {}
        
        try:
            if file_type in ('video', 'audio'):
                import subprocess
                
                result = subprocess.run(
                    ['ffprobe', '-v', 'quiet', '-print_format', 'json',
                     '-show_format', '-show_streams', file_path],
                    capture_output=True, text=True
                )
                data = json.loads(result.stdout)
                
                fmt = data.get('format', {})
                streams = data.get('streams', [])
                
                metadata['duration'] = float(fmt.get('duration', 0))
                
                for stream in streams:
                    if stream.get('codec_type') == 'video':
                        metadata['width'] = int(stream.get('width', 0))
                        metadata['height'] = int(stream.get('height', 0))
                        metadata['codec'] = stream.get('codec_name', '')
                        break
            
            elif file_type == 'image':
                from PIL import Image
                with Image.open(file_path) as img:
                    metadata['width'] = img.width
                    metadata['height'] = img.height
                    metadata['codec'] = img.format
        
        except Exception:
            pass
        
        return metadata
    
    def _generate_thumbnail(self, file_path: str, 
                           file_type: str) -> Optional[str]:
        """生成缩略图"""
        try:
            path = Path(file_path)
            thumb_name = f"{path.stem}_thumb.jpg"
            thumb_path = self.thumbs_dir / thumb_name
            
            if file_type == 'video':
                import subprocess
                subprocess.run([
                    'ffmpeg', '-y', '-ss', '5', '-i', file_path,
                    '-vframes', '1', '-vf', 'scale=320:-1',
                    '-q:v', '85', str(thumb_path)
                ], capture_output=True, check=True)
                
                if thumb_path.exists():
                    return str(thumb_path)
            
            elif file_type == 'image':
                from PIL import Image
                with Image.open(file_path) as img:
                    img.thumbnail((320, 320))
                    if img.mode in ('RGBA', 'P'):
                        img = img.convert('RGB')
                    img.save(thumb_path, 'JPEG', quality=85)
                    return str(thumb_path)
        
        except Exception:
            pass
        
        return None
    
    def search(self, **kwargs) -> Tuple[List[Asset], int]:
        """搜索素材"""
        return self.db.search_assets(**kwargs)
    
    def get_stats(self) -> Dict:
```

```python
class CopyrightInfo:

class CopyrightChecker:
    """版权检查器"""

        'pixabay license': 'Pixabay License (免费商用)',
        'unsplash license': 'Unsplash License (免费商用)',
        'royalty-free': '免版税 (RF)',
        'editorial use only': '仅编辑使用',

        'shutterstock': 'Shutterstock',
        'adobestock': 'Adobe Stock',
        'gettyimages': 'Getty Images',
        'istock': 'iStock',
        'dreamstime': 'Dreamstime',
        '123rf': '123RF',
        '视觉中国': '视觉中国',
        '摄图网': '摄图网',
        '包图网': '包图网',
        '千图网': '千图网',
    }
    
    def __init__(self):
        pass
    
    def check_file(self, file_path: str) -> CopyrightInfo:
        """检查单个文件的版权信息"""
        path = Path(file_path)
        if not path.exists():
            raise FileNotFoundError(f"文件不存在: {file_path}")
        
        ext = path.suffix.lower()
        file_type = self._detect_type(ext)
        
        info = CopyrightInfo(
            file_path=str(path),
            file_type=file_type
        )
        
        # 从文件名检查
        self._check_filename(path.name, info)
        
        # 从元数据检查
        if file_type == 'image':
            self._check_image_metadata(str(path), info)
        elif file_type in ('video', 'audio'):
            self._check_media_metadata(str(path), info)
        
        # 评估风险等级
        self._assess_risk(info)
        
        return info
    
    def _detect_type(self, ext: str) -> str:
        """检测文件类型"""
        ext = ext.lower()
        if ext in {'.jpg', '.jpeg', '.png', '.gif', '.bmp', '.tiff', '.tif', '.webp'}:
            return 'image'
        elif ext in {'.mp4', '.mov', '.avi', '.mkv', '.webm', '.flv', '.m4v'}:
            return 'video'
        elif ext in {'.mp3', '.wav', '.flac', '.aac', '.ogg', '.m4a'}:
            return 'audio'
        else:
            return 'unknown'
    
    def _check_filename(self, filename: str, info: CopyrightInfo):
        """从文件名检测版权线索"""
        filename_lower = filename.lower()
        
        # 检查版权关键词
        for keyword in self.COPYRIGHT_KEYWORDS:
            if re.search(keyword, filename_lower, re.IGNORECASE):
                info.has_copyright_notice = True
                info.warnings.append(f"文件名包含版权关键词: {keyword}")
                break
        
        # 检查素材站标识
        for site_key, site_name in self.STOCK_SITES.items():
            if site_key.lower() in filename_lower:
                info.source = site_name
                info.warnings.append(f"文件名包含素材站标识: {site_name}")
                break
    
    def _check_image_metadata(self, image_path: str, info: CopyrightInfo):
        """检查图片元数据"""
        try:
            from PIL import Image
            from PIL.ExifTags import TAGS
            
            with Image.open(image_path) as img:
                # EXIF信息
                try:
                    exif_data = img._getexif()
                    if exif_data:
                        for tag_id, value in exif_data.items():
                            tag_name = TAGS.get(tag_id, str(tag_id))
                            
                            if 'copyright' in tag_name.lower():
                                info.exif_copyright = str(value)
                                info.has_copyright_notice = True
                                info.copyright_text = str(value)
                            
                            if tag_name in ('Artist', 'Author', 'Creator'):
                                info.author = str(value)
                    
                    # 版权状态
                    if info.exif_copyright:
                        info.warnings.append(f"EXIF包含版权信息: {info.exif_copyright}")
                except Exception:
                    pass
                
                # XMP信息
                try:
                    xmp_data = img.info.get('xmp', b'')
                    if xmp_data:
                        xmp_str = xmp_data.decode('utf-8', errors='ignore')
                        
                        if 'copyright' in xmp_str.lower() or '©' in xmp_str:
                            info.xmp_copyright = 'detected'
                            info.has_copyright_notice = True
                            info.warnings.append("XMP元数据包含版权信息")
                        
                        # 检查CC授权
                        for cc_key, cc_name in self.CC_LICENSES.items():
                            if cc_key in xmp_str.lower():
                                info.license_type = cc_name
                                break
                except Exception:
                    pass
                
                # IPTC信息
                try:
                    iptc_data = img.info.get('iptc', b'')
                    if iptc_data:
                        iptc_str = str(iptc_data)
                        if 'copyright' in iptc_str.lower():
                            info.warnings.append("IPTC数据包含版权信息")
                except Exception:
                    pass
        
        except ImportError:
            info.warnings.append("未安装Pillow，无法检查图片元数据")
        except Exception as e:
            info.warnings.append(f"读取图片元数据失败: {e}")
    
    def _check_media_metadata(self, media_path: str, info: CopyrightInfo):
        """检查音视频元数据"""
        try:
            result = subprocess.run(
                ['ffprobe', '-v', 'quiet', '-print_format', 'json',
                 '-show_format', '-show_streams', media_path],
                capture_output=True, text=True, timeout=30
            )
            data = json.loads(result.stdout)
            
            fmt = data.get('format', {})
            tags = fmt.get('tags', {})
            
            # 检查各种版权字段
            copyright_fields = [
                'copyright', 'Copyright', 'COPYRIGHT',
                'publisher', 'publisher_name',
                'artist', 'ARTIST',
                'album_artist',
                'composer',
                'author',
                'encoded_by',
            ]
            
            for field in copyright_fields:
                if field in tags:
                    value = str(tags[field])
                    if value.strip():
                        info.has_copyright_notice = True
                        if not info.copyright_text:
                            info.copyright_text = value
                        if field.lower() in ('artist', 'author', 'composer'):
                            info.author = value
                        info.warnings.append(f"元数据{field}: {value}")
            
            # 检查CC授权
            for tag_key, tag_value in tags.items():
                tag_str = str(tag_value).lower()
                for cc_key, cc_name in self.CC_LICENSES.items():
                    if cc_key in tag_str:
                        info.license_type = cc_name
                        break
                if info.license_type:
                    break
        
        except FileNotFoundError:
            info.warnings.append("未安装ffprobe，无法检查媒体元数据")
        except Exception as e:
            info.warnings.append(f"读取媒体元数据失败: {e}")
    
    def _assess_risk(self, info: CopyrightInfo):
        """评估版权风险等级"""
        risk_score = 50  # 起始分数（未知风险）
        
        # 明确的CC0/公共领域 - 低风险
        if info.license_type and ('CC0' in info.license_type or 
                                   '公共领域' in info.license_type or
                                   '免费商用' in info.license_type):
            risk_score = 10
            info.risk_level = 'low'
            info.confidence = 0.9
            return
        
        # RF免版税 - 中低风险
        if info.license_type and '免版税' in info.license_type:
            risk_score = 30
            info.risk_level = 'low'
            info.confidence = 0.7
            return
        
        # CC BY系列（需要署名）- 中风险
        if info.license_type and 'CC BY' in info.license_type:
            risk_score = 50
            info.risk_level = 'medium'
            info.confidence = 0.8
            return
        
        # 仅编辑使用 - 高风险（商用受限）
        if info.license_type and '仅编辑使用' in info.license_type:
            risk_score = 80
            info.risk_level = 'high'
            info.confidence = 0.85
            return
        
        # 有明确版权声明
        if info.has_copyright_notice:
            risk_score = 70
            info.risk_level = 'high'
            info.confidence = 0.6
            return
        
        # 素材站水印/标识
        if info.source and info.source in self.STOCK_SITES.values():
            risk_score = 75
            info.risk_level = 'high'
            info.confidence = 0.5
            info.warnings.append("文件可能来自付费素材站，需确认授权")
            return
        
        # 没有任何版权信息 - 未知风险
        info.risk_level = 'unknown'
        info.confidence = 0.3
        info.warnings.append("未检测到明确的版权信息，来源不明")
    
    def check_directory(self, directory: str,
                       recursive: bool = True,
                       file_types: List[str] = None) -> List[CopyrightInfo]:
        """批量检查目录"""
        results = []
        path = Path(directory)
        
        if not path.is_dir():
            raise ValueError(f"不是有效目录: {directory}")
        
        pattern = '**/*' if recursive else '*'
        
        for file_path in path.glob(pattern):
            if not file_path.is_file():
                continue
            
            ext = file_path.suffix.lower()
            file_type = self._detect_type(ext)
            
            if file_types and file_type not in file_types:
                continue
            
            if file_type == 'unknown':
                continue
            
            try:
                info = self.check_file(str(file_path))
                results.append(info)
            except Exception as e:
                info = CopyrightInfo(
                    file_path=str(file_path),
                    file_type=file_type,
                    warnings=[f"检查失败: {e}"]
                )
                results.append(info)
        
        return results
    
    def generate_report(self, results: List[CopyrightInfo]) -> Dict:
        """生成检查报告"""
        report = {
            'total_files': len(results),
            'risk_summary': {
                'low': 0,
                'medium': 0,
                'high': 0,
                'unknown': 0
            },
            'by_type': {},
            'high_risk_files': [],
            'files_with_warnings': [],
            'license_distribution': {}
        }
        
        for info in results:
            # 风险统计
            report['risk_summary'][info.risk_level] = \
                report['risk_summary'].get(info.risk_level, 0) + 1
            
            # 类型统计
            report['by_type'][info.file_type] = \
                report['by_type'].get(info.file_type, 0) + 1
            
            # 高风险文件
            if info.risk_level == 'high':
                report['high_risk_files'].append({
                    'file': info.file_path,
                    'copyright': info.copyright_text,
                    'source': info.source,
                    'warnings': info.warnings
                })
            
            # 有警告的文件
            if info.warnings:
                report['files_with_warnings'].append({
                    'file': info.file_path,
                    'risk_level': info.risk_level,
                    'warnings': info.warnings
                })
            
            # 授权分布
            if info.license_type:
                report['license_distribution'][info.license_type] = \
                    report['license_distribution'].get(info.license_type, 0) + 1
        
        return report
    
    def export_report(self, results: List[CopyrightInfo], 
                     output_path: str):
        """导出报告"""
        report = self.generate_report(results)
        
        # 添加详细数据
        report['details'] = [
            {
                'file_path': info.file_path,
                'file_type': info.file_type,
                'risk_level': info.risk_level,
                'confidence': info.confidence,
                'has_copyright': info.has_copyright_notice,
                'copyright_text': info.copyright_text,
                'author': info.author,
                'license_type': info.license_type,
                'source': info.source,
                'warnings': info.warnings
            }
            for info in results
        ]
        
        with open(output_path, 'w', encoding='utf-8') as f:
            json.dump(report, f, ensure_ascii=False, indent=2)
```

**侵权风险预警机制：**

```python
class InfringementChecker:
    """侵权风险检查器"""
    
    RISK_LEVELS = {
        'low': '低风险 - 合规使用',
        'medium': '中风险 - 需要确认',
        'high': '高风险 - 可能侵权',
        'critical': '严重风险 - 立即停用'
    }
    
    def check_usage_risk(self, asset_id: str, usage_context: dict) -> dict:
        """
        检查素材使用风险
        
        Args:
            asset_id: 素材ID
            usage_context: 使用上下文
                - project_type: 项目类型（商业/非商业）
                - distribution: 发行渠道
                - audience_size: 受众规模
                - territory: 使用地域
                - duration: 使用时长
                - modification: 是否二次创作
        
        Returns:
            风险评估报告
        """
        asset = self.get_asset(asset_id)
        license_info = asset.get('license', {})
        
        risks = []
        risk_score = 0
        
        # 1. 商业使用检查
        if usage_context.get('project_type') == 'commercial':
            if not license_info.get('commercial_use', False):
                risks.append({
                    'type': 'commercial_use',
                    'severity': 'critical',
                    'description': '该素材不允许商业使用'
                })
                risk_score += 40
        
        # 2. 二次创作检查
        if usage_context.get('modification'):
            if not license_info.get('derivative_work', False):
                risks.append({
                    'type': 'derivative_work',
                    'severity': 'high',
                    'description': '该素材不允许二次创作'
                })
                risk_score += 30
        
        # 3. 地域限制检查
        territory = usage_context.get('territory', 'worldwide')
        allowed_territories = license_info.get('territories', [])
        if allowed_territories and territory not in allowed_territories:
            risks.append({
                'type': 'territory_restriction',
                'severity': 'high',
                'description': f'该素材在{territory}地区无授权'
            })
            risk_score += 30
        
        # 4. 期限检查
        expiry_date = license_info.get('expiry_date')
        if expiry_date:
            from datetime import datetime
            if datetime.now() > datetime.fromisoformat(expiry_date):
                risks.append({
                    'type': 'license_expired',
                    'severity': 'critical',
                    'description': '该素材授权已过期'
                })
                risk_score += 50
        
        # 5. 署名要求检查
        if license_info.get('attribution_required'):
            if not usage_context.get('attribution_provided'):
                risks.append({
                    'type': 'missing_attribution',
                    'severity': 'medium',
                    'description': '该素材需要署名，使用时未提供'
                })
                risk_score += 15
        
        # 6. 量级限制检查
        max_audience = license_info.get('max_audience_size')
        if max_audience and usage_context.get('audience_size', 0) > max_audience:
            risks.append({
                'type': 'audience_limit_exceeded',
                'severity': 'high',
                'description': f'受众规模超出授权限制（限制: {max_audience}）'
            })
            risk_score += 25
        
        # 综合风险等级
        if risk_score >= 80:
            level = 'critical'
        elif risk_score >= 50:
            level = 'high'
        elif risk_score >= 20:
            level = 'medium'
        else:
            level = 'low'
        
        return {
            'asset_id': asset_id,
            'risk_level': level,
            'risk_score': risk_score,
            'risks': risks,
            'recommendations': self._generate_recommendations(risks),
            'license_summary': license_info
        }
    
    def _generate_recommendations(self, risks: list) -> list:
        """生成合规建议"""
        recommendations = []
        for risk in risks:
            if risk['severity'] in ('high', 'critical'):
                recommendations.append(
                    f"【高风险】{risk['description']} - 建议立即停用并咨询法务"
                )
            elif risk['severity'] == 'medium':
                recommendations.append(
                    f"【中风险】{risk['description']} - 建议尽快补全合规手续"
                )
        return recommendations
```
