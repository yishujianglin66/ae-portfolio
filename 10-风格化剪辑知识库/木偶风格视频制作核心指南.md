## 一、产品定位与核心理念

### 1.1 核心理念

**"把真人视频变成木偶戏"**

这是一个将真人视频通过 AI 分析、专业抠像、多维度跟踪、风格化渲染等技术手段，转化为具有木偶戏视觉效果的视频自动化生产平台。

**完整流程链路**：
```
输入真人视频
    ↓
AI 画面理解 + 主体检测
    ↓
Silhouette 专业级逐帧 Roto 抠像
    ↓
平面跟踪 + 关节跟踪 + 面部跟踪
    ↓
AE 8大风格化子系统处理
    ↓
木质 / 陶瓷 / 布偶 / 黏土 / 金属 等多种木偶风格
    ↓
输出木偶风格视频
```

**产品价值主张**：
- **技术领先**：从普通特效APP的一键滤镜级，跃升到专业级逐帧Roto + 多维度跟踪 + 16个子模块精细控制
- **效果惊艳**：真正做到"以假乱真"的木偶效果，而不是简单的滤镜叠加
- **高效生产**：从手工制作数天一条，缩短到自动化数分钟一条
- **企业级能力**：支持批量生产、多租户、弹性伸缩

### 1.2 差异化竞争力矩阵

| 维度 | 普通特效APP | 我们的平台 | 技术实现路径 | 领先幅度 |
|------|------------|-----------|------------|---------|
| 抠像精度 | AI一键（边缘差） | Silhouette专业级逐帧Roto | Silhouette RotoNode + AI辅助 + 逐帧手工调整 | 3-5倍 |
| 跟踪能力 | 2D平面跟踪 | 平面+点+面部+关节 多维度跟踪 | TrackerNode + PointTracker + MediaPipe + Face Mesh | 4-6倍 |
| 风格化深度 | 滤镜级（一键） | 16个子模块精细控制 | AE 8大子系统，每子模块2-3个效果模块 | 5-8倍 |
| 3D能力 | 无 / 弱 | Blender + AE 3D 完整场景 | Blender bpy API + AE 3D图层 + 3D摄像机跟踪 | 10倍+ |
| 批量能力 | 单条处理 | 企业级批量生产 | Celery + Redis + K8s弹性伸缩 + 任务队列 | 50-100倍 |
| 可定制性 | 预设固定 | 全参数可调 + 插件扩展 | 参数化系统 + 插件SDK + API开放 | 全方位领先 |

**核心竞争壁垒**：
1. **Silhouette 专业抠像**：发丝级边缘精度，支持运动模糊，这是普通APP无法企及的
2. **关节跟踪 + 关节化处理**：知道哪里该有关节缝，哪里该有木偶的机械感
3. **8大风格化子系统**：不是一个滤镜，而是一个完整的风格化流水线
4. **多引擎协同**：AE + Silhouette + Resolve + Blender + Topaz，各擅其长

## 二、四阶段特效流水线详解

### Phase 1：素材预处理（Topaz + 自研分析引擎）

**核心作用**：为后续抠像/跟踪/风格化提供高质量输入和元数据。

#### 1.1 画质增强（Topaz Video AI）

**工具**：Topaz Video AI CLI

**输入**：原始视频文件

**输出**：超分/补帧/降噪后的高质量素材

**核心功能**：
- **超分辨率**：将低分辨率视频提升到4K/8K
  - 模型：Proteus / Artemis / Gaia
  - 适用场景：老视频修复、低清素材提升
- **补帧**：将低帧率视频补到60fps/120fps
  - 模型：Chronos / Chronos Fast
  - 适用场景：慢动作制作、流畅度提升
- **降噪**：去除视频噪点
  - 模型：Noise / Grain
  - 适用场景：低光拍摄、高ISO素材
- **去隔行**：将隔行扫描转为逐行
  - 模型：Deinterlace
- **抖动修复**：视频稳定化
  - 模型：Stabilization

**参数配置表**：

| 功能 | 模型 | 质量 | 速度 | 适用场景 |
|------|------|------|------|---------|
| 超分辨率 | Proteus v5 | ⭐⭐⭐⭐⭐ | ⭐⭐ | 通用场景，细节保留最好 |
| 超分辨率 | Artemis v14 | ⭐⭐⭐⭐ | ⭐⭐⭐ | 人像、自然场景 |
| 超分辨率 | Gaia CG | ⭐⭐⭐⭐ | ⭐⭐⭐ | CG动画、游戏画面 |
| 补帧 | Chronos v5 | ⭐⭐⭐⭐⭐ | ⭐ | 最高质量慢动作 |
| 补帧 | Chronos Fast | ⭐⭐⭐ | ⭐⭐⭐⭐ | 快速补帧，实时预览 |
| 降噪 | Noise AI | ⭐⭐⭐⭐ | ⭐⭐⭐ | 通用降噪 |
| 降噪 | Grain AI | ⭐⭐⭐ | ⭐⭐⭐ | 胶片颗粒模拟 |

import subprocess
import os
from typing import Dict, Any, Optional

class TopazVideoEnhancer:
    """Topaz Video AI 封装类"""
    
    def __init__(self, topaz_path: str = "topaz-video-ai"):
        self.topaz_path = topaz_path
    
    def enhance(
        self,
        input_path: str,
        output_path: str,
        params: Dict[str, Any]
    ) -> bool:
        """
        画质增强处理
        
        Args:
            input_path: 输入视频路径
            output_path: 输出视频路径
            params: 参数字典
                - output_size: 输出分辨率 (width, height)
                - output_fps: 输出帧率
                - model_type: 模型类型
                - noise_reduction: 降噪强度 0-100
                - blur_reduction: 模糊恢复 0-100
        
        Returns:
            是否成功
        """
        cmd = [self.topaz_path, "cli", input_path, output_path]
        
        if "output_size" in params:
            w, h = params["output_size"]
            cmd.extend(["--output-size", f"{w}x{h}"])
        
        if "output_fps" in params:
            cmd.extend(["--output-fps", str(params["output_fps"])])
        
        if "model_type" in params:
            cmd.extend(["--model-type", params["model_type"]])
        
        if "noise_reduction" in params:
            cmd.extend(["--noise-reduction", str(params["noise_reduction"])])
        
        if "blur_reduction" in params:
            cmd.extend(["--blur-reduction", str(params["blur_reduction"])])
        
        try:
            result = subprocess.run(
                cmd,
                capture_output=True,
                text=True,
                timeout=3600
            )
            return result.returncode == 0
        except Exception as e:
            print(f"Topaz 处理失败: {e}")
            return False
    
    def get_video_info(self, video_path: str) -> Dict[str, Any]:
        """获取视频信息"""
        # 使用 ffprobe 获取信息
        cmd = ["ffprobe", "-v", "quiet", "-print_format", "json",
               "-show_format", "-show_streams", video_path]
        result = subprocess.run(cmd, capture_output=True, text=True)
        import json
        info = json.loads(result.stdout)
        return info

# 使用示例

#### 1.2 镜头分割（PySceneDetect + 帧差法）

**工具**：PySceneDetect + OpenCV

**输入**：原始视频文件

**输出**：镜头列表 + 关键帧

**核心功能**：
- **基于内容的镜头检测**（ContentDetector）：比较相邻帧的内容变化
- **基于阈值的镜头检测**（ThresholdDetector）：基于亮度阈值
- **自适应检测**（AdaptiveDetector）：自适应阈值
- **关键帧提取**：每个镜头提取代表性帧
- **镜头时长统计**：每个镜头的起止时间和时长

**参数配置表**：

| 参数 | 默认值 | 推荐范围 | 说明 |
|------|--------|---------|------|
| threshold | 30.0 | 20-50 | 内容变化阈值，越高越不敏感 |
| min_scene_len | 15 | 10-30 | 最小镜头长度（帧） |
| luma_only | False | True/False | 仅使用亮度 |
| kernel_size | None | 3-7 | 模糊核大小，减少噪点影响 |
| downscale_factor | 1 | 1-4 | 降采样因子，提高速度 |

**Python 实现示例**：
```python
from scenedetect import open_video, SceneManager
from scenedetect.detectors import ContentDetector, ThresholdDetector, AdaptiveDetector
from typing import List, Dict, Tuple
import cv2
import numpy as np

class SceneAnalyzer:
    """镜头分析器"""
    
    def __init__(self, threshold: float = 30.0, min_scene_len: int = 15):
        self.threshold = threshold
        self.min_scene_len = min_scene_len
    
    def detect_scenes(self, video_path: str, detector_type: str = "content") -> List[Dict[str, Any]]:
        """
        检测镜头边界
        
        Args:
            video_path: 视频路径
            detector_type: 检测器类型 (content/threshold/adaptive)
        
        Returns:
            镜头列表，每个包含 start_time, end_time, start_frame, end_frame
        """
        video = open_video(video_path)
        scene_manager = SceneManager()
        
        if detector_type == "content":
            scene_manager.add_detector(
                ContentDetector(threshold=self.threshold, min_scene_len=self.min_scene_len)
            )
        elif detector_type == "threshold":
            scene_manager.add_detector(
                ThresholdDetector(threshold=self.threshold)
            )
        elif detector_type == "adaptive":
            scene_manager.add_detector(
                AdaptiveDetector(
                    adaptive_threshold=self.threshold,
                    min_scene_len=self.min_scene_len
                )
            )
        
        scene_manager.detect_scenes(video=video)
        scene_list = scene_manager.get_scene_list()
        
        result = []
        for i, scene in enumerate(scene_list):
            result.append({
                "index": i,
                "start_time": scene[0].get_seconds(),
                "end_time": scene[1].get_seconds(),
                "start_frame": scene[0].get_frames(),
                "end_frame": scene[1].get_frames(),
                "duration": scene[1].get_seconds() - scene[0].get_seconds()
            })
        
        return result
    
    def extract_keyframes(self, video_path: str, scenes: List[Dict], method: str = "middle") -> List[str]:
        """
        提取关键帧
        
        Args:
            video_path: 视频路径
            scenes: 镜头列表
            method: 提取方法 (middle/random/threshold)
        
        Returns:
            关键帧文件路径列表
        """
        cap = cv2.VideoCapture(video_path)
        keyframes = []
        
        for scene in scenes:
            if method == "middle":
                # 中间帧
                frame_num = (scene["start_frame"] + scene["end_frame"]) // 2
            elif method == "random":
                # 随机帧
                frame_num = np.random.randint(scene["start_frame"], scene["end_frame"])
            else:
                frame_num = scene["start_frame"]
            
            cap.set(cv2.CAP_PROP_POS_FRAMES, frame_num)
            ret, frame = cap.read()
            
            if ret:
                frame_path = f"keyframe_{scene['index']}.jpg"
                cv2.imwrite(frame_path, frame)
                keyframes.append(frame_path)
        
        cap.release()
        return keyframes
    
    def frame_diff_detection(self, video_path: str, threshold: float = 25.0) -> List[Dict]:
        """
        帧差法检测（简单快速）
        
        Args:
            video_path: 视频路径
            threshold: 差异阈值
        
        Returns:
            镜头边界列表
        """
        cap = cv2.VideoCapture(video_path)
        prev_frame = None
        scene_boundaries = []
        frame_count = 0
        
        while True:
            ret, frame = cap.read()
            if not ret:
                break
            
            # 转灰度
            gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
            gray = cv2.GaussianBlur(gray, (21, 21), 0)
            
            if prev_frame is not None:
                # 计算帧差
                frame_diff = cv2.absdiff(prev_frame, gray)
                diff_mean = np.mean(frame_diff)
                
                if diff_mean > threshold:
                    scene_boundaries.append({
                        "frame": frame_count,
                        "time": frame_count / cap.get(cv2.CAP_PROP_FPS),
                        "diff": diff_mean
                    })
            
            prev_frame = gray
            frame_count += 1
        
        cap.release()
        return scene_boundaries
```

#### 1.3 音频分析（librosa）

**工具**：librosa + numpy

**输入**：音频文件

**输出**：BPM / 节拍点 / 能量曲线 / 频谱特征

**核心功能**：
- **BPM检测**：tempo 估计
- **节拍跟踪**：beat 时间点
- **能量曲线**：RMS 能量包络
- **频谱特征**：梅尔频谱、MFCC、色度特征
- **音乐结构分析**：段落分割（副歌、主歌等）

**参数配置表**：

| 功能 | 参数 | 默认值 | 推荐范围 | 说明 |
|------|------|--------|---------|------|
| BPM检测 | start_bpm | 120 | 60-180 | 起始BPM估计 |
| BPM检测 | tightness | 100 | 10-1000 | 节拍紧密程度 |
| 节拍跟踪 | hop_length | 512 | 256-2048 | 跳帧长度 |
| 能量计算 | frame_length | 2048 | 1024-4096 | 帧长度 |
| 频谱分析 | n_mels | 128 | 64-256 | 梅尔带数量 |

**Python 实现示例**：
```python
import librosa
import librosa.display
import numpy as np
from typing import Dict, Any, List, Tuple

class AudioAnalyzer:
    """音频分析器"""
    
    def __init__(self, sr: int = 22050):
        self.sr = sr
    
    def load_audio(self, audio_path: str) -> Tuple[np.ndarray, int]:
        """加载音频"""
        y, sr = librosa.load(audio_path, sr=self.sr)
        return y, sr
    
    def detect_bpm(self, y: np.ndarray) -> Dict[str, Any]:
        """
        检测BPM和节拍点
        
        Returns:
            {'tempo': BPM值, 'beat_times': 节拍时间点列表}
        """
        tempo, beat_frames = librosa.beat.beat_track(y=y, sr=self.sr)
        beat_times = librosa.frames_to_time(beat_frames, sr=self.sr)
        
        return {
            "tempo": float(tempo),
            "beat_times": beat_times.tolist(),
            "beat_count": len(beat_times)
        }
    
    def compute_energy(self, y: np.ndarray) -> Dict[str, Any]:
        """
        计算能量曲线
        
        Returns:
            {'rms': RMS能量数组, 'times': 时间数组, 'peaks': 峰值点}
        """
        # RMS 能量
        rms = librosa.feature.rms(y=y)[0]
        times = librosa.times_like(rms, sr=self.sr)
        
        # 找峰值
        peaks = librosa.util.peak_pick(rms, pre_max=3, post_max=3, 
                                         pre_avg=3, post_avg=3, 
                                         delta=0.05, wait=10)
        peak_times = times[peaks].tolist()
        peak_values = rms[peaks].tolist()
        
        return {
            "rms": rms.tolist(),
            "times": times.tolist(),
            "peaks": [{"time": t, "value": float(v)} for t, v in zip(peak_times, peak_values)],
            "average_energy": float(np.mean(rms)),
            "max_energy": float(np.max(rms))
        }
    
    def compute_spectral_features(self, y: np.ndarray) -> Dict[str, Any]:
        """
        计算频谱特征
        
        Returns:
            频谱特征字典
        """
        # 梅尔频谱
        mel_spec = librosa.feature.melspectrogram(y=y, sr=self.sr, n_mels=128)
        mel_spec_db = librosa.power_to_db(mel_spec, ref=np.max)
        
        # MFCC
        mfcc = librosa.feature.mfcc(y=y, sr=self.sr, n_mfcc=20)
        
        # 色度特征
        chroma = librosa.feature.chroma_stft(y=y, sr=self.sr)
        
        # 谱质心
        spectral_centroid = librosa.feature.spectral_centroid(y=y, sr=self.sr)[0]
        
        # 谱带宽
        spectral_bandwidth = librosa.feature.spectral_bandwidth(y=y, sr=self.sr)[0]
        
        return {
            "mel_spectrogram_shape": mel_spec_db.shape,
            "mfcc_shape": mfcc.shape,
            "chroma_shape": chroma.shape,
            "spectral_centroid_mean": float(np.mean(spectral_centroid)),
            "spectral_bandwidth_mean": float(np.mean(spectral_bandwidth)),
            "average_chroma": np.mean(chroma, axis=1).tolist()
        }
    
    def detect_segments(self, y: np.ndarray) -> List[Dict[str, Any]]:
        """
        音乐段落检测（粗略）
        
        Returns:
            段落列表
        """
        # 基于能量变化的简单分段
        rms = librosa.feature.rms(y=y)[0]
        times = librosa.times_like(rms, sr=self.sr)
        
        # 平滑能量曲线
        rms_smooth = np.convolve(rms, np.ones(50)/50, mode='same')
        
        # 找显著变化点
        diff = np.diff(rms_smooth)
        threshold = np.std(diff) * 2
        
        segment_boundaries = np.where(np.abs(diff) > threshold)[0]
        segment_times = times[segment_boundaries].tolist()
        
        # 合并相近边界
        merged = []
        last_time = -1
        for t in segment_times:
            if t - last_time > 5:  # 最小段落5秒
                merged.append(t)
                last_time = t
        
        # 生成段落
        segments = []
        for i in range(len(merged) - 1):
            segments.append({
                "index": i,
                "start_time": merged[i],
                "end_time": merged[i + 1],
                "duration": merged[i + 1] - merged[i],
                "avg_energy": float(np.mean(rms_smooth[segment_boundaries[i]:segment_boundaries[i+1]]))
            })
        
        return segments
    
    def full_analysis(self, audio_path: str) -> Dict[str, Any]:
        """完整音频分析"""
        y, sr = self.load_audio(audio_path)
        duration = librosa.get_duration(y=y, sr=sr)
        
        return {
            "duration": duration,
            "sample_rate": sr,
            "num_samples": len(y),
            "bpm": self.detect_bpm(y),
            "energy": self.compute_energy(y),
            "spectral": self.compute_spectral_features(y),
            "segments": self.detect_segments(y)
        }
```

#### 1.4 语音识别（Whisper / FunASR）

**工具**：OpenAI Whisper / 阿里 FunASR

**输入**：音频文件

**输出**：字幕时间轴 / 台词文本

**核心功能**：
- **语音转文字**：将语音内容转换为文字
- **时间戳**：每个词/句子的起止时间
- **说话人识别**：多说话人分离（可选）
- **语言检测**：自动检测语言
- **字幕格式输出**：SRT / VTT / ASS

**参数配置表**：

import whisper
from typing import List, Dict, Any, Optional

class SpeechRecognizer:
    """语音识别器"""
    
    def __init__(self, model_name: str = "base", device: str = "cpu"):
        self.model_name = model_name
        self.device = device
        self.model = None
    
    def load_model(self):
        """加载模型"""
        if self.model is None:
            self.model = whisper.load_model(self.model_name, device=self.device)
    
    def transcribe(
        self,
        audio_path: str,
        language: Optional[str] = None,
        task: str = "transcribe"
    ) -> Dict[str, Any]:
        """
        语音转文字
        
        Args:
            audio_path: 音频文件路径
            language: 指定语言（zh/en/ja等），None自动检测
            task: transcribe（转录）/ translate（翻译为英文）
        
        Returns:
            转写结果字典
        """
        self.load_model()
        
        result = self.model.transcribe(
            audio_path,
            language=language,
            task=task,
            word_timestamps=True,  # 词级别时间戳
            fp16=False  # CPU模式下关闭
        )
        
        # 处理结果
        segments = []
        for seg in result["segments"]:
            words = []
            if "words" in seg:
                for w in seg["words"]:
                    words.append({
                        "word": w["word"],
                        "start": w["start"],
                        "end": w["end"],
                        "probability": w.get("probability", 0)
                    })
            
            segments.append({
                "id": seg["id"],
                "start": seg["start"],
                "end": seg["end"],
                "text": seg["text"].strip(),
                "words": words
            })
        
        return {
            "text": result["text"],
            "language": result.get("language", "unknown"),
            "segments": segments,
            "duration": result.get("segments", [{}])[-1].get("end", 0) if result.get("segments") else 0
        }
    
    def export_srt(self, result: Dict[str, Any], output_path: str):
        """导出SRT字幕文件"""
        with open(output_path, "w", encoding="utf-8") as f:
            for i, seg in enumerate(result["segments"], 1):
                start = self._format_time(seg["start"])
                end = self._format_time(seg["end"])
                f.write(f"{i}\n")
                f.write(f"{start} --> {end}\n")
                f.write(f"{seg['text']}\n\n")
    
    def _format_time(self, seconds: float) -> str:
        """格式化时间为 SRT 格式"""
        h = int(seconds // 3600)
        m = int((seconds % 3600) // 60)
        s = int(seconds % 60)
        ms = int((seconds % 1) * 1000)
        return f"{h:02d}:{m:02d}:{s:02d},{ms:03d}"
```

from PIL import Image
from transformers import BlipProcessor, BlipForConditionalGeneration
from typing import List, Dict, Any
import torch

class ImageUnderstander:
    """画面理解器"""
    
    def __init__(self, model_name: str = "Salesforce/blip-image-captioning-base"):
        self.model_name = model_name
        self.processor = None
        self.model = None
    
    def load_model(self):
        """加载模型"""
        if self.model is None:
            self.processor = BlipProcessor.from_pretrained(self.model_name)
            self.model = BlipForConditionalGeneration.from_pretrained(self.model_name)
    
    def generate_caption(
        self,
        image_path: str,
        max_length: int = 100,
        num_beams: int = 5
    ) -> str:
        """
        生成图像描述
        
        Args:
            image_path: 图片路径
            max_length: 最大生成长度
            num_beams: beam search数量
        
        Returns:
            描述文本
        """
        self.load_model()
        
        image = Image.open(image_path).convert("RGB")
        inputs = self.processor(image, return_tensors="pt")
        
        with torch.no_grad():
            out = self.model.generate(
                **inputs,
                max_length=max_length,
                num_beams=num_beams,
                early_stopping=True
            )
        
        caption = self.processor.decode(out[0], skip_special_tokens=True)
        return caption
    
    def analyze_frame_batch(
        self,
        image_paths: List[str],
        batch_size: int = 4
    ) -> List[Dict[str, Any]]:
        """
        批量分析帧
        
        Args:
            image_paths: 图片路径列表
            batch_size: 批大小
        
        Returns:
            分析结果列表
        """
        self.load_model()
        results = []
        
        for i in range(0, len(image_paths), batch_size):
            batch = image_paths[i:i + batch_size]
            images = [Image.open(p).convert("RGB") for p in batch]
            
            inputs = self.processor(images=images, return_tensors="pt")
            
            with torch.no_grad():
                out = self.model.generate(
                    **inputs,
                    max_length=100,
                    num_beams=5,
                    early_stopping=True
                )
            
            for j, output in enumerate(out):
                caption = self.processor.decode(output, skip_special_tokens=True)
                results.append({
                    "image_path": batch[j],
                    "caption": caption,
                    "index": i + j
                })
        
        return results
```

### 2.3 关节跟踪（木偶绑定数据）⭐

#### MediaPipe 检测示例
```python
import cv2
import mediapipe as mp
import numpy as np
from typing import List, Dict, Any

class PoseEstimator:
    """姿态估计器（MediaPipe）"""
    
    def __init__(self, model_complexity: int = 1):
        self.mp_pose = mp.solutions.pose
        self.pose = self.mp_pose.Pose(
            model_complexity=model_complexity,
            smooth_landmarks=True,
            min_detection_confidence=0.5,
            min_tracking_confidence=0.5
        )
        self.mp_draw = mp.solutions.drawing_utils
    
    def estimate(self, frame: np.ndarray) -> Dict[str, Any]:
        """
        估计人体姿态
        
        Returns:
            姿态结果，包含17个关键点
        """
        rgb_frame = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
        results = self.pose.process(rgb_frame)
        
        if not results.pose_landmarks:
            return {"detected": False}
        
        landmarks = results.pose_landmarks.landmark
        
        # 提取17个关键点（COCO格式映射）
        keypoints_map = {
            0: 0,   # 鼻子
            1: 2,   # 左眼
            2: 5,   # 右眼
            3: 7,   # 左耳
            4: 8,   # 右耳
            5: 11,  # 左肩
            6: 12,  # 右肩
            7: 13,  # 左肘
            8: 14,  # 右肘
            9: 15,  # 左手
            10: 16, # 右手
            11: 23, # 左髋
            12: 24, # 右髋
            13: 25, # 左膝
            14: 26, # 右膝
            15: 27, # 左脚
            16: 28  # 右脚
        }
        
        h, w = frame.shape[:2]
        keypoints = []
        
        for coco_id, mp_id in keypoints_map.items():
            lm = landmarks[mp_id]
            keypoints.append({
                "id": coco_id,
                "name": self._get_name(coco_id),
                "x": lm.x * w,
                "y": lm.y * h,
                "visibility": lm.visibility,
                "presence": lm.presence
            })
        
        return {
            "detected": True,
            "keypoints": keypoints,
            "bounding_box": self._get_bbox(keypoints),
            "confidence": min(kp["visibility"] for kp in keypoints)
        }
    
    def _get_name(self, coco_id: int) -> str:
        names = [
            "nose", "left_eye", "right_eye", "left_ear", "right_ear",
            "left_shoulder", "right_shoulder", "left_elbow", "right_elbow",
            "left_wrist", "right_wrist", "left_hip", "right_hip",
            "left_knee", "right_knee", "left_ankle", "right_ankle"
        ]
        return names[coco_id]
    
    def _get_bbox(self, keypoints: list) -> List[float]:
        """计算包围盒"""
        xs = [kp["x"] for kp in keypoints if kp["visibility"] > 0.5]
        ys = [kp["y"] for kp in keypoints if kp["visibility"] > 0.5]
        
        if not xs or not ys:
            return [0, 0, 0, 0]
        
        return [min(xs), min(ys), max(xs), max(ys)]
    
    def process_video(self, video_path: str) -> List[Dict[str, Any]]:
        """
        处理视频，提取逐帧关节点
        
        Returns:
            每帧的姿态结果列表
        """
        cap = cv2.VideoCapture(video_path)
        results = []
        frame_idx = 0
        
        while True:
            ret, frame = cap.read()
            if not ret:
                break
            
            pose_result = self.estimate(frame)
            pose_result["frame"] = frame_idx
            pose_result["time"] = frame_idx / cap.get(cv2.CAP_PROP_FPS)
            results.append(pose_result)
            
            frame_idx += 1
        
        cap.release()
        return results
```

#### 关节点后处理
```python
import numpy as np
from scipy.interpolate import interp1d
from scipy.signal import savgol_filter
from typing import List, Dict, Any

class JointSmoother:
    """关节点平滑器"""
    
    def __init__(self):
        pass
    
    def smooth_temporal(self, joint_data: List[Dict], method: str = "savgol", **kwargs) -> List[Dict]:
        """
        时间域平滑
        
        Args:
            joint_data: 关节点数据列表（逐帧）
            method: 平滑方法 (savgol/interp/median)
        
        Returns:
            平滑后的关节点数据
        """
        if not joint_data:
            return joint_data
        
        num_joints = 17  # COCO 17点
        num_frames = len(joint_data)
        
        # 提取坐标数组
        xs = np.zeros((num_frames, num_joints))
        ys = np.zeros((num_frames, num_joints))
        vis = np.zeros((num_frames, num_joints))
        
        for f_idx, frame_data in enumerate(joint_data):
            if frame_data.get("detected", False):
                for kp in frame_data["keypoints"]:
                    jid = kp["id"]
                    xs[f_idx, jid] = kp["x"]
                    ys[f_idx, jid] = kp["y"]
                    vis[f_idx, jid] = kp.get("visibility", 0)
            else:
                vis[f_idx, :] = 0
        
        # 填充缺失帧
        for j in range(num_joints):
            valid = vis[:, j] > 0.3
            if np.any(valid):
                valid_indices = np.where(valid)[0]
                f_interp_x = interp1d(
                    valid_indices, xs[valid, j],
                    kind='linear', fill_value="extrapolate"
                )
                f_interp_y = interp1d(
                    valid_indices, ys[valid, j],
                    kind='linear', fill_value="extrapolate"
                )
                all_indices = np.arange(num_frames)
                xs[:, j] = f_interp_x(all_indices)
                ys[:, j] = f_interp_y(all_indices)
        
        # 平滑
        if method == "savgol":
            window = kwargs.get("window_length", 11)
            polyorder = kwargs.get("polyorder", 2)
            xs = savgol_filter(xs, window, polyorder, axis=0)
            ys = savgol_filter(ys, window, polyorder, axis=0)
        
        elif method == "gaussian":
            sigma = kwargs.get("sigma", 2.0)
            from scipy.ndimage import gaussian_filter1d
            xs = gaussian_filter1d(xs, sigma, axis=0)
            ys = gaussian_filter1d(ys, sigma, axis=0)
        
        # 写回结果
        smoothed_data = []
        for f_idx in range(num_frames):
            frame_data = {
                "frame": f_idx,
                "detected": True,
                "keypoints": []
            }
            for j in range(num_joints):
                frame_data["keypoints"].append({
                    "id": j,
                    "x": float(xs[f_idx, j]),
                    "y": float(ys[f_idx, j]),
                    "visibility": float(vis[f_idx, j])
                })
            smoothed_data.append(frame_data)
        
        return smoothed_data
    
    def compute_joint_angles(self, joint_data: List[Dict]) -> List[Dict]:
        """
        计算关节角度
        
        Returns:
            每帧的关节角度数据
        """
        angle_data = []
        
        for frame_data in joint_data:
            if not frame_data.get("detected", False):
                angle_data.append({})
                continue
            
            kps = {kp["id"]: (kp["x"], kp["y"]) for kp in frame_data["keypoints"]}
            
            angles = {}
            
            # 左肘角度（肩-肘-腕）
            if all(i in kps for i in [5, 7, 9]):
                angles["left_elbow"] = self._angle(kps[5], kps[7], kps[9])
            
            # 右肘角度
            if all(i in kps for i in [6, 8, 10]):
                angles["right_elbow"] = self._angle(kps[6], kps[8], kps[10])
            
            # 左肩角度（颈-肩-肘）
            if all(i in kps for i in [5, 7]):
                neck = ((kps[5][0] + kps[6][0]) / 2, (kps[5][1] + kps[6][1]) / 2)
                angles["left_shoulder"] = self._angle(neck, kps[5], kps[7])
            
            # 右肩角度
            if all(i in kps for i in [6, 8]):
                neck = ((kps[5][0] + kps[6][0]) / 2, (kps[5][1] + kps[6][1]) / 2)
                angles["right_shoulder"] = self._angle(neck, kps[6], kps[8])
            
            # 左膝角度
            if all(i in kps for i in [11, 13, 15]):
                angles["left_knee"] = self._angle(kps[11], kps[13], kps[15])
            
            # 右膝角度
            if all(i in kps for i in [12, 14, 16]):
                angles["right_knee"] = self._angle(kps[12], kps[14], kps[16])
            
            angle_data.append(angles)
        
        return angle_data
    
    def _angle(self, p1: tuple, p2: tuple, p3: tuple) -> float:
        """计算三点角度（以p2为顶点）"""
        v1 = np.array([p1[0] - p2[0], p1[1] - p2[1]])
        v2 = np.array([p3[0] - p2[0], p3[1] - p2[1]])
        
        cos_theta = np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2))
        cos_theta = np.clip(cos_theta, -1, 1)
        theta = np.arccos(cos_theta)
        
        return np.degrees(theta)
```

#### MediaPipe Face Mesh 示例
```python
import cv2
import mediapipe as mp
import numpy as np
from typing import Dict, Any

class FaceTracker:
    """面部跟踪器"""
    
    def __init__(self, refine_landmarks: bool = True):
        self.mp_face_mesh = mp.solutions.face_mesh
        self.face_mesh = self.mp_face_mesh.FaceMesh(
            max_num_faces=1,
            refine_landmarks=refine_landmarks,
            min_detection_confidence=0.5,
            min_tracking_confidence=0.5
        )
        self.mp_draw = mp.solutions.drawing_utils
    
    def track(self, frame: np.ndarray) -> Dict[str, Any]:
        """
        跟踪面部关键点
        
        Returns:
            面部跟踪结果
        """
        rgb_frame = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
        results = self.face_mesh.process(rgb_frame)
        
        if not results.multi_face_landmarks:
            return {"detected": False}
        
        face_landmarks = results.multi_face_landmarks[0]
        h, w = frame.shape[:2]
        
        # 提取所有468个关键点
        all_landmarks = []
        for lm in face_landmarks.landmark:
            all_landmarks.append({
                "x": lm.x * w,
                "y": lm.y * h,
                "z": lm.z * w
            })
        
        # 计算表情参数
        expression_params = self._compute_expression_params(all_landmarks)
        
        # 计算头部姿态
        head_pose = self._compute_head_pose(all_landmarks, (w, h))
        
        return {
            "detected": True,
            "num_landmarks": len(all_landmarks),
            "landmarks": all_landmarks,
            "expression_params": expression_params,
            "head_pose": head_pose
        }
    
    def _compute_expression_params(self, landmarks: list) -> Dict[str, float]:
        """计算表情参数（从468点简化为20个参数）"""
        # 关键点索引（MediaPipe Face Mesh）
        LEFT_EYE_TOP = 386
        LEFT_EYE_BOTTOM = 374
        RIGHT_EYE_TOP = 159
        RIGHT_EYE_BOTTOM = 145
        MOUTH_TOP = 13
        MOUTH_BOTTOM = 14
        MOUTH_LEFT = 78
        MOUTH_RIGHT = 308
        LEFT_BROW = 105
        RIGHT_BROW = 334
        NOSE_TIP = 1
        JAW = 152
        FACE_LEFT = 234
        FACE_RIGHT = 454
        FACE_TOP = 10
        FACE_BOTTOM = 152
        
        def dist(i, j):
            return np.sqrt(
                (landmarks[i]["x"] - landmarks[j]["x"]) ** 2 +
                (landmarks[i]["y"] - landmarks[j]["y"]) ** 2
            )
        
        face_height = dist(FACE_TOP, FACE_BOTTOM)
        face_width = dist(FACE_LEFT, FACE_RIGHT)
        
        params = {}
        
        # 眼睛开合度（归一化）
        left_eye_dist = dist(LEFT_EYE_TOP, LEFT_EYE_BOTTOM) / face_height
        right_eye_dist = dist(RIGHT_EYE_TOP, RIGHT_EYE_BOTTOM) / face_height
        params["eye_openness_left"] = np.clip(left_eye_dist / 0.05, 0, 1)
        params["eye_openness_right"] = np.clip(right_eye_dist / 0.05, 0, 1)
        
        # 嘴巴开合度
        mouth_open = dist(MOUTH_TOP, MOUTH_BOTTOM) / face_height
        params["mouth_openness"] = np.clip(mouth_open / 0.15, 0, 1)
        
        # 嘴巴宽度
        mouth_width_val = dist(MOUTH_LEFT, MOUTH_RIGHT) / face_width
        params["mouth_width"] = np.clip((mouth_width_val - 0.3) / 0.2, 0, 1)
        
        # 眉毛高度
        brow_ref_y = (landmarks[NOSE_TIP]["y"]) / face_height
        left_brow_y = landmarks[LEFT_BROW]["y"] / face_height
        right_brow_y = landmarks[RIGHT_BROW]["y"] / face_height
        params["brow_left_height"] = np.clip((brow_ref_y - left_brow_y - 0.3) / 0.1, -1, 1)
        params["brow_right_height"] = np.clip((brow_ref_y - right_brow_y - 0.3) / 0.1, -1, 1)
        
        # 下颌张开度
        jaw_dist = dist(NOSE_TIP, JAW) / face_height
        params["jaw_openness"] = np.clip((jaw_dist - 0.45) / 0.15, 0, 1)
        
        # 微笑强度（嘴角上扬）
        mouth_mid_y = (landmarks[MOUTH_LEFT]["y"] + landmarks[MOUTH_RIGHT]["y"]) / 2
        lip_top_y = landmarks[MOUTH_TOP]["y"]
        smile_val = (lip_top_y - mouth_mid_y) / face_height
        params["smile_intensity"] = np.clip((smile_val + 0.03) / 0.05, 0, 1)
        
        return params
    
    def _compute_head_pose(self, landmarks: list, img_size: tuple) -> Dict[str, float]:
        """计算头部姿态（翻滚/俯仰/偏航）"""
        w, h = img_size
        
        # 选取关键点
        model_points = np.array([
            (0.0, 0.0, 0.0),       # 鼻尖
            (0.0, -330.0, -65.0),  # 下巴
            (-225.0, 170.0, -135.0),  # 左眼角
            (225.0, 170.0, -135.0),   # 右眼角
            (-150.0, -150.0, -125.0), # 左嘴角
            (150.0, -150.0, -125.0)   # 右嘴角
        ], dtype=np.float64)
        
        image_points = np.array([
            (landmarks[1]["x"], landmarks[1]["y"]),      # 鼻尖
            (landmarks[152]["x"], landmarks[152]["y"]),  # 下巴
            (landmarks[263]["x"], landmarks[263]["y"]),  # 左眼角
            (landmarks[33]["x"], landmarks[33]["y"]),    # 右眼角
            (landmarks[287]["x"], landmarks[287]["y"]),  # 左嘴角
            (landmarks[57]["x"], landmarks[57]["y"]),    # 右嘴角
        ], dtype=np.float64)
        
        focal_length = w
        center = (w / 2, h / 2)
        camera_matrix = np.array([
            [focal_length, 0, center[0]],
            [0, focal_length, center[1]],
            [0, 0, 1]
        ], dtype=np.float64)
        
        dist_coeffs = np.zeros((4, 1), dtype=np.float64)
        
        success, rotation_vec, translation_vec = cv2.solvePnP(
            model_points, image_points, camera_matrix, dist_coeffs
        )
        
        if success:
            rotation_mat, _ = cv2.Rodrigues(rotation_vec)
            # 计算欧拉角
            roll = np.degrees(np.arctan2(rotation_mat[2, 1], rotation_mat[2, 2]))
            pitch = np.degrees(-np.arcsin(rotation_mat[2, 0]))
            yaw = np.degrees(np.arctan2(rotation_mat[1, 0], rotation_mat[0, 0]))
        else:
            roll, pitch, yaw = 0, 0, 0
        
        return {
            "roll": roll,
            "pitch": pitch,
            "yaw": yaw
        }
```

### 5.3 ffmpeg 命令库

```python
import subprocess
import os
from typing import Dict, List, Optional

class FFmpegRenderer:
    """FFmpeg 渲染器"""
    
    def __init__(self, ffmpeg_path: str = "ffmpeg"):
        self.ffmpeg_path = ffmpeg_path
    
    def render_mp4(
        self,
        input_path: str,
        output_path: str,
        codec: str = "h264",
        bitrate: str = "20M",
        resolution: Optional[tuple] = None,
        framerate: Optional[int] = None
    ) -> bool:
        """渲染 MP4"""
        cmd = [self.ffmpeg_path, "-i", input_path]
        
        if codec == "h264":
            cmd.extend(["-c:v", "libx264", "-preset", "slow", "-crf", "20"])
        elif codec == "h265":
            cmd.extend(["-c:v", "libx265", "-preset", "slow", "-crf", "22"])
        
        if resolution:
            cmd.extend(["-s", f"{resolution[0]}x{resolution[1]}"])
        
        if framerate:
            cmd.extend(["-r", str(framerate)])
        
        cmd.extend(["-c:a", "aac", "-b:a", "256k"])
        cmd.extend(["-y", output_path])
        
        result = subprocess.run(cmd, capture_output=True)
        return result.returncode == 0
    
    def render_gif(
        self,
        input_path: str,
        output_path: str,
        fps: int = 15,
        scale: int = 480
    ) -> bool:
        """渲染 GIF"""
        palette = "/tmp/palette.png"
        
        # 生成调色板
        cmd1 = [
            self.ffmpeg_path, "-i", input_path,
            "-vf", f"fps={fps},scale={scale}:-1:flags=lanczos,palettegen",
            "-y", palette
        ]
        subprocess.run(cmd1, capture_output=True)
        
        # 使用调色板生成GIF
        cmd2 = [
            self.ffmpeg_path, "-i", input_path, "-i", palette,
            "-lavfi", f"fps={fps},scale={scale}:-1:flags=lanczos [x]; [x][1:v] paletteuse",
            "-y", output_path
        ]
        result = subprocess.run(cmd2, capture_output=True)
        
        os.remove(palette)
        return result.returncode == 0
    
    def extract_thumbnail(
        self,
        input_path: str,
        output_path: str,
        time_point: float = 1.0,
        resolution: Optional[tuple] = None
    ) -> bool:
        """提取缩略图"""
        cmd = [
            self.ffmpeg_path, "-ss", str(time_point),
            "-i", input_path, "-vframes", "1",
            "-q:v", "2"
        ]
        
        if resolution:
            cmd.extend(["-s", f"{resolution[0]}x{resolution[1]}"])
        
        cmd.extend(["-y", output_path])
        result = subprocess.run(cmd, capture_output=True)
        return result.returncode == 0
    
    def batch_render(self, input_path: str, output_dir: str, presets: List[Dict]) -> Dict[str, str]:
        """批量渲染多种格式"""
        os.makedirs(output_dir, exist_ok=True)
        results = {}
        
        for preset in presets:
            name = preset["name"]
            ext = preset.get("format", "mp4")
            output_path = os.path.join(output_dir, f"{name}.{ext}")
            
            if ext == "gif":
                success = self.render_gif(
                    input_path, output_path,
                    fps=preset.get("fps", 15),
                    scale=preset.get("scale", 480)
                )
            else:
                success = self.render_mp4(
                    input_path, output_path,
                    codec=preset.get("codec", "h264"),
                    bitrate=preset.get("bitrate", "20M"),
                    resolution=preset.get("resolution"),
                    framerate=preset.get("framerate")
                )
            
            results[name] = output_path if success else None
        
        return results
```
