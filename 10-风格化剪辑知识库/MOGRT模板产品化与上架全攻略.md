# 📦 MOGRT 模板产品化与上架全攻略

> 从技术底层到市场分发——MOGRT 作为 AE 模板的编译后二进制格式，从 Adobe Stock 到 Envato，从响应式设计到批量自动化，构建模板即产品的完整知识体系。

---

## 🔧 MOGRT 技术深度

### 内部结构：双层 ZIP

```
template.mogrt
  └── .zip 解压
       └── Project.aegraphic        ← 核心包文件
            └── 再次 .zip 解压
                 ├── Project.aep    ← AE 工程文件
                 ├── XMP/metadata   ← XML 元数据（EGP 控件定义）
                 ├── fonts/         ← 嵌入字体 (.otf/.ttf)
                 ├── images/        ← 嵌入图片 (PNG/JPEG)
                 ├── videos/        ← 嵌入视频 (MP4/MOV)
                 └── scripts/       ← Adobe 表达式脚本 (JSX/JSON)
```

### Essential Graphics Panel 完整控件清单

| 控件类型 | 对应 AE 属性 | 说明 |
|----------|-------------|------|
| **文本控件** | Source Text | Premiere 中直接编辑文字 |
| **颜色控件** | Color 属性 | 色块/渐变色调整 |
| **滑块控件** | Slider Control | 数值 0-100，透明度/速度等 |
| **角度控件** | Angle Control | 0-360° 旋转控制 |
| **点控件** | Point Control | 二维位置点 |
| **复选框** | Checkbox Control | 布尔开关（效果/图层可见性） |
| **媒体替换** | Footage 图层 | 用户替换图片/视频（★PR 核心功能） |
| **下拉菜单** | Dropdown Menu Control | 预定义选项（风格 1/2/3） |
| **字体控件** | Font 属性 | 换字体（需 AE 2019+） |

### 支持与不支持

#### ✅ 支持
- 标准关键帧动画（位置/缩放/旋转/透明度）
- 遮罩和形状图层动画
- 表达式（JavaScript 引擎，含 `sourceRectAtTime()`）
- Protected Regions 响应式设计
- 原生 AE 效果（PR 兼容子集）
- 文本动画器（范围选择器/摆动）
- 形状图层修剪路径

#### ❌ 不支持/受限
- **第三方插件效果**（需预渲染为视频嵌入）
- Cinema 4D / Cineware 效果
- 非 Classic 3D 渲染器
- 复杂粒子系统（Trapcode 等需预渲染）
- 部分高级混合模式和图层样式
- 动态链接 MOGRT（需 AE 安装，性能极差）

### 字体处理策略

| 策略 | 适用场景 | 要点 |
|------|---------|------|
| **仅 Adobe Fonts** | Adobe Stock 上架（**强制**） | CC 自动激活，零用户摩擦；最常见拒绝原因就是不遵守 |
| **Google Fonts (SIL OFL)** | Envato/Motion Array | 法律允许嵌入和商业分发，需附带 OFL 许可证文件 |
| **打包 .otf/.ttf** | 任何平台 | 确保可用但占空间，注意许可 |
| **硬编码为形状** | 简短标题/Logo | 零字体依赖，无法编辑文字 |

> ⚠️ **关键警告**：不要将商业桌面许可字体（MyFonts/Creative Market 购买）嵌入 MOGRT 销售——桌面许可不覆盖再分发！

### 版本兼容性：向前兼容，不可向后

| AE 导出版本 | PR 2022 | PR 2023 | PR 2024 | PR 2025 |
|------------|---------|---------|---------|---------|
| AE 2022 | ✅ | ✅ | ✅ | ✅ |
| AE 2023 | ❌ | ✅ | ✅ | ✅ |
| AE 2024 | ❌ | ❌ | ✅ | ✅ |
| AE 2025 | ❌ | ❌ | ❌ | ✅ |

> 💡 **最佳实践**：用最旧目标 AE 版本导出 MOGRT。要支持 PR 2022 用户，就用 AE 2022 导出。

## 🏪 上架平台全攻略

### 平台对比总览

| 维度 | Adobe Stock | Envato Elements | Motion Array | VideoHive |
|------|------------|----------------|-------------|-----------|
| **类型** | 素材库+模板 | 订阅制素材库 | 订阅制模板 | 单次购买模板 |
| **收益模式** | 版权费 35% | 订阅池分成 | 7 级分层 10-45% | 统一 50% 分成 |
| **审核难度** | 高（字体严） | 中-高 | 中-高 | 高（设计趋势） |
| **MOGRT 接受** | ✅ EGP 模板 | ✅ PR 模板 | ✅ | ✅ |
| **字体要求** | **仅 Adobe Fonts** | 合法即可 | 合法即可 | 合法即可 |
| **独家要求** | 非独家 | 非独家（2026.7 起） | 非独家 | 非独家（2026.7 起） |

### Adobe Stock 详细

- 版税率：视频/模板 35%
- 审核重点：**字体必须是 Adobe Fonts** → 最常见拒绝原因
- 最低提现：$25（PayPal/Payoneer/Skrill）
- 优势：Creative Cloud 应用内集成，曝光度极高，**#1 贡献者收入平台**
- 中国可用性：需 VPN + Payoneer，无直接人民币渠道

### Envato Elements

- 订阅池分成：按下载量占比分配月度订阅收入
- **2026.07.01 重大变化**：废除独家制度，**所有作者统一 50% 分成**
  - 顶级独家作者（曾 87.5%）收入腰斩
  - 非独家作者（曾 32.5-45%）涨薪 5-17.5%
  - → **多平台分发成为必然策略**

### Motion Array

- 7 级分层版税（基于月度下载量）：
  - 第 7 级（1601+ AE 模板下载）= **45%**
  - 第 1 级（0-50）= 15%
- 额外激励：Top 20 最热项目 200% 下载计数加成；每月 $150 奖励

### 多平台分发策略

```
阶段 1：Motion Array / VideoHive → 测试设计接受度
阶段 2：修改字体为 Adobe Fonts → 提交 Adobe Stock
阶段 3：6 个月后推变体 → 扩展到其他平台
最终：Adobe Stock + Motion Array + Envato Elements = 最大覆盖
```

## 🎨 模板产品设计原则

### 2025 热卖品类

| 排名 | 品类 | 趋势 |
|------|------|------|
| **1** | 短视频/竖屏模板（9:16） | 最大且增长最快 |
| **2** | 社交媒体字幕条（Lower Thirds） | 常年热销 |
| **3** | 转场过渡（Transitions） | 抖音/TikTok 驱动 |
| **4** | 片头/Logo 动画 | 光效/粒子/赛博朋克/酸性设计 |
| **5** | 动态排版（Kinetic Typography） | 快闪文字/卡点字幕 |
| **6** | MG 循环背景 | 2D 扁平几何/渐变液态 |
| **7** | 数据可视化/信息图 | 企业需求稳定 |
| **8** | 节日模板 | 季节性（新年/春节/圣诞） |

> ❌ 避免饱和品类：外太空飞行、云层延时、通用"现代幻灯片"、基础粒子

### 竖版优先策略

- **9:16 是 2025 默认格式**——优先设计竖版，再制横版变体
- 每个 MOGRT 可包含多个分辨率版本
- 竖版模板市场增速远超横版（TikTok/Reels/Shorts 驱动）

### 模块化设计原则

| 原则 | 实施 |
|------|------|
| **多场景** | 一个模板解决多个场景 |
| **多时长** | 15s / 30s / 60s 版本 |
| **多配色** | 3-5 个配色方案（下拉菜单切换） |
| **通用化** | 避免过于具体的使用场景，保持视觉特色 |
| **分离式** | 文字/颜色/Logo/背景独立可控 |

### 定价策略

| 复杂度 | 制作时间 | 建议售价 |
|--------|---------|---------|
| 简单（字幕条/转场） | 2-4 小时 | $10-$25 |
| 中等（包装/片头） | 1-3 天 | $25-$49 |
| 复杂（广播包/工具包） | 1-4 周 | $49-$199 |

**终身价值（LTV）**：一个畅销模板在 Elements 上终身可赚 $50-$500+；通过量大积累（500-5,000+ 模板）实现复利。

## 📣 营销与增长

### 预览视频制作规则

- 仅使用许可合规媒体（Pexels/Pixabay/Unsplash 或平台内置库）
- 展示真实功能和可定制性——不添加模板不具备的效果
- **不得出现**：软件界面截图、4K/HD 标记、第三方 Logo、邮箱地址
- 使用平台内置音乐库，附上链接

### SEO 优化

- 标题：描述性 + 独特 + 核心功能词（如 "Responsive Lower Thirds | Media Replacement | 4K"）
- **不要**加过多标点、版本号、分辨率参数
- 标签覆盖使用场景（titles, transitions, social media, YouTube, corporate）
- 描述清晰列出所有功能

### 品牌建设

- 统一视觉风格 → 品牌辨识度
- 一致命名规范
- 高质量帮助文档 + 教程视频（≤10MB，Help 文件夹）
- **免费引流 + 付费转化**：发布免费轻量版建立受众 → 推广付费完整版

## 🤖 工作流与自动化

### Nexrender（开源/免费）

- GitHub: `github.com/inlife/nexrender`（MIT 开源）
- Node.js CLI，JSON job 定义数据驱动 AE 渲染
- **不需要 AE GUI**，使用 `aerender` 命令行
- 支持 Render Farm（`nexrender-server` + `nexrender-worker` HTTP API）
- **Nexrender Cloud（2024 新增）**：直接上传 .mogrt → 自动自省 EGP 字段 → JSON 参数映射 → REST API → Webhooks

### Dataclay Templater（商业/企业级）

| 版本 | 价格 | 能力 |
|------|------|------|
| **Templater Rig** | — | 准备/映射 AE 项目数据 |
| **Templater Pro** | $225/月起 | 批量复制渲染、自定义命名、AME 集成 |
| **Templater Bot** | 联系报价 | CLI 自动化、无头运行、15-15,000+ 视频/批次 |

企业特性：Google Sheets / JSON / REST API 数据源、Time Sculpting 专利技术、Projector 并行渲染系统。

### 完整 Checklist

**阶段 1：开发**
- [ ] 确认目标平台规范（Adobe Stock/Envato/Motion Array）
- [ ] 选择字体策略（Adobe Fonts vs Google Fonts）
- [ ] 设计 3-5 个变体方案
- [ ] 实现响应式设计（sourceRectAtTime + Protected Regions）
- [ ] Expression Universalizer 通用化所有表达式

**阶段 2：QC**
- [ ] 目标 PR 版本中测试所有控件
- [ ] 所有文字设通用占位符（无真实品牌/名称/地点）
- [ ] 所有颜色控制器链接到实际元素
- [ ] 预览视频准确反映模板

**阶段 3：打包**
- [ ] File → Dependencies → Collect Files
- [ ] 文件夹结构：MOGRT/ + Fonts/ + Help/
- [ ] 包含许可证文件（OFL.txt）
- [ ] Help 文件夹：PDF + 视频教程（≤10MB）

**阶段 4：上架**
- [ ] 标题：描述性 + 无过多标点
- [ ] 标签覆盖场景和风格
- [ ] 预览视频无品牌/Logo/截图
- [ ] 预览图 16:9 高分辨率

### 版本管理

- 同模板为不同 AE 版本导出多个 MOGRT（`_2023.mogrt`, `_2024.mogrt`, `_2025.mogrt`）
- 重大更新 → 新商品发布；小幅更新 → 免费更新
- Git 管理 .aep 源文件
- 通过 CC "Other versions" 保留旧版 AE 安装

## ⚖️ 法律与合规

### 第三方资产许可

| 资产类型 | 合规方案 | 注意 |
|---------|---------|------|
| **字体** | Adobe Fonts（Stock 强制）/ Google Fonts（OFL） | 商业桌面许可字体不可嵌入 |
| **音乐** | 平台内置音乐库 / Artlist/Epidemic Sound | 需"可再分发"许可 |
| **视频素材** | Pexels/Pixabay/Unsplash（CC0）或自拍 | CC0 标签可能不保真 |
| **图片** | Unsplash/Pexels 或自创 | 不可含版权图片/图标/矢量 |
| **插件效果** | AE 中预渲染为视频 → 嵌入 MOGRT | 不要求用户安装插件 |

### Adobe Stock 内容政策要点

- ❌ 不得含真实品牌/商标/商业外观
- ❌ 不得含可识别的个人/公司/地点
- ✅ 使用通用虚构文本
- ✅ 所有字体通过 Adobe Fonts 可获取
- ❌ 预览不得出现 Adobe 软件界面截图

### 版权保护

- 创作者保留完整版权所有权
- 平台获得非独家分发许可
- 发现侵权：创作者自行发送 **DMCA 删除通知**（法定姓名+联系方式+原始/侵权 URL+善意声明+伪证罚则声明+签名）
- 额外补救：请求 Google 从搜索结果中移除

## 🇨🇳 中国市场特色

### 国内 MOGRT 市场

| 平台 | 类型 | 特点 |
|------|------|------|
| **CG模板网** (cgmuban.com) | 独立垂直站 | 10000+ 素材，MOGRT/PR/AE/FCP 全覆盖，百度/夸克网盘分发 |
| **PR模板网** (prmuban.com) | 独立垂直站 | 专注 PR 模板，含片头/快闪/企业宣传 |
| **千图网** | 综合素材 | 老牌，会员订阅制，市场份额大 |
| **新片场** | 视频社区 | 高质量视频模板和素材 |
| **剪映/CapCut** | 编辑工具内模板 | 最大短视频模板生态（非 MOGRT 格式） |

### 中国创作者出海策略

```
步骤 1：国内平台积累经验（CG模板网/千图网）
步骤 2：注册 Motion Array 或 Envato → 提交第一套适应国际审核标准
步骤 3：最佳作品改造为 Adobe Fonts 版本 → 提交 Adobe Stock
步骤 4：三线并行 → Adobe Stock + Envato Elements + Motion Array
```

**关键挑战**：
- 语言障碍（英文标题/描述/帮助文档需专业水平）
- 设计风格差异（国内偏好华丽/炫酷 vs 国际偏好简洁/现代）
- 支付渠道（需 Payoneer/PayPal 接收美元）

### 微信/抖音 MOGRT 生态

- 微信视频号和抖音**不直接支持 MOGRT 格式**——使用自有模板体系
- 剪映模板生态是短视频模板最大中国市场入口（非 MOGRT）
- MOGRT 在中国服务于 Premiere Pro 用户群（专业/半专业创作者）
- 国内分发可通过 CG模板网/PR模板网 + B站教程导流

## 💰 收入与案例

### 市场规模

| 指标 | 数值 |
|------|------|
| 全球 VFX 模板市场（2025） | $18 亿 |
| 预测 2034 | $39 亿（CAGR 9.2%） |
| AE 模板份额 | 32.5%（~$5.85 亿） |

### 全职可行性路线图

| 时间线 | 月收入 | 条件 |
|--------|--------|------|
| 0-6 个月 | $0-$200 | 20-50 个模板，学习什么好卖 |
| 6-18 个月 | $200-$1,500 | 100-500 个模板，质量提升 |
| 18-36 个月 | $1,500-$5,000 | 500-1,500 个模板，季节性策略 |
| 3-5 年 | $5,000-$20,000 | 1,500-5,000+ 模板，品牌声誉 |

### 关键成功因素

1. **体量**——大资产池（500-5,000+ 模板）利用订阅池复利
2. **多样性**——覆盖多个细分品类（社媒/企业/节日/婚礼/YouTube/字幕条/转场）
3. **季节性**——提前 2-3 个月上传节假日内容
4. **趋势跟踪**——企业/金融/社媒/健身/房地产模板持续有需求

### 收入构成建议

> 60% 单品平台（VideoHive/Adobe Stock） + 40% 订阅池平台（Elements/Motion Array）

## 🎯 关键行动清单

1. **技术**：掌握 `sourceRectAtTime()` + Protected Regions 响应式动画
2. **字体**：Adobe Stock 用 Adobe Fonts，其他平台用 Google Fonts（SIL OFL）
3. **平台**：Adobe Stock + Motion Array 为 MOGRT 最佳入口
4. **产品**：9:16 竖版优先、模块化多场景、适配社媒
5. **自动化**：Nexrender/Templater 批量，CSV/JSON 数据驱动
6. **合规**：验证所有第三方资产许可，OFL 字体附许可证
7. **长期**：3-5 年时间线，1000+ 模板池，多渠道分销
