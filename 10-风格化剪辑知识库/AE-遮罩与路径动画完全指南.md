# AE 遮罩与路径动画完全指南

> 版本: 2025-v1 | 适用: 遮罩动画/路径动画/形状图层

## 一、遮罩基础

### 1.1 遮罩类型

| 类型 | 创建方式 | 用途 |
|------|---------|------|
| 矩形遮罩 | Q键矩形工具 | 规则区域 |
| 椭圆遮罩 | Q键椭圆工具 | 圆形区域 |
| 钢笔遮罩 | G键钢笔工具 | 自定义形状 |
| 旋转矩形 | 矩形+旋转 | 倾斜区域 |
| 贝塞尔遮罩 | 钢笔+曲线 | 平滑曲线 |

### 1.2 遮罩属性

| 属性 | 说明 | 快捷键 |
|------|------|--------|
| 遮罩路径 | 形状定义 | M |
| 遮罩羽化 | 边缘柔化 | Ctrl+Shift+F |
| 遮罩不透明度 | 透明程度 | T |
| 遮罩扩展 | 扩大/缩小 | F |
| 遮罩模式 | 相加/相减/相交 | 下拉菜单 |

### 1.3 遮罩动画

```
遮罩路径动画:
1. 创建遮罩
2. 在起始帧设置遮罩路径关键帧
3. 移动到结束帧
4. 调整遮罩形状
5. 自动创建关键帧

遮罩扩展动画:
1. 设置遮罩扩展关键帧(0)
2. 移动到目标帧
3. 调整遮罩扩展值
4. 创建生长/收缩动画
```

## 二、路径动画

### 2.1 路径类型

| 类型 | 特点 | 用途 |
|------|------|------|
| 开放路径 | 起点≠终点 | 运动路径 |
| 闭合路径 | 起点=终点 | 遮罩/形状 |
| 贝塞尔路径 | 平滑曲线 | 自然运动 |
| 直线段路径 | 折线 | 机械运动 |

### 2.2 路径动画应用

```
沿路径运动:
1. 创建路径(形状图层或遮罩)
2. 选择运动图层
3. 按P展开位置
4. Alt+点击位置秒表
5. 输入表达式:
   path = thisComp.layer("Shape Layer 1").content("Shape 1").path;
   createPath(points, inTangents, outTangents, isClosed);

或使用"路径跟随"效果:
1. 效果→生成→路径跟随
2. 选择路径图层
3. 调整跟随参数
```

### 2.3 路径文本

```
文本沿路径:
1. 创建路径(形状图层)
2. 创建文本图层
3. 效果→文本→路径文本
4. 选择路径图层
5. 调整文本位置和方向

高级设置:
- 首字边距: 文本起始位置
- 字间距: 字符间距
- 反转路径: 文本方向
- 垂直于路径: 文字旋转
```

## 三、形状图层

### 3.1 形状类型

| 形状 | 参数 | 用途 |
|------|------|------|
| 矩形 | 大小/圆角 | 基础图形 |
| 椭圆 | 大小 | 圆形/椭圆 |
| 多边形 | 边数/大小 | 星形/多边形 |
| 星形 | 外半径/内半径/点数 | 星形 |
| 自定义路径 | 贝塞尔点 | 自由形状 |

### 3.2 形状属性

| 属性 | 说明 | 动画 |
|------|------|------|
| 变换 | 位置/缩放/旋转 | ✅ |
| 填充 | 颜色/不透明度 | ✅ |
| 描边 | 颜色/宽度/虚线 | ✅ |
| 渐变 | 线性/径向 | ✅ |
| 修剪路径 | 起始/结束/偏移 | ✅ |

### 3.3 修剪路径动画

```
修剪路径(Trim Paths):
1. 添加修剪路径到形状
2. 设置起始(Start): 0%→100%
3. 设置结束(End): 0%→100%
4. 创建生长动画

应用场景:
- 线条生长动画
- 文字书写效果
- Logo描绘效果
- 进度条动画
```

## 四、高级遮罩技术

### 4.1 遮罩插值

```
遮罩形状插值:
1. 创建两个不同形状的遮罩
2. 确保点数相同
3. 在中间帧设置遮罩路径关键帧
4. AE自动插值过渡

注意:
- 点数必须匹配
- 点顺序必须一致
- 可使用"自动蒙版"工具辅助
```

### 4.2 遮罩跟踪

```
遮罩跟踪:
1. 窗口→跟踪器
2. 选择跟踪内容→遮罩
3. 设置跟踪点
4. 分析跟踪
5. 应用跟踪数据到遮罩

应用场景:
- 跟踪物体运动
- 跟踪面部特征
- 跟踪文字位置
```

### 4.3 遮罩与Alpha

```
遮罩创建Alpha:
1. 遮罩默认创建Alpha通道
2. 遮罩模式:
   - 相加: 显示遮罩内
   - 相减: 隐藏遮罩内
   - 相交: 多遮罩交集
   - 差值: 排除重叠

遮罩与轨道遮罩:
- 遮罩: 同图层内
- 轨道遮罩: 跨图层
- 亮度遮罩: 基于亮度
- Alpha遮罩: 基于透明度
```

## 五、表达式与路径

### 5.1 路径表达式

```javascript
// 创建动态路径
var points = [
    [0, 0],
    [100, 50],
    [200, 0]
];
createPath(points, [], [], false);

// 路径点动画
var t = time;
var p1 = [100 * Math.sin(t), 100 * Math.cos(t)];
createPath([p1], [], [], false);
```

### 5.2 遮罩表达式

```javascript
// 遮罩羽化动画
var breathe = Math.sin(time * 2) * 10 + 20;
breathe;

// 遮罩扩展动画
var grow = time * 50;
grow;
```
