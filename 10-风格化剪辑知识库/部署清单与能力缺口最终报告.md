## 4. 行动路线图

### 4.1 第一阶段：环境验证（0.5天）

**目标：确认所有工具链可用，跑通基本流程**

```
第1步：验证 AE 2025 + MCP Bridge
  ├── 打开 AE 2025
  ├── 检查 MCP Bridge 面板
  ├── 测试创建合成/图层
  └── 测试添加效果/关键帧

第2步：验证 AE 原子编译器
  ├── 运行 npm run test:phase3
  ├── 运行 npm run test:phase4
  ├── 运行 npm run test:phase5
  └── 手动编译一个测试用例

第3步：验证 Python 分析能力
  ├── 测试 librosa BPM 检测
  ├── 测试 opencv 光流计算
  └── 测试完整 MusicAtom 生成
```

### 4.2 第二阶段：桥接联调（1天）

**目标：Python分析 → TS引擎 → MCP → AE 全链路打通**

```
第1步：Python-TS Subprocess 桥接
  ├── Node.js 调用 Python 脚本
  ├── JSON 数据传输测试
  ├── 错误处理与超时
  └── 性能基准测试

第2步：端到端最小测试
  ├── 输入：1首短音乐 + 1个片段
  ├── 音乐分析 → 片段分析
  ├── 音画匹配 → 参数反推
  ├── CompilerInput 生成
  ├── AE 脚本编译
  ├── MCP 执行到 AE
  └── 验证成片效果
```

### 4.3 第三阶段：实战训练（2-4周）

**目标：按照训练体系从入门到进阶，熟练掌握全流程**

```
Week 1-2：入门级训练（10个练习）
  ├── librosa/OpenCV 基础
  ├── AE 编译器基本用法
  └── MCP 工具测试

Week 3-4：基础级训练（8个练习）
  ├── 段落分割/情绪识别
  ├── 运动估计/场景检测
  └── DP对齐/匈牙利配对

Week 5-8：进阶级训练（6个练习）
  ├── 端到端流水线跑通
  ├── 效果-频段绑定
  └── 转场方案生成
```

> 📖 详细训练计划见 [[实战模拟与训练体系完全手册]]
