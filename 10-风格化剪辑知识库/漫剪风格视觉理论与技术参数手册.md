## 一、外网主流漫剪风格核心视觉特征

### 1.1 六大核心技法

| 技法 | 视觉特征 | 节奏功能 | AE实现方式 |
|------|----------|----------|------------|
| **色差分离** | RGB通道偏移2-8px, 边缘彩色溢出 | 冲击感/故障感 | 3层文字(红/绿/蓝) + Add混合 + 位置偏移 |
| **速度线/集中线** | 从中心放射的细线条, 快速闪现 | 力量集中/速度感 | Shape Layer放射线 + opacity表达式脉冲 |
| **帧冻结+震动** | 画面突然定格, 高频微震 | 时间暂停/力量蓄积 | position表达式random偏移 + 时间重映射 |
| **弹性缓动** | 过冲回弹(overshoot), 果冻感 | 活力/节奏弹性 | 弹性表达式 amp/freq/decay |
| **多层粒子** | 2-3层不同大小/速度/颜色粒子叠加 | 层次/深度/氛围 | 多Solid + CC Particle World/Particular |
| **高对比闪帧** | 2-3帧纯白/纯黑插入, 双闪/三闪 | 节拍切割/冲击 | opacity表达式: abs(t-beat)<0.04 → 100 |

### 1.2 风格分支特征

| 风格 | 核心配色 | 节奏特征 | 必备效果 |
|------|----------|----------|----------|
| **Cyberpunk** | 青+品红+黑 | 快速glitch, 不规则闪烁 | 色差分离, 故障抖动, 电子粒子 |
| **Cinematic** | 暖金+深蓝+黑 | 缓慢推拉, 呼吸感 | 暗角, 胶片颗粒, 信宽比, DOF拉焦 |
| **Neon/Dream** | 粉+紫+蓝渐变 | 流动, 漂浮感 | 多层Glow, 路径文字, 彩色粒子 |
| **Epic/Extreme** | 红+橙+黑 | 重击节拍, 突然静止 | 速度线, 帧冻结, 粒子爆发, 摄像机震动 |
| **Retro VHS** | 低饱和+扫描线 | Lo-fi摇摆 | 噪点, 扫描线, 色带, 时间码 |
| **Kinetic Type** | 高对比黑白+强调色 | 文字即画面 | 逐字弹跳, 3D翻转, 描边发光 |

## 二、运动规律与节奏理论

### 2.1 动画十二法则在漫剪中的应用

| 法则 | 漫剪应用 | 技术参数 |
|------|----------|----------|
| **挤压与拉伸** | 文字入场时scale过冲 | scale: [130,70]→[90,110]→[100,100] |
| **预备动作** | 冲击前反向微移 | position先退20px再冲出 |
| **缓入缓出** | 所有运动避免线性 | 弹性表达式或Easy Ease |
| **跟随与重叠** | 逐字错帧入场 | 每字延迟0.05-0.1s |
| **次要动作** | 主文字+粒子+光晕同步 | 多层叠加不同时间偏移 |

### 2.2 弹性表达式 (Overshoot/Bounce)

```javascript
// 万能弹性表达式 (ES3兼容, 适用于scale/position/rotation)
var amp = 0.12;   // 振幅: 0.05(微弹)~0.3(强弹)
var freq = 3.0;   // 频率: 2(慢晃)~6(快颤)
var decay = 4.0;  // 衰减: 2(长尾)~8(急停)
var n = 0;
if (numKeys > 0) {
    n = nearestKey(time).index;
    if (key(n).time > time) n--;
}
if (n == 0) { var t = 0; }
else { var t = time - key(n).time; }
if (n > 0 && t < 1.5) {
    var v = velocityAtTime(key(n).time - thisComp.frameDuration / 10);
    value + v * amp * Math.sin(freq * t * 2 * Math.PI) / Math.exp(decay * t);
} else { value; }
```

**参数调节指南：**
- 文字入场: amp=0.15, freq=3, decay=4 (明显回弹)
- UI元素: amp=0.06, freq=4, decay=6 (轻微弹性)
- 重击效果: amp=0.25, freq=2, decay=3 (大幅震荡)

### 2.3 节拍联动理论

```
BPM → 每拍时长 = 60/BPM 秒
常用BPM:
- 燃系AMV: 140-180 BPM (每拍0.33-0.43s)
- 抒情MAD: 70-100 BPM (每拍0.6-0.86s)
- Epic/Trailer: 120-140 BPM (每拍0.43-0.5s)

闪帧时机: 每拍起点 ± 1帧
粒子爆发: 每4拍(小节起点)
转场: 每8拍(段落切换)
```

### 2.4 摄像机震动参数

```javascript
// 冲击震动 (适用于camera position)
var t = time;
var base = [960, 540, -2000]; // 原始位置
var shakeAmount = 30; // 震动幅度(px)
var shakeDuration = 0.4; // 持续时间(s)
var impactTime = 2.5; // 冲击时刻
if (Math.abs(t - impactTime) < shakeDuration) {
    var decay = 1 - Math.abs(t - impactTime) / shakeDuration;
    [base[0] + (Math.random()-0.5) * shakeAmount * decay,
     base[1] + (Math.random()-0.5) * shakeAmount * decay,
     base[2]];
} else { base; }
```

## 三、色差分离 (Chromatic Aberration) 实现

### 3.1 三层叠加法 (实测验证)

```javascript
// 创建3层文字, 分别设为R/G/B, 用Add混合模式叠加
var colors = [[1,0,0], [0,1,0], [0,0,1]];
var offsets = [[-4,0], [0,0], [4,0]]; // R左移4px, B右移4px
for (var c = 0; c < 3; c++) {
    var txt = comp.layers.addText('TEXT');
    // ... 设置文字属性 ...
    txt.property('Text').property('ADBE Text Document').value.fillColor = colors[c];
    txt.position.setValue([960 + offsets[c][0], 540 + offsets[c][1]]);
    txt.blendMode = 5; // Add
    txt.opacity.setValue(80);
}
```

### 3.2 动态色差 (故障时加强)

```javascript
// 位置表达式: 正常时微偏移, 故障时大幅偏移
var t = time;
var baseOffset = 3; // 常态偏移
var glitchOffset = 15; // 故障偏移
var isGlitch = Math.sin(t * 47) > 0.9; // 随机触发
var offset = isGlitch ? glitchOffset : baseOffset;
[value[0] + offset, value[1]];
```

## 四、速度线/集中线 (Speed Lines) 实现

### 4.1 放射状集中线 (Shape Layer)

```javascript
// 从中心点放射16条线
var sl = comp.layers.addShape();
var rg = sl.property('ADBE Root Vectors Group');
for (var i = 0; i < 16; i++) {
    var lg = rg.addProperty('ADBE Vector Group');
    var lc = lg.property('ADBE Vectors Group');
    var path = lc.addProperty('ADBE Vector Shape - Group');
    var angle = i * 22.5 * Math.PI / 180;
    var x1 = 960 + Math.cos(angle) * 150; // 内径
    var y1 = 540 + Math.sin(angle) * 150;
    var x2 = 960 + Math.cos(angle) * 1100; // 外径
    var y2 = 540 + Math.sin(angle) * 1100;
    var s = new Shape();
    s.vertices = [[x1, y1], [x2, y2]];
    s.closed = false;
    path.property('ADBE Vector Shape').setValue(s);
    var stroke = lc.addProperty('ADBE Vector Graphic - Stroke');
    stroke.property('ADBE Vector Stroke Color').setValue([1, 1, 1, 0.7]);
    stroke.property('ADBE Vector Stroke Width').setValue(1.5);
}
// 快速闪现: 仅在冲击帧显示
sl.opacity.expression = 'var t=time; if(Math.abs(t-2.5)<0.1) 90; else 0;';
```
