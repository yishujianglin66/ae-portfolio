# 🖼️ 静止系 MAD 知识体系

> 静止系（Still-Image MAD / 静止画MAD）——使用静态图片通过运动图形、合成、特效创造音乐视频的艺术形式。源自日本 MAD 文化，在中国 B站 社区蓬勃发展。

---

## 📖 定义与历史

### 什么是静止系 MAD

| 术语 | 定义 |
|------|------|
| **静止系 MAD** | 以静态图片（动漫插图、游戏 CG、漫画页面）为素材，通过 AE/PS 合成动画 + 特效 + 排版制作的音乐视频 |
| **AMV（Anime Music Video）** | 动漫片段 + 音乐，强调节奏卡点、情感共鸣、试听流畅 |
| **MAD** | 源自日文"マッド"，更注重创意表达与画面叙事，常搭配字幕、特效 |

### 核心区别

| 维度 | 静止系 MAD | 传统 AMV/漫剪 |
|------|-----------|-------------|
| 素材 | 静态图片（插画/CG/漫画）| 动画视频片段 |
| 运动来源 | 完全人造（关键帧/表达式/插件）| 原有动画片段 |
| 创作自由度 | 极高——每个像素都可控制 | 受限于原始动画素材 |
| 难度门槛 | 高——需要 AE 合成 + PS 修图 + 排版设计 | 中等——重心在剪辑节奏 |
| 代表作 | *Frame*（halfear）、*灯火的命题*（nntk）、*空鸣*（懒白）| — |

### MAD 的词源

**1978 年大阪芸術大学**：CAS（Comic Animation Study）社团的 **MAD島川氏** 和 **Y氏** 开始故意用吉他弹奏跑调的动画特摄主题曲作为搞笑表演。同期，高中生 **今井氏** 将电视录制的《宇宙戦艦ヤマト》音频剪辑去除对白重新拼接。三人汇合后将自制磁带命名为 **MAD**——名称沿用至今。

### 静止画M@D大賞（2001-2012）

- **2001** 年由 **美凪ちよ** 创立，凍音社团协办
- **2005** 年起由 **八八（baban）** 接手
- 社区投票年度最佳评选——静止系文化的标志性制度
- **軍魔（Gunma）** 在此赛事中连续 **8 年（2004-2011）** 获得年度最佳作者，2014 年以最终作 *Black Swan ~さいはてにて~* 引退

## 🏗️ 制作全流程

### 阶段 1：素材准备

| 步骤 | 工具 | 说明 |
|------|------|------|
| **找图** | Pixiv、游戏 CG 提取、漫画扫描 | 越高分辨率越好 |
| **抠图** | Photoshop 钢笔/套索 | 将主体/中景/背景分离为独立图层 |
| **补洞** | PS 内容识别填充 / ComfyUI+Flux AI 修补 | 补全抠图后留下的空洞 |
| **扩图** | ComfyUI+Flux / Real-ESRGAN | AI 放大低分辨率素材 |
| **保存** | PSD（保留图层）| 导入 AE 时选"合成-保留图层大小"|

### 阶段 2：空间布局（2.5D 视差）

**核心原则**：

- **前景**：离虚拟摄影机最近，移动最快
- **中景**：中等速度
- **背景**：最远，移动最慢

**AE 工作流**：

1. 全部图层开启 **3D 开关**（小立方体图标）
2. 在 Z 轴上推开各层（背景 Z=800-1000，缩放回补；前景靠近摄影机）
3. 新建 **3D 摄影机**（推荐双节点摄影机）
4. 动画摄影机 Position / Point of Interest（缓慢推拉/平移/微旋转）
5. 开启摄影机 **景深** → 调光圈和焦点距离
6. 添加 **3D 灯光**（点光/聚光）+ 开启投影
7. 层间 Z 空间漂浮粒子（灰尘/火花/光斑）

**比例补偿公式**：层推到 Z 深处后，`Scale = (distance / original_distance) × 100`

### 阶段 3：打光

#### NNTK 三件套打光法（行业标准）

1. **Drop Shadow（投影）** → 主体背后投下阴影
2. **CC Composite** → 将阴影与原始图层合成
3. **Set Matte（设置遮罩）** → 控制灯光作用范围

#### 其他打光技法

| 技法 | 方法 |
|------|------|
| **轮廓光/背光** | 方法 A：3D 灯光分层；方法 B：曲线+蒙版局部提亮 |
| **OP 光（Optical Flares）** | 沿光源方向加镜头光晕，大幅提升画面质感 |
| **体积光/上帝光** | CC Light Rays / CC Light Burst 2.5 作用于亮区 |
| **手绘阴影** | 钢笔工具逐层绘制，注意遮挡关系（什么挡住什么）|
| **CC Light Sweep** | 快速添加表面光扫描效果 |

### 阶段 4：合成与特效

#### 必备插件

| 插件 | 用途 | 开发者 |
|------|------|--------|
| **Trapcode Particular** | 核心粒子系统——大气灰尘、火花、余烬、烟雾、雪花、能量拖尾 | Maxon/Red Giant |
| **Optical Flares** | 镜头光晕与光源创建，3D 跟踪 | Video Copilot |
| **Sapphire** | 270+ 效果——S_Glow / S_Glint / S_Rays / S_Warp | Boris FX |
| **Deep Glow** | 高品质发光，阈值/平滑度控制优于 AE 内置 Glow | Plugin Everything |
| **Saber** | **免费**——光束、霓虹、能量效果 | Video Copilot |
| **Element 3D** | 3D 模型导入与渲染 | Video Copilot |
| **RSMB** | 像素级动态模糊（AE 内置 Motion Blur 不足时）| RE:Vision Effects |
| **Magic Bullet Looks** | 电影级调色 | Maxon/Red Giant |

| 效果 | 用途 |

| **Wave Warp** | 旗帜飘动、水波纹 |
| **Polar Coordinates** | 圆形扭曲、隧道效果 |
| **Turbulent Displace** | 有机变形——烟雾/热浪 |
| **CC Kaleidoscope** | 对称图案生成——超现实背景 |
| **CC Light Rays** | 上帝光/体积光 |
| **CC Particle World** | 3D 粒子（雪/雨/火花）|
| **Glow** | 基础光晕——叠加多层使用 |
| **Roughen Edges** | 腐蚀/溶解/磨损效果 |
| **Find Edges** | 线稿风格、轮廓提取 |

#### 常见效果组合

| 想要的效果 | 效果栈 |
|-----------|--------|
| **焼き演出（烧灼效果）** | Advanced Lightning + Glow + S_Glow |
| **結城光（Yuki 式光泄）** | Lens Flare/Optical Flares + Soft Light 混合 + 色调曲线 |
| **水面波纹** | Wave Warp + Fractal Noise + Displacement Map |
| **RGB 偏移/色差** | Channel Shift + Optics Compensation + CC Force Motion Blur |
| **VHS/复古** | CC Threshold RGB + Noise + 轻 Wave Warp + Blur |
| **上帝光** | CC Light Rays；S_Rays；纯色层+蒙版+模糊+Screen 混合 |
| **背景图案** | Venetian Blinds + Polar Coordinates；Cell Pattern + Colorama |

### 阶段 5：调色与氛围

#### 调色工具链

| 工具 | 用法 |
|------|------|
| **曲线（Curves）** | 主工具——独立控制阴影/中间调/高光；RGB 通道分别调整 |
| **三色调（Tritone）** | 统一全片色彩——分别映射阴影/中间调/高光到三种颜色 |
| **四色渐变（4-Color Gradient）** | 纯色层 + 四色渐变 + 叠加/柔光混合——四个区域独立偏色 |
| **Looks 插件** | 综合调色 + Fast Box Blur + Soft Light/Screen 混合 |
| **LUT** | 应用在 40-70% 不透明度，在校正之后 |

#### 情绪色彩配方

| 配色 | 情绪 | 适用场景 |
|------|------|---------|
| **Teal & Orange** | 能量、大片感 | 动作/高张力段落 |
| **冷蓝/去饱和** | 忧郁、孤独、恐怖 | 悲伤/夜景/心理紧张 |
| **暖金/琥珀** | 怀旧、浪漫、温暖 | 闪回/柔情/日落 |
| **去饱和棕/深褐** | 末日、荒芜 | 黑暗主题/失落 |
| **红移/品红** | 激情、危险、强度 | 高潮对抗 |
| **高调/粉彩** | 纯真、青春、梦幻 | 日常/喜剧/童年 |

#### 氛围营造

| 技法 | 方法 |
|------|------|
| **柔光扩散** | 复制图层 → 重度模糊 → 柔光/屏幕混合低不透明度 |
| **渐变叠加** | Ramp 效果 → 正片叠底（去亮留暗）/ 屏幕（去暗留亮）→ 暗角感 |
| **Fractal Noise 纹理** | 低不透明度 Fractal Noise 叠加到平面区域 → 有机质感 |
| **漏光效果** | Fractal Noise → 曲线压爆 → 上色 → Screen/Add 混合 → 模糊 |
| **调整层扩散** | 调整层 + Fast Blur + Soft Light——全局梦幻柔焦 |

## 🔤 排版与动态文字

### 字体选择（ACG 审美）

| 风格 | 推荐字体类型 |
|------|------------|
| **严肃/戏剧** | 明朝体（标宋）、粗宋 |
| **清新/可爱** | 幼圆、圆体、手写体 |
| **现代/动作** | ゴシック体（黑体）、无衬线 |
| **情感/年代** | 书法体、手写体 |

### 文字布局

| 技法 | 应用 |
|------|------|
| **黑字+白底+投影** | 简洁高对比，适合亮场景 |
| **半透明黑底+白边框+白字** | 在复杂画面上保证可读性 |
| **单色文字+小装饰文字** | 画面为主，文字为辅 |
| **文字作为主体+背景纹理叠加** | 纯文字分镜——排版即构图 |
| **大小/颜色变化** | 参差不齐的字号与颜色——设计感 |
| **中英文配对** | 用意译非直译（如"旁人与我无关"→"Who cares?"）|

### 动态文字动画

| 揭示方式 | 方法 | 适用 |
|----------|------|------|
| **打字机** | Range Selector 的 Opacity + Character Offset 动画 | 歌词逐字显示 |
| **滑入** | Position + 逐字错开（Stagger）| 活力出场、标题卡 |
| **缩放爆破** | Scale 从 0 加 overshoot 回弹 | 重拍冲击 |
| **蒙版揭示** | 蒙版路径动画横跨文字 | 优雅流动出场 |
| **模糊变清晰** | Gaussian Blur 从高到 0 | 梦幻淡入 |
| **不透明度错开** | 逐字淡入 | 微妙氛围入场 |
| **字间距揭示** | 字间距从宽到正常 | 戏剧性间距释放 |

### 歌词同步方法

| 方法 | 操作 |
|------|------|
| **音频转关键帧** | 选音频层 → 动画 → 关键帧辅助 → 将音频转换为关键帧 → pick-whip 文字属性到音频振幅 |
| **标记法** | 预览音频时按小键盘 `*` 在每拍/每词打标记 → 表达式跳转到标记 |
| **TextExploder + BeatEdit** | TextExploder 拆分单字 → BeatEdit 自动检测节拍标记 |
| **Text At Marker 插件** | 在每个图层标记触发自定义文字动画 |

## ⚡ 表达式与自动化

### 必备表达式

```javascript
// 呼吸/随机浮动效果
wiggle(freq, amp)
// wiggle(0.5, 50) — 缓慢漂移
// wiggle(5, 20)  — 烛光闪烁

// 无限循环
loopOut("cycle")

// 逐层延迟级联
thisComp.layer(index-1).transform.position.valueAtTime(time - 0.1)

// 连续旋转
time * 360  // 每秒一圈

// 单轴抖动
wiggle(3, 50)[0]  // 仅 X 轴

// 弹性/弹簧模拟
// 需 Duik → Spring 工具提供物理弹簧动力学
```

## 🚀 性能优化

### 预渲染（MAD 第一策略）

1. 隔离已完成的复杂合成
2. 预渲染为 ProRes / PNG 序列 / 中间编码
3. 在主项目中用渲染文件替换合成
4. AE 解码视频帧而非重新计算所有效果

### 项目组织

- 按音乐段落拆分大项目，最终在主合成装配
- 文件 → 依赖关系 → 精简项目（删除未使用素材）
- 编辑时 Solo 图层，避免 AE 计算隐藏层

### 预览优化

- 编辑期间关闭 Motion Blur（仅最终渲染开启）
- Draft 3D 模式（关闭灯光/阴影/景深）
- 合成分辨率设为 Half 或 Third
- Caps Lock 暂停所有面板更新
- 渲染感兴趣区域（Region of Interest）

## 🎓 推荐学习路径

### 社区共识学习路径

1. **大量观看（6-12 个月）**——吸收经典作品建立审美
   - 入门：halfear *Frame*、軍魔 *沙漏中的最后一粒砂*
   - 进阶：Show/nntk *灯火的命题*、懒白 *空鸣*

2. **基础学习**——AE 基础（位置/旋转/缩放/不透明度）→ PS（抠图/修补/调色）→ 文字动画 → 木偶动画

3. **逆向工程**——下载公开的 MAD 工程文件，逐帧拆解

4. **模仿练习（难度递进）**：
   - Lv.1：仿 *no title*——学文字动画+形状图层+运动基础
   - Lv.2：仿 *青空*——学蒙版/遮罩+粒子+摄影机+转场
   - Lv.3：仿 *鲨鱼*——学形状图层+运动曲线+表达式+排版
   - Lv.4：仿 *彼岸花*——终极形状图层与曲线掌握

5. **原创创作**——从 15-30 秒短篇入手

6. **发布与反馈**——B站上传 + 社区参与
