## 一、Lightroom 专业调色核心

### 1.1 调色工具深度解析

#### HSL 色彩控制
HSL (Hue/Saturation/Luminance) 是 Lightroom 最精细的色彩控制工具：

| 参数 | 范围 | 作用 | 电影感常用调整 |
|------|------|------|---------------|
| 色相 (Hue) | -100~+100 | 改变颜色倾向 | 肤色偏橙(+5~+10)，天空偏青(-10~-20) |
| 饱和度 (Saturation) | -100~+100 | 颜色浓度 | 整体降饱和(-10~-20)，肤色微增(+5) |
| 明亮度 (Luminance) | -100~+100 | 颜色明暗 | 肤色提亮(+10~+20)，蓝色压暗(-10) |

#### 曲线调色 (Tone Curve)
- **RGB曲线**: 控制整体对比度，S形曲线增强电影感
- **红色曲线**: 高光加红/阴影加青 = 经典好莱坞色调
- **绿色曲线**: 微调肤色自然度
- **蓝色曲线**: 阴影加蓝 = 冷调电影感

#### 分离色调 (Color Grading)
三向色轮控制：
- **阴影 (Shadows)**: 通常加青/蓝，营造深度
- **中间调 (Midtones)**: 控制整体色调倾向
- **高光 (Highlights)**: 通常加暖/橙，营造光感

### 1.2 批量同步设置

**同步流程：**
1. 选择已调好的参考照片
2. Ctrl+A 全选同批次照片
3. 同步设置 (Ctrl+Shift+S)
4. 选择同步项目（基础/色调曲线/HSL/分离色调等）
5. 一键应用到所有照片

**批量预设应用：**
- 创建项目专用预设（包含完整调色参数）
- 导入时自动应用预设
- 通过智能预览加速批量处理

### 1.3 色彩配置文件与校准

**相机校准 (Camera Calibration)：**
- 配置文件选择影响整体色彩基调
- 常用: Adobe Color / Adobe Standard / Camera Matching
- 电影感推荐: Adobe Landscape (增强对比和饱和)

**色彩空间选择：**
- sRGB: 网络发布标准
- Adobe RGB: 印刷/专业显示
- ProPhoto RGB: 最大色域，适合深度调色
- Rec.709: 视频标准（导出LUT时必需）

## 二、LUT 生成与应用

### 2.1 LUT 格式详解

| 格式 | 精度 | 兼容性 | 用途 |
|------|------|--------|------|
| .cube (3D LUT) | 17-65点 | AE/PR/DaVinci/FCP | 通用标准 |
| .3dl | 33点 | 老系统兼容 | legacy |
| .look | 完整参数 | Lightroom 专用 | LR预设 |

**推荐**: 始终使用 .cube 格式，兼容性最佳。

### 2.2 从 LR 预设导出 LUT 的方法

**方法一: 通过 Photoshop 中转（推荐）**
1. Lightroom 中导出参考图片为 16-bit TIFF
2. Photoshop 打开 → 图像 → 调整 → 应用LR预设
3. 使用 LUT Generator 插件生成 .cube 文件
4. 或使用 `3D LUT Creator` 软件直接转换

**方法二: 通过 DaVinci Resolve**
1. LR 导出调色前后对比图
2. DaVinci 中用 Color Warper 匹配
3. 导出 .cube LUT

**方法三: 手动参数映射**
将 LR 调色参数转换为 AE Lumetri 等效参数：
```
LR 参数          → AE Lumetri 等效
曝光 +0.5        → 曝光 +0.5
对比度 +20       → 对比度 +20
高光 -30         → 高光 -30
阴影 +20         → 阴影 +20
白色 +10         → 白色 +10
黑色 -10         → 黑色 -10
色温 +15         → 色温 +15
色调 +5          → 色调 +5
HSL 橙色饱和度+10 → HSL 橙色饱和度 +10

```

### 2.3 LUT 在 AE/PR 中的正确应用流程

```
正确流程:
1. 素材导入 → 基础校正（曝光/白平衡）
2. 应用 LUT（作为创意调色起点）
3. LUT 之后微调（曲线/HSL/二级调色）
4. 输出前检查色彩空间转换

错误流程:
❌ 直接应用 LUT 不做基础校正
❌ LUT 放在调整图层最顶层
❌ 多个 LUT 叠加使用
❌ 忽略色彩空间不匹配
```

**AE 中加载 LUT：**
- 效果 → Lumetri Color → 创意 → 查找颜色 LUT
- 或: 调整图层 → Lumetri Color → 应用 LUT

**PR 中加载 LUT：**
- Lumetri Color 面板 → 创意 → 浏览 LUT
- 或: 项目面板右键素材 → 解释素材 → 应用 LUT

## 三、自动化工作流

### 3.1 Lightroom 批量导出规范

**导出预设配置：**
```
用于AE/PR的素材导出:
- 格式: TIFF 16-bit (最大质量)
- 色彩空间: ProPhoto RGB 或 Adobe RGB
- 分辨率: 原始尺寸（不缩放）
- 命名: [项目]_[场景]_[序号]

用于预览的缩略图导出:
- 格式: JPEG 85%
- 色彩空间: sRGB
- 尺寸: 长边 1920px
- 命名: [项目]_preview_[序号]
```

### 3.2 批量导出脚本思路

通过 Lightroom SDK (Lua) 实现自动化：
```lua
-- 批量应用预设并导出
local exportSettings = {
    LR_format = "TIFF",
    LR_colorSpace = "ProPhoto",
    LR_bitDepth = "16",
    LR_jpegQuality = 1.0,
    LR_resize = false,
}

LrTasks.startAsyncTask(function()
    local photos = catalog:getTargetPhotos()
    for _, photo in ipairs(photos) do
        photo:applyDevelopSettings(presetSettings)
        photo:export{to = exportPath, settings = exportSettings}
    end
end)
```

### 3.3 调色预设传递到 AE

**工作流：**
1. Lightroom 中完成批量调色
2. 导出为带嵌入配置文件的 TIFF
3. AE 中导入，色彩管理自动识别配置文件
4. 或通过 LUT 将 LR 调色风格应用到视频素材

## 四、实战案例：完整调色流程

### 4.1 动漫混剪调色流程

```
Step 1: 基础校正
  - 曝光校正（确保不欠曝/过曝）
  - 白平衡调整（统一色温）
  - 镜头校正（去暗角/畸变）

Step 2: 风格化调色
  - 应用项目预设（如"高燃暖调"）
  - HSL 精细调整（肤色/主色调）
  - 分离色调（阴影冷/高光暖）

Step 3: 细节增强
  - 清晰度 +10~20
  - 去朦胧 +5~15
  - 锐化（数量 40-60）

Step 4: 导出 LUT
  - 生成 .cube 文件
  - 在 AE 中应用到视频素材
  - 微调匹配视频特性
```

### 4.2 多素材统一色调

当使用多个来源的素材时：
1. 在 Lightroom 中建立"主色调"预设
2. 对每个素材单独做基础校正
3. 统一应用主色调预设
4. 微调个别素材的 HSL 匹配整体
5. 导出统一 LUT 应用到 AE 项目
