# Photoshop 图层系统完全手册

> 版本: 2025-v1 | 适用: Photoshop 2025/2026 + AE/PR 联动

## 一、图层核心概念

### 1.1 图层类型

| 类型 | 图标 | 特性 | 用途 |
|------|------|------|------|
| 像素图层 | 普通图层 | 可绘画/滤镜 | 基础编辑 |
| 调整图层 | 半黑半白 | 非破坏性调色 | 色彩校正 |
| 填充图层 | 纯色/渐变/图案 | 可重复编辑 | 背景/遮罩 |
| 文字图层 | T图标 | 矢量可编辑 | 排版设计 |
| 形状图层 | 路径图标 | 矢量无损 | UI/图形 |
| 智能对象 | 折角图标 | 非破坏性变换 | 核心工作流 |
| 视频图层 | 胶片图标 | 可播放视频 | 动态设计 |
| 3D图层 | 3D图标 | 三维对象 | 3D合成 |

## 二、混合模式完全指南

### 2.1 混合模式分组

| 分组 | 模式 | 核心效果 |
|------|------|---------|
| 正常组 | 正常/溶解 | 基础显示 |
| 变暗组 | 正片叠底/颜色加深/线性加深/深色 | 变暗画面 |
| 变亮组 | 滤色/颜色减淡/线性减淡/浅色 | 提亮画面 |
| 对比组 | 叠加/柔光/强光/亮光/线性光/点光/实色混合 | 增强对比 |
| 取消组 | 差值/排除 | 反转/差异 |
| HSL组 | 色相/饱和度/颜色/明度 | 分量控制 |

### 2.2 最常用混合模式详解

#### 正片叠底 (Multiply)
- **效果**: 白色变透明，黑色保留，中间色变暗
- **应用**: 阴影叠加、纹理叠加、线稿上色
- **公式**: 结果 = 基色 × 混合色

#### 滤色 (Screen)
- **效果**: 黑色变透明，白色保留，中间色变亮
- **应用**: 光效叠加、镜头光晕、发光效果
- **公式**: 结果 = 1 - (1-基色) × (1-混合色)

#### 叠加 (Overlay)
- **效果**: 暗区更暗，亮区更亮，增强对比
- **应用**: 增强质感、锐化辅助、纹理融合

#### 柔光 (Soft Light)
- **效果**: 比叠加更温和的对比增强
- **应用**: 微调对比度、肤色优化

## 三、智能对象深度指南

### 3.1 智能对象核心优势

| 优势 | 说明 |
|------|------|
| 非破坏性变换 | 缩放/旋转不损失原始质量 |
| 智能滤镜 | 滤镜可随时修改参数 |
| 同步更新 | 修改源文件，所有实例同步 |
| 嵌入/链接 | 支持PSD/AI/PDF等格式嵌入 |
| 堆栈模式 | 多张图合成(均值/中值/最大值) |

### 3.2 创建智能对象

```
方法1: 右键图层 → 转换为智能对象
方法2: 文件 → 置入嵌入对象/链接对象
方法3: 双击图层缩略图(直接打开)
方法4: 图层 → 智能对象 → 转换
```

### 3.3 智能对象堆栈

| 模式 | 效果 | 应用 |
|------|------|------|
| 平均值 | 多帧平均 | 降噪/去路人 |
| 中值 | 取中间值 | 去噪/全景去鬼影 |
| 最大值 | 取最亮值 | 星轨合成 |
| 最小值 | 取最暗值 | 暗部增强 |
| 标准差 | 变化检测 | 运动检测 |

## 四、图层样式系统

### 4.1 图层样式类型

| 样式 | 参数 | 典型应用 |
|------|------|---------|

## 五、图层组与图层复合

### 5.1 图层组管理

```
推荐图层组结构:
├── [组] 调色 (调整图层)
│   ├── 曲线
│   ├── 色相/饱和度
│   └── 色彩平衡
├── [组] 修图
│   ├── 修复层
│   └── 磨皮层
├── [组] 合成元素
│   ├── 前景
│   ├── 主体
│   └── 背景
├── [组] 文字/图形
│   └── 标题/Logo
└── [组] 效果
    ├── 颗粒
    └── 暗角
```

### 5.2 图层复合

- **用途**: 保存图层可见性/位置/外观的不同状态
- **应用**: 向客户展示多个设计方案
- **操作**: 窗口 → 图层复合 → 新建

## 六、与 AE 联动

### 6.1 PSD 导入 AE

```
导入方式:
1. 素材 → 合成(保留图层结构) → AE中可单独操作每层
2. 素材 → 合成-保留图层大小 → 保持原始尺寸
3. 素材 → 合并 → 单层导入

最佳实践:
- PSD 中使用智能对象
- 图层命名清晰(AE中直接显示)
- 合理编组(AE中自动创建预合成)
- 调整图层在AE中可转换为效果
```

### 6.2 动态链接

```
PS → AE: 复制图层 → 粘贴到AE(保留为形状/智能对象)
AE → PS: 右键AE素材 → 在Photoshop中替换
```
