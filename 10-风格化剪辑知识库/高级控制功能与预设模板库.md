## 一、高级控制功能

### 1.1 多层级控制器系统

```
Master_Controller (全局)
├── 缩放控制
├── 速度控制
├── 颜色控制
│   ├── 主色
│   ├── 副色
│   └── 强调色
├── 效果控制
│   ├── 发光强度
│   ├── 模糊程度
│   └── 对比度
└── 动画控制
    ├── 缓动类型
    ├── 循环模式
    └── 随机种子

Scene_Controller (场景级)
├── 场景编号
├── 场景时长
└── 转场类型

Layer_Controller (图层级)
├── 图层偏移
├── 图层延迟
└── 图层权重
```

### 1.2 表达式驱动系统

```js
// 多层级表达式
masterScale = thisComp.layer("Master_Controller").effect("缩放")("滑块");
sceneOffset = thisComp.layer("Scene_Controller").effect("偏移")("滑块");
layerDelay = thisComp.layer("Layer_Controller").effect("延迟")("滑块");

// 综合计算
value * masterScale + sceneOffset + [0, layerDelay];
```

### 1.3 音频响应系统

```js
// 多频段音频分析
audio = thisComp.layer("音频").audioLevels;
bass = audio[0];
treble = audio[1];

// 频段映射
scale = 100 + bass * 200;
rotation = treble * 90;

[scale, scale];
```

## 三、自动化工作流

### 3.1 一键生成流程

```
输入: 音乐文件 + 视频片段
  ↓
步骤1: 音乐分析 (BPM/节拍/能量/情感)
  ↓
步骤2: 片段分析 (运动/颜色/构图/时长)
  ↓
步骤3: 音画匹配 (节拍-片段对齐)
  ↓
步骤4: 模板应用 (选择预设风格)
  ↓
步骤5: AE执行 (自动创建合成/图层/效果/关键帧)
  ↓
输出: 完整视频
```

### 3.2 参数映射表

| 音乐特征 | AE参数 | 映射关系 |
|---------|--------|---------|
| BPM | 剪辑频率 | BPM/60 = 剪辑次数/秒 |
| 能量 | 缩放/亮度 | 能量↑ → 缩放↑/亮度↑ |
| 情感(悲伤) | 饱和度/对比度 | 悲伤↓ → 饱和度↓/对比度↓ |
| 情感(欢快) | 颜色鲜艳度 | 欢快↑ → 颜色鲜艳度↑ |

## 四、预设打包与分享

### 4.1 导出预设

```jsx
// 导出合成预设
app.project.activeItem.saveAs(File("MyPreset.aep"), true);

// 导出效果预设
app.project.activeItem.selectedProperties[0].savePreset("EffectPreset.ffx");
```

### 4.2 导入预设

```jsx
// 导入合成预设
app.open(File("MyPreset.aep"));

// 导入效果预设
app.project.activeItem.selectedProperties[0].applyPreset(File("EffectPreset.ffx"));
```
