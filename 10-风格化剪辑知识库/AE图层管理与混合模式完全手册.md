## 一、图层基础概念

### 1.1 图层定义与作用

**图层（Layer）** 是 After Effects 中最基本的构建单元。可以将图层想象为堆叠在一起的透明醋酸纤维纸，每张纸上可以有不同的图像、文字或效果，透过上层的透明区域可以看到下层的内容。

**核心作用：**

| 作用 | 说明 |
|------|------|
| 分层管理 | 将不同元素分离，便于独立编辑 |
| 合成叠加 | 通过堆叠顺序和混合模式创造复杂视觉效果 |
| 动画控制 | 每个图层拥有独立的时间轴和变换属性 |
| 效果应用 | 效果可以针对单个图层，也可以跨图层作用 |
| 渲染控制 | 通过开关控制哪些图层参与渲染 |

> **原理说明**：AE 的合成本质是一个图层堆栈，渲染器从底部图层开始，逐层向上渲染，最终输出合成图像。每个图层都是一个完整的图像平面，拥有自己的像素数据和变换矩阵。

### 1.2 图层类型大全

After Effects 2026 提供了 10 种主要图层类型，每种类型都有其独特的属性和用途。

#### 1.2.1 视频层（Footage Layer）

**定义**：基于导入的素材文件创建的图层，包括视频、图片、音频等。

**创建方式**：
- 从项目面板拖拽素材到时间轴
- 选中素材按 `Ctrl+/` 添加到当前合成
- 右键素材 → 替换素材

**特有属性**：
- 源素材（Source）：关联的项目素材项
- 时间重映射（Time Remapping）：控制素材播放速度
- 像素宽高比（Pixel Aspect Ratio）
- 循环（Loop）：通过解释素材设置

**典型应用**：
- 主视频素材放置
- 背景图片
- 音频轨道
- 参考素材层

---

#### 1.2.2 纯色层（Solid Layer）

**定义**：单一颜色的纯色图层，是 AE 中最基础的图层类型。

**创建方式**：
- 菜单：图层 → 新建 → 纯色层
- 快捷键：`Ctrl+Y`
- 右键时间轴空白处 → 新建 → 纯色层

**参数示例**：
```
名称：BG_Solid
宽度：1920
高度：1080
像素长宽比：方形像素
颜色：#000000（纯黑）
```

**典型应用**：
- 背景底色
- 效果载体（如分形杂色、渐变）
- 蒙版基底
- 轨道蒙版层
- 灯光/阴影接收层

> **技巧**：纯色层是占用内存最小的图层类型之一，优先使用纯色层 + 效果的组合，而不是导入静态图片。

#### 1.2.3 形状层（Shape Layer）

**定义**：使用钢笔工具或形状工具创建的矢量图形图层。

**创建方式**：
- 选择形状工具（矩形/椭圆/多边形/星形）在合成中点击拖动
- 钢笔工具绘制路径

- 变换（Transform）：组级变换 + 图层级变换
- 路径操作（Path Operators）：合并路径、偏移路径、收缩和膨胀、中继器、修剪路径、Z字形

**参数示例**：

```
│   └── 描边 1
│       ├── 颜色：#FFFFFF
│       └── 描边宽度：3
└── 变换
    ├── 位置：[960, 540]
    └── 缩放：[100, 100]
```

**典型应用**：
- MG动画元素
- UI界面绘制
- 蒙版形状
- 装饰性图形
- 动态图标

## 二、图层顺序与渲染原理

### 2.1 时间轴顺序 = 渲染顺序

**核心原理**：AE 的渲染顺序是从时间轴底部向上逐层渲染的。

```
渲染方向 ↑↑↑

┌─────────────────────┐
│  图层 5（最顶层）   │  ← 最后渲染，显示在最上面
├─────────────────────┤
│  图层 4             │
├─────────────────────┤
│  图层 3             │
├─────────────────────┤
│  图层 2             │
├─────────────────────┤
│  图层 1（最底层）   │  ← 最先渲染，作为基底
└─────────────────────┘
```

**重要结论**：
- 时间轴顶部的图层 = 画面最上层
- 时间轴底部的图层 = 画面最底层
- 调整层影响其下方的所有图层
- 轨道蒙版层必须在被蒙版层的上方

### 2.2 新图层添加位置规则

#### 2.2.1 默认添加位置

| 操作 | 添加位置 |
|------|----------|
| 拖拽素材到合成预览 | 时间轴顶部（最上层） |
| 拖拽素材到时间轴面板 | 鼠标放置的位置 |
| `Ctrl+/` 添加素材 | 当前选中图层上方 |
| 新建纯色/形状/文字层 | 当前选中图层上方 |
| 新建空对象/调整层/灯光/摄像机 | 时间轴顶部 |

#### 2.2.2 改变默认行为

- 按住 `Ctrl` 拖拽素材到时间轴：添加到底部
- 按住 `Shift` 拖拽：添加到当前时间指示器位置

### 2.3 图层移动方法详解

#### 2.3.1 手动拖拽

**操作方法**：
1. 选中一个或多个图层
2. 按住鼠标左键上下拖动
3. 出现黑色指示线时释放鼠标

**快捷键辅助**：
- 按住 `Shift` 拖拽：吸附到图层边界
- 按住 `Alt` 拖拽：复制图层

#### 2.3.2 菜单命令法

| 命令 | 说明 |
|------|------|
| 图层 → 排列 → 置于顶层 | 移动到最上方 |
| 图层 → 排列 → 前移一层 | 向上移动一层 |
| 图层 → 排列 → 后移一层 | 向下移动一层 |
| 图层 → 排列 → 置于底层 | 移动到最下方 |

**快捷键**：
- 置于顶层：`Ctrl+Shift+]`
- 前移一层：`Ctrl+]`
- 后移一层：`Ctrl+[`
- 置于底层：`Ctrl+Shift+[`

### 2.4 ExtendScript 图层移动 API

#### 2.4.1 moveToBeginning()

**定义**：将图层移动到时间轴最顶部（第一层）。

```javascript
// 示例：将选中图层移到最顶层
var comp = app.project.activeItem;
var layer = comp.selectedLayers[0];
layer.moveToBeginning();
```

**应用场景**：
- 调整层置顶
- 参考层置底后恢复
- 动态创建的控制层置顶

---

#### 2.4.2 moveToEnd()

**定义**：将图层移动到时间轴最底部（最后一层）。

```javascript
// 示例：将背景层移到底层
var bgLayer = comp.layer("Background");
bgLayer.moveToEnd();
```

**应用场景**：
- 背景图层置底
- 调整层置底（影响所有图层）
- 参考层置底

---

#### 2.4.3 moveAfter(targetLayer)

**定义**：将图层移动到目标图层的下方（之后）。

```javascript
// 示例：将图层A移到图层B的下方
var layerA = comp.layer("Layer_A");
var layerB = comp.layer("Layer_B");
layerA.moveAfter(layerB);
```

**注意**：移动后 layerA 在 layerB 的下方，索引更大。

---

#### 2.4.4 moveBefore(targetLayer)

**定义**：将图层移动到目标图层的上方（之前）。

```javascript
// 示例：将调整层移到特效组上方
var adjLayer = comp.layer("Adjustment");
var fxGroup = comp.layer("FX_Group");
adjLayer.moveBefore(fxGroup);
```

**注意**：移动后 adjLayer 在 fxGroup 的上方，索引更小。

---

#### 2.4.5 moveTo(index)

**定义**：将图层移动到指定索引位置。

```javascript
// 示例：将图层移到第5层
var layer = comp.selectedLayers[0];
layer.moveTo(5);
```

**参数说明**：
- index 从 1 开始计数
- 1 = 最顶层
- comp.numLayers = 最底层

### 2.5 索引动态变化陷阱

#### 2.5.1 问题描述

图层索引是动态变化的，当你移动或删除图层时，其他图层的索引会随之改变。

**错误示例**：
```javascript
// ❌ 错误：循环中按索引删除会导致索引错位
var comp = app.project.activeItem;
for (var i = 1; i <= comp.numLayers; i++) {
    if (comp.layer(i).name.indexOf("temp_") === 0) {
        comp.layer(i).remove();  // 删除后后面的图层索引都变了！
    }
}
```

#### 2.5.2 正确做法

**从后往前遍历**：
```javascript
// ✅ 正确：从最后一层往前遍历
var comp = app.project.activeItem;
for (var i = comp.numLayers; i >= 1; i--) {
    if (comp.layer(i).name.indexOf("temp_") === 0) {
        comp.layer(i).remove();
    }
}
```

**先收集再操作**：
```javascript
// ✅ 正确：先收集所有要删除的图层，再批量删除
var comp = app.project.activeItem;
var layersToRemove = [];

for (var i = 1; i <= comp.numLayers; i++) {
    var layer = comp.layer(i);
    if (layer.name.indexOf("temp_") === 0) {
        layersToRemove.push(layer);
    }
}

// 再逐个删除（此时使用引用而非索引）
for (var j = 0; j < layersToRemove.length; j++) {
    layersToRemove[j].remove();
}
```

#### 2.5.3 移动操作的索引变化

```javascript
// 假设初始顺序：Layer1, Layer2, Layer3, Layer4（索引1-4）

var layer1 = comp.layer(1);  // Layer1
var layer4 = comp.layer(4);  // Layer4

layer4.moveToBeginning();    // Layer4 移到最顶层

// 此时索引变为：
// comp.layer(1) = Layer4
// comp.layer(2) = Layer1  ← 索引变了！
// comp.layer(3) = Layer2
// comp.layer(4) = Layer3
```

> **最佳实践**：尽量使用图层名称（`comp.layer("name")`）或图层对象引用，而不是索引编号来访问图层。

## 三、空对象（Null Object）深度解析

### 3.1 空对象本质

**空对象（Null Object）** 是 After Effects 中最强大的辅助工具之一，它本质上是一个不可见的图层，只拥有变换属性，不参与最终渲染。

**核心特征**：

| 特征 | 说明 |
|------|------|
| 可见性 | 默认视频开关关闭，渲染时不可见 |
| 默认尺寸 | 100×100 像素（仅在合成中显示为框线） |
| 拥有属性 | 位置、缩放、旋转、锚点、不透明度 |
| 无像素数据 | 没有自身的图像像素 |
| 可被父级 | 可以作为父图层控制其他图层 |
| 可添加效果 | 可以添加效果（用于表达式控制） |
| 可添加蒙版 | 可以添加蒙版路径（用于表达式引用） |

**显示样式**：
```
合成面板中空对象的显示：
┌─────────────────────┐
│  ○  ○  ○  ○  ○     │  ← 边角控制点
│                     │
│  ○     Null     ○   │  ← 中心点 + 名称
│                     │
│  ○  ○  ○  ○  ○     │  ← 边角控制点
└─────────────────────┘
```

### 3.2 空对象的 5 大用途

#### 3.2.1 父级控制（Parenting Control）

**原理**：将多个图层的父级设为同一个空对象，通过控制空对象的变换来统一控制所有子图层。

```
空对象（控制器）
    ├── 子图层 1 ← 跟随父级运动
    ├── 子图层 2 ← 跟随父级运动
    └── 子图层 3 ← 跟随父级运动
```

**典型应用**：
- 一组元素的整体位移动画
- 多个图层的统一缩放
- 批量旋转效果
- 镜头推拉（通过空对象缩放实现）

**参数示例**：
```
Null_Controller（空对象）
├── 位置：[960, 540]
├── 缩放：[100, 100]  ← 关键帧动画：0s→50%, 2s→120%
└── 旋转：0°

子图层1（父级：Null_Controller）
子图层2（父级：Null_Controller）
子图层3（父级：Null_Controller）
```

---

#### 3.2.2 表达式引用（Expression Reference）

**原理**：将空对象的属性作为表达式的控制参数，其他图层引用这些属性。

**典型应用**：
- 全局速度控制器
- 颜色统一控制
- 动画幅度调节
- 时间偏移控制

**参数示例**：
```
Null_Global（空对象）
├── 效果 → 滑块控制
│   ├── "全局速度"：1.0
│   ├── "振幅"：50
│   └── "频率"：2
└── 效果 → 颜色控制
    └── "主色调"：#FF6B6B

图层1.位置表达式：
freq = thisComp.layer("Null_Global").effect("频率")("滑块");
amp = thisComp.layer("Null_Global").effect("振幅")("滑块");
value + [0, Math.sin(time * freq) * amp]
```

---

#### 3.2.3 摄像机绑定（Camera Rig）

**原理**：用空对象搭建摄像机绑定系统，实现复杂的摄像机运动控制。

**典型配置**：
```
Cam_Rig（空对象 - 整体位移）
├── Cam_Orbit（空对象 - 轨道旋转）
│   └── Cam_Zoom（空对象 - 推拉位移）
│       └── Main_Camera（摄像机）
└── Cam_Target（空对象 - 关注点）
```

**优势**：
- 分离控制维度（位移/旋转/推拉）
- 便于制作复杂相机动画
- 易于调整和修改
- 可保存为预设重复使用

---

#### 3.2.4 效果控制（Effect Control）

**原理**：在空对象上添加效果控制元件（滑块、角度、颜色等），作为全局控制面板。

**典型应用**：
- 全局调色控制
- 粒子系统主控
- 动画曲线调节
- 多图层效果统一开关

**参数示例**：
```
Null_Master_Control（空对象 - 主控面板）
├── 效果 → 滑块控制
│   ├── "主强度"：100
│   ├── "辉光强度"：50
│   ├── "模糊量"：5
│   └── "饱和度"：110
├── 效果 → 角度控制
│   └── "光照角度"：45°
└── 效果 → 颜色控制
    ├── "高光色"：#FFFFFF
    └── "阴影色"：#000000
```

---

#### 3.2.5 时间标记（Time Marker）

**原理**：利用空对象的入点/出点作为时间标记点，配合表达式实现时间触发。

**典型应用**：
- 动画触发点标记
- 节拍同步标记
- 场景切换点
- 效果开启/关闭时间点

**参数示例**：
```
Null_Beat_1（空对象 - 第1拍标记）
└── 入点：0.5s

Null_Beat_2（空对象 - 第2拍标记）
└── 入点：1.0s

// 表达式：检测是否到达某一拍
beatTime = thisComp.layer("Null_Beat_1").inPoint;
if (time >= beatTime) {
    // 触发动画
}
```

### 3.4 空对象隐藏技巧

#### 3.4.1 标准隐藏方式

| 方法 | 效果 | 注意事项 |
|------|------|----------|
| 关闭视频开关（眼睛图标） | 合成中不显示，渲染不可见 | 仍可被选择和操作 |
| 关闭塌陷变换开关 | 不影响渲染 | 仅预合成层有 |
| 设置为引导层（Guide Layer） | 仅在当前合成可见 | 嵌套后不可见 |
| 降低不透明度到 0% | 视觉不可见 | 仍参与渲染，影响性能 |

#### 3.4.2 最佳实践

**控制器图层的标准设置**：
```
Null_Controller（空对象）
├── 视频开关：关闭 ✓（不显示在画面中）
├── 独奏：忽略
├── 锁定：开启 ✓（防止误操作）
├── 标签色：红色（控制器专用色）
├── 命名前缀：Null_ 或 Ctrl_
└── 位置：时间轴最顶部
```

#### 3.4.3 命名规范建议

| 前缀 | 用途 | 示例 |
|------|------|------|
| `Null_` | 通用空对象 | `Null_Target` |
| `Ctrl_` | 控制器空对象 | `Ctrl_Global` |
| `Cam_` | 摄像机绑定空对象 | `Cam_Orbit` |
| `Rig_` | 绑定系统空对象 | `Rig_Main` |
| `Mark_` | 时间标记空对象 | `Mark_Beat1` |

## 四、调整层（Adjustment Layer）完全指南

### 4.1 调整层工作原理

**调整层（Adjustment Layer）** 是一种特殊的图层，它本身不包含任何像素内容，但可以将效果应用于其下方的所有图层。

**工作原理示意图**：
```
┌─────────────────────────────────┐
│  图层 C（最顶层）                │  ← 不受调整层影响
├─────────────────────────────────┤
│  调整层（Adjustment Layer）     │  ← 效果作用分界线
│  └─ 效果：高斯模糊              │
├─────────────────────────────────┤
│  图层 B                         │  ← 被调整层影响（加模糊）
├─────────────────────────────────┤
│  图层 A（最底层）                │  ← 被调整层影响（加模糊）
└─────────────────────────────────┘
```

**核心规则**：
1. 调整层只影响其**下方**的图层
2. 调整层上方的图层完全不受影响
3. 调整层的不透明度控制效果强度
4. 调整层的混合模式改变效果叠加方式
5. 调整层的蒙版限制效果作用区域

### 4.2 调整层与直接加效果的区别

| 对比项 | 调整层加效果 | 直接给图层加效果 |
|--------|-------------|-----------------|
| 影响范围 | 下方所有图层 | 仅当前图层 |
| 修改效率 | 改一处影响所有 | 需逐个修改 |
| 灵活性 | 可通过蒙版限定区域 | 只能影响本层 |
| 性能开销 | 单次计算 | 每个图层各算一次 |
| 混合模式 | 可改变效果叠加方式 | 效果内部参数控制 |
| 预设复用 | 可保存为动画预设 | 同样可保存 |

**选择建议**：
- 多个图层需要相同效果 → 用调整层
- 只需要单个图层有效果 → 直接加
- 需要控制效果区域形状 → 调整层 + 蒙版
- 需要效果与图层内容交互 → 直接加

### 4.3 调整层堆栈策略

#### 4.3.1 多层调整层叠加顺序

当有多个调整层时，它们按照从上到下的顺序依次作用：

```
┌─────────────────────────────────┐
│  调整层 3（最顶层调整层）        │  ← 最后应用
│  └─ 效果：发光（Glow）          │
├─────────────────────────────────┤
│  调整层 2                       │  ← 中间应用
│  └─ 效果：色相/饱和度           │
├─────────────────────────────────┤
│  调整层 1（最底层调整层）        │  ← 最先应用
│  └─ 效果：高斯模糊              │
├─────────────────────────────────┤
│  素材图层                       │
└─────────────────────────────────┘
```

**渲染顺序**：素材图层 → 调整层1（模糊）→ 调整层2（调色）→ 调整层3（发光）

#### 4.3.2 推荐堆栈顺序

**电影感调色标准顺序**：
```
从上到下（后应用 → 先应用）：
┌─────────────────────────────┐
│ 调整层 - 输出（最后）         │  ← 胶片颗粒、暗角、最终对比
├─────────────────────────────┤
│ 调整层 - 创意调色            │  ← 风格化LUT、色彩分级
├─────────────────────────────┤
│ 调整层 - 二级调色            │  ← HSL、曲线精细调整
├─────────────────────────────┤
│ 调整层 - 一级调色            │  ← 曝光、对比度、白平衡
├─────────────────────────────┤
│ 素材图层                     │
└─────────────────────────────┘
```

**特效叠加标准顺序**：
```
从上到下：
┌─────────────────────────────┐
│ 调整层 - 最终发光             │  ← 整体辉光、Bloom
├─────────────────────────────┤
│ 调整层 - 景深/模糊           │  ← 镜头模糊、景深
├─────────────────────────────┤
│ 调整层 - 扭曲变形            │  ← 鱼眼、畸变
├─────────────────────────────┤
│ 调整层 - 基础调色            │
├─────────────────────────────┤
│ 素材图层                     │
└─────────────────────────────┘
```

### 4.4 调整层透明度/混合模式对效果的影响

#### 4.4.1 不透明度的作用

调整层的不透明度控制**效果的强度**，而不是图层自身的可见度。

**参数示例**：
```
调整层 - 模糊
├── 不透明度：50%
└── 效果：高斯模糊（20像素）
```

**实际效果**：相当于模糊强度为 20 × 50% = 10 像素的模糊效果

**应用技巧**：
- 不透明度 0% = 完全没有效果
- 不透明度 100% = 效果完全应用
- 可以给不透明度打关键帧，做效果渐入渐出

#### 4.4.2 混合模式的作用

调整层的混合模式决定效果如何与下方图层叠加。

| 混合模式 | 调整层效果 | 典型应用 |
|----------|-----------|----------|
| Normal | 正常应用效果 | 默认、大多数情况 |
| Screen | 效果只提亮 | 发光、辉光效果 |
| Multiply | 效果只压暗 | 暗角、阴影加深 |
| Overlay | 效果增强对比 | 对比度提升 |
| Color | 只改变颜色 | 统一色调 |
| Luminosity | 只改变亮度 | 亮度调整 |

**参数示例 - 发光效果优化**：
```
调整层 - Glow
├── 混合模式：Screen  ← 只叠加亮部
├── 不透明度：80%
└── 效果：发光
    ├── 发光基于：Alpha
    ├── 发光阈值：50%
    └── 发光半径：30
```

```
    └── 圆形暗角
        ├── 数量：-0.3
        ├── 圆度：+0.2
        ├── 柔和度：0.8
        └── 高光：0
```

## 五、混合模式（Blending Mode）原理与应用

### 5.1 混合模式基础

**混合模式（Blending Mode）** 决定了当前图层（上层）的像素如何与下方图层（下层）的像素进行数学运算，产生最终的显示效果。

**基础概念**：
- **基色（Base Color）**：下层图层的颜色
- **混合色（Blend Color）**：当前图层的颜色
- **结果色（Result Color）**：最终显示的颜色

**计算公式通用形式**：
```
结果色 = f(基色, 混合色)
```

> 所有颜色值都归一化到 [0, 1] 区间进行计算，0 代表纯黑，1 代表纯白。

### 5.2 38 种混合模式分类详解

After Effects 2026 共提供 38 种混合模式，分为 6 大类。

---

#### 5.2.1 常规组（Normal Group）

##### Normal（正常）

**数学原理**：
```
结果色 = 混合色          （不透明度 = 100%）
结果色 = 混合色 × α + 基色 × (1-α)  （α = 不透明度）
```

**效果说明**：上层完全覆盖下层，仅通过透明度产生融合。

**典型应用**：
- 默认模式，大多数图层使用
- 普通素材层
- 文字层
- 不透明的图形元素

**参数示例**：
```
图层：Title_Text
├── 混合模式：Normal
├── 不透明度：100%
└── 文字内容："NORMAL MODE"
效果：文字完全覆盖下方背景
```

---

##### Dissolve（溶解）

**数学原理**：
```
随机选取像素显示混合色或基色，概率 = 不透明度
```

**效果说明**：基于不透明度随机显示上层或下层像素，产生颗粒状溶解效果。

**典型应用**：
- 颗粒纹理效果
- 故障艺术（Glitch）
- 老式电视噪点
- 渐隐转场（配合不透明度动画）

**参数示例**：
```
图层：Noise_Texture
├── 混合模式：Dissolve
├── 不透明度：30%
└── 内容：白色纯色层
效果：随机散布的白色颗粒点
```

**效果对比**：
| 不透明度 | 视觉效果 |
|----------|----------|
| 90% | 少量缺失像素，接近完整图层 |
| 50% | 密集颗粒，上下各半 |
| 10% | 稀疏像素点，接近透明 |

---

##### Dancing Dissolve（动态溶解）

**数学原理**：
```
与 Dissolve 相同，但随机图案每一帧都重新生成
```

**效果说明**：溶解效果的动态版本，每帧的随机图案不同，产生跳动/闪烁的颗粒效果。

**典型应用**：
- 动态噪点效果
- 闪烁的星空
- 电视雪花
- 粒子替代方案

**参数示例**：
```
图层：TV_Static
├── 混合模式：Dancing Dissolve
├── 不透明度：15%
└── 内容：50%灰色纯色层
效果：动态闪烁的噪点颗粒
```

---

#### 5.2.2 变暗组（Darken Group）

**组特征**：结果色 ≤ 基色（结果不会比基色更亮）

##### Darken（变暗）

**数学原理**：
```
结果色 = min(基色, 混合色)
```
逐通道比较，取较小的值。

**效果说明**：上下层对比，哪个暗显示哪个。保留两个图层中较暗的部分。

**典型应用**：
- 叠加暗部细节
- 阴影叠加
- 去除亮色背景
- 暗部信息合成

**参数示例**：
```
图层A（基色）：渐变（黑→白）
图层B（混合色）：红色纯色
混合模式：Darken

结果：
- 暗部（黑）：显示黑色（因为黑 < 红）
- 中间灰：显示暗红色（取较小值）
- 亮部（白）：显示红色（因为红 < 白）
```

---

##### Multiply（正片叠底）

**数学原理**：
```
结果色 = 基色 × 混合色
```

**效果说明**：两图层颜色相乘，结果总是更暗。任何颜色与黑色相乘得黑色，与白色相乘保持不变。

**典型应用**：
- 阴影叠加
- 叠加线稿/扫描稿
- 加深暗部
- 去除白色背景（黑色主体）
- 模拟投影效果

**参数示例**：
```
基色 = 中灰 (0.5, 0.5, 0.5)
混合色 = 红色 (1, 0, 0)
结果色 = (0.5×1, 0.5×0, 0.5×0) = (0.5, 0, 0) = 暗红
```

**亮度变化表**：
| 基色 | 混合色 | 结果色 | 亮度变化 |
|------|--------|--------|----------|
| 白 (1) | 50%灰 (0.5) | 0.5 | 变暗 50% |
| 50%灰 (0.5) | 50%灰 (0.5) | 0.25 | 变暗 75% |
| 黑 (0) | 任何颜色 | 0 | 保持黑色 |

> **速记口诀**：正片叠底 = 越乘越暗

---

##### Color Burn（颜色加深）

**数学原理**：
```
结果色 = 1 - (1 - 基色) / 混合色
```
如果混合色 = 0（黑色），结果色 = 0（数学上未定义，AE处理为黑色）

**效果说明**：通过增加对比度来加深颜色，混合色越暗效果越强。白色无效果。

**典型应用**：
- 强烈的暗部加深
- 增加色彩饱和度
- 营造浓郁色彩
- 边缘强化

**参数示例**：
```
图层：Color_Overlay
├── 混合模式：Color Burn
├── 不透明度：50%
└── 内容：橙色纯色
效果：下方图层暗部加深，色彩更浓郁
```

**与 Multiply 的对比**：
| 模式 | 暗部表现 | 对比度 | 饱和度 |
|------|----------|--------|--------|
| Multiply | 均匀变暗 | 低 | 低 |
| Color Burn | 暗部更暗 | 高 | 高 |

---

##### Classic Color Burn（经典颜色加深）

**数学原理**：旧版 Color Burn 的算法，为兼容性保留。

**效果说明**：与 Color Burn 类似，但算法略有不同，在某些边缘情况下表现不同。

**典型应用**：
- 打开旧版项目时保持一致
- 需要特定旧版效果时

> **注意**：新项目推荐使用 Color Burn，Classic 版本仅用于兼容性。

---

##### Linear Burn（线性加深）

**数学原理**：
```
结果色 = 基色 + 混合色 - 1
```
如果结果 < 0，则为 0。

**效果说明**：通过降低亮度来加深颜色，比 Multiply 更强烈、更线性。

**典型应用**：
- 强烈变暗效果
- 加深阴影
- 合成暗部元素
- 更均匀的变暗（相比Color Burn）

**参数示例**：
```
基色 = 50%灰 (0.5)
混合色 = 40%灰 (0.4)
结果色 = 0.5 + 0.4 - 1 = -0.1 → 0（纯黑）
```

**三种变暗模式对比**：
| 基色 | 混合色 | Multiply | Linear Burn | Color Burn |
|------|--------|----------|-------------|------------|
| 0.8 | 0.6 | 0.48 | 0.4 | 0.5 |
| 0.5 | 0.5 | 0.25 | 0.0 | 0.0 |
| 0.3 | 0.7 | 0.21 | 0.0 | 0.04 |

---

##### Darker Color（深色/较暗颜色）

**数学原理**：
```
比较基色和混合色的亮度，显示较暗的那个图层的完整颜色
```

**效果说明**：与 Darken 不同的是，Darker Color 比较整体亮度，然后显示完整的较暗图层的颜色（不混合通道）。

**典型应用**：
- 比较两个图层的整体亮度
- 保留更暗的完整图层信息
- 某些合成工作流

**与 Darken 的区别**：
```
Darken（逐通道）：
  R结果 = min(R基, R混)
  G结果 = min(G基, G混)
  B结果 = min(B基, B混)
  → 可能产生新的颜色

Darker Color（整体亮度比较）：
  如果亮度(基色) < 亮度(混合色):
    结果 = 基色（完整RGB）
  否则:
    结果 = 混合色（完整RGB）
  → 不会产生新颜色
```

---

#### 5.2.3 变亮组（Lighten Group）

**组特征**：结果色 ≥ 基色（结果不会比基色更暗）

##### Lighten（变亮）

**数学原理**：
```
结果色 = max(基色, 混合色)
```
逐通道比较，取较大的值。

**效果说明**：上下层对比，哪个亮显示哪个。保留两个图层中较亮的部分。

**典型应用**：
- 叠加光效、光斑
- 提亮高光
- 叠加火焰/爆炸
- 去除黑色背景（亮色主体）

**参数示例**：
```
图层A（基色）：渐变（黑→白）
图层B（混合色）：蓝色纯色
混合模式：Lighten

结果：
- 暗部（黑）：显示蓝色（因为蓝 > 黑）
- 中间灰：显示浅蓝灰色（取较大值）
- 亮部（白）：显示白色（因为白 > 蓝）
```

---

##### Screen（滤色/屏幕）

**数学原理**：
```
结果色 = 1 - (1 - 基色) × (1 - 混合色)
```

**效果说明**：正片叠底的反运算。结果总是更亮，任何颜色与白色相乘得白色，与黑色相乘保持不变。

**典型应用**：
- 叠加光效、发光、镜头光晕
- 提亮画面
- 叠加火焰、爆炸、闪电
- 去除黑色背景
- 模拟发光效果

**参数示例**：
```
基色 = 中灰 (0.5, 0.5, 0.5)
混合色 = 红色 (1, 0, 0)
结果色 = 1 - (0.5×1, 0.5×0, 0.5×0)
       = 1 - (0.5, 0, 0)
       = (0.5, 1, 1) = 青色偏亮
```

**亮度变化表**：
| 基色 | 混合色 | 结果色 | 亮度变化 |
|------|--------|--------|----------|
| 黑 (0) | 50%灰 (0.5) | 0.5 | 变亮 50% |
| 50%灰 (0.5) | 50%灰 (0.5) | 0.75 | 变亮 25% |
| 白 (1) | 任何颜色 | 1 | 保持白色 |

> **速记口诀**：滤色 = 越叠越亮

---

##### Color Dodge（颜色减淡）

**数学原理**：
```
结果色 = 基色 / (1 - 混合色)
```
如果混合色 = 1（白色），数学上未定义，AE处理为白色。

**效果说明**：通过降低对比度来提亮颜色，混合色越亮效果越强。黑色无效果。

**典型应用**：
- 强烈的亮部提亮
- 发光效果增强
- 高光过曝效果
- 色彩提亮

**参数示例**：
```
图层：Glow_Hotspot
├── 混合模式：Color Dodge
├── 不透明度：60%
└── 内容：径向渐变（中心白，边缘黑）
效果：中心区域强烈提亮，接近过曝
```

**与 Screen 的对比**：
| 模式 | 亮部表现 | 对比度 | 强度 |
|------|----------|--------|------|
| Screen | 均匀变亮 | 低 | 中等 |
| Color Dodge | 亮部更亮 | 高 | 强烈 |

---

##### Classic Color Dodge（经典颜色减淡）

**数学原理**：旧版 Color Dodge 的算法，为兼容性保留。

**效果说明**：与 Color Dodge 类似，但算法略有不同。

**典型应用**：
- 旧项目兼容性
- 特定效果需求

---

##### Linear Dodge（线性减淡/添加）

**数学原理**：
```
结果色 = 基色 + 混合色
```
如果结果 > 1，则为 1（白色）。

**效果说明**：两个图层的颜色值直接相加，产生最亮的效果。也叫 Add（添加）模式。

**典型应用**：
- 光效叠加（最强发光）
- 体积光
- 粒子合成
- 火焰爆炸
- 双重曝光亮部叠加

**参数示例**：
```
基色 = 50%灰 (0.5)
混合色 = 60%灰 (0.6)
结果色 = 0.5 + 0.6 = 1.1 → 1.0（纯白，过曝）
```

**三种变亮模式对比**：
| 基色 | 混合色 | Screen | Linear Dodge | Color Dodge |
|------|--------|--------|--------------|-------------|
| 0.2 | 0.3 | 0.44 | 0.5 | 0.29 |
| 0.5 | 0.5 | 0.75 | 1.0 | 1.0 |
| 0.8 | 0.6 | 0.92 | 1.0 | 0.95 |

> **线性减淡 = Add 模式**：在某些软件中称为 Add，AE 中称为 Linear Dodge。

---

##### Lighter Color（浅色/较亮颜色）

**数学原理**：
```
比较基色和混合色的亮度，显示较亮的那个图层的完整颜色
```

**效果说明**：与 Lighten 不同的是，Lighter Color 比较整体亮度，然后显示完整的较亮图层的颜色。

**典型应用**：
- 比较两个图层的整体亮度
- 保留更亮的完整图层信息
- 光效合成（保留完整光效颜色）

#### 5.2.4 对比组（Contrast Group）

**组特征**：亮部更亮，暗部更暗，增强对比度

##### Overlay（叠加）

**数学原理**：
```
如果基色 ≤ 0.5:
    结果色 = 2 × 基色 × 混合色
如果基色 > 0.5:
    结果色 = 1 - 2 × (1 - 基色) × (1 - 混合色)
```

**效果说明**：基色决定使用 Multiply 还是 Screen 模式。50%灰色无效果。增强画面对比度。

**典型应用**：
- 增强画面对比度
- 叠加纹理
- 增加层次感
- 加深阴影和高光

**参数示例**：
```
图层：Texture_Overlay
├── 混合模式：Overlay
├── 不透明度：30%
└── 内容：噪波纹理（50%灰为基础）
效果：增加纹理质感，增强对比
```

**亮度变化表**：
| 基色 | 混合色 | 结果色 | 效果 |
|------|--------|--------|------|
| 黑 (0) | 任何 | 0 | 保持黑色 |
| 50%灰 (0.5) | 任何 | =混合色? 不，0.5×2×0.5=0.5 | 无变化 |
| 白 (1) | 任何 | 1 | 保持白色 |

---

##### Soft Light（柔光）

**数学原理**：
```
如果混合色 ≤ 0.5:
    结果色 = 基色 - (1 - 2×混合色) × 基色 × (1 - 基色)
如果混合色 > 0.5:
    结果色 = 基色 + (2×混合色 - 1) × (√基色 - 基色)
```

**效果说明**：柔和的聚光灯效果。比 Overlay 更温和。混合色为 50% 灰时无效果。

**典型应用**：
- 柔和增加对比
- 柔光效果
- 自然的明暗调整
- 皮肤修饰

**参数示例**：
```
调整层：Soft_Contrast
├── 混合模式：Soft Light
├── 不透明度：50%
└── 效果：曲线（轻微S曲线）
效果：自然的对比度提升，不过度
```

**与 Overlay 的对比**：
| 模式 | 对比度 | 强度 | 适用场景 |
|------|--------|------|----------|
| Overlay | 高 | 强 | 需要强烈对比 |
| Soft Light | 中 | 柔和 | 自然增强 |

---

##### Hard Light（强光）

**数学原理**：
```
如果混合色 ≤ 0.5:
    结果色 = 2 × 基色 × 混合色
如果混合色 > 0.5:
    结果色 = 1 - 2 × (1 - 基色) × (1 - 混合色)
```

**效果说明**：与 Overlay 类似，但由混合色决定使用 Multiply 还是 Screen。效果更强烈。

**典型应用**：
- 强烈的光影效果
- 聚光灯效果
- 特殊合成效果

> **注意**：Overlay 基于基色，Hard Light 基于混合色。

---

##### Linear Light（线性光）

**数学原理**：
```
结果色 = 基色 + 2×混合色 - 1
```
实际上是 Linear Burn（混合色暗半部分）+ Linear Dodge（混合色亮半部分）。

**效果说明**：通过增减亮度来产生对比，比 Vivid Light 更线性。50%灰无效果。

**典型应用**：
- 强烈的对比效果
- 线条增强
- 特殊风格化效果

---

##### Vivid Light（亮光）

**数学原理**：
```
如果混合色 ≤ 0.5:
    结果色 = 1 - (1 - 基色) / (2×混合色)
如果混合色 > 0.5:
    结果色 = 基色 / (2×(1 - 混合色))
```
实际上是 Color Burn + Color Dodge 的组合。

**效果说明**：通过增减对比度来产生对比，非常强烈。50%灰无效果。

**典型应用**：
- 极端对比效果
- 高反差风格
- 特殊视觉效果

---

##### Pin Light（点光）

**数学原理**：
```
如果混合色 ≤ 0.5:
    结果色 = min(基色, 2×混合色)
如果混合色 > 0.5:
    结果色 = max(基色, 2×混合色 - 1)
```
实际上是 Darken + Lighten 的组合。

**效果说明**：替换暗于或亮于混合色的像素，中等亮度的像素被替换。50%灰无效果。

**典型应用**：
- 特殊效果
- 风格化处理
- 某些遮罩效果

---

##### Hard Mix（实色混合/硬混合）

**数学原理**：
```
R结果 = R基 + R混 >= 1 ? 1 : 0
G结果 = G基 + G混 >= 1 ? 1 : 0
B结果 = B基 + B混 >= 1 ? 1 : 0
```
每个通道只有 0 或 1 两种可能。

**效果说明**：产生高对比度、有限颜色的海报化效果。结果只有8种可能的颜色（黑/白/红/绿/蓝/青/品红/黄）。

**典型应用**：
- 海报化效果
- 8-bit风格
- 高对比图形
- 特殊视觉风格

**参数示例**：
```
图层：Posterize_Effect
├── 混合模式：Hard Mix
├── 不透明度：100%
└── 内容：50%灰色纯色层
效果：下方图像变成纯黑白（二值化）
```

---

#### 5.2.5 差值组（Difference Group）

##### Difference（差值）

**数学原理**：
```
结果色 = |基色 - 混合色|
```
取两个颜色差值的绝对值。

**效果说明**：显示两个图层的差异。白色表示差异最大，黑色表示完全相同。

**典型应用**：
- 对比两个版本的差异
- 颜色反转效果
- 故障艺术
- 特殊色彩效果
- 对齐检查

**参数示例**：
```
基色 = 红色 (1, 0, 0)
混合色 = 蓝色 (0, 0, 1)
结果色 = (1, 0, 1) = 品红色

基色 = 白色 (1, 1, 1)
混合色 = 白色 (1, 1, 1)
结果色 = (0, 0, 0) = 黑色（相同）
```

> **有趣特性**：与白色混合 = 反相；与黑色混合 = 不变

---

##### Classic Difference（经典差值）

**数学原理**：旧版 Difference 算法。

**效果说明**：与 Difference 类似，用于旧项目兼容性。

---

##### Exclusion（排除）

**数学原理**：
```
结果色 = 基色 + 混合色 - 2 × 基色 × 混合色
```

**效果说明**：与 Difference 类似但对比度更低，效果更柔和。

**典型应用**：
- 更柔和的差值效果
- 颜色叠加
- 营造氛围

**与 Difference 的对比**：
| 基色 | 混合色 | Difference | Exclusion |
|------|--------|------------|-----------|
| 0.5 | 0.5 | 0.0 | 0.5 |
| 0.8 | 0.2 | 0.6 | 0.48 |
| 1.0 | 0.0 | 1.0 | 1.0 |

---

##### Subtract（减去）

**数学原理**：
```
结果色 = 基色 - 混合色
```
如果结果 < 0，则为 0。

**效果说明**：从基色中减去混合色的亮度。结果总是更暗。

**典型应用**：
- 减去特定颜色
- 暗部调整
- 颜色校正
- 创建特殊暗部效果

**参数示例**：
```
基色 = 黄色 (1, 1, 0)
混合色 = 红色 (1, 0, 0)
结果色 = (0, 1, 0) = 绿色（红被减掉了）
```

---

##### Divide（划分/相除）

**数学原理**：
```
结果色 = 基色 / 混合色
```
如果混合色 = 0，结果为白色。

**效果说明**：基色除以混合色，用于颜色校正和特殊效果。

**典型应用**：
- 颜色校正
- 去除色偏
- 特殊合成效果

**参数示例**：
```
基色 = 中灰 (0.5, 0.5, 0.5)
混合色 = 红色 (1, 0.5, 0.5)
结果色 = (0.5/1, 0.5/0.5, 0.5/0.5) = (0.5, 1, 1) = 青色
```

---

#### 5.2.6 色彩组（Color Group）

**组特征**：基于 HSL 色彩模型，混合色相/饱和度/明度

##### Hue（色相）

**数学原理**：
```
结果色 = 基色的饱和度和明度 + 混合色的色相
```

**效果说明**：保持基色的饱和度和明度，使用混合色的色相。

**典型应用**：
- 改变物体颜色
- 统一色调
- 色彩替换
- 调色

**参数示例**：
```
基色 = 高饱和红色
混合色 = 蓝色纯色
结果色 = 高饱和蓝色（饱和度和明度来自基色，色相来自混合色）
```

---

##### Saturation（饱和度）

**数学原理**：
```
结果色 = 基色的色相和明度 + 混合色的饱和度
```

**效果说明**：保持基色的色相和明度，使用混合色的饱和度。

**典型应用**：
- 增加/降低饱和度
- 局部饱和度调整
- 灰度化（用0饱和度图层）

**参数示例**：
```
图层：Desaturate
├── 混合模式：Saturation
├── 不透明度：100%
└── 内容：50%灰色纯色层（饱和度为0）
效果：下方图层变成灰度（饱和度为0）
```

---

##### Color（颜色/色彩）

**数学原理**：
```
结果色 = 基色的明度 + 混合色的色相和饱和度
```

**效果说明**：保持基色的明度，使用混合色的色相和饱和度。

**典型应用**：
- 上色（给灰度图上色）
- 统一色调
- 色彩风格化
- 双色调效果

**参数示例**：
```
图层：Color_Tint
├── 混合模式：Color
├── 不透明度：80%
└── 内容：橙黄色纯色
效果：下方图像保持亮度，色调变为橙黄
```

---

##### Luminosity（明度/发光度）

**数学原理**：
```
结果色 = 基色的色相和饱和度 + 混合色的明度
```

**效果说明**：保持基色的色相和饱和度，使用混合色的明度。Color 的反操作。

**典型应用**：
- 亮度叠加
- 高光阴影调整
- 保持颜色不变改变亮度
- 纹理亮度叠加

**参数示例**：
```
图层：Light_Texture
├── 混合模式：Luminosity
├── 不透明度：50%
└── 内容：噪波纹理
效果：给下方图层添加噪波纹理的亮度变化，颜色不变
```

## 六、轨道蒙版（Track Matte）详解

### 6.1 轨道蒙版基础概念

**轨道蒙版（Track Matte）** 是利用上方图层的 Alpha 通道或亮度信息，来控制下方图层的可见区域。

**工作原理示意图**：
```
┌─────────────────────────────────┐
│  蒙版层（Matte Layer）          │  ← 提供蒙版形状
│  └─ TrkMat 列：(无)             │
├─────────────────────────────────┤
│  被蒙版层（Fill Layer）         │  ← 被蒙版影响的图层
│  └─ TrkMat 列：Alpha Matte     │
└─────────────────────────────────┘
```

**核心规则**：
1. 蒙版层必须在被蒙版层的**正上方**
2. 蒙版层的视频开关可以关闭（不影响蒙版效果）
3. 一个蒙版层只能给其正下方的一个图层做蒙版
4. 要给多个图层使用同一蒙版，先预合成

### 6.2 四种轨道蒙版类型

#### 6.2.1 Alpha Matte（Alpha 蒙版）

**原理**：使用蒙版层的 Alpha 通道作为蒙版。
- Alpha = 255（不透明）→ 被蒙版层可见
- Alpha = 0（透明）→ 被蒙版层不可见

```
蒙版层 Alpha:  ██████████░░░░░░
被蒙版层:      ██████████      ← 只有左半部分可见
```

**典型应用**：
- 文字形状蒙版
- LOGO 形状显示
- 规则形状裁剪
- 有 Alpha 通道的素材作为蒙版

**参数示例**：
```
图层1：Text_Matte（文字层 - "MASK"）
├── 视频开关：关闭（可选）
└── TrkMat：(无)

图层2：Photo（图片层）
├── 视频开关：开启
└── TrkMat：Alpha Matte "Text_Matte"

效果：图片只在文字形状内可见
```

---

#### 6.2.2 Alpha Inverted Matte（Alpha 反转蒙版）

**原理**：Alpha 蒙版的反向版本。
- Alpha = 255 → 被蒙版层不可见
- Alpha = 0 → 被蒙版层可见

```
蒙版层 Alpha:  ██████████░░░░░░
被蒙版层:              ░░░░░░  ← 只有右半部分可见
```

**典型应用**：
- 挖空效果
- 形状外显示
- 相框效果（外框显示）

**参数示例**：
```
图层1：Frame（形状层 - 矩形框）
├── 视频开关：关闭
└── TrkMat：(无)

图层2：Photo（图片层）
├── 视频开关：开启
└── TrkMat：Alpha Inverted Matte "Frame"

效果：图片只在矩形框外可见，框内透明
```

---

#### 6.2.3 Luma Matte（亮度蒙版）

**原理**：使用蒙版层的亮度信息作为蒙版。
- 白色（亮度255）→ 完全可见
- 黑色（亮度0）→ 完全不可见
- 灰色 → 半透明（对应灰度值）

```
蒙版层亮度:  ████░░░░▒▒▒▒████
                白   黑   灰   白
被蒙版层:      ████    ░░░░████  ← 灰色区域半透明
```

**典型应用**：
- 渐变透明度
- 纹理蒙版
- 噪声蒙版
- 亮度转透明度
- 水墨扩散效果

**参数示例**：
```
图层1：Gradient（渐变层 - 左黑右白）
├── 视频开关：关闭
└── TrkMat：(无)

图层2：Photo（图片层）
├── 视频开关：开启
└── TrkMat：Luma Matte "Gradient"

效果：图片从左到右逐渐显示（左透明右不透明）
```

---

#### 6.2.4 Luma Inverted Matte（亮度反转蒙版）

**原理**：Luma 蒙版的反向版本。
- 白色 → 不可见
- 黑色 → 可见
- 灰色 → 半透明（反转）

```
蒙版层亮度:  ████░░░░▒▒▒▒████
                白   黑   灰   白
被蒙版层:          ████░░░░      ← 反转
```

**典型应用**：
- 反向渐变
- 暗部透明
- 特殊转场效果

### 6.3 轨道蒙版工作流程

#### 6.3.1 标准步骤


#### 6.3.2 多图层使用同一蒙版

**方法：预合成**

```

│ 蒙版层                    │
├──────────────────────────┤

│  ├── 图层 A              │
```

## 七、父级关系（Parenting）深度指南

### 7.1 父子链接原理

**父级关系（Parenting）** 是将一个图层的变换属性（位置、缩放、旋转）应用到另一个图层上的机制。

**基本概念**：
- **父图层（Parent Layer）**：主动变换的图层，控制子图层
- **子图层（Child Layer）**：跟随父图层变换的图层
- **变换继承**：子图层继承父图层的位置、缩放、旋转

**关系示意**：
```
父图层（独立运动）
    ↓ 控制
子图层（跟随 + 自身运动）
```

### 7.2 建立父子关系的 3 种方法

#### 方法1：拾取线（Pick Whip）

**操作步骤**：
1. 选中子图层
2. 在父级列找到螺旋线图标（拾取线）
3. 按住鼠标左键拖动到父图层上
4. 释放鼠标

**优势**：
- 直观快捷
- 不容易选错
- 适合单个图层操作

---

#### 方法2：下拉菜单

**操作步骤**：
1. 选中子图层
2. 点击父级列的下拉菜单
3. 从列表中选择父图层

**适用场景**：
- 图层名称明确
- 需要精确选择
- 图层较多时

---

#### 方法3：快捷键

**操作步骤**：
1. 先选中父图层
2. 按住 `Shift` 再选中子图层（多选）
3. 按 `Alt+Shift+P` 设置父级

> **注意**：选择顺序很重要，最后选中的图层成为子图层。

### 7.3 父子链接的数学原理

#### 7.3.1 变换累积计算

子图层的最终变换 = 父图层变换 × 子图层自身变换

```
最终位置 = 父位置 + 子位置 × 父缩放 × 父旋转
最终缩放 = 父缩放 × 子缩放
最终旋转 = 父旋转 + 子旋转
```

**简化示例（只有位置）**：
```
父图层位置：[100, 100]
子图层位置：[50, 50]（相对于父图层）

子图层最终位置 = [100+50, 100+50] = [150, 150]
```

#### 7.3.2 多级父子链

```
祖父图层
    ↓
父图层
    ↓
子图层
    ↓
孙图层
```

**变换累积**：
- 子图层 = 父变换 + 自身变换
- 孙图层 = 祖父变换 + 父变换 + 自身变换

> **注意**：嵌套层级越深，计算越复杂，性能开销越大。建议不超过 5-6 级。

### 7.4 父级空对象控制模式

#### 7.4.1 中心控制模式

```
Null_Group（空对象 - 中心控制点）
├── Layer_01（父级：Null_Group）
├── Layer_02（父级：Null_Group）
├── Layer_03（父级：Null_Group）
└── Layer_04（父级：Null_Group）
```

**应用场景**：
- 一组元素的整体移动
- 批量缩放/旋转
- 组动画控制

---

#### 7.4.2 层级控制模式

```
Null_Main（主控）
├── Null_Sub_01（次级控制）
│   ├── Layer_01
│   └── Layer_02
├── Null_Sub_02（次级控制）
│   ├── Layer_03
│   └── Layer_04
└── Layer_Main
```

**应用场景**：
- 复杂角色绑定
- 多层次动画
- 分组控制

---

#### 7.4.3 摄像机绑定模式

详见第三章 3.3.3 摄像机控制器。

### 7.5 注意事项

#### 7.5.1 缩放继承问题

**问题**：子图层会继承父图层的缩放，包括不均匀缩放。

```
父图层缩放：[200%, 100%]（横向拉伸）
子图层缩放：[100%, 100%]

结果：子图层也被横向拉伸了！
```

**解决方案**：
1. 尽量保持父图层等比缩放
2. 使用空对象分离缩放和位移
3. 用表达式补偿缩放
4. 使用预合成 + 折叠变换

---

#### 7.5.2 旋转中心问题

**问题**：子图层绕父图层的锚点旋转，而不是自己的锚点。

```
父图层锚点：[960, 540]（屏幕中心）
子图层位置：[200, 0]（相对于父图层）
父图层旋转：360°

结果：子图层绕屏幕中心公转，而不是自转
```

**自转效果实现**：
```
父图层：不旋转
子图层：自己设置旋转关键帧

→ 子图层绕自己的锚点旋转
```

**公转 + 自转**：
```
Null_Orbit（父级，旋转：公转）
└── Planet（子级，旋转：自转）
```

---

#### 7.5.3 位移累积问题

**问题**：多层父级嵌套时，位移会层层叠加。

```
祖父位置：[100, 0]
父位置：[100, 0]
子位置：[100, 0]

子最终位置 = [300, 0]（叠加了3次）
```

**注意**：
- 设计层级时考虑位移叠加
- 使用相对坐标思维
- 预合成可以"重置"坐标系

---

#### 7.5.4 解除父子关系

**方法**：
1. 在父级下拉菜单选择「无」
2. 选中子图层，按 `Alt+Shift+P`（再次按下可解除？不一定）

**解除后行为**：
- 子图层保持当前的变换值
- 不再跟随父图层运动
- 动画关键帧保留在各自图层

> **重要**：解除前如果父图层有位移，子图层的位置值会"加上"父位移后成为新的绝对值。

## 八、预合成（Pre-composing）与嵌套

### 8.1 预合成的作用

**预合成（Pre-compose）** 是将当前合成中的一个或多个图层打包成一个新的合成，然后用这个新合成替换原来的图层。

**核心作用**：

| 作用 | 说明 |
|------|------|
| 组织管理 | 将相关图层打包，简化时间轴 |
| 效果统一 | 给一组图层统一加效果/蒙版 |
| 坐标重置 | 在新合成中重新建立坐标系 |
| 嵌套动画 | 创建复杂的多层级动画 |
| 性能优化 | 预渲染复杂合成提升性能 |
| 复用合成 | 同一合成可在多处使用 |

### 8.2 预合成操作

#### 8.2.1 操作步骤

1. 选中要预合成的图层（可多选）
2. 菜单：图层 → 预合成
3. 或按快捷键：`Ctrl+Shift+C`
4. 设置预合成选项
5. 点击确定

#### 8.2.2 预合成选项

| 选项 | 说明 |
|------|------|
| 保留所有属性 | 在新合成中保留原图层的关键帧和属性 |
| 将所有属性移动到新合成 | 将所有属性移到预合成层 |
| 新建合成名称 | 预合成的名称 |
| 打开新合成 | 是否在合成面板打开新合成 |

> **建议**：通常选择「保留所有属性」，这样可以在预合成内独立编辑。

### 8.3 预合成 vs 直接组织图层

| 对比项 | 预合成 | 直接组织（用空对象/文件夹） |
|--------|--------|---------------------------|
| 层级结构 | 清晰，嵌套合成 | 扁平，同一时间轴 |
| 效果统一 | ✅ 方便加统一效果 | ❌ 需逐个加 |
| 蒙版统一 | ✅ 可用轨道蒙版 | ❌ 不行 |
| 坐标系统 | 独立坐标系 | 同一坐标系 |
| 性能 | 嵌套过多影响性能 | 较好 |
| 编辑方便性 | 需进入子合成编辑 | 直接编辑 |
| 复用性 | ✅ 可多处复用 | ❌ 不可复用 |

**选择建议**：
- 逻辑上属于同一模块 → 预合成
- 只是临时分组 → 用标签色/颜色标记
- 需要统一加效果/蒙版 → 预合成
- 简单位置动画组 → 空对象父级
- 需要多处使用 → 预合成

### 8.4 嵌套深度对性能的影响

#### 8.4.1 性能开销来源

每一层嵌套都会增加渲染时间：
```
渲染主合成 → 遇到预合成 → 渲染子合成 → 返回结果 → 继续渲染
```

**开销来源**：
1. 合成切换开销
2. 像素数据传递
3. 内存占用增加
4. 折叠变换的额外计算

#### 8.4.2 建议嵌套深度

| 项目类型 | 建议最大嵌套深度 |
|---------|----------------|
| 简单MG动画 | 3-4 层 |
| 复杂角色动画 | 5-6 层 |
| 电影特效合成 | 5-8 层 |
| 实时预览要求高 | ≤ 3 层 |

> **经验法则**：如果嵌套超过 5 层，考虑优化结构或使用预渲染。

#### 8.4.3 性能优化技巧

1. **关闭不必要的折叠变换**
2. **使用代理（Proxy）**
3. **预渲染（Pre-render）**
4. **降低预览分辨率**
5. **使用 Region of Interest（ROI）**
6. **合理使用缓存**

### 8.5 预合成最佳实践

#### 8.5.1 命名规范

```
主合成：Main_Comp / Final_Comp
子合成：模块名_Comp / 功能名_Precomp
通用合成：Shared_元素名
```

**示例**：
```
Main_Title_Sequence（主合成）
├── Intro_Section（第一段）
├── Logo_Reveal_Precomp（LOGO动画）
├── Title_Text_Group（标题组）
└── Outro_Section（结尾段）
```

#### 8.5.2 组织建议

**项目面板结构**：
```
项目根目录
├── 01_Main Comps（主合成）
│   ├── Main_Comp
│   └── Preview_Comp
├── 02_Sub Comps（子合成）
│   ├── Intro_Section
│   ├── Logo_Anim
│   └── Outro_Section
├── 03_Elements（元素合成）
│   ├── Button_Precomp
│   ├── Icon_Set
│   └── Particle_System
└── 04_Footage（素材）
```

#### 8.5.3 常见陷阱

**陷阱1：预合成后尺寸不符**
- 症状：预合成后画面位置变了
- 原因：图层超出合成范围，预合成后被裁切
- 解决：预合成前调整位置，或使用更大尺寸的合成

**陷阱2：折叠变换失效**
- 症状：开启折叠变换后效果不对
- 原因：混合模式、效果、蒙版的组合问题
- 解决：理解渲染顺序，调整结构

**陷阱3：表达式引用断裂**
- 症状：预合成后表达式报错
- 原因：表达式引用了原图层，预合成后图层路径变了
- 解决：修改表达式路径，或使用效果控制传递


### 9.2 详细说明

#### 9.2.1 视频开关（Video）

**图标**：眼睛图标 👁  
**作用**：控制图层是否在合成中显示  
**快捷键**：点击眼睛图标

**状态说明**：
- 眼睛显示 = 图层可见
- 眼睛隐藏 = 图层不可见
- Alt + 点击 = 独奏该图层（其他全部隐藏）

**注意**：
- 关闭视频开关的图层仍会渲染（如果有参考等）
- 渲染输出时，关闭视频的图层不会被渲染
- 关闭视频的空对象仍可作为父级

---

#### 9.2.2 音频开关（Audio）

**图标**：喇叭图标 🔊  
**作用**：控制音频层是否播放声音  
**快捷键**：点击喇叭图标

**状态说明**：
- 喇叭显示 = 有声音
- 喇叭隐藏 = 静音
- 仅音频/视频层有此开关

---

#### 9.2.3 独奏（Solo）

**图标**：独奏图标 👁‍🗨  
**作用**：只显示开启独奏的图层  
**快捷键**：`S`（选中图层后按 S 切换独奏？不对，S是独奏列显示）

**正确快捷键**：点击独奏列

**状态说明**：
- 无独奏开启 = 所有图层正常显示
- 有独奏开启 = 只显示独奏的图层
- 多个图层可同时开启独奏

**应用场景**：
- 单独查看某个图层效果
- 对比不同图层
- 渲染单个元素

---

#### 9.2.4 锁定（Lock）

**图标**：锁图标 🔒  
**作用**：锁定图层，防止误操作  
**快捷键**：`Ctrl+L`

**状态说明**：
- 解锁 = 可选择、可编辑
- 锁定 = 不可选择、不可编辑
- 锁定的图层仍可见

**应用场景**：
- 背景图层锁定
- 参考图层锁定
- 完成的部分锁定
- 控制器图层（防止误移动）

---

#### 9.2.5 消隐（Shy）

**图标**：害羞图标 / 眼睛躲起来  
**作用**：在时间轴中隐藏图层显示（不影响渲染）  
**快捷键**：点击害羞图标

**使用方法**：
1. 给图层开启「消隐」开关
2. 点击时间轴顶部的「隐藏消隐图层」按钮
3. 开启消隐的图层就从时间轴中隐藏了

**应用场景**：
- 隐藏已完成的图层
- 简化时间轴显示
- 整理大量图层

> **注意**：消隐只是在时间轴中隐藏，渲染时仍会显示！

---

#### 9.2.6 折叠变换（Collapse Transformations）

**图标**：太阳图标 / 斜杠方块  
**作用**：对于预合成层，忽略其合成尺寸，直接使用其图层的变换  
**快捷键**：点击该列

**对预合成层的作用**：
- 不进行预合成的光栅化
- 子图层的 3D 属性继续生效
- 提高质量（矢量保持清晰度）
- 可能改变渲染顺序

**对形状层/文字层的作用**：
- 连续栅格化（Continuously Rasterize）
- 缩放时保持清晰
- 但增加渲染时间

> **注意**：开启后，预合成层的蒙版、效果、混合模式的渲染顺序可能改变。

---

#### 9.2.7 质量（Quality）

**图标**：斜线 / 方块  
**作用**：切换图层的渲染质量  
**快捷键**：`Ctrl+U`

**模式**：
- 线框（Wireframe）：只显示轮廓，最快
- 草稿（Draft）：低质量，较快
- 最佳（Best）：最高质量，最慢

**应用场景**：
- 预览时降低质量提升速度
- 最终渲染时使用最佳质量
- 复杂场景优化预览

---

#### 9.2.8 效果（Effects）

**图标**：fx  
**作用**：开关图层上所有效果的总开关  
**快捷键**：点击 fx 列

**状态说明**：
- fx 显示 = 效果生效
- fx 灰色 = 所有效果禁用

**应用场景**：
- 对比有无效果的差异
- 暂时禁用效果提升预览速度
- 排查效果问题

> **注意**：这是所有效果的总开关，单个效果的开关在效果控件面板。

---

#### 9.2.9 帧混合（Frame Blending）

**图标**：胶片帧图标  
**作用**：当素材被放慢或加速时，使用帧混合产生更平滑的运动  
**快捷键**：`Ctrl+Alt+F`

**模式**：
- 关（Off）：无帧混合
- 帧混合（Frame Mix）：相邻帧混合
- 像素运动（Pixel Motion）：光流法插帧（质量更高，更慢）

**应用场景**：
- 慢动作视频
- 时间重映射
- 提升低帧率素材的平滑度

> **注意**：需要开启时间轴顶部的「启用帧混合」总开关。

---

#### 9.2.10 运动模糊（Motion Blur）

**图标**：运动模糊图标  
**作用**：给运动的图层添加运动模糊效果  
**快捷键**：`Alt+Shift+M`

**效果**：
- 模拟真实相机的运动模糊
- 让动画更平滑自然
- 增加真实感

**参数设置**：
- 在合成设置中调整：
  - 快门角度（Shutter Angle）：控制模糊量
  - 快门相位（Shutter Phase）：控制模糊偏移
  - 每帧样本数：控制质量

**应用场景**：
- 快速运动的元素
- 位移动画
- 旋转动画
- 增强动效真实感

> **注意**：需要开启时间轴顶部的「启用运动模糊」总开关。

---

#### 9.2.11 调整层（Adjustment Layer）

**图标**：调整层图标（圆形加一半黑）  
**作用**：将当前图层变为调整层  
**快捷键**：点击该列

**效果**：
- 图层自身内容不再显示
- 图层上的效果应用于下方所有图层
- 详见第四章

**应用场景**：
- 将普通图层转换为调整层
- 快速创建调整层
- 临时切换调整层效果

---

#### 9.2.12 3D 图层（3D Layer）

**图标**：3D 立方体图标  
**作用**：将图层转换为 3D 图层  
**快捷键**：点击该列

**效果**：
- 增加 Z 轴位置属性
- 增加 X/Y/Z 旋转属性
- 增加材质选项（接受灯光、投影等）
- 受灯光和摄像机影响

**应用场景**：
- 3D 空间合成
- 景深效果
- 3D 文字
- 摄像机运动
- 体积感营造

> 开启后会增加属性：方向、X旋转、Y旋转、Z旋转、材质选项。

### 11.2 混合模式异常排查

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| 混合模式没效果 | 上下层颜色相同/相似 | 检查图层内容，调整上层颜色 |
| 效果太强烈 | 不透明度太高 | 降低不透明度 |
| 黑色背景去不掉 | 用了 Multiply 而非 Screen | 黑色背景用 Screen/Linear Dodge |
| 白色背景去不掉 | 用了 Screen 而非 Multiply | 白色背景用 Multiply/Darken |
| 颜色不对 | 混合模式选择错误 | 重新选择合适的混合模式 |
| 文字看不清 | 背景太亮/太暗 | 加投影/发光，调整混合模式 |
| 整体太亮 | 多个 Screen 层叠加 | 减少层数或降低不透明度 |

### 11.3 调整层无效排查

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| 调整层完全没效果 | 调整层在所有图层下方 | 移到需要影响的图层上方 |
| 部分图层不受影响 | 那些图层在调整层上方 | 调整图层顺序 |
| 效果太弱 | 不透明度太低 | 提高不透明度 |
| 效果不对 | 混合模式不对 | 改为 Normal 或合适模式 |
| 效果区域不对 | 蒙版限制了区域 | 检查/删除蒙版 |
| 3D图层不受影响 | 调整层不是3D的？ | 检查渲染顺序和3D设置 |
| 性能很慢 | 调整层效果太复杂 | 优化效果或预渲染 |

**检查清单**：
1. ✅ 调整层开关是否开启？
2. ✅ 调整层是否在要影响的图层上方？
3. ✅ 视频开关是否开启？
4. ✅ 不透明度是否 > 0？
5. ✅ 效果是否添加且开启？
6. ✅ 蒙版是否限制了区域？
7. ✅ 混合模式是否正确？

### 11.4 3D图层渲染顺序异常排查

#### 11.4.1 常见问题

| 问题 | 原因 | 解决方法 |
|------|------|---------|
| 图层前后顺序不对 | 时间轴顺序≠3D空间顺序 | 调整Z轴位置 |
| 图层穿插不对 | 渲染顺序问题 | 检查图层顺序 + Z值 |
| 灯光不照射 | 材质选项没开 | 开启「接受灯光」 |
| 没有阴影 | 投影没开 | 灯光开投影 + 图层开「投影」 |
| 摄像机看不到 | 图层在摄像机后面 | 调整Z轴位置 |
| 文字/形状模糊 | 没开折叠变换 | 开启连续栅格化 |

#### 11.4.2 3D渲染规则

**3D 图层渲染顺序规则**：
1. 首先按 Z 轴深度排序（远离摄像机的先渲染）
2. 相同 Z 深度的 3D 图层按时间轴顺序
3. 2D 图层不受 Z 轴影响，按时间轴顺序
4. 调整层影响其下方的所有 2D 和 3D 图层

**混合规则**：
- 2D 图层和 3D 图层混合时，2D 图层按时间轴顺序
- 可能出现 3D 图层被 2D 图层"夹"在中间的情况

> **解决方法**：保持所有 3D 图层连续，不要在中间插入 2D 图层。

## 十二、性能优化

### 12.1 图层数量优化

#### 12.1.1 减少图层数量的方法

| 方法 | 说明 | 效果 |
|------|------|------|
| 预合成 | 将一组图层打包 | 简化管理，不一定提升性能 |
| 合并效果 | 一个调整层代替多个图层效果 | 减少重复计算 |
| 使用形状层 | 代替多个纯色层+蒙版 | 一个形状层可包含多个形状 |
| 预渲染 | 渲染好的视频代替合成 | 大幅提升性能 |
| 合并素材 | 静态元素导出为图片 | 减少实时计算 |

#### 12.1.2 多少图层算"多"

| 项目类型 | 正常范围 | 需优化 |
|---------|---------|--------|
| 简单动画 | 10-30 层 | > 50 层 |
| MG动画 | 30-80 层 | > 150 层 |
| 视频剪辑 | 20-50 层 | > 100 层 |
| 特效合成 | 50-150 层 | > 300 层 |
| 粒子系统 | 30-100 层 | > 200 层 |

> 这些数字仅供参考，实际性能还取决于效果复杂度、分辨率、硬件等。

### 12.2 预合成优化

#### 12.2.1 什么时候用预合成

| 适合预合成 | 不适合预合成 |
|-----------|-------------|
| 一组相关的元素 | 简单的位置动画组（用空对象即可） |
| 需要统一加效果 | 频繁需要单独调整的图层 |
| 需要统一蒙版 | 单个简单图层 |
| 多次复用的元素 | 性能敏感且简单的场景 |
| 复杂的嵌套动画 | 非常深的嵌套（>5层） |

#### 12.2.2 预渲染优化

**何时预渲染**：
1. 合成已完成，不再修改
2. 预览卡顿严重
3. 嵌套层数过多
4. 效果计算复杂（粒子、模糊等）
5. 需要多次复用

**预渲染方法**：
- 菜单：合成 → 预渲染
- 或：合成 → 保存帧 → 文件（单帧）
- 输出为 QuickTime 或图像序列
- 替换项目中的合成

### 12.3 调整层优化

#### 12.3.1 调整层性能影响

| 效果类型 | 性能开销 | 优化建议 |
|---------|---------|---------|
| 简单调色（曲线/色阶） | 低 | 放心使用 |
| 高斯模糊 | 中 | 半径越大越慢 |
| 发光/辉光 | 中高 | 合理控制半径 |
| 镜头模糊 | 高 | 尽量少用，或预渲染 |
| 颗粒/噪波 | 中高 | 降低数量 |
| 扭曲类 | 高 | 减少使用 |
| 抠像类 | 高 | 预渲染抠好的素材 |

#### 12.3.2 优化技巧

1. **合并调整层**：相同类型的效果合并到一个调整层
2. **使用蒙版限制区域**：只在需要的区域应用效果
3. **降低效果参数**：模糊半径、采样数等不要太大
4. **使用快速版本预览**：预览时用低质量
5. **关闭不必要的调整层**：编辑时临时关闭

### 12.4 混合模式性能对比

#### 12.4.1 性能开销等级

| 开销等级 | 混合模式 | 相对速度 |
|---------|---------|---------|
| ⚡ 最快 | Normal | 1x |
| ⚡ 快 | Dissolve, Darken, Lighten | 1.1x |
| ⚡ 快 | Multiply, Screen | 1.2x |
| 🟢 中 | Overlay, Soft Light, Hard Light | 1.5x |
| 🟡 较慢 | Color Burn, Color Dodge | 1.8x |
| 🟡 较慢 | Linear Burn, Linear Dodge | 1.5x |
| 🔴 慢 | Difference, Exclusion | 2x |
| 🔴 慢 | Hue, Saturation, Color, Luminosity | 2.5x |
| 🔴 慢 | Vivid Light, Linear Light, Pin Light | 2x |

> 相对速度为近似值，实际取决于显卡、分辨率等。

#### 12.4.2 优化建议

1. **优先使用 Normal + 不透明度**：性能最好
2. **大量图层时避免 Color/Luminosity**：转换颜色空间较慢
3. **光效优先用 Screen**：比 Linear Dodge 稍慢但效果好控制
4. **阴影优先用 Multiply**：最常用的变暗模式
5. **预览时可临时改为 Normal**：提升预览速度

### 12.5 综合性能优化清单

#### 预览优化
- [ ] 降低预览分辨率（1/2 或 1/4）
- [ ] 关闭运动模糊（预览时）
- [ ] 关闭帧混合（预览时）
- [ ] 使用 Region of Interest 只看部分区域
- [ ] 关闭不必要的效果
- [ ] 隐藏不相关的图层

#### 项目优化
- [ ] 合理使用预合成
- [ ] 预渲染复杂合成
- [ ] 使用代理素材
- [ ] 减少图层数量
- [ ] 合并重复效果
- [ ] 控制嵌套深度

#### 硬件相关
- [ ] 启用 GPU 加速
- [ ] 足够的内存（建议 32GB+）
- [ ] 使用 SSD 存储素材和缓存
- [ ] 清理磁盘缓存
- [ ] 更新显卡驱动
