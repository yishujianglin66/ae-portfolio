# AE 跟踪与稳定器完全指南

> 版本: 2025-v1 | 适用: 运动跟踪/镜头稳定/3D摄像机反求

## 一、单点跟踪

### 1.1 跟踪器面板

| 功能 | 用途 | 操作 |
|------|------|------|
| 跟踪运动 | 单点/双点跟踪 | 窗口→跟踪器 |
| 稳定跟踪 | 镜头稳定 | 选择稳定 |
| 跟踪运动 | 应用跟踪数据 | 选择跟踪运动 |
| 跟踪raw | 原始跟踪数据 | 用于分析 |

### 1.2 单点跟踪流程

```
单点跟踪:
1. 选择图层→窗口→跟踪器
2. 跟踪运动→跟踪单个点
3. 调整跟踪区域:
   - 外框: 搜索区域
   - 内框: 跟踪特征点
4. 选择目标:
   - 变换: 位置/缩放/旋转
   - 原始: 原始数据
5. 分析→向前/向后
6. 应用跟踪数据

应用场景:
- 跟踪物体位置
- 跟踪角点
- 跟踪面部特征
```

### 1.3 双点跟踪

```
双点跟踪:
1. 跟踪运动→跟踪两个点
2. 点1: 位置参考
3. 点2: 缩放/旋转参考
4. 分析跟踪
5. 应用数据

应用场景:
- 跟踪平面
- 跟踪缩放
- 跟踪旋转
```

## 二、3D摄像机跟踪

### 2.1 3D摄像机跟踪器

| 功能 | 说明 | 用途 |
|------|------|------|
| 3D摄像机跟踪器 | 自动反求摄像机 | 3D场景重建 |
| 跟踪点 | 自动检测特征 | 分析基础 |
| 解算 | 计算摄像机运动 | 3D匹配 |
| 创建摄像机 | 生成3D摄像机 | 合成基础 |

### 2.2 跟踪流程

```
3D摄像机跟踪:
1. 选择 footage 图层
2. 效果→跟踪运动→3D摄像机跟踪器
3. 分析镜头:
   - 自动检测跟踪点
   - 计算摄像机运动
4. 检查解算状态:
   - 绿色: 成功
   - 红色: 失败
5. 选择地面点和原点
6. 右键→创建摄像机
7. 创建3D图层匹配场景

设置参数:
- 镜头类型: 固定焦距/可变焦距
- 镜头焦距: 已知/未知
- 裁剪: 自动/手动
```

### 2.3 跟踪点管理

```
跟踪点操作:
- 选择跟踪点: 点击
- 多选: Shift+点击
- 删除: Delete
- 创建空对象: 右键→创建空对象和文本
- 创建文字: 右键→创建文本和跟踪点
- 创建实色: 右键→创建实色和跟踪点

地面点和原点:
1. 选择3个跟踪点作为地面
2. 右键→设置地面平面
3. 选择1个点作为原点
4. 右键→设置原点
```

## 三、变形稳定器

### 3.1 变形稳定器VST

| 参数 | 说明 | 建议值 |
|------|------|--------|
| 结果 | 稳定/模糊/自动 | 自动 |
| 平滑运动 | 平滑程度 | 50-90% |
| 平滑旋转 | 旋转平滑 | 5-20° |
| 稳定裁剪 | 自动/手动 | 自动 |
| 稳定缩放 | 缩放平滑 | 自动 |
| 方法 | 子空间扭曲/仅位置 | 子空间扭曲 |

### 3.2 稳定流程

```
变形稳定器:
1. 选择 footage 图层
2. 效果→扭曲→变形稳定器VST
3. 等待分析完成
4. 调整参数:
   - 平滑运动: 越高越平滑
   - 平滑旋转: 旋转补偿
   - 方法: 子空间扭曲(推荐)
5. 查看结果
6. 如需调整→重新分析

高级设置:
- 详细分析: 更精确但更慢
- 滚动快门: 修复果冻效应
- 裁剪更少: 保留更多画面
```

### 3.3 稳定技巧

```
稳定技巧:
1. 先稳定后裁剪
2. 使用代理加速分析
3. 复杂镜头分段稳定
4. 结合手动关键帧微调
5. 使用嵌套预合成

常见问题:
- 果冻效应: 启用滚动快门修复
- 边缘拉伸: 增加裁剪
- 模糊: 降低平滑度
- 失败: 检查跟踪点
```

## 四、Mocha跟踪

### 4.1 Mocha AE

| 功能 | 说明 | 用途 |
|------|------|------|
| 平面跟踪 | 基于平面跟踪 | 精确跟踪 |
| 遮罩跟踪 | 跟踪遮罩形状 | 复杂遮罩 |
| 镜头跟踪 | 摄像机反求 | 3D匹配 |
| 对象移除 | 跟踪+移除 | 清洁画面 |
| 插入 | 跟踪+插入 | 合成元素 |

### 4.2 Mocha工作流

```
Mocha跟踪:
1. 效果→Mocha AE→启动
2. 创建X-Spline遮罩
3. 调整遮罩覆盖跟踪区域
4. 设置跟踪参数:
   - 运动: 平移/缩放/旋转/透视
   - 表面: 插入平面
   - 遮罩: 遮罩形状
5. 跟踪→向前
6. 导出跟踪数据:
   - AE变换数据
   - 3D摄像机数据
   - 遮罩形状数据
7. 在AE中应用数据

应用场景:
- 屏幕替换
- 物体跟踪
- 面部跟踪
- 平面插入
```

## 五、高级跟踪技术

### 5.1 多点跟踪

```
多点跟踪策略:
1. 识别关键特征点
2. 为每个点创建跟踪
3. 分析所有点
4. 综合数据创建3D解算
5. 验证跟踪精度

应用:
- 复杂场景跟踪
- 高精度匹配
- 多平面跟踪
```

### 5.2 跟踪数据管理

```
跟踪数据组织:
1. 命名规范:
   - Track_位置_01
   - Track_旋转_01
   - Track_缩放_01
2. 颜色编码:
   - 红色: 位置
   - 绿色: 旋转
   - 蓝色: 缩放
3. 空对象承载:
   - 跟踪数据→空对象
   - 图层→链接到空对象
```

## 六、表达式与跟踪

### 6.1 跟踪表达式

```javascript
// 链接到跟踪数据
var trackPoint = thisComp.layer("Null 1").transform.position;
value + trackPoint;

// 平滑跟踪
var smoothPos = transform.position;
var smooth = smooth(smoothPos, 0.5);
smooth;

// 跟踪+偏移
var base = thisComp.layer("Null 1").transform.position;
var offset = [50, 30];
base + offset;
```
