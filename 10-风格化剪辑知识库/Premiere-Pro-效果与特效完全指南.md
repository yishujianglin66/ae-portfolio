## 二、变形稳定器

### 2.1 参数详解

| 参数 | 范围 | 推荐 |
|------|------|------|
| 平滑度 | 1-100% | 50-80% |
| 方法 | 子空间/透视/合成/无变换 | 子空间(默认) |
| 裁剪 < | 自动-100% | 自动 |
| 滚动快门校正 | 开/关 | 果冻效应严重时开 |

### 2.2 最佳实践

```
1. 在嵌套序列上应用(避免重复分析)
2. 分析完成后检查裁剪区域
3. 如果裁剪过多: 降低平滑度
4. 如果仍有抖动: 增加平滑度
5. 滚动快门: 仅在果冻效应明显时开启
```

## 三、键控(抠像)

### 3.1 超级键(Ultra Key)

| 参数 | 作用 | 建议 |
|------|------|------|
| 遮罩生成 | 创建遮罩 | 吸管选取绿色 |
| 遮罩清除 | 清理边缘 | 抑制溢色 |
| 溢色抑制 | 去绿色溢出 | 中度 |
| 遮罩仅显 | 查看遮罩 | 调试用 |
| 柔和度 | 边缘柔化 | 1-5 |
| 溢出 | 去溢色 | 20-50 |

### 3.2 键控工作流

```
1. 应用超级键效果
2. 用吸管选取绿幕纯色区域
3. 切换到"遮罩仅显"视图
4. 调整遮罩生成(黑白分明)
5. 调整遮罩清除(去绿色残留)
6. 调整溢色抑制(去色溢)
7. 回到正常视图检查
8. 边缘精修(柔和度/透明度)
```

## 四、创意特效

### 4.1 分屏效果

```
方法: 使用裁剪效果+位置
1. 复制视频到多轨道
2. 每轨裁剪不同区域
3. 排列成网格布局
4. 添加白色分隔线(形状图层)
```

### 4.2 文字跟踪

```
1. 创建文字图层
2. 使用变形稳定器跟踪运动
3. 或使用Mocha Pro跟踪
4. 将跟踪数据应用到文字位置
```

### 4.3 画面内文字

```
1. 创建文字
2. 应用基本3D效果
3. 匹配画面透视
4. 使用轨道遮罩限制在物体表面
5. 色彩匹配(混合模式:叠加/柔光)
```

## 五、转场效果进阶

### 5.1 自定义转场

| 技术 | 实现 | 效果 |
|------|------|------|
| 调整图层+效果 | 在转场区添加调整图层 | 自定义效果转场 |
| 不透明度关键帧 | 手动控制淡入淡出 | 精确控制 |
| 混合模式 | 滤色/叠加/柔光 | 光效转场 |
| 遮罩动画 | 线性/径向遮罩展开 | 擦除转场 |
| MOGRT模板 | AE制作→PR使用 | 专业动态图形 |

### 5.2 效果转场类型

| 类型 | 实现 | 适用 |
|------|------|------|
| 模糊转场 | 高斯模糊关键帧 | 梦幻/回忆 |
| 缩放转场 | 缩放关键帧+模糊 | 冲击/能量 |
| 旋转转场 | 旋转关键帧 | 动感/活力 |
| 色差转场 | RGB分离关键帧 | 故障/科技 |
| 光效转场 | 镜头光晕+滤色 | 梦幻/过渡 |
| 遮罩转场 | 物体经过触发遮罩 | 无缝切换 |

## 六、Essential Graphics 动态图形

### 6.1 创建图形

```
1. 窗口 → 基本图形面板
2. 使用文字/矩形/椭圆工具
3. 创建模板(可复用)
4. 导出为MOGRT(在AE中)
```

### 6.2 常用图形模板

| 模板 | 用途 | 参数 |
|------|------|------|
| Lower Third | 人名/职位条 | 文字/颜色/动画 |
| 标题条 | 章节标题 | 文字/背景/动画 |
| 字幕条 | 对话字幕 | 文字/位置 |
| 进度条 | 列表/排行 | 数值/颜色 |
| 社交媒体框 | 平台适配 | 尺寸/安全区 |
