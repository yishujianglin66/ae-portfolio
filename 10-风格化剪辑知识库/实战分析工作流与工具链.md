# 实战分析工作流与工具链

> [!abstract] 文档摘要

## 一、分析准备阶段

> [!important] 基础准备章节
> 工欲善其事，必先利其器。分析准备阶段决定了后续分析的效率和准确性。工具配置、视频预处理、笔记模板搭建这三步是每次分析前的必修课。跳过准备阶段直接上手分析，往往会事倍功半。

### 1.1 工具准备

```
必备工具：
├── After Effects 2024+（主分析环境）
├── PotPlayer 或 VLC（快速逐帧预览）
├── 截图工具（Snipaste / Win+Shift+S）
├── 取色工具（AE内置吸管 / 第三方取色器）
└── 笔记工具（Obsidian / Notion / 记事本）

可选工具：
├── Photoshop（帧对比、颜色分析）
├── DaVinci Resolve（专业调色分析）
├── AI工具（字体识别、场景分析）
│   ├── WhatTheFont（字体识别）
│   ├── ChatGPT/Claude（效果推理辅助）
│   └── Runway（视频分析）
└── 参考资源
    ├── AE效果列表（用于对照）
    ├── 插件文档（确认插件参数）
    └── 预设目录（确认预设效果）
```

### 1.2 视频准备

```
1. 获取最高质量的视频源
   ├── 优先获取原始分辨率视频
   ├── 避免经过多次压缩的视频
   └── 记录视频的帧率和分辨率

2. 导入AE
   ├── 新建项目
   ├── 新建合成（匹配视频分辨率和帧率）
   ├── 导入视频 → 拖入时间轴
   └── 确认帧率匹配（Composition Settings → Frame Rate）

3. 预处理
   ├── 展开音频波形（如需音频分析）
   ├── 设置工作区覆盖整个视频
   └── 开启 Draft 3D 模式（如果分析3D内容）
```

## 二、分层分析流程

> [!important] 核心工作流章节
> 本章是整个实战分析的核心流程，七轮分析法从全局到局部、从宏观到微观，逐层拆解视频效果。每一轮都有明确的目标、操作方法和输出物。严格按照这个流程分析，可以确保不遗漏任何重要细节，分析效率提升3倍以上。

### 2.1 第一轮：全局概览（5分钟）

```
目标：建立整体印象，标记关键节点

操作：
1. 全速播放视频2-3遍
2. 在关键时间点暂停并标记
   ├── 所有转场时间点
   ├── 所有文字出入场
   ├── 所有特效出现/消失
   ├── 所有速度变化点
   └── 所有音乐节拍重音
3. 在AE时间轴上打标记（小键盘"*"）
4. 记录初步印象

输出：带标记的AE项目 + 时间线笔记
```

### 2.2 第二轮：调色与风格化分析（10分钟）

```
目标：确定全局调色方案和风格化效果

分析顺序：
1. 先看整体色调
   ├── 取色画面中最亮和最暗的区域
   ├── 判断色调偏向（暖/冷/中性）
   ├── 判断对比度（高/中/低）
   └── 判断饱和度（鲜艳/正常/褪色）

2. 再看风格化效果
   ├── 有无暗角 → 取暗角颜色和强度
   ├── 有无颗粒 → 判断颗粒大小和强度
   ├── 有无柔焦 → 判断模糊程度
   ├── 有无CRT/扫描线 → 判断线条密度
   ├── 有无RGB分离 → 判断分离幅度
   └── 有无其他纹理 → 判断纹理类型

3. 对照风格库
   ├── 对比 [[风格化预设宝典]] 中的风格
   ├── 匹配最接近的风格
   └── 记录差异点

输出：调色方案 + 调整层列表
```

### 2.3 第三轮：转场分析（10分钟）

```
目标：还原所有转场效果

分析顺序：
1. 标记每个转场的起止帧
   ├── 转场开始帧：画面A开始变化
   ├── 转场中间帧：画面A和B各占一半
   └── 转场结束帧：画面B完全清晰

2. 判断转场类型
   ├── 缩放转场 → Scale关键帧变化
   ├── 位移转场 → Position关键帧变化
   ├── 旋转转场 → Rotation关键帧变化
   ├── 光效转场 → 光效叠加
   ├── 遮罩转场 → 遮罩形状变化
   ├── 模糊转场 → 模糊程度变化
   ├── 故障转场 → RGB分离/像素化变化
   └── 组合转场 → 多种属性同时变化

3. 逐帧分析转场
   ├── 逐帧截图，观察画面变化
   ├── 记录每帧的属性变化
   ├── 判断关键帧位置
   └── 判断缓动曲线类型

4. 检查是否有动态拼贴
   ├── 缩放时是否有黑边 → 没有 → 有动态拼贴
   ├── 边缘像素是否镜像 → 是 → 动态拼贴开启
   └── 输出宽度/高度 → 通常200-300%

5. 检查运动模糊
   ├── 转场时画面是否模糊 → 是 → MB开启
   ├── 模糊强度 → 判断快门角度
   │   ├── 轻微模糊 → 180°
   │   └── 强烈模糊 → 360°
   └── 如果使用Transform效果 → 可能独立设置了Shutter Angle

输出：每个转场的关键帧参数表
```

### 2.4 第四轮：主体动画分析（15分钟）

```
目标：还原所有关键帧驱动的动画

分析对象：
├── 素材的缩放/位移/旋转
├── 文字动画
├── 图形动画
├── Logo动画
└── 3D物体动画

分析步骤：
1. 选择一个动画对象
2. 逐帧追踪其变化
   ├── 位置变化 → 记录每帧的Position
   ├── 大小变化 → 记录每帧的Scale
   ├── 旋转变化 → 记录每帧的Rotation
   └── 透明度变化 → 记录每帧的Opacity
3. 绘制位移-时间曲线
   ├── 横轴 = 帧号
   ├── 纵轴 = 属性值
   └── 曲线形状 → 缓动类型
4. 在AE中复现
   ├── 创建对应图层
   ├── 设置关键帧
   ├── 调整Graph Editor手柄
   └── 叠加原视频对比

输出：每个动画对象的关键帧表
```

### 2.5 第五轮：特效叠加分析（15分钟）

```
目标：还原所有特效叠加

分析步骤：
1. 识别特效类型
   ├── 对照 [[AE效果视觉特征库]]
   ├── 判断是内置效果还是插件
   └── 记录效果名称

2. 推断特效参数
   ├── 粒子：发射器类型、数量、速度、生命周期、颜色
   ├── 辉光：发光半径、强度、阈值、颜色
   ├── 光效：光线方向、长度、强度、颜色
   ├── 模糊：模糊类型、半径、方向
   ├── 扭曲：扭曲类型、幅度、复杂度
   └── 其他：参照视觉特征库

3. 确定特效的作用范围
   ├── 全局特效 → 调整层
   ├── 局部特效 → 特定图层
   └── 遮罩限制 → 调整层+遮罩

4. 确定混合模式
   ├── 对照混合模式识别表
   ├── 观察与下层画面的混合效果
   └── 确定混合模式和不透明度

输出：特效参数表 + 混合模式列表
```

### 2.6 第六轮：文字与图形分析（10分钟）

```
目标：还原所有文字层和形状层

文字分析：
1. 识别文字内容
2. 识别字体 → 使用 WhatTheFont 或手动比对
3. 测量文字属性
   ├── 字号 → 测量文字高度，反推pt
   ├── 字间距 → 测量字符间距
   ├── 行间距 → 测量行间距
   ├── 颜色 → 取色
   ├── 描边 → 观察描边粗细和颜色
   ├── 投影 → 观察阴影方向和距离
   └── 发光 → 观察发光半径和颜色
4. 识别文字动画
   ├── 入场方式 → 逐字/逐词/逐行/整体
   ├── 动画属性 → 缩放/位移/透明度/旋转/模糊
   ├── 动画时长 → 数帧
   └── 对照[[preset-catalog]] → 匹配预设

图形分析：
1. 识别图形类型 → 矩形/圆形/线条/多边形/自定义路径
2. 测量图形属性 → 大小/位置/颜色/描边/圆角
3. 识别图形动画 → 路径变化/缩放/旋转/透明度
4. 判断是否是形状层还是素材

输出：文字层参数表 + 图形层参数表
```

### 2.7 第七轮：3D与摄像机分析（10分钟）

```
目标：还原3D场景和摄像机设置

分析步骤：
1. 判断是否使用3D
   ├── 有无透视变形 → 有 → 3D
   ├── 有无视差 → 有 → 3D
   ├── 有无景深 → 有 → 3D
   └── 有无真实阴影 → 有 → 3D

2. 还原摄像机
   ├── 焦距 → 观察透视程度
   ├── 景深 → 观察模糊区域
   ├── 动画 → 推拉/平移/旋转/轨道
   └── 参照 [[3d-compositing-guide]]

3. 还原灯光
   ├── 灯光类型 → 点光/聚光/平行光/环境光
   ├── 灯光颜色 → 观察受光面颜色
   ├── 灯光强度 → 观察亮度
   ├── 灯光位置 → 观察阴影方向
   └── 参照 [[3d-compositing-guide]]

4. 推断3D层级
   ├── 各3D图层的Z轴位置
   ├── 空对象作为控制器
   └── 摄像机父子关系

输出：3D场景结构图 + 摄像机参数
```

### 2.8 第八轮：音频驱动分析（5分钟）

```
目标：还原音频驱动的动画

分析步骤：
1. 展开音频波形
2. 标记节拍重音（小键盘"*"）
3. 观察哪些动画与节拍对齐
   ├── 缩放脉冲 → 音频振幅 → Scale
   ├── 透明度闪烁 → 音频振幅 → Opacity
   ├── 位置跳动 → 音频振幅 → Position
   └── 粒子爆发 → 节拍触发
4. 推断音频联动参数
   ├── 触发阈值
   ├── 映射范围
   └── 平滑度

输出：音频联动参数表
```

## 三、复现与验证阶段

> [!note] 质量验证章节
> 分析完不等于分析对了，复现验证才是检验分析质量的唯一标准。本章的逐层复现法和精度评估方法，可以确保你的分析结果经得起检验。从"看起来像"到"参数精确"，这一步是专业与业余的分水岭。

### 3.1 逐层复现法

```
复现顺序（从底到顶）：
1. 背景层
2. 素材/视频层
3. 预合成（如需要）
4. 图形层
5. 文字层
6. 3D元素 + 摄像机 + 灯光
7. 特效叠加层（粒子/辉光/光效）
8. 调整层（风格化/调色/暗角/颗粒/柔焦）
9. 空对象（运镜控制）
10. 音频

复现原则：
├── 每完成一层，立即与原视频对比
├── 发现问题立即修正，不要积累
├── 保持图层结构清晰，命名规范
└── 使用颜色标签区分图层类型
```

### 3.2 叠加验证法

```
方法：
1. 将原视频放在复现合成的顶层
2. 原视频不透明度设为 50%
3. 逐帧播放，观察差异
4. 差异分析：
   ├── 位置偏差 → 调整Position关键帧
   ├── 大小偏差 → 调整Scale
   ├── 时机偏差 → 移动关键帧
   ├── 颜色偏差 → 调整调色参数
   ├── 模糊偏差 → 调整Blur参数
   └── 曲线偏差 → 调整Graph Editor手柄

高级技巧：
├── 使用Difference混合模式 → 差异区域高亮显示
├── 只有在完全匹配时画面才全黑
└── 差异越明显，匹配度越低
```

### 3.3 A/B对比法

```
方法：
1. 在复现的合成中，对每个效果做开关对比
2. 关闭效果 → 与原视频对比 → 差异明显
3. 开启效果 → 与原视频对比 → 差异减小
4. 微调参数直到差异最小

对比清单：
□ 暗角开关 → 暗角强度匹配
□ 颗粒开关 → 颗粒强度匹配
□ 柔焦开关 → 模糊程度匹配
□ 调色开关 → 色调匹配
□ 发光开关 → 发光强度匹配
□ 粒子开关 → 粒子效果匹配
□ 转场效果 → 转场视觉匹配
□ 文字动画 → 文字动画匹配
□ 摄像机运动 → 透视匹配
□ 运动模糊 → 模糊强度匹配
```

## 四、完整分析案例演示

### 4.1 案例：假设一个30秒的AMV片段

```
═══════════════════════════════════════════
第1步：全局概览
═══════════════════════════════════════════

视频信息：
- 分辨率：1920×1080
- 帧率：30fps
- 时长：0:30
- 类型：AMV/漫剪

标记节点：
- 0:00 → 视频开始，文字入场
- 0:02 → 转场1（缩放拉镜）
- 0:05 → 转场2（旋转拉镜）
- 0:08 → 粒子爆发
- 0:10 → 文字退场
- 0:12 → 转场3（光效转场）
- 0:15 → 高潮开始，快速拉镜
- 0:22 → 转场4（模糊转场）
- 0:25 → 慢放开始
- 0:28 → 文字出场
- 0:30 → 视频结束

═══════════════════════════════════════════
第2步：调色分析
═══════════════════════════════════════════

观察：
- 整体色调偏暖，暗部有青色调
- 对比度中等偏高
- 有暗角，边缘暗度约60%
- 有轻微胶片颗粒

推断：
- Lumetri Color：色温5800K，对比度115，阴影偏青
- CC Vignette：Amount -60
- Add Grain：Intensity 0.3，Size 2

═══════════════════════════════════════════
第3步：转场分析
═══════════════════════════════════════════

转场1（0:00-0:02:15，缩放拉镜）：
- 画面A：Scale 100% → 130%（Ease Out）
- 画面B：Scale 130% → 100%（Ease In）
- 伴随：Motion Blur（快门角度360°）
- 动态拼贴：是（无黑边）

转场2（0:05-0:06:10，旋转拉镜）：
- 画面A：Rotation 0° → 8°（Ease Out）
- 画面B：Rotation -8° → 0°（Ease In）
- 伴随：Scale 100% → 110% → 100%
- Motion Blur：是

转场3（0:12-0:13:05，光效转场）：
- 画面A：Opacity 100% → 0%（5帧）
- 画面B：Opacity 0% → 100%（5帧）
- 叠加：白色闪光（纯色层 + Opacity 0→100→0）
- 伴随：CC Light Burst

转场4（0:22-0:23:00，模糊转场）：
- 画面A：Gaussian Blur 0 → 50px（Ease In）
- 画面B：Gaussian Blur 50 → 0px（Ease Out）
```

## 五、高效分析技巧

### 5.1 快速判断技巧

```
1. "一眼识别"列表：
   ├── 画面偏暖+暗角+颗粒 → 电影感风格
   ├── 青蓝+霓虹+扫描线 → 赛博朋克
   ├── RGB分离+噪点+偏暖 → 复古VHS
   ├── 快速缩放+运动模糊 → 拉镜转场
   ├── 白色闪光+快速切换 → 光效转场
   ├── 弹性缩放+文字 → 弹性表达式
   └── 画面持续微晃 → wiggle表达式

2. "排除法"：
   ├── 不是CC Particle World → 就是Particular
   ├── 不是Gaussian Blur → 就是Camera Lens Blur
   ├── 不是内置效果 → 就是第三方插件
   ├── 不是纯关键帧 → 就是表达式驱动
   └── 不是2D → 就是3D
```

### 5.3 常见陷阱

```
陷阱1：过度分析
├── 症状：在细节上花费太多时间
├── 解决：先完成整体框架，再细化细节
└── 原则：80%的匹配度优先于100%的完美

陷阱2：忽略图层顺序
├── 症状：效果叠错了层级
├── 解决：从视觉遮挡关系推断图层顺序
└── 原则：被遮挡的在下面

陷阱3：忽略预合成
├── 症状：无法复现复杂的嵌套动画
├── 解决：识别哪些元素总是一起运动，预合成它们
└── 原则：模块化思想

陷阱4：忽略表达式
├── 症状：用大量关键帧复现表达式驱动的动画
├── 解决：识别弹性/随机/循环/音频驱动的特征
└── 原则：表达式比人工关键帧更高效

陷阱5：忽略混合模式
├── 症状：颜色和亮度不对
├── 解决：检查画面叠加效果，确定混合模式
└── 原则：Screen/Add让画面变亮，Multiply让画面变暗
```

## 九、企业级逆向分析工作流

### 9.3 时间预算模型（30 秒镜头基准）

```

        = 1.2h   + 4.0h    + 1.8h
        ≈ 7.0h（标准复杂度）

  • 简单（2D 平面、纯转场）       k = 0.6

时间预算 = 7.0h × k × (镜头时长 / 30s)^0.85
```

## 十、自动化分析工具链

> 人工逐帧分析在 30s 镜头上耗费 7+ 小时，其中 40% 时间用于重复的元数据提取、帧采样、颜色采样等机械操作。自动化工具链将这部分时间压缩到 15 分钟内。

### 10.1 视频预处理工具：ffprobe / ffmpeg

```bash
# 1. 提取完整元数据（JSON 格式，便于脚本解析）
ffprobe -v quiet -print_format json \
        -show_format -show_streams -show_chapters \
        input.mp4 > metadata.json

# 2. 提取关键帧时间码（用于镜头切分预判）
ffprobe -v quiet -print_format json \
        -select_streams v:0 -show_entries frame=key_frame,pkt_pts_time \
        -of json input.mp4 > keyframes.json

# 3. 提取场景切换点（libavfilter 场景检测）
ffprobe -v quiet -print_format json -f lavfi \
        "movie=input.mp4,select='gt(scene,0.3)',showinfo" \
        -show_entries frame=pts_time > scene_cuts.json

# 4. 提取音频峰值与节拍（送入 Audacity 或 aubio 进行 onset 检测）
ffmpeg -i input.mp4 -vn -ac 1 -ar 44100 audio.wav
aubiotrack audio.wav > beats.txt

# 5. 生成视频缩略图序列（每秒一帧，用于快速浏览）
ffmpeg -i input.mp4 -vf fps=1 thumbs/frame_%04d.png
```

### 10.2 帧提取与批量分析（Python 自动化）

```python
# frame_extractor.py - 帧提取与批量分析
import subprocess, json, os
from pathlib import Path

class FrameExtractor:
    def __init__(self, video_path, output_dir="frames"):
        self.video = video_path
        self.out = Path(output_dir)
        self.out.mkdir(parents=True, exist_ok=True)

    def extract_all_frames(self, fps=None):
        """提取所有帧或按指定 fps 抽帧"""
        if fps:
            cmd = ["ffmpeg", "-i", self.video,
                   "-vf", f"fps={fps}",
                   str(self.out / "frame_%05d.png")]
        else:
            cmd = ["ffmpeg", "-i", self.video,
                   str(self.out / "frame_%05d.png")]
        subprocess.run(cmd, check=True)

    def extract_keyframes(self):
```

```python
# color_sampler.py - 批量颜色采样
import cv2, numpy as np, csv
from pathlib import Path

class ColorSampler:
    """对帧序列进行批量颜色采样，输出 CSV + 统计"""

    def __init__(self, frames_dir):
        self.frames = sorted(Path(frames_dir).glob("*.png"))

    def sample_point(self, frame_path, x, y, sample_radius=3):
        """对单点进行多点采样（取半径内均值）"""
        img = cv2.imread(str(frame_path))
        h, w = img.shape[:2]
        x, y = int(x * w), int(y * h)
        region = img[max(0,y-sample_radius):y+sample_radius,
                     max(0,x-sample_radius):x+sample_radius]
        mean_bgr = region.mean(axis=(0,1))
        mean_rgb = mean_bgr[::-1]  # BGR → RGB
        return tuple(int(v) for v in mean_rgb)

    def batch_sample(self, points, output_csv="colors.csv"):
        """
        points: [{"name": "high_light", "x": 0.5, "y": 0.2}, ...]
        """
        with open(output_csv, "w", newline="") as f:
            writer = csv.writer(f)
            header = ["frame"] + [f"{p['name']}_R,G,B" for p in points]
            writer.writerow(header)
            for fp in self.frames:
                row = [fp.name]
                for p in points:
                    r, g, b = self.sample_point(fp, p["x"], p["y"])
                    row.extend([r, g, b])
                writer.writerow(row)

    def detect_dominant_color(self, frame_path, k=3):
        """K-Means 提取主色调"""
        img = cv2.imread(str(frame_path))
        img = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
        pixels = img.reshape(-1, 3).astype(np.float32)
        criteria = (cv2.TERM_CRITERIA_EPS | cv2.TERM_CRITERIA_MAX_ITER, 20, 1.0)
        _, labels, centers = cv2.kmeans(pixels, k, None, criteria, 3,
                                         cv2.KMEANS_PP_CENTERS)
        counts = np.bincount(labels.flatten())
        return sorted(zip([tuple(c) for c in centers.astype(int)], counts),
                     key=lambda x: -x[1])
```

```python
class EffectClassifier:
    """零样本效果识别：无需训练即可识别新效果"""

        "a frame with strong vignette darkening edges",
        "a frame with film grain texture noise",
        "a frame with RGB channel split glitch",
        "a frame with bright glow halation around lights",
        "a frame with CRT scanlines and chromatic aberration",
        "a frame with particles flying in golden color",
        "a frame with motion blur streaks",
        "a frame with shallow depth of field bokeh",
        # 扩展：参照 AE 效果视觉特征库
    ]

    def __init__(self):
        self.model = CLIPModel.from_pretrained("openai/clip-vit-base-patch32")
        self.processor = CLIPProcessor.from_pretrained("openai/clip-vit-base-patch32")

    def classify(self, image_path, top_k=3):
        image = Image.open(image_path)
        inputs = self.processor(text=self.EFFECT_PROMPTS,
                                images=image, return_tensors="pt", padding=True)
        with torch.no_grad():
            outputs = self.model(**inputs)
        logits = outputs.logits_per_image.softmax(dim=-1)[0]

        return [(self.EFFECT_PROMPTS[i], logits[i].item())
```

### 11.4 关键帧预测 LSTM：从运动序列预测关键帧位置

```python
# keyframe_predictor.py - LSTM 关键帧预测
import numpy as np
import tensorflow as tf
from tensorflow.keras import layers

class KeyframePredictor:
    """
    输入：连续 N 帧的属性序列（Position、Scale、Rotation 等）
    输出：每帧为"关键帧"的概率（0-1）
    """

    def __init__(self, seq_length=30, feature_dim=8):
        self.seq_length = seq_length
        self.feature_dim = feature_dim
        self.model = self._build_model()

    def _build_model(self):
        model = tf.keras.Sequential([
            layers.LSTM(128, return_sequences=True,
                       input_shape=(self.seq_length, self.feature_dim)),
            layers.Dropout(0.2),
            layers.LSTM(64, return_sequences=True),
            layers.Dropout(0.2),
            layers.TimeDistributed(layers.Dense(1, activation='sigmoid'))
        ])
        model.compile(optimizer='adam',
                      loss='binary_crossentropy',
                      metrics=['accuracy'])
        return model

    def predict(self, sequence):
        """
        sequence: shape (seq_length, feature_dim)
                  feature_dim = [x, y, scale_x, scale_y, rotation, opacity, ...]
        """
        predictions = self.model.predict(sequence[np.newaxis, ...])
        return predictions[0]  # shape: (seq_length, 1)

    # 关键帧判定阈值
    KEYFRAME_THRESHOLD = 0.85
```

### 11.5 参数回归模型：从视觉特征回归参数值

```
参数回归模型架构：

[帧特征 (2048-d)] → [MLP 1024] → [BatchNorm] → [Dropout 0.3]
                  → [MLP 512]  → [BatchNorm] → [Dropout 0.3]
                  → [MLP 256]  → [输出头]
                                  ├── 头1：粒子数量（回归）
                                  ├── 头2：粒子速度（回归）
                                  ├── 头3：发光强度（回归）
                                  └── 头4：模糊半径（回归）

训练目标：MSE Loss（回归） + L1 正则
评估指标：MAE、RMSE、R²

预期精度：
  • 粒子数量：MAE ≤ 5%（相对误差）
  • 模糊半径：MAE ≤ 2px
  • 发光强度：MAE ≤ 0.05（归一化）
  • 调色参数：ΔE2000 ≤ 3.0
```

```python
# param_regressor.py - 参数回归（伪代码）
import torch.nn as nn

class ParamRegressor(nn.Module):
    def __init__(self, feature_dim=2048, num_params=8):
        super().__init__()
        self.backbone = nn.Sequential(
            nn.Linear(feature_dim, 1024),
            nn.BatchNorm1d(1024),
            nn.ReLU(),
            nn.Dropout(0.3),
            nn.Linear(1024, 512),
            nn.BatchNorm1d(512),
            nn.ReLU(),
            nn.Dropout(0.3),
            nn.Linear(512, 256),
            nn.ReLU()
        )
        # 多任务输出头
        self.heads = nn.ModuleList([
            nn.Linear(256, 1) for _ in range(num_params)
        ])

    def forward(self, x):
        features = self.backbone(x)
        return [head(features) for head in self.heads]
```

### 12.2 PSNR / SSIM / LPIPS 计算工具与脚本

```python
# metrics.py - 量化指标计算
import numpy as np
import cv2
from skimage.metrics import peak_signal_noise_ratio as psnr
from skimage.metrics import structural_similarity as ssim
# pip install lpips
import lpips

class VideoMetrics:
    """视频量化指标计算"""

    def __init__(self):
        # LPIPS 模型（AlexNet 版本，速度更快）
        self.lpips_model = lpips.LPIPS(net='alex')

    def compute_frame_metrics(self, img_a, img_b):
        """
        img_a, img_b: BGR numpy 数组或图像路径
        返回：PSNR, SSIM, LPIPS
        """
        if isinstance(img_a, str):
            img_a = cv2.imread(img_a)
            img_b = cv2.imread(img_b)
        # PSNR（越高越好，>30dB 为优）
        p = psnr(img_a, img_b, data_range=255)
        # SSIM（越高越好，0-1，>0.9 为优）
        s = ssim(img_a, img_b, channel_axis=2, data_range=255)
        # LPIPS（越低越好，<0.1 为优）
        tensor_a = self._to_tensor(img_a)
        tensor_b = self._to_tensor(img_b)
        l = self.lpips_model(tensor_a, tensor_b).item()
        return {"PSNR": p, "SSIM": s, "LPIPS": l}

    def compute_video_metrics(self, frames_a_dir, frames_b_dir):
        """对齐帧序列批量计算"""
        import glob
        frames_a = sorted(glob.glob(f"{frames_a_dir}/*.png"))
        frames_b = sorted(glob.glob(f"{frames_b_dir}/*.png"))
        assert len(frames_a) == len(frames_b), "帧数不匹配"
        results = []
        for fa, fb in zip(frames_a, frames_b):
            m = self.compute_frame_metrics(fa, fb)
            m["frame"] = fa
            results.append(m)
        return results

    @staticmethod
    def summarize(results):
        """汇总统计"""
        return {
            "PSNR_mean": np.mean([r["PSNR"] for r in results]),
            "PSNR_min":  np.min([r["PSNR"] for r in results]),
            "SSIM_mean": np.mean([r["SSIM"] for r in results]),
            "LPIPS_mean": np.mean([r["LPIPS"] for r in results]),
        }

    def _to_tensor(self, img_bgr):
        """BGR numpy → LPIPS 输入张量"""
        img_rgb = cv2.cvtColor(img_bgr, cv2.COLOR_BGR2RGB)
        tensor = torch.from_numpy(img_rgb).float() / 127.5 - 1.0
        return tensor.permute(2, 0, 1).unsqueeze(0)
```

### 12.3 色彩差异 ΔE2000 批量计算

```python
# delta_e.py - CIEDE2000 色彩差异计算
import numpy as np
from colormath.color_objects import sRGBColor, LabColor
from colormath.color_conversions import convert_color
from colormath.color_diff import delta_e_cie2000

class ColorDifferenceCalculator:
    """批量计算 ΔE2000，用于调色参数验证"""

    @staticmethod
    def rgb_to_lab(rgb):
        """RGB → Lab"""
        srgb = sRGBColor(rgb[0]/255, rgb[1]/255, rgb[2]/255, is_upscaled=False)
        return convert_color(srgb, LabColor)

    def delta_e2000(self, rgb_a, rgb_b):
        """计算两 RGB 颜色的 ΔE2000"""
        lab_a = self.rgb_to_lab(rgb_a)
        lab_b = self.rgb_to_lab(rgb_b)
        return delta_e_cie2000(lab_a, lab_b)

    def batch_delta_e(self, colors_a, colors_b):
        """
        colors_a, colors_b: [(R,G,B), ...]
        返回每对颜色的 ΔE2000
        """
        return [self.delta_e2000(a, b) for a, b in zip(colors_a, colors_b)]

# 验收阈值（CIEDE2000 标准）：
#   ΔE < 1.0  ：人眼几乎无法分辨
#   ΔE < 2.0  ：可接受的商业级差异
#   ΔE < 3.0  ：可接受的专业级差异
#   ΔE < 5.0  ：明显差异，但可识别为同一调色
#   ΔE ≥ 5.0  ：调色失败，需要重新校准
```

### 12.4 运动矢量场的可视化与误差分析

```
运动矢量场（Motion Vector Field）可视化流程：

[原视频帧] ┐
            ├→ [光流计算（Lucas-Kanade / Farneback）] → [矢量场]
[复现帧]   ┘                                            ↓
                                                    [矢量场相减]
                                                        ↓
                                              [误差热力图]

工具选择：
├── OpenCV（推荐）
│   • cv2.calcOpticalFlowFarneback：稠密光流
│   • cv2.goodFeaturesToTrack + cv2.calcOpticalFlowPyrLK：稀疏光流
```

```python
# motion_flow.py - 运动矢量场分析
import cv2, numpy as np

class MotionFlowAnalyzer:
    def compute_flow(self, frame_a, frame_b):
        """计算稠密光流（Farneback 算法）"""
        gray_a = cv2.cvtColor(frame_a, cv2.COLOR_BGR2GRAY)
        gray_b = cv2.cvtColor(frame_b, cv2.COLOR_BGR2GRAY)
        flow = cv2.calcOpticalFlowFarneback(
            gray_a, gray_b, None,
            pyr_scale=0.5, levels=3, winsize=15,
            iterations=3, poly_n=5, poly_sigma=1.2, flags=0
        )
        return flow  # shape: (H, W, 2)

    def visualize(self, flow):
        """可视化光流（HSV 编码）"""
        h, w = flow.shape[:2]
        hsv = np.zeros((h, w, 3), dtype=np.uint8)
        mag, ang = cv2.cartToPolar(flow[..., 0], flow[..., 1])
        hsv[..., 0] = ang * 180 / np.pi / 2
        hsv[..., 1] = 255
        hsv[..., 2] = cv2.normalize(mag, None, 0, 255, cv2.NORM_MINMAX)
        return cv2.cvtColor(hsv, cv2.COLOR_HSV2BGR)

    def flow_difference(self, flow_a, flow_b):
        """两光流场的差异（用于复现验证）"""
        diff = flow_a - flow_b
        magnitude = np.sqrt(diff[..., 0]**2 + diff[..., 1]**2)
        return magnitude  # 误差热力图
```

### 12.5 频谱分析：FFT 在效果识别中的应用

```python
# fft_analysis.py - 频谱分析识别重复模式
import numpy as np
import cv2

class FFTAnalyzer:
    """FFT 频谱分析用于识别：
       - 扫描线（规律性垂直/水平条纹）
       - 噪点颗粒（高频能量分布）
       - RGB 分离（频域偏移）
       - 摩尔纹（规律性干涉条纹）
    """

    @staticmethod
    def compute_spectrum(frame_bgr):
        """计算灰度图的 FFT 频谱"""
        gray = cv2.cvtColor(frame_bgr, cv2.COLOR_BGR2GRAY)
        f = np.fft.fft2(gray)
        f_shift = np.fft.fftshift(f)
        magnitude = 20 * np.log(np.abs(f_shift) + 1)
        return magnitude

    @staticmethod
    def detect_scanlines(frame_bgr):
        """检测扫描线（频域中水平方向的强能量峰）"""
        spectrum = FFTAnalyzer.compute_spectrum(frame_bgr)
        h, w = spectrum.shape
        # 取水平中线附近的能量分布
        vertical_profile = spectrum[h // 2, :]
        # 寻找规律性峰值
        peaks = np.where(vertical_profile > vertical_profile.mean() * 2)[0]
        return len(peaks) > 5  # 强能量峰多于 5 个 → 存在扫描线

    @staticmethod
    def detect_rgb_split(frame_bgr):
        """检测 RGB 通道分离（频域相位偏移）"""
        b, g, r = cv2.split(frame_bgr)
        # 计算各通道的相位差
        f_r = np.fft.fftshift(np.fft.fft2(r.astype(np.float32)))
        f_b = np.fft.fftshift(np.fft.fft2(b.astype(np.float32)))
        phase_diff = np.angle(f_r) - np.angle(f_b)
        return np.std(phase_diff)
```

```
场景：4K 60fps 5 分钟视频
  • 内存占用估算：3840×2160×4byte×60fps×5min ≈ 14.9 TB（不可全内存）

策略：
1. 切片分析（Chunking）
   • 将 5 分钟视频切为 10 个 30 秒片段
   • 每次仅加载一个片段
   • 使用 ffmpeg 切片：
     $ ffmpeg -i input.mp4 -c copy -segment_time 30 -f segment chunk_%03d.mp4

2. 代理预览
   • 创建 1/2 分辨率代理用于实时预览
   • 最终渲染切换回原素材

3. 内存预分配
   • AE Preferences → Memory → 设置 AE 内存上限
   • 推荐：系统内存 - 8GB（系统保留）
   • 32GB 系统：AE 可用 24GB
   • 64GB 系统：AE 可用 56GB

4. 清理缓存
   • Edit → Purge → All Memory & Disk Cache
   • 长时间分析每 30 分钟清理一次

5. 关闭其他 Adobe 应用
   • Photoshop / Premiere / Media Encoder 都占用相同内存池
```

```python
# render_dispatcher.py - 简易渲染分发器（伪代码）
import subprocess, redis, json

class RenderDispatcher:
    def __init__(self, redis_host="localhost"):
        self.redis = redis.Redis(host=redis_host)
        self.queue_name = "render_jobs"

    def submit_job(self, project, comp, frame_range, output_template):
        """提交渲染任务到队列"""
        job = {
            "project": project,
            "comp": comp,
            "frame_range": frame_range,
            "output": output_template
        }
        self.redis.lpush(self.queue_name, json.dumps(job))

    def worker_loop(self, aerender_path):
        """worker 循环：从队列取任务执行"""
        while True:
            _, data = self.redis.brpop(self.queue_name)
            job = json.loads(data)
            cmd = [
                aerender_path,
                "-project", job["project"],
                "-comp", job["comp"],
                "-s", str(job["frame_range"][0]),
                "-e", str(job["frame_range"][1]),
                "-output", job["output"]
            ]
            subprocess.run(cmd, check=True)
```

### 15.2 AE ↔ DaVinci Resolve：调色参数转换

```
DaVinci → AE 调色反推工作流：

1. 在 DaVinci 中分析原视频：
   • Color Page → 节点 1： primaries（色温/对比度）
   • 节点 2：曲线（RGB 曲线、Luma 曲线）
   • 节点 3：qualifier（HSL 选区调整）
   • 节点 4：色彩空间转换
```

### 15.3 AE ↔ Premiere Pro：动态链接与项目交换

```
AE ↔ Premiere 协作方式：

方式 1：Dynamic Link（动态链接，实时同步）
  • Premiere 中右键素材 → Replace with After Effects Composition
  • AE 修改后 Premiere 自动同步
  • 优点：实时同步
  • 缺点：性能消耗大

方式 2：Project Exchange via XML
  • Premiere: File → Export → Final Cut Pro XML
  • AE: File → Import → 选择 XML
  • 优点：轻量、跨版本兼容
  • 缺点：仅传递时间线信息，不传素材

方式 3：AAF（Advanced Authoring Format）
  • 适合复杂多轨项目
  • 保留更多元数据
  • $ ffmpeg -i input.aaf -c copy output.mp4

方式 4：ProRes 中间片
  • Premiere 渲染 ProRes 422 HQ 中间片
  • AE 导入中间片
  • 优点：稳定、高质量
  • 缺点：文件大
```

### 15.4 AE ↔ Nuke：节点式合成工作流对接

```
AE → Nuke 工作流：

1. AE 完成特效合成 → 渲染 EXR 序列（多通道）
   • Render Settings → Output Module → OpenEXR with Alpha
   • 选择 Multichannel EXR（保留 Z、Cryptomatte 等）

2. Nuke 中导入 EXR 序列
   • Read 节点 → 选择 EXR 序列
   • Shuffle 节点分离 RGBA、Z、Cryptomatte
   • 在节点图中合成

Nuke → AE：
  • Nuke 渲染 ProRes 4444（带 Alpha）
  • AE 中直接导入作为图层

工具差异注意：
┌──────────────────┬──────────────────────┬──────────────────────┐
│ 概念              │ AE                   │ Nuke                  │
├──────────────────┼──────────────────────┼──────────────────────┤
│ 合成              │ Composition          │ Comp                  │
│ 图层              │ Layer                │ Node                  │
│ 蒙版              │ Mask                 │ Roto/RotoPaint         │
│ 调整层           │ Adjustment Layer     │ Grade/ColorCorrect    │
│ 预合成           │ Precomp              │ Group/Backdrop        │
│ 表达式           │ Expression (JS)       │ Expression (TCL/Py)   │
│ 追踪             │ Track Motion         │ Tracker/PlanarTracker │
└──────────────────┴──────────────────────┴──────────────────────┘
```

### 15.5 AE ↔ C4D / Blender：3D 元素协同

```
3D ↔ AE 协同方式：

C4D → AE：
  • Cineware（C4D Lite 内嵌 AE）
    • AE 中直接创建/编辑 C4D 文件
    • 修改 C4D 模型/动画 → AE 实时更新
  • Cineware 渲染：在 AE 内调用 C4D 渲染器
  • 多通道输出：用 Multi-Pass 渲染分离 Object Buffer、Z、UV、Normal

Blender → AE：
  • 渲染 EXR 多通道序列 → 导入 AE
  • 用 Cryptomatte 节点分离对象
  • 推荐：Blender 4.x 的 Compositor 与 AE 配合

通用工作流：
  1. 3D 软件中渲染基础动画 → EXR 序列（含 Alpha、Z、Normal）
  2. AE 中合成、特效、调色
  3. 渲染输出 → 跨平台交付
```

### 15.6 跨平台文件格式兼容性

| 格式 | 用途 | 兼容平台 | 备注 |
|------|------|---------|------|
| **XML (FCPXML)** | 时间线交换 | Premiere, FCP, Resolve | 剪辑信息与基础效果 |
| **AAF** | 多轨音频+视频 | Premiere, Pro Tools, Resolve | 保留轨道、音频元数据 |
| **EDL** | 简单时间线 | 全部 | 仅支持单轨、 Cut 决策 |
| **ProRes 422 HQ** | 视频中间片 | 全部（Linux 需解码器） | 高质量、大文件 |
| **ProRes 4444** | 视频+ Alpha | AE, Premiere, Resolve, Nuke | 含透明通道 |
| **DNxHR HQX** | 视频中间片 | Avid, Premiere, Resolve | Windows 友好 |
| **EXR 序列** | 多通道合成 | 全部（HDR 色彩） | 多通道、文件大 |
| **.cube LUT** | 调色查找表 | AE, Resolve, Premiere | 通用 LUT 格式 |
| **.3dl LUT** | 调色查找表 | AE, Resolve | 老式 LUT 格式 |

### 17.2 参数还原表的原子级规范

```
原子级参数还原表规范（Parameter Table Atomic Spec）：

每个参数项必须包含：
  1. layer_id       # 图层唯一 ID
  2. property_path  # 属性路径（如 "Effects.Particular.Emitter.Rate"）
  3. value          # 参数值（带单位）
  4. unit           # 单位（%, px, deg, sec, count, ...）
  5. confidence     # 置信度（0-1）
  6. source         # 参数来源（visual / metric / regression / manual）
  7. tolerance      # 允许误差
  8. verified       # 是否经 QC 验证（bool）

示例（YAML）：
  - layer_id: "L15"
    property_path: "Effects.CC Vignette.Amount"
    value: -60
    unit: "int"
    confidence: 0.95
    source: "visual"
    tolerance: ±5
    verified: true
    qc_reviewer: "QC-002"

  - layer_id: "L17"
    property_path: "Effects.Particular.Emitter.Particles/sec"
    value: 540
    unit: "count"
    confidence: 0.88
    source: "regression"
    tolerance: ±27  # 5%
    verified: true
    qc_reviewer: "QC-002"
```
