## ⚡ 1. 性能革命

### 高性能预览回放 (HPPP) — v25.2

> AE 历史上最大的性能改进！

预览现在**同时使用 RAM 和本地磁盘**，而非仅依赖内存：

- RAM 满时从 NVMe 磁盘无缝流式传输缓存帧
- 即使内存仅 2GB 也能实现不间断全合成回放
- 默认开启：偏好设置 → 媒体与磁盘缓存 → 磁盘缓存

**硬件策略变更：**
```
旧思维：最大化 RAM（128GB+）
新思维：充足 RAM（64-96GB）+ 超大快速 NVMe（4TB+ PCIe Gen4/5）
```

> 来源：Puget Systems 深度评测

## 🎯 2. 3D 工作流（重大变革）

### 动画环境光 — v25.2

此前环境光只能用**静态** HDR/EXR 图像。现在可以使用：
- ✅ 视频
- ✅ 图像序列
- ✅ 预合成
- ✅ 任意图层

3D 模型会随时间对变化光源动态响应，产生逼真的反射和颜色变化。

> 访问：高级 3D 合成 → 图层 → 灯光 → 从所选图层创建环境光背景图层

### 原生 FBX 导入 — v25.2

终于原生支持 FBX！解锁 TurboSquid、CGTrader、Mixamo 等平台的百万级 3D 模型。

**当前支持的 3D 格式：** GLB / GLTF / OBJ / FBX

### 多图层 3D Gizmo — v25.6

选中多个 3D 图层，用**单一统一 gizmo** 同时移动/缩放/旋转，大大简化复杂场景管理。

### 阴影捕获器 — v25.2

透明实体，**只接收阴影但隐藏其余内容**。将 3D 对象放入实景镜头无需第三方插件。

### Parametric 网格工具 — 26.0 Beta

直接在 AE 中创建 3D 基本体（球体/立方体/圆锥体/圆柱体），形状和材质支持关键帧——相当于"3D 的形状图层"。

### Substance 3D 材质 (.sbsar) — 26.0 Beta

支持动态可调整的基于物理的材质，数千种免费材质可从 Substance 社区获取。

### 其他 3D 改进

| 功能 | 版本 | 说明 |
|------|------|------|
| 属性面板 3D 动画控制 | 25.2 | 光照/阴影/嵌入动画直接控制 |
| 一键 3D 辅助命令 | 25.2 | 创建3D实例/摄像机控制灯光/环境光可视化 |
| 默认摄像机设置 | 25.6 | 自定义默认摄像机参数 |

## 📝 3. 文本引擎升级

### 逐字文本样式表达式 — v25.0

通过表达式对**每个单独字符**进行样式控制！之前只能设置整个图层的样式，现在可以逐字指定字体、大小、颜色。

```javascript
// 示例：前5个字符红色，其余蓝色
text.sourceText.style
  .setFillColor([1,0,0,1], 0, 5)
  .setFillColor([0,0,1,1], 5);
```

**支持的方法：** setFontSize / setFont / setFauxBold / setFauxItalic / setAllCaps / setSmallCaps / setTracking / setLeading / setBaselineShift / setFillColor / setStrokeColor / setStrokeWidth

> 需要 JavaScript 表达式引擎

### 段落样式表达式 — v25.0

14 个新段落级属性：direction、justification、leadingType、leftMargin、rightMargin、spaceAfter、spaceBefore 等。

## 🎬 4. 图层与关键帧工作流

### 快速偏移 — v25.4

均匀错开选中图层或关键帧：

- **Windows：** `Ctrl + Alt + 拖动`
- **Mac：** `Command + Option + 拖动`
- 显示总偏移和每层偏移的时间指示

### 粘贴反转关键帧 — v25.4

复制关键帧并以**相反顺序**粘贴——完美创建与入场对称的出场动画。

### 位置属性的 Null 控制器 — v25.2

从任意位置属性创建独立 Null 控制器：

| 来源 | 可控制对象 |
|------|-----------|
| 形状图层 | 渐变点、形状组位置 |
| Puppet 图钉 | 基本+高级图钉（含旋转缩放） |
| 效果点 | 镜头光晕、粒子发射器、光束 |
| 摄像机 | 兴趣点 |
| 灯光 | 光斑链接到点光源 |

## 🧩 7. 新效果

### Unmult 键控效果 — 26.0 Beta

专为 VFX 合成素材（火焰/烟雾/漏光/爆炸）设计的新型键控器，智能移除纯黑/白色背景，保留前景细节和颜色。支持 8/16/32 bpc。

直接导入 SVG 为原生可编辑矢量形状图层，无需栅格化。
