## 一、逆向分析的核心思维框架

> [!important] 核心章节
> 本章是整个逆向分析体系的思维基础，三问分析法和分层拆解原则是所有后续分析工作的出发点。掌握这两个核心思维工具，才能在面对复杂视频效果时保持清晰的分析思路。

### 1.1 三问分析法

拿到一个视频，按顺序问三个问题：

```
Q1: 我看到了什么？（视觉层）
    → 颜色、运动、形状、纹理、光效、文字

Q2: 它是怎么做到的？（技术层）
    → 哪个效果类？哪个插件？什么参数方向？

Q3: 参数是多少？（量化层）
    → 具体数值、关键帧位置、缓动曲线类型
```

### 1.2 分层拆解原则

不要试图一次性分析整个视频，而是**逐层剥离**：

```
┌─────────────────────────────────┐
│  第1层：全局调色与风格化        │ ← 调整层 / LUT / 胶片颗粒
├─────────────────────────────────┤
│  第2层：转场与过渡              │ ← 缩放/位移/遮罩/光效转场
├─────────────────────────────────┤
│  第3层：主体动画                │ ← 关键帧驱动的运动/缩放/旋转
├─────────────────────────────────┤
│  第4层：特效叠加                │ ← 粒子/辉光/光晕/模糊
├─────────────────────────────────┤
│  第5层：文字与图形              │ ← 文字动画/形状层/预设
├─────────────────────────────────┤
│  第6层：3D空间与摄像机          │ ← 摄像机运动/景深/视差
├─────────────────────────────────┤
│  第7层：音频驱动                │ ← 节拍对齐/音频振幅联动
└─────────────────────────────────┘
```

### 1.3 分析工具链

| 工具 | 用途 | 操作 |
|------|------|------|
| **VLC / PotPlayer** | 逐帧回放 | 按 `E` 逐帧前进，`F` 快速切换 |
| **AE 自身** | 导入视频逐帧参考 | 拖入时间轴，步进帧检查 |
| **截图对比** | 效果前后对比 | 关键帧前后截图并排分析 |
| **色值采样** | 提取颜色参数 | 吸管工具取色，记录 HEX/RGB |
| **音频波形** | 节拍分析 | 展开音频波形，数节拍间隔 |
| **参考叠加** | 半透明叠加对比 | 原视频在上层50%透明度，与你的复现对比 |

## 二、逐帧观察法（Frame-by-Frame Analysis）

### 2.1 关键帧识别

对话中切换到关键帧的前后帧，观察以下变化：

| 变化的属性 | 如何识别 | 对应 AE 属性 |
|-----------|---------|-------------|
| 物体变大/变小 | 边缘向外/向内移动 | Scale |
| 物体整体移动 | 所有像素同向偏移 | Position |
| 物体旋转 | 像素绕中心旋转 | Rotation |
| 逐渐出现/消失 | 像素透明度变化 | Opacity |
| 边缘模糊 | 像素边界变柔和 | Blur / Motion Blur |
| 颜色变化 | 整体/局部色相偏移 | Color Correction |
| 形状变形 | 轮廓改变 | Distort / Mesh Warp |

### 2.2 运动速度判断

逐帧追踪一个特征点（如文字的一角、物体的边缘）：

```
帧间位移量 → 速度曲线
─────────────────────────
位移递增 → 加速中（Ease In）
位移递减 → 减速中（Ease Out）
位移恒定 → 匀速（Linear）
位移归零 → 停止
位移反向 → 回弹/Overshoot
```

### 2.3 时长量化

| 你要分析 | 方法 |
|---------|------|
| 转场时长 | 从画面A最后清晰帧 → 画面B第一清晰帧，数帧数 |
| 文字出入场时长 | 从文字开始出现 → 完全到位，数帧数 |
| 速度变化时机 | 观察运动速度改变的帧，标记时间点 |
| 节拍间隔 | 展开音频波形，两个峰值之间的帧数 |

## 三、效果分类推断矩阵

> [!important] 核心章节
> 本章是逆向分析的"速查表"，建立了从视觉现象到效果插件的快速映射。无论是新手还是老手，遇到不确定的效果时都应先查阅此矩阵。按视觉现象反查效果 + 按风格反查效果组合，两种路径可覆盖绝大多数视频效果的快速识别。

### 3.1 按视觉现象反查效果

| 你看到的 | 最可能的效果/插件 | 参数方向 |
|---------|-----------------|---------|
| 画面边缘变暗 | CC Vignette / Lumetri Vignette / S_Vignette | Amount: 负值，Angle of View: 范围 |

| 物体边缘发光 | Glow / Deep Glow / S_Glow / Layer Style | Intensity、Radius、Threshold |
| 颜色通道错位 | Channel Blur / Set Channels / RGB Shift | 红/绿/蓝通道分别偏移 |
| 像素块状化 | CC Block Load / Mosaic | Block Size、Completion |
| 画面扭曲/波浪 | 湍流置换 / Wave Warp / CC Glass | Amount、Size、Evolution |
| 粒子飘散 | Particular / CC Particle World / Particle Playground | 发射器类型、速度、生命周期 |
| 光柱/体积光 | CC Light Rays / Shine / S_EdgeRays | Intensity、Ray Length、Angle |
| 镜头光晕 | Lens Flare / Optical Flares / CC Lens | Flare Brightness、Position |
| 扫描线/CRT | CC Grid + 叠加 / PX-CRT / Universe VHS | 线条间距、混合模式 |
| 画面抖动 | wiggle() 表达式 / Turbulent Displace / S_Shake | 频率、振幅 |
| 快速模糊过渡 | Directional Blur / CC Radial Blur | 方向、长度、关键帧 |

| 画面撕裂 | Displacement Map + 噪点贴图 | 位移量、贴图对比度 |
| 频闪 | 隔帧透明度 0/100 切换 | 间隔帧数、占空比 |

### 3.2 按风格反查效果组合

| 风格 | 必查效果路径 | 调色方向 |
|------|------------|---------|
| 赛博朋克 | CRT扫描线 → RGB分离 → 霓虹发光 → 频闪故障 | 阴影青蓝，高光品红 |
| 复古VHS | Channel Blur颜色偏移 → 扫描线 → 胶片颗粒 → 色温偏暖 | 饱和度-15~25%，暖色底色 |
| 故障艺术 | RGB通道分离 → 方块遮罩 → 像素撕裂 → 隔帧切换 | 高对比度，冷色偏色 |
| 电影感 | 暗角 → 柔焦 → 胶片颗粒 → LUT调色 | 橙青调/褪色复古 |
| 梦幻柔焦 | 高斯模糊 → 混合模式滤色/柔光 → 低不透明度 | 低对比度，暖色 |
| 科技HUD | 描边+发光 → CC Light Sweep → 网格叠加 → RGB偏移 | 青色/蓝色，暗背景 |

## 四、参数量化推断法

> [!note] 进阶章节
> 本章从定性分析进入定量分析阶段，提供了精确还原参数的数学方法。掌握本章内容可以将参数推断的误差从"大概方向"缩小到"±5-10%的精确值"，是从"看起来像"到"精确复现"的关键一步。

### 4.1 缩放参数推断

```
方法：找到画面中一个已知尺寸的参照物

例如：画面中有一个圆形，原始直径100px，当前直径150px
→ Scale = 150/100 = 150%

如果物体在画面中的占比从30%变到60%：
→ Scale 变化 = 60%/30% = 200%
```

### 4.2 位置参数推断

```
方法：以画面中心为原点 (960, 540)，追踪特征点位移

帧1: 物体中心在 (960, 540)
帧5: 物体中心在 (1200, 540)
→ Position X 偏移 = +240px

帧1: 物体中心在 (960, 540)
帧10: 物体中心在 (960, 300)
→ Position Y 偏移 = -240px
```

### 4.3 旋转参数推断

```
方法：追踪物体上的一个特征点，计算连线角度变化

帧1: 角度 = 0°
帧10: 角度 = 15°
→ Rotation = 15°（顺时针）

如果10帧转15°，30fps项目：
→ 角速度 = 15°/(10/30) = 45°/秒
```

### 4.4 透明度参数推断

```
方法：在物体与背景交界处采样颜色值

已知：物体颜色 = RGB(255, 255, 255)，背景颜色 = RGB(0, 0, 0)
采样点颜色 = RGB(128, 128, 128)
→ Opacity ≈ 50%（线性混合）

实际更精确的方法：
→ 对比物体区域与背景区域的颜色差异
→ 或直接用吸管工具在AE中对比
```

### 4.5 模糊参数推断

```
方法：找到画面中的清晰边缘，观察模糊扩散范围

边缘从清晰变模糊，模糊扩散约5px半径
→ Gaussian Blur ≈ 5px

定向模糊的角度 → 观察像素拖尾方向
→ Directional Blur Angle = 拖尾方向

径向模糊 → 观察模糊是否从中心向外辐射
→ CC Radial Blur / Radial Blur
```

## 五、逐帧对比复现法

### 5.1 叠加对比技术

```
1. 将原视频导入AE作为顶层
2. 不透明度设为 50%
3. 在下方建立你的复现合成
4. 逐帧对比，微调参数直到完全重合
5. 切换顶层可见性做 A/B 对比
```

### 5.2 差异分析法

```
原视频截图 vs 你的复现截图：
├── 位置不对 → 调整 Position 关键帧
├── 大小不对 → 调整 Scale 数值
├── 时机不对 → 移动关键帧位置
├── 颜色不对 → 调整调色参数
├── 模糊度不对 → 调整 Blur 数值
└── 运动曲线不对 → 调整 Graph Editor 手柄
```

### 5.3 复现精度检查清单

- [ ] 关键帧的时间位置与原视频一致（误差 ≤ 1帧）
- [ ] 运动曲线的形状匹配（加速/减速时机一致）
- [ ] 颜色在吸管取样下偏差 ≤ 5%
- [ ] 效果参数产生的视觉效果肉眼无法区分
- [ ] 转场时长的帧数完全一致
- [ ] 如果有音频联动，节拍对齐点一致

## 八、逆向分析速查流程

```
① 导入视频 → 全片预览 → 标记节点
   ├── 标记所有转场时间点
   ├── 标记所有文字出入场
   ├── 标记速度变化点
   └── 标记特效时间点

② 逐段分析（从简单到复杂）
   ├── 先分析调色 → 最外层
   ├── 再分析转场 → 过渡层
   ├── 再分析主体 → 动画层
   ├── 再分析特效 → 叠加层

③ 逐帧比对关键帧
   ├── 找出每个关键帧的精确帧号

   └── 判断缓动曲线类型

④ 分层复现
   ├── 先建调整层做调色
   ├── 再建空对象做运镜
   ├── 再建素材层做动画
   ├── 再叠加特效层
   └── 最后加文字层

⑤ 叠加校验
   ├── 原视频 50% 透明度叠加
   ├── 逐帧对比差异
   └── 微调参数直到重合
```

## 九、逆向分析的数学基础

> 本章为逆向分析建立严格的数学底层。前八章描述的是"怎么做"，本章回答"为什么这样做才严谨"。所有量化推断（详见第四章《参数量化推断法》）均可在本章找到数学依据。

### 9.1 信号处理理论：奈奎斯特-香农采样定理在帧率分析中的应用

**理论基础**

奈奎斯特-香农采样定理（Nyquist-Shannon Sampling Theorem）指出：要从采样信号中无失真地重建原始连续信号，采样频率必须至少为原始信号最高频率的两倍：

```
fs ≥ 2 · fmax
```

其中：
- `fs`：采样频率（视频中的帧率，如 24/25/30/60/120 fps）
- `fmax`：原始信号的最高频率分量（画面中变化最快的运动/闪烁）

**视频分析中的物理意义**

视频本质上是二维空间信号在时间轴上的离散采样。一个运动物体在画面中以速度 `v`（px/秒）移动，其在空间上产生的"时间频率"为：

```
f_temporal = v / λ_feature
```

其中 `λ_feature` 为该物体的空间特征尺寸（如文字笔画的宽度、物体的边缘锐度）。

**实战推论：识别原项目帧率**

当一个快节奏视频中观察到以下现象时，可反推项目帧率：

| 观察到的现象 | 推论 | 数学依据 |
|------------|------|---------|
| 高速运动出现"阶梯状"锯齿 | 帧率不足，存在混叠（Aliasing） | `fs < 2·fmax` |
| 转场在单帧内完成（无中间过渡） | 帧率≥30fps，且转场时长=1帧 | 时间分辨率=1/fs |
| 慢动作流畅无插帧痕迹 | 拍摄帧率≥120fps，再以30fps播放 | 采样率远超奈奎斯特频率 |
| 频闪效果在每3帧出现一次 | 项目帧率30fps，频闪周期=3帧=0.1秒 | 离散事件周期=3/fs |

**案例**：某AMV中的拉镜在5帧内完成1920px位移，速度 `v = 1920 × 30 / 5 = 11520 px/s`。若文字笔画宽度仅2px，则 `fmax = 11520/2 = 5760 Hz`，远超30fps的奈奎斯特频率15Hz。结论：必然启用了运动模糊（Motion Blur），否则画面会出现严重混叠。这与第三章3.1表中"运动模糊"项的判定一致。

### 9.2 频域分析：傅里叶变换识别周期性动画

**理论基础**

任何周期性信号 `f(t)` 都可分解为一系列正弦/余弦波的叠加：

```
f(t) = Σ [an · cos(n·ω·t) + bn · sin(n·ω·t)]
```

通过快速傅里叶变换（FFT），可从时域信号 `f(t)` 转换为频域表示 `F(ω)`：

```
F(ω) = ∫ f(t) · e^(-iωt) dt
```

**应用于逆向分析**

在AE中，许多动画具有周期性：
- `wiggle(frequency, amplitude)` 表达式 → 纯周期信号
- 循环动画（Loop）→ 离散频谱
- 节拍驱动的关键帧 → 准周期信号
- 抖动/Turbulent Displace → 宽带噪声 + 周期分量

**操作流程**

1. 在视频某特征点（如文字中心）提取其位置序列 `x[n], y[n]`，`n = 0, 1, ..., N-1`
2. 对 `x[n]` 执行FFT，得到幅度谱 `|X(k)|`
3. 寻找谱峰位置 `k_peak`，对应频率 `f_peak = k_peak · fs / N`
4. 若 `f_peak` 恰为整数（如2Hz、3Hz），则高度疑似 `wiggle()` 表达式

**案例：识别wiggle表达式参数**

某文字标题在静止时持续轻微抖动，采样200帧位置数据，FFT后谱峰在 `k=10`，则：

```
频率 = 10 × 30 / 200 = 1.5 Hz
振幅 = 2·|X(10)| / N ≈ 实际抖动幅度
```

→ 推断 wiggle 表达式为 `wiggle(1.5, amp)`。这与第二章2.2的运动速度判断方法形成补充：当运动是周期性的，频域分析比逐帧测量更精准。

### 9.3 信息论：从视频流信息熵推断效果复杂度

**理论基础**

香农信息熵（Shannon Entropy）衡量信号的不确定度：

```
H(X) = -Σ p(x) · log2 p(x)
```

单位为比特（bits）。熵越高，信息量越大，画面越"复杂"。

**视频帧的空间熵**

将每一帧划分为像素块（如8×8），统计像素值的直方图分布，计算空间熵：

```
H_frame = -Σ p(I) · log2 p(I)
```

其中 `p(I)` 为灰度级 `I` 的出现概率。

**应用：效果复杂度量化**

| 效果类型 | 熵的变化 | 解读 |
|---------|---------|------|
| 均匀调色（LUT） | 熵几乎不变 | 仅映射像素值，分布形状不变 |
| 高斯模糊 | 熵显著降低 | 像素值趋于均值，分布变窄 |
| 噪点/胶片颗粒 | 熵显著升高 | 引入随机性，分布变宽 |
| 像素块化（Mosaic） | 熵先降后平 | 块内像素同质化 |
| 置换/扭曲 | 熵几乎不变 | 仅重排像素位置，分布不变 |

**案例**：分析某段视频，第3秒处熵从7.2 bits突降至4.1 bits，3.5秒后回升至6.8 bits。推论：3秒处启用模糊入场，3.5秒后模糊淡出。这与第四章4.5的模糊参数推断法可交叉验证：模糊扩散范围对应熵降幅度。

### 9.4 概率推断：贝叶斯推断在多效果叠加场景的参数还原

**理论基础**

贝叶斯定理（Bayes' Theorem）：

```
P(θ|D) = P(D|θ) · P(θ) / P(D)
```

- `P(θ)`：先验概率（基于经验，如"赛博朋克视频RGB分离幅度通常5-15px"）
- `P(D|θ)`：似然函数（在参数θ下，观测到画面数据D的概率）
- `P(θ|D)`：后验概率（看到数据后，参数θ的真实概率）

**应用于参数还原**

当多个效果叠加时，观测画面是各效果参数的复合函数：

```
D_observed = f1(θ1) ∘ f2(θ2) ∘ ... ∘ fn(θn)
```

无法直接反解单个参数。此时采用**最大后验估计（MAP）**：

```
θ̂_MAP = argmax_θ [ P(D|θ) · P(θ) ]
```

**操作步骤**

1. 建立参数先验分布（参考《参数-效果原子级映射库》的典型值范围）
2. 对每个候选参数组合，计算合成画面的预测值
3. 比较预测值与观测画面的残差
4. 选取残差最小且先验概率最大的参数组合

**案例**：某赛博朋克场景观察到的画面中，红色通道右移了约8px。先验：RGB分离幅度通常为5、8、10、12、15px（先验概率分别为0.15, 0.30, 0.25, 0.20, 0.10）。结合模糊程度的似然函数计算，后验概率最高的是8px。这就是贝叶斯推断在参数还原中的实际应用。

### 9.5 矩阵运算：颜色矩阵变换的逆向计算

**理论基础**

线性颜色变换可用3×3矩阵表示：

```
| R' |   | a11 a12 a13 |   | R |
| G' | = | a21 a22 a23 | · | G |
| B' |   | a31 a32 a33 |   | B |
```

常见颜色矩阵：
- 亮度/对比度：对角矩阵 `diag(c, c, c) + offset`
- 色相旋转：3D旋转矩阵 `R_hue(θ)`
- 饱和度：`S·I + (1-S)·L`，L为亮度投影矩阵

**逆向计算**

若有至少3个已知对应像素（原色 → 改色），可列出9元线性方程组，解出矩阵元素：

```
[R'_1]                    [R_1]
[G'_1]   = M   ·          [G_1]
[B'_1]                    [B_1]
...（至少3组）...
```

使用伪逆求解：`M = (A^T A)^(-1) A^T B`

**案例**：某视频调色前后，3个采样点：
- (255, 0, 0) → (240, 20, 30)
- (0, 255, 0) → (10, 245, 5)
- (0, 0, 255) → (5, 0, 250)

解出矩阵后可判断为"轻微暖偏+低饱和"，对应 Lumetri Color 的色温+5、饱和度-8。这与第六章6.1的参数表生成流程衔接：矩阵反解后可直接填入Lumetri参数。

## 十、视觉感知与认知科学

> 视频效果最终作用于人眼。本章从视觉感知与认知科学出发，建立"画面→视觉系统→认知判断"的完整链路，为逆向分析提供感知依据。交叉引用第一章《逆向分析的核心思维框架》中的"Q1：我看到了什么"。

### 10.1 人眼视觉系统（HVS）模型：对比敏感度函数（CSF）

**理论基础**

人眼对不同空间频率的对比度敏感度不同，由对比敏感度函数（Contrast Sensitivity Function, CSF）描述。Daly模型简化形式：

```
CSF(f) = a · f^c · exp(-b · f)
```

其中 `f` 为空间频率（cycles/degree），`a, b, c` 为模型参数（典型值 a=100, b=0.114, c=0.1）。

**关键特性**

- 中频段（约2-10 cycles/degree）最敏感 → 文字、轮廓、人脸
- 高频段（>30 cycles/degree）敏感度急剧下降 → 极细微纹理、噪点
- 低频段（<1 cycle/degree）敏感度也下降 → 大面积均匀区域

**逆向分析应用**

| 效果类型 | 主要频段 | 感知影响 | 逆向策略 |
|---------|---------|---------|---------|
| 胶片颗粒 | 高频 | 即使数值大，感知也弱 | 忽略细节，关注整体风格 |
| 暗角 | 低频 | 边缘渐变感知敏锐 | 精确量化Amount和Feather |
| 文字描边 | 中频 | 感知最敏感 | 参数误差容忍度≤2% |
| 微弱噪点 | 高频 | 阈值附近难辨 | 不必还原，标"近似"即可 |

**案例**：某视频添加了高斯模糊5px。从CSF曲线看，5px模糊对应的空间频率约为0.2 cycles/px（在1080p下约2 cycles/degree），正位于CSF峰值附近，故人眼对这一模糊极为敏感。这意味着复现时模糊参数误差必须≤0.5px，否则可识别。

### 10.2 韦伯-费希纳定律：亮度感知对数关系

**理论基础**

韦伯定律（Weber's Law）：能被察觉的最小刺激变化与刺激强度成正比：

```
ΔI / I = k  （韦伯分数，亮度k≈0.02-0.08）
```

费希纳定律（Fechner's Law）：感知强度与物理刺激的对数成正比：

```
S = k · log(I / I_0)
```

**视频分析中的体现**

- 暗部细节：亮度10→15（Δ=5），人眼明显感知变化
- 亮部细节：亮度200→205（Δ=5），人眼几乎察觉不到
- 故暗部参数必须精确量化，亮部可放宽

**实战推论**

| 亮度区间 | 韦伯分数 | 参数精度要求 |
|---------|---------|-------------|
| 0-32（暗部） | 0.08 | ±1级 |
| 33-128（中调） | 0.04 | ±3级 |
| 129-255（高光） | 0.02 | ±5级 |

**案例**：分析某电影感调色，阴影区RGB(15,18,20)。当复现参数为RGB(18,21,23)时，ΔI/I≈20%，远超韦伯分数0.08，人眼能明显察觉差异。故阴影部分必须精确到±1级。这与第五章5.3"复现精度检查清单"中"颜色在吸管取样下偏差≤5%"形成补充：暗部应更严格到±1级。

### 10.3 颜色空间转换：XYZ Lab LCH 对逆向推断的影响

**理论基础**

常见颜色空间层级：
- **CIEXYZ**：基于人眼三种视锥细胞，与设备无关
- **CIELAB**：通过 XYZ 非线性变换得到感知均匀空间
- **LCH（Lab的极坐标）**：L=亮度，C=饱和度，H=色相

转换关系：
```
L = 116 · f(Y/Yn) - 16
a = 500 · [f(X/Xn) - f(Y/Yn)]
b = 200 · [f(Y/Yn) - f(Z/Zn)]
```
其中 `f(t) = t^(1/3)` 当 `t > 0.008856`，否则 `f(t) = 7.787·t + 16/116`

**逆向推断中的影响**

不同颜色空间下，"颜色差异"的度量完全不同：

| 颜色空间 | 色差公式 | 适用场景 |
|---------|---------|---------|
| RGB | ΔR+ΔG+ΔB | 粗略估算 |
| XYZ | ΔX²+ΔY²+ΔZ² | 设备相关，不推荐 |
| Lab | ΔE_ab = √(ΔL²+Δa²+Δb²) | 感知均匀，标准做法 |
| LCH | ΔH, ΔC, ΔL分离 | 调色参数分离推断 |

**实战流程**

1. 在AE/Lumetri中取样原视频颜色 → 得到RGB
2. 转换至Lab → 计算与基线（如sRGB D65白点）的ΔE
3. ΔE > 3：人眼可辨识差异；ΔE > 6：明显差异；ΔE > 12：完全不同调色
4. 在LCH中分离：ΔL → 亮度调整、ΔC → 饱和度调整、ΔH → 色相调整
5. 直接对应到 Lumetri Color 各项参数

**案例**：某品牌广告主色调应为 Pantone 186C（RGB: 200,16,46），视频中实际采样得到 RGB(195,22,52)。转Lab后：
- 基线：L=46, a=68, b=42
- 实测：L=44, a=64, b=40
- ΔE = √(4+16+4) = √24 ≈ 4.9
- 拆解：ΔL=-2（亮度略低）、Δa=-4（饱和度略低）、Δb=-2（色相微偏蓝）

→ 建议Lumetri：亮度-2、饱和度-4、色相-1°。详见第十四章14.2"广告级分析：品牌还原的色卡比对流程"。

### 10.4 视觉注意力模型：从眼动追踪推断画面焦点

**理论基础**

视觉显著性模型（Visual Saliency Model）预测人眼视线落点：
- 低层特征：亮度、颜色、运动、方向的对比
- 高层特征：人脸、文字、物体轮廓
- Itti-Koch模型：多尺度特征图融合 → 显著性图（Saliency Map）

数学化：每个像素的显著性 `S(p) = Σ w_i · F_i(p)`，其中 `F_i` 为第i个特征通道的对比图。

**逆向分析应用**

若无法做眼动追踪，可通过显著性模型反推创作者的视觉引导意图：

| 显著性高 → | 推断创作者意图 | 对应AE操作 |
|------------|-------------|-----------|
| 暗角暗化边缘 | 引导中心聚焦 | CC Vignette Amount<0 |
| 主体高对比 | 突出主体 | Curves对比度提升 |
| 运动物体高速 | 引导追踪运动 | Motion Blur 强度匹配 |
| 文字高亮发光 | 强制视觉锚点 | Glow + 高饱和 |

**案例**：分析某广告片，开篇0.5秒为大面积黑场+中央白色Logo。显著性模型预测视线100%集中于Logo。复现时，必须保证Logo的Glow Radius≥20px、Glow Intensity≥2.0，否则显著性不足。这与第十四章14.2的品牌还原流程关联。

### 10.5 格式塔原理：画面分组识别图层结构

**理论基础**

格式塔心理学（Gestalt Psychology）的视觉分组原则：
1. **接近性（Proximity）**：相邻元素视为一组
2. **相似性（Similarity）**：相似元素视为一组
3. **连续性（Continuity）**：沿光滑曲线分组
4. **闭合性（Closure）**：倾向闭合未完成形状
5. **共同命运（Common Fate）**：同向运动的元素为一组
6. **主体-背景（Figure-Ground）**：自动区分主体与背景

**逆向分析应用：识别图层结构**

| 格式塔原则 | 推断的图层关系 | AE中的对应 |
|-----------|-------------|----------|
| 共同命运 | 多个元素同步运动 → 同一父级 | 共享Null Object作为Parent |
| 相似性 | 颜色/形状相似的元素 → 同一预合成 | Pre-comp打包 |
| 接近性 | 空间相邻的UI元素 → 同一组 | 形状层组/Group |
| 连续性 | 沿路径排列的元素 → 路径动画 | Path文本/Motion Path |
| 主体-背景 | 高对比区域为主体 | 调整层主体优化 |

**案例**：分析某科技HUD界面，发现6个图标同步呼吸缩放。由"共同命运"原则推断：6个图标绑定同一Null Object，Scale属性由表达式 `amp=2; freq=1; S=transform.scale[0]; S+[amp*Math.sin(freq*time*2*Math.PI), amp*Math.sin(freq*time*2*Math.PI)]` 驱动。这就是第一章1.2分层拆解中的"第5层：文字与图形"的具体识别方法。

## 十一、自动化逆向分析框架

> 前十章以人工分析为主。本章构建从"导入视频"到"输出参数表"的自动化流水线，将逆向分析从"经验艺术"提升为"工程科学"。与第八章《逆向分析速查流程》的人工步骤形成对照：自动化版本可逐项替换。

### 11.1 像素差异分析算法：前后帧差分提取运动区域

**算法基础**

帧差分（Frame Differencing）：

```
D_n(x,y) = | I_n(x,y) - I_{n-1}(x,y) |
```

其中 `I_n(x,y)` 为第n帧在坐标 `(x,y)` 的像素值。

二值化阈值化：
```
M_n(x,y) = 1, 若 D_n(x,y) > T
         = 0, 否则
```

阈值T的选取：通常取 Otsu 自适应阈值，或固定为亮度范围的5-10%。

**多帧差分累积**

为提高鲁棒性，使用累积差分图像（Accumulative Difference Image, ADI）：

```
ADI_n = Σ_{k=1}^{n} w_k · D_k
```

`w_k` 为衰减权重（如 `0.9^k`）。

**应用：自动检测转场/动画时机**

```python
def detect_transitions(video, threshold=15):
    """检测视频中的转场/动画时机点"""
    transitions = []
    prev_frame = video.get_frame(0)
    for i in range(1, video.frame_count):
        curr_frame = video.get_frame(i)
        diff = np.abs(curr_frame.astype(int) - prev_frame.astype(int))
        diff_ratio = np.mean(diff > threshold)
        if diff_ratio > 0.3:  # 30%以上像素变化 → 转场
            transitions.append({
                'frame': i,
                'time': i / video.fps,
                'change_ratio': diff_ratio
            })
        prev_frame = curr_frame
    return transitions
```

输出：转场时间点列表，对应第二章2.3的转场时长量化方法，但自动化。

**局部运动区域提取**

对差分图 `D_n`，使用形态学操作去除噪点：
```
开运算（先腐蚀后膨胀） → 去除孤立点
闭运算（先膨胀后腐蚀） → 连接相邻区域
```

最终得到运动区域Mask，用于：
- 识别主体位置 → 对应Position关键帧
- 识别运动方向 → 对应Motion Blur方向
- 识别变形区域 → 对应Distort/Mesh Warp

### 11.2 光流法：LK光流/Kronecker光流反推运动参数

**理论基础**

光流（Optical Flow）描述相邻帧间像素的运动场 `(u, v)`。

Lucas-Kanade（LK）光流假设：
1. 亮度恒定：`I(x+u, y+v, t+1) = I(x, y, t)`
2. 邻域运动一致：小窗口内 `(u, v)` 相同
3. 运动较小：`u, v` 足够小，可线性化

最小二乘解：
```
| u |   1   | Σ I_x²   Σ I_x I_y |^-1  | Σ I_x I_t |
| v | = --- | Σ I_x I_y  Σ I_y²  |     | Σ I_y I_t |
        N
```

**全局运动参数反推**

若整个画面整体运动（即Position/Scale/Rotation），可用仿射模型拟合光流场：

```
u(x,y) = a1 + a2·x + a3·y
v(x,y) = a4 + a5·x + a6·y
```

通过最小二乘求解 `a1...a6`：
- `a1` → Position X偏移
- `a4` → Position Y偏移
- `a2, a6` → Scale变化
- `a3, a5` → Rotation角度

**伪代码实现**

```python
def estimate_global_motion(prev_frame, curr_frame):
    """反推Position/Scale/Rotation"""
    # 1. 计算稠密光流
    flow = cv2.calcOpticalFlowFarneback(
        prev_frame, curr_frame, None,
        pyr_scale=0.5, levels=3, winsize=15,
        iterations=3, poly_n=5, poly_sigma=1.2, flags=0
    )
    
    # 2. 提取特征点
    u = flow[:,:,0].flatten()
    v = flow[:,:,1].flatten()
    x, y = np.meshgrid(range(W), range(H))
    x, y = x.flatten(), y.flatten()
    
    # 3. 仿射模型最小二乘拟合
    A = np.column_stack([np.ones_like(x), x, y])
    sol_u = np.linalg.lstsq(A, u, rcond=None)[0]
    sol_v = np.linalg.lstsq(A, v, rcond=None)[0]
    
    # 4. 转换为AE参数
    position = (sol_u[0], sol_v[0])
    scale_x = sol_u[1] + 1  # 缩放因子
    scale_y = sol_v[2] + 1
    rotation = (sol_u[2] - sol_v[1]) / 2  # 旋转分量
    return position, scale_x, scale_y, rotation
```

输出：每帧的Position/Scale/Rotation，直接对应第四章4.1-4.3的参数推断，但精度更高、批量更快。

### 11.3 频谱分析：FFT提取周期性效果参数

**理论基础**

详见第9.2节。这里给出工程实现。

**频谱提取流程**

```python
def extract_periodic_params(video, feature_point):
    """从特征点位置序列提取周期性参数"""
    # 1. 跟踪特征点
    positions = track_feature(video, feature_point)
    x = [p[0] for p in positions]
    y = [p[1] for p in positions]
    
    # 2. FFT
    X = np.fft.fft(x - np.mean(x))
    Y = np.fft.fft(y - np.mean(y))
    freqs = np.fft.fftfreq(len(x), d=1/video.fps)
    
    # 3. 找谱峰
    peak_x_idx = np.argmax(np.abs(X))
    peak_y_idx = np.argmax(np.abs(Y))
    
    freq_x = abs(freqs[peak_x_idx])
    amp_x = 2 * np.abs(X[peak_x_idx]) / len(x)
    freq_y = abs(freqs[peak_y_idx])
    amp_y = 2 * np.abs(Y[peak_y_idx]) / len(y)
    
    return {
        'wiggle_freq': max(freq_x, freq_y),
        'wiggle_amp': max(amp_x, amp_y),
        'expression': f'wiggle({max(freq_x, freq_y):.2f}, {max(amp_x, amp_y):.1f})'
    }
```

**应用场景**

- 识别 `wiggle(frequency, amplitude)` 表达式参数
- 识别循环动画（Loop）的周期
- 识别节拍驱动的关键帧频率

**案例**：跟踪某抖动文字200帧，FFT后得到 `freq=2.5Hz, amp=4px` → 推断表达式为 `wiggle(2.5, 4)`。这与9.2节理论分析对应，这里给出工程化实现。

## 十二、多效果叠加的解耦分析

> 真实视频往往不是单一效果，而是多个效果层层叠加。本章解决"如何从复合画面中分离出每个效果的独立贡献"。交叉引用第三章3.2的"按风格反查效果组合"：组合方式已知，但具体顺序与参数需本章方法解耦。

### 12.1 效果顺序识别矩阵（哪个效果在上层）

**理论基础**

AE中效果的渲染顺序为：从上至下（效果面板内），同一图层的多个效果顺序影响最终画面。某些情况下，效果顺序的改变会产生显著不同的视觉结果。

**识别矩阵**

通过观察"效果A作用于效果B的结果"还是"效果B作用于效果A的结果"，可以判定上下层关系：

| 效果A | 效果B | 顺序1: A→B的特征 | 顺序2: B→A的特征 |
|-------|-------|---------------|---------------|
| 模糊 | 发光 | 模糊后再发光，辉光边缘柔和 | 发光后再模糊，整体朦胧无锐边 |
| 调色 | 暗角 | 调色影响全画面，暗角仅作用于调色后 | 暗角先压暗，调色时暗部受影响 |
| RGB分离 | 模糊 | 三个分离的通道各自模糊 | 整体模糊，无通道分离特征 |
| 颗粒 | 模糊 | 颗粒在模糊层之上，颗粒清晰 | 颗粒被模糊，纹理消失 |
| 像素块化 | 发光 | 块状边缘有锐利辉光 | 整体辉光，块边界不可辨 |

**判定流程**

1. 观察效果A和B的"互作用特征"
2. 查表识别为顺序1还是顺序2
3. 在AE复现中调整效果顺序，验证视觉效果

**案例**：观察某赛博朋克画面，RGB通道有清晰可辨的偏移，且每个通道边缘有辉光。判定为"RGB分离→发光"顺序。若整体辉光模糊了通道偏移，则为"发光→RGB分离"。

### 12.2 颜色空间叠加的非交换性

**理论基础**

颜色变换在数学上为矩阵乘法，而矩阵乘法**不满足交换律**：

```
M_A · M_B ≠ M_B · M_A  （一般情况下）
```

**实战影响**

| 操作A | 操作B | A→B | B→A |
|-------|-------|-----|-----|
| 色温+5 | 饱和度-10 | 先变暖再降低饱和，结果偏黄弱 | 先降饱和再变暖，结果偏灰暖 |
| 亮度+10 | 对比度+15 | 亮部更亮，对比度提升在亮区间 | 整体提亮后再拉对比，中调拉伸明显 |
| 色相+10° | 饱和度-20 | 色相旋转后降饱和，颜色仍可辨 | 降饱和后旋转色相，旋转效果弱 |
| 阴影+5 | 高光-5 | 暗部提亮，亮部保持 | 亮部压暗，阴影保持 |

**逆向分析策略**

为还原原始调色流程，需确定每个调色操作的应用顺序：

1. 选取3-5个像素采样点（覆盖暗部/中调/高光）
2. 对每种可能顺序，计算预测颜色值
3. 与实际颜色比较，残差最小的顺序即为原顺序
4. 多效果叠加时，复杂度为 O(n!)，但实际可通过先验减少候选

**案例**：某调色疑似"亮度+对比度+饱和度"三步操作，6种顺序。采样5个像素后，计算每种顺序的预测值，发现"对比度→饱和度→亮度"残差最小。该顺序即为原始流程。

### 12.3 混合模式叠加的代数运算还原

**理论基础**

AE中的混合模式本质是像素值的代数运算。常用模式的数学表达：

| 混合模式 | 公式（A在上，B在下） | 备注 |
|---------|-------------------|------|
| Normal | `C = A·α + B·(1-α)` | α为不透明度 |
| Multiply | `C = A·B / 255` | 整体变暗 |
| Screen | `C = 255 - (255-A)·(255-B)/255` | 整体变亮 |
| Overlay | `B>128`: Screen; `B≤128`: Multiply | 对比分明的区域分别处理 |
| Add | `C = min(255, A+B)` | 线性加法 |
| Subtract | `C = max(0, B-A)` | 线性减法 |
| Difference | `C = |A-B|` | 绝对差值 |

**逆向还原**

若已知混合后画面 `C` 和底层 `B`，可反推上层 `A`：

```
Multiply:  A = C·255 / B
Screen:    A = 255 - (255-C)·255 / (255-B)
Add:       A = C - B
Difference: A = |C-B| 或 |B-C|
```

**案例**：某辉光效果叠加在文字上，使用Screen模式。已知：
- 文字底层 B = (50, 50, 50)
- 合成后 C = (200, 180, 160)
- 求辉光层 A

```
A_R = 255 - (255-200)·255/(255-50) = 255 - 55·1.244 = 255 - 68.4 = 186.6
A_G = 255 - (255-180)·255/(255-50) = 255 - 75·1.244 = 255 - 93.3 = 161.7
A_B = 255 - (255-160)·255/(255-50) = 255 - 95·1.244 = 255 - 118.2 = 136.8
```

→ 辉光层颜色约为 (187, 162, 137)，偏暖白光。配合Glow Radius和Intensity参数，可完整复现。

### 12.4 模糊+发光+调色的复合解耦流程

**典型复合效果链**

许多美风格视频的标准效果链：

```
原始素材 → 模糊 → 发光 → 调色 → 输出
```

**解耦步骤**

**Step 1: 调色反推**
- 调色是最后一步，作用于已模糊+已发光的画面
- 通过画面"未发光区域"（如背景）采样，反推调色矩阵（见9.5）
- 计算反调色变换 `M_inv = M_color^(-1)`
- 应用反调色，得到"模糊+发光后但未调色"的画面

**Step 2: 发光反推**
- 发光通常使亮部"溢出"，特征为高光区域 RGB 值接近 255 且有色彩偏移
- 通过分析溢出范围，估算 Glow Radius
- 通过分析溢出强度，估算 Glow Intensity
- 通过分析溢出颜色，估算 Glow Color
- 反向应用 Screen 公式（见12.3），减去发光贡献

**Step 3: 模糊反推**
- 经过前两步反推后，剩余画面为"模糊后但未发光未调色"
- 通过分析边缘模糊扩散范围，估算 Blur 半径
- 反卷积（Deconvolution）算法可部分还原清晰图像

**案例**

某梦幻柔焦人像，分析如下：
- Step 1：背景采样反推 Lumetri 调色为色温+8、饱和度-15
- Step 2：高光区域分析，Glow Radius=25px, Intensity=1.8, Color=(255,240,220)
- Step 3：边缘扩散5px，高斯模糊 σ=2

→ 完整复现链：高斯模糊5px → Deep Glow(R=25, I=1.8) → Lumetri(色温+8, 饱和度-15)。

### 12.5 案例分析：赛博朋克场景的8层效果解耦

**场景描述**

某30秒赛博朋克短片，含霓虹街景、人物、HUD元素。

**初步识别的8层效果**

1. 基础调色：青/品红双色 LUT
2. CRT扫描线
3. RGB分离
4. 高光发光
5. 边缘发光（霓虹边）
6. 暗角
7. 胶片颗粒
8. 整体抖动 wiggle()

**解耦流程**

**阶段1：从外到内剥离**

观察：颗粒感清晰可见，未被任何效果模糊 → 颗粒在最上层（第7层之上无效果）

观察：抖动影响所有元素，包括颗粒 → 抖动在第8层（最外层）

→ 剥离抖动：用光流法（11.2）反推每帧位移，反向位移补偿，得到稳定画面

**阶段2：剥离调色与暗角**

观察：暗角仅作用于画面边缘 → 通过中心区域采样反推调色，对边缘区域反推暗角参数

→ 反调色：应用LUT逆变换（近似）

**阶段3：分离发光**

观察：高光区域有溢出辉光，霓虹边缘有独立辉光

→ 高光发光：全局高亮区域，使用12.4的发光反推

→ 边缘发光：仅在物体边缘，识别边缘像素（Canny边缘检测），分析其颜色

**阶段4：分离RGB分离与CRT**

观察：RGB通道在水平方向偏移，且每隔3px有亮线

→ RGB分离：分析红/蓝通道相对绿通道的偏移量

→ CRT扫描线：频谱分析（FFT）在水平方向有3px周期的强响应

**最终输出**

```
效果链（从上至下）：
1. wiggle(2, 3)  → 整体抖动
2. 胶片颗粒 Amount=15  → 颗粒
3. CC Vignette Amount=-40  → 暗角
4. Lumetri 色温=-10, 饱和度+20, 阴影青/高光品红  → 调色
5. Deep Glow Radius=30, Intensity=2.5  → 高光发光
6. Deep Glow Radius=8, Intensity=3.0, Threshold=180  → 边缘发光
7. RGB分离 R=+4px, B=-4px  → 通道偏移
8. 扫描线 间隔3px, 不透明度40%  → CRT效果
```

| 粗粒度 | 0.1秒 | "0:01.5" | 视觉粗略对齐 |
| 帧级 | 1帧（30fps下≈0.033秒） | "0:01:15" (1秒15帧) | 标准AE时间码 |
| 子帧级 | 1/100秒 | "0:01.530" | 高精度对齐 |
| 子帧级 | 1/1000秒 | "0:01.5307" | 极高精度（学术研究） |

**应用规范**

- 帧级（默认）：用于绝大多数关键帧标注
- 子帧级：用于以下场景
  - 音频节拍对齐（精度需<10ms）
  - 表达式驱动的连续动画（如wiggle相位）
  - 高速运动的关键帧（如快速转场）

**案例**

```
帧级：    关键帧 @ 0:02:15  (2秒15帧 = 2.5秒)
子帧级：  关键帧 @ 0:02.530  (2.530秒，对应30fps下2秒15.9帧)
```

**注意**：AE内部使用子帧级时间，但UI显示为帧级。逆向分析报告中默认帧级，特殊场景下使用子帧级并明确标注。

### 13.3 参数不确定度量化：±5% / ±10% / ±20%的标注规范

**不确定度来源**

逆向分析中，参数推断的精确度受限于：
- 视频压缩损失（H.264/H.265的块效应）
- 视频分辨率（1080p vs 4K）
- 帧率（30fps vs 60fps，影响时序精度）
- 视觉模糊（运动模糊、景深模糊）

**标注规范**

| 不确定度等级 | 数值范围 | 视觉影响 | 标注方式 |
|------------|---------|---------|---------|
| ±5% | 高精度 | 复现差异肉眼可辨 | `数值 ±5%` |
| ±10% | 中精度 | 复现差异需对比可见 | `数值 ±10%` |
| ±20% | 低精度 | 复现差异仅方向性正确 | `数值 ±20%` |
| 方向性 | 最低 | 仅知道参数方向（增/减） | `>原值` 或 `<原值` |

**判断准则**

```
若参数取值具有明确参照（如尺寸/位置） → ±5%
若参数通过视觉特征推断（如模糊半径） → ±10%
若参数通过风格经验推断（如调色强度） → ±20%
若仅观察到效果存在但参数不可量化 → 方向性
```

**案例**

```
错误（缺精度）：Glow Radius = 25
正确（高精度）：Glow Radius = 25 ±5%  [基于已知文字笔画的发光扩散范围]
正确（中精度）：Glow Radius = 25 ±10% [基于视觉扩散范围估算]
正确（方向性）：Glow Radius > 10  [仅能确认发光存在，参数不可量化]
```

### 13.4 决策置信度评分：0-100分的解析置信度

**评分维度**

每个解析结论的置信度由以下维度加权：

| 维度 | 权重 | 评分依据 |
|------|------|---------|
| 视觉证据强度 | 30% | 直接可见的视觉特征数量 |
| 数学严谨度 | 25% | 是否有数学依据/算法支撑 |
| 工具验证 | 20% | 是否在AE中实际复现验证 |
| 多方法交叉验证 | 15% | 不同方法是否得到一致结论 |
| 先验知识匹配 | 10% | 是否与已知效果库匹配 |

**评分计算**

```
Confidence = Σ (维度得分 × 权重)
```

每个维度得分0-100。

**置信度等级**

| 总分 | 等级 | 解读 | 处理建议 |
|------|------|------|---------|
| 90-100 | A级 | 高度可信 | 直接采用 |
| 75-89 | B级 | 较可信 | 采用但标注置信度 |
| 60-74 | C级 | 模糊 | 仅作参考，需进一步验证 |
| <60 | D级 | 推测 | 标"待验证"，不进入最终参数表 |

**案例**

某发光效果分析：
- 视觉证据：观察到明显辉光扩散、颜色偏移、阈值截断（90分）
- 数学严谨度：通过Screen模式反推计算颜色值（80分）
- 工具验证：在AE中实际复现，差异<5%（95分）
- 多方法交叉：颜色反推与边缘采样一致（85分）
- 先验知识：Deep Glow的典型参数范围匹配（90分）

```
Confidence = 90×0.30 + 80×0.25 + 95×0.20 + 85×0.15 + 90×0.10
           = 27 + 20 + 19 + 12.75 + 9 = 87.75
           ≈ 88分 → B级（较可信）
```

→ 参数进入最终表，标注置信度88。

## 十四、行业级分析工作流

> 不同行业对逆向分析的精度、速度、协作方式要求迥异。本章针对影视、广告、AMV/漫剪、短视频四类场景，给出定制化工作流。交叉引用第七章《常见视频类型的分析切入点》：本章为其"工业化升级版"。

### 14.1 影视级分析：与DI调色师协作的逆向流程

**行业特点**

- 精度要求：极高（影院大屏可见任何瑕疵）
- 协作需求：多角色协作（DI调色师、特效师、剪辑师）
- 工具链：DaVinci Resolve、Baselight、Filmlight
- 交付物：CDL（Color Decision List）、LUT、EDL

**协作流程**

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│ 逆向分析师   │ →  │  DI 调色师   │ →  │  影院交付    │
│ 提取效果参数 │    │ CDL/LUT生成 │    │  DCP/IMAX   │
└─────────────┘    └─────────────┘    └─────────────┘
       ↓                  ↓                   ↓
   参数表YAML      CDL XML文件         最终影院版本
```

**关键交接物**

1. **CDL（Color Decision List）**：包含Slope/Offset/Power三参数的调色决策列表
   ```
   ASC_SOP: <Slope> <Offset> <Power>
   例: 1.05 0.02 0.95 / 0.01 -0.02 0.00 / 0.95 1.02 1.10
   ```
2. **LUT文件**：1D LUT（用于色温）+ 3D LUT（用于风格化）
3. **效果参数表**：YAML格式（见13.5），与DI调色师共享

**精度要求**

- 颜色：ΔE < 2（专业显示器校准）
- 时间码：子帧级（1/100秒）
- 参数不确定度：±5%

**案例**：分析某好莱坞调色风格，逆向得到LUT后，与DI调色师协作微调。最终CDL交付影院版本。

### 14.2 广告级分析：品牌还原的色卡比对流程

**行业特点**

- 精度要求：中-高（品牌色必须精确）
- 工具链：Pantone色卡、X-Rite ColorChecker、AE Lumetri
- 交付物：品牌色卡对照表、调色预设

**色卡比对流程**

```
Step 1: 提取视频中的品牌色
   - 识别Logo区域
   - 采样主色调（如Pantone 186C）

Step 2: 与标准色卡比对
   - 计算ΔE（见10.3）
   - 记录偏差

Step 3: 反推Lumetri参数
   - ΔL → 亮度调整
   - ΔC → 饱和度调整
   - ΔH → 色相调整

Step 4: 输出品牌色卡对照表
```

**品牌色卡对照表格式**

```markdown
## 品牌色还原表

| 标准色 | 视频中实测 | ΔE | ΔL | ΔC | ΔH | Lumetri参数 |
|--------|---------|-----|-----|-----|-----|-----------|
| Pantone 186C | RGB(195,22,52) | 4.9 | -2 | -4 | -2° | 亮度-2, 饱和度-4, 色相-1° |
| Pantone 294C | RGB(0,38,108) | 3.2 | +1 | -2 | +1° | 亮度+1, 饱和度-2, 色相+1° |
| Pantone 109C | RGB(255,194,0) | 2.1 | +1 | -1 | 0° | 亮度+1, 饱和度-1 |
```

**精度要求**

- 颜色：ΔE < 5（消费者可接受）
- 时间码：帧级
- 参数不确定度：±5%（品牌色）/ ±10%（其他）

**案例**：某广告片主色调偏差ΔE=4.9，按上表调整Lumetri参数后复现，ΔE降至1.2，符合品牌规范。

### 14.3 AMV/漫剪分析：节拍对齐精度的量化评估

**行业特点**

- 精度要求：高（节拍对齐是AMV核心质量指标）
- 工具链：AE、音频分析软件（如Sonic Visualiser）
- 交付物：节拍对齐表、关键帧时间码列表

**节拍对齐精度评估**

```
对齐误差 = |关键帧时间 - 音乐重音时间|
```

**评估流程**

1. **提取音乐节拍**：使用音频分析工具，提取所有节拍时间点 `t_beat[k]`
2. **提取关键帧时间**：从AE项目中导出所有视觉关键帧时间 `t_key[j]`
3. **匹配**：对每个关键帧，找最近的节拍时间，计算误差
4. **统计**

```python
def evaluate_beat_alignment(keyframes, beats):
    errors = []
    for kf in keyframes:
        nearest_beat = min(beats, key=lambda b: abs(b - kf))
        error = abs(kf - nearest_beat)
        errors.append(error)
    
    return {
        'max_error_ms': max(errors) * 1000,
        'avg_error_ms': sum(errors) / len(errors) * 1000,
        'within_50ms_ratio': sum(1 for e in errors if e < 0.050) / len(errors),
        'within_100ms_ratio': sum(1 for e in errors if e < 0.100) / len(errors)
    }
```

**评估标准**

| 等级 | 平均误差 | 50ms内比例 | 解读 |
|------|---------|-----------|------|
| S级 | <20ms | >95% | 顶级节拍对齐 |
| A级 | <50ms | >85% | 优秀 |
| B级 | <80ms | >70% | 良好 |
| C级 | <120ms | >50% | 一般 |
| D级 | >120ms | <50% | 节拍错位 |

**案例**：分析某顶级AMV，关键帧200个，平均误差18ms，50ms内比例96%。→ S级节拍对齐，可参考其拉镜节奏。

### 14.4 短视频分析：竖屏9:16与横屏16:9的转换分析

**行业特点**

- 精度要求：中（速度优先）
- 多版本：常需同时输出9:16、16:9、1:1三版本
- 工具链：AE动态画布、Premiere Auto Reframe

**转换分析的关键问题**

1. **构图重心迁移**：横屏左右构图 → 竖屏居中，需识别原横屏的视觉焦点
2. **文字安全区**：竖屏顶部/底部UI遮挡区（如TikTok的右侧按钮、底部文案）
3. **运动范围适配**：横屏的水平运动 → 竖屏需转为垂直或缩放
4. **粒子/特效边界**：横屏的边缘粒子在竖屏中可能被裁切

**分析流程**

```
Step 1: 原横屏分析（标准逆向流程）
   → 得到16:9版本的完整参数表

Step 2: 焦点识别
   → 使用视觉显著性模型（10.4）
   → 识别每帧的视觉焦点

Step 3: 竖屏适配
   → 焦点居中：将焦点对齐到9:16画面中心
   → 边缘元素重排：原横屏边缘的文字/Logo移至竖屏安全区
   → 运动方向调整：水平运动 → 缩放运动或垂直运动

Step 4: 安全区校验
   → 顶部80px / 底部200px / 右侧80px为不安全区
   → 关键元素必须避开
```

**转换参数表**

```yaml
conversion_strategy:
  source: "16:9 (1920x1080)"
  target: "9:16 (1080x1920)"
  
  refocus:
    method: "saliency_based"
    focal_points:
      - time_range: "0:00 - 0:03"
        source_pos: [480, 540]   # 横屏左1/4处
        target_pos: [540, 960]   # 竖屏中心
    
  text_relocation:
    - source: "right-side logo"
      target: "top-center"
      offset: [0, -50]
  
  motion_adaptation:
    - property: "Position"
      source_motion: "horizontal_pan"
      target_motion: "zoom_in"
      rationale: "竖屏宽度有限，水平pan效果差，改为缩放"
  
  safe_zone:
    top_exclusion: 80
    bottom_exclusion: 200
    right_exclusion: 80
```

**精度要求**

- 构图重心：±20px（竖屏中心±20px范围内）
- 时间码：帧级
- 参数不确定度：±10%

**案例**：某横屏广告转为竖屏后，原横屏左右两侧的产品Logo被裁切。通过显著性模型识别产品为视觉焦点，将画面中心重定位至产品位置，并将Logo移至顶部安全区。最终竖屏版本通过品牌方审核。
