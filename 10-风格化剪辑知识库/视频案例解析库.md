## 文档使用说明

> [!note] 必读说明
> 本章是使用案例库的前提，包含案例ID命名规则、参数表字段约定、关键帧表字段约定等重要规范。在开始阅读案例之前，请务必先理解这些规范，这样才能正确解读每个案例的原子级解析数据。

### 案例ID命名规则

所有案例采用统一编号：`CASE-{章}-{节}`，例如 `CASE-1-1` 表示第一章案例1。

### 参数表字段约定

| 字段 | 含义 |
|------|------|
| 参数 | 插件/效果的参数名（保留英文原文） |
| 值 | 推荐取值或关键帧值 |
| 单位 | px / px/s / 秒 / % / 度 / Hz |
| 关键帧 | 是否使用关键帧动画（是/否） |
| 不确定度 | 参数推断误差范围（基于视频逐帧分析） |

### 关键帧表字段约定

| 字段 | 含义 |
|------|------|
| 时间 | 时间码（HH:MM:SS:FF，PAL 25fps / NTSC 29.97fps） |
| 属性 | 关键帧驱动的属性名 |
| 值 | 关键帧时刻的属性值 |
| 缓动 | 缓动曲线类型（Linear/Ease In/Ease Out/Ease In-Out/Hold/贝塞尔） |
| 贝塞尔控制点 | Speed Graph 控制点坐标（用于精确复现） |

#### 完整表达式代码

```javascript
// Elastic Overshoot 表达式
amp = 0.1;        // 振幅
freq = 3.0;       // 频率
decay = 5.0;      // 衰减
tStart = inPoint; // 入场时间
duration = 0.6;   // 动画时长（秒）

t = time - tStart;
if (t < duration) {
    // 入场阶段：Ease Out 三次方
    p = t / duration;
    ease = 1 - Math.pow(1 - p, 3);
    scale = ease;
} else if (t < duration + 1.5) {
    // 弹性阶段：阻尼振荡
    tt = t - duration;
    scale = 1 + amp * Math.sin(tt * freq * 2 * Math.PI) * Math.exp(-decay * tt);
} else {
    scale = 1;
}

[scale * 100, scale * 100];
```

## 第八章 案例QC与精度评估

### 8.1 复现精度评估标准

#### 8.1.1 PSNR/SSIM 阈值体系

| 案例类型 | PSNR 阈值 | SSIM 阈值 | 说明 |
|---------|----------|----------|------|
| 调色类 | ≥ 38dB | ≥ 0.95 | 色彩精度要求最高 |
| 发光类 | ≥ 36dB | ≥ 0.93 | 衰减曲线需精确 |
| 文字动画类 | ≥ 35dB | ≥ 0.92 | 时机精度要求高 |
| 粒子类 | ≥ 32dB | ≥ 0.90 | 粒子随机性允许误差 |
| 3D 合成类 | ≥ 33dB | ≥ 0.92 | 摄像机运动需匹配 |
| 转场类 | ≥ 35dB | ≥ 0.93 | 时机是关键 |
| 综合案例 | ≥ 32dB | ≥ 0.90 | 综合误差允许放宽 |

**PSNR 计算公式**：
```
PSNR = 10 * log10(MAX² / MSE)
MAX = 255（8位）/ 1023（10位）
MSE = 均方误差
```

#### 8.1.2 色彩差异 ΔE2000

| ΔE2000 范围 | 视觉感受 | QC 评级 |
|------------|---------|---------|
| 0-1 | 几乎无差异 | A+ |
| 1-3 | 轻微差异 | A |
| 3-5 | 可见差异但可接受 | B |
| 5-10 | 明显差异 | C |
| >10 | 严重不匹配 | D（需重新分析） |

**CIE ΔE2000 公式**（简化）：
```
ΔE2000 = √(ΔL'² + ΔC'² + ΔH'² + RT·ΔC'·ΔH')
```
其中 L', C', H' 是 Lab 空间的修正色度值，RT 是旋转项。

#### 8.1.3 关键帧时机误差

| 误差范围 | 评级 | 说明 |
|---------|------|------|
| 0 帧 | A+ | 完美对齐 |
| ±1 帧 | A | 优秀 |
| ±2 帧 | B | 可接受 |
| ±3 帧 | C | 需优化 |
| >±3 帧 | D | 不合格 |

**测量方法**：
1. 在原视频和复现视频中分别标记关键帧时刻
2. 计算时间差 Δt = |t_original - t_repro|
3. 转换为帧数：Δframe = Δt × fps

#### 8.2.2 参数不确定度来源

| QC验证标准 | PSNR + SSIM + 时序 + 其他 | 见案例1.1 |

#### 9.1.2 参数表格式

参数表必须遵循以下格式：

```markdown
| 参数 | 值 | 单位 | 关键帧 | 不确定度 |
|------|-----|------|--------|----------|
| 参数名（英文原文） | 数值 | px/秒/%/度/Hz | 是/否 | ±X% |
```

**字段填写规范**：
- 参数名：保留插件英文原文（如 Emitter Type，不翻译为"发射器类型"）
- 值：具体数值，范围用"-"分隔（如 100-200）
- 单位：必须标明，无单位的填"-"
- 关键帧：是/否（不允许空值）
- 不确定度：百分比形式，无法量化的填"-"

#### 9.1.3 关键帧表格式

```markdown
| 时间 | 属性 | 值 | 缓动 | 贝塞尔控制点 |
|------|------|-----|------|--------------|
| HH:MM:SS:FF | 属性名 | 数值 | 缓动类型 | (x1,y1)→(x2,y2) |
```

**时间码规范**：
- PAL 制式：25fps，时间码格式 HH:MM:SS:FF（FF 0-24）
- NTSC 制式：29.97fps，时间码格式 HH:MM:SS:FF（FF 0-29）
- 必须在案例头部注明制式

**缓动类型枚举**：
- Linear（线性）
- Ease In（缓入）
- Ease Out（缓出）
- Ease In-Out（缓入缓出）
- Hold（保持）
- Exponential（指数）
- Cubic Ease Out（三次方缓出）
- 贝塞尔（自定义）

#### 9.1.4 QC标准要求

每个案例必须包含至少以下QC指标：
- PSNR 阈值（dB）
- SSIM 阈值（0-1）
- 时机误差阈值（帧）
- 至少1个案例特定的QC指标（如色彩 ΔE2000、粒子密度等）
