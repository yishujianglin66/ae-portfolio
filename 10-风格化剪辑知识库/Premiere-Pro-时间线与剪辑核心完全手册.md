# Premiere Pro 时间线与剪辑核心完全手册

> 版本: 2025-v1 | 适用: PR 2025/2026 + AE/AU 联动

## 一、项目管理

### 1.1 项目设置

| 设置项 | 推荐值 | 说明 |
|--------|--------|------|
| 视频渲染格式 | Mercury Playback GPU | 硬件加速 |
| 渲染器 | CUDA/OpenCL/Metal | 按显卡选择 |
| 预览文件格式 | I-Frame Only MPEG | 快速预览 |
| 预览分辨率 | 1/2 或 1/4 | 流畅编辑 |

### 1.2 素材管理

```
素材箱(Bin)推荐结构:
├── 01-原始素材
│   ├── 视频
│   ├── 音频
│   └── 图片
├── 02-序列
│   ├── 粗剪
│   ├── 精剪
│   └── 输出
├── 03-调色
├── 04-音频
│   ├── BGM
│   ├── SFX
│   └── VO
├── 05-图形/字幕
└── 06-输出
```

### 1.3 代理工作流

```
代理流程:
1. 选中素材 → 右键 → 代理 → 创建代理
2. 选择代理格式(ProRes Proxy / DNxHR LB)
3. 切换代理: 切换代理按钮(程序监视器下方)
4. 编辑时使用低分辨率代理
5. 输出时自动使用原始素材

代理分辨率:
- 4K素材: 1080p代理
- 1080素材: 720p代理
- 格式: ProRes Proxy(Mac) / DNxHR LB(Win)
```

## 二、时间线操作

### 2.1 核心快捷键

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 剃刀工具 | C | 剪切 |
| 选择工具 | V | 选择/移动 |
| 波纹删除 | Shift+Delete | 删除并闭合间隙 |
| 标记入点 | I | 设置入点 |
| 标记出点 | O | 设置出点 |

| 覆盖 | . | 覆盖到时间线 |
| 匹配帧 | F | 在源监视器中显示 |
| 添加编辑 | Ctrl+K | 在播放头处剪切 |
| 波纹修剪 | Q/W | 左侧/右侧修剪 |

### 2.2 修剪工具

| 工具 | 快捷键 | 功能 |
|------|--------|------|
| 滚动编辑 | N | 同时移动两侧剪辑点 |
| 波纹编辑 | B | 移动剪辑点并波纹 |
| 多帧修剪 | - | 逐帧修剪 |
| 滑动 | Y | 在素材内滑动 |
| 滑行 | U | 在时间线上滑行 |

### 2.3 多机位剪辑

```
多机位流程:
1. 导入所有机位素材
2. 选中所有素材 → 右键 → 创建多机位源序列
3. 同步方式: 时间码/音频波形/标记点
4. 创建嵌套序列
5. 启用多机位视图
6. 实时播放并切换机位(数字键1-9)
7. 可在时间线上微调切换点
```

## 三、转场效果

### 3.1 内置转场分类

| 分类 | 代表效果 | 用途 |
|------|---------|------|
| 溶解 | 交叉溶解/黑场过渡 | 最通用 |
| 滑动 | 推/滑动/时钟 | 方向感 |
| 擦除 | 带状擦除/时钟擦除 | 文字/图形 |
| 页面剥裂 | 页面剥裂/翻转 | 相册/回忆 |
| 特殊 | 光学流动/变形器 | 创意 |

### 3.2 转场使用原则

| 原则 | 说明 |
|------|------|
| 少即是多 | 80%用交叉溶解或硬切 |
| 叙事服务 | 转场服务于故事，不是炫技 |
| 一致性 | 同一风格内保持一致 |
| 节奏匹配 | 转场时长匹配节奏 |
| 声音配合 | 转场配合声音设计 |

### 3.3 自定义转场

```
方法1: 调整图层 + 效果
  创建调整图层 → 添加效果 → 应用到转场区域

方法2: 不透明度关键帧
  手动设置不透明度从100%→0%

方法3: 轨道遮罩键
  上层作为遮罩控制下层显示

方法4: 从AE导入动态图形模板(MOGRT)
```

## 四、速度控制

### 4.1 速度/持续时间

| 操作 | 方法 | 说明 |
|------|------|------|
| 整体变速 | Ctrl+R | 改变速度百分比 |
| 时间重映射 | 右键→显示剪辑关键帧 | 速度曲线 |
| 光流法 | 时间插值→光流法 | AI补帧 |
| 帧采样 | 时间插值→帧采样 | 原始帧 |
| 光流+补帧 | 光流法(自动) | 慢动作补帧 |

### 4.2 时间重映射曲线

```
速度曲线类型:
线性: 匀速变化
贝塞尔: 平滑加减速(推荐)
保持: 突然变化(跳切感)

常用曲线:
- 正常→慢动作→正常: 子弹时间
- 慢→快: 加速感
- 快→慢: 冲击感
```

## 五、字幕与图形

### 5.1 基本图形面板

```
文字工具:
- T键: 文字工具
- 属性面板: 字体/大小/颜色/对齐
- 基本图形: 创建可复用模板

字幕类型:
- 下方三分之一(Lower Third): 人名/职位
- 标题: 大标题
- 滚动字幕: 片尾字幕
- 字幕条: 对话字幕
```

### 5.2 MOGRT 动态图形模板

```
创建MOGRT:
1. 在AE中设计动态图形
2. 在基本图形面板中导出为MOGRT
3. 在PR中导入MOGRT
4. 编辑面板中修改文字/颜色/参数

安装MOGRT:
- 拖入PR的"基本图形"面板
- 或放入 Motion Graphics Templates 文件夹
```

## 六、与 AE/AU 联动

### 6.1 动态链接(Dynamic Link)

```
PR → AE:
1. 选中剪辑 → 右键 → 在After Effects中替换
2. AE自动打开，编辑后PR自动更新
3. 无需渲染中间文件

PR → AU:
1. 选中音频 → 右键 → 在Audition中编辑
2. AU编辑后PR自动更新

AE → PR:
1. 在AE中创建合成
2. 导入PR作为动态链接素材
```

### 6.2 嵌套序列

```
嵌套用途:
- 简化复杂时间线
- 应用整体效果
- 稳定化(变形稳定器需要嵌套)
- 多机位嵌套
- 复用剪辑段落
```
