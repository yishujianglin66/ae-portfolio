# 一、调色理论基础

## 1.1 色彩空间与色彩模型

### 1.1.1 色彩模型分类

色彩模型是用数学方式描述颜色的系统，不同的色彩模型适用于不同的应用场景。

#### RGB加色模型

RGB模型是基于光的加色法原理，通过红（Red）、绿（Green）、蓝（Blue）三种原色光的叠加来产生各种颜色。

| 属性 | 说明 |
|------|------|
| 原理 | 加色法（光叠加） |
| 原色 | 红、绿、蓝 |
| 应用 | 显示器、相机、电视、数字图像 |
| 数值范围 | 0-255（8bit）、0-1023（10bit）、0-65535（16bit） |
| 混合规律 | R+G=Y（黄）、R+B=M（品红）、G+B=C（青）、R+G+B=W（白） |

**RGB各通道作用详解**：

| 通道 | 颜色 | 范围 | 主要影响 |
|------|------|------|----------|
| Red | 红色通道 | 0-255 | 控制红色到青色的色彩偏移 |
| Green | 绿色通道 | 0-255 | 控制绿色到品红的色彩偏移，影响亮度感知最大 |
| Blue | 蓝色通道 | 0-255 | 控制蓝色到黄色的色彩偏移，影响色温感知 |

#### CMYK减色模型

CMYK模型是基于颜料的减色法原理，主要用于印刷领域。

| 属性 | 说明 |
|------|------|
| 原理 | 减色法（光吸收） |
| 原色 | 青、品红、黄 |
| 应用 | 印刷、打印 |
| 黑色版（K） | 增加黑色解决油墨混合不纯和细节不足问题 |

#### HSL/HSV模型

HSL和HSV是基于人眼感知的色彩模型，更符合调色时的直觉操作。

| 模型 | 分量 | 说明 | 调色用途 |
|------|------|------|----------|
| HSL | H（色相） | 0-360°，色相环位置 | 改变颜色种类 |
| HSL | S（饱和度） | 0-100%，颜色纯度 | 控制颜色鲜艳程度 |
| HSL | L（明度） | 0-100%，亮度 | 控制颜色明暗 |
| HSV | H（色相） | 0-360° | 同HSL |
| HSV | S（饱和度） | 0-100% | 同HSL |
| HSV | V（明度值） | 0-100% | 与L略有差异，V是最大值 |

**HSL与HSV的差别**：
- HSL中L=50%时为纯色，L=0为黑，L=100为白
- HSV中V=100%且S=100%时为纯色，V=0为黑

#### Lab色彩模型

Lab模型是最接近人眼感知的色彩空间，设备无关性最强。

| 分量 | 名称 | 范围 | 说明 |
|------|------|------|------|
| L | 明度 | 0-100 | 纯粹亮度信息 |
| a | 红绿轴 | -128到+127 | 负值偏绿，正值偏红 |
| b | 黄蓝轴 | -128到+127 | 负值偏蓝，正值偏黄 |

Lab色彩空间特点：
- 设备无关性：不依赖于任何特定设备
- 感知均匀性：相同数值变化在人眼感知上是均匀的
- 色域最大：包含RGB和CMYK的所有颜色
- 调色应用：分离亮度与色彩信息进行调色

### 1.1.2 色彩空间详解

#### sRGB（标准RGB）

| 属性 | 数值 |
|------|------|
| 色域 | 较小，约占CIE 1931的35% |
| 白点 | D65（6500K） |
| 伽马 | 约2.2 |
| 应用 | 网页、消费级显示器、移动设备 |
| 优点 | 兼容性最强，几乎所有设备支持 |
| 缺点 | 色域小，无法显示高饱和度颜色 |

sRGB是网络和消费级设备的标准色彩空间。几乎所有显示器、手机、相机都支持sRGB。对于面向普通观众的视频内容，sRGB是最安全的输出选择。

**sRGB使用场景**：
- YouTube短视频（普通画质）
- 抖音/快手短视频
- B站普通视频
- 朋友圈、Instagram等社交媒体
- 网页图片

#### Rec.709（BT.709）

| 属性 | 数值 |
|------|------|
| 色域 | 与sRGB相同 |
| 白点 | D65（6500K） |
| 伽马 | 2.4 |
| 应用 | HDTV电视广播、蓝光、流媒体 |
| 优点 | 广播电视标准 |
| 缺点 | 色域与sRGB相同，无法显示广色域 |

Rec.709是高清电视的国际标准，与sRGB拥有相同的色域，但伽马值不同（2.4 vs 2.2），更适合电视观看环境。

**Rec.709使用场景**：
- HDTV电视广播
- 蓝光光盘
- Netflix、HBO等流媒体平台（SDR内容）
- YouTube专业内容

#### Rec.2020（BT.2020）

| 属性 | 数值 |
|------|------|
| 色域 | 极大，约占CIE 1931的75.8% |
| 白点 | D65（6500K） |
| 伽马 | 2.4（SDR）或PQ/HLG（HDR） |
| 应用 | UHDTV、4K/8K超高清、HDR |
| 优点 | 色域大，能显示更丰富的颜色 |
| 缺点 | 显示设备支持有限 |

Rec.2020是超高清电视（UHDTV）的色彩标准，色域远大于Rec.709和sRGB。是4K/8K内容和HDR内容的标准色彩空间。

**Rec.2020使用场景**：
- 4K/8K超高清电视
- HDR内容制作
- Netflix 4K HDR
- 高端电影院数字放映

#### DCI-P3

| 属性 | 数值 |
|------|------|
| 色域 | 约占CIE 1931的45.5% |
| 白点 | DCI（6300K）或D65 |
| 伽马 | 2.6 |
| 应用 | 数字电影放映、Apple设备 |
| 优点 | 比sRGB色域大25%，红色更鲜艳 |
| 缺点 | 不如Rec.2020大 |

DCI-P3是数字电影联合组织（DCI）制定的数字电影放映色彩标准。Apple设备（iPhone、iPad、MacBook）也广泛支持DCI-P3。

**DCI-P3使用场景**：
- 数字电影院放映
- Apple生态系统（iPhone、iPad、MacBook Pro）
- 高端显示器
- HDR内容（与PQ配合）

#### ACES（Academy Color Encoding System）

| 属性 | 数值 |
|------|------|
| 色域 | AP0，约占CIE 1931的100%+ |
| 白点 | D60 |
| 编码 | 线性ACES2065-1或ACEScg |
| 应用 | 电影制作、专业调色全流程 |
| 优点 | 统一色彩管理，跨设备一致 |
| 缺点 | 学习成本高，需要正确配置 |

ACES是电影艺术与科学学院（AMPAS）开发的色彩管理系统，旨在统一整个制作流程的色彩管理。ACES工作流是好莱坞电影制作的标准。

**ACES工作流阶段**：

| 阶段 | 名称 | 说明 |
|------|------|------|
| IDT | Input Device Transform | 将相机原始色彩转换到ACES色彩空间 |
| RRT | Reference Rendering Transform | ACES到显示设备的参考渲染 |
| ODT | Output Device Transform | ACES到最终输出设备的转换 |

**ACES色彩空间变体**：

| 变体 | 色域 | 用途 |
|------|------|------|
| ACES2065-1 | AP0 | 归档和交换（最广色域） |
| ACEScg | AP1 | 调色和合成工作空间 |
| ACEScct | AP1 | 调色工作空间（对数编码） |

### 1.1.3 色彩空间转换

色彩空间转换是调色中的核心概念，不同色彩空间之间需要正确的转换以避免色彩失真。

```
源色彩空间 → 线性光 → 目标色彩空间
（伽马解码）        （伽马编码）
```

**常见转换路径**：

| 源空间 | 目标空间 | 应用场景 |
|--------|----------|----------|
| sRGB | Rec.709 | 网页转电视 |
| Rec.709 | Rec.2020 | HDTV转UHDTV |
| Log | Rec.709 | Log素材调色 |
| Rec.2020 | DCI-P3 | UHDTV转影院 |
| ACES | Rec.709 | ACES调色输出 |
| sRGB | DCI-P3 | 网页转影院 |

**色彩空间转换注意事项**：
1. 色域裁切：从小色域转大色域安全，反之会丢失颜色
2. 伽马转换：不同伽马值会导致亮度感知差异
3. 白点转换：不同白点会导致色温偏移
4. 编码方式：线性vs对数vs伽马编码的转换

## 1.2 色彩深度

### 1.2.1 色彩深度分级

色彩深度（Bit Depth）决定了每个颜色通道可以表示的颜色数量，直接影响调色的精度和过渡的平滑度。

| 色彩深度 | 每通道颜色数 | 总颜色数 | 文件大小 | 应用 |
|----------|-------------|----------|----------|------|
| 8bit | 256 | 1670万 | 基准 | 消费级显示、网络视频 |
| 10bit | 1024 | 10.7亿 | 1.25x | 专业视频、HDR |
| 12bit | 4096 | 687亿 | 1.5x | 高端调色、影院 |
| 16bit | 65536 | 281万亿 | 2x | 后期制作中间格式 |
| 32bit浮点 | 无限 | 无限 | 4x | HDR合成、专业调色 |

### 1.2.2 不同色彩深度的优势

#### 8bit色彩深度

- **优势**：文件小，兼容性好，所有设备支持
- **劣势**：调色后容易出现色带（banding），过渡不细腻
- **应用**：网络视频、消费级显示、预览

#### 10bit色彩深度

- **优势**：颜色过渡平滑，调色余量大，HDR基本要求
- **劣势**：文件较大，部分老旧设备不支持
- **应用**：专业视频制作、HDR内容、流媒体高质量输出

#### 12bit色彩深度

- **优势**：极高调色精度，几乎无色带
- **劣势**：文件大，需要专业设备
- **应用**：高端调色、电影院、HDR母版

#### 16bit色彩深度

- **优势**：极大调色空间，多次调色无损
- **劣势**：文件巨大
- **应用**：调色中间格式、VFX合成

#### 32bit浮点

- **优势**：超越显示范围的色彩信息，HDR合成必需
- **劣势**：处理慢，需要专业GPU
- **应用**：HDR制作、ACES工作流、专业合成

### 1.2.3 色彩深度与色带问题

色带（Banding）是由于色彩深度不足导致的渐变区域出现条纹的现象。

**色带产生原因**：
1. 8bit素材剧烈调色后量化误差累积
2. 渐变区域颜色过渡被压缩
3. 多次压缩编码导致信息丢失

**色带解决方案**：

| 方案 | 效果 | 实现方法 |
|------|------|----------|
| 使用高色彩深度素材 | ⭐⭐⭐⭐⭐ | 拍摄时使用10bit+ |
| 调色时使用32bit模式 | ⭐⭐⭐⭐ | AE中切换到32bit |
| 添加噪点 | ⭐⭐⭐ | 1-3%噪点打破色带 |
| 抖动处理 | ⭐⭐⭐⭐ | 输出时启用抖动 |
| 使用ProRes 4444中间格式 | ⭐⭐⭐⭐ | 避免8bit中间格式 |

### 1.3.2 白平衡调整方法

白平衡（White Balance）是调整图像使其在不同光源下显示正确颜色的过程。

#### 白平衡调整策略

| 策略 | 方法 | 适用场景 |
|------|------|----------|
| 灰卡白平衡 | 拍摄时使用灰卡 | 专业拍摄 |
| 自动白平衡 | 软件自动分析 | 快速调整 |
| 手动色温调整 | 设置具体K值 | 精确控制 |
| 白色拾取 | 点击画面白色区域 | 快速准确 |
| 数值微调 | 调整色温色调参数 | 创意调色 |

#### 色温色调参数详解

| 参数 | 单位 | 范围 | 作用 |
|------|------|------|------|
| 色温（Temperature） | K | 2000-50000 | 蓝黄轴调整 |
| 色调（Tint） | 度 | -150到+150 | 绿品红轴调整 |
| 白平衡选择 | - | 自动/日光/阴天等 | 预设白平衡 |

**色温调整对画面的影响**：

| 色温调整 | 画面变化 | 适用场景 |
|----------|----------|----------|
| 降低色温（如5500K→3200K） | 画面变暖偏黄 | 营造温暖氛围、夕阳效果 |
| 提高色温（如5500K→7500K） | 画面变冷偏蓝 | 营造冷峻氛围、未来感 |
| 匹配光源色温 | 中性准确 | 真实还原场景 |

### 1.4.2 调色风格与情绪映射

|----------|--------|------|----------|----------|

| 文艺片 | 暖黄低饱和 | 怀旧、感伤 | 暖色、低饱和、低对比 | 色温+15，饱和度-15，对比度-5 |
| 战争片 | 黄绿低饱和 | 残酷、压抑 | 去饱和、黄绿色调 | 色温-5，饱和度-30，对比度+10 |
| 喜剧片 | 高饱和暖色 | 欢快、活泼 | 高饱和、明亮、暖色 | 色温+10，饱和度+25，对比度+5 |
| 纪录片 | 自然中性 | 真实、客观 | 自然色、中性 | 色温0，饱和度0，对比度+5 |
| MV | 高饱和多变 | 情绪、艺术 | 高饱和、风格化 | 视风格而定 |

### 1.4.3 色彩搭配理论

#### 经典色彩搭配方案

| 搭配方案 | 色彩组合 | 视觉效果 | 应用场景 |
|----------|----------|----------|----------|
| 互补色 | 红绿、蓝橙、黄紫 | 强烈对比、视觉冲击 | 动作片、戏剧性场景 |
| 类似色 | 红橙黄、蓝青绿 | 和谐统一、柔和 | 温馨场景、自然画面 |
| 三角色 | 红黄蓝 | 平衡丰富、活泼 | 童趣、活泼场景 |
| 分裂互补 | 红+黄绿+蓝绿 | 对比但不刺眼 | 现代感设计 |
| 四角色 | 红黄蓝绿 | 丰富多变 | 复杂构图 |
| 单色 | 同色相不同明度 | 极简统一 | 高级感、艺术片 |

## 1.5 调色三要素

### 1.5.1 亮度（Luminance/Brightness）

亮度是图像的明暗程度，是调色中最基础的要素。

#### 亮度分级

| 亮度区域 | 数值范围（0-100） | 说明 | 调色重点 |
|----------|-------------------|------|----------|
| 纯黑 | 0 | 完全黑色 | 避免细节丢失 |
| 极深阴影 | 0-10 | 接近黑色 | 保持微小细节 |
| 阴影 | 10-30 | 暗部区域 | 控制黑场不溢出 |
| 深中间调 | 30-45 | 偏暗中间调 | 调整整体明暗 |
| 中间调 | 45-65 | 中间亮度 | 主体颜色主要区域 |
| 浅中间调 | 65-80 | 偏亮中间调 | 提亮主体 |
| 高光 | 80-95 | 亮部区域 | 控制白场不溢出 |
| 极亮高光 | 95-100 | 接近白色 | 保持高光细节 |
| 纯白 | 100 | 完全白色 | 避免过曝 |

#### 亮度调整工具

| 工具 | 调整方式 | 精度 | 应用 |
|------|----------|------|------|
| Brightness | 整体偏移 | 低 | 简单亮度调整 |
| Exposure | 曝光值调整 | 中 | 模拟相机曝光 |
| Levels | 黑场/白场/中间调 | 高 | 精确亮度控制 |
| Curves | 曲线任意点调整 | 最高 | 精细亮度控制 |
| Lift/Gamma/Gain | 阴影/中间调/高光 | 高 | 专业调色标准 |

### 1.5.2 对比度（Contrast）

对比度是图像中最亮和最暗区域的差异程度。

#### 对比度类型

| 对比度类型 | 定义 | 调整工具 | 视觉效果 |
|------------|------|----------|----------|
| 整体对比度 | 最亮与最暗差异 | Brightness & Contrast | 整体明暗反差 |
| 局部对比度 | 相邻像素差异 | Clarity, Unsharp Mask | 细节清晰度 |
| 色彩对比度 | 颜色间差异 | Saturation, Vibrance | 颜色鲜艳度 |
| 微对比度 | 小范围细节 | High Pass, Sharpen | 边缘锐利度 |

#### 对比度调整策略

| 风格 | 对比度设置 | 黑场 | 白场 | 中间调 | 应用 |
|------|------------|------|------|--------|------|
| 高对比度电影感 | +15到+25 | 压暗5-10 | 保持或略提 | S曲线 | 动作片、商业片 |
| 低对比度日系 | -10到-20 | 提亮5-10 | 压低5-10 | 提亮 | 日系小清新、文艺 |
| 中性自然 | 0到+5 | 准确 | 准确 | 自然 | 纪录片、纪实 |
| 高调低对比 | -5到-15 | 提亮 | 提亮 | 提亮 | 时尚、产品广告 |
| 低调高对比 | +20到+30 | 压暗 | 保持 | 压暗 | 暗黑系、悬疑 |

### 1.5.3 饱和度（Saturation）

饱和度是颜色的纯度或鲜艳程度。

#### 饱和度分级

| 饱和度范围 | 视觉效果 | 应用场景 |
|------------|----------|----------|
| -100（去饱和） | 黑白 | 黑白电影、艺术效果 |
| -50到-80 | 极低饱和 | 战争片、压抑氛围 |
| -20到-50 | 低饱和 | 文艺片、纪实风格 |
| -10到+10 | 自然饱和 | 纪录片、真实场景 |
| +10到+30 | 中等饱和 | 商业广告、网络视频 |
| +30到+50 | 高饱和 | MV、动漫风格 |
| +50以上 | 极高饱和 | 赛博朋克、超现实 |

#### 饱和度与自然饱和度的区别

| 属性 | 饱和度（Saturation） | 自然饱和度（Vibrance） |
|------|---------------------|----------------------|
| 调整方式 | 整体统一调整 | 智能选择性调整 |
| 低饱和区域 | 同等增强 | 优先增强 |
| 高饱和区域 | 同等增强（可能过饱和） | 较少增强 |
| 肤色保护 | 无 | 自动保护 |
| 适用场景 | 全局调整 | 自然增强 |

## 1.6 直方图与波形图分析

### 1.6.1 直方图（Histogram）

直方图显示图像中各亮度级别的像素分布。

#### 直方图解读

| 直方图形态 | 画面特征 | 调整建议 |
|------------|----------|----------|
| 左侧堆积 | 画面偏暗 | 提亮阴影、增加曝光 |
| 右侧堆积 | 画面偏亮 | 压暗高光、减少曝光 |
| 中间堆积、两端空 | 低对比度 | 拉伸黑场白场、增加对比度 |
| 两端堆积、中间空 | 高对比度 | 调整中间调、降低对比度 |
| 左侧溢出 | 暗部细节丢失 | 提亮阴影、提升黑场 |
| 右侧溢出 | 高光过曝 | 压低高光、降低白场 |
| 均匀分布 | 曝光良好 | 微调即可 |
| 多峰分布 | 多个亮度区域 | 分区调整 |

#### RGB直方图分析

| 直方图类型 | 显示内容 | 用途 |
|------------|----------|------|
| 亮度直方图 | 整体亮度分布 | 检查曝光 |
| RGB直方图 | 三通道分别显示 | 检查色彩偏移 |
| 红绿蓝分离 | 各通道独立 | 精确色彩分析 |
| 叠加RGB | 三通道叠加 | 整体色彩平衡 |

### 1.6.2 波形图（Waveform）

波形图是视频调色中最重要的示波器，显示图像每一列的亮度分布。

#### 波形图类型

| 波形类型 | 显示内容 | 应用 |
|----------|----------|------|
| RGB波形 | 三通道分别显示 | 色彩平衡分析 |
| YC波形 | 亮度+色度 | 广播合规检查 |
| YCbCr波形 | 数字视频分量 | 专业视频分析 |
| 亮度波形 | 仅亮度 | 曝光分析 |

#### 波形图解读

| 波形位置 | 亮度值 | 内容 | 调整建议 |
|----------|--------|------|----------|
| 0-20 | 阴影 | 暗部细节 | 保持有信息，不溢出0 |
| 20-40 | 深中间调 | 暗部主体 | 根据需要调整 |
| 40-60 | 中间调 | 主要内容 | 关键调整区域 |
| 60-80 | 浅中间调 | 亮部主体 | 根据需要调整 |
| 80-100 | 高光 | 亮部细节 | 保持有信息，不溢出100 |

**波形图典型形态**：

| 形态 | 画面特征 | 说明 |
|------|----------|------|
| 平整水平 | 整体均匀 | 曝光均匀，画面平衡 |

| 底部密集 | 画面偏暗 | 暗调画面 |
| 顶部密集 | 画面偏亮 | 高调画面 |

### 1.6.3 分量波形（RGB Parade）

分量波形将RGB三通道分别显示，便于分析色彩平衡。

#### 分量波形分析

| 分析方法 | 现象 | 原因 | 调整 |
|----------|------|------|------|
| 三通道高度一致 | 色彩平衡 | 中性色 | 无需调整 |
| 红通道偏高 | 画面偏红 | 色温过高或红色过多 | 降低红色或降低色温 |
| 绿通道偏高 | 画面偏绿 | 绿色光源或绿色调 | 降低绿色 |
| 蓝通道偏高 | 画面偏蓝 | 色温过低或蓝色调 | 降低蓝色或提高色温 |
| 红通道偏低 | 画面偏青 | 青色调或红色不足 | 增加红色 |
| 绿通道偏低 | 画面偏品红 | 品红色调 | 增加绿色 |
| 蓝通道偏低 | 画面偏黄 | 黄色调或蓝色不足 | 增加蓝色 |

## 1.7 矢量示波器与HSL分析

### 1.7.1 矢量示波器（Vectorscope）

```python
import DaVinciResolveScript as dvr_script

def auto_color_grade(resolve, project_name, media_path, output_path):
    # 创建项目
    project_manager = resolve.GetProjectManager()
    project = project_manager.CreateProject(project_name)

        "SelectRenderCodec": "ProRes 4444",
        "TargetDir": output_path
    })
    project.AddRenderJob()
    project.StartRendering()
```

## 4.2 1D LUT vs 3D LUT

### 4.2.1 1D LUT

1D LUT只对一个通道进行独立映射，无法处理通道间的相互影响。

| 特性 | 说明 |
|------|------|
| 数据量 | 小（256×3 = 768个值） |
| 精度 | 较低 |
| 通道关系 | 独立处理，无相互影响 |
| 应用 | 伽马校正、色温调整、黑白点调整 |
| 局限 | 无法处理饱和度、色相变化 |

### 4.2.2 3D LUT

3D LUT对三个通道同时映射，可以处理通道间的复杂关系。

| 特性 | 说明 |
|------|------|
| 数据量 | 大（33³ = 35937个点） |
| 精度 | 高 |
| 通道关系 | 三通道同时映射 |
| 应用 | 胶片模拟、创意调色、色彩空间转换 |
| 优势 | 可以处理任意颜色变换 |

### 4.2.3 1D与3D LUT对比

| 特性 | 1D LUT | 3D LUT |
|------|--------|--------|
| 数据量 | 小 | 大 |
| 精度 | 低 | 高 |
| 通道关系 | 独立 | 联动 |
| 色相变化 | 不能 | 能 |
| 饱和度变化 | 不能 | 能 |
| 伽马校正 | 能 | 能 |
| 色温调整 | 能 | 能 |
| 胶片模拟 | 不能 | 能 |
| 文件大小 | KB级 | KB-MB级 |

### 4.5.3 编程方式生成LUT

```python
# Python: 生成简单的色温调整LUT
import numpy as np

def generate_warm_lut(size=33, warmth=0.1):
    """生成暖色调LUT"""
    lut = np.zeros((size, size, size, 3))
    
    for r in range(size):
        for g in range(size):
            for b in range(size):
                # 归一化到0-1
                rn = r / (size - 1)
                gn = g / (size - 1)
                bn = b / (size - 1)
                
                # 应用暖色调（增加红，减少蓝）
                rn = min(1.0, rn + warmth)
                bn = max(0.0, bn - warmth)
                
                lut[r, g, b] = [rn, gn, bn]
    
    return lut

def save_cube_lut(filename, lut):
    """保存为.cube格式"""
    size = lut.shape[0]
    with open(filename, 'w') as f:
        f.write(f'TITLE "Custom LUT"\n')
        f.write(f'LUT_3D_SIZE {size}\n')
        f.write(f'LUT_3D_INPUT_RANGE 0 1\n\n')
        
        for b in range(size):
            for g in range(size):
                for r in range(size):
                    values = lut[r, g, b]
                    f.write(f'{values[0]:.6f} {values[1]:.6f} {values[2]:.6f}\n')

# 生成并保存LUT
warm_lut = generate_warm_lut(33, 0.1)
save_cube_lut('warm_look.cube', warm_lut)
```

# 七、自适应调色系统

## 7.1 图片分析与特征提取

### 7.1.1 特征提取参数

自适应调色系统的核心是分析图片特征，自动生成调色参数。

| 特征 | 计算方法 | 应用 |
|------|----------|------|
| 平均亮度 | 所有像素亮度的平均值 | 曝光调整 |
| 亮度分布 | 直方图分析 | 对比度调整 |
| 平均饱和度 | 所有像素饱和度平均值 | 饱和度调整 |
| 色温估计 | RGB通道比例分析 | 色温调整 |
| 色调分布 | HSL色相分布 | 色调调整 |
| 对比度 | 亮度标准差 | 对比度调整 |

### 7.1.2 Python特征提取代码

```python
import cv2
import numpy as np
from PIL import Image
from colorsys import rgb_to_hls

def analyze_image(image_path):
    """分析图片特征，返回调色参数"""
    # 读取图片
    img = cv2.imread(image_path)
    img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
    
    # 1. 亮度分析
    gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    brightness = np.mean(gray)
    brightness_std = np.std(gray)
    
    # 2. 饱和度分析
    hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)
    saturation = np.mean(hsv[:, :, 1])
    
    # 3. 色温估计
    r_mean = np.mean(img_rgb[:, :, 0])
    g_mean = np.mean(img_rgb[:, :, 1])
    b_mean = np.mean(img_rgb[:, :, 2])
    color_temp = estimate_color_temp(r_mean, g_mean, b_mean)
    
    # 4. 对比度计算
    contrast = brightness_std / 255.0
    
    # 5. 直方图分析
    hist = cv2.calcHist([gray], [0], None, [256], [0, 256])
    hist_normalized = hist / hist.sum()
    
    return {
        'brightness': brightness,
        'brightness_std': brightness_std,
        'saturation': saturation,
        'color_temp': color_temp,
        'contrast': contrast,
        'r_mean': r_mean,
        'g_mean': g_mean,
        'b_mean': b_mean,
        'histogram': hist_normalized
    }

def estimate_color_temp(r, g, b):
    """根据RGB值估计色温"""
    # 简化的色温估计
    if b > r:
        # 冷色
        temp = 5500 + (b - r) * 10
    else:
        # 暖色
        temp = 5500 - (r - b) * 10
    return max(2000, min(10000, temp))

# 使用示例
features = analyze_image("input.jpg")
print(f"亮度: {features['brightness']}")
print(f"对比度: {features['contrast']}")
print(f"饱和度: {features['saturation']}")
print(f"估计色温: {features['color_temp']}K")
```

```python
def generate_color_params(features, target_style='cinematic'):
    """根据图片特征生成调色参数"""
    params = {
        'temperature': 0,
        'tint': 0,
        'exposure': 0,
        'contrast': 0,
        'highlights': 0,
        'shadows': 0,
        'saturation': 100
    }
    
    # 曝光调整
    if features['brightness'] < 100:
        params['exposure'] = int((100 - features['brightness']) * 0.3)
    elif features['brightness'] > 160:
        params['exposure'] = -int((features['brightness'] - 160) * 0.3)
    
    # 对比度调整
    if features['contrast'] < 0.2:
        params['contrast'] = int((0.2 - features['contrast']) * 100)
    elif features['contrast'] > 0.4:
        params['contrast'] = -int((features['contrast'] - 0.4) * 100)
    
    # 色温调整
    if features['color_temp'] > 6000:
        params['temperature'] = -int((features['color_temp'] - 5500) / 50)
    elif features['color_temp'] < 5000:
        params['temperature'] = int((5500 - features['color_temp']) / 50)
    
    # 饱和度调整
    if features['saturation'] < 80:
        params['saturation'] = 100 + (80 - features['saturation'])
    elif features['saturation'] > 150:
        params['saturation'] = 100 - (features['saturation'] - 150) / 2
    
    # 风格化调整
    if target_style == 'cinematic':
        params['contrast'] += 15
        params['saturation'] -= 5
        params['highlights'] = -10
        params['shadows'] = 10
    elif target_style == 'japanese':
        params['contrast'] -= 10
        params['saturation'] -= 10
        params['exposure'] += 5
        params['shadows'] += 15
    elif target_style == 'cyberpunk':
        params['temperature'] -= 25
        params['saturation'] += 30
        params['contrast'] += 20
    
    return params

# 使用示例

print(f"调色参数: {params}")
```

```python
def optimize_params(current_features, target_features, current_params):
    """优化调色参数"""
    optimized = current_params.copy()
    
    # 亮度优化
    brightness_diff = target_features['brightness'] - current_features['brightness']
    if abs(brightness_diff) > 5:
        optimized['exposure'] += brightness_diff * 0.1
    
    # 对比度优化
    contrast_diff = target_features['contrast'] - current_features['contrast']
    if abs(contrast_diff) > 0.05:
        optimized['contrast'] += contrast_diff * 50
    
    # 饱和度优化
    sat_diff = target_features['saturation'] - current_features['saturation']
    if abs(sat_diff) > 10:
        optimized['saturation'] += sat_diff * 0.5
    
    # 色温优化
    temp_diff = target_features['color_temp'] - current_features['color_temp']
    if abs(temp_diff) > 200:
        optimized['temperature'] += temp_diff / 100
    
    # 参数范围限制
    optimized['exposure'] = max(-50, min(50, optimized['exposure']))
    optimized['contrast'] = max(-50, min(50, optimized['contrast']))
    optimized['saturation'] = max(0, min(200, optimized['saturation']))
    optimized['temperature'] = max(-100, min(100, optimized['temperature']))
    
    return optimized
```

```python
def apply_color_grade(input_path, output_path, params):
    """应用调色到图片"""
    img = cv2.imread(input_path)
    
    # 色温调整
    if params['temperature'] != 0:
        img = adjust_temperature(img, params['temperature'])
    
    # 曝光调整
    if params['exposure'] != 0:
        img = adjust_exposure(img, params['exposure'])
    
    # 对比度调整
    if params['contrast'] != 0:
        img = adjust_contrast(img, params['contrast'])
    
    # 饱和度调整
    if params['saturation'] != 100:
        img = adjust_saturation(img, params['saturation'])
    
    cv2.imwrite(output_path, img)

def adjust_temperature(img, temp):
    """色温调整"""
    if temp > 0:
        img[:, :, 2] = np.clip(img[:, :, 2].astype(int) + temp, 0, 255).astype(np.uint8)
    else:
        img[:, :, 0] = np.clip(img[:, :, 0].astype(int) - temp, 0, 255).astype(np.uint8)
    return img

def adjust_exposure(img, exposure):
    """曝光调整"""
    return np.clip(img.astype(int) + exposure, 0, 255).astype(np.uint8)

def adjust_contrast(img, contrast):
    """对比度调整"""
    factor = (259 * (contrast + 255)) / (255 * (259 - contrast))
    return np.clip(factor * (img.astype(float) - 128) + 128, 0, 255).astype(np.uint8)

def adjust_saturation(img, saturation):
    """饱和度调整"""
    hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV).astype(np.float32)
    hsv[:, :, 1] = np.clip(hsv[:, :, 1] * (saturation / 100.0), 0, 255)
    return cv2.cvtColor(hsv.astype(np.uint8), cv2.COLOR_HSV2BGR)
```

```python
def generate_jsx_script(params, layer_index=1):
    """生成AE JSX调色脚本"""

(function() {{
    var comp = app.project.activeItem;
    if (!(comp instanceof CompItem)) return alert("请选择合成");
    var layer = comp.layer({layer_index});
    if (!layer) return alert("图层不存在");
    
    // 应用Levels
    var levels = layer.Effects.addProperty("ADBE Adj Layer");
    levels.property("ADBE Adj Layer Input Black").setValue({max(0, 10 - params.get('shadows', 0)/3)});
    levels.property("ADBE Adj Layer Gamma").setValue({0.95 + params.get('exposure', 0)/100});
    levels.property("ADBE Adj Layer Input White").setValue({min(255, 245 + params.get('highlights', 0)/3)});
    
    // 应用Color Balance

    cb.property("ADBE Color Balance Shadows Blue").setValue({params.get('shadow_blue', 0)});

    var hs = layer.Effects.addProperty("ADBE HUE SATURATION");
    hs.property("ADBE HUE SATURATION Master Saturation").setValue({params.get('saturation', 0) - 100});

    return jsx
```

## 8.1 一级调色→二级调色→创意调色流程

### 8.1.1 三级调色流程

| 阶段 | 名称 | 目的 | 工具 |
|------|------|------|------|
| 一级调色 | 基础校正 | 修正曝光、白平衡、对比度 | Levels, Curves, Color Balance |
| 二级调色 | 局部调整 | 针对特定区域或颜色调整 | HSL Secondary, Power Window |
| 创意调色 | 风格化 | 应用特定视觉风格 | LUT, Color Balance, Curves |

### 8.1.2 详细流程

#### 一级调色（基础校正）

| 步骤 | 操作 | 参数目标 |
|------|------|----------|
| 1 | 曝光校正 | 亮度分布均匀，直方图居中 |
| 2 | 白平衡校正 | 中性色准确，无偏色 |
| 3 | 对比度调整 | 黑场白场正确，对比适中 |
| 4 | 饱和度校正 | 颜色自然，无过饱和 |
| 5 | 色彩平衡 | RGB通道平衡 |

#### 二级调色（局部调整）

| 步骤 | 操作 | 参数目标 |
|------|------|----------|
| 1 | 肤色调整 | 肤色在肤色线上 |
| 2 | 天空调色 | 天空颜色自然或风格化 |
| 3 | 局部提亮 | 主体突出 |
| 4 | 局部压暗 | 引导视线 |
| 5 | 颜色修正 | 特定颜色调整 |

#### 创意调色（风格化）

| 步骤 | 操作 | 参数目标 |
|------|------|----------|
| 1 | 应用LUT | 整体风格基调 |
| 2 | 色调调整 | 阴影高光色彩偏移 |
| 3 | 对比度强化 | 风格化对比度 |
| 4 | 暗角添加 | 聚焦主体 |
| 5 | 颗粒添加 | 胶片质感 |

## 8.2 调色顺序的重要性

### 8.2.1 推荐调色顺序

```
1. 噪点降噪 → 2. 曝光校正 → 3. 白平衡 → 4. 对比度 → 
5. 色彩平衡 → 6. 饱和度 → 7. 二级调色 → 8. 创意LUT → 
9. 暗角 → 10. 颗粒
```

### 8.2.2 顺序影响示例

| 顺序 | 结果 |
|------|------|
| 先LUT后校正 | LUT可能破坏校正效果 |
| 先校正后LUT | 校正为LUT提供良好基础 |
| 先饱和后对比 | 对比度影响饱和度感知 |
| 先对比后饱和 | 更准确的饱和度调整 |

# 九、调色常见问题

## 9.1 色彩偏移问题

### 9.1.1 色彩偏移原因

| 原因 | 现象 | 解决方案 |
|------|------|----------|
| 白平衡错误 | 整体偏色 | 重新校正白平衡 |
| 显示器不准 | 调色不准 | 校准显示器 |
| 素材色域不同 | 色彩不一致 | 统一色彩空间 |
| LUT应用错误 | 色彩异常 | 检查LUT适配 |

## 9.2 色带问题（banding）

### 9.2.1 色带解决方案

| 方案 | 效果 | 实现 |
|------|------|------|
| 使用10bit+素材 | 最佳 | 拍摄时选择 |
| 添加噪点 | 良好 | 1-3%噪点 |
| 32bit调色 | 良好 | AE切换32bit |
| 抖动处理 | 良好 | 输出时启用 |

## 9.3 肤色保护

### 9.3.1 肤色保护技巧

| 技巧 | 方法 |
|------|------|
| HSL选区 | 选择肤色范围单独调整 |
| 肤色线对齐 | 矢量示波器对齐肤色线 |
| 避免过饱和 | 肤色饱和度适中 |
| 使用Vibrance | 自动保护肤色 |

## 9.4 高光/阴影细节丢失

### 9.4.1 细节恢复方法

| 问题 | 解决方案 |
|------|----------|
| 高光过曝 | 降低高光，使用Highlights效果 |
| 阴影过暗 | 提升阴影，使用Shadows效果 |
| 细节丢失 | 使用Shadow/Highlight效果 |

## 9.5 跨平台色彩一致性

### 9.5.1 跨平台问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 不同设备显示不同 | 色彩空间差异 | 统一色彩空间 |
| 网络平台压缩 | 平台二次编码 | 预留调整余量 |
| 移动端偏色 | 屏幕差异 | 多设备测试 |

## 9.6 调色后画面变暗/变亮的解决方案

### 9.6.1 亮度问题解决

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 调色后变暗 | 对比度过高 | 降低对比度或提亮中间调 |
| 调色后变亮 | 黑场提升 | 压低黑场 |
| LUT后变暗 | LUT设计如此 | 调整LUT强度或提亮 |

## B.1 标准调色工作流模板

### B.1.1 短视频调色工作流

```
1. 素材导入
2. 基础校正（曝光、白平衡）
3. 对比度调整
4. 色彩平衡
5. 饱和度调整
6. 应用LUT
7. 局部调整
8. 暗角添加
9. 输出
```

### B.1.2 电影调色工作流

```
1. 素材导入与整理
2. 色彩空间转换（CST）
3. 一级调色（校正）
   - 曝光校正
   - 白平衡
   - 对比度
   - 色彩平衡
4. 二级调色（局部）
   - 肤色调整
   - 天空调整
   - 局部提亮
5. 创意调色（风格）
   - 应用LUT
   - 色调调整
   - 暗角
6. 输出转换（CST）
7. 渲染输出
```

### B.1.3 MV调色工作流

```
1. 素材分析
2. 风格确定
3. 基础校正
4. 风格化调色
5. 特效调色（Glow、Glitch等）
6. 节拍同步调色
7. 最终输出
```

## B.2 调色节点树模板

### B.2.1 标准节点树

```
[CST输入] → [一级校正] → [对比度] → [二级调色] → [创意LUT] → [CST输出]
```

### B.2.2 高级节点树

```
[CST输入] → [一级校正] → [皮肤修饰] ∥ [天空调色] ∥ [前景调色] → [混合器] → [创意LUT] → [胶片颗粒] → [CST输出]
```


```javascript
// 电影感调色预设
function applyCinematicPreset(layer) {
    // Levels
    var levels = layer.Effects.addProperty("ADBE Adj Layer");
    levels.property("ADBE Adj Layer Input Black").setValue(10);
    levels.property("ADBE Adj Layer Gamma").setValue(0.95);
    levels.property("ADBE Adj Layer Input White").setValue(245);
    
    // Color Balance
    var cb = layer.Effects.addProperty("ADBE Color Balance");
    cb.property("ADBE Color Balance Shadows Red").setValue(-15);
    cb.property("ADBE Color Balance Shadows Blue").setValue(15);
    cb.property("ADBE Color Balance Highlights Red").setValue(15);
    cb.property("ADBE Color Balance Highlights Blue").setValue(-15);
    cb.property("ADBE Color Balance Preserve Luminosity").setValue(1);
    
    // Hue/Saturation
    var hs = layer.Effects.addProperty("ADBE HUE SATURATION");
    hs.property("ADBE HUE SATURATION Master Saturation").setValue(-5);
    
    // Vignette
    var vg = layer.Effects.addProperty("ADBE Vignette");
    vg.property("Amount").setValue(-30);
    vg.property("Midpoint").setValue(40);
}
```

## F.1 色彩偏移问题详解

### F.1.1 色彩偏移诊断流程

```
1. 检查白平衡 → 2. 检查色彩空间 → 3. 检查LUT → 4. 检查显示器 → 5. 检查素材
```

### F.1.2 常见色彩偏移及解决方案

| 偏色类型 | 原因 | 解决方案 |
|----------|------|----------|
| 整体偏蓝 | 色温过高 | 降低色温 |
| 整体偏黄 | 色温过低 | 提高色温 |
| 整体偏绿 | 色调异常 | 调整色调（Tint） |
| 整体偏品红 | 色调异常 | 调整色调（Tint） |
| 阴影偏色 | Color Balance错误 | 调整阴影色彩平衡 |
| 高光偏色 | Color Balance错误 | 调整高光色彩平衡 |
| 肤色偏色 | 肤色调整不当 | 使用HSL Secondary调整 |

## F.2 色带问题详解

### F.2.1 色带产生原因

| 原因 | 说明 | 预防 |
|------|------|------|

### G.1.3 调色参数导入导出

```javascript
// 导出调色参数
function exportColorGrade(layer) {
    var grade = {
        effects: []
    };
    
    for (var i = 1; i <= layer.Effects.numProperties; i++) {
        var effect = layer.Effects.property(i);
        var effectData = {
            name: effect.name,
            matchName: effect.matchName,
            properties: {}
        };
        
        for (var j = 1; j <= effect.numProperties; j++) {
            var prop = effect.property(j);
            if (prop.canSetValue) {
                effectData.properties[prop.name] = prop.value;
            }
        }
        
        grade.effects.push(effectData);
    }
    
    return JSON.stringify(grade);
}

// 导入调色参数
function importColorGrade(layer, gradeJson) {
    var grade = JSON.parse(gradeJson);
    
    grade.effects.forEach(function(effectData) {
        var effect = layer.Effects.addProperty(effectData.matchName);
        
        for (var propName in effectData.properties) {
            var prop = effect.property(propName);
            if (prop && prop.canSetValue) {
                prop.setValue(effectData.properties[propName]);
            }
        }
    });
}
```

## G.2 Python调色自动化

### G.2.1 完整调色系统

```python
class AutoColorGradeSystem:
    """自动调色系统"""
    
    def __init__(self):
        self.style_presets = {
            'cinematic': {'temperature': -10, 'contrast': 20, 'saturation': 95},
            'japanese': {'temperature': -5, 'contrast': -15, 'saturation': 90},
            'cyberpunk': {'temperature': -30, 'contrast': 25, 'saturation': 130},
            'vintage': {'temperature': 15, 'contrast': 10, 'saturation': 85}
        }
    
    def analyze_and_grade(self, image_path, style='cinematic'):
        """分析并调色"""
        features = self.analyze_image(image_path)
        params = self.generate_params(features, style)
        jsx = self.generate_jsx(params)
        return {'features': features, 'params': params, 'jsx': jsx}
    
    def analyze_image(self, image_path):
        """分析图片特征"""
        import cv2
        import numpy as np
        
        img = cv2.imread(image_path)
        gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
        hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)
        
        return {
            'brightness': np.mean(gray),
            'contrast': np.std(gray) / 255.0,
            'saturation': np.mean(hsv[:, :, 1]),
            'color_temp': self.estimate_color_temp(img)
        }
    
    def generate_params(self, features, style):
        """生成调色参数"""
        preset = self.style_presets.get(style, {})
        return {
            'temperature': preset.get('temperature', 0),
            'contrast': preset.get('contrast', 0),
            'saturation': preset.get('saturation', 100)
        }
    
    def generate_jsx(self, params):
        """生成JSX脚本"""
        return f"""
        var layer = app.project.activeItem.layer(1);
        var cb = layer.Effects.addProperty("ADBE Color Balance");
        var hs = layer.Effects.addProperty("ADBE HUE SATURATION");
        hs.property("ADBE HUE SATURATION Master Saturation").setValue({params['saturation'] - 100});
        """
```
