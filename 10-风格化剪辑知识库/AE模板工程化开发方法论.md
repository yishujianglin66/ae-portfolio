# 🏗️ AE 模板工程化开发方法论

> 把 AE 项目当作**软件产品**来开发——架构设计、表达式编码、MOGRT 封装、市场分发、持续迭代。

---

## 🧱 模板结构与组织

### 命名规范

用统一前缀一目了然分类：
```
CMP_  合成（Composition）
PRE_  预合成（Precomp）
FFX_  效果（Effects）
CTRL_ 控制层（Controls）
```

**绝不**留下"Layer 1"或"Text Copy 3"。

### 文件夹结构（磁盘 + AE 项目同步）

```
project_root/
  01_Footage/        — 源视频/图像
  02_Audio/          — 音乐、音效
  03_Graphics/       — AI/PSD 链接文件
  04_Project/        — .aep 文件
  05_Prerenders/     — 烘焙重合成
  06_Renders/        — 最终输出
```

### 核心原则

- **从主模板项目起步**——预配好 Bins、色标、引导层、安全边距
- **唯一主合成**（通常命名 `main`）——自动化工具和 MOGRT 的入口
- **锁定静态层**——防止开发/交接时的意外编辑
- **单职责预合成**——每个预合成只做一件事（开场/转场/下三分之一标题/背景）

## 🧬 表达式：模板的"代码层"

### 核心表达式技术

| 技术 | 用途 |
|------|------|
| `sourceRectAtTime()` | 背景框自动匹配文字尺寸 |
| `linear()` / `ease()` | 滑块值映射到动画范围 |
| `if/else` 条件 | 切换可见性、切换动画变体 |
| `seedRandom()` | **关键**——保证跨渲染一致随机 |
| 集中控制 Null | 所有表达式控件放一个 Null 层 |
| 下拉菜单（表达式驱动）| 滑块→文本映射实现多选 |

### 关键警告

- **禁用不含 seed 的 random()**——每次渲染不同输出，自动化灾难
- 避免硬编码文件路径
- 将昂贵的时间表达式转为关键帧
- 使用**现代 JavaScript 引擎**（CC 2019+）——比 Legacy ExtendScript 快 ~5x

## 🎛️ Master Properties 与 Essential Graphics Panel（EGP）

### Master Properties 工作流

1. 将合成嵌套到另一个合成中（Precomp）
2. 拖时间线中的图层/效果属性到 EGP
3. 它们成为外部合成中 Precomp 层的可覆盖 **Master Properties**
4. 覆盖值"断链"于源——**创建唯一实例**
5. Pull/Push 按钮丢弃或回写变更到源

### 响应式设计

用 **Protected Regions**（销钉和填充）→ 背景框随文字长度自动缩放 → 结合 `sourceRectAtTime()` 实现全动态。

## 📦 MOGRT：Motion Graphics Templates

MOGRT 是 AE 模板的**编译后二进制格式**，可在 Premiere Pro 中使用而无需 AE。

### 创建流程

1. AE 中完成动画
2. 打开 EGP，选择**主要合成**
3. 拖支持的属性进入 EGP（文字/颜色/滑块/复选框）
4. 重命名控件、分组、加注释
5. 拖图像/视频层入 EGP 做媒体替换
6. 点击**导出动态图形模板**
7. 选择目标：CC Libraries / 本地模板文件夹 / 本地驱动器

### 关键限制

- 仅 Classic 3D 渲染器支持
- 无 Puppet Tool / Warp Stabilizer / Dynamic Link 素材
- 第三方插件阻止 Premiere 内免 AE 使用
- 当文字通过表达式来自其他图层时，字体控件不工作

### 版本控制

通过 **Creative Cloud Libraries** 分发——设计者更新模板，编辑者在 PR 中收到更新提示。

## 🔧 模板性能优化

| 策略 | 效果 |
|------|------|
| **预渲染重效果**（粒子/发光/3D/置换）| 渲染时间减 50-80% |
| **Reduce Project**（文件→依赖关系→精简项目）| 清除未用资产 |
| **裁剪预合成**到可见区域 | 减少像素处理 |
| **代理工作流** | 编辑用轻代理，最终渲染切全分辨率 |
| `aerender` CLI **-noui** 模式 | 跳过 UI 开销 |
| 独立 SSD 做磁碟缓存 30GB+ | 显著加速 |

## 🚫 七大常见 Bug

| Bug | 原因 | 预防 |
|-----|------|------|
| 打开缺文件 | 用户从 .zip 内直接打开 | 文档加"先全部解压" |
| 缺字体 | 用户未安装 | 用 Google Fonts / Adobe Fonts（自动同步）|
| 插件缺失 | 用户没买 | **产品页明确列出** |
| 非英文 AE 表达式报错 | 表达式引用英文属性名 | 用 `matchName`，至少测一种非英文 AE |
| 版本不兼容 | CC 2024+ 模板在 CC 2020 打开 | 产品页标最低版本 |
| 表达式引擎不匹配 | 现代 JS vs Legacy | 文档注明引擎要求 |
| 播放慢/崩溃 | 优化不足 | 预渲染、代理、精简项目 |

## 🌐 本地化/国际化

### 核心策略

| 方法 | 工具 | 能力 |
|------|------|------|
| **AE 内 AI 翻译** | LingoFlip ($22) / AE Sheets ($69) | 扫描所有文字层→创建翻译合成→自动字体大小+映射 |
| **电子表驱动** | Templater / Text2Spreadsheet | 导出文字到表格→外部翻译→重新导入 |
| **云端全自动** | Adobe DGR API / Plainly + Airtable + ChatGPT + 11Labs | 输入内容→20+ 语言→AI 配音→自动渲染→交付 |

### 关键考量

- **RTL**：阿拉伯语/希伯来语/乌尔都语需镜像布局
- **CJK**：中日韩需特定字体+行高调整
- **文本扩展**：德语可能比英语长 30%+
- **垂直文字**：日文和某些中文排布需求

## 🤖 脚本与自动化

### ExtendScript 关键用例

| 用例 | 方法 |
|------|------|
| 批处理表达式应用/移除/禁用 | 遍历 `app.project` 图层树 |
| CSV 驱动文字导入/导出 | `File` 对象读 CSV |
| 批处理渲染队列填充 | `app.project.renderQueue.items.add()` |
| 自动字体替换 | 遍历所有文字层 |
| 错开/级联动画生成 | 脚本添加顺序关键帧+缓动 |

### 自动化平台

| 平台 | 模式 | 能力 |
|------|------|------|
| **Nexrender** | Node.js CLI | 无头 AE 渲染 + 数据注入 |
| **Templater**（Dataclay）| 插件 | 电子表集成+CLI+事件脚本 API |
| **Plainly** | 云端 | Airtable/Zapier 集成 |
| **Adobe DGR API** | Adobe 官方 | CSV→MOGRT→批量渲染 |
