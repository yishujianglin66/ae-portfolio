## 🎨 预设效果参数库

### 四、调色预设

| 风格 | 参数设置 | AE效果组合 |
|------|---------|-----------|
| **日系清新** | 高光-20, 阴影+20, 对比度-15, 饱和度-10, 色温+5 | 曲线 + 颜色平衡 + 饱和度 |
| **电影胶片** | 对比度+20, 饱和度-15, 高光+10, 阴影+10, 颗粒+15 | Curves + Film Grain + Vignette |
| **赛博朋克** | 青色+30, 洋红+20, 高光青色+40, 阴影蓝色+30 | 颜色平衡 + 色调分离 + Glow |
| **复古港风** | 色温+15, 色调+10, 饱和度+20, 对比度+10 | 颜色校正 + 曲线 + 暗角 |
| **黑白电影** | 饱和度-100, 对比度+30, 高光-10, 阴影+10 | 黑白效果 + 曲线 + 颗粒 |

### 五、转场预设

| 转场类型 | 参数设置 | AE效果组合 |
|----------|---------|-----------|
| **缩放转场** | 缩放从100%到120%再到100%, 持续0.5秒 | Scale Keyframes + Ease In/Out |
| **闪白转场** | 白色图层从0%到100%再到0%, 持续0.1秒 | White Solid + Opacity Keyframes |
| **模糊转场** | 高斯模糊从0到100再到0, 持续0.3秒 | Gaussian Blur + Keyframes |
| **位移转场** | 画面向左移出, 新画面向右移入 | Position Keyframes + Overlap |
| **溶解转场** | 透明度从100%到0%, 持续0.4秒 | Crossfade |

### 六、文字动画预设

| 动画类型 | 参数设置 | AE效果组合 |
|----------|---------|-----------|
| **打字机** | 逐字显示, 光标闪烁, 速度20字/秒 | Text Animator (Range Selector) + Blink |
| **弹跳进入** | 缩放从0到110%再到100%, 持续0.3秒 | Scale Keyframes + Elastic Ease |
| **淡入上浮** | 透明度0→100, Y轴-50→0, 持续0.5秒 | Opacity + Position Keyframes |
| **扫光效果** | 线性渐变从左到右, 叠加模式 | Gradient Overlay + Position Animation |

## 🎯 速通复刻方案

### 七、10分钟复刻抖音热门模板

```
模板: 赛博朋克卡点变装

步骤1: 创建合成 (1920×1080, 30fps)
步骤2: 导入音乐和视频片段
步骤3: 音频分析 (Audio Spectrum效果)
步骤4: 设置节拍标记 (自动或手动)
步骤5: 在节拍点切割视频
步骤6: 添加转场 (缩放+模糊)
步骤7: 添加效果
  - CC Glow (发光半径20, 强度1.5)
  - CC Lens Distortion (扭曲度20)
  - Scan Lines (扫描线效果)
步骤8: 添加文字 (赛博朋克字体)
步骤9: 调色 (青色+洋红)
步骤10: 渲染输出
```

### 八、AE预设打包指南

```jsx
// 保存预设
app.project.activeItem.selectedProperties[0].savePreset("MyPreset.ffx");

// 加载预设
app.project.activeItem.selectedProperties[0].applyPreset(File("MyPreset.ffx"));
```
