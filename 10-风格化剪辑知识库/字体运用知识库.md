## 一、字体基础知识

### 1.1 字体分类

**按字族分类**：

| 分类 | 特点 | 示例 |
|------|------|------|
| 衬线体（Serif） | 字脚有装饰线条 | Times New Roman, 宋体, 思源宋体 |
| 无衬线体（Sans-serif） | 字脚无装饰线条 | Arial, 黑体, 思源黑体 |
| 手写体（Script） | 模拟手写效果 | Brush Script, 华文行楷 |
| 装饰体（Display） | 特殊装饰效果 | Impact, 综艺体 |
| 等宽体（Monospace） | 每个字宽度相同 | Consolas, 仿宋 |

**按风格分类**：

| 风格 | 特点 | 适用场景 |
|------|------|---------|
| 常规（Regular） | 标准样式 | 正文、通用 |
| 粗体（Bold） | 笔画加粗 | 标题、强调 |
| 斜体（Italic） | 倾斜样式 | 引用、强调 |
| 细体（Light/Thin） | 笔画纤细 | 副标题、优雅感 |
| 中等（Medium） | 介于常规和粗体之间 | 标题、导航 |
| 特粗（Extra Bold/Bold） | 极粗笔画 | 大标题、冲击 |

**按语言分类**：

| 语言 | 特点 | 推荐字体 |
|------|------|---------|
| 中文 | 方块字，字形复杂 | 思源黑体、阿里巴巴普惠体 |
| 英文 | 字母文字，字形简单 | Montserrat, Roboto, Helvetica |
| 日文 | 假名+汉字混合 | Source Han Sans JP, ヒラギノ |
| 韩文 | 谚文字母 | Source Han Sans KR, 나눔고딕 |

### 1.2 字体文件格式

| 格式 | 特点 | 适用场景 |
|------|------|---------|
| TrueType (.ttf) | 最通用，跨平台 | Windows, macOS, AE |
| OpenType (.otf) | 支持更多字形，高级特性 | 专业排版 |
| Web Open Font Format (.woff/.woff2) | 网页专用，压缩率高 | 网页设计 |
| Embedded OpenType (.eot) | IE专用 | 旧版IE兼容 |
| SVG Font (.svg) | 矢量格式 | 网页、移动端 |

**字体格式选择建议**：
- AE项目：优先使用 .otf 或 .ttf
- 网页：使用 .woff2（现代浏览器）
- 跨平台项目：同时提供 .ttf 和 .otf

### 1.3 字体度量指标

| 指标 | 说明 | 影响 |
|------|------|------|
| 字高（Ascender） | 从基线到最高点的距离 | 影响行高 |
| 字深（Descender） | 从基线到最低点的距离 | 影响行高 |
| 大写高度（Cap Height） | 大写字母高度 | 影响大小写对齐 |
| x高度（x-height） | 小写字母x的高度 | 影响可读性 |
| 字宽（Width） | 字符宽度 | 影响字距和排版 |
| 字重（Weight） | 笔画粗细 | 影响视觉层级 |

## 二、字体选择指南

### 2.1 字体选择原则

**可读性原则**：
1. 正文字体需要高可读性，避免过于花哨的字体
2. 标题字体可以更有个性，但仍需保持辨识度
3. 小字号使用简洁字体，大字号可以使用装饰性字体

**风格匹配原则**：
1. 科技感：使用简洁的无衬线体（Roboto, Montserrat）
2. 文艺风：使用衬线体或手写体（Playfair Display, Lora）
3. 商务风：使用稳重的无衬线体（Helvetica, Poppins）
4. 活泼风：使用圆润或有个性的字体（Nunito, Bangers）

**对比度原则**：
1. 标题和正文使用不同字族形成对比
2. 使用字重和字号创建层级
3. 避免使用过多字体（一般不超过3种）

## 三、字体搭配技巧

### 3.1 搭配原则

**1. 字族对比**：
- 衬线体 + 无衬线体：经典组合，层次分明
- 无衬线体 + 手写体：现代与个性的结合
- 避免同字族搭配：缺乏对比，视觉单调

**2. 字重对比**：
- 标题使用粗体，正文使用常规或细体
- 同一字族不同字重搭配：保持统一感
- 使用中等字重作为过渡

**3. 大小对比**：
- 标题字号明显大于正文
- 建立清晰的层级关系（大标题 > 小标题 > 正文 > 注释）
- 避免字号过于接近

**4. 颜色对比**：
- 标题使用主色，正文使用深色
- 确保文字与背景的对比度（WCAG标准：最小对比度4.5:1）
- 使用颜色区分不同层级

## 四、字体参数规范

### 4.1 字号规范

**视频/屏幕设计**：

| 元素 | 推荐字号（1080p） | 推荐字号（4K） | 说明 |
|------|------------------|---------------|------|
| 大标题 | 64-96px | 128-192px | 主标题，醒目 |
| 副标题 | 32-48px | 64-96px | 次要标题 |
| 正文 | 20-28px | 40-56px | 主要内容 |
| 小标题 | 18-24px | 36-48px | 段落标题 |
| 注释 | 14-18px | 28-36px | 辅助信息 |
| 页脚 | 12-16px | 24-32px | 版权、日期 |

**印刷设计**：

| 元素 | 推荐字号 | 说明 |
|------|---------|------|
| 大标题 | 36-48pt | 主标题 |
| 副标题 | 24-32pt | 次要标题 |
| 正文 | 10-12pt | 书籍、文档 |
| 注释 | 8-10pt | 脚注、说明 |

### 4.2 字间距规范

**字距（Tracking/Kerning）**：

| 场景 | 推荐值 | 说明 |
|------|-------|------|
| 正文 | 0-10 | 正常阅读 |
| 大标题 | 10-50 | 增加字距提升气质 |
| 超大型标题 | 50-100+ | 夸张效果 |
| 紧凑排版 | -5到0 | 节省空间 |

**行距（Leading/Line Height）**：

| 场景 | 推荐比例 | 说明 |
|------|---------|------|
| 正文 | 1.5-1.8 | 舒适阅读 |
| 标题 | 1.1-1.3 | 紧凑有力 |
| 多行文本文字 | 1.6-2.0 | 清晰易读 |
| 紧凑排版 | 1.2-1.4 | 节省空间 |

### 4.3 安全区域规范

**视频安全区域**：

| 区域类型 | 安全边距（1080p） | 安全边距（4K） | 说明 |
|---------|------------------|---------------|------|
| 标题安全区 | 左右60px，上下40px | 左右120px，上下80px | 标题不被裁剪 |
| 正文安全区 | 左右40px，上下30px | 左右80px，上下60px | 正文不被裁剪 |
| 字幕安全区 | 左右20px，底部40px | 左右40px，底部80px | 字幕不被遮挡 |
| 边缘安全区 | 左右20px，上下20px | 左右40px，上下40px | 避免边缘失真 |

**不同平台的安全区域**：

| 平台 | 安全区域 | 注意事项 |
|------|---------|---------|
| YouTube | 标题距边缘至少10% | 避免被UI遮挡 |
| 抖音/快手 | 底部留100px | 避免被评论区遮挡 |
| B站 | 顶部留50px，底部留80px | 避免被播放控制遮挡 |
| 微信视频号 | 四周留5% | 适配不同屏幕 |
| 电视播放 | 四周留10-15% | 电视边框裁剪 |

## 六、字体资源管理

### 6.1 字体安装

**Windows**：
1. 下载字体文件（.ttf 或 .otf）
2. 右键点击字体文件，选择"安装"
3. 或复制到 C:\Windows\Fonts 目录

**macOS**：
1. 下载字体文件
2. 双击字体文件，点击"安装字体"
3. 或复制到 /Library/Fonts 目录

**AE中使用**：
1. 确保字体已安装在系统中
2. AE启动时会自动加载系统字体
3. 如果字体未显示，重启AE

### 6.2 字体打包与迁移

**打包步骤**：
1. 收集项目中使用的所有字体文件
2. 创建字体文件夹，命名为"Fonts"
3. 将字体文件放入文件夹
4. 记录字体列表和版本

**迁移步骤**：
1. 将字体文件夹复制到目标电脑
2. 在目标电脑上安装所有字体
3. 打开项目，确认字体正常显示

## 八、字体问题排查

### 8.1 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 字体未显示 | 字体未安装或AE未加载 | 安装字体并重启AE |
| 文字乱码 | 字体不支持该语言 | 使用支持该语言的字体 |
| 文字模糊 | 抗锯齿设置不当 | 调整抗锯齿设置 |
| 文字被裁剪 | 超出安全区域 | 调整文字位置和大小 |
| 导出后字体丢失 | 字体未嵌入 | 使用系统字体或确保字体已安装 |
| 字体变形 | 字号太小或渲染引擎问题 | 增大字号或更换渲染引擎 |
| 字距不均匀 | 字体设计问题 | 使用字距微调或更换字体 |

## 十三、字体排版黄金法则

本章详细阐述字体排版的50条黄金法则，涵盖层级设计、对比度、留白、对齐、网格系统、黄金比例等核心知识，是视觉设计的基础规范。

### 13.1 字体层级设计法则（H1-H6规范）

字体层级是信息架构的视觉表达，通过字号、字重、颜色等属性建立清晰的信息优先级。

#### 层级规范表

| 层级 | 用途 | 推荐字号（1080p视频） | 推荐字号（网页） | 推荐字重 | 推荐字距 |
|------|------|----------------------|-----------------|---------|---------|
| H1 | 主标题 | 64-96px | 32-48px | Bold/Black | -2到5 |
| H2 | 副标题/章节标题 | 48-64px | 24-32px | Bold/SemiBold | -1到5 |
| H3 | 小节标题 | 32-48px | 20-24px | SemiBold/Medium | 0到10 |
| H4 | 段落标题 | 24-32px | 18-20px | Medium/Regular | 0到10 |
| H5 | 子标题 | 20-24px | 16-18px | Medium/Regular | 0到10 |
| H6 | 强调文字 | 18-20px | 14-16px | Medium | 0到15 |
| 正文 | 主体内容 | 20-28px | 14-16px | Regular | 0到10 |
| 注释 | 辅助信息 | 14-18px | 12-14px | Regular/Light | 0到15 |

#### 层级设计法则

**法则1：字号对比原则**
- 相邻层级字号比建议为1.2-1.5倍（黄金比例约1.618）
- H1与正文字号比建议为3-4倍
- 避免相邻层级字号过于接近（差异应大于30%）

**法则2：字重对比原则**
- 标题使用Bold/Black，正文使用Regular
- 通过字重变化而非仅靠字号建立层级
- 避免在同一层级使用过多不同字重

**法则3：颜色层级原则**
- 标题使用深色或主色，正文使用中灰色
- 通过颜色深浅建立视觉层级
- 确保所有层级文字的可读性

**法则4：字体族层级原则**
- 标题和正文可使用不同字族形成对比
- 常见组合：衬线标题 + 无衬线正文
- 同一项目字体族不宜超过3种

### 13.2 字体对比度设计法则

对比度是视觉设计的核心，通过对比创造视觉张力和信息层级。

#### 对比度类型详解

**法则5：大小对比法则**
- 最大与最小字号比至少为3:1
- 理想大小对比为4:1到6:1
- 大标题使用展示字号（64px+），正文使用标准字号（16-20px）

**法则6：字重对比法则**
- 标题使用粗体（700+），正文使用常规体（400）
- 通过字重差异建立强弱对比
- 避免使用过多中间字重造成层级模糊

**法则7：颜色对比法则**
- 文字与背景对比度至少4.5:1（WCAG AA标准）
- 大文字（24px+）对比度至少3:1
- 品牌色文字需确保可读性

**法则8：字体族对比法则**
- 衬线体 + 无衬线体 = 经典对比
- 装饰体 + 无衬线体 = 个性对比
- 手写体 + 无衬线体 = 温度对比
- 避免同族搭配（如两种衬线体），缺乏对比

**法则9：风格对比法则**
- 罗马体 + 斜体 = 微妙对比
- 大写 + 小写 = 结构对比
- 紧凑 + 宽松 = 空间对比

### 13.3 字体留白设计法则

留白（Negative Space）是排版呼吸感的来源，合理的留白让设计更具品质感。

#### 留白规范

**法则10：行距法则**
- 正文行距为字号的1.4-1.8倍
- 标题行距为字号的1.1-1.3倍
- 长文本行距宜大（1.6-1.8），短文本行距宜小（1.2-1.4）

**法则11：字距法则**
- 正文Tracking：0到10（基本无变化）
- 小标题Tracking：5到20（略加宽）
- 大标题Tracking：-5到20（视设计而定）
- 超大标题Tracking：20到100+（拉开提升气质）

**法则12：段间距法则**
- 段间距为行距的1.5-2.5倍
- 段间距大于行距，确保段落分明
- 避免段间距过小导致段落不分

**法则13：边距法则**
- 安全边距至少为画布宽度的5-10%
- 标题安全区大于正文安全区
- 移动端边距建议为屏幕宽度的5-8%

**法则14：元素间距法则**
- 标题与正文间距为标题字号的0.5-1倍
- 图片与文字间距为正文字号的1-2倍
- 相关元素间距小，不相关元素间距大（亲密性原则）

### 13.4 字体对齐设计法则

对齐方式影响阅读节奏和视觉秩序。

**法则15：左对齐法则**
- 正文首选左对齐，阅读最自然
- 左对齐保持左边缘整齐，右边缘自然
- 适用于大多数文本内容

**法则16：居中对齐法则**
- 标题、短文本可用居中对齐
- 居中对齐的正文不超过3-4行
- 居中对齐需要左右留白对称

**法则17：右对齐法则**
- 用于特殊设计效果
- 适合数据、数字、日期
- 不适合长正文阅读

**法则18：两端对齐法则**
- 报纸、书籍可用两端对齐
- 需要注意行末避免出现大空隙
- 视频和屏幕设计慎用

**法则19：混合对齐法则**
- 同一版面不超过2种对齐方式
- 标题和正文可使用不同对齐
- 确保视觉有一条隐含的对齐线

### 13.5 字体网格系统设计

网格系统是排版的骨架，确保布局有序和一致。

**法则20：列网格法则**
- 常用列数：2列、3列、4列、6列、12列
- 12列网格最灵活，适合复杂布局
- 列间距为正文字号的1-2倍

**法则21：基线网格法则**
- 所有文字元素对齐到基线网格
- 基线间距通常为正文字号的1.4-1.8倍
- 确保不同元素之间的垂直节奏一致

**法则22：模块网格法则**
- 将画面划分为等高模块
- 每个模块高度为基线的倍数
- 图片和文字对齐到模块边界

**法则23：横向网格法则**
- 使用黄金分割（1:1.618）划分横向区域
- 标题区:正文区 = 1:2 或 2:3
- 天头（上边距）> 地脚（下边距）

### 13.6 黄金比例在排版中的应用

**法则24：黄金比例字号法则**
- H1:H2:H3 ≈ 1.618:1:0.618
- 正文:H1 ≈ 1:2.618 或 1:3.236
- 利用斐波那契数列确定字号阶梯

**法则25：黄金比例留白法则**
- 画面比例：内容区:留白区 ≈ 1.618:1
- 上边距:下边距 ≈ 1.618:1
- 左边距:右边距 ≈ 1:1（对称）或 1.618:1（不对称）

**法则26：黄金比例版面法则**
- 将版面按黄金比例分割
- 重要内容放置在黄金分割点
- 视觉重心在画面1/3或2/3处

### 13.7 视觉重心与平衡

**法则27：视觉重心法则**
- 大字号、粗字重、深颜色 = 重量大
- 小字号、细字重、浅颜色 = 重量小
- 画面左右重量应基本平衡

**法则28：对称平衡法则**
- 中轴对称：庄重、正式
- 适合官方、正式场合
- 可能过于严肃，缺乏活力

**法则29：不对称平衡法则**
- 左大右小或左小右大
- 通过重量感平衡视觉
- 更具设计感和现代感

**法则30：张力平衡法则**
- 对角线构图创造动态平衡
- 通过引导线创造视觉流动
- 适合动感、活跃的设计

### 13.8 排版细节法则

**法则31：行长法则**
- 中文每行20-35字
- 英文每行45-75字符（含空格）
- 理想行长为50-65字符

**法则32：断行法则**
- 避免孤行（Orphan，段落首行出现在页面底部）
- 避免寡行（Widow，段落末行出现在页面顶部）
- 标题不与正文分页

**法则33：标点法则**
- 中文使用全角标点，英文使用半角标点
- 标点不出现在行首（避头尾）
- 引号、括号等成对标点不分开

**法则34：数字法则**
- 大数字使用千位分隔符（1,000,000）
- 货币符号紧贴数字（¥100, $50）
- 表格中数字右对齐

**法则35：强调法则**
- 优先使用字重变化（Bold）而非斜体
- 中文不使用斜体（设计字体而非倾斜）
- 下划线仅用于超链接

**法则36：大小写法则**
- 英文标题使用Title Case或ALL CAPS
- ALL CAPS需要增加字距（Tracking +50到+100）
- 正文使用Sentence case

**法则37：字距微调法则**
- 大字号标题需要手动微调字距（Kerning）
- 注意AV、AW、VA、LT等字母组合
- 中文字距基本统一，注意标点字距

**法则38：行末对齐法则**
- 避免行末出现单个字符
- 避免行末标点悬挂过长
- 两端对齐时注意词距均匀

**法则39：视觉补偿法则**
- 圆形字母（O、C）在视觉上偏小，需略微放大或上移
- 字号相同时，大写字母比小写字母视觉更大
- 深色背景上的白色文字视觉上更粗，需使用更细字重

**法则40：色彩层级法则**
- 主标题：最深色或主色
- 副标题：次深色
- 正文：中深色
- 注释：中灰色
- 确保色彩层级与字号层级一致

### 13.9 排版一致性法则

**法则41：字体限制法则**
- 一个项目最多使用2-3种字体
- 标题1种 + 正文1种 + 强调1种
- 字体过多导致视觉混乱

**法则42：字号阶梯法则**
- 预设5-8级字号阶梯
- 所有文字使用阶梯中的字号
- 避免随意设定字号

**法则43：间距系统法则**
- 基于8px或4px间距系统
- 所有间距为基数的倍数
- 确保间距一致性

**法则44：颜色系统法则**
- 预设文字颜色色板（3-5个）
- 不同层级使用固定颜色
- 避免随意使用颜色

**法则45：对齐系统法则**
- 全局对齐到统一的网格
- 所有元素水平/垂直对齐
- 避免随意摆放

### 13.10 特殊排版法则

**法则46：竖排法则**
- 中文竖排从右到左
- 标点符号旋转90度
- 英文竖排需旋转或堆叠

**法则47：混排法则**
- 中英文混排时，英文略小于中文
- 中英文之间留1/4字宽空隙
- 数字与中文之间也需留空隙

**法则48：叠加法则**
- 文字叠加图片时需确保可读性
- 使用半透明遮罩或文字阴影
- 避免文字与图片复杂区域重叠

**法则49：动效法则**
- 文字动效遵循自然运动规律
- 缓动函数使用Ease In Out
- 动效持续时间200-600ms

**法则50：响应式法则**
- 使用相对单位（em、rem、%）设定字号
- 不同屏幕尺寸调整字号比例
- 确保最小字号可读（不小于12px）

## 十四、多语言字体搭配

本章详述中英日韩多语言混排的字体匹配方案，涵盖字号匹配、行高匹配、字距匹配等核心技术。

### 14.1 多语言混排基础

#### 多语言混排挑战

| 挑战 | 说明 | 解决方案 |
|------|------|---------|
| 字号差异 | 中文字形复杂，视觉上比英文大 | 中文字号略小于英文（约80-90%） |
| 行高差异 | 中文需要更大行高 | 统一行高取最大值 |
| 字距差异 | 中文字距固定，英文字距可变 | 分别设定字距 |
| 字重差异 | 中文笔画密集，视觉更重 | 中文字重比英文轻一档 |
| 标点差异 | 中英文标点不同 | 使用相应语言的标点 |

#### 多语言混排原则

1. **视觉协调原则**：不同语言在视觉上应协调统一
2. **可读性优先原则**：每种语言都应保持良好的可读性
3. **风格一致原则**：不同语言的字体风格应相近
4. **度量统一原则**：行高、边距等使用统一度量

### 14.2 多语言字体匹配算法

#### 匹配步骤

```
1. 确定主要语言（通常为中文）
2. 选择主语言字体（如思源黑体）
3. 根据主字体风格选择匹配语言字体
   - 中文无衬线 → 英文无衬线 → 日文无衬线 → 韩文无衬线
   - 中文衬线 → 英文衬线 → 日文衬线 → 韩文衬线
4. 调整各语言字号使视觉一致
5. 统一行高和间距
6. 测试混排效果
```

#### 匹配评分标准

| 评分维度 | 权重 | 评分标准 |
|---------|------|---------|
| 风格一致 | 30% | 字体风格是否相近 |
| 字重匹配 | 20% | 视觉粗细是否一致 |
| x高度匹配 | 20% | x高度是否相近 |
| 字宽匹配 | 15% | 字宽比例是否协调 |
| 可读性 | 15% | 各语言是否清晰可读 |

### 14.3 字号匹配（中文字号 vs 英文字号）

#### 字号匹配比例表

| 中文字号 | 英文字号 | 匹配比例 | 说明 |
|---------|---------|---------|------|

| 14pt | 16pt | 1:1.14 | 标准正文 |
| 16pt | 18pt | 1:1.13 | 大正文 |
| 18pt | 20pt | 1:1.11 | 小标题 |
| 24pt | 26pt | 1:1.08 | 中标题 |

**匹配原则**：
- 中文字号通常为英文字号的85-95%
- 字号越大，差异越小
- 需要根据具体字体微调

### 15.4 字体心理学应用原则

**原则1：一致性原则**
- 字体情绪与品牌情绪一致
- 避免使用与品牌气质冲突的字体

**原则2：适度原则**
- 装饰性字体仅用于标题，不用于正文
- 情绪传达通过整体设计而非单一元素

**原则3：受众原则**
- 考虑目标受众的字体偏好
- 不同年龄段、文化背景对字体感知不同

**原则4：场景原则**
- 字体情绪需适配使用场景
- 同一品牌在不同场景可使用不同字重的同款字体

(function autoFitFontSize() {
    var comp = app.project.activeItem;
    if (!comp || !(comp instanceof CompItem)) {
        alert("请先打开一个合成");
        return;
    }

    var minFontSize = 12;             // 最小字号
    var maxFontSize = 120;            // 最大字号
    var fontFamily = "Source Han Sans CN";

    app.beginUndoGroup("字体自动适配");

    for (var i = 0; i < selectedLayers.length; i++) {

        while (layerWidth > maxWidth && currentFontSize > minFontSize) {

        ["第一句字幕", 0, 2],
        ["第二句字幕", 2, 4],
        ["第三句字幕", 4, 6],
        ["第四句字幕", 6, 8],
        ["第五句字幕", 8, 10]
    ];

    var fontSize = 36;
    var fontFamily = "Source Han Sans CN";
    var posY = comp.height - 80; // 字幕位置（底部）

    app.beginUndoGroup("批量生成字幕");

    for (var i = 0; i < subtitleData.length; i++) {
        var text = subtitleData[i][0];
        var startTime = subtitleData[i][1];
        var endTime = subtitleData[i][2];

        var textLayer = comp.layers.addText(text);
        
        // 设置文字属性
        var textProp = textLayer.property("Source Text");
        var textDocument = textProp.value;
        textDocument.fontSize = fontSize;
        textDocument.font = fontFamily;
        textDocument.fillColor = [1, 1, 1];
        textDocument.justification = ParagraphJustification.CENTER_JUSTIFY;
        textProp.setValue(textDocument);

        // 设置位置
        textLayer.property("Position").setValue([comp.width / 2, posY]);

        // 设置时间范围
        textLayer.startTime = startTime;
        textLayer.outPoint = endTime;

        // 添加投影
        var shadowEffect = textLayer.property("ADBE Effect Parade").addProperty("ADBE Drop Shadow");
        shadowEffect.property("ADBE Drop Shadow-0001").setValue(315); // 角度
        shadowEffect.property("ADBE Drop Shadow-0002").setValue(3);   // 距离
        shadowEffect.property("ADBE Drop Shadow-0003").setValue(5);   // 柔和度
        shadowEffect.property("ADBE Drop Shadow-0004").setValue(0.8); // 不透明度

        textLayer.name = "字幕_" + (i + 1);
    }

    app.endUndoGroup();
    alert("成功生成 " + subtitleData.length + " 条字幕");
})();

### 18.3 字体度量参数设计

#### 核心度量参数

| 参数 | 说明 | 设计要点 |
|------|------|---------|
| 基线（Baseline） | 字符底部对齐线 | 所有字符共享基线 |
| 上行高度（Ascender） | 从基线到最高点 | 约为字号的0.8倍 |
| 下行深度（Descender） | 从基线到最低点 | 约为字号的0.2倍 |
| x高度（x-height） | 小写字母x的高度 | 影响可读性，越高可读性越好 |
| 大写高度（Cap Height） | 大写字母高度 | 约为字号的0.7倍 |
| 字宽（Advance Width） | 字符的水平推进量 | 每个字符独立设定 |
| 侧边距（Side Bearing） | 字符轮廓到字宽边界的距离 | 左侧边距和右侧边距 |

#### 度量参数设计原则

1. **一致性原则**：同类字符度量参数保持一致
2. **视觉平衡原则**：度量参数应符合视觉感受而非数学等值
3. **可读性原则**：x高度不宜过小，影响小字号可读性
4. **节奏感原则**：字宽变化创造排版节奏

### 18.4 字体轮廓设计原则

#### 轮廓设计基本规则

1. **贝塞尔曲线原则**
   - 使用最少控制点描述轮廓
   - 控制点尽量在极值点
   - 避免控制点过密导致轮廓不平滑

2. **笔画一致性原则**
   - 同字号下笔画粗细基本一致
   - 横画略细于竖画（视觉补偿）
   - 保持笔画末端的风格统一

3. **比例原则**
   - 中文方块字保持在1:1的比例内
   - 圆形字符（O）略大于方形字符（H）做视觉补偿
   - 保持字符内部空间的均匀

4. **细节统一原则**
   - 笔画起始/结束风格统一
   - 转角处理风格统一
   - 装饰元素风格统一

### 18.5 字体间距设计

#### 间距设计层次

1. **字宽设计**：每个字符的总宽度
2. **侧边距设计**：字符轮廓到字宽边界的距离
3. **字距对设计**：特定字符组合的间距调整

#### 间距设计原则

- 中文：字宽基本统一，侧边距基本为零
- 英文：字宽根据字符变化（如W宽，I窄）
- 字距对：修正视觉不均匀（如AV、LA、To等组合）

### 18.7 从手稿到数字字体的完整流程

#### 流程详解

**阶段1：手稿设计**
1. 在纸上用铅笔绘制字符草图
2. 确定字体整体风格和特征
3. 设计基础字符（中文"永"字，英文"Hamburg"等）

**阶段2：数字化描摹**
1. 扫描手稿导入设计软件
2. 用贝塞尔曲线描绘轮廓
3. 调整曲线使轮廓平滑

**阶段3：度量调整**
1. 设定基线、上行高度等度量参数
2. 调整每个字符的字宽和侧边距
3. 测试排版效果并微调

**阶段4：字重扩展**
1. 从Regular字重出发
2. 向Bold方向扩展（加粗笔画）
3. 向Light方向扩展（减细笔画）
4. 保持各字重风格一致

**阶段5：完善与发布**
1. 补充标点、符号等字符
2. 进行hinting优化
3. 导出多种格式
4. 编写授权协议
5. 发布到字体平台
