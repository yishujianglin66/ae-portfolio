# 🎭 木偶视频剪辑技巧与制作思路

> 从物理定格动画到数字 Puppet Tool，从台湾布袋戏到剪映手机特效——木偶视频创作的完整知识体系。

---

## 🏗️ 两大制作范式

### A. 物理定格动画（Stop-Motion Puppet）

| 阶段 | 内容 |
|------|------|
| **前期** | 故事板 → 角色设计 → 脚本 → 临时音频动画分镜 |
| **偶制作** | 铝丝骨架 + 泡沫/黏土/木头塑形 + 服装制作；关键部位多做备份 |
| **场景搭建** | 微缩模型，比例匹配人偶，预留机位和灯光位 |
| **灯光** | 微缩版三点布光，所有灯光必须锁定（防帧间闪烁） |
| **拍摄** | Dragonframe 逐帧拍摄，洋葱皮预览；12/15/24 fps 按需选择 |
| **后期** | 图片序列导入 PR → AE 去支架/去线 → 调色 → 音效 → 导出 |

### B. 数字 Puppet Warp 动画（AE 2D）

| 阶段 | 内容 |
|------|------|
| **素材准备** | PS 中将角色各部位裁切为独立图层，内容识别填充修补空洞 |
| **骨骼搭建** | 关节处打 Deform Pin，不变区域打 Starch Pin 防撕裂 |
| **粗略动画** | 逐帧制作骨骼引导动画作为参考 |
| **关键帧匹配** | 将 Pin 位置匹配到引导动画的每一帧 |
| **细节打磨** | 全部关键帧加缓动 → 次要动作（头发/布料飘动） |
| **合成** | 背景 + 光效 + 粒子 + 调色 |

## 🎬 布袋戏剪辑体系（台湾霹雳/金光）

### 核心制作流程

```
剧本 → 口白录音（前期完成）→ （分镜）→ 拍摄 → 后期剪辑
```

> ⚠️ **关键区别**：布袋戏**先录口白再拍摄**，操偶和运镜完全配合已有音频。

### 镜头语言

| 镜头类型 | 用途 |
|----------|------|
| **特写/大特写** | 布袋戏最常用——偶的表情无法变化，情绪全靠镜头+灯光+音乐+配音合成 |
| **低角度仰拍** | 武角出场制造压迫感、威严气场 |
| **缓慢推镜** | 角色特写营造戏剧张力 |
| **过肩镜头** | 双偶对话场景 |
| **侧面拍摄** | 帮助隐藏操偶线和支架 |
| **广角慢动作** | 武戏战斗场景 |

### 灯光系统

| 灯光层 | 说明 |
|--------|------|
| **轮廓光/逆光** | 暖金色从背后打来，分离角色与背景，制造神秘感 |
| **漫射补光** | 正面柔光，约主光 1/3 强度 |
| **环境光/效果光** | 粒子、四色渐变、辉光叠加 |
| **脚光** | 爆炸/气劲特效（"气功爆发"） |

### 武戏剪辑（最核心）

- **动作拆解**：操偶师将完整战斗拆分为单个离散动作，逐个拍摄
- **蒙太奇重组**：后期通过快速蒙太奇将碎片拼接为流畅战斗
- **超高剪辑密度**：武戏镜头极短、切换极快
- **预留特效空间**：画面故意留空（如 2 秒天空）给后期 CG 特效
- **绿幕合成**：超出实景限制的复杂动作
- **非线性叙事**：闪回/闪前穿插在打斗中

### 文戏剪辑

- 节奏主要在**剧本阶段**已确定；配音后内容基本锁定
- 编辑核心任务：保证信息完整传达
- 偶的表情 = **错觉**：镜头角度 + 灯光 + 动作 + 对手反应 + 音乐 + 配音

## 🧩 AE Puppet Tool 高级技法

### 三种 Pin 类型

| Pin | 作用 | 高级用法 |
|-----|------|---------|
| **Deform Pin** | 控制移动位置 | 右键→"显示关键帧曲线"可微调 |
| **Overlap Pin** | 重叠时控制前后渲染顺序 | 使用 Hold 关键帧切换前后关系 |
| **Starch Pin** | 硬化区域防止变形 | 极小值 (<0.1) 放 Deform Pin 附近防撕裂 |

### 进阶工作流

- **Pin 绑定 Null 对象**：表达式 `thisComp.layer("Null").transform.position` 让曲线可编辑
- **独立网格**：在图层内不同闭合轮廓各点一次 → 多个独立变形区域
- **Puppet Sketch**（Ctrl+拖拽）：录制实时运动，自动生成关键帧
- **三角形优化**：文字/角色约 50 三角面，大幅角色 500+
- **配合 Turbulent Displace**：制造烟雾/水流/能量效果
- **配合 CC Bend**：平滑弧形身体运动
- **录制时用 Draft 模式**：复杂网格忽略 Starch Pin 提高性能

## 🎯 偶的"顿挫感"美学

这是木偶视频的独特审美——模仿提线木偶被线牵引的机械感：

- 每两个关键帧之间插入 **1-2 帧微停顿或微回弹**
- 阶梯运动模式：「前进 3 帧 → 暂停 1 帧 → 继续前进」
- **各身体部位时间错位**：手臂、头部、身体不同步到达终点

## 🧵 支架/线去除技术

### 行业标准：Clean Plate 法

1. 动画前后各拍 **10+ 帧空背景**
2. AE 中：底层放 Clean Plate，上层放原始素材
3. Vector Paint 效果（Hold Strokes + Inverse Matte）或蒙版"擦除"支架
4. **用多帧序列 Clean Plate**（非单帧）保留自然噪点/颗粒

### 其他方法

| 方法 | 适用场景 |
|------|---------|
| **钢笔蒙版** | 线越过角色身体；用 Hold 关键帧 |
| **仿制图章** | 小面积支架与偶体交叠处 |
| **CC Wire Removal** | 线静止但前景运动（定格动画价值有限）|
| **Mocha AE** | 完整抠出主体合成到 Clean Plate |

### 片场预防

- 支架涂哑光黑/缠黑胶带（消除反光）
- 支架尽可能从道具后面伸出
- 绝不将线完全缠绕偶体
- 避免支架经过脸部区域
- 移动镜头：**每个机位都拍 Clean Plate**

## 🧵 软体和布料动画

| 对象 | 推荐方法 |
|------|---------|
| **披风/斗篷（大面积）** | 布局菜单 → 波形效果 → 调振幅和速度 |
| **裙摆（局部摆动）** | 布局菜单 → 弯曲效果（固定上半，摆动下半）|
| **头发** | 摆动效果 —— 最自然 |
| **眨眼** | 上眼皮+瞳孔打 Pin → 下移动画 → 首尾帧复制循环 |
| **通用柔体** | autosway 插件（自动节奏摆动）+ Deep Glow（发光边缘）|

## 📱 剪映移动端简化流程

无需 AE 的木偶视频制作方案：

1. 导入偶绿幕素材 → 加滑动动画 → 导出
2. 背景 + 导出绿幕为画中画
3. 色度抠图去绿 → 对齐时长
4. 背景加左右震动 → 叠加丁达尔悬胶
5. 混合模式：叠加 → 加气泡变焦（模糊到清晰入场）
6. 搜索"光束" → 调光源 → 混合模式：绿色
7. 全局调色 + 暗角 + 音乐

## 🎥 定格拍摄核心参数

- **全手动模式（M）**：锁定 ISO、光圈、快门、白平衡
- **三脚架锁定相机**：任何帧间位移都会毁掉镜头
- **微距镜头**：微型人偶需要近距离对焦能力
- **浅景深**（大光圈）：模糊背景、隐藏支架/线
- **人工光源**：自然光会随时间变化导致闪烁
- **背光/轮廓光**：木偶摄影的关键——分离角色与背景
