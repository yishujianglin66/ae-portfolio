#### 1.2.2 智能滤镜 (Smart Filter) 工作原理

智能滤镜是Photoshop的非破坏性编辑核心技术：

1. **智能对象容器**：将图层转换为智能对象，保护原始像素
2. **滤镜栈管理**：多个滤镜按顺序堆叠，可随时调整顺序
3. **参数可编辑**：双击滤镜名称即可重新打开参数对话框
4. **滤镜蒙版**：每个智能滤镜自带蒙版，控制滤镜影响区域
5. **不透明度与混合模式**：每个滤镜可独立设置强度和混合方式

```
智能对象图层
├── 智能滤镜
│   ├── 滤镜1: 高斯模糊 (可编辑参数 + 蒙版 + 不透明度 + 混合模式)
│   ├── 滤镜2: USM锐化 (可编辑参数 + 蒙版 + 不透明度 + 混合模式)
│   └── 滤镜3: ...
└── 原始像素数据 (始终保留)
```

#### 1.2.3 调整图层 vs 智能滤镜

| 特性 | 调整图层 | 智能滤镜 |
|------|---------|---------|
| 非破坏性 | ✓ | ✓ |
| 可编辑参数 | ✓ | ✓ |
| 自带蒙版 | ✓ | ✓ |
| 支持混合模式 | ✓ | ✓ |
| 支持不透明度 | ✓ | ✓ |
| 影响下方所有图层 | ✓ | ✗ (仅当前智能对象) |
| 可创建剪贴蒙版 | ✓ | ✓ |
| 可堆叠多个效果 | 多个调整图层 | 多个智能滤镜 |
| 适用范围 | 色彩/色调调整 | 像素级滤镜效果 |

#### 1.3.2 参数记忆系统

Photoshop的参数记忆机制：

1. **上次滤镜效果**：`Ctrl+F` / `Cmd+F` 重复应用上次使用的滤镜（相同参数）
2. **重新打开对话框**：`Ctrl+Alt+F` / `Cmd+Option+F` 打开上次滤镜的参数对话框
3. **渐隐效果**：`Ctrl+Shift+F` / `Cmd+Shift+F` 调整上次滤镜的不透明度和混合模式
4. **智能滤镜记忆**：每个智能滤镜独立保存参数设置

### 1.4 智能滤镜系统详解

#### 1.4.1 智能对象类型

| 类型 | 创建方式 | 特点 |
|------|---------|------|
| 嵌入式智能对象 | 图层→智能对象→转换为智能对象 | 数据嵌入PSD，文件较大 |
| 链接智能对象 | 文件→置入链接对象 | 外部链接，可批量更新 |
| 智能对象中的智能对象 | 嵌套转换 | 复杂合成，分层管理 |

#### 1.4.2 智能滤镜蒙版

智能滤镜蒙版控制滤镜效果的可见区域：

- **白色区域**：滤镜完全生效
- **黑色区域**：滤镜完全不生效
- **灰色区域**：滤镜部分生效（灰度对应强度）
- **编辑方式**：画笔工具、渐变工具、选区填充

#### 6.3.1 高反差保留 (High Pass)

**参数：**
- **半径**：0.1-1000像素

**核心应用：**
1. **锐化增强**：
   ```
   1. 复制图层
   2. 滤镜→其他→高反差保留 (半径1-2px)
   3. 图层混合模式改为"叠加"或"柔光"
   4. 调整不透明度控制锐度
   ```

2. **频率分离**：
   ```
   1. 复制图层两次
   2. 下层：高斯模糊（半径：皮肤纹理大小）
   3. 上层：图像→应用图像（通道: 图层 混合: 减去 缩放:2 补偿值:128）
   4. 上层混合模式改为"线性光"
   5. 下层=低频（颜色光影），上层=高频（纹理细节）
   ```

#### 6.3.2 最大值与最小值

**最大值 (Maximum)**：扩展亮部区域，收缩暗部
- 半径：1-100像素
- 用途：蒙版扩展、白色加粗、缩小暗部

**最小值 (Minimum)**：扩展暗部区域，收缩亮部
- 半径：1-100像素
- 用途：蒙版收缩、黑色加粗、缩小亮部

### 10.1 批量滤镜处理脚本

#### 10.1.1 使用win32com自动化Photoshop

以下Python脚本演示如何使用win32com客户端自动化Photoshop进行批量滤镜处理：

```python
"""
Photoshop 批量滤镜处理工具
使用 win32com 客户端自动化 Photoshop
"""

import os
import win32com.client
import pythoncom
from pathlib import Path


class PhotoshopFilterBatch:
    """Photoshop批量滤镜处理类"""

    def __init__(self):
        """初始化Photoshop应用程序"""
        pythoncom.CoInitialize()
        self.ps_app = None
        self._connect_photoshop()

    def _connect_photoshop(self):
        """连接到Photoshop应用程序"""
        try:
            self.ps_app = win32com.client.Dispatch("Photoshop.Application")
            print("已成功连接到 Photoshop")
        except Exception as e:
            print(f"连接 Photoshop 失败: {e}")
            raise

    def open_document(self, file_path):
        """打开文档"""
        return self.ps_app.Open(file_path)

    def save_as_jpeg(self, doc, output_path, quality=8):
        """保存为JPEG格式"""
        jpeg_options = win32com.client.Dispatch("Photoshop.JPEGSaveOptions")
        jpeg_options.Quality = quality
        jpeg_options.EmbedColorProfile = True
        jpeg_options.FormatOptions = 2  # psStandardBaseline
        doc.SaveAs(output_path, jpeg_options, True)

    def save_as_png(self, doc, output_path):
        """保存为PNG格式"""
        png_options = win32com.client.Dispatch("Photoshop.PNGSaveOptions")
        png_options.PNG8 = False
        png_options.Interlaced = False
        doc.SaveAs(output_path, png_options, True)

    def apply_gaussian_blur(self, doc, radius=5.0):
        """应用高斯模糊滤镜"""
        active_layer = doc.ActiveLayer
        if not active_layer.IsBackgroundLayer:
            doc.ActiveLayer = active_layer
        
        doc.ArtLayers.Add()
        # 合并可见图层到新图层用于滤镜
        self.ps_app.ExecuteAction(
            self.ps_app.StringIDToTypeID("mergeVisible"),
            win32com.client.Dispatch("Photoshop.ActionDescriptor"),
            3  # psDialogSilent
        )
        
        # 应用高斯模糊
        self.ps_app.ExecuteAction(
            self.ps_app.StringIDToTypeID("gaussianBlur"),
            self._create_blur_descriptor(radius),
            3
        )

    def _create_blur_descriptor(self, radius):
        """创建模糊滤镜描述符"""
        desc = win32com.client.Dispatch("Photoshop.ActionDescriptor")
        desc.PutUnitDouble(
            self.ps_app.StringIDToTypeID("radius"),
            self.ps_app.StringIDToTypeID("pixelsUnit"),
            radius
        )
        return desc

    def apply_unsharp_mask(self, doc, amount=100, radius=1.0, threshold=0):
        """应用USM锐化滤镜"""
        desc = win32com.client.Dispatch("Photoshop.ActionDescriptor")
        desc.PutDouble(self.ps_app.StringIDToTypeID("amount"), amount)
        desc.PutUnitDouble(
            self.ps_app.StringIDToTypeID("radius"),
            self.ps_app.StringIDToTypeID("pixelsUnit"),
            radius
        )
        desc.PutInteger(self.ps_app.StringIDToTypeID("threshold"), threshold)

        self.ps_app.ExecuteAction(
            self.ps_app.StringIDToTypeID("unsharpMask"),
            desc,
            3
        )

    def convert_to_smart_object(self, doc):
        """将当前图层转换为智能对象"""
        self.ps_app.ExecuteAction(
            self.ps_app.StringIDToTypeID("newPlacedLayer"),
            win32com.client.Dispatch("Photoshop.ActionDescriptor"),
            3
        )

    def add_smart_filter(self, doc, filter_name, params):
        """添加智能滤镜"""
        # 先确保是智能对象
        self.convert_to_smart_object(doc)
        # 具体滤镜实现取决于滤镜类型
        pass

    def batch_process_folder(
        self,
        input_folder,
        output_folder,
        filter_type="gaussian_blur",
        filter_params=None,
        output_format="jpeg",
        quality=8
    ):
        """
        批量处理文件夹中的图片
        
        Args:
            input_folder: 输入文件夹路径
            output_folder: 输出文件夹路径
            filter_type: 滤镜类型
            filter_params: 滤镜参数字典
            output_format: 输出格式 (jpeg/png)
            quality: JPEG质量 (0-12)
        """
        input_path = Path(input_folder)
        output_path = Path(output_folder)
        output_path.mkdir(parents=True, exist_ok=True)

        # 支持的图片格式
        extensions = ['*.jpg', '*.jpeg', '*.png', '*.bmp', '*.tiff']
        image_files = []
        for ext in extensions:
            image_files.extend(input_path.glob(ext))

        if not image_files:
            print("未找到图片文件")
            return

        print(f"找到 {len(image_files)} 张图片，开始处理...")

        for i, img_file in enumerate(image_files, 1):
            print(f"处理 [{i}/{len(image_files)}]: {img_file.name}")
            
            try:
                doc = self.open_document(str(img_file))
                
                # 应用滤镜
                if filter_type == "gaussian_blur":
                    radius = filter_params.get("radius", 5.0) if filter_params else 5.0
                    self.apply_gaussian_blur(doc, radius)
                elif filter_type == "unsharp_mask":
                    self.apply_unsharp_mask(
                        doc,
                        amount=filter_params.get("amount", 100) if filter_params else 100,
                        radius=filter_params.get("radius", 1.0) if filter_params else 1.0,
                        threshold=filter_params.get("threshold", 0) if filter_params else 0
                    )
                
                # 保存输出
                if output_format.lower() == "jpeg":
                    out_file = output_path / f"{img_file.stem}_filtered.jpg"
                    self.save_as_jpeg(doc, str(out_file), quality)
                elif output_format.lower() == "png":
                    out_file = output_path / f"{img_file.stem}_filtered.png"
                    self.save_as_png(doc, str(out_file))
                
                doc.Close(2)  # 不保存原始文档
                
            except Exception as e:
                print(f"  处理失败: {e}")

        print("批量处理完成！")

    def close(self):
        """关闭连接"""
        if self.ps_app:
            self.ps_app = None
        pythoncom.CoUninitialize()


# 使用示例
if __name__ == "__main__":

            filter_type="unsharp_mask",
            filter_params={"amount": 150, "radius": 1.5, "threshold": 2},
            output_format="jpeg",
            quality=10
        )
        
    finally:
        batch_processor.close()
```

```python
"""

import os
import win32com.client
import pythoncom
from pathlib import Path


class StyleBatchApplier:
    """样式批量应用器"""

    def __init__(self):
        pythoncom.CoInitialize()
        self.ps_app = win32com.client.Dispatch("Photoshop.Application")

    def load_style_library(self, asl_path):
        """加载ASL样式库文件"""
        self.ps_app.LoadStyles(asl_path)
        print(f"已加载样式库: {asl_path}")

    def apply_style_by_name(self, layer, style_name):
        """按名称应用样式（需要样式已加载）"""
        # 方法：通过动作描述符应用样式
        try:
            desc = win32com.client.Dispatch("Photoshop.ActionDescriptor")
            ref = win32com.client.Dispatch("Photoshop.ActionReference")
            ref.PutName(self.ps_app.StringIDToTypeID("style"), style_name)
            desc.PutReference(self.ps_app.StringIDToTypeID("null"), ref)
            
            self.ps_app.ExecuteAction(
                self.ps_app.StringIDToTypeID("applyStyle"),
                desc,
                3
            )
            return True
        except Exception as e:
            print(f"应用样式 '{style_name}' 失败: {e}")
            return False

    def copy_layer_style(self, source_layer, target_layer):
        """拷贝/粘贴图层样式"""
        # 选中源图层
        self.ps_app.ActiveDocument.ActiveLayer = source_layer
        
        # 拷贝图层样式
        copy_desc = win32com.client.Dispatch("Photoshop.ActionDescriptor")
        copy_ref = win32com.client.Dispatch("Photoshop.ActionReference")
        copy_ref.PutClass(self.ps_app.StringIDToTypeID("layerEffects"))
        copy_desc.PutReference(self.ps_app.StringIDToTypeID("null"), copy_ref)
        
        self.ps_app.ExecuteAction(
            self.ps_app.StringIDToTypeID("copy"),
            copy_desc,
            3
        )
        
        # 选中目标图层
        self.ps_app.ActiveDocument.ActiveLayer = target_layer
        
        # 粘贴图层样式
        paste_desc = win32com.client.Dispatch("Photoshop.ActionDescriptor")
        paste_ref = win32com.client.Dispatch("Photoshop.ActionReference")
        paste_ref.PutClass(self.ps_app.StringIDToTypeID("layerEffects"))
        paste_desc.PutReference(self.ps_app.StringIDToTypeID("null"), paste_ref)
        
        self.ps_app.ExecuteAction(
            self.ps_app.StringIDToTypeID("paste"),
            paste_desc,
            3
        )

    def find_text_layers(self, doc):
        """查找所有文字图层"""
        text_layers = []
        for layer in doc.Layers:
            if layer.Kind == 2:  # psTextLayer
                text_layers.append(layer)
        return text_layers

    def apply_style_to_all_text_layers(self, doc, style_name):
        """将样式应用到所有文字图层"""
        text_layers = self.find_text_layers(doc)
        print(f"找到 {len(text_layers)} 个文字图层")
        
        for i, layer in enumerate(text_layers, 1):
            print(f"  应用样式到图层 {i}: {layer.Name}")
            doc.ActiveLayer = layer
            self.apply_style_by_name(layer, style_name)

    def batch_apply_style_to_psd(
        self,
        input_folder,
        output_folder,
        style_name=None,
        asl_path=None
    ):
        """
        批量为PSD文件应用样式
        
        Args:
            input_folder: 输入PSD文件夹
            output_folder: 输出文件夹
            style_name: 要应用的样式名称
            asl_path: 样式库文件路径（可选）
        """
        input_path = Path(input_folder)
        output_path = Path(output_folder)
        output_path.mkdir(parents=True, exist_ok=True)

        if asl_path and os.path.exists(asl_path):
            self.load_style_library(asl_path)

        psd_files = list(input_path.glob("*.psd"))
        if not psd_files:
            print("未找到PSD文件")
            return

        print(f"找到 {len(psd_files)} 个PSD文件")

        for i, psd_file in enumerate(psd_files, 1):
            print(f"处理 [{i}/{len(psd_files)}]: {psd_file.name}")
            
            try:
                doc = self.ps_app.Open(str(psd_file))
                
                if style_name:
                    self.apply_style_to_all_text_layers(doc, style_name)
                
                # 保存为新文件
                out_file = output_path / f"{psd_file.stem}_styled.psd"
                doc.SaveAs(str(out_file))
                doc.Close(2)
                
            except Exception as e:
                print(f"  处理失败: {e}")

        print("批量样式应用完成！")

    def export_styles_from_psd(self, psd_file, output_folder):
        """从PSD文件导出所有图层样式"""
        doc = self.ps_app.Open(psd_file)
        output_path = Path(output_folder)
        output_path.mkdir(parents=True, exist_ok=True)
        
        style_count = 0
        
        for layer in doc.Layers:
            try:
                # 检查图层是否有效果

                    style_name = f"{layer.Name}_style"
                    # 保存样式（这里用动作的方式）
                    print(f"导出样式: {style_name}")
                    style_count += 1
            except:
                pass
        
        doc.Close(2)
        print(f"共导出 {style_count} 个样式")

    def close(self):
        pythoncom.CoUninitialize()
```

```python
    def create_filter_comparison(
        self,
        input_image,
        filters_list,
        output_path,
        cols=3
    ):
        """
        生成滤镜对比图
        
        Args:
            input_image: 输入图片路径
            filters_list: 滤镜列表 [(name, params), ...]
            output_path: 输出图片路径
            cols: 每行显示的列数
        """
        # 首先应用所有滤镜并保存临时文件
        import tempfile
        temp_dir = tempfile.mkdtemp()
        
        original = Image.open(input_image)
        thumb_size = (300, 200)
        
        processed_images = []
        labels = []
        
        # 原图
        orig_thumb = original.copy()
        orig_thumb.thumbnail(thumb_size)
        processed_images.append(orig_thumb)
        labels.append("原图")
        
        # 应用各个滤镜
        doc = self.ps_app.Open(input_image)
        
        for filter_name, filter_params in filters_list:
            # 每次从原图开始
            doc2 = self.ps_app.Open(input_image)
            
            try:
                self.apply_filter_by_name(doc2, filter_name, filter_params)
                
                # 保存临时文件
                temp_file = os.path.join(temp_dir, f"{filter_name}.jpg")
                jpeg_options = win32com.client.Dispatch("Photoshop.JPEGSaveOptions")
                jpeg_options.Quality = 8
                doc2.SaveAs(temp_file, jpeg_options, True)
                
                # 打开并缩放
                img = Image.open(temp_file)
                img.thumbnail(thumb_size)
                processed_images.append(img)
                labels.append(filter_name)
                
            except Exception as e:
                print(f"滤镜 {filter_name} 处理失败: {e}")
            
            doc2.Close(2)
        
        doc.Close(2)
        
        # 创建对比图
        rows = (len(processed_images) + cols - 1) // cols
        thumb_w, thumb_h = thumb_size
        gap = 10
        label_h = 30
        
        canvas_w = cols * thumb_w + (cols + 1) * gap
        canvas_h = rows * (thumb_h + label_h) + (rows + 1) * gap
        
        canvas = Image.new('RGB', (canvas_w, canvas_h), (255, 255, 255))
        
        from PIL import ImageDraw, ImageFont
        draw = ImageDraw.Draw(canvas)
        
        try:
            font = ImageFont.truetype("arial.ttf", 16)
        except:
            font = ImageFont.load_default()
        
        for i, (img, label) in enumerate(zip(processed_images, labels)):
            row = i // cols
            col = i % cols
            
            x = gap + col * (thumb_w + gap)
            y = gap + row * (thumb_h + label_h + gap)
            
            # 粘贴图片（居中）
            img_w, img_h = img.size
            offset_x = (thumb_w - img_w) // 2
            offset_y = (thumb_h - img_h) // 2
            canvas.paste(img, (x + offset_x, y + offset_y))
            
            # 绘制标签
            draw.text((x, y + thumb_h + 5), label, fill=(0, 0, 0), font=font)
        
        canvas.save(output_path)
        print(f"对比图已保存: {output_path}")
        
        # 清理临时文件
        import shutil
        shutil.rmtree(temp_dir)
```

```python
            text_item = layer.TextItem
            info = {
                "layer_name": layer.Name,
                "layer_id": layer.ID,
                "content": text_item.Contents,
                "font": text_item.Font,
                "size": text_item.Size,

                },
                "justification": str(text_item.Justification),
                "leading": text_item.Leading,
                "tracking": text_item.Tracking,
                "kerning": text_item.Kerning,
                "visible": layer.Visible,
                "opacity": layer.Opacity,
            }
            return info
        except Exception as e:
            return {
                "layer_name": layer.Name,
                "error": str(e)
            }

    def traverse_layers(self, layers, doc_path="", prefix=""):
        """遍历所有图层（包括图层组）"""
        text_info_list = []
        
        for i in range(1, layers.Count + 1):
            layer = layers[i]
            layer_path = f"{prefix}/{layer.Name}" if prefix else layer.Name
            
            try:
                # 检查是否为文字图层
                if layer.Kind == 2:  # psTextLayer
                    info = self.extract_text_info(layer, doc_path)
                    info["layer_path"] = layer_path
                    text_info_list.append(info)
                
                # 检查是否为图层组
                elif hasattr(layer, 'Layers') and layer.Layers.Count > 0:
                    # 递归遍历图层组
                    group_texts = self.traverse_layers(
                        layer.Layers, doc_path, layer_path
                    )
                    text_info_list.extend(group_texts)
                    
            except Exception as e:
                pass

            text_info = {
                "file_name": Path(psd_path).name,
                "file_path": psd_path,
                "width": doc.Width,
                "height": doc.Height,
                "resolution": doc.Resolution,
                "text_layers": self.traverse_layers(doc.Layers, psd_path)
            }
            
            doc.Close(2)
            return text_info
            
        except Exception as e:
            print(f"  提取失败: {e}")

        if not psd_files:
            print("未找到PSD文件")

        print(f"找到 {len(psd_files)} 个PSD文件")
        
        results = []
        for i, psd_file in enumerate(psd_files, 1):

                            "file": psd_file.name,

                        f.write(f"内容:\n{text_layer.get('content', '')}\n")

        print(f"报告已导出: {output_file}")

                        replace_in_layers(layer.Layers)
                except:
                    pass

        if count > 0:
            doc.SaveAs(output_path)
            print(f"共替换 {count} 处文字")
        else:
            print("未找到可替换的文字")
        
        doc.Close(2)
        
        return count
```

### 10.6 滤镜参数解析工具

```python
"""
ATN/ASL文件解析工具
解析Photoshop动作文件和样式文件中的滤镜参数
"""

import struct
import os
import json
from pathlib import Path


class ATNParser:
    """Photoshop ATN动作文件解析器"""
    
    # Photoshop 类型ID常量（部分）
    TYPE_IDS = {
        0x74657874: "text",
        0x6c6f6e67: "long",       # 整数
        0x656e756d: "enum",       # 枚举
        0x646f7562: "double",     # 双精度浮点
        0x556e7446: "unitFloat",  # 单位浮点数
        0x6f626a63: "object",     # 对象
        0x676c6f62: "globalObject",
        0x616c6973: "alias",
        0x434c5220: "color",      # 颜色
        0x656e616d: "enumerated",
        0x66726d20: "referenceForm",
        0x636c6173: "class",
        0x70726f70: "property",
        0x5245464c: "reference",
        0x4f424a43: "object",
        0x54455854: "text",
        0x6c697374: "list",
        0x4c495354: "array",
    }
    
    def __init__(self):
        self.offset = 0
        self.data = b""
    
    def read_byte(self):
        """读取1字节"""
        val = struct.unpack_from(">B", self.data, self.offset)[0]
        self.offset += 1
        return val
    
    def read_short(self):
        """读取2字节整数"""
        val = struct.unpack_from(">H", self.data, self.offset)[0]
        self.offset += 2
        return val
    
    def read_long(self):
        """读取4字节整数"""
        val = struct.unpack_from(">I", self.data, self.offset)[0]
        self.offset += 4
        return val
    
    def read_double(self):
        """读取8字节浮点数"""
        val = struct.unpack_from(">d", self.data, self.offset)[0]
        self.offset += 8
        return val
    
    def read_pascal_string(self):
        """读取Pascal字符串"""
        length = self.read_byte()
        text = self.data[self.offset:self.offset + length].decode(
            'ascii', errors='replace'
        )
        self.offset += length
        # 字节对齐
        if (length + 1) % 2 != 0:
            self.offset += 1
        return text
    
    def read_ostring(self, length=None):
        """读取定长字符串"""
        if length is None:
            length = self.read_long()
        text = self.data[self.offset:self.offset + length].decode(
            'ascii', errors='replace'
        )
        self.offset += length
        # 4字节对齐
        while self.offset % 4 != 0:
            self.offset += 1
        return text
    
    def read_type(self):
        """读取4字节类型ID"""
        type_id = struct.unpack_from(">4s", self.data, self.offset)[0]
        self.offset += 4
        return type_id
    
    def type_id_to_name(self, type_id):
        """类型ID转名称"""
        if type_id in self.TYPE_IDS:
            return self.TYPE_IDS[type_id]
        try:
            return type_id.decode('ascii', errors='replace')
        except:
            return hex(type_id)
    
    def parse_descriptor(self):
        """解析描述符"""
        result = {}
        
        # 类名Unicode字符串
        name_length = self.read_long()
        if name_length > 0:
            class_name = self.data[self.offset:self.offset + name_length * 2].decode(
                'utf-16-be', errors='replace'
            )
            self.offset += name_length * 2
        else:
            class_name = ""
        
        # 类ID
        class_id = self.read_type()
        result["class_id"] = self.type_id_to_name(class_id)
        result["class_name"] = class_name
        
        # 项目数量
        num_items = self.read_long()
        result["num_items"] = num_items
        
        # 解析每个项目
        items = {}
        for _ in range(num_items):
            # 键ID
            key_id = self.read_type()
            key_name = self.type_id_to_name(key_id)
            
            # 值类型
            value_type = self.read_type()
            value = self.parse_value(value_type)
            
            items[key_name] = value
        
        result["items"] = items
        return result
    
    def parse_value(self, value_type):
        """根据类型解析值"""
        type_str = self.type_id_to_name(value_type)
        
        if value_type == b'long' or value_type == b'LON ':
            return {"type": "long", "value": self.read_long()}
        
        elif value_type == b'doub' or value_type == b'DOUB':
            return {"type": "double", "value": self.read_double()}
        
        elif value_type == b'TEXT' or value_type == b'text':
            length = self.read_long()
            text = self.data[self.offset:self.offset + length * 2].decode(
                'utf-16-be', errors='replace'
            )
            self.offset += length * 2
            return {"type": "text", "value": text}
        
        elif value_type == b'ENUM' or value_type == b'enum':
            enum_type = self.read_type()
            enum_value = self.read_type()
            return {
                "type": "enum",
                "enum_type": self.type_id_to_name(enum_type),
                "value": self.type_id_to_name(enum_value)
            }
        
        elif value_type == b'UNIT' or value_type == b'untF':
            unit_id = self.read_type()
            unit_value = self.read_double()
            return {
                "type": "unit",
                "unit": self.type_id_to_name(unit_id),
                "value": unit_value
            }
        
        elif value_type == b'OBJc' or value_type == b'obje':
            return {"type": "object", "value": self.parse_descriptor()}
        
        elif value_type == b'VlLs' or value_type == b'list':
            count = self.read_long()
            items = []
            for _ in range(count):
                item_type = self.read_type()
                items.append(self.parse_value(item_type))
            return {"type": "list", "value": items}
        
        elif value_type == b'bool' or value_type == b'BOOL':
            val = self.read_byte()
            return {"type": "bool", "value": val != 0}
        
        elif value_type == b'type' or value_type == b'TYPE':
            val = self.read_type()
            return {"type": "type", "value": self.type_id_to_name(val)}
        
        elif value_type == b'GlbO' or value_type == b'glob':
            return {"type": "global_object", "value": self.parse_descriptor()}
        
        else:
            # 未知类型，跳过4字节
            self.offset += 4
            return {"type": "unknown", "raw_type": type_str}
    
    def parse_action(self):
        """解析单个动作"""
        action = {}
        
        # 动作名称
        action["name"] = self.read_pascal_string()
        
        # 动作ID
        action["action_id"] = self.read_byte()
        
        # 事件数量
        num_events = self.read_long()
        action["num_events"] = num_events
        
        # 解析事件
        events = []
        for _ in range(num_events):
            event = self.parse_event()
            events.append(event)
        
        action["events"] = events
        return action
    
    def parse_event(self):
        """解析事件（动作中的单个命令）"""
        event = {}
        
        # 扩展（2字节+4字节+2字节）
        self.offset += 8  # 跳过扩展数据
        
        # 事件ID
        event["event_id"] = self.type_id_to_name(self.read_type())
        
        # 是否有对话框
        dialog_state = self.read_long()
        event["dialog_state"] = dialog_state
        
        # 描述符
        event["descriptor"] = self.parse_descriptor()
        
        return event
    
    def parse_atn_file(self, atn_path):
        """解析整个ATN文件"""
        self.offset = 0
        
        with open(atn_path, 'rb') as f:
            self.data = f.read()
        
        result = {
            "file_name": Path(atn_path).name,
            "file_size": len(self.data),
            "actions": []
        }
        
        # ATN文件头
        # 版本（2字节）
        version = self.read_short()
        result["version"] = version
        
        # 动作组数量
        num_sets = self.read_short()
        result["num_sets"] = num_sets
        
        # 解析每个动作组
        for _ in range(num_sets):
            action_set = {}
            
            # 动作组名称
            action_set["name"] = self.read_pascal_string()
            
            # 动作组ID
            action_set["set_id"] = self.read_byte()
            
            # 动作数量
            num_actions = self.read_short()
            action_set["num_actions"] = num_actions
            
            # 解析动作
            actions = []
            for _ in range(num_actions):
                action = self.parse_action()
                actions.append(action)
            
            action_set["actions"] = actions
            result["actions"].append(action_set)
        
        return result
    
    def extract_filters_from_atn(self, atn_path):
        """从ATN文件中提取所有滤镜命令"""
        data = self.parse_atn_file(atn_path)
        filters = []
        
        filter_keywords = [
            "blur", "sharpen", "distort", "noise", "render", 
            "stylize", "pixelate", "texture", "sketch", "artistic",
            "brush", "video", "other"
        ]
        
        for action_set in data["actions"]:
            for action in action_set["actions"]:
                for event in action["events"]:
                    event_id = event["event_id"].lower()
                    
                    if any(kw in event_id for kw in filter_keywords):
                        filters.append({
                            "set_name": action_set["name"],
                            "action_name": action["name"],
                            "filter_name": event["event_id"],
                            "parameters": event["descriptor"].get("items", {})
                        })
        
        return filters


class ASLParser:
    """Photoshop ASL样式文件解析器"""
    
    def __init__(self):
        self.atn_parser = ATNParser()
    
    def parse_asl_file(self, asl_path):
        """解析ASL样式文件
        
        ASL文件格式与ATN类似，存储的是图层样式预设
        """
        # ASL使用与ATN相似的格式
        # 这里复用ATN解析器的基础结构
        self.atn_parser.offset = 0
        
        with open(asl_path, 'rb') as f:
            self.atn_parser.data = f.read()
        
        result = {
            "file_name": Path(asl_path).name,
            "file_size": len(self.atn_parser.data),
            "styles": []
        }
        
        # ASL版本
        version = self.atn_parser.read_short()
        result["version"] = version
        
        # 样式数量
        num_styles = self.atn_parser.read_short()
        result["num_styles"] = num_styles
        
        # 解析每个样式
        for i in range(num_styles):
            try:
                style = self._parse_style()
                result["styles"].append(style)
            except Exception as e:
                print(f"解析样式 {i} 失败: {e}")
                break
        
        return result
    
    def _parse_style(self):
        """解析单个样式"""
        style = {}
        
        # 样式名称
        style["name"] = self.atn_parser.read_pascal_string()
        
        # 样式ID
        style["style_id"] = self.atn_parser.read_byte()
        
        # 样式描述符数量
        num_descriptors = self.atn_parser.read_long()
        style["num_descriptors"] = num_descriptors
        
        # 解析效果描述符
        effects = []
        for _ in range(num_descriptors):
            try:
                # 跳过一些头字节
                self.atn_parser.offset += 8
                
                effect_type = self.atn_parser.read_type()
                self.atn_parser.offset += 4  # 跳过dialog状态
                
                desc = self.atn_parser.parse_descriptor()
                effects.append({
                    "effect_type": self.atn_parser.type_id_to_name(effect_type),
                    "descriptor": desc
                })
            except:
                break
        
        style["effects"] = effects
        return style
    
    def extract_style_effects(self, asl_path):
        """提取样式中的所有效果"""
        data = self.parse_asl_file(asl_path)
        styles_info = []
        
        effect_type_names = {
            "DrSh": "Drop Shadow",
            "IrSh": "Inner Shadow",
            "OrGl": "Outer Glow",
            "IrGl": "Inner Glow",
            "BeEm": "Bevel and Emboss",
            "SoFi": "Satin",
            "SoCo": "Color Overlay",
            "GdFl": "Gradient Overlay",
            "PtFl": "Pattern Overlay",
            "FrFX": "Stroke",
        }
        
        for style in data["styles"]:
            style_effects = []
            for effect in style["effects"]:
                effect_type = effect["effect_type"]
                effect_name = effect_type_names.get(effect_type, effect_type)
                style_effects.append(effect_name)
            
            styles_info.append({
                "style_name": style["name"],
                "effects": style_effects,
                "num_effects": len(style_effects)
            })
        
        return styles_info


class FilterParamExtractor:
```

```python
        for ext in extensions:
            image_files.extend(input_path.glob(ext))

                    new_width,
                    new_height,
                    resolution,
                    8  # psBicubicAutomatic
                )

                    out_file = output_path / f"{img_file.stem}.jpg"
                    jpeg_options = win32com.client.Dispatch("Photoshop.JPEGSaveOptions")
                    jpeg_options.Quality = quality
```

```python
            target_height = max(target_height_before, target_height_after)
            
            doc_before.ResizeImage(target_width, target_height_before, 72)
            doc_after.ResizeImage(target_width, target_height_after, 72)
            
            # 创建对比画布
            gap = 20
            label_height = 40
            canvas_width = target_width * 2 + gap * 3
            canvas_height = target_height + label_height + gap * 2
            
            doc = self.ps_app.Documents.Add(
                canvas_width, canvas_height, 72,
                "Before After Comparison",
                2,  # psRGB
                1   # psWhiteFill
            )
            
            # 复制Before图
            doc_before.Selection.SelectAll()
            doc_before.Selection.Copy()
            layer_before = doc.Paste()
            layer_before.Translate(gap, gap + label_height)
            
            # 复制After图
            doc_after.Selection.SelectAll()
            doc_after.Selection.Copy()
            layer_after = doc.Paste()
            layer_after.Translate(target_width + gap * 2, gap + label_height)
            
            # 添加标签
            for i, (label, x_pos) in enumerate([
                (label_before, gap + target_width / 2),
                (label_after, target_width + gap * 2 + target_width / 2)
            ]):
                text_layer = doc.ArtLayers.Add()
                text_layer.Kind = 2
                text_item = text_layer.TextItem
                text_item.Contents = label
                text_item.Size = 24
                text_item.Font = "Arial Bold"
                text_item.Justification = 2  # psCenter
                text_item.Position = (x_pos, label_height)
                text_item.Color.Red = 0
                text_item.Color.Green = 0
                text_item.Color.Blue = 0
            
            # 保存
            jpeg_options = win32com.client.Dispatch("Photoshop.JPEGSaveOptions")
            jpeg_options.Quality = 10
            doc.SaveAs(output_path, jpeg_options, True)
            doc.Close(2)
            
            print(f"对比图已创建: {output_path}")
            
        finally:
            doc_before.Close(2)
            doc_after.Close(2)

    def close(self):
        pythoncom.CoUninitialize()
```
