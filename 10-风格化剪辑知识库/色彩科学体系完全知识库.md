> 版本: 2025-v1 | 适用: AE/PR/DaVinci + 影视后期全流程

## 一、色彩科学基础

### 1.1 什么是色彩科学

色彩科学是研究颜色的产生、感知、测量和再现的跨学科领域，涉及物理学(光学)、生理学(人眼感知)和数学(色彩空间模型)。在影视后期中，色彩科学决定了从拍摄到最终显示的每个环节中颜色如何被记录、处理和呈现。

### 1.2 色彩三要素

| 属性 | 英文 | 含义 | 后期对应 |
|------|------|------|---------|
| 色相 | Hue | 颜色种类(红/蓝/绿) | 色轮调整 |
| 饱和度 | Saturation | 颜色纯度/鲜艳度 | 饱和度控制 |
| 明度 | Value/Lightness | 颜色明暗程度 | 曲线/色阶 |

### 1.3 色彩模型

| 模型 | 维度 | 用途 |
|------|------|------|
| RGB | 红绿蓝加色混合 | 显示器/传感器 |
| HSL/HSV | 色相/饱和度/明度 | 调色直觉控制 |
| LAB | 亮度+色度分离 | 科学色彩分析 |
| YCbCr | 亮度+色度分量 | 视频编码 |
| CMYK | 青品黄黑减色混合 | 印刷输出 |

## 三、ACES 色彩管理工作流

### 3.1 ACES 概述

**ACES (Academy Color Encoding System)** 由美国电影艺术与科学学院(AMPAS)于2004年启动，2014年发布1.0版本。它不是单一色彩空间，而是**全流程色彩管理体系**。

核心理念: **场景参考(Scene Reference)** — 以真实世界光线为基准，而非以某个显示设备为基准。

### 3.2 ACES 核心组件

| 组件 | 全称 | 功能 |
|------|------|------|
| IDT | Input Device Transform | 将摄影机原始数据转换到ACES |
| RRT | Reference Rendering Transform | 标准渲染变换(色调映射) |
| ODT | Output Device Transform | 从ACES转换到目标显示 |
| AP0 | ACES 2065-1 | 超宽色域线性空间(归档) |
| AP1 | ACEScg基础 | 实用工作空间 |
| ACEScg | AP1线性 | VFX/合成工作空间 |
| ACEScc | AP1对数 | 调色工作空间 |
| ACEScct | AP1对数+Toe | 调色(带暗部增强) |

### 3.3 ACES 工作流架构

```
拍摄素材(各品牌Log)
    ↓ IDT(摄影机匹配)
ACES 2065-1 (AP0)
    ↓ 转换
ACEScg (AP1线性) ← VFX/合成/渲染
    ↓ 转换
ACEScc/ACEScct ← 调色
    ↓ RRT + ODT
目标显示(Rec.709/P3-DCI/HDR10/HLG)
```

### 3.4 在 After Effects 中使用 ACES

1. **项目设置**: 编辑 → 项目设置 → 颜色
   - 颜色引擎: OpenColorIO (OCIO)
   - 工作空间: ACEScg 或 ACEScct
2. **素材解释**: 为每个素材指定正确的IDT
   - Sony S-Log3/S-Gamut3.Cine → Sony IDT
   - Canon C-Log3/Cinema Gamut → Canon IDT
   - ARRI LogC3/ARRI Wide Gamut → ARRI IDT
3. **合成**: 在ACEScg中工作（线性，值可超1.0）
4. **输出**: 选择ODT → Rec.709(显示器) 或 P3-DCI(影院)

### 3.5 ACES 在达芬奇中

```
项目设置 → 色彩管理:
  色彩科学: ACEScct
  ACES版本: 1.3
  ACES输入变换: 按素材选择
  输出变换: Rec.709 Gamma 2.4
```

## 四、HDR 色彩科学

### 4.1 HDR 核心概念

| 概念 | 含义 | 数值 |
|------|------|------|
| 峰值亮度 | 画面最亮部分 | 1000-4000 nits |
| 黑位 | 画面最暗部分 | 0.005 nits (OLED) |
| 对比度 | 最亮/最暗比 | 200,000:1+ |
| 色深 | 每通道色阶数 | 10bit(1024级)/12bit |
| 色域 | 颜色范围 | Rec.2020/DCI-P3 |

### 4.2 HDR 格式对比

| 格式 | 传输曲线 | 色域 | 元数据 | 兼容SDR |
|------|---------|------|--------|---------|
| HDR10 | PQ(ST2084) | Rec.2020 | 静态 | 部分 |
| HDR10+ | PQ | Rec.2020 | 动态 | 部分 |
| Dolby Vision | PQ | Rec.2020 | 动态逐帧 | 是(双层) |
| HLG | HLG | Rec.2020 | 无 | 完全 |
| SL-HDR1 | PQ/HLG | Rec.2020 | 动态 | 是 |

### 4.3 HDR 调色注意事项

- **不要**直接在Rec.709中"模拟"HDR
- 高光保留: 使用软裁剪(Soft Clip)而非硬截断
- 色调映射: ACES RRT 自动处理超亮值映射
- 监看: 需要HDR监看器或支持HDR的显示器
- 安全区: 保留0.005-10000 nits范围内的关键信息

## 五、调色理论与技法

### 5.1 一级调色(Primary Grading)

一级调色处理**整个画面**的全局属性:

| 工具 | 作用 | 典型调整 |
|------|------|---------|
| 曝光/偏移 | 整体亮度 | ±0.5EV |
| 对比度 | 明暗差异 | S曲线 |
| 白平衡 | 色温/色调 | 5600K(日光)/3200K(钨丝) |
| 饱和度 | 整体色彩浓度 | 通常降10-20%增加电影感 |

### 5.2 二级调色(Secondary Grading)

二级调色处理**画面局部**:

| 工具 | 作用 | 应用 |
|------|------|------|
| 曲线(HSL) | 按色相/饱和度/亮度选色 | 单独调整天空/肤色 |
| 限定器(Qualifier) | 选取特定颜色区域 | 肤色隔离、天空增强 |
| 遮罩(Mask) | 空间区域选择 | 压暗四周、提亮主体 |
| 跟踪(Tracking) | 让遮罩跟随运动 | 跟踪人物面部调色 |

### 5.3 电影感调色技法

#### 分离色调(Split Toning)
- 高光加暖色(橙/黄): +5~15
- 阴影加冷色(青/蓝): +5~15
- 效果: 经典好莱坞色调

#### 暗部偏移
- 阴影不完全黑，偏向深青/深蓝
- 效果: 增加深度感和电影氛围

#### 胶片模拟
- 暗部提亮( lifted blacks ): 黑色偏灰
- 高光柔化: 减少对比度
- 颗粒添加: 模拟胶片颗粒感
- 色彩偏移: 绿色偏黄，红色偏橙

### 5.4 肤色处理

| 参数 | 目标值 | 说明 |
|------|--------|------|
| 色相 | 25-35° (矢量示波器) | 肤色线位置 |
| 饱和度 | 30-50 IRE | 自然肤色 |
| 亮度 | 55-75 IRE | 中等肤色 |

**肤色线(Skin Tone Line)**: 在矢量示波器上，从中心到黄红之间的连线，所有种族肤色都落在这条线上。

## 六、LUT 体系

### 6.1 LUT 类型

| 类型 | 用途 | 维度 |
|------|------|------|
| 1D LUT | 简单映射(伽马/曝光) | 每通道独立 |
| 3D LUT | 色彩空间转换/风格化 | 全色彩体 |
| .cube | 通用3D LUT格式 | 行业标准 |
| .3dl | Autodesk格式 | Flame/Smoke |
| .mga | Pandora格式 | 老式系统 |

### 6.2 LUT 生成工作流

```
1. 在 Lightroom/DaVinci 中调色满意效果
2. 导出 .cube LUT 文件
3. 在 AE 中通过 Lumetri Color 加载
4. 应用到同场景其他机位素材
```

### 6.3 LUT 使用注意事项

- **输入色彩空间匹配**: LUT 必须匹配素材的输入空间(Log→Log)
- **曝光匹配**: LUT 对曝光敏感，±0.5EV偏差会导致明显偏色
- **强度控制**: 通常 60-80% 强度比 100% 更自然
- **不要叠加多个LUT**: 除非明确知道每个LUT的作用

## 七、色彩心理学与视觉叙事

### 7.1 色彩情绪映射

| 色彩 | 情绪 | 经典应用 |
|------|------|---------|
| 红色 | 激情/危险/愤怒 | 动作片高潮、恐怖片 |
| 蓝色 | 冷静/忧郁/科技 | 科幻片、悬疑片 |
| 绿色 | 自然/诡异/疾病 | 黑客帝国(绿色滤镜) |
| 黄色 | 温暖/不安/疯狂 | 老照片、回忆场景 |
| 橙色+青色 | 现代电影感 | 好莱坞大片标配 |
| 去饱和 | 压抑/写实 | 战争片、纪录片 |

### 7.2 色彩叙事策略

- **色彩弧线**: 全片色彩随剧情变化（如从暖到冷）
- **角色色彩**: 不同角色关联不同色调
- **时间色彩**: 不同时间段使用不同色彩风格
- **空间色彩**: 不同场景/地点使用色彩区分

## 八、色彩管理最佳实践

### 8.1 项目色彩管理设置清单

```
□ 确定目标交付色彩空间(Rec.709/P3-DCI/HDR10)
□ 设置项目工作色彩空间(ACEScg推荐)
□ 为每个素材指定正确的IDT/输入变换
□ 设置正确的监看环境(D65, 100nits SDR)
□ 使用示波器监控(矢量/波形/直方图/parade)
□ 输出时应用正确的ODT
□ 保留完整色彩管理元数据
```

### 8.2 常见色彩问题排查

| 问题 | 原因 | 解决 |
|------|------|------|
| 素材偏灰/过亮 | Log素材未应用IDT | 指定正确的摄影机IDT |
| 色彩过饱和 | 色彩空间不匹配 | 检查输入/输出空间 |
| 肤色偏绿/偏品 | 白平衡错误 | 用灰卡/肤色线校准 |
| 高光溢出 | 超出显示范围 | 使用软裁剪/色调映射 |
| 暗部噪声 | 欠曝/ISO过高 | 降噪+暗部提升 |
| 跨软件偏色 | 色彩管理不一致 | 统一使用OCIO/ACES |
