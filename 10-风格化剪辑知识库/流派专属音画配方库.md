### 1.2 流派配方的5层Schema

每个流派配方都遵循统一的5层Schema结构，确保配方的完整性和可组合性。

#### 1.2.1 色彩基调层（Color Palette）
- 主色调（Primary Color）：决定整体氛围的核心颜色
- 辅助色（Secondary Color）：用于强调和对比的颜色
- 点缀色（Accent Color）：用于高亮和视觉冲击的颜色
- 饱和度范围（Saturation Range）：整体色彩鲜艳程度
- 对比度范围（Contrast Range）：明暗对比强度

#### 1.2.2 效果栈层（Effect Stack）
- 层级顺序（Layer Order）：从底层到顶层的效果叠加顺序
- 每个效果的matchName：AE内部效果标识符
- 参数值范围（Parameter Ranges）：每个参数的典型取值区间
- 强度调制参数（Intensity Modulation）：随音乐变化的参数
- 混合模式（Blend Modes）：各效果层的混合方式

#### 1.2.3 关键帧节奏层（Keyframe Rhythm）
- 重拍映射（Beat Mapping）：哪些参数跟随重拍变化
- 缓动曲线（Easing Curves）：关键帧之间的插值方式
- 节奏型（Rhythm Pattern）：关键帧的时间分布模式
- Build-up曲线（Build-up Curve）：能量上升段的参数变化
- Drop冲击（Drop Impact）：能量释放点的参数跳变

#### 1.2.4 转场策略层（Transition Strategy）
- 主转场类型（Primary Transition）：段落间的主要转场方式
- 辅助转场（Secondary Transition）：镜头间的次要转场
- 转场时长（Transition Duration）：转场持续时间
- 转场触发点（Transition Trigger）：转场发生的音乐位置
- 转场效果参数（Transition Parameters）：转场效果的具体设置

#### 1.2.5 音效体系层（Sound Design System）
- 核心音效元素（Core Sound Elements）：流派标志性音效
- 音效触发规则（Sound Trigger Rules）：音效与画面的同步规则
- 频率分区（Frequency Zones）：低频/中频/高频的视觉映射
- 空间感参数（Space Parameters）：混响、延迟对应的视觉效果
- 动态范围（Dynamic Range）：音量变化对应的视觉强度

```
民谣: 70-110 BPM
赛博朋克: 100-170 BPM
```

#### 1.3.2 乐器配置指纹
- **EDM**: 合成器(Synth)、鼓机(Drum Machine)、采样器(Sampler)
- **国潮古风**: 古筝、笛子、古琴、琵琶、二胡、大鼓
- **摇滚**: 电吉他、贝斯、架子鼓、主唱
- **流行**: 合成器、鼓机、人声、钢琴
- **嘻哈Trap**: 808贝斯、Hi-Hat、Snare、人声切片

- **古典交响**: 弦乐组、木管组、铜管组、打击乐组、钢琴
- **爵士**: 萨克斯、小号、钢琴、贝斯、架子鼓
- **民谣**: 木吉他、口琴、手鼓、人声
- **赛博朋克**: 合成器Lead、Arpeggio、Glitch音效、科幻音效

#### 1.3.3 和声进行指纹
- **EDM**: I-V-vi-IV、i-VI-III-VII、五声音阶旋律
- **国潮古风**: 五声音阶、宫商角徵羽、传统调式
- **摇滚**: 强力和弦、I-IV-V、布鲁斯进行
- **流行**: I-V-vi-IV、vi-IV-I-V、卡农进行

- **Lo-Fi**: 爵士和弦延伸、七和弦、九和弦
- **古典交响**: 功能性和声、副属和弦、模进
- **爵士**:  ii-V-I、蓝调音阶、延伸和弦
- **民谣**: 三和弦为主、I-IV-V、转调较少
- **赛博朋克**: 合成器琶音、氛围和弦、不协和音

#### 1.3.4 节奏型指纹
- **EDM**: 4/4拍稳定拍、Kick每拍都有、Hi-Hat 8分/16分音符
- **国潮古风**: 自由节奏、散板、弹性速度
- **摇滚**: 强拍重音、反拍镲片、切分节奏
- **流行**: 稳定节拍、拍手节奏、规律鼓点
- **嘻哈Trap**: 808重低音、Hi-Hat三连音、切分节奏
- **Lo-Fi**: 慵懒鼓点、轻微拖拍、Shuffle节奏
- **古典交响**: 多变节拍、复节奏、弹性速度
- **爵士**: Swing摇摆、切分节奏、即兴装饰
- **民谣**: 简单节奏、稳定节拍、分解和弦
- **赛博朋克**: 快速琶音、Glitch节奏、多变节拍

#### 1.3.5 频谱特征指纹
- **低频段(20-200Hz)**: 流派的能量基底
- **中低频(200-500Hz)**: 温暖度和厚度
- **中频段(500Hz-2kHz)**: 人声和主要乐器
- **中高频(2kHz-8kHz)**: 清晰度和穿透力
- **高频段(8kHz-20kHz)**: 空气感和细节

## 第2章 EDM电子舞曲配方

### 2.1 子流派细分

EDM（Electronic Dance Music）是一个庞大的音乐类别，包含多种子流派，每种子流派都有其独特的视觉语言。

| 子流派 | BPM | 核心特征 | 视觉关键词 |
|--------|-----|---------|-----------|
| **House** | 120-130 | 4/4拍稳定节奏、钢琴/合成器音色 | 霓虹、派对、舞池、渐变 |
| **Techno** | 120-140 | 重复性强、工业感、极简主义 | 工业、机械、暗调、几何 |
| **Dubstep** | 70/140 | 重低音Wobble、半拍节奏、Drop | 故障、扭曲、冲击、暗色系 |
| **Future Bass** | 140-160 | 彩色和弦、Future感、旋律性强 | 霓虹、粒子、糖果色、梦幻 |
| **Drum & Bass** | 160-180 | 快速鼓点、重贝斯、高速节奏 | 速度线、动感、都市、夜色 |
| **Psytrance** | 135-150 | 迷幻合成器、持续低音、视觉幻觉 | 迷幻、万花筒、曼陀罗、荧光 |

### 2.2 色彩基调

EDM的色彩基调以霓虹紫和青色为主，高饱和度高对比度，营造强烈的电子音乐氛围。

```
主色调: 霓虹紫 (#9D00FF) - RGB(157, 0, 255)
辅助色: 电光青 (#00FFFF) - RGB(0, 255, 255)
点缀色: 荧光粉 (#FF00FF) - RGB(255, 0, 255)
背景色: 深黑/深蓝 (#0A0A1A) - RGB(10, 10, 26)
饱和度: +30 ~ +50
对比度: +20 ~ +40
```

> [!tip] 子流派色彩变体
> - **Techno**: 偏冷色调，以深蓝和银灰为主
> - **Dubstep**: 偏暗色调，以深紫和暗红为主
> - **Future Bass**: 偏糖果色，以粉紫和青蓝为主
> - **Psytrance**: 偏迷幻色，以荧光绿和橙红为主

### 2.4 关键帧节奏

#### 2.4.1 重拍映射规则
```
Kick鼓 (低频): 
  - 缩放: 100% → 103% → 100% (每拍)
  - 位置: 轻微向下移动2-3px
  - Glow强度: 0.8 → 1.5 → 0.8

Snare军鼓 (中频):
  - 闪白: 0% → 30% → 0% (持续2帧)
  - Glitch强度: 低 → 高 → 低
  - 粒子爆发: 额外发射50-100个粒子

Hi-Hat踩镲 (高频):
  - 微小闪烁: 亮度+5%
  - 扫描线速度: 瞬时加快
```

#### 2.4.2 缓动曲线设计
```
重拍冲击 (Impact):
  - 入点: Easy Ease In (速度从快到慢)
  - 出点: Easy Ease Out (速度从慢到快)
  - 曲线形状: 先快后慢，模拟物理冲击

Build-up上升:
  - 缓动类型: Easy Ease In
  - 曲线形状: 指数上升，开始慢后来快
  - 时间跨度: 4-8小节

Drop释放:
  - 入点: Hold (瞬时跳变)
  - 出点: Easy Ease Out
  - 幅度: 参数值瞬时跳到最大值，然后逐渐衰减
```

#### 2.4.3 典型节奏型
```
4/4拍稳定节奏:
  - 每拍一次Kick冲击
  - 第2、4拍Snare加重
  - 16分音符Hi-Hat持续闪烁

Build-up节奏:
  - 第1-4小节: 效果强度线性增加20%→60%
  - 第5-6小节: 效果强度指数增加60%→90%
  - 第7小节: 白噪声渐强，视觉模糊渐增
  - 第8小节最后1拍: 完全黑屏/白屏

Drop节奏:
  - 第1拍: 全效果爆发，参数瞬时到100%
  - 第1-4拍: 效果强度从100%衰减到80%
  - 后续循环: 每拍有节奏性起伏
```

### 2.5 转场策略

#### 2.5.1 主转场类型
| 转场类型 | 使用场景 | 时长 | 参数设置 |
|---------|---------|------|---------|
| **硬切** | 段落内镜头切换 | 0帧 | 无 |
| **闪白转场** | Drop点转场 | 2-3帧 | 亮度从0→100→0 |
| **故障转场** | 高能段落转场 | 8-12帧 | RGB分离+扫描线偏移+随机块 |
| **缩放转场** | Build-up到Drop | 24-48帧 | 缩放从100%→120%→100%，配合模糊 |
| **黑场淡入淡出** | Intro/Outro | 48-72帧 | 不透明度0↔100% |

#### 2.5.2 转场触发点
```
Intro → Build: 
  - 第一个明显的合成器旋律进入时
  - 转场类型: 缩放+辉光渐强

Build → Drop:
  - Drop的第一拍Kick
  - 转场类型: 闪白+故障冲击
  - 转场时机: 精确对齐Kick的起始点

Drop → Breakdown:
  - 最后一个重拍之后
  - 转场类型: 模糊淡出+黑场
  - 转场时长: 1-2秒

Breakdown → Second Drop:
  - Build-up结束后的Drop点
  - 转场类型: 同第一次Drop，可加变化
```

### 2.6 音效体系

#### 2.6.1 核心音效元素
| 音效 | 频率范围 | 视觉映射 | 触发方式 |
|------|---------|---------|---------|
| **Kick鼓** | 60-120Hz | 缩放冲击、位置震动 | 每拍触发 |
| **Snare军鼓** | 200-500Hz | 闪白、Glitch爆发 | 第2、4拍 |
| **Hi-Hat踩镲** | 5k-10kHz | 微小闪烁、细节增强 | 8/16分音符 |
| **Riser上升音效** | 全频段爬升 | Build-up效果增强 | Build段持续 |
| **Impact重击** | 全频段冲击 | 全屏冲击效果 | Drop起始点 |
| **Downer下降音效** | 高频→低频 | 效果衰减 | 段落结束 |
| **白噪声** | 全频段 | 噪点/颗粒感 | Build-up段 |

#### 2.6.2 音效-视觉同步规则
```
低频 (20-200Hz) → 缩放 + 位置抖动 + 整体亮度
中频 (200Hz-2kHz) → 色彩饱和度 + 粒子发射
高频 (2kHz-20kHz) → 锐化 + 细节 + 微小闪烁

音量变化 → 效果强度
  - 音量增加10dB → 效果强度增加20%
  - 音量峰值 → 效果强度峰值
```

```
  - 对称结构: 规整的乐句对应规整的画面
  - 可预测性: 观众能预期下一个变化
  - 满足感: 变化如期而至，恰到好处
```

#### 5.4.2 弹性缓动曲线
```
标准Pop缓动 (Elastic):
  - 起始: 快速启动
  - 过冲: 轻微超过目标值
  - 回弹: 回弹一两次
  - 稳定: 最终停在目标值
  - 感觉: 弹跳、活力、可爱

呼吸感曲线 (Breathing):
  - 缓慢正弦变化
  - 缩放: 100% ↔ 102%
  - 位置: 轻微上下浮动
  - 模拟: 呼吸/心跳的韵律
```

#### 5.4.3 结构映射
```
主歌:
  - 变化频率: 每4拍/每乐句
  - 运动: 缓慢推进/横移
  - 效果: 低强度

预副歌:
  - 变化频率: 加快
  - 效果强度: 渐强
  - 运动: 加速

副歌:
  - 变化频率: 每2拍/每拍都有小变化
  - 效果: 最强
  - 画面: 最丰富
```

```
  - 群奏 → 层次感/景深变化

木管组 (长笛/单簧管/双簧管):
  - 长音 → 持续光晕
  - 快速音阶 → 快速光点流线
  - 独奏 → 焦点清晰

铜管组 (小号/圆号/长号):
  - 辉煌 → 强光/金色
  - 激昂 → 画面扩张
  - 庄严 → 稳定/厚重

打击乐组 (定音鼓/钹):
  - 定音鼓 → 低频震动/缩放
  - 钹 → 闪光/泛光
  - 三角铁 → 微小高光
```

#### 8.4.3 戏剧化曲线
```
Crescendo渐强曲线:
  - 起始: 低强度
  - 中段: 缓慢增强
  - 后段: 快速增强
  - 顶点: 突然到顶峰
  - 模拟: 管弦乐渐强的张力

Decrescendo渐弱曲线:
  - 起始: 高峰
  - 快速衰减到中等
  - 缓慢减弱到消失
  - 余韵悠长
```

### 8.5 转场策略

#### 8.5.1 主转场类型

| **匹配剪辑** | 创意转场 | 10-30帧 | 巧妙、电影语言 |
| **光圈/暗角转场** | 开始/结束 | 60-120帧 | 经典、剧场感 |

#### 8.5.2 电影化转场
```
古典转场原则:
  1. 电影感: 像电影一样的镜头语言
  2. 流畅性: 转场如行云流水
  3. 叙事性: 转场推动情绪/叙事
  4. 仪式感: 大转场要有分量

避免:
  - 快速切镜 (除非音乐要求)
  - 花哨转场
  - 流行效果
```

## 第10章 流派混合与转场策略

### 10.1 流派融合的效果叠加规则

#### 10.1.1 混合原则
```
1. 主次原则: 一个主流派 + 一个或多个次流派
   - 主流派 (70%): 决定整体风格和基调
   - 次流派 (30%): 提供特色元素和点缀

2. 分层原则: 不同流派的效果放在不同层
   - 底层: 主流派的基础效果 (调色、颗粒)
   - 中层: 主流派+次流派的混合效果
   - 顶层: 次流派的点缀效果 (粒子、光效)

3. 协调原则: 确保混合后不冲突
   - 色彩系统协调: 主色调统一，辅助色互补
   - 节奏系统协调: 以主流派节奏为骨架
   - 效果强度协调: 总效果强度不超过100%
```

#### 10.1.2 效果叠加计算
```
混合强度计算公式:
  final_effect = primary_effect * primary_weight + secondary_effect * secondary_weight

权重分配:
  - 70/30混合: 主流派70%，次流派30%
  - 50/50混合: 各占50% (需谨慎，容易混乱)
  - 80/20混合: 以主流派为主，轻微点缀

效果分层叠加顺序 (从下到上):
  1. 基础调色 (主流派)
  2. 颗粒/质感 (主流派+次流派混合)
  3. 核心效果 (主流派)
  4. 特色效果 (次流派)
  5. 光效/粒子 (两派混合)
  6. 最终调色 (统一调整)
```

#### 10.1.3 冲突解决规则
```
色彩冲突:
  - 当两个流派主色冲突时，降低次流派饱和度
  - 或使用渐变/分割画面分别展示
  - 或选择中性色作为过渡

节奏冲突:
  - 以主流派的节奏型为主
  - 次流派的节奏作为装饰/加花
  - 避免同时使用两个强节奏系统

效果冲突:
  - 同类效果取强度较高的
  - 或分层使用不同的参数
  - 或使用遮罩分区应用
```

### 10.2 跨流派转场的视觉过渡方案

#### 10.2.1 转场过渡策略
```
风格A → 过渡段 → 风格B

过渡段时长:
  - 快速过渡: 1-2秒 (硬切换+少量过渡)
  - 中速过渡: 3-5秒 (标准过渡)
  - 慢速过渡: 8-16秒 (渐变式融合)

过渡方法:
  1. 效果渐变法: A效果减弱，B效果增强
  2. 色彩过渡法: 从A色调渐变到B色调
  3. 节奏过渡法: 从A节奏渐变到B节奏
  4. 蒙版过渡法: 使用形状/纹理遮罩过渡
  5. 故障过渡法: Glitch干扰后切换风格
```

#### 10.2.2 常见流派过渡组合
```
EDM → 古风:
  过渡方式: 霓虹渐隐 + 水墨晕染渐显
  过渡时长: 3-5秒
  中间状态: 半霓虹半水墨的融合效果

古风 → 现代流行:
  过渡方式: 卷轴收起 → 现代画面展开
  过渡时长: 2-3秒
  关键元素: 水墨粒子化作现代粒子

摇滚 → 古典:
  过渡方式: 失真渐弱 + 弦乐渐强
  过渡时长: 4-6秒
  视觉变化: 从高对比颗粒到柔和电影感

Lo-Fi → 赛博朋克:
  过渡方式: 暖色调变冷色调 + 颗粒变故障
  过渡时长: 3-4秒
  触发点: 一个强故障效果
```

```python
def generate_genre_recipe(
    genre: str,
    sub_genre: Optional[str] = None,
    music_atom: Optional[MusicAtom] = None,
    intensity_mod: float = 1.0,
    custom_prefs: Optional[Dict] = None
) -> FullRecipe:
    """
    根据流派和音乐特征生成完整的音画配方
    
    Args:
        genre: 主流派名称
        sub_genre: 子流派名称 (可选)
        music_atom: 音乐原子特征 (可选，用于精细化匹配)
        intensity_mod: 强度修正系数 (0.5-2.0)
        custom_prefs: 用户自定义偏好 (可选)
    
    Returns:
        FullRecipe: 完整的配方对象
    """
    # 1. 获取基础配方模板
    genre_key = genre.lower().replace(" ", "_")
    if genre_key not in GENRE_RECIPE_DB:
        raise ValueError(f"不支持的流派: {genre}. 支持的流派: {list(GENRE_RECIPE_DB.keys())}")
    
    base_recipe = GENRE_RECIPE_DB[genre_key]
    
    # 2. 初始化音乐原子（如果未提供）
    if music_atom is None:
        music_atom = MusicAtom(
            bpm=get_default_bpm(genre_key),
            genre=genre
        )
    
    # 3. 计算动态强度曲线
    intensity_profile = compute_intensity_profile(music_atom, base_recipe, intensity_mod)
    
    # 4. 生成色彩调色板
    color_palette = generate_color_palette(base_recipe, music_atom, custom_prefs)
    
    # 5. 生成效果栈
    effect_stack = generate_effect_stack(
        base_recipe["effect_templates"],
        intensity_profile,
        music_atom,
        custom_prefs
    )
    
    # 6. 生成关键帧节奏
    keyframe_rhythm = generate_keyframe_rhythm(
        base_recipe,
        music_atom,
        intensity_profile
    )
    
    # 7. 生成转场策略
    transitions = generate_transition_strategy(
        genre_key,
        sub_genre,
        music_atom,
        intensity_profile
    )
    
    # 8. 生成音效体系映射
    sound_design = generate_sound_design(
        genre_key,
        music_atom
    )
    
    # 9. 生成段落配方
    segments = generate_segment_recipes(
        music_atom,
        intensity_profile,
        effect_stack,
        transitions
    )
    
    # 10. 应用用户自定义偏好
    if custom_prefs:
        apply_custom_preferences(
            color_palette, effect_stack, keyframe_rhythm,
            transitions, sound_design, custom_prefs
        )
    
    return FullRecipe(
        genre=genre,
        sub_genre=sub_genre or genre,
        color_palette=color_palette,
        effect_stack=effect_stack,
        keyframe_rhythm=keyframe_rhythm,
        transitions=transitions,
        sound_design=sound_design,
        segments=segments,
        intensity_profile=intensity_profile
    )


def compute_intensity_profile(
    music_atom: MusicAtom,
    base_recipe: Dict,
    intensity_mod: float
) -> List[float]:
    """计算强度曲线（按时间点的强度值序列）"""
    sections = music_atom.sections
    
    if not sections:
        # 默认的七段式强度曲线
        return [0.3, 0.5, 0.7, 0.9, 1.0, 0.85, 0.6, 0.3]
    
    profile = []
    for section in sections:
        section_type = section.get("type", "normal")
        base_intensity = {
            "intro": 0.3,
            "verse": 0.5,
            "pre_chorus": 0.75,
            "chorus": 1.0,
            "build": 0.8,
            "drop": 1.0,
            "breakdown": 0.4,
            "bridge": 0.6,
            "solo": 0.85,
            "outro": 0.3
        }.get(section_type, 0.5)
        
        profile.append(base_intensity * intensity_mod)
    
    return profile


def generate_color_palette(
    base_recipe: Dict,
    music_atom: MusicAtom,
    custom_prefs: Optional[Dict]
) -> Dict:
    """生成色彩调色板"""
    base_colors = base_recipe["color_palette"].copy()
    
    # 根据能量调整饱和度和对比度
    energy = music_atom.energy_level
    sat_range = base_colors["saturation"]
    con_range = base_colors["contrast"]
    
    base_colors["saturation"] = sat_range[0] + (sat_range[1] - sat_range[0]) * energy
    base_colors["contrast"] = con_range[0] + (con_range[1] - con_range[0]) * energy
    
    # 应用用户自定义颜色
    if custom_prefs and "color" in custom_prefs:
        for key, value in custom_prefs["color"].items():
            if key in base_colors:
                base_colors[key] = value
    
    return base_colors
```

#### 11.3.1 流水线架构
```
输入音频 → 特征提取 → 流派分类 → 子流派分类 → 音乐结构分析 → 配方生成 → 输出配方
     ↓          ↓           ↓            ↓              ↓
   音频文件  MIR特征   主流派概率   子流派概率     段落时间点
            (BPM,     分布          分布
             频谱,
             乐器,
             节拍)
```

#### 11.3.2 特征提取模块
```
输入: 音频文件 (WAV/MP3)
输出: MusicAtom对象

提取特征:
1. 基础特征
   - BPM ( tempo )
   - 拍号 (time signature)
   - 调性 (key)
   - 能量值 (RMS energy)

2. 频谱特征
   - 频谱质心 (spectral centroid)
   - 频谱带宽 (bandwidth)
   - 频谱滚降点 (rolloff)
   - 零交叉率 (zero crossing rate)
   - MFCC (梅尔频率倒谱系数)

3. 节奏特征
   - 节拍置信度
   - 节奏规律性
   - 节拍模式 (on/off beat)
   - 鼓点检测

4. 乐器/音色特征
   - 鼓机 vs 真实鼓
   - 合成器 vs 真实乐器
   - 人声存在概率
   - 贝斯类型

5. 结构特征
   - 段落分割 (intro/verse/chorus...)
   - 相似度矩阵
   - 重复性度量
```

```python
def classify_genre(features: Dict) -> Tuple[str, float, Dict[str, float]]:
    """
    基于规则的流派分类器（可替换为ML模型）
    
    返回: (主流派, 置信度, 各流派概率分布)
    """
    scores = {}
    
    bpm = features.get("bpm", 120)
    spectral_centroid = features.get("spectral_centroid", 1000)
    has_synth = features.get("has_synthesizer", False)
    has_distortion = features.get("has_distortion_guitar", False)
    has_orchestral = features.get("has_orchestral", False)
    has_traditional = features.get("has_traditional_chinese", False)
    energy = features.get("energy", 0.5)
    beat_strength = features.get("beat_strength", 0.5)
    
    # EDM评分
    edm_score = 0
    if 120 <= bpm <= 150:
        edm_score += 30
    if has_synth:
        edm_score += 25
    if beat_strength > 0.7:
        edm_score += 20
    if spectral_centroid > 1500:
        edm_score += 15
    if energy > 0.6:
        edm_score += 10
    scores["edm"] = min(edm_score, 100)
    
    # 摇滚评分
    rock_score = 0
    if 100 <= bpm <= 180:
        rock_score += 25
    if has_distortion:
        rock_score += 35
    if energy > 0.7:
        rock_score += 20
    if beat_strength > 0.6:
        rock_score += 10
    scores["rock"] = min(rock_score, 100)
    
    # 古风评分
    guofeng_score = 0
    if 60 <= bpm <= 100:
        guofeng_score += 20
    if has_traditional:
        guofeng_score += 40
    if energy < 0.6:
        guofeng_score += 15
    if spectral_centroid < 1500:
        guofeng_score += 10
    scores["guofeng"] = min(guofeng_score, 100)
    
    # 流行评分
    pop_score = 0
    if 90 <= bpm <= 130:
        pop_score += 25
    if features.get("has_vocal", False):
        pop_score += 30
    if 0.4 <= energy <= 0.8:
        pop_score += 20
    scores["pop"] = min(pop_score, 100)
    
    # 嘻哈/Trap评分
    trap_score = 0
    if 70 <= bpm <= 160:
        trap_score += 20
    if features.get("has_808_bass", False):
        trap_score += 35
    if has_synth:
        trap_score += 15
    if features.get("has_rap_vocal", False):
        trap_score += 25
    scores["trap"] = min(trap_score, 100)
    
    # Lo-Fi评分
    lofi_score = 0
    if 70 <= bpm <= 90:
        lofi_score += 30
    if features.get("has_vinyl_noise", False):
        lofi_score += 25
    if energy < 0.5:
        lofi_score += 20
    if beat_strength < 0.5:
        lofi_score += 15
    scores["lofi"] = min(lofi_score, 100)
    
    # 古典评分
    classical_score = 0
    if 60 <= bpm <= 120:
        classical_score += 20
    if has_orchestral:
        classical_score += 40
    if spectral_centroid < 2000:
        classical_score += 15
    if features.get("dynamic_range", 0) > 0.6:
        classical_score += 15
    scores["classical"] = min(classical_score, 100)
    
    # 找最高分
    max_genre = max(scores, key=scores.get)
    max_score = scores[max_genre]
    total_score = sum(scores.values())
    
    # 归一化概率
    probabilities = {k: v / total_score for k, v in scores.items()} if total_score > 0 else {}
    
    return max_genre, max_score / 100, probabilities
```

```python
def audio_to_recipe_pipeline(
    audio_path: str,
    preferred_genre: Optional[str] = None,
    intensity_mod: float = 1.0,
    custom_prefs: Optional[Dict] = None
) -> FullRecipe:
    """
    完整的音频到配方流水线
    
    Args:
        audio_path: 音频文件路径
        preferred_genre: 用户指定的流派（可选）
        intensity_mod: 强度修正
        custom_prefs: 自定义偏好
    
    Returns:
        FullRecipe: 完整配方
    """
    # 1. 加载音频
    audio = load_audio(audio_path)
    
    # 2. 提取MIR特征
    features = extract_mir_features(audio)
    
    # 3. 流派识别
    if preferred_genre:
        genre = preferred_genre
        confidence = 1.0
    else:
        genre, confidence, probs = classify_genre(features)
    
    # 4. 子流派分类
    sub_genre = classify_sub_genre(features, genre)
    
    # 5. 音乐结构分析
    sections = analyze_structure(audio, features, genre)
    
    # 6. 构建音乐原子

        beat_times=features.get("beat_times", []),
        instruments=features.get("instruments", []),
        spectral_centroid=features.get("spectral_centroid", 0)
    )
    
    # 7. 生成配方
    recipe = generate_genre_recipe(
        genre=genre,
        sub_genre=sub_genre,
        music_atom=music_atom,
        intensity_mod=intensity_mod,
        custom_prefs=custom_prefs
    )
    
    # 8. 附加元数据
    recipe.confidence = confidence
    recipe.feature_vector = features
    recipe.audio_path = audio_path
    
    return recipe

def analyze_structure(audio, features: Dict, genre: str) -> List[Dict]:
    """分析音乐结构段落"""

    section_templates = {
```

### 11.4 个人化微调策略

#### 11.4.1 微调维度
```
可微调的参数维度:

1. 色彩维度 (Color Tuning)
   - 整体色温偏移: ±30
   - 主色调偏移: 色相±30°
   - 饱和度修正: ±20%
   - 对比度修正: ±20%

2. 强度维度 (Intensity Tuning)
   - 全局效果强度: 0.5x - 2.0x
   - 各效果层独立强度
   - 峰值强度限制
   - 基线强度调整

3. 节奏维度 (Rhythm Tuning)
   - 节拍敏感度: 低/中/高
   - 反应延迟: 提前/延迟 (ms)
   - 缓动硬度: 软/中/硬
   - 切镜频率: 慢/中/快

4. 效果维度 (Effect Tuning)
   - 效果启用/禁用
   - 效果顺序调整
   - 混合模式调整
   - 插件替换

5. 转场维度 (Transition Tuning)
   - 转场风格偏好
   - 转场频率调整
   - 转场时长调整
   - 自定义转场添加
```

```python
def create_user_profile(
    liked_recipes: List[FullRecipe],
    disliked_recipes: List[FullRecipe]
) -> Dict:
    """
    基于用户喜好创建个人偏好配置
    
    Args:
        liked_recipes: 用户喜欢的配方列表
        disliked_recipes: 用户不喜欢的配方列表
    
    Returns:
        Dict: 用户偏好配置
    """
    profile = {
        "color_preferences": {},
        "intensity_preference": 1.0,
        "rhythm_preference": "medium",
        "effect_preferences": [],
        "transition_preferences": []
    }
    
    if not liked_recipes:
        return profile
    
    # 分析颜色偏好
    color_sums = {"r": 0, "g": 0, "b": 0}
    for recipe in liked_recipes:
        primary = recipe.color_palette.get("primary", "#000000")
        r, g, b = hex_to_rgb(primary)
        color_sums["r"] += r
        color_sums["g"] += g
        color_sums["b"] += b
    
    n = len(liked_recipes)
    avg_color = rgb_to_hex(
        color_sums["r"] // n,
        color_sums["g"] // n,
        color_sums["b"] // n
    )
    profile["color_preferences"]["avg_primary"] = avg_color
    
    # 分析强度偏好
    intensities = [max(r.intensity_profile) for r in liked_recipes if r.intensity_profile]
    if intensities:
        profile["intensity_preference"] = sum(intensities) / len(intensities)
    
    return profile


def hex_to_rgb(hex_color: str) -> Tuple[int, int, int]:
    hex_color = hex_color.lstrip('#')
    return tuple(int(hex_color[i:i+2], 16) for i in (0, 2, 4))


def rgb_to_hex(r: int, g: int, b: int) -> str:
    return f'#{r:02x}{g:02x}{b:02x}'
```

### 12.3 风格一致性评估方法

> [!tip] 风格一致性评估
> 风格一致性是衡量配方应用效果的核心指标。本节定义完整的评估体系，包含主观评估和客观评估两个维度。

#### 12.3.1 主观评估体系

**专家评估量表（7分制）：**

| 评估维度 | 1分(极差) | 4分(一般) | 7分(极佳) | 权重 |
|---------|----------|----------|----------|------|
| **色彩一致性** | 完全不符 | 基本符合 | 完美还原流派色调 | 20% |
| **节奏匹配度** | 完全脱节 | 大致同步 | 精确到帧的同步 | 25% |
| **效果恰当性** | 效果违和 | 效果合理 | 效果精准且有创意 | 20% |
| **转场流畅度** | 转场生硬 | 转场可接受 | 转场自然且加分 | 15% |
| **音效-视觉协同** | 各说各话 | 有一定关联 | 音画融为一体 | 20% |

**评估流程：**
```
1. 准备评估样本
   - 随机抽取10段应用配方的视频
   - 每段视频长度: 15-30秒
   - 涵盖不同流派和段落类型

2. 招募评估者
   - 专家评估组: 3-5名资深剪辑师
   - 用户评估组: 20-30名普通用户
   - 每组独立评分，取平均值

3. 评估步骤
   a. 观看完整视频 (不告知流派标签)
   b. 猜测流派 (验证风格辨识度)
   c. 按5个维度打分
   d. 填写开放性反馈

4. 结果计算
   - 综合得分 = Σ(维度得分 × 权重)
   - 流派识别准确率 = 猜对数量 / 总数
   - 组内一致性 = Cronbach's α系数
```

**主观评分基准线：**
```
专家评分基准:
  优秀: > 6.0分
  良好: 5.0-6.0分
  合格: 4.0-5.0分
  待改进: < 4.0分

用户评分基准:
  通常比专家评分低0.5-1.0分
  更注重视觉冲击力，较少关注细节

流派辨识度基准:
  Top-1识别率: > 70% (合格)
  Top-3识别率: > 90% (优秀)
```

#### 12.3.2 客观评估指标

**色彩一致性指标：**
```
指标1: 主色偏差 (Primary Color Deviation)
  公式: ΔE = sqrt((ΔL)² + (Δa)² + (Δb)²)  (CIE LAB色彩空间)
  合格: ΔE < 10
  优秀: ΔE < 5

指标2: 饱和度偏差 (Saturation Deviation)
  公式: |实际饱和度 - 目标饱和度|
  合格: ±15%以内
  优秀: ±10%以内

指标3: 色偏方向一致性
  方法: 计算整体色调方向与目标的夹角
  合格: < 30°
  优秀: < 15°
```

**节奏同步性指标：**
```
指标1: 节拍偏移量 (Beat Offset)
  公式: |视觉变化时间 - 音乐节拍时间| / 拍长 × 100%
  单位: 拍的百分比
  合格: < 10% 偏移
  优秀: < 5% 偏移

指标2: 重拍响应率 (Beat Response Rate)
  公式: 有视觉响应的重拍数 / 总重拍数
  合格: > 70%
  优秀: > 90%

指标3: 节奏相关性 (Rhythm Correlation)
  方法: 计算视觉强度曲线与音频能量曲线的互相关
  合格: 相关系数 > 0.5
  优秀: 相关系数 > 0.7
```

**效果强度一致性指标：**
```
指标1: 效果强度偏差
  公式: |实际效果强度 - 目标强度| / 目标强度 × 100%
  合格: ±20%以内
  优秀: ±10%以内

指标2: 相对强度关系
  方法: 验证各效果层的强度排序是否正确
  合格: 80%的排序正确
  优秀: 100%排序正确

指标3: 动态范围匹配
  公式: |实际动态范围 - 目标动态范围|
  合格: ±20%以内
  优秀: ±10%以内
```

#### 12.3.3 A/B测试评估方法

**A/B测试设计规范：**
```
测试类型: 配对比较 (Paired Comparison)
样本量: 每组至少20人
测试视频: 2个版本对比 (A vs B)
观看顺序: 随机化 (一半人先A后B，一半先B后A)
评价方式: 强制选择 + 量表评分
```

**A/B测试统计学要求：**
```
显著性水平: α = 0.05
统计检验: 配对t检验 / Wilcoxon符号秩检验
效应量: Cohen's d
  小效应: d = 0.2
  中效应: d = 0.5
  大效应: d = 0.8

样本量估算 (检测d=0.5的效应):
  α = 0.05, β = 0.8
  需要样本量: ~34人/组
```

**A/B测试报告模板：**
```
测试名称: [配方名称] A/B测试
测试日期: YYYY-MM-DD
测试目的: [验证X改进是否有效]

版本描述:
  A版本: [对照组描述]
  B版本: [实验组描述]

结果:
  主观评分:
    A版本平均: X.X ± X.X
    B版本平均: X.X ± X.X
    p值: X.XX
    结论: 显著/不显著
  
  偏好分布:
    偏好A: X% (X人)
    偏好B: X% (X人)
    无偏好: X% (X人)

结论与建议:
  [是否采纳B版本，具体改进点]
```

### 12.4 配方库的扩展与迭代策略

> [!abstract] 持续迭代体系
> 配方库不是一成不变的，需要建立持续扩展和迭代的机制。本节定义配方库的版本管理、扩展流程、质量控制和社区贡献机制。

#### 12.4.1 版本管理规范

**语义化版本号：**
```
版本格式: MAJOR.MINOR.PATCH
  MAJOR: 不兼容的API/结构变更
  MINOR: 新增流派/效果，向后兼容
  PATCH: 向后兼容的问题修正和参数微调

示例:
  v1.0.0 - 初始版本，10个主流派
  v1.1.0 - 新增2个子流派，新增3个效果
  v1.1.1 - 修正EDM配方的参数错误
  v2.0.0 - Schema结构重大升级，不兼容旧版
```

**版本发布周期：**
```
PATCH版本: 每周发布 (bug修复、参数微调)
MINOR版本: 每月发布 (新增流派、新效果)
MAJOR版本: 每6-12个月 (架构升级)

发布流程:
  1. 开发分支开发新功能
  2. 内部测试 (alpha)
  3. 公测版本 (beta)
  4. 正式发布 (release)
  5. 文档更新 + 变更日志
```

```
## [1.2.0] - 2026-07-01
```

## 附录A：实战配方案例 - 冰海战记战斗史诗混剪

> [!example] 案例信息
> - **项目名称**：Vinland Saga Battle Cinematic
> - **流派定位**：战斗史诗 / 燃向混剪（摇滚+古典交响混合）
> - **BPM**：约 120-140（战斗节奏）
> - **时长**：23.12 秒
> - **分辨率**：2160×3840（4K 竖屏 9:16）
> - **帧率**：60fps（Topaz 补帧 from 30fps）
> - **完成日期**：2026-07-19
> - **版本演进**：V8 → V11（AE 工程）→ V12（DaVinci 调色）→ V12_4K_60fps（Topaz 超分补帧）→ Final Cinematic（FFmpeg 精修）

### A.1 色彩基调层（Color Palette）

**青橙色调（Teal & Orange）战斗电影感**

| 参数 | 值 | 说明 |
|------|-----|------|
| 主色调 | 青蓝（暗部）+ 暖橙（高光） | 经典电影感双色 |
| 饱和度 | 0.85（降低15%） | 电影感去饱和 |
| 对比度 | 1.15（提升15%） | 强化中间调 |
| Gamma | 1.05（轻微提亮） | 暗部细节保留 |
| 曝光 | +0.02 | 微量提亮 |

**FFmpeg colorbalance 参数**：
```
colorbalance=rs=-0.08:gs=-0.03:bs=0.12:rm=0.05:gm=-0.02:bm=-0.05:rh=0.08:gh=0.02:bh=-0.08
```
- 暗部（shadows）：偏青蓝（bs=+0.12）
- 中间调（midtones）：轻微暖偏移
- 高光（highlights）：偏暖橙（rh=+0.08, bh=-0.08）

**DaVinci 一级调色预设**（来自 `vinland_saga_v12_davinci.py`）：
```python
"Lift": [0.92, 0.94, 0.97, 1.0],    # 暗部偏青
"Gamma": [1.08, 1.03, 0.95, 1.0],   # 中间调偏暖
"Gain": [1.05, 1.0, 0.92, 1.0],     # 高光偏暖橙
"Contrast": 1.15,
"Saturation": 0.85,
```

### A.2 效果栈层（Effect Stack）

**三层调色体系**（V14_safe 脚本设计）：

| 层级 | 效果 | matchName | 参数 |
|------|------|-----------|------|
| 1 | Kodak 2383 LUT | ADBE Lumetri | LUT 路径 + 强度 40% |
| 2 | 青橙色调 | ADBE Color Balance | Shadow Blue +20, Highlight Red +15 |
| 3 | 段落级色调 | ADBE Hue & Saturation | 按段落动态调整 |

**FFmpeg 等效效果栈**（Final Cinematic 版本）：
```
curves=r='0/0 0.5/0.55 1/1':g='0/0 0.5/0.5 1/1':b='0/0 0.5/0.45 1/1'
```
- 红通道 S 曲线：提升中间调红色（肤色/暖色）
- 蓝通道反向 S 曲线：压低中间调蓝色（去冷）

**风格化效果**：
| 效果 | 参数 | 说明 |
|------|------|------|
| 暗角 | vignette=PI/4.5 | 聚焦中心，增强史诗感 |
| 电影颗粒 | noise=alls=8:allf=t+u | 8% 时域+空间域噪点 |
| 锐化 | unsharp=5:5:0.8:3:3:0.4 | 轻微锐化，补偿超分软化 |

### A.3 关键帧节奏层（Keyframe Rhythm）

**5大镜头语言**（V14_safe 脚本设计）：

| 镜头语言 | 名称 | 特征 | 适用段落 |
|---------|------|------|---------|
| Molob | 动量冲击 | 缩放+位移随节拍冲击 | Drop |
| Floby | 流动飘移 | 慢速平移+模糊 | Build |
| Xenoz | 零度定格 | 节拍点瞬停 | Break |
| DxshNova | 爆裂新星 | 缩放爆炸+闪白 | Drop 冲击 |
| 基础 | 节拍同步 | 简单缩放跟随 | Intro/Outro |

**2.5D 视差增强**：
- 前景层缩放 1.05-1.10
- 背景层缩放 0.95-0.98
- 摄像机 Z 轴微移跟随节拍

### A.4 转场策略层（Transition Strategy）

| 转场类型 | 触发点 | 时长 | 参数 |
|---------|--------|------|------|
| 匹配剪辑（Match Cut） | 段落切换 | 0 帧 | 动作连续性匹配 |
| 闪白 | Drop 冲击 | 2 帧 | 100% → 0% 不透明度 |
| 动态模糊 | 镜头间 | 4 帧 | 方向跟随运动 |

**音效标记系统**（V14_safe 脚本设计）：
- 节拍标记 → 自动对齐剪辑点

### A.7 关键经验教训

1. **AE 版本兼容性**：AE 2026 (v26.x) 的 V8 引擎不兼容 ExtendScript，会导致 MCP Bridge 崩溃。**必须使用 AE 2025 (v25.x)**。
2. **Lumetri 高级属性崩溃**：AE 2025 的 Lumetri 高级属性（LUT 强度、阴影色调等）可能导致渲染崩溃，使用 Color Balance + Hue/Saturation 替代。
3. **aerender -s 不是 script**：aerender 的 `-s` 参数是 start_frame，不是 script。执行脚本用 `AfterFX.exe -r script.jsx`。
4. **MCP Bridge 作用域问题**：listener 脚本用 `{ ... }` 块作用域包裹时，`app.scheduleTask("func()")` 的 eval 在全局作用域找不到块内函数。**所有函数必须注册到全局作用域**。
5. **Topaz 超分补帧顺序**：先调色再超分，避免超分后调色引入伪影。
6. **FFmpeg 滤镜转义**：`curves` 滤镜含空格和冒号，在 PowerShell 中直接传递会被错误解析。用 Python subprocess 或写入文件避免 shell 转义。

### A.8 可复用 FFmpeg 调色命令

```bash
# 电影感精修一键命令（替换 INPUT 和 OUTPUT）
ffmpeg -i INPUT.mp4 \
  -vf "colorbalance=rs=-0.08:gs=-0.03:bs=0.12:rm=0.05:gm=-0.02:bm=-0.05:rh=0.08:gh=0.02:bh=-0.08,eq=contrast=1.15:saturation=0.85:brightness=0.02:gamma=1.05,curves=r='0/0 0.5/0.55 1/1':g='0/0 0.5/0.5 1/1':b='0/0 0.5/0.45 1/1',unsharp=5:5:0.8:3:3:0.4,vignette=PI/4.5,noise=alls=8:allf=t+u" \
  -c:v libx264 -preset slow -crf 18 \
  -pix_fmt yuv420p -movflags +faststart \
  -c:a copy \
  OUTPUT.mp4
```

**参数调整指南**：
- 想要更暖：增加 `rh`（高光红）、减少 `bh`（高光蓝）
- 想要更冷：增加 `bs`（暗部蓝）、减少 `rm`（中间调红）
- 想要更强暗角：`vignette=PI/3.5`（角度越小暗角越强）
- 想要更多颗粒：`noise=alls=12`（值越大颗粒越粗）
- 想要更高画质：`-crf 16`（更小=更高质，文件更大）
