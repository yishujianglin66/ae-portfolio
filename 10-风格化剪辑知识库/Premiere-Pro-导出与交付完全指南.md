# Premiere Pro 导出与交付完全指南

> 版本: 2025-v1 | 适用: 多平台交付/编码规范/批量导出

## 一、导出设置

### 1.1 导出面板

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 导出媒体 | Ctrl+M | 打开导出面板 |
| 队列到AME | 队列按钮 | 发送到Media Encoder |
| 匹配源 | 匹配源按钮 | 匹配素材参数 |

### 1.2 常用导出预设

| 平台 | 格式 | 编码 | 分辨率 | 码率 |
|------|------|------|--------|------|
| YouTube | H.264 | Main | 1080p/4K | 10-50Mbps |
| B站 | H.264 | High | 1080p | 6-10Mbps |
| 抖音/TikTok | H.264 | High | 1080x1920 | 8-15Mbps |
| 微信 | H.264 | Baseline | 720p | 2-4Mbps |
| Instagram | H.264 | High | 1080x1080 | 5-8Mbps |
| 广播 | ProRes/DNxHR | - | 1080p | 无损 |
| 存档 | HAP/ProRes | - | 原始 | 高质量 |

### 1.3 H.264 参数详解

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| Profile | High | 质量/兼容性平衡 |
| Level | 4.2(1080p)/5.2(4K) | 分辨率上限 |
| Bitrate Encoding | VBR 1pass | 效率/质量平衡 |
| Target Bitrate | 10-20Mbps(1080p) | 质量关键参数 |
| Max Bitrate | 1.5x Target | VBR峰值 |
| Keyframe Distance | 2x帧率(如48) | GOP大小 |

## 二、平台交付规范

### 2.1 YouTube

| 参数 | 推荐值 |
|------|--------|
| 分辨率 | 1920x1080 或 3840x2160 |
| 帧率 | 与源素材一致 |
| 编码 | H.264 High Profile |
| 码率 | 1080p: 8Mbps, 4K: 35-45Mbps |
| 音频 | AAC 320kbps, 48kHz |
| 容器 | MP4 |
| HDR | HDR10(如需要) |

### 2.2 抖音/短视频

| 参数 | 推荐值 |
|------|--------|
| 分辨率 | 1080x1920(竖屏) |
| 帧率 | 30fps |
| 编码 | H.264 High |
| 码率 | 8-15Mbps |
| 音频 | AAC 192kbps |
| 时长 | 15s-10min |
| 安全区 | 上下各留10%(UI遮挡) |

### 2.3 广播交付

| 参数 | 标准 |
|------|------|
| 编码 | ProRes 422HQ / DNxHR HQ |
| 分辨率 | 1920x1080 |
| 帧率 | 25fps(PAL)/24fps(电影) |
| 音频 | PCM 48kHz/24bit |
| 响度 | -24 LUFS(中国广播) |
| 安全区 | 动作安全区90%/字幕安全区80% |

## 三、批量导出

### 3.1 序列标记导出

```
1. 在时间线上设置标记点(M键)
2. 标记 → 设置导出范围标记
3. 导出 → 勾选"使用标记"
4. 自动按标记点分段导出
```

### 3.2 队列批量导出

```
1. Ctrl+M 打开导出
2. 设置参数 → 点击"队列"
3. 添加到Media Encoder队列
4. 在AME中批量渲染
5. 或使用PR内置批量导出
```

## 四、音频导出

### 4.1 音频编码

| 格式 | 码率 | 用途 |
|------|------|------|
| AAC | 128-320kbps | 网络视频 |
| PCM | 16/24bit | 广播/存档 |
| MP3 | 192-320kbps | 播客 |
| WAV | 未压缩 | 专业编辑 |

### 4.2 多轨音频导出

```
方法1: 导出为多轨WAV(每轨独立)
方法2: 混合导出(所有轨道合并)
方法3: 导出XML → 在Audition中打开
```
