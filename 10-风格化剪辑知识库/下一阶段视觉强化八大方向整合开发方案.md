## 2. 各方向技术路线

### D1 镜头级光效融合（mask / track matte 跟随主体）

**路线 A（主体框遮罩，首选）**：
1. 从 `shot_scenes_raw.json` 取每镜头主体框（肤色代理 box）；缺失镜头回退画面中心偏上 1/3。
2. 在 Glow/粒子层上加椭圆 Mask：`layer.Masks.addProperty("ADBE Mask Parade")` → `ADBE Mask Shape`（椭圆路径，中心=主体中心，半径=主体框×1.6）→ `ADBE Mask Feather` = 120–200（柔边）。
3. 主体移动镜头：每镜头取 2–4 个采样点关键帧 `ADBE Mask Shape.setValueAtTime` 插值跟随。

**路线 B（亮度 track matte，高光跟随）**：
1. 预合成视频 → Levels 提取高光（input black 提至 180+）→ 作为 luma matte 层。
2. 光晕层设 track matte。AE 2025 新 API `layer.setTrackMatte(matteLayer, type)` 与旧 `trackMatteType` 并存，**实机探针确认后固化其一**。
3. 效果：光晕只出现在画面高光区（人物受光面/爆炸火光），天然跟随主体。

**验证**：渲染后对光晕层单独输出（solo），计算亮度质心，与主体框中心距离 < 框对角线 0.5 倍为 PASS。

### D2 粒子拖尾强化

1. **Streaklet 粒子类型**：Particular 粒子类型属性（已实证索引 `tc Particular-0703`，Sprite=6）；Streaklet 枚举值**实机探针固化**（遍历 menu 值渲染 1 帧对比）。Streaklet 自带速度方向拉伸=物理拖尾。
2. **Echo 拖尾（保底路线）**：粒子层加 `ADBE Echo`：Echo Time 0.03–0.05 / Echoes 3–4 / Decay 0.6 / Operator=Add → 离散残影拖尾，参数全内置无插件风险。
3. **CC Force Motion Blur**（已实证 `CC Force Motion Blur-0001` amount / `-0003` angle）：amount 16–28，angle 取 `shot_motion.json` 光流角，仅快切镜头启用。
4. 图层运动模糊双开关：`comp.motionBlur=true` + `layer.motionBlur=true`（V4 已实证）。

**验证**：爆发后第 2–3 帧抽帧，粒子应呈条状/残影而非圆点；渲染体积较基线 +20% 以上。

### D3 动态模糊 + 摄像机微震

1. 快切判定：`speed>=1.5` 或光流 mag ≥ p70 → 该镜头层 `motionBlur=true`。
2. 摄像机微震：master comp 加摄像机（仅影响 3D 层——**需将受震层 threeDLayer=true**，铁律继承）；强 onset 处 position 关键帧 ±4–6px、2–3 帧衰减（复用包络语法）；或 `wiggle(8,5)` 表达式限定 amplitude 包络。
3. 与 D2 的 FMB 互斥调度：同镜头只选其一（FMB 优先于摄像机震，避免双重糊）。

**验证**：切点帧 vs 切点+2 帧差分图应见方向性涂抹；静止段差分近零（防常时抖动）。

### D4 节拍脉冲联动（onset 全量加密）

1. onset 源从 23 强切点扩展到 `true_onsets.json` 全量（强度 s 过滤 s≥0.5）。
2. burst 粒子 pps 尖峰：每个 onset `setValueAtTime(t-0.03, 0) / (t, 150+250*s) / (t+0.35, 0)`；size 同步 `4+4*s`。
3. **beat-pulse**：Glow intensity 与文字/主体层 scale 在 onset 处脉冲：scale `100→100+3*s→100`（3 帧）、Glow intensity `base→base+0.4*s→base`。
4. 密度护栏：相邻 pulse 间隔 <0.18s 时合并（防连爆，继承 plan_bursts 的 gap 逻辑）。

**验证**：脉冲峰值帧与 onset 偏差 ≤2 帧（ffprobe 逐帧亮度曲线峰值对齐检测）。

### D5 色彩统一（shot-match）

1. 逐镜头统计：ffmpeg 按 segments 窗口抽 raw rgb24 缩 160×90，算每镜头 R/G/B 均值与亮度中位。
2. 全局目标：全片加权中位（或参照集实测语法：高对比+高饱和+冷阴影，继承 v23 结论）。
3. 逐镜头校正：`ADBE Color Balance`（build_master_polish 已实证 property 1=R / 3=B，0 中心 ±100）+ `ADBE Brightness & Contrast 2`（0001/0002）把每镜头拉向目标；校正量限幅（|Δ|≤12）防风格抹平。
4. **不用 Lumetri/调整层做逐镜头 grade**（调整层黑叠加陷阱，见 §4）；校正直挂镜头层。
5. 可选：全片统一 LUT 通道 `{tag}_lut.mp4` 已存在，作为二级全局匹配。

**验证**：校正前后镜头间 R-B 色差方差与亮度方差下降 ≥50%；抽 4 帧目视无风格断裂。

### D6 画质提升

1. 母版路线：aerender 输出模块改 ProRes 422 HQ（模板名含空格需引号包裹，实证约束）→ ffmpeg `libx264 -b:v 30M -maxrate 36M -bufsize 72M -crf 17` + aac 192k。
2. 直出路线（快）：现有 H.264 模板比特率 15M→30M（输出模块设置或 ffmpeg 重编码）。
3. 超分（可选）：Real-ESRGAN 实机检查（GPU/模型在位性），仅对 1080p 母版做 1.5× 再回缩锐化，避免 4K 渲染时间爆炸。
4. 帧数铁律继承：ffmpeg 规范化硬裁 `-frames:v round(dur*fps)`，ffprobe `-count_frames` 复核。

**验证**：ffprobe bit_rate ≥28M；720 帧数精确；暗部块效应目视消失。

### D7 转场冲击（白闪 / RGB split / 速度线）

1. 白闪：顶层白色 Solid，in=切点、长 2–3 帧，opacity `80→0` 线性衰减；与 `kept_events.json` 保留闪帧 ±0.35s 互斥（继承）。
2. RGB split：切点处 2 帧——复制镜头层×2，分别 Tint 纯红/纯蓝，Add 混合，position 各偏移 ±(4–8)px 水平反向；第 3 帧恢复。
3. 速度线：强 drop 切点复用 `burst_radial`（CC Radial Fast Blur 90 包络）+ 可选径向形状层条纹（Shape layer 放射线，Add，1 帧峰值）。
4. 调度：drop 区白闪+RGB split 二选一，build 区仅速度线（继承分区语法）。

**验证**：切点抽帧见闪/split 痕迹且 ≤3 帧；非切点段零残留。

### D8 暗角 + 边缘 anamorphic flare

1. Vignette：顶层 Solid（黑）+ 椭圆 Mask（Inverted=false、Feather 250–350、覆盖中心 70% 区域反向遮罩）→ 混合 Multiply 或 Normal opacity 18–25%；角/心亮度比目标 0.8–0.9。
2. Anamorphic flare：高光镜头（亮度 p80+）加横向 streak：Glow 副本层 scale=[130, 6]（压扁成水平条）+ Add、opacity 10–15%，仅高光帧包络内出现。
3. 与 D1 主体遮罩共用主体框数据（vignette 中心=主体中心偏移，非死中心）。

**验证**：四角平均亮度 / 中心亮度 ∈ [0.78, 0.92]；主体区亮度损失 <5%。

## 4. 实证约束与陷阱清单（本会话新增 + 继承）

| # | 陷阱 | 实证 | 规避 |
|---|------|------|------|
| T1 | **调整层黑叠加压暗**：adjustmentLayer Solid 在本环境渲染为黑实体叠加，亮度比=1-opacity（65% → 0.35x 全片压暗） | 本会话隔离渲染实验 | 调色直挂视频/镜头层；用调整层必先做 luma 比例探针 |
| T2 | **Easy Levels2 索引陷阱**：`0006` 非 output black（误设 8 → 全帧吹白 246.8） | 本会话 v5 渲染事故 | Levels 属性序实机探针固化；提亮优先 Brightness&Contrast 2（0001/0002 已实证） |

| T5 | aerender `-s/-e` 为**帧号**非秒 | 本会话 4 帧事故 | 秒×fps 换算 |
| T6 | 源/渲染 luma 比例是黑屏/压暗/吹白的最快判据 | 本会话诊断法 | 合理区间 0.9–1.25；越界先隔离实验 |
| T7 | 继承：BlendMode 数值（SCREEN=5282/ADD=5220/NORMAL=5212）、tc Particular 扁平 matchName、ES3 语法、渲染 >100KB | 历史会话 | 沿用 |

## 5. 验证规范（统一门）

1. **体积门**：每段渲染 >100KB。
2. **亮度门**：渲染/源 luma 比 ∈ [0.9, 1.25]（逐 6 采样点）。
3. **节拍门**：pulse/impact 峰值帧 vs onset ≤2 帧。
4. **遮挡门**：文字/光晕 bbox 与主体框 IoU < 0.35；vignette 主体区损失 <5%。
5. **目视门**：每方向首验抽 3 帧（暗/中/亮镜头各一）用户确认后才进下一方向（逐步视觉验证规范继承）。
6. **分阶段渲染**：先 CRF 23-26 预览验证节奏/动效，确认后 30M 高质量。

## 7. 文字动画专线（P0–P4 + 后续方向）

> 目标：文字不是静态叠加，而是锚定镜头节拍/情绪/运镜的动态元素。解锁差距 G1–G5（文字评估结论）。

### 7.1 P0 文字-剪辑集成调度器（解锁 G1，最高优先）

- 新建 `scripts/build_text_overlay.py`：消费 `production_report.json` segments + `tmp/true_onsets.json` + `tmp/music_envelope.json`
- 文字事件模型：`{t_in=onset, t_hold=镜头时长, t_out=下一切点-2帧, mood, energy, style_id}`
- 语义规则：mood/energy → 字体/颜色/位置（intro/outro=衬线居中低饱和；build=无衬线侧置；drop=impact 字体居中+描边；closeup 镜头避让主体框置上下安全带）
- 注入：复用 build_master_polish 的 JSX 通道（Bridge 文件协议）与 ENV_DECAY/TAIL 包络语法；文字层 = AE Text Layer + Text Animator（属性名实证见 §7.5 引用手册）
- 离线验证：`--dry-run` 只出事件表 + JSX 不碰 AE（继承 build_master_polish 契约）

### 7.2 P1 复合语法配方库（解锁 G2/G3）

8 套参数化 JSX 配方，每套带强度包络 + 字体-情绪映射：

1. 描边+投影层次（fill=0 + stroke 2-3 + 黑投影黑线）
2. 扫光逐字揭示（逐字 opacity 0→100→0 跟随扫光位置）
3. 纹理叠层（叠层纹理/水波纹防"干"）
4. 双层发光（主 Glow + 边缘低强度泛光）
5. RGB 分离抖动（切点 2 帧 ±offset Add，与 D7 共用语法）
6. liquid 扭曲（Turbulent Displace / 波纹关键帧）
7. 金属浮雕（Bevel Alpha + DropShadow + Tracking 字距）
8. 粒子化爆炸（Particular Layer Grid 发射器=文字预合成，知识报告 §3.2 已实证）

- 字体-情绪映射表：从 `字体知识库.md` / `字体预设库.md` 抽取（impact→drop 冲击 / 衬线→intro/outro / 手写→水墨 / 无衬线→build 叙事）

### 7.3 P2 MG 运动库（解锁 G4）

- easing 函数库：easeOutBack（已实证 s=1.70158）/ elastic / expo / quint + 逐字 stagger 错帧曲线
- 预备-跟随模板：入场前 scale 0.9 预备 2 帧 → 过冲 1.06 → settle 1.0（12 原则参数化）
- 图形化转场配方：mask wipe（矩形/圆形遮罩已实证）/ slide / zoom-through（摄像机推镜穿文字面）

### 7.4 P3 文字-运镜-主体联动（解锁 G5）

- 文字 3D 层 Z 视差跟随摄像机推镜（复用 V4 `_cameraPush`/`_cameraOrbit`；铁律：摄像机只影响 3D 层）
- 入场方向 = 光流角（`shot_motion.json` h/ang）：文字沿画面运动方向或其反向滑入
- 安全区避让：`shot_scenes_raw.json` 肤色代理框 → 文字 bbox IoU < 0.35，违例移上下安全带或缩字号

### 7.5 P4 验证闭环

- 逐配方单段 aerender 渲染 >100KB + 关键帧截图
- 节拍对齐：文字入场帧 vs onset 偏差 ≤2 帧
- 遮挡：文字 bbox vs 主体框 IoU 阈值（同 §5 遮挡门）
- 分阶段渲染：先 CRF 23-26 预览确认，再高质量
- 文字可读性门：暗/中/亮三镜头抽帧，描边/对比保证可读

### 7.6 后续实现方向（P4 之后）

1. 节拍脉冲联动：文字 scale/glow 随 kick 呼吸（复用 D4 pulse 语法）
2. 拖尾：Echo / CC Wide Time 文字层
3. 文字动态模糊：motionBlur + 快速位移（V4 `_motionBlur` 已实证）

### 8.2 关键路径论证

- 文字线依赖链 P0→P1→P2/P3→P4：**P0 是唯一咽喉**，延后它=整条文字线等比延后。
- P1 配方脱离 P0 只能跑 Showcase，重蹈"文字与剪辑两张皮"（G1）错误；P0 的事件 schema 是 P1-P3 的契约，先定契约=后续零返工。
- D4/D7/D2 属粒子线并行分支，与 P0 无依赖冲突 → 可配菜不可主线。

### 8.3 风险论证

- P0 新增代码 = 纯 Python 调度 + 已实证 JSX 文字层模板（MangaEdit_TextFX 448 行模板、音画同步训练 15 层合成两重先例）；Bridge 通道与 aerender 验证链成熟。
- 最大不确定项（字体在位性）已有储备：字体清单与 Bridge 字体配置实证过，dry-run 阶段定义 fallback 字体栈即可闭环。
- 反证：若先推 P1，将直面未实证语法（扫光逐字关键帧/纹理叠层参数）且无注入载体，风险高、价值锁死。

### 8.4 结论与波次计划

**最先推进：文字 P0 文字-剪辑集成调度器。**

- 主线交付：`build_text_overlay.py` + run53 文字事件表 + 首次注入渲染（P0 自带 P1 配方 1/4 作为默认样式——描边+双层发光，形成最小闭环）。
- 并行配菜（容量允许时）：D7 转场冲击、D4 节拍脉冲（均为半日级 quick win，独立层无 schema 冲突）。
- 门禁：P0 过五门 + 文字可读性门后，启动 P1 全 8 配方。
