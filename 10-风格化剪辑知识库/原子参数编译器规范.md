# 原子参数编译器规范

> [!abstract] 文档摘要
> 本规范定义了原子参数编译器（APC）的完整架构——从YAML/JSON原子参数到ExtendScript可执行代码的编译管线。包含11种IR节点类型、14个代码生成模板、12个JSON Schema，以及与知识库所有文档的对接规范。编译器是"知识→执行"的核心桥梁，将逆向分析结果转化为AE可自动执行的操作序列。

> [!tip] 使用指南
> - 编译器开发者：从第一章架构总览开始，按顺序阅读至第七章伪代码实现
> - 知识库对接：第八章定义了与所有知识库文档的接口规范
> - 快速上手：第二章的输入规范 + 第五章的代码模板 = 最小可运行编译器
> - 测试验证：第九章的测试套件使用《视频案例解析库》的25个案例作为测试数据

> [!important] 核心定位
> 编译器是整个知识库体系从"认知"走向"行动"的关键一环。没有编译器，知识库只能输出YAML参数表；有了编译器，知识库可以直接驱动AE执行操作。

## 第一章 编译器架构总览

### 1.1 编译器定位

原子参数编译器（Atomic Parameter Compiler，简称 APC）是 AE-Knowledge-Vault 知识库体系中的核心执行组件。它的职责是将知识库从视频中逆向分析出的原子级参数描述（YAML/JSON格式）编译为 Adobe After Effects 可执行的 ExtendScript 代码或通过 MCP（Model Context Protocol）协议直接调用的命令序列。

整个知识库的数据流可概括为：

```
视频素材 → 逆向分析 → 原子参数(YAML/JSON) → [APC编译器] → ExtendScript / MCP命令 → AE执行
```

APC 编译器处于"分析结果"与"可执行代码"之间的关键桥梁位置，确保知识库的推理输出能够精确、高效、安全地转化为 AE 可执行的操作。

### 1.2 编译器三阶段模型

APC 编译器采用经典的三阶段编译模型：

| 阶段 | 输入 | 输出 | 职责 |
|------|------|------|------|
| 前端（Frontend） | 原子参数 YAML/JSON | 操作序列 AST（IR） | 解析、验证、构建中间表示 |
| 中端（Middle-end） | 操作序列 AST | 优化后的 AST | 依赖排序、冗余消除、批量合并 |
| 后端（Backend） | 优化后的 AST | ExtendScript .jsx / MCP 调用 | 代码生成、模板匹配、格式输出 |

### 1.4 编译流程详解

完整的编译流程分为以下步骤：

1. **输入加载**：读取 YAML/JSON 格式的原子参数文件，进行格式检测和预处理
2. **解析（Parser）**：将原始参数数据解析为结构化的操作列表，每个操作包含操作类型和参数字典
3. **验证（Validator）**：对照《参数-效果原子级映射库》中的规则，验证 matchName 有效性、参数范围、引用完整性和时间合法性
4. **IR 构建（IR Builder）**：将验证通过的操作列表构建为带依赖关系的 AST 节点图
5. **排序（Scheduler）**：对 IR 节点进行拓扑排序，确保执行顺序正确（合成→图层→效果→属性→关键帧→表达式）
6. **优化（Optimizer）**：合并批量操作、消除冗余节点、压缩代码大小
7. **代码生成（Code Generator）**：将优化后的 IR 节点逐个匹配代码模板，生成 ExtendScript 代码
8. **输出**：根据输出模式生成最终的 .jsx 文件或 MCP 命令序列

### 1.5 与 after-effects-mcp-main 的对接方式

APC 编译器支持通过 after-effects-mcp-main 项目提供的 MCP 接口直接与 AE 通信：

**MCP 对接架构：**

```
APC 编译器 ──→ MCP 命令序列 ──→ after-effects-mcp-main ──→ AE ExtendScript 引擎
```

**对接协议：**

- **通信方式**：通过 MCP 协议的 `run-script` 工具执行 ExtendScript 代码片段
- **会话管理**：每个编译任务创建独立的 MCP 会话，确保操作隔离
- **错误反馈**：AE 执行错误通过 MCP 协议回传至编译器，支持重试和降级
- **状态同步**：编译器可通过 MCP 的 `get-active-comp`、`get-layer-info` 等工具获取 AE 当前状态

**MCP 命令封装格式：**

```typescript
interface MCPCommand {
  tool: "run-script";
  arguments: {
    script: string;  // ExtendScript 代码片段
  };
}
```

**批量执行模式：**

```typescript
interface MCPBatch {
  commands: MCPCommand[];
  stopOnError: boolean;  // 遇错是否停止
  rollbackOnError: boolean;  // 出错是否回滚
}
```

### 2.2 元数据字段详解

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `source` | string | 是 | 来源标识，用于溯源到具体的分析过程和原始视频 |
| `confidence` | number | 否 | 整体分析置信度，低于0.5时编译器应发出警告 |
| `timestamp` | string | 是 | ISO 8601 格式时间戳，标记分析结果生成时间 |
| `analyzer` | string | 否 | 分析器版本标识，用于兼容性判断 |
| `version` | string | 否 | 原子参数格式版本，用于向后兼容 |

### 3.3 依赖图与执行顺序

#### 3.3.1 依赖关系规则

IR 节点之间的依赖关系由以下规则确定：

| 操作类型 | 必须在之后执行 | 依赖说明 |
|----------|---------------|----------|
| CreateComp | 无 | 顶层节点，无依赖 |
| AddLayer | CreateComp | 图层必须添加到已存在的合成中 |
| AddEffect | AddLayer | 效果必须添加到已存在的图层上 |
| SetProperty | AddLayer（或AddEffect） | 属性属于图层或效果 |
| SetKeyframe | AddLayer（或AddEffect） | 关键帧设置在属性上 |
| SetExpression | AddLayer（或AddEffect） | 表达式设置在属性上 |
| AddMask | AddLayer | 遮罩添加在图层上 |
| SetBlendMode | AddLayer | 混合模式属于图层属性 |
| SetParent | AddLayer（两个） | 父子关系需要两个图层 |
| SetTrackMatte | AddLayer（两个） | 轨道遮罩需要目标层和遮罩层 |

#### 3.3.2 依赖图示例

```
CreateComp(op_main_comp)
    ├── AddLayer(op_bg_solid) ──── AddEffect(op_bg_gradient)
    │                         └─── AddMask(op_vignette_mask)
    ├── AddLayer(op_product_layer) ──── AddEffect(op_glow_effect)
    │                            └─── SetBlendMode(op_blend_screen)
    ├── AddLayer(op_text_title)
    │     └── SetExpression(op_text_wiggle)
    ├── AddLayer(op_particle_layer) ──── AddEffect(op_particular)
    ├── SetParent(op_parent_product) ──── 依赖 op_text_title + op_product_layer
    ├── SetKeyframe(op_product_fadein)
    └── SetKeyframe(op_product_visible)
```

#### 3.3.3 引用解析机制

编译器维护一个引用解析表（Reference Resolution Table），将逻辑引用ID映射到运行时变量名：

```typescript
interface ReferenceTable {
  /** compId → 运行时变量名 */
  compRefs: Map<string, string>;
  /** layerId → 运行时变量名 */
  layerRefs: Map<string, string>;
  /** effectId → 运行时变量名（自动生成的效果操作ID） */
  effectRefs: Map<string, string>;

  /** 解析引用，返回运行时变量名表达式 */
  resolve(refId: string): string;

  /** 注册新的引用映射 */
  register(refId: string, varName: string, type: "comp" | "layer" | "effect"): void;
}
```

引用解析在代码生成阶段执行，确保每个 ID 被替换为正确的 ExtendScript 变量引用。例如：
- `op_main_comp` → `comp_mainComp`
- `op_bg_solid` → `layer_bgSolid`
- `op_bg_gradient` → `fx_bgGradient`

## 第四章 编译器核心算法

### 4.1 解析器（Parser）

解析器负责将原始的 JSON/YAML 输入转换为 IR 节点列表。它执行以下步骤：

1. 格式检测与加载（JSON直接解析，YAML通过yaml库解析）
2. 元数据提取与版本兼容性检查
3. 操作列表遍历与IR节点构建
4. 依赖关系提取

```typescript
class Parser {
  private readonly supportedVersions = ["1.0.0"];

  /**
   * 解析原子参数输入为IR节点列表
   */
  parse(input: string): ParseResult {
    // 1. 格式检测与加载
    const raw = this.loadInput(input);

    // 2. 版本兼容性检查
    if (raw.metadata.version && !this.supportedVersions.includes(raw.metadata.version)) {
      return {
        success: false,
        errors: [`Unsupported version: ${raw.metadata.version}`],
        nodes: []
      };
    }

    // 3. 遍历操作列表，构建IR节点
    const nodes: IRNode[] = [];
    const errors: ParseError[] = [];

    for (let i = 0; i < raw.operations.length; i++) {
      const op = raw.operations[i];
      try {
        const node = this.buildIRNode(op, i);
        if (node) {
          nodes.push(node);
        }
      } catch (e) {
        errors.push({
          operationIndex: i,
          operationId: op.id || `unknown_${i}`,
          message: `Failed to parse operation: ${(e as Error).message}`
        });
      }
    }

    return {
      success: errors.length === 0,
      errors,
      nodes,
      metadata: raw.metadata
    };
  }

  /**
   * 构建单个IR节点
   */
  private buildIRNode(op: RawOperation, index: number): IRNode {
    const base = {
      id: op.id || `op_${index}`,
      dependencies: op.dependsOn || [],
      meta: {
        source: op.comment,
        confidence: undefined,
        comment: op.comment
      }
    };

    switch (op.type) {
      case "createComp":
        return {
          ...base,
          nodeType: "CreateComp",
          name: op.params.name,
          width: op.params.width,
          height: op.params.height,
          fps: op.params.fps,
          duration: op.params.duration,
          pixelAspect: op.params.pixelAspect || 1,
          bgColor: op.params.bgColor || [0, 0, 0, 0]
        } as CreateCompNode;

      case "addLayer":
        return {
          ...base,
          nodeType: "AddLayer",
          compRef: op.params.compRef,
          layerType: op.params.layerType,
          layerName: op.params.layerName,
          properties: op.params.properties || {},
          index: op.params.index
        } as AddLayerNode;

      case "addEffect":
        return {
          ...base,
          nodeType: "AddEffect",
          layerRef: op.params.layerRef,
          effectMatchName: op.params.effectMatchName,
          effectName: op.params.effectName,
          settings: op.params.settings || []
        } as AddEffectNode;

      case "setProperty":
        return {
          ...base,
          nodeType: "SetProperty",
          layerRef: op.params.layerRef,
          propertyPath: op.params.propertyPath,
          value: op.params.value,
          valueType: op.params.valueType
        } as SetPropertyNode;

      case "setKeyframe":
        return {
          ...base,
          nodeType: "SetKeyframe",
          layerRef: op.params.layerRef,
          propertyPath: op.params.propertyPath,
          time: op.params.time,
          value: op.params.value,
          easingIn: op.params.easingIn,
          easingOut: op.params.easingOut,
          spatialBezier: op.params.spatialBezier,
          roving: op.params.roving || false
        } as SetKeyframeNode;

      case "setExpression":
        return {
          ...base,
          nodeType: "SetExpression",
          layerRef: op.params.layerRef,
          propertyPath: op.params.propertyPath,
          expression: op.params.expression
        } as SetExpressionNode;

      case "addMask":
        return {
          ...base,
          nodeType: "AddMask",
          layerRef: op.params.layerRef,
          maskName: op.params.maskName,
          maskShape: op.params.maskShape,
          maskMode: op.params.maskMode || "add",
          maskFeather: op.params.maskFeather || [0, 0],
          maskOpacity: op.params.maskOpacity ?? 100,
          maskExpansion: op.params.maskExpansion ?? 0,
          inverted: op.params.inverted ?? false
        } as AddMaskNode;

      case "setBlendMode":
        return {
          ...base,
          nodeType: "SetBlendMode",
          layerRef: op.params.layerRef,
          blendMode: op.params.blendMode
        } as SetBlendModeNode;

      case "setParent":
        return {
          ...base,
          nodeType: "SetParent",
          layerRef: op.params.layerRef,
          parentRef: op.params.parentRef
        } as SetParentNode;

      case "setTrackMatte":
        return {
          ...base,
          nodeType: "SetTrackMatte",
          layerRef: op.params.layerRef,
          matteRef: op.params.matteRef,
          matteType: op.params.matteType
        } as SetTrackMatteNode;

      default:
        throw new Error(`Unknown operation type: ${op.type}`);
    }
  }

  private loadInput(input: string): AtomicParameterInput {
    const trimmed = input.trim();
    if (trimmed.startsWith("{") || trimmed.startsWith("[")) {
      return JSON.parse(trimmed);
    }
    // YAML格式：使用yaml库解析
    return this.parseYAML(trimmed);
  }

  private parseYAML(input: string): AtomicParameterInput {
    // 使用js-yaml库解析，此处为伪代码
    const YAML = require("js-yaml");
    return YAML.load(input) as AtomicParameterInput;
  }
}
```

### 4.2 验证器（Validator）

验证器对解析后的 IR 节点进行多维度校验，确保输入数据的正确性和安全性。

```typescript
class Validator {
  private matchNameRegistry: MatchNameRegistry;
  private paramRangeRegistry: ParamRangeRegistry;

  constructor(
    matchNameRegistry: MatchNameRegistry,
    paramRangeRegistry: ParamRangeRegistry
  ) {
    this.matchNameRegistry = matchNameRegistry;
    this.paramRangeRegistry = paramRangeRegistry;
  }

  /**
   * 验证IR节点列表
   */
  validate(nodes: IRNode[]): ValidationResult {
    const errors: ValidationError[] = [];
    const warnings: ValidationWarning[] = [];

    // 构建节点索引
    const nodeMap = new Map<string, IRNode>();
    for (const node of nodes) {
      nodeMap.set(node.id, node);
    }

    for (const node of nodes) {
      // 1. matchName有效性检查（仅对AddEffectNode）
      if (node.nodeType === "AddEffect") {
        const effectNode = node as AddEffectNode;
        if (!this.matchNameRegistry.isValid(effectNode.effectMatchName)) {
          errors.push({
            nodeId: node.id,
            rule: "INVALID_MATCH_NAME",
            message: `Unknown matchName: ${effectNode.effectMatchName}`
          });
        }
      }

      // 2. 参数范围检查
      const rangeErrors = this.checkParamRanges(node);
      errors.push(...rangeErrors);

      // 3. 引用完整性检查
      const refErrors = this.checkReferences(node, nodeMap);
      errors.push(...refErrors);

      // 4. 时间合法性检查
      const timeErrors = this.checkTimeValidity(node, nodeMap);
      errors.push(...timeErrors);

      // 5. 置信度警告
      if (node.meta.confidence && node.meta.confidence < 0.5) {
        warnings.push({
          nodeId: node.id,
          message: `Low confidence: ${node.meta.confidence}`
        });
      }
    }

    return {
      valid: errors.length === 0,
      errors,
      warnings
    };
  }

  /**
   * 参数范围检查
   */
  private checkParamRanges(node: IRNode): ValidationError[] {
    const errors: ValidationError[] = [];

    switch (node.nodeType) {
      case "CreateComp": {
        const comp = node as CreateCompNode;
        if (comp.width < 1 || comp.width > 30000) {
          errors.push({
            nodeId: node.id,
            rule: "PARAM_OUT_OF_RANGE",
            message: `Comp width ${comp.width} out of range [1, 30000]`
          });
        }
        if (comp.height < 1 || comp.height > 30000) {
          errors.push({
            nodeId: node.id,
            rule: "PARAM_OUT_OF_RANGE",
            message: `Comp height ${comp.height} out of range [1, 30000]`
          });
        }
        if (comp.fps < 1 || comp.fps > 240) {
          errors.push({
            nodeId: node.id,
            rule: "PARAM_OUT_OF_RANGE",
            message: `FPS ${comp.fps} out of range [1, 240]`
          });
        }
        break;
      }
      case "AddEffect": {
        const effect = node as AddEffectNode;
        for (const setting of effect.settings) {
          const range = this.paramRangeRegistry.getRange(
            effect.effectMatchName,
            setting.propertyPath
          );
          if (range && typeof setting.value === "number") {
            if (setting.value < range.min || setting.value > range.max) {
              errors.push({
                nodeId: node.id,
                rule: "PARAM_OUT_OF_RANGE",
                message: `Effect param ${setting.propertyPath} value ${setting.value} out of range [${range.min}, ${range.max}]`
              });
            }
          }
        }
        break;
      }
      case "SetKeyframe": {
        const kf = node as SetKeyframeNode;
        if (kf.time < 0) {
          errors.push({
            nodeId: node.id,
            rule: "INVALID_TIME",
            message: `Keyframe time ${kf.time} cannot be negative`
          });
        }
        break;
      }
    }

    return errors;
  }

  /**
   * 引用完整性检查
   */
  private checkReferences(node: IRNode, nodeMap: Map<string, IRNode>): ValidationError[] {
    const errors: ValidationError[] = [];

    // 检查显式依赖
    for (const depId of node.dependencies) {
      if (!nodeMap.has(depId)) {
        errors.push({
          nodeId: node.id,
          rule: "UNRESOLVED_REFERENCE",
          message: `Dependency ${depId} not found`
        });
      }
    }

    // 检查类型特定引用
    switch (node.nodeType) {
      case "AddLayer": {
        const layer = node as AddLayerNode;
        if (!nodeMap.has(layer.compRef)) {
          errors.push({
            nodeId: node.id,
            rule: "UNRESOLVED_REFERENCE",
            message: `Comp reference ${layer.compRef} not found`
          });
        } else {
          const compNode = nodeMap.get(layer.compRef)!;
          if (compNode.nodeType !== "CreateComp") {
            errors.push({
              nodeId: node.id,
              rule: "INVALID_REFERENCE_TYPE",
              message: `Comp reference ${layer.compRef} is not a CreateComp node`
            });
          }
        }
        break;
      }
      case "AddEffect": {
        const effect = node as AddEffectNode;
        if (!nodeMap.has(effect.layerRef)) {
          errors.push({
            nodeId: node.id,
            rule: "UNRESOLVED_REFERENCE",
            message: `Layer reference ${effect.layerRef} not found`
          });
        }
        break;
      }
      case "SetParent": {
        const parent = node as SetParentNode;
        if (!nodeMap.has(parent.layerRef) || !nodeMap.has(parent.parentRef)) {
          errors.push({
            nodeId: node.id,
            rule: "UNRESOLVED_REFERENCE",
            message: `SetParent references not found`
          });
        }
        break;
      }
    }

    return errors;
  }

  /**
   * 时间合法性检查
   */
  private checkTimeValidity(node: IRNode, nodeMap: Map<string, IRNode>): ValidationError[] {
    const errors: ValidationError[] = [];

    if (node.nodeType === "SetKeyframe") {
      const kf = node as SetKeyframeNode;
      // 查找所属合成的时长
      const layerNode = nodeMap.get(kf.layerRef) as AddLayerNode | undefined;
      if (layerNode) {
        const compNode = nodeMap.get(layerNode.compRef) as CreateCompNode | undefined;
        if (compNode && kf.time > compNode.duration) {
          errors.push({
            nodeId: node.id,
            rule: "TIME_EXCEEDS_DURATION",
            message: `Keyframe time ${kf.time} exceeds comp duration ${compNode.duration}`
          });
        }
      }
    }

    return errors;
  }
}
```

### 4.3 排序器（Scheduler）

排序器对 IR 节点执行拓扑排序，确保操作按正确的依赖顺序执行。

```typescript
class Scheduler {
  /**
   * 对IR节点进行拓扑排序
   */
  schedule(nodes: IRNode[]): IRNode[] {
    // 构建邻接表
    const nodeMap = new Map<string, IRNode>();
    const inDegree = new Map<string, number>();
    const adjacency = new Map<string, string[]>();

    for (const node of nodes) {
      nodeMap.set(node.id, node);
      inDegree.set(node.id, 0);
      adjacency.set(node.id, []);
    }

    for (const node of nodes) {
      for (const depId of node.dependencies) {
        if (adjacency.has(depId)) {
          adjacency.get(depId)!.push(node.id);
          inDegree.set(node.id, (inDegree.get(node.id) || 0) + 1);
        }
      }
    }

    // 补充隐式依赖（从引用关系推导）
    for (const node of nodes) {
      const implicitDeps = this.getImplicitDependencies(node, nodeMap);
      for (const depId of implicitDeps) {
        if (adjacency.has(depId) && !node.dependencies.includes(depId)) {
          adjacency.get(depId)!.push(node.id);
          inDegree.set(node.id, (inDegree.get(node.id) || 0) + 1);
        }
      }
    }

    // Kahn算法拓扑排序
    const queue: string[] = [];
    for (const [id, degree] of inDegree) {
      if (degree === 0) {
        queue.push(id);
      }
    }

    // 按操作优先级排序队列（同层级时的执行优先级）
    const priorityOrder: IRNodeType[] = [
      "CreateComp", "AddLayer", "AddEffect", "SetProperty",
      "SetKeyframe", "SetExpression", "AddMask", "SetBlendMode",
      "SetParent", "SetTrackMatte"
    ];

    queue.sort((a, b) => {
      const nodeA = nodeMap.get(a)!;
      const nodeB = nodeMap.get(b)!;
      return priorityOrder.indexOf(nodeA.nodeType) - priorityOrder.indexOf(nodeB.nodeType);
    });

    const sorted: IRNode[] = [];
    while (queue.length > 0) {
      const currentId = queue.shift()!;
      sorted.push(nodeMap.get(currentId)!);

      const neighbors = adjacency.get(currentId) || [];
      for (const neighborId of neighbors) {
        const newDegree = (inDegree.get(neighborId) || 1) - 1;
        inDegree.set(neighborId, newDegree);
        if (newDegree === 0) {
          // 插入排序保持优先级
          let inserted = false;
          for (let i = 0; i < queue.length; i++) {
            const queuedNode = nodeMap.get(queue[i])!;
            const neighborNode = nodeMap.get(neighborId)!;
            if (priorityOrder.indexOf(neighborNode.nodeType) < priorityOrder.indexOf(queuedNode.nodeType)) {
              queue.splice(i, 0, neighborId);
              inserted = true;
              break;
            }
          }
          if (!inserted) {
            queue.push(neighborId);
          }
        }
      }
    }

    // 检测循环依赖
    if (sorted.length !== nodes.length) {
      const missingIds = nodes.map(n => n.id).filter(id => !sorted.find(s => s.id === id));
      throw new Error(`Circular dependency detected involving nodes: ${missingIds.join(", ")}`);
    }

    return sorted;
  }

  /**
   * 获取隐式依赖（从引用字段推导）
   */
  private getImplicitDependencies(node: IRNode, nodeMap: Map<string, IRNode>): string[] {
    const deps: string[] = [];

    switch (node.nodeType) {
      case "AddLayer":
        deps.push((node as AddLayerNode).compRef);
        break;
      case "AddEffect":
        deps.push((node as AddEffectNode).layerRef);
        break;
      case "SetProperty":
        deps.push((node as SetPropertyNode).layerRef);
        break;
      case "SetKeyframe":
        deps.push((node as SetKeyframeNode).layerRef);
        break;
      case "SetExpression":
        deps.push((node as SetExpressionNode).layerRef);
        break;
      case "AddMask":
        deps.push((node as AddMaskNode).layerRef);
        break;
      case "SetBlendMode":
        deps.push((node as SetBlendModeNode).layerRef);
        break;
      case "SetParent":
        deps.push((node as SetParentNode).layerRef);
        deps.push((node as SetParentNode).parentRef);
        break;
      case "SetTrackMatte":
        deps.push((node as SetTrackMatteNode).layerRef);
        deps.push((node as SetTrackMatteNode).matteRef);
        break;
    }

    return deps.filter(id => id && nodeMap.has(id));
  }
}
```

### 4.4 优化器（Optimizer）

优化器对排序后的 IR 节点列表进行变换，减少生成代码的体积和执行时间。

```typescript
class Optimizer {
  /**
   * 优化IR节点列表
   */
  optimize(nodes: IRNode[]): IRNode[] {
    let optimized = [...nodes];

    // Pass 1: 批量操作合并
    optimized = this.mergeBatchOperations(optimized);

    // Pass 2: 冗余操作消除
    optimized = this.eliminateRedundancy(optimized);

    // Pass 3: 代码大小压缩
    optimized = this.compressCodeSize(optimized);

    return optimized;
  }

  /**
   * Pass 1: 合并同一图层的多个setProperty为批量操作
   */
  private mergeBatchOperations(nodes: IRNode[]): IRNode[] {
    const result: IRNode[] = [];
    const propertyGroups = new Map<string, SetPropertyNode[]>();

    // 按layerRef分组setProperty节点
    for (const node of nodes) {
      if (node.nodeType === "SetProperty") {
        const prop = node as SetPropertyNode;
        const key = `${prop.layerRef}`;
        if (!propertyGroups.has(key)) {
          propertyGroups.set(key, []);
        }
        propertyGroups.get(key)!.push(prop);
      }
    }

    // 合并每组为BatchSetPropertyNode
    const mergedIds = new Set<string>();
    for (const [_, props] of propertyGroups) {
      if (props.length > 1) {
        mergedIds.add(props[0].id);
        const batchNode: BatchSetPropertyNode = {
          id: `batch_${props[0].layerRef}`,
          nodeType: "BatchSetProperty",
          layerRef: props[0].layerRef,
          properties: props.map(p => ({
            propertyPath: p.propertyPath,
            value: p.value,
            valueType: p.valueType
          })),
          dependencies: props[0].dependencies,
          meta: { comment: `Batch merged from ${props.length} SetProperty operations` }
        };
        result.push(batchNode);
        // 其余节点标记为已合并
        for (let i = 1; i < props.length; i++) {
          mergedIds.add(props[i].id);
        }
      }
    }

    // 添加非setProperty节点
    for (const node of nodes) {
      if (!mergedIds.has(node.id)) {
        result.push(node);
      }
    }

    return result;
  }

  /**
   * Pass 2: 消除冗余操作
   * - 同一属性的重复设置只保留最后一个
   * - 值为默认值的设置操作可删除
   */
  private eliminateRedundancy(nodes: IRNode[]): IRNode[] {
    const result: IRNode[] = [];
    const lastPropertySet = new Map<string, number>(); // key → index in result

    // 从后向前扫描，标记冗余节点
    const redundant = new Set<string>();

    for (let i = nodes.length - 1; i >= 0; i--) {
      const node = nodes[i];
      if (node.nodeType === "SetProperty") {
        const prop = node as SetPropertyNode;
        const key = `${prop.layerRef}::${prop.propertyPath}`;
        if (lastPropertySet.has(key)) {
          redundant.add(node.id); // 之前的设置被后面的覆盖
        }
        lastPropertySet.set(key, i);
      }
    }

    for (const node of nodes) {
      if (!redundant.has(node.id)) {
        result.push(node);
      }
    }

    return result;
  }

  /**
   * Pass 3: 代码大小压缩
   * - 合并连续的addLayer操作到同一合成
   * - 将内联值提取为常量
   */
  private compressCodeSize(nodes: IRNode[]): IRNode[] {
    // 提取重复使用的常量值
    const valueFrequency = new Map<string, number>();
    for (const node of nodes) {
      this.collectValues(node, valueFrequency);
    }

    // 频率超过3的值提取为常量
    const constants = new Map<string, string>();
    let constIndex = 0;
    for (const [value, freq] of valueFrequency) {
      if (freq >= 3) {
        const constName = `CONST_${constIndex++}`;
        constants.set(value, constName);
      }
    }

    // 标记节点中的常量引用
    for (const node of nodes) {
      this.replaceWithConstants(node, constants);
    }

    return nodes;
  }
```

```typescript
class CodeGenerator {
  private refTable: ReferenceTable;
  private templateEngine: TemplateEngine;
  private indentLevel: number = 0;

  constructor() {
    this.refTable = new ReferenceTable();
    this.templateEngine = new TemplateEngine();
  }

  /**
   * 生成ExtendScript代码
   */
  generate(nodes: IRNode[], mode: OutputMode = "single-script"): CodeGenResult {
    switch (mode) {
      case "single-script":
        return this.generateSingleScript(nodes);
      case "mcp-commands":
        return this.generateMCPCommands(nodes);
      case "batch":
        return this.generateBatchCommands(nodes);
    }
  }

  /**
   * 单脚本模式生成
   */
  private generateSingleScript(nodes: IRNode[]): CodeGenResult {
    const lines: string[] = [];
    const varDeclarations: string[] = [];

    // 文件头部
    lines.push("// ============================================================");
    lines.push("// Generated by Atomic Parameter Compiler (APC)");
    lines.push(`// Date: ${new Date().toISOString()}`);
    lines.push("// ============================================================");
    lines.push("");
    lines.push("app.beginUndoGroup(\"APC Generated Script\");");
    lines.push("");

    for (const node of nodes) {
      const code = this.generateNodeCode(node);
      if (code) {
        lines.push(`// --- ${node.nodeType}: ${node.id} ---`);
        lines.push(...code);
        lines.push("");
      }
    }

    lines.push("app.endUndoGroup();");
    lines.push("");
    lines.push("// Script execution complete");

    const script = lines.join("\n");

    return {
      success: true,
      output: script,
      mode: "single-script",
      stats: {
        totalNodes: nodes.length,
        linesOfCode: lines.length
      }
    };
  }
```

## 第六章 编译器输出格式

### 6.1 单脚本模式（Single Script Mode）

将所有操作编译为一个完整的 .jsx 文件，一次性在 AE 中执行。

**输出结构：**

```javascript
// ============================================================
// Generated by Atomic Parameter Compiler (APC)
// Source: reverse-analysis://commercial-30s-brand-x-2026
// Date: 2026-07-05T10:30:00+08:00
// Nodes: 14 | Lines: 156
// ============================================================

app.beginUndoGroup("APC: BrandX_30s_Main");

// --- CreateComp: op_main_comp ---
var comp_mainComposition = app.project.items.addComp(
  "Main_Composition", 1920, 1080, 1, 30, 29.97
);
comp_mainComposition.bgColor = [0.05, 0.02, 0.12, 1];

// --- AddLayer: op_bg_solid ---
var layer_bgGradient = comp_mainComposition.layers.addSolid(
  [0.05, 0.02, 0.12], "BG_Gradient", 1920, 1080, 1
);

// ... (更多操作)

app.endUndoGroup();
```

**优点：**
- 执行速度最快，单次脚本调用完成所有操作
- 支持 `beginUndoGroup/endUndoGroup` 整体撤销
- 便于离线编辑和调试
- 可嵌入版本控制和代码审查流程

**缺点：**
- 无法实时监控中间状态
- 单点失败导致整个脚本中断
- 难以实现条件分支执行
- 不适合长时间操作（可能触发AE脚本超时）

### 6.2 MCP命令模式（MCP Command Mode）

每个操作编译为独立的 MCP `run-script` 调用，逐条发送执行。

**输出结构：**

```json
[
  {
    "tool": "run-script",
    "arguments": {
      "script": "var comp_mainComposition = app.project.items.addComp(\"Main_Composition\", 1920, 1080, 1, 30, 29.97); comp_mainComposition.bgColor = [0.05, 0.02, 0.12, 1];"
    }
  },
  {
    "tool": "run-script",
    "arguments": {
      "script": "var layer_bgGradient = comp_mainComposition.layers.addSolid([0.05, 0.02, 0.12], \"BG_Gradient\", 1920, 1080, 1);"
    }
  }
]
```

**优点：**
- 可实时监控每步执行结果
- 单步失败不影响后续操作（可跳过）
- 支持条件执行（根据上一步结果决定下一步）
- 便于与 MCP 生态集成

**缺点：**
- 执行速度较慢（每步一次AE通信）
- 不支持整体撤销
- 脚本间变量共享需要特殊处理
- 网络延迟影响执行效率

### 6.3 批处理模式（Batch Mode）

操作序列编译为命令队列，按分组批量执行。

**输出结构：**

**缺点：**
- 配置较复杂
- 跨阶段变量共享需要持久化
- 分组策略需要精心设计

```typescript
class AtomicParameterCompiler {
  private parser: Parser;
  private validator: Validator;
  private scheduler: Scheduler;
  private optimizer: Optimizer;
  private codeGenerator: CodeGenerator;
  private config: CompilerConfig;

  constructor(config: CompilerConfig) {
    this.config = config;
    this.parser = new Parser();
    this.validator = new Validator(
      new MatchNameRegistry(),
      new ParamRangeRegistry()
    );
    this.scheduler = new Scheduler();
    this.optimizer = new Optimizer();
    this.codeGenerator = new CodeGenerator(config.codeStyle);
  }

  /**
   * 编译入口
   */
  compile(input: string): CompileResult {
    const startTime = Date.now();

    // 1. 解析
    const parseResult = this.parser.parse(input);
    if (!parseResult.success) {
      return {
        success: false,
        output: "",
        mode: this.config.outputMode,
        stats: { totalNodes: 0, optimizedNodes: 0, linesOfCode: 0, compileTimeMs: 0 },
        errors: parseResult.errors.map(e => ({
          nodeId: e.operationId,
          phase: "parse",
          message: e.message
        })),
        warnings: []
      };
    }

    // 2. 验证
    if (this.config.enableValidation) {
      const validationResult = this.validator.validate(parseResult.nodes);
      if (!validationResult.valid) {
        return {
          success: false,
          output: "",
          mode: this.config.outputMode,
          stats: { totalNodes: parseResult.nodes.length, optimizedNodes: 0, linesOfCode: 0, compileTimeMs: Date.now() - startTime },
          errors: validationResult.errors.map(e => ({
            nodeId: e.nodeId,
            phase: "validation",
            message: `[${e.rule}] ${e.message}`
          })),
          warnings: validationResult.warnings.map(w => ({
            nodeId: w.nodeId,
            message: w.message
          }))
        };
      }
    }

    // 3. 排序
    let sortedNodes: IRNode[];
    try {
      sortedNodes = this.scheduler.schedule(parseResult.nodes);
    } catch (e) {
      return {
        success: false,
        output: "",
        mode: this.config.outputMode,
        stats: { totalNodes: parseResult.nodes.length, optimizedNodes: 0, linesOfCode: 0, compileTimeMs: Date.now() - startTime },
        errors: [{
          nodeId: "scheduler",
          phase: "schedule",
          message: (e as Error).message
        }],
        warnings: []
      };
    }

    // 4. 优化
    let optimizedNodes = sortedNodes;
    if (this.config.enableOptimization) {
      optimizedNodes = this.optimizer.optimize(sortedNodes);
    }

    // 5. 代码生成
    const codeGenResult = this.codeGenerator.generate(
      optimizedNodes,
      this.config.outputMode
    );

    return {
      success: codeGenResult.success,
      output: codeGenResult.output,
      mode: this.config.outputMode,
      stats: {
        totalNodes: parseResult.nodes.length,
        optimizedNodes: optimizedNodes.length,
        linesOfCode: codeGenResult.stats.linesOfCode,
        compileTimeMs: Date.now() - startTime
      },
      errors: [],
      warnings: []
    };
  }
}
```

```typescript
class MCPIntegration {
  private mcpClient: MCPClient;
  private session: MCPSession | null = null;

  constructor(config: { endpoint: string; sessionTimeout: number }) {
    this.mcpClient = new MCPClient(config.endpoint);
  }

  /**
   * 初始化MCP会话
   */
  async initialize(): Promise<void> {
    this.session = await this.mcpClient.createSession();
  }

  /**
   * 执行编译结果
   */
  async execute(result: CompileResult): Promise<ExecutionResult> {
    if (!this.session) {
      throw new Error("MCP session not initialized");
    }

    switch (result.mode) {
      case "single-script":
        return this.executeSingleScript(result.output);
      case "mcp-commands":
        return this.executeMCPCommands(result.output);
      case "batch":
        return this.executeBatch(result.output);
    }
  }

  /**
   * 执行单脚本
   */
  private async executeSingleScript(script: string): Promise<ExecutionResult> {
    try {
      const response = await this.session.callTool("run-script", {
        script
      });
      return {
        success: true,
        response: response.content
      };
    } catch (error) {
      return {
        success: false,
        response: null,
        error: (error as Error).message
      };
    }
  }

  /**
   * 执行MCP命令序列
   */
  private async executeMCPCommands(commandsJson: string): Promise<ExecutionResult> {
    const commands = JSON.parse(commandsJson) as MCPCommand[];
    const results: StepResult[] = [];
    let allSuccess = true;

    for (let i = 0; i < commands.length; i++) {
      const cmd = commands[i];
      try {
        const response = await this.session!.callTool(cmd.tool, cmd.arguments);
        results.push({
          step: i,
          success: true,
          response: response.content
        });
      } catch (error) {
        results.push({
          step: i,
          success: false,
          error: (error as Error).message
        });
        allSuccess = false;
        break; // 遇错停止
      }
    }

    return {
      success: allSuccess,
      response: results,
      error: allSuccess ? undefined : `Failed at step ${results.length - 1}`
    };
  }

  /**
   * 执行批处理
   */
  private async executeBatch(batchJson: string): Promise<ExecutionResult> {
    const batch = JSON.parse(batchJson) as BatchExecution;
    const phaseResults: PhaseResult[] = [];
    let allSuccess = true;

    for (const phase of batch.batch) {
      try {
        for (const cmd of phase.commands) {
          await this.session!.callTool(cmd.tool, cmd.arguments);
        }
        phaseResults.push({
          phaseId: phase.id,
          success: true
        });
      } catch (error) {
        phaseResults.push({
          phaseId: phase.id,
          success: false,
          error: (error as Error).message
        });

        // 执行回滚
        if (batch.options.rollbackOnError && phase.rollback) {
          try {
            await this.session!.callTool("run-script", {
              script: phase.rollback
            });
          } catch (rollbackError) {
            // 回滚失败，记录但不中断
          }
        }

        if (batch.options.stopOnError) {
          allSuccess = false;
          break;
        }
      }
    }

    return {
      success: allSuccess,
      response: phaseResults,
      error: allSuccess ? undefined : `Failed at phase ${phaseResults.length - 1}`
    };
  }

  /**
   * 获取AE当前状态
   */
  async getAEState(): Promise<AEState> {
    const activeComp = await this.session!.callTool("get-active-comp", {});
    return {
      activeComp: activeComp.content
    };
  }

  /**
   * 关闭会话
   */
  async close(): Promise<void> {
    if (this.session) {
      await this.session.close();
      this.session = null;
    }
  }
```

**转换规则：**

| YAML结构 | 编译器JSON结构 | 说明 |
|----------|---------------|------|
| `analysis` | `metadata` | 直接映射，字段名可能不同 |
| `composition` | `createComp`操作 | 拆分为独立操作 |
| `layers[].effects[]` | `addEffect`操作 | 从内嵌结构提取为独立操作 |
| `transform.opacity.keyframes[]` | `setKeyframe`操作 | 从内嵌结构提取 |
| `blend_mode` | `setBlendMode`操作 | 从图层属性提取 |
| 颜色值`#RRGGBB` | `[R, G, B, A]`数组 | 十六进制转归一化RGBA |
| `easing: "ease_out"` | `easingOut: {type: "bezier"}` | 语义缓动名转贝塞尔参数 |

**转换器实现：**

```typescript
class YAMLToInputConverter {
  convert(yaml: YAMLAnalysis): AtomicParameterInput {
    const operations: Operation[] = [];

    // 1. 从composition生成createComp操作
    const compId = "op_main_comp";
    operations.push({
      id: compId,
      type: "createComp",
      params: {
        name: yaml.composition.name,
        width: yaml.composition.resolution[0],
        height: yaml.composition.resolution[1],
        fps: yaml.composition.fps,
        duration: yaml.composition.duration,
        bgColor: this.hexToRGBA(yaml.composition.background)
      }
    });

    // 2. 从layers生成addLayer + 关联操作
    for (const layer of yaml.layers) {
      const layerId = `op_${layer.id}`;
      const layerOp = this.buildLayerOperation(layer, compId, layerId);
      operations.push(layerOp);

      // 2a. 效果操作
      if (layer.effects) {
        for (let i = 0; i < layer.effects.length; i++) {
          const effect = layer.effects[i];
          operations.push(this.buildEffectOperation(effect, layerId, `${layerId}_fx${i}`));
        }
      }

      // 2b. 关键帧操作
      if (layer.transform) {
        this.extractKeyframeOperations(layer.transform, layerId, operations);
      }

      // 2c. 混合模式
      if (layer.blend_mode) {
        operations.push({
          id: `${layerId}_blend`,
          type: "setBlendMode",
          dependsOn: [layerId],
          params: {
            layerRef: layerId,
            blendMode: layer.blend_mode.toUpperCase()
          }
        });
      }
    }

    return {
      metadata: {
        source: yaml.analysis.source,
        confidence: yaml.analysis.confidence,
        timestamp: yaml.analysis.timestamp,
        version: "1.0.0"
      },
      operations
    };
  }

  private hexToRGBA(hex: string): [number, number, number, number] {
    const r = parseInt(hex.slice(1, 3), 16) / 255;
    const g = parseInt(hex.slice(3, 5), 16) / 255;
    const b = parseInt(hex.slice(5, 7), 16) / 255;
    return [r, g, b, 1];
  }

  private buildLayerOperation(layer: YAMLLayer, compId: string, layerId: string): Operation {
    const params: any = {
      compRef: compId,
      layerType: layer.type,
      layerName: layer.name
    };

    if (layer.color) params.color = this.hexToRGBA(layer.color);
    if (layer.source) params.footagePath = layer.source;
    if (layer.transform?.position) params.position = layer.transform.position;
    if (layer.transform?.scale) params.scale = layer.transform.scale;

    return {
      id: layerId,
      type: "addLayer",
      dependsOn: [compId],
      params
    };
  }

  private buildEffectOperation(effect: YAMLEffect, layerId: string, effectId: string): Operation {
    const settings = Object.entries(effect.settings || {}).map(([key, value]) => {
      // 将snake_case的YAML键名转换为AE的属性名
      const propertyPath = this.snakeToPropertyName(key);
      return { propertyPath, value };
    });

    return {
      id: effectId,
      type: "addEffect",
      dependsOn: [layerId],
      params: {
        layerRef: layerId,
        effectMatchName: effect.matchName,
        settings
      }
    };
  }

  private extractKeyframeOperations(transform: any, layerId: string, operations: Operation[]): void {
    for (const [propName, propValue] of Object.entries(transform)) {
      if (propValue && typeof propValue === "object" && Array.isArray(propValue.keyframes)) {
        for (const kf of propValue.keyframes) {
          operations.push({
            id: `${layerId}_kf_${propName}_${kf.time}`,
            type: "setKeyframe",
            dependsOn: [layerId],
            params: {
              layerRef: layerId,
              propertyPath: `Transform.${this.snakeToPropertyName(propName)}`,
              time: kf.time,
              value: kf.value,
              easingOut: kf.easing ? this.parseEasing(kf.easing) : undefined
            }
          });
        }
      }
    }
  }

  private parseEasing(easing: string): EasingDescriptor | undefined {
    const easingMap: Record<string, EasingDescriptor> = {
      "linear": { type: "linear" },
      "ease_in": { type: "bezier", bezierIn: [0.42, 0], influence: 65 },
      "ease_out": { type: "bezier", bezierOut: [0.58, 1], influence: 65 },
      "ease_in_out": { type: "bezier", bezierIn: [0.42, 0], bezierOut: [0.58, 1], influence: 65 },
      "hold": { type: "hold" }
    };
    return easingMap[easing];
  }

  private snakeToPropertyName(snake: string): string {
    return snake
      .split("_")
      .map((word, i) => i === 0 ? word.charAt(0).toUpperCase() + word.slice(1) : word.charAt(0).toUpperCase() + word.slice(1))
      .join(" ");
  }
}
```

### 8.2 从《参数-效果原子级映射库》到 Validator 规则

《参数-效果原子级映射库》定义了每个效果的参数范围、matchName 和属性路径映射。编译器的 Validator 通过 ParamRangeRegistry 消费这些定义：

**映射库中的定义格式：**

```yaml
effect:
  matchName: "ADBE Gaussian Blur 2"
  displayName: "Gaussian Blur"
  category: "builtin"
  properties:
    - path: "Blurriness"
      type: "float"
      range: [0, 1000]
      default: 10
    - path: "Repeat Edge Pixels"
      type: "menu"
      items: ["Off", "On"]
      default: 0
```

**转换规则：**

1. `matchName` → MatchNameRegistry 的有效性检查
2. `properties[].path` + `range` → ParamRangeRegistry 的参数范围检查
3. `properties[].type` → 值类型验证
4. `properties[].items` → 枚举值验证

编译器启动时自动加载映射库的最新版本，将其注入到 Validator 中：

```typescript
function loadValidatorFromMappingLib(): Validator {
  const matchNameReg = new MatchNameRegistry();
  const paramRangeReg = new ParamRangeRegistry();

  // 从映射库YAML文件加载
  const mappingFiles = glob.sync("参数-效果原子级映射库/*.yaml");
  for (const file of mappingFiles) {
    const mapping = YAML.load(fs.readFileSync(file, "utf-8"));
    for (const effect of mapping.effects || []) {
      matchNameReg.registerCustom(effect.matchName, effect.category);
      const params: Record<string, ParamRange> = {};
      for (const prop of effect.properties || []) {
        params[prop.path] = {
          min: prop.range ? prop.range[0] : -Infinity,
          max: prop.range ? prop.range[1] : Infinity,
          default: prop.default ?? 0,
          type: prop.type,
          menuItems: prop.items
        };
      }
      paramRangeReg.registerCustomEffect(effect.matchName, params);
    }
  }

  return new Validator(matchNameReg, paramRangeReg);
}
```

### 10.4 插件系统架构

编译器采用分层插件架构，支持在解析、验证、优化、代码生成四个阶段插入自定义逻辑。

```typescript
/**
 * 编译器插件接口
 */
interface CompilerPlugin {
  /** 插件名称 */
  name: string;
  /** 插件版本 */
  version: string;

  /** 初始化钩子 */
  onInit?(compiler: AtomicParameterCompiler): void;

  /** 解析阶段钩子 - 在Parser之后执行 */
  postParse?(nodes: IRNode[]): IRNode[];

  /** 验证阶段钩子 - 在Validator之后执行 */
  postValidate?(nodes: IRNode[], errors: ValidationError[]): {
    nodes: IRNode[];
    errors: ValidationError[];
  };

  /** 优化阶段钩子 - 在Optimizer之后执行 */
  postOptimize?(nodes: IRNode[]): IRNode[];

  /** 代码生成阶段钩子 - 在CodeGenerator之后执行 */
  postGenerate?(output: string): string;
}

/**
 * 插件管理器
 */
class PluginManager {
  private plugins: CompilerPlugin[] = [];

  register(plugin: CompilerPlugin): void {
    this.plugins.push(plugin);
  }

  unregister(name: string): void {
    this.plugins = this.plugins.filter(p => p.name !== name);
  }

  async onInit(compiler: AtomicParameterCompiler): Promise<void> {
    for (const plugin of this.plugins) {
      if (plugin.onInit) {
        plugin.onInit(compiler);
      }
    }
  }

  postParse(nodes: IRNode[]): IRNode[] {
    let result = nodes;
    for (const plugin of this.plugins) {
      if (plugin.postParse) {
        result = plugin.postParse(result);
      }
    }
    return result;
  }

  postValidate(nodes: IRNode[], errors: ValidationError[]): { nodes: IRNode[]; errors: ValidationError[] } {
    let result = { nodes, errors };
    for (const plugin of this.plugins) {
      if (plugin.postValidate) {
        result = plugin.postValidate(result.nodes, result.errors);
      }
    }
    return result;
  }

  postOptimize(nodes: IRNode[]): IRNode[] {
    let result = nodes;
    for (const plugin of this.plugins) {
      if (plugin.postOptimize) {
        result = plugin.postOptimize(result);
      }
    }
    return result;
  }

  postGenerate(output: string): string {
    let result = output;
    for (const plugin of this.plugins) {
      if (plugin.postGenerate) {
        result = plugin.postGenerate(result);
      }
    }
    return result;
  }
}

/**
 * 插件示例：日志记录插件
 */
const loggingPlugin: CompilerPlugin = {
  name: "apc-logger",
  version: "1.0.0",

  onInit(compiler) {
    console.log(`[APC Logger] Compiler initialized`);
  },

  postParse(nodes) {
    console.log(`[APC Logger] Parsed ${nodes.length} nodes`);
    return nodes;
  },

  postValidate(nodes, errors) {
    console.log(`[APC Logger] Validation: ${errors.length} errors found`);
    return { nodes, errors };
  },

  postOptimize(nodes) {
    console.log(`[APC Logger] Optimized to ${nodes.length} nodes`);
    return nodes;
  },

  postGenerate(output) {
    console.log(`[APC Logger] Generated ${output.split("\n").length} lines of code`);
    return output;
  }
};

/**
 * 插件示例：安全检查插件
 */
const securityPlugin: CompilerPlugin = {
  name: "apc-security",
  version: "1.0.0",

  postValidate(nodes, errors) {
    // 检查表达式中的潜在危险代码
    const dangerousPatterns = [
      /eval\s*\(/,
      /File\s*\(/,
      /Folder\s*\(/,
      /system\s*\./,
      /app\.system/,
      /\.execute\s*\(/
    ];

    const newErrors = [...errors];
    for (const node of nodes) {
      if (node.nodeType === "SetExpression") {
        const expr = (node as SetExpressionNode).expression;
        for (const pattern of dangerousPatterns) {
          if (pattern.test(expr)) {
            newErrors.push({
              nodeId: node.id,
              rule: "SECURITY_VIOLATION",
              message: `Potentially dangerous expression pattern: ${pattern.source}`
            });
          }
        }
      }
    }

    return { nodes, errors: newErrors };
  }
};
```

**插件生命周期：**

```
Compiler Init → Plugin.onInit()
     │
     ▼
  Parser → Plugin.postParse()
     │
     ▼
  Validator → Plugin.postValidate()
     │
     ▼
  Scheduler (无插件钩子)
     │
     ▼
  Optimizer → Plugin.postOptimize()
     │
     ▼
  CodeGenerator → Plugin.postGenerate()
     │
     ▼
  Output
```
