### 2.2 Neural Filters 工作流

```
1. 滤镜 → Neural Filters
2. 下载所需模型(首次使用)
3. 调整参数
4. 输出选项:
   - 新图层(推荐)
   - 新文档
   - 当前图层
```

## 三、特效制作实战

### 3.1 发光效果

```
方法1: 外发光图层样式
方法2: 复制图层 → 高斯模糊 → 滤色混合
方法3: 新建图层 → 柔光画笔绘制 → 高斯模糊
```

### 3.2 粒子/星光效果

```
1. 新建黑色图层
2. 滤镜 → 渲染 → 云彩
3. 色阶(Ctrl+L)大幅增强对比
4. 混合模式: 滤色
5. 添加外发光图层样式
```

### 3.3 故障效果(Glitch)

```
1. 复制3个图层
2. 分别只保留R/G/B通道
3. 各层微移(不同方向)
4. 添加扫描线(图案叠加)
5. 随机切片位移
```

### 3.4 双重曝光

```
1. 底层: 人物剪影(黑白)
2. 上层: 风景/纹理
3. 上层混合模式: 正片叠底
4. 用底层蒙版控制显示范围
```

### 3.5 文字特效

| 效果 | 实现方法 |
|------|---------|
| 金属文字 | 斜面浮雕+渐变叠加+外发光 |
| 霓虹灯 | 外发光(多层)+内发光 |
| 火焰文字 | 滤镜→液化(向上)+色彩平衡 |
| 冰冻文字 | 滤镜→纹理→裂纹+蓝色外发光 |
| 溶解文字 | 滤镜→像素化→晶格化 |
| 流体文字 | 滤镜→液化→扭曲 |

## 五、ExtendScript 滤镜自动化

### 5.1 批量滤镜脚本

```javascript
// batch_blur.jsx - 批量高斯模糊
var doc = app.activeDocument;
var layers = doc.layers;

for (var i = 0; i < layers.length; i++) {
    if (layers[i].kind == LayerKind.NORMAL) {
        doc.activeLayer = layers[i];
        doc.activeLayer.applyGaussianBlur(3.5);
    }
}
```

### 5.2 液化自动化

```javascript
// 注意: 液化滤镜不支持ExtendScript直接调用
// 替代方案: 使用变形工具(liquify替代)
var doc = app.activeDocument;
// 使用透视变形作为替代
doc.activeLayer.applyPerspectiveWarp(...);
```
