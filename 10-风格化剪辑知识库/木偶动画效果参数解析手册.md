## 🎭 Puppet Tool 核心参数

### 一、Deform Pin（变形钉）

| 参数 | 范围 | 默认值 | 用途 |
|------|------|--------|------|
| **Position** | -∞ ~ +∞ | 0,0 | 控制钉的位置 |
| **Rotation** | -180° ~ 180° | 0° | 旋转角度 |
| **Scale** | 0% ~ 200% | 100% | 缩放影响范围 |
| **Weight** | 0 ~ 100 | 50 | 影响力权重 |
| **Auto Rotate** | On/Off | Off | 自动旋转跟随 |

### 二、Starch Pin（固定钉）

| 参数 | 范围 | 默认值 | 用途 |
|------|------|--------|------|
| **Position** | -∞ ~ +∞ | 0,0 | 固定点位置 |
| **Weight** | 0 ~ 100 | 50 | 固定强度 |

### 三、Puppet Overlap（重叠）

| 参数 | 范围 | 默认值 | 用途 |
|------|------|--------|------|
| **Position** | -∞ ~ +∞ | 0,0 | 重叠区域位置 |
| **Depth** | 0 ~ 200 | 100 | 重叠深度 |

### 四、Puppet Tool 全局设置

| 参数 | 范围 | 默认值 | 用途 |
|------|------|--------|------|
| **Pin Spacing** | 1 ~ 100 | 10 | 网格密度 |
| **Triangle Detail** | Low/Medium/High | Medium | 三角网格精度 |
| **Subdivision** | 0 ~ 3 | 0 | 细分级别 |

## 🔧 骨骼绑定方案

### 五、人物角色绑定

```
头部: 1个Deform Pin (头顶)
颈部: 1个Deform Pin (颈部连接点)
肩部: 2个Deform Pin (左右肩)
肘部: 2个Deform Pin (左右肘)
手腕: 2个Deform Pin (左右腕)
腰部: 1个Deform Pin (腰部)
臀部: 2个Deform Pin (左右臀)
膝盖: 2个Deform Pin (左右膝)
脚踝: 2个Deform Pin (左右踝)
```

### 六、布偶角色绑定

```
头部: 1个Deform Pin + 1个Starch Pin (面部)
身体: 1个Deform Pin (胸部) + 1个Starch Pin (背部)
手臂: 肩部Pin + 肘部Pin + 手腕Pin
腿部: 臀部Pin + 膝盖Pin + 脚踝Pin
衣物褶皱: 额外Deform Pin (褶皱处)
```

## 🎬 动画技巧

### 七、关键帧设置

```jsx
// 自动生成关键帧
var puppetLayer = app.project.activeItem.layer("角色");
var puppetProp = puppetLayer.property("ADBE Puppet");

for (var i = 0; i < 30; i++) {
    var time = i * 0.1;
    puppetProp.property("Pin 1").property("Position").setValueAtTime(time, [200 + Math.sin(i) * 20, 300]);
}
```

### 八、表达式控制

```js
// 跟随 Null 控制器
thisComp.layer("Null_Controller").transform.position

// 波浪运动
freq = 2; amp = 30;
value + [0, Math.sin(time * freq * 2 * Math.PI) * amp]

// 随机抖动
wiggle(3, 10)

// 惯性跟随
lag = 0.05;
target = thisComp.layer("目标").transform.position;
value + (target - value) * lag;
```
