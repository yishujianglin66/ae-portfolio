# Photoshop 合成与创意工作流完全指南

> 版本: 2025-v1 | 适用: 创意合成/海报设计/视觉特效

## 一、合成基础理论

### 1.1 合成三要素

| 要素 | 说明 | 检查标准 |
|------|------|---------|
| 透视匹配 | 所有元素透视一致 | 消失点统一 |
| 光照匹配 | 光源方向/强度/色温一致 | 阴影方向统一 |
| 色彩匹配 | 色温/对比度/颗粒一致 | 无明显色差 |

### 1.2 合成工作流程

```
1. 概念设计(草图/参考)
2. 素材收集/拍摄
3. 初步合成(摆放位置)
4. 透视校正(匹配消失点)
5. 光照匹配(添加阴影/高光)
6. 色彩统一(调整图层统一色调)
7. 边缘融合(蒙版/修复)
8. 最终调色(整体风格化)
```

## 二、核心合成技术

### 2.1 透视匹配

```
方法1: 消失点滤镜
  滤镜 → 消失点 → 定义透视网格 → 粘贴元素

方法2: 自由变换+透视
  Ctrl+T → 右键 → 透视/扭曲

方法3: 消失点工具
  在合成中创建透视参考线
```

### 2.2 光照匹配

| 技术 | 实现 | 用途 |
|------|------|------|
| 阴影绘制 | 新图层+柔边画笔+低不透明度 | 地面阴影 |
| 接触阴影 | 深色窄渐变 | 物体接地感 |
| 高光添加 | 滤色层+白色柔边画笔 | 光照反射 |
| 环境光遮蔽 | 正片叠底+深色柔边 | 缝隙/角落暗化 |
| 色彩溢出 | 柔光+环境色 | 环境反射 |

### 2.3 边缘融合技术

| 方法 | 适用 | 技巧 |
|------|------|------|
| 蒙版羽化 | 柔和边缘 | 低斯模糊蒙版 |
| 仿制图章 | 硬边过渡 | 交替采样区域 |
| 混合画笔 | 自然过渡 | 湿边效果 |
| 选择并遮住 | 毛发/复杂边缘 | 智能半径 |
| 内容感知 | 大区域融合 | AI自动填充 |

## 三、创意合成案例

### 3.1 天空替换

```
1. 选择天空(色彩范围/蒙版)
2. 新建天空图层在下方
3. 蒙版精修边缘(建筑/树木)
4. 色彩匹配(天空色温匹配环境光)
5. 反射处理(水面/玻璃反射新天空)
6. 整体调色(统一色调)
```

### 3.2 物体移除

```
方法1: 内容感知填充(简单背景)
方法2: 仿制图章(复杂背景)
方法3: 内容识别填充(编辑→内容识别填充)
  - 采样区域好
  - 填充设置: 颜色适应+旋转+缩放
方法4: 生成式填充(AI, PS 2024+)
  - 选区 → 生成式填充 → 输入描述
```

### 3.3 生成式填充(Generative Fill)

```
PS 2024+ AI功能:
1. 创建选区
2. 编辑 → 生成式填充
3. 输入文字描述(或留空自动生成)
4. AI生成3个选项供选择
5. 结果在新生成图层上(可重新生成)

应用场景:
- 扩展画面边界
- 添加/移除物体
- 创建新元素
- 背景扩展
```

## 四、海报设计

### 4.1 海报构图模板

| 类型 | 特征 | 适用 |
|------|------|------|
| 居中式 | 主体居中，文字环绕 | 产品/电影海报 |
| 对角线 | 元素沿对角线排列 | 运动/活力 |
| 三分法 | 主体在三分点 | 通用 |
| 满版式 | 元素充满画面 | 时尚/杂志 |
| 极简式 | 大量留白+小元素 | 高端/文艺 |
| 拼贴式 | 多元素组合 | 创意/活动 |

### 4.2 文字排版

| 原则 | 说明 |
|------|------|
| 对比 | 大小/粗细/颜色对比 |
| 对齐 | 左对齐/居中/右对齐统一 |
| 亲密 | 相关内容靠近 |
| 重复 | 统一风格元素 |
| 留白 | 呼吸空间 |

## 五、纹理与材质制作

### 5.1 纹理生成方法

| 方法 | 效果 | 用途 |
|------|------|------|
| 滤镜→纹理→颗粒 | 基础颗粒 | 胶片感 |
| 滤镜→纹理→纹理化 | 应用纹理图案 | 墙面/画布 |
| 滤镜→渲染→云彩 | 随机纹理 | 自然纹理 |
| 滤镜→扭曲→波纹 | 波纹纹理 | 水面/金属 |
| 图案图章 | 自定义图案 | 重复纹理 |
| 定义图案 | 保存为可复用 | 无缝纹理 |

### 5.2 材质贴图到3D表面

```
1. 准备材质纹理(无缝)
2. 在AE/3D软件中创建3D模型
3. 使用置换滤镜将纹理映射到表面
4. 或使用AE的CC Environment效果
```

## 六、与视频工作流集成

### 6.1 PSD序列帧导入AE

```
1. PS: 文件→导出→渲染视频(逐帧PNG序列)
2. AE: 导入PNG序列
3. 每帧独立图层 → 可单独调整
4. 适合: 逐帧动画/复杂合成
```

### 6.2 AE合成导出PS精修

```
1. AE: 导出单帧PNG(最大分辨率)
2. PS: 打开进行精修(调色/修图)
3. 精修后导出 → 重新导入AE
4. 适合: 关键帧精修
```
