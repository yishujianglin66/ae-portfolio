## 十一、素材版权知识

### 11.1 素材授权类型详解

#### 1. Royalty-Free (RF) 免版税
- **定义**：一次付费，永久使用，无需按使用次数付费
- **典型站点**：Shutterstock、Adobe Stock、iStock
- **特点**：
  - 一次购买永久使用
  - 无使用次数限制
  - 但仍有用途限制（如不可转售）
  - 通常有数量上限（如印刷量）

#### 2. Rights-Managed (RM) 版权管理
- **定义**：按使用范围、时长、地域、用途付费
- **典型站点**：Getty Images、Alamy
- **特点**：
  - 价格灵活
  - 可独占使用
  - 适合高端项目
  - 需明确使用范围

#### 3. Creative Commons (CC) 知识共享
- **定义**：作者保留版权，但允许在特定条件下使用
- **典型站点**：Flickr、Wikimedia、Freesound
- **特点**：
  - 多种协议组合
  - 需遵守具体协议
  - 通常需署名

#### 4. Public Domain 公共领域
- **定义**：版权已过期或作者放弃版权
- **典型站点**：Wikimedia Commons、New Old Stock、Pond5 Public Domain
- **特点**：
  - 完全免费
  - 可任意使用
  - 无需署名
  - 但需确认是否真的 PD

#### 5. Editorial Use Only 仅编辑用途
- **定义**：仅用于新闻报道、评论等编辑用途，不可商用
- **典型站点**：Getty Images、Shutterstock 编辑区
- **特点**：
  - 不可用于广告
  - 不可用于商业推广
  - 含名人肖像、品牌 Logo 等

### 11.2 CC 协议详解

#### CC-BY（署名）
- **要求**：必须署名作者
- **商用**：可商用
- **修改**：可修改
- **示例**：Freesound 部分素材

#### CC-BY-SA（署名-相同方式共享）
- **要求**：署名 + 衍生作品必须使用相同协议
- **商用**：可商用
- **修改**：可修改，但衍生作品必须 CC-BY-SA
- **示例**：Wikipedia 内容

#### CC-BY-NC（署名-非商用）
- **要求**：署名
- **商用**：**不可商用**
- **修改**：可修改
- **示例**：FMA 部分音乐

#### CC-BY-ND（署名-禁止演绎）
- **要求**：署名
- **商用**：可商用
- **修改**：**不可修改**
- **示例**：部分摄影师作品

#### CC-BY-NC-SA（署名-非商用-相同方式共享）
- **要求**：署名 + 相同协议
- **商用**：**不可商用**
- **修改**：可修改，衍生作品必须 CC-BY-NC-SA

#### CC-BY-NC-ND（署名-非商用-禁止演绎）
- **要求**：署名
- **商用**：**不可商用**
- **修改**：**不可修改**
- **最严格的 CC 协议**

#### CC0（公共领域宣告）
- **要求**：无要求
- **商用**：可商用
- **修改**：可修改
- **示例**：Pexels、Pixabay、Unsplash

### 11.3 商用素材使用注意事项

#### 1. 确认授权范围
- 阅读完整 License 文档
- 确认使用场景是否在授权内
- 注意地域限制
- 注意使用期限

#### 2. 保留授权凭证
- 保存购买记录
- 保存 License 文件
- 保存下载时间戳
- 建立授权台账

#### 3. 注意肖像权
- 含人物素材需确认是否有肖像授权
- Editorial Use Only 素材不可用于广告
- 名人肖像需额外授权

#### 4. 注意商标权
- 素材中含品牌 Logo 需谨慎
- 不可用于诋毁品牌
- 商业使用需品牌授权

#### 5. 注意敏感内容
- 不得用于违法用途
- 不得涉及政治敏感
- 不得涉及色情暴力

### 11.4 素材修改与二次创作

#### 1. 修改权限
- RF 素材通常可修改
- RM 素材需确认协议
- CC 协议需查看具体条款
- CC-BY-ND 不可修改

#### 2. 二次创作
- 修改后仍需保留原授权
- 衍生作品版权归属
- AI 生成素材的版权问题

#### 3. 修改建议
- 保留原始素材备份
- 记录修改过程
- 标注素材来源

### 11.5 版权风险防范

#### 1. 风险来源
- 免费素材站的版权陷阱
- 国产素材站的二次授权问题
- AI 生成素材的版权争议
- 素材中含第三方版权内容

#### 2. 防范措施
- 优先使用大平台素材
- 保留所有授权凭证
- 商用前咨询律师
- 购买版权保险

#### 3. 风险处理
- 收到侵权通知立即下架
- 联系素材平台核实
- 必要时寻求法律援助

### 11.6 侵权案例分析

#### 案例 1：视觉中国黑洞照片事件
- **事件**：视觉中国将公共领域照片声明版权
- **教训**：Public Domain 素材无版权
- **启示**：警惕版权流氓

#### 案例 2：Getty Images 嵌入功能侵权
- **事件**：Getty 嵌入功能被指侵权
- **教训**：嵌入也算使用
- **启示**：所有使用都需授权

#### 案例 3：Freesound 商用纠纷
- **事件**：CC-BY-NC 素材被商用
- **教训**：CC 协议需严格遵守
- **启示**：商用前确认 CC 协议

#### 案例 4：YouTube Content ID 误判
- **事件**：原创音乐被误判侵权
- **教训**：保留创作证据
- **启示**：使用 Content ID 友好平台音乐

#### 案例 5：AI 生成素材版权争议
- **事件**：AI 生成图片版权归属不明
- **教训**：AI 生成素材版权存争议
- **启示**：优先使用 Adobe Firefly 等版权安全工具

| ⭐⭐⭐⭐ 较安全 | Mixkit、Coverr、Freesound（CC0）、Poly Haven | 免费但授权明确 |
| ⭐⭐⭐ 需注意 | Freesound（部分）、FMA、SoundCloud | 需查看具体协议 |
| ⭐⭐ 需谨慎 | 国内聚合站、个人博客 | 可能存在二次授权问题 |
| ⭐ 高风险 | 不明来源、破解版 | 不建议使用 |

### 素材使用工作流

```
1. 需求分析 → 确定素材类型与风格
2. 关键词准备 → 中英文关键词组合
3. 多平台搜索 → 至少 3 个平台对比
4. 筛选评估 → 质量、授权、相关性
5. 下载保存 → 保留 License 信息
6. 整理归档 → Eagle/Billfish 分类管理
7. 使用记录 → 注明素材来源
8. 授权存档 → 保留购买凭证
9. 定期复查 → 检查授权变更
10. 版权维护 → 持续学习版权知识
```
