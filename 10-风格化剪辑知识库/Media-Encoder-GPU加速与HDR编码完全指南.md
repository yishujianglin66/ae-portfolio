# Media Encoder GPU加速与HDR编码完全指南

> 版本: 2025-v1 | 适用: GPU加速/HDR编码/高级渲染

## 一、GPU加速

### 1.1 GPU加速类型

| 类型 | 说明 | 支持 |
|------|------|------|
| CUDA | NVIDIA GPU加速 | 编码/解码/效果 |
| OpenCL | AMD/Intel GPU加速 | 编码/解码 |
| NVENC | NVIDIA硬件编码器 | H.264/H.265编码 |
| QSV | Intel Quick Sync | H.264/H.265编码 |
| AMF | AMD硬件编码器 | H.264/H.265编码 |

### 1.2 启用GPU加速

```
设置GPU加速:
1. 编辑→首选项→常规
2. 渲染程序选择:
   - CUDA (NVIDIA GPU)
   - OpenCL (AMD/Intel)
   - 仅软件 (CPU)
3. 重启Media Encoder

效果:
- 渲染速度提升2-5倍
- 实时预览更流畅
- 批量处理更快
```

## 二、HDR编码

### 2.1 HDR格式

| 格式 | 位深 | 色彩空间 | 传输函数 | 用途 |
|------|------|---------|---------|------|
| HDR10 | 10-bit | Rec.2020 | PQ | 静态HDR |
| HDR10+ | 10-bit | Rec.2020 | PQ+动态元数据 | 动态HDR |
| HLG | 10-bit | Rec.2020 | HLG | 广播HDR |
| Dolby Vision | 12-bit | P3/Rec.2020 | PQ+动态元数据 | 高端HDR |

### 2.2 HDR导出设置

```
HDR10导出:
1. 格式: HEVC(H.265)
2. 配置: Main 10
3. 色彩空间: Rec.2020
4. 位深: 10-bit
5. HDR元数据: 启用
6. 最大CLL: 1000-4000 nits
7. 最大FALL: 根据内容设置

HLG导出:
1. 格式: HEVC(H.265)
2. 配置: Main 10
3. 色彩空间: Rec.2020
4. 传输函数: HLG
5. 无需元数据

Dolby Vision:
- 需要专业工具
- 需要Dolby授权
- 使用专业编码软件
```

### 2.3 HDR质量控制

| 指标 | 标准 | 说明 |
|------|------|------|
| 峰值亮度 | 1000-4000 nits | 最大亮度 |
| 黑位 | 0.005 nits | 最暗细节 |
| 对比度 | >1000:1 | 明暗对比 |
| 色域 | >90% P3 | 色彩覆盖 |
| 位深 | 10-bit+ | 色彩层次 |

## 三、高级编码

### 3.1 多通道编码

```
多通道编码:
1. 文件→导出→多通道
2. 添加多个输出格式
3. 设置不同参数
4. 同时渲染多个版本

应用场景:
- 同时输出4K/1080p/720p
- 同时输出H.264/ProRes
- 同时输出不同平台版本
```

### 3.2 自定义预设

```
创建自定义预设:
1. 设置导出参数
2. 预设→保存预设
3. 命名并保存

预设管理:
- 导出预设集合
- 导入预设
- 共享预设给团队
```

## 四、批量渲染

### 4.1 队列管理

```
批量渲染流程:
1. 添加多个文件到队列
2. 为每个文件设置预设
3. 设置输出位置
4. 点击"开始队列"
5. 监控渲染进度

队列管理:
- 调整优先级
- 暂停/恢复
- 取消任务
- 查看日志
```

### 4.3 Watch Folders

```
监视文件夹:
1. 设置监视文件夹
2. 自动检测新文件
3. 应用预设自动渲染
4. 输出到指定位置

应用场景:
- 自动转码上传素材
- 批量处理每日素材
- 自动化工作流
```

## 五、API自动化

### 5.1 命令行接口

```bash
# 命令行渲染
Adobe Media Encoder.exe -input "input.mp4" -preset "H.264 High" -output "output.mp4"

# 批量渲染
for %%f in (*.mp4) do (
    Adobe Media Encoder.exe -input "%%f" -preset "YouTube 1080p" -output "output\%%~nf.mp4"
)
```

### 5.2 CEP面板扩展

```javascript
// 自定义渲染面板
var csInterface = new CSInterface();
csInterface.evalScript('renderWithPreset("' + preset + '")');
```
