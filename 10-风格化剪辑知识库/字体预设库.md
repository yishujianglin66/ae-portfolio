# 字体预设库

> **核心目标**:整合系统与用户安装的所有字体资源,按艺术字与字幕版式场景分类,提供 AE JSX 调用示例与字体搭配方案。
> **适用版本**:After Effects 2026 | **平台**:Windows | **语法标准**:ExtendScript ES3
> **调用方式**:MCP `executeAtomScript` 命令直接执行 IIFE JSX 字符串

---

## 一、字体资源总览

### 1.1 字体统计

| 字体来源 | 目录路径 | 文件数 |
|---------|---------|--------|
| Windows 系统字体 | `C:\Windows\Fonts` | 110+ TTF |
| 用户安装字体 | `C:\Users\Administrator\AppData\Local\Microsoft\Windows\Fonts` | 200+ TTF |
| **合计** | — | **60+ 款家族 / 310+ 文件** |

### 1.2 字体分类体系

按用途分为 8 大类:

1. **中文正文字体**(8 款) - 黑体/宋体/楷体/仿宋/思源/阿里普惠/方正/马善政
2. **英文正文字体**(35+ 款) - Arial/Calibri/Cambria/Consolas/Segoe UI/Times/Verdana 等
3. **数字专用字体**(5 款) - DIN Next Pro / NumberOnly / Bahnschrift / Segoe UI Symbol / DIN 替代
4. **现代无衬线家族**(12 款) - Lato/Kanit/Inter/Cocogoose/Brandon Grotesque/Alegreya Sans SC/Merriweather/Bebas Neue/DejaVu/Karla/Antonio/Franklin Gothic
5. **粗犷冲击字体**(8+ 款) - Impact/Anton/Bebas/BlackOpsOne/Hanson 等
6. **手写签名字体**(10+ 款) - GreatVibes/Allura/Dhanikans/Austhina Brush 等
7. **童趣装饰字体**(8+ 款) - Bangers/Chewy/LuckiestGuy/Frijole 等
8. **中文手写字体**(3 款) - MaShanZheng/AliandoRocky/方正粗黑宋

### 1.3 文档使用约定

- 所有 JSX 代码块标注为 ```` ```jsx ````,可直接复制到 MCP `executeAtomScript` 的 `scriptContent` 字段
- 字体名一律使用 PostScript name(JSX 调用唯一可信标识)
- 占位符统一采用 `{{param_name}}` 语法,MCP 端替换后下发
- 所有 IIFE 模板显式 `return JSON.stringify(_r)`,行宽不超过 80 字符

## 四、现代无衬线家族(项目主力字体)

12 款现代无衬线字体家族,字重丰富,作为字幕版式与艺术字主力。

### 4.1 Lato(18 字重)

- **PostScript name 前缀**: `Lato-`
- **完整字重**:Hairline / HairlineItalic / Thin / ThinItalic / Light / LightItalic / Italic / Regular / Medium / MediumItalic / Semibold / SemiboldItalic / Bold / BoldItalic / Heavy / HeavyItalic / Black / BlackItalic
- **设计风格**:波兰设计师 Łukasz Dziedzic,均衡中性,经典现代无衬线
- **适用场景**:企业片头、字幕主文字、品牌名(常搭配 Heavy / Black 作大标题)
- **JSX 调用片段**:
```jsx
td.font = "Lato-Heavy";
td.fontSize = 72;
td.tracking = -20;
```
