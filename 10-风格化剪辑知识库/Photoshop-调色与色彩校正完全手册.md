# Photoshop 调色与色彩校正完全手册

> 版本: 2025-v1 | 适用: 调色/风格化/电影感工作流

## 一、调色工具全景

### 1.1 调整图层 vs 直接调整

| 方式 | 特性 | 推荐 |
|------|------|------|
| 调整图层 | 非破坏性、可蒙版、可调序 | 强烈推荐 |
| 图像→调整 | 直接修改像素 | 不推荐(除非栅格化) |

### 1.2 核心调色工具

| 工具 | 控制维度 | 最佳用途 |
|------|---------|---------|
| 曲线(Curves) | 色调/对比度/通道 | 最强大的调色工具 |
| 色阶(Levels) | 黑白场/中间调 | 快速曝光校正 |
| 色相/饱和度 | 色相/饱和度/明度 | 单色调整 |
| 色彩平衡 | 阴影/中间调/高光 | 色调偏移 |
| 可选颜色 | CMYK分量微调 | 肤色精修 |
| 通道混合器 | 通道间混合 | B&W转换/创意调色 |
| 渐变映射 | 亮度→颜色映射 | 风格化调色 |
| 照片滤镜 | 全局色温偏移 | 快速暖/冷调 |

## 二、曲线(Curves)深度

### 2.1 RGB曲线

| 曲线形状 | 效果 | 应用 |
|----------|------|------|
| S形 | 增强对比度 | 最常用 |
| 反S形 | 降低对比度 | 柔和/梦幻 |
| 暗部上提 | 抬起黑色(胶片感) | 复古/文艺 |
| 高光下压 | 压缩白色 | 柔和高光 |
| 单通道(R/G/B) | 分别调整色彩通道 | 色彩校正/创意 |

### 2.2 单通道曲线调色

```
红色曲线:
- 上提 = 加红
- 下拉 = 加青(减红)
- 经典: 高光微加红，阴影微加青

绿色曲线:
- 上提 = 加绿
- 下拉 = 加品红
- 经典: 中间调微减绿(肤色)

蓝色曲线:
- 上提 = 加蓝
- 下拉 = 加黄(减蓝)
- 经典: 阴影加蓝(冷调电影感)
```

### 2.3 曲线预设

| 预设名 | 曲线描述 | 风格 |
|--------|---------|------|
| 电影感 | RGB S曲线 + 暗部抬起 + 蓝阴影 | 好莱坞 |
| 胶片模拟 | 暗部抬起 + 高光压缩 + 轻微S | 复古 |
| 冷调 | 蓝曲线上提 + 红曲线阴影下拉 | 冷酷 |
| 暖调 | 红曲线高光微提 + 蓝曲线下拉 | 温暖 |
| 高对比 | 陡峭S曲线 | 戏剧性 |
| 低对比 | 反S曲线 + 暗部大幅抬起 | 梦幻 |

## 三、HSL 精修

### 3.1 色相/饱和度调整

| 颜色范围 | 电影感常用 | 说明 |
|----------|-----------|------|
| 红色 | 色相+5~10, 饱和+10 | 肤色偏暖 |
| 黄色 | 色相+10~15, 饱和-10 | 环境偏橙 |
| 绿色 | 色相-20~-30, 饱和-20 | 墨绿/军绿 |
| 青色 | 色相-10, 饱和+10 | 海洋/天空 |
| 蓝色 | 色相-10~-20, 饱和-10 | 深沉蓝 |
| 洋红 | 色相+5, 饱和-20 | 减少品红 |

### 3.2 目标调整工具

- **操作**: 选择目标调整工具 → 在图像上拖动
- **向上拖**: 增加该区域对应属性
- **向下拖**: 减少
- **优势**: 直觉式调色，所见即所得

## 四、色彩平衡与分离色调

### 4.1 色彩平衡

| 区域 | 调整方向 | 效果 |
|------|---------|------|
| 阴影 | 加青/蓝 | 冷调阴影 |
| 中间调 | 微调红/黄 | 肤色温暖 |
| 高光 | 加黄/红 | 暖调高光 |

### 4.2 分离色调(Gradient Map)

```
经典电影分离色调:
渐变映射 → 黑到白映射为:
  黑色端: 深蓝/深青 (#001a33)
  白色端: 暖橙/米黄 (#ffe0b3)
混合模式: 柔光 不透明度: 30-50%
```

## 五、可选颜色(Selective Color)

### 5.1 肤色精修

| 颜色 | 青 | 品红 | 黄 | 黑 |
|------|-----|------|-----|-----|

|------|-----|------|-----|-----|

| 青色 | +10 | 0 | -5 | 0 |

## 六、LUT 应用

### 6.1 PS 中加载 .cube LUT

```
方法1: 滤镜 → Camera Raw滤镜 → 配置文件→浏览
方法2: 图层 → 新建调整图层 → 3D LUT
方法3: 文件 → 自动 → 颜色配置(批量)
```

### 6.2 从 PS 导出 LUT 给 AE

```
1. PS 调色完成后: 文件 → 导出 → 颜色查找表
2. 保存为 .cube 文件
3. AE 中: 效果 → 颜色校正 → Lumetri Color → 创意 → 查找
4. 加载 .cube 文件
```

## 七、Camera Raw 滤镜

### 7.1 Camera Raw 核心工具

| 工具 | 作用 |
|------|------|
| 基本面板 | 曝光/对比度/高光/阴影/白色/黑色 |
| 色调曲线 | 与独立曲线相同 |
| HSL/颜色 | 按颜色调整 |
| 分离色调 | 高光/阴影着色 |
| 细节 | 锐化/降噪 |
| 镜头校正 | 畸变/色差/暗角 |
| 效果 | 颗粒/去雾 |
| 校准 | 红/绿/蓝原色调整 |

### 7.2 Camera Raw 作为智能滤镜

```
1. 图层转换为智能对象
2. 滤镜 → Camera Raw 滤镜
3. 所有参数可随时修改
4. 支持蒙版控制应用范围
```
