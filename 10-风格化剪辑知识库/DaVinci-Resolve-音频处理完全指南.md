## 二、音频处理

### 2.1 EQ均衡器

| 类型 | 用途 | 参数 |
|------|------|------|
| 6段参量EQ | 基础调整 | 频率/增益/Q值 |
| 10段参量EQ | 精细调整 | 更多频段 |
| 图形EQ | 快速调整 | 固定频段 |
| 通道EQ | 通道处理 | 每通道独立 |

### 2.2 动态处理

| 效果 | 用途 | 参数 |
|------|------|------|
| 压缩器 | 动态控制 | 阈值/比率/启动/释放 |
| 限制器 | 峰值限制 | 阈值/天花板 |
| 扩展器 | 动态扩展 | 阈值/比率 |
| 噪声门 | 噪声消除 | 阈值/启动/释放 |
| 多段压缩 | 频段压缩 | 多频段独立 |

### 2.3 效果器

| 效果 | 用途 | 参数 |
|------|------|------|
| 混响 | 空间感 | 房间大小/衰减/湿度 |
| 延迟 | 回声 | 时间/反馈/混合 |
| 合唱 | 厚度 | 速率/深度/混合 |
| 失真 | 粗糙感 | 类型/驱动/音色 |
| 降噪 | 噪声消除 | 采样/减少 |

## 三、音频编辑

### 3.1 剪辑操作

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 分割 | Ctrl+B | 在播放头分割 |
| 删除 | Delete | 删除选中 |
| 波纹删除 | Shift+Delete | 删除并闭合 |
| 复制 | Ctrl+C | 复制 |
| 粘贴 | Ctrl+V | 粘贴 |
| 淡入 | 拖动边缘 | 音量淡入 |
| 淡出 | 拖动边缘 | 音量淡出 |

### 3.2 音频修复

```
音频修复工具:
1. 降噪: 采样环境噪声→应用降噪
2. 去齿音: 检测齿音频率→衰减
3. 去爆音: 检测爆破音→修复
4. 去混响: 分析混响→减少
5. 修复剪辑: 选择区域→自动修复

修复工作流:
1. 识别问题区域
2. 选择修复工具
3. 调整参数
4. 预览效果
5. 应用修复
```

## 四、混音

### 4.1 混音工作流

```
标准混音流程:
1. 整理轨道(命名/颜色/分组)
2. 清理音频(去噪/修复)
3. 音量平衡(各轨道基础音量)
4. EQ调整(频率平衡)
5. 动态处理(压缩/限制)
6. 空间效果(混响/延迟)
7. 自动化(音量/效果变化)
8. 响度标准化(目标响度)
9. 最终检查(监听/分析)
```

### 4.2 总线处理

| 总线 | 处理 | 用途 |
|------|------|------|
| 对话总线 | EQ+压缩 | 统一人声 |
| 音乐总线 | 轻度压缩 | 统一音乐 |
| 音效总线 | 限制器 | 控制峰值 |
| Master | 响度+限制 | 最终输出 |

## 六、导出

### 6.1 音频导出

| 格式 | 位深 | 用途 |
|------|------|------|
| WAV | 24-bit | 高质量 |
| AIFF | 24-bit | Mac兼容 |
| MP3 | 320kbps | 网络分享 |
| AAC | 256kbps | Apple设备 |
| FLAC | 无损 | 归档 |

### 6.2 导出设置

```
导出音频:
1. 文件→导出→音频
2. 选择格式(WAV推荐)
3. 设置采样率(48kHz)
4. 设置位深(24-bit)
5. 选择轨道(全部/选中)
6. 设置输出位置
7. 导出
```
