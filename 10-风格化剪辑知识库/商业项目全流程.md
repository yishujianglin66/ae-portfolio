## 一、项目生命周期管理

### 1.1 项目立项阶段

#### 1.1.1 需求分析与客户沟通

项目立项是商业视频项目的起点,需求分析的深度直接决定项目后续走向。立项阶段需要完成以下核心任务:

**需求挖掘要点：**
- 项目背景：客户为什么要做这个视频?是新品发布、品牌升级、还是危机公关?
- 目标受众：B 端决策者、C 端消费者、还是内部员工?不同受众决定内容调性
- 核心信息：希望观众看完后记住什么?行动什么?
- 投放渠道：电视、电梯、抖音、B 站、展会、官网?渠道决定规格
- 预算区间：直接询问预算往往得不到答案,可用"同类项目通常 X-Y 万,您预期在哪个区间?"
- 时间节点：是否对应某个具体活动/发布会/节日?
- 决策链条：谁出钱?谁拍板?谁执行对接?

**需求访谈清单模板：**

| 类别 | 问题示例 | 备注 |
|------|---------|------|
| 项目背景 | 这个视频服务的业务目标是什么? | 区分品牌/销售/培训 |
| 受众画像 | 目标用户的年龄/职业/消费力? | 影响调性 |
| 核心信息 | 用一句话说出观众必须记住的内容 | 强制收敛 |
| 情绪目标 | 观众看完应该有什么感受? | 走心/燃/专业/幽默 |
| 投放渠道 | 主要在哪投放?次要是? | 决定规格矩阵 |
| 预算范围 | 您的预算预期在什么区间? | 给区间不给点 |
| 时间节点 | 期望什么时间交付?有无硬截止? | 评估加急 |
| 参考案例 | 有没有喜欢的片子?喜欢哪里? | 风格收敛最快 |
| 决策流程 | 内部审批走几级?谁最终签字? | 影响周期 |
| 素材现状 | 是否已有拍摄素材?品牌资产? | 影响报价 |

#### 1.1.2 项目预算评估

预算评估需要基于项目类型、时长、复杂度、交付规格综合测算。

**预算评估维度：**

| 维度 | 权重 | 评估方法 |
|------|------|---------|
| 项目类型 | 30% | 参考历史同类项目 |
| 视频时长 | 15% | 按分钟单价测算 |
| 制作复杂度 | 25% | 特效数量、合成层数、3D 资产 |
| 交付规格数量 | 10% | 每增加一个版本加 5-15% |
| 时间紧迫度 | 10% | 加急系数 1.2-2.0 |
| 修改轮数 | 5% | 默认含 2 轮,超出按 5-10%/轮 |
| 素材采购 | 5% | 音乐/字体/图片/视频版权 |

**预算评估公式：**
```
项目总价 = 基础制作费 × 复杂度系数 × 时长系数 × 加急系数 + 素材费 + 税费
```

**复杂度系数参考：**
- 简单（纯剪辑+基础字幕）：1.0
- 中等（含 MG 动画/简单特效）：1.5-2.0
- 复杂（含 3D/角色动画/大量合成）：2.5-4.0
- 极复杂（电影级 VFX/全景/交互）：5.0+

#### 1.1.3 时间周期规划

**标准项目周期参考：**

| 项目类型 | 前期 | 制作 | 后期 | 合计 |
|---------|------|------|------|------|
| 15s 产品广告（纯剪辑） | 2 天 | 2 天 | 1 天 | 5 天 |
| 60s MG 动画 | 5 天 | 10 天 | 3 天 | 18 天 |
| 3 分钟企业宣传片 | 7 天 | 15 天 | 5 天 | 27 天 |
| 5 分钟纪录片 | 10 天 | 20 天 | 7 天 | 37 天 |
| 30s 产品广告（含 3D） | 5 天 | 15 天 | 5 天 | 25 天 |
| 4 分钟 MV | 7 天 | 20 天 | 7 天 | 34 天 |

**加急项目处理：**
- 加急 30%：周期压缩 50%,加收 20%
- 加急 50%：周期压缩 70%,加收 50%
- 极限加急：需评估团队产能,加收 80-100%

#### 1.1.4 人员配置方案

**按项目规模的人员配置：**

| 项目规模 | 团队配置 | 月产能 |
|---------|---------|--------|
| 小型（5 万以下） | 剪辑师 ×1 | 4-6 条 |
| 中型（5-30 万） | 制片 + 剪辑 + 特效 + 调色 | 2-3 条 |
| 大型（30-100 万） | 制片 + 导演 + 剪辑 + 特效 + 调色 + 音频 + 动画 | 1 条 |
| 超大型（100 万+） | 完整团队 + 外协 | 0.5 条 |

#### 1.1.5 技术可行性评估

**技术评估清单：**
- 拍摄可行性：场地、灯光、设备、演员
- 特效可行性：是否超出团队技术栈
- 渲染可行性：算力是否足够、渲染时间评估
- 交付可行性：目标平台规格是否明确
- 版权可行性：素材授权范围是否覆盖用途

### 1.2 项目前期阶段

#### 1.2.1 创意方案设计

**创意方案文档结构：**
1. 项目背景与目标
2. 目标受众分析
3. 核心创意概念（一句话）
4. 创意阐述（500 字）
5. 视觉风格参考（情绪板）
6. 叙事结构（三幕式/线性/碎片化）
7. 关键画面描述
8. 音乐音效方向
9. 时长与节奏规划
10. 风险与备选方案

#### 1.2.2 分镜脚本制作

**分镜脚本标准格式：**

| 镜号 | 时长 | 画面描述 | 镜头运动 | 台词/VO | 音效 | 备注 |
|------|------|---------|---------|--------|------|------|
| S01 | 3s | 全景:城市天际线日出 | 缓慢推进 | "每一天..." | 城市环境音 | 建立镜头 |
| S02 | 2s | 特写:咖啡杯冒热气 | 固定 | "...从一杯咖啡开始" | 咖啡机声 | 转场:叠化 |
| S03 | 4s | 中景:主人公走进办公室 | 跟拍 | "我们用专业..." | 脚步声 | - |

**分镜制作工具：**
- 手绘:Procreate / Photoshop
- 软件:Storyboarder / Toon Boom Storyboard / FrameForge
- 在线:Boords / Plot
- AI 辅助:Midjourney 生成参考 / Runway 生成动态分镜

#### 1.2.3 素材清单确认

**素材清单模板：**

| 类别 | 素材名称 | 规格 | 数量 | 来源 | 状态 | 备注 |
|------|---------|------|------|------|------|------|
| 拍摄视频 | 老板访谈 | 4K 25p | 30 分钟 | 客户拍摄 | 待交付 | 含机位 A/B |
| 存档视频 | 工厂空镜 | 1080p | 5 段 | 客户提供 | 已收 | 需确认授权 |
| 音乐 | 背景音乐 BGM | WAV | 1 首 | 商用版权库 | 待采购 | 预算 2000 |
| 字体 | 品牌字体 | OTF | 2 款 | 客户提供 | 已收 | 含授权书 |
| Logo | 客户 Logo | AI/SVG | 1 套 | 客户提供 | 已收 | 含横版/竖版 |
| 图片 | 产品图 | PSD | 8 张 | 客户提供 | 已收 | 含透明底 |

#### 1.2.4 风格参考确定

风格参考是减少返工的关键。需要明确:
- 色调参考（暖/冷/对比/低饱和）
- 节奏参考（快剪/慢镜/呼吸感）
- 调性参考（高端/亲和/科技/文艺）
- 转场参考（硬切/叠化/特效转场）
- 字体风格（无衬线/衬线/手写/展示）
- 动效风格（平滑/弹性/机械/有机）

#### 1.2.5 合同签订与付款节点

**标准付款节点：**
```
预付款 40% → 中期款 40%（粗剪确认）→ 尾款 20%（终版验收）
```

**中国市场常用结构：**
```
预付款 50% → 尾款 50%（验收后交付原文件）
```

**预付款必须到账才开工**,这是行业铁律。

### 1.3 项目中期阶段

#### 1.3.1 素材收集与整理

**素材接收流程：**
1. 客户通过网盘/NAS 传素材
2. 助理下载并核对清单
3. 按 `项目_类别_日期` 归档
4. 转码代理（如原始为 8K RAW）
5. 制作素材索引表
6. 备份到第二存储

#### 1.3.2 初剪版本制作

**初剪（粗剪）目标：**
- 完整叙事结构
- 镜头顺序确定
- 节奏大致到位
- 不做精细调色
- 临时音乐占位
- 字幕位置占位

**初剪交付前自检：**
- [ ] 时长符合要求（±10%）
- [ ] 叙事完整无缺失
- [ ] 无明显穿帮镜头
- [ ] 音画同步基本准确
- [ ] 字幕内容无错别字
- [ ] 输出规格正确

#### 1.3.3 精剪版本制作

**精剪目标：**
- 每一帧都有存在的理由
- 节奏精准到帧
- 转场自然流畅
- 情绪曲线明确
- 声音设计完整

#### 1.3.4 特效与合成

**特效制作流程：**
1. 拆解特效需求（每个特效单独立项）
2. 资产准备（素材、模型、贴图）
3. 制作 Demo（单镜头测试）
4. 客户确认方向
5. 批量制作
6. 合成到主工程
7. 渲染输出

#### 1.3.5 调色与音频

**调色流程：**
1. 一级校色（白平衡、曝光、对比）
2. 二级调色（色彩风格化）
3. 肤色保护
4. 镜头间匹配
5. 输出 LUT 备份

**音频后期流程：**
1. 对白清理（降噪、修复）
2. VO 录制/编辑
3. 音效设计（Foley + 库音效）
4. 音乐编辑（裁剪、混音）
5. 混音（响度标准化）
6. 终混输出

### 1.4 项目后期阶段

#### 1.4.1 客户审阅与修改

**修改管理核心原则：**
- 单点联系人:一个窗口收发反馈
- 书面留痕:微信+邮件双确认
- 阶段把关:不同阶段允许的修改幅度不同
- 计数修改:超出轮次需变更单

**修改轮次标准：**
| 阶段 | 含修改轮数 | 允许修改幅度 |
|------|-----------|------------|
| 创意方案 | 3 轮 | 大改 |
| 分镜脚本 | 2 轮 | 中改 |
| 初剪 | 2 轮 | 结构性调整 |
| 精剪 | 2 轮 | 节奏/镜头微调 |
| 终版 | 1 轮 | 仅技术修正 |

#### 1.4.2 终版输出

**终版输出检查清单：**
- [ ] 画面:分辨率、帧率、色彩空间
- [ ] 音频:采样率、位深、响度
- [ ] 字幕:内容、时间码、样式
- [ ] 片尾:Logo、致谢、版权
- [ ] 时长:精确到帧
- [ ] 文件命名:符合交付规范
- [ ] 多版本:各平台规格齐全

#### 1.4.3 项目归档

**归档清单：**
- 工程文件（AE/PR/DAVINCI）
- 素材原始文件
- 输出成片（含母版+播放版）
- 项目文档（合同、需求、分镜、修改记录）
- 字体与预设
- LUT 文件
- 项目复盘报告

#### 1.4.4 尾款结算

**尾款结算流程：**
1. 客户书面验收确认
2. 开具发票
3. 交付无水印母版（收到尾款后）
4. 交付源文件（如合同约定）
5. 项目归档封存

## 二、客户沟通管理

### 2.1 需求沟通技巧

**沟通核心原则：**
1. 倾听多于表达（7:3 法则）
2. 复述确认理解（"我理解您的意思是..."）
3. 用客户语言,不用专业术语
4. 给选项,不给开放式问题
5. 记录留痕,邮件/微信双确认

**需求引导话术：**

| 客户表述 | 引导话术 |
|---------|---------|
| "我要高大上" | "您指的是 Apple 那种极简高级,还是奢侈品那种华丽高级?" |
| "节奏快点" | "是像抖音那种快剪,还是像电影预告片那种紧凑?" |
| "颜色亮一点" | "是饱和度高,还是对比度强,还是整体偏暖?" |
| "感觉不对" | "能具体说说哪里不对吗?是节奏、色调、还是内容?" |
| "再改改" | "我们当前在第 X 轮修改,本轮我们重点解决 Y 问题" |

### 2.2 创意方案提案方法

**提案结构（20 分钟版）：**
1. 开场:复述客户需求（2 分钟）
2. 洞察:市场/受众分析（3 分钟）
3. 创意:核心概念阐述（5 分钟）
4. 视觉:情绪板+风格帧（5 分钟）
5. 执行:周期+报价（3 分钟）
6. 互动:Q&A（2 分钟）

**提案技巧：**
- 用故事开场,不用 PPT 目录
- 先讲"为什么",再讲"是什么"
- 视觉>文字,情绪板先行
- 报价放在最后,先建立价值
- 准备 2-3 个备选方向

### 2.3 报价策略与谈判

**报价心理战：**
- 永远不要第一个报数字（如果可能）
- 报价区间:低端是你能接受的最低,高端是客户能接受的最高的 1.2 倍
- 锚定效应:先报高价套餐,再报目标价
- 价值锚定:不报"剪辑费",报"完整品牌视频解决方案"

**谈判策略矩阵：**

| 客户压价理由 | 应对策略 |
|------------|---------|
| "预算有限" | 提供降配版方案,而非降价 |
| "别人更便宜" | 比较交付物/服务/保障差异 |
| "长期合作" | 签年框协议再给折扣 |
| "朋友介绍" | 给介绍人返点,不降项目价 |
| "这次先低价,下次补" | 不接受,下次未必来 |

### 2.4 修改意见处理流程

**标准化修改流程：**
```
客户反馈收集 → 整理为修改清单 → 评估工作量 → 判断是否在范围内
  → 在范围:直接执行
  → 超范围:出变更单+报价 → 客户确认 → 执行
```

**修改意见表模板：**

| 序号 | 时间码 | 修改内容 | 客户提出 | 处理方式 | 工作量 | 状态 |
|------|--------|---------|---------|---------|--------|------|
| 1 | 00:15 | Logo 换新版本 | 张总 | 替换素材 | 0.5h | 已完成 |
| 2 | 00:32 | 节奏太慢 | 李经理 | 删减 2 个镜头 | 1h | 已完成 |
| 3 | 01:05 | 加一句旁白 | 张总 | 重新录音+重剪 | 3h | 进行中 |
| 4 | 01:30 | 换背景音乐 | 李经理 | 重新选曲+混音 | 4h | 待确认(超范围) |

### 2.5 客户预期管理

**预期管理三原则：**
1. 永远低承诺,高交付
2. 进度透明,问题早说
3. 不确定时说"我确认后回复",不说"应该可以"

**预期管理时间表：**
- 立项时:报周期 +20% 缓冲
- 制作中:每周同步进度截图
- 交付前:提前 1 天告知"明天下午 3 点前给到"
- 出问题时:立即告知+给出解决方案

### 2.8 10 个客户沟通案例

**案例 1:需求变更 3 次的客户**
- 情景:客户在初剪后要求把"产品介绍"改成"品牌故事"
- 处理:出示需求确认书,说明已超出范围,出变更单+报价
- 结果:客户接受加价,顺利推进

**案例 2:无限修改的客户**
- 情景:客户第 5 轮还在改
- 处理:出示合同修改条款,超出 2 轮按 5000/轮收费
- 结果:客户收敛,聚焦核心修改

**案例 3:压价 50% 的客户**
- 情景:报价 10 万,客户说只有 5 万
- 处理:提供 5 万降配方案（去 3D、简特效、缩时长）
- 结果:客户选择加预算到 8 万走中配方案

**案例 4:紧急加急的客户**
- 情景:周五下午要求下周一交付
- 处理:评估可行性,加收 80% 加急费,降期望
- 结果:团队加班完成,客户满意

**案例 5:多方意见冲突**
- 情景:市场部要年轻化,老板要稳重
- 处理:要求指定单一决策人,制作两个版本对比
- 结果:老板拍板,市场部接受

**案例 6:不付尾款的客户**
- 情景:终版交付后客户拖延付款
- 处理: withheld 源文件,发律师函
- 结果:1 周内收到尾款

**案例 7:参考案例不一致**
- 情景:客户给的参考是电影级,预算是短视频级
- 处理:展示同等预算的真实案例,管理期望
- 结果:客户调整预期,项目顺利

**案例 8:跨部门协作混乱**
- 情景:对接人换了 3 次,需求反复
- 处理:要求客户方指定项目 owner,所有变更需 owner 确认
- 结果:沟通效率提升 50%

**案例 9:版权纠纷风险**
- 情景:客户要求用某流行歌曲
- 处理:说明版权风险,提供商用版权库替代
- 结果:避免法律风险,客户认可专业

**案例 10:长期合作客户**
- 情景:年度框架客户突然单方面压价
- 处理:回顾年度合作价值,提供阶梯报价
- 结果:维持合作关系,价格回归合理

**表达式示例：**
```javascript
// 弹性动画表达式
freq = 3;  // 频率
decay = 5; // 衰减
n = 0;
if (numKeys > 0) {
    n = nearestKey(time).index;
    if (key(n).time > time) n--;
}
if (n > 0) {
    t = time - key(n).time;
    amp = velocityAtTime(key(n).time - 0.001);
    omega = freq * 2 * Math.PI;
    value + amp * (Math.sin(omega * t) / (Math.exp(decay * t) * omega));
} else {
    value;
}
```

```
内部 QC → 客户预览 → 客户反馈 → 修改 → 终版确认 → 交付
```

**验收步骤：**
1. 制作方内部 QC（质量检查清单）
2. 上传审阅版到 Frame.io
3. 客户在线批注反馈
4. 制作方修改
5. 客户书面确认"验收通过"
6. 制作方交付正式版+源文件（收尾款后）
7. 双方签署验收确认书

### A. 三阶段宏观管线（速查）

| 阶段 | 时间占比 | 核心活动 |
|------|---------|---------|
| **前期制作** | 25-30% | Brief → 脚本 → 情绪板 → 风格帧 → 故事板 → 动态分镜 → 签收 |
| **制作** | 50-60% | 资产创建 → 动画 → 灯光 → VFX → 渲染 |
| **后期** | 15-20% | 合成 → 声音设计 → 调色 → 剪辑 → QC → 母版 → 交付 |

### B. 剪辑阶段流程（速查）

| 阶段 | 焦点 | 允许变更 |
|------|------|---------|
| **装配** | 排列素材、同步音频 | 一切可调整 |
| **粗剪** | 结构、流畅度、叙事连贯性 | 可大改 |
| **精剪** | 收紧节奏、精炼转场、选最佳条 | 仅微调 |
| **画面锁定** | 视觉内容绝对确定 | **不再变更画面** |
| **终剪** | 调色、混音、最终 VFX、字幕 | 仅收尾 |

| 中级 | $500/天 |

### E. 定价模型对比

| 模型 | 最佳场景 | 优点 | 缺点 |
|------|---------|------|------|
| **时薪/日薪** | 范围模糊、嵌入团队 | 范围变更=多收 | 效率惩罚收入 |
| **固定项目费** | 范围明确 | 客户确定性;效率有回报 | 范围蔓延杀利润 |
| **价值定价** | 高 ROI 项目 | 上限无限 | 需深度商业洞察 |
| **长期合约** | 持续工作 | 可预测收入 | 需清晰边界 |
| **混合（固定+超量时薪）** | **最常用** | 兼顾双方 | 需明确"边缘"定义 |

### F. 合同关键条款速查

1. **精确范围**:不是"社交媒体版本",而是"一个 15 秒 9:16 竖屏 H.264 MP4"
2. **明确排除项**:一行话挡住范围纠纷
3. **修改政策**:每阶段 2-3 轮
4. **变更单流程**:书面批准后方开工
5. **取消费**:已完成工作按标准费率全额结算 + 剩余合同价值 25-50%
6. **源文件**:**不包括**,除非明确列出;如购买,溢价项目费 50-100%+
7. **IP 转让**:**仅在全额付款后**转移
