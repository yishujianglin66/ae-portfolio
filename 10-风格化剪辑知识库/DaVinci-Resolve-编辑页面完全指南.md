# DaVinci Resolve 编辑页面完全指南

> 版本: 2025-v1 | 适用: 剪辑/媒体管理/交付

## 一、媒体页面(Media)

### 1.1 媒体池管理

| 功能 | 用途 | 操作 |
|------|------|------|
| 智能媒体夹 | 自动分类 | 规则自动整理 |
| 元数据 | 详细信息 | 添加自定义标签 |
| 代理生成 | 低分辨率代理 | 右键→生成代理 |
| 优化媒体 | 统一格式 | 转码为ProRes/DNxHR |

### 1.2 代理工作流

```
代理生成流程:
1. 选中素材→右键→生成代理媒体
2. 选择代理格式(ProRes Proxy/DNxHR LB)
3. 等待代理生成完成
4. 自动切换到代理模式
5. 剪辑完成后切换回原始素材输出

优势:
- 流畅剪辑4K/RAW素材
- 减少存储需求
- 适合笔记本剪辑
```

```
多机位工作流:
1. 选中多个素材→右键→创建多机位剪辑
2. 选择同步方式(时间码/音频/入点)
3. 拖入时间线
4. 启用多机位视图(四个图标)

高级技巧:
- 嵌套多机位(多层切换)
- 混合自动切换和手动切换
- 切换后微调
```

## 四、交付页面(Deliver)

### 4.1 导出设置

| 预设 | 格式 | 用途 |
|------|------|------|
| YouTube | H.264 4K/1080p | YouTube上传 |
| Vimeo | H.264 高质量 | Vimeo上传 |
| H.264 Master | 高码率 | 主文件 |
| DNxHR | DNxHR HQX | Avid协作 |
| ProRes | ProRes 422/4444 | 后期协作 |
| 音频仅 | MP3/WAV | 音频导出 |
| 自定义 | 任意格式 | 自定义设置 |

### 4.2 批量导出

```
批量导出流程:
1. 添加所有序列到渲染队列
2. 为每个序列设置导出预设
3. 选择输出位置
4. 点击"全部添加到渲染队列"
5. 开始渲染

渲染设置:
- 使用GPU加速
- 启用网络渲染(可选)
- 设置渲染优先级
```

## 五、协作工作流

### 5.1 多用户协作

```
协作模式:
1. 创建协作项目(服务器)
2. 邀请用户加入
3. 分配权限
4. 多用户同时编辑
5. 实时同步

注意:
- 需要Blackmagic服务器
- 或Cloud协作订阅
- 同一时间线不能多人编辑
```

### 5.2 项目归档

```
归档项目:
1. 文件→导出项目归档
2. 包含: 素材/时间线/设置
3. 压缩为单一文件
4. 传输到其他系统

导入归档:
1. 文件→导入项目归档
2. 解压到指定位置
3. 恢复所有素材和设置
```

## 六、脚本自动化

### 6.1 Python脚本

```python
# resolve_script.py
from pythonapi import resolve

# 获取当前项目
project = resolve.GetProjectManager().GetCurrentProject()

# 获取时间线
timeline = project.GetCurrentTimeline()

# 获取轨道数量
track_count = timeline.GetTrackCount("video")
print(f"视频轨道数: {track_count}")

# 批量导出
for i in range(1, 10):
    timeline = project.GetTimelineByIndex(i)
    if timeline:
        # 添加到渲染队列
        project.AddRenderJob({
            "TimelineIndex": i,
            "TargetDir": "/exports/",
            "CustomName": timeline.GetName()
        })
```
