## 二、AR素材准备

### 2.1 AR尺寸规范

| 平台 | 格式 | 尺寸 | 用途 |
|------|------|------|------|
| Spark AR | PNG序列 | 512x512 | 滤镜 |
| Lens Studio | PNG序列 | 1024x1024 | Snapchat |
| Reality Composer | USDZ | - | iOS AR |
| WebAR | GLTF/GLB | - | 网页AR |

### 2.2 纹理准备

```
AR纹理规范:
1. 尺寸: 512x512 或 1024x1024(2的幂)
2. 格式: PNG(支持透明)
3. 色彩空间: sRGB
4. 命名规范: texture_name_diffuse.png

贴图类型:
- Diffuse(漫反射): 基础颜色
- Normal(法线): 表面细节
- Metallic(金属): 金属度
- Roughness(粗糙): 粗糙度
- AO(环境遮蔽): 阴影细节
```

## 三、VR全景

### 3.1 全景格式

| 格式 | 比例 | 说明 |
|------|------|------|
| 等距柱状投影 | 2:1 | 标准全景 |
| 立方体面 | 6面 | 高质量 |
| 小行星 | 1:1 | 创意效果 |

### 3.2 全景编辑

```
全景编辑流程:
1. 打开全景图(2:1比例)
2. 3D→球形全景
3. 进入全景编辑模式
4. 绘制/修改内容
5. 注意接缝处理
6. 导出为等距柱状投影

注意事项:
- 左右边缘是连续的(360度)
- 顶部和底部是极点
- 避免在极点放置重要内容
```

## 四、3D文字与对象

### 4.1 3D文字

```
创建3D文字:
1. 输入文字
2. 3D→从所选图层新建3D挤出
3. 调整挤出深度
4. 设置材质属性
5. 添加灯光
6. 渲染

3D文字效果:
- 金属字: 金属材质+环境光遮蔽
- 玻璃字: 透明材质+折射
- 霓虹字: 自发光材质+光晕
```

## 五、导出与集成

### 5.1 3D导出

| 格式 | 用途 | 说明 |
|------|------|------|
| OBJ | 通用3D | 最兼容 |
| GLTF | Web 3D | 网页使用 |
| USDZ | iOS AR | Apple生态 |
| STL | 3D打印 | 实体输出 |

### 5.2 与AE集成

```
PS→AE 3D工作流:
1. PS中创建3D对象/材质
2. 导出为PSD(保留3D图层)
3. AE中导入PSD
4. AE 3D管道中处理
5. 添加动画/效果

注意:
- AE支持PSD 3D图层
- 可继续编辑材质
- 可添加AE动画
```
