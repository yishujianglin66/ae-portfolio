# Bridge 高级工作流与自动化完全指南

> 版本: 2025-v1 | 适用: 高级筛选/批量处理/自动化工作流

## 一、高级筛选

### 1.1 筛选条件

| 条件 | 说明 | 示例 |
|------|------|------|
| 评级 | 星级筛选 | 1-5星 |
| 标签 | 颜色标签 | 红/黄/绿/蓝/紫 |
| 关键字 | 关键词搜索 | 自定义标签 |
| 元数据 | EXIF/IPTC | 相机/镜头/日期 |
| 文件名 | 名称匹配 | 通配符 |
| 文件类型 | 格式筛选 | RAW/JPEG/PSD |
| 尺寸 | 分辨率筛选 | 宽度/高度 |
| 颜色空间 | 色彩模式 | RGB/CMYK |

### 1.2 智能集合

```
创建智能集合:
1. 筛选面板→新建智能集合
2. 设置条件:
   - 评级 ≥ 4星
   - AND 标签 = 红色
   - AND 日期 = 本月
3. 自动更新
4. 保存集合

应用场景:
- 自动收集待处理素材
- 按项目自动分类
- 按日期归档
```

## 二、批量处理

### 2.1 批量重命名

```
批量重命名:
1. 选中多个文件
2. 工具→批量重命名
3. 设置命名规则:
   - 项目名称_日期_序号
   - {项目}_{YYYYMMDD}_{###}
4. 预览结果
5. 应用重命名

命名变量:
- {filename} 原文件名
- {date} 日期
- {###} 序号
- {extension} 扩展名
```

### 2.2 批量转换

```
批量转换:
1. 工具→Camera Raw
2. 选中多个RAW文件
3. 调整一张→同步设置到其他
4. 导出为JPEG/TIFF/DNG

批量导出:
1. 文件→导出到
2. 选择格式/质量/尺寸
3. 设置输出位置
4. 批量导出
```

## 三、自动化

### 3.1 动作批处理

```
配合Photoshop动作:
1. Bridge选中文件
2. 工具→Photoshop→批处理
3. 选择动作
4. 应用到所有文件
5. 自动处理

应用场景:
- 批量应用调色
- 批量添加水印
- 批量调整尺寸
- 批量格式转换
```

### 3.2 脚本自动化

```javascript
// Bridge脚本示例
// 批量添加关键字
var items = app.document.selections;
for (var i = 0; i < items.length; i++) {
    var md = items[i].metadata;
    md.namespace = "http://ns.adobe.com/xap/1.0/";
    md["dc:subject"] = ["landscape", "nature", "2024"];
}

// 批量评级
for (var i = 0; i < items.length; i++) {
    items[i].thumbnail.rating = 5;
}
```

## 四、元数据管理

### 4.1 IPTC元数据

| 字段 | 用途 | 示例 |
|------|------|------|
| 标题 | 作品名称 | 日落风景 |
| 描述 | 作品说明 | 拍摄于海边 |
| 关键字 | 搜索标签 | 风景/日落/海 |
| 创作者 | 作者姓名 | 张三 |
| 版权 | 版权信息 | ©2024 |
| 位置 | 拍摄地点 | 青岛 |

### 4.2 元数据模板

```
创建元数据模板:
1. 编辑→首选项→元数据
2. 创建新模板
3. 设置默认值:
   - 版权信息
   - 联系方式
   - 默认关键字
4. 保存模板
5. 批量应用
```

## 五、与其他软件集成

### 5.1 Adobe生态集成

| 软件 | 集成方式 | 用途 |
|------|---------|------|
| Photoshop | 右键→在PS中打开 | 精细编辑 |
| Lightroom | 右键→在LR中编辑 | 调色 |
| Premiere Pro | 右键→在PR中导入 | 视频剪辑 |
| After Effects | 右键→替换为AE合成 | 特效 |
| Camera Raw | 自动打开RAW | RAW处理 |

### 5.2 工作流示例

```
摄影后期工作流:
1. Bridge导入素材
2. 筛选→评级→关键字
3. Camera Raw处理RAW
4. Photoshop精细修图
5. Bridge导出最终文件
6. 归档原始文件
```
