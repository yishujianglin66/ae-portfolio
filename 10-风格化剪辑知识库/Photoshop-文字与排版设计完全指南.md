# Photoshop 文字与排版设计完全指南

> 版本: 2025-v1 | 适用: 排版设计/文字特效/海报设计

## 一、文字工具

### 1.1 文字类型

| 类型 | 特性 | 用途 |
|------|------|------|
| 点文字 | 单行/点击创建 | 标题/短文本 |
| 段落文字 | 文本框/自动换行 | 正文/多行文本 |
| 路径文字 | 沿路径排列 | 弧形文字/圆形文字 |
| 变形文字 | 自由变形 | 创意排版 |

### 1.2 文字属性

| 属性 | 范围 | 说明 |
|------|------|------|
| 字体 | 系统字体 | 选择字体族 |
| 字重 | Thin-Black | 粗细 |
| 大小 | 0.1-1296pt | 字号 |
| 行距 | 自动/手动 | 行间距 |
| 字距 | -1000~+10000 | 字间距 |
| 字间距微调 | -50~+200 | 整体间距 |
| 对齐 | 左/中/右/两端 | 对齐方式 |

## 二、排版原则

### 2.1 字体搭配

| 组合 | 标题 | 正文 | 风格 |
|------|------|------|------|
| 经典 | Serif(衬线) | Sans-serif(无衬线) | 传统/专业 |
| 现代 | Sans-serif | Sans-serif(不同字重) | 简洁/现代 |
| 对比 | Display(展示体) | Body(正文字体) | 戏剧性 |
| 统一 | 同一字体族不同字重 | 同族Regular | 和谐 |

### 2.2 排版层级

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| H1 | 48-72pt | Bold/Black | 主标题 |
| H2 | 32-48pt | Bold | 副标题 |
| H3 | 24-32pt | SemiBold | 小节标题 |
| Body | 12-16pt | Regular | 正文 |
| Caption | 10-12pt | Light/Regular | 注释 |

### 2.3 排版网格

```
常用网格系统:
- 12列网格: 最灵活,适合杂志/海报
- 8列网格: 简洁,适合网页
- 6列网格: 对称,适合画册

边距(Margin): 页面边缘留白
间距(Gutter): 列与列之间距
基线网格(Baseline Grid): 文字对齐基准线
```

## 三、文字特效

### 3.1 图层样式文字效果

| 效果 | 关键样式 | 步骤 |
|------|---------|------|
| 金属文字 | 斜面浮雕+渐变叠加+外发光 | 立体+金属色+光晕 |
| 霓虹灯 | 外发光(多层)+内发光 | 发光+颜色 |
| 3D文字 | 斜面浮雕(深度)+投影 | 立体感 |
| 火焰文字 | 外发光(橙红)+变形 | 火焰形状 |
| 冰冻文字 | 斜面浮雕+内发光(蓝) | 冰晶感 |
| 溶解文字 | 图层样式→混合选项→溶解 | 颗粒消散 |
| 描边文字 | 描边+无填充 | 空心字 |
| 渐变文字 | 渐变叠加 | 多彩文字 |

### 3.2 变形文字

```
路径文字:
1. 钢笔工具创建路径
2. 文字工具→点击路径
3. 输入文字(自动沿路径)
4. 调整路径形状改变文字排列

透视文字:
1. 创建文字图层
2. 转换为智能对象
3. 编辑→变换→透视/扭曲
4. 匹配场景透视
```

## 五、自动化排版

### 5.1 数据驱动排版

```
变量数据排版:
1. 创建PSD模板(使用变量占位)
2. 准备CSV数据文件
3. 变量面板→导入数据
4. 文件→导出→数据组作为文件
5. 批量生成个性化图片

应用场景:
- 名片批量生成
- 证书批量制作
- 社交媒体模板批量出图
```

### 5.2 ExtendScript文字操作

```javascript
// create_text.jsx
var doc = app.activeDocument;
var textLayer = doc.artLayers.add();
textLayer.kind = LayerKind.TEXT;
var textItem = textLayer.textItem;
textItem.contents = "Hello World";
textItem.font = "ArialMT";
textItem.size = 72;
textItem.color = makeColor(255, 0, 0);
textItem.position = [100, 200];
```
