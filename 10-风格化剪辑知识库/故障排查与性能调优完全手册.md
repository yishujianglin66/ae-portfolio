## 第1章 故障排查总览

### 1.1 故障分类体系

在 AI 辅助视频生成系统中，故障可以按照发生层级和影响范围分为六大类。理解故障分类是高效排查的第一步。

| 故障类别 | 发生层级 | 典型表现 | 影响范围 |
|---------|---------|---------|---------|
| **环境故障** | 操作系统 / Python 环境 | 程序无法启动、依赖安装失败、DLL 加载错误 | 全局 - 所有功能不可用 |
| **依赖故障** | 第三方库 / 插件 | 特定功能报错、模块导入失败、版本冲突 | 模块级 - 部分功能失效 |
| **数据故障** | 输入数据 / 中间结果 | 分析结果异常、文件加载失败、格式不兼容 | 任务级 - 单个任务失败 |
| **算法故障** | 核心算法逻辑 | 结果质量差、匹配不合理、检测不准 | 质量级 - 输出不符合预期 |
| **性能故障** | 资源利用 / 执行效率 | 处理速度慢、内存溢出、响应超时 | 效率级 - 功能可用但缓慢 |
| **AE执行故障** | After Effects 执行层 | 脚本执行失败、效果添加错误、AE 崩溃 | 输出级 - 最终合成失败 |

> [!warning] 故障演化链
> 故障往往不是孤立存在的，它们可能沿着依赖链演化。例如：
> **环境故障 → 依赖故障 → 数据故障 → 算法故障 → 性能故障 → AE执行故障**
>
> 排查时应从底层开始验证，逐层向上排除。

### 1.2 排查方法论

#### 1.2.1 分层排查法

分层排查法是最基础也最可靠的排查策略，遵循从底到上的顺序：

```
┌─────────────────────────────────────┐
│     第6层：AE 执行层验证             │  验证脚本是否能在AE中正常执行
├─────────────────────────────────────┤
│     第5层：编译器层验证              │  验证生成的JSX脚本是否正确
├─────────────────────────────────────┤
│     第4层：算法层验证                │  验证音画匹配/分析算法输出
├─────────────────────────────────────┤
│     第3层：数据层验证                │  验证输入数据和中间结果格式
├─────────────────────────────────────┤
│     第2层：依赖层验证                │  验证所有Python依赖和AE插件
├─────────────────────────────────────┤
│     第1层：环境层验证                │  验证Python、CUDA、AE基础环境
└─────────────────────────────────────┘
```

**排查步骤**：
1. 从第1层开始，确认基础环境正常
2. 逐层向上验证，每层运行对应的诊断脚本
3. 发现问题所在层后，在该层内深入排查
4. 修复后重新从该层开始验证，确保所有上层功能正常

#### 1.2.2 二分法定位

当故障范围不明确时，使用二分法快速缩小范围：

**适用场景**：
- 大型项目中不知道哪个模块出了问题
- 长流程中不知道在哪一步失败
- 版本迭代后出现回归bug

**操作步骤**：
1. 确定完整流程的起点和终点
2. 在中间位置设置检查点，验证中间结果
3. 根据中间结果正常与否，排除一半的范围
4. 在剩余范围内继续二分，直到定位到具体问题

#### 1.2.3 控制变量法

当怀疑多个因素共同导致问题时，使用控制变量法逐一验证：

**操作原则**：
- 每次只改变一个变量
- 其他条件保持完全一致
- 记录每次变化的结果
- 对比分析确定因果关系

**常见变量维度**：
- 输入文件（换一个素材测试）
- 软件版本（降级/升级特定组件）
- 配置参数（使用默认配置）
- 运行环境（换一台机器测试）
- 执行路径（绕过某个中间模块）

> [!example] 实战案例
> **问题**：音画匹配结果质量不稳定
> **排查过程**：
> 1. 保持音乐不变，更换视频素材 → 问题依旧 → 排除视频因素
> 2. 保持视频不变，更换音乐文件 → 问题消失 → 定位到音乐分析
> 3. 保持音乐不变，更换BPM检测算法 → 结果改善 → 定位到BPM检测模块
> 4. 最终发现：特定BPM范围的音乐检测精度不足

### 1.3 日志系统与错误收集

#### 1.3.1 日志层级定义

系统采用五级日志体系，不同级别对应不同的严重程度和处理策略：

| 日志级别 | 标识颜色 | 含义 | 触发动作 |
|---------|---------|------|---------|
| **DEBUG** | 灰色 | 详细调试信息 | 开发调试时查看 |
| **INFO** | 蓝色 | 正常运行信息 | 常规监控 |
| **WARNING** | 黄色 | 警告，功能可用但可能有问题 | 记录并关注 |
| **ERROR** | 红色 | 错误，部分功能失效 | 报警，需排查 |
| **CRITICAL** | 紫红色 | 严重错误，系统无法运行 | 立即处理 |

#### 1.3.2 日志位置

Windows 环境下各模块日志位置：

```
# Python 服务日志
%APPDATA%\AE-AI-Video\logs\

# MCP 服务日志
%APPDATA%\MCP\logs\

# AE 脚本日志
%APPDATA%\Adobe\After Effects\25.0\logs\

# 编译器日志
./compiler/logs/

# 桥接层日志
./bridge/logs/
```

#### 1.3.3 错误收集规范

每个错误报告应包含以下信息，便于快速定位和复现：

1. **基本信息**
   - 错误发生时间
   - 系统版本（Windows 版本号）
   - AE 版本（2025.x.x）
   - Python 版本
   - 软件版本号

2. **错误描述**
   - 错误现象（看到了什么）
   - 预期行为（应该发生什么）
   - 复现步骤（如何再次触发）
   - 发生频率（每次 / 偶尔 / 特定条件）

3. **环境信息**
   - CPU / GPU / 内存配置
   - 磁盘剩余空间
   - 网络状态

4. **日志附件**
   - 相关日志文件
   - 截图 / 录屏
   - 输入文件样本

### 1.4 故障分级标准

根据故障的影响范围和严重程度，将故障分为四个等级：

#### P0 - 阻断级（Critical）
**定义**：系统核心功能完全不可用，业务无法进行

**典型场景**：
- 系统无法启动
- 所有任务都失败
- AE 持续崩溃无法打开
- 数据丢失或损坏

**响应要求**：
- 响应时间：立即（15分钟内）
- 处理优先级：最高
- 通知范围：全体技术团队

#### P1 - 严重级（High）
**定义**：核心功能严重受损，主要业务流程无法正常完成

**典型场景**：
- 音画匹配完全失效
- 视频分析全部报错
- MCP 连接断开无法恢复
- 关键功能模块崩溃

**响应要求**：
- 响应时间：2小时内
- 处理优先级：高
- 通知范围：相关模块负责人

#### P2 - 一般级（Medium）
**定义**：非核心功能故障，或核心功能有可用替代方案

**典型场景**：
- 某个特效参数设置不正确
- 分析精度略有下降
- 非关键功能报错
- 性能明显下降但仍可使用

**响应要求**：
- 响应时间：1个工作日内
- 处理优先级：中
- 通知范围：对应开发人员

#### P3 - 轻微级（Low）
**定义**：轻微问题，不影响功能使用，仅影响体验或美观

**典型场景**：
- UI 显示小问题
- 日志中有警告但不影响功能
- 文档描述不准确
- 性能轻微波动

**响应要求**：
- 响应时间：下一个版本修复
- 处理优先级：低
- 通知范围：记录在案

## 第2章 Python 环境故障

### 2.1 安装失败问题

#### 2.1.1 pip install 报错

**症状**：
```
ERROR: Could not find a version that satisfies the requirement xxx
ERROR: No matching distribution found for xxx
```

**原因分析**：
1. **包名错误**：拼写错误或包已更名
2. **Python 版本不兼容**：包不支持当前 Python 版本
3. **网络问题**：无法连接到 PyPI
4. **操作系统不兼容**：包没有 Windows 版本
5. **pip 版本过旧**：旧版 pip 不支持新的包格式

**解决方案**：

```bash
# 1. 升级 pip 到最新版本
python -m pip install --upgrade pip

# 2. 使用国内镜像源（推荐清华大学镜像）
pip install package-name -i https://pypi.tuna.tsinghua.edu.cn/simple

# 3. 指定版本号安装
pip install package-name==1.2.3

# 4. 检查包名是否正确（搜索包）
pip search package-name

# 5. 安装预编译版本（针对需要编译的包）
pip install --only-binary :all: package-name
```

**预防措施**：
- 始终使用虚拟环境，避免污染系统 Python
- 固定依赖版本，使用 `requirements.txt`
- 配置永久镜像源

> [!tip] 配置永久镜像源
> ```bash
> # 创建 pip 配置目录
> mkdir %APPDATA%\pip
> 
> # 创建配置文件
> echo [global] > %APPDATA%\pip\pip.ini
> echo index-url = https://pypi.tuna.tsinghua.edu.cn/simple >> %APPDATA%\pip\pip.ini
> echo trusted-host = pypi.tuna.tsinghua.edu.cn >> %APPDATA%\pip\pip.ini
> ```

#### 2.1.2 权限问题

**症状**：
```
PermissionError: [WinError 5] 拒绝访问。
ERROR: Could not install packages due to an OSError: [WinError 5] Access is denied
```

**原因分析**：
1. 安装到系统 Python 目录需要管理员权限
2. 文件被其他程序占用
3. 杀毒软件阻止了写入操作
4. 用户目录权限设置异常

**解决方案**：

```bash
# 方案1：使用 --user 选项安装到用户目录（推荐）
pip install package-name --user

# 方案2：以管理员身份运行命令提示符
# 右键命令提示符 → 以管理员身份运行

# 方案3：使用虚拟环境（最佳实践）
python -m venv myenv
myenv\Scripts\activate
pip install package-name

# 方案4：关闭占用程序后重试
# 使用任务管理器关闭相关进程
```

**预防措施**：
- 始终使用虚拟环境开发
- 不要直接修改系统 Python 环境
- 定期检查用户目录权限

#### 2.1.3 网络问题

**症状**：
```
pip._vendor.urllib3.exceptions.ReadTimeoutError: HTTPSConnectionPool(host='pypi.org', port=443): Read timed out
```

**原因分析**：
1. 网络连接不稳定
2. 防火墙阻止了连接
3. PyPI 服务器访问慢
4. 代理设置问题

**解决方案**：

```bash
# 1. 使用国内镜像源
pip install package-name -i https://pypi.tuna.tsinghua.edu.cn/simple

# 2. 增加超时时间
pip install package-name --timeout 120

# 3. 配置代理
pip install package-name --proxy http://proxy-server:port

# 4. 离线安装（先下载whl文件）
pip download package-name -d ./packages
pip install package-name --no-index --find-links ./packages
```

### 2.2 版本冲突问题

#### 2.2.1 numpy / scipy / librosa 版本不兼容

**症状**：
```
ImportError: numpy.core.multiarray failed to import
RuntimeError: module compiled against API version 0x10 but this version of numpy is 0xf
```

**原因分析**：
- 不同包依赖的 numpy 版本不一致
- 先安装了高版本 numpy，后安装依赖低版本的包
- scipy 与 numpy 版本不匹配
- librosa 依赖的 numba 与 numpy 版本冲突

**解决方案**：

```bash
# 1. 检查当前版本
pip list | findstr "numpy scipy librosa numba"

# 2. 卸载冲突的包
pip uninstall numpy scipy librosa numba -y

# 3. 按正确顺序安装（先装numpy，再装scipy，最后装librosa）
pip install numpy==1.24.3
pip install scipy==1.10.1
pip install librosa==0.10.1

# 4. 使用 pip check 验证
pip check
```

**推荐版本组合（Windows + Python 3.10）**：

| 包名 | 推荐版本 | 说明 |
|------|---------|------|
| numpy | 1.24.3 | 兼容性最好的版本 |
| scipy | 1.10.1 | 与 numpy 1.24.x 兼容 |
| librosa | 0.10.1 | 最新稳定版 |
| numba | 0.57.1 | librosa 依赖，与 numpy 1.24 兼容 |
| soundfile | 0.12.1 | 音频文件读写 |

> [!warning] 版本兼容性警告
> - numpy 1.25+ 可能与部分旧版 scipy 不兼容
> - Python 3.11 可能存在更多兼容性问题，推荐使用 3.10
> - 安装时严格按照依赖顺序，避免自动升级依赖

#### 2.2.2 通用版本冲突排查

**诊断步骤**：

```bash
# 1. 检查所有已安装包
pip list

# 2. 检查依赖冲突
pip check

# 3. 查看某个包的依赖
pip show package-name

# 4. 生成依赖树（需要 pipdeptree）
pip install pipdeptree
pipdeptree

# 5. 查看包的所有可用版本
pip index versions package-name
```

**解决策略**：
1. **降级法**：将高版本包降级到兼容版本
2. **升级法**：将低版本包升级到兼容版本
3. **替换法**：寻找功能相同但兼容性更好的替代包
4. **隔离法**：使用虚拟环境隔离不同项目的依赖

### 2.3 DLL 加载失败

#### 2.3.1 常见 DLL 错误

**症状**：
```
ImportError: DLL load failed while importing _xxx: 找不到指定的模块。
OSError: [WinError 126] 找不到指定的模块
```

**常见原因**：
1. **缺少 Visual C++ Redistributable**：很多 Python 包依赖 C++ 运行库
2. **缺少 FFmpeg**：音频视频处理相关包依赖

### 3.2 BPM 检测不准

#### 3.2.1 低速音乐检测不准

**问题描述**：
- BPM 低于 60 的慢速音乐（如古典音乐、氛围音乐）
- 检测结果可能是实际 BPM 的 2 倍（倍频错误）

**原因分析**：
- 节拍检测算法对低频瞬态敏感度低
- 慢速音乐的节拍间隔大，容易被误判为半速
- 没有明显的鼓点或打击乐

**解决方案**：

```python
import librosa
import numpy as np

def detect_bpm_slow(y, sr):
    """针对慢速音乐的 BPM 检测优化"""
    
    # 方法1: 调整 BPM 搜索范围
    tempo, beat_frames = librosa.beat.beat_track(
        y=y, sr=sr,
        start_bpm=50,        # 降低起始 BPM
        tightness=100,       # 增加紧密度
        trim=True,
        bpm_range=[40, 120]  # 限制搜索范围
    )
    
    # 方法2: 使用 onset envelope 手动检测
    onset_env = librosa.onset.onset_strength(y=y, sr=sr)
    
    # 尝试不同的 BPM 范围
    bpms = []
    for bpm_min, bpm_max in [(40, 80), (80, 160), (160, 240)]:
        t, _ = librosa.beat.beat_track(
            onset_envelope=onset_env,
            sr=sr,
            bpm_range=[bpm_min, bpm_max]
        )
        bpms.append(t)
    
    # 选择最合理的（通常选择中间范围或根据音乐特征判断）
    return bpms


def verify_bpm(tempo, beat_frames, sr):
    """验证 BPM 检测结果的合理性"""
    if len(beat_frames) < 2:
        return False
    
    # 计算节拍间隔的标准差
    beat_times = librosa.frames_to_time(beat_frames, sr=sr)
    intervals = np.diff(beat_times)
    
    if len(intervals) == 0:
        return False
    
    mean_interval = np.mean(intervals)
    std_interval = np.std(intervals)
    
    # 变异系数（标准差/均值）
    cv = std_interval / mean_interval if mean_interval > 0 else float('inf')
    
    # 变异系数越小，节拍越稳定
    return cv < 0.3  # 阈值可调整
```

#### 3.2.2 变速音乐检测不准

**问题描述**：
- 音乐有 tempo 变化（渐快/渐慢）
- 电子音乐中的 drop 部分速度变化
- 现场演奏的速度波动

**解决方案**：

```python
def detect_bpm_dynamic(y, sr, window_size=30, hop_size=10):
    """动态 BPM 检测，分段计算"""
    
    duration = len(y) / sr
    bpms = []
    
    for start in range(0, int(duration - window_size), hop_size):
        end = start + window_size
        y_segment = y[start*sr:end*sr]
        
        if len(y_segment) < sr:  # 至少1秒
            continue
        
        tempo, _ = librosa.beat.beat_track(y=y_segment, sr=sr)
        bpms.append({
            'start': start,
            'end': end,
            'bpm': tempo
        })
    
    return bpms


def get_overall_bpm(bpm_segments):
    """从分段 BPM 计算整体 BPM"""
    if not bpm_segments:
        return 0
    
    bpms = [s['bpm'] for s in bpm_segments]
    
    # 使用中位数，减少异常值影响
    median_bpm = np.median(bpms)
    
    # 检查是否有明显的速度变化
    bpm_range = max(bpms) - min(bpms)
    
    return median_bpm, bpm_range
```

### 3.3 节拍点偏移

#### 3.3.1 相位问题

**问题描述**：
- 检测到的节拍点整体偏移（都提前或都滞后）
- 视觉上与音乐不对齐

**原因分析**：
- 攻击时间（attack time）的定义差异
- Onset 检测的阈值设置
- 不同频段的瞬态响应时间不同

**解决方案**：

```python
def correct_beat_phase(beat_frames, y, sr):
    """校正节拍点的相位偏移"""
    
    beat_times = librosa.frames_to_time(beat_frames, sr=sr)
    
    # 方法1: 找到每个节拍附近的真正瞬态点
    corrected_beats = []
    
    for beat_time in beat_times:
        # 在节拍点前后 50ms 范围内搜索最强瞬态
        search_start = max(0, int((beat_time - 0.05) * sr))
        search_end = min(len(y), int((beat_time + 0.05) * sr))
        
        if search_end <= search_start:
            corrected_beats.append(beat_time)
            continue
        
        # 计算能量包络
        segment = y[search_start:search_end]
        energy = np.abs(segment)
        
        # 找到能量峰值
        peak_offset = np.argmax(energy)
        corrected_time = search_start / sr + peak_offset / sr
        corrected_beats.append(corrected_time)
    
    return np.array(corrected_beats)


def adjust_beat_offset(beat_times, offset_ms):
    """手动调整节拍偏移量
    
    Args:
        beat_times: 节拍时间数组（秒）
        offset_ms: 偏移量（毫秒），正值表示延后，负值表示提前
    """
    return beat_times + offset_ms / 1000.0
```

def fill_missing_beats(beat_times, estimated_bpm):
    """补全缺失的节拍点"""
    
    if len(beat_times) < 2:
        return beat_times
    
    interval = 60.0 / estimated_bpm
    expected_count = int((beat_times[-1] - beat_times[0]) / interval) + 1
    
    # 创建预期的节拍点序列
    expected_beats = beat_times[0] + np.arange(expected_count) * interval
    
    # 合并检测到的和预期的
    # 对于检测到的节拍点，优先使用检测值
    filled = []
    detected_idx = 0
    
    for expected in expected_beats:
        if detected_idx < len(beat_times):
            # 如果检测到的节拍点在预期位置附近，使用检测值
            if abs(beat_times[detected_idx] - expected) < interval * 0.3:
                filled.append(beat_times[detected_idx])
                detected_idx += 1
            else:
                # 否则使用预期值
                filled.append(expected)
        else:
            filled.append(expected)
    
    return np.array(filled)
```

### 3.4 段落分割错误

#### 3.4.1 边界不准

**问题描述**：
- 段落（verse/chorus/bridge）的分割点不准确
- 把一个段落分成了两个
- 把两个段落合并成了一个

**解决方案**：

```python
def segment_audio_simple(y, sr):
    """简化但更稳定的段落分割"""
    
    # 计算音频特征
    tempo, beat_frames = librosa.beat.beat_track(y=y, sr=sr)
    beat_times = librosa.frames_to_time(beat_frames, sr=sr)
    
    # 方法1: 基于能量变化的分割
    # 计算每个节拍的能量
    beat_energy = []
    for i in range(len(beat_frames) - 1):
        start = beat_frames[i]
        end = beat_frames[i + 1]
        if end < len(y):
            energy = np.mean(np.abs(y[start:end]))
            beat_energy.append(energy)
    
    # 检测能量突变点
    if len(beat_energy) > 4:
        energy_smooth = np.convolve(
            beat_energy,
            np.ones(8) / 8,
            mode='same'
        )
        energy_diff = np.abs(np.diff(energy_smooth))
        
        # 找到能量变化大的点
        threshold = np.mean(energy_diff) + 2 * np.std(energy_diff)
        segment_boundaries = np.where(energy_diff > threshold)[0]
        
        # 转换为时间
        boundary_times = beat_times[segment_boundaries]
    else:
        boundary_times = []
    
    return boundary_times


def refine_boundaries(boundary_times, min_duration=10):
    """优化段落边界，合并过短的段落"""
    
    if len(boundary_times) < 2:
        return boundary_times
    
    refined = [boundary_times[0]]
    
    for i in range(1, len(boundary_times)):
        current = boundary_times[i]
        last = refined[-1]
        
        if current - last >= min_duration:
            refined.append(current)
        else:
            # 间隔太短，跳过这个边界
            pass
    
    return np.array(refined)
```

### 3.5 情绪识别偏差

#### 3.5.1 常见偏差类型

| 偏差类型 | 表现 | 原因 |
|---------|------|------|
| **效价偏差** | 快乐/悲伤判断反了 | 音色特征不典型 |
| **能量偏差** | 激昂/平静判断不准 | 音量影响判断 |
| **情绪混淆** | 难以区分相似情绪 | 特征空间重叠 |
| **文化差异** | 东西方音乐情绪差异 | 训练数据偏向西方 |

#### 3.5.2 改进策略

```python
def improved_emotion_detection(y, sr):
    """改进的情绪识别 - 多特征融合"""
    
    # 特征1: 节奏特征
    tempo, _ = librosa.beat.beat_track(y=y, sr=sr)
    onset_env = librosa.onset.onset_strength(y=y, sr=sr)
    rhythm_energy = np.mean(onset_env)
    
    # 特征2: 音高特征
    pitches, magnitudes = librosa.piptrack(y=y, sr=sr)
    pitch_mean = np.mean(pitches[magnitudes > 0.1 * np.max(magnitudes)])
    pitch_std = np.std(pitches[magnitudes > 0.1 * np.max(magnitudes)])
    
    # 特征3: 音色特征
    mfccs = librosa.feature.mfcc(y=y, sr=sr, n_mfcc=13)
    mfcc_mean = np.mean(mfccs, axis=1)
    
    # 特征4: 响度特征
    rms = librosa.feature.rms(y=y)[0]
    loudness_mean = np.mean(rms)
    loudness_std = np.std(rms)
    
    # 特征5: 调式特征（大调/小调）
    chroma = librosa.feature.chroma_cqt(y=y, sr=sr)
    chroma_mean = np.mean(chroma, axis=1)
    
    # 综合评分
    arousal = (
        0.3 * (tempo / 180.0) +
        0.3 * (rhythm_energy / (np.max(onset_env) + 1e-6)) +
        0.4 * (loudness_mean / (np.max(rms) + 1e-6))
    )
    
    valence = (
        0.4 * (pitch_mean / 1000.0) +
        0.3 * (1 - pitch_std / (pitch_mean + 1e-6)) +
        0.3 * np.mean(chroma_mean[[0, 2, 4, 5, 7, 9, 11]])  # 大调音阶
    )
    
    return {
        'arousal': min(1.0, max(0.0, arousal)),      # 能量值 0-1
        'valence': min(1.0, max(0.0, valence)),      # 效价 0-1
        'tempo': tempo,
        'loudness': loudness_mean,
    }
```

### 3.6 频谱分析异常

#### 3.6.1 常见异常现象

| 异常现象 | 可能原因 | 解决方法 |

```python
def check_spectrum_quality(y, sr):
    """检查频谱质量"""
    
    # 计算 STFT
    D = librosa.stft(y)
    S = np.abs(D)
    
    # 检查1: 总能量
    total_energy = np.sum(S)
    if total_energy < 1e-6:
        return False, "音频能量极低，可能是静音或损坏"
    
    # 检查2: 频率分布
    freq_energy = np.sum(S, axis=1)
    low_freq_ratio = np.sum(freq_energy[:len(freq_energy)//4]) / total_energy
    high_freq_ratio = np.sum(freq_energy[-len(freq_energy)//4:]) / total_energy
    
    if low_freq_ratio > 0.95:
        return False, "能量几乎全在低频，可能有问题"
    
    if high_freq_ratio < 0.01:
        return False, "高频能量极低，可能是低质量音频"
    
    # 检查3: 时间分布
    time_energy = np.sum(S, axis=0)
    if np.max(time_energy) / (np.mean(time_energy) + 1e-6) > 100:
        return False, "能量分布过于不均，可能有突变"
    
    return True, "频谱质量正常"
```

### 3.7 降级策略

当音频分析失败时，使用降级策略确保系统继续运行：

```python
def analyze_audio_with_fallback(file_path):
    """带降级策略的音频分析"""
    
    result = {
        'success': False,
        'method': 'none',
        'bpm': 120,
        'beat_times': [],
        'duration': 0,
        'error': None
    }
    
    # Level 1: 完整分析
    try:
        y, sr = librosa.load(file_path, sr=None)
        result['duration'] = len(y) / sr
        
        tempo, beat_frames = librosa.beat.beat_track(y=y, sr=sr)
        beat_times = librosa.frames_to_time(beat_frames, sr=sr)
        
        result['bpm'] = float(tempo)
        result['beat_times'] = beat_times.tolist()
        result['success'] = True
        result['method'] = 'full'
        
        return result
    except Exception as e:
        result['error'] = f"完整分析失败: {e}"
    
    # Level 2: 简化分析（使用较低采样率）
    try:
        y, sr = librosa.load(file_path, sr=22050, duration=300)  # 只分析前5分钟
        result['duration'] = len(y) / sr
        
        tempo, beat_frames = librosa.beat.beat_track(y=y, sr=sr)
        beat_times = librosa.frames_to_time(beat_frames, sr=sr)
        
        result['bpm'] = float(tempo)
        result['beat_times'] = beat_times.tolist()
        result['success'] = True
        result['method'] = 'simplified'
        
        return result
    except Exception as e:
        result['error'] += f"; 简化分析失败: {e}"
    
    # Level 3: 使用 FFmpeg 获取基本信息
    try:
        cmd = ['ffprobe', '-v', 'error', '-show_entries', 
               'format=duration', '-of', 'default=noprint_wrappers=1:nokey=1',
               file_path]
        result_ff = subprocess.run(cmd, capture_output=True, text=True,
                                  creationflags=subprocess.CREATE_NO_WINDOW)
        duration = float(result_ff.stdout.strip())
        result['duration'] = duration
        
        # 使用默认 BPM，生成均匀节拍
        default_bpm = 120
        beat_interval = 60.0 / default_bpm
        beat_times = np.arange(0, duration, beat_interval)
        
        result['bpm'] = default_bpm
        result['beat_times'] = beat_times.tolist()
        result['success'] = True
        result['method'] = 'fallback_default'
        
        return result
    except Exception as e:
        result['error'] += f"; 降级分析失败: {e}"
    
    # Level 4: 完全使用默认值
    result['bpm'] = 120
    result['duration'] = 180  # 默认3分钟
    result['beat_times'] = list(np.arange(0, 180, 0.5))
    result['method'] = 'fallback_all_default'
    result['success'] = True  # 功能可用，但质量下降
    
    return result
```

> [!important] 降级策略原则
> 1. **功能优先**：保证系统能继续运行，哪怕结果质量下降
> 2. **逐级降级**：从完整功能逐步降级，每一级都比上一级更快更简单
> 3. **信息透明**：明确告知用户当前使用的是降级模式
> 4. **可恢复性**：问题解决后能自动恢复到正常模式

### 4.2 光流计算报错

#### 4.2.1 尺寸不匹配

**症状**：
```
cv2.error: ... error: (-215:Assertion failed) prevImg.type() == nextImg.type() && prevImg.size() == nextImg.size()
```

**原因分析**：
- 视频尺寸在播放过程中变化（很少见）
- 手动裁剪后尺寸不一致
- 多视频拼接时尺寸不同

**解决方案**：

```python
def ensure_same_size(frame1, frame2, target_size=None):
    """确保两帧图像尺寸一致"""
    import cv2
    import numpy as np
    
    if target_size is None:
        h1, w1 = frame1.shape[:2]
        h2, w2 = frame2.shape[:2]
        target_h = min(h1, h2)
        target_w = min(w1, w2)
        target_size = (target_w, target_h)
    
    if frame1.shape[:2][::-1] != target_size:
        frame1 = cv2.resize(frame1, target_size)
    
    if frame2.shape[:2][::-1] != target_size:
        frame2 = cv2.resize(frame2, target_size)
    
    return frame1, frame2


def compute_optical_flow_safe(prev_frame, next_frame):
    """安全的光流计算，包含错误处理"""
    import cv2
    import numpy as np
    
    try:
        # 转换为灰度图
        if len(prev_frame.shape) == 3:
            prev_gray = cv2.cvtColor(prev_frame, cv2.COLOR_BGR2GRAY)
        else:
            prev_gray = prev_frame.copy()
        
        if len(next_frame.shape) == 3:
            next_gray = cv2.cvtColor(next_frame, cv2.COLOR_BGR2GRAY)
        else:
            next_gray = next_frame.copy()
        
        # 确保尺寸一致
        prev_gray, next_gray = ensure_same_size(prev_gray, next_gray)
        
        # 计算光流
        flow = cv2.calcOpticalFlowFarneback(
            prev_gray, next_gray, None,
            pyr_scale=0.5,
            levels=3,
            winsize=15,
            iterations=3,
            poly_n=5,
            poly_sigma=1.2,
            flags=0
        )
        
        return True, flow
        
    except Exception as e:
        # 返回零光流作为降级
        h, w = prev_gray.shape[:2]
        zero_flow = np.zeros((h, w, 2), dtype=np.float32)
        return False, zero_flow
```

#### 4.2.2 全黑帧 / 过曝帧

**问题描述**：
- 全黑帧导致光流计算全零
- 过曝帧（全白）导致特征点缺失
- 极端明暗变化导致光流异常

**检测与处理**：

```python
def is_problematic_frame(frame, threshold_dark=10, threshold_bright=245):
    """检测问题帧（全黑/全白/过曝）"""
    import numpy as np
    
    if frame is None or frame.size == 0:
        return True, "空帧"
    
    gray = frame if len(frame.shape) == 2 else cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    
    mean_val = np.mean(gray)
    std_val = np.std(gray)
    
    # 全黑检测
    if mean_val < threshold_dark and std_val < 5:
        return True, f"全黑帧 (均值={mean_val:.1f})"
    
    # 全白/过曝检测
    if mean_val > threshold_bright and std_val < 5:
        return True, f"过曝帧 (均值={mean_val:.1f})"
    
    # 低对比度检测
    if std_val < 10:
        return False, f"低对比度 (标准差={std_val:.1f})"  # 警告但不跳过
    
    return False, "正常"


def compute_motion_safe(video_path, sample_interval=10):
    """安全的运动强度计算，跳过问题帧"""
    import cv2
    import numpy as np
    
    cap = cv2.VideoCapture(video_path)
    if not cap.isOpened():
        return None
    
    motion_values = []
    prev_frame = None
    frame_idx = 0
    
    while True:
        ret, frame = cap.read()
        if not ret:
            break
        
        if frame_idx % sample_interval != 0:
            frame_idx += 1
            continue
        
        is_problem, reason = is_problematic_frame(frame)
        
        if is_problem:
            # 跳过问题帧，使用上一个有效值或零
            if motion_values:
                motion_values.append(motion_values[-1])
            else:
                motion_values.append(0.0)
            prev_frame = None  # 重置前一帧
            frame_idx += 1
            continue
        
        if prev_frame is not None:
            # 确保尺寸一致
            frame_resized = cv2.resize(frame, (prev_frame.shape[1], prev_frame.shape[0]))
            
            # 计算帧差
            diff = cv2.absdiff(prev_frame, frame_resized)
            motion = np.mean(diff)
            motion_values.append(motion)
        else:
            motion_values.append(0.0)
        
        prev_frame = frame.copy()
        frame_idx += 1
    
    cap.release()
    return np.array(motion_values)
```

### 4.3 颜色分析偏差

#### 4.3.1 色彩空间问题

**常见问题**：
- OpenCV 默认 BGR，其他库用 RGB
- HSV 范围定义不一致
- YUV / YCbCr 转换公式差异
- 伽马校正（Gamma）问题

**解决方案**：

```python
def safe_color_analysis(frame):
    """安全的颜色分析，处理各种色彩空间问题"""
    import cv2
    import numpy as np
    
    if frame is None:
        return None
    
    # 确保是 BGR 格式（OpenCV 默认）
    if len(frame.shape) == 2:
        frame = cv2.cvtColor(frame, cv2.COLOR_GRAY2BGR)
    
    # 转换为 RGB
    frame_rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
    
    # 转换为 HSV（注意 OpenCV 的 H 范围是 0-179）
    frame_hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
    
    # 计算主色调
    h_channel = frame_hsv[:, :, 0]
    s_channel = frame_hsv[:, :, 1]
    v_channel = frame_hsv[:, :, 2]
    
    # 只考虑饱和度足够的像素
    valid_pixels = s_channel > 30  # 饱和度阈值
    
    if np.any(valid_pixels):
        # 计算有效像素的平均色调
        # 注意：因为色调是环形的（0和179接近），需要特殊处理
        h_valid = h_channel[valid_pixels]
        # 转换为弧度计算圆周平均
        h_rad = h_valid * 2 * np.pi / 180.0
        mean_sin = np.mean(np.sin(h_rad))
        mean_cos = np.mean(np.cos(h_rad))
        mean_hue = np.arctan2(mean_sin, mean_cos) * 180.0 / (2 * np.pi)
        if mean_hue < 0:
            mean_hue += 180  # OpenCV H 范围 0-179
    else:
        mean_hue = 0  # 灰度图像
    
    # 计算平均亮度
    mean_brightness = np.mean(v_channel) / 255.0
    
    # 计算平均饱和度
    mean_saturation = np.mean(s_channel) / 255.0
    
    return {
        'mean_hue': mean_hue,
        'mean_saturation': mean_saturation,
        'mean_brightness': mean_brightness,
        'dominant_colors': get_dominant_colors(frame_rgb),
        'contrast': np.std(v_channel) / 255.0
    }


def get_dominant_colors(frame_rgb, k=5):
    """使用 K-Means 获取主导色"""
    import numpy as np
    from sklearn.cluster import KMeans
    
    pixels = frame_rgb.reshape(-1, 3)
    
    # 采样以加速
    if len(pixels) > 10000:
        indices = np.random.choice(len(pixels), 10000, replace=False)
        pixels_sample = pixels[indices]
    else:
        pixels_sample = pixels
    
    try:
        kmeans = KMeans(n_clusters=k, n_init=10, random_state=42)
        kmeans.fit(pixels_sample)
        
        colors = kmeans.cluster_centers_.astype(int)
        # 计算各颜色占比
        labels = kmeans.predict(pixels)
        counts = np.bincount(labels, minlength=k)
        ratios = counts / len(labels)
        
        # 按占比排序
        sorted_idx = np.argsort(ratios)[::-1]
        
        return [
            {
                'color': colors[i].tolist(),
                'ratio': float(ratios[i])
            }
            for i in sorted_idx
        ]
    except Exception:
        # 降级：返回平均色
        avg_color = np.mean(pixels_sample, axis=0).astype(int).tolist()
        return [{'color': avg_color, 'ratio': 1.0}]
```

### 4.4 场景检测失败

#### 4.4.1 渐变 / 淡入淡出误判

**问题描述**：
- 淡入淡出被误判为多个场景切换
- 渐变过渡被分割成多个片段
- 闪白/闪黑帧导致误检测

**解决方案**：

```python
def detect_scenes_robust(video_path, threshold=30.0, min_scene_length=1.0):
    """鲁棒的场景检测，处理渐变和闪白"""
    import cv2
    import numpy as np
    
    cap = cv2.VideoCapture(video_path)
    if not cap.isOpened():
        return []
    
    fps = cap.get(cv2.CAP_PROP_FPS)
    min_frames = int(min_scene_length * fps)
    
    prev_frame = None
    frame_idx = 0
    diffs = []
    scene_changes = []
    
    while True:
        ret, frame = cap.read()
        if not ret:
            break
        
        # 缩小尺寸加速计算
        frame_small = cv2.resize(frame, (320, 180))
        gray = cv2.cvtColor(frame_small, cv2.COLOR_BGR2GRAY)
        
        if prev_frame is not None:
            # 计算帧差
            diff = cv2.absdiff(prev_frame, gray)
            mean_diff = np.mean(diff)
            diffs.append(mean_diff)
            
            # 检测突变（不是渐变）
            if len(diffs) >= 3:
                # 当前帧差远大于前两帧的平均 → 突变
                recent_avg = np.mean(diffs[-3:-1])
                if mean_diff > threshold and mean_diff > recent_avg * 2:
                    # 检查是否为闪白/闪黑
                    is_flash = is_flash_frame(gray, prev_frame)
                    if not is_flash:
                        scene_changes.append(frame_idx)
        
        prev_frame = gray
        frame_idx += 1
    
    cap.release()
    
    # 合并过近的场景切换
    filtered_changes = []
    last_change = -min_frames
    
    for change in scene_changes:
        if change - last_change >= min_frames:
            filtered_changes.append(change)
            last_change = change
    
    # 转换为时间
    scene_times = [f / fps for f in filtered_changes]
    
    return scene_times


def is_flash_frame(current_gray, prev_gray):
    """检测是否为闪白/闪黑帧"""
    import numpy as np
    
    mean_current = np.mean(current_gray)
    mean_prev = np.mean(prev_gray)
    
    diff = abs(mean_current - mean_prev)
    
    # 闪白：突然变亮很多
    if mean_current > 240 and diff > 100:
        return True
    
    # 闪黑：突然变暗很多
    if mean_current < 15 and diff > 100:
        return True
    
    return False
```

def process_video_sampled(video_path, analysis_func, target_fps=2.0, max_resolution=(640, 360)):
    """采样处理视频，大幅提升速度
    
    Args:
        video_path: 视频路径
        analysis_func: 分析函数，接收单帧返回结果
        target_fps: 目标采样帧率
        max_resolution: 最大处理分辨率
    """
    import cv2
    
    cap = cv2.VideoCapture(video_path)
    if not cap.isOpened():
        return []
    
    original_fps = cap.get(cv2.CAP_PROP_FPS)
    total_frames = int(cap.get(cv2.CAP_PROP_FRAME_COUNT))
    width = int(cap.get(cv2.CAP_PROP_FRAME_WIDTH))
    height = int(cap.get(cv2.CAP_PROP_FRAME_HEIGHT))
    
    # 计算采样间隔
    if target_fps >= original_fps:
        frame_interval = 1
    else:
        frame_interval = max(1, int(original_fps / target_fps))
    
    # 计算缩放比例
    scale_w = max_resolution[0] / width
    scale_h = max_resolution[1] / height
    scale = min(1.0, scale_w, scale_h)
    
    new_width = int(width * scale)
    new_height = int(height * scale)
    
    results = []
    frame_idx = 0
    
    while True:
        ret, frame = cap.read()
        if not ret:
            break
        
        if frame_idx % frame_interval != 0:
            frame_idx += 1
            continue
        
        # 缩放
        if scale < 1.0:
            frame = cv2.resize(frame, (new_width, new_height))
        
        # 分析
        timestamp = frame_idx / original_fps
        result = analysis_func(frame)
        results.append((timestamp, result))
        
        frame_idx += 1
    
    cap.release()
    return results
```

## 第5章 音画匹配故障

### 5.1 对齐失败

#### 5.1.1 音乐与片段时长不匹配

**症状**：
- 视频素材比音乐短很多，需要重复或拉长
- 视频素材比音乐长，需要裁剪或加速
- 对齐后节奏明显不对

**解决方案**：

```python
def calculate_alignment_strategy(music_duration, video_duration):
    """计算音画对齐策略"""
    
    strategies = []
    
    ratio = video_duration / music_duration if music_duration > 0 else 1.0
    
    if abs(ratio - 1.0) < 0.05:
        # 时长接近，直接对齐
        strategies.append({
            'type': 'direct',
            'description': '直接对齐',
            'speed_change': 1.0,
            'quality_impact': '无影响'
        })
    
    if ratio > 1.0:
        # 视频比音乐长
        strategies.append({
            'type': 'trim',
            'description': '裁剪视频',
            'trim_amount': video_duration - music_duration,
            'quality_impact': '损失部分内容'
        })
        
        strategies.append({
            'type': 'slowdown_music',
            'description': '放慢音乐',
            'speed_factor': music_duration / video_duration,
            'quality_impact': '轻微失真（<10% 影响不大）'
        })
    
    if ratio < 1.0:
        # 视频比音乐短
        strategies.append({
            'type': 'loop',
            'description': '循环视频',
            'loop_count': int(music_duration / video_duration) + 1,
            'quality_impact': '重复感'
        })
        
        strategies.append({
            'type': 'speedup_video',
            'description': '加速视频',
            'speed_factor': video_duration / music_duration,
            'quality_impact': '加速感'
        })
        
        strategies.append({
            'type': 'extend',
            'description': '延长首尾帧',
            'extend_amount': music_duration - video_duration,
            'quality_impact': '静态感'
        })
    
    return strategies


def smart_align(music_beats, video_segments, music_duration, video_duration):
    """智能音画对齐"""
    import numpy as np
    
    # 计算基准策略
    strategies = calculate_alignment_strategy(music_duration, video_duration)
    
    # 选择最优策略（简化：选第一个）
    best_strategy = strategies[0] if strategies else {'type': 'direct'}
    
    if best_strategy['type'] == 'loop':
        # 循环视频片段
        loops_needed = int(np.ceil(music_duration / video_duration))
        aligned_segments = []
        
        for i in range(loops_needed):
            offset = i * video_duration
            for seg in video_segments:
                new_seg = seg.copy()
                new_seg['start'] += offset
                new_seg['end'] += offset
                aligned_segments.append(new_seg)
        
        # 裁剪到音乐长度
        aligned_segments = [s for s in aligned_segments if s['start'] < music_duration]
        
    elif best_strategy['type'] == 'trim':
        # 裁剪视频
        # 找到最合适的裁剪点（在段落边界）
        aligned_segments = []
        cumulative = 0
        
        for seg in video_segments:
            seg_duration = seg['end'] - seg['start']
            if cumulative + seg_duration <= music_duration:
                aligned_segments.append(seg)
                cumulative += seg_duration
            else:
                # 部分裁剪
                new_seg = seg.copy()
                new_seg['end'] = seg['start'] + (music_duration - cumulative)
                aligned_segments.append(new_seg)
                break
    else:
        # 直接使用
        aligned_segments = video_segments
    
    # 将视频段落映射到音乐节拍
    beat_mapping = map_segments_to_beats(aligned_segments, music_beats)
    
    return aligned_segments, beat_mapping, best_strategy


def map_segments_to_beats(segments, beats):
    """将视频段落映射到音乐节拍点"""
    mapping = []
    
    beat_idx = 0
    
    for seg in segments:
        seg_beats = []
        while beat_idx < len(beats) and beats[beat_idx] < seg['end']:
            if beats[beat_idx] >= seg['start']:
                seg_beats.append(beats[beat_idx])
            beat_idx += 1
        
        mapping.append({
            'segment': seg,
            'beats': seg_beats,
            'beat_count': len(seg_beats)
        })
    
    return mapping
```

#### 5.3.1 视觉噪音问题

**问题表现**：

```python
def detect_effect_overload(effect_list, video_duration):
    """检测效果堆叠过度"""
    
    issues = []
    
    # 1. 效果密度
    effect_density = len(effect_list) / video_duration if video_duration > 0 else 0
    if effect_density > 0.5:  # 每秒超过0.5个效果
        issues.append({
            'type': 'high_density',
            'severity': 'high' if effect_density > 1.0 else 'medium',
            'description': f'效果密度过高: {effect_density:.2f} 个/秒',
            'threshold': 0.3,
            'current': effect_density
        })
    
    # 2. 同时出现的效果数量
    # 按时间排序
    sorted_effects = sorted(effect_list, key=lambda e: e.get('start', 0))
    
    max_simultaneous = 0
    active_effects = []
    
    for effect in sorted_effects:
        start = effect.get('start', 0)
        end = effect.get('end', start + 1.0)
        
        # 移除已结束的效果
        active_effects = [e for e in active_effects if e['end'] > start]
        
        # 添加当前效果
        active_effects.append({'start': start, 'end': end, 'effect': effect})
        
        max_simultaneous = max(max_simultaneous, len(active_effects))
    
    if max_simultaneous > 4:
        issues.append({
            'type': 'too_many_simultaneous',
            'severity': 'high' if max_simultaneous > 6 else 'medium',
            'description': f'同时出现的效果过多: 最多 {max_simultaneous} 个',
            'threshold': 4,
            'current': max_simultaneous
        })
    
    # 3. 转场频率
    transitions = [e for e in effect_list if e.get('type') == 'transition']
    transition_count = len(transitions)
    avg_transition_interval = video_duration / (transition_count + 1)
    
    if avg_transition_interval < 1.0:  # 平均不到1秒一个转场
        issues.append({
            'type': 'frequent_transitions',
            'severity': 'high',
            'description': f'转场过于频繁: 平均每 {avg_transition_interval:.2f} 秒一个',
            'threshold': 1.0,
            'current': avg_transition_interval
        })
    
    return issues


def optimize_effects(effect_list, strategy='balanced'):
    """优化效果列表，减少堆叠"""
    
    if strategy == 'minimal':
        # 极简模式：只保留最重要的效果
        # 按重要性排序
        priority_order = ['cut', 'transition', 'color', 'motion', 'particle', 'text']
        
        # 每个时间点只保留最高优先级的效果
        optimized = []
        sorted_effects = sorted(effect_list, key=lambda e: e.get('start', 0))
        
        last_end = 0
        for effect in sorted_effects:
            if effect.get('start', 0) >= last_end:
                optimized.append(effect)
                last_end = effect.get('end', effect.get('start', 0) + 1.0)
        
        return optimized
    
    elif strategy == 'balanced':
        # 平衡模式：减少密度但保留主要效果
        # 确保每个时间段效果不超过3个
        optimized = []
        sorted_effects = sorted(effects_list, key=lambda e: e.get('start', 0))
        active_effects = []
        
        for effect in sorted_effects:
            start = effect.get('start', 0)
            
            # 移除已结束的效果
            active_effects = [e for e in active_effects if e['end'] > start]
            
            if len(active_effects) < 3:
                optimized.append(effect)
                active_effects.append({
                    'start': start,
                    'end': effect.get('end', start + 1.0)
                })
        
        return optimized
    
    else:
        return effect_list
```

### 5.4 转场方案错误

#### 5.4.1 常见转场错误类型

| 错误类型 | 表现 | 原因 | 修正方法 |
|---------|------|------|---------|
| **节奏不符** | 慢节奏音乐用快切 | 未考虑音乐速度 | 匹配 BPM 调整转场时长 |
| **方向混乱** | 转场方向不一致 | 随机选择方向 | 建立一致的视觉动线 |
| **强度不当** | 平静段落用剧烈转场 | 未考虑情绪曲线 | 按情绪强度分级转场 |
| **过度重复** | 一直用同一种转场 | 选择逻辑单一 | 增加转场多样性 |

**转场选择决策树**：

```python
def select_transition(music_context, visual_context):
    """智能选择转场效果
    
    Args:
        music_context: 音乐上下文 (tempo, intensity, beat_type)
        visual_context: 视觉上下文 (motion, color, scene_change)
    """
    
    tempo = music_context.get('tempo', 120)
    intensity = music_context.get('intensity', 0.5)
    beat_type = music_context.get('beat_type', 'normal')  # normal/downbeat/upbeat
    
    motion = visual_context.get('motion', 0.5)
    is_scene_change = visual_context.get('scene_change', False)
    color_diff = visual_context.get('color_diff', 0.3)
    
    # 计算转场强度
    transition_intensity = (
        0.3 * (tempo / 180.0) +
        0.3 * intensity +
        0.2 * motion +
        0.2 * color_diff
    )
    
    # 选择转场类型
    if is_scene_change and transition_intensity > 0.7:
        # 大场景切换 + 高强度 → 炫酷转场
        if beat_type == 'downbeat':
            transition = 'zoom_blast'  # 缩放冲击
        else:
            transition = 'glitch'     # 故障转场
    elif transition_intensity > 0.6:
        # 高强度 → 动态转场
        transition = 'whip_pan'   # 甩镜头
    elif transition_intensity > 0.3:
        # 中等强度 → 标准转场
        transition = 'cross_dissolve'  # 交叉溶解
    else:
        # 低强度 → 柔和转场
        transition = 'fade'       # 淡入淡出
    
    # 计算转场时长
    if tempo > 140:
        duration = 0.2  # 快节奏用短转场
    elif tempo > 100:
        duration = 0.4
    else:
        duration = 0.8  # 慢节奏用长转场
    
    return {
        'type': transition,
        'duration': duration,
        'intensity': transition_intensity
    }
```

async function executeWithTimeout(command, timeoutMs) {

    const timeoutId = setTimeout(() => controller.abort(), timeoutMs);

        const result = await executeCommand(command, { signal: controller.signal });
        clearTimeout(timeoutId);

// 带重试的执行
async function executeWithRetry(command, maxRetries = 3, timeoutMs = 15000) {
    for (let attempt = 1; attempt <= maxRetries; attempt++) {
        try {
            return await executeWithTimeout(command, timeoutMs);
        } catch (error) {
            if (attempt < maxRetries && isRetriableError(error)) {
                console.log(`第 ${attempt} 次失败， ${2 ** attempt} 秒后重试...`);
                await sleep(2 ** attempt * 1000);
            } else {
                throw error;
            }
        }
    }
}

    const retriableMessages = [

        'busy',
        'connection',
        'temporarily'

// 脚本执行前的安全检查和崩溃恢复

var SafeExecutor = {
    maxExecutionTime: 30000, // 最长执行时间 30 秒
    maxOperations: 10000,    // 最大操作次数
    operationCount: 0,
    
    // 开始安全执行
    start: function(name) {
        this.startTime = Date.now();
        this.operationCount = 0;
        this.scriptName = name;
        
        // 保存项目（作为恢复点）
        this.saveRecoveryPoint();
        
        $.writeln("[SafeExecutor] 开始执行: " + name);
    },
    
    // 检查是否应该继续
    check: function() {
        this.operationCount++;
        
        // 检查操作次数
        if (this.operationCount > this.maxOperations) {
            throw new Error("操作次数超过限制 (" + this.maxOperations + ")，可能存在死循环");
        }
        
        // 检查执行时间
        var elapsed = Date.now() - this.startTime;
        if (elapsed > this.maxExecutionTime) {
            throw new Error("执行时间超过限制 (" + this.maxExecutionTime + "ms)");
        }
        
        return true;
    },
    
    // 保存恢复点
    saveRecoveryPoint: function() {
        try {
            var recoveryPath = Folder.temp + "/mcp_recovery_" + Date.now() + ".aep";
            app.project.save(new File(recoveryPath));
            this.recoveryFile = recoveryPath;
            $.writeln("[SafeExecutor] 恢复点已保存: " + recoveryPath);
        } catch (e) {
            $.writeln("[SafeExecutor] 保存恢复点失败: " + e.message);
        }
    },
    
    // 完成执行
    finish: function() {
        var elapsed = Date.now() - this.startTime;
        $.writeln("[SafeExecutor] 执行完成，耗时: " + elapsed + "ms");
        $.writeln("[SafeExecutor] 操作次数: " + this.operationCount);
    },
    
    // 处理错误
    handleError: function(error) {
        $.writeln("[SafeExecutor] 执行出错: " + error.message);
        $.writeln("[SafeExecutor] 恢复点文件: " + (this.recoveryFile || "无"));
        
        // 尝试撤销
        try {
            app.executeCommand(2); // Undo
            $.writeln("[SafeExecutor] 已尝试撤销");
        } catch (e) {}
        
        return {
            success: false,
            error: error.message,
            recoveryFile: this.recoveryFile || null
        };
    }
};

function validateJSON(jsonString) {
    try {
        JSON.parse(jsonString);
        return { valid: true, error: null };
    } catch (e) {
        // 尝试定位错误位置
        const match = e.message.match(/position (\d+)/);
        let position = -1;
        if (match) {
            position = parseInt(match[1]);
        }
        
        // 获取错误上下文
        let context = '';
        if (position >= 0) {

            const end = Math.min(jsonString.length, position + 20);

            error: e.message,
            position: position,
            context: context
        };

#### 7.1.2 参数验证错误

**症状**：
```

```

**常见验证失败**：

| 验证类型 | 失败原因 | 修复方法 |
|---------|---------|---------|
| 必填字段 | 缺少必需的 key | 检查是否遗漏必填参数 |
| 类型错误 | 字符串传了数字 | 确保数据类型正确 |
| 范围错误 | 数值超出范围 | 检查参数的合法范围 |
| 枚举错误 | 值不在允许列表中 | 使用正确的枚举值 |
| 格式错误 | 格式不符合预期 | 检查格式要求（如时间格式） |

```typescript
// validator.ts
interface ValidationRule {
    field: string;
    type: 'string' | 'number' | 'boolean' | 'object' | 'array';
    required?: boolean;
    min?: number;
    max?: number;
    enum?: any[];
    validator?: (value: any) => boolean;
}

function validateParams(params: Record<string, any>, rules: ValidationRule[]) {
    const errors: string[] = [];
    
    for (const rule of rules) {
        const value = params[rule.field];
        
        // 必填检查
        if (rule.required && (value === undefined || value === null)) {
            errors.push(`字段 "${rule.field}" 是必填项`);
            continue;
        }
        
        if (value === undefined || value === null) {
            continue;
        }
        
        // 类型检查
        const actualType = Array.isArray(value) ? 'array' : typeof value;
        if (actualType !== rule.type) {
            errors.push(`字段 "${rule.field}" 类型错误，期望 ${rule.type}，实际 ${actualType}`);
            continue;
        }
        
        // 范围检查
        if (rule.type === 'number') {
            if (rule.min !== undefined && value < rule.min) {
                errors.push(`字段 "${rule.field}" 不能小于 ${rule.min}`);
            }
            if (rule.max !== undefined && value > rule.max) {
                errors.push(`字段 "${rule.field}" 不能大于 ${rule.max}`);
            }
        }
        
        // 枚举检查
        if (rule.enum && !rule.enum.includes(value)) {
            errors.push(`字段 "${rule.field}" 值 "${value}" 不在允许列表中: ${rule.enum.join(', ')}`);
        }
        
        // 自定义验证
        if (rule.validator && !rule.validator(value)) {
            errors.push(`字段 "${rule.field}" 验证失败`);
        }
    }
    
    return {
        valid: errors.length === 0,
        errors: errors
    };
}
```

// 简单的 JSX 语法检查

function checkJSXSyntax(jsxCode) {
    const issues = [];
    
    // 1. 检查括号匹配
    const brackets = { '(': ')', '[': ']', '{': '}' };
    const stack = [];
    
    for (let i = 0; i < jsxCode.length; i++) {
        const char = jsxCode[i];
        if (brackets[char]) {
            stack.push({ char, position: i });
        } else if (Object.values(brackets).includes(char)) {
            const last = stack.pop();
            if (!last || brackets[last.char] !== char) {
                issues.push({
                    type: 'bracket_mismatch',
                    position: i,
                    message: `不匹配的括号 "${char}"`
                });
            }
        }
    }
    
    // 检查未闭合的括号
    for (const item of stack) {
        issues.push({
            type: 'unclosed_bracket',
            position: item.position,
            message: `未闭合的括号 "${item.char}"`
        });
    }
    
    // 2. 检查常见的 ExtendScript 问题
    const lines = jsxCode.split('\n');
    
    for (let lineNum = 0; lineNum < lines.length; lineNum++) {
        const line = lines[lineNum];
        
        // 检查 let/const（ExtendScript 不支持 ES6）
        if (/\b(let|const)\s+\w/.test(line)) {
            issues.push({
                type: 'es6_syntax',
                line: lineNum + 1,
                message: 'ExtendScript 不支持 let/const，请使用 var'
            });
        }
        
        // 检查箭头函数
        if (/=>/.test(line)) {
            issues.push({
                type: 'es6_syntax',
                line: lineNum + 1,
                message: 'ExtendScript 不支持箭头函数'
            });
        }
        
        // 检查模板字符串
        if(/`.*`/.test(line)) {
            issues.push({
                type: 'es6_syntax',
                line: lineNum + 1,
                message: 'ExtendScript 不支持模板字符串，请使用字符串拼接'
            });
        }
    }
    
    return issues;
}

// time-utils.js
function validateKeyframes(keyframes, compDuration, compFps) {
    const issues = [];
    
    if (!keyframes || keyframes.length === 0) {
        return issues;
    }
    
    // 检查时间顺序
    for (let i = 1; i < keyframes.length; i++) {
        if (keyframes[i].time < keyframes[i-1].time) {
            issues.push({
                type: 'time_order',
                index: i,
                message: `关键帧 ${i} 的时间 (${keyframes[i].time}) 早于前一帧 (${keyframes[i-1].time})`
            });
        }
    }
    
    // 检查是否超出合成时长
    for (let i = 0; i < keyframes.length; i++) {
        const time = keyframes[i].time;
        if (time < 0) {
            issues.push({
                type: 'negative_time',
                index: i,
                time: time,
                message: `关键帧 ${i} 时间为负值: ${time}`
            });
        }
        if (time > compDuration) {
            issues.push({
                type: 'out_of_range',
                index: i,
                time: time,
                compDuration: compDuration,
                message: `关键帧 ${i} 时间 (${time}) 超出合成时长 (${compDuration})`
            });
        }
    }
    
    // 检查时间间隔是否过近
    const minInterval = 1 / compFps; // 至少一帧间隔
    for (let i = 1; i < keyframes.length; i++) {
        const interval = keyframes[i].time - keyframes[i-1].time;
        if (interval < minInterval && interval > 0) {
            issues.push({
                type: 'too_close',
                index: i,
                interval: interval,
                minInterval: minInterval,
                message: `关键帧 ${i-1} 和 ${i} 间隔过短 (${interval.toFixed(4)}s < ${minInterval.toFixed(4)}s)`
            });
        }
    }
    
    return issues;
}

function safeSpawn(command, args, options = {}) {
    return new Promise((resolve, reject) => {
        const timeout = options.timeout || 30000;
        const maxBuffer = options.maxBuffer || 10 * 1024 * 1024; // 10MB
        
        const child = spawn(command, args, {
            ...options,
            windowsHide: true
        });
        
        let stdout = '';
        let stderr = '';
        let timedOut = false;
        
        const timer = setTimeout(() => {
            timedOut = true;
            child.kill('SIGTERM');
            setTimeout(() => child.kill('SIGKILL'), 2000);
        }, timeout);
        
        child.stdout.on('data', (data) => {
            stdout += data.toString();
            if (stdout.length > maxBuffer) {
                child.kill();
                reject(new Error('stdout 超出最大限制'));
            }
        });
        
        child.stderr.on('data', (data) => {
            stderr += data.toString();
        });
        
        child.on('error', (err) => {
            clearTimeout(timer);
            reject(err);
        });
        
        child.on('close', (code) => {
            clearTimeout(timer);
            
            if (timedOut) {
                reject(new Error(`进程超时 (${timeout}ms)`));
                return;
            }
            
            if (code === 0) {
                resolve({ stdout, stderr, code });
            } else {
                const error = new Error(`进程退出码: ${code}`);
                error.stdout = stdout;
                error.stderr = stderr;
                error.code = code;
                reject(error);
            }
        });
    });

            encoding: 'buffer',  // 获取原始 buffer
            windowsHide: true
        });

            try {
                // 尝试多种编码
                const stdoutStr = decodeBuffer(stdout, encoding);
                const stderrStr = decodeBuffer(stderr, encoding);
                
                if (code === 0) {
                    resolve({ stdout: stdoutStr, stderr: stderrStr, code });
                } else {
                    const err = new Error(`命令失败: ${stderrStr}`);
                    err.stdout = stdoutStr;
                    err.stderr = stderrStr;
                    reject(err);
                }
            } catch (e) {
                reject(e);
            }
        });
    });
}

function decodeBuffer(buffer, defaultEncoding) {
    // 尝试 UTF-8
    try {
        const str = buffer.toString('utf-8');
        // 检查是否有替换字符（表示解码失败）
        if (!str.includes('\uFFFD') || buffer.length < 10) {
            return str;
        }
    } catch (e) {}
    
    // 尝试默认编码（GBK/CP936）
    try {
        return iconv.decode(buffer, defaultEncoding);
    } catch (e) {}
    
    // 最后尝试 GBK
    try {
        return iconv.decode(buffer, 'gbk');
    } catch (e) {
        return buffer.toString('binary');
    }

import json
import numpy as np
from datetime import datetime, date
from pathlib import Path

class SafeJSONEncoder(json.JSONEncoder):
    """安全的 JSON 编码器"""
    
    def default(self, obj):
        # numpy 类型
        if isinstance(obj, np.ndarray):
            return obj.tolist()
        if isinstance(obj, (np.int_, np.intc, np.intp, np.int8,
                           np.int16, np.int32, np.int64,
                           np.uint8, np.uint16, np.uint32, np.uint64)):
            return int(obj)
        if isinstance(obj, (np.float_, np.float16, np.float32, np.float64)):
            return float(obj)
        if isinstance(obj, (np.bool_)):
            return bool(obj)
        
        # 日期时间
        if isinstance(obj, (datetime, date)):
            return obj.isoformat()
        
        # Path 对象
        if isinstance(obj, Path):
            return str(obj)
        
        # 字节
        if isinstance(obj, bytes):
            import base64
            return base64.b64encode(obj).decode('utf-8')
        
        # 有 __dict__ 的对象
        if hasattr(obj, '__dict__'):
            return obj.__dict__
        
        # 最后尝试转换为字符串
        try:
            return str(obj)
        except Exception:
            return f"<{type(obj).__name__}>"


def safe_dumps(obj, **kwargs):
    """安全的 JSON 序列化"""
    return json.dumps(obj, cls=SafeJSONEncoder, ensure_ascii=False, **kwargs)


def safe_loads(s, **kwargs):
    """安全的 JSON 反序列化"""
    if isinstance(s, bytes):
        s = s.decode('utf-8')

import threading
import asyncio
from pathlib import Path
import time

# 文件锁
class FileLock:
    """简单的文件锁实现"""
    
    def __init__(self, lock_file_path, timeout=30):
        self.lock_file = Path(lock_file_path)
        self.timeout = timeout
        self._acquired = False
    
    def acquire(self):
        start_time = time.time()
        
        while time.time() - start_time < self.timeout:
            try:
                # 尝试创建锁文件
                self.lock_file.parent.mkdir(parents=True, exist_ok=True)
                with open(self.lock_file, 'x') as f:
                    f.write(str(time.time()))
                self._acquired = True
                return True
            except FileExistsError:
                # 检查锁是否过期
                try:
                    with open(self.lock_file, 'r') as f:
                        lock_time = float(f.read().strip())
                    if time.time() - lock_time > self.timeout:
                        # 锁过期，强制获取
                        self.lock_file.unlink()
                        continue
                except:
                    pass
                
                time.sleep(0.1)
        
        return False
    
    def release(self):
        if self._acquired:
            try:
                self.lock_file.unlink()
            except:
                pass
            self._acquired = False
    
    def __enter__(self):
        self.acquire()
        return self
    
    def __exit__(self, *args):
        self.release()


# 任务队列
class TaskQueue:
    """顺序执行任务队列"""
    
    def __init__(self, max_workers=1):
        self._lock = threading.Lock()
        self._tasks = []
        self._running = False
        self._max_workers = max_workers
        self._active_workers = 0
    
    def add_task(self, func, *args, **kwargs):
        with self._lock:
            task = (func, args, kwargs)
            self._tasks.append(task)
        
        self._try_start_worker()
    
    def _try_start_worker(self):
        with self._lock:
            if self._active_workers < self._max_workers and self._tasks:
                self._active_workers += 1
                threading.Thread(target=self._worker, daemon=True).start()
    
    def _worker(self):
        while True:
            with self._lock:
                if not self._tasks:
                    self._active_workers -= 1
                    break
                func, args, kwargs = self._tasks.pop(0)
            
            try:
                func(*args, **kwargs)
            except Exception as e:
                print(f"任务执行错误: {e}")

### 8.5 错误处理与重试机制

#### 8.5.1 重试装饰器

```python
# retry-utils.py
import time
import functools
import logging

logger = logging.getLogger(__name__)

def retry(max_retries=3, delay=1.0, backoff=2.0, exceptions=(Exception,)):
    """重试装饰器
    
    Args:
        max_retries: 最大重试次数
        delay: 初始延迟（秒）
        backoff: 延迟倍增因子
        exceptions: 需要重试的异常类型
    """
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            last_exception = None
            current_delay = delay
            
            for attempt in range(max_retries + 1):
                try:
                    return func(*args, **kwargs)
                except exceptions as e:
                    last_exception = e
                    
                    if attempt < max_retries:
                        logger.warning(
                            f"函数 {func.__name__} 第 {attempt + 1} 次失败，"
                            f"{current_delay:.1f}s 后重试... 错误: {e}"
                        )
                        time.sleep(current_delay)
                        current_delay *= backoff
                    else:
                        logger.error(
                            f"函数 {func.__name__} 在 {max_retries + 1} 次尝试后仍然失败"
                        )
            
            raise last_exception
        
        return wrapper
    return decorator


# 断路器模式
class CircuitBreaker:
    """断路器 - 防止故障级联"""
    
    def __init__(self, failure_threshold=5, recovery_timeout=30):
        self.failure_threshold = failure_threshold
        self.recovery_timeout = recovery_timeout
        
        self.failure_count = 0
        self.last_failure_time = 0
        self.state = 'closed'  # closed/open/half-open
    
    def call(self, func, *args, **kwargs):
        if self.state == 'open':
            # 检查是否进入半开状态
            if time.time() - self.last_failure_time > self.recovery_timeout:
                self.state = 'half-open'
            else:
                raise Exception("断路器已打开，请求被拒绝")
        
        try:
            result = func(*args, **kwargs)
            self._on_success()
            return result
        except Exception as e:
            self._on_failure()
            raise
    
    def _on_success(self):
        if self.state == 'half-open':
            self.state = 'closed'
        self.failure_count = 0
    
    def _on_failure(self):
        self.failure_count += 1
        self.last_failure_time = time.time()
        
        if self.state == 'half-open' or self.failure_count >= self.failure_threshold:
            self.state = 'open'

    @wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)

        print(f"函数 {func.__name__} 耗时: {end - start:.4f}秒")

### 9.3 Amdahl 定律与优化优先级

#### 9.3.1 Amdahl 定律

Amdahl 定律描述了并行计算（或任何优化）能带来的最大加速比：

**加速比 = 1 / (s + (1-s)/p)**

其中：
- **s** = 串行部分的比例（无法优化的部分）
- **p** = 并行加速倍数（或优化倍数）

**举例**：
- 如果一个程序有 10% 的时间是串行的（无法并行），即使有无限多的处理器，最大加速比也只有 10 倍
- 如果一个程序有 50% 的时间可以优化，最多只能加速 2 倍
- 如果一个程序只有 10% 的时间可以优化，加速比上限约 1.1 倍

> [!important] 优化启示
> 1. **优先优化热点**：找到程序中耗时最长的部分，优化它得到的收益最大
> 2. **避免过早优化**：先让程序正确运行，再优化热点
> 3. **关注整体性能**：不要在只占 1% 时间的函数上花太多精力

#### 9.3.2 优化优先级矩阵

| 优化效果 \ 实现难度 | 低难度 | 中难度 | 高难度 |
|-------------------|--------|--------|--------|
| **效果大** | ⭐⭐⭐ 立即做 | ⭐⭐ 计划做 | ⭐ 评估收益 |
| **效果中** | ⭐⭐ 有空做 | ⭐ 考虑做 | ✗ 不值得 |
| **效果小** | ⭐ 顺手做 | ✗ 不做 | ✗ 绝对不做 |

#### 9.4.1 建立性能基线

```python
# baseline.py
"""性能基线管理"""

import json
import time
import os
from pathlib import Path

class PerformanceBaseline:
    def __init__(self, baseline_file='performance_baseline.json'):
        self.baseline_file = Path(baseline_file)
        self.baselines = self._load()
    
    def _load(self):
        if self.baseline_file.exists():
            with open(self.baseline_file, 'r') as f:
                return json.load(f)
        return {}
    
    def save(self):
        with open(self.baseline_file, 'w') as f:
            json.dump(self.baselines, f, indent=2, ensure_ascii=False)
    
    def record(self, test_name, metrics):
        """记录测试结果"""
        if test_name not in self.baselines:
            self.baselines[test_name] = {
                'history': [],
                'baseline': None
            }
        
        entry = {
            'timestamp': time.time(),
            'metrics': metrics
        }
        self.baselines[test_name]['history'].append(entry)
        
        # 只保留最近20次记录
        if len(self.baselines[test_name]['history']) > 20:
            self.baselines[test_name]['history'].pop(0)
    
    def set_baseline(self, test_name, metrics):
        """设置基线值"""
        if test_name not in self.baselines:
            self.baselines[test_name] = {'history': [], 'baseline': None}
        
        self.baselines[test_name]['baseline'] = {
            'timestamp': time.time(),
            'metrics': metrics
        }
    
    def compare(self, test_name, current_metrics):
        """与基线对比"""
        if test_name not in self.baselines or not self.baselines[test_name]['baseline']:
            return None
        
        baseline = self.baselines[test_name]['baseline']['metrics']
        comparison = {}
        
        for key in current_metrics:
            if key in baseline:
                baseline_val = baseline[key]
                current_val = current_metrics[key]
                
                if baseline_val != 0:
                    change_percent = ((current_val - baseline_val) / baseline_val) * 100
                else:
                    change_percent = float('inf') if current_val > 0 else 0
                
                comparison[key] = {
                    'baseline': baseline_val,
                    'current': current_val,
                    'change_percent': change_percent,
                    'direction': 'worse' if change_percent > 5 else ('better' if change_percent < -5 else 'same')
                }
        
        return comparison
    
    def report(self):
        """生成报告"""
        print("\n" + "="*60)
        print("性能基线报告")
        print("="*60)
        
        for test_name, data in self.baselines.items():
            print(f"\n测试: {test_name}")
            
            if data['baseline']:
                print(f"  基线值: {data['baseline']['metrics']}")
            else:
                print(f"  基线: 未设置")
            
            print(f"  历史记录: {len(data['history'])} 次")

### 9.5 优化的投入产出比

#### 9.5.1 ROI 计算

**性能优化 ROI = 性能提升收益 / 优化投入成本**

**收益计算**：
- 时间节省：(原时间 - 新时间) × 任务数 × 人力成本
- 资源节省：(原资源 - 新资源) × 资源单价
- 用户体验：转化率提升、用户留存等（较难量化）

**成本计算**：
- 开发时间：开发人员工时 × 时薪
- 测试成本：测试人员工时
- 维护成本：后续维护的复杂度增加

#### 9.5.2 优化决策树

```
性能问题
    │
    ├─ 用户可感知吗？
    │   ├─ 否 → 不优化，记录在案
    │   └─ 是 → 继续
    │
    ├─ 影响范围有多大？
    │   ├─ 很小（<5%用户）→ 低优先级
    │   ├─ 中等 → 中优先级
    │   └─ 很大（>50%用户）→ 高优先级
    │
    ├─ 优化难度如何？
    │   ├─ 简单（<1天）→ 立即做
    │   ├─ 中等（1-5天）→ 计划做
    │   └─ 困难（>1周）→ 评估必要性
    │
    └─ 收益有多大？
        ├─ 很大（>50%提升）→ 高价值
        ├─ 中等（20-50%）→ 中价值
        └─ 很小（<10%）→ 低价值
```

> [!tip] 性能优化原则
> 1. **先测量，再优化**：不要凭感觉优化，用数据说话
> 2. **优化热点**：把精力花在最耗时的地方
> 3. **设定目标**：明确要达到什么性能指标
> 4. **对比测试**：优化前后对比，确保真的有提升
> 5. **考虑长期维护**：为了性能牺牲可读性是否值得？

### 10.1 向量化优化

#### 10.1.1 NumPy 向量化基础

**问题**：Python 循环慢，处理大量数据时性能瓶颈明显。

**解决方案**：使用 NumPy 向量化操作替代显式循环。

```python
import numpy as np
import time

# 慢版本：Python 循环
def slow_sum(arr):
    total = 0
    for x in arr:
        total += x
    return total

# 快版本：NumPy 向量化
def fast_sum(arr):
    return np.sum(arr)

# 性能对比
size = 10_000_000
arr = np.random.rand(size)

t0 = time.time()
slow_sum(arr)
print(f"Python 循环: {time.time() - t0:.4f}s")

t0 = time.time()
fast_sum(arr)
print(f"NumPy 向量化: {time.time() - t0:.4f}s")
```

**常见向量化模式**：

| 操作 | 慢版本（循环） | 快版本（向量化） | 加速比 |
|-----|--------------|----------------|--------|
| 求和 | `for x in arr: s += x` | `np.sum(arr)` | 50-100x |
| 均值 | `for x in arr: s += x; s/n` | `np.mean(arr)` | 50-100x |
| 标准差 | 手动计算 | `np.std(arr)` | 100-200x |
| 矩阵乘法 | 三重循环 | `np.dot(A, B)` | 1000x+ |
| 条件筛选 | 列表推导 | `arr[arr > threshold]` | 20-50x |

#### 10.1.3 音频处理向量化实例

```python
import numpy as np
import librosa

def extract_features_slow(audio, sr):
    """慢版本：逐帧处理"""
    n_fft = 2048
    hop_length = 512
    n_frames = (len(audio) - n_fft) // hop_length + 1
    
    features = []
    for i in range(n_frames):
        start = i * hop_length
        frame = audio[start:start + n_fft]
        
        # 加窗
        windowed = frame * np.hanning(n_fft)
        
        # FFT
        spectrum = np.abs(np.fft.rfft(windowed))
        
        # 计算频谱质心
        freqs = np.fft.rfftfreq(n_fft, 1/sr)
        if np.sum(spectrum) > 0:
            centroid = np.sum(freqs * spectrum) / np.sum(spectrum)
        else:
            centroid = 0
        
        features.append(centroid)
    
    return np.array(features)


def extract_features_fast(audio, sr):
    """快版本：全向量化"""
    n_fft = 2048
    hop_length = 512
    
    # 使用 librosa 的向量化 STFT
    stft = librosa.stft(audio, n_fft=n_fft, hop_length=hop_length)
    magnitude = np.abs(stft)
    
    # 向量化计算频谱质心
    freqs = librosa.fft_frequencies(sr=sr, n_fft=n_fft)
    spectrum_sum = np.sum(magnitude, axis=0)
    spectrum_sum[spectrum_sum == 0] = 1e-10  # 避免除零
    
    centroid = np.sum(freqs[:, np.newaxis] * magnitude, axis=0) / spectrum_sum
    
    return centroid
```

> [!success] 性能提升
> 向量化后的音频特征提取速度通常提升 **10-50 倍**，具体取决于数据量和操作复杂度。

#### 10.2.1 函数结果缓存

```python
from functools import lru_cache
import numpy as np

# 简单缓存（注意：参数必须可哈希）
@lru_cache(maxsize=128)
def expensive_computation(n, factor):
    """昂贵的计算，结果缓存"""
    result = 0
    for i in range(n):
        result += np.sqrt(i) * factor
    return result

# 对于不可哈希参数（如 numpy 数组），手动缓存
class ResultCache:
    def __init__(self, max_size=100):
        self.max_size = max_size
        self.cache = {}
        self.order = []
    
    def _make_key(self, args, kwargs):
        import hashlib
        import pickle
        key_data = pickle.dumps((args, sorted(kwargs.items())))
        return hashlib.md5(key_data).hexdigest()
    
    def get(self, *args, **kwargs):
        key = self._make_key(args, kwargs)
        if key in self.cache:
            self.order.remove(key)
            self.order.append(key)
            return self.cache[key]
        return None
    
    def set(self, value, *args, **kwargs):
        key = self._make_key(args, kwargs)
        if key in self.cache:
            self.order.remove(key)
        elif len(self.cache) >= self.max_size:
            oldest = self.order.pop(0)
            del self.cache[oldest]
        
        self.cache[key] = value
        self.order.append(key)


# 使用示例
audio_cache = ResultCache(max_size=50)

def load_audio_cached(filepath):
    """带缓存的音频加载"""
    cached = audio_cache.get(filepath)
    if cached is not None:
        return cached
    
    audio, sr = librosa.load(filepath, sr=None)
    audio_cache.set((audio, sr), filepath)
    return audio, sr
```

```python
class AudioAnalyzer:
    """音频分析器：缓存中间结果，避免重复计算"""
    
    def __init__(self, audio, sr):
        self.audio = audio
        self.sr = sr
        
        # 缓存的中间结果
        self._stft = None
        self._magnitude = None
        self._phase = None
        self._mel_spec = None
        self._mfcc = None
    
    @property
    def stft(self):
        if self._stft is None:
            self._stft = librosa.stft(self.audio, n_fft=2048, hop_length=512)
        return self._stft
    
    @property
    def magnitude(self):
        if self._magnitude is None:
            self._magnitude = np.abs(self.stft)
        return self._magnitude
    
    @property
    def phase(self):
        if self._phase is None:
            self._phase = np.angle(self.stft)
        return self._phase
    
    @property
    def mel_spectrogram(self):
        if self._mel_spec is None:
            self._mel_spec = librosa.feature.melspectrogram(
                S=self.magnitude**2, sr=self.sr
            )
        return self._mel_spec
    
    @property
    def mfcc(self):
        if self._mfcc is None:
            self._mfcc = librosa.feature.mfcc(
                S=librosa.power_to_db(self.mel_spectrogram),
                n_mfcc=20
            )
        return self._mfcc
    
    def get_beat_times(self):
        """节拍检测（复用 magnitude）"""
        onset_env = librosa.onset.onset_strength(
            S=self.magnitude, sr=self.sr
        )
        tempo, beats = librosa.beat.beat_track(
            onset_envelope=onset_env, sr=self.sr, units='time'
        )
        return beats
    
    def get_spectral_centroid(self):
        """频谱质心（复用 magnitude）"""
        return librosa.feature.spectral_centroid(
            S=self.magnitude, sr=self.sr
        )[0]
```

> [!tip] 缓存设计原则
> 1. **缓存不变的数据**：只缓存计算后不会变化的结果

### 10.3 多进程与多线程

#### 10.3.1 多进程（CPU 密集型）

```python
import multiprocessing
from multiprocessing import Pool, cpu_count
import numpy as np
import time

def process_chunk(args):
    """处理单个数据块"""
    chunk_id, data = args
    result = np.zeros_like(data)
    
    for i in range(len(data)):
        result[i] = np.sqrt(data[i]) * np.sin(data[i]) + np.cos(data[i])
    
    return chunk_id, result


def parallel_process(data, n_processes=None):
    """并行处理数据"""
    if n_processes is None:
        n_processes = cpu_count()
    
    # 数据分块
    chunk_size = len(data) // n_processes
    chunks = []
    
    for i in range(n_processes):
        start = i * chunk_size
        end = start + chunk_size if i < n_processes - 1 else len(data)
        chunks.append((i, data[start:end]))
    
    # 并行处理
    with Pool(n_processes) as pool:
        results = pool.map(process_chunk, chunks)
    
    # 按顺序合并结果
    results.sort(key=lambda x: x[0])
    return np.concatenate([r[1] for r in results])


# 性能对比
if __name__ == '__main__':
    data = np.random.rand(10_000_000)
    
    t0 = time.time()
    result1 = process_chunk((0, data))[1]
    print(f"单进程: {time.time() - t0:.2f}s")
    
    t0 = time.time()
    result2 = parallel_process(data)
    print(f"多进程: {time.time() - t0:.2f}s")
    
    print(f"结果一致: {np.allclose(result1, result2)}")

#### 10.3.2 多线程（I/O 密集型）

```python
import concurrent.futures
import threading
import time
import os
import librosa

def load_audio_file(filepath):
    """加载音频文件（I/O 密集型）"""
    try:
        audio, sr = librosa.load(filepath, sr=None)
        return filepath, audio, sr, None
    except Exception as e:
        return filepath, None, None, str(e)


def load_audio_parallel(file_list, max_workers=8):
    """并行加载多个音频文件"""
    results = {}
    errors = {}
    
    with concurrent.futures.ThreadPoolExecutor(max_workers=max_workers) as executor:
        future_to_file = {
            executor.submit(load_audio_file, f): f for f in file_list
        }
        
        for future in concurrent.futures.as_completed(future_to_file):
            filepath = future_to_file[future]
            try:
                fname, audio, sr, error = future.result()
                if error:
                    errors[fname] = error
                else:
                    results[fname] = (audio, sr)
            except Exception as e:
                errors[filepath] = str(e)
    
    return results, errors
```

#### 10.3.3 选择多进程还是多线程

| 场景 | 推荐方式 | 原因 |
|-----|---------|------|
| CPU 密集型计算 | 多进程 | 避开 GIL，真正并行 |
| I/O 密集型（文件读写） | 多线程 | 等待 I/O 时切换线程，开销小 |
| I/O 密集型（网络请求） | 多线程 / asyncio | 网络延迟高，线程切换开销可忽略 |
| 混合场景 | 多进程 + 多线程 | 进程间 CPU 并行，线程内 I/O 并发 |
| 简单任务 | 单线程 | 避免并发带来的复杂度 |

> [!warning] GIL 全局解释器锁
> Python 的 GIL 导致同一时刻只能有一个线程执行 Python 字节码。对于 CPU 密集型任务，多线程无法提速，必须用多进程。但 I/O 等待时 GIL 会释放，所以多线程对 I/O 密集型任务有效。

#### 10.4.1 基础用法

```python
import numpy as np
from numba import jit, njit, prange
import time

# 不用 Numba
def slow_function(arr):
    result = 0
    for i in range(len(arr)):
        for j in range(len(arr)):
            result += arr[i] * arr[j] * np.sin(i + j)
    return result

# 使用 Numba JIT 编译
@njit  # 相当于 @jit(nopython=True)
def fast_function(arr):
    result = 0.0
    n = len(arr)
    for i in range(n):
        for j in range(n):
            result += arr[i] * arr[j] * np.sin(i + j)
    return result

# 并行版本
@njit(parallel=True)
def parallel_function(arr):
    result = 0.0
    n = len(arr)
    for i in prange(n):  # prange = 并行 range
        for j in range(n):
            result += arr[i] * arr[j] * np.sin(i + j)
    return result

```python
from numba import njit, float32, int32
import numpy as np

@njit(float32[:](float32[:], int32))
def moving_average(signal, window_size):
    """移动平均滤波（Numba 加速）"""
    n = len(signal)
    result = np.zeros(n, dtype=np.float32)
    half_window = window_size // 2
    
    for i in range(n):
        start = max(0, i - half_window)
        end = min(n, i + half_window + 1)
        count = end - start
        total = 0.0
        
        for j in range(start, end):
            total += signal[j]
        
        result[i] = total / count
    
    return result


@njit(parallel=True)
def compute_energy_envelope(audio, frame_size, hop_size):
    """计算能量包络"""
    n_frames = (len(audio) - frame_size) // hop_size + 1
    energy = np.zeros(n_frames, dtype=np.float32)
    
    for i in prange(n_frames):
        start = i * hop_size
        frame = audio[start:start + frame_size]
        e = 0.0
        for j in range(len(frame)):
            e += frame[j] * frame[j]
        energy[i] = np.sqrt(e / frame_size)
    
    return energy
```

import numpy as np
import librosa

def process_audio_in_chunks(filepath, chunk_duration=10.0, sr=None):
    """分块处理大音频文件"""
    # 获取音频信息
    info = librosa.get_duration(filename=filepath, sr=sr)
    total_duration = info
    if sr is None:
        sr = 22050
    
    # 逐块加载和处理
    offset = 0.0
    results = []
    
    while offset < total_duration:
        # 加载一块
        chunk, _ = librosa.load(
            filepath,
            sr=sr,
            offset=offset,
            duration=chunk_duration
        )
        
        # 处理这块
        chunk_result = process_chunk(chunk, sr)
        results.append(chunk_result)
        
        offset += chunk_duration
        print(f"进度: {offset:.1f}s / {total_duration:.1f}s")
    
    # 合并结果
    return merge_results(results)


def process_chunk(chunk, sr):
    """处理单个块"""
    return {
        'rms': np.sqrt(np.mean(chunk**2)),
        'max_amplitude': np.max(np.abs(chunk)),
        'zero_crossings': np.sum(np.diff(np.sign(chunk)) != 0)
    }


def merge_results(results):
    """合并分块结果"""
    return {
        'total_rms': np.mean([r['rms'] for r in results]),
        'max_amplitude': max(r['max_amplitude'] for r in results),
        'total_zero_crossings': sum(r['zero_crossings'] for r in results)
    }

### 11.2 预合成优化

#### 11.2.1 合理使用预合成

**何时应该预合成**：
- 多个图层使用相同的效果组合
- 需要对一组图层应用整体变换
- 时间重映射一组图层
- 降低时间轴复杂度

**何时避免预合成**：
- 只有 1-2 个图层（预合成反而增加开销）
- 需要频繁调整单个图层参数
- 简单的变换操作（直接在主合成里做）

        }
    }
    
    // 扁平化处理（手动操作更安全）
    return layersToFlatten.length;
}

// 优化嵌套层级
function checkNestingDepth(comp, depth, maxDepth) {
    if (depth > maxDepth) {
        return false;
    }
    
    for (var i = 1; i <= comp.numLayers; i++) {
        var layer = comp.layer(i);
        if (layer instanceof CompItem) {
            if (!checkNestingDepth(layer.source, depth + 1, maxDepth)) {
                $.writeln("嵌套过深: " + layer.name + " (深度: " + (depth + 1) + ")");
                return false;
            }
        }
    }
    return true;
}

// 用法：检查是否有超过 5 层的嵌套
var hasDeepNesting = !checkNestingDepth(app.project.activeItem, 0, 5);
```

> [!warning] 预合成陷阱
> - **过度嵌套**：每增加一层嵌套，渲染时间会叠加
> - **效果重复**：预合成内外都有同类效果，浪费计算
> - **分辨率不匹配**：预合成分辨率远大于显示区域
> - **不必要的 3D**：预合成开启 3D 但没有 3D 变换

#### 11.3.2 表达式优化

**慢表达式 vs 快表达式**：

```javascript
// 慢：每秒执行几十次，每次都重新计算
// 位置属性表达式
wiggle(1, 50) + [value[0], value[1]]

// 更慢：每帧都调用 sourceRectAtTime
// 每帧重新计算
var r = thisLayer.sourceRectAtTime(time, false);
[r.width, r.height]

// 快：尽量使用简单表达式
// 只在需要时计算
value + [0, 0]

// 优化技巧 1：减少函数调用
// 慢
wiggle(2, 30) + wiggle(1, 10)

// 快：合并计算
var w1 = wiggle(2, 30);
var w2 = wiggle(1, 10);
[w1[0] + w2[0], w1[1] + w2[1]]

// 优化技巧 2：避免循环引用
// 慢：A 引用 B，B 引用 A
thisComp.layer("B").transform.position

// 优化技巧 3：使用 value 而非属性名
// 慢（会触发额外查找）
transform.position + [10, 10]

// 快
value + [10, 10]
```

**表达式性能检查清单**：

```javascript
// 检查表达式性能瓶颈
function auditExpressions(comp) {
    var issues = [];
    
    for (var i = 1; i <= comp.numLayers; i++) {
        var layer = comp.layer(i);
        
        for (var p = 1; p <= layer.numProperties; p++) {
            var prop = layer.property(p);
            
            if (prop.expression && prop.expression.length > 0) {
                var expr = prop.expression;
                
                // 检查可能慢的模式
                if (expr.indexOf("for(") !== -1 || expr.indexOf("for (") !== -1) {
                    issues.push({
                        layer: layer.name,
                        property: prop.name,
                        issue: "包含循环",
                        severity: "high"
                    });
                }
                
                if (expr.indexOf("sourceRectAtTime") !== -1) {
                    issues.push({
                        layer: layer.name,
                        property: prop.name,
                        issue: "使用 sourceRectAtTime",
                        severity: "medium"
                    });
                }
                
                if (expr.indexOf("wiggle") !== -1 && expr.indexOf("wiggle") !== expr.lastIndexOf("wiggle")) {
                    issues.push({
                        layer: layer.name,
                        property: prop.name,
                        issue: "多次调用 wiggle",
                        severity: "low"
                    });
                }
                
                // 检查表达式长度
                if (expr.length > 500) {
                    issues.push({
                        layer: layer.name,
                        property: prop.name,
                        issue: "表达式过长 (" + expr.length + " 字符)",
                        severity: "medium"
                    });
                }
            }
        }
        
        // 递归检查预合成
        if (layer instanceof CompItem) {
            issues = issues.concat(auditExpressions(layer.source));
        }
    }
    
    return issues;
}
```

> [!tip] 表达式优化原则
> 1. **保持简短**：表达式越短越快
> 2. **减少函数调用**：尤其是 sourceRectAtTime、sampleImage 等
> 3. **避免循环**：能不用循环就不用
> 4. **减少图层引用**：跨图层引用会增加查找开销
> 5. **使用 value 关键字**：直接访问当前属性的值
> 6. **关掉不用的表达式**：禁用比删除更方便测试

"""磁盘性能测试"""

import time
import os
import tempfile

def disk_write_test(path, size_mb=1000):
    """测试写入速度"""
    test_file = os.path.join(path, 'disk_benchmark.tmp')
    data = os.urandom(1024 * 1024)  # 1 MB 数据块
    
    start = time.time()
    with open(test_file, 'wb') as f:
        for _ in range(size_mb):
            f.write(data)
    os.fsync(f.fileno())  # 确保写入磁盘
    elapsed = time.time() - start
    
    os.remove(test_file)
    
    speed = size_mb / elapsed
    return speed  # MB/s


def disk_read_test(path, size_mb=1000):
    """测试读取速度"""
    test_file = os.path.join(path, 'disk_benchmark.tmp')
    data = os.urandom(1024 * 1024)
    
    # 先写入测试数据
    with open(test_file, 'wb') as f:
        for _ in range(size_mb):
            f.write(data)
    
    # 强制刷新到磁盘
    import ctypes
    ctypes.windll.kernel32.FlushFileBuffers(None)  # 简化
    
    # 读取测试
    start = time.time()
    total_read = 0
    with open(test_file, 'rb') as f:
        while True:
            chunk = f.read(1024 * 1024)
            if not chunk:
                break
            total_read += len(chunk)
    elapsed = time.time() - start
    
    os.remove(test_file)
    
    speed = (total_read / 1024 / 1024) / elapsed
    return speed  # MB/s

import subprocess

def get_power_plans():

    result = subprocess.run(

    return result.returncode == 0


def enable_high_performance():
    """启用高性能电源计划"""
    # 查找高性能计划
    plans = get_power_plans()
    
    high_perf = None
    for plan in plans:
        if '高性能' in plan['name'] or 'High performance' in plan['name']:
            high_perf = plan
            break
    
    if high_perf:
        set_power_plan(high_perf['guid'])
        print(f"已启用: {high_perf['name']}")
        return True
    else:
        # 创建高性能计划（如果不存在）

        print("已启用高性能计划")

def disable_sleep():
    """禁用睡眠和休眠"""
    # 禁用睡眠
    subprocess.run(['powercfg', '/change', 'standby-timeout-ac', '0'])
    subprocess.run(['powercfg', '/change', 'standby-timeout-dc', '0'])
    
    # 禁用休眠
    subprocess.run(['powercfg', '/hibernate', 'off'])
    
    print("已禁用睡眠和休眠")


def get_power_status():
    """获取电源状态"""
    class SystemPowerStatus(ctypes.Structure):
        _fields_ = [
            ("ACLineStatus", ctypes.c_byte),
            ("BatteryFlag", ctypes.c_byte),
            ("BatteryLifePercent", ctypes.c_byte),
            ("Reserved1", ctypes.c_byte),
            ("BatteryLifeTime", ctypes.c_ulong),
            ("BatteryFullLifeTime", ctypes.c_ulong),
        ]
    
    sps = SystemPowerStatus()
    ctypes.windll.kernel32.GetSystemPowerStatus(ctypes.byref(sps))
    
    return {
        'ac_power': sps.ACLineStatus == 1,
        'battery_percent': sps.BatteryLifePercent,
        'battery_time': sps.BatteryLifeTime
    }

# process_cleanup.py
"""后台进程清理工具"""

import psutil
import time

def get_top_processes(by='memory', limit=10):
    """获取占用资源最多的进程"""
    processes = []
    
    for proc in psutil.process_iter(['pid', 'name', 'memory_info', 'cpu_percent']):
        try:
            pinfo = proc.info
            processes.append(pinfo)
        except (psutil.NoSuchProcess, psutil.AccessDenied):
            pass
    
    if by == 'memory':
        processes.sort(key=lambda x: x['memory_info'].rss, reverse=True)
    elif by == 'cpu':
        processes.sort(key=lambda x: x['cpu_percent'], reverse=True)
    
    return processes[:limit]


def print_top_processes():
    """打印进程排行"""
    print("=" * 70)
    print("内存占用 Top 10")
    print("=" * 70)
    print(f"{'进程名':<30} {'PID':>6} {'内存(MB)':>10} {'CPU%':>6}")
    print("-" * 70)
    
    for proc in get_top_processes('memory', 10):
        mem_mb = proc['memory_info'].rss / 1024**2
        print(f"{proc['name']:<30} {proc['pid']:>6} {mem_mb:>10.1f} {proc['cpu_percent']:>6.1f}")


def find_unnecessary_processes():
    """找出可以关闭的进程"""
    # 通常可以安全关闭的进程名（用户自启动的）
    candidates = [
        'WeChat.exe', 'WeChatWork.exe', 'QQ.exe', 'Dingtalk.exe',
        'chrome.exe', 'msedge.exe', 'firefox.exe',
        'Spotify.exe', 'NetEaseMusic.exe', 'QQMusic.exe',
        'OneDrive.exe', 'Dropbox.exe', 'BaiduNetdisk.exe',
    ]
    
    found = []
    for proc in psutil.process_iter(['pid', 'name']):
        try:
            if proc.info['name'] in candidates:
                found.append(proc.info)
        except:
            pass
    
    return found


def kill_processes(pid_list):
    """结束进程列表"""
    killed = []
    for pid in pid_list:
        try:
            proc = psutil.Process(pid)
            proc.terminate()
            killed.append(pid)
        except:
            pass
    return killed


def get_startup_programs():
    """获取开机启动项"""
    import winreg
    
    startup_programs = []
    
    # 注册表启动项位置
    key_paths = [
        r"Software\Microsoft\Windows\CurrentVersion\Run",
        r"Software\Microsoft\Windows\CurrentVersion\RunOnce",
    ]
    
    for key_path in key_paths:
        try:
            key = winreg.OpenKey(winreg.HKEY_CURRENT_USER, key_path)
            i = 0
            while True:
                try:
                    name, value, _ = winreg.EnumValue(key, i)
                    startup_programs.append({'name': name, 'path': value})
                    i += 1
                except OSError:
                    break
            winreg.CloseKey(key)
        except:
            pass
    
    return startup_programs


if __name__ == '__main__':
    print_top_processes()
    
    print("\n可以关闭的程序:")
    unneeded = find_unnecessary_processes()
    for p in unneeded:
        print(f"  {p['name']} (PID: {p['pid']})")
    
    print("\n开机启动项:")
    startups = get_startup_programs()
    for s in startups:
        print(f"  {s['name']}")

#!/usr/bin/env python
# -*- coding: utf-8 -*-
"""
一键环境诊断脚本
检查 Python 环境、依赖包、系统资源、AE 相关配置
"""

import sys
import os
import platform
import importlib
import subprocess


class EnvironmentDiagnostic:
    """环境诊断器"""
    
    def __init__(self):
        self.results = []
        self.warnings = []
        self.errors = []
    
    def check_python_version(self):
        """检查 Python 版本"""
        version = sys.version
        major, minor = sys.version_info[:2]
        
        if major >= 3 and minor >= 8:
            self.results.append(("Python 版本", f"{major}.{minor}", "✅ 通过"))
        else:
            self.errors.append(("Python 版本", f"{major}.{minor}", "❌ 需要 3.8+"))
    
    def check_os(self):
        """检查操作系统"""
        os_name = platform.system()
        os_ver = platform.version()
        
        if os_name == 'Windows':
            self.results.append(("操作系统", f"Windows {os_ver}", "✅ 通过"))
        else:
            self.warnings.append(("操作系统", os_name, "⚠️  建议 Windows"))
    
    def check_cpu(self):
        """检查 CPU"""
        cpu_count = os.cpu_count()
        cpu_name = platform.processor()
        
        if cpu_count >= 4:
            status = "✅ 良好"
        elif cpu_count >= 2:
            status = "⚠️  一般"
            self.warnings.append(("CPU 核心数", str(cpu_count), "建议 4 核以上"))
        else:
            status = "❌ 不足"
            self.errors.append(("CPU 核心数", str(cpu_count), "至少 2 核"))
        
        self.results.append(("CPU 核心数", str(cpu_count), status))
    
    def check_memory(self):
        """检查内存"""
        try:
            import psutil
            mem = psutil.virtual_memory()
            total_gb = mem.total / 1024**3
            
            if total_gb >= 16:
                status = "✅ 充足"
            elif total_gb >= 8:
                status = "⚠️  基本够用"
                self.warnings.append(("系统内存", f"{total_gb:.1f} GB", "建议 16 GB 以上"))
            else:
                status = "❌ 不足"
                self.errors.append(("系统内存", f"{total_gb:.1f} GB", "至少 8 GB"))
            
            self.results.append(("系统内存", f"{total_gb:.1f} GB", status))
        except ImportError:
            self.warnings.append(("内存检查", "无法检测", "安装 psutil 可检测"))
    
    def check_disk(self):
        """检查磁盘空间"""
        try:
            import psutil
            disk = psutil.disk_usage('.')
            free_gb = disk.free / 1024**3
            
            if free_gb >= 50:
                status = "✅ 充足"
            elif free_gb >= 20:
                status = "⚠️  紧张"
                self.warnings.append(("磁盘空间", f"{free_gb:.1f} GB 可用", "建议 50 GB 以上"))
            else:
                status = "❌ 不足"
                self.errors.append(("磁盘空间", f"{free_gb:.1f} GB 可用", "至少 20 GB"))
            
            self.results.append(("磁盘空间", f"{free_gb:.1f} GB 可用", status))
        except:
            pass
    
    def check_gpu(self):
        """检查 GPU"""
        try:
            result = subprocess.run(
                ['nvidia-smi', '--query-gpu=name,memory.total', '--format=csv,noheader'],
                capture_output=True, text=True, timeout=5
            )
            if result.returncode == 0:
                gpu_info = result.stdout.strip()
                self.results.append(("GPU", gpu_info, "✅ 可用"))
            else:
                self.warnings.append(("GPU", "未检测到", "安装显卡驱动可启用 GPU 加速"))
        except:
            self.warnings.append(("GPU", "无法检测", "可选，用于 GPU 加速"))
    
    def check_package(self, name, min_version=None):
        """检查 Python 包"""
        try:
            module = importlib.import_module(name)
            version = getattr(module, '__version__', 'unknown')
            
            if min_version:
                from packaging.version import parse
                if parse(version) >= parse(min_version):
                    self.results.append((name, version, "✅ 通过"))
                else:
                    self.warnings.append((name, version, f"⚠️  需要 {min_version}+"))
            else:
                self.results.append((name, version, "✅ 已安装"))
        except ImportError:
            self.errors.append((name, "未安装", "❌ 需要安装"))
    
    def check_ffmpeg(self):
        """检查 FFmpeg"""
        try:
            result = subprocess.run(
                ['ffmpeg', '-version'],
                capture_output=True, text=True, timeout=5
            )
            if result.returncode == 0:
                version_line = result.stdout.split('\n')[0]
                self.results.append(("FFmpeg", "已安装", "✅ 通过"))
            else:
                self.errors.append(("FFmpeg", "未找到", "❌ 请安装 FFmpeg"))
        except:
            self.warnings.append(("FFmpeg", "无法检测", "音频处理需要"))
    
    def check_all(self):
        """运行所有检查"""
        print("=" * 70)
        print("环境诊断报告")
        print("=" * 70)
        
        # 基本环境
        print("\n📋 基本环境")
        print("-" * 70)
        self.check_python_version()
        self.check_os()
        self.check_cpu()
        self.check_memory()
        self.check_disk()
        self.check_gpu()
        
        # 核心依赖
        print("\n📦 核心依赖包")
        print("-" * 70)
        core_packages = [
            ('numpy', '1.20.0'),
            ('scipy', '1.7.0'),
            ('librosa', '0.9.0'),
            ('opencv-python', None),
            ('torch', None),
        ]
        for pkg, ver in core_packages:
            self.check_package(pkg, ver)
        
        # 工具包
        print("\n🔧 工具包")
        print("-" * 70)
        util_packages = [
            ('numba', None),
            ('psutil', None),
            ('fastapi', None),
        ]
        for pkg, ver in util_packages:
            self.check_package(pkg, ver)
        
        # FFmpeg
        print("\n🎬 外部工具")
        print("-" * 70)
        self.check_ffmpeg()
        
        # 打印结果表格
        print("\n" + "=" * 70)
        print("检查结果汇总")
        print("=" * 70)
        print(f"{'项目':<25} {'详情':<25} {'状态':<15}")
        print("-" * 70)
        
        for name, detail, status in self.results:
            print(f"{name:<25} {detail:<25} {status:<15}")
        
        # 警告
        if self.warnings:
            print("\n⚠️  警告:")
            for name, detail, msg in self.warnings:
                print(f"  - {name}: {msg}")
        
        # 错误
        if self.errors:
            print("\n❌ 错误:")
            for name, detail, msg in self.errors:
                print(f"  - {name}: {msg}")
        
        # 总结
        print("\n" + "=" * 70)
        total = len(self.results) + len(self.warnings) + len(self.errors)
        passed = len(self.results)
        print(f"总计: {total} 项检查")
        print(f"通过: {passed} 项")
        print(f"警告: {len(self.warnings)} 项")
        print(f"错误: {len(self.errors)} 项")
        
        if len(self.errors) == 0:
            print("\n✅ 环境基本就绪！")
        else:
            print("\n❌ 请先解决上述错误后再使用")
        
        print("=" * 70)
        
        return len(self.errors) == 0


if __name__ == '__main__':
    diag = EnvironmentDiagnostic()
    ok = diag.check_all()
    input("\n按回车键退出...")
    sys.exit(0 if ok else 1)

        write_time = time.time() - start
        
        data_gb = arr.nbytes / 1024**3
        read_bw = data_gb / read_time

        data = os.urandom(1024 * 1024)  # 1 MB

        start = time.time()
        with open(test_file, 'wb') as f:

        # 读测试
        start = time.time()

        read_speed = size_mb / read_time

            'read_speed': read_speed,
            'write_speed': write_speed,
            'unit': 'MB/s'
        }
        
        print(f"读: {read_speed:.0f} MB/s, 写: {write_speed:.0f} MB/s")

    def bench_gpu(self):

            # 节拍检测
            tempo, beats = librosa.beat.beat_track(y=audio, sr=sr)
            
            elapsed = time.time() - start
            
            self.scores['audio'] = {
                'elapsed': elapsed,
                'audio_duration': duration,
                'rtf': elapsed / duration,  # 实时率

    def generate_report(self):

### B.3 一键日志收集脚本

```python
#!/usr/bin/env python
# -*- coding: utf-8 -*-
"""
一键日志收集脚本
收集系统信息、Python 环境、应用日志，打包为诊断包
"""

import os
import sys
import time
import json
import platform
import subprocess
import zipfile
from pathlib import Path


class LogCollector:
    """日志收集器"""
    
    def __init__(self, output_dir='diagnostic_logs'):
        self.output_dir = Path(output_dir)
        self.output_dir.mkdir(exist_ok=True)
        self.timestamp = time.strftime('%Y%m%d_%H%M%S')
        self.log_files = []
    
    def collect_system_info(self):
        """收集系统信息"""
        print("📋 收集系统信息...")
        
        info = {
            'timestamp': self.timestamp,
            'os': {
                'system': platform.system(),
                'release': platform.release(),
                'version': platform.version(),
                'machine': platform.machine(),
                'processor': platform.processor(),
            },
            'python': {
                'version': sys.version,
                'executable': sys.executable,
                'path': sys.path,
            },
            'environment': dict(os.environ),
        }
        
        # CPU 信息
        try:
            import psutil
            info['cpu'] = {
                'count': psutil.cpu_count(),
                'percent': psutil.cpu_percent(interval=1),
            }
            mem = psutil.virtual_memory()
            info['memory'] = {
                'total_gb': mem.total / 1024**3,
                'available_gb': mem.available / 1024**3,
                'percent': mem.percent,
            }
        except ImportError:
            pass
        
        # 磁盘信息
        try:
            import psutil
            disks = []
            for part in psutil.disk_partitions():
                try:
                    usage = psutil.disk_usage(part.mountpoint)
                    disks.append({
                        'device': part.device,
                        'mountpoint': part.mountpoint,
                        'fstype': part.fstype,
                        'total_gb': usage.total / 1024**3,
                        'free_gb': usage.free / 1024**3,
                        'percent': usage.percent,
                    })
                except:
                    pass
            info['disks'] = disks
        except:
            pass
        
        # GPU 信息
        try:
            result = subprocess.run(
                ['nvidia-smi'],
                capture_output=True, text=True, timeout=10
            )
            info['gpu'] = result.stdout
        except:
            info['gpu'] = '未检测到 NVIDIA GPU'
        
        filename = self.output_dir / f'system_info_{self.timestamp}.json'
        with open(filename, 'w', encoding='utf-8') as f:
            json.dump(info, f, indent=2, ensure_ascii=False)
        
        self.log_files.append(filename)
        print(f"  ✓ 保存到: {filename.name}")
    
    def collect_python_packages(self):
        """收集 Python 包列表"""
        print("📦 收集 Python 包列表...")
        
        try:
            result = subprocess.run(
                [sys.executable, '-m', 'pip', 'list', '--format=json'],
                capture_output=True, text=True, timeout=30
            )
            packages = json.loads(result.stdout)
            
            filename = self.output_dir / f'pip_packages_{self.timestamp}.json'
            with open(filename, 'w', encoding='utf-8') as f:
                json.dump(packages, f, indent=2, ensure_ascii=False)
            
            self.log_files.append(filename)
            print(f"  ✓ 共 {len(packages)} 个包")
        except Exception as e:
            print(f"  ⚠️  收集失败: {e}")
    
    def collect_application_logs(self, log_dirs=None):
        """收集应用日志"""
        print("📝 收集应用日志...")
        
        if log_dirs is None:
            log_dirs = [
                './logs',
                './log',
                './output/logs',
            ]
        
        found = 0
        for log_dir in log_dirs:
            log_path = Path(log_dir)
            if not log_path.exists():
                continue
            
            for log_file in log_path.rglob('*.log'):
                # 只收集最近的日志
                try:
                    mtime = log_file.stat().st_mtime
                    age_days = (time.time() - mtime) / 86400
                    
                    if age_days < 7:  # 最近 7 天的日志
                        dest = self.output_dir / f'app_{log_file.name}'
                        with open(log_file, 'r', encoding='utf-8', errors='ignore') as src:
                            content = src.read()
                            # 截断过大的日志
                            if len(content) > 1024 * 1024:  # 1MB
                                content = content[-512*1024:]  # 只留最后 512KB
                        
                        with open(dest, 'w', encoding='utf-8') as dst:
                            dst.write(content)
                        
                        self.log_files.append(dest)
                        found += 1
                except:
                    pass
        
        print(f"  ✓ 收集了 {found} 个日志文件")
    
    def collect_ae_info(self):
        """收集 AE 相关信息"""
        print("🎬 收集 AE 相关信息...")
        
        ae_info = {}
        
        # 查找 AE 安装
        possible_paths = [
            r"C:\Program Files\Adobe\Adobe After Effects 2025",
            r"C:\Program Files\Adobe\Adobe After Effects 2024",
            r"C:\Program Files\Adobe\Adobe After Effects 2023",
        ]
        
        for path in possible_paths:
            if os.path.exists(path):
                ae_info['installed_path'] = path
                break
        
        # AE 首选项
        ae_prefs = Path(os.environ.get('APPDATA', '')) / 'Adobe' / 'After Effects'
        if ae_prefs.exists():
            ae_info['prefs_dir'] = str(ae_prefs)
            # 列出首选项文件
            prefs_files = []
            for f in ae_prefs.rglob('*'):
                if f.is_file():
                    prefs_files.append(str(f.relative_to(ae_prefs)))
            ae_info['prefs_files'] = prefs_files[:50]  # 最多 50 个
        
        filename = self.output_dir / f'ae_info_{self.timestamp}.json'
        with open(filename, 'w', encoding='utf-8') as f:
            json.dump(ae_info, f, indent=2, ensure_ascii=False)
        
        self.log_files.append(filename)
        print(f"  ✓ AE 信息已收集")
    
    def create_summary(self):
        """创建摘要文件"""
        print("📑 创建诊断摘要...")
        
        summary = {
            'timestamp': self.timestamp,
            'total_files': len(self.log_files),
            'files': [f.name for f in self.log_files],
            'system': f"{platform.system()} {platform.release()}",
            'python': sys.version.split()[0],
        }
        
        filename = self.output_dir / f'README_{self.timestamp}.md'
        with open(filename, 'w', encoding='utf-8') as f:
            f.write(f"# 诊断报告 - {self.timestamp}\n\n")
            f.write(f"## 基本信息\n\n")
            f.write(f"- 收集时间: {self.timestamp}\n")
            f.write(f"- 操作系统: {summary['system']}\n")
            f.write(f"- Python 版本: {summary['python']}\n")
            f.write(f"- 日志文件数: {summary['total_files']}\n\n")
            f.write(f"## 文件清单\n\n")
            for fname in summary['files']:
                f.write(f"- {fname}\n")
        
        self.log_files.append(filename)
        print(f"  ✓ 摘要已创建")
    
    def create_zip(self):
        """打包为 ZIP"""
        print("📦 打包诊断包...")
        
        zip_name = f'diagnostic_package_{self.timestamp}.zip'
        zip_path = self.output_dir.parent / zip_name
        
        with zipfile.ZipFile(zip_path, 'w', zipfile.ZIP_DEFLATED) as zf:
            for log_file in self.log_files:
                zf.write(log_file, log_file.name)
        
        size_mb = zip_path.stat().st_size / 1024**2
        print(f"  ✓ 已打包: {zip_name} ({size_mb:.1f} MB)")
        
        return zip_path
    
    def run(self, log_dirs=None):
        """运行完整收集"""
        print("=" * 70)
        print("📋 一键日志收集工具")
        print("=" * 70)
        print()
        
        self.collect_system_info()
        self.collect_python_packages()
        self.collect_application_logs(log_dirs)
        self.collect_ae_info()
        self.create_summary()
        zip_path = self.create_zip()
        
        print("\n" + "=" * 70)
        print("✅ 收集完成！")
        print(f"📦 诊断包: {zip_path}")
        print("=" * 70)
        
        return zip_path


if __name__ == '__main__':
    collector = LogCollector()
    collector.run()
    input("\n按回车键退出...")
```
