## 📐 数学模型与物理仿真

### 十四、弹簧-质点系统参数

```
公式: F = -k * x + c * v

其中:
- k = 弹簧刚度系数 (推荐: 50-200, 角色越硬越高)
- c = 阻尼系数 (推荐: 0.1-0.5, 越高衰减越快)
- x = 位移量 (当前位置 - 平衡位置)
- v = 速度 (位移变化率)

时间步长积分:
x(t+dt) = x(t) + v(t) * dt
v(t+dt) = v(t) + F/m * dt

推荐参数组合:
- 柔软布料: k=50, c=0.2
- 披风飘动: k=80, c=0.3
- 角色肢体: k=150, c=0.4
- 硬物体: k=200, c=0.5
```

### 十五、IK求解参数

```
CCD (Cyclic Coordinate Descent) 算法参数:
- 最大迭代次数: 100-500 (精度要求高时取大值)
- 收敛阈值: 0.001-0.01 (越小精度越高)
- 步长: 0.1-1.0 (越小越稳定)

FABRIK (Forward And Backward Reaching Inverse Kinematics) 算法参数:
- 前向迭代: 3-10次 (从末端向根部)
- 后向迭代: 3-10次 (从根部向末端)
- 容差: 0.5-2.0px (目标位置误差)

Jacobian 伪逆算法参数:
- 阻尼因子: 0.01-0.1 (防止奇异)
- 最大步长: 0.1-1.0 (每次迭代最大变化)
- 权重矩阵: 对角矩阵，控制各关节优先级
```

function createGroundShake(time, duration) {
    var groundLayer = null;
    for (var i = 1; i <= comp.numLayers; i++) {
        var layer = comp.layer(i);
        if (layer.name.indexOf("地面") !== -1 || layer.name.indexOf("Ground") !== -1) {
            groundLayer = layer;
            break;
        }
    }
    
    if (groundLayer) {
        var pos = groundLayer.property("Position");
        var originalPos = pos.value;
        
        pos.setValueAtTime(time, originalPos);
        for (var t = 0; t < duration / 0.1; t++) {
            var shakeTime = time + t * 0.1;
            var shakeAmount = Math.max(0, 15 - t * 2);
            pos.setValueAtTime(shakeTime, [originalPos[0] + wiggle(10, shakeAmount)[0], originalPos[1] + wiggle(10, shakeAmount)[1]]);
        }
        pos.setValueAtTime(time + duration, originalPos);
    }
    
    return groundLayer;
}
