## 二、6种歌词动画风格

### 2.1 pop_per_char (逐字弹出)

**适用**：标题/关键词入场
**实现**：Text Animator + Range Selector + Scale 3D [0,0,0]

```javascript
// JSX 核心代码
var TA = layer.property('Text').property('ADBE Text Animators').addProperty('ADBE Text Animator');
var RS = TA.property('ADBE Text Selectors').addProperty('ADBE Text Selector');
var Props = TA.property('ADBE Text Animator Properties');
Props.addProperty('ADBE Text Scale 3D').setValue([0, 0, 0]);
// Range Selector 表达式驱动
RS.property('ADBE Text Percent Start').expression = 
  'var spd = 2.5;\nvar t0 = ' + startTime + ';\n' +
  'clamp((time - t0) * spd / 100, 0, 1) * 100;';
```

### 2.2 slam (冲击缩放)

**适用**：能量峰/drop 处的强拍词
**实现**：Scale 300%→90%→105%→100% (0.25s内完成)

```javascript
layer.property('Scale').setValueAtTime(t, [300, 300]);
layer.property('Scale').setValueAtTime(t + 0.08, [90, 90]);
layer.property('Scale').setValueAtTime(t + 0.15, [105, 105]);
layer.property('Scale').setValueAtTime(t + 0.25, [100, 100]);
```

### 2.3 slam_rgb (冲击+RGB分离)

**适用**：高潮段/终极冲击
**实现**：slam动画 + 创建 RGB_R_(红, x-6px) 和 RGB_C_(青, x+6px) 副本层

```javascript
// 主层: Scale 400%→85%→108%→100%
// RGB_R_ 层: fillColor=[1,0,0], position.x -= 6, blendMode=SCREEN, opacity=60
// RGB_C_ 层: fillColor=[0,1,1], position.x += 6, blendMode=SCREEN, opacity=60
```

### 2.4 typewriter (打字机)

**适用**：长句/叙述性歌词
**实现**：Text Animator + ADBE Text Opacity=0 + Percent End 表达式

```javascript
Props.addProperty('ADBE Text Opacity').setValue(0);
RS.property('ADBE Text Percent End').expression = 
  'var t0 = ' + start + '; var dur = ' + duration + ';\n' +
  'clamp((time - t0) / dur * 100, 0, 100);';
```

### 2.5 fade_slide (渐入上滑)

**适用**：过渡句/柔和入场
**实现**：Position Y+40→Y + Opacity 0→100 (0.3s)

### 2.6 finale (终场脉冲)

**适用**：最后一句/大结局
**实现**：Scale 0→110→100 + 节拍脉冲表达式

```javascript
layer.property('Scale').expression = 
  'var bpm = 143.6;\nvar beat = 60/bpm;\n' +
  'var t0 = ' + (start + 0.35) + ';\n' +
  'var dt = (time - t0) % beat;\n' +
  'var pulse = 1 + 0.03 * Math.exp(-dt * 8);\n' +
  '[value[0] * pulse, value[1] * pulse];';
```

## 三、歌词-节拍对齐方法

### 3.1 数据流

```
beat_data.json (librosa分析)
├── downbeats[24] → 每句歌词的 start 时间
├── energy_peaks[8] → 选择 slam/slam_rgb 风格的触发点
├── segments[5] → 段落划分 → 动画风格分配策略
└── bpm=143.6 → finale脉冲表达式的节拍周期
```

### 3.2 风格分配策略

| 段落 | 时间范围 | 情绪 | 推荐风格 |
|------|---------|------|---------|
| Intro | 0-0.92s | 静默 | 无歌词 |
| Build | 0.92-10.94s | 渐起 | pop_per_char + typewriter 交替 |
| Drop/Peak | 10.94-21.0s | 爆发 | slam_rgb + slam + pop_per_char |
| Sustain | 21.0-31.16s | 持续 | pop_per_char + slam + fade_slide |
| Outro | 31.16-40.0s | 终极 | slam_rgb快速切换 + finale |

### 3.3 排版规则

- **关键词** (highlight=True): 字号 100-200px, 颜色鲜明, x/y 错落偏移
- **叙述句** (highlight=False): 字号 40-56px, 灰白色, tracking=20, 居中偏下
- **错落布局**: 相邻歌词 x 坐标交替偏移 ±200px, y 坐标分层 (400/550/680)
- **终极拆字**: "ALL EYES ON ME" 拆为4个独立层, 每字不同位置+颜色+0.8s间隔

## 四、轻量化渲染方案

### 4.1 aerender 直出 MP4 (推荐迭代期使用)

```python
AERENDER = r"C:\Program Files\Adobe\Adobe After Effects 2025\Support Files\aerender.exe"
render_cmd = [AERENDER, "-project", aep_path, "-comp", "CompName", "-output", "output.mp4"]
subprocess.run(render_cmd, timeout=600)
```

**优势**：
- 跳过 7GB 无损 AVI 中间产物
- 一步输出 H.264 MP4 (AE 自动根据 .mp4 后缀选择编码器)
- 40s/1080p 约 90s 完成, 输出 ~13MB

### 4.2 正式交付渲染 (质量优先)

```python
# 方案A: AE渲染队列无损 → ffmpeg CRF18
# 方案B: aerender + -format "H.264" + 自定义输出模块(高码率)
```

### 4.3 中文AE兼容性要点

| 问题 | 解决方案 |
|------|---------|
| 字体名含空格报错 | 用PostScript名 `Arial-Black` + try-catch |
| 渲染模板名本地化 | 循环尝试 `['Lossless','Best Settings','无损','最佳设置']` |
| 遮罩属性名 | 用matchName: `ADBE Mask Parade` / `ADBE Mask Shape` |
| JSX字符串含撇号 | `text.replace("'", "\\'")` 转义 |

## 六、能量峰闪白 + 相机震动

### 6.1 闪白层

```javascript
var flash = comp.layers.addSolid([1,1,1], 'Flash', 1920, 1080, 1);
flash.property('Opacity').setValue(0);
// 每个能量峰: 0→90→0 (0.15s内)
flash.property('Opacity').setValueAtTime(peak - 0.03, 0);
flash.property('Opacity').setValueAtTime(peak, 90);      // MAX峰用90
flash.property('Opacity').setValueAtTime(peak + 0.12, 0); // 普通峰用60
```

### 6.2 相机漂移+震动表达式

```javascript
// Camera Position 表达式
var t = time;
var x = 960 + Math.sin(t * 0.3) * 30;  // 慢速水平漂移
var y = 540 + Math.cos(t * 0.2) * 20;  // 慢速垂直漂移
// 能量峰震动
var peaks = [5.64, 9.28, 12.97, 31.16, 36.25];
var shake = [0,0,0];
for (var i = 0; i < peaks.length; i++) {
  var dt = t - peaks[i];
  if (dt >= 0 && dt < 0.4) {
    var d = 1 - dt / 0.4;  // 衰减
    shake[0] += (seedRandom(i*7+1, true) - 0.5) * 12 * d;
    shake[1] += (seedRandom(i*7+2, true) - 0.5) * 12 * d;
  }
}
[x + shake[0], y + shake[1], 0];
```
