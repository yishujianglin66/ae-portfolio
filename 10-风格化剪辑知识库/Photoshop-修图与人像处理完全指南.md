# Photoshop 修图与人像处理完全指南

> 版本: 2025-v1 | 适用: 人像精修/商业修图/风格化处理

## 一、人像修图工作流

### 1.1 标准修图流程

```
1. RAW处理(Camera Raw)
   → 曝光/白平衡/镜头校正
2. 基础调整
   → 曲线/色阶/色彩平衡
3. 瑕疵修复
   → 修复画笔/污点修复/仿制图章
4. 肤色统一
   → 频率分离/可选颜色
5. 五官精修
   → 加深减淡(Dodge & Burn)
6. 身形调整
   → 液化
7. 风格化
   → 调色/颗粒/暗角
8. 锐化输出
   → USM锐化/智能锐化
```

### 1.2 修复工具对比

| 工具 | 原理 | 最佳用途 |
|------|------|---------|
| 污点修复画笔 | 自动采样周围 | 小瑕疵/痘印 |
| 修复画笔 | 手动采样+匹配 | 较大瑕疵 |
| 仿制图章 | 直接复制像素 | 精确修复/克隆 |
| 内容感知填充 | AI分析填充 | 大区域去除 |
| 修复画笔(增强) | AI驱动 | 复杂修复 |

### 1.3 加深减淡(Dodge & Burn)

```
原理: 通过局部提亮(减淡)和压暗(加深)来塑造光影
工具: 减淡工具(O) / 加深工具(O)
或使用: 中性灰图层(50%灰) + 柔光模式 + 画笔

中性灰流程:
1. 新建图层 → 填充50%灰色
2. 混合模式: 柔光
3. 减淡: 白色画笔(低流量10-20%)提亮
4. 加深: 黑色画笔(低流量10-20%)压暗
5. 塑造面部轮廓/消除瑕疵/增强立体感
```

## 二、频率分离精修

### 2.1 完整流程

```
步骤1: 创建频率分离
  - 复制两层(低频+高频)
  - 低频: 高斯模糊(半径8-15)
  - 高频: 应用图像(低频, 减去, 缩放2, 补偿128)
  - 高频混合模式: 线性光

步骤2: 低频层修肤色
  - 选择柔软画笔(硬度0%, 流量30%)
  - 吸取均匀肤色
  - 涂抹不均匀区域
  - 只改颜色，不动纹理

步骤3: 高频层修瑕疵
  - 修复画笔/仿制图章
  - 去除痘印/疤痕/杂毛
  - 只改纹理，不动颜色
```

### 2.2 频率分离变体

| 变体 | 分离层数 | 用途 |
|------|---------|------|
| 2层分离 | 低频+高频 | 基础修图 |
| 3层分离 | 低频+中频+高频 | 更精细控制 |
| 5层分离 | 多个频率层 | 商业级精修 |

## 三、液化(Liquify)

### 3.1 液化工具

| 工具 | 功能 | 用途 |
|------|------|------|
| 向前变形 | 推像素 | 微调轮廓 |
| 重建 | 恢复原始 | 修正过度 |
| 平滑 | 平滑区域 | 柔化线条 |
| 湍流 | 随机变形 | 创意效果 |
| 褶皱 | 收缩 | 缩小区域 |
| 膨胀 | 扩展 | 放大区域 |
| 左推 | 向左推 | 对称调整 |
| 镜像 | 对称变形 | 对称修正 |
| 面部感知 | AI识别面部 | 五官微调 |

### 3.2 面部感知液化

| 参数 | 控制 | 范围 |
|------|------|------|
| 眼睛大小 | 眼睛缩放 | -100~100 |
| 眼睛高度 | 眼睛上下 | -100~100 |
| 眼睛距离 | 两眼间距 | -100~100 |
| 鼻子宽度 | 鼻翼宽度 | -100~100 |
| 鼻子高度 | 鼻尖位置 | -100~100 |
| 嘴部微笑 | 嘴角上扬 | -100~100 |
| 上唇 | 上唇厚度 | -100~100 |
| 下唇 | 下唇厚度 | -100~100 |
| 脸部宽度 | 整体脸宽 | -100~100 |
| 下颌 | 下颌形状 | -100~100 |

### 3.3 液化最佳实践

```
1. 在智能对象上操作(可重新编辑)
2. 面部感知优先(比手动推更自然)
3. 微调原则: 单次调整不超过±20
4. 重建工具随时修正过度区域
5. 冻结蒙版: 保护不需要变形的区域
```

## 四、商业人像修图标准

### 4.1 肤色标准

| 指标 | 标准值 | 说明 |
|------|--------|------|
| 肤色色相 | 25-35° | 矢量示波器肤色线 |
| 肤色饱和度 | 30-50 IRE | 自然 |
| 亮度均匀性 | ±5 IRE | 面部无明显色差 |
| 瑕疵覆盖率 | >95% | 商业标准 |

### 4.2 修图检查清单

```
□ 眼睛: 对称、明亮、无红眼
□ 皮肤: 均匀、无瑕疵、无油光
□ 鼻子: 对称、高光自然
□ 嘴唇: 对称、颜色均匀
□ 头发: 无杂毛、边缘自然
□ 颈部: 无颈纹、颜色与脸一致
□ 身形: 线条流畅、无扭曲痕迹
□ 背景: 干净、无干扰元素
□ 整体: 肤色统一、光影自然
```

## 五、批量处理与自动化

### 5.1 动作(Action)录制

```
录制流程:
1. 动作面板 → 新建动作
2. 执行一系列操作
3. 停止录制
4. 批处理: 文件→自动→批处理

常用批处理动作:
- 调整大小+锐化+保存
- 水印添加
- 色彩校正(应用LUT)
- 社交媒体裁切
```

### 5.2 ExtendScript 批量修图

```javascript
// batch_resize_export.jsx
var folder = Folder.selectDialog("选择文件夹");
var files = folder.getFiles("*.jpg");

for (var i = 0; i < files.length; i++) {
    var doc = app.open(files[i]);
    // 调整大小
    doc.resizeImage(1920, 1080, 72);
    // 锐化
    doc.activeLayer.applySmartSharpen(80, 1.5);
    // 导出
    var outFile = new File(folder + "/output_" + files[i].name);
    var opts = new JPEGSaveOptions();
    opts.quality = 10;
    doc.saveAs(outFile, opts);
    doc.close(SaveOptions.DONOTSAVECHANGES);
}
```
