# 音画匹配实战案例库与知识图谱

> [!abstract] 文档摘要
> 本文档提供 12 个完整的音画匹配推演案例，涵盖不同音乐类型（电子/流行/抒情/EDM）和不同风格目标（赛博朋克/电影感/梦幻/MG）。每个案例包含完整的输入原子、推演过程、输出 CompilerInput 和预判结果。同时构建跨案例的知识图谱。

> [!tip] 使用指南
> - 学习者：从案例1开始读，逐步理解推演过程
> - 开发者：参考案例作为单元测试输入

## 第二章 案例 C01：EDM 赛博朋克卡点

### 2.1 输入

**音乐**：Trance 128bpm，3分钟

```yaml
music_atom:
  rhythm:
    bpm: 128
    time_signature: "4/4"
    beat_grid: [0.47, 0.94, 1.41, ...]  # 共 384 个节拍
    downbeats: [0.47, 2.35, 4.23, ...]  # 96 个强拍
  structure:
    segments:
      - {type: "intro",    start: 0,    end: 15,   energy: 0.2}
      - {type: "build",    start: 15,   end: 45,   energy: 0.4}   # 能量渐增
      - {type: "drop",     start: 45,   end: 75,   energy: 0.95}  # 高潮
      - {type: "breakdown",start: 75,   end: 90,   energy: 0.3}   # 抽空
      - {type: "build",    start: 90,   end: 120,  energy: 0.5}
      - {type: "drop",     start: 120,  end: 150,  energy: 1.0}   # 终极爆发
      - {type: "outro",    start: 150,  end: 180,  energy: 0.2}
  energy:
    peaks:
      - {time: 45.0,  intensity: 0.95, type: "drop"}
      - {time: 120.0, intensity: 1.0,  type: "drop"}
  spectrum:
    sub_bass_peak: 45.0    # 次低频爆发
    bass_dominant: true
```

**片段**：

```yaml
clips:
  - file: "cityscape_night.mp4"
    duration: 12s
    motion: {intensity: 0.4, direction: "right", camera: "pan_right"}
    color: {palette: ["#1a0033", "#00ffea", "#ff007a"], temperature: "cool", saturation: 0.8}
    energy: {overall: 0.5, peak_time: 6.0}
    semantic: {scene_type: "cityscape", mood: ["mysterious", "energetic"]}
  
  - file: "neon_signs.mp4"
    duration: 8s
    motion: {intensity: 0.3, direction: "static", camera: "static"}
    color: {palette: ["#ff007a", "#00ffea", "#9d00ff"], temperature: "cool", saturation: 0.9}
    energy: {overall: 0.7, peak_time: 4.0}
    semantic: {scene_type: "cityscape", mood: ["intense", "vibrant"]}
  
  - file: "highway_drive.mp4"
    duration: 15s
    motion: {intensity: 0.8, direction: "forward", camera: "forward"}
    color: {palette: ["#1a0033", "#00aaff", "#ffffff"], temperature: "cool", saturation: 0.6}
    energy: {overall: 0.8, peak_time: 7.5}
    semantic: {scene_type: "action", mood: ["intense", "fast"]}
```

### 2.2 推演过程

```yaml
reasoning_path:
  - step: "P1 音乐分析"
    notes: "BPM=128，强节奏电子，2个drop段（45s和120s），sub_bass 在 drop 段爆发"
  
  - step: "P2 片段分析"
    notes: "3个片段都是冷调城市夜景，色板与赛博朋克完美匹配。highway_drive 运动强度最高（0.8），适合 drop 段"
  
  - step: "P3 段落-片段配对"
    notes: "intro→cityscape_night(冷开场), build→neon_signs(铺垫), drop→highway_drive(高潮爆发), breakdown→cityscape_night(回到冷静), 第二drop→highway_drive(终极爆发)"
    energy_match_score: 0.92
  
  - step: "P4 节拍对齐"
    notes: "drop 段切镜密度=0.5/s（每2拍切一次），其他段=0.2/s"
    beat_alignment_score: 0.95
  
  - step: "P5 效果绑定"
    bindings:
      - time_range: [0, 15]
        effect: "soft_glow"
        intensity: 0.3
        reason: "intro 段 sub_bass 低，仅叠加柔和发光"
      
      - time_range: [15, 45]
        effect: "glitch_buildup"
        intensity: 0.5
        reason: "build 段 bass 渐强，叠加渐强故障"
      
      - time_range: [45, 75]
        effects: ["glow", "glitch", "particles", "shake"]
        intensity: 0.9
        reason: "drop 段全频段爆发，多效果叠加"
      
      - time_range: [75, 90]
        effect: "soft_glow"
        intensity: 0.2
        reason: "breakdown 抽空，仅柔和效果"
      
      - time_range: [120, 150]
        effects: ["glow", "glitch", "particles", "shake", "flash"]
        intensity: 1.0
        reason: "终极 drop，全效果叠加+闪光"
  
  - step: "P6 转场方案"
    transitions:
      - {time: 15, type: "zoom_blur", reason: "build 段进入"}
      - {time: 45, type: "flash", reason: "drop 爆发"}
      - {time: 75, type: "dissolve", reason: "进入 breakdown"}
      - {time: 90, type: "zoom_blur", reason: "重新 build"}
      - {time: 120, type: "flash", reason: "终极 drop"}
  
  - step: "P7 剪辑思路"
    narrative: ["cold_open", "build", "explosion", "release", "finale"]
    energy_curve_target: [0.2, 0.4, 0.95, 0.3, 1.0]
    pacing_curve: "intro=0.1/s, build=0.3/s, drop=0.5/s, breakdown=0.05/s, finale=0.5/s"
```

## 第三章 案例 C02：抒情电影感

### 3.1 输入

**音乐**：抒情流行 90bpm，4分钟

```yaml
music_atom:
  rhythm:
    bpm: 90
    time_signature: "4/4"
  structure:
    segments:
      - {type: "intro", start: 0,    end: 20,  energy: 0.15}
      - {type: "verse", start: 20,   end: 60,  energy: 0.3}
      - {type: "chorus",start: 60,   end: 100, energy: 0.6}
      - {type: "verse", start: 100,  end: 140, energy: 0.35}
      - {type: "chorus",start: 140,  end: 180, energy: 0.65}
      - {type: "outro", start: 180,  end: 240, energy: 0.2}
  spectrum:
    high_mid_dominant: true   # 中高频为主（人声）
  emotional:
    valence: 0.7
    arousal: 0.4
    dominant_key: "G major"
    mode: "major"
```

**片段**：4个人物特写

```yaml
clips:
  - {file: "portrait_smile.mp4",  duration: 10s, mood: "warm",     energy: 0.4}
  - {file: "portrait_think.mp4",  duration: 8s,  mood: "contemplative", energy: 0.3}
  - {file: "portrait_laugh.mp4",  duration: 6s,  mood: "joyful",   energy: 0.6}
  - {file: "portrait_walk.mp4",   duration: 12s, mood: "active",   energy: 0.5}
```

### 3.2 推演过程摘要

```yaml
reasoning_path:
  - "BPM=90 慢板，建议低切镜密度 0.1-0.2/s"
  - "电影感风格：长镜头为主，转场用 dissolve"
  - "情绪：valence=0.7 积极，配大调歌曲"
  - "色彩调色：橙青对比（电影感经典）"
  - "效果叠加：Vignette + Film Grain + Curves（S曲线）"
  - "verse 段：portrait_think（沉思），chorus 段：portrait_laugh（愉悦）"
```

### 3.3 输出预判

```yaml
outcome_prediction:
  visual_style:
    primary_style: "cinematic"
    match_score: 0.85
    color_palette: ["#ff9966", "#66ccff", "#1a1a1a"]  # 橙青对比
  rhythm:
    cut_density: 0.12
    average_shot_length: 8.3
  quality_assessment:
    overall_score: 8.4
```
