# Photoshop 蒙版与通道深度指南

> 版本: 2025-v1 | 适用: 合成/抠像/调色核心工作流

## 一、蒙版系统

### 1.1 蒙版类型

| 类型 | 特性 | 可编辑性 | 用途 |
|------|------|---------|------|
| 图层蒙版 | 灰度控制透明度 | 完全可编辑 | 非破坏性隐藏/显示 |
| 矢量蒙版 | 路径控制形状 | 贝塞尔编辑 | 硬边遮罩 |
| 剪贴蒙版 | 下层形状控制上层可见 | 移动下层 | 文字填充/形状约束 |
| 快速蒙版 | 临时选区编辑 | 转换为选区 | 精细选区创建 |

### 1.2 图层蒙版核心操作

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 添加图层蒙版 | 图层面板底部蒙版按钮 | 白色(全显示) |
| 添加隐藏全部蒙版 | Alt+蒙版按钮 | 黑色(全隐藏) |
| 停用/启用蒙版 | Shift+点击蒙版 | 临时关闭 |
| 查看蒙版 | Alt+点击蒙版 | 灰度视图 |
| 应用蒙版 | 右键→应用图层蒙版 | 永久删除像素 |
| 从蒙版建立选区 | Ctrl+点击蒙版 | 载入选区 |

### 1.3 蒙版编辑技巧

```
画笔绘制蒙版:
- 黑色画笔 = 隐藏(擦除)
- 白色画笔 = 显示(恢复)
- 灰色画笔 = 半透明
- 硬度0% = 柔和过渡
- 硬度100% = 硬边

渐变蒙版:
- 黑白渐变 = 平滑过渡
- 用于天空替换/全景融合

滤镜辅助蒙版:
- 高斯模糊蒙版 = 柔和边缘
- 最小值/最大值 = 收缩/扩展
- 色阶/曲线 = 调整蒙版对比度
```

## 二、通道系统

### 2.1 通道类型

| 类型 | 数量 | 用途 |
|------|------|------|
| 颜色通道(RGB) | 3个(R/G/B) | 存储颜色信息 |
| 复合通道 | 1个(RGB) | 预览合成效果 |
| Alpha通道 | 用户创建 | 存储选区/遮罩 |
| 专色通道 | 用户创建 | 印刷专色 |

### 2.2 通道与选区的关系

```
通道 = 灰度图像 = 选区的存储形式
白色 = 选中(255)
黑色 = 未选中(0)
灰色 = 部分选中(1-254)

操作:
通道 → 载入选区: Ctrl+点击通道
选区 → 存储为通道: 选择→存储选区
```

### 2.3 通道抠像(高级)

#### 通道抠像流程(适合毛发/半透明)

```
1. 打开通道面板，找到对比度最高的通道
2. 复制该通道(Ctrl+J)
3. 色阶(Ctrl+L)增强对比度
   - 黑色滑块右移(背景更黑)
   - 白色滑块左移(主体更白)
4. 用画笔修正细节(黑色填充背景)
5. Ctrl+点击复制通道 → 载入选区
6. 回到图层面板 → 添加图层蒙版
7. 边缘精修: 选择并遮住(Refine Edge)
```

#### 通道抠像适用场景

| 场景 | 最佳通道 | 难度 |
|------|---------|------|
| 绿色植物 | 红色通道 | 中 |
| 毛发/头发 | 对比度最高通道 | 高 |
| 烟雾/火焰 | 对应颜色通道 | 中 |
| 半透明物体 | 计算通道 | 高 |
| 婚纱/蕾丝 | 蓝色通道 | 高 |

## 三、选择并遮住(Refine Edge)

### 3.1 核心参数

| 参数 | 范围 | 作用 |
|------|------|------|
| 半径 | 0-250px | 边缘检测范围 |
| 平滑 | 0-100 | 边缘平滑度 |
| 羽化 | 0-250px | 边缘柔化 |
| 对比度 | 0-100% | 边缘锐度 |
| 移动边缘 | -100~+100% | 收缩/扩展选区 |
| Shift Edge | -100~+100% | 边缘偏移 |

### 3.2 输出设置

| 选项 | 效果 |
|------|------|
| 输出到: 图层蒙版 | 最常用，非破坏性 |
| 输出到: 新建带图层蒙版的图层 | 保留原始 |
| 输出到: 选区 | 仅创建选区 |
| 输出到: 新建文档 | 独立文件 |
| 净化颜色 | 去除边缘色溢 |

## 四、计算与应用图像

### 4.1 计算(Calculations)

- **用途**: 将两个通道的像素混合，创建新通道
- **混合模式**: 与图层混合模式相同
- **应用**: 创建复杂遮罩、增强通道对比度

### 4.2 应用图像(Apply Image)

- **用途**: 将一个图层的像素混合到当前图层
- **应用**: 频率分离中的高低频混合

## 五、频率分离(高级修图)

### 5.1 原理

```
频率分离 = 低频层(颜色/光影) + 高频层(纹理/细节)
- 低频: 控制肤色均匀度
- 高频: 控制毛孔/纹理/细节
- 独立调整 = 修色不损纹理，修纹理不影响颜色
```

### 5.2 操作步骤

```
1. 复制两层: 低频层 + 高频层
2. 低频层: 应用高斯模糊(半径5-15px，模糊到看不到纹理)
3. 高频层: 应用图像 → 选择低频层 → 减去
   - 缩放: 2
   - 补偿值: 128
   - 混合模式改为: 线性光
4. 修图:
   - 低频层上: 用画笔修肤色(颜色均匀)
   - 高频层上: 用修复画笔修瑕疵(不损肤色)
```

## 六、蒙版自动化(ExtendScript)

### 6.1 批量蒙版脚本

```javascript
// batch_mask.jsx - 批量创建蒙版
var doc = app.activeDocument;
var layer = doc.activeLayer;

// 创建基于亮度的蒙版
var origSelection = doc.selection;
doc.selection.load(doc.channels[0]); // 从红通道载入选区
layer.mask.fromSelection(); // 从选区创建蒙版
```
