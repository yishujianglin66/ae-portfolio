# 其他重要插件与脚本详解

> 除了四大核心套件（Trapcode/Sapphire/BCC/VideoCopilot）外，AE 生态中还有大量专业插件和脚本，覆盖物理动力学、角色绑定、表面跟踪、3D粒子、运动图形等细分领域。

---

## 一、Newton 3 — 2D 物理动力学

> Motion Boutique 出品的 2D 刚体物理模拟插件，让 AE 图层拥有真实的重力、碰撞、弹跳等物理行为。

### 1.1 核心概念

| 概念 | 说明 |
|------|------|
| **Body（物体）** | 参与物理模拟的图层 |
| **Body Type（类型）** | Static（静态）/ Dynamic（动态）/ Kinematic（运动学）/ Dormant（休眠） |
| **Collider（碰撞体）** | 参与碰撞检测的物体 |
| **Joints（关节）** | 连接两个物体的约束（Pivot/Distance/Spring/Pulley等） |
| **Magnet（磁铁）** | 吸引力/排斥力场 |

### 1.2 物体属性

| 属性 | 范围 | 说明 |
|------|------|------|
| **Type** | Static / Dynamic / Kinematic / Dormant | 物体类型 |
| **Density** | 0-10 | 密度（影响质量） |
| **Bounciness / Restitution** | 0-1 | 弹性/反弹系数 |
| **Friction** | 0-1 | 摩擦系数 |
| **Linear Damping** | 0-10 | 线性阻尼（空气阻力） |
| **Angular Damping** | 0-10 | 角度阻尼 |
| **Initial Velocity X/Y** | - | 初始速度 |
| **Initial Angular Velocity** | - | 初始角速度 |
| **Collision Group** | - | 碰撞组（控制哪些物体互相碰撞） |
| **Shape** | Auto / Rectangle / Circle / Polygon / Mask | 碰撞形状 |

### 1.3 全局物理属性

| 属性 | 范围 | 说明 |
|------|------|------|
| **Gravity X/Y** | - | 重力方向与大小（默认Y=1） |
| **Time Scale** | 0-5 | 时间缩放（慢动作/快放） |
| **Substeps** | 1-10 | 子步数（精度越高越稳定） |
| **Solver Iterations** | 1-100 | 求解器迭代次数 |
| **Auto Clean** | On/Off | 自动清理超出画面的物体 |

### 1.4 关节类型

| 关节 | 说明 |
|------|------|
| **Pivot Joint** | 枢轴关节（两点间旋转） |
| **Distance Joint** | 距离关节（两点保持固定距离） |
| **Spring Joint** | 弹簧关节（弹性距离） |
| **Piston Joint** | 活塞关节（线性运动） |
| **Pulley Joint** | 滑轮关节 |
| **Gear Joint** | 齿轮关节 |
| **Wheel Joint** | 车轮关节 |

### 1.5 典型应用

- 文字散落/堆积动画
- 物体掉落弹跳
- 机械连杆/联动装置
- 弹簧/绳索动画
- 多米诺骨牌效应
- 破碎/爆炸碎片
- 玻璃碎裂效果

## 二、Stardust — 节点式 3D 粒子系统

> Superluminal 出品的节点式 3D 粒子插件，基于节点工作流，灵活性极高。本地安装 18 个效果模块。

### 2.1 核心模块（节点）

| 模块 | 说明 |
|------|------|
| **Emitter** | 发射器（Point/Box/Sphere/Light/Layer/Path） |
| **Particle** | 粒子属性（大小/颜色/不透明度/旋转/形状） |
| **Physics** | 物理（重力/风力/阻力/湍流/碰撞） |
| **Force** | 力场（球面力/径向力/涡旋力/层贴图力） |
| **Turbulence** | 湍流/分形场 |
| **Replica** | 复制器（阵列复制/复制粒子） |
| **Aux System** | 辅助系统（子粒子/拖尾） |
| **Path** | 路径粒子（沿路径运动） |
| **Model** | 3D 模型粒子 |
| **Text** | 文字粒子 |
| **Volume** | 体积粒子（烟雾/云） |
| **Light** | 灯光节点 |
| **Camera** | 摄像机节点 |
| **World** | 世界/环境 |
| **Render** | 渲染设置 |

### 2.2 关键特性

- **节点工作流**：可视化连接，灵活组合
- **3D 空间粒子**：真实的 3D 粒子系统
- **体积渲染**：真正的体积光/体积雾
- **3D 模型**：支持 OBJ 模型作为粒子
- **路径发射**：沿路径发射粒子
- **图层映射**：用图层控制粒子属性
- **表达式**：支持 JavaScript 表达式
- **预设库**：内置大量效果预设
- **性能优化**：GPU 加速渲染

### 2.3 与 Particular 的对比

| 特性 | Stardust | Particular |
|------|---------|-----------|
| 工作流 | 节点式 | 参数面板 |
| 灵活性 | 极高 | 高 |
| 学习曲线 | 较陡 | 较平缓 |
| 体积渲染 | 优秀 | 一般 |
| 3D 模型 | 原生支持 | 需精灵粒子 |
| 渲染速度 | 快 | 快 |
| 预设丰富度 | 中 | 高 |
| 表达式 | JS原生 | 有限支持 |

## 三、Lockdown — 表面跟踪/变形追踪

> 把效果/纹理追踪到曲面（衣服、皮肤、建筑等）上的专业跟踪插件。

### 3.1 核心功能

| 功能 | 说明 |
|------|------|
| **Surface Tracking** | 表面跟踪，将效果锁定到移动物体表面 |
| **Warp Stabilizer** | 扭曲稳定，校正变形 |
| **Mesh Deformation** | 网格变形，适应曲面变化 |
| **Corner Pin + Warp** | 四角定位+曲面变形 |
| **Mask Tracking** | 遮罩跟踪 |

### 3.2 工作流程

1. **创建跟踪点**：在画面上放置跟踪点
2. **自动跟踪**：Lockdown 自动跟踪每个点
3. **生成网格**：根据跟踪点生成变形网格
4. **应用效果**：把效果/图层应用到跟踪的曲面上
5. **精细调整**：手动修正跟踪误差

### 3.3 典型应用

- 在皮肤上贴纹身/Logo
- 衣服上贴图/文字
- 建筑墙面贴海报
- 曲面屏幕替换
- 包裹文字到物体表面
- 替换汽车贴纸/涂装

## 四、Duik Bassel / Duik Angela — 角色骨骼绑定

> Duik 是 AE 最强大的免费角色动画插件，支持骨骼绑定、IK/FK、皮肤变形等。

### 4.1 核心功能模块

| 模块 | 说明 |
|------|------|
| **Rigging（绑定）** | 骨骼创建、父子关系、IK 控制器 |
| **Auto-rig** | 自动绑定（一键人物/四足动物绑定） |
| **Skin（皮肤）** | 网格皮肤变形（DUIK Duffle） |
| **Animation Tools** | 动画工具（循环、行走周期、摆动） |
| **Camera Tools** | 摄像机工具（震动、滑轨、变焦） |
| **Constraint** | 约束系统（父子、路径、注视） |
| **Expression Tools** | 表达式工具（随机、摆动、弹性） |
| **Kinefx** | 关键帧动画辅助 |

### 4.2 骨骼绑定工作流

1. **创建骨骼**：用骨骼工具创建角色骨架
2. **设置父子关系**：建立骨骼层级
3. **添加 IK**：为四肢添加反向运动学
4. **绑定图层**：把角色图层绑定到骨骼
5. **设置控制器**：创建动画控制器
6. **蒙皮（可选）**：用皮肤工具做网格变形

### 4.3 常用动画功能

- **Walk Cycle**：行走循环生成
- **Wiggle**：摆动/抖动动画
- **Swing**：摇摆动画
- **Bounce**：弹跳动画
- **Spring**：弹性动画
- **Motion Trail**：运动拖尾
- **Rubberhose**：橡皮管风格四肢

## 六、Mocha Pro — 平面跟踪与摩卡

> 业界领先的平面跟踪系统，内置在 BCC 中也有独立版本。

### 6.1 核心功能

| 功能 | 说明 |
|------|------|
| **Planar Tracking** | 平面跟踪（跟踪矩形/平面区域） |
| **Remove Module** | 物体移除（擦除画面中不需要的物体） |
| **Stabilize** | 画面稳定 |
| **Screen Insert** | 屏幕替换（插入到平面上） |
| **Lens Calibration** | 镜头畸变校准 |
| **Spline Tools** | 样条遮罩工具（精细遮罩） |
| **3D Solver** | 3D 摄像机解算 |

### 6.2 平面跟踪工作流

1. **绘制跟踪区域**：用 X 样条绘制要跟踪的平面
2. **跟踪**：点击播放自动跟踪
3. **手动修正**：在跟踪丢失的帧手动调整
4. **导出数据**：导出为 Corner Pin / Transform / 3D 数据
5. **应用**：应用到目标图层/效果

## 十、AE 脚本快速入门

### 10.1 脚本安装位置
```
AE 安装目录/Support Files/Scripts/ScriptUI Panels/
```
安装后在 AE 菜单：窗口 → 扩展 → 脚本名

### 10.2 脚本使用技巧

1. **先选图层，再运行脚本**：大部分脚本需要先选择目标图层
2. **可设置快捷键**：在 Edit → Keyboard Shortcuts 中为常用脚本设置快捷键
3. **KBar 集成**：把常用脚本按钮放到 KBar 工具栏
4. **组合使用**：不同脚本可以配合使用（如 Motion2 + Duik）

### 10.3 推荐学习路径

```
入门期（1-2周）：
  ├── Motion 2（基础缓动）
  ├── TypeMonkey（文字动画）
  └── Animation Composer（预设动画）

进阶期（1-2月）：
  ├── Duik（角色绑定）
  ├── Newton（物理模拟）
  ├── KBar（效率工具）
  └── Overlord（AI工作流）

高手期（持续提升）：
  ├── Stardust（节点式粒子）
  ├── Lockdown（表面跟踪）
  ├── Mocha Pro（专业跟踪）
  └── 表达式自定义开发
```
