> [!abstract] 文档摘要
> 本文档是视频逆向分析的"大脑"，建立了从视觉特征推理出原子级参数的完整决策系统。内容涵盖七类解析词汇的元模型、原子级视觉特征词汇库、效果识别推理决策树、参数推断决策树、置信度评估体系等核心模块。通过结构化的词汇定义和系统化的推理流程，可以将模糊的视觉感知转化为精确的参数推断，是整个逆向分析知识体系的智能核心。

## 第一章 解析词汇的元模型

> [!important] 理论基础章节
> 本章是整个推理系统的理论基石，定义了解析词汇的分类体系、原子结构和层级关系。理解了词汇的元模型，才能正确使用后续的词汇库和决策树。七类词汇构成了完整的推理链条，从视觉感知到参数输出，环环相扣。

### 1.1 词汇的分类体系

逆向分析的本质是"从看到什么 → 推出怎么做的 → 量化成参数"。整个推理链路涉及七类词汇，每一类对应推理链条上的一个环节。

| 词汇类别 | 英文标识 | 回答的问题 | ID前缀 | 在推理链中的位置 |
|---------|---------|-----------|--------|----------------|
| 视觉特征词 | Visual Feature Terms | "看到了什么" | VT-XXX | 推理链起点（感知层） |
| 效果识别词 | Effect Identification Terms | "用了什么效果" | EI-XXX | 推理链第二步（识别层） |
| 参数值词 | Parameter Value Terms | "参数是多少" | PV-XXX | 推理链第三步（量化层） |
| 时间轴词 | Timeline Terms | "什么时候发生" | TL-XXX | 推理链第四步（时序层） |
| 关键帧词 | Keyframe Terms | "如何变化" | KF-XXX | 推理链第五步（动画层） |
| 缓动曲线词 | Easing Curve Terms | "如何加速减速" | EC-XXX | 推理链第六步（曲线层） |
| 置信度词 | Confidence Terms | "有多确定" | CF-XXX | 推理链终点（验证层） |

**词汇流转图**：
```
[VT视觉特征] → [EI效果识别] → [PV参数值]
                                    ↓
[CF置信度] ← [EC缓动曲线] ← [KF关键帧] ← [TL时间轴]
```

### 1.2 词汇的原子结构

每一个解析词汇不是一段散文描述，而是一个由5个原子字段构成的"原子"。这种结构化的字段定义使得词汇可以被决策树机器化读取、推理、组合。

```yaml
# 词汇原子结构标准定义
term_id: VT-001                    # 词汇ID（全局唯一）
term_name: "均匀模糊扩散"            # 词汇名（中文+英文）
category: visual_feature           # 类别（7类之一）
definition: "画面四周均匀柔化，无方向性"  # 定义（一句话精确描述）
inference_chain:                   # 推理链（词汇如何被推理使用）
  - effect: Gaussian Blur          #   → 推理出的效果
  - parameter: Blurriness          #   → 推理出的参数
  - value_range: [5, 50]           #   → 推理出的取值范围
  - confidence: 0.85               #   → 推理置信度
visual_signature:                  # 视觉签名（用于识别）
  - "无方向性"
  - "边缘四周均匀扩散"
  - "无拖尾"
false_positive_exclusion:          # 误识别排除
  - "若出现多边形光斑 → 实为Camera Lens Blur"
  - "若出现方向性拖尾 → 实为Directional Blur"
hypernym: "模糊类视觉特征"           # 上位词
hyponym: "高斯型均匀扩散"            # 下位词
synonym: ["柔化", "各向同性模糊"]     # 同义词
antonym: ["锐化", "清晰"]            # 反义词
```

### 1.3 词汇的层级关系

词汇之间不是扁平的列表，而是构成一个有向图。层级关系包含四种：

- **上位词（Hypernym）**：模糊 → 视觉特征。上位词更抽象，覆盖范围更广。
- **下位词（Hyponym）**：高斯模糊 → 均匀模糊扩散。下位词更具体，参数映射更精确。
- **同义词（Synonym）**：柔化 ≈ 模糊 ≈ Soften。同义词在视频中可能以不同表述出现，但映射到同一效果。
- **反义词（Antonym）**：清晰 ↔ 模糊。反义词用于"排除推理"——如果观察到反义词的特征，则可以否定当前推理分支。

**层级推理规则**：
```
规则H1：下位词存在 → 上位词必然存在（继承性）
规则H2：同义词可以互相替换推理（等价性）
规则H3：反义词存在 → 当前推理分支置信度归零（互斥性）
规则H4：从上位词推理只能得到效果类别，从下位词推理才能得到精确参数
```

## 第二章 视觉特征词汇库（原子级）

> [!important] 核心词汇章节
> 视觉特征是推理链的起点，也是整个逆向分析的输入。本章的原子级视觉特征词是所有后续推理的基础。每个特征词都有明确的定义、视觉签名、误识别排除条件和推理链路。掌握这些特征词，可以大幅提升效果识别的速度和准确率。

### 2.1 模糊类视觉特征词

```yaml
term_id: VT-001
term_name: "均匀模糊扩散 (Uniform Blur Diffusion)"

inference_chain:
  - effect: Gaussian Blur
  - parameter: Blurriness
  - value_range: [5, 50]
  - confidence: 0.85

  - "无方向性，四周均匀扩散"
  - "边缘过渡平滑自然"
  - "高光不形成多边形光斑"
  - "无拖尾感"
false_positive_exclusion:
  - "若高光呈多边形 → 排除，转向VT-004 镜头光斑模糊"
  - "若有方向性拖尾 → 排除，转向VT-002 方向性拖尾"
  - "若从中心放射 → 排除，转向VT-003 径向辐射模糊"
hypernym: "模糊类视觉特征"
hyponym: "高斯型均匀扩散"
synonym: ["柔化", "各向同性模糊", "Soften"]
antonym: ["锐化", "清晰"]
```

### 6.1 多效果叠加的识别优先级

当一个视频同时使用多个效果时，识别顺序至关重要。识别顺序遵循"从外到内、从全局到局部"的原则：

```
识别优先级（从高到低）：
┌─────────────────────────────────────────┐
│ 1. 调色层（最外层，覆盖一切）             │
│    识别特征：整体偏色、对比度变化         │
│    优先级最高，因为影响所有元素             │
├─────────────────────────────────────────┤
│ 2. 转场层                                │
│    识别特征：画面切换瞬间                  │
│    仅在切点附近出现                       │
├─────────────────────────────────────────┤
│ 3. 主体动画层                            │
│    识别特征：物体整体运动                  │
│    可能是关键帧驱动或表达式驱动             │
├─────────────────────────────────────────┤
│ 4. 特效叠加层                            │
│    识别特征：粒子、发光、模糊等            │
│    通常在Adjustment Layer上              │
├─────────────────────────────────────────┤
│ 5. 文字动画层                            │
│    识别特征：文字出现/运动                 │
│    通常独立于背景                         │
├─────────────────────────────────────────┤
│ 6. 3D空间层（最内层）                     │
│    识别特征：3D摄像机运动、视差           │
│    影响所有2D元素的空间关系               │
└─────────────────────────────────────────┘
```

**叠加识别规则**：
- **规则C1**：调色层最先剥离。先识别并"移除"调色，再分析下层。
- **规则C2**：转场仅在切点附近有效，不影响切点外的画面。
- **规则C3**：主体动画影响所有元素，应作为"基线运动"。
- **规则C4**：特效叠加通常是Adjustment Layer，影响其下方所有层。
- **规则C5**：文字动画与背景独立，可分别分析。
- **规则C6**：3D空间层影响视差和摄像机运动，应最后分析。

### 6.2 效果解耦推理

#### 已知A+B=C的代数运算

当两个效果叠加时，已知结果C和其中一个效果A，可以推算另一个效果B：

```
解耦推理公式：

【模糊叠加】
若A模糊 + B模糊 = C模糊
则 B模糊 ≈ √(C² - A²)  （高斯型近似）

【透明度叠加】
若A层Opacity=α + B层Opacity=β = 总不透明度γ
则 γ = 1 - (1-α)(1-β)  → β = 1 - (1-γ)/(1-α)

【颜色叠加】
若A颜色 + B混合模式 = C颜色
混合模式=Normal → C = α*A + (1-α)*B
混合模式=Screen → C = 1 - (1-A)(1-B)
混合模式=Multiply → C = A * B
混合模式=Add → C = min(A + B, 1)
混合模式=Overlay → C = A < 0.5 ? 2AB : 1 - 2(1-A)(1-B)

【位移叠加】
若A位移 + B位移 = C位移
则 B位移 = C位移 - A位移
```

#### 混合模式的逆向运算

```
已知最终颜色C和原始颜色A，反推混合模式：

步骤：
1. 测试C = A + B（Add模式）→ B = C - A
2. 测试C = 1 - (1-A)(1-B)（Screen模式）→ B = 1 - (1-C)/(1-A) [需A≠1]
3. 测试C = A * B（Multiply模式）→ B = C / A [需A≠0]
4. 测试C = A < 0.5 ? 2AB : 1 - 2(1-A)(1-B)（Overlay模式）

判断方法：
- 若C ≥ A → 可能是Screen或Add
- 若C ≤ A → 可能是Multiply
- 若C和A的明暗关系反转 → 可能是Difference
```

## 第七章 推理置信度系统

### 7.1 置信度评分规则

每一个推理结果都需要标注置信度，置信度由四个维度合成：

#### 视觉特征清晰度（Visual Clarity, VC）

```
评分标准：
1.0：视觉特征极其明显，无歧义
0.8：视觉特征明显，但可能有细微歧义
0.6：视觉特征可见，但需要细看
0.4：视觉特征模糊，可能存在
0.2：视觉特征勉强可辨
0.0：无法识别
```

#### 效果识别确定性（Effect Certainty, EC）

```
评分标准：
1.0：唯一可能的效果
0.8：最可能的效果，但有1-2个备选
0.6：可能的效果之一
0.4：仅猜测
0.2：纯推测
0.0：完全不确定
```

#### 参数值精度（Parameter Precision, PP）

```
评分标准：
1.0：参数值精确（±5%）
0.8：参数值较精确（±10%）
0.6：参数值范围合理（±20%）
0.4：参数值范围宽（±50%）
0.2：仅知道大致方向
0.0：无法量化
```

#### 关键帧精度（Keyframe Precision, KP）

```
评分标准：
1.0：关键帧位置精确到帧
0.8：关键帧位置±2帧
0.6：关键帧位置±5帧
0.4：关键帧位置±10帧
0.2：仅知道大致时间
0.0：无法定位
```

#### 综合置信度计算公式

```
综合置信度 C = w1*VC + w2*EC + w3*PP + w4*KP

权重建议：
w1 = 0.25  # 视觉特征清晰度
w2 = 0.30  # 效果识别确定性（最重要）
w3 = 0.25  # 参数值精度
w4 = 0.20  # 关键帧精度

示例：
VC=0.8, EC=0.9, PP=0.7, KP=0.8
C = 0.25*0.8 + 0.30*0.9 + 0.25*0.7 + 0.20*0.8
  = 0.20 + 0.27 + 0.175 + 0.16
  = 0.805  → 高置信度
```

### 7.2 不确定度来源

置信度受多种因素影响，每个因素都会降低推理精度：

#### 视频压缩损失（Compression Loss）

```
影响：
- 高压缩（如H.264低码率）：边缘细节丢失，模糊类型难以区分
  → VC降低0.2-0.3
- 中等压缩（H.264中码率）：细节保留，可正常识别
  → VC降低0.0-0.1
- 低压缩（ProRes/DNxHR）：细节完整
  → VC不降低
```

#### 多效果叠加干扰（Effect Stacking Interference）

```
影响：
- 调色 + 模糊叠加：模糊类型可能被调色掩盖
  → EC降低0.1-0.2
- 发光 + 模糊叠加：发光区域被模糊柔化
  → VC降低0.1
- 多个发光叠加：难以区分是Glow还是S_Glow
  → EC降低0.2-0.3
```

#### 帧率不足（Low Frame Rate）

```
影响：
- 24fps：标准电影帧率，正常分析
- 30fps：标准网络帧率，正常分析
- 60fps：高帧率，更易观察缓动曲线
  → KP提升0.1
- 低于24fps（如15fps）：缓动曲线难以推断
  → KP降低0.2-0.3
- 隔行扫描（50i/60i）：需先去隔行
  → KP降低0.1
```

#### 用户主观判断（Subjective Bias）

```
影响：
- 经验丰富：判断更准确
  → 不降低
- 经验中等：可能误判细微特征
  → EC降低0.1
- 经验不足：可能误判主要特征
  → EC降低0.2-0.3

缓解方法：
- 多人交叉验证
- 使用参考对比
- 量化测量（如像素级采样）
```

### 7.3 置信度阈值与行动建议

```
置信度范围 → 行动建议
┌──────────────────────────────────────────────┐
│ C ≥ 0.9 → 直接采用                            │
│           无需验证，写入参数表                  │
│           示例：明显的Gaussian Blur             │
├──────────────────────────────────────────────┤

```

```
节点类型：
  [VT] 视觉特征节点
  [EI] 效果节点
  [PV] 参数节点
  [TL] 时间节点
  [KF] 关键帧节点
  [EC] 缓动曲线节点

边类型：
  is-a       继承关系（下位词 → 上位词）
  has-a      包含关系（效果 → 参数）
  leads-to   推理关系（视觉特征 → 效果）
  excludes   互斥关系（视觉特征 → 排除某效果）
  co-occurs  共现关系（两个效果常一起出现）

权重：
  leads-to边的权重 = 推理置信度（0-1）
  co-occurs边的权重 = 共现概率（0-1）

示例图谱：
  [VT-001均匀模糊] --leads-to(0.85)--> [EI-001 Gaussian Blur] --has-a--> [PV: Blurriness]
  [VT-001均匀模糊] --excludes--> [EI-004 Camera Lens Blur]
  [EI-001 Gaussian Blur] --co-occurs(0.6)--> [EI-101 Glow]
```

```
   ├── 每个案例归档到"视频案例解析库"
```

## 结语：从词汇到推理的闭环

本词汇表与决策树构成了一个完整的"感知→识别→推理→验证→输出"闭环：

1. **感知**：从视频中识别VT-XXX视觉特征词
2. **识别**：通过EI-XXX效果识别词匹配效果
3. **推理**：通过PV/TL/KF/EC参数词量化参数
4. **验证**：通过CF-XXX置信度词评估推理质量
5. **输出**：生成原子级YAML参数表，可执行AE脚本

整个系统的最终目标是：**给定任意视频片段，输出可执行的AE参数表，使复现误差控制在5%以内。**

持续的案例积累和反馈学习将不断优化决策树的准确性和词汇库的覆盖率，使本系统逐步逼近"原子级精确"的逆向分析能力。
