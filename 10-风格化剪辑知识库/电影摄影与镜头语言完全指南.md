# 电影摄影与镜头语言完全指南

> 版本: 2025-v1 | 适用: 影视后期/AE动画/剪辑叙事参考

## 一、景别体系

### 1.1 基础景别

| 景别 | 英文 | 画面范围 | 叙事功能 |
|------|------|---------|---------|
| 大远景 | Extreme Long Shot | 人物极小，环境为主 | 建立场景、史诗感、孤独 |
| 远景 | Long Shot | 人物全身+大量环境 | 交代环境关系、定位 |
| 全景 | Full Shot | 人物全身+少量环境 | 展示人物动作、体态语言 |
| 中景 | Medium Shot | 腰部以上 | 对话、日常互动 |
| 中近景 | Medium Close-up | 胸部以上 | 新闻播报、访谈 |
| 近景 | Close-up | 肩部以上 | 情感表达、细节 |
| 特写 | Big Close-up | 面部局部/物体细节 | 强烈情感、关键道具 |
| 大特写 | Extreme Close-up | 眼睛/嘴唇等 | 极致情感张力 |

### 1.2 景别切换的叙事逻辑

```
远景(建立) → 中景(互动) → 近景(情感) → 特写(高潮)
→ 远景(结束/过渡)
```

**经典三段式**: 远-中-近（环境→人物→细节）
**反常规**: 特写开场 → 拉远揭示（悬念/反转）

|------|------|------|------|
| 鸟瞰 | Bird's Eye | 上帝视角、全知、渺小 | 航拍、建立镜头 |

| 平视 | Eye Level | 平等、客观、自然 | 对话、日常 |
| 低角度 | Low Angle | 权威、压迫、力量 | 英雄、反派登场 |
| 蚁视 | Worm's Eye | 极端仰视、崇高、恐惧 | 建筑、巨人化 |

### 2.2 水平角度

| 角度 | 含义 |
|------|------|
| 正面 | 直接、对抗、坦诚 |

| 背面 | 神秘、代入、跟随 |

## 三、镜头运动

### 3.1 基础运镜

| 运动 | 英文 | 描述 | 情感效果 |
|------|------|------|---------|
| 推 | Push In/Dolly In | 靠近主体 | 聚焦、紧张、强调 |
| 拉 | Pull Out/Dolly Out | 远离主体 | 揭示、孤立、释然 |
| 摇 | Pan | 水平旋转 | 扫描、跟随、引导 |
| 俯仰 | Tilt | 垂直旋转 | 展示高度、审视 |
| 移 | Track/Dolly | 平行移动 | 跟随、探索 |
| 升降 | Boom/Crane | 垂直升降 | 宏大、揭示、过渡 |
| 跟 | Follow | 跟随主体 | 参与感、紧张 |
| 甩 | Whip Pan | 快速水平摇 | 转场、惊讶、时间流逝 |

### 3.2 高级运镜

| 运动 | 描述 | 经典应用 |
|------|------|---------|
| 斯坦尼康长镜头 | 稳定器跟随穿越空间 | 闪灵、鸟人 |
| 环绕镜头 | 360°围绕主体 | 黑客帝国子弹时间 |
| 升降+推拉组合 | 复合运动 | 教父开场 |
| 手持跟拍 | 不稳定的参与感 | 谍影重重、荒野猎人 |
| 一镜到底 | 无剪切连续运动 | 1917、赎罪 |
| 变焦推拉 | 焦距变化改变景别 | 迷魂记变焦(Dolly Zoom) |

### 3.3 Dolly Zoom (迷魂记效果)

```
同时执行: 推轨前进 + 变焦拉远(或反之)
效果: 主体大小不变，背景压缩/扩展
情感: 恐惧、顿悟、世界崩塌
```

## 四、构图法则

### 4.1 核心构图法则

| 法则 | 描述 | 应用 |
|------|------|------|
| 三分法 | 画面分为3x3网格，主体放交叉点 | 最通用构图 |
| 黄金比例 | 1:1.618螺旋线 | 自然美感 |
| 对称构图 | 左右/上下对称 | 庄严、秩序、库布里克 |
| 框架式构图 | 利用前景元素框住主体 | 深度、聚焦 |
| 引导线 | 利用线条引导视线到主体 | 道路、建筑、光线 |
| 对角线 | 主体沿对角线排列 | 动感、不安 |
| 留白 | 主体一侧大量空白 | 孤独、思考、方向感 |
| 填充式 | 主体充满画面 | 压迫感、亲密感 |

### 4.2 构图与情绪

```
稳定构图(水平线水平、对称): 平静、秩序、安全
不稳定构图(倾斜、失衡): 紧张、混乱、危险
居中构图: 权威、力量、直接
偏侧构图: 孤独、思考、方向
```

### 4.3 视线规则

- **视线方向**: 角色看向画面内侧（留空间给视线方向）
- **180°规则**: 两个角色对话时，摄影机不越过连接线
- **30°规则**: 连续两个镜头角度至少差30°（避免跳切感）

## 五、焦距与透视

### 5.1 焦距分类

| 焦距范围 | 类型 | 透视特征 | 情感效果 |
|----------|------|---------|---------|
| 8-16mm | 鱼眼 | 极端畸变 | 扭曲、疯狂 |
| 16-24mm | 超广角 | 强烈透视畸变 | 空间感、压迫 |
| 24-35mm | 广角 | 适度透视夸张 | 环境叙事、纪录感 |
| 35-85mm | 标准 | 接近人眼 | 自然、客观 |
| 85-200mm | 中长焦 | 压缩空间 | 亲密、窥视 |
| 200mm+ | 超长焦 | 极度压缩 | 孤立、扁平化 |

### 5.2 焦距心理学

- **广角(24mm)**: 近大远小夸张 → 空间纵深 → 角色与环境关系
- **标准(50mm)**: 接近人眼 → 客观、真实 → 日常叙事
- **长焦(135mm)**: 空间压缩 → 前后景叠合 → 孤立/监视感

### 5.3 景深控制

| 参数 | 浅景深效果 | 深景深效果 |
|------|-----------|-----------|
| 光圈 | 大光圈(f/1.4-2.8) | 小光圈(f/8-16) |
| 焦距 | 长焦 | 广角 |
| 距离 | 近距离拍摄 | 远距离拍摄 |
| 情感 | 主体突出、梦幻 | 全清晰、纪实 |

## 六、光线与照明

### 6.1 光线方向

| 光位 | 效果 | 经典应用 |
|------|------|---------|
| 正面光 | 平坦、无阴影 | 喜剧、时尚 |
| 45°侧光 | 立体感、自然 | 最常用、肖像 |
| 正侧光 | 半明半暗、戏剧 | 性格双面性 |
| 逆光 | 轮廓光、剪影 | 神秘、神圣 |
| 顶光 | 眼窝阴影 | 恐怖、审讯 |
| 底光 | 反向阴影 | 恐怖、超自然 |

### 6.2 经典布光方案

#### 三点布光
```
主光(Key): 45°侧前，最强光
辅光(Fill): 对侧，弱于主光(控制对比)
背光(Back): 后方，勾勒轮廓
```

#### 伦勃朗光
- 主光45°高角度 → 暗面出现三角形光斑
- 效果: 经典肖像、戏剧性

#### 蝴蝶光
- 主光正上方 → 鼻下蝴蝶形阴影
- 效果: 优雅、时尚

## 七、镜头语言与AE动画映射
