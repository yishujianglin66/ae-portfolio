## 1. 调研概述

### 1.1 调研背景

随着 AI 技术的快速发展和 MCP（Model Context Protocol）协议的兴起，After Effects 的自动化和智能化正在经历前所未有的变革。从传统的手动操作到脚本自动化，再到如今的 AI 驱动智能创作，AE 生态正在经历一场深刻的技术革命。

GitHub 作为全球最大的开源代码托管平台，汇聚了大量优秀的 AE 开源项目。这些项目涵盖了从基础脚本到复杂自动化系统的各个层面，为 AE 用户提供了丰富的免费工具选择。
