# AE 性能优化完全指南

> 版本: 2025-v1 | 适用: 性能调优/内存管理/渲染加速

## 一、内存管理

### 1.1 内存分配

| 设置 | 说明 | 建议 |
|------|------|------|
| RAM预留 | 系统预留内存 | 3-6GB |
| 多帧渲染 | 启用多核渲染 | 启用 |
| 内存利用率 | AE使用内存比例 | 70-80% |

### 1.2 内存优化

```
内存优化技巧:
1. 清理内存: Ctrl+Alt+Delete
2. 关闭不必要的应用
3. 增加物理内存
4. 使用SSD作为暂存盘
5. 定期重启AE

内存监控:
- 编辑→首选项→内存
- 查看内存使用情况
- 调整分配比例
```

## 二、缓存管理

### 2.1 缓存类型

| 类型 | 位置 | 用途 |
|------|------|------|
| 内存缓存 | RAM | 快速预览 |
| 磁盘缓存 | 硬盘 | 持久缓存 |
| 媒体缓存 | 硬盘 | 代理/优化媒体 |

### 2.2 缓存设置

```
磁盘缓存设置:
1. 编辑→首选项→媒体缓存
2. 设置缓存路径(建议SSD)
3. 设置最大缓存大小:
   - 内存缓存: 根据RAM
   - 磁盘缓存: 50-200GB
4. 启用磁盘缓存

缓存清理:
- 编辑→清理→所有内存和磁盘缓存
- 或手动删除缓存文件
```

## 三、预览优化

### 3.1 预览设置

| 设置 | 说明 | 建议 |
|------|------|------|
| 分辨率 | 预览分辨率 | 自动/半 |
| 帧率 | 预览帧率 | 自动 |
| 跳帧 | 跳过帧预览 | 启用 |
| 缓存 | 缓存预览帧 | 启用 |

### 3.2 预览优化技巧

```
预览优化:
1. 降低预览分辨率(1/2或1/4)
2. 使用RAM预览缓存
3. 预渲染复杂段落
4. 使用代理剪辑
5. 关闭不必要图层
6. 使用草稿3D模式

快捷键:
- 0: RAM预览
- Shift+0: 预览工作区域
- Ctrl+0: 清除RAM预览
- .: 从当前时间点预览
```

## 八、故障排除

### 8.1 性能问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 预览卡顿 | 内存不足 | 增加RAM/清理缓存 |
| 渲染缓慢 | CPU/GPU瓶颈 | 升级硬件/优化设置 |
| 崩溃 | 内存溢出 | 增加虚拟内存 |
| 磁盘满 | 缓存过多 | 清理缓存 |

### 8.2 诊断工具

```
诊断工具:
```
