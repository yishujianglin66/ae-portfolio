## 🎵 L1 节拍级映射

### 二、节拍检测与时间码生成

```
MIR分析流程:
1. 音频输入 → librosa.load()
2. 节拍检测 → librosa.beat.beat_track()
3. 强拍识别 → librosa.onset.onset_strength()
4. 时间码生成 → beat_times * 1000 (毫秒)
5. 节奏特征提取 → tempo, beat_frequency, onset_energy

关键参数:
- tempo: BPM值 (60-200)
- beat_frequency: 节拍间隔秒数 = 60 / BPM
- onset_energy: 每个节拍的能量强度 (0-1)
- downbeat: 强拍位置标记
```

### 三、节拍→关键帧映射规则

| 节拍类型 | 视觉响应 | 关键帧操作 | AE表达式 |
|---------|---------|-----------|---------|
| **强拍 (Downbeat)** | 画面切换/缩放/颜色突变 | Position/Scale/Rotation关键帧 | `valueAtTime(beat_time)` |
| **弱拍 (Beat)** | 轻微震动/粒子爆发 | Wiggle/Particle关键帧 | `wiggle(BPM/60, amplitude)` |
| **次强拍 (Off-beat)** | 字幕出现/图标动画 | Opacity/Position关键帧 | `linear(time, in_time, out_time, 0, 100)` |
| **连音 (Legato)** | 平滑过渡/渐变 | Interpolation曲线调整 | `easeInOut(value, time)` |

### 四、BPM→速度值映射表

| BPM范围 | 节奏类型 | 视频速度 | 关键帧间隔 | 转场时长 |
|---------|---------|---------|-----------|---------|
| 60-80 | 慢节奏/抒情 | 1x (正常) | 0.75-1.0秒 | 0.5-1.0秒 |
| 80-100 | 中等/叙事 | 1x | 0.6-0.75秒 | 0.3-0.5秒 |
| 100-120 | 流行/轻快 | 1.0-1.2x | 0.5-0.6秒 | 0.2-0.3秒 |
| 120-140 | 电子/摇滚 | 1.2-1.5x | 0.4-0.5秒 | 0.15-0.25秒 |
| 140-160 | 快节奏/舞曲 | 1.5-2x | 0.35-0.43秒 | 0.1-0.15秒 |
| 160-200 | 极速/硬核 | 2x+ | 0.3-0.375秒 | 0.05-0.1秒 |

### 五、节拍能量→效果强度映射

```
公式: effect_intensity = base_intensity * (onset_energy + 0.5)

其中:
- onset_energy: 0-1 (MIR提取的节拍能量)
- base_intensity: 基础强度 (根据效果类型)
- effect_intensity: 最终效果强度

示例:
- 粒子爆发强度 = 300 * (0.8 + 0.5) = 390
- 镜头震动幅度 = 10 * (0.9 + 0.5) = 14px
- 发光强度 = 2 * (0.7 + 0.5) = 2.4
```

### 六、毫秒级关键帧对齐脚本

```jsx
// AE 2026 节拍关键帧自动对齐脚本
// 输入: 节拍时间数组 (毫秒)
// 输出: 在每个节拍位置创建关键帧

function alignKeyframesToBeats(beatTimes, layer, propertyName) {
    var prop = layer.property(propertyName);
    var currentValue = prop.value;
    
    for (var i = 0; i < beatTimes.length; i++) {
        var time = beatTimes[i] / 1000;
        prop.setValueAtTime(time, currentValue);
        
        if (i > 0) {
            var prevTime = beatTimes[i-1] / 1000;
            var duration = time - prevTime;
            
            if (propertyName === "Position") {
                var offset = [Math.random() * 20 - 10, Math.random() * 20 - 10];
                prop.setValueAtTime(time - duration * 0.1, [currentValue[0] + offset[0], currentValue[1] + offset[1]]);
            } else if (propertyName === "Scale") {
                prop.setValueAtTime(time - duration * 0.1, [105, 105]);
                prop.setValueAtTime(time, [100, 100]);
            }
        }
    }
    
    return beatTimes.length;
}
```

## 🎬 L2 段落级映射

### 七、音乐段落检测算法

```
段落检测流程:
1. 特征提取 → Chroma特征 (12个半音)
2. 相似度计算 → 相邻帧余弦相似度
3. 边界检测 → 相似度突变点 = 段落边界
4. 段落标签 → 根据Chroma特征分类 (A/B/C段)

段落类型:
- Intro (前奏): 0-30秒, 乐器逐步增加
- Verse (主歌): 歌词开始, 节奏稳定
- Pre-Chorus (预副歌): 能量上升, 期待感
- Chorus (副歌): 能量峰值, 旋律重复
- Bridge (桥段): 节奏/和弦变化, 对比段
- Outro (尾奏): 能量下降, 乐器减少
```

### 十一、状态机设计

```
状态机状态:
IDLE → PLAYING → BUILDUP → PEAK → DECAY → END

状态转换条件:
IDLE → PLAYING: 音频开始
PLAYING → BUILDUP: 能量持续上升 (>0.5s)
BUILDUP → PEAK: 能量达到峰值 (>0.8)
PEAK → DECAY: 能量下降 (>0.3)
DECAY → PLAYING: 能量恢复稳定
PLAYING → END: 音频结束

每个状态的效果配置:
- IDLE: 无效果
- PLAYING: 基础粒子 + 稳定镜头
- BUILDUP: 粒子加速 + 镜头推进 + 对比度提升
- PEAK: 粒子爆发 + 镜头震动 + 闪白 + 高对比
- DECAY: 粒子减速 + 镜头拉远 + 对比度恢复
- END: 粒子消散 + 淡入淡出
```

```jsx
// AE 2026 四维联动事件系统

var eventSystem = {
    events: [],
    
    registerEvent: function(type, callback) {
        if (!this.events[type]) this.events[type] = [];
        this.events[type].push(callback);
    },
    
    triggerEvent: function(type, data) {
        var callbacks = this.events[type];
        if (callbacks) {
            for (var i = 0; i < callbacks.length; i++) {
                callbacks[i](data);
            }
        }
    }
};

    createCameraShake(data.time, 0.1, data.intensity * 10);

});
```

### 二十、完整时间轴生成脚本

```jsx
// AE 2026 智能时间轴生成脚本
// 输入: 音乐特征JSON + 视频片段列表
// 输出: 完整的AE合成时间轴

app.beginUndoGroup("Generate Timeline 2026");

var comp = app.project.activeItem;
if (!(comp instanceof CompItem)) {
    alert("请先选择一个合成");
    app.endUndoGroup();
}

function generateTimeline(musicData, clips) {
    var beatTimes = musicData.beat_times;
    var sections = musicData.sections;
    var recipe = musicData.recipe;
    
    // 清除现有图层
    while (comp.numLayers > 0) {
        comp.layer(1).remove();
    }
    
    // 创建背景层
    var bgLayer = comp.layers.addSolid([0.1, 0.1, 0.1], "Background", comp.width, comp.height, 1);
    
    // 放置视频片段
    var currentTime = 0;
    var clipIndex = 0;
    
    for (var i = 0; i < sections.length; i++) {
        var section = sections[i];
        var sectionDuration = section.end_time - section.start_time;
        
        while (currentTime < section.end_time && clipIndex < clips.length) {
            var clip = clips[clipIndex];
            var clipLayer = comp.layers.addFootageItem(clip.path);
            clipLayer.name = "Clip_" + clipIndex;
            clipLayer.startTime = currentTime;
            
            var beatInterval = 60 / musicData.tempo;
            var clipDuration = beatInterval * Math.ceil(clip.duration / beatInterval);
            
            clipLayer.outPoint = currentTime + clipDuration;
            
            // 应用调色方案
            applyColorGrade(clipLayer, recipe.color_grade);
            
            // 应用镜头运动
            applyCameraMotion(clipLayer, recipe.camera_motion, currentTime, clipDuration);
            
            currentTime += clipDuration;
            clipIndex++;
        }
    }
    
    // 添加效果图层
    addEffects(comp, beatTimes, recipe.effects);
    
    // 添加文字图层
    addTextLayers(comp, sections, recipe.text_style);
    
    // 添加音频图层
    var audioLayer = comp.layers.addFootageItem(musicData.audio_path);
    audioLayer.name = "Music";
    
    alert("时间轴生成完成！\n\n视频片段: " + clipIndex + "个\n节拍数: " + beatTimes.length + "\n段落数: " + sections.length);
}

function applyColorGrade(layer, colorGrade) {
    var sat = layer.Effects.addProperty("ADBE Saturation");
    sat.property("Master Saturation").setValue(colorGrade.saturation);
    
    var cc = layer.Effects.addProperty("ADBE Color Balance");
    if (colorGrade.color_temperature > 5000) {
        cc.property("Midtones").setValue([10, 5, -5]);
    } else {
        cc.property("Midtones").setValue([-5, -5, 10]);
    }
}

function applyCameraMotion(layer, motion, startTime, duration) {
    var scale = layer.property("Scale");
    scale.setValueAtTime(startTime, [100, 100]);
    scale.setValueAtTime(startTime + duration, [100 + motion.zoom_speed * 10, 100 + motion.zoom_speed * 10]);
    
    var pos = layer.property("Position");
    var originalPos = pos.value;
    pos.setValueAtTime(startTime, originalPos);
    pos.setValueAtTime(startTime + duration, [originalPos[0] + motion.pan_speed * 50, originalPos[1]]);
}

function addEffects(comp, beatTimes, effectsConfig) {
    // 粒子层
    var particleLayer = comp.layers.addSolid([1, 1, 1], "Particles", comp.width, comp.height, 1);
    particleLayer.blendingMode = BlendingMode.ADD;
    
    var ccpw = particleLayer.Effects.addProperty("ADBE CC Particle World");
    ccpw.property("Birth Rate").setValue(effectsConfig.particles.count);
    ccpw.property("Speed").setValue(effectsConfig.particles.speed);
    ccpw.property("Size").setValue(5);
    
    // 发光层
    var glowLayer = comp.layers.addAdjustmentLayer();
    glowLayer.name = "Glow";
    var glow = glowLayer.Effects.addProperty("ADBE Glo2");
    glow.property("Glow Intensity").setValue(effectsConfig.glow.intensity);
    glow.property("Glow Radius").setValue(effectsConfig.glow.radius);
}

function addTextLayers(comp, sections, textStyle) {
    for (var i = 0; i < sections.length; i++) {
        if (sections[i].type === "Chorus") {
            var textLayer = comp.layers.addText(sections[i].type);
            textLayer.name = "Section_" + sections[i].type;
            textLayer.startTime = sections[i].start_time;
            textLayer.outPoint = sections[i].end_time;
            
            var sourceText = textLayer.property("Source Text");
            var textDoc = sourceText.value;
            textDoc.fontSize = textStyle.size;
            textDoc.fillColor = [1, 1, 1];
            textDoc.font = "Arial Black";
            sourceText.setValue(textDoc);
            
            textLayer.property("Position").setValue([comp.width/2, comp.height*0.1]);
            textLayer.property("Opacity").setValueAtTime(sections[i].start_time, 0);
            textLayer.property("Opacity").setValueAtTime(sections[i].start_time + 0.5, 100);
            textLayer.property("Opacity").setValueAtTime(sections[i].end_time - 0.5, 100);
            textLayer.property("Opacity").setValueAtTime(sections[i].end_time, 0);
        }
    }
}
```
