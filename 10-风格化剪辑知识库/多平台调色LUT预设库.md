## 一、LUT技术基础

### 1.1 LUT（Look-Up Table）概念详解

LUT（Look-Up Table，查找表）是一种用于色彩转换的数据表，它将输入的色彩值映射到输出色彩值。LUT的本质是一个数学函数的离散化表达，通过预先计算好的对应关系，实现高效的色彩空间转换或创意调色。

**LUT的核心作用：**

1. **色彩空间转换**：将一种色彩空间（如Log）转换为另一种（如Rec.709）
2. **创意调色**：快速应用预设的调色风格
3. **设备校准**：校正显示器的色彩偏差
4. **胶片模拟**：模拟特定胶片的色彩特征
5. **标准化**：统一不同设备拍摄的素材色彩

**LUT的工作流程：**

```
原始素材 → 输入色彩值(R,G,B) → LUT查找表 → 输出色彩值(R',G',B') → 最终画面
```

**LUT的优势：**

- **高效性**：预先计算，实时应用，无需复杂运算
- **一致性**：保证不同镜头、不同项目之间的色彩统一
- **可移植性**：跨软件、跨平台使用
- **标准化**：行业通用格式，便于团队协作

### 1.2 1D LUT vs 3D LUT 技术原理

#### 1D LUT（一维查找表）

1D LUT对每个颜色通道独立进行映射，每个通道有独立的查找表。

**特点：**
- 仅改变亮度和对比度
- 不能改变色相和饱和度
- 文件体积小（通常几KB）
- 计算速度快
- 适用于伽马转换、黑白点设置

**示例数据结构：**

| 输入值 | 输出值 |
|--------|--------|
| 0 | 5 |
| 64 | 78 |
| 128 | 156 |
| 192 | 230 |
| 255 | 255 |

**应用场景：**
- 伽马曲线调整
- 黑白点设置
- 灰度系数转换
- 色温调整（通过RGB通道分别调整）

#### 3D LUT（三维查找表）

3D LUT将RGB三个通道作为三维坐标系，建立立体查找表。

**特点：**
- 可以同时改变亮度、对比度、色相、饱和度
- 真正的色彩空间转换
- 文件体积较大（几十KB到几MB）
- 计算量相对较大
- 适用于所有复杂调色需求

**3D LUT数据结构示例：**

```
LUT_3D_SIZE 17
0.000000 0.000000 0.000000
0.062500 0.000000 0.000000
0.125000 0.000000 0.000000
...
1.000000 1.000000 1.000000
```

**对比表：**

| 特性 | 1D LUT | 3D LUT |
|------|--------|--------|
| 通道处理 | 独立处理 | 联合处理 |
| 色相改变 | 否 | 是 |
| 饱和度改变 | 否 | 是 |
| 色彩空间转换 | 有限 | 完全支持 |
| 文件体积 | 几KB | 几十KB-几MB |
| 计算速度 | 极快 | 快 |
| 应用范围 | 简单调整 | 复杂调色 |
| 格式 | .cms, .csp | .cube, .3dl |

### 1.3 LUT文件格式对比

#### .cube 格式

**最通用的3D LUT格式**，由Adobe推动，文本格式，可读性强。

```
# Created by AE Knowledge Vault
TITLE "Kodak 2383"
LUT_3D_SIZE 33
LUT_3D_INPUT_RANGE 0 1
0.000000 0.000000 0.000000
0.031250 0.000000 0.000000
...
```

- **兼容性**：DaVinci Resolve、Premiere Pro、After Effects、Final Cut Pro X、Photoshop、Nuke
- **优势**：通用性强、可读性好、支持注释
- **劣势**：文本格式，文件较大

#### .3dl 格式

Autodesk Lustre使用的格式，文本格式。

```
3DLUTSIZE 17
0 0 0
256 0 0
512 0 0
...
```

- **兼容性**：DaVinci Resolve、Autodesk Lustre、Premiere Pro
- **优势**：兼容专业电影后期软件
- **劣势**：不如.cube通用

#### .look 格式

Adobe SpeedGrade原生格式，包含LUT + 二级调色信息。

- **兼容性**： Premiere Pro（有限支持）、SpeedGrade
- **优势**：包含完整调色信息
- **劣势**：Adobe已停止SpeedGrade开发

#### .vlt 格式

Panasonic摄像机的LUT格式，用于VariCam系列。

- **兼容性**：Panasonic摄像机、DaVinci Resolve
- **优势**：可直接加载到摄像机
- **劣势**：仅限Panasonic设备

#### .cms 格式

Colorfront使用的格式，同时支持1D和3D LUT。

- **兼容性**：Colorfront、DaVinci Resolve
- **优势**：支持1D + 3D组合
- **劣势**：专用性强

#### .csp 格式

Cinespace格式，Rising Sun Research开发。

- **兼容性**：Nuke、DaVinci Resolve、Baselight
- **优势**：支持校准LUT
- **劣势**：结构复杂

**格式选择建议：**

| 使用场景 | 推荐格式 | 原因 |
|---------|---------|------|
| 通用调色 | .cube | 兼容性最佳 |
| 电影后期 | .3dl | 专业标准 |
| Adobe工作流 | .cube | 原生支持 |
| 摄像机监看 | .vlt/.cube | 设备支持 |
| 显示器校准 | .csp/.cms | 校准专用 |

### 1.4 LUT的色彩空间与位深要求

#### 色彩空间

LUT涉及的常见色彩空间：

| 色彩空间 | 用途 | 色域范围 | 伽马 |
|---------|------|---------|------|
| Rec.709 | HDTV/网络视频 | 有限 | 2.4 |
| Rec.2020 | UHDTV/4K/8K | 宽广 | 10-12bit |
| DCI-P3 | 数字电影 | 较广 | 2.6 |
| sRGB | 网页/电脑显示 | 有限 | 2.2 |
| Adobe RGB | 专业摄影 | 较广 | 2.2 |
| ProPhoto RGB | 高端摄影 | 极广 | 1.8 |
| ARRI Log C | ARRI摄影机 | 宽广 | Log |
| Sony S-Log | Sony摄影机 | 宽广 | Log |
| Canon C-Log | Canon摄影机 | 宽广 | Log |

#### 位深要求

| 位深 | 颜色数 | 适用场景 | 文件大小影响 |
|------|--------|---------|------------|
| 8-bit | 1670万 | 网络视频 | 小 |
| 10-bit | 10.7亿 | 专业视频 | 中 |
| 12-bit | 687亿 | 电影后期 | 大 |
| 16-bit | 281万亿 | 高端调色 | 极大 |
| 32-bit float | 无限 | HDR调色 | 极大 |

**重要提示：**
- LUT应用建议在10-bit以上环境进行
- 8-bit环境下应用LUT容易出现色带
- Log素材应用LUT必须使用10-bit以上
- HDR项目建议使用16-bit或32-bit float

### 1.5 LUT的尺寸规格

3D LUT的尺寸决定了色彩取样的精度：

#### 17×17×17（标准）

- **数据点数**：4913个
- **文件大小**：约15-25KB
- **适用场景**：网络视频、实时监看
- **精度**：标准精度，适合大多数应用
- **优势**：体积小，加载快

#### 33×33×33（专业）

- **数据点数**：35937个
- **文件大小**：约100-150KB
- **适用场景**：专业调色、电影后期
- **精度**：高精度，色带风险低
- **优势**：质量与体积平衡

#### 65×65×65（高端）

- **数据点数**：274625个
- **文件大小**：约700KB-1MB
- **适用场景**：HDR调色、高端电影
- **精度**：极高精度，无色带
- **优势**：最高质量

#### 257×257×257（极致）

- **数据点数**：16974593个
- **文件大小**：约40-50MB
- **适用场景**：科研、校准
- **精度**：极致精度
- **劣势**：体积过大，实用性低

**尺寸选择建议：**

```
网络视频/实时监看 → 17×17×17
专业调色/电影后期 → 33×33×33
HDR/高端项目      → 65×65×65
```

### 1.6 技术LUT vs 创意LUT

#### 技术LUT（Technical LUT）

用于色彩空间转换的标准化LUT。

**主要用途：**
- Log转Rec.709
- 色彩空间转换
- 显示器校准
- 摄影机色彩标准化

**常见技术LUT：**

| LUT名称 | 输入 | 输出 | 用途 |
|---------|------|------|------|
| ARRI LogC to Rec709 | ARRI LogC | Rec.709 | ARRI素材转换 |
| Sony S-Log3 to Rec709 | S-Log3 | Rec.709 | Sony素材转换 |
| Canon C-Log3 to Rec709 | C-Log3 | Rec.709 | Canon素材转换 |
| Rec709 to Rec2020 | Rec.709 | Rec.2020 | 升级到HDR |
| Rec2020 to Rec709 | Rec.2020 | Rec.709 | HDR降级SDR |

**应用位置：** 调色流程的最开始

#### 创意LUT（Creative LUT）

用于创意调色的风格化LUT。

**主要用途：**
- 电影风格模拟
- 胶片质感
- 社交媒体风格
- 艺术化调色

**应用位置：** 调色流程的中后段

**对比表：**

| 特性 | 技术LUT | 创意LUT |
|------|---------|---------|
| 用途 | 标准化 | 风格化 |
| 应用顺序 | 前置 | 后置 |
| 可调节性 | 通常不调整 | 可调强度 |
| 标准化 | 行业标准 | 自由发挥 |
| 制作难度 | 高（需精确） | 中（看效果） |

### 1.7 LUT的工作原理图解

```
┌─────────────────────────────────────────────────────────────┐
│                    LUT工作流程                                │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  原始像素(R,G,B)                                            │
│       │                                                     │
│       ▼                                                     │
│  ┌─────────────┐                                           │
│  │ 输入色彩空间 │  例如：S-Log3 (0.123, 0.456, 0.789)        │
│  └─────────────┘                                           │
│       │                                                     │
│       ▼                                                     │
│  ┌─────────────────────────────────────┐                   │
│  │         3D LUT查找表                 │                   │
│  │                                     │                   │
│  │   R ─┐                              │                   │
│  │   G ─┼─→ 三维坐标查找 ─→ 输出值      │                   │
│  │   B ─┘                              │                   │
│  │                                     │                   │
│  │   插值算法：三线性插值               │                   │
│  └─────────────────────────────────────┘                   │
│       │                                                     │
│       ▼                                                     │
│  ┌─────────────┐                                           │
│  │ 输出色彩空间 │  例如：Rec.709 (0.234, 0.567, 0.890)       │
│  └─────────────┘                                           │
│       │                                                     │
│       ▼                                                     │
│  最终像素(R',G',B')                                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**三线性插值过程：**

1. 在3D LUT网格中找到输入值所在的立方体单元
2. 在X轴方向进行两次插值
3. 在Y轴方向进行两次插值
4. 在Z轴方向进行一次插值
5. 得到最终的输出值

### 1.8 LUT质量评估标准

#### 1.8.1 色彩精度

| 评估指标 | 优秀 | 良好 | 合格 | 不合格 |
|---------|------|------|------|--------|
| Delta E < 1 | 极佳 | - | - | - |
| Delta E 1-3 | - | 优秀 | - | - |
| Delta E 3-5 | - | - | 良好 | - |

| 色域标准 | 覆盖率要求 |
|---------|----------|

#### 1.8.4 色带检查

| 检查项 | 标准 |
|--------|------|
| 渐变平滑度 | 无可见色带 |
| 暗部细节 | 无色带 |
| 高光过渡 | 无色带 |

## 二、LUT制作方法

### 2.1 AE中制作LUT

#### 2.1.1 使用Lumetri Color制作LUT

**步骤：**

1. **创建合成**
   - 新建合成，分辨率1920×1080
   - 色彩深度设置为32-bit
   - 色彩工作空间设为Rec.709

2. **导入测试素材**
   - 使用色彩测试图（ColorChecker）
   - 或使用灰阶渐变图

3. **应用Lumetri Color效果**
   ```
   效果 → 颜色校正 → Lumetri Color
   ```

4. **调色参数设置**

   **白平衡：**
   | 参数 | 数值 | 说明 |
   |------|------|------|
   | 色温 | +15 | 暖色调 |
   | 色调 | -5 | 微调绿色 |

   **色调：**
   | 参数 | 数值 | 说明 |
   |------|------|------|
   | 曝光 | +0.2 | 整体提亮 |
   | 对比度 | +15 | 增加对比 |
   | 高光 | -20 | 压暗高光 |
   | 阴影 | +25 | 提亮阴影 |
   | 白色 | +10 | 增加白场 |
   | 黑色 | -10 | 加深黑场 |

   **饱和度：**
   | 参数 | 数值 | 说明 |
   |------|------|------|
   | 饱和度 | +10 | 整体增加 |
   | 自然饱和度 | +15 | 智能增加 |

5. **导出LUT**
   ```
   Lumetri Color面板 → 导出LUT → 选择.cube格式 → 33×33×33尺寸
   ```

#### 2.1.2 使用Curves制作LUT

**RGB曲线调色：**

```
主曲线：
  输入128 → 输出135 (S曲线增加对比)
  输入64 → 输出58 (暗部压暗)
  输入192 → 输出198 (高光提亮)

红色通道：
  输入128 → 输出132 (中间调偏红)
  输入0 → 输出5 (暗部偏暖)

绿色通道：
  输入128 → 输出125 (中间调减少绿色)

蓝色通道：
  输入128 → 输出120 (中间调减少蓝色，偏暖)
  输入255 → 输出250 (高光减少蓝色)
```

| 特性 | CST节点 | LUT |

| 精度 | 高 | 取决于LUT尺寸 |

| 文件 | 无需文件 | 需要文件 |

**CST参数设置：**

| 参数 | 输入设置 | 输出设置 |
|------|---------|---------|
| 色彩空间 | ARRI Alexa | Rec.709 |
| 伽马 | LogC | Gamma 2.4 |
| 色调映射 | Simple | Simple |
| 自适应 | - | 中等 |

### 2.3 专业LUT制作工具

#### 2.3.1 Lattice

## 十一、LUT常见问题

### 11.1 LUT应用后色彩偏移

**原因：**
1. 色彩空间不匹配
2. LUT设计基于不同色彩空间
3. 伽马值不正确

**解决方案：**

| 问题原因 | 解决方案 |
|---------|---------|
| 色彩空间不匹配 | 先转换色彩空间 |
| 伽马不正确 | 调整伽马值 |
| LUT不适用 | 选择合适LUT |
| 素材问题 | 检查原始素材 |

### 11.2 LUT应用后画面变暗/变亮

**原因：**
1. LUT改变了曝光
2. 黑白场设置不同
3. 伽马曲线差异

**解决方案：**

```
1. 检查LUT的输入输出范围
2. 调整曝光补偿
3. 使用CST节点代替LUT
4. 手动调整亮度
```

### 11.3 LUT应用后色带问题

**原因：**
1. 8-bit素材
2. LUT尺寸过小（17点）
3. 强烈调色

**解决方案：**

| 问题原因 | 解决方案 |
|---------|---------|
| 8-bit素材 | 使用10-bit以上 |
| LUT过小 | 使用33点以上LUT |
| 调色过强 | 降低LUT强度 |
| 压缩问题 | 使用高质量编码 |

### 11.4 LUT兼容性问题

**原因：**
1. 格式不支持
2. 软件版本不兼容
3. 文件损坏

**解决方案：**

```
1. 转换LUT格式（使用Lattice）
2. 更新软件版本
3. 重新下载LUT
4. 检查文件完整性
```

### 11.5 LUT强度调节

**方法：**

1. **AE中调节**
   ```jsx
   lutEffect.property("Mix with Original").setValue(50); // 50%强度
   ```

2. **Premiere中调节**
   - Lumetri Color → 创意 → 强度

3. **DaVinci中调节**
   - 节点Key → 输出增益

### 11.6 多LUT叠加

**注意事项：**

1. LUT叠加会累积效果
2. 建议技术LUT + 创意LUT
3. 避免多个创意LUT叠加
4. 注意色彩空间转换顺序

**推荐叠加方式：**

```
技术LUT（Log→Rec.709）
    ↓
创意LUT（调色风格）
    ↓
输出LUT（平台适配）
```

### 11.7 15个常见问题解答

#### Q1: LUT和预设有什么区别？

**A:** LUT是查找表，仅包含色彩映射信息；预设可能包含多个效果参数。LUT更通用，预设更灵活。

#### Q2: 如何选择合适的LUT尺寸？

**A:** 网络视频用17点，专业调色用33点，HDR用65点。

#### Q3: LUT可以反转吗？

**A:** 可以，使用Lattice等工具生成反向LUT，但精度会有损失。

#### Q4: 为什么我的LUT在其他软件中效果不同？

**A:** 可能是色彩空间设置不同，检查各软件的色彩管理设置。

#### Q5: LUT会影响渲染速度吗？

**A:** 会有轻微影响，但现代软件优化良好，影响可忽略。

#### Q6: 如何制作自己的LUT？

**A:** 在AE或DaVinci中调色后导出，参考第二节制作方法。

#### Q7: LUT能用于照片吗？

**A:** 可以，Photoshop支持LUT应用。

#### Q8: HDR项目如何使用LUT？

**A:** 使用HDR专用LUT，确保色彩空间为Rec.2020，位深10-bit以上。

#### Q9: LUT文件太大怎么办？

**A:** 使用较小的LUT尺寸（17点），或压缩LUT数据。

#### Q10: 如何批量应用LUT？

**A:** 使用JSX脚本批量应用，参考第十二节脚本。

#### Q11: LUT能修复拍摄问题吗？

**A:** 部分可以，如白平衡、曝光问题，但严重问题无法完全修复。

#### Q12: 不同摄影机的LUT能通用吗？

**A:** 不能，不同摄影机有专属Log格式，需使用对应技术LUT。

#### Q13: LUT过期了吗？

**A:** LUT不会过期，但技术LUT可能随标准更新而需要更换。

#### Q14: 如何学习LUT调色？

**A:** 从技术LUT开始学习，理解色彩空间，再学习创意调色。

#### Q15: 商业项目中使用LUT有版权问题吗？

**A:** 自制LUT无版权问题，商用LUT需购买授权。

## 十二、LUT预设JSX脚本

### 12.1 批量应用LUT脚本

```javascript
// 批量应用LUT到所有图层
(function batchApplyLUT() {
    var comp = app.project.activeItem;
    if (!comp || !(comp instanceof CompItem)) {
        alert("请先激活一个合成");
        return;
    }
    
    var lutPath = File.openDialog("选择LUT文件", "*.cube;*.3dl");
    if (!lutPath) return;
    
    var layers = comp.layers;
    for (var i = 1; i <= layers.length; i++) {
        var layer = layers[i];
        var lutEffect = layer.Effects.addProperty("ADBE Apply Color LUT");
        lutEffect.property("LUT").setValue(lutPath);
        lutEffect.property("Mix with Original").setValue(100);
    }
    
    alert("已批量应用LUT到" + layers.length + "个图层");
})();
```

### 12.2 LUT强度调节脚本

```javascript
// 调节所有LUT效果的强度
(function adjustLUTIntensity() {
    var comp = app.project.activeItem;
    if (!comp || !(comp instanceof CompItem)) return;
    
    var intensity = parseFloat(prompt("输入LUT强度（0-100）", "75"));
    if (isNaN(intensity) || intensity < 0 || intensity > 100) {
        alert("请输入0-100之间的数值");
        return;
    }
    
    var layers = comp.layers;
    for (var i = 1; i <= layers.length; i++) {
        var layer = layers[i];
        var effects = layer.Effects;
        for (var j = 1; j <= effects.numProperties; j++) {
            var effect = effects.property(j);
            if (effect.matchName === "ADBE Apply Color LUT") {
                effect.property("Mix with Original").setValue(100 - intensity);
            }
        }
    }
    
    alert("LUT强度已设置为" + intensity + "%");
})();
```

// LUT强度动画
(function animateLUTIntensity() {
    var comp = app.project.activeItem;
    if (!comp) return;
    var layer = comp.selectedLayers[0];
    if (!layer) return;
    
    var lutEffect = layer.Effects.addProperty("ADBE Apply Color LUT");
    var mixProp = lutEffect.property("Mix with Original");
    
    // 关键帧动画
    mixProp.setValueAtTime(0, 100);      // 开始：0%强度
    mixProp.setValueAtTime(1, 50);       // 1秒：50%强度
    mixProp.setValueAtTime(2, 25);       // 2秒：75%强度
    mixProp.setValueAtTime(3, 0);        // 3秒：100%强度
    
    // 设置缓动
    for (var i = 1; i <= 3; i++) {
        var keyframe = mixProp.keyValue(i);
        var easeIn = new KeyframeEase(0, 50);
        var easeOut = new KeyframeEase(0, 50);
        mixProp.setTemporalEaseAtKey(i, [easeIn], [easeOut]);
    }
})();
