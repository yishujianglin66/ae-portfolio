# 📦 素材收集与管理技巧

> 整理看似"浪费时间"，但不整理的代价是后期十倍的时间损耗。

---

## 📁 标准项目文件夹结构

### 磁盘端（推荐模板）

```
Project_Name/
├── 01_Assets/              ← 所有原始素材
│   ├── Footage/            ← 视频素材
│   ├── Images/             ← 图片/插画/贴纸
│   ├── Audio/              ← 音频素材
│   │   ├── BGM/            ← 背景音乐
│   │   └── SFX/            ← 音效
│   ├── Graphics/           ← 图形/矢量/Logo
│   └── Fonts/              ← 字体文件
├── 02_Compositions/        ← AE 合成文件
│   ├── Final/              ← 最终合成
│   └── Working/            ← 工作草稿
├── 03_Precomps/            ← 预合成
├── 04_Exports/             ← 渲染输出
│   ├── Drafts/             ← 预览版本
│   └── Final/              ← 最终交付
├── 05_References/          ← 参考素材（情绪板、风格参考）
└── Project_v01.aep         ← AE 项目文件
```

### AE 项目面板内分类

| 文件夹 | 内容 |
|--------|------|
| `_FOOTAGE` | 所有原始视频素材 |
| `_AUDIO` | BGM + SFX |
| `_GRAPHICS` | 图片、Logo、图形元素 |
| `_COMPS` | 合成（按场景分） |
| `_PRECOMPS` | 预合成 |
| `_SOLIDS` | 纯色层、调整层 |
| `_NULLS` | 空对象 |
| `_TEXT` | 文字层 |

> `_` 前缀让文件夹排在前面，`z_` 后缀让归档排最后。

## 🏷️ 命名规范

### 黄金法则

> 命名要有意义——"Red_Car_Side" 比 "DSC008.mp4" 有用 100 倍

### 命名模板

| 对象类型 | 命名格式 | 示例 |
|---------|---------|------|
| 主合成 | `[项目]_[场景]_v[版本号]` | `BrandFilm_Opening_v03` |
| 预合成 | `pc_[功能描述]` | `pc_BG_Cyberpunk`, `pc_Logo_Anim` |
| 视频素材 | `[内容]_[取景]_[编号]` | `City_Tokyo_Shinjuku_01.mp4` |
| 图片素材 | `[内容]_[风格]_[尺寸]` | `Logo_Main_White_1920.png` |
| 音频素材 | `[类型]_[情绪/用途]` | `BGM_Energetic_120bpm.wav`, `SFX_Whoosh_Heavy.wav` |
| 固态层 | `[颜色]_[用途]` | `White_BG`, `Black_Shadow` |
| 文字层 | `txt_[内容]` | `txt_Title_Main`, `txt_Subtitle_01` |

## 🎨 图层管理 — 时间轴不乱

| 技巧 | 操作 | 效果 |
|------|------|------|
| **颜色标签** | 右键图层 → 标签 | 红=文字, 蓝=特效, 黄=调整层, 绿=素材 |
| **Shy 图层** | 点击图层旁的害羞图标 | 不常编辑的图层一键隐藏 |
| **预合成** | `Ctrl+Shift+C` → 选第二个 | 把关联图层打包，时间轴清爽 |
| **图层搜索** | 时间轴顶部搜索栏 | 输入名称秒定位图层 |

## ⚡ 效率工具与脚本

### Declutter v1.5.1（强烈推荐）

一键自动将素材按类型整理到预设文件夹结构：

- 支持自定义父/子文件夹
- 支持自定义标签和颜色
- 可保存多套模板，适配不同项目类型
- 支持 AE 2019–2025，Win/Mac 双平台
- 下载：LookAE.com（搜索 Declutter）

### AE 内置提效功能

| 功能 | 操作 | 效果 |
|------|------|------|
| 搜索缺失素材 | 项目面板搜索 `missing` | 找出所有脱机素材 |
| 移除未使用素材 | `文件 → 依赖项 → 移除未使用素材` | 项目瘦身 |
| 整合重复素材 | `文件 → 依赖项 → 整合所有素材` | 消除重复 |
| 精简项目 | `文件 → 依赖项 → 精简项目` | 删除冗余 |
| 递增保存 | `Ctrl+Alt+Shift+S` | 保版本历史，不怕回退 |

## 🔄 代理与占位符工作流

### 代理（Proxy）
- 用低分辨率版本替代 4K/8K 原始素材
- 渲染预览飞快，切回高清丝滑
- 设置：右键素材 → `创建代理 → 影片`

### 占位符（Placeholder）
- 素材未就绪时用彩条占位，保持工作推进
- `文件 → 导入 → 占位符`
- 后期替换：右键 → `替换素材 → 文件`

### 冻结帧
- `图层 → 时间 → 在最后一帧上冻结`
- 自动设置时间重映射

## 🔗 合成嵌套

- 背景动画、元素动画、文字动画**分别放在独立合成**
- 项目面板分 `Main Composition` 和 `Working` 两个文件夹
- 用关联器（Pick Whip）连接图层属性，**减少关键帧数量**

## 📋 每日好习惯清单

| ✅ 习惯 | 收益 |
|---------|------|
| 项目开始先建文件夹结构 | 不乱放素材 |
| 导入后立刻重命名+归类 | 后期不找瞎 |
| 图层创建后马上命名+上色 | 时间轴一目了然 |
| 每天收工时「递增保存」 | 不怕崩溃回退 |
| 每周「移除未使用素材」 | 项目文件瘦身 |
| 交付前「整合所有素材」 | 清理重复项 |
| 渲染前检查所有素材在线 | 避免渲染中断 |
