# AE 色彩管理与HDR工作流完全指南

> 版本: 2025-v1 | 适用: 色彩管理/HDR合成/ACES工作流

## 一、色彩管理基础

### 1.1 项目色彩管理

| 设置 | 说明 | 建议 |
|------|------|------|
| 色彩空间 | 项目工作色彩空间 | ACES/AP0 |
| 合成色彩空间 | 合成工作空间 | ACEScg |
| 查看变换 | 显示变换 | sRGB/Rec.709 |
| 线性化 | 素材线性化 | 自动 |

### 1.2 色彩管理设置

```
启用色彩管理:
1. 文件→项目设置→色彩管理
2. 色彩空间: ACES
3. 合成色彩空间: ACEScg
4. 查看变换: sRGB
5. 线性化工作流程: 启用

素材色彩管理:
1. 右键素材→解释素材→色彩管理
2. 色彩空间: 选择素材原始空间
   - sRGB: 普通图片
   - Rec.709: 视频素材
   - ACEScg: 渲染输出
   - 自定义: 特定色彩空间
3. 应用设置
```

## 二、ACES工作流

### 2.1 ACES概述

| 组件 | 说明 | 用途 |
|------|------|------|
| IDT | 输入设备变换 | 素材→ACES |
| ACEScg | 工作色彩空间 | 合成空间 |
| RRT | 渲染变换 | 色调映射 |
| ODT | 输出设备变换 | ACES→显示 |

### 2.2 ACES工作流

```
ACES工作流:
1. 项目设置→色彩管理→ACES
2. 素材导入→自动IDT转换
   - sRGB→ACES
   - Rec.709→ACES
   - RAW→ACES
3. 合成在ACEScg中进行
4. 应用效果(线性空间)
5. 输出→ODT转换
   - ACES→sRGB
   - ACES→Rec.709
   - ACES→HDR

优势:
- 统一色彩空间
- 线性工作流程
- 精确色彩还原
- HDR支持
```

### 2.3 ACES表达式

```javascript
// ACES色彩空间转换
// 在效果控制中使用
var color = effect("Color Correction")("Color");
// ACES自动处理转换
```

## 三、HDR工作流

### 3.1 HDR格式

| 格式 | 位深 | 色彩空间 | 传输函数 | 用途 |
|------|------|---------|---------|------|
| HDR10 | 10-bit | Rec.2020 | PQ | 静态HDR |
| HDR10+ | 10-bit | Rec.2020 | PQ+动态 | 动态HDR |
| HLG | 10-bit | Rec.2020 | HLG | 广播HDR |
| Dolby Vision | 12-bit | P3/Rec.2020 | PQ+动态 | 高端HDR |

### 3.2 HDR项目设置

```
HDR项目配置:
1. 文件→项目设置→色彩管理
2. 色彩空间: Rec.2020
3. 位深: 10-bit或更高
4. 启用HDR

合成设置:
1. 合成设置→色彩管理
2. 工作色彩空间: ACEScg
3. 查看变换: PQ/HLG
4. 峰值亮度: 1000-4000 nits
```

### 3.3 HDR合成

```
HDR合成技巧:
1. 使用32位/通道合成
2. 线性工作流程
3. 避免裁剪高光
4. 使用HDR兼容效果
5. 正确设置峰值亮度

注意事项:
- 普通效果可能不支持HDR
- 使用"HDR效果"或"线性效果"
- 检查效果是否支持32位
```

## 四、LUT应用

### 4.1 LUT类型

| 类型 | 说明 | 用途 |
|------|------|------|
| 技术LUT | 色彩空间转换 | 标准化 |
| 创意LUT | 风格化调色 | 电影感 |
| 显示LUT | 监视器校准 | 准确预览 |
| 校准LUT | 设备校准 | 色彩准确 |

### 4.2 LUT应用方法

```
应用LUT:
1. 效果→颜色校正→应用自定义LUT
2. 选择LUT文件(.cube/.3dl)
3. 调整强度: 0-100%
4. 预览效果

LUT顺序:
1. 技术LUT(色彩空间)
2. 曝光/白平衡
3. 创意LUT(风格)
4. 输出LUT(标准化)

注意事项:
- LUT顺序影响结果
- 在线性空间应用LUT
- 避免过度处理
```

## 五、色彩校正效果

### 5.1 Lumetri颜色

| 模块 | 功能 | 用途 |
|------|------|------|
| 基本校正 | 曝光/对比度/白平衡 | 一级校正 |
| 创意 | 褪色胶片/锐化/饱和度 | 风格化 |

### 5.2 颜色校正工作流

```
标准调色流程:
1. 一级校正:
   - 曝光/对比度
   - 白平衡
   - 基本色调

2. 二级校正:
   - 特定颜色调整
   - 分区调色
   - 局部调整

3. 创意调色:
   - 应用LUT
   - 风格化
   - 最终调整

4. 输出标准化:
   - 检查色彩空间
   - 应用输出LUT
   - 验证色彩准确
```

### 6.2 色彩空间转换

```javascript
// 色彩空间转换表达式
// 在效果控制中使用
function linearToSRGB(c) {
    return c <= 0.0031308 ? 
        12.92 * c : 
        1.055 * Math.pow(c, 1/2.4) - 0.055;
}

function sRGBToLinear(c) {
    return c <= 0.04045 ? 
        c / 12.92 : 
        Math.pow((c + 0.055) / 1.055, 2.4);
}
```
