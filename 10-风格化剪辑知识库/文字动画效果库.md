## 二、Text Animator 深度指南

### 2.1 Text Animator 核心概念

**Text Animator** 是 AE 中最强大的文字动画工具，可以实现精细的逐字、逐行动画控制。

**核心组件**：
1. **Animator Group（动画器组）**：包含一个或多个属性和选择器
2. **Property（属性）**：要动画的属性（位置、缩放、透明度等）
3. **Selector（选择器）**：控制哪些文字受到动画影响
4. **Range Selector（范围选择器）**：定义一个连续的文字范围
5. **Wiggly Selector（摇摆选择器）**：随机选择文字
6. **Expression Selector（表达式选择器）**：通过表达式控制选择

### 2.2 常用 Animator 属性详解

**变换属性**：
- `ADBE Text Position` - 位置偏移（相对于锚点）
- `ADBE Text Scale` - 缩放（百分比）
- `ADBE Text Rotation` - 旋转（度数）
- `ADBE Text Opacity` - 透明度（百分比）
- `ADBE Text Skew` - 倾斜（度数）
- `ADBE Text Anchor Point` - 锚点位置

**文字属性**：
- `ADBE Text Tracking` - 字间距（像素）
- `ADBE Text Leading` - 行间距（像素）
- `ADBE Text Fill Color` - 填充色（RGB）
- `ADBE Text Stroke Color` - 描边色（RGB）
- `ADBE Text Stroke Width` - 描边宽度（像素）
- `ADBE Text Blur` - 模糊（像素）
- `ADBE Text Baseline Shift` - 基线偏移（像素）

### 2.3 Range Selector 属性详解

| 属性 | 说明 | 取值范围 |
|------|------|---------|
| Start | 选择范围起始位置 | 0-100% |
| End | 选择范围结束位置 | 0-100% |
| Offset | 选择范围偏移 | 任意值 |
| Amount | 影响程度 | 0-100% |
| Units | 单位 | Percent/Index/Characters/Words/Lines |
| Mode | 混合模式 | Add/Subtract/Intersect/Min/Max/Difference |
| Smoothness | 平滑度 | 0-100% |
| Ease High | 高端缓动 | 0-100% |
| Ease Low | 低端缓动 | 0-100% |
| Randomize Order | 随机顺序 | On/Off |
| Random Seed | 随机种子 | 整数 |

### 2.4 高级 Selector 技巧

**技巧 1：多个 Range Selector 叠加**
```jsx
// 添加多个选择器实现复杂效果
var animGroup = textLayer.property("ADBE Text Properties").addProperty("ADBE Text Animator");
animGroup.addProperty("ADBE Text Property Group").addProperty("ADBE Text Opacity").setValue(0);

// 选择器1：控制淡入范围
var sel1 = animGroup.property("ADBE Text Selectors").addProperty("ADBE Text Selector");
sel1.property("ADBE Text Selector Start").setValueAtTime(0, 0);
sel1.property("ADBE Text Selector Start").setValueAtTime(1, 100);

// 选择器2：添加延迟效果
var sel2 = animGroup.property("ADBE Text Selectors").addProperty("ADBE Text Selector");
sel2.property("ADBE Text Selector Offset").setValueAtTime(0, -50);
sel2.property("ADBE Text Selector Offset").setValueAtTime(1, 50);
```

**技巧 2：Wiggly Selector 实现随机效果**
```jsx
var animGroup = textLayer.property("ADBE Text Properties").addProperty("ADBE Text Animator");
animGroup.addProperty("ADBE Text Property Group").addProperty("ADBE Text Position").setValue([0, 20]);

// 添加摇摆选择器
var wiggly = animGroup.property("ADBE Text Selectors").addProperty("ADBE Wiggly Selector");
wiggly.property("ADBE Text Selector Wiggles").setValue(3);  // 摆动次数
wiggly.property("ADBE Text Selector Correlation").setValue(0);  // 相关性
wiggly.property("ADBE Text Selector Temporal Phase").setValue(0);
wiggly.property("ADBE Text Selector Spatial Phase").setValue(0);
```

**技巧 3：Expression Selector 实现复杂逻辑**
```jsx
var animGroup = textLayer.property("ADBE Text Properties").addProperty("ADBE Text Animator");
animGroup.addProperty("ADBE Text Property Group").addProperty("ADBE Text Scale").setValue([150, 150]);

var exprSelector = animGroup.property("ADBE Text Selectors").addProperty("ADBE Expression Selector");
// 表达式：奇数位置的文字放大
exprSelector.property("ADBE Text Selector Amount").expression = "index % 2 == 1 ? 100 : 0";
```

## 三、文字动画表达式高级技巧

### 3.1 基础表达式

**随机抖动**：
```jsx
// 位置随机抖动
var seed = 123;
var amp = 5;
wiggle(5, amp, octaves=1, amp_mult=0.5, t=time, seed=seed)
```

**弹性效果**：
```jsx
// 弹性缩放
freq = 3;
decay = 2;
amp = 10;
value + [0, Math.sin(time * freq * Math.PI * 2) * amp / Math.exp(decay * time)]
```

**跟随音频**：
```jsx
// 根据音频振幅缩放
audioLayer = thisComp.layer("Audio");
audioLevels = audioLayer.audioLevels;
avgAudio = (audioLevels[0] + audioLevels[1]) / 2;
scaleFactor = linear(avgAudio, -20, 0, 100, 130);
[scaleFactor, scaleFactor]
```

### 3.2 高级表达式

**波浪效果**：
```jsx
// 文字波浪效果（需要在 Text Animator 中使用）
freq = 2;
amp = 30;
offset = 0;
[0, Math.sin((textIndex + offset) * freq * Math.PI / 180 + time * 5) * amp]
```

**打字机效果**：
```jsx
// 打字机效果（Text Animator Offset）
charsPerSecond = 10;
textIndex / charsPerSecond
```

**字符级延迟**：
```jsx
// 每个字符延迟不同时间
delay = 0.05;
time - (textIndex * delay)
```

**颜色渐变**：
```jsx
// 从红色渐变到蓝色
startColor = [1, 0, 0];
endColor = [0, 0, 1];
linear(textIndex, 1, textTotal, startColor, endColor)
```

### 3.3 实用表达式库

**循环动画**：
```jsx
// 无限循环
loopDuration = 2;
t = time % loopDuration;
// 在 t 范围内定义动画
```

**缓入缓出**：
```jsx
// 自定义缓入缓出
easeInOut(time, 0, 1, 0, 1)
```

**弹跳曲线**：
```jsx
// 弹跳效果
bounce(time, 0, 1, 1)
```

## 六、文字动画性能优化

### 6.1 性能瓶颈

| 瓶颈类型 | 原因 | 影响 |
|---------|------|------|
| 复杂表达式 | 每帧计算量大 | 预览卡顿 |
| 大量粒子 | Particular/Form 粒子数过多 | 渲染缓慢 |
| 多层文字动画 | 多个 Text Animator 叠加 | 内存占用高 |
| 高分辨率合成 | 4K/8K 合成 | 预览和渲染慢 |

### 6.2 优化策略

**表达式优化**：
- 减少循环计算
- 使用预计算变量
- 避免在表达式中调用复杂函数

**粒子优化**：
- 减少粒子数量
- 使用较低分辨率的粒子图层
- 关闭不必要的物理模拟

**图层优化**：
- 使用预合成（Pre-compose）
- 渲染缓存
- 使用代理

**渲染优化**：
- 使用多帧渲染（Multi-Frame Rendering）
- 开启 GPU 加速
- 使用渲染队列优化

## 七、文字动画常见问题与解决方案

### 7.1 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 文字动画不生效 | Animator 属性值为0 | 检查属性值是否正确设置 |
| 逐字动画不流畅 | Selector Smoothness 过低 | 增加 Smoothness 值 |
| 文字闪烁 | 关键帧间隔太小 | 增加关键帧间隔或使用缓动 |
| 性能卡顿 | 表达式太复杂 | 简化表达式或使用预合成 |
| 导出后文字丢失 | 字体未嵌入 | 确保字体已安装或使用系统字体 |
| 动画不同步 | 时间轴对齐问题 | 对齐到节拍点 |

### 7.2 调试技巧

1. **使用关键帧图表**：查看动画曲线是否正确
2. **预览单个属性**：单独预览每个动画属性
3. **禁用表达式**：临时禁用表达式检查是否为表达式问题
4. **使用合成流程图**：查看图层关系
5. **清理缓存**：清除渲染缓存重新渲染

## 十一、逐字动画深度解析

### 11.1 Range Selector 逐字动画完整参数表

Range Selector（范围选择器）是 AE Text Animator 中最核心的组件，通过精确控制选择范围实现逐字动画效果。以下为完整参数表：

| 参数名称 | 英文名 | 说明 | 取值范围 | 默认值 | 单位 |
|---------|--------|------|---------|--------|------|
| Start | 起始位置 | 选择范围起始点 | 0-100 | 0 | % |
| End | 结束位置 | 选择范围结束点 | 0-100 | 100 | % |
| Offset | 偏移量 | 整体偏移选择范围 | -100到100 | 0 | % |
| Units | 单位模式 | 定义选择单位 | Percent/Index | Percent | - |
| Based On | 基于类型 | 选择基于的元素 | Characters/Chars Excluding Spaces/Words/Lines | Characters | - |
| Amount | 影响量 | 选择器影响程度 | 0-100 | 100 | % |
| Shape | 形状 | 选择范围边缘形状 | Square/Ramp Up/Ramp Down/Triangle/Round/Smooth | Square | - |
| Smoothness | 平滑度 | 边缘过渡平滑度 | 0-100 | 0 | % |
| Ease High | 高端缓动 | 上边缘缓动 | 0-100 | 0 | % |
| Ease Low | 低端缓动 | 下边缘缓动 | 0-100 | 0 | % |
| Mode | 混合模式 | 多选择器混合方式 | Add/Subtract/Intersect/Min/Max/Difference | Add | - |
| Randomize Order | 随机顺序 | 是否随机化选择顺序 | On/Off | Off | - |
| Random Seed | 随机种子 | 随机化种子值 | 0-99999 | 0 | 整数 |
| Index | 索引 | 在Index模式下的起始索引 | 0-N | 0 | 整数 |

**关键参数详解**：

**Shape（形状）参数**：
- `Square`：方形选择，边缘锐利，无过渡
- `Ramp Up`：渐入，从0到100%线性过渡
- `Ramp Down`：渐出，从100%到0线性过渡
- `Triangle`：三角形，中间最高，两端为0
- `Round`：圆形，类似三角形但更平滑
- `Smooth`：平滑，使用三次贝塞尔曲线过渡

**Based On（基于类型）参数**：
- `Characters`：基于每个字符（包括空格）
- `Chars Excluding Spaces`：基于字符（排除空格）
- `Words`：基于单词
- `Lines`：基于行

**Mode（混合模式）详解**：
- `Add`：将选择器结果添加到其他选择器
- `Subtract`：从其他选择器中减去
- `Intersect`：取交集
- `Min`：取最小值
- `Max`：取最大值
- `Difference`：取差值

### 11.2 逐字淡入淡出动画

**实现步骤**：
1. 创建文字图层
2. 添加 Text Animator，选择 Opacity 属性
3. 设置 Opacity 为 0
4. 添加 Range Selector
5. 动画 Offset 从 -100 到 100
6. 调整 Shape 为 Ramp Up
7. 设置 Smoothness 为 50%

**完整 JSX 脚本**：

```jsx
/**
 * 逐字淡入淡出动画
 * 功能：创建文字逐字淡入淡出效果
 * 参数：可自定义淡入速度、方向、缓动
 */
(function perCharFadeAnim() {
    var comp = app.project.activeItem;
    if (!comp || !(comp instanceof CompItem)) {
        alert("请先打开一个合成");
        return;
    }

    var textLayer = comp.selectedLayers[0];
    if (!textLayer || !(textLayer instanceof TextLayer)) {
        alert("请先选择一个文字图层");
        return;
    }

    // 配置参数
    var config = {
        fadeInDuration: 1.0,       // 淡入持续时间（秒）
        fadeOutDuration: 1.0,      // 淡出持续时间（秒）
        holdDuration: 2.0,         // 停留时间（秒）
        smoothness: 50,            // 平滑度
        easeHigh: 50,              // 高端缓动
        easeLow: 50,               // 低端缓动
        perCharDelay: 0.05,        // 每字延迟（秒）
        shape: "Ramp Up"           // 选择器形状
    };

    app.beginUndoGroup("逐字淡入淡出动画");

    var textProp = textLayer.property("ADBE Text Properties");
    var textAnimators = textProp.property("ADBE Text Animators");

    // 创建淡入动画器
    var fadeInAnim = textAnimators.addProperty("ADBE Text Animator");
    fadeInAnim.name = "淡入动画";

    // 添加透明度属性
    var opacityProp = fadeInAnim.property("ADBE Text Properties").addProperty("ADBE Text Opacity");
    opacityProp.setValue(0); // 初始透明度为0

    // 获取Range Selector
    var rangeSelector = fadeInAnim.property("ADBE Text Selectors").property(1);

    // 设置选择器参数
    rangeSelector.property("ADBE Text Selector Shape").setValue(config.shape === "Ramp Up" ? 1 : 0);
    rangeSelector.property("ADBE Text Selector Smoothness").setValue(config.smoothness);
    rangeSelector.property("ADBE Text Selector Ease High").setValue(config.easeHigh);
    rangeSelector.property("ADBE Text Selector Ease Low").setValue(config.easeLow);

    // 设置Offset关键帧 - 淡入
    var startTime = textLayer.inPoint;
    rangeSelector.property("ADBE Text Selector Offset").setValueAtTime(startTime, -100);
    rangeSelector.property("ADBE Text Selector Offset").setValueAtTime(startTime + config.fadeInDuration, 100);

    // 添加缓动
    var fadeInKeyframes = rangeSelector.property("ADBE Text Selector Offset").keyTimes;
    for (var i = 0; i < fadeInKeyframes.length; i++) {
        rangeSelector.property("ADBE Text Selector Offset").setTemporalEaseAtKey(i + 1, [new KeyframeEase(0, 33)], [new KeyframeEase(0, 33)]);
    }

    // 创建淡出动画器
    var fadeOutAnim = textAnimators.addProperty("ADBE Text Animator");
    fadeOutAnim.name = "淡出动画";

    var opacityOutProp = fadeOutAnim.property("ADBE Text Properties").addProperty("ADBE Text Opacity");
    opacityOutProp.setValue(0);

    var rangeOutSelector = fadeOutAnim.property("ADBE Text Selectors").property(1);
    rangeOutSelector.property("ADBE Text Selector Shape").setValue(config.shape === "Ramp Up" ? 1 : 0);
    rangeOutSelector.property("ADBE Text Selector Smoothness").setValue(config.smoothness);

    var fadeOutStartTime = startTime + config.fadeInDuration + config.holdDuration;
    rangeOutSelector.property("ADBE Text Selector Offset").setValueAtTime(fadeOutStartTime, 100);
    rangeOutSelector.property("ADBE Text Selector Offset").setValueAtTime(fadeOutStartTime + config.fadeOutDuration, -100);

    // 设置淡出缓动
    var fadeOutKeyframes = rangeOutSelector.property("ADBE Text Selector Offset").keyTimes;
    for (var j = 0; j < fadeOutKeyframes.length; j++) {
        rangeOutSelector.property("ADBE Text Selector Offset").setTemporalEaseAtKey(j + 1, [new KeyframeEase(0, 33)], [new KeyframeEase(0, 33)]);
    }

    app.endUndoGroup();
    alert("逐字淡入淡出动画创建完成！");
})();
```

### 11.3 逐字缩放动画

**实现步骤**：
1. 创建文字图层
2. 添加 Text Animator，选择 Scale 属性
3. 设置 Scale 为 [200, 200]（放大2倍）

**完整 JSX 脚本**：

```jsx
/**
 * 逐字缩放动画
 * 功能：文字逐字放大缩小效果
 * 参数：可自定义缩放比例、动画速度、缓动类型
 */
(function perCharScaleAnim() {
    var comp = app.project.activeItem;
    if (!comp || !(comp instanceof CompItem)) {
        alert("请先打开一个合成");
        return;
    }

    var textLayer = comp.selectedLayers[0];
    if (!textLayer || !(textLayer instanceof TextLayer)) {
        alert("请先选择一个文字图层");
        return;
    }

    // 配置参数
    var config = {
        startScale: [200, 200],    // 起始缩放（百分比）
        endScale: [100, 100],      // 结束缩放
        duration: 2.0,             // 动画持续时间
        smoothness: 75,            // 平滑度
        easeHigh: 75,              // 高端缓动
        easeLow: 75,               // 低端缓动
        shape: "Round",            // 选择器形状
        randomizeOrder: false,     // 是否随机顺序
        randomSeed: 42             // 随机种子
    };

    app.beginUndoGroup("逐字缩放动画");

    var textProp = textLayer.property("ADBE Text Properties");
    var textAnimators = textProp.property("ADBE Text Animators");

    // 创建缩放动画器
    var scaleAnim = textAnimators.addProperty("ADBE Text Animator");
    scaleAnim.name = "逐字缩放";

    // 添加缩放属性
    var scaleProp = scaleAnim.property("ADBE Text Properties").addProperty("ADBE Text Scale");
    scaleProp.setValue(config.startScale);

    // 获取并配置Range Selector
    var rangeSelector = scaleAnim.property("ADBE Text Selectors").property(1);

    // 设置形状
    var shapeValue = 0;
    switch (config.shape) {
        case "Square": shapeValue = 0; break;
        case "Ramp Up": shapeValue = 1; break;
        case "Ramp Down": shapeValue = 2; break;
        case "Triangle": shapeValue = 3; break;
        case "Round": shapeValue = 4; break;
        case "Smooth": shapeValue = 5; break;
        default: shapeValue = 4;
    }
    rangeSelector.property("ADBE Text Selector Shape").setValue(shapeValue);
    rangeSelector.property("ADBE Text Selector Smoothness").setValue(config.smoothness);
    rangeSelector.property("ADBE Text Selector Ease High").setValue(config.easeHigh);
    rangeSelector.property("ADBE Text Selector Ease Low").setValue(config.easeLow);

    // 设置随机顺序
    if (config.randomizeOrder) {
        rangeSelector.property("ADBE Text Selector Randomize Order").setValue(1);
        rangeSelector.property("ADBE Text Selector Random Seed").setValue(config.randomSeed);
    }

    // 动画Offset实现逐字效果
    var startTime = textLayer.inPoint;
    rangeSelector.property("ADBE Text Selector Offset").setValueAtTime(startTime, -100);
    rangeSelector.property("ADBE Text Selector Offset").setValueAtTime(startTime + config.duration, 100);

    // 添加Ease缓动
    var offsetProp = rangeSelector.property("ADBE Text Selector Offset");
    var numKeys = offsetProp.numKeys;
    for (var i = 1; i <= numKeys; i++) {
        var easeIn = new KeyframeEase(0, 50);
        var easeOut = new KeyframeEase(0, 50);
        offsetProp.setTemporalEaseAtKey(i, [easeIn], [easeOut]);
    }

    // 同时添加透明度动画增强效果
    var opacityProp = scaleAnim.property("ADBE Text Properties").addProperty("ADBE Text Opacity");
    opacityProp.setValue(0);

    app.endUndoGroup();
    alert("逐字缩放动画创建完成！");
})();
```

### 11.5 逐字位移动画（上/下/左/右）

**实现步骤**：

```jsx
/**
 * 逐字位移动画
 * 功能：文字逐字从指定方向位移入场
 * 参数：方向（上/下/左/右）、距离、速度
 */
(function perCharPositionAnim() {
    var comp = app.project.activeItem;
    if (!comp || !(comp instanceof CompItem)) {
        alert("请先打开一个合成");
        return;
    }

    var textLayer = comp.selectedLayers[0];
    if (!textLayer || !(textLayer instanceof TextLayer)) {
        alert("请先选择一个文字图层");
        return;
    }

    // 配置参数
    var config = {
        direction: "up",           // 方向: up/down/left/right
        distance: 50,              // 位移距离（像素）
        duration: 1.5,             // 动画持续时间
        smoothness: 60,            // 平滑度
        easeHigh: 80,              // 高端缓动
        easeLow: 80,               // 低端缓动
        shape: "Ramp Up",          // 选择器形状
        bounce: true,              // 是否添加弹性
        bounceAmount: 1.15         // 弹性幅度
    };

    app.beginUndoGroup("逐字位移动画");

    var textProp = textLayer.property("ADBE Text Properties");
    var textAnimators = textProp.property("ADBE Text Animators");

    // 创建位移动画器
    var posAnim = textAnimators.addProperty("ADBE Text Animator");
    posAnim.name = "逐字位移_" + config.direction;

    var animProps = posAnim.property("ADBE Text Properties");

    // 根据方向设置位移
    var positionValue = [0, 0];
    switch (config.direction) {
        case "up":
            positionValue = [0, -config.distance];
            break;
        case "down":
            positionValue = [0, config.distance];
            break;
        case "left":
            positionValue = [-config.distance, 0];
            break;
        case "right":
            positionValue = [config.distance, 0];
            break;
        default:
            positionValue = [0, -config.distance];
    }

    // 添加位置属性
    var posProp = animProps.addProperty("ADBE Text Position");
    posProp.setValue(positionValue);

    // 添加透明度
    var opacityProp = animProps.addProperty("ADBE Text Opacity");
    opacityProp.setValue(0);

    // 配置Range Selector
    var rangeSelector = posAnim.property("ADBE Text Selectors").property(1);

    // 设置形状和平滑度
    var shapeValue = 1; // Ramp Up
    rangeSelector.property("ADBE Text Selector Shape").setValue(shapeValue);
    rangeSelector.property("ADBE Text Selector Smoothness").setValue(config.smoothness);
    rangeSelector.property("ADBE Text Selector Ease High").setValue(config.easeHigh);
    rangeSelector.property("ADBE Text Selector Ease Low").setValue(config.easeLow);

    // 动画Offset
    var startTime = textLayer.inPoint;
    var offsetProp = rangeSelector.property("ADBE Text Selector Offset");

    if (config.bounce) {
        // 弹性入场：先过冲再回弹
        offsetProp.setValueAtTime(startTime, -100);
        offsetProp.setValueAtTime(startTime + config.duration * 0.7, 115);
        offsetProp.setValueAtTime(startTime + config.duration, 100);

        // 设置弹性缓动
        var easeIn1 = new KeyframeEase(0, 30);
        var easeOut1 = new KeyframeEase(0.3, 60);
        offsetProp.setTemporalEaseAtKey(1, [easeIn1], [easeOut1]);

        var easeIn2 = new KeyframeEase(0.5, 70);
        var easeOut2 = new KeyframeEase(0.5, 70);
        offsetProp.setTemporalEaseAtKey(2, [easeIn2], [easeOut2]);

        var easeIn3 = new KeyframeEase(0.3, 80);
        var easeOut3 = new KeyframeEase(0, 30);
        offsetProp.setTemporalEaseAtKey(3, [easeIn3], [easeOut3]);
    } else {
        offsetProp.setValueAtTime(startTime, -100);
        offsetProp.setValueAtTime(startTime + config.duration, 100);
```

文字路径动画是指文字沿指定的路径（直线、曲线、圆形、自定义贝塞尔曲线等）进行运动的效果。AE中实现路径文字动画主要有以下几种方式：

1. **Mask Path 方式**：通过遮罩路径驱动文字
2. **Text on Path 方式**：使用文字图层的路径选项
3. **Expression 方式**：通过表达式计算路径上的位置
4. **插件方式**：使用 BCC Text on Path 等第三方插件

### 12.2 路径类型详解

| 路径类型 | 描述 | 适用场景 | 实现难度 |
|---------|------|---------|---------|
| 直线路径 | 文字沿直线运动 | 简单字幕、滚动文字 | ⭐ |
| 曲线路径 | 文字沿贝塞尔曲线运动 | 创意标题、流动文字 | ⭐⭐ |
| 圆形路径 | 文字沿圆形排列 | LOGO、徽章、环绕文字 | ⭐⭐ |
| 螺旋路径 | 文字沿螺旋线运动 | 创意展示、艺术效果 | ⭐⭐⭐ |
| 自定义路径 | 文字沿手绘路径运动 | 手写效果、创意动画 | ⭐⭐⭐ |
| 波浪路径 | 文字沿波浪线运动 | 水面效果、音乐律动 | ⭐⭐⭐ |
| 3D路径 | 文字在3D空间沿路径运动 | 3D展示、空间动画 | ⭐⭐⭐⭐ |

### 12.3 路径动画参数表

| 参数名称 | 说明 | 取值范围 | 默认值 |
|---------|------|---------|--------|
| Path | 路径选择 | Mask Path | - |
| Reverse Path | 反转路径方向 | On/Off | Off |
| Perpendicular to Path | 垂直于路径 | On/Off | On |
| Force Alignment | 强制对齐 | On/Off | Off |

### 12.4 文字方向控制

文字在路径上的方向控制包括：

- **Perpendicular to Path**：文字垂直于路径切线方向
- **Vertical Baseline**：文字基线垂直于路径
- **Reverse Path**：反转路径方向，文字反向排列
- **Flip Text**：翻转文字方向
- **Force Alignment**：强制文字填满整个路径

```jsx
/**
 * 文字路径动画通用函数
 * 功能：为文字图层添加路径动画
 * 参数：路径类型、速度、方向等
 */
function createTextPathAnimation(textLayer, pathType, config) {
    if (!textLayer || !(textLayer instanceof TextLayer)) {
        alert("请选择有效的文字图层");
        return false;
    }

    config = config || {};
    var defaultConfig = {
        pathType: "circle",        // 路径类型
        pathRadius: 200,           // 圆形半径
        speed: 1.0,                // 动画速度
        duration: 5.0,             // 持续时间
        reversePath: false,        // 是否反转路径
        perpendicular: true,       // 是否垂直于路径
        forceAlignment: false,     // 是否强制对齐
        baselineShift: 0,          // 基线偏移
        firstMargin: 0,            // 起始边距
        lastMargin: 0,             // 结束边距
        rotateAroundPath: false,   // 是否围绕路径旋转
        alignToPath: true          // 是否对齐到路径
    };

    for (var key in config) {
        defaultConfig[key] = config[key];
    }
    config = defaultConfig;

    app.beginUndoGroup("文字路径动画");

    var comp = textLayer.containingComp;
    var centerX = comp.width / 2;
    var centerY = comp.height / 2;

    // 创建遮罩路径
    var maskPath = null;

    switch (pathType) {
        case "circle":
            // 创建圆形路径
            maskPath = createCirclePath(centerX, centerY, config.pathRadius);
            break;
        case "line":
            // 创建直线路径
            maskPath = createLinePath(centerX, centerY, config.pathRadius * 2);
            break;
        case "wave":
            // 创建波浪路径
            maskPath = createWavePath(centerX, centerY, config.pathRadius * 2, 50, 3);
            break;
        case "spiral":
            // 创建螺旋路径
            maskPath = createSpiralPath(centerX, centerY, config.pathRadius);
            break;
        case "bezier":
            // 创建贝塞尔曲线路径
            maskPath = createBezierPath(centerX, centerY);
            break;
        default:
            maskPath = createCirclePath(centerX, centerY, config.pathRadius);
    }

    // 为文字图层添加遮罩
    var mask = textLayer.property("ADBE Mask Parade").addProperty("ADBE Mask Atom");
    mask.name = "路径遮罩";
    mask.property("ADBE Mask Shape").setValue(maskPath);
    mask.property("ADBE Mask Opacity").setValue(0); // 不可见遮罩

    // 设置文字路径选项
    var textProp = textLayer.property("ADBE Text Properties");
    var pathOptions = textProp.property("ADBE Text Path Options");
    pathOptions.property("ADBE Text Path").setValue(1); // 选择Mask 1

    // 设置路径参数
    pathOptions.property("ADBE Text Reverse Path").setValue(config.reversePath ? 1 : 0);
    pathOptions.property("ADBE Text Perpendicular to Path").setValue(config.perpendicular ? 1 : 0);
    pathOptions.property("ADBE Text Force Alignment").setValue(config.forceAlignment ? 1 : 0);
    pathOptions.property("ADBE Text Baseline Shift").setValue(config.baselineShift);
    pathOptions.property("ADBE Text First Margin").setValue(config.firstMargin);
    pathOptions.property("ADBE Text Last Margin").setValue(config.lastMargin);

    // 动画 First Margin 实现路径运动
    var firstMarginProp = pathOptions.property("ADBE Text First Margin");
    var startTime = textLayer.inPoint;
    var startMargin = -comp.width;
    var endMargin = comp.width * 2;

    firstMarginProp.setValueAtTime(startTime, startMargin);
    firstMarginProp.setValueAtTime(startTime + config.duration, endMargin);

    // 添加缓动
    for (var i = 1; i <= firstMarginProp.numKeys; i++) {
        var easeIn = new KeyframeEase(0, 50);
        var easeOut = new KeyframeEase(0, 50);
        firstMarginProp.setTemporalEaseAtKey(i, [easeIn], [easeOut]);
    }

    app.endUndoGroup();
    return true;
}

/**
 * 创建圆形路径
 */
function createCirclePath(cx, cy, radius) {
    var pathPoints = [];
    var pathInTangents = [];
    var pathOutTangents = [];
    var numPoints = 8;

    for (var i = 0; i < numPoints; i++) {
        var angle = (i / numPoints) * Math.PI * 2;
        var x = cx + Math.cos(angle) * radius;
        var y = cy + Math.sin(angle) * radius;
        pathPoints.push([x, y]);

        var tangentLength = radius * 0.4142; // tan(22.5°) * radius
        var inX = -Math.cos(angle - Math.PI / 2) * tangentLength;
        var inY = -Math.sin(angle - Math.PI / 2) * tangentLength;
        pathInTangents.push([inX, inY]);

        var outX = Math.cos(angle + Math.PI / 2) * tangentLength;
        var outY = Math.sin(angle + Math.PI / 2) * tangentLength;
        pathOutTangents.push([outX, outY]);
    }

    return {
        vertices: pathPoints,
        inTangents: pathInTangents,
        outTangents: pathOutTangents,
        closed: true
    };
}

/**
 * 创建直线路径
 */
function createLinePath(cx, cy, length) {
    return {
        vertices: [[cx - length / 2, cy], [cx + length / 2, cy]],
        inTangents: [[0, 0], [0, 0]],
        outTangents: [[0, 0], [0, 0]],
        closed: false
    };
}

/**
 * 创建波浪路径
 */
function createWavePath(cx, cy, length, amplitude, frequency) {
    var pathPoints = [];
    var pathInTangents = [];
    var pathOutTangents = [];
    var numPoints = 20;

    for (var i = 0; i <= numPoints; i++) {
        var t = i / numPoints;
        var x = cx - length / 2 + t * length;
        var y = cy + Math.sin(t * Math.PI * 2 * frequency) * amplitude;
        pathPoints.push([x, y]);
        pathInTangents.push([0, 0]);
        pathOutTangents.push([0, 0]);
    }

    return {
        vertices: pathPoints,
        inTangents: pathInTangents,
        outTangents: pathOutTangents,
        closed: false
    };
}

/**
 * 创建螺旋路径
 */
function createSpiralPath(cx, cy, maxRadius) {
    var pathPoints = [];
    var pathInTangents = [];
    var pathOutTangents = [];
    var numPoints = 50;
    var turns = 3;

    for (var i = 0; i <= numPoints; i++) {
        var t = i / numPoints;
        var angle = t * Math.PI * 2 * turns;
        var radius = maxRadius * t;
        var x = cx + Math.cos(angle) * radius;
        var y = cy + Math.sin(angle) * radius;
        pathPoints.push([x, y]);
        pathInTangents.push([0, 0]);
        pathOutTangents.push([0, 0]);
    }

    return {
        vertices: pathPoints,
        inTangents: pathInTangents,
        outTangents: pathOutTangents,
        closed: false
    };
}

/**
 * 创建贝塞尔曲线路径
 */
function createBezierPath(cx, cy) {
    var pathPoints = [
        [cx - 300, cy + 100],
        [cx - 100, cy - 200],
        [cx + 100, cy + 200],
        [cx + 300, cy - 100]
    ];
    var pathInTangents = [[0, 0], [50, -50], [-50, 50], [0, 0]];
    var pathOutTangents = [[-50, 50], [50, -50], [50, -50], [0, 0]];

    return {
        vertices: pathPoints,
        inTangents: pathInTangents,
        outTangents: pathOutTangents,
        closed: false
    };
}
```

```jsx
function add3DLight(comp, lightType, position, config) {

        color: [1, 1, 1],
        falloff: 0,

    };

    for (var key in config) {
        defaultConfig[key] = config[key];
    }
    config = defaultConfig;

    var light = comp.layers.addLight(lightType, position);
    light.lightType = lightType;

    var lightOptions = light.property("ADBE Light Options");
    lightOptions.property("ADBE Light Intensity").setValue(config.intensity);
    lightOptions.property("ADBE Light Color").setValue(config.color);
    lightOptions.property("ADBE Light Falloff").setValue(config.falloff);
    lightOptions.property("ADBE Light Falloff Distance").setValue(config.falloffDistance);
    lightOptions.property("ADBE Light Casts Shadows").setValue(config.castShadows ? 1 : 0);
    lightOptions.property("ADBE Light Shadow Darkness").setValue(config.shadowDarkness);
    lightOptions.property("ADBE Light Shadow Diffusion").setValue(config.shadowDiffusion);

    return light;
}
```

## 十四、文字遮罩与Track Matte

### 14.1 文字作为遮罩使用

在AE中，文字图层可以作为遮罩（Track Matte）使用，将上方图层的Alpha或亮度信息作为下方图层的显示区域。这种技术常用于：
- 文字内部显示视频或图片
- 文字揭示效果
- 文字过渡动画
- 创意合成效果

### 14.2 Track Matte类型详解

| 类型 | 英文名 | 说明 | 使用场景 |
|------|--------|------|---------|
| Alpha Matte | Alpha遮罩 | 使用上方图层的Alpha通道 | 文字内显示视频 |
| Alpha Inverted Matte | Alpha反转遮罩 | 反转Alpha通道 | 文字外显示内容 |
| Luma Matte | 亮度遮罩 | 使用上方图层的亮度 | 亮度渐变揭示 |
| Luma Inverted Matte | 亮度反转遮罩 | 反转亮度通道 | 暗部区域显示 |
| No Track Matte | 无遮罩 | 关闭遮罩 | 默认状态 |

### 14.3 遮罩文字效果实现

**遮罩文字效果（文字内部显示视频/图片）**：
1. 创建文字图层（上方）
2. 创建视频/图片图层（下方）
3. 将下方图层的Track Matte设置为Alpha Matte
4. 文字内部的区域将显示下方视频/图片

### 14.4 遮罩动画效果

遮罩动画可以通过以下方式实现：
- 动画文字图层的位置、缩放、旋转
- 动画文字的透明度
- 使用Text Animator控制文字逐字揭示
- 配合Mask Path动画

### 14.5 文字与遮罩组合技巧

1. **多层遮罩叠加**：使用多个文字图层创建复杂的遮罩效果
2. **遮罩与混合模式**：结合混合模式增强效果
3. **遮罩与预合成**：预合成后使用遮罩实现更复杂的效果
4. **遮罩与效果**：在遮罩图层上添加效果（如模糊、发光）

### 14.6 遮罩文字JSX实现代码

```jsx
/**
 * 遮罩文字动画通用函数
 * 功能：创建文字遮罩效果
 * 参数：文字内容、遮罩类型、动画类型
 */
function createTextMatteEffect(comp, text, contentLayer, config) {
    config = config || {};
    var defaultConfig = {
        matteType: "Alpha Matte",   // 遮罩类型
        fontSize: 120,
        fontName: "Arial Black",
        fillColor: [1, 1, 1, 1],
        position: null,
        animationType: "scale",     // 动画类型: scale/position/opacity/rotate
        duration: 2.0,
        matteAnimation: true,       // 是否动画遮罩
        preserveTextLayer: true,    // 是否保留文字图层
        textLayerOpacity: 0         // 文字图层透明度
    };

    for (var key in config) {
        defaultConfig[key] = config[key];
    }
    config = defaultConfig;

    app.beginUndoGroup("遮罩文字效果");

    // 创建文字图层
    var textLayer = comp.layers.addText(text);
    var textDoc = textLayer.property("ADBE Text Properties").property("ADBE Text Document").value;
    textDoc.fontSize = config.fontSize;
    textDoc.fillColor = config.fillColor;
    textDoc.font = config.fontName;
    textLayer.property("ADBE Text Properties").property("ADBE Text Document").setValue(textDoc);

    // 设置位置
    if (config.position) {
        textLayer.property("ADBE Transform Group").property("ADBE Position").setValue(config.position);
    } else {
        textLayer.property("ADBE Transform Group").property("ADBE Position").setValue([comp.width/2, comp.height/2]);
    }

    // 确保文字图层在内容图层上方
    textLayer.moveBefore(contentLayer);

    // 设置Track Matte
    var matteIndex = 0;
    switch (config.matteType) {
        case "Alpha Matte": matteIndex = 1; break;
        case "Alpha Inverted Matte": matteIndex = 2; break;
        case "Luma Matte": matteIndex = 3; break;
        case "Luma Inverted Matte": matteIndex = 4; break;
        default: matteIndex = 1;
    }

    // 动画遮罩
    if (config.matteAnimation) {
        var startTime = comp.time;
        var transformGroup = textLayer.property("ADBE Transform Group");

        switch (config.animationType) {
            case "scale":
                var scaleProp = transformGroup.property("ADBE Scale");
                scaleProp.setValueAtTime(startTime, [0, 0]);
                scaleProp.setValueAtTime(startTime + config.duration, [100, 100]);
                for (var i = 1; i <= scaleProp.numKeys; i++) {
                    scaleProp.setTemporalEaseAtKey(i, [new KeyframeEase(0.3, 80)], [new KeyframeEase(0.3, 80)]);
                }
                break;

            case "position":
                var posProp = transformGroup.property("ADBE Position");
                var startY = -config.fontSize;
                var endY = comp.height / 2;
                posProp.setValueAtTime(startTime, [comp.width/2, startY]);
                posProp.setValueAtTime(startTime + config.duration, [comp.width/2, endY]);
                for (var j = 1; j <= posProp.numKeys; j++) {
                    posProp.setTemporalEaseAtKey(j, [new KeyframeEase(0, 50)], [new KeyframeEase(0, 50)]);
                }
                break;

            case "opacity":
                var opacityProp = transformGroup.property("ADBE Opacity");
                opacityProp.setValueAtTime(startTime, 0);
                opacityProp.setValueAtTime(startTime + config.duration, 100);
                break;

            case "rotate":
                var rotProp = transformGroup.property("ADBE Rotate Z");
                rotProp.setValueAtTime(startTime, -180);
                rotProp.setValueAtTime(startTime + config.duration, 0);
                for (var k = 1; k <= rotProp.numKeys; k++) {
                    rotProp.setTemporalEaseAtKey(k, [new KeyframeEase(0.3, 70)], [new KeyframeEase(0.3, 70)]);
                }
                break;
        }
    }

    // 设置文字图层透明度（如果需要保留文字图层）
    if (!config.preserveTextLayer) {
        textLayer.property("ADBE Transform Group").property("ADBE Opacity").setValue(config.textLayerOpacity);
    }

    app.endUndoGroup();
    return { textLayer: textLayer, contentLayer: contentLayer };
}
```

## 十五、文字粒子系统

### 15.1 粒子文字效果概述

粒子文字效果是AE中最具视觉冲击力的文字动画类型，通过将文字转换为粒子或从粒子汇聚成文字，实现梦幻、科幻的视觉效果。主要使用Trapcode Particular和Trapcode Form两个插件实现。

### 15.2 Particular文字粒子效果

**Particular插件关键参数**：

| 参数组 | 参数 | 说明 | 推荐值 |
|--------|------|------|--------|
| Emitter | Emitter Type | 发射器类型 | Layer/Grid/Box |
| Emitter | Layer | 发射图层 | 文字预合成 |
| Emitter | Particles/sec | 每秒粒子数 | 100-5000 |
| Emitter | Size X/Y/Z | 发射器尺寸 | 根据文字大小 |
| Particle | Life | 粒子生命 | 2-5秒 |
| Particle | Size | 粒子大小 | 2-10 |
| Particle | Color | 粒子颜色 | 文字颜色 |
| Physics | Gravity | 重力 | 0（无重力） |
| Physics | Wind | 风力 | 根据效果调整 |

### 15.3 Form文字变形效果

**Form插件关键参数**：

| 参数组 | 参数 | 说明 | 推荐值 |
|--------|------|------|--------|
| Base Form | Size X/Y/Z | 基础形状尺寸 | 合成尺寸 |
| Base Form | Particles in X/Y/Z | 粒子数量 | 50-200 |
| Particle | Size | 粒子大小 | 2-5 |
| Layer Maps | Layer to Displace | 位移图层 | 文字图层 |
| Layer Maps | Functionality | 功能模式 | Displace |
| Disperse & Twist | Disperse | 分散度 | 0-200 |
| Shading | Ambient | 环境光 | 0-100 |

### 15.4 粒子汇聚成文字JSX实现

```jsx
/**
 * 粒子汇聚成文字效果
 * 功能：使用Particular实现粒子汇聚成文字
 */
function createParticleConverge(comp, text, config) {
    config = config || {};
    var defaultConfig = {
        fontSize: 120,
        fontName: "Arial Black",
        particlesPerSec: 2000,
        particleLife: 3.0,
        particleSize: 3,
        particleColor: [1, 1, 1],
        convergenceTime: 2.0,
        holdTime: 2.0,
        dissipateTime: 1.5,
        addGlow: true,
        glowRadius: 15,
        glowIntensity: 0.5
    };

    for (var key in config) {
        defaultConfig[key] = config[key];
    }
    config = defaultConfig;

    app.beginUndoGroup("粒子汇聚成文字");

    // 创建文字预合成
    var textLayer = comp.layers.addText(text);
    var textDoc = textLayer.property("ADBE Text Properties").property("ADBE Text Document").value;
    textDoc.fontSize = config.fontSize;
    textDoc.fillColor = [1, 1, 1, 1];
    textDoc.font = config.fontName;
    textLayer.property("ADBE Text Properties").property("ADBE Text Document").setValue(textDoc);
    textLayer.property("ADBE Transform Group").property("ADBE Position").setValue([comp.width/2, comp.height/2]);

    // 预合成文字
    var textComp = comp.layers.precompose([textLayer.index], "文字粒子源", false);

    // 创建粒子图层
    var particleLayer = comp.layers.addSolid(config.particleColor, "粒子层", comp.width, comp.height, 1);
    particleLayer.property("ADBE Transform Group").property("ADBE Position").setValue([comp.width/2, comp.height/2]);

    // 添加Particular效果
    var particular = particleLayer.property("ADBE Effect Parade").addProperty("ADBE Particular");
    
    // 设置发射器
    particular.property("ADBE Particular Emitter").property("ADBE Particular Emitter Type").setValue(6); // Layer
    particular.property("ADBE Particular Emitter").property("ADBE Particular Layer").setValue(textComp.index);
    particular.property("ADBE Particular Emitter").property("ADBE Particular Emitter Size X").setValue(config.fontSize * 2);
    particular.property("ADBE Particular Emitter").property("ADBE Particular Emitter Size Y").setValue(config.fontSize);
    particular.property("ADBE Particular Emitter").property("ADBE Particular Particles/sec").setValue(config.particlesPerSec);

    // 设置粒子
    particular.property("ADBE Particular Particle").property("ADBE Particular Life").setValue(config.particleLife);
    particular.property("ADBE Particular Particle").property("ADBE Particular Size").setValue(config.particleSize);
    particular.property("ADBE Particular Particle").property("ADBE Particular Color").setValue(config.particleColor);

    // 设置物理
    particular.property("ADBE Particular Physics").property("ADBE Particular Gravity").setValue(0);

    // 动画汇聚和消散
    var startTime = comp.time;
    var particularProp = particular.property("ADBE Particular Emitter").property("ADBE Particular Particles/sec");

    // 汇聚阶段
    particularProp.setValueAtTime(startTime, config.particlesPerSec);
    particularProp.setValueAtTime(startTime + config.convergenceTime, config.particlesPerSec);
    
    // 保持阶段
    particularProp.setValueAtTime(startTime + config.convergenceTime + config.holdTime, config.particlesPerSec);
    
    // 消散阶段
    particularProp.setValueAtTime(startTime + config.convergenceTime + config.holdTime + 0.1, 0);

    // 添加发光
    if (config.addGlow) {
        var glow = particleLayer.property("ADBE Effect Parade").addProperty("ADBE Glo2");
        glow.property("ADBE Glo2-0001").setValue(config.glowRadius);
        glow.property("ADBE Glo2-0002").setValue(0.5);
        glow.property("ADBE Glo2-0004").setValue(config.glowIntensity);
    }

    app.endUndoGroup();
    return particleLayer;
}
```

## 十六、文字发光与光效

### 16.1 Glow发光效果参数详解

Glow（发光）是文字光效中最基础也是最常用的效果，AE内置的Glow效果可以实现各种发光风格。

**Glow效果完整参数表**：

| 参数 | 英文名 | 说明 | 取值范围 | 推荐值 |
|------|--------|------|---------|--------|
| 发光阈值 | Glow Threshold | 发光起始亮度阈值 | 0-100% | 50% |
| 发光半径 | Glow Radius | 发光扩散半径 | 0-1000 | 20-50 |
| 发光强度 | Glow Intensity | 发光亮度 | 0-100 | 1-3 |
| 发光颜色 | Glow Colors | 发光颜色类型 | Original/AB/A&B/Gradient | Original |
| 色彩相位 | Color Phase | 颜色相位 | 0-360 | 0 |
| A色 | Color A | 起始色 | RGB | - |
| B色 | Color B | 结束色 | RGB | - |
| 发光维度 | Glow Dimensions | 发光方向 | Horizontal/Vertical/All | All |
| 混合模式 | Blend Mode | 混合模式 | Add/Screen/Normal | Add |

### 16.2 霓虹灯效果实现

霓虹灯效果通过多层发光叠加和颜色设置实现，模拟真实霓虹灯管的光感。

**霓虹灯效果参数**：
- 外发光：Glow Radius=30, Glow Intensity=2
- 内发光：Glow Radius=10, Glow Intensity=3
- 描边：Stroke Width=2
- 颜色：通常使用青色、粉色、紫色等鲜艳颜色

### 16.3 光晕效果实现

光晕效果通过CC Light Rays或CC Light Burst实现，模拟从文字发出的光芒。

### 16.4 能量光束效果（Saber）

Video Copilot Saber插件可以创建能量光束、光剑等效果。

**Saber关键参数**：

| 参数 | 说明 | 推荐值 |
|------|------|--------|
| Preset Type | 预设类型 | Energy/Electric/Neon |
| Core Color | 核心颜色 | 白色 |
| Glow Color | 发光颜色 | 蓝色/红色 |
| Core Thickness | 核心厚度 | 2-5 |
| Glow Intensity | 发光强度 | 50-100 |
| Glow Spread | 发光扩散 | 30-60 |

### 16.5 金属光泽效果

金属光泽通过CC Glass和Gradient Ramp组合实现。

### 16.6 玻璃质感效果

玻璃质感通过CC Glass效果配合透明度调整实现。

### 16.7 全息投影效果

全息投影通过多层效果叠加实现：扫描线+发光+噪点+颜色偏移。

### 16.8 光效文字JSX通用函数

```jsx
/**
 * 光效文字通用函数
 * 功能：为文字添加各种光效
 */
function applyTextGlowEffect(textLayer, effectType, config) {
    config = config || {};
    var defaultConfig = {
        glowThreshold: 50,
        glowRadius: 30,
        glowIntensity: 2,
        glowColor: [0, 1, 1],
        glowColors: "Original",
        blendMode: "Add",
        coreThickness: 3,
        coreColor: [1, 1, 1],
        glowSpread: 40
    };

    for (var key in config) {
        defaultConfig[key] = config[key];
    }
    config = defaultConfig;

    var effects = textLayer.property("ADBE Effect Parade");

    switch (effectType) {
        case "neon":
            // 霓虹灯效果
            var glow1 = effects.addProperty("ADBE Glo2");
            glow1.name = "外发光";
            glow1.property("ADBE Glo2-0001").setValue(config.glowRadius);
            glow1.property("ADBE Glo2-0002").setValue(0.5);
            glow1.property("ADBE Glo2-0003").setValue(config.glowIntensity);
            glow1.property("ADBE Glo2-0005").setValue(3); // A&B Colors
            glow1.property("ADBE Glo2-0007").setValue(config.glowColor);
            glow1.property("ADBE Glo2-0008").setValue([config.glowColor[0], config.glowColor[1], config.glowColor[2]]);
            glow1.property("ADBE Glo2-0009").setValue(1); // Add

            var glow2 = effects.addProperty("ADBE Glo2");
            glow2.name = "内发光";
            glow2.property("ADBE Glo2-0001").setValue(10);
            glow2.property("ADBE Glo2-0002").setValue(0.5);
            glow2.property("ADBE Glo2-0003").setValue(config.glowIntensity * 1.5);
            glow2.property("ADBE Glo2-0009").setValue(1);
            break;

        case "hologram":
            // 全息投影效果
            var glowH = effects.addProperty("ADBE Glo2");
            glowH.property("ADBE Glo2-0001").setValue(25);
            glowH.property("ADBE Glo2-0003").setValue(1.5);
            glowH.property("ADBE Glo2-0009").setValue(1);

            // 扫描线
            var grid = effects.addProperty("ADBE Grid");
            grid.property("ADBE Grid-0002").setValue(3);
            grid.property("ADBE Grid-0003").setValue(1);

            // 噪点
            var noise = effects.addProperty("ADBE Noise");
            noise.property("ADBE Noise-0001").setValue(5);

            // 颜色偏移
            var shift = effects.addProperty("ADBE Offset");
            shift.property("ADBE Offset-0001").setValue([2, 0]);
            break;

        case "metal":
            // 金属光泽
            var glass = effects.addProperty("ADBE CC Glass");
            glass.property("ADBE CC Glass-0001").setValue(5);
            glass.property("ADBE CC Glass-0002").setValue(10);
            glass.property("ADBE CC Glass-0004").setValue(50);

            var ramp = effects.addProperty("ADBE Ramp");
            ramp.property("ADBE Ramp Start Color").setValue([1, 0.84, 0]);
            ramp.property("ADBE Ramp End Color").setValue([0.5, 0.3, 0]);
            break;

        case "glass":
            // 玻璃质感
            var glassEffect = effects.addProperty("ADBE CC Glass");
            glassEffect.property("ADBE CC Glass-0001").setValue(3);
            glassEffect.property("ADBE CC Glass-0002").setValue(8);
            glassEffect.property("ADBE CC Glass-0004").setValue(30);

            var glassGlow = effects.addProperty("ADBE Glo2");
            glassGlow.property("ADBE Glo2-0001").setValue(15);
            glassGlow.property("ADBE Glo2-0003").setValue(0.8);
            break;

        case "energyBeam":
            // 能量光束
            var saber = effects.addProperty("ADBE VC Saber");
            saber.property("ADBE VC Saber Preset Type").setValue(0);
            saber.property("ADBE VC Saber Core Thickness").setValue(config.coreThickness);
            saber.property("ADBE VC Saber Glow Intensity").setValue(80);
            saber.property("ADBE VC Saber Glow Spread").setValue(config.glowSpread);
            saber.property("ADBE VC Saber Core Color").setValue(config.coreColor);
            saber.property("ADBE VC Saber Glow Color").setValue(config.glowColor);
            break;
    }

    return textLayer;
}
```

## 十七、文字故障效果大全

### 17.1 信号故障效果概述

文字故障（Glitch）效果是模拟信号干扰、数据损坏等视觉效果的风格化文字动画，常用于赛博朋克、科技感、数字损坏等场景。

### 17.2 故障效果参数表

| 故障类型 | 主要效果 | 关键参数 | 推荐插件/效果 |
|---------|---------|---------|-------------|
| RGB分离 | 红绿蓝通道偏移 | 偏移距离 | Displacement Map/Shift Channels |
| 位移故障 | 文字片段随机位移 | 位移幅度、频率 | Displacement Map |
| 像素化 | 马赛克效果 | 像素大小 | Mosaic |
| 扫描线 | 水平线条干扰 | 线条间距 | Grid/Venetian Blinds |
| 色彩偏移 | 通道颜色分离 | 偏移量 | Shift Channels |
| 数据损坏 | 随机数据块 | 块大小、密度 | Custom/Expression |
| 抖动 | 位置随机抖动 | 幅度、频率 | Expression |
| 波形扭曲 | 波形变形 | 频率、幅度 | Wave Warp |

### 17.3 RGB分离故障效果JSX实现

```jsx
/**
 * RGB分离故障效果
 * 功能：创建RGB通道分离的故障文字效果
 */
function createRGBGlitch(textLayer, config) {
    config = config || {};
    var defaultConfig = {
        offsetAmount: 10,          // 偏移量
        glitchFrequency: 5,        // 故障频率
        glitchIntensity: 80,       // 故障强度
        randomGlitch: true,        // 随机故障
        scanlineOpacity: 30        // 扫描线透明度
    };

    for (var key in config) {
        defaultConfig[key] = config[key];
    }
    config = defaultConfig;

    var effects = textLayer.property("ADBE Effect Parade");

    // RGB通道分离
    var shiftR = effects.addProperty("ADBE Shift Channels");
    shiftR.name = "红色通道偏移";
    shiftR.property("ADBE Shift Channels-0001").setValue(0); // Take Red from Red

    var offset = effects.addProperty("ADBE Offset");
    offset.name = "RGB偏移";
    offset.property("ADBE Offset-0001").expression =
        "var freq = " + config.glitchFrequency + ";\n" +
        "var amp = " + config.offsetAmount + ";\n" +
        "var noise = noise(time * freq) * amp;\n" +
        "[noise, 0]";

    // 波形扭曲
    var waveWarp = effects.addProperty("ADBE Wave Warp");
    waveWarp.name = "波形扭曲";
    waveWarp.property("ADBE Wave Warp-0001").setValue(0); // 水平
    waveWarp.property("ADBE Wave Warp-0002").expression = "5 + noise(time * 3) * 10";
    waveWarp.property("ADBE Wave Warp-0003").expression = "1 + noise(time * 2) * 3";
    waveWarp.property("ADBE Wave Warp-0004").setValue(0);

    // 扫描线
    var grid = effects.addProperty("ADBE Grid");
    grid.name = "扫描线";
    grid.property("ADBE Grid-0002").setValue(2);
    grid.property("ADBE Grid-0003").setValue(1);
    grid.property("ADBE Grid-0005").setValue(0);
    grid.property("ADBE Grid-0007").setValue(config.scanlineOpacity / 100);

    // 噪点
    var noise2 = effects.addProperty("ADBE Noise");
    noise2.name = "噪点";
    noise2.property("ADBE Noise-0001").expression = "5 + noise(time * 10) * 15";

    return textLayer;
}
```

### 19.7 MCP 端自动化预设系统概述

19.1~19.6 小节介绍的预设系统侧重于 AE 端手动创建、管理与批量应用，调用链需要人工运行 JSX 脚本文件。本小节起的 19.7~19.13 将介绍与之配套的 MCP 端自动化预设系统，该系统通过 MCP 网关直接执行 JSX 字符串，无需在 AE 端手动运行脚本，适合智能体驱动的批量剪辑流水线。

**核心机制**：

MCP 网关通过 `executeAtomScript` 命令直接执行 JSX 字符串实现预设调用。预设模板以 IIFE（立即调用函数表达式）形式包装，内部显式 `return JSON.stringify(_r)` 返回结构化结果，AE 端执行完成后将 JSON 回传给 MCP 调用方。

**完整数据源**：

- 完整 60 预设数据源位于 `c:\Users\Administrator\Desktop\AE-Knowledge-Vault\config\text_animation_presets.json`，其中包含每个预设的 `id`、`name`、`parameters`、`jsx_template` 等字段
- 完整参数表 + JSX 实现代码位于 `c:\Users\Administrator\Desktop\AE-Knowledge-Vault\10-风格化剪辑知识库\文字动画预设库-MCP自动化版.md`，覆盖 4 大品类各 15 个预设

**占位符语法**：

`{{param_name}}` 由 MCP 网关运行时替换为实际参数值。例如 `{{textLayerName}}` 在调用时被替换为目标文字图层名，`{{fallHeight}}` 被替换为下落高度数值。

**调用示例（JSON-RPC 格式）**：

```json
{
  "command": "executeAtomScript",
  "params": {
    "scriptContent": "<IIFE JSX with placeholders replaced>"
  }
}
```

**期望响应**：

```json
{"status":"success","preset":"kt_char_waterfall","layer":"标题文字"}
```

调用失败时返回 `{"status":"error","message":"<错误描述>"}`，MCP 网关可根据 `status` 字段判断执行结果并决定重试或回退策略。

**步骤 2：用实际参数值替换 `{{param_name}}` 占位符**

根据预设的 `parameters` 定义，将 `jsx_template` 中的 `{{param_name}}` 占位符替换为实际值。替换规则按参数类型区分：

- 字符串类型（`type:"string"`）：用单引号包裹，如 `{{textLayerName}}` → `'标题文字'`
- 数字类型（`type:"number"`）：直接写入原始值，如 `{{fallHeight}}` → `200`、`{{duration}}` → `1.5`
- 颜色数组类型（`type:"color"`）：以 `[r,g,b]` 浮点格式写入（0-1 范围），如 `{{neonColor}}` → `[1,0,1]`
- 枚举类型（`type:"string"` 带 `options`）：按字符串规则用单引号包裹，如 `{{direction}}` → `'left'`

替换伪代码：

```javascript
var params = {
  textLayerName: '标题文字',
  fallHeight: 200,
  charDelay: 3,
  duration: 1.5
};
var filledJsx = jsxTemplate;
for (var key in params) {
  var placeholder = '{{' + key + '}}';
  var value = params[key];
  var replacement;
  if (typeof value === 'string') {
    replacement = "'" + value + "'";  // 字符串用单引号
  } else if (Array.isArray(value)) {
    replacement = '[' + value.join(',') + ']';  // 颜色数组
  } else {
    replacement = String(value);  // 数字直接写入
  }
  filledJsx = filledJsx.split(placeholder).join(replacement);
}
```

```jsx
(function textSlideIn() {
```
