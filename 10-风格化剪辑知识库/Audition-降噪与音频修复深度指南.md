# Audition 降噪与音频修复深度指南

> 版本: 2025-v1 | 适用: 专业降噪/音频修复/播客后期

## 一、降噪技术体系

### 1.1 降噪方法分类

| 方法 | 原理 | 适用场景 | 质量 |
|------|------|---------|------|
| 采样降噪 | 噪声样本建模 | 恒定底噪 | 高 |
| 自适应降噪 | 实时噪声分析 | 变化噪声 | 中-高 |
| 频谱修复 | 频率级操作 | 特定频率干扰 | 极高 |
| AI降噪 | 深度学习分离 | 复杂环境 | 最高 |
| 门限降噪 | 低于阈值静音 | 间歇噪声 | 低 |

### 1.2 采样降噪详解

```
标准流程:
1. 选取纯噪声段(0.5-2秒)
2. 效果→降噪/恢复→降噪(处理)
3. 点击"捕捉噪声样本"
4. 全选音频(Ctrl+A)
5. 调整参数:
   - 降噪: 60-80%
   - 降噪量: 6-12dB
   - 平滑: 2-3
6. 预览(播放按钮)
7. 应用

注意事项:
- 过度降噪会产生"水下感"
- 先保守处理,不够再叠加
- 保留一些环境声更自然
```

### 1.3 自适应降噪

| 参数 | 作用 | 建议 |
|------|------|------|
| 降噪量 | 降噪强度 | 5-15dB |
| 降噪幅度 | 处理比例 | 60-90% |
| 频率平滑 | 频率域平滑 | 2-5 |
| 时间平滑 | 时间域平滑 | 2-4 |

### 1.4 频谱修复

```
频谱编辑器(Shift+D):
1. 切换到频谱视图
2. 用套索工具选择干扰区域
3. 可以:
   - 删除特定频率
   - 用周围频谱填充
   - 降低特定频段增益

适用场景:
- 手机铃声
- 警笛声
- 反馈啸叫
- 咳嗽/喷嚏
- 椅子吱嘎声
```

## 二、去混响

### 2.1 减少混响效果器

| 参数 | 范围 | 建议 |
|------|------|------|
| 混响减少 | 0-100% | 30-60% |
| 去噪 | 0-100% | 10-20% |
| 仅输出混响 | 开/关 | 调试用 |
| 详细调整 | 开/关 | 精细控制 |

### 2.2 去混响最佳实践

```
1. 先降噪,再去混响(顺序重要)
2. 混响减少不要超过60%(否则失真)
3. 配合EQ减少房间共振频率
4. 使用门限控制尾音
5. 如果混响严重,考虑AI增强工具
```

## 三、人声增强

### 3.1 人声处理链

```
完整人声处理链:
1. 降噪(采样法) → 去底噪
2. 去混响 → 减少空间感
3. 消除嗡嗡声 → 去电源干扰
4. 参数EQ → 
   - 高通80Hz(去隆隆声)
   - 衰减200-400Hz(去浑浊)
   - 提升3-5kHz(增加清晰度)
   - 衰减8-10kHz(去齿音)
5. 压缩 → 
   - 比率3:1
   - 阈值-18dB
   - 启动10ms
   - 释放100ms
6. 去齿音 → 7kHz, 阈值调整
7. 限制器 → -1dB天花板
8. 响度标准化 → -16 LUFS
```

### 3.2 人声增强效果器

| 效果器 | 参数 | 效果 |
|--------|------|------|
| 人声增强 | 强度/频率 | 增加临场感 |
| 谐波激励 | 频率/量 | 增加空气感 |
| 立体声扩展 | 宽度 | 增加空间感 |
| 齿音消除 | 频率/阈值 | 减少刺耳声 |

## 四、音频修复实战

### 4.1 常见音频问题修复

| 问题 | 工具 | 方法 |
|------|------|------|
| 底噪/嘶嘶声 | 采样降噪 | 捕捉噪声样本 |
| 嗡嗡声(50/60Hz) | 消除嗡嗡声 | 自动检测 |
| 咔嗒声 | 自动咔嗒声移除 | 自动检测移除 |
| 爆音 | 自动咔嗒声移除 | 高灵敏度 |
| 削波失真 | 消除削波 | 重建峰值 |
| 混响过重 | 减少混响 | 30-60% |
| 音量不均 | 硬限制+压缩 | 统一动态 |
| 齿音 | 去齿音 | 5-10kHz |

### 4.2 削波失真修复

```
1. 效果→降噪/恢复→消除削波
2. 参数:
   - 削波修复量: 50-80%
   - 残余削波: 0-20%
3. 预览检查
4. 如果严重,可能需要:
   - 动态处理修复
   - 或AI修复工具
```

## 五、播客后期处理

### 5.1 播客处理模板

```
标准播客后期:
1. 导入所有录音
2. 匹配响度(-16 LUFS)
3. 降噪(采样法)
4. EQ: 高通80Hz + 3kHz增强2dB
5. 压缩: 3:1, -18dB阈值
6. 去齿音: 7kHz
7. 删除静音段(自动标记)
8. 添加片头片尾音乐
9. BGM闪避: -6dB(对话时)
10. 导出: MP3 192kbps
```

### 5.2 多嘉宾处理

```
多嘉宾混音:
1. 每个嘉宾独立轨道
2. 分别降噪+EQ+压缩
3. 统一响度(-16 LUFS)
4. 添加闪避BGM
5. 总线上加限制器(-1dB)
6. 导出单轨混合版
7. 导出多轨分轨版(备份)
```
