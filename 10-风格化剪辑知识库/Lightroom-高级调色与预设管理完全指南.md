# Lightroom 高级调色与预设管理完全指南

> 版本: 2025-v1 | 适用: 高级调色/预设管理/批量处理

## 一、高级调色

### 1.1 颜色分级

| 功能 | 说明 | 用途 |
|------|------|------|
| 阴影/中间调/高光 | 分区调色 | 电影感色调 |
| 色轮 | 直观调色 | 色彩平衡 |
| 色相/饱和度/明度 | 精细调整 | 特定颜色 |
| 校准 | 原色调整 | 风格化 |

### 1.2 HSL精细调整

```
HSL调整技巧:
1. 色相(Hue): 改变颜色
   - 蓝色→青色(电影感)
   - 绿色→黄色(复古)
   - 红色→橙色(肤色)

2. 饱和度(Saturation): 调整鲜艳度
   - 整体降低(胶片感)
   - 特定颜色增强(强调)

3. 明度(Luminance): 调整亮度
   - 蓝色降低(天空更深)
   - 绿色提升(植物更亮)
   - 黄色提升(肤色更亮)
```

### 1.3 颜色分级轮

```
电影感调色:
┌─────────────────────────────────┐
│  阴影(Shadows)                  │
│  色相: 210°(青蓝)               │
│  饱和度: 15-25%                 │
├─────────────────────────────────┤
│  中间调(Midtones)               │
│  色相: 30°(橙黄)                │
│  饱和度: 5-10%                  │
├─────────────────────────────────┤
│  高光(Highlights)               │
│  色相: 45°(暖黄)                │
│  饱和度: 10-15%                 │
└─────────────────────────────────┘

效果: 青橙色调(Teal & Orange)
```

## 二、预设管理

### 2.1 创建预设

```
创建预设:
1. 调整一张照片
2. 左侧预设面板→+
3. 创建预设
4. 选择要包含的设置:
   - 基本色调
   - 色调曲线
   - HSL
   - 颜色分级
   - 效果
   - 校准
5. 命名并保存

预设组织:
- 按风格分类(电影/复古/胶片)
- 按场景分类(风景/人像/夜景)
- 按季节分类(春/夏/秋/冬)
```

### 2.2 预设类型

| 类型 | 特点 | 用途 |
|------|------|------|
| 电影感 | 青橙色调/低饱和 | 视频截图风格 |
| 胶片模拟 | 颗粒/褪色 | 复古风格 |
| 黑白 | 高对比/颗粒 | 经典风格 |
| 清新 | 高饱和/明亮 | 日系风格 |
| 暗调 | 低曝光/高对比 | 情绪风格 |
| 复古 | 褪色/暖色调 | 怀旧风格 |

### 2.3 预设导出导入

```
导出预设:
1. 文件→导出预设
2. 选择预设组
3. 保存为.zip文件
4. 分享给他人

导入预设:
1. 文件→导入预设
2. 选择.zip文件
3. 自动安装
4. 在预设面板中使用
```

## 三、批量处理

### 3.1 同步设置

```
同步设置:
1. 调整一张照片
2. 选中多张照片
3. 点击"同步"
4. 选择要同步的设置:
   - 基本色调
   - 曲线
   - HSL
   - 颜色分级
   - 裁剪
5. 同步

应用场景:
- 同一场景多张照片统一调色
- 批量应用预设
- 快速处理大量素材
```

### 3.2 自动同步

```
自动同步:
1. 开启自动同步
2. 调整一张照片
3. 后续导入自动应用相同设置

应用场景:
- 连续拍摄统一风格
- 快速处理同场景素材
```

## 四、智能收藏

### 4.1 智能收藏集

```
创建智能收藏集:
1. 库模块→+→创建智能收藏集
2. 设置条件:
   - 评级 ≥ 4星
   - AND 标签 = 风景
   - AND 日期 = 2024
3. 自动更新
4. 保存

应用场景:
- 自动收集精选作品
- 按项目自动分类
- 按日期归档
```
