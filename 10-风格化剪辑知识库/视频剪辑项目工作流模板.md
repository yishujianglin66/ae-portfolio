# 视频剪辑项目工作流模板

> [!abstract] 文档摘要
> 本文档提供视频剪辑项目的标准化目录结构、命名规范和工作流程模板。所有生产项目（素材、工程、渲染输出）与知识库（AE-Knowledge-Vault）完全分离，确保知识库纯净不被污染。

> [!tip] 使用指南
> - 新建项目时，复制本模板的目录结构到你的工作目录（如 `D:\AE-Work\`）
> - 严格遵循命名规范，便于后期检索和团队协作
> - 知识库（AE-Knowledge-Vault）只放文档和代码，不放任何生产文件

---

## 二、命名规范

### 2.1 项目命名

```
格式：YYYY-MM-DD-项目名称

示例：
  2026-07-05-618产品宣传片
  2026-07-10-漫剪卡点视频
  2026-07-15-品牌发布会开场
```

### 2.2 工程文件命名

```
格式：项目名_版本号.扩展名

示例：
  产品宣传片_v1.aep
  产品宣传片_v2.aep
  产品宣传片_最终版.aep
  产品宣传片_客户确认版.aep
```

> [!important] 重要
> 每次大改之前，**另存为新版本**，不要直接覆盖。版本号递增（v1 → v2 → v3），不要用"新建文件夹_副本"这种混乱命名。

### 2.3 渲染输出命名

```
格式：项目名_版本_分辨率_编码.扩展名

示例：
  产品宣传片_v1_1080p_H264.mp4
  产品宣传片_最终版_4K_H265.mp4
  产品宣传片_竖版_1080x1920.mp4
  卡点视频_抖音版_1080x1920.mp4
```

### 2.4 素材命名

```
格式：类型_描述_编号

示例：
  video_城市航拍_01.mp4
  img_产品特写_03.png
  audio_BGM_电子_01.wav
  sfx_转场_嗖.mp3
```

## 三、工作流程（8步法）

### 阶段1：前期准备

```
┌─────────────────────────────────────────┐
│  1. 需求沟通 → 2. 资料收集 → 3. 方案策划  │
└─────────────────────────────────────────┘
```

1. **需求沟通**：明确目标受众、时长、风格、交付时间
2. **资料收集**：收集参考视频、品牌素材、文案脚本
3. **方案策划**：写脚本、画分镜、确定风格参考

> 产出物放在 `01-策划/`

### 阶段2：素材准备

```
┌─────────────────────────────────────────┐
│  4. 素材整理 → 5. 粗剪初排               │
└─────────────────────────────────────────┘
```

4. **素材整理**：所有素材导入 `02-素材/`，分类命名
5. **粗剪初排**：在 PR 中粗剪，确定节奏和结构

> 产出物：粗剪工程 + 粗剪视频，放在 `04-渲染输出/草稿/`

### 阶段3：精剪包装

```
┌─────────────────────────────────────────┐
│  6. 精剪调整 → 7. 特效包装 → 8. 调色输出  │
└─────────────────────────────────────────┘
```

6. **精剪调整**：节奏调整、转场设计、字幕制作
7. **特效包装**：AE 特效、MG动画、粒子效果
8. **调色输出**：统一色调、混音、导出各版本

> 最终版放在 `04-渲染输出/最终版/`

## 四、AE 工程组织规范

### 4.1 合成命名

```
格式：[类型]_描述_分辨率

示例：
  [Main]_主合成_1920x1080
  [Pre]_文字动画_1920x1080
  [Pre]_粒子效果_1920x1080
  [Ref]_参考素材_1920x1080
```

### 4.2 图层命名与分组

```
图层前缀规范：
  [ADJ] 调整层
  [FX]  效果层
  [TXT] 文字层
  [IMG] 图片层
  [VID] 视频层
  [SHP] 形状层
  [NUL] 空对象
  [CAM] 摄像机
  [LGT] 灯光

分组（颜色标签）：
  红色 - 主要合成
  橙色 - 文字元素
  黄色 - 效果元素
  绿色 - 素材
  蓝色 - 调整/控制
  紫色 - 预合成
```

### 4.3 插件清单

每个 AE 工程目录下必须有 `插件列表.md`，记录用到的所有第三方插件：

```markdown
# 插件列表

## 必装插件
- [x] Trapcode Particular
- [x] Optical Flares
- [x] Saber
- [x] Deep Glow

## 可选插件
- [ ] Boris Continuum
- [ ] Sapphire
```

## 五、快速开始模板

### 5.1 新建项目清单

新建一个项目时，按这个 checklist 走：

- [ ] 创建项目目录（按 `YYYY-MM-DD-项目名` 命名）
- [ ] 创建子目录（01-策划 到 99-归档）
- [ ] 填写 `01-策划/需求文档.md`
- [ ] 收集素材放入 `02-素材/`
- [ ] 创建 AE 工程，保存到 `03-工程/AE/`
- [ ] 设置合成命名和图层颜色规范
- [ ] 记录插件列表到 `03-工程/插件列表.md`

### 5.2 交付检查清单

交付前逐项检查：

- [ ] 视频时长符合要求
- [ ] 分辨率和帧率正确
- [ ] 音画同步
- [ ] 无黑边/白边
- [ ] 字幕无错别字
- [ ] 调色风格统一
- [ ] 音频无爆音
- [ ] 文件名符合规范
- [ ] 工程文件已备份
- [ ] 素材已归档

## 六、知识库与工作目录的关系

```
┌─────────────────────────────────────────────────┐
│           AE-Knowledge-Vault（知识库）            │
│  纯文档 + 代码，不包含任何生产文件                  │
│  ✓ 知识文档     ✓ 编译器代码     ✓ MCP扩展       │
└────────────────────┬────────────────────────────┘
                     │
                     │ 参考 / 调用
                     ▼
┌─────────────────────────────────────────────────┐
│                AE-Work（工作目录）                │
│  所有生产文件都在这里，与知识库完全隔离             │
│  ✓ 素材         ✓ 工程文件       ✓ 渲染输出       │
└─────────────────────────────────────────────────┘
```

> [!note] 为什么要分开？
> 1. **知识库纯净**：知识库是长期积累的知识资产，项目文件是临时的
> 2. **Obsidian 流畅**：视频文件会让 Obsidian 索引变慢
> 3. **备份高效**：知识库单独备份（小），项目文件按需备份（大）
> 4. **版本控制**：知识库可以用 Git 管理，视频不行
> 5. **协作方便**：知识库可分享给团队，项目文件独立
