## 1. AE Puppet Tool 完全解析

### 1.1 Puppet Tool 系统架构

Adobe After Effects 的 Puppet Tool 系统基于 **三角网格变形（Triangular Mesh Deformation）** 算法，通过在图层上放置控制点（Pins）来驱动网格顶点的位移，从而实现 2D 图像的有机变形。

#### 1.1.1 底层算法原理

Puppet Tool 采用 **As-Rigid-As-Possible (ARAP) 表面变形** 算法的 2D 变体，核心数学模型为：

```
目标函数 E = Σ (i,j) ∈ N || vi' - vj' - Ri(vi - vj) ||²
```

其中：
- `vi, vj` 为原始网格顶点位置
- `vi', vj'` 为变形后顶点位置
- `Ri` 为局部旋转矩阵（2×2）
- `N` 为相邻顶点对集合
- 最小化 E 保证局部形状刚性

**算法时间复杂度**：O(n·log n)，n 为网格三角形数量

#### 1.1.2 三种钉子工具的功能分工

| 工具名称 | 英文名称 | 快捷键 | 核心功能 | 作用域 |
|---------|---------|-------|---------|-------|
| 变形钉 | Puppet Pin Tool | Ctrl+P | 放置控制钉，定义变形控制点 | 驱动变形 |
| 硬化钉 | Puppet Starch Tool | 无 | 增加局部刚性，防止不自然拉伸 | 约束变形 |
| 重叠钉 | Puppet Overlap Tool | 无 | 定义图层前后重叠关系 | 深度排序 |

### 1.2 Puppet Pin Tool（变形钉）深度解析

#### 1.2.1 变形钉参数体系

每个变形钉（Puppet Pin）在时间轴上的完整参数结构：

```
Puppet Pin 1
├── Position (位置)
│   ├── X 轴坐标 (像素)
│   └── Y 轴坐标 (像素)
├── Rotation (旋转) - AE 2023+ 新增
│   └── 角度 (度)
└── Mesh Deformation (网格变形)
    └── 影响权重分布
```

**精确参数范围**：
- **Position.X / Position.Y**：-30000.00 ~ 30000.00 像素（精确到 0.01 像素）
- **Rotation**：-36000.00° ~ 36000.00°（精确到 0.01°）
- **影响半径**：由网格密度和钉间距自动计算，通常 20.00 ~ 500.00 像素

#### 1.2.2 变形钉权重分布模型

变形钉对周围网格顶点的影响遵循 **高斯衰减（Gaussian Falloff）** 模型：

```
w(d) = exp(-d² / (2σ²))
```

其中：
- `d` 为顶点到钉的距离（像素）
- `σ` 为标准差，由 Expansion 参数控制
- `w(d)` 为权重值，范围 [0, 1]

**多钉混合公式**（线性混合蒙皮 LBS）：
```
v' = Σ (wi * Ti * v) / Σ wi
```
其中 `Ti` 为第 i 个钉的变换矩阵（平移+旋转）

#### 1.2.3 变形钉放置最佳实践

**黄金放置原则**：
1. **关节点放置**：在角色关节处（肩、肘、腕、髋、膝、踝）各放置 1 个钉
2. **锚点放置**：在角色重心或固定点放置 1-2 个钉作为锚
3. **密度控制**：钉间距不应小于 15.00 像素，否则会产生网格撕裂
4. **边缘避免**：钉距离图层边缘不应小于 10.00 像素

**人体标准钉位配置**（17 钉方案）：
```
头部组：头顶(1)、下颌(1) → 2钉
躯干组：左肩(1)、右肩(1)、胸骨(1)、肚脐(1)、左髋(1)、右髋(1) → 6钉
左臂组：左上臂(1)、左肘(1)、左腕(1) → 3钉
右臂组：右上臂(1)、右肘(1)、右腕(1) → 3钉
左腿组：左膝(1)、左踝(1) → 2钉
右腿组：右膝(1)、右踝(1) → 2钉
合计：17钉
```

### 1.3 Puppet Starch Tool（硬化钉）深度解析

#### 1.3.1 硬化钉作用原理

硬化钉通过修改局部区域的 **刚度矩阵（Stiffness Matrix）** 来抵抗变形，其数学表达为：

```
E_starch = E_deformation + λ · E_stiffness
```

其中：
- `λ` 为硬化系数，由硬化钉强度决定
- `E_stiffness` 为刚性能量项，惩罚局部形状变化

#### 1.3.2 硬化钉参数

**精确参数表**：

| 参数名称 | 数值范围 | 步长 | 默认值 | 物理意义 |
|---------|---------|------|-------|---------|
| Amount (强度) | 0.00 ~ 100.00 | 0.10 | 50.00 | 硬化程度百分比 |
| Radius (半径) | 1.00 ~ 1000.00 | 1.00 | 50.00 像素 | 影响范围 |
| Feather (羽化) | 0.00 ~ 100.00 | 0.50 | 20.00% | 边缘柔化程度 |

**强度值与等效弹性模量对照表**：

| Amount | 等效弹性模量 (相对) | 变形衰减比 | 适用场景 |
|--------|-------------------|-----------|---------|
| 10.00 | 1.2× | 83% | 轻微硬化，保持柔韧性 |
| 25.00 | 1.8× | 56% | 半刚性关节 |
| 50.00 | 3.0× | 33% | 默认值，一般刚性部位 |
| 75.00 | 5.5× | 18% | 较硬的骨骼区域 |
| 90.00 | 10.0× | 10% | 接近刚性的部位 |
| 100.00 | 25.0× | 4% | 完全刚性，几乎不变形 |

#### 1.3.3 硬化钉应用场景

**必须使用硬化钉的场景**：
1. **关节反向弯曲**：肘部、膝盖内侧放置硬化钉，防止反向弯折
2. **刚性骨骼**：头骨、胸骨、骨盆区域放置多个硬化钉
3. **道具手持**：角色手握的道具周围放置硬化钉，防止道具变形
4. **文字变形**：文字做木偶动画时，在笔画交叉处放置硬化钉

### 1.4 Puppet Overlap Tool（重叠钉）深度解析

#### 1.4.1 重叠钉作用原理

重叠钉通过为网格顶点分配 **深度值（Z-order）** 来决定重叠时的前后关系，解决 2D 变形中的 **交叉穿透** 问题。

**深度排序算法**：
```
深度值 = 基础深度 + 重叠钉贡献值
贡献值 = InFront × Amount × (1 - d/R)   （d < R 时）
```

其中：
- `InFront`：方向系数，前部为 +1，后部为 -1
- `Amount`：重叠钉强度
- `d`：顶点到钉的距离
- `R`：重叠钉影响半径

#### 1.4.2 重叠钉参数

| 参数名称 | 数值范围 | 步长 | 默认值 | 说明 |
|---------|---------|------|-------|------|
| In Front (在前) | 布尔 | - | 启用 | 勾选=在前，不勾=在后 |
| Amount (强度) | 0.00 ~ 100.00 | 0.50 | 100.00 | 深度偏移量 |
| Radius (半径) | 5.00 ~ 500.00 | 1.00 | 30.00 像素 | 影响范围 |

#### 1.4.3 重叠钉配置方案

**标准角色重叠钉配置**（8 钉方案）：
```
前部组（In Front = true）：
├── 左前臂重叠钉（Amount=80, Radius=40）
├── 右前臂重叠钉（Amount=80, Radius=40）
├── 左小腿重叠钉（Amount=70, Radius=35）
└── 右小腿重叠钉（Amount=70, Radius=35）

后部组（In Front = false）：
├── 左上臂后重叠钉（Amount=60, Radius=35）
├── 右上臂后重叠钉（Amount=60, Radius=35）
├── 左大腿后重叠钉（Amount=50, Radius=30）
└── 右大腿后重叠钉（Amount=50, Radius=30）
```

## 2. 木偶动画参数体系

### 2.1 Mesh Triangles（网格密度）参数深度解析

#### 2.1.1 网格生成原理

Puppet 网格使用 **Delaunay 三角剖分（Delaunay Triangulation）** 算法生成，具有以下特性：
- 最大化最小角，避免"瘦"三角形
- 空外接圆性质，优化变形质量
- 时间复杂度：O(n·log n)，n 为轮廓点数量

#### 2.1.2 Triangle 参数精确控制

**参数定义**：
- **Triangle count**：三角形数量，范围 10 ~ 10000（可手动调整）
- 间接参数：通过 Expansion 和 Mesh Quality 控制

**精确数值对照表**：

| 图层尺寸 | Expansion=10 | Expansion=20 | Expansion=30 | Expansion=50 |
|---------|-------------|-------------|-------------|-------------|
| 1920×1080 | ~320 个 | ~580 个 | ~890 个 | ~1520 个 |
| 1280×720 | ~180 个 | ~340 个 | ~520 个 | ~910 个 |
| 720×480 | ~90 个 | ~170 个 | ~260 个 | ~460 个 |
| 400×400 | ~55 个 | ~100 个 | ~155 个 | ~275 个 |

**三角形数量计算公式（经验公式）**：
```
N ≈ 0.00008 × W × H × (1 + E/25)
```
其中：
- `N`：预估三角形数量
- `W × H`：图层像素面积
- `E`：Expansion 值（像素）

#### 2.1.3 网格密度与变形质量关系

**变形精度评估模型**：
```
变形误差 ε = C / √N
```
其中 `C` 为形状复杂度系数，`N` 为三角形数量

| 三角形数量 | 变形精度等级 | 适用场景 | 单帧计算时间 |
|-----------|------------|---------|-------------|
| < 50 | 低精度 | 快速预览、草图阶段 | < 2ms |
| 50 ~ 200 | 中精度 | 一般动画、远镜头 | 2 ~ 8ms |
| 200 ~ 500 | 高精度 | 近景角色、常规制作 | 8 ~ 25ms |
| 500 ~ 1000 | 超高清 | 特写镜头、高品质输出 | 25 ~ 60ms |
| > 1000 | 电影级 | 4K 特写、电影项目 | 60 ~ 200ms |

### 2.2 Expansion（扩展）参数深度解析

#### 2.2.1 Expansion 的物理意义

Expansion 参数控制网格向外扩展的像素距离，决定了变形影响范围超出图层 alpha 边界的程度。

**数学定义**：
```
网格外边界 = alpha 轮廓 + Expansion × 法线方向
```

#### 2.2.2 Expansion 精确参数表

| Expansion 值 | 扩展距离 (像素) | 适用场景 | 注意事项 |
|-------------|----------------|---------|---------|
| 0.00 | 0 | 精确贴合轮廓 | 边缘变形可能出现锯齿 |
| 5.00 | 5 | 紧凑图形、文字 | 轻微边缘柔化 |
| 10.00 | 10 | 默认值，大多数情况 | 平衡选择 |
| 20.00 | 20 | 有机角色、弹性变形 | 边缘有缓冲空间 |
| 30.00 | 30 | 大幅变形、拉伸动画 | 网格面积增加约 30% |
| 50.00 | 50 | 极端变形、流体效果 | 网格面积增加约 60% |
| 100.00 | 100 | 特殊效果、烟雾变形 | 性能开销显著增加 |

#### 2.2.3 Expansion 对性能的影响

**性能模型**：
```
计算时间 T ∝ (1 + E/25)²
内存占用 M ∝ (1 + E/25)²
```

其中 `E` 为 Expansion 值。

| Expansion | 相对计算时间 | 相对内存占用 | 相对三角形数 |

| 10 | 1.00× | 1.00× | 1.00× |

### 2.4 Rotation 关键帧曲线体系（AE 2023+）

#### 2.4.1 Puppet Pin Rotation 参数

AE 2023 及以后版本新增了 Puppet Pin Rotation 属性，允许直接控制每个钉的旋转角度，而不仅仅是位置。

**参数规格**：
- **属性路径**：效果 → Puppet → Mesh → Deform → Puppet Pin x → Rotation
- **单位**：度 (°)
- **范围**：-36000.00° ~ 36000.00°
- **精确到**：0.01°

#### 2.4.2 旋转与位置的协同关系

**正向运动学 FK 下的旋转-位置关系**：
```
Px = L × cos(θ) + Px_parent
Py = L × sin(θ) + Py_parent
```

其中：
- `Px, Py`：子钉位置
- `Px_parent, Py_parent`：父钉位置
- `L`：骨长（两钉间距）
- `θ`：骨骼旋转角度

**旋转权重混合公式**：
```
θ_final = θ_pin × w_rot + θ_pos_based × (1 - w_rot)
```
其中 `w_rot` 为旋转属性权重（默认 1.0，即完全使用 Rotation 属性）

#### 3.1.3 Duik 表达式核心代码

**两骨 IK 求解器（解析法）**：
```javascript
// 两骨 IK 解析 - Duik 简化版
function solveIK(a, b, c, l1, l2, pole) {
    // a: 肩部位置, b: 目标位置, c: 当前肘部位置
    // l1: 上臂长, l2: 下臂长, pole: 极向量方向
    
    var d = length(a, b);  // 肩到目标的距离
    var maxLen = l1 + l2;
    var minLen = Math.abs(l1 - l2);
    
    // Soft IK 处理
    var softIK = effect("Puppet Pin 1")("Soft IK") / 100;
    if (d > maxLen && softIK > 0) {
        var over = d - maxLen;
        var softDist = maxLen * softIK * 0.5;
        var ratio = over < softDist ? 1 - Math.pow(1 - over/softDist, 2) : 1;
        d = maxLen + over * (1 - ratio);
    }
    
    // 距离钳制
    d = Math.max(minLen, Math.min(maxLen, d));
    
    // 余弦定理求角度
    var cosAngle = (l1*l1 + d*d - l2*l2) / (2 * l1 * d);
    cosAngle = Math.max(-1, Math.min(1, cosAngle));
    var angle1 = Math.acos(cosAngle);
    
    // 基线角度
    var baseAngle = Math.atan2(b[1] - a[1], b[0] - a[0]);
    
    // 极向量方向判定
    var poleAngle = Math.atan2(pole[1] - a[1], pole[0] - a[0]);
    var side = (poleAngle - baseAngle + Math.PI * 4) % (Math.PI * 2) < Math.PI ? 1 : -1;
    
    // 肘部位置
    var elbowAngle = baseAngle + angle1 * side;
    var elbow = [a[0] + l1 * Math.cos(elbowAngle), 
                 a[1] + l1 * Math.sin(elbowAngle)];
    
    return { elbow: elbow, angle: elbowAngle };
```

**欠阻尼振动方程**（RubberHose 弹性核心）：

- `φ`：初始相位

**RubberHose 参数映射关系**：
```
Bounce = A × 100 （归一化到 0-100）
Damping = ζ × 100 （百分比）
Frequency = ωn / (2π) （Hz）
```

**Verlet 积分算法**（Motion Scripts 动力学核心）：
```javascript
// Verlet 积分 - 动力学骨骼核心
function verletUpdate(points, constraints, dt, gravity, damping) {
    // points: [{pos, prevPos, pinned}]
    // constraints: [{a, b, length}]
    // dt: 时间步长
    
    // 更新位置 (Verlet 积分)
    for (var i = 0; i < points.length; i++) {
        if (points[i].pinned) continue;
        
        var vel = points[i].pos - points[i].prevPos;
        vel *= (1 - damping);
        
        var newPos = points[i].pos + vel;
        newPos[1] += gravity * dt * dt;
        
        points[i].prevPos = points[i].pos;
        points[i].pos = newPos;
    }
    
    // 约束求解 (多次迭代)
    for (var iter = 0; iter < iterations; iter++) {
        for (var c = 0; c < constraints.length; c++) {
            var con = constraints[c];
            var a = points[con.a];
            var b = points[con.b];
            
            var delta = b.pos - a.pos;
            var dist = length(delta);
            var diff = (dist - con.length) / dist;
            
            if (dist < 0.001) continue;
            
            var offset = delta * 0.5 * diff;
            if (!a.pinned) a.pos += offset;
            if (!b.pinned) b.pos -= offset;
        }
    }
}
```

## 4. 效果参数逆向工程

### 4.1 帧差分析法

#### 4.1.1 帧差分析原理

帧差分析通过比较相邻帧之间的像素差异来推断动画参数，是木偶动画逆向工程的基础方法。

**基础帧差公式**：
```
D(x,y,t) = |I(x,y,t) - I(x,y,t-1)|
```

其中：
- `I(x,y,t)`：t 时刻 (x,y) 处的像素值
- `D(x,y,t)`：t 时刻的帧差图

#### 4.1.2 帧差后处理流水线

**完整处理流程**：
```
原始视频 → 灰度化 → 高斯模糊 → 帧差计算 → 二值化 → 
形态学开运算 → 连通域分析 → 运动区域提取 → 参数拟合
```

**每步精确参数**：

| 步骤 | 算法/参数 | 数值 | 说明 |
|-----|----------|------|------|
| 灰度化 | 加权灰度 | R×0.299 + G×0.587 + B×0.114 | 标准亮度转换 |
| 高斯模糊 | 核大小 | 5×5 | 降噪 |
| 高斯模糊 | σ | 1.50 像素 | 模糊强度 |
| 二值化 | 阈值 | 15.00 / 255 | 差异判定阈值 |
| 形态学开运算 | 核大小 | 3×3 | 去除噪点 |
| 形态学开运算 | 迭代次数 | 2 次 | 强化效果 |
| 连通域分析 | 最小面积 | 50 像素 | 过滤小噪点 |

#### 4.1.3 运动矢量场计算

**Lucas-Kanade 光流法**（稀疏光流）：
```
I_x · u + I_y · v = -I_t
```

其中：
- `I_x, I_y`：空间梯度（x、y 方向）
- `I_t`：时间梯度（帧差）
- `u, v`：x、y 方向的运动速度

**稠密光流 - Farneback 算法参数**：

### 4.2 轮廓追踪法

#### 4.2.1 主动轮廓模型（Snake）

Snake 模型通过能量最小化来追踪物体轮廓，适用于木偶动画中角色轮廓的提取。

**能量函数**：
```
E_snake = α · E_cont + β · E_curv + γ · E_img
```

其中：
- `E_cont`：连续性能量（控制轮廓长度）
- `E_curv`：曲率能量（控制平滑度）
- `E_img`：图像能量（吸引到边缘）
- `α, β, γ`：权重系数

**标准参数值**：
- α = 0.10（连续性权重）
- β = 0.50（曲率权重）
- γ = 1.00（图像能量权重）

#### 4.2.2 轮廓特征点提取

**曲率极值点检测**：
```
κ(s) = (x'(s)y''(s) - y'(s)x''(s)) / (x'(s)² + y'(s)²)^(3/2)
```

其中 `κ(s)` 为轮廓在弧长 s 处的曲率。

**关节点推断规则**：
1. 曲率局部极大值 → 可能是关节点或骨骼端点
2. 曲率极大值间距 30-200 像素 → 可能是一段骨骼
3. 曲率方向周期性变化 → 可能是运动中的关节

```javascript
// Douglas-Peucker 曲线简化
function douglasPeucker(points, epsilon) {
    if (points.length < 3) return points;
    
    // 找到距离最远的点
    var maxDist = 0;
    var maxIndex = 0;
    
    var start = points[0];
    var end = points[points.length - 1];
    
    for (var i = 1; i < points.length - 1; i++) {
        var d = pointLineDistance(points[i], start, end);
        if (d > maxDist) {
            maxDist = d;
            maxIndex = i;
        }
    }
    
    // 递归简化
    if (maxDist > epsilon) {
        var left = douglasPeucker(points.slice(0, maxIndex + 1), epsilon);
        var right = douglasPeucker(points.slice(maxIndex), epsilon);
        return left.slice(0, -1).concat(right);
    } else {
        return [start, end];
    }
}
```

**epsilon 参数参考值**：
- 高精度保留：0.50 像素

#### 5.4.2 机械关节表达式

```javascript
// 机械关节梯形速度曲线
function trapezoidalMotion(t, T, accelRatio) {
    // t: 当前时间, T: 总时长, accelRatio: 加减速比例
    var t_norm = t / T;
    var a = accelRatio;
    
    if (t_norm < a) {
        // 加速段
        return 0.5 * t_norm * t_norm / a;
    } else if (t_norm > 1 - a) {
        // 减速段
        var t_dec = t_norm - (1 - a);
        return 1 - 0.5 * t_dec * t_dec / a;
    } else {
        // 匀速段
        return t_norm - a / 2;
    }
}

// 机械回差（反向间隙）
function backlash(value, lastValue, gap) {
    var diff = value - lastValue;
    if (Math.abs(diff) < gap) {
        return lastValue;  // 死区，不跟随
    } else {
        return value - Math.sign(diff) * gap;
    }
}
```
