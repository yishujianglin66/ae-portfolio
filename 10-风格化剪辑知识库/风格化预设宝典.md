## 一、AE 预设系统基础

### 1.1 预设类型分类

#### 1.1.1 动画预设（.ffx）
动画预设是 After Effects 中最常用的预设类型，以 `.ffx` 格式存储，可保存图层属性的关键帧动画、表达式、效果参数及其动画曲线。

| 属性 | 说明 |
|------|------|
| 文件格式 | `.ffx`（XML 二进制封装） |
| 存储内容 | 关键帧、表达式、效果参数、图层属性 |
| 应用范围 | 单图层或多图层属性 |
| 跨版本兼容 | AE CS6 及以上版本通用 |
| 文件大小 | 通常 2KB - 200KB |

#### 1.1.2 效果预设
效果预设保存的是特效插件参数组合，应用于图层后直接生效。

| 属性 | 说明 |
|------|------|
| 存储内容 | 单个或多个效果的参数配置 |
| 应用方式 | 拖拽至图层或效果面板 |
| 兼容性 | 依赖原效果插件是否已安装 |
| 典型场景 | 调色 LUT、模糊组合、光效组合 |

#### 1.1.3 文字预设
专用于文字图层的动画预设，包含文字动画器（Animator）、范围选择器（Range Selector）等配置。

| 属性 | 说明 |
|------|------|
| 存储内容 | 文字动画器、表达式选择器、关键帧 |
| 应用对象 | 仅限 Text 图层 |
| 典型场景 | 打字机、弹跳入场、抖动、循环偏移 |

#### 1.1.4 形状预设
针对 Shape 图层的路径、描边、填充、路径动画等配置。

| 属性 | 说明 |
|------|------|
| 存储内容 | Path、Stroke、Fill、Trim Paths、Repeater |
| 应用对象 | Shape 图层或 Shape 组 |
| 典型场景 | 路径绘制、形状变形、重复阵列 |

#### 1.1.5 颜色预设
保存调色相关参数组合，包括 Lumetri、Curves、HSL、三色调等。

| 属性 | 说明 |
|------|------|
| 存储内容 | 调色效果参数、LUT 引用、表达式联动 |
| 应用对象 | 调整图层或素材图层 |
| 典型场景 | 电影感、日系、赛博朋克、复古调色 |

#### 1.1.6 表达式预设
以表达式为核心的预设，通过表达式实现动态效果，便于跨项目复用。

| 属性 | 说明 |
|------|------|
| 存储内容 | 表达式字符串、关联属性 |
| 应用对象 | 任意支持表达式的属性 |
| 典型场景 | 抖动、循环、弹性、跟随、时间偏移 |

### 1.2 预设的保存与加载

#### 保存流程
1. 选中包含目标动画/效果的图层
2. 菜单：`Animation → Save Animation Preset`（动画预设）
3. 或在效果面板右键效果 → `Save Preset`（效果预设）
4. 命名（建议使用英文+版本号，如 `LightSweep_v02.ffx`）
5. 选择保存路径（默认 `User Presets` 目录）

#### 加载流程
- **方式一**：拖拽 `.ffx` 文件至 `Effects & Presets` 面板
- **方式二**：右键 `Effects & Presets` 面板 → `Import Preset`
- **方式三**：将 `.ffx` 复制到 `User Presets` 目录后重启 AE
- **方式四**：通过脚本 `app.applyPreset(File)` 程序化应用

### 1.3 预设的批量管理

| 操作 | 方法 |
|------|------|
| 批量导入 | 将多个 `.ffx` 文件复制到 User Presets 目录 |
| 批量应用 | 使用 JSX 脚本遍历图层调用 `applyPreset()` |
| 分类管理 | 在 User Presets 下建立子文件夹分类存放 |
| 搜索定位 | Effects & Presets 面板顶部搜索框输入关键词 |
| 收藏标记 | 右键预设 → `Add to Favorites` |

### 1.4 预设的跨项目使用

- **跨项目**：预设独立于项目存在，保存在 `.ffx` 文件中，任何项目都可调用
- **跨版本**：AE CS6+ 版本基本兼容；新版特性在旧版中可能丢失
- **跨平台**：Windows 与 macOS 路径不同，但 `.ffx` 文件本身通用
- **跨软件**：部分预设可在 Premiere Pro 中使用（动画预设需为属性动画）

### 1.5 预设文件路径

| 平台 | 默认 User Presets 路径 |
|------|------------------------|
| Windows | `C:\Users\<用户名>\AppData\Roaming\Adobe\After Effects\<版本>\User Presets` |
| macOS | `~/Library/Application Support/Adobe/After Effects/<版本>/User Presets/` |
| 系统预设 | `Adobe After Effects\Support Files\Presets`（只读） |

> 提示：可在脚本中通过 `app.preferences.getFolderUserData()` 获取用户数据目录。

## 十、预设制作教程

### 10.1 动画预设制作流程

#### 10.1.1 准备工作
1. **新建合成**：创建测试合成（建议 1920×1080，30fps，10 秒）
2. **创建图层**：新建文字/形状/固态层作为载体
3. **规划动画**：明确动画的起始、过程、结束三阶段

#### 10.1.2 制作关键帧动画
1. **选择属性**：展开图层属性，定位到目标属性（Position、Scale、Opacity 等）
2. **设置起始关键帧**：移动时间指示器到起始位置，点击秒表图标
3. **设置终止关键帧**：移动时间指示器到终止位置，修改属性值
4. **调整缓动曲线**：选中关键帧 → `Animation → Keyframe Assistant → Easy Ease`（F9）
5. **精细化曲线**：在图表编辑器（Graph Editor）中调整贝塞尔手柄

#### 10.1.3 添加表达式（可选）
1. **Alt+点击秒表**：打开表达式输入框
2. **编写表达式**：如 `wiggle(5, 20)` 实现抖动
3. **关联控制**：使用拾取器关联到其他属性

#### 10.1.4 保存为预设
1. **选中属性**：在时间轴面板选中所有要保存的属性
2. **保存预设**：`Animation → Save Animation Preset`
3. **命名规范**：使用 `类别_效果名_版本.ffx` 格式，如 `Transition_LightSweep_v01.ffx`
4. **选择路径**：保存到 `User Presets` 下对应分类文件夹

#### 10.1.5 测试与优化
1. **应用测试**：新建图层应用预设，验证效果
2. **参数检查**：检查所有属性是否正确应用
3. **跨版本测试**：在不同 AE 版本中测试兼容性
4. **优化文件**：删除不必要的属性，减小文件体积

### 10.2 效果预设制作流程

#### 10.2.1 添加效果
1. **选择图层**：选中目标图层
2. **添加效果**：`Effect → 对应分类 → 具体效果`
3. **添加多个效果**：按顺序添加组合效果

#### 10.2.2 调整参数
1. **打开效果控件**：双击效果或打开 `Effect Controls` 面板
2. **设置参数**：调整每个效果的参数到目标值
3. **添加关键帧**：对需要动画的参数添加关键帧

#### 10.2.3 保存效果预设
1. **选中效果**：在效果控件面板选中所有效果
2. **保存预设**：`Animation → Save Animation Preset` 或右键 → `Save Preset`
3. **命名保存**：使用规范命名保存到对应分类

### 10.3 表达式预设制作

#### 10.3.1 常用表达式模板

**抖动表达式**：
```javascript
// 频率 5Hz，幅度 20
wiggle(5, 20);
```

**循环表达式**：
```javascript
// 无缝循环
loopOut("cycle");
// 往返循环
loopOut("pingpong");
```

**弹性表达式**：
```javascript
// 弹性超调
amp = 0.1;
freq = 2.0;
decay = 4.0;
n = 0;
if (numKeys > 0) {
    n = nearestKey(time).index;
    if (key(n).time > time) n--;
}
if (n > 0) {
    t = time - key(n).time;
    v = velocityAtTime(key(n).time - thisComp.frameDuration/10);
    value + v * amp * Math.sin(freq * t * 2 * Math.PI) / Math.exp(decay * t);
} else {
    value;
}
```

**跟随表达式**：
```javascript
// 延迟 5 帧跟随前一图层
thisComp.layer(index - 1).position.valueAtTime(time - 5 * thisComp.frameDuration);
```

**时间偏移**：
```javascript
// 偏移 2 秒
valueAtTime(time - 2);
```

#### 10.3.2 表达式控制
使用表达式控制效果（Expression Controls）作为预设的可调参数：

| 控制类型 | 用途 | 示例 |
|----------|------|------|
| 滑块控制 | 数值参数 | 频率、幅度 |

```javascript
// 批量应用预设到选中图层
(function batchApplyPreset() {
    var comp = app.project.activeItem;
    if (!comp || !(comp instanceof CompItem)) {
        alert("请先打开合成");
        return;
    }
    
    var selectedLayers = comp.selectedLayers;
    if (selectedLayers.length === 0) {
        alert("请选择图层");
        return;
    }
    
    var presetFile = File.openDialog("选择预设文件", "*.ffx", false);
    if (!presetFile) return;
    
    app.beginUndoGroup("批量应用预设");
    
    for (var i = 0; i < selectedLayers.length; i++) {
        var layer = selectedLayers[i];
        layer.selected = true;
        // 取消其他图层选择
        for (var j = 0; j < selectedLayers.length; j++) {
            if (j !== i) selectedLayers[j].selected = false;
        }
        layer.applyPreset(presetFile);
    }
    
    // 恢复选择
    for (var k = 0; k < selectedLayers.length; k++) {
        selectedLayers[k].selected = true;
    }
    
    app.endUndoGroup();
    alert("已应用预设到 " + selectedLayers.length + " 个图层");
})();
```
