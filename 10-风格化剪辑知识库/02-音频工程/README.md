# 音频工程知识库

## 📚 概述

本目录包含音频工程的核心理论、节拍分析、音乐动力学和音画同步技术。

## 📖 核心主题

### 1. 音频基础理论
- 采样率与位深度
- 频谱分析
- 动态范围处理
- 相位与立体声

### 2. 节拍与节奏
- BPM 检测算法
- Onset 检测技术
- 节拍对齐方法
- 节奏模式识别

### 3. 音乐动力学
- RMS 与响度分析
- 动态压缩技术
- 峰值控制
- 音乐情绪识别

### 4. 音画同步
- 音视频时间轴对齐
- 卡点剪辑技术
- 音乐驱动运镜
- 音效触发机制

### 5. 实际应用
- AMV 节拍分析案例
- 电影预告片配乐
- MV 音乐可视化
- 游戏音效设计
