# Premiere Pro Lumetri调色完全指南

> 版本: 2025-v1 | 适用: PR调色/电影感/风格化

## 一、Lumetri Color 面板

### 1.1 六大调色模块

| 模块 | 功能 | 常用工具 |
|------|------|---------|
| 基本校正 | 曝光/白平衡/色调 | 曝光/对比度/高光/阴影 |
| 创意 | 风格化调色 | 褪色胶片/锐化/模糊 |
| 曲线 | 精确色调控制 | RGB曲线/Hue Sat曲线 |
| 色轮 | 分离色调 | 阴影/中间调/高光色轮 |
| HSL辅助 | 按颜色选择调整 | 限定器+调色 |
| 晕影 | 暗角效果 | 数量/中点/圆度 |

### 1.2 基本校正参数

| 参数 | 范围 | 作用 |
|------|------|------|
| 曝光度 | -5~+5 | 整体亮度 |
| 对比度 | -100~+100 | 明暗差异 |
| 高光 | -100~+100 | 亮部细节 |
| 阴影 | -100~+100 | 暗部细节 |
| 白色 | -100~+100 | 白场 |
| 黑色 | -100~+100 | 黑场 |
| 饱和度 | -100~+100 | 整体色彩浓度 |
| 自然饱和度 | -100~+100 | 保护已饱和色 |

### 1.3 创意模块

| 参数 | 效果 | 电影感常用值 |
|------|------|-------------|
| 褪色胶片 | 降低对比度/褪色 | 10-25 |
| 锐化 | 边缘锐化 | 10-30 |
| 模糊 | 高斯模糊 | 0(调色时关闭) |
| 暗角 | 四周暗化 | 10-30 |
| 阴影色调 | 阴影着色 | 偏青/蓝 |
| 平衡 | 暖/冷偏移 | -10~+10 |

## 二、调色工作流

### 2.1 标准调色流程

```
1. 素材校正(一级)
   → 白平衡/曝光/对比度
   → 确保素材基础一致

2. 风格化(二级)
   → 创意调色/LUT
   → 建立整体风格

3. 局部调整(三级)
   → HSL辅助/遮罩
   → 肤色/天空单独调整

4. 最终检查
   → 示波器验证
   → 多设备预览
```

### 2.2 LUT 应用

| LUT类型 | 用途 | 强度建议 |
|---------|------|---------|
| 技术LUT | Log→Rec.709转换 | 100% |
| 创意LUT | 风格化调色 | 50-80% |
| 显示LUT | 监看参考 | 100% |
| 打印LUT | 打印预览 | 100% |

### 2.3 调整图层调色

```
推荐调色架构:
V3: [调整图层] 最终效果(颗粒/暗角)
V2: [调整图层] 风格化(创意调色/LUT)
V1: [调整图层] 一级校正(曝光/白平衡)
V0: 视频素材
```

## 三、示波器与质量监控

### 3.1 示波器类型

| 示波器 | 显示 | 用途 |
|--------|------|------|
| 波形(Waveform) | 亮度分布 | 曝光/动态范围 |
| 矢量(YUV) | 色彩相位 | 饱和度/色相 |
| RGB叠加 | 三通道波形 | 白平衡/色偏 |
| 直方图 | 像素分布 | 整体曝光 |
| 分量 | YUV分量 | 亮度/色度分离 |

### 3.2 示波器读数标准

| 指标 | 标准值 | 说明 |
|------|--------|------|
| 黑场 | 0-16 IRE (SD) / 0 (数字) | 不应低于0 |
| 白场 | 235 IRE (SD) / 100 (数字) | 不应超过100 |
| 肤色线 | 中间偏右 | 所有种族相同位置 |
| 饱和度 | <70% | 过高会失真 |
| 合法范围 | 16-235 IRE | 广播标准 |

## 四、色彩匹配

### 4.1 Lumetri 色彩匹配

```
1. 选择参考帧(在源监视器中)
2. 选择需要匹配的剪辑
3. Lumetri → 色轮 → 色彩匹配
4. 自动分析并匹配色彩
5. 手动微调
```

### 4.2 多机位色彩统一

```
流程:
1. 所有机位使用相同调色预设
2. 在调整图层上应用基础校正
3. 用HSL辅助匹配肤色
4. 用矢量示波器验证一致性
5. 保存为调色预设复用
```

## 五、调色预设管理

### 5.1 创建预设

```
1. 调好Lumetri参数
2. 右键效果 → 保存预设
3. 命名并分类
4. 可导出.mpr文件分享
```

### 5.2 常用电影感预设参数

| 预设 | 关键参数 |
|------|---------|
| 好莱坞 | 对比+15, 褪色胶片15, 阴影偏青, 高光偏橙 |
| 胶片 | 褪色25, 暗角20, 颗粒15, 饱和度-10 |
| 冷调 | 阴影色轮偏蓝, 色温-500K, 平衡偏冷 |
| 暖调 | 阴影色轮偏橙, 色温+300K, 平衡偏暖 |
| 高对比 | 对比+40, 黑色-20, 白色+20 |
| 低饱和 | 饱和度-30, 自然饱和度-15 |
