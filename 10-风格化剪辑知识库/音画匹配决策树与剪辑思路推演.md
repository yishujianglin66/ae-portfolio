## 第二章 节拍-片段对齐

### 2.1 对齐目标

把 N 个片段按照时长切分后，对齐到音乐节拍点：

```
音乐节拍：  ●     ●     ●     ●     ●     ●     ●     ●
            │     │     │     │     │     │     │     │
片段A：     [────────────]                          ← 时长8s
片段B：                   [─────]                    ← 时长5s
片段C：                               [──────────────] ← 时长12s

对齐结果：  ├─A1─┤├─B─┤├──A2──┤├──C1──┤├──C2──┤
```

### 2.2 动态规划对齐算法

```python
def align_clips_to_beats(beat_times, clip_durations, target_duration):
    """
    动态规划：将片段序列对齐到节拍点
    目标：最小化"对齐误差" + "片段切分次数"
    """
    n_clips = len(clip_durations)
    n_beats = len(beat_times)
    
    # dp[i][j] = 用前 i 个片段覆盖到第 j 个节拍的最小代价
    INF = float('inf')
    dp = [[INF] * (n_beats + 1) for _ in range(n_clips + 1)]
    dp[0][0] = 0
    
    parent = [[None] * (n_beats + 1) for _ in range(n_clips + 1)]
    
    for i in range(1, n_clips + 1):
        for j in range(1, n_beats + 1):
            # 尝试所有可能的起始节拍
            for k in range(j):
                if dp[i-1][k] == INF: continue
                
                # 第 i 个片段覆盖节拍 k 到 j
                start_time = beat_times[k] if k < n_beats else 0
                end_time = beat_times[j-1] if j-1 < n_beats else target_duration
                segment_duration = end_time - start_time
                
                # 代价：片段时长与片段持续时间的差异
                cost = abs(segment_duration - clip_durations[i-1])
                
                # 切分次数（如果片段被截断）
                if segment_duration < clip_durations[i-1]:
                    cost += 0.1  # 切分代价
                
                total_cost = dp[i-1][k] + cost
                if total_cost < dp[i][j]:
                    dp[i][j] = total_cost
                    parent[i][j] = (k, i-1)
    
    # 回溯找最优对齐
    alignment = []
    i, j = n_clips, n_beats
    while i > 0 and j > 0:
        k, prev_i = parent[i][j]
        alignment.append({
            "start_beat": k,
            "end_beat": j,
            "clip_index": prev_i,
            "start_time": beat_times[k] if k < n_beats else 0,
            "end_time": beat_times[j-1] if j-1 < n_beats else target_duration
        })
        i, j = prev_i, k
    
    alignment.reverse()
    return alignment
```

### 2.3 切点类型

| 切点类型 | 描述 | 触发条件 |
|---------|------|---------|
| hard | 硬切（无过渡） | 节拍点 + 同片段不连续 |
| beat_sync | 踩拍切 | downbeat + 高能量 |
| transition | 转场切 | 段落边界 |
| soft | 软切（溶解） | 段落内连续 |

## 第三章 段落-片段配对

### 3.1 配对目标

把每个音乐段落配上最适合的片段（或片段组合）：

```
音乐段落：
  intro(0-15s, energy=0.2)  → ？
  verse(15-45s, energy=0.4) → ？
  chorus(45-75s, energy=0.9) → ？
  bridge(75-90s, energy=0.6) → ？
  chorus(90-120s, energy=0.95) → ？

片段能量：
  片段A: energy=0.4
  片段B: energy=0.7
  片段C: energy=0.5

配对：
  intro  → 片段A (低能↔低能)
  verse  → 片段C (中能↔中能)
  chorus → 片段B (高能↔高能)
  bridge → 片段A (变化避免重复)
  chorus → 片段B (副歌重复用相同片段)
```

### 3.2 能量匹配算法

```python
def match_clips_to_segments(segments, clip_atoms):
    """
    基于能量相似度的匹配
    """
    # 构建代价矩阵
    cost_matrix = np.zeros((len(segments), len(clip_atoms)))
    for i, seg in enumerate(segments):
        for j, clip in enumerate(clip_atoms):
            # 能量差异
            energy_diff = abs(seg["energy"] - clip["energy"]["overall"])
            
            # 色彩匹配度
            color_match = compute_color_match(clip, seg)
            
            # 总代价
            cost_matrix[i, j] = energy_diff * 0.6 + (1 - color_match) * 0.4
    
    # 匈牙利算法求最优匹配
    from scipy.optimize import linear_sum_assignment
    row_ind, col_ind = linear_sum_assignment(cost_matrix)
    
    matches = []
    for i, j in zip(row_ind, col_ind):
        matches.append({
            "segment_index": i,
            "clip_index": j,
            "cost": cost_matrix[i, j],
            "confidence": 1 - cost_matrix[i, j]
        })
    
    return matches
```

### 3.3 多片段复用策略

当片段数 < 段落数时：

| 策略 | 描述 | 适用 |
|------|------|------|
| repeat | 同一片段重复使用 | 副歌段重复 |
| reverse | 倒放 | 抽象/自然片段 |
| subdivide | 切分子段落用不同片段 | 高潮段 |
| variation | 加不同效果使重复看起来不同 | 通用 |

### 3.4 色彩匹配

```python
def compute_color_match(clip, segment):
    """
    计算片段色彩与段落情绪的匹配度
    """
    # 段落期望色调（基于情绪）
    segment_color_expectation = {
        "intro": "neutral_or_cool",
        "verse": "match_dominant",
        "chorus": "warm_or_vibrant",
        "bridge": "contrast",
        "outro": "fade_to_neutral"
    }
    
    expected = segment_color_expectation.get(segment["type"], "neutral")
    clip_temp = clip["color"]["temperature"]
    
    if expected == "warm_or_vibrant":
        return 1.0 if clip_temp == "warm" or clip["color"]["saturation"] > 0.7 else 0.5
    elif expected == "cool":
        return 1.0 if clip_temp == "cool" else 0.5
    elif expected == "contrast":
        return 0.7  # 桥段允许任何色彩
    else:
        return 0.8  # 中性段接受度高
```

### 4.3 强度映射曲线

效果强度不直接等于频段强度，需要非线性映射：

```python
def map_intensity_to_effect(band_intensity, band_name, segment_type):
    """
    band_intensity: 0-1
    band_name: sub_bass/bass/...
    segment_type: intro/verse/chorus/...
    """
    # 段落修正系数
    segment_factor = {
        "intro": 0.5,
        "verse": 0.7,
        "chorus": 1.0,
        "bridge": 0.8,
        "drop": 1.2  # 高潮段放大效果
    }.get(segment_type, 0.8)
    
    # 频段敏感度
    sensitivity = {
        "sub_bass": 1.2,    # 次低频很敏感
        "bass": 1.0,
        "low_mid": 0.8,
        "mid": 0.9,
        "high_mid": 1.1,
        "high": 1.0
    }.get(band_name, 1.0)
    
    # 非线性映射（让低强度更柔和，高强度更激进）
    mapped = band_intensity ** 1.5
    
    return min(1.0, mapped * segment_factor * sensitivity)
```

## 第六章 剪辑思路推演

### 6.1 节奏曲线设计

基于音乐段落和能量峰值设计剪辑节奏：

```python
def design_pacing_curve(music_atom):
    """
    输出每秒期望切镜数
    """
    pacing_curve = []
    
    for segment in music_atom["structure"]["segments"]:
        seg_duration = segment["end"] - segment["start"]
        energy = segment["energy"]
        bpm = music_atom["rhythm"]["bpm"]
        
        # 段落基础切镜密度
        if segment["type"] == "intro":
            base_density = 0.1  # 10秒一切
        elif segment["type"] == "verse":
            base_density = 0.3  # 3秒一切
        elif segment["type"] == "chorus":
            base_density = 0.5  # 2秒一切（每2拍）
        elif segment["type"] == "bridge":
            base_density = 0.2
        elif segment["type"] == "drop":
            base_density = 0.8  # 1.25秒一切
        else:
            base_density = 0.2
        
        # 能量修正
        adjusted_density = base_density * (0.5 + energy * 0.5)
        
        # 写入曲线
        n_samples = int(seg_duration * 2)  # 0.5s采样
        for i in range(n_samples):
            pacing_curve.append({
                "time": segment["start"] + i * 0.5,
                "cut_density": adjusted_density
            })
    
    return pacing_curve
```

```python
def generate_narrative_structure(music_atom, target_style):
    """
    根据音乐段落+目标风格生成叙事结构
    """
    segments = music_atom["structure"]["segments"]
    
    # 风格对应的叙事模板
    narrative_templates = {
        "cyberpunk": {
            "structure": ["cold_open", "build", "explosion", "twist", "finale"],
            "energy_curve": [0.2, 0.5, 0.95, 0.6, 1.0]
        },
        "cinematic": {
            "structure": ["exposition", "rising_action", "climax", "falling_action", "resolution"],
            "energy_curve": [0.3, 0.5, 0.9, 0.6, 0.3]
        },
        "dream": {
            "structure": ["enter", "explore", "drift", "transform", "exit"],
            "energy_curve": [0.2, 0.4, 0.5, 0.7, 0.3]
        }
    }
    
    template = narrative_templates.get(target_style, narrative_templates["cinematic"])
    
    # 把音乐段落映射到叙事结构
    narrative = []
    for i, seg in enumerate(segments):
        narrative_pos = i / len(segments) * len(template["structure"])
        narrative_pos = min(int(narrative_pos), len(template["structure"]) - 1)
        
        narrative.append({
            "time_range": [seg["start"], seg["end"]],
            "narrative_stage": template["structure"][narrative_pos],
            "expected_energy": template["energy_curve"][narrative_pos],
            "actual_energy": seg["energy"]
        })
    
    return {
        "structure": template["structure"],
        "energy_curve": template["energy_curve"],
        "mapping": narrative
    }
```

```python
def design_emotional_curve(music_atom, narrative):

    curve = []
    for mapping in narrative["mapping"]:
        expected_energy = mapping["expected_energy"]

            "explore": 0.5,
            "drift": 0.4,
```

## 第八章 QC 标准

### 8.1 匹配质量评分

```python
def evaluate_match_quality(match_plan, music_atom, clip_atoms):
    """
    评估匹配方案质量 0-10
    """
    scores = {}
    
    # 1. 节拍对齐度（0-3分）
    aligned_beats = sum(1 for a in match_plan["alignment"] if a.get("cut_type") == "beat_sync")
    total_beats = len(music_atom["rhythm"]["beat_grid"])
    scores["beat_alignment"] = (aligned_beats / total_beats) * 3
    
    # 2. 能量匹配度（0-3分）
    energy_correlation = compute_energy_correlation(match_plan, music_atom, clip_atoms)
    scores["energy_match"] = energy_correlation * 3
    
    # 3. 色彩协调度（0-2分）
    color_consistency = compute_color_consistency(match_plan, clip_atoms)
    scores["color_harmony"] = color_consistency * 2
    
    # 4. 节奏合理性（0-2分）
    pacing_score = evaluate_pacing(match_plan, music_atom)
    scores["pacing"] = pacing_score * 2
    
    total = sum(scores.values())
    return {
        "total": total,
        "sub_scores": scores
    }
```
