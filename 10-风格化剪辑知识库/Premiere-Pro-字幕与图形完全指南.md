# Premiere Pro 字幕与图形完全指南

> 版本: 2025-v1 | 适用: 字幕制作/动态图形/MOGRT

## 一、字幕制作

### 1.1 字幕类型

| 类型 | 用途 | 特点 |
|------|------|------|
| 基本图形字幕 | 标准字幕 | 最常用 |
| 滚动字幕 | 片头/片尾 | 垂直滚动 |
| 单边字幕 | 单侧显示 | 新闻/采访 |
| 卡拉OK字幕 | 音乐视频 | 同步高亮 |

### 1.2 基本图形面板

```
基本图形工作流:
1. 窗口→基本图形
2. 浏览/编辑模式
3. 创建新字幕:
   - 文件→新建→字幕
   - 或使用文字工具(T)点击
4. 输入文字内容
5. 设置样式和位置
6. 调整时间线长度
```

### 1.3 字幕样式

| 属性 | 说明 | 建议 |
|------|------|------|
| 字体 | 选择字体 | 清晰易读 |
| 大小 | 字号 | 根据画面调整 |
| 颜色 | 文字颜色 | 对比背景 |
| 描边 | 外边框 | 增强可读性 |
| 阴影 | 投影效果 | 增加层次 |
| 背景 | 文字背景 | 半透明 |

## 二、MOGRT

### 2.1 MOGRT概述

```
MOGRT(Motion Graphics Template):
- AE创建的动态图形模板
- PR中直接使用和编辑
- 无需AE知识即可使用
- 参数化控制

工作流:
1. AE中创建图形动画
2. 定义可编辑属性
3. 导出为.mogrt文件
4. PR中导入使用
5. 调整参数适配内容
```

### 2.2 创建MOGRT

```
AE中创建:
1. 创建合成(图形动画)
2. 使用基本图形属性:
   - 文字内容
   - 颜色
   - 位置/大小
   - 显示/隐藏
3. 基本图形面板→导出MOGRT
4. 选择属性暴露给PR
5. 导出.mogrt文件

PR中使用:
1. 基本图形面板→浏览
2. 安装.mogrt或拖入时间线
3. 编辑面板调整参数
4. 替换文字/颜色/内容
```

### 2.3 MOGRT类型

| 类型 | 用途 | 示例 |
|------|------|------|
| 下三分之一 | 人物介绍 | 姓名/职位 |
| 转场 | 场景转换 | 图形转场 |
| 标题 | 章节标题 | 动态标题 |
| 字幕条 | 字幕样式 | 装饰字幕 |
| 片头 | 开场动画 | Logo演绎 |
| 片尾 | 结束画面 | 致谢/订阅 |

## 三、动态图形

### 3.1 关键帧动画

| 属性 | 动画 | 用途 |
|------|------|------|
| 位置 | 移动 | 物体运动 |
| 缩放 | 放大缩小 | 强调/转场 |
| 旋转 | 旋转 | 动态效果 |
| 不透明度 | 淡入淡出 | 显示/隐藏 |
| 锚点 | 调整中心 | 旋转中心 |

### 3.2 图形预设

| 预设 | 效果 | 参数 |
|------|------|------|
| 淡入 | 渐显 | 不透明度0→100 |
| 滑入 | 滑入 | 位置偏移 |
| 缩放 | 缩放 | 缩放50→100 |
| 旋转 | 旋转 | 旋转0→360 |
| 弹跳 | 弹性效果 | 缩放+缓动 |

## 四、字幕导入导出

### 4.1 字幕导入

| 格式 | 说明 | 用途 |
|------|------|------|
| SRT | 标准字幕 | 通用 |
| SCC | 封闭字幕 | 广播 |
| MCC | 媒体封闭字幕 | 专业 |
| STL | 字幕模板 | 欧洲 |
| TXT | 文本文件 | 简单 |

### 4.2 字幕导出

```
导出字幕:
1. 文件→导出→字幕
2. 选择格式(SRT最常用)
3. 设置输出位置
4. 导出

SRT格式示例:
1
00:00:01,000 --> 00:00:04,000
第一句字幕内容

2
00:00:05,000 --> 00:00:08,000
第二句字幕内容
```

## 五、自动化字幕

### 5.1 语音转文字

```
自动字幕:
1. 窗口→文本
2. 转录→创建新转录
3. 选择语言
4. 等待转录完成
5. 创建字幕
6. 校对和修正

支持语言:
- 中文(简/繁)
- 英语
- 日语
- 韩语
- 等多种语言
```

### 5.2 批量字幕

```
批量处理:
1. 使用SRT文件批量导入
2. 或使用脚本批量创建
3. 统一样式和位置
4. 批量导出多语言版本
```
