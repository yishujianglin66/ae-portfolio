# 音乐结构原子分析与节拍映射

> [!abstract] 文档摘要
> 本文档定义音乐文件的原子级分析规范，输出 MusicAtom YAML。涵盖节奏（BPM/节拍网格）、结构（段落分割）、能量（RMS/峰值曲线）、频谱（6 频段分解）、情绪（valence-arousal）五大维度。所有输出可直接被音画匹配决策树消费。

> [!tip] 使用指南
> - 算法实现者：第二至六章是核心算法规范
> - 决策树开发者：第七章是与决策树的接口
> - 调试者：第八章是 QC 标准和误差容忍

## 第二章 节奏原子分析

### 2.1 BPM 检测算法

**主算法**：librosa.beat.tempo（基于 onset 包络）

```python
import librosa

y, sr = librosa.load("music.mp3", sr=44100)
onset_env = librosa.onset.onset_strength(y=y, sr=sr)
tempo, _ = librosa.beat.beat_track(onset_envelope=onset_env, sr=sr)
```

**置信度评估**：

| BPM 范围 | 音乐类型 | 置信度基准 |
|---------|---------|----------|
| 60-90 | 慢板/抒情 | 0.85 |
| 90-120 | 中板/流行 | 0.95（最稳定区间） |
| 120-140 | 快板/电子 | 0.95 |
| 140-180 | 极快板 | 0.85 |
| 180+ | Drum&Bass | 0.75 |

**倍频/半频修正**：

```python
# 检测到的 BPM 可能是真实 BPM 的 2 倍或 1/2
# 通过强拍间隔的众数判断真实 BPM
true_bpm = tempo
if tempo > 200:
    true_bpm = tempo / 2
elif tempo < 60:
    true_bpm = tempo * 2
```

### 2.2 节拍网格（Beat Grid）

**算法**：librosa.beat.plp（predominant local pulse）

```python
pulse = librosa.beat.plp(onset_envelope=onset_env, sr=sr)
beats = librosa.util.peak_pick(pulse, pre_max=3, post_max=3, pre_avg=3, post_avg=5, delta=0.1, wait=10)
beat_times = librosa.frames_to_time(beats, sr=sr)
```

**输出**：节拍时间戳数组（秒，精度 0.01s）

```yaml
beat_grid:
  - 0.47    # 第1拍
  - 0.94    # 第2拍
  - 1.41    # 第3拍
  - 1.88    # 第4拍
  - 2.35    # 第5拍（下一小节起点）
```

### 2.3 强拍检测（Downbeat）

强拍 = 每小节的第1拍，决定卡点的"重音"位置。

**算法**：

```python
# 假设 4/4 拍
downbeats = beat_times[::4]  # 每4拍取1个
```

**复杂情况**：

| 拍号 | 强拍间隔 | 典型音乐类型 |
|------|---------|------------|
| 2/4 | 每2拍 | 进行曲、波尔卡 |
| 3/4 | 每3拍 | 华尔兹 |
| 4/4 | 每4拍 | 流行、电子、Hip-Hop |
| 6/8 | 每6拍 | 摇摆、布鲁斯 |
| 7/8 | 每7拍 | 民谣、前卫 |

### 2.4 速度曲线（Tempo Curve）

用于检测速度变化（如渐快、渐慢、变速段）：

```python
# 滑动窗口检测局部 BPM
tempo_curve = []
window_size = sr * 4  # 4秒窗口
hop_size = sr * 1    # 1秒步长

for i in range(0, len(y) - window_size, hop_size):
    window = y[i:i+window_size]
    local_onset = librosa.onset.onset_strength(y=window, sr=sr)
    local_tempo, _ = librosa.beat.beat_track(onset_envelope=local_onset, sr=sr)
    tempo_curve.append({
        "time": i / sr,
        "tempo": float(local_tempo)
    })
```

## 第三章 结构原子分析

### 3.1 段落分割算法

**主算法**：自相似矩阵（Self-Similarity Matrix）+ 边界检测

```python
# 1. 提取 MFCC 特征
mfcc = librosa.feature.mfcc(y=y, sr=sr, n_mfcc=13)

# 2. 计算自相似矩阵
S = librosa.segment.cross_similarity(mfcc, mfcc, mode='affinity')

# 3. 边界检测
bounds = librosa.segment.agglomerative(S, k=6)  # 假设 6 段
bound_times = librosa.frames_to_time(bounds, sr=sr)
```

### 3.2 段落类型识别

基于特征向量分类：

| 段落类型 | 能量 | 频谱质心 | 持续时间 | 典型特征 |
|---------|------|---------|---------|---------|
| intro | 0.1-0.3 | 低 | 8-16s | 乐器少，建立基调 |
| verse | 0.3-0.5 | 中 | 16-32s | 主旋律，人声主导 |
| chorus | 0.7-1.0 | 高 | 16-32s | 全频段，能量峰值 |
| bridge | 0.4-0.7 | 中高 | 8-16s | 转折段，变化大 |
| breakdown | 0.1-0.3 | 低 | 4-16s | 突然抽空 |
| buildup | 0.3-0.7 | 渐增 | 8-32s | 能量渐增 |
| drop | 0.9-1.0 | 高 | 4-8s | 能量爆发 |
| outro | 0.2-0.4 | 渐降 | 8-16s | 收尾，渐弱 |

### 3.3 段落分类器

```python
def classify_segment(segment_audio, sr):
    rms = librosa.feature.rms(y=segment_audio).mean()
    centroid = librosa.feature.spectral_centroid(y=segment_audio, sr=sr).mean()
    duration = len(segment_audio) / sr
    
    if rms < 0.3 and duration < 16:
        return "intro" if centroid < 2000 else "breakdown"
    elif rms > 0.9 and duration < 8:
        return "drop"
    elif rms > 0.7:
        return "chorus"
    elif 0.4 <= rms <= 0.7:
        return "bridge" if centroid > 3000 else "verse"
    else:
        return "outro"
```

### 3.4 边界置信度

```yaml
segments:
  - {type: "intro",  start: 0,    end: 15.2, confidence: 0.95}  # 强边界
  - {type: "verse",  start: 15.2, end: 45.3, confidence: 0.85}  # 中等边界
  - {type: "chorus", start: 45.3, end: 75.4, confidence: 0.95}  # 强边界
```

置信度决定该边界是否作为"硬切点"使用：

- **>0.9**：可作硬切点
- **0.7-0.9**：建议作为软转场点
- **<0.7**：仅作参考，不强制对齐

## 第四章 能量原子分析

### 4.1 RMS 能量曲线

```python
# 每 0.5s 采样一次
hop_length = sr // 2  # 0.5s 步长
frame_length = sr    # 1s 窗口
rms = librosa.feature.rms(y=y, frame_length=frame_length, hop_length=hop_length)[0]

# 归一化到 0-1
rms_normalized = (rms - rms.min()) / (rms.max() - rms.min())

energy_curve = []
for i, value in enumerate(rms_normalized):
    energy_curve.append({
        "time": i * 0.5,
        "energy": float(value)
    })
```

### 4.2 峰值检测

**算法**：scipy.signal.find_peaks

```python
from scipy.signal import find_peaks

# 找显著峰值（高于均值+1σ）
threshold = rms_normalized.mean() + rms_normalized.std()
peaks, properties = find_peaks(
    rms_normalized,
    height=threshold,
    distance=4,        # 至少间隔 2s
    prominence=0.2     # 显著度
)

peak_times = [i * 0.5 for i in peaks]
```

**峰值分类**：

| 类型 | 描述 | 触发条件 | 视觉对应 |
|------|------|---------|---------|
| drop | 能量爆发点 | height > 0.9, prominence > 0.5 | 粒子爆发/闪光 |
| build | 能量上升点 | prominence > 0.3, 上升斜率 > 0.1/s | 拉镜/缩放 |
| accent | 重音点 | 局部最大值, prominence > 0.2 | 短促故障/抖动 |
| lift | 能量提升 | 段落起始, height 跳变 | 转场切换 |

### 4.3 动态范围

```python
dynamic_range = {
    "max": float(rms.max()),
    "min": float(rms.min()),
    "mean": float(rms.mean()),
    "std": float(rms.std()),
    "dynamic_range_db": 20 * np.log10(rms.max() / rms.min())
}
```

动态范围影响剪辑密度：

| DR (dB) | 类型 | 剪辑密度建议 |
|---------|------|------------|
| <6 | 压缩严重 | 切镜密集 |
| 6-12 | 流行音乐 | 中等密度 |
| 12-20 | 古典/爵士 | 较低密度 |

## 第五章 频谱原子分析

### 5.1 6 频段分解

基于 ISO 266 标准调整：

```python
bands = {
    "sub_bass":   (20, 60),     # 次低频
    "bass":       (60, 250),    # 低频
    "low_mid":    (250, 500),   # 中低频
    "mid":        (500, 2000),  # 中频
    "high_mid":   (2000, 4000), # 中高频
    "high":       (4000, 20000) # 高频
}

band_curves = {}
for name, (low, high) in bands.items():
    # 巴特沃斯带通滤波
    from scipy.signal import butter, filtfilt
    b, a = butter(4, [low / (sr/2), high / (sr/2)], btype='band')
    filtered = filtfilt(b, a, y)
    
    # 计算 RMS
    rms_band = librosa.feature.rms(y=filtered, hop_length=sr//2)[0]
    band_curves[name] = {
        "range": [low, high],
        "curve": normalize(rms_band)
    }
```

### 5.2 频段-视觉映射

每段频段对应一类视觉效果：

| 频段 | 视觉效果 | 强度映射 |
|------|---------|---------|
| sub_bass (20-60Hz) | 画面震动/缩放脉冲 | 振幅 → 震动幅度 |
| bass (60-250Hz) | 故障/位移/抖动 | 振幅 → 位移像素 |
| low_mid (250-500Hz) | 慢动作/速度变化 | 振幅 → 时间速率 |
| mid (500-2kHz) | 主体动作/缩放 | 振幅 → 缩放倍数 |
| high_mid (2-4kHz) | 闪烁/光晕 | 振幅 → Glow 强度 |
| high (4-20kHz) | 粒子/光斑/扫描线 | 振幅 → 粒子密度 |

### 5.3 频谱质心（Spectral Centroid）

音色"亮度"的量化指标：

```python
centroid = librosa.feature.spectral_centroid(y=y, sr=sr)[0]
centroid_curve = []
for i, value in enumerate(centroid):
    centroid_curve.append({
        "time": i * 512 / sr,  # hop_length=512
        "value": float(value)
    })
```

质心与情绪映射：

| 质心 (Hz) | 音色描述 | 情绪对应 |
|----------|---------|---------|
| <1000 | 沉闷/低沉 | 压抑/沉重 |
| 1000-2500 | 温暖/中性 | 平静/中性 |
| 2500-4000 | 明亮/清晰 | 愉悦/积极 |
| >4000 | 锐利/刺耳 | 紧张/激烈 |

### 5.4 频谱通量（Spectral Flux）

频谱变化速率，用于检测"音色突变"：

```python
flux = librosa.onset.onset_strength(y=y, sr=sr)
# 高通量点 = 音色变化大 = 适合做转场
```

## 第六章 情绪原子分析

### 6.1 Valence-Arousal 模型

二维情绪空间：

```
高唤醒
   │
   │  紧张/激烈        兴奋/愉悦
   │  (高A 低V)        (高A 高V)
   │
   ├─────────────────────────
   │
   │  悲伤/压抑        平静/满足
   │  (低A 低V)        (低A 高V)
   │
低唤醒           高积极度
```

### 6.2 情绪推断

```python
def estimate_emotion(music_atom):
    # 基于 RMS、频谱质心、调式
    arousal = music_atom.energy.curve_mean * 0.5 + \
              music_atom.spectrum.spectral_centroid_mean / 5000 * 0.5
    
    # 调式判断（大调积极，小调消极）
    is_major = detect_key_mode(music_atom.metadata.dominant_key)
    valence = (1 if is_major else 0) * 0.4 + \
              (music_atom.spectrum.spectral_centroid_mean > 2000) * 0.3 + \
              music_atom.emotional.tempo_stability * 0.3
    
    return {
        "valence": float(np.clip(valence, 0, 1)),
        "arousal": float(np.clip(arousal, 0, 1))
    }
```

### 6.3 情绪曲线

每段落计算一个 (valence, arousal) 点，形成情绪轨迹：

```yaml
emotional_curve:
  - {time: 0,   valence: 0.4, arousal: 0.3}   # 前奏：中性低唤醒
  - {time: 15,  valence: 0.5, arousal: 0.5}   # 主歌：偏中性
  - {time: 45,  valence: 0.7, arousal: 0.9}   # 副歌：积极高唤醒
  - {time: 75,  valence: 0.3, arousal: 0.6}   # 桥段：紧张
  - {time: 90,  valence: 0.8, arousal: 1.0}   # 副歌：极积极极高唤醒
```

### 6.4 调式检测

```python
# Krumhansl-Schmuckler 算法
chroma = librosa.feature.chroma_cqt(y=y, sr=sr)
key = librosa.key_estimate(chroma)
# 返回：('C', 'major') 或 ('A', 'minor')
```

| 调式 | 情绪倾向 | 典型用途 |
|------|---------|---------|
| Major | 积极/明亮 | 欢快视频 |
| Minor | 消极/暗沉 | 戏剧性视频 |
| Dorian | 神秘/爵士 | 艺术视频 |
| Phrygian | 西班牙/异域 | 风格化视频 |

## 第八章 QC 标准与误差容忍

### 8.1 准确率目标

| 指标 | 目标 | 边界 |
|------|------|------|
| BPM 检测 | ±2 BPM | 90% 落在 ±2 内 |
| 节拍点位置 | ±50ms | 95% 落在 ±50ms 内 |
| 强拍识别 | ±100ms | 90% 落在 ±100ms 内 |
| 段落边界 | ±500ms | 80% 落在 ±500ms 内 |
| 段落类型分类 | >85% 准确 | - |

### 8.2 已知失败模式

| 失败模式 | 现象 | 修复建议 |
|---------|------|---------|
| 倍频错误 | BPM=256 (真实128) | 强拍间隔众数修正 |
| 自由节奏 | 古典/爵士无固定节拍 | 用 onset 包络代替节拍 |
| 渐变段 | 段落边界模糊 | 置信度<0.7 不强制对齐 |
| 极静段 | 能量曲线接近0 | 用 onset_strength 代替 RMS |
| 多调式 | 转调频繁 | 滑动窗口分段检测 |

### 8.3 备用算法

| 主算法失败 | 备用算法 |
|-----------|---------|
| librosa.beat | madmom.BeatDetector（更准但更慢） |
| 自相似矩阵 | 结构注释模型（深度学习） |
| Krumhansl | 深度学习 key 检测器 |
