# AE-色彩心理学与调色理论

> 版本: 2025-v1 | 适用: 色彩心理学/调色理论/情感表达

## 一、色彩心理学

### 1.1 色彩情感

| 色彩 | 情感 | 应用 |
|------|------|------|
| 红色 | 激情/危险/能量 | 动作/爱情 |
| 蓝色 | 冷静/信任/忧郁 | 科幻/商业 |
| 绿色 | 自然/成长/嫉妒 | 自然/恐怖 |
| 黄色 | 快乐/警告/乐观 | 喜剧/警示 |
| 紫色 | 神秘/奢华/精神 | 奇幻/宗教 |
| 橙色 | 活力/友好/温暖 | 冒险/家庭 |
| 黑色 | 死亡/优雅/神秘 | 恐怖/时尚 |
| 白色 | 纯洁/简约/空虚 | 浪漫/极简 |

### 1.2 色彩和谐

| 和谐类型 | 说明 | 应用 |
|---------|------|------|
| 互补色 | 色轮对角 | 强烈对比 |
| 类似色 | 色轮相邻 | 和谐统一 |
| 三角色 | 色轮三等分 | 平衡丰富 |
| 分裂互补 | 互补色两侧 | 对比柔和 |
| 单色 | 同一色相 | 统一层次 |

## 二、调色理论

### 2.1 一级调色

```
一级校正流程:
1. 白平衡: 色温/色调
2. 曝光: 亮度/对比度
3. 饱和度: 整体鲜艳度
4. 基础色调: 暗部/中间调/亮部

目标:
- 还原真实色彩
- 建立基础影调
- 统一素材色彩
```

### 2.2 二级调色

```
二级校正流程:
1. 限定器: 选择特定颜色
2. 分区调色: 暗部/中间调/亮部
3. 曲线精修: RGB曲线
4. HSL调整: 特定颜色

目标:
- 风格化调色
- 局部调整
- 色彩分级
```

### 2.3 色彩分级

| 区域 | 调整 | 效果 |
|------|------|------|
| 暗部 | 偏青蓝 | 电影感 |
| 中间调 | 保持中性 | 自然 |
| 亮部 | 偏橙黄 | 温暖 |

## 三、调色风格

### 3.1 电影感调色

```
电影感调色:
1. 青橙色调: 暗部青蓝+亮部橙黄
2. 低饱和: 整体降低饱和度
3. 高对比: S型曲线增加对比
4. 暗角: 边缘压暗
5. 颗粒: 添加胶片颗粒
```

### 3.2 复古调色

```
复古调色:
1. 褪色: 降低对比度
2. 暖色调: 偏黄/橙
3. 低饱和: 褪色效果
4. 暗角: 边缘压暗
5. 颗粒: 胶片颗粒
```

### 3.3 高对比调色

```
高对比调色:
1. 强对比: 深暗+亮亮部
2. 高饱和: 鲜艳色彩
3. 锐化: 增强细节
4. 清晰: 中间调对比
```

## 四、调色工作流

### 4.1 标准工作流

```
调色工作流:
1. 素材准备: 统一色彩空间
2. 一级校正: 基础校正
3. 二级校正: 风格化
4. 局部调整: 限定器/遮罩
5. 最终检查: 多设备验证
6. 输出: 色彩空间转换
```

### 4.2 调色顺序

```
推荐调色顺序:
1. 曝光/对比度
2. 白平衡
3. 饱和度
4. 曲线
5. HSL
6. 色彩分级
7. 特效(暗角/颗粒)
```
