## 一、三维合成基础

### 1.1 2D与3D图层的区别

After Effects中的图层可以在2D模式和3D模式之间切换，两种模式在空间感知、变换属性、渲染方式上存在本质差异。

| 特性 | 2D图层 | 3D图层 |
|------|--------|--------|
| 空间维度 | 仅X/Y轴 | X/Y/Z三轴 |
| 变换属性 | Position, Anchor Point, Scale, Rotation, Opacity | 增加Z轴、Orientation、Material Options |
| 透视关系 | 无透视，平行投影 | 真实透视，近大远小 |
| 灯光影响 | 不受灯光影响 | 受灯光影响，可产生高光、阴影 |
| 阴影投射 | 无法投射/接受阴影 | 可投射和接受阴影 |
| 摄像机交互 | 不受摄像机影响 | 受摄像机视角、焦距、景深影响 |
| 渲染顺序 | 按图层面板顺序堆叠 | 按Z轴深度排序渲染 |
| 混合模式 | 正常工作 | 部分模式受3D空间影响 |
| 调整层 | 影响下方所有图层 | 仅影响同深度范围图层 |
| 运动模糊 | 2D运动模糊 | 3D运动模糊（更真实） |

### 1.2 3D坐标系

#### 1.2.1 坐标轴方向定义

After Effects采用**右手坐标系**（Right-Hand Coordinate System），三轴方向如下：

```
         Y轴 (+) 向上
          ↑
          │
          │
          │
          └──────────→ X轴 (+) 向右
         /
        /
       /
      Z轴 (+) 朝向观察者（从屏幕向外）
```

| 轴 | 正方向 | 负方向 | 说明 |
|----|--------|--------|------|
| X轴 | 向右 | 向左 | 水平方向 |
| Y轴 | 向上 | 向下 | 垂直方向（与屏幕坐标系Y轴相反） |
| Z轴 | 朝向观察者（出屏） | 远离观察者（入屏） | 深度方向 |

#### 1.2.2 右手坐标系判定方法

右手定则：
- **右手四指从X轴正方向弯向Y轴正方向**
- **大拇指所指方向即为Z轴正方向**

在AE中验证：
- 图层Z值增大 → 图层向观察者靠近 → 视觉上变大
- 图层Z值减小 → 图层远离观察者 → 视觉上变小

#### 1.2.3 坐标系原点

- **合成坐标系原点**：位于合成画面的左上角（0,0,0）
- **图层坐标系原点**：位于图层的Anchor Point（锚点）位置
- **世界坐标系**：以合成中心为基准的全局坐标系（可通过表达式访问）

### 1.3 启用3D图层的方法和影响

#### 1.3.1 启用方法

**方法一：图层面板开关**
1. 在时间轴面板中找到目标图层
2. 点击图层开关列中的 **3D图层开关**（立方体图标）
3. 开关亮起即表示已启用3D模式

**方法二：菜单命令**
- 选择图层 → `Layer` → `3D Layer` （快捷键：无默认，可自定义）

**方法三：快捷键**
- 选中图层后按 `Ctrl+Alt+Shift+Y` （需在键盘快捷键中设置）

#### 1.3.2 启用后的影响

启用3D图层后，图层面板中会新增以下属性组：

```
图层
├── Transform（变换）
│   ├── Anchor Point（新增Z轴）
│   ├── Position（新增Z轴）
│   ├── Scale（新增Z轴）
│   ├── Orientation（新属性）
│   ├── X Rotation（新属性）
│   ├── Y Rotation（新属性）
│   ├── Z Rotation（原Rotation）
│   ├── Opacity
│   └── ...
├── Material Options（材质选项）← 新增属性组
│   ├── Casts Shadows
│   ├── Accepts Shadows
│   ├── Accepts Lights
│   ├── Ambient
│   ├── Diffuse
│   ├── Specular
│   ├── Shininess
│   ├── Metal
│   ├── Reflection
│   ├── Transparency
│   ├── Index of Refraction
│   └── Thickness
└── ...
```

#### 1.3.3 注意事项

1. **性能消耗**：3D图层渲染比2D图层慢约2-5倍，大量使用需注意优化
2. **混合模式变化**：部分混合模式在3D空间中行为不同
3. **调整层**：3D调整层只影响同深度的图层
4. **预合成**：预合成内的3D图层需要开启"塌陷变换"才能与外部3D空间交互
5. **文字图层**：文字图层启用3D后，每个字符可单独设置3D属性（需启用Per-character 3D）

### 1.4 三维空间概念

#### 1.4.1 深度（Depth）

深度是3D空间中最重要的概念，指物体沿Z轴方向的位置关系。

**深度感知线索：**
- **相对大小**：近处物体大，远处物体小
- **遮挡关系**：近处物体遮挡远处物体
- **透视变形**：平行线在远处汇聚
- **景深模糊**：焦点外的物体模糊
- **大气透视**：远处物体对比度降低、偏蓝

#### 1.4.2 透视（Perspective）

透视是3D空间中模拟真实视觉的关键。AE中的透视由摄像机控制。

**透视类型对比：**

| 透视类型 | 特点 | 视觉效果 |
|----------|------|----------|
| 平行投影（正交） | 无透视，平行线保持平行 | 扁平化、无深度感 |
| 一点透视 | 一个消失点 | 正面观看，深度感适中 |
| 两点透视 | 两个消失点 | 斜角观看，建筑感强 |
| 三点透视 | 三个消失点 | 仰视/俯视，戏剧感强 |

**AE中的透视控制：**
- 摄像机的 **Zoom（焦距）** 决定透视强度
- 焦距越短（广角），透视越强，变形越明显
- 焦距越长（长焦），透视越弱，空间越扁平

#### 1.4.3 视差（Parallax）

视差是指从不同位置观察物体时，物体位置相对背景发生偏移的现象。

**视差原理：**
- 近处物体移动时，相对位移大
- 远处物体移动时，相对位移小
- 极远处物体（如天空）几乎无位移

**视差计算公式：**
```
视差位移 = 摄像机移动距离 × (1 / 图层Z轴深度)
```

**视差的应用：**
- 增强空间层次感
- 模拟真实相机运动
- 创建伪3D效果（2D照片模拟3D）
- 沉浸式场景构建

## 二、3D图层变换属性详解

### 2.1 Anchor Point（锚点）

#### 2.1.1 3D锚点的作用

锚点是图层的"中心点"，所有变换（旋转、缩放、位移）都围绕锚点进行。

**3D锚点的特点：**
- 默认位置：图层几何中心（width/2, height/2, 0）
- 单位：像素（X/Y轴）、像素（Z轴）
- 影响：旋转中心、缩放中心、位置基准

#### 2.1.2 属性详情

| 属性 | 数值范围 | 默认值 | 说明 |
|------|----------|--------|------|
| Anchor Point X | -∞ ~ +∞ | 图层宽度/2 | 水平锚点位置 |
| Anchor Point Y | -∞ ~ +∞ | 图层高度/2 | 垂直锚点位置 |
| Anchor Point Z | -∞ ~ +∞ | 0 | 深度锚点位置 |

#### 2.1.3 锚点的应用场景

1. **旋转中心控制**
   - 将锚点移到底部 → 图层像门一样绕底边旋转
   - 将锚点移到侧边 → 图层绕侧边翻转
   - 将锚点移出图层 → 图层围绕外部点旋转

2. **Z轴锚点与厚度**
   - 当图层有厚度时（Thickness > 0），Z轴锚点决定厚度中心位置
   - 锚点Z = 0，厚度均匀分布在图层前后
   - 锚点Z > 0，厚度更多分布在图层后方

### 2.2 Position（位置）

#### 2.2.1 三轴位置定义

| 轴 | 正方向 | 负方向 | 单位 | 默认值 |
|----|--------|--------|------|--------|
| X Position | 向右 | 向左 | 像素 | 合成宽度/2 |
| Y Position | 向上 | 向下 | 像素 | 合成高度/2 |
| Z Position | 朝向观察者 | 远离观察者 | 像素 | 0 |

#### 2.2.2 位置与视觉大小的关系

当摄像机存在时，图层Z轴位置影响视觉大小：

```
视觉大小 = 实际大小 × (焦距 / (焦距 - 图层Z位置))
```

**示例（焦距=1000像素）：**

| 图层Z位置 | 视觉缩放比例 | 说明 |
|-----------|-------------|------|
| -2000 | 33% | 远离摄像机，变小 |
| -1000 | 50% | 焦距一半距离 |
| 0 | 100% | 原大小 |
| +500 | 200% | 靠近摄像机，变大 |
| +900 | 1000% | 接近焦距位置，极大 |
| +1000 | ∞ | 与摄像机同平面，无限大 |

> **注意**：图层Z位置不能等于或超过摄像机Z位置（+焦距值），否则会出现翻转或不可见。

### 2.3 Scale（缩放）

#### 2.3.1 三维缩放特点

3D图层的缩放有三个维度：X、Y、Z。

| 属性 | 数值范围 | 默认值 | 说明 |
|------|----------|--------|------|
| Scale X | -∞ ~ +∞ (%) | 100 | 水平缩放 |
| Scale Y | -∞ ~ +∞ (%) | 100 | 垂直缩放 |
| Scale Z | -∞ ~ +∞ (%) | 100 | 深度缩放（影响厚度） |

#### 2.3.2 Z轴缩放的作用

- **普通平面图层**：Z轴缩放影响材质厚度的视觉表现
- **有厚度的图层**：Z轴缩放改变厚度方向的尺寸
- **3D文字/形状**：Z轴缩放改变挤出深度

#### 2.3.3 等比缩放与非等比缩放

**等比缩放（约束比例）：**
- 按住 `Shift` 拖动缩放手柄
- 表达式：`[value[0], value[0], value[0]]` 保持三轴等比

**非等比缩放的应用：**
- 压扁/拉伸效果
- 模拟透视变形
- 创建特殊视觉效果

### 2.4 Orientation（方向）

#### 2.4.1 Orientation与Rotation的区别

| 特性 | Orientation | Rotation (X/Y/Z) |
|------|-------------|------------------|
| 旋转顺序 | 同时计算X/Y/Z | 按Z→X→Y顺序应用 |
| 插值方式 | 四元数插值，路径最短 | 角度插值，可能走长路径 |
| 万向节锁 | 不会出现 | 可能出现 |
| 动画平滑度 | 旋转动画更平滑 | 大角度旋转可能异常 |
| 适用场景 | 朝向、姿态设置 | 逐轴旋转动画 |

#### 2.4.2 属性详情

| 属性 | 数值范围 | 默认值 | 说明 |
|------|----------|--------|------|
| Orientation X | 0° ~ 360° | 0° | X轴方向角 |
| Orientation Y | 0° ~ 360° | 0° | Y轴方向角 |
| Orientation Z | 0° ~ 360° | 0° | Z轴方向角 |

#### 2.4.3 使用建议

1. **设置固定朝向**：优先使用Orientation
2. **旋转动画**：使用X/Y/Z Rotation关键帧
3. **避免万向节锁**：大角度旋转使用Orientation
4. **表达式控制朝向**：使用`lookAt()`生成Orientation

### 2.5 X Rotation / Y Rotation / Z Rotation

#### 2.5.1 三维旋转详解

| 旋转轴 | 旋转效果 | 视觉比喻 |
|--------|----------|----------|
| X Rotation | 绕水平轴翻转 | 翻书、点头 |
| Y Rotation | 绕垂直轴翻转 | 转身、摇头 |
| Z Rotation | 绕深度轴旋转 | 钟表、歪头 |

#### 2.5.2 属性详情

| 属性 | 数值范围 | 默认值 | 单位 |
|------|----------|--------|------|
| X Rotation | -∞ ~ +∞ | 0° | 度 |
| Y Rotation | -∞ ~ +∞ | 0° | 度 |
| Z Rotation | -∞ ~ +∞ | 0° | 度 |

#### 2.5.3 旋转顺序与万向节锁

**AE旋转顺序（从外到内）：Z → X → Y**

这意味着：
1. 先应用Z Rotation（绕Z轴旋转）
2. 再应用X Rotation（绕X轴旋转）
3. 最后应用Y Rotation（绕Y轴旋转）

**万向节锁（Gimbal Lock）：**
- 当X Rotation = ±90°时，Z轴和Y轴重合
- 此时Z Rotation和Y Rotation效果相同，丢失一个自由度
- **解决方法**：使用Orientation属性，或调整旋转顺序

### 2.6 Opacity（透明度）

#### 2.6.1 3D空间中的透明度

| 属性 | 数值范围 | 默认值 | 说明 |
|------|----------|--------|------|
| Opacity | 0% ~ 100% | 100% | 不透明度 |

#### 2.6.2 3D透明度特点

1. **深度排序**：3D图层按Z轴深度从后往前渲染，透明度按正确顺序叠加
2. **自遮挡**：有厚度的图层，自身不同面之间也会有透明度叠加
3. **与材质透明度的关系**：
   - Transform Opacity：整个图层的透明度
   - Material Options > Transparency：材质的透明度（受灯光影响）

### 2.7 Material Options（材质选项）完整参数

材质选项控制3D图层如何与灯光和阴影交互，是3D合成中最核心的属性组之一。

#### 2.7.1 Casts Shadows（投射阴影）

| 项目 | 详情 |
|------|------|
| **作用** | 决定图层是否向其他图层投射阴影 |
| **数值类型** | 下拉选项 |
| **可选值** | `Off` / `On` / `Only` |
| **默认值** | `Off` |

**选项说明：**
- **Off**：不投射阴影
- **On**：正常投射阴影，图层本身也可见
- **Only**：仅投射阴影，图层本身不可见（阴影捕捉器专用）

**使用场景：**
- 主体物体：设为On
- 地面/接收面：设为Off（只接受阴影）
- 阴影捕捉层：设为Only（配合Accepts Shadows使用）

#### 2.7.2 Accepts Shadows（接受阴影）

| 项目 | 详情 |
|------|------|
| **作用** | 决定图层是否接受其他图层投射的阴影 |
| **数值类型** | 下拉选项 |
| **可选值** | `Off` / `On` |
| **默认值** | `On` |

**使用建议：**
- 地面、墙壁等承载面：On
- 发光物体、天空：Off
- 前景装饰：视情况而定

#### 2.7.3 Accepts Lights（接受灯光）

| 项目 | 详情 |
|------|------|
| **作用** | 决定图层是否受灯光影响 |
| **数值类型** | 下拉选项 |
| **可选值** | `Off` / `On` |
| **默认值** | `On` |

**使用场景：**
- **On（默认）**：大多数物体，受光照影响
- **Off**：自发光物体、UI元素、不需要光照的图层

> **注意**：设为Off后，图层显示为完全自发光状态，不受任何灯光影响，但仍可投射/接受阴影。

#### 2.7.4 Ambient（环境光）

| 项目 | 详情 |
|------|------|
| **作用** | 控制图层对环境光的反射程度 |
| **数值范围** | 0% ~ 100% |
| **默认值** | 100% |

**详细说明：**
- 环境光是均匀照射所有方向的光
- Ambient值越高，图层受环境光影响越大
- 100%：完全反映环境光颜色
- 0%：不受环境光影响，环境光部分为纯黑

**调节技巧：**
- 降低Ambient可以增加对比度
- 提高Ambient可以减少暗部死黑
- 配合灯光的Ambient参数一起调节

#### 2.7.5 Diffuse（漫反射）

| 项目 | 详情 |
|------|------|
| **作用** | 控制图层漫反射的强度 |
| **数值范围** | 0% ~ 100% |
| **默认值** | 100% |

**详细说明：**
- 漫反射是光线照射到粗糙表面后向各个方向反射的现象
- Diffuse值决定图层"接收"光线的能力
- 数值越高，被灯光照射的部分越亮
- 漫反射的亮度取决于光线入射角（Lambert余弦定律）

**材质参考：**

| 材质 | Diffuse值参考 | 特点 |
|------|--------------|------|
| 粗糙布料 | 80% ~ 100% | 高漫反射，均匀受光 |
| 塑料 | 60% ~ 80% | 中等漫反射 |
| 金属 | 20% ~ 50% | 低漫反射，高反射 |
| 镜子 | 0% ~ 10% | 几乎无漫反射 |

#### 2.7.6 Specular（高光）

| 项目 | 详情 |
|------|------|
| **作用** | 控制图层镜面高光的强度 |
| **数值范围** | 0% ~ 100% |
| **默认值** | 100% |

**详细说明：**
- 高光是光线在光滑表面镜面反射形成的亮斑
- Specular值决定高光的亮度
- 高光颜色 = 灯光颜色 × Specular值
- 高光位置取决于视角和光源位置

**材质参考：**

| 材质 | Specular值参考 |
|------|---------------|
| 粗糙表面 | 0% ~ 20% |
| 半光滑 | 30% ~ 60% |
| 光滑塑料 | 70% ~ 90% |
| 金属/玻璃 | 80% ~ 100% |

#### 2.7.7 Shininess（光泽度）

| 项目 | 详情 |
|------|------|
| **作用** | 控制高光的大小和集中度 |
| **数值范围** | 0% ~ 100% |
| **默认值** | 50% |

**详细说明：**
- Shininess决定高光的"锐利"程度
- 数值越高，高光越小、越锐利
- 数值越低，高光越大、越柔和
- 与Specular配合使用：Specular控制亮度，Shininess控制大小

**视觉效果对比：**

| Shininess值 | 高光效果 | 材质感 |
|-------------|----------|--------|
| 10% | 大而模糊的高光 | 粗糙、哑光 |
| 30% | 中等大小高光 | 半光滑 |
| 50%（默认） | 标准高光 | 一般光滑 |
| 80% | 小而锐利的高光 | 光滑、抛光 |
| 100% | 极小极亮的高光 | 镜面、金属 |

#### 2.7.8 Metal（金属质感）

| 项目 | 详情 |
|------|------|
| **作用** | 控制材质的金属感程度 |
| **数值范围** | 0% ~ 100% |
| **默认值** | 0% |

**详细说明：**
- 金属材质的特点：高光颜色 = 材质颜色（而非灯光颜色）
- Metal = 0%：非金属，高光为灯光颜色（塑料、陶瓷、木头）
- Metal = 100%：完全金属，高光为图层自身颜色
- 中间值：过渡效果

**真实材质参数参考：**

| 材质 | Metal | Diffuse | Specular | Shininess |
|------|-------|---------|----------|-----------|
| 金 | 100% | 30% | 100% | 90% |
| 银 | 100% | 20% | 100% | 95% |
| 铜 | 100% | 40% | 90% | 85% |
| 钢 | 100% | 35% | 95% | 90% |
| 塑料（白） | 0% | 80% | 60% | 40% |
| 橡胶 | 0% | 90% | 10% | 10% |
| 玻璃 | 0% | 20% | 100% | 95% |

#### 2.7.9 Reflection（反射）

| 项目 | 详情 |
|------|------|
| **作用** | 控制图层的反射强度 |
| **数值范围** | 0% ~ 100% |
| **默认值** | 0% |

**详细说明：**
- Reflection控制图层反射周围环境的能力
- 需要配合环境贴图（Environment Layer）使用
- 仅在Classic 3D和Ray-traced 3D渲染器中有效
- 反射强度影响高光和环境反射

**使用方法：**
1. 在合成中创建一个图层作为环境贴图
2. 在图层的Material Options中设置Reflection > 0%
3. 反射效果会自动计算（取决于渲染器类型）

#### 2.7.10 Transparency（透明度）

| 项目 | 详情 |
|------|------|
| **作用** | 控制材质的透明度（受灯光影响） |
| **数值范围** | 0% ~ 100% |
| **默认值** | 0% |

**与Transform Opacity的区别：**

| 特性 | Transform Opacity | Material Transparency |
|------|-------------------|----------------------|
| 影响范围 | 整个图层（包括所有通道） | 仅材质的透明度 |
| 灯光交互 | 不受灯光影响 | 受灯光角度影响（类似折射） |
| 阴影 | 透明物体仍可投射阴影 | 透明度影响阴影 |
| 适用场景 | 整体淡入淡出 | 玻璃、水等透明材质 |

#### 2.7.11 Index of Refraction（折射率）

| 项目 | 详情 |
|------|------|
| **作用** | 控制透明材质的光折射程度 |
| **数值范围** | 1.0 ~ 4.0 |
| **默认值** | 1.45 |

**详细说明：**
- IOR决定光线穿过透明材质时的弯曲程度
- 仅在Transparency > 0%时有意义
- 仅在Ray-traced 3D渲染器中完全有效

**常见材质IOR参考：**

| 材质 | IOR值 |
|------|-------|
| 真空/空气 | 1.0 |
| 水 | 1.33 |
| 冰 | 1.31 |
| 普通玻璃 | 1.52 |
| 水晶 | 1.54 |
| 钻石 | 2.42 |
| 有机玻璃 | 1.49 |

#### 2.7.12 Thickness（厚度）

| 项目 | 详情 |
|------|------|
| **作用** | 控制3D图层的厚度（挤出深度） |
| **数值范围** | 0 ~ 1000+ 像素 |
| **默认值** | 0 |

**详细说明：**
- Thickness给2D平面图层增加Z轴厚度，使其成为3D立体对象
- 厚度沿图层法线方向（Z轴）延伸
- 厚度值 = 0时为纯平面
- 厚度渲染需要Ray-traced 3D或特定渲染器支持

**厚度效果的应用：**
- 立体文字（挤出文字）
- 3D LOGO
- 卡片厚度
- 立体几何形状

> **注意**：Thickness在Classic 3D模式下可能不显示立体效果，仅在Ray-traced 3D模式下完全渲染。

## 三、摄像机系统详解

摄像机是After Effects 3D合成的核心组件，决定了观看3D场景的视角、透视和景深效果。

### 3.1 摄像机类型

AE提供了4种预设摄像机类型和自定义选项：

| 类型 | 英文名称 | 特点 | 适用场景 |
|------|----------|------|----------|
| 一点透视 | 1-Point | 正面观看，一个消失点 | 正面展示、UI动效 |
| 两点透视 | 2-Point | 斜角观看，两个消失点 | 建筑展示、产品展示 |
| 三点透视 | 3-Point | 仰视/俯视，三个消失点 | 戏剧感、夸张视角 |
| 自定义 | Custom | 自由设置所有参数 | 精确控制、动画 |

#### 3.1.1 1-Point Camera（一点透视摄像机）

```
      ← 消失点在中心 →
    ┌──────────────────┐
    │  ┌────────────┐  │
    │  │            │  │
    │  │   正面     │  │
    │  │            │  │
    │  └────────────┘  │
    └──────────────────┘
```

**特点：**
- 观看方向与场景正面垂直
- 水平线和垂直线保持平行
- 只有Z轴方向的线汇聚到消失点
- 透视变形最小

**参数预设：**
- Zoom：根据合成尺寸自动计算
- Angle of View：约39°（标准镜头）
- Film Size：36mm
- 无倾斜、偏移

#### 3.1.2 2-Point Camera（两点透视摄像机）

```
    ← 消失点1            消失点2 →
    ────┬───────────────┬────
        │  ┌────────┐   │
        │ /        /    │
        │/        /     │
        └────────┘      │
                        │
```

**特点：**
- 从斜角观看场景
- 垂直线保持平行
- 水平线向左右两个消失点汇聚
- 建筑感、立体感强

**参数预设：**
- 默认有一定Y轴旋转角度
- 适合展示物体的多个面

#### 3.1.3 3-Point Camera（三点透视摄像机）

```
              ↖ 消失点3（上方）
           ╱    ╲
         ╱        ╲
       ╱            ╲
     ╱  ┌────────┐    ╲
   ╱    │        │      ╲
  ←消失点1      消失点2→
```

**特点：**
- 仰视或俯视视角
- 三个方向的线都有消失点
- 戏剧感、夸张感强
- 透视变形最大

**适用场景：**
- 英雄视角（仰视英雄）
- 上帝视角（俯视场景）
- 科幻、震撼场景

#### 3.1.4 Custom Camera（自定义摄像机）

完全自定义的摄像机，所有参数均可自由调整，是制作动画时最常用的类型。

### 3.2 摄像机核心参数详解

#### 3.2.1 Zoom（缩放/焦距）

| 项目 | 详情 |
|------|------|
| **作用** | 控制摄像机的焦距，决定视角宽窄和透视强度 |
| **数值范围** | 1 ~ 10000 像素 |
| **默认值** | 取决于合成尺寸（约为合成宽度） |
| **单位** | 像素 |

**焦距与视角的关系：**

| 焦距类型 | Zoom值范围 | 视角 | 透视效果 |
|----------|-----------|------|----------|
| 超广角 | < 500px | > 90° | 极强透视，边缘变形 |
| 广角 | 500 ~ 1000px | 60° ~ 90° | 强透视，空间感强 |
| 标准 | 1000 ~ 2000px | 30° ~ 60° | 自然透视，人眼感 |
| 中长焦 | 2000 ~ 5000px | 10° ~ 30° | 弱透视，压缩空间 |
| 长焦 | > 5000px | < 10° | 极弱透视，扁平化 |

**等效焦距换算（35mm胶片）：**
```
等效焦距(mm) = 36mm × (Zoom / 合成宽度像素)
```

**视觉效果：**
- 短焦距（广角）：近大远小明显，空间延伸感强
- 长焦距（长焦）：空间压缩，前后物体大小接近

#### 3.2.2 Depth of Field（景深开关）

| 项目 | 详情 |
|------|------|
| **作用** | 开启/关闭景深效果 |
| **数值类型** | 开关（On/Off） |
| **默认值** | Off |

**景深效果说明：**
- 开启后，焦点距离处的物体最清晰
- 远离焦点的物体逐渐模糊
- 模拟真实相机的光学效果
- 增加真实感、突出主体、引导视线

> **注意**：景深会显著增加渲染时间，编辑时可暂时关闭以提高预览速度。

#### 3.2.3 Focus Distance（聚焦距离）

| 项目 | 详情 |
|------|------|
| **作用** | 设置摄像机到焦平面的距离 |
| **数值范围** | 1 ~ 100000 像素 |
| **默认值** | 与Zoom值相同 |
| **单位** | 像素 |

**详细说明：**
- 聚焦距离是从摄像机镜头到最清晰平面的距离
- 位于焦平面上的物体最清晰
- 焦平面前后的物体逐渐模糊
- 可动画化，实现焦点拉移（Rack Focus）效果

**快速设置方法：**
1. 选中摄像机图层
2. 按 `F` 展开Focus Distance
3. 按住 `Alt` 点击Focus Distance的数值
4. 用吸管工具点击合成窗口中需要对焦的图层

#### 3.2.4 Aperture（光圈）

| 项目 | 详情 |
|------|------|
| **作用** | 控制景深的强弱（模糊程度） |
| **数值范围** | 0 ~ 1000+ 像素 |
| **默认值** | 0（即无景深效果） |
| **单位** | 像素 |

**光圈与景深的关系：**

| Aperture值 | 景深效果 | 模糊程度 | 真实感 |
|------------|----------|----------|--------|
| 0 | 无景深 | 无模糊 | 2D感 |
| 10 ~ 30 | 极浅景深 | 轻微模糊 | 微妙自然 |
| 50 ~ 100 | 浅景深 | 中等模糊 | 突出主体 |
| 200 ~ 500 | 极浅景深 | 强烈模糊 | 戏剧化 |
| 500+ | 超浅景深 | 极度模糊 | 特效感 |

**与F值的换算：**
```
F值 = 焦距(Zoom) / 光圈(Aperture)
```

**真实相机参考：**
- F1.4 ~ F2.8：大光圈，浅景深
- F4 ~ F8：中等光圈，适中景深
- F11 ~ F22：小光圈，大景深

#### 3.2.5 Blur Level（模糊程度）

| 项目 | 详情 |
|------|------|
| **作用** | 调整景深模糊的整体强度（倍增器） |
| **数值范围** | 0% ~ 100%+ |
| **默认值** | 100% |

**使用场景：**
- 觉得Aperture调整不够精确时
- 需要快速减弱/增强景深效果
- 动画时微调模糊量

> **注意**：Blur Level是后期倍增，不会改变景深的物理特性，只改变模糊强度。

#### 3.2.6 Iris Shape（光圈形状）

| 项目 | 详情 |
|------|------|
| **作用** | 控制散景（Bokeh）的形状 |
| **数值类型** | 下拉选项 |
| **可选值** | `Polygon` / `Circle` |
| **默认值** | `Polygon` |

**形状说明：**
- **Polygon（多边形）**：模拟真实相机的光圈叶片形状，可设置边数
- **Circle（圆形）**：完美圆形散景，更理想化

#### 3.2.7 Iris Rotation（光圈旋转）

| 项目 | 详情 |
|------|------|
| **作用** | 旋转光圈形状的角度 |
| **数值范围** | 0° ~ 360° |
| **默认值** | 0° |
| **适用** | 仅Iris Shape为Polygon时有效 |

**应用：**
- 匹配真实镜头的光圈角度
- 创造特定的散景方向感
- 动画化产生旋转散景效果

#### 3.2.8 Iris Roundness（光圈圆度）

| 项目 | 详情 |
|------|------|
| **作用** | 控制多边形光圈的圆滑程度 |
| **数值范围** | 0% ~ 100% |
| **默认值** | 0% |
| **适用** | 仅Iris Shape为Polygon时有效 |

**效果说明：**
- 0%：完全多边形，棱角分明
- 50%：圆角多边形
- 100%：接近圆形

**真实感建议：**
- 模拟廉价镜头：0% ~ 20%（明显多边形）
- 模拟标准镜头：30% ~ 60%（轻微圆角）
- 模拟高端镜头：70% ~ 100%（接近圆形）

#### 3.2.9 Iris Aspect Ratio（光圈宽高比）

| 项目 | 详情 |
|------|------|
| **作用** | 控制光圈形状的宽高比（变形效果） |
| **数值范围** | 0.1 ~ 10.0 |
| **默认值** | 1.0（正圆形） |

**效果说明：**
- < 1.0：垂直方向拉伸（瘦长散景）
- = 1.0：正圆形（默认）
- \> 1.0：水平方向拉伸（宽扁散景）

**应用场景：**
- 模拟变形镜头（Anamorphic）效果（2.35:1，约2.35）
- 创造特殊视觉风格
- 模拟某些特殊镜头的散景特征

#### 3.2.10 Iris Diffraction Fringe（衍射条纹）

| 项目 | 详情 |
|------|------|
| **作用** | 模拟小光圈下的衍射条纹效果 |
| **数值范围** | 0% ~ 100% |
| **默认值** | 0% |

**物理原理：**
- 真实相机在小光圈（高F值）下，光线通过光圈边缘会产生衍射
- 衍射会在高光边缘产生彩色条纹
- 这是真实光学现象

**使用建议：**
- 模拟真实摄影效果时添加5% ~ 15%
- 过强（>30%）会显得不自然
- 配合高F值（小光圈）使用更真实

#### 3.2.11 Highlight Gain（高光增益）

| 项目 | 详情 |
|------|------|
| **作用** | 增强景深模糊中高光区域的亮度 |
| **数值范围** | 0% ~ 1000%+ |
| **默认值** | 100% |

**效果说明：**
- 真实相机中，散景高光通常比周围更亮
- Highlight Gain可以放大模糊区域的高光
- 创造更梦幻、更有氛围感的散景

**推荐值：**
- 自然效果：100% ~ 150%
- 梦幻效果：200% ~ 400%
- 极端效果：500%+

#### 3.2.12 Highlight Threshold（高光阈值）

| 项目 | 详情 |
|------|------|
| **作用** | 设定被视为"高光"的亮度阈值 |
| **数值范围** | 0% ~ 100% |
| **默认值** | 100% |

**详细说明：**
- 亮度高于此阈值的像素才会被当作高光处理
- 阈值越低，越多像素被视为高光
- 配合Highlight Gain使用

**调节技巧：**
- 降低阈值 → 更多区域产生高光散景
- 提高阈值 → 只有最亮的点产生高光散景
- 夜景/灯光场景：20% ~ 50%
- 一般场景：50% ~ 80%

#### 3.2.13 Highlight Saturation（高光饱和度）

| 项目 | 详情 |
|------|------|
| **作用** | 控制高光散景的色彩饱和度 |
| **数值范围** | 0% ~ 100%+ |
| **默认值** | 100% |

**效果说明：**
- 0%：高光散景为白色（去饱和）
- 100%：保留原始颜色
- \>100%：增强色彩饱和度

**应用：**
- 降低饱和度 → 更真实的散景（真实高光偏白）
- 提高饱和度 → 更梦幻、更有风格化效果

#### 3.4.3 多视图布局

## 四、灯光系统详解

灯光是3D合成中营造氛围、塑造体积感的关键元素。AE提供4种灯光类型，每种都有独特的光照特性。

### 4.1 灯光类型

#### 4.1.1 Parallel（平行光）

**特点：**
- 光线从无限远处发射，所有光线互相平行
- 光照强度不随距离衰减
- 阴影边界清晰（硬阴影）
- 模拟太阳光、月光等远距光源

**适用场景：**
- 室外日光场景
- 月光夜景
- 需要均匀硬阴影的场景
- 整体环境主光

**参数限制：**
- 无Cone Angle（锥形角度）
- 无Cone Feather（锥形羽化）
- 位置只影响方向，不影响光照强度

**光照示意图：**
```
    → → → → → → → → →  平行光线
    → → → → → → → → →
    → → → → → → → → →
    ───────────────────  物体
          ████
          ████  ← 均匀照射
          ████
```

#### 4.1.2 Spot（聚光灯）

**特点：**
- 从一个点向锥形方向发射光线
- 光照范围受Cone Angle控制
- 边缘可羽化（Cone Feather）
- 可产生柔和或锐利的阴影
- 最常用的灯光类型

**适用场景：**
- 舞台聚光灯
- 手电筒、车灯
- 重点照明（突出主体）
- 室内灯具模拟
- 电影级布光

**光照示意图：**
```
        ●  光源点
       ╱ ╲
      ╱   ╲
     ╱     ╲
    ╱  光照  ╲
   ╱   范围    ╲
  ╱             ╲
 ╱_______________╲
       物体
     ████████
```

**核心参数（详见4.2节）：**
- Cone Angle：锥形角度，控制照射范围
- Cone Feather：锥形羽化，控制边缘柔和度

#### 4.1.3 Point（点光源）

**特点：**
- 从一个点向所有方向发射光线（360度）
- 光照强度随距离衰减
- 阴影从光源点发散
- 模拟灯泡、蜡烛、星星等点光源

**适用场景：**
- 灯泡、蜡烛
- 夜景中的点点灯光
- 科幻场景中的发光体
- 室内环境补光

**光照示意图：**
```
          ●  光源点
        ╱ │ ╲
       ╱  │  ╲
      ╱   │   ╲
     ╱    │    ╲
    ╱ 光  │ 光  ╲
   ╱   照  │  照   ╲
  ╱        │        ╲
 ║         │         ║
 ║ 物体    │    物体  ║
 ║████     │     ████║
```

#### 4.1.4 Ambient（环境光）

**特点：**
- 无特定方向，均匀照亮整个场景
- 不产生阴影
- 无位置和方向属性
- 只影响物体的暗部亮度

**适用场景：**
- 提升整体亮度
- 减少暗部死黑
- 模拟环境反射光
- 调整画面基调

**使用注意：**
- 环境光过高会导致画面发灰、缺乏层次
- 建议配合其他灯光使用，强度不宜过高
- 通常设置为10% ~ 30%强度

**环境光对比：**
```
  无环境光              有环境光
  ┌─────────┐          ┌─────────┐
  │         │          │         │
  │ ████    │          │ ████    │
  │ ██░░    │          │ ██▒▒    │
  │ ░░░░    │          │ ▒▒▒▒    │
  └─────────┘          └─────────┘
  暗部纯黑              暗部有细节
  对比度高              对比度适中
```

### 4.2 灯光参数详解

#### 4.2.1 Intensity（强度）

| 项目 | 详情 |
|------|------|
| **作用** | 控制灯光的整体亮度 |
| **数值范围** | 0% ~ 1000%+ |
| **默认值** | 100% |
| 适用灯光类型 | 全部 |

**效果说明：**
- 0%：灯光关闭
- 100%：标准亮度
- 200%：亮度翻倍
- 负值：吸光（减去光线，制造阴影感）

**使用技巧：**
- 主光：100% ~ 150%
- 补光：30% ~ 60%
- 背光：80% ~ 120%
- 环境光：10% ~ 30%

#### 4.2.2 Color（颜色）

| 项目 | 详情 |
|------|------|
| **作用** | 控制灯光的颜色 |
| **默认值** | 白色 (#FFFFFF) |
| 适用灯光类型 | 全部 |

**色温参考：**

| 光源 | 色温 | 颜色倾向 |
|------|------|----------|
| 烛光 | 1500K | 暖红 |
| 钨丝灯 | 2800K ~ 3200K | 暖黄 |
| 暖白荧光 | 3500K | 暖白 |
| 日光 | 5500K ~ 6500K | 白色 |
| 阴天 | 6500K ~ 8000K | 冷白 |
| 蓝天阴影 | 9000K+ | 蓝色 |

**情绪与灯光颜色：**
- 暖色（红、橙、黄）：温暖、热情、怀旧、危险
- 冷色（蓝、青）：冷静、科技、忧伤、夜晚
- 绿色：诡异、科幻、病态
- 紫色：神秘、梦幻、奢华

#### 4.2.3 Cone Angle（锥形角度）

| 项目 | 详情 |
|------|------|
| **作用** | 控制聚光灯的照射范围角度 |
| **数值范围** | 0° ~ 180° |
| **默认值** | 90° |
| 适用灯光类型 | 仅Spot |

**角度与范围：**

| Cone Angle | 照射范围 | 用途举例 |
|------------|----------|----------|
| 10° ~ 20° | 极窄光束 | 追光灯、激光 |
| 30° ~ 45° | 窄光束 | 重点照明、射灯 |
| 60° ~ 90° | 中等范围 | 主光、常规照明 |
| 100° ~ 120° | 宽光束 | 环境光、泛光灯 |
| 150° ~ 180° | 极宽范围 | 接近半球照明 |

#### 4.2.4 Cone Feather（锥形羽化）

| 项目 | 详情 |
|------|------|
| **作用** | 控制聚光灯边缘的柔和过渡程度 |
| **数值范围** | 0% ~ 100% |
| **默认值** | 50% |
| 适用灯光类型 | 仅Spot |

**羽化效果：**

| Cone Feather | 边缘效果 | 适用场景 |
|--------------|----------|----------|
| 0% | 硬边，界限分明 | 投影、追光 |
| 20% | 轻微软化 | 射灯、舞台光 |
| 50%（默认） | 中等柔和 | 常规照明 |
| 80% | 非常柔和 | 环境补光 |
| 100% | 渐变到几乎无边缘 | 漫反射效果 |

#### 4.2.5 Falloff（衰减）

| 项目 | 详情 |
|------|------|
| **作用** | 控制灯光强度随距离衰减的方式 |
| **数值类型** | 下拉选项 |
| **可选值** | `None` / `Smooth` / `Inverse Square Clamped` |
| **默认值** | `None` |
| 适用灯光类型 | Spot、Point |

**衰减类型详解：**

| 衰减类型 | 特点 | 真实感 | 性能 |
|----------|------|--------|------|
| None（无衰减） | 强度不随距离变化 | 低 | 快 |
| Smooth（平滑衰减） | 自定义衰减曲线 | 中 | 中 |
| Inverse Square（平方反比） | 物理真实衰减 | 高 | 稍慢 |

**平方反比定律（物理真实）：**
```
光照强度 ∝ 1 / 距离²
```

即距离加倍，强度变为1/4；距离变为3倍，强度变为1/9。

#### 4.2.6 Radius（半径）

| 项目 | 详情 |
|------|------|
| **作用** | 设置灯光开始衰减的距离（仅Smooth衰减） |
| **数值范围** | 0 ~ 10000+ 像素 |
| **默认值** | 500 像素 |
| 适用灯光类型 | Spot、Point（Falloff=Smooth时） |

#### 4.2.7 Falloff Distance（衰减距离）

| 项目 | 详情 |
|------|------|
| **作用** | 设置灯光完全衰减到0的距离（仅Smooth衰减） |
| **数值范围** | 0 ~ 10000+ 像素 |
| **默认值** | 1500 像素 |
| 适用灯光类型 | Spot、Point（Falloff=Smooth时） |

**Smooth衰减曲线：**
```
强度
100%┼───────┐
    │       ┐
    │        ┐
    │         ┐
  0%┼──────────┼───── 距离
    0        衰减距离
    (Radius) (Falloff Dist)
```

#### 4.2.8 Shadow Darkness（阴影暗度）

| 项目 | 详情 |
|------|------|
| **作用** | 控制灯光投射阴影的暗度 |
| **数值范围** | 0% ~ 100% |
| **默认值** | 100% |
| 适用灯光类型 | Parallel、Spot、Point |

**效果说明：**
- 100%：完全黑暗的阴影（最真实）
- 50%：半透明阴影
- 0%：无阴影（等同于关闭阴影）

**使用场景：**
- 强烈日光：80% ~ 100%（阴影浓重）
- 阴天/室内：30% ~ 60%（阴影柔和）
- 多光源场景：20% ~ 40%（阴影被补光冲淡）

#### 4.2.9 Shadow Diffusion（阴影扩散）

| 项目 | 详情 |
|------|------|
| **作用** | 控制阴影边缘的柔和程度（阴影模糊） |
| **数值范围** | 0 ~ 1000+ 像素 |
| **默认值** | 0 像素 |
| 适用灯光类型 | Parallel、Spot、Point |

**效果对比：**

| Shadow Diffusion | 阴影效果 | 光源类型模拟 |
|------------------|----------|-------------|
| 0px | 硬边阴影 | 小光源、太阳光 |
| 5 ~ 20px | 轻微柔和 | 灯泡、射灯 |
| 50 ~ 100px | 柔和阴影 | 大光源、柔光箱 |
| 200px+ | 极柔阴影 | 天光、阴天 |

> **注意**：Shadow Diffusion会增加渲染时间，值越高渲染越慢。

### 4.3 三点布光法

三点布光是影视、摄影、三维中最经典的布光方案，通过三个不同角度的光源塑造主体的立体感。

#### 4.3.1 三灯位置示意

```
                    背光 (Back Light)
                        ●
                       ╱ ╲
                      ╱   ╲
                     ╱     ╲
                    ╱ 主体   ╲
                   ╱  ████    ╲
                  ╱            ╲
  主光 (Key Light) ●            ○ 补光 (Fill Light)
```

#### 4.3.2 各灯作用与参数

**1. 主光（Key Light）**

| 项目 | 说明 |
|------|------|
| **作用** | 主要照明，决定画面主基调、阴影方向 |
| **位置** | 主体侧前方45°，略高于主体 |
| **强度** | 100% ~ 150%（最强光） |
| **类型** | Spot 或 Parallel |
| **阴影** | 开启，Shadow Darkness 80% ~ 100% |
| **颜色** | 主色调（日光白、暖黄等） |

**2. 补光（Fill Light）**

| 项目 | 说明 |
|------|------|
| **作用** | 照亮主光形成的阴影，减少对比度 |
| **位置** | 主光对侧，高度略低于主光 |
| **强度** | 30% ~ 60%（主光的1/2 ~ 1/3） |
| **类型** | Spot 或 Point |
| **阴影** | 通常关闭 |
| **颜色** | 与主光同色系或略冷 |

**3. 背光（Back Light / Rim Light）**

| 项目 | 说明 |
|------|------|
| **作用** | 照亮主体边缘，将主体从背景分离，增强立体感 |
| **位置** | 主体后方，略高于主体 |
| **强度** | 80% ~ 120% |
| **类型** | Spot |
| **阴影** | 通常关闭 |
| **颜色** | 常偏冷色（与主光形成对比） |

#### 4.3.3 光比与情绪

**光比（主光强度 : 补光强度）：**

| 光比 | 对比度 | 情绪效果 | 适用场景 |
|------|--------|----------|----------|
| 1:1 | 极低 | 平淡、柔和 | 儿童、美妆 |
| 2:1 | 低 | 柔和、自然 | 访谈、宣传片 |
| 4:1 | 中 | 正常、立体 | 常规产品展示 |
| 8:1 | 高 | 戏剧、硬朗 | 电影感、硬汉 |
| 16:1 | 极高 | 强烈、神秘 | 悬疑、恐怖片 |

### 4.4 布光方案

#### 4.4.1 电影级布光

## 五、阴影系统

阴影是3D合成中增强真实感和空间感的关键元素。AE提供了完整的阴影系统，支持多种阴影类型和参数控制。

### 5.1 阴影工作原理

#### 5.1.1 阴影生成条件

要在AE中产生阴影，需要满足以下全部条件：

```
条件1：图层启用3D模式
    ↓
条件2：灯光存在且开启阴影投射
    ↓
条件3：投射阴影图层 Casts Shadows = On/Only
    ↓
条件4：接受阴影图层 Accepts Shadows = On
    ↓
条件5：渲染器支持阴影（Classic 3D / Ray-traced 3D）
```

#### 5.1.2 阴影的构成

```
         ● 光源
        ╱ ╲
       ╱   ╲
      ╱ 物体 ╲
     ╱  ████  ╲
    ╱          ╲
   ╱            ╲
  ╱ ░░░░░░░░░░░░ ╲
 ╱  本影 (Umbra)   ╲
╱░▒▒▒▒▒▒▒▒▒▒▒▒▒░╲
   半影 (Penumbra)

本影：完全遮挡，最暗的区域
半影：部分遮挡，边缘过渡区域
```

- **本影（Umbra）**：光源完全被遮挡的区域，阴影最暗
- **半影（Penumbra）**：光源部分被遮挡的区域，阴影边缘渐变
- 半影大小与光源大小、Shadow Diffusion参数相关

### 5.2 阴影类型

#### 5.2.1 Classic 3D 阴影

**特点：**
- AE传统的阴影渲染方式
- 基于深度图（Depth Map）生成阴影
- 渲染速度较快
- 阴影质量中等

**优势：**
- 渲染速度快
- 兼容性好
- 性能消耗低

**局限：**
- 阴影边缘可能有锯齿
- 不支持透明物体阴影
- 自阴影效果差
- 不支持光线反弹（间接照明）

#### 5.2.2 Ray-traced 3D 阴影

**特点：**
- 基于光线追踪技术
- 物理真实的阴影效果
- 支持透明、反射、折射
- 渲染质量最高

**优势：**
- 阴影质量极高，边缘平滑
- 支持透明物体的彩色阴影
- 正确的自阴影
- 支持面光源产生的软阴影

**局限：**
- 渲染速度慢（比Classic 3D慢3~10倍）
- 需要GPU加速
- 内存消耗大

#### 5.2.3 渲染器切换方法

1. `File` → `Project Settings...`
2. `Expressions & 3D` 标签页
3. 3D Renderer 下拉选择：
   - **Classic 3D**（默认，快速）
   - **Ray-traced 3D**（高质量）

> AE 2026中还新增了 **Advanced 3D** 渲染器，在质量和速度之间取得平衡。

### 5.3 阴影参数详解

#### 5.3.1 灯光层面的阴影控制

| 参数 | 说明 | 数值范围 | 默认值 |
|------|------|----------|--------|
| Casts Shadows | 灯光是否投射阴影 | On/Off | On |
| Shadow Darkness | 阴影暗度 | 0% ~ 100% | 100% |
| Shadow Diffusion | 阴影扩散（柔和度） | 0 ~ 1000+ px | 0px |

#### 5.3.2 图层层面的阴影控制

| 参数 | 说明 | 数值范围 | 默认值 |
|------|------|----------|--------|
| Casts Shadows | 图层是否投射阴影 | Off/On/Only | Off |
| Accepts Shadows | 图层是否接受阴影 | Off/On | On |

#### 5.3.3 合成层面的阴影质量

在 `Composition Settings` → `Advanced` 中：

| 参数 | 说明 |
|------|------|
| 3D Renderer | 选择渲染器类型 |
| Ray-traced Quality | 光线追踪质量（1 ~ 12） |
| Anti-aliasing | 抗锯齿设置 |

### 5.4 阴影质量设置

#### 5.4.1 Classic 3D 阴影质量优化

**提高阴影质量的方法：**

1. **调整阴影贴图分辨率**
   - 在 `Project Settings` 中调整
   - 分辨率越高，阴影越清晰
   - 但渲染更慢、内存占用更大

2. **使用Shadow Diffusion柔化边缘**
   - 硬边锯齿可通过轻微扩散掩盖
   - 推荐值：2 ~ 5px（轻微柔化，不明显损失清晰度）

3. **调整图层精度**
   - 右键图层 → `Quality` → `Best`
   - 高质量模式下阴影更精确

#### 5.4.2 Ray-traced 3D 阴影质量

| Quality级别 | 光线数量 | 质量 | 速度 | 适用阶段 |
|-------------|----------|------|------|----------|
| 1 | 少 | 低 | 极快 | 草稿预览 |
| 3 | 较少 | 较低 | 快 | 快速预览 |
| 6（默认） | 中 | 中 | 中 | 工作预览 |
| 9 | 较多 | 高 | 慢 | 最终检查 |
| 12 | 多 | 极高 | 极慢 | 最终渲染 |

**抗锯齿（Anti-aliasing）设置：**
- **Off**：无抗锯齿，最快
- **Low**：低质量抗锯齿
- **Medium**：中等质量（推荐）
- **High**：高质量抗锯齿，最慢

### 5.5 优化阴影渲染速度

#### 5.5.1 通用优化技巧

| 优化方法 | 效果 | 代价 |
|----------|------|------|
| 关闭不需要的阴影 | 大幅加速 | 无（正确配置时） |
| 减少阴影投射图层数量 | 大幅加速 | 场景限制 |
| 降低Shadow Diffusion值 | 中等加速 | 阴影变硬 |
| 使用Classic 3D渲染器 | 大幅加速 | 质量降低 |
| 降低光线追踪质量 | 大幅加速 | 噪点增加 |
| 使用代理预览 | 大幅加速 | 画质降低 |
| 关闭预览时的阴影 | 大幅加速 | 预览无阴影 |

#### 5.5.2 预览时临时关闭阴影

**方法一：单独关闭灯光阴影**
1. 选中灯光图层
2. 按 `AA` 展开灯光选项
3. 将 `Casts Shadows` 设为 `Off`

**方法二：使用调整预览设置**
- 合成窗口底部 → `Fast Previews` 按钮
- 选择 `Off`（关闭硬件加速）或调整设置

**方法三：使用图层 Solo 功能**
- 单独预览某个图层时，阴影自动不计算

#### 5.5.3 渲染优化清单

- [ ] 只给必要的图层开启 Casts Shadows
- [ ] 只给必要的灯光开启阴影
- [ ] 地面/背景只开 Accepts Shadows，不开 Casts Shadows
- [ ] Shadow Diffusion 不超过必要值
- [ ] 使用适当的渲染器和质量设置

## 六、摄像机运动类型与实战

摄像机运动是动态设计中最重要的表现手法之一。本章详解10种经典摄像机运动类型，包含原理、实现、参数和表达式。

### 6.1 Dolly Zoom（推拉变焦/眩晕效果）

#### 6.1.1 原理

Dolly Zoom（又称Vertigo Effect、Zolly）是一种经典电影技巧：**摄像机前后移动的同时反向调整焦距**，使主体大小保持不变，但背景透视发生剧烈变化，产生眩晕、扭曲、不安的视觉效果。

**核心原理公式：**
```
保持主体视觉大小不变 → 移动距离 / 焦距变化 = 恒定比例
```

**视觉效果：**
- 主体大小不变
- 背景透视被压缩/拉伸
- 空间感扭曲
- 心理感受：眩晕、不安、震撼、强调

#### 6.1.2 实现步骤

**方法一：关键帧手动制作**

```
步骤1：设置起始状态
  - 摄像机Position Z = 0
  - 摄像机Zoom = 1000
  - 确认主体在画面中大小合适

步骤2：设置结束状态（第N帧）
  - 摄像机Position Z = -500（后移，远离主体）
  - 摄像机Zoom = 1500（增加焦距，拉近主体）
  - 调整数值使主体大小与起始一致

步骤3：添加关键帧
  - Position和Zoom都设置关键帧
  - 调整缓动曲线（Easy Ease）
```

**方法二：表达式自动计算（推荐）**

在Zoom属性上添加表达式：
```javascript
// 保持主体视觉大小不变的Dolly Zoom表达式
// 主体图层名称："Subject"
subjectZ = thisComp.layer("Subject").transform.position[2];
cameraZ = transform.position[2];
distance = subjectZ - cameraZ;

// 基准焦距和距离（根据需要调整）
baseFocalLength = 1000; // 基准焦距
baseDistance = 1000;    // 基准距离

// 计算需要的焦距以保持主体大小不变
baseFocalLength * distance / baseDistance
```

#### 6.1.3 参数表

| 参数 | 起始值 | 结束值 | 说明 |
|------|--------|--------|------|
| 摄像机Position Z | 0 px | -800 px | 后移800像素 |
| 摄像机Zoom | 1000 px | 1800 px | 焦距增加 |
| 时长 | 2秒 | - | 变化周期 |
| 缓动 | Easy Ease In/Out | - | 平滑过渡 |
| 强度比例 | 1 : 1.8 | - | 移动:焦距变化比 |

**强度参考：**

| 效果强度 | 移动距离 | 焦距变化比 | 适用场景 |
|----------|----------|-----------|----------|
| 微妙 | 200px | 1.2倍 | 情感暗示 |
| 中等 | 500px | 1.5倍 | 一般强调 |
| 强烈 | 1000px | 2.0倍 | 戏剧转折 |
| 极端 | 2000px+ | 3.0倍+ | 眩晕/恐怖 |

#### 6.1.4 应用场景

1. **心理表现**：角色震惊、发现真相、眩晕
2. **空间扭曲**：梦境、幻觉、超现实场景
3. **强调主体**：重要时刻、关键物体
4. **转场效果**：场景切换、时间流逝
5. **恐怖氛围**：不安、压迫感

### 6.2 Ken Burns（缓慢推拉）

#### 6.2.1 原理

Ken Burns效果得名于纪录片导演Ken Burns，指对静态照片进行**缓慢的移动和缩放**，赋予照片动感和生命力。

**核心要素：**
- 缓慢移动（Position动画）
- 缓慢缩放（Scale动画）
- 长时长（3~10秒）
- 平滑运动（无突变）

#### 6.2.2 实现方法

**标准Ken Burns制作步骤：**
```
1. 导入照片，启用3D图层
2. 放大照片（Scale = 120% ~ 150%），留出动量空间
3. 设置起始关键帧（第0帧）：
   - Position：画面偏左，Scale = 120%
4. 设置结束关键帧（第5秒）：
   - Position：画面偏右，Scale = 140%
5. 全选关键帧，按F9添加Easy Ease
6. 调整曲线为极缓的S曲线
```

#### 6.2.3 参数参考

| 运动类型 | 移动距离 | 缩放变化 | 时长 | 应用 |
|----------|----------|----------|------|------|
| 缓慢推入 | 很小 | 100% → 120% | 5~10s | 强调主体 |
| 缓慢拉出 | 很小 | 120% → 100% | 5~10s | 展示环境 |
| 横移 | 画面宽度20% | 无变化 | 5~8s | 展示全景 |
| 左移推近 | 左移+放大 | +20% | 4~6s | 从环境到主体 |
| 右移拉远 | 右移+缩小 | -15% | 4~6s | 从主体到环境 |

#### 6.2.4 多照片Ken Burns序列

```
照片1: 推入+左移 (0~5s)
    ↓ 交叉溶解转场 (0.5s)
照片2: 拉出+右移 (4.5~9.5s)
    ↓ 交叉溶解转场 (0.5s)
照片3: 横移+微缩放 (9~14s)
```

### 6.3 Orbital Camera（环绕拍摄）

#### 6.3.1 原理

摄像机围绕主体做**圆周运动**，可以全方位展示物体的立体感。常用于产品展示、角色介绍、Logo演绎。

**几何原理：**
```
      摄像机运动轨迹
      ╭───────╮
     ╱         ╲
    │   主体    │  ← 摄像机始终看向主体
    │   ●      │
     ╲         ╱
      ╰───────╯
```

#### 6.3.2 实现方法

**方法一：Null Object + 父子关系**

```
步骤1：创建Null Object（命名为"Orbit Control"）
  - 位置在主体中心

步骤2：将摄像机设为Null的子图层
  - 摄像机Position设为 (半径, 0, 0)

步骤3：给Null的Y Rotation添加关键帧
  - 起始：0°
  - 结束：360°
```

**方法二：表达式 + lookAt（推荐）**

摄像机Orientation表达式：
```javascript
// 摄像机始终看向主体
target = thisComp.layer("Subject").transform.position;
lookAt(transform.position, target)
```

摄像机Position表达式（环绕运动）：
```javascript
// 环绕主体的圆周运动
target = thisComp.layer("Subject").transform.position;
radius = 500;          // 环绕半径
speed = 0.5;           // 速度（圈/秒）
height = 100;          // 高度偏移

angle = time * speed * Math.PI * 2;

x = target[0] + Math.cos(angle) * radius;
y = target[1] + height;
z = target[2] + Math.sin(angle) * radius;

[x, y, z]
```

#### 6.3.3 参数表

| 参数 | 数值 | 说明 |
|------|------|------|
| 环绕半径 | 300 ~ 1000 px | 离主体的距离 |
| 环绕速度 | 0.1 ~ 1 圈/秒 | 旋转速度 |
| 高度偏移 | -200 ~ 200 px | 摄像机俯仰角度 |
| 俯仰角度 | -30° ~ 30° | 俯视/仰视 |

**环绕变体：**

| 变体 | 特点 | 实现 |
|------|------|------|
| 正圆环绕 | 匀速圆周运动 | 标准表达式 |
| 椭圆环绕 | X/Z轴半径不同 | radiusX, radiusZ分开设置 |
| 螺旋上升 | 半径不变，高度增加 | Y随时间增加 |
| 螺旋下降 | 半径不变，高度减少 | Y随时间减少 |
| 螺旋进入 | 半径减小，高度不变 | radius随时间减小 |
| 8字环绕 | 8字形轨迹 | Lissajous曲线 |

### 6.4 Fly-Through（穿越飞行）

#### 6.4.1 原理

摄像机沿Z轴快速移动，穿越多层3D空间，产生强烈的空间穿梭感。

**核心要素：**
- 多层3D图层，沿Z轴分布
- 摄像机高速Z轴运动
- 视差效果（近快远慢）
- 运动模糊

#### 6.4.2 实现步骤

```
步骤1：创建多层空间
  - 近景层：Z = -200
  - 中景层：Z = -800
  - 远景层：Z = -2000
  - 背景层：Z = -5000

步骤2：设置摄像机动画
  - 起始：Position Z = 500
  - 结束：Position Z = -6000
  - 时长：3 ~ 5秒

步骤3：增强效果
  - 开启运动模糊
  - 添加速度模糊（可选）
  - 配合音效（嗖嗖声）
```

#### 6.4.3 参数参考

| 参数 | 数值 | 说明 |
|------|------|------|
| 起始Z位置 | 500 px | 摄像机初始位置 |
| 结束Z位置 | -6000 px | 摄像机最终位置 |
| 穿越距离 | 6500 px | 总移动距离 |
| 时长 | 3 ~ 5 秒 | 穿越时间 |
| 速度 | 1300 ~ 2200 px/s | 平均速度 |

**速度与感受：**
- 慢速（< 500px/s）：悠闲、探索感
- 中速（500~1500px/s）：动感、穿越感
- 快速（1500~3000px/s）：刺激、高速感
- 极速（>3000px/s）：眩晕、超空间

### 6.5 J-Cut / L-Cut（音频先/画面先）

#### 6.5.1 原理

这是剪辑技巧与摄像机运动的配合：

- **J-Cut（J形剪辑）**：音频先入，画面后切。声音先出现，画面再跟上。
- **L-Cut（L形剪辑）**：画面先切，音频延后。画面先走，声音延续。

**与摄像机运动的配合：**
- J-Cut配合推镜：先听到声音，再推到声源
- L-Cut配合拉镜：画面拉开，声音还在

### 6.6 Shake（震动效果）

#### 6.6.1 原理

使用`wiggle()`表达式产生随机震动，模拟地震、爆炸、手持效果等。

#### 6.6.2 表达式示例

**基础位移震动：**
```javascript
// 位置震动
// freq: 震动频率（次/秒）
// amp: 震动幅度（像素）
wiggle(5, 20)
```

**三轴分离控制：**
```javascript
// X/Y轴震动，Z轴不震动
freq = 5;
amp = 20;
w = wiggle(freq, amp);
[w[0], w[1], transform.position[2]]
```

**旋转震动：**
```javascript
// Z轴旋转震动（摇晃）
wiggle(3, 2) // 在Rotation Z上使用
```

**缩放震动：**
```javascript
// 轻微缩放震动（冲击感）
freq = 10;
amp = 5; // 百分比
wiggle(freq, amp)
```

**衰减震动（爆炸后逐渐停止）：**
```javascript
// 随时间衰减的震动
freq = 20;
amp = 50;
decayTime = 1; // 衰减时间（秒）
decay = Math.exp(-time * decayTime);
wiggle(freq, amp * decay)
```

**定向震动（只在某方向）：**
```javascript
// 只在X轴方向震动（左右晃）
freq = 8;
amp = 30;
w = wiggle(freq, amp);
[w[0], transform.position[1], transform.position[2]]
```

#### 6.6.3 震动类型参数表

| 震动类型 | 频率 | 幅度 | 应用场景 |
|----------|------|------|----------|
| 微震（手持） | 2 ~ 5 Hz | 2 ~ 10 px | 纪录片、手持感 |
| 中等震动 | 5 ~ 10 Hz | 10 ~ 30 px | 爆炸近景、撞击 |
| 强震 | 10 ~ 20 Hz | 30 ~ 80 px | 地震、大爆炸 |
| 极震 | 20 ~ 50 Hz | 80 ~ 200 px | 灾难、极端冲击 |
| 旋转摇晃 | 1 ~ 3 Hz | 1° ~ 5° | 晕船、醉酒 |
| 缩放脉冲 | 5 ~ 15 Hz | 2% ~ 10% | 心跳、冲击反馈 |

### 6.7 Zoom Burst（变焦爆发）

#### 6.7.1 原理

极速改变焦距，配合径向模糊，产生强烈的冲击爆发效果。常用于：强调、转场、打击感。

#### 6.7.2 实现方法

**方法一：纯摄像机Zoom动画**
```
第0帧: Zoom = 500（广角）
第2帧: Zoom = 3000（长焦）
第10帧: Zoom = 1500（恢复正常）
```

**方法二：配合径向模糊效果（推荐）**
```
1. 调整图层添加CC Radial Fast Blur或径向模糊
2. 模糊量动画：
   - 起始：0
   - 冲击帧：100（最大模糊）
   - 结束：0
3. 与Zoom动画同步
```

### 6.8 Pan & Scan（横移扫描）

#### 6.8.1 原理

摄像机沿水平或垂直方向平移，扫描场景。常用于：宽银幕展示、全景浏览、字幕滚动。

#### 6.8.2 实现

**横移（Pan）：**
- 摄像机X轴位移动画
- 保持Z轴和Y轴不变

**竖移（Tilt）：**
- 摄像机Y轴位移动画
- 保持X轴和Z轴不变

### 6.9 Rotation Burst（旋转爆发）

#### 6.9.1 原理

摄像机极速旋转，配合运动模糊，产生眩晕、冲击效果。

#### 6.9.2 表达式示例

```javascript
// 爆发式旋转（快速旋转然后减速）
startTime = 1; // 开始时间
duration = 0.5; // 持续时间
maxSpeed = 720; // 最大速度（度/秒）

if (time < startTime) {
  value
} else {
  t = time - startTime;
  // 减速曲线
  speedFactor = Math.max(0, 1 - t / duration);
  angle = maxSpeed * t * speedFactor;
  value + angle
}
```

### 6.10 Multi-Camera Switch（多摄像机切换）

#### 6.10.1 原理

创建多台摄像机，通过表达式或关键帧切换活动视角，模拟多机位拍摄。

#### 6.10.2 实现方法

**方法一：使用摄像机选择器表达式**

在一个主控摄像机的Position上：
```javascript
// 多摄像机切换
// 根据标记切换摄像机视角
cam1 = thisComp.layer("Camera 1").transform.position;
cam2 = thisComp.layer("Camera 2").transform.position;
cam3 = thisComp.layer("Camera 3").transform.position;

// 获取当前最近的标记
markerName = marker.nearestKey(time).comment;

if (markerName == "cam2") {
  cam2;
} else if (markerName == "cam3") {
  cam3;
} else {
  cam1;
}
```

**方法二：使用时间重映射或调整图层**
- 预合成整个场景
- 使用时间重映射选择不同时间点（不同摄像机视角）

## 七、景深（Depth of Field）高级技巧

景深是3D合成中提升真实感和艺术感的重要手段。本章深入探讨景深的原理、参数调节和高级应用。

### 7.1 景深原理

#### 7.1.1 物理原理

景深是指画面中清晰成像的前后距离范围。

**影响景深的三要素：**

| 因素 | 增大 → 景深变化 | 减小 → 景深变化 |
|------|----------------|----------------|
| 光圈（Aperture） | 减小（更浅） | 增大（更深） |
| 焦距（Focal Length） | 减小（更浅） | 增大（更深） |
| 拍摄距离（Focus Distance） | 增大（更深） | 减小（更浅） |

**景深计算公式（简化）：**
```
景深 ≈ 2 × (距离²) × 光圈系数 × 弥散圆 / 焦距²
```

> 简单记忆：**光圈越大、焦距越长、距离越近，景深越浅。**

#### 7.1.2 AE中的景深实现

AE的景深基于以下原理：
1. 计算每个像素到摄像机的距离
2. 根据距离和聚焦距离的差值计算模糊量
3. 根据光圈形状和参数渲染模糊效果
4. 高光部分特殊处理（Highlight Gain等）

### 7.2 景深参数详解与调节

#### 7.2.1 核心参数关系

```
景深模糊程度 = 距离偏差 × 光圈大小 / 焦距
```

**各参数的作用：**

| 参数 | 增大效果 | 减小效果 |
|------|----------|----------|
| Aperture（光圈） | 模糊增强，景深更浅 | 模糊减弱，景深更深 |
| Focus Distance（聚焦距离） | 焦平面后移 | 焦平面前移 |
| Blur Level（模糊级别） | 模糊倍增 | 模糊减弱 |
| Zoom（焦距） | 景深变浅，视角变窄 | 景深变深，视角变宽 |

#### 7.2.2 调节流程建议

```
1. 确定构图和焦距
   ↓
2. 开启Depth of Field
   ↓
3. 设置Focus Distance（对焦到主体）
   ↓
4. 调整Aperture（控制景深大小）
   ↓
5. 微调Blur Level（整体强度）
   ↓
6. 设置散景参数（Iris系列）
   ↓
7. 调整高光参数（Highlight系列）
```

### 7.3 散景（Bokeh）效果设置

#### 7.3.1 散景形状控制

散景是指画面中失焦的高光点形成的光斑形状，由光圈形状决定。

| Iris Shape设置 | 散景效果 | 模拟镜头 |
|----------------|----------|----------|
| Polygon + 6边 + 0% Roundness | 六边形 | 标准6叶片光圈 |
| Polygon + 8边 + 30% Roundness | 圆角八边形 | 高端8叶片镜头 |
| Polygon + 9边 + 50% Roundness | 接近圆形 | 电影镜头 |
| Circle | 完美圆形 | 理想镜头/折返镜头 |

#### 7.3.2 散景风格设置

**电影感散景：**
```
Iris Shape: Polygon
Iris Roundness: 30%
Iris Rotation: 15°
Iris Aspect Ratio: 1.0
Highlight Gain: 150%
Highlight Saturation: 80%
```

**变形镜头散景（Anamorphic）：**
```
Iris Shape: Circle
Iris Aspect Ratio: 2.35
Highlight Gain: 200%
Highlight Threshold: 30%
```

**梦幻散景：**
```
Iris Shape: Circle
Iris Roundness: 100%
Highlight Gain: 300%
Highlight Saturation: 120%
Highlight Threshold: 20%
```

### 7.4 景深表达式控制

#### 7.4.1 自动对焦表达式

**跟随特定图层对焦：**
```javascript
// 自动对焦到"Target"图层
target = thisComp.layer("Target").transform.position;
cameraPos = thisLayer.transform.position;

// 计算距离
distance = length(target, cameraPos);
distance
```

#### 7.4.2 平滑焦点过渡

```javascript
// 焦点在两个图层之间平滑过渡
target1 = thisComp.layer("Target 1").transform.position;
target2 = thisComp.layer("Target 2").transform.position;
cameraPos = thisLayer.transform.position;

dist1 = length(target1, cameraPos);
dist2 = length(target2, cameraPos);

// 过渡时间点（秒）
transitionTime = 2;
blend = ease(time, 1, 1 + transitionTime, 0, 1);

linear(blend, dist1, dist2)
```

### 7.5 焦点拉移（Rack Focus）技巧

#### 7.5.1 原理

焦点从一个物体移动到另一个物体，引导观众视线，是电影语言的重要手法。

#### 7.5.2 实现步骤

```
1. 确定两个对焦点（前景/后景）
   - 记录各自的Focus Distance值

2. 设置焦点关键帧
   - 第0帧：Focus Distance = 前景距离
   - 第2秒：Focus Distance = 后景距离

3. 调整曲线
   - 使用Easy Ease
   - 或自定义曲线：先快后慢 / 先慢后快
```

#### 7.5.3 焦点拉移的节奏

| 拉移速度 | 时长 | 效果 |
|----------|------|------|
| 快速 | 0.5 ~ 1 秒 | 干脆、有力、强调 |
| 中速 | 1 ~ 2 秒 | 自然、平滑 |
| 慢速 | 3 ~ 5 秒 | 抒情、缓慢揭示 |

### 7.6 景深与叙事

#### 7.6.1 引导视线

景深最直接的作用是**引导观众视线**：
- 清晰的区域 = 观众应该看的地方
- 模糊的区域 = 次要信息

**应用：**
- 对话场景：焦点在说话者身上
- 揭示场景：焦点从前景移到后景
- 主观镜头：模拟人眼对焦

#### 7.6.2 突出主体

浅景深可以**将主体从背景中分离**：
- 背景虚化 → 主体更突出
- 减少背景干扰
- 增强画面层次感

#### 7.6.3 营造氛围

不同的景深营造不同氛围：

| 景深类型 | 氛围 | 适用场景 |
|----------|------|----------|
| 极浅景深 | 梦幻、浪漫、主观 | 爱情片、MV、回忆 |
| 浅景深 | 电影感、专注 | 剧情片、人物特写 |
| 中等景深 | 自然、真实 | 纪录片、访谈 |
| 大景深 | 客观、宏大 | 风景、建筑、群戏 |

## 八、视差滚动（Parallax）与空间层次

视差是利用不同深度图层的移动速度差异来模拟3D空间感的技术，是AE中最常用的伪3D效果。

### 8.1 视差原理

#### 8.1.1 基本原理

```
视差速度 ∝ 1 / 深度

深度越深（越远） → 移动越慢
深度越浅（越近） → 移动越快
```

**示例（摄像机水平移动100px）：**

| 图层 | Z轴深度 | 相对位移量 | 移动量 |
|------|---------|-----------|--------|
| 极前景 | -100px | 2.0倍 | 200px |
| 前景 | -300px | 1.4倍 | 140px |
| 主体 | -500px | 1.0倍 | 100px |
| 中景 | -1000px | 0.5倍 | 50px |
| 背景 | -2000px | 0.25倍 | 25px |
| 远背景 | -5000px | 0.1倍 | 10px |

#### 8.1.2 视差的类型

| 类型 | 运动方式 | 效果 |
|------|----------|------|
| 横向视差 | 摄像机左右移动 | 水平视差 |
| 纵向视差 | 摄像机上下移动 | 垂直视差 |
| 推近视差 | 摄像机向前移动 | 放大差异 |
| 拉远视差 | 摄像机向后移动 | 缩小差异 |
| 旋转视差 | 摄像机环绕移动 | 全方位视差 |

### 8.2 7层空间层次法

经典的7层空间分层法，每层有不同的Z轴位置和作用，共同构成丰富的空间感。

#### 8.2.1 七层结构示意

```
观察者 →
  ① 极前景层 (Extreme FG)   ← 最近，最快
  ② 前景层 (FG)
  ③ 近景层 (Near FG)
  ④ 主体层 (Subject)        ← 焦平面
  ⑤ 中景层 (Mid)
  ⑥ 背景层 (BG)
  ⑦ 远背景层 (Far BG)       ← 最远，最慢
```

#### 8.2.2 各层详细参数

**第1层：极前景层（Extreme FG）**

| 参数 | 数值范围 | 作用 |
|------|----------|------|
| Z轴位置 | -50 ~ -150 px | 最近的装饰元素 |
| 缩放 | 150% ~ 200% | 因近而大 |
| 透明度 | 20% ~ 50% | 轻微遮挡，不抢戏 |
| 模糊 | 强模糊（失焦） | 模拟景深前景虚化 |
| 移动速度 | 2.0 ~ 3.0倍 | 移动最快 |
| 占屏面积 | < 30% | 边缘装饰 |

**典型元素：**
- 树叶、花瓣
- 玻璃上的水滴
- 镜头污渍
- 前景物体的边缘

**第2层：前景层（FG）**

| 参数 | 数值范围 | 作用 |
|------|----------|------|
| Z轴位置 | -200 ~ -400 px | 前景主体装饰 |
| 缩放 | 130% ~ 160% | 较大 |
| 透明度 | 40% ~ 80% | 半透明或边缘虚化 |
| 模糊 | 中等模糊 | 轻微失焦 |
| 移动速度 | 1.5 ~ 2.0倍 | 较快 |

**典型元素：**
- 门框、窗户
- 前景人物剪影
- 树枝、植物
- 建筑结构

**第3层：近景层（Near FG）**

| 参数 | 数值范围 | 作用 |
|------|----------|------|
| Z轴位置 | -400 ~ -450 px | 靠近主体的前景 |
| 缩放 | 110% ~ 130% | 略大 |
| 透明度 | 60% ~ 100% | 较清晰 |
| 模糊 | 轻微模糊 | 接近焦平面 |
| 移动速度 | 1.1 ~ 1.3倍 | 略快于主体 |

**典型元素：**
- 主体周围的道具
- 近景装饰
- 互动元素

**第4层：主体层（Subject）**

| 参数 | 数值范围 | 作用 |
|------|----------|------|
| Z轴位置 | -500 px（基准） | 画面焦点，最清晰 |
| 缩放 | 100% | 标准大小 |
| 透明度 | 100% | 完全清晰 |
| 模糊 | 无（最清晰） | 焦平面 |
| 移动速度 | 1.0倍（基准） | 标准速度 |

**典型元素：**
- 主要角色
- 核心产品
- 标题文字
- 画面主体

**第5层：中景层（Mid）**

| 参数 | 数值范围 | 作用 |
|------|----------|------|
| Z轴位置 | -700 ~ -1500 px | 主体后面的空间 |
| 缩放 | 60% ~ 85% | 较小 |
| 透明度 | 80% ~ 100% | 清晰 |
| 模糊 | 轻微 ~ 中等模糊 | 开始失焦 |
| 移动速度 | 0.4 ~ 0.7倍 | 较慢 |

**典型元素：**
- 背景建筑
- 远处的人物
- 道具、家具
- 山峦、树木

**第6层：背景层（BG）**

| 参数 | 数值范围 | 作用 |
|------|----------|------|
| Z轴位置 | -2000 ~ -4000 px | 主要背景 |
| 缩放 | 30% ~ 50% | 小 |
| 透明度 | 90% ~ 100% | 略有大气透视 |
| 模糊 | 中等模糊 | 明显失焦 |
| 移动速度 | 0.15 ~ 0.3倍 | 很慢 |

**典型元素：**
- 天空
- 远山
- 城市天际线
- 大环境背景

**第7层：远背景层（Far BG）**

| 参数 | 数值范围 | 作用 |
|------|----------|------|
| Z轴位置 | -5000 ~ -10000 px | 最远的背景 |
| 缩放 | 10% ~ 20% | 极小 |
| 透明度 | 70% ~ 90% | 大气透视强 |
| 模糊 | 强模糊 | 完全失焦 |
| 移动速度 | 0.05 ~ 0.1倍 | 几乎不动 |

**典型元素：**
- 天空渐变
- 最远的山轮廓
- 星空
- 大气层效果

#### 8.2.3 七层参数总表

| 层级 | Z轴位置 | 相对大小 | 透明度 | 模糊程度 | 移动速度比 |
|------|---------|---------|--------|----------|-----------|
| 极前景 (Extreme FG) | -100px | 180% | 30% | 强模糊 | 2.5x |
| 前景 (FG) | -300px | 150% | 60% | 中模糊 | 1.7x |
| 近景 (Near FG) | -450px | 110% | 90% | 微模糊 | 1.2x |
| 主体 (Subject) | -500px | 100% | 100% | 无 | 1.0x |
| 中景 (Mid) | -1000px | 70% | 95% | 轻模糊 | 0.5x |
| 背景 (BG) | -3000px | 40% | 85% | 中模糊 | 0.2x |
| 远背景 (Far BG) | -8000px | 15% | 75% | 强模糊 | 0.06x |

### 8.3 摄像机移动时的视差效果

#### 8.3.1 横向移动视差

摄像机沿X轴移动时，各层位移量不同：
- 近层位移大 → 有"划过"的感觉
- 远层位移小 → 感觉遥远

**效果强度 = 移动距离 × (1 / 深度)**

#### 8.3.2 纵向移动视差

摄像机沿Z轴移动（推/拉）时：
- 近层大小变化大
- 远层大小变化小

**推入效果：**
- 前景快速变大并"冲出"画面
- 主体稳步变大
- 背景缓慢变大
- 层次感强烈

#### 8.3.3 视差效果增强技巧

1. **增加层数**：层数越多，层次越丰富
2. **拉大深度差**：前后层深度差越大，视差越明显
3. **添加景深**：配合景深模糊，真实感倍增
4. **添加大气透视**：远处偏蓝、对比度低
5. **运动模糊**：快速移动时添加运动模糊
6. **细节叠加**：每层添加不同的细节纹理

## 九、2D/3D混合渲染

在实际项目中，经常需要同时使用2D和3D图层。理解混合渲染的规则对于避免问题、正确实现效果至关重要。

### 9.1 混合渲染规则

#### 9.1.1 基本渲染顺序

AE的渲染顺序（从后到前）：

```
1. 所有3D图层（按Z轴深度排序）
   ├── 最远的3D图层
   ├── ...
   ├── 最近的3D图层
   └── （3D调整层影响3D图层）

2. 所有2D图层（按时间轴顺序）
   ├── 下方的2D图层
   ├── ...
   ├── 上方的2D图层
   └── （2D调整层影响2D图层）
```

**关键规则：**
- 3D图层和2D图层是分开渲染的
- 3D图层按Z轴深度排序，与时间轴顺序无关
- 2D图层按时间轴从上到下（后到前）渲染
- 3D图层整体位于2D图层之下

#### 9.1.2 2D/3D分界

当时间轴上出现一个2D图层时，它会"打断"3D空间：

```
时间轴（从上到下 = 从前到后）
─────────────────────────────
  图层A (2D) ← 2D层，在最上层
  图层B (3D) ─┐
  图层C (3D)  ├ 3D层，按Z轴深度排序
  图层D (2D) ← 2D层，中断3D空间
  图层E (3D) ─┐
  图层F (3D)  └ 另一组3D层
  图层G (2D) ← 最底层2D
```

**结果：**
- 3D图层B和C在一个3D空间中
- 3D图层E和F在另一个3D空间中
- 2D图层D隔开了两个3D空间
- 每个2D图层都在自己的平面上

### 9.2 塌陷变换（Collapse Transformations）

#### 9.2.1 什么是塌陷变换

塌陷变换（Continuously Rasterize / Collapse Transformations）是预合成图层的一个开关：
- **对于矢量图层**：Continuously Rasterize（持续栅格化）
- **对于预合成**：Collapse Transformations（塌陷变换）

**开关位置：** 图层面板开关列中的"太阳"/"三角形"图标

#### 9.2.2 塌陷变换的作用

开启后：
- 预合成内的3D图层可以与外部3D空间交互
- 预合成内的3D图层可以投射/接受外部的阴影
- 预合成内的3D图层受外部摄像机影响
- 矢量图形保持清晰度（无损缩放）

未开启时：
- 预合成作为一个平面2D图层处理
- 内部3D效果被"拍平"
- 不与外部3D空间交互

#### 9.2.3 使用场景

**需要开启塌陷变换：**
- 预合成内有3D图层，需要与外部3D空间整合
- 矢量图形需要缩放而不失真
- 预合成内的文字需要保持清晰

**不需要开启：**
- 纯2D预合成
- 有效果应用在预合成上（效果会被应用到内部每帧，可能改变渲染结果）
- 预合成有调整层（塌陷后调整层作用范围变化）

#### 9.2.4 注意事项

1. **效果顺序变化**：开启塌陷后，效果的应用顺序可能改变
2. **调整层范围**：预合成内的调整层可能影响外部图层
3. **渲染顺序**：塌陷后，内部图层参与全局3D排序
4. **性能**：开启塌陷可能增加渲染时间

### 9.3 调整层与3D图层的交互

#### 9.3.1 2D调整层

**特点：**
- 影响其下方的所有图层（包括2D和3D）
- 不参与3D空间
- 按2D方式处理

**应用：**
- 整体调色
- 全局效果（如胶片颗粒、晕影）
- 最终效果叠加

#### 9.3.2 3D调整层

**特点：**
- 只影响与其在相同3D空间、深度相近的图层
- 受3D空间透视影响
- 有Z轴位置和方向

**创建方法：**
1. 创建调整层
2. 启用3D模式

**应用：**
- 3D空间中的体积光
- 深度相关的效果
- 3D空间中的雾效

### 9.4 常见混合渲染问题与解决

#### 9.4.1 问题：3D图层显示在2D图层前面

**现象：** 时间轴上2D图层在上面，但3D图层显示在前面

**原因：** 3D图层整体在2D图层之下，但如果3D图层的Z值很大（非常靠近摄像机），可能会...

**解决：**
- 检查图层Z轴位置
- 使用2D图层作为"分隔层"
- 调整图层顺序或Z值

#### 9.4.2 问题：阴影不显示

**可能原因：**
1. 投射阴影图层的Casts Shadows未开启
2. 接受阴影图层的Accepts Shadows未开启
3. 灯光的Casts Shadows未开启
4. 2D图层打断了3D空间
5. 渲染器不支持阴影

**排查步骤：**
```
1. 确认所有相关图层都是3D图层
2. 确认灯光存在且开启阴影
3. 确认Casts Shadows和Accepts Shadows设置
4. 检查中间是否有2D图层分隔
5. 确认渲染器设置正确
```

#### 9.4.3 问题：预合成内的3D不工作

**原因：** 未开启塌陷变换

**解决：** 点击预合成图层的塌陷变换开关（太阳图标）

#### 9.4.4 问题：调整层效果不正确

**原因：** 3D调整层和2D调整层作用范围不同

**解决：**
- 全局效果 → 使用2D调整层
- 3D空间效果 → 使用3D调整层
- 确保调整层类型正确

// 衰减
decayTime = 2;
startTime = 1;

if (time < startTime) {
  transform.position;

  decay = Math.exp(-t * decayTime);
  
  w1 = wiggle(freq1, amp1 * decay);
  w2 = wiggle(freq2, amp2 * decay);
  w3 = wiggle(freq3, amp3 * decay);
  
  // 叠加
  [
    w1[0] + w2[0] + w3[0] - transform.position[0] * 2,
    w1[1] + w2[1] + w3[1] - transform.position[1] * 2,
    w1[2] + w2[2] + w3[2] - transform.position[2] * 2
  ]
}
```

**摄像机Rotation Z：**

// 轻微旋转摇晃
if (time < 1) {
  value;
} else {
  t = time - 1;
  decay = Math.exp(-t * 1.5);
  wiggle(5, 3 * decay)
}
```

## 十一、性能优化

3D合成对计算机性能要求较高，合理的优化可以显著提升工作效率。

### 11.1 3D图层性能消耗

#### 11.1.1 性能消耗排序

从快到慢（同数量级下）：

```
2D图层 < Classic 3D无阴影 < Classic 3D有阴影 < Ray-traced 3D
```

**相对性能消耗（估算）：**

| 图层类型 | 相对消耗倍数 | 说明 |
|----------|-------------|------|
| 2D图层 | 1x | 基准 |
| Classic 3D（无灯光阴影） | 2 ~ 3x | 仅计算3D变换 |
| Classic 3D（有灯光无阴影） | 3 ~ 5x | 计算光照 |
| Classic 3D（有阴影） | 5 ~ 10x | 计算阴影贴图 |
| Ray-traced 3D（低质量） | 10 ~ 20x | 光线追踪 |
| Ray-traced 3D（高质量） | 30 ~ 100x | 高质量光线追踪 |

### 11.2 阴影渲染优化

1. **减少阴影投射图层**
   - 只给重要的物体开启Casts Shadows
   - 远处的小物体可以关闭阴影

2. **减少接受阴影的图层**
   - 只给地面/墙面等必要图层开启Accepts Shadows
   - 发光物体、天空等不需要接受阴影

3. **降低Shadow Diffusion**
   - 值越高，渲染越慢
   - 预览时设为0，最终渲染再调高

4. **合理设置阴影分辨率**
   - 在Project Settings中调整
   - 预览用低分辨率，最终渲染用高分辨率

5. **使用Classic 3D预览，Ray-traced最终渲染**
   - 编辑阶段使用Classic 3D
   - 最终渲染切换到Ray-traced 3D

### 11.3 景深优化

1. **预览时关闭景深**
   - 编辑时Depth of Field设为Off
   - 最终渲染时再开启

2. **降低Blur Level**
   - 预览时设为50%或更低
   - 最终渲染恢复100%

3. **减少Iris复杂度**
   - Polygon边数越少，渲染越快
   - 预览时用简单形状

4. **关闭高光特效**
   - Highlight相关计算较慢
   - 预览时Highlight Gain设为100%

### 11.4 代理预览设置

#### 11.4.1 分辨率代理

在合成窗口底部设置分辨率：
- **Full（完整）**：100%，最慢，质量最高
- **Half（一半）**：50%，4倍速度
- **Third（三分之一）**：33%，9倍速度
- **Quarter（四分之一）**：25%，16倍速度
- **Custom（自定义）**：自定义比例

**工作流建议：**
- 粗调动画：Quarter或Third
- 精细调整：Half
- 最终检查：Full

#### 11.4.2 快速预览（Fast Previews）

AE的Fast Previews模式：
- **Off**：完全渲染，质量最高
- **Wireframe**：线框显示，最快
- **Adaptive Resolution**：自适应分辨率
- **OpenGL / GPU加速**：GPU加速预览

### 11.5 渲染队列优化

1. **使用渲染队列而非实时预览**
   - 复杂场景用渲染队列输出后再观看

2. **分段渲染**
   - 长场景分段渲染，再拼接
   - 避免长时间渲染出错

3. **合理设置输出质量**
   - 预览输出：低码率、低分辨率
   - 最终输出：高质量

4. **利用多核和GPU**
   - 确保AE使用GPU加速
   - 在Preferences中设置内存和多核

5. **清理缓存**
   - 定期清理磁盘缓存
   - `Edit` → `Purge` → `All Memory & Disk Cache`

## 十二、故障排查

### 12.1 3D图层不显示

#### 可能原因与解决方案

| 原因 | 检查方法 | 解决方案 |
|------|----------|----------|
| Z轴位置超出视野 | 检查Position Z值 | 调整Z值到可见范围 |
| 摄像机被遮挡 | 切换到Top视图查看 | 移动摄像机或图层 |
| 图层在摄像机后面 | 检查Z值大小关系 | 确保图层Z < 摄像机Z（注意方向） |
| 图层背面朝向摄像机 | 切换视图检查旋转 | 翻转图层或调整旋转 |
| 透明度为0 | 检查Opacity | 恢复Opacity |
| 被其他图层遮挡 |  Solo图层查看 | 调整图层顺序/Z值 |
| 合成设置问题 | 检查合成设置 | 确认渲染器正确 |

**排查步骤：**
```
1. Solo该图层 → 确认是否被遮挡
2. 切换到Custom View → 查看3D空间位置
3. 检查图层Transform属性 → 确认位置/缩放/透明度
4. 检查摄像机设置 → 确认视角正确
5. 检查渲染器设置 → 确认3D渲染器
```

### 12.2 阴影不显示

#### 可能原因与解决方案

| 原因 | 检查方法 | 解决方案 |
|------|----------|----------|
| 图层未开启3D | 检查3D开关 | 启用3D图层 |
| Casts Shadows关闭 | 检查材质选项 | 设为On |
| Accepts Shadows关闭 | 检查接收层 | 设为On |
| 灯光未开阴影 | 检查灯光选项 | 开启灯光阴影 |
| 灯光类型不支持 | 检查灯光类型 | Ambient光不投射阴影 |
| 2D图层分隔 | 检查时间轴 | 移除中间的2D图层 |
| 渲染器不支持 | 检查渲染器 | 使用Classic或Ray-traced |
| 阴影太淡 | 检查Shadow Darkness | 提高暗度 |

### 12.3 景深无效果

#### 可能原因与解决方案

| 原因 | 检查方法 | 解决方案 |
|------|----------|----------|
| Depth of Field未开启 | 摄像机选项 | 设为On |
| Aperture为0 | 检查Aperture值 | 设置大于0的值 |
| 所有图层都在焦平面 | 检查图层Z分布 | 增大Z轴范围 |
| Blur Level为0 | 检查Blur Level | 恢复100% |
| 渲染器不支持 | 检查渲染器 | 更换渲染器 |
| 预览分辨率太低 | 检查预览设置 | 提高分辨率 |

### 12.4 渲染报错

#### 常见报错与解决

| 错误信息 | 可能原因 | 解决方案 |
|----------|----------|----------|
| 光线追踪错误 | GPU不支持/驱动问题 | 更新显卡驱动/降低质量 |
| 内存不足 | 场景太复杂 | 增加内存/降低分辨率/使用代理 |
| 渲染超时 | 单帧渲染时间过长 | 降低质量/优化场景 |

| 图层错误 | 某图层损坏 | 检查并修复问题图层 |

### 12.5 摄像机视角异常

#### 可能原因与解决方案

| 现象 | 原因 | 解决方案 |
|------|------|----------|
