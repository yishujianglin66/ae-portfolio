# 时间轴推理引擎与决策规范

> [!abstract] 文档摘要
> 本文档定义从音乐输入到完整时间轴输出的原子级推理引擎架构——将所有映射知识整合为一个可执行的推理管线。涵盖9层推理架构、完整Schema定义、算法伪代码、TypeScript/Python接口、QC验证体系与性能优化策略。是连接[[音乐结构原子分析与节拍映射]]、[[片段元数据与视觉能量图谱]]与[[音画匹配决策树与剪辑思路推演]]的核心执行引擎。

> [!tip] 使用指南
> - 引擎架构师：第1-2章是顶层设计，第10章是输出Schema
> - 算法工程师：第3-9章是各层推理算法，第11章是主推理循环
> - 集成开发者：第12章是接口与集成规范
> - QA团队：第13章是QC与验证体系
> - 性能工程师：第14章是性能优化与扩展

> [!important] 核心定位
> 时间轴推理引擎 = MusicAtom + ClipAtom[] → TimelinePlan
> 输入音乐原子 + 片段原子数组 → 输出完整时间轴方案（含节拍/段落/片段分配/视觉效果/音效/转场/质量评分/推理路径）

## 第1章 时间轴推理引擎总览

### 1.1 引擎定位与边界

时间轴推理引擎（Timeline Reasoning Engine, TRE）是音画匹配推演系统的核心执行组件，负责将音乐分析结果与片段分析结果转化为可执行的完整时间轴方案。

```
┌─────────────────────────────────────────────────────────────────┐
│                    时间轴推理引擎（TRE）                          │
│                                                                 │
│  输入：                                                          │
│    • MusicAtom      — 音乐原子（来自音乐分析模块）                │
│    • ClipAtom[]     — 片段原子数组（来自片段分析模块）            │
│    • UserPreference — 用户偏好（可选）                           │
│                                                                 │
│  输出：                                                          │
│    • TimelinePlan   — 完整时间轴方案                             │
│                                                                 │
│  核心能力：                                                       │
│    • 节拍级精确对齐                                               │
│    • 段落级语义匹配                                               │
│    • 多目标优化决策                                               │
│    • 可解释推理路径                                               │
│    • 质量评分与回溯                                               │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 9层推理架构

时间轴推理引擎采用9层递进式架构，每层输出作为下一层的输入，同时支持层间反馈与回溯。

```
┌───────────────────────────────────────────────────────────────┐
│ L9 输出层（Output Layer）                                      │
│   → TimelinePlan 完整时间轴方案 + 推理路径 + 质量评分           │
├───────────────────────────────────────────────────────────────┤
│ L8 音效层（SFX Layer）                                         │
│   → 音效时间轴 + 混音方案 + 转场音效联动                        │
├───────────────────────────────────────────────────────────────┤
│ L7 效果层（Effects Layer）                                     │
│   → 视觉效果栈 + 关键帧 + 转场 + 调色 + 相机运动               │
├───────────────────────────────────────────────────────────────┤
│ L6 匹配层（Matching Layer）                                    │
│   → 片段分配 + 排序优化 + 时长分配                              │
├───────────────────────────────────────────────────────────────┤
│ L5 情绪层（Emotion Layer）                                     │
│   → VA值序列 + 情绪段 + 情绪弧线 + 高潮点                       │
├───────────────────────────────────────────────────────────────┤
│ L4 能量层（Energy Layer）                                      │
│   → 9频段能量 + 峰值/谷值 + 变化率                              │
├───────────────────────────────────────────────────────────────┤
│ L3 段落层（Segment Layer）                                     │
│   → 标注段落列表 + 能量梯级 + 叙事弧线                          │
├───────────────────────────────────────────────────────────────┤
│ L2 节拍层（Beat Layer）                                        │
│   → 带类型+强度+重要性的节拍网格                                │
├───────────────────────────────────────────────────────────────┤
│ L1 输入层（Input Layer）                                       │
│   → 输入验证 + 清洗 + 标准化 + 格式转换                         │
└───────────────────────────────────────────────────────────────┘
```

**各层职责详解：**

| 层级 | 名称 | 输入 | 核心算法 | 输出 |
|------|------|------|---------|------|
| L1 | 输入层 | 原始MusicAtom/ClipAtom/Preference | Schema验证 + 数据清洗 + 归一化 | 标准化输入数据 |
| L2 | 节拍层 | 标准化节拍网格 | 节拍分类 + 强度评分 + 重要性排序 | AnnotatedBeatGrid |
| L3 | 段落层 | 原始段落 + 能量曲线 | 类型确认 + 边界校准 + 叙事拟合 | AnnotatedSegments |
| L4 | 能量层 | 音频波形 + 频谱 | 6频段分解 + 峰值检测 + 导数计算 | EnergyAnalysis |
| L5 | 情绪层 | 能量 + 频谱 + 调式 | VA计算 + 情绪段划分 + 弧线拟合 | EmotionTimeline |
| L6 | 匹配层 | 节拍 + 段落 + 片段 | 动态规划 + 匈牙利算法 + 排序优化 | ClipAssignment |
| L7 | 效果层 | 匹配结果 + 情绪 + 能量 | 效果栈生成 + 关键帧 + 转场方案 | VisualEffectsTimeline |
| L8 | 音效层 | 节拍 + 段落 + 转场 | 音效匹配 + 混音方案 + 联动设计 | SfxTimeline |
| L9 | 输出层 | 所有中间结果 | 整合 + 评分 + 推理路径记录 | TimelinePlan |

### 1.3 推理精度等级（L1-L4）

引擎支持4个精度等级，根据计算资源和质量需求灵活选择。

| 等级 | 名称 | 精度 | 计算开销 | 适用场景 |
|------|------|------|---------|---------|
| L1 | 快速模式 | 节拍级（~500ms） | 低（<1s） | 快速预览/批量处理 |
| L2 | 标准模式 | 半拍级（~250ms） | 中（~5s） | 常规制作 |
| L3 | 精细模式 | 10ms级 | 高（~30s） | 专业制作/高质量输出 |
| L4 | 研究模式 | 1ms级 + 多假设 | 极高（~5min） | 研究/最优解搜索 |

**各等级启用的功能：**

```yaml
precision_levels:
  L1_fast:
    beat_analysis: basic_downbeat_only
    segment_analysis: coarse_8s_grid
    energy_analysis: single_band_rms
    emotion_analysis: segment_level_only
    clip_matching: greedy_first_fit
    effects: minimal_preset
    sfx: beat_sync_only
    typical_latency: "0.5-1s"
    
  L2_standard:
    beat_analysis: full_beat_grid
    segment_analysis: energy_based
    energy_analysis: 3_band
    emotion_analysis: 2s_resolution
    clip_matching: dynamic_programming
    effects: full_style_stack
    sfx: full_pipeline
    typical_latency: "3-8s"
    
  L3_fine:
    beat_analysis: annotated_with_subdivisions
    segment_analysis: 10ms_boundary_precision
    energy_analysis: 9_band_full
    emotion_analysis: 100ms_resolution
    clip_matching: hungarian + multi_objective
    effects: keyframe_level_precision
    sfx: 5_layer_mix
    typical_latency: "20-60s"
    
  L4_research:
    beat_analysis: probabilistic_multihypothesis
    segment_analysis: multimodal_fusion
    energy_analysis: 32_band_spectral
    emotion_analysis: 10ms_continuous
    clip_matching: genetic_algorithm_search
    effects: parameter_optimization
    sfx: generative_sound_design
    typical_latency: "2-10min"
```

### 1.4 与既有 Phase 1-5 引擎的对接关系

时间轴推理引擎是 Phase 1-5 引擎的上游智能决策层，通过统一的「原子参数 JSON」接口对接。

```
┌──────────────────────────────────────────────────────────────────┐
│                    时间轴推理引擎（TRE）                           │
│  MusicAtom + ClipAtom[] → TimelinePlan                           │
└─────────────────────────────┬────────────────────────────────────┘
                              │
                              ▼ TimelinePlan
┌──────────────────────────────────────────────────────────────────┐
│                    转换层（Adapter）                               │
│  TimelinePlan → CompilerInput（原子参数JSON）                     │
└─────────────────────────────┬────────────────────────────────────┘
                              │
                              ▼ CompilerInput
┌──────────────────────────────────────────────────────────────────┐
│              Phase 1-5 编译器引擎（既有）                          │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐         │
│  │ Phase 1  │→│ Phase 2  │→│ Phase 3  │→│ Phase 4  │→ ...     │
│  │ 意图解析  │  │ 澄清优化  │  │ 操作生成  │  │ 代码生成  │         │
│  └──────────┘  └──────────┘  └──────────┘  └──────────┘         │
└─────────────────────────────┬────────────────────────────────────┘
                              │
                              ▼
                          AE 成片
```

**对接要点：**

1. **TRE → Phase 3**：TimelinePlan 中的 visual_effects 直接映射为 Phase 3 的操作序列
2. **TRE → Phase 4**：clip_assignments 转化为图层操作指令
3. **TRE → Phase 5**：quality_score 作为验证基准，推理路径用于错误追溯
4. **Phase 5 → TRE**：执行结果反馈用于优化推理参数（学习闭环）

详细接口规范见 [[#第12章 接口与集成]]。

## 第2章 输入数据规范

### 2.1 MusicAtom 完整 Schema

MusicAtom 是音乐的原子级表示，包含节奏、结构、能量、频谱、情绪、调式、流派七大维度。

```typescript
interface MusicAtom {
  metadata: {
    file_path: string;
    duration: number;          // 秒
    sample_rate: number;       // Hz
    channels: number;
    format: string;            // mp3/wav/flac等
    analysis_timestamp: string;
    analyzer_version: string;
    confidence: number;        // 整体分析置信度 0-1
  };

  rhythm: {
    bpm: number;               // 全局BPM
    bpm_confidence: number;    // BPM检测置信度
    time_signature: {
      numerator: number;       // 拍号分子
      denominator: number;     // 拍号分母
    };
    beat_grid: number[];       // 节拍时间戳数组（秒）
    downbeats: number[];       // 强拍时间戳数组
    tempo_curve: TempoPoint[]; // 速度曲线
    beat_offsets?: {
      measure: number;
      beat: number;
      time: number;
    }[];
  };

  structure: {
    segments: MusicSegment[];
    segment_confidence: number;
    section_labels: string[];   // 所有出现的段落类型
  };

  energy: {
    rms_curve: number[];        // RMS能量曲线（每帧一个值）
    peak_curve: number[];       // 峰值能量曲线
    dynamic_range: number;      // 动态范围dB
    rms_frame_size: number;     // 帧长（秒）
    rms_hop_size: number;       // 帧移（秒）
  };

  spectrum: {
    bands: SpectrumBand[];      // 6频段
    spectral_centroid: number[]; // 频谱质心曲线
    spectral_flux: number[];    // 频谱通量曲线
    spectral_rolloff: number[]; // 频谱滚降点
    mfcc: number[][];           // MFCC系数
    frame_size: number;
    hop_size: number;
  };

  emotion: {
    valence: number[];          // 情绪价曲线 -1到1
    arousal: number[];          // 唤醒度曲线 0到1
    valence_arousal_resolution: number; // 秒/帧
    overall_valence: number;    // 整体情绪价
    overall_arousal: number;    // 整体唤醒度
    mood_tags: string[];        // 情绪标签
  };

  tonality: {
    key: string;                // 调式 C/D/E/...
    mode: "major" | "minor";    // 大调/小调
    key_confidence: number;
    chord_progressions?: ChordProgression[];
  };

  genre: {
    primary: string;            // 主要流派
    secondary: string[];        // 次要流派
    genre_confidence: number;
    bpm_range: [number, number]; // 流派典型BPM范围
    stylistic_features: string[]; // 风格特征标签
  };
}
```

**子类型定义：**

```typescript
interface TempoPoint {
  time: number;
  tempo: number;
  confidence: number;
}

interface MusicSegment {
  id: string;
  type: "intro" | "verse" | "pre_chorus" | "chorus" | "bridge" 
      | "breakdown" | "buildup" | "drop" | "outro" | "instrumental"
      | "solo" | "interlude";
  start_time: number;
  end_time: number;
  duration: number;
  energy_level: number;        // 0-1 段落平均能量
  confidence: number;
  features?: {
    has_vocal: boolean;
    has_drums: boolean;
    has_bass: boolean;
    texture_density: number;   // 0-1 织体密度
  };
}

interface SpectrumBand {
  name: string;                // sub_bass / bass / low_mid / mid / high_mid / treble
  frequency_range: [number, number]; // Hz
  energy_curve: number[];      // 该频段能量曲线
  average_energy: number;      // 平均能量
  peak_energy: number;         // 峰值能量
}

interface ChordProgression {
  start_time: number;
  end_time: number;
  chords: string[];            // 和弦序列
  confidence: number;
}
```

### 2.2 ClipAtom 完整 Schema

ClipAtom 是视频片段的原子级表示，包含运动、色彩、构图、能量、语义、时长、质量七大维度。

```typescript
interface ClipAtom {
  metadata: {
    file_path: string;
    duration: number;          // 秒
    frame_rate: number;        // fps
    width: number;             // 像素
    height: number;            // 像素
    codec: string;
    bitrate: number;           // kbps
    analysis_timestamp: string;
    analyzer_version: string;
    quality_score: number;     // 素材质量 0-1
  };

  motion: {
    overall_intensity: number;  // 整体运动强度 0-1
    intensity_curve: number[];  // 运动强度曲线（每帧）
    dominant_direction: string; // 主运动方向 8方向
    direction_histogram: Record<string, number>; // 方向分布
    camera_motion: CameraMotion; // 相机运动分类
    motion_peaks: MotionPeak[]; // 运动峰值点
    optical_flow_stats?: {
      mean_magnitude: number;
      std_magnitude: number;
      max_magnitude: number;
    };
  };

  color: {
    color_palette: ColorSwatch[]; // 主色板（Top 5）
    overall_tone: "warm" | "cool" | "neutral" | "mixed";
    temperature: number;        // 色温 0(冷)-1(暖)
    saturation: number;         // 平均饱和度 0-1
    brightness: number;         // 平均亮度 0-1
    contrast: number;           // 对比度 0-1
    histogram: ColorHistogram;  // 颜色直方图
    dominant_hue: number;       // 主色调 0-360
  };

  composition: {
    rule_of_thirds_score: number; // 三分法符合度 0-1
    symmetry_score: number;     // 对称性 0-1
    depth_of_field: "shallow" | "medium" | "deep";
    subject_position: { x: number; y: number }; // 主体位置（归一化）
    subject_size: number;       // 主体占比 0-1
    framing: "close_up" | "medium" | "wide" | "extreme_wide";
    balance_score: number;      // 画面平衡度 0-1
  };

  energy: {
    visual_energy: number;      // 综合视觉能量 0-1
    energy_curve: number[];     // 视觉能量曲线
    energy_peaks: EnergyPeak[]; // 能量峰值
    energy_valleys: EnergyPeak[]; // 能量谷值
    energy_dynamics: number;    // 能量动态范围
    components: {
      motion_contribution: number;  // 运动贡献占比
      color_contribution: number;   // 色彩贡献占比
      contrast_contribution: number; // 对比贡献占比
      activity_contribution: number; // 活跃度贡献占比
    };
  };

  semantic: {
    scene_type: string;         // 场景类型
    scene_confidence: number;
    main_subject: string;       // 主要主体
    subject_tags: string[];     // 主体标签
    mood_tags: string[];        // 情绪氛围标签
    action_tags: string[];      // 动作标签
    people_count: number;       // 人数
    has_text: boolean;          // 是否有文字
    text_content?: string;
  };

  temporal: {
    scene_cuts: number[];       // 场景切换时间点
    shot_count: number;         // 镜头数量
    average_shot_duration: number; // 平均镜头时长
    pacing: number;             // 节奏快慢 0(慢)-1(快)
  };

  quality: {
    overall: number;            // 总体质量 0-1
    sharpness: number;          // 锐度 0-1
    noise_level: number;        // 噪点水平 0-1（越低越好）
    exposure: "underexposed" | "normal" | "overexposed";
    stability: number;          // 稳定性 0-1
    compression_artifacts: number; // 压缩伪影 0-1（越低越好）
    usable_segments?: UsableSegment[]; // 可用片段区间
  };
}
```

### 2.3 UserPreference Schema

UserPreference 定义用户的风格与强度偏好，用于引导推理决策。

```typescript
interface UserPreference {
  style: {
    primary_style: string;     // 主要风格：赛博朋克/复古/电影感/极简/...
    secondary_styles: string[]; // 次要风格
    style_intensity: number;   // 风格强度 0-1
    reference_images?: string[]; // 参考图路径
  };

  intensity: {
    overall: number;           // 整体效果强度 0-1
    effects_level: "minimal" | "subtle" | "moderate" | "intense" | "extreme";
    transitions_level: "minimal" | "subtle" | "moderate" | "intense" | "extreme";
    color_grading_level: "minimal" | "subtle" | "moderate" | "intense" | "extreme";
    motion_level: "minimal" | "subtle" | "moderate" | "intense" | "extreme";
  };

  rhythm: {
    pacing: "slow" | "medium" | "fast" | "dynamic";
    beat_sync_level: number;   // 节拍同步程度 0-1
    cut_frequency: "low" | "medium" | "high" | "beat_aligned";
    transition_speed: "slow" | "medium" | "fast";
  };

  color: {
    palette_preference: "original" | "warm" | "cool" | "moody" | "vibrant" | "mono";
    saturation_bias: number;   // 饱和度偏移 -1到1
    brightness_bias: number;   // 亮度偏移 -1到1
```

```
┌─────────────┐
│ 范围校验    │  → 数值范围/时长一致性/时间排序
```

```python
def validate_and_clean_input(music_atom, clip_atoms, user_preference=None):
    """
    输入验证与清洗主流程
    返回：(cleaned_data, validation_report)
    """
    report = {
        "errors": [],
        "warnings": [],
        "repairs": []
    }
    
    # 1. MusicAtom 验证
    if not validate_music_atom(music_atom, report):
        raise ValidationError(f"MusicAtom 验证失败: {report['errors']}")
    
    # 2. ClipAtom 数组验证
    if not clip_atoms or len(clip_atoms) == 0:
        report["errors"].append("ClipAtom 数组为空")
        raise ValidationError("至少需要一个视频片段")
    
    for i, clip in enumerate(clip_atoms):
        if not validate_clip_atom(clip, i, report):
            report["warnings"].append(f"Clip[{i}] 验证失败，已跳过")
            clip_atoms[i] = None
    
    clip_atoms = [c for c in clip_atoms if c is not None]
    if len(clip_atoms) == 0:
        raise ValidationError("所有片段均验证失败")
    
    # 3. 用户偏好验证（使用默认值填充）
    if user_preference is None:

    # 4. 数据清洗
    music_atom = clean_music_atom(music_atom, report)
    clip_atoms = [clean_clip_atom(c, report) for c in clip_atoms]
    
    # 5. 跨数据一致性检查
    check_cross_consistency(music_atom, clip_atoms, report)
    
    return {
        "music": music_atom,
        "clips": clip_atoms,
        "preferences": user_preference,
        "validation_report": report
    }
```

## 第3章 节拍层推理

### 3.1 节拍类型识别算法

节拍层的核心任务是将原始节拍网格转化为带有类型、强度和重要性标注的结构化节拍数据。

**节拍类型体系：**

| 类型 | 英文标识 | 定义 | 典型位置 | 权重系数 |
|------|---------|------|---------|---------|
| 重拍 | downbeat | 每小节第1拍 | 小节起点 | 1.0 |
| 次重拍 | secondary | 偶数拍或特定强拍 | 第2/3拍 | 0.7 |
| 弱拍 | upbeat | 非强调拍 | 第2/4拍 | 0.4 |
| 反拍 | offbeat | 正拍之间的反拍 | 半拍位置 | 0.5 |
| 切分 | syncopation | 切分节奏点 | 不规则位置 | 0.6 |
| 附点 | dotted | 附点节奏延长 | 附点位置 | 0.55 |
| 三连音 | triplet | 三连音均分 | 三分之一位置 | 0.45 |

**节拍类型识别算法：**

```python
def classify_beat_types(beat_grid, music_atom):
    """
    对节拍网格中的每个节拍进行类型分类
    
    输入：
        beat_grid: 节拍时间戳数组
        music_atom: 音乐原子（含节奏/能量/频谱信息）
    
    输出：
        annotated_beats: 带类型标注的节拍列表
    """
    time_sig = music_atom.rhythm.time_signature
    beats_per_measure = time_sig.numerator
    
    # 1. 基础节拍位置标注
    annotated_beats = []
    for i, beat_time in enumerate(beat_grid):
        measure_index = i // beats_per_measure
        beat_in_measure = i % beats_per_measure
        
        # 基础类型判断
        if beat_in_measure == 0:
            base_type = "downbeat"
        elif beat_in_measure == beats_per_measure // 2:
            base_type = "secondary"
        else:
            base_type = "upbeat"
        
        annotated_beats.append({
            "index": i,
            "time": beat_time,
            "measure": measure_index,
            "beat_in_measure": beat_in_measure,
            "base_type": base_type,
            "strength": 0.0,      # 后面计算
            "importance": 0.0,     # 后面计算
            "subdivisions": []     # 细分节拍
        })
    
    # 2. 检测细分节拍（反拍/三连音/切分）
    onset_env = music_atom.energy.peak_curve  # 使用峰值曲线作为onset近似
    frame_rate = len(onset_env) / music_atom.metadata.duration
    
    for beat in annotated_beats:
        next_beat_idx = beat["index"] + 1
        if next_beat_idx >= len(annotated_beats):
            continue
        
        next_beat = annotated_beats[next_beat_idx]
        beat_duration = next_beat["time"] - beat["time"]
        
        # 检测半拍位置（反拍）
        half_beat_time = beat["time"] + beat_duration / 2
        half_beat_frame = int(half_beat_time * frame_rate)
        if half_beat_frame < len(onset_env):
            # 检查半拍位置是否有onset峰值
            local_region = onset_env[max(0, half_beat_frame-2):half_beat_frame+3]
            peak_val = max(local_region)
            avg_val = sum(local_region) / len(local_region)
            
            if peak_val > avg_val * 1.5:  # 有显著峰值
                beat["subdivisions"].append({
                    "type": "offbeat",
                    "time": half_beat_time,
                    "strength": peak_val * 0.5
                })
        
        # 检测三连音
        triplet_positions = [beat["time"] + beat_duration * (i/3) for i in range(1, 3)]
        for trip_time in triplet_positions:
            trip_frame = int(trip_time * frame_rate)
            if trip_frame < len(onset_env):
                local_region = onset_env[max(0, trip_frame-1):trip_frame+2]
                if max(local_region) > sum(local_region)/len(local_region) * 1.3:
                    beat["subdivisions"].append({
                        "type": "triplet",
                        "time": trip_time,
                        "strength": max(local_region) * 0.4
                    })
    
    # 3. 切分检测（基于onset的不规则位置）
    # ... （更复杂的切分检测算法，需要分析频谱通量）
    
    return annotated_beats
```

### 3.2 节拍强度评分计算

每个节拍的强度由多维度特征加权计算得出：

**强度计算公式：**

```
beat_strength = w₁·E_impact + w₂·E_bass + w₃·E_drum + w₄·E_spectral_flux + w₅·rhythmic_role
```

其中：
- **E_impact** (0.30)：瞬时冲击能量（onset强度）
- **E_bass** (0.25)：低频段能量（20-200Hz）
- **E_drum** (0.20)：鼓组频段能量（200-2000Hz）
- **E_spectral_flux** (0.15)：频谱通量（变化程度）
- **rhythmic_role** (0.10)：节奏角色权重（重拍=1.0，次重拍=0.7...）

```python
def calculate_beat_strength(annotated_beats, music_atom):
    """
    计算每个节拍的强度值
    """
    # 获取各频段能量曲线
    sub_bass_energy = music_atom.spectrum.bands[0].energy_curve
    bass_energy = music_atom.spectrum.bands[1].energy_curve
    low_mid_energy = music_atom.spectrum.bands[2].energy_curve
    
    # 频谱通量
    spectral_flux = music_atom.spectrum.spectral_flux
    
    # 帧时间转换
    hop_size = music_atom.spectrum.hop_size
    
    for beat in annotated_beats:
        beat_frame = int(beat["time"] / hop_size)
        
        # 1. 冲击能量（取beat前后小窗口的最大值）
        impact_window = range(max(0, beat_frame-1), min(len(spectral_flux), beat_frame+3))
        e_impact = max([spectral_flux[f] for f in impact_window]) if impact_window else 0
        
        # 2. 低频能量
        e_bass = 0
        if beat_frame < len(sub_bass_energy):
            e_bass += sub_bass_energy[beat_frame] * 0.6
        if beat_frame < len(bass_energy):
            e_bass += bass_energy[beat_frame] * 0.4
        
        # 3. 鼓组能量（中低频）
        e_drum = low_mid_energy[beat_frame] if beat_frame < len(low_mid_energy) else 0
        
        # 4. 频谱通量
        e_flux = spectral_flux[beat_frame] if beat_frame < len(spectral_flux) else 0
        
        # 5. 节奏角色权重
        role_weights = {
            "downbeat": 1.0,
            "secondary": 0.7,
            "upbeat": 0.4
        }
        rhythmic_role = role_weights.get(beat["base_type"], 0.5)
        
        # 加权求和
        strength = (
            0.30 * normalize(e_impact, "spectral_flux") +
            0.25 * normalize(e_bass, "bass_energy") +
            0.20 * normalize(e_drum, "low_mid_energy") +
            0.15 * normalize(e_flux, "spectral_flux") +
            0.10 * rhythmic_role
        )
        
        beat["strength"] = min(1.0, max(0.0, strength))
        
        # 同时计算细分节拍的强度
        for sub in beat["subdivisions"]:
            sub_frame = int(sub["time"] / hop_size)
            # 简化的细分节拍强度计算
            sub_strength = 0
            if sub_frame < len(spectral_flux):
                sub_strength = spectral_flux[sub_frame] * 0.7
            sub["strength"] = min(1.0, normalize(sub_strength, "spectral_flux"))
    
    return annotated_beats
```

### 3.3 节拍重要性排序

节拍重要性 = 节拍强度 × 位置权重 × 上下文权重

**重要性维度：**

| 维度 | 说明 | 权重 |
|------|------|------|
| 节拍强度 | 上一节计算的强度值 | 0.40 |
| 段落边界 | 是否在段落开头/结尾 | 0.25 |
| 能量峰值 | 是否在能量曲线上的峰值点 | 0.15 |
| 小节位置 | 在小节中的位置 | 0.10 |
| 频率密度 | 周围节拍的密集程度 | 0.10 |

```python
def calculate_beat_importance(annotated_beats, music_atom, segments):
    """
    计算每个节拍的重要性分数，并排序
    """
    energy_curve = music_atom.energy.rms_curve
    energy_frame_rate = len(energy_curve) / music_atom.metadata.duration
    
    for beat in annotated_beats:
        beat_time = beat["time"]
        
        # 1. 节拍强度（已计算）
        s_strength = beat["strength"]
        
        # 2. 段落边界权重
        s_boundary = 0.0
        for seg in segments:
            # 距离段落开头越近越重要
            dist_to_start = abs(beat_time - seg.start_time)
            if dist_to_start < 0.5:  # 500ms以内认为是边界
                s_boundary = max(s_boundary, 1.0 - dist_to_start / 0.5)
            
            # 距离段落结尾
            dist_to_end = abs(beat_time - seg.end_time)
            if dist_to_end < 0.5:
                s_boundary = max(s_boundary, 1.0 - dist_to_end / 0.5)
        
        # 3. 能量峰值权重
        beat_frame = int(beat_time * energy_frame_rate)
        s_peak = 0.0
        if 2 < beat_frame < len(energy_curve) - 2:
            # 局部最大值检测
            local_window = energy_curve[beat_frame-2:beat_frame+3]
            if energy_curve[beat_frame] == max(local_window):
                # 是局部峰值，计算突出度
                prominence = energy_curve[beat_frame] - min([
                    min(energy_curve[beat_frame-2:beat_frame]),
                    min(energy_curve[beat_frame+1:beat_frame+3])
                ])
                s_peak = min(1.0, prominence * 2)
        
        # 4. 小节位置权重
        position_weights = {
            "downbeat": 1.0,
            "secondary": 0.6,
            "upbeat": 0.3
        }
        s_position = position_weights.get(beat["base_type"], 0.5)
        
        # 5. 频率密度权重（周围节拍越少越重要）
        # 计算前后2秒内的节拍数
        nearby_beats = sum(
            1 for b in annotated_beats 
            if abs(b["time"] - beat_time) < 2.0 and b["index"] != beat["index"]
        )
        s_density = max(0.0, 1.0 - nearby_beats / 20)  # 2秒内20个以上则为0
        
        # 加权求和
        importance = (
            0.40 * s_strength +
            0.25 * s_boundary +
            0.15 * s_peak +
            0.10 * s_position +
            0.10 * s_density
        )
        
        beat["importance"] = min(1.0, max(0.0, importance))
    
    # 按重要性排序
    sorted_beats = sorted(annotated_beats, key=lambda b: b["importance"], reverse=True)
    
    return annotated_beats, sorted_beats
```

**重要性排序规则（从高到低）：**

```
1. 段落边界重拍 + 能量峰值 → 最重要（卡点黄金点）
2. 副歌段重拍 + 高强度 → 次重要
3. 段落边界次重拍 → 第三级
4. 普通重拍 → 常规卡点
5. 能量峰值弱拍 → 次要卡点
6. 普通次重拍 → 装饰性卡点
7. 弱拍/反拍 → 细节增强
8. 三连音/切分 → 特殊效果触发
```

## 第4章 段落层推理

### 4.1 段落类型确认与修正

段落层在音乐结构分析的基础上，结合能量曲线和频谱特征，对段落类型进行确认和修正，确保段落划分的准确性。

**段落类型体系：**

| 类型 | 英文名 | 能量特征 | 典型时长 | 叙事角色 |
|------|--------|---------|---------|---------|
| 前奏 | intro | 低→中，渐增 | 8-16s | 建立基调，引入主题 |
| 主歌 | verse | 中低，稳定 | 16-32s | 叙事铺陈，旋律发展 |
| 预副歌 | pre_chorus | 中→高，渐增 | 4-8s | 张力积累，过渡 |
| 副歌 | chorus | 高，峰值 | 16-32s | 情绪高潮，主题再现 |
| 桥段 | bridge | 中高，变化 | 8-16s | 转折对比，新元素 |
| 间奏 | interlude | 中，器乐 | 4-16s | 过渡喘息，器乐展示 |
| 独奏 | solo | 中高，炫技 | 8-16s | 乐器独奏，技巧展示 |
|  breakdown | breakdown | 低，抽空 | 4-16s | 能量骤降，铺垫爆发 |
|  buildup | buildup | 低→高，渐增 | 8-32s | 能量爬升，张力构建 |
| drop | drop | 极高，爆发 | 4-8s | 能量释放，高潮爆发 |
| 器乐段 | instrumental | 中高 | 8-32s | 无主唱，器乐主导 |
| 尾奏 | outro | 高→低，渐弱 | 8-16s | 收尾收束，淡出 |

**段落类型确认算法：**

```python
def confirm_and_correct_segments(segments, music_atom):
    """
    基于能量曲线和频谱特征确认和修正段落类型
    
    输入：
        segments: 原始段落列表（来自音乐结构分析）
        music_atom: 音乐原子
    
    输出：
        corrected_segments: 修正后的段落列表
    """
    energy_curve = music_atom.energy.rms_curve
    spectral_centroid = music_atom.spectrum.spectral_centroid
    frame_rate = len(energy_curve) / music_atom.metadata.duration
    
    corrected_segments = []
    
    for i, seg in enumerate(segments):
        start_frame = int(seg.start_time * frame_rate)
        end_frame = int(seg.end_time * frame_rate)
        
        # 1. 计算段落内的能量特征
        seg_energy = energy_curve[start_frame:end_frame]
        avg_energy = np.mean(seg_energy)
        max_energy = np.max(seg_energy)
        min_energy = np.min(seg_energy)
        energy_range = max_energy - min_energy
        
        # 能量趋势（升/降/平）
        first_half = np.mean(seg_energy[:len(seg_energy)//2])
        second_half = np.mean(seg_energy[len(seg_energy)//2:])
        energy_trend = "rising" if second_half > first_half * 1.1 else \
                       "falling" if second_half < first_half * 0.9 else "stable"
        
        # 2. 计算频谱特征
        seg_centroid = spectral_centroid[start_frame:end_frame]
        avg_centroid = np.mean(seg_centroid)
        centroid_trend = "rising" if np.mean(seg_centroid[len(seg_centroid)//2:]) > np.mean(seg_centroid[:len(seg_centroid)//2]) * 1.1 else \
                         "falling" if np.mean(seg_centroid[len(seg_centroid)//2:]) < np.mean(seg_centroid[:len(seg_centroid)//2]) * 0.9 else "stable"
        
        # 3. 基于特征确认/修正类型
        features = {
            "avg_energy": normalize_energy(avg_energy),
            "max_energy": normalize_energy(max_energy),
            "energy_range": energy_range,
            "energy_trend": energy_trend,
            "avg_centroid": avg_centroid,
            "centroid_trend": centroid_trend,
            "duration": seg.duration
        }
        
        corrected_type = classify_segment_type(seg.type, features)
        corrected_confidence = calculate_segment_confidence(seg.type, corrected_type, features)
        
        # 4. 检查是否需要拆分段落
        if needs_split(seg_energy, seg_centroid):
            split_point = find_split_point(seg_energy, seg_centroid)
            split_time = seg.start_time + (split_point / frame_rate)
            
            # 拆分为两段
            seg1 = create_corrected_segment(
                seg, seg.start_time, split_time, features, 
                determine_type_for_subsegment(seg, 0, split_point, features)
            )
            seg2 = create_corrected_segment(
                seg, split_time, seg.end_time, features,
                determine_type_for_subsegment(seg, split_point, len(seg_energy), features)
            )
            corrected_segments.extend([seg1, seg2])
        else:
            corrected_seg = {
                **seg,
                "type": corrected_type,
                "confidence": corrected_confidence,
                "energy_level": normalize_energy(avg_energy),
                "energy_trend": energy_trend,
                "energy_range": energy_range,
                "spectral_brightness": normalize_centroid(avg_centroid),
                "original_type": seg.type
            }
            corrected_segments.append(corrected_seg)
    
    # 5. 合并过短的相邻段落
    corrected_segments = merge_short_segments(corrected_segments, min_duration=2.0)
    
    # 6. 重新编号
    for i, seg in enumerate(corrected_segments):
        seg["id"] = f"seg_{i:03d}"
        seg["index"] = i
    
    return corrected_segments

def classify_segment_type(original_type, features):
    """
    基于特征向量分类段落类型
    使用规则推理 + 特征匹配
    """
    score_matrix = {}
    
    # 对每种类型计算匹配分数
    for seg_type in SEGMENT_TYPE_PROFILES:
        profile = SEGMENT_TYPE_PROFILES[seg_type]
        score = 0
        
        # 能量水平匹配
        energy_match = 1.0 - abs(features["avg_energy"] - profile["typical_energy"])
        score += 0.30 * energy_match
        
        # 能量趋势匹配
        if features["energy_trend"] == profile["typical_trend"]:
            score += 0.20
        else:
            score += 0.05
        
        # 时长匹配
        duration = features["duration"]
        typical_dur = profile["typical_duration"]
        duration_match = max(0, 1.0 - abs(duration - typical_dur) / typical_dur)
        score += 0.20 * duration_match
        
        # 频谱亮度匹配
        brightness_match = 1.0 - abs(features["spectral_brightness"] - profile["typical_brightness"])
        score += 0.15 * brightness_match
        
        # 原始类型的先验权重
        if seg_type == original_type:
            score += 0.15
        
        score_matrix[seg_type] = score
    
    # 返回最高分的类型
    return max(score_matrix, key=score_matrix.get)
```

### 4.2 段落边界精度校准

原始段落边界可能存在数十到数百毫秒的误差，需要通过能量突变点和节拍位置进行精确校准。

**校准策略：**

```
原始边界（粗略，~500ms误差）
    │
    ▼
┌─────────────────────────┐
│ 1. 能量突变点检测        │ → 找到能量变化最快的位置
└───────────┬─────────────┘
            │
            ▼
┌─────────────────────────┐
│ 2. 节拍对齐              │ → 将边界对齐到最近的节拍点
└───────────┬─────────────┘
            │
            ▼
┌─────────────────────────┐
│ 3. 频谱通量验证          │ → 用频谱变化确认边界
└───────────┬─────────────┘
            │
            ▼
精确边界（10ms级）
```

```python
def calibrate_segment_boundaries(segments, music_atom, beat_grid):
    """
    精确校准段落边界到10ms级
    
    策略：
    1. 在原始边界±1s范围内搜索能量变化率最大的点
    2. 将边界对齐到最近的重拍或次重拍
    3. 用频谱通量突变点验证
    """
    energy_curve = music_atom.energy.rms_curve
    spectral_flux = music_atom.spectrum.spectral_flux
    frame_rate = len(energy_curve) / music_atom.metadata.duration
    
    calibrated_segments = []
    
    for i, seg in enumerate(segments):
        # 校准开始边界
        if i == 0:
            # 第一个段落，从0开始
            calibrated_start = 0.0
        else:
            calibrated_start = calibrate_boundary(
                seg.start_time, energy_curve, spectral_flux,
                beat_grid, frame_rate, direction="start"
            )
        
        # 校准结束边界
        if i == len(segments) - 1:
            # 最后一个段落，到音乐结束
            calibrated_end = music_atom.metadata.duration
        else:
            calibrated_end = calibrate_boundary(
                seg.end_time, energy_curve, spectral_flux,
                beat_grid, frame_rate, direction="end"
            )
        
        calibrated_seg = {
            **seg,
            "start_time": calibrated_start,
            "end_time": calibrated_end,
            "duration": calibrated_end - calibrated_start,
            "boundary_precision": "fine"  # coarse/fine/exact
        }
        calibrated_segments.append(calibrated_seg)
    
    return calibrated_segments

def calibrate_boundary(original_time, energy_curve, spectral_flux, beat_grid, frame_rate, direction):
    """
    校准单个边界点
    """
    # 搜索窗口：±1秒
    search_window = 1.0
    original_frame = int(original_time * frame_rate)
    start_frame = max(0, int((original_time - search_window) * frame_rate))
    end_frame = min(len(energy_curve), int((original_time + search_window) * frame_rate))
    
    # 1. 计算能量变化率（一阶导数）
    energy_derivative = np.gradient(energy_curve[start_frame:end_frame])
    
    # 2. 找到能量变化率绝对值最大的点
    if direction == "start":
        # 开始边界：找能量从低变高的上升沿
        max_deriv_idx = np.argmax(energy_derivative)
    else:
        # 结束边界：找能量从高变低的下降沿
        max_deriv_idx = np.argmin(energy_derivative)
    
    energy_boundary_frame = start_frame + max_deriv_idx
    
    # 3. 用频谱通量加权确认
    flux_derivative = np.gradient(spectral_flux[start_frame:end_frame])
    flux_max_idx = np.argmax(np.abs(flux_derivative))
    flux_boundary_frame = start_frame + flux_max_idx
    
    # 能量和频谱的加权平均
    boundary_frame = int(0.6 * energy_boundary_frame + 0.4 * flux_boundary_frame)
    
    # 4. 对齐到最近的节拍点（优先重拍）
    boundary_time = boundary_frame / frame_rate
    
    # 找最近的节拍
    nearest_beat = find_nearest_beat(boundary_time, beat_grid, max_offset=0.3)
    
    if nearest_beat:
        final_time = nearest_beat["time"]
    else:
        final_time = boundary_time
    
    return round(final_time, 3)  # 精确到毫秒级
```

```python
def calculate_segment_energy_ladder(segment, music_atom, num_steps=8):
    """
    计算段落的能量梯级 Schema
    """
    energy_curve = music_atom.energy.rms_curve
    frame_rate = len(energy_curve) / music_atom.metadata.duration
    
    start_frame = int(segment["start_time"] * frame_rate)
    end_frame = int(segment["end_time"] * frame_rate)
    seg_energy = energy_curve[start_frame:end_frame]
    
    # 归一化到0-1
    seg_energy_norm = (seg_energy - seg_energy.min()) / (seg_energy.max() - seg_energy.min() + 1e-8)
    
    # 重采样到固定点数（用于能量梯级）
    resampled = np.interp(
        np.linspace(0, 1, num_steps + 1),
        np.linspace(0, 1, len(seg_energy_norm)),
        seg_energy_norm
    )
    
    # 计算能量梯级步骤
    ladder_steps = []
    duration = segment["end_time"] - segment["start_time"]
    
    for i in range(num_steps + 1):
        t = i * duration / num_steps
        level = resampled[i]
        
        if i == 0:
            step_type = "entry"
        elif i == num_steps:
            step_type = "exit"
        else:
            prev_level = resampled[i-1]
            next_level = resampled[i+1] if i < num_steps else level
            
            if level > prev_level and level > next_level:
                step_type = "peak"
            elif level < prev_level and level < next_level:
                step_type = "valley"
            elif level > prev_level:
                step_type = "rise"
            elif level < prev_level:
                step_type = "fall"
            else:
                step_type = "plateau"
        
        ladder_steps.append({
            "time": round(t, 3),
            "level": round(float(level), 4),
            "step_type": step_type,
            "duration": round(duration / num_steps, 3)
        })
    
    # 计算ADSR包络
    peak_idx = np.argmax(seg_energy_norm)
    peak_time = peak_idx / frame_rate
    
    # Attack: 从10%到90%峰值的时间
    peak_val = seg_energy_norm[peak_idx]
    attack_start = find_first_crossing(seg_energy_norm, peak_val * 0.1, 0, peak_idx)
    attack_end = find_first_crossing(seg_energy_norm, peak_val * 0.9, 0, peak_idx)
    attack = (attack_end - attack_start) / frame_rate if attack_start >= 0 and attack_end >= 0 else 0
    
    # Release: 从90%到10%峰值的时间（从峰值后）
    release_start = find_last_crossing(seg_energy_norm, peak_val * 0.9, peak_idx, len(seg_energy_norm))
    release_end = find_last_crossing(seg_energy_norm, peak_val * 0.1, peak_idx, len(seg_energy_norm))
    release = (release_end - release_start) / frame_rate if release_start >= 0 and release_end >= 0 else 0
    
    return {
        "segment_id": segment["id"],
        "overall_level": float(np.mean(seg_energy_norm)),
        "entry_level": float(seg_energy_norm[0]),
        "peak_level": float(peak_val),
        "peak_time": round(peak_time, 3),
        "exit_level": float(seg_energy_norm[-1]),
        "energy_curve_resampled": [round(float(x), 4) for x in resampled],
        "ladder_steps": ladder_steps,
        "dynamics": {
            "attack": round(attack, 3),
            "decay": 0.0,  # 简化，可进一步计算
            "sustain": float(np.mean(seg_energy_norm[peak_idx:])) if peak_idx < len(seg_energy_norm) else 0,
            "release": round(release, 3),
            "shape": determine_energy_shape(seg_energy_norm)
        }
    }
```

## 第5章 能量层推理

### 5.1 6频段能量曲线计算

能量层将音频频谱分解为6个标准频段，为后续的效果绑定和音效匹配提供频域依据。

**6频段划分标准：**

| 频段编号 | 名称 | 频率范围 | 感知特征 | 典型关联 |
|---------|------|---------|---------|---------|
| Band 1 | Sub Bass 超低音 | 20-60 Hz | 身体感、震撼 | 底鼓、贝斯、爆炸 |
| Band 2 | Bass 低音 | 60-250 Hz | 节奏基础、厚度 | 贝斯、底鼓主体 |
| Band 3 | Low Mid 中低音 | 250-500 Hz | 温暖度、浑浊度 | 人声基频、吉他 |
| Band 4 | Mid 中音 | 500-2000 Hz | 清晰度、主体感 | 人声、主乐器 |
| Band 5 | High Mid 中高音 | 2000-6000 Hz | 临场感、穿透力 | 镲片、人声高频 |
| Band 6 | Treble 高音 | 6000-20000 Hz | 空气感、细节 | 高频泛音、呼吸声 |

```python
def calculate_six_band_energy(audio, sr, frame_size=2048, hop_size=512):
    """
    计算6频段能量曲线
    
    输入：
        audio: 音频波形数组
        sr: 采样率
        frame_size: STFT帧大小
        hop_size: 帧移
    
    输出：
        bands: 6个频段的能量曲线
    """
    # 1. 计算STFT
    stft = librosa.stft(audio, n_fft=frame_size, hop_length=hop_size)
    magnitude = np.abs(stft)
    power = magnitude ** 2  # 功率谱
    
    # 频率轴
    freqs = librosa.fft_frequencies(sr=sr, n_fft=frame_size)
    
    # 2. 定义6个频段边界
    band_edges = [
        (20, 60),       # Sub Bass
        (60, 250),      # Bass
        (250, 500),     # Low Mid
        (500, 2000),    # Mid
        (2000, 6000),   # High Mid
        (6000, 20000)   # Treble
    ]
    
    # 3. 计算每个频段的能量
    bands = []
    for low_freq, high_freq in band_edges:
        # 找到频率范围内的频率bin
        low_bin = np.argmin(np.abs(freqs - low_freq))
        high_bin = np.argmin(np.abs(freqs - high_freq))
        
        # 计算该频段的总能量（每帧）
        band_energy = np.sum(power[low_bin:high_bin, :], axis=0)
        
        # 归一化
        band_energy_norm = band_energy / (high_bin - low_bin)
        
        bands.append({
            "name": ["sub_bass", "bass", "low_mid", "mid", "high_mid", "treble"][len(bands)],
            "frequency_range": [low_freq, high_freq],
            "energy_curve": band_energy_norm.tolist(),
            "average_energy": float(np.mean(band_energy_norm)),
            "peak_energy": float(np.max(band_energy_norm))
        })
    
    return bands
```

### 5.2 能量峰值检测

检测能量曲线上的所有局部峰值（峰），用于确定卡点位置和效果触发时机。

```python
def detect_energy_peaks(energy_curve, min_prominence=0.1, min_distance=3):
    """
    检测能量曲线上的峰值点
    
    使用改进的局部最大值算法，结合峰值突出度（prominence）过滤
    
    输入：
        energy_curve: 能量曲线数组
        min_prominence: 最小突出度（峰值与周围谷值的差）
        min_distance: 峰值之间的最小距离（帧）
    
    输出：
        peaks: 峰值列表，每个包含位置、值、突出度
    """
    peaks = []
    n = len(energy_curve)
    
    for i in range(1, n - 1):
        # 1. 检查是否为局部最大值
        if energy_curve[i] <= energy_curve[i-1] or energy_curve[i] <= energy_curve[i+1]:
            continue
        
        # 2. 向左找谷值
        left_valley = i - 1
        while left_valley > 0 and energy_curve[left_valley - 1] <= energy_curve[left_valley]:
            left_valley -= 1
        
        # 向右找谷值
        right_valley = i + 1
        while right_valley < n - 1 and energy_curve[right_valley + 1] <= energy_curve[right_valley]:
            right_valley += 1
        
        # 3. 计算突出度
        left_base = energy_curve[left_valley]
        right_base = energy_curve[right_valley]
        base = max(left_base, right_base)
        prominence = energy_curve[i] - base
        
        if prominence < min_prominence:
            continue
        
        peaks.append({
            "index": i,
            "time": i,  # 后面再转换为秒
            "value": float(energy_curve[i]),
            "prominence": float(prominence),
            "width_left": i - left_valley,
            "width_right": right_valley - i,
            "width": right_valley - left_valley,
            "steepness_left": prominence / (i - left_valley) if i > left_valley else 0,
            "steepness_right": prominence / (right_valley - i) if right_valley > i else 0
        })
    
    # 4. 按最小距离过滤（保留突出度高的）
    peaks.sort(key=lambda p: p["prominence"], reverse=True)
    filtered_peaks = []
    used_positions = set()
    
    for peak in peaks:
        # 检查周围是否已有更高的峰值
        too_close = False
        for pos in used_positions:
            if abs(peak["index"] - pos) < min_distance:
                too_close = True
                break
        
        if not too_close:
            filtered_peaks.append(peak)
            used_positions.add(peak["index"])
    
    # 恢复按时间排序
    filtered_peaks.sort(key=lambda p: p["index"])
    
    return filtered_peaks
```

### 5.3 能量谷值检测

与峰值对应，谷值代表能量的低点，常用于转场和效果释放。

```python
def detect_energy_valleys(energy_curve, min_prominence=0.1, min_distance=3):
    """
    检测能量谷值（通过反转曲线后使用峰值检测算法）
    """
    inverted_curve = 1.0 - (energy_curve - energy_curve.min()) / (energy_curve.max() - energy_curve.min() + 1e-8)
    inverted_peaks = detect_energy_peaks(inverted_curve, min_prominence, min_distance)

    for inv_peak in inverted_peaks:

            "index": idx,
            "time": idx,
            "value": float(energy_curve[idx]),
            "prominence": float(inv_peak["prominence"]),
            "width": inv_peak["width"]
        })
    
    return valleys
```

### 5.4 能量变化率（导数）计算

能量的变化率（一阶导数）反映能量变化的速度，用于检测冲击、爆发、渐强渐弱等动态特征。

```python
def calculate_energy_derivatives(energy_curve, frame_time):
    """
    计算能量曲线的一阶和二阶导数
    
    输入：
        energy_curve: 能量曲线
        frame_time: 每帧的时间间隔（秒）
    
    输出：
        first_derivative: 一阶导数（能量变化率）
        second_derivative: 二阶导数（加速度）
        feature_points: 特征点列表
    """
    # 1. 一阶导数（变化率）
    first_derivative = np.gradient(energy_curve, frame_time)
    
    # 2. 二阶导数（加速度）
    second_derivative = np.gradient(first_derivative, frame_time)
    
    # 3. 检测特征点
    feature_points = []
    
    for i in range(1, len(energy_curve) - 1):
        # 过零点（一阶导数符号变化 = 极值点）
        if first_derivative[i-1] * first_derivative[i] < 0:
            if first_derivative[i-1] > 0:
                point_type = "peak"  # 正→负 = 峰
            else:
                point_type = "valley"  # 负→正 = 谷
            
            feature_points.append({
                "index": i,
                "time": i * frame_time,
                "type": point_type,
                "value": float(energy_curve[i]),
                "derivative": 0.0
            })
        
        # 拐点（二阶导数符号变化 = 斜率变化方向）
        if i > 1 and second_derivative[i-1] * second_derivative[i] < 0:
            if second_derivative[i-1] > 0:
                inflection_type = "decelerating"  # 加速→减速
            else:
                inflection_type = "accelerating"  # 减速→加速
            
            feature_points.append({
                "index": i,
                "time": i * frame_time,
                "type": "inflection",
                "inflection_type": inflection_type,
                "value": float(energy_curve[i]),
                "derivative": float(first_derivative[i])
            })
    
    return {
        "first_derivative": first_derivative.tolist(),
        "second_derivative": second_derivative.tolist(),
        "feature_points": feature_points,
        "max_rate_of_rise": float(np.max(first_derivative)),
        "max_rate_of_fall": float(np.min(first_derivative)),
        "avg_rate_change": float(np.mean(np.abs(first_derivative)))
    }
```

### 5.5 能量 Schema 分箱（9箱模型）

将能量水平（低/中/高）× 频段（低/中/高）组合成9个能量箱，用于快速效果匹配。

```
              频段
         低    中    高
      ┌────┬────┬────┐
  高  │ L-H│ M-H│ H-H│  高能级
  能  ├────┼────┼────┤
  量  中  │ L-M│ M-M│ H-M│  中能级
  水  ├────┼────┼────┤
  平  低  │ L-L│ M-L│ H-L│  低能级
      └────┴────┴────┘
```

| 箱体编号 | 能量水平 | 频段 | 典型效果 |
|---------|---------|------|---------|
| Box 1 | 高能 | 低频 | 重低音冲击、爆炸、地震 |
| Box 2 | 高能 | 中频 | 人声强调、主乐器突出 |
| Box 3 | 高能 | 高频 | 闪烁、闪光、细节增强 |
| Box 4 | 中能 | 低频 | 脉搏、心跳感 |
| Box 5 | 中能 | 中频 | 稳定推进 |
| Box 6 | 中能 | 高频 | 轻微闪烁 |
| Box 7 | 低能 | 低频 | 深沉、压迫感 |

```python
def calculate_energy_bins(bands, num_levels=3):
    """
    计算9箱能量模型（3能量水平 × 3频段组）
    
    频段组：
        - 低频组：sub_bass + bass
        - 中频组：low_mid + mid
        - 高频组：high_mid + treble
    """
    # 合并为3个频段组
    low_freq_group = combine_bands(bands[0], bands[1])
    mid_freq_group = combine_bands(bands[2], bands[3])
    high_freq_group = combine_bands(bands[4], bands[5])
    
    freq_groups = [low_freq_group, mid_freq_group, high_freq_group]
    freq_group_names = ["low", "mid", "high"]
    
    # 计算每个频段组的能量分位数
    bins = {}
    
    for i, (group, gname) in enumerate(zip(freq_groups, freq_group_names)):
        energy_curve = np.array(group["energy_curve"])
        
        # 归一化
        norm_curve = (energy_curve - energy_curve.min()) / (energy_curve.max() - energy_curve.min() + 1e-8)
        
        # 计算分箱阈值
        thresholds = np.linspace(0, 1, num_levels + 1)[1:-1]  # 中间两个阈值
        
        # 为每个时间点分配能量水平
        for t in range(len(norm_curve)):
            val = norm_curve[t]
            
            if val < thresholds[0]:
                level = "low"
            elif val < thresholds[1]:
                level = "mid"
            else:
                level = "high"
            
            bin_key = f"{level}_{gname}"
            if bin_key not in bins:
                bins[bin_key] = {
                    "energy_level": level,
                    "freq_group": gname,
                    "time_fraction": 0.0,
                    "count": 0,
                    "avg_value": 0.0
                }
            bins[bin_key]["count"] += 1
            bins[bin_key]["avg_value"] += val
    
    # 计算比例
    total_frames = len(low_freq_group["energy_curve"])
    for bin_key in bins:
        bins[bin_key]["time_fraction"] = bins[bin_key]["count"] / total_frames
        bins[bin_key]["avg_value"] /= bins[bin_key]["count"]
    
    return bins

def combine_bands(band1, band2):
    """将两个频段合并为一个频段组"""
    curve1 = np.array(band1["energy_curve"])
    curve2 = np.array(band2["energy_curve"])
    
    combined = (curve1 + curve2) / 2
    
    return {
        "name": f"{band1['name']}_{band2['name']}",
        "energy_curve": combined.tolist(),
        "average_energy": float(np.mean(combined)),
        "peak_energy": float(np.max(combined))
    }
```

## 第6章 情绪层推理

### 6.1 逐秒 valence-arousal 计算

情绪层基于能量、频谱、调式等多维度特征，计算逐秒的 valence-arousal（情绪价-唤醒度）值。

**Valence-Arousal 模型：**

```
         Arousal (唤醒度)
              ↑
              │
     激动   │   愉悦
  (高唤醒)  │  (高唤醒)
  负价     │     正价
              │
←─────────────┼─────────────→ Valence (情绪价)
负价          │            正价
              │
     忧郁   │   平静
  (低唤醒)  │  (低唤醒)
  负价     │     正价
              │
              ↓
```

```python
def calculate_valence_arousal(music_atom, resolution=1.0):
    """
    计算逐秒的 valence-arousal 值
    
    输入：
        music_atom: 音乐原子
        resolution: 时间分辨率（秒）
    
    输出：
        va_curve: [{time, valence, arousal}]
    """
    duration = music_atom.metadata.duration
    num_points = int(duration / resolution)
    
    # 获取特征曲线
    energy_curve = music_atom.energy.rms_curve
    energy_frame_rate = len(energy_curve) / duration
    
    spectral_centroid = music_atom.spectrum.spectral_centroid
    spec_frame_rate = len(spectral_centroid) / duration
    
    mode = music_atom.tonality.mode  # major/minor
    key_confidence = music_atom.tonality.key_confidence
    
    # 流派先验
    genre = music_atom.genre.primary
    genre_va_prior = get_genre_va_prior(genre)
    
    va_curve = []
    
    for i in range(num_points):
        t = i * resolution
        
        # 1. 能量 → 唤醒度（主要贡献）
        energy_frame = int(t * energy_frame_rate)
        if energy_frame < len(energy_curve):
            energy_val = energy_curve[energy_frame]
        else:
            energy_val = 0.5
        
        # 2. 频谱质心 → 唤醒度 + 情绪价
        spec_frame = int(t * spec_frame_rate)
        if spec_frame < len(spectral_centroid):
            centroid_val = normalize_centroid(spectral_centroid[spec_frame])
        else:
            centroid_val = 0.5
        
        # 3. 调式 → 情绪价（大调积极，小调消极）
        mode_valence = 1.0 if mode == "major" else -1.0
        mode_weight = key_confidence * 0.3  # 调式的贡献权重
        
        # 4. 计算Arousal（唤醒度）
        arousal = (
            0.50 * energy_val +
            0.30 * centroid_val +
            0.20 * genre_va_prior["arousal"]
        )
        arousal = max(0.0, min(1.0, arousal))
        
        # 5. 计算Valence（情绪价）
        valence = (
            mode_valence * mode_weight +
            0.20 * centroid_val +  # 高频多偏积极
            genre_va_prior["valence"] * 0.2
        )
        valence = max(-1.0, min(1.0, valence))
        
        # 6. 能量动态对valence的调制
        # 能量上升 → 更积极；能量下降 → 更消极
        if energy_frame > 0 and energy_frame < len(energy_curve) - 1:
            energy_trend = energy_curve[energy_frame] - energy_curve[energy_frame - 1]
            valence += energy_trend * 0.5
            valence = max(-1.0, min(1.0, valence))
        
        va_curve.append({
            "time": round(t, 3),
            "valence": round(valence, 4),
            "arousal": round(arousal, 4),
            "energy_component": round(energy_val, 4),
            "centroid_component": round(centroid_val, 4)
        })
    
    return va_curve

def get_genre_va_prior(genre):
    """获取流派的先验valence-arousal值"""
    genre_priors = {
        "electronic": {"valence": 0.3, "arousal": 0.8},
        "pop": {"valence": 0.5, "arousal": 0.6},
        "rock": {"valence": 0.2, "arousal": 0.8},
        "hip_hop": {"valence": 0.1, "arousal": 0.7},
        "jazz": {"valence": 0.4, "arousal": 0.3},
        "classical": {"valence": 0.2, "arousal": 0.2},
        "ambient": {"valence": 0.3, "arousal": 0.1},
        "film_score": {"valence": 0.1, "arousal": 0.5}
    }
    return genre_priors.get(genre, {"valence": 0.0, "arousal": 0.5})
```

### 6.2 情绪段划分

将连续的VA曲线划分为离散的情绪段（稳定情绪段和过渡情绪段），便于段落级的效果和片段匹配。

```python
def segment_emotion_curve(va_curve, stability_threshold=0.15):
    """
    划分情绪段
    
    稳定情绪段：valence和arousal变化都很小
    过渡情绪段：valence或arousal有显著变化
    """
    segments = []
    current_segment = None
    
    for i, point in enumerate(va_curve):
        if current_segment is None:
            current_segment = {
                "start_time": point["time"],
                "start_valence": point["valence"],
                "start_arousal": point["arousal"],
                "type": "unknown",
                "points": [point]
            }
            continue
        
        # 计算与段起点的变化量
        v_change = abs(point["valence"] - current_segment["start_valence"])
        a_change = abs(point["arousal"] - current_segment["start_arousal"])
        
        # 判断是否需要分割
        is_stable = v_change < stability_threshold and a_change < stability_threshold
        
        if current_segment["type"] == "unknown":
            current_segment["type"] = "stable" if is_stable else "transition"
        
        # 如果类型发生变化，分割
        new_type = "stable" if is_stable else "transition"
        
        if new_type != current_segment["type"] and len(current_segment["points"]) >= 3:
            # 结束当前段
            end_segment(current_segment, va_curve[i-1])
            segments.append(current_segment)
            
            # 开始新段
            current_segment = {
                "start_time": point["time"],
                "start_valence": point["valence"],
                "start_arousal": point["arousal"],
                "type": new_type,
                "points": [point]
            }
        else:
            current_segment["points"].append(point)
    
    # 处理最后一段
    if current_segment:
        end_segment(current_segment, va_curve[-1])
        segments.append(current_segment)
    
    # 合并过短的段
    segments = merge_short_emotion_segments(segments, min_duration=2.0)
    
    return segments

def end_segment(segment, end_point):
    """完成情绪段的计算"""
    points = segment["points"]
    valences = [p["valence"] for p in points]
    arousals = [p["arousal"] for p in points]
    
    segment["end_time"] = end_point["time"]
    segment["duration"] = end_point["time"] - segment["start_time"]
    segment["end_valence"] = end_point["valence"]
    segment["end_arousal"] = end_point["arousal"]
    segment["avg_valence"] = np.mean(valences)
    segment["avg_arousal"] = np.mean(arousals)
    segment["valence_range"] = max(valences) - min(valences)
    segment["arousal_range"] = max(arousals) - min(arousals)
    
    # 情绪象限
    segment["emotion_quadrant"] = get_emotion_quadrant(
        segment["avg_valence"], segment["avg_arousal"]
    )
    
    del segment["points"]
```

### 6.4 情绪高潮点检测

精确检测情绪高潮点，这是整个剪辑中视觉效果最强的时刻。

```python
def detect_emotional_climax_points(va_curve, energy_peaks, segments):
    """
    检测情绪高潮点
    
    综合考虑：
    1. 情绪强度峰值（|valence| × arousal）
    2. 能量峰值
    3. 段落类型（副歌/drop优先）
    """
    # 计算情绪强度曲线
    intensity_curve = []
    for point in va_curve:
        intensity = abs(point["valence"]) * point["arousal"]
        intensity_curve.append({
            "time": point["time"],
            "intensity": intensity,
            "valence": point["valence"],
            "arousal": point["arousal"]
        })
    
    # 检测强度峰值
    intensity_values = [p["intensity"] for p in intensity_curve]
    intensity_peaks = detect_energy_peaks(np.array(intensity_values), 
                                          min_prominence=0.1,
                                          min_distance=5)
    
    # 为每个强度峰值计算综合分数
    scored_climaxes = []
    
    for peak in intensity_peaks:
        t = peak["time"]  # 这里是索引，需要转换
        actual_time = intensity_curve[peak["index"]]["time"]
        intensity_val = peak["value"]
        
        # 1. 情绪强度分（已计算）
        intensity_score = intensity_val
        
        # 2. 能量匹配分（附近是否有能量峰值）
        energy_score = 0.0
        for e_peak in energy_peaks:
            if abs(e_peak["time"] - actual_time) < 2.0:
                energy_score = max(energy_score, e_peak["prominence"])
        
        # 3. 段落权重分
        segment_score = 0.0
        for seg in segments:
            if seg.start_time <= actual_time <= seg.end_time:
                seg_weights = {
                    "chorus": 1.0,
                    "drop": 1.0,
                    "pre_chorus": 0.7,
                    "bridge": 0.6,
                    "verse": 0.4,
                    "buildup": 0.8,
                    "breakdown": 0.3,
                    "intro": 0.2,
                    "outro": 0.2
                }
                segment_score = seg_weights.get(seg.type, 0.5)
                break
        
        # 综合分数
        total_score = (
            0.50 * intensity_score +
            0.30 * energy_score +
            0.20 * segment_score
        )
        
        scored_climaxes.append({
            "time": round(actual_time, 3),
            "intensity": round(intensity_val, 4),
            "valence": intensity_curve[peak["index"]]["valence"],
            "arousal": intensity_curve[peak["index"]]["arousal"],
            "energy_score": round(energy_score, 4),
            "segment_score": segment_score,
            "total_score": round(total_score, 4),
            "level": "primary" if total_score > 0.7 else "secondary"
        })
    
    # 按总分排序
    scored_climaxes.sort(key=lambda x: x["total_score"], reverse=True)
    
    # 划分主/次高潮
    primary_climaxes = [c for c in scored_climaxes if c["level"] == "primary"]
    secondary_climaxes = [c for c in scored_climaxes if c["level"] == "secondary"]
    
    return {
        "primary_climaxes": primary_climaxes[:3],  # 最多3个主高潮
        "secondary_climaxes": secondary_climaxes[:5],
        "all_climaxes": scored_climaxes
    }
```

### 7.1 节拍-片段动态规划对齐

使用动态规划（DP）算法将片段对齐到节拍网格，确保每个切镜点都落在节拍上。

```python
def align_clips_to_beats_dp(beat_grid, clip_atoms, target_duration, preferences):
    """
    动态规划：将片段序列对齐到节拍点
    
    状态定义：
        dp[i][j] = 用前i个片段覆盖到第j个节拍的最小代价
    
    代价函数：
        cost = 对齐误差 + 切分次数惩罚 + 能量不匹配惩罚
    """
    n_clips = len(clip_atoms)
    n_beats = len(beat_grid)
    
    # 初始化DP表
    INF = float('inf')
    dp = [[INF] * (n_beats + 1) for _ in range(n_clips + 1)]
    dp[0][0] = 0
    
    # 记录路径
    parent = [[None] * (n_beats + 1) for _ in range(n_clips + 1)]
    
    # 预处理：每个片段的能量曲线（用于能量匹配）
    clip_energy_curves = [clip.energy.energy_curve for clip in clip_atoms]
    
    for i in range(1, n_clips + 1):
        clip = clip_atoms[i - 1]
        clip_duration = clip.metadata.duration
        clip_energy = clip.energy.visual_energy
        
        for j in range(1, n_beats + 1):
            # 尝试所有可能的起始节拍k
            for k in range(max(0, j - 32), j):  # 最多32拍的窗口
                if dp[i-1][k] == INF:
                    continue
                
                # 第i个片段从第k拍开始，到第j拍结束
                start_time = beat_grid[k] if k < n_beats else 0
                end_time = beat_grid[j-1] if j-1 < n_beats else target_duration
                segment_duration = end_time - start_time
                
                if segment_duration <= 0:
                    continue
                
                # 1. 时长对齐代价
                duration_cost = abs(segment_duration - clip_duration) / clip_duration
                
                # 2. 切分惩罚
                split_penalty = 0.0
                if segment_duration < clip_duration * 0.5:
                    split_penalty = 0.5  # 切得太碎，惩罚
                elif segment_duration < clip_duration:
                    split_penalty = 0.2
                
                # 3. 能量匹配代价（音乐能量 vs 片段能量）
                music_energy_at_segment = get_avg_music_energy(start_time, end_time, beat_grid)
                energy_mismatch = abs(music_energy_at_segment - clip_energy)
                energy_cost = energy_mismatch * 0.5
                
                # 4. 最小时长检查
                min_duration = preferences.advanced.min_clip_duration if preferences.advanced else 0.5
                if segment_duration < min_duration:
                    continue
                
                # 总代价
                cost = (
                    0.40 * duration_cost +
                    0.25 * split_penalty +
                    0.35 * energy_cost
                )
                
                total_cost = dp[i-1][k] + cost
                
                if total_cost < dp[i][j]:
                    dp[i][j] = total_cost
                    parent[i][j] = (k, i - 1)
    
    # 回溯找最优路径
    alignment = []
    i, j = n_clips, n_beats
    
    # 如果没用完所有节拍，找到最好的结束点
    if dp[n_clips][n_beats] == INF:
        # 找到最小代价的结束点
        best_j = min(range(n_beats + 1), key=lambda jj: dp[n_clips][jj])
        j = best_j
    
    while i > 0 and j > 0:
        if parent[i][j] is None:
            i -= 1
            continue
        
        k, prev_i = parent[i][j]
        
        start_time = beat_grid[k] if k < n_beats else 0
        end_time = beat_grid[j-1] if j-1 < n_beats else target_duration
        
        alignment.append({
            "clip_index": prev_i,
            "start_beat_index": k,
            "end_beat_index": j - 1,
            "start_time": round(start_time, 3),
            "end_time": round(end_time, 3),
            "duration": round(end_time - start_time, 3),
            "clip_start_offset": 0.0,  # 片段内的起始偏移
            "playback_speed": 1.0
        })
        
        i, j = prev_i, k
    
    alignment.reverse()
    
    return {
        "alignment": alignment,
        "total_cost": dp[n_clips][j] if j < len(dp[0]) else INF,
        "coverage_ratio": (alignment[-1]["end_time"] if alignment else 0) / target_duration
    }
```

### 7.2 段落-片段匈牙利算法配对

当片段数量有限时，使用匈牙利算法（Hungarian Algorithm）进行最优的段落-片段配对，最大化整体匹配度。

```python
def match_segments_clips_hungarian(segments, clip_atoms, preferences):
    """
    匈牙利算法：段落-片段最优配对
    
    构建代价矩阵，找到最小代价匹配
    代价 = 1 - 匹配度（能量/色彩/运动/语义等）
    """
    n_segments = len(segments)
    n_clips = len(clip_atoms)
    
    # 构建代价矩阵（n_segments × n_clips）
    cost_matrix = np.zeros((n_segments, n_clips))
    
    for i, seg in enumerate(segments):
        seg_energy = seg.energy.overall_level if hasattr(seg.energy, 'overall_level') else 0.5
        seg_mood = seg.emotion.mood_tags if hasattr(seg.emotion, 'mood_tags') else []
        seg_type = seg.type
        
        for j, clip in enumerate(clip_atoms):
            # 计算匹配度（0-1，越高越好）
            match_score = calculate_segment_clip_match(seg, clip, preferences)
            
            # 代价 = 1 - 匹配度
            cost_matrix[i][j] = 1.0 - match_score
    
    # 匈牙利算法求解最小代价匹配
    # 使用 scipy.optimize.linear_sum_assignment
    try:
        from scipy.optimize import linear_sum_assignment
        row_ind, col_ind = linear_sum_assignment(cost_matrix)
    except ImportError:
        # 备用：简单的贪心匹配
        row_ind, col_ind = greedy_matching(cost_matrix)
    
    # 构建配对结果
    pairs = []
    for row, col in zip(row_ind, col_ind):
        pairs.append({
            "segment_id": segments[row].id,
            "segment_index": row,
            "clip_index": col,
            "match_score": 1.0 - cost_matrix[row][col],
            "assignment_type": "primary"
        })
    
    # 处理未分配的片段（用于重复使用）
    assigned_clips = set(col_ind)
    unassigned_clips = [j for j in range(n_clips) if j not in assigned_clips]
    
    # 为重复段落分配次优片段
    all_pairs = pairs.copy()
    for i in range(n_segments):
        if i in row_ind:
            continue
        
        # 找最好的可用片段
        if unassigned_clips:
            best_clip = min(unassigned_clips, key=lambda j: cost_matrix[i][j])
            all_pairs.append({
                "segment_id": segments[i].id,
                "segment_index": i,
                "clip_index": best_clip,
                "match_score": 1.0 - cost_matrix[i][best_clip],
                "assignment_type": "secondary"
            })
            unassigned_clips.remove(best_clip)
        else:
            # 所有片段都用过了，允许重复使用
            best_clip = min(range(n_clips), key=lambda j: cost_matrix[i][j])
            all_pairs.append({
                "segment_id": segments[i].id,
                "segment_index": i,
                "clip_index": best_clip,
                "match_score": 1.0 - cost_matrix[i][best_clip],
                "assignment_type": "reused"
            })
    
    # 按段排序
    all_pairs.sort(key=lambda p: p["segment_index"])
    
    return {
        "pairs": all_pairs,
        "total_match_score": sum(p["match_score"] for p in all_pairs) / n_segments,
        "cost_matrix": cost_matrix.tolist()
    }

def calculate_segment_clip_match(seg, clip, preferences):
    """
    计算段落-片段的匹配度（0-1）
    """
    # 1. 能量匹配（30%）
    seg_energy = seg.energy.overall_level if hasattr(seg.energy, 'overall_level') else 0.5
    clip_energy = clip.energy.visual_energy
    energy_match = 1.0 - abs(seg_energy - clip_energy)
    
    # 2. 情绪匹配（25%）
    seg_valence = seg.emotion.valence if hasattr(seg.emotion, 'valence') else 0.0
    seg_arousal = seg.emotion.arousal if hasattr(seg.emotion, 'arousal') else 0.5
    
    # 从片段情绪标签估计VA
    clip_valence = estimate_clip_valence(clip)
    clip_arousal = clip.motion.overall_intensity
    
    # VA空间距离
    va_distance = np.sqrt((seg_valence - clip_valence)**2 + (seg_arousal - clip_arousal)**2)
    emotion_match = 1.0 - (va_distance / 2.0)  # 最大距离是2（从-1,-1到1,1）
    
    # 3. 运动匹配（20%）
    seg_pace = get_segment_pace(seg)
    clip_motion = clip.motion.overall_intensity
    motion_match = 1.0 - abs(seg_pace - clip_motion)
    
    # 4. 色彩匹配（15%）
    seg_tone = get_segment_color_tone(seg)
    clip_tone = clip.color.temperature
    color_match = 1.0 - abs(seg_tone - clip_tone)
    
    # 5. 语义匹配（10%）
    semantic_match = calculate_semantic_similarity(seg, clip)
    
    # 加权求和
    total_match = (
        0.30 * energy_match +
        0.25 * emotion_match +
        0.20 * motion_match +
        0.15 * color_match +
        0.10 * semantic_match
    )
    
    return max(0.0, min(1.0, total_match))
```

### 7.3 片段排序优化

在确定了每个段落用什么片段后，需要优化片段的排列顺序，确保叙事连贯性、色彩连贯性和运动连贯性。

```python
def optimize_clip_ordering(clip_assignments, clip_atoms, segments):
    """
    优化片段排序，最大化连贯性
    
    使用贪心 + 局部搜索的方法
    """
    if len(clip_assignments) <= 2:
        return clip_assignments
    
    # 1. 构建连贯性矩阵
    n = len(clip_assignments)
    coherence_matrix = np.zeros((n, n))
    
    for i in range(n):
        for j in range(n):
            if i == j:
                coherence_matrix[i][j] = 0
                continue
            
            clip_i = clip_atoms[clip_assignments[i]["clip_index"]]
            clip_j = clip_atoms[clip_assignments[j]["clip_index"]]
            
            coherence_matrix[i][j] = calculate_pair_coherence(clip_i, clip_j)
    
    # 2. 贪心构建初始序列
    remaining = set(range(n))
    ordered = []
    
    # 从能量最低的片段开始（假设是开头）
    start_idx = min(range(n), key=lambda i: clip_atoms[clip_assignments[i]["clip_index"]].energy.visual_energy)
    ordered.append(start_idx)
    remaining.remove(start_idx)
    
    while remaining:
        last = ordered[-1]
        
        # 找下一个最连贯的
        next_idx = max(remaining, key=lambda j: coherence_matrix[last][j])
        ordered.append(next_idx)
        remaining.remove(next_idx)
    
    # 3. 局部搜索优化（2-opt）
    improved = True
    while improved:
        improved = False
        for i in range(1, n - 1):
            for j in range(i + 1, n):
                # 尝试反转i到j之间的顺序
                current_coherence = calculate_sequence_coherence(ordered, coherence_matrix)
                new_order = ordered[:i] + ordered[i:j+1][::-1] + ordered[j+1:]
                new_coherence = calculate_sequence_coherence(new_order, coherence_matrix)
                
                if new_coherence > current_coherence:
                    ordered = new_order
                    improved = True
    
    # 4. 重新映射
    optimized_assignments = [clip_assignments[i] for i in ordered]
    
    return optimized_assignments

def calculate_pair_coherence(clip_a, clip_b):
    """
    计算两个片段之间的连贯度（0-1）
    """
    # 1. 色彩连贯性（主色过渡是否自然）
    color_coherence = calculate_color_coherence(clip_a, clip_b)
    
    # 2. 运动连贯性（运动方向/速度是否衔接）
    motion_coherence = calculate_motion_coherence(clip_a, clip_b)
    
    # 3. 语义连贯性（场景/主体是否相关）
    semantic_coherence = calculate_semantic_similarity_simple(clip_a, clip_b)
    
    # 4. 亮度连贯性
    brightness_diff = abs(clip_a.color.brightness - clip_b.color.brightness)
    brightness_coherence = 1.0 - brightness_diff
    
    return (
        0.30 * color_coherence +
        0.30 * motion_coherence +
        0.25 * semantic_coherence +
        0.15 * brightness_coherence
    )
```

### 7.4 片段时长分配

根据段落能量、片段质量和节奏要求，为每个片段分配最佳时长。

```python
def allocate_clip_durations(segments, clip_assignments, clip_atoms, beat_grid, preferences):
    """
    为每个片段分配时长
    
    原则：
    - 高能量段落 → 更短的片段（更快的节奏）
    - 高质量片段 → 更长的展示时间
    - 节拍对齐 → 时长必须是节拍的整数倍
    """
    allocations = []
    
    for seg_idx, seg in enumerate(segments):
        seg_start = seg.start_time
        seg_end = seg.end_time
        seg_duration = seg_end - seg_start
        seg_energy = seg.energy.overall_level if hasattr(seg.energy, 'overall_level') else 0.5
        
        # 该段落的片段列表
        seg_clips = [a for a in clip_assignments if a["segment_index"] == seg_idx]
        
        if not seg_clips:
            continue
        
        # 1. 计算该段落的基础切镜频率
        pacing = preferences.rhythm.pacing if preferences else "medium"
        base_cut_rate = {
            "slow": 0.5,    # 每秒0.5次切镜（2秒一个镜头）
            "medium": 1.0,  # 每秒1次
            "fast": 2.0,    # 每秒2次
            "dynamic": 1.5
        }.get(pacing, 1.0)
        
        # 能量调制：高能段切得更快
        energy_factor = 0.5 + seg_energy * 1.0  # 0.5x - 1.5x
        cut_rate = base_cut_rate * energy_factor
        
        # 目标镜头数
        target_shots = max(1, int(seg_duration * cut_rate))
        
        # 2. 根据片段质量分配时长权重
        quality_weights = []
        for a in seg_clips:
            clip = clip_atoms[a["clip_index"]]
            quality = clip.quality.overall if hasattr(clip.quality, 'overall') else 0.7
            quality_weights.append(quality)
        
        # 归一化权重
        total_weight = sum(quality_weights)
        if total_weight > 0:
            duration_ratios = [w / total_weight for w in quality_weights]
        else:
            duration_ratios = [1.0 / len(seg_clips)] * len(seg_clips)
        
        # 3. 分配时长（对齐到节拍）
        shots_in_segment = []
        current_time = seg_start
        remaining_shots = target_shots
        remaining_duration = seg_duration
        
        for i, assignment in enumerate(seg_clips):
            if i == len(seg_clips) - 1:
                # 最后一个片段，占满剩余时间
                shot_duration = remaining_duration
            else:
                shot_duration = seg_duration * duration_ratios[i]
                shot_duration = max(0.5, shot_duration)  # 最短0.5秒
            
            # 对齐到最近的节拍
            end_time = current_time + shot_duration
            end_beat = snap_to_beat(end_time, beat_grid, direction="nearest")
            shot_duration = end_beat - current_time
            
            # 确保不超过段落边界
            if end_beat > seg_end:
                end_beat = seg_end
                shot_duration = end_beat - current_time
            
            shots_in_segment.append({
                **assignment,
                "segment_id": seg.id,
                "start_time": round(current_time, 3),
                "end_time": round(end_beat, 3),
                "duration": round(shot_duration, 3),
                "start_beat": find_beat_index(current_time, beat_grid),
                "end_beat": find_beat_index(end_beat, beat_grid)
            })
            
            current_time = end_beat
            remaining_duration = seg_end - current_time
            
            if current_time >= seg_end:
                break
        
        allocations.extend(shots_in_segment)
    
    return allocations
```

### 8.1 段落效果栈生成

效果层的核心任务是为每个段落生成一组协调的视觉效果栈（Effect Stack），效果的选择和强度由段落类型、流派、情绪和用户偏好共同决定。

**效果栈架构：**

```
┌───────────────────────────────────────────┐
│              调整层（Adjustment）          │  ← 全局调色/整体效果
├───────────────────────────────────────────┤
│              风格层（Style）               │  ← 风格化效果（故障/发光/颗粒）
├───────────────────────────────────────────┤
│              强化层（Enhancement）        │  ← 锐化/对比度/细节增强
├───────────────────────────────────────────┤
│              动态层（Motion）             │  ← 运动模糊/变形/镜头运动
├───────────────────────────────────────────┤
│              氛围层（Atmosphere）         │  ← 雾/光效/粒子/暗角
└───────────────────────────────────────────┘
```

```python
def generate_segment_effect_stack(segment, music_atom, clip_assignment, preferences):
    """
    为单个段落生成效果栈
    
    效果选择逻辑：
    1. 基础效果（所有段落都有）
    2. 风格效果（基于用户偏好的风格）
    3. 能量驱动效果（基于段落能量）
    4. 情绪驱动效果（基于段落情绪）
    5. 流派专属效果（基于音乐流派）
    """
    seg_type = segment.type
    seg_energy = segment.energy.overall_level if hasattr(segment.energy, 'overall_level') else 0.5
    seg_valence = segment.emotion.valence if hasattr(segment.emotion, 'valence') else 0.0
    seg_arousal = segment.emotion.arousal if hasattr(segment.emotion, 'arousal') else 0.5
    
    genre = music_atom.genre.primary
    style = preferences.style.primary_style if preferences else "default"
    intensity_level = preferences.intensity.effects_level if preferences else "moderate"
    
    effect_stack = []
    
    # 1. 基础调整效果（始终存在，强度根据能量调整）
    base_effects = generate_base_effects(seg_energy, seg_valence, preferences)
    effect_stack.extend(base_effects)
    
    # 2. 风格化效果（根据用户选择的风格）
    style_effects = generate_style_effects(style, intensity_level, seg_energy)
    effect_stack.extend(style_effects)
    
    # 3. 能量驱动效果
    energy_effects = generate_energy_driven_effects(seg_energy, segment.energy.dynamics)
    effect_stack.extend(energy_effects)
    
    # 4. 情绪驱动效果
    emotion_effects = generate_emotion_driven_effects(seg_valence, seg_arousal)
    effect_stack.extend(emotion_effects)
    
    # 5. 流派专属效果
    genre_effects = generate_genre_specific_effects(genre, seg_type, seg_energy)
    effect_stack.extend(genre_effects)
    
    # 6. 段落类型调制
    effect_stack = modulate_by_segment_type(effect_stack, seg_type, seg_energy)
    
    # 7. 按层排序（调整层 → 风格层 → 强化层 → 动态层 → 氛围层）
    effect_stack = sort_effects_by_layer(effect_stack)
    
    # 8. 限制效果数量（避免过度效果）
    max_effects = get_max_effects(preferences)
    if len(effect_stack) > max_effects:
        effect_stack = prioritize_effects(effect_stack, max_effects)
    
    return {
        "segment_id": segment.id,
        "effect_stack": effect_stack,
        "effect_count": len(effect_stack),
        "overall_intensity": calculate_overall_effect_intensity(effect_stack),
        "layers": {
            "adjustment": [e for e in effect_stack if e["layer"] == "adjustment"],
            "style": [e for e in effect_stack if e["layer"] == "style"],
            "enhancement": [e for e in effect_stack if e["layer"] == "enhancement"],
            "motion": [e for e in effect_stack if e["layer"] == "motion"],
            "atmosphere": [e for e in effect_stack if e["layer"] == "atmosphere"]
        }
    }

def generate_base_effects(energy, valence, preferences):
```

### 8.2 节拍关键帧生成

为每个效果生成节拍同步的关键帧动画，确保视觉变化与音乐节奏精确对齐。

```python
def generate_beat_keyframes(effect_stack, segment, annotated_beats, energy_analysis):
    """
    为效果栈中的每个效果生成节拍同步的关键帧
    
    关键帧类型：
    - 脉冲型：每个节拍跳一下（如缩放、透明度）
    - 渐进型：随能量逐渐变化（如模糊、色彩）
    - 冲击型：重拍强效果，逐渐衰减（如glow、shockwave）
    - 持续型：段落内稳定，段落间切换
    """
    keyframed_effects = []
    
    # 获取该段落内的节拍
    seg_beats = [b for b in annotated_beats 
                 if segment.start_time <= b["time"] <= segment.end_time]
    
    for effect in effect_stack:
        effect_name = effect["name"]
        base_intensity = effect.get("intensity", 0.5)
        effect_layer = effect.get("layer", "style")
        
        # 根据效果类型选择关键帧模式
        keyframe_pattern = get_keyframe_pattern(effect_name, segment.type)
        
        keyframes = []
        
        if keyframe_pattern == "pulse":
            # 脉冲型：每个节拍有一个峰值
            keyframes = generate_pulse_keyframes(
                seg_beats, effect_name, base_intensity, energy_analysis
            )
        
        elif keyframe_pattern == "progressive":
            # 渐进型：随段落能量曲线变化
            keyframes = generate_progressive_keyframes(
                segment, effect_name, base_intensity, energy_analysis
            )
        
        elif keyframe_pattern == "impact":
            # 冲击型：只在重拍有强效果
            keyframes = generate_impact_keyframes(
                seg_beats, effect_name, base_intensity, energy_analysis
            )
        
        elif keyframe_pattern == "sustained":
            # 持续型：段落开始和结束两个关键帧
            keyframes = [
                {"time": segment.start_time, "value": base_intensity * 0.8, "easing": "ease_out"},
                {"time": segment.end_time, "value": base_intensity * 0.8, "easing": "ease_in"}
            ]
        
        keyframed_effect = {
            **effect,
            "keyframes": keyframes,
            "keyframe_pattern": keyframe_pattern,
            "beat_sync": len([k for k in keyframes if k.get("beat_aligned", False)])
        }
        
        keyframed_effects.append(keyframed_effect)
    
    return keyframed_effects

def generate_pulse_keyframes(beats, effect_name, base_intensity, energy_analysis):
    """生成脉冲型关键帧（每个节拍一次脉冲）"""
    keyframes = []
    
    for beat in beats:
        beat_time = beat["time"]
        beat_strength = beat.get("strength", 0.5)
        beat_importance = beat.get("importance", 0.5)
        
        # 强度 = 基础强度 × 节拍强度 × 重要性
        peak_intensity = base_intensity * (0.5 + 0.5 * beat_strength) * (0.7 + 0.3 * beat_importance)
        
        # 脉冲持续时间（与节拍间隔相关）
        pulse_duration = 0.15  # 150ms 标准脉冲
        
        # 三个关键帧：起始低 → 峰值 → 结束低
        # 起音
        keyframes.append({
            "time": round(beat_time - pulse_duration * 0.3, 4),
            "value": base_intensity * 0.3,
            "easing": "ease_out",
            "beat_aligned": True,
            "beat_id": beat.get("id", "")
        })
        
        # 峰值（在节拍点）
        keyframes.append({
            "time": round(beat_time, 4),
            "value": peak_intensity,
            "easing": "ease_in_out",
            "beat_aligned": True,
            "beat_id": beat.get("id", "")
        })
        
        # 衰减
        keyframes.append({
            "time": round(beat_time + pulse_duration * 0.7, 4),
            "value": base_intensity * 0.3,
            "easing": "ease_in",
            "beat_aligned": False
        })
    
    return keyframes
```

```python
def generate_transitions(segments, clip_assignments, annotated_beats, preferences):
    """
    生成完整的转场方案
    
    转场触发时机：
    1. 段落边界（主要转场）
    2. 高重要性节拍的切镜点（节拍转场）
    3. 能量峰值点（冲击转场）
    4. 情绪转换点（情绪转场）
    """
    transitions = []
    style = preferences.style.primary_style if preferences else "default"
    trans_level = preferences.intensity.transitions_level if preferences else "moderate"
    
    # 1. 段落边界转场
    for i in range(len(segments) - 1):
        current_seg = segments[i]
        next_seg = segments[i + 1]
        
        # 找到段落边界最近的重拍
        boundary_time = next_seg.start_time
        nearest_downbeat = find_nearest_downbeat(boundary_time, annotated_beats)
        
        if nearest_downbeat:
            trans_time = nearest_downbeat["time"]
            beat_aligned = True
            beat_id = nearest_downbeat["id"]
        else:
            trans_time = boundary_time
            beat_aligned = False
            beat_id = None
        
        # 选择转场类型
        trans_type = select_segment_transition(
            current_seg.type, next_seg.type, 
            current_seg.energy.overall_level if hasattr(current_seg.energy, 'overall_level') else 0.5,
            next_seg.energy.overall_level if hasattr(next_seg.energy, 'overall_level') else 0.5,
            style, trans_level
        )
        
        # 计算转场时长
        trans_duration = calculate_transition_duration(
            current_seg.type, next_seg.type, trans_level
        )
        
        transitions.append({
            "id": f"trans_seg_{i:03d}",
            "start_time": round(trans_time - trans_duration / 2, 4),
            "end_time": round(trans_time + trans_duration / 2, 4),
            "duration": trans_duration,
            "type": trans_type,
            "intensity": calculate_transition_intensity(current_seg, next_seg),
            "trigger_reason": "segment_boundary",
            "from_segment": current_seg.id,
            "to_segment": next_seg.id,
            "beat_aligned": beat_aligned,
            "beat_id": beat_id
        })
    
    # 2. 节拍切镜转场（在重要切镜点）
    beat_cut_transitions = generate_beat_cut_transitions(
        clip_assignments, annotated_beats, style, trans_level
    )
    transitions.extend(beat_cut_transitions)
    
    # 3. 能量峰值转场
    peak_transitions = generate_energy_peak_transitions(
        segments, annotated_beats, style, trans_level
    )
    transitions.extend(peak_transitions)
    
    # 按时间排序
    transitions.sort(key=lambda t: t["start_time"])
    
    # 移除重叠的转场（保留强度高的）
    transitions = remove_overlapping_transitions(transitions)
    
    return transitions

def select_segment_transition(from_type, to_type, from_energy, to_energy, style, level):
    """根据段落类型和能量变化选择转场类型"""
    energy_change = to_energy - from_energy
    
    # 能量上升 → 更有冲击力的转场
    if energy_change > 0.3:
        # 大幅上升（如buildup → drop）
        transition_candidates = ["glitch", "zoom", "shake", "morph"]
    elif energy_change > 0.1:
        # 小幅上升
        transition_candidates = ["push", "wipe", "slide"]
    elif energy_change < -0.3:
        # 大幅下降（如drop → breakdown）
        transition_candidates = ["blur", "dissolve", "fade"]
    else:
        # 能量变化不大
        transition_candidates = ["dissolve", "wipe", "light_leak"]
    
    # 风格调制
    style_transitions = {
        "cyberpunk": ["glitch", "digital_distortion", "scan_line"],
        "cinematic": ["dissolve", "lens_flare", "light_leak"],
        "vintage": ["film_burn", "grain_dissolve", "fade"],
        "minimal": ["dissolve", "cut", "fade"],
        "energetic": ["zoom", "shake", "push", "morph"]
    }
    
    if style in style_transitions:
        style_pool = style_transitions[style]
        # 取交集，优先选择同时在两个列表中的
        common = [t for t in transition_candidates if t in style_pool]
        if common:
            return common[0]
    
    return transition_candidates[0]
```

```python
    1. 全局色彩基调（由整体情绪和风格决定）

def calculate_global_color_grade(emotion_timeline, color_prefs, style):

    avg_valence = emotion_timeline.stats.avg_valence
    avg_arousal = emotion_timeline.stats.avg_arousal
    
    # 基调色温
    # 积极情绪 → 暖色；高唤醒 → 更暖
    temperature = 5000 + avg_valence * 1000 + avg_arousal * 500  # K
    
    # 饱和度
    base_saturation = 1.0
    if color_prefs:
        base_saturation += color_prefs.saturation_bias * 0.5
    saturation = base_saturation + avg_valence * 0.2
    
    # 对比度
    contrast = 1.0 + avg_arousal * 0.3
    
    # 主色板
    palette = generate_color_palette(avg_valence, avg_arousal, style)
    
    return {
        "temperature": temperature,
        "tint": avg_valence * 10,  # 绿色/品红偏移
        "saturation": saturation,
        "contrast": contrast,
        "brightness": 0.0,
        "tone": "warm" if temperature > 5500 else "cool" if temperature < 4800 else "neutral",
        "palette": palette
    }
```

### 9.1 音效-节拍匹配

为重要的节拍点配上合适的音效，增强节奏的冲击力和沉浸感。

```python
def generate_beat_sfx(annotated_beats, energy_analysis, segments, preferences):
    """
    生成节拍同步音效
    
    匹配规则：
    - 重拍 + 高能量底鼓 → kick/impact
    - 次重拍 + 高频 → snare/clap
    - 反拍 → hat/click
    - 三连音 → triplet_fx
    - 切分 → glitch_sfx
    """
    if not preferences.sfx.enabled:
        return []
    
    beat_sfx = []
    sfx_volume = preferences.sfx.volume if preferences.sfx else 0.5
    
    for beat in annotated_beats:
        beat_time = beat["time"]
        beat_type = beat["type"]
        beat_strength = beat.get("strength", 0.5)
        beat_importance = beat.get("importance", 0.5)
        beat_bass = beat.get("energy_contribution", {}).get("bass", 0)
        beat_treble = beat.get("energy_contribution", {}).get("treble", 0)
        
        # 只处理足够重要的节拍
        if beat_importance < 0.3:
            continue
        
        # 根据节拍类型和能量分布选择音效
        sfx_type = select_beat_sfx_type(
            beat_type, beat_bass, beat_treble, beat_strength
        )
        
        if not sfx_type:
            continue
        
        # 音量（与节拍强度成正比）
        volume = sfx_volume * (0.4 + 0.6 * beat_strength)
        
        # 音效变体（避免重复感）
        variation = get_sfx_variation(sfx_type, beat["index"])
        
        beat_sfx.append({
            "id": f"sfx_beat_{beat['index']:04d}",
            "type": "beat",
            "sfx_type": sfx_type,
            "time": round(beat_time, 4),
            "duration": get_sfx_duration(sfx_type),
            "volume": volume,
            "variation": variation,
            "beat_id": beat.get("id", ""),
            "beat_type": beat_type,
            "beat_strength": beat_strength,
            "layer": "beat_sfx",
            "priority": beat_importance
        })
    
    # 限制音效密度（避免过于密集）
    beat_sfx = limit_sfx_density(beat_sfx, max_per_second=4)
    
    return beat_sfx

def select_beat_sfx_type(beat_type, bass_contrib, treble_contrib, strength):
    """根据节拍特征选择音效类型"""
    # 低频主导 → 底鼓/冲击
    if bass_contrib > 0.6 and strength > 0.5:
        return "kick" if beat_type == "downbeat" else "boom"
    
    # 高频主导 → 军鼓/拍手
    if treble_contrib > 0.5 and strength > 0.4:
        return "snare" if beat_type == "secondary" else "clap"
    
    # 重拍
    if beat_type == "downbeat":
        if strength > 0.6:
            return "impact"
        else:
            return "kick"
    
    # 次重拍
    if beat_type == "secondary":
        return "snare"
    
    # 弱拍
    if beat_type == "upbeat":
        if treble_contrib > 0.4:
            return "hat"
        else:
            return "click"
    
    return None
```

### 9.2 音效-段落匹配

为每个段落配上适合的氛围音效和过渡音效，增强段落的情绪氛围。

```python
def generate_segment_sfx(segments, emotion_timeline, preferences):
    """
    生成段落级音效
    
    包括：
    - 氛围音效（整个段落持续）
    - 入场音效（段落开始）
    - 退场音效（段落结束）
    - 段落内标志性音效
    """
    if not preferences.sfx.enabled:
        return []
    
    segment_sfx = []
    
    for seg in segments:
        seg_type = seg.type
        seg_emotion = seg.emotion
        seg_energy = seg.energy.overall_level if hasattr(seg.energy, 'overall_level') else 0.5
        
        # 1. 氛围音效（持续整个段落）
        ambience_sfx = generate_ambience_sfx(seg, seg_emotion, preferences)
        segment_sfx.extend(ambience_sfx)
        
        # 2. 入场音效
        intro_sfx = generate_segment_intro_sfx(seg_type, seg_energy)
        if intro_sfx:
            intro_sfx["time"] = seg.start_time
            intro_sfx["segment_id"] = seg.id
            segment_sfx.append(intro_sfx)
        
        # 3. 退场音效
        outro_sfx = generate_segment_outro_sfx(seg_type, seg_energy)
        if outro_sfx:
            outro_sfx["time"] = seg.end_time - outro_sfx["duration"]
            outro_sfx["segment_id"] = seg.id
            segment_sfx.append(outro_sfx)
        
        # 4. 段落内标志性音效（如drop的impact）
        signature_sfx = generate_segment_signature_sfx(seg, seg_energy)
        if signature_sfx:
            segment_sfx.extend(signature_sfx)
    
    return segment_sfx

def generate_ambience_sfx(segment, emotion, preferences):
    """生成氛围音效"""
    ambience_types = []
    
    valence = emotion.valence if hasattr(emotion, 'valence') else 0.0
    arousal = emotion.arousal if hasattr(emotion, 'arousal') else 0.5
    
    # 根据情绪选择氛围
    if arousal < 0.3:
        # 低唤醒 → pad/drone
        ambience_types.append({
            "type": "pad",
            "volume": 0.3,
            "layer": "ambience"
        })
    elif arousal > 0.7:
        # 高唤醒 → noise/rise
        ambience_types.append({
            "type": "riser" if segment.energy.dynamics.shape == "rising" else "drone",
            "volume": 0.25,
            "layer": "ambience"
        })
    
    # 转换为音效实例
    sfx_list = []
    for i, atm in enumerate(ambience_types):
        sfx_list.append({
            "id": f"sfx_amb_{segment.id}_{i}",
            "type": "ambience",
            "sfx_type": atm["type"],
            "time": segment.start_time,
            "duration": segment.duration,
            "volume": atm["volume"] * (preferences.sfx.volume if preferences.sfx else 0.5),
            "segment_id": segment.id,
            "layer": atm["layer"],
            "fade_in": 0.5,
            "fade_out": 0.5,
            "loop": True
        })
    
    return sfx_list
```

### 9.3 音效-转场联动

转场时配合音效，使视听体验更加一体化。

```python
def generate_transition_sfx(transitions, style, preferences):
    """
    生成转场联动音效
    
    转场类型 ↔ 音效类型映射：
    - glitch → glitch_sfx / digital_noise
    - zoom → whoosh / swoosh
    - wipe → sweep / whoosh
    - dissolve → whoosh_soft / ambient
    - shake → impact / rumble
    - light_leak → chime / sparkle
    - push → whoosh / impact
    """
    if not preferences.sfx.enabled or not preferences.sfx.transition_sfx:
        return []
    
    transition_sfx_map = {
        "glitch": ["glitch", "digital_distortion"],
        "zoom": ["whoosh_rise", "swoosh"],
        "wipe": ["sweep", "whoosh"],
        "dissolve": ["whoosh_soft", "ambient_swell"],
        "shake": ["impact", "rumble"],
        "light_leak": ["chime", "sparkle"],
        "push": ["whoosh", "impact_soft"],
        "slide": ["swoosh", "whoosh"],
        "blur": ["ambient_swell", "whoosh_soft"],
        "morph": ["glitch", "morph_sfx"],
        "spin": ["whoosh", "rise"],
        "cut": []  # 硬切不需要音效
    }
    
    trans_sfx = []
    
    for trans in transitions:
        trans_type = trans["type"]
        trans_intensity = trans.get("intensity", 0.5)
        
        # 查找对应的音效
        sfx_candidates = transition_sfx_map.get(trans_type, ["whoosh"])
        
        if not sfx_candidates:
            continue
        
        # 选择第一个候选（可以加入随机性）
        sfx_type = sfx_candidates[0]
        
        # 音量与转场强度成正比
        volume = 0.4 + trans_intensity * 0.4
        volume *= preferences.sfx.volume if preferences.sfx else 0.5
        
        # 音效时长与转场时长匹配
        sfx_duration = trans["duration"] * 1.2  # 略长于转场
        
        trans_sfx.append({
            "id": f"sfx_{trans['id']}",
            "type": "transition",
            "sfx_type": sfx_type,
            "time": round(trans["start_time"], 4),
            "duration": sfx_duration,
            "volume": volume,
            "transition_id": trans["id"],
            "transition_type": trans_type,
            "layer": "transition_sfx",
            "sync": "start_aligned",  # start_aligned / center_aligned / end_aligned
            "priority": trans_intensity
        })
    
    return trans_sfx
```

```python
def setup_sfx_mix(preferences, music_atom):
```

## 第11章 推理算法与决策树

### 11.1 主推理循环算法伪代码

时间轴推理引擎的核心是一个9层递进式推理循环，每层输出作为下一层输入，同时支持层间反馈与回溯。

```python
class TimelineReasoningEngine:
    """时间轴推理引擎主类"""
    
    def __init__(self, config=None):
        self.config = config or get_default_config()
        self.precision_level = self.config.get("precision_level", "L2")
        self.reasoning_path = ReasoningPathBuilder()
        self.knowledge_base = KnowledgeBaseLoader()
        self.confidence_manager = ConfidenceManager()
        
    def generate(self, music_atom, clip_atoms, user_preference=None):
        """
        主推理入口
        
        输入：
            music_atom: 音乐原子
            clip_atoms: 片段原子数组
            user_preference: 用户偏好（可选）
            
        输出：
            TimelinePlan: 完整时间轴方案
        """
        timer = PerformanceTimer()
        timer.start("total")
        
        # === L1 输入层 ===
        timer.start("L1_input")
        self.reasoning_path.start_layer("L1_input")
        
        validated = validate_and_clean_input(
            music_atom, clip_atoms, user_preference
        )
        
        self.reasoning_path.record_step(
            layer="L1",
            step_name="input_validation",
            input_summary=f"{len(clip_atoms)} clips, "
                         f"{validated['music'].metadata.duration:.1f}s music",
            output_summary=f"validation_report: "
                          f"{len(validated['validation_report']['errors'])} errors, "
                          f"{len(validated['validation_report']['warnings'])} warnings",
            confidence=0.95
        )
        
        music = validated["music"]
        clips = validated["clips"]
        prefs = validated["preferences"]
        
        timer.end("L1_input")
        
        # === L2 节拍层 ===
        timer.start("L2_beat")
        self.reasoning_path.start_layer("L2_beat")
        
        beat_grid = self.infer_beat_layer(music, prefs)
        
        self.reasoning_path.record_decision(
            decision_type="beat_analysis",
            description="节拍类型分类与重要性排序",
            options_considered=3,
            selected_option="multi_feature_weighted",
            selection_criteria="accuracy+coverage balance",
            confidence=beat_grid.confidence
        )
        
        timer.end("L2_beat")
        
        # === L3 段落层 ===
        timer.start("L3_segment")
        self.reasoning_path.start_layer("L3_segment")
        
        segments = self.infer_segment_layer(music, beat_grid, prefs)
        
        self.reasoning_path.record_decision(
            decision_type="segment_boundary",
            description="段落边界校准与类型确认",
            options_considered=5,
            selected_option="energy+spectrum+beat alignment",
            selection_criteria="boundary precision + type accuracy",
            confidence=segments.confidence
        )
        
        timer.end("L3_segment")
        
        # === L4 能量层 ===
        timer.start("L4_energy")
        self.reasoning_path.start_layer("L4_energy")
        
        energy_analysis = self.infer_energy_layer(music, segments, prefs)
        
        timer.end("L4_energy")
        
        # === L5 情绪层 ===
        timer.start("L5_emotion")
        self.reasoning_path.start_layer("L5_emotion")
        
        emotion_timeline = self.infer_emotion_layer(
            music, energy_analysis, segments, prefs
        )
        
        timer.end("L5_emotion")
        
        # === L6 匹配层 ===
        timer.start("L6_matching")
        self.reasoning_path.start_layer("L6_matching")
        
        clip_assignment = self.infer_matching_layer(
            beat_grid, segments, energy_analysis, 
            emotion_timeline, clips, prefs
        )
        
        # 匹配质量检查，不满足则回溯
        if clip_assignment.quality_score < self.config["matching_quality_threshold"]:
            self.reasoning_path.record_backtrack(
                reason="matching quality too low",
                backtrack_from="L6_matching",
                backtrack_to="L2_beat",
                iterations=1
            )
            # 重新调整节拍标注，增加细分节拍
            beat_grid = self.refine_beat_layer(beat_grid, music)
            segments = self.refine_segment_layer(segments, beat_grid)
            clip_assignment = self.infer_matching_layer(
                beat_grid, segments, energy_analysis,
                emotion_timeline, clips, prefs
            )
        
        timer.end("L6_matching")
        
        # === L7 效果层 ===
        timer.start("L7_effects")
        self.reasoning_path.start_layer("L7_effects")
        
        visual_effects = self.infer_effects_layer(
            beat_grid, segments, energy_analysis,
            emotion_timeline, clip_assignment, prefs
        )
        
        # 效果冲突检测与解决
        conflicts = detect_effect_conflicts(visual_effects)
        if conflicts:
            visual_effects = resolve_effect_conflicts(visual_effects, conflicts)
            self.reasoning_path.record_decision(
                decision_type="conflict_resolution",
                description=f"解决 {len(conflicts)} 个效果冲突",
                options_considered=3,
                selected_option="priority_based_resolution",
                confidence=0.85
            )
        
        timer.end("L7_effects")
        
        # === L8 音效层 ===
        timer.start("L8_sfx")
        self.reasoning_path.start_layer("L8_sfx")
        
        sfx_timeline = self.infer_sfx_layer(
            beat_grid, segments, energy_analysis,
            emotion_timeline, visual_effects, prefs
        )
        
        timer.end("L8_sfx")
        
        # === L9 输出层 ===
        timer.start("L9_output")
        self.reasoning_path.start_layer("L9_output")
        
        timeline_plan = self.assemble_output(
            music, clips, prefs,
            beat_grid, segments, energy_analysis,
            emotion_timeline, clip_assignment,
            visual_effects, sfx_timeline,
            self.reasoning_path.build()
        )
        
        # 最终质量评分
        quality_score = calculate_quality_score(timeline_plan)
        timeline_plan.quality_score = quality_score
        
        timer.end("L9_output")
        timer.end("total")
        
        # 记录性能数据
        timeline_plan.metadata.timing = {
            "total_processing_time_ms": timer.get("total"),
            "per_layer_times": timer.get_all()
        }
        
        return timeline_plan
```

### 11.2 冲突检测与解决

推理过程中可能产生多种冲突，需要检测并智能解决。

#### 11.2.1 冲突类型体系

| 冲突类型 | 说明 | 严重程度 | 典型场景 |
|---------|------|---------|---------|
| 效果过载 | 同一时间点效果数量过多 | high | 副歌段叠加8+效果 |
| 效果互斥 | 效果之间相互抵消或矛盾 | high | 同时加模糊和锐化 |
| 节奏冲突 | 剪辑节奏与音乐节奏不符 | medium | 慢音乐配快切 |
| 色彩冲突 | 相邻片段色调跳变过大 | medium | 暖色调突然切冷色调 |
| 音效过密 | 音效时间间隔过短 | low | 每0.1秒一个音效 |
| 转场冲突 | 转场与效果不兼容 | medium | 3D转场+平面效果 |
| 时长不匹配 | 片段时长与段落不匹配 | high | 16s段落配20s片段 |

#### 11.2.2 冲突检测算法

```python
def detect_effect_conflicts(visual_effects):
    """
    检测视觉效果时间轴上的冲突
    
    返回：Conflict[] 冲突列表
    """
    conflicts = []
    
    # 1. 效果过载检测
    time_points = collect_all_effect_time_points(visual_effects)
    for t in time_points:
        active_effects = get_active_effects_at_time(visual_effects, t)
        if len(active_effects) > MAX_EFFECTS_PER_TIMEPOINT:
            conflicts.append({
                "type": "effect_overload",
                "severity": "high" if len(active_effects) > MAX_EFFECTS_PER_TIMEPOINT + 2 else "medium",
                "time": t,
                "active_effects": [e.id for e in active_effects],
                "count": len(active_effects),
                "limit": MAX_EFFECTS_PER_TIMEPOINT
            })
    
    # 2. 效果互斥检测
    mutex_pairs = [
        ({"blur", "sharpen"}, "blur_sharpen_mutex"),
        ({"desaturate", "vibrance"}, "saturation_mutex"),
        ({"zoom_in", "zoom_out"}, "zoom_direction_mutex"),
        ({"brighten", "darken"}, "brightness_mutex"),
    ]
    
    for t in time_points:
        active_types = set(get_active_effect_types(visual_effects, t))
        for mutex_set, conflict_name in mutex_pairs:
            if mutex_set.issubset(active_types):
                conflicts.append({
                    "type": "effect_mutex",
                    "severity": "high",
                    "time": t,
                    "conflict_name": conflict_name,
                    "effects": [e for e in get_active_effects(visual_effects, t) 
                               if e.type in mutex_set]
                })
    
    # 3. 节奏冲突检测
    clip_durations = get_clip_duration_series(visual_effects.clip_assignments)
    beat_intervals = get_beat_interval_series(visual_effects.beat_grid)
    rhythm_correlation = calculate_correlation(clip_durations, beat_intervals)
    
    if rhythm_correlation < RHYTHM_CORRELATION_THRESHOLD:
        conflicts.append({
            "type": "rhythm_mismatch",
            "severity": "medium",
            "correlation": rhythm_correlation,
            "threshold": RHYTHM_CORRELATION_THRESHOLD,
            "description": "剪辑节奏与音乐节拍相关性过低"
        })
    
    # 4. 色彩跳变检测
    color_transitions = get_color_transitions(visual_effects)
    for i, transition in enumerate(color_transitions):
        delta_e = transition["delta_e"]
        if delta_e > COLOR_JUMP_THRESHOLD:
            conflicts.append({
                "type": "color_jump",
                "severity": "medium" if delta_e < COLOR_JUMP_THRESHOLD * 1.5 else "high",
                "transition_index": i,
                "time": transition["time"],
                "delta_e": delta_e,
                "threshold": COLOR_JUMP_THRESHOLD
            })
    
    return conflicts
```

#### 11.2.3 冲突解决策略

```python
def resolve_effect_conflicts(visual_effects, conflicts):
    """
    解决效果冲突
    
    策略优先级：
    1. 移除优先级最低的效果
    2. 减弱冲突效果的强度
    3. 时间上错开冲突效果
    4. 用兼容效果替代
    """
    resolved_effects = visual_effects.deepcopy()
    
    # 按严重程度排序，先解决高严重度冲突
    conflicts_sorted = sorted(conflicts, key=lambda c: 
        {"critical": 0, "high": 1, "medium": 2, "low": 3}[c["severity"]])
    
    for conflict in conflicts_sorted:
        if conflict["type"] == "effect_overload":
            # 策略：按优先级移除效果
            active_effects = get_active_effects_at_time(
                resolved_effects, conflict["time"]
            )
            # 按效果优先级排序（数字越小优先级越高）
            sorted_effects = sorted(active_effects, key=lambda e: EFFECT_PRIORITY[e.type])
            
            # 移除超出限制的效果（从优先级最低的开始）
            effects_to_remove = sorted_effects[conflict["limit"]:]
            for effect in effects_to_remove:
                remove_effect(resolved_effects, effect.id)
                
        elif conflict["type"] == "effect_mutex":
            # 策略：保留优先级高的，减弱或移除优先级低的
            effects = conflict["effects"]
            effects_sorted = sorted(effects, key=lambda e: EFFECT_PRIORITY[e.type])
            effect_to_keep = effects_sorted[0]
            effect_to_adjust = effects_sorted[1]
            
            # 先尝试减弱强度
            if can_reduce_intensity(effect_to_adjust):
                reduce_effect_intensity(resolved_effects, effect_to_adjust.id, 0.5)
            else:
                remove_effect(resolved_effects, effect_to_adjust.id)
                
        elif conflict["type"] == "color_jump":
            # 策略：添加过渡效果平滑色彩
            add_color_transition_effect(
                resolved_effects,
                conflict["time"],
                duration=0.5,
                transition_type="cross_fade"
            )
            
        elif conflict["type"] == "rhythm_mismatch":
            # 策略：重新对齐剪辑节奏
            realign_clip_timing_to_beats(resolved_effects)
    
    return resolved_effects
```

### 11.3 多目标优化

时间轴推理本质上是一个多目标优化问题，需要在多个维度之间取得平衡。

#### 11.3.1 优化目标体系

| 目标 | 说明 | 权重范围 | 计算方式 |
|------|------|---------|---------|
| 节拍对齐度 | 剪辑点与节拍的对齐程度 | 0.20-0.35 | 卡点命中率×精度加权 |
| 风格一致性 | 整体风格的统一程度 | 0.15-0.25 | 风格特征方差的倒数 |
| 叙事流畅度 | 故事/情绪的连贯程度 | 0.15-0.25 | 转场平滑度+情绪连续性 |
| 视觉丰富度 | 视觉效果的多样性 | 0.10-0.20 | 效果类型熵值 |
| 音画和谐度 | 音乐与视觉的匹配度 | 0.15-0.25 | 能量/情绪相关性 |
| 技术质量 | 输出的技术质量 | 0.05-0.15 | 分辨率/帧率/压缩质量 |

#### 11.3.2 多目标优化算法

```python
def multi_objective_optimize(
    base_timeline, 
    objectives, 
    weights,
    constraints,
    max_iterations=100
):
    """
    多目标优化（加权求和 + 局部搜索）
    
    输入：
        base_timeline: 基础时间轴方案
        objectives: 目标函数列表
        weights: 各目标权重
        constraints: 约束条件列表
        max_iterations: 最大迭代次数
        
    输出：
        优化后的时间轴方案
    """
    current = base_timeline
    current_score = weighted_score(current, objectives, weights)
    best = current
    best_score = current_score
    
    iteration = 0
    no_improve_count = 0
    
    while iteration < max_iterations and no_improve_count < 20:
        iteration += 1
        
        # 生成邻域解（随机扰动一个维度）
        neighbor = generate_neighbor(current, iteration)
        
        # 检查约束
        if not satisfies_constraints(neighbor, constraints):
            continue
        
        # 计算评分
        neighbor_score = weighted_score(neighbor, objectives, weights)
        
        # 接受准则：模拟退火
        if neighbor_score > current_score:
            current = neighbor
            current_score = neighbor_score
            no_improve_count = 0
            
            if neighbor_score > best_score:
                best = neighbor
                best_score = neighbor_score
        else:
            # 以一定概率接受更差的解（避免局部最优）
            temperature = initial_temperature * (0.95 ** iteration)
            delta = neighbor_score - current_score
            acceptance_prob = math.exp(delta / temperature)
            
            if random.random() < acceptance_prob:
                current = neighbor
                current_score = neighbor_score
            
            no_improve_count += 1
    
    return best

def weighted_score(timeline, objectives, weights):
    """计算加权综合评分"""
    total = 0.0
    total_weight = sum(weights.values())
    
    for obj_name, obj_func in objectives.items():
        score = obj_func(timeline)
        weight = weights.get(obj_name, 0.1)
        total += score * weight
    
    return total / total_weight

def generate_neighbor(timeline, iteration):
    """
    生成邻域解（随机选择一个操作）
    
    操作类型：
    - 调整剪辑点位置（±50ms）
    - 交换两个相邻片段
    - 调整效果强度（±10%）
    - 添加/移除一个装饰性效果
    - 调整转场时长
    """
    neighbor = timeline.deepcopy()
    
    operations = [
        "adjust_clip_timing",
        "swap_adjacent_clips", 
        "adjust_effect_intensity",
        "toggle_decorative_effect",
        "adjust_transition_duration"
    ]
    
    # 随着迭代增加，操作幅度减小
    scale_factor = max(0.1, 1.0 - iteration / 100)
    
    op = random.choice(operations)
    
    if op == "adjust_clip_timing":
        adjust_random_clip_timing(neighbor, max_offset=0.05 * scale_factor)
    elif op == "swap_adjacent_clips":
        swap_random_adjacent_clips(neighbor)
    elif op == "adjust_effect_intensity":
        adjust_random_effect_intensity(neighbor, max_delta=0.1 * scale_factor)
    elif op == "toggle_decorative_effect":
        toggle_random_decorative_effect(neighbor)
    elif op == "adjust_transition_duration":
        adjust_random_transition_duration(neighbor, max_delta=0.1 * scale_factor)
    
    return neighbor
```

### 11.4 置信度传播与不确定性管理

推理各层的不确定性通过置信度传播机制向下传递，并在输出层汇总为整体置信度。

#### 11.4.1 置信度传播模型

```
L1 输入层置信度 (C1)
   │
   ▼
L2 节拍层置信度 = C1 × 节拍检测置信度
   │
   ▼
L3 段落层置信度 = C2 × 段落划分置信度
   │
   ▼
...
   │
   ▼
L9 输出层置信度 = ∏(各层置信度)
```

#### 11.4.2 不确定性类型

| 类型 | 来源 | 传播方式 | 处理策略 |
|------|------|---------|---------|
| 输入不确定 | 音乐分析误差、片段标注误差 | 直接传递 | 增加置信度衰减 |
| 模型不确定 | 算法本身的不确定性 | 概率分布传播 | 多假设推理 |
| 数据稀疏 | 某些类型数据不足 | 置信度降低 | 使用先验知识补充 |
| 歧义性 | 多种合理解释 | 分支并行推理 | 保留Top-K备选 |
| 偏好模糊 | 用户偏好不明确 | 权重区间 | 生成多风格方案 |

#### 11.4.3 置信度管理算法

```python
class ConfidenceManager:
    """置信度管理器"""
    
    def __init__(self):
        self.layer_confidences = {}
        self.uncertainty_sources = []
        
    def set_layer_confidence(self, layer_name, confidence, sources=None):
        """设置某层的置信度"""
        self.layer_confidences[layer_name] = {
            "confidence": confidence,
            "sources": sources or []
        }
        if sources:
            self.uncertainty_sources.extend(sources)
    
    def propagate_confidence(self, from_layer, to_layer, factor=1.0):
        """
        置信度传播
        
        factor: 传播因子（0-1），表示不确定性的传递比例
        """
        from_conf = self.layer_confidences.get(from_layer, {}).get("confidence", 1.0)
        to_conf = self.layer_confidences.get(to_layer, {}).get("confidence", 1.0)
        
        # 置信度衰减（乘以传播因子）
        propagated_conf = from_conf * factor
        
        # 目标层置信度取两者的较低值（保守估计）
        new_conf = min(to_conf, propagated_conf)
        
        self.layer_confidences[to_layer] = {
            "confidence": new_conf,
            "propagated_from": from_layer,
            "propagation_factor": factor
        }
    
    def get_overall_confidence(self):
        """计算整体置信度"""
        if not self.layer_confidences:
            return 1.0
        
        # 取各层置信度的加权平均
        layer_weights = {
            "L1_input": 0.10,
            "L2_beat": 0.20,
            "L3_segment": 0.15,
            "L4_energy": 0.10,
            "L5_emotion": 0.10,
            "L6_matching": 0.15,
            "L7_effects": 0.10,
            "L8_sfx": 0.05,
            "L9_output": 0.05
        }
        
        total = 0.0
        total_weight = 0.0
        
        for layer, weight in layer_weights.items():
            if layer in self.layer_confidences:
                conf = self.layer_confidences[layer]["confidence"]
                total += conf * weight
                total_weight += weight
        
        return total / total_weight if total_weight > 0 else 1.0
    
    def get_low_confidence_layers(self, threshold=0.7):
        """获取置信度低于阈值的层"""
        low_conf = []
        for layer, data in self.layer_confidences.items():
            if data["confidence"] < threshold:
                low_conf.append({
                    "layer": layer,
                    "confidence": data["confidence"],
                    "sources": data.get("sources", [])
                })
        return low_conf
```

### 11.5 回溯与重推理机制

当某层推理结果质量不达标时，引擎支持回溯到上游层重新推理。

#### 11.5.1 回溯触发条件

| 触发条件 | 阈值 | 回溯目标 | 调整策略 |
|---------|------|---------|---------|
| 匹配质量过低 | <0.6 | L2节拍层 | 增加细分节拍，调整节拍重要性 |
| 效果冲突过多 | >5个冲突 | L7效果层 | 减少效果密度，调整效果栈 |
| 叙事流畅度低 | <0.5 | L6匹配层 | 重新排序片段，调整转场 |
| 节拍置信度低 | <0.7 | L1输入层 | 使用更保守的节拍检测 |
| 整体评分低 | <6.0 | L5情绪层 | 重新计算情绪弧线，调整权重 |

#### 11.5.2 回溯算法

```python
class BacktrackManager:
    """回溯管理器"""
    
    def __init__(self, engine):
        self.engine = engine
        self.backtrack_history = []
        self.max_backtracks = 5
    
    def should_backtrack(self, current_layer, current_result):
        """判断是否需要回溯"""
        quality_score = self._evaluate_layer_quality(current_layer, current_result)
        
        thresholds = {
            "L2_beat": 0.7,
            "L3_segment": 0.7,
            "L4_energy": 0.6,
            "L5_emotion": 0.6,
            "L6_matching": 0.6,
            "L7_effects": 0.5,
            "L8_sfx": 0.5
        }
        
        threshold = thresholds.get(current_layer, 0.6)
        return quality_score < threshold
    
    def get_backtrack_target(self, current_layer, reason):
        """
        确定回溯目标层
        
        根据问题类型决定回溯到哪一层
        """
        backtrack_map = {
            "beat_confidence_low": ("L1_input", "increase beat detection sensitivity"),
            "segment_boundary_inaccurate": ("L2_beat", "refine beat grid for alignment"),
            "matching_quality_low": ("L3_segment", "re-segment for better matching"),
            "effect_conflicts": ("L6_matching", "adjust clip timing to reduce conflicts"),
            "narrative_flow_poor": ("L5_emotion", "recalculate emotion arc"),
            "overall_quality_low": ("L2_beat", "full re-reasoning from beat layer")
        }
        
        return backtrack_map.get(reason, (current_layer, "no backtrack needed"))
    
    def execute_backtrack(self, from_layer, to_layer, adjustment_strategy):
        """执行回溯"""
        if len(self.backtrack_history) >= self.max_backtracks:
            return None  # 达到最大回溯次数
        
        # 记录回溯
        self.backtrack_history.append({
            "from_layer": from_layer,
            "to_layer": to_layer,
            "strategy": adjustment_strategy,
            "timestamp": time.time()
        })
        
        # 应用调整策略
        self._apply_adjustment(adjustment_strategy)
        
        # 从目标层重新开始推理
        return to_layer
    
    def _evaluate_layer_quality(self, layer, result):
        """评估某层输出质量"""
        if hasattr(result, 'confidence'):
            return result.confidence
        if isinstance(result, dict) and 'confidence' in result:
            return result['confidence']
        return 0.8  # 默认值
    
    def _apply_adjustment(self, strategy):
        """应用调整策略到引擎配置"""
        # 根据策略调整引擎参数
        if "sensitivity" in strategy:
            self.engine.config["beat_detection_sensitivity"] += 0.1
        elif "refine" in strategy:
            self.engine.config["beat_subdivision_level"] += 1
        elif "re-segment" in strategy:
            self.engine.config["segment_min_duration"] -= 1.0
        # ... 更多策略
```

```python
class TimelineEngine:
    """
    时间轴推理引擎主类
    
    核心方法：
        generate(): 生成时间轴方案
        generate_async(): 异步生成
        generate_batch(): 批量生成
        optimize(): 优化已有方案
        validate(): 验证方案质量
    """
    
    def __init__(
        self,
        precision_level: str = "L2",
        config: Optional[Dict] = None,
        config_path: Optional[str] = None,
        knowledge_base_path: Optional[str] = None,
        enable_cache: bool = True,
        cache_dir: Optional[str] = None,
        logger=None
    ):
        """
        初始化时间轴推理引擎
        
        Args:
            precision_level: 推理精度等级 L1/L2/L3/L4
            config: 配置字典
            config_path: 配置文件路径（YAML/JSON）
            knowledge_base_path: 知识库路径
            enable_cache: 是否启用缓存
            cache_dir: 缓存目录
            logger: 日志记录器
        """
        self.precision_level = precision_level
        self.config = config or self._load_config(config_path)
        self.knowledge_base = KnowledgeBase(knowledge_base_path)
        
        # 子模块初始化
        self.input_validator = InputValidator()
        self.beat_inferencer = BeatInferencer(self.config)
        self.segment_inferencer = SegmentInferencer(self.config)
        self.energy_inferencer = EnergyInferencer(self.config)
        self.emotion_inferencer = EmotionInferencer(self.config)
        self.matching_inferencer = MatchingInferencer(self.config)
        self.effects_inferencer = EffectsInferencer(self.config)
        self.sfx_inferencer = SfxInferencer(self.config)
        self.output_assembler = OutputAssembler()
        
        # 缓存管理器
        self.cache = CacheManager(cache_dir) if enable_cache else None
        
        # 回溯管理器
        self.backtrack_manager = BacktrackManager(self)
        
        # 置信度管理器
        self.confidence_manager = ConfidenceManager()
        
        # 日志
        self.logger = logger or logging.getLogger(__name__)
    
    def generate(
        self,
        music_atom: MusicAtom,
        clip_atoms: List[ClipAtom],
        user_preference: Optional[UserPreference] = None,
        options: Optional[GenerateOptions] = None
    ) -> TimelinePlan:
        """
        生成时间轴方案
        
        Args:
            music_atom: 音乐原子
            clip_atoms: 片段原子列表
            user_preference: 用户偏好
            options: 生成选项
            
        Returns:
            TimelinePlan: 完整时间轴方案
            
        Raises:
            ValidationError: 输入验证失败
            InferenceError: 推理过程出错
        """
        options = options or GenerateOptions()
        
        # 检查缓存
        if self.cache and options.use_cache:
            cache_key = self._compute_cache_key(
                music_atom, clip_atoms, user_preference, options
            )
            cached = self.cache.get(cache_key)
            if cached:
                self.logger.info("Cache hit")
                return cached
        
        # 执行推理
        try:
            timeline_plan = self._execute_reasoning(
                music_atom, clip_atoms, user_preference, options
            )
        except Exception as e:
            self.logger.error(f"Inference failed: {e}")
            raise InferenceError(f"推理失败: {e}") from e
        
        # 写入缓存
        if self.cache and options.cache_output:
            self.cache.set(cache_key, timeline_plan)
        
        return timeline_plan
    
    async def generate_async(
        self,
        music_atom: MusicAtom,
        clip_atoms: List[ClipAtom],
        user_preference: Optional[UserPreference] = None,
        options: Optional[GenerateOptions] = None,
        progress_callback: Optional[Callable[[float, str], None]] = None
    ) -> TimelinePlan:
        """
        异步生成时间轴方案（支持进度回调）
        
        Args:
            music_atom: 音乐原子
            clip_atoms: 片段原子列表
            user_preference: 用户偏好
            options: 生成选项
            progress_callback: 进度回调函数 (进度0-1, 状态描述)
            
        Returns:
            TimelinePlan: 完整时间轴方案
        """
        loop = asyncio.get_event_loop()
        
        def progress_wrapper(progress, status):
            if progress_callback:
                loop.call_soon_threadsafe(progress_callback, progress, status)
        
        return await loop.run_in_executor(
            None,
            lambda: self.generate(
                music_atom, clip_atoms, user_preference, options
            )
        )
    
    def optimize(
        self,
        timeline_plan: TimelinePlan,
        optimization_goals: Dict[str, float],
        max_iterations: int = 50
    ) -> TimelinePlan:
        """
        优化已有时间轴方案
        
        Args:
            timeline_plan: 初始方案
            optimization_goals: 优化目标权重
            max_iterations: 最大迭代次数
            
        Returns:
            优化后的方案
        """
        return multi_objective_optimize(
            timeline_plan,
            objectives=get_default_objectives(),
            weights=optimization_goals,
            constraints=get_default_constraints(),
            max_iterations=max_iterations
        )
    
    def validate(self, timeline_plan: TimelinePlan) -> ValidationReport:
        """
        验证时间轴方案质量
        
        Args:
            timeline_plan: 待验证方案
            
        Returns:
            验证报告
        """
        return validate_timeline_plan(timeline_plan)
    
    def explain(self, timeline_plan: TimelinePlan) -> Explanation:
        """
        生成方案解释（基于推理路径）
        
        Args:
            timeline_plan: 时间轴方案
            
        Returns:
            解释对象
        """
        return generate_explanation(timeline_plan.reasoning_path)
```

```typescript
function timelinePlanToCompilerInput(timeline: TimelinePlan): CompilerInput {
  /**
   * 将 TimelinePlan 转换为 Phase 1 编译器的 CompilerInput
   */
  
  const operations: CompilationOperation[] = [];
  
  // 1. 项目初始化操作
  operations.push({
    type: "init_project",
    params: {
      width: timeline.metadata.output.width,
      height: timeline.metadata.output.height,
      frame_rate: timeline.metadata.output.frame_rate,
      duration: timeline.metadata.output.duration,
      pixel_aspect_ratio: 1.0
    }
  });
  
  // 2. 导入素材
  for (const clip of timeline.clip_assignments.clips) {
    operations.push({
      type: "import_file",
      params: {
        file_path: clip.clip_atom.metadata.file_path,
        target_layer: `Clip_${clip.index}`,
        start_time: clip.start_time,
        duration: clip.duration
      }
    });
  }
  
  // 3. 图层排列
  for (const clip of timeline.clip_assignments.clips) {
    operations.push({
      type: "arrange_layer",
      params: {
        layer: `Clip_${clip.index}`,
        start_time: clip.start_time,
        duration: clip.duration,
        z_index: clip.index,
        scale: clip.scale || 1.0,
        position: clip.position || [0, 0]
      }
    });
  }
  
  // 4. 应用效果
  for (const effect_group of timeline.visual_effects.per_clip) {
    for (const effect of effect_group.effects) {
      operations.push({
        type: "apply_effect",
        params: {
          layer: `Clip_${effect_group.clip_index}`,
          effect_name: effect.name,
          effect_type: effect.type,
          parameters: effect.parameters,
          keyframes: effect.keyframes,
          start_time: effect.start_time,
          duration: effect.duration
        }
      });
    }
  }
  
  // 5. 转场
  for (const transition of timeline.transitions) {
    operations.push({
      type: "apply_transition",
      params: {
        transition_type: transition.type,
        from_layer: `Clip_${transition.from_clip_index}`,
        to_layer: `Clip_${transition.to_clip_index}`,
        duration: transition.duration,
        parameters: transition.parameters || {}
      }
    });
  }
  
  // 6. 色彩分级
  if (timeline.visual_effects.color_grading) {
    const cg = timeline.visual_effects.color_grading;
    operations.push({
      type: "color_grading",
      params: {
        global: {
          saturation: cg.global.saturation,
          brightness: cg.global.brightness,
          contrast: cg.global.contrast,
          temperature: cg.global.temperature,
          tint: cg.global.tint
        },
        per_segment: cg.per_segment,
        keyframes: cg.keyframes
      }
    });
  }
  
  // 7. 音效
  if (timeline.sfx_timeline.effects.length > 0) {
    operations.push({
      type: "add_sound_effects",
      params: {
        effects: timeline.sfx_timeline.effects.map(sfx => ({
          file_path: sfx.file_path,
          start_time: sfx.start_time,
          volume: sfx.volume,
          duration: sfx.duration,
          effects: sfx.effects || []
        }))
      }
    });
  }
  
  // 8. 相机运动
  if (timeline.visual_effects.camera_motion) {
    for (const camera_move of timeline.visual_effects.camera_motion.moves) {
      operations.push({
        type: "camera_motion",
        params: {
          layer: `Clip_${camera_move.clip_index}`,
          motion_type: camera_move.type,
          start_position: camera_move.start_position,
          end_position: camera_move.end_position,
          start_scale: camera_move.start_scale,
          end_scale: camera_move.end_scale,
          start_rotation: camera_move.start_rotation,
          end_rotation: camera_move.end_rotation,
          easing: camera_move.easing,
          start_time: camera_move.start_time,
          duration: camera_move.duration
        }
      });
    }
  }
  
  // 9. 渲染设置
  operations.push({
    type: "render_settings",
    params: {
      output_path: `output/${timeline.id}.mp4`,
      format: "h264",
      quality: timeline.metadata.output.quality,
      audio_codec: "aac",
      sample_rate: 48000
    }
  });
  
  return {
    version: "1.0.0",
    project_type: "after_effects",
    operations: operations,
    metadata: {
      source_timeline_id: timeline.id,
      generated_at: new Date().toISOString()
    }
  };
}
```

```python
class FeedbackIntegration:
    """Phase 5 反馈闭环集成"""
    
    def __init__(self, engine):
        self.engine = engine
        self.feedback_buffer = []
        self.learning_rate = 0.01
    
    def receive_feedback(self, feedback: ExecutionFeedback):
        """
        接收执行结果反馈
        
        feedback 包含：
        - timeline_id: 原始时间轴方案ID
        - execution_quality: 执行质量评分
        - user_rating: 用户评分（如果有）
        - issues: 发现的问题
        - suggestions: 改进建议
        - execution_log: 执行日志
        """
        self.feedback_buffer.append(feedback)
        
        # 积累足够反馈后进行学习
        if len(self.feedback_buffer) >= self.feedback_batch_size:
            self._process_feedback_batch()
    
    def _process_feedback_batch(self):
        """批量处理反馈，优化推理参数"""
        batch = self.feedback_buffer
        self.feedback_buffer = []
        
        # 1. 分析高评分方案的共性特征
        high_quality = [f for f in batch if f.execution_quality >= 8.0]
        low_quality = [f for f in batch if f.execution_quality < 6.0]
        
        # 2. 提取成功模式
        success_patterns = self._extract_patterns(high_quality)
        failure_patterns = self._extract_patterns(low_quality)
        
        # 3. 更新效果优先级权重
        self._update_effect_priorities(success_patterns, failure_patterns)
        
        # 4. 更新匹配权重
        self._update_matching_weights(success_patterns, failure_patterns)
        
        # 5. 更新知识库
        self._update_knowledge_base(success_patterns, failure_patterns)
    
    def _update_effect_priorities(self, success, failure):
        """更新效果优先级"""
        for pattern in success.effects:
            if pattern in self.engine.config["effect_priorities"]:
                self.engine.config["effect_priorities"][pattern] += self.learning_rate
                self.engine.config["effect_priorities"][pattern] = min(
                    1.0, self.engine.config["effect_priorities"][pattern]
                )
        
        for pattern in failure.effects:
            if pattern in self.engine.config["effect_priorities"]:
                self.engine.config["effect_priorities"][pattern] -= self.learning_rate
                self.engine.config["effect_priorities"][pattern] = max(
                    0.1, self.engine.config["effect_priorities"][pattern]
                )
    
    def export_knowledge_updates(self):
        """导出知识库更新（用于持久化）"""
        return {
            "effect_priorities": self.engine.config["effect_priorities"],
            "matching_weights": self.engine.config["matching_weights"],
            "learned_patterns": len(self.feedback_buffer),
            "last_update": time.time()
        }
```

```python
class StreamingTimelineEngine:
    """流式时间轴推理引擎（实时模式）"""
    
    def __init__(self, config=None):
        self.config = config or get_default_config()
        self.engine = TimelineEngine(config)
        self.buffer = AudioBuffer(max_duration=30.0)  # 30秒滑动窗口
        self.current_timeline = None
        self.lookahead = 5.0  # 预测未来5秒
        self.latency_target = 200  # 目标延迟（毫秒）
    
    def process_audio_chunk(self, audio_chunk, timestamp):
        """
        处理新的音频chunk
        
        Args:
            audio_chunk: 音频数据chunk
            timestamp: 当前时间戳
            
        Returns:
            更新后的时间轴片段（从当前时间到预测窗口）
        """
        # 1. 存入缓冲
        self.buffer.add(audio_chunk, timestamp)
        
        # 2. 增量音乐分析
        music_atom_partial = self._incremental_mir_analysis(
            self.buffer, timestamp
        )
        
        # 3. 如果已有足够数据，进行推理
        if self.buffer.duration >= self.config["min_buffer_duration"]:
            timeline_update = self._streaming_inference(
                music_atom_partial, timestamp
            )
            return timeline_update
        
        return None
    
    def _streaming_inference(self, music_atom, current_time):
        """
        流式推理（滑动窗口）
        
        策略：
        - 已确定部分（过去+当前）：完全确定
        - 预测部分（未来）：基于当前趋势预测
        - 每接收到新数据，修正预测部分
        """
        # 1. 已确定的时间范围 [buffer_start, current_time]
        confirmed_range = (self.buffer.start_time, current_time)
        
        # 2. 预测的时间范围 [current_time, current_time + lookahead]
        predicted_range = (current_time, current_time + self.lookahead)
        
        # 3. 对已确定部分进行完整推理
        confirmed_music = self._extract_music_range(music_atom, confirmed_range)
        confirmed_timeline = self.engine.generate(
            confirmed_music,
            self.clip_pool,
            self.user_preference,
            options=GenerateOptions(
                precision_level="L2",  # 流式用较低精度保证速度
                enable_backtrack=False
            )
        )
        
        # 4. 对预测部分进行预测式推理
        predicted_music = self._predict_future_music(music_atom, predicted_range)
        predicted_timeline = self._predict_timeline(
            predicted_music, confirmed_timeline
        )
        
        # 5. 合并
        merged = self._merge_timelines(confirmed_timeline, predicted_timeline)
        
        return {
            "current_time": current_time,
            "confirmed_range": confirmed_range,
            "predicted_range": predicted_range,
            "timeline": merged,
            "confidence": {
                "confirmed": 0.9,
                "predicted": 0.6
            }
        }
    
    def _predict_future_music(self, music_atom, future_range):
        """
        预测未来的音乐特征
        
        基于当前的节拍/段落/能量趋势进行外推
        """
        # 节拍预测：假设BPM稳定
        bpm = music_atom.rhythm.bpm
        beat_duration = 60.0 / bpm
        last_beat = music_atom.rhythm.beat_grid[-1]
        
        future_beats = []
        t = last_beat + beat_duration
        while t < future_range[1]:
            future_beats.append(t)
            t += beat_duration
        
        # 能量预测：基于当前段落类型的典型能量包络
        current_segment = self._get_current_segment(music_atom)
        energy_prediction = self._extrapolate_energy(
            music_atom.energy.rms_curve,
            current_segment.type,
            future_range
        )
        
        return {
            "rhythm": {
                "bpm": bpm,
                "beat_grid": future_beats,
                "prediction_confidence": 0.7
            },
            "energy": {
                "rms_curve": energy_prediction,
                "prediction_confidence": 0.5
            },
            "prediction_range": future_range
        }
```

```python
def calculate_quality_score(timeline_plan):
    """计算6维质量评分"""
    
    dimensions = {}
    
    # 1. 节拍对齐度
    dimensions["beat_alignment"] = calculate_beat_alignment(timeline_plan)
    
    # 2. 风格一致性
    dimensions["style_consistency"] = calculate_style_consistency(timeline_plan)
    
    # 3. 叙事流畅度
    dimensions["narrative_flow"] = calculate_narrative_flow(timeline_plan)
    
    # 4. 视觉丰富度
    dimensions["visual_variety"] = calculate_visual_variety(timeline_plan)
    
    # 5. 音画和谐度
    dimensions["audio_visual_harmony"] = calculate_audio_visual_harmony(timeline_plan)
    
    # 6. 技术质量
    dimensions["technical_quality"] = calculate_technical_quality(timeline_plan)
    
    # 加权综合
    weights = {
        "beat_alignment": 0.25,
        "style_consistency": 0.20,
        "narrative_flow": 0.20,
        "visual_variety": 0.15,
        "audio_visual_harmony": 0.15,
        "technical_quality": 0.05
    }
    
    overall = sum(dimensions[k] * weights[k] for k in dimensions)
    overall_10 = overall * 10  # 转换为0-10分制
    
    return {
        "overall": round(overall_10, 2),
        "dimensions": {k: round(v, 4) for k, v in dimensions.items()},
        "confidence": 0.85  # 评分本身的置信度
    }

def calculate_beat_alignment(timeline):
    """
    节拍对齐度计算
    
    评分标准：
    - 剪辑点与最近节拍的距离 < 50ms: 1.0 分
    - 50-100ms: 0.8 分
    - 100-200ms: 0.6 分
    - 200-500ms: 0.3 分
    - > 500ms: 0 分
    """
    clip_times = get_all_clip_boundaries(timeline)
    beat_times = timeline.beat_grid.beats
    
    if not clip_times or not beat_times:
        return 0.0
    
    total_score = 0.0
    for ct in clip_times:
        # 找最近的节拍
        nearest_beat = min(beat_times, key=lambda b: abs(b.time - ct))
        distance_ms = abs(nearest_beat.time - ct) * 1000
        
        if distance_ms < 50:
            score = 1.0
        elif distance_ms < 100:
            score = 0.8
        elif distance_ms < 200:
            score = 0.6
        elif distance_ms < 500:
            score = 0.3
        else:
            score = 0.0
        
        # 按节拍重要性加权
        weight = 0.5 + 0.5 * nearest_beat.importance
        total_score += score * weight
    
    return total_score / len(clip_times)

def calculate_style_consistency(timeline):
    """
    风格一致性计算
    
    方法：
    1. 提取每个片段的风格特征向量
    2. 计算特征向量之间的方差
    3. 1 - 方差系数 = 一致性得分
    """
    style_features = []
    
    for clip in timeline.clip_assignments.clips:
        features = extract_style_features(clip.clip_atom)
        style_features.append(features)
    
    if len(style_features) < 2:
        return 1.0  # 单个片段无一致性问题
    
    # 计算每个特征维度的方差
    import numpy as np
    feature_matrix = np.array(style_features)
    variances = np.var(feature_matrix, axis=0)
    mean_var = np.mean(variances)
    
    # 方差系数（归一化）
    mean_val = np.mean(feature_matrix)
    cv = mean_var / (mean_val + 1e-8)
    
    # 1 - 方差系数 = 一致性
    consistency = max(0.0, min(1.0, 1.0 - cv))
    
    return consistency

def calculate_audio_visual_harmony(timeline):
    """
    音画和谐度计算
    
    方法：
    1. 音乐能量曲线 vs 视觉能量曲线 的相关性
    2. 音乐情绪曲线 vs 视觉情绪曲线 的相关性
    3. 两者加权平均
    """
    # 能量相关性
    music_energy = timeline.energy_analysis.overall.rms_curve
    visual_energy = get_visual_energy_curve(timeline)
    
    # 重采样到相同长度
    n = min(len(music_energy), len(visual_energy))
    music_resampled = resample(music_energy, n)
    visual_resampled = resample(visual_energy, n)
    
    # 皮尔逊相关系数
    energy_correlation = pearson_correlation(music_resampled, visual_resampled)
    energy_correlation = max(0, energy_correlation)  # 只考虑正相关
    
    # 情绪相关性
    music_emotion = extract_emotion_curve(timeline.emotion_timeline)
    visual_emotion = extract_visual_emotion_curve(timeline)
    
    emotion_correlation = pearson_correlation(music_emotion, visual_emotion)
    emotion_correlation = max(0, emotion_correlation)
    
    # 加权平均
    harmony = 0.6 * energy_correlation + 0.4 * emotion_correlation
    
    return harmony
```

```python
class QualityControlEngine:

    def __init__(self):

        """汇总检查结果"""
        summary = {
            "total": len(results),
            "passed": sum(1 for r in results if r["passed"]),
            "failed": sum(1 for r in results if not r["passed"]),
            "critical": sum(1 for r in results if not r["passed"] and r["severity"] == "critical"),
            "high": sum(1 for r in results if not r["passed"] and r["severity"] == "high"),
            "major": sum(1 for r in results if not r["passed"] and r["severity"] == "major"),
            "minor": sum(1 for r in results if not r["passed"] and r["severity"] == "minor"),
            "by_category": {}
        }
        
        # 按类别统计
        for r in results:
            cat = r["category"]
            if cat not in summary["by_category"]:
                summary["by_category"][cat] = {"total": 0, "passed": 0, "failed": 0}
            summary["by_category"][cat]["total"] += 1
            if r["passed"]:
                summary["by_category"][cat]["passed"] += 1
            else:
                summary["by_category"][cat]["failed"] += 1
        
        return summary
```

```python
def calculate_inter_rater_reliability(scores):
    """
    计算评分者间信度（ICC - Intraclass Correlation Coefficient）
    
    scores: shape = (n_subjects, n_raters)
    """
    import numpy as np
    
    n_subjects, n_raters = scores.shape
    
    # 计算各类平方和
    grand_mean = np.mean(scores)
    
    # 受试者间平方和
    subject_means = np.mean(scores, axis=1)
    ss_between_subjects = n_raters * np.sum((subject_means - grand_mean) ** 2)
    
    # 评分者间平方和
    rater_means = np.mean(scores, axis=0)
    ss_between_raters = n_subjects * np.sum((rater_means - grand_mean) ** 2)
    
    # 残差平方和
    ss_residual = np.sum((scores - subject_means[:, None] - rater_means[None, :] + grand_mean) ** 2)
    
    # 自由度
    df_subjects = n_subjects - 1
    df_raters = n_raters - 1
    df_residual = (n_subjects - 1) * (n_raters - 1)
    
    # 均方
    ms_subjects = ss_between_subjects / df_subjects
    ms_raters = ss_between_raters / df_raters
    ms_residual = ss_residual / df_residual
    
    # ICC(2,1) - 双向随机，单个评分者
    icc_2_1 = (ms_subjects - ms_residual) / (ms_subjects + (n_raters - 1) * ms_residual + 
                                              n_raters * (ms_raters - ms_residual) / n_subjects)
    
    return {
        "icc_2_1": icc_2_1,
        "interpretation": (
            "excellent" if icc_2_1 > 0.75 else
            "good" if icc_2_1 > 0.6 else
            "moderate" if icc_2_1 > 0.4 else
            "poor"
        )
    }
```

```python
        self.results = []
    
    def run_test(self, music_atom, clip_atoms, user_preference):
        """运行单个测试用例"""
        test_results = {}
        
        for variant in self.variants:
            engine = TimelineEngine(
                precision_level=variant["config"].get("precision_level", "L2"),
                config=variant["config"].get("engine_config")
            )
            
            timeline = engine.generate(music_atom, clip_atoms, user_preference)
            
            # 计算指标
            variant_results = {}
            for metric in self.metrics:
                variant_results[metric] = calculate_metric(timeline, metric)
            
            test_results[variant["name"]] = {
                "timeline_id": timeline.id,
                "metrics": variant_results,
                "quality_score": timeline.quality_score
            }
        
        self.results.append(test_results)
        return test_results
    
    def analyze_results(self):
        """
        统计分析
        
        使用配对t检验比较各组差异
        """
        analysis = {}
        
        for metric in self.metrics:
            # 收集各组数据
            group_data = {}
            for variant in self.variants:
                vname = variant["name"]
                group_data[vname] = [r[vname]["metrics"][metric] for r in self.results]
            
            # 描述统计
            stats = {}
            for vname, data in group_data.items():
                stats[vname] = {
                    "mean": np.mean(data),
                    "std": np.std(data),
                    "median": np.median(data),
                    "min": np.min(data),
                    "max": np.max(data),
                    "n": len(data)
                }
            
            # 假设检验（两两比较）
            pair_tests = []
            variant_names = [v["name"] for v in self.variants]
            
            for i in range(len(variant_names)):
                for j in range(i+1, len(variant_names)):
                    v1, v2 = variant_names[i], variant_names[j]
                    data1, data2 = group_data[v1], group_data[v2]
                    
                    # 配对t检验
                    t_stat, p_value = stats.ttest_rel(data1, data2)
                    
                    # 效应量（Cohen's d）
                    cohens_d = (np.mean(data1) - np.mean(data2)) / \
                               (np.sqrt((np.std(data1)**2 + np.std(data2)**2) / 2) + 1e-8)
                    
                    pair_tests.append({
                        "variant_a": v1,
                        "variant_b": v2,
                        "t_statistic": t_stat,
                        "p_value": p_value,
                        "significant": p_value < 0.05,
                        "cohens_d": cohens_d,
                        "effect_size": (
                            "large" if abs(cohens_d) > 0.8 else
                            "medium" if abs(cohens_d) > 0.5 else
                            "small" if abs(cohens_d) > 0.2 else
                            "negligible"
                        )
                    })
            
            analysis[metric] = {
                "descriptive": stats,
                "pairwise_tests": pair_tests,
                "best_variant": self._find_best(stats)
            }
        
        return analysis
    
    def _find_best(self, stats):
        """找出表现最好的变体"""
        best_name = max(stats.keys(), key=lambda k: stats[k]["mean"])
        return {
            "name": best_name,
            "mean": stats[best_name]["mean"]
        }
```

```python
class MultiLevelCache:
    """多级缓存管理器"""
    
    def __init__(self, config):
        self.l1_cache = LRUCache(max_size=config.get("l1_size", 128))
        self.l2_cache = DiskCache(directory=config.get("l2_dir", "./cache"))
        self.l3_cache = None  # RedisCache(url=...) 可选
        
        self.hit_counts = {"l1": 0, "l2": 0, "l3": 0, "miss": 0}
    
    def get(self, key):
        """
        多级缓存读取
        
        L1命中 → 直接返回
        L1未命中 → L2查找 → 找到则回填L1
        L2未命中 → L3查找 → 找到则回填L1+L2
        """
        # L1
        value = self.l1_cache.get(key)
        if value is not None:
            self.hit_counts["l1"] += 1
            return value
        
        # L2
        value = self.l2_cache.get(key)
        if value is not None:
            self.hit_counts["l2"] += 1
            self.l1_cache.set(key, value)  # 回填L1
            return value
        
        # L3（如果配置了）
        if self.l3_cache:
            value = self.l3_cache.get(key)
            if value is not None:
                self.hit_counts["l3"] += 1
                self.l1_cache.set(key, value)
                self.l2_cache.set(key, value)
                return value
        
        self.hit_counts["miss"] += 1
        return None
    
    def set(self, key, value, ttl=None):
        """写入所有层级"""
        self.l1_cache.set(key, value, ttl)
        self.l2_cache.set(key, value, ttl)
        if self.l3_cache:
            self.l3_cache.set(key, value, ttl)
    
    def get_stats(self):
        """获取缓存统计"""
        total = sum(self.hit_counts.values())
        hit_rate = (total - self.hit_counts["miss"]) / (total + 1e-8)
        
        return {
            "hit_counts": self.hit_counts.copy(),
            "total_requests": total,
            "hit_rate": hit_rate,
            "l1_size": self.l1_cache.size(),
            "l2_size": self.l2_cache.size()
        }
```

```python
class ParallelInferenceEngine(TimelineEngine):

    def __init__(self, config=None, max_workers=None):
        super().__init__(config)
        self.max_workers = max_workers or multiprocessing.cpu_count()
        self.executor = concurrent.futures.ProcessPoolExecutor(
            max_workers=self.max_workers
        )
    
    def _execute_parallel(self, tasks):
        """
        并行执行任务
        
        支持的并行模式：
        1. 同层内多子任务并行（如多频段能量计算）
        2. 多片段分析并行
        3. 多假设推理并行
        """
        futures = []
        for task in tasks:
            future = self.executor.submit(task["func"], *task["args"], **task["kwargs"])
            futures.append(future)
        
        results = []
        for future in concurrent.futures.as_completed(futures):
            results.append(future.result())
        
        return results
```

```python
class IncrementalInferenceEngine:
    """增量推理引擎"""
    
    def __init__(self, base_engine):
        self.base_engine = base_engine
        self.dependency_graph = self._build_dependency_graph()
    
    def _build_dependency_graph(self):
        """
        构建层间依赖图
        
        用于确定某个输入变化会影响哪些下游层
        """
        return {
            "music_atom.rhythm.beat_grid": ["L2_beat", "L3_segment", "L6_matching", "L7_effects", "L8_sfx"],
            "music_atom.energy.rms_curve": ["L4_energy", "L5_emotion", "L6_matching", "L7_effects"],
            "music_atom.structure.segments": ["L3_segment", "L6_matching", "L7_effects"],
            "clip_atoms": ["L6_matching", "L7_effects"],
            "user_preference.style": ["L7_effects", "L8_sfx"],
            "user_preference.intensity": ["L7_effects", "L8_sfx"],
            "user_preference.rhythm": ["L6_matching", "L7_effects"],
        }
    
    def incremental_update(self, base_timeline, changes):
        """
        增量更新时间轴方案
        
        Args:
            base_timeline: 原始时间轴方案
            changes: 变更描述
                {
                    "type": "music" | "clips" | "preferences",
                    "field": "具体字段",
                    "old_value": ...,
                    "new_value": ...
                }
        
        Returns:
            更新后的时间轴方案
        """
        # 1. 确定受影响的层
        affected_layers = self._get_affected_layers(changes)
        
        if not affected_layers:
            return base_timeline  # 无影响，直接返回
        
        # 2. 找到需要重新计算的最上游层
        reentry_layer = min(affected_layers, key=lambda l: LAYER_ORDER.index(l))
        
        # 3. 从该层开始重新推理（复用上游结果）
        updated = base_timeline.deepcopy()
        
        if reentry_layer == "L2_beat":
            # 重新从节拍层开始
            music = apply_change(base_timeline.music, changes)
            beat_grid = self.base_engine.infer_beat_layer(music, ...)
            updated.beat_grid = beat_grid
            # ... 继续下游层
        elif reentry_layer == "L6_matching":
            # 只重新匹配层及下游
            clip_assignment = self.base_engine.infer_matching_layer(
                updated.beat_grid,
                updated.segments,
                updated.energy_analysis,
                updated.emotion_timeline,
                apply_changes_to_clips(base_timeline.clips, changes),
                updated.preferences
            )
            updated.clip_assignments = clip_assignment
            # ... 继续效果层、音效层、输出层
        
        # 4. 更新推理路径
        updated.reasoning_path = self._mark_incremental(
            updated.reasoning_path, reentry_layer, changes
        )
        
        return updated
```

```python
class KnowledgeBaseManager:
    """知识库管理器"""
    
    def __init__(self, base_path):
        self.base_path = base_path
        self.cache = {}
        self.schema_validator = SchemaValidator()
    
    def load_effect(self, effect_id):
        """加载效果知识"""
        return self._load(f"effects/{effect_id}.yaml")
    
    def load_genre(self, genre_id):
        """加载流派知识"""
        return self._load(f"genres/{genre_id}.yaml")
    
    def load_transition(self, transition_id):
        """加载转场知识"""
        return self._load(f"transitions/{transition_id}.yaml")
    
    def load_style(self, style_id):
        """加载风格知识"""
        return self._load(f"styles/{style_id}.yaml")
    
    def _load(self, rel_path):
        """加载并缓存知识项"""
        if rel_path in self.cache:
            return self.cache[rel_path]
        
        full_path = os.path.join(self.base_path, rel_path)
        with open(full_path, 'r', encoding='utf-8') as f:
            data = yaml.safe_load(f)
        
        # 验证Schema
        self.schema_validator.validate(data, rel_path)
        
        self.cache[rel_path] = data
        return data
    
    def add_knowledge(self, category, data):
        """
        添加新知识项
        
        1. 验证Schema
        2. 保存到磁盘
        3. 更新缓存
        """
        # 1. 验证
        self.schema_validator.validate(data, category)
        
        # 2. 保存
        item_id = data["id"]
        rel_path = f"{category}/{item_id}.yaml"
        full_path = os.path.join(self.base_path, rel_path)
        
        os.makedirs(os.path.dirname(full_path), exist_ok=True)
        with open(full_path, 'w', encoding='utf-8') as f:
            yaml.dump(data, f, default_flow_style=False, allow_unicode=True)
        
        # 3. 缓存
        self.cache[rel_path] = data
        
        return item_id
    
    def update_learned_weights(self, item_id, category, updates):
        """更新学习到的权重（来自反馈闭环）"""
        rel_path = f"{category}/{item_id}.yaml"
        data = self._load(rel_path)
        
        if "learned_weights" not in data:
            data["learned_weights"] = {}
        
        for key, value in updates.items():
            # 指数移动平均更新
            if key in data["learned_weights"]:
                old = data["learned_weights"][key]
                alpha = 0.1
                data["learned_weights"][key] = old * (1 - alpha) + value * alpha
            else:
                data["learned_weights"][key] = value
        
        data["learned_weights"]["last_updated"] = datetime.now().isoformat()
        
        # 保存
        full_path = os.path.join(self.base_path, rel_path)
        with open(full_path, 'w', encoding='utf-8') as f:
            yaml.dump(data, f, default_flow_style=False, allow_unicode=True)
        
        self.cache[rel_path] = data
        
        return data["learned_weights"]
    
    def search(self, query, category=None, filters=None, limit=20):
        """
        搜索知识库
        
        支持：关键词搜索、相似度匹配、标签过滤
        """
        results = []
        
        # 遍历知识库
        all_items = self._get_all_items(category)
        
        for item in all_items:
            # 计算相似度
            score = self._compute_relevance(item, query, filters)
            
            if score > 0.1:
                results.append({
                    "item": item,
                    "relevance_score": score
                })
        
        # 排序
        results.sort(key=lambda r: r["relevance_score"], reverse=True)
        
        return results[:limit]
```

```python
class OnlineLearner:
    """在线学习器（参数级）"""
    
    def __init__(self, initial_params, learning_rate=0.01):
        self.params = initial_params
        self.learning_rate = learning_rate
        self.update_count = 0
    
    def update_from_feedback(self, feedback):
        """
        从单条反馈中学习
        
        feedback 结构：
        {
            "timeline_id": "...",
            "config": {...},
            "quality_score": 8.5,
            "dimension_scores": {...},
            "preferences": {...},
            "music_features": {...},
            "clip_features": {...}
        }
        """
        self.update_count += 1
        
        # 学习率衰减
        lr = self.learning_rate / (1 + self.update_count * 0.001)
        
        # 根据质量评分调整参数
        quality = feedback["quality_score"] / 10.0
        
        if quality > 0.7:
            self._reinforce(feedback["config"], quality, lr)
        elif quality < 0.5:
            self._weaken(feedback["config"], quality, lr)
    
    def _reinforce(self, config, quality, lr):
        """强化（增加高分参数的权重）"""
        for param_name, value in config.items():
            if param_name in self.params:
                delta = lr * (quality - 0.7)
                if isinstance(value, (int, float)):
                    self.params[param_name] += delta * value
                    self.params[param_name] = max(0.0, min(1.0, self.params[param_name]))
    
    def _weaken(self, config, quality, lr):
        """削弱（降低低分参数的权重）"""
        for param_name, value in config.items():
            if param_name in self.params:
                delta = lr * (0.5 - quality)
                if isinstance(value, (int, float)):
                    default = 0.5
                    self.params[param_name] += delta * (default - value)
    
    def get_optimal_params(self, context=None):
        """获取当前最优参数"""
        if context is None:
            return self.params.copy()
        
        return self.params.copy()
```

```python
class DistributedTimelineEngine:
    """分布式时间轴推理引擎"""
    
    def __init__(self, scheduler_url, api_key=None):
        self.scheduler_url = scheduler_url
        self.api_key = api_key
        self.session = requests.Session()
    
    def submit_job(self, music_atom, clip_atoms, user_preference=None, 
                   priority="normal", callback_url=None):
        """
        提交推理任务
        
        返回：job_id
        """
        payload = {
            "music_atom": music_atom,
            "clip_atoms": clip_atoms,
            "user_preference": user_preference,
            "priority": priority,
            "callback_url": callback_url
        }
        
        response = self.session.post(
            f"{self.scheduler_url}/api/v1/jobs",
            json=payload,
            headers={"Authorization": f"Bearer {self.api_key}"}
        )
        response.raise_for_status()
        
        return response.json()["job_id"]
    
    def get_job_status(self, job_id):
        """查询任务状态"""
        response = self.session.get(
            f"{self.scheduler_url}/api/v1/jobs/{job_id}"
        )
        response.raise_for_status()
        return response.json()
    
    def get_job_result(self, job_id):
        """获取任务结果"""
        response = self.session.get(
            f"{self.scheduler_url}/api/v1/jobs/{job_id}/result"
        )
        response.raise_for_status()
        
        result_data = response.json()
        return TimelinePlan.from_dict(result_data["timeline_plan"])
    
    def submit_batch(self, jobs, priority="normal"):
        """批量提交任务"""
        job_ids = []
        for job in jobs:
            job_id = self.submit_job(
                job["music_atom"],
                job["clip_atoms"],
                job.get("user_preference"),
                priority=priority
            )
            job_ids.append(job_id)
        return job_ids
    
    def wait_for_completion(self, job_id, timeout=300, poll_interval=1):
        """等待任务完成"""
        start_time = time.time()
        
        while time.time() - start_time < timeout:
            status = self.get_job_status(job_id)
            
            if status["state"] == "completed":
                return self.get_job_result(job_id)
            elif status["state"] == "failed":
                raise Exception(f"Job failed: {status.get('error')}")
            
            time.sleep(poll_interval)
        
        raise TimeoutError(f"Job timed out after {timeout}s")
```
