# 参数-效果原子级映射库

> [!abstract] 文档摘要
> 本文档是视频逆向解析的核心引擎，建立了参数与效果之间的原子级双向映射关系。内容涵盖模糊类、发光辉光类、色彩调色类、扭曲类、粒子类等各大效果类型的参数-效果精确对应，每个参数都标注了取值范围、视觉效果、应用场景和关键帧动画模式。通过本映射库，可以从观察到的视觉特征直接反查出对应的参数和取值范围，是逆向分析从定性到定量的核心工具。

> [!tip] 使用指南
> - 入门读者：建议从第一章"使用说明"开始，理解双向查询和原子格式的含义
> - 快速查询：直接按效果类别查找对应的参数映射表，按视觉效果反查参数范围
> - 深入研究：结合[[解析词汇表与推理决策树]]进行系统化的推理分析
> - 实践应用：在AE中拖动参数滑块，观察视觉变化，与本文档的描述对照验证

> 每个参数能做什么效果？每个视觉效果对应什么参数？原子级精确映射，从参数→效果和效果→参数双向对照。
>
> 本库是"视频逆向解析"的核心引擎：给定一个视觉特征，查出对应的参数和取值范围。

## 一、使用说明

### 1.1 双向查询

```
正向查询（参数→效果）：
  已知使用了某个参数 → 查这个参数能产生什么视觉效果

逆向查询（效果→参数）：
  在视频中观察到某个视觉特征 → 查对应参数和取值范围
```

### 1.2 参数描述原子格式

每个参数按以下原子格式描述：

```
[参数名] | [范围] | [效果描述] | [视觉签名] | [关键帧常用] | [常见组合]
```

## 二、模糊类参数原子映射 ⚛️

> [!important] 基础核心映射
> 模糊类效果是所有视频效果的基石，也是参数推断的入门。高斯模糊、定向模糊、径向模糊三大基础模糊的参数-效果映射必须熟记于心。掌握模糊类参数的量化规律，可以快速推断出80%常见效果的模糊参数。

### 2.1 高斯模糊（Gaussian Blur）

| 参数值 | 视觉效果 | 应用场景 | 关键帧动画 |
|--------|---------|---------|-----------|
| 0-2 | 几乎无变化，极轻微柔化 | 去除噪点/锐度过高 | 否 |
| 2-5 | 轻微柔化，皮肤磨皮感 | 美颜/去锐度 | 否 |
| 5-15 | 明显模糊，可辨认物体 | 梦幻回忆/聚焦前景 | ✅ 0→15转场 |
| 15-30 | 强模糊，轮廓不清 | 背景虚化/隐私遮挡 | ✅ 景深切换 |
| 30-60 | 极强模糊，只剩色块 | 抽象背景/色彩提取 | ✅ |
| 60-100+ | 完全模糊 | 颜色取样/极端风格 | ✅ |

**关键帧模式**：
```
模糊转场（Blur Transition）：
  0:00  Blurriness = 0
  0:10  Blurriness = 30（关键帧）
  0:20  Blurriness = 0
效果：画面模糊再清晰，常用于场景切换
```

### 2.2 定向模糊（Directional Blur）

| 参数组合 | 视觉效果 | 应用场景 |
|---------|---------|---------|
| Direction=0°, Length=10 | 水平轻微拖尾 | 水平运动模糊 |
| Direction=90°, Length=20 | 垂直拖尾 | 下落运动模糊 |
| Direction=45°, Length=30 | 斜向拖尾 | 冲刺/速度感 |
| Direction=任意, Length=50+ | 极端拉丝 | 转场/抽象效果 |
| Direction=0°, Length=0→80→0 | 水平冲击转场 | 快速切换场景 |

### 2.3 径向模糊（Radial Blur）

| 类型+参数 | 视觉效果 | 应用场景 |
|----------|---------|---------|
| Zoom, Amount=20 | 中心清晰，向外扩散 | 轻微速度感 |
| Zoom, Amount=50 | 强烈放射状模糊 | 冲击/震撼感 |
| Zoom, Amount=100 | 极端放射 | 穿越时空效果 |
| Spin, Amount=30 | 旋转模糊 | 旋转转场 |
| Spin, Amount=80 | 强烈旋转模糊 | 眩晕/催眠效果 |

### 2.4 镜头模糊（Camera Lens Blur / Lens Blur）

| 参数 | 范围 | 效果 | 视觉签名 |
|------|------|------|---------|
| Blur Radius | 0-100 | 模糊量 | 越大越虚 |
| Iris Shape | Triangle→Octagon | 光斑形状 | 三角/五边/六边/八边形光斑 |
| Iris Rounded | 0-100 | 光斑圆度 | 0=多边形明显，100=接近圆形 |
| Highlight Gain | 0-100 | 高光增强 | 高光区域更亮更明显 |
| Highlight Threshold | 0-100 | 高光阈值 | 只有亮度高于此值的高光才增强 |

**识别要点**：高光呈现多边形光斑 → 镜头模糊；高光柔和渐变 → 高斯模糊

## 三、发光/辉光类参数原子映射 ⚛️

> [!important] 高频应用映射
> 发光辉光是风格化视频中最常见的效果之一，也是识别难度较高的类型。阈值、半径、强度三大核心参数的组合可以产生千变万化的辉光效果。掌握本章的参数组合规律，可以快速判断辉光效果的具体参数设置。

### 3.1 AE原生 Glow（发光）

| 参数 | 范围 | 效果 | 视觉签名 |
|------|------|------|---------|
| Glow Threshold | 0-100 | 发光阈值 | 只有亮度高于此值的区域发光 |
| Glow Radius | 0-100 | 发光半径 | 发光扩散范围 |
| Glow Intensity | 0-100+ | 发光强度 | 亮度倍增 |
| Glow Colors | Original/Original+A&B/Arbitrary | 颜色模式 | 原色/双色渐变/任意色 |
| Color A/B | RGB | 发光渐变色 | 从A色到B色的渐变 |
| Glow Operation | None/Add/Screen等 | 混合模式 | 叠加方式 |

**参数→效果映射**：
```
Threshold 80 + Radius 10 + Intensity 2 → 只有最亮的高光发光，范围小
Threshold 50 + Radius 30 + Intensity 3 → 中等亮度区域发光，范围中等
Threshold 20 + Radius 50 + Intensity 5 → 大面积发光，强烈辉光
Threshold 0 + Radius 80 + Intensity 8 → 全画面发光，梦幻/过曝感
```

| Threshold=0.4, Brightness=2.0, Radius=60 | 明显发光 | 人物边缘光/魔法效果 |
| Threshold=0.2, Brightness=4.0, Radius=100 | 强烈辉光 | 霓虹灯/能量场 |
| Threshold=0.1, Brightness=8.0, Radius=200 | 极端发光 | 爆炸/闪光/转场 |
| +Colorize=On, Tint=青色 | 青色发光 | 科技/赛博朋克 |
| +Colorize=On, Tint=品红 | 品红发光 | 霓虹/梦幻 |
| +Shimmer=0.5 | 闪烁微光 | 动态光效/水波 |

### 3.3 Optical Flares 光晕参数→效果

## 四、色彩/调色类参数原子映射 ⚛️

> [!note] 必备技能映射
> 调色是所有视频的必经之路，也是逆向分析的第一环。色阶、曲线、色相饱和度三大调色工具的参数变化直接决定视频的整体风格。掌握本章的参数-效果对应关系，可以快速还原视频的调色参数。

### 4.1 色阶（Levels）

| 参数 | 范围 | 效果 | 视觉签名 |
|------|------|------|---------|
| Input Black | 0-254 | 提高黑色纯度 | 暗部更暗 |
| Input White | 1-255 | 提高白色纯度 | 亮部更亮 |
| Gamma | 0.1-10 | 中间调亮度 | 整体明暗 |
| Output Black | 0-254 | 限制最暗值 | 黑色变灰 |
| Output White | 1-255 | 限制最亮值 | 白色变灰 |

**关键帧模式**：
```
日落到夜景转换：
  0:00  Input Black=0, Gamma=1.0, Output White=255
  2:00  Input Black=15, Gamma=0.7, Output White=200
效果：画面变暗、对比度增加、最亮处降低
```

### 4.2 色相/饱和度（Hue/Saturation）

| 参数 | 范围 | 效果 | 应用 |
|------|------|------|------|
| Master Hue | -180°到+180° | 整体色相旋转 | 色彩替换 |
| Master Saturation | -100到+100 | 整体饱和度 | 去色/增艳 |
| Master Lightness | -100到+100 | 整体亮度 | 明暗调整 |
| Channel R/G/B Hue | -180°到+180° | 单通道色相 | 精确调色 |
| Colorize | On/Off | 单色化 | 复古/单色风格 |

**经典效果配方**：
```
单色复古：Saturation=-80, Colorize=On, Color=棕褐色
科幻青橙：R通道Hue=-10, B通道Hue=+10, Saturation=+20
梦幻低饱和：Saturation=-40, Lightness=+10
```

### 4.3 曲线（Curves）

| 曲线形状 | 视觉效果 | 应用场景 |
|---------|---------|---------|
| S型曲线（暗更暗亮更亮） | 增加对比度 | 电影感/增强质感 |
| 上凸曲线 | 整体提亮 | 曝光不足修正 |
| 下凹曲线 | 整体压暗 | 过曝修正 |
| 反S曲线 | 降低对比度 | 柔和/梦幻 |
| 红色通道S曲线 | 红色对比增强 | 暖色调强化 |
| 蓝色通道上凸 | 蓝色偏移 | 冷色调/夜景 |

### 4.4 三级调色（Three-Way Color）

| 调整区域 | 参数 | 效果 | 视觉特征 |
|---------|------|------|---------|
| Shadows | 色盘向暖 | 暗部偏暖 | 阴影带橙红色 |
| Shadows | 色盘向冷 | 暗部偏冷 | 阴影带蓝色 |
| Midtones | 色盘向绿 | 中间调偏绿 | 自然/科技感 |
| Highlights | 色盘向暖 | 高光偏暖 | 高光带金黄 |
| Highlights | 色盘向冷 | 高光偏冷 | 高光带青蓝 |

**经典调色组合**：
```
电影橙青调色（Orange & Teal）：
  Shadows → 偏青蓝（色盘左下）
  Highlights → 偏橙黄（色盘右上）
  Midtones → 微调
  → 形成经典好莱坞调色风格
```

```
要发光/光效 → Add 或 Screen

要颜色替换 → Color 或 Hue
```

## 十四、参数推断决策树 🔀

### 14.1 从视觉效果推断参数的决策流程

```
观察到发光效果 →
├── 发光范围小且硬 → AE原生Glow, Threshold高(70+), Radius低(5-15)
├── 发光范围中等柔和 → S_Glow, Threshold中(40-60), Radius中(30-60)
├── 发光范围大且自然衰减 → Deep Glow, Radius大(50-100)
├── 带镜头光斑/星芒 → Optical Flares
├── 从特定方向放射 → Trapcode Shine
└── 多色星光 → Starglow

观察到模糊效果 →
├── 均匀无方向 → 高斯模糊
├── 有方向性 → 定向模糊, Direction=拖尾方向
├── 从中心放射 → 径向模糊(Zoom)
├── 绕中心旋转 → 径向模糊(Spin)
├── 高光呈多边形光斑 → 镜头模糊
├── 有深度差异 → 景深(配合Z通道)
└── 运动模糊 → CC Force Motion Blur 或 RSMB

观察到粒子 →
├── 点状/球形粒子 → Particular, Type=Sphere/Glow Sphere
├── 云团状 → Particular, Type=Cloudlet
├── 条纹拖尾 → Particular, Type=Streaklet
├── 自定义形状 → Particular, Type=Sprite
├── 3D模型粒子 → E3D Particle Replicator
├── 规则网格排列 → Form, Base Form=Box-Grid
├── 音频驱动 → Form + Audio React
└── 流体感 → Particular Fluid 或 Stardust

观察到扭曲 →
├── 随机抖动 → Displacement Map + 噪声层 或 Turbulent Displace
├── 水面波纹 → Wave Warp 或 Ripple
├── 热浪 → S_WarpBubble 或 Displacement Map
├── 液化变形 → Liquify 或 Mesh Warp
├── 透视/桶形 → Optics Compensation 或 Lens Distortion
├── 极坐标变换 → Polar Coordinates
└── 万花筒 → Kaleidoscope 或 BCC Kaleidoscope

观察到文字动画 →
├── 逐字出现 → Range Selector + Opacity
├── 逐字滑动 → Range Selector + Position
├── 逐字缩放 → Range Selector + Scale
├── 打字机 → Source Text表达式 或 Range Selector+Offset
├── 路径文字 → Text on Path
└── 3D文字 → E3D 或 BCC Extruded Text

观察到转场 →
├── 渐变叠化 → Opacity 0→100
├── 白闪 → Brightness 0→100→0 (0.2秒)
├── 缩放穿越 → Scale 100→150 + 模糊
├── 故障切换 → Twitch 或 Glitch效果
├── 光效扩散 → Shine/Glow 扩散
├── 粒子消散 → Particular 粒子爆发
└── 推动切换 → Position 滑动
```
