### 2.2 Element 3D合成

```
E3D工作流:
1. 导入3D模型(OBJ/FBX)
2. 设置材质和纹理
3. 配置灯光和阴影
4. 与实拍素材合成
5. 添加粒子/光效增强
6. 色彩匹配统一

应用场景:
- 机械/机器人合成
- 建筑/场景扩展
- 产品展示
- 科幻元素
```

## 四、工作流程

### 4.1 VFX制作流程

```
标准VFX流程:
1. 前期规划(分镜/参考)
2. 素材拍摄(绿幕/跟踪标记)
3. 素材准备(抠像/跟踪)
4. CG制作(模型/材质/动画)
5. 合成(多元素整合)
6. 调色(统一色彩)
7. 输出(渲染/交付)
```

### 4.2 品质标准

- 物理准确性: 光影/透视/比例
- 细节丰富度: 纹理/颗粒/噪声
- 运动自然度: 物理/惯性/缓动
- 色彩融合度: 色温/饱和度/对比
