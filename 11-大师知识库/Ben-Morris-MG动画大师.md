## 二、核心技法

### 2.1 形状动画

| 技法 | 原理 | 应用 |
|------|------|------|
| 形变动画 | 路径关键帧插值 | 图形变换 |
| 修剪路径 | Trim Paths动画 | 线条生长 |
| 重复器 | Repeater递归 | 图案生成 |
| 合并路径 | Merge Paths运算 | 布尔运算 |
| 变换动画 | 位置/缩放/旋转 | 基础运动 |

### 2.2 信息图形

```
信息图形设计:
1. 数据可视化: 图表→动画→叙事
2. 图标动画: 静态图标→动态演绎
3. 流程展示: 步骤→连接→动画
4. 地图动画: 路径→标注→数据

设计原则:
- 简洁清晰: 信息层次分明
- 视觉引导: 运动引导视线
- 节奏控制: 快慢交替
- 色彩编码: 信息分类
```

## 三、工作流程

### 3.1 设计流程

```
MG动画流程:
1. 需求分析(目标/受众/时长)
2. 概念设计(风格/色彩/构图)
3. 分镜脚本(画面/运动/时间)
4. 设计稿(静态设计)
5. 动画制作(关键帧/表达式)
6. 音效设计(配乐/音效)
7. 输出交付(格式/编码)
```

### 3.2 效率技巧

- 使用形状图层(非光栅)
- 建立动画预设库
- 使用表达式控制运动
- 善用图形编辑器(曲线)
- 预合成重复元素
