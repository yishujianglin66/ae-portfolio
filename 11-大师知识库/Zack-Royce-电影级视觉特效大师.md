## 二、核心技法体系

### 2.1 创意转场设计

| 技法 | 原理 | AE实现 |
|------|------|--------|
| 遮罩转场 | 利用画面元素做遮罩 | Track Matte |
| 变焦转场 | 快速缩放+模糊 | Transform+Directional Blur |
| 光效转场 | 光晕/镜头光斑 | Optical Flares/光效插件 |
| 故障转场 | 数据损坏效果 | Datamosh+Glitch效果 |
| 液体转场 | 流体模拟 | Turbulent Displace+Displacement Map |
| 粒子转场 | 粒子消散 | Particular+遮罩 |

### 2.2 视觉特效设计

```
电影级VFX制作流程:
1. 分析场景需求
2. 设计特效层次
3. 制作基础元素
4. 添加细节纹理
5. 色彩匹配
6. 光影整合
7. 最终合成

品质标准:
- 物理准确性(光影/透视/比例)
- 细节丰富度(纹理/噪声/颗粒)
- 运动自然度(缓动/物理/惯性)
- 色彩融合度(色温/饱和度/对比)
```

## 三、代表作品分析

### 3.1 电影级转场合集

```
技法拆解:
1. 无缝转场: 利用运动模糊+遮罩
2. 匹配剪辑: 形状/颜色/运动匹配
3. 速度 ramp: 时间重映射曲线
4. 音效设计: 转场配合音效增强冲击
```

### 3.2 VFX特效演示

```
特效层次:
├── 基础层: 实拍素材
├── 特效层: CG元素/粒子
├── 光效层: 光晕/体积光
├── 调色层: 色彩统一
└── 后期层: 颗粒/暗角/镜头畸变
```
