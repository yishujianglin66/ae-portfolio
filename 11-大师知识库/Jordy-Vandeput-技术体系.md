## 💻 软件体系

### Premiere Pro（主剪辑）

Jordy 的三部曲 Coursera 课程覆盖了完整 PR 工作流：

| 模块 | 核心内容 |
|------|---------|
| **Part 1: 剪辑基础** | 项目设置、工作区导航、修剪、重构图、混合 |
| **Part 2: 转场 + 图形** | 自定义转场、文字设计、遮罩、动态图形 |
| **Part 3: 音频 + 调色** | 对话增强、音景构建、调色、多平台导出 |

**关键技法：**
- 用遮罩引导观众注意力（masking to direct attention）
- 关键帧动画制作漂浮效果（animated position/keyframes for floatation）
- 自定义转场而非依赖预设（custom transitions over presets）
- 音频自动转录为字幕（transcribe audio → captions）
- 可复用模板保持品牌一致性

## 🖥️ 硬件哲学

### CPU > GPU

> *"视频剪辑更依赖处理器（CPU），不是显卡（GPU），这是最常见的误区。"*

| 硬件 | 优先级 | 原因 |
|------|--------|------|
| **CPU** | 最高 | 编解码、渲染、多任务全靠它 |
| **RAM** | 高 | 32GB 起步，64GB 理想 |
| **NVMe SSD** | 高 | 素材读写速度直接决定流畅度 |
| **GPU** | 中 | 辅助渲染，但非瓶颈 |

### 平台选择：从 Mac 到 PC

```
MacBook Pro（初期）
    │
    └── 贵，性能可预测，生态好
            │
            ↓ 转向
            │
MSI 工作站（现在）
    │
    └── 同等或更高性能，价格更低
        Premiere Pro 在 Mac 和 Windows 上"看起来一模一样"
        稳定性优先于最新配置
```

## 🔧 具体技法速查

### 5 种单灯恐怖布光

| 布光方式 | 实现方法 | 效果 |
|---------|---------|------|
| **剪影** | 光源放在主体背后 | 神秘、匿名感 |
| **半脸阴影** | 遮光板/纸筒控制光束 | 隐藏、暗黑 |
| **门缝光** | 纸板切缝 + 灯光穿过 | 偷窥、紧张 |
| **手电筒光** | 菲涅尔透镜聚焦光束 | 搜索、不安 |
| **底光** | 灯光从下方打 | 诡异、超自然 |

> 所有效果用**烟雾/薄雾**增强——让光束可见。

### 眼缩放转场

```
实拍阶段：
├── 缓慢推近被摄者眼睛
├── 确保充足照明（眼睛有高光）
└── 最终画面停在瞳孔全黑

后期阶段（AE）：
├── 隔离瞳孔区域（遮罩）
├── 在瞳孔全黑帧切入新场景
└── 确保新场景暗度匹配瞳孔黑色
```

### 3D 摄像机追踪

```
① AE → 效果 → 3D 摄像机追踪器
② 分析素材，提取摄像机运动
③ 设置原点 + 地平面
④ 添加虚拟元素（文字/模型）
⑤ 遮罩前景遮挡物
⑥ 开启运动模糊
```

## 📐 镜头规划公式

> **1 分钟银幕故事 = 7-10 个独立镜头**

应用：
- 30 秒短片 → 规划 4-5 个镜头
- 5 分钟教程 → 规划 35-50 个镜头
- 每个镜头预留 30 分钟拍摄时间
