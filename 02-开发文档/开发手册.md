### 通信流程

```
UI 按钮点击
  → CSInterface.evalScript("AEStudioKit.dispatch('action', '{...}')")
    → host/index.jsx dispatch 路由
      → 功能模块处理
        → [ExtendScript 本地操作] 或 [system.callSystem → Python 脚本]
      → 返回 JSON 结果
    → CEP 面板接收结果 → UI 更新
```

## 3. 如何添加新预设

### 3.1 添加到预设数据库

编辑 `_storage/presets/text_presets_database.json`，在 `presets` 数组中添加新条目：

```json
{
    "id": "my_custom_preset",
    "name": "我的自定义预设",
    "category": "entrance",
    "duration": 1.0,
    "desc": "自定义文字动画描述",
    "keywords": ["自定义", "关键词"],
    "source": "custom",
    "emotion": "dynamic"
}
```

### 3.2 实现动画逻辑

在 `host/text_engine.jsx` 的 `ART_DESCENDS_PRESETS` 中添加动画实现函数。

### 3.3 重新扫描

在面板中点击 **🔄 刷新** 或重启面板。

## 4. 如何添加新效果模块

### 4.1 ExtendScript 端

在 `host/utils/` 创建新的效果模块，遵循 dispatch 模式：

```javascript
// host/utils/my-effect.jsx
AEStudioKit.MyEffect = {
    applyToLayer: function(layer, params) {
        // 1. 校验输入
        // 2. 使用 scheduleTask 异步应用
        // 3. 返回 { success, data, error, code }
    }
};
```

### 4.2 注册到 dispatch

在 `host/index.jsx` 的 dispatch switch 中添加新 action。

### 4.3 面板端

在 `host/index.html` 中添加 UI 控件并绑定事件。

## 5. 关键技术决策

### 5.1 为什么用 ExtendScript ES3

- AE 的 ExtendScript 引擎仅支持 ES3 (JavaScript 1.5)
- 不能使用 const/let/箭头函数/模板字符串/class/Promise
- 必须使用 `var` 和 `function` 关键字

### 5.2 为什么用 scheduleTask 异步

- AE 是单线程，长同步操作会完全冻结 UI
- `app.scheduleTask(string, delay, repeat)` 将任务加入队列
- 每个 task 处理 3-5 个项目，然后 `app.redraw()` 刷新 UI

### 5.3 为什么用 system.callSystem

- ExtendScript 没有网络请求 API (无 fetch/XMLHttpRequest)
- `system.callSystem(cmd)` 是唯一执行外部程序的方式
- 通过调用 Python 脚本实现 AI 功能

### 5.4 为什么用 ONNX 模型

- 跨平台 (Windows/macOS/Linux)
- 支持 CPU/CUDA/CoreML 多后端
- 单文件分发，无需 PyTorch/TensorFlow 环境

## 7. 部署

### 开发版

```
VSCode 任务: 📦 部署到 CEP
→ 复制所有文件到 %APPDATA%\Adobe\CEP\extensions\ae-vocal-remover\
→ 重启 AE
```

### 发布版

```
1. 复制项目文件夹
2. 删除 _storage/temp/ (临时文件)
3. 删除 __pycache__/ 和 node_modules/
4. 压缩为 .zip
5. 附带 README.md 安装说明
```
