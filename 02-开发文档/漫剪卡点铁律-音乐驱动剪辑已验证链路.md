## 1. 卡点链路（已验证，顺序固定）

```
BGM → music_dynamics 能量分层 → 切点密度按能量级
    → kick/strong 强制锚定(beatgrid) → 逐镜头变速运镜(beat_strength)
```

- **切点密度按能量级**（用 `_arc_levels`，勿用 onset 密度——low 段 hihat 会误判高密）：
  high 段 onset∪beat 全切(0.18s) / mid 段 beat 逐拍 / low 段仅 downbeat 长镜头(呼吸)
- **边界吸附到拍**：非首尾边界 250ms 内有拍/onset 则吸附
- **空档正确性**：200ms 内无拍的边界保留（长镜头跨越空档=正确）

## 2. 变速（已验证）

- `BeatStrengthEngine.classify_beats` → `speed_for_shot(level, beat_strength, e_norm, is_downbeat)`
  - high+强拍→1.0x pulse / high+普通→1.3-1.5x fast_pan
  - low+强拍→0.55x slowmo / low+普通→0.7x
  - mid+强拍→0.9x zoom_back / mid+普通→1.0x static
- **beat 匹配必须最近回退**（否则 55% 退化 MEDIUM 全原速）
- **e_norm 用 RMS 真实能量 P10/P90 分位归一**
- **变速镜头强制硬切**（setpts 与 xfade 预补偿叠加会引入 98% 切点滞后）

## 3. 撞拍锚定（beatgrid）

- **kick(<150Hz) + strong 拍** 强制并入切点（排除 hihat/riser/glitch）
- 加载器 `ProductionDirector._load_beatgrid()`（缓存 tmp/audiomap_*.json）
- 实测 kick 命中 91%

## 4. 节奏呼吸（information_density 旋钮）

- **旋钮必须接入切点密度**（否则默认值→一直快切无呼吸）
- low 段间隔 `max(0.3, 1.5-0.12*info_d)`，mid `max(0.18, 0.8-0.06*info_d)`，high 保持 0.18s
- **加载风格卡** `ProductionDirector(taste_profile=风格卡)`，高燃用 `amv_highenergy.json`
- 实测 <0.3s 镜头 76%→33%，评分 68.5→82.3
