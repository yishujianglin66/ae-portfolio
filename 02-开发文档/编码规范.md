## 1. 文件编码

### 规则
| 文件类型 | 编码 | 说明 |
|----------|------|------|
| `.jsx` | **UTF-8 BOM** | ExtendScript 强制要求 |
| `.js` | UTF-8 | CEP 面板脚本 |
| `.html` | UTF-8 | CEP 面板 HTML |
| `.css` | UTF-8 | 样式文件 |
| `.py` | UTF-8 | Python 脚本 |
| `.json` | UTF-8 | 数据文件 |

### 检查方法
```bash
# 运行 VSCode 任务
✅ 检查 UTF-8 BOM

# 或手动
xxd -l 3 -p host/main.jsx
# 应输出: efbbbf (BOM 标记)
```

## 2. 语法限制

### ExtendScript (.jsx) — 仅 ES3

| ✅ 允许 | ❌ 禁止 |
|---------|---------|
| `var` | `const`, `let` |
| `function name() {}` | `() => {}` 箭头函数 |
| `"str " + var` | `` `str ${var}` `` 模板字符串 |
| `if/else/for/while` | `for...of` |
| `typeof`, `instanceof` | `class`, `extends` |
| `try/catch` | `Promise`, `async/await` |
| `JSON.parse/stringify` (polyfill) | `fetch` |
| `$.evalFile()` | `import/export` |
| `app.scheduleTask()` | `setTimeout/setInterval` |

### CEP Panel (.js) — 仅 ES5

| ✅ 允许 | ❌ 禁止 |
|---------|---------|
| `var` | `const`, `let` |
| `function() {}` | `() => {}` |
| `XMLHttpRequest` | `fetch` |
| `addEventListener` | `class` |
| `Array.prototype.forEach` | `for...of` |

## 3. API 使用规范

### 🔴 绝对禁止

```javascript
// ❌ 错误: app.refresh 不存在
app.refresh();

// ✅ 正确: 使用 app.redraw
app.redraw();
```

```javascript
// ❌ 错误: layer.selected 不可靠
if (layer.selected) { ... }

// ✅ 正确: 使用 comp.selectedLayers
var selLayers = comp.selectedLayers;
if (selLayers && selLayers.length > 0) { ... }
```

```javascript
// ❌ 错误: 长操作同步执行 — 阻塞 UI
for (var i = 0; i < 100; i++) { process(layer(i)); }

// ✅ 正确: 使用 scheduleTask 分片
app.scheduleTask("processChunk()", 50, false);
```

```javascript
// ❌ 错误: CEP 面板中调用 confirm()
if (confirm("确定吗?")) { ... }

// ✅ 正确: 自定义 toast/模态 UI
showConfirm("确定吗?", function(ok) { ... });
```

## 4. 错误处理规范

### 标准错误返回格式

```javascript
// 成功
{ success: true, data: { ... } }

// 失败
{
    success: false,
    error: "人类可读的错误描述",
    code: "E_XXX"  // 错误码，全局唯一
}
```

### 错误码约定

| 前缀 | 含义 | 示例 |
|------|------|------|
| `E_` | 客户端/逻辑错误 | `E_NULL_INPUT`, `E_TIMEOUT` |
| `E_CS_` | CEP 通信错误 | `E_CS_NULL`, `E_CS_PARSE` |
| `E_RQ_` | 渲染队列错误 | `E_RQ_BUSY` |

### 错误传播链

```
Python 异常 → JSON { status: "error", message: "..." }
  → system.callSystem 捕获 stdout
    → ExtendScript try/catch → { success: false, error, code }
      → CEP 面板接收 → toast 显示 + 日志记录
```

## 5. 路径管理规范

### 原则: 零硬编码

```javascript
// ❌ 硬编码
var path = "C:/Users/Administrator/Desktop/skills/ae-vocal-remover/";

// ✅ 动态检测
var f = new File($.fileName);
var root = f.parent.fsName; // 从脚本位置推断
```

### 标准路径前缀

| 路径 | 用途 |
|------|------|
| `_storage/logs/` | 日志文件 |
| `_storage/temp/` | 临时文件 |
| `_storage/models/` | AI 模型 |
| `_storage/output/` | 处理结果 |
| `_storage/presets/` | 预设数据库 |

## 6. 命名约定

| 类型 | 约定 | 示例 |
|------|------|------|
| ExtendScript 函数 | camelCase | `extractAudioToTemp` |
| CEP JS 函数 | camelCase | `showToast` |
| Python 函数 | snake_case | `separate_vocals` |
| 错误码 | E_XXX (大写+下划线) | `E_NULL_INPUT` |
| 全局命名空间 | PascalCase | `AEStudioKit` |
| action 名称 | camelCase | `applyTextPreset` |

## 7. 注释规范

### 原则: 注释解释 "为什么"，而非 "做了什么"

```javascript
// ❌ 无意义注释
var x = 5; // 设置 x 为 5

// ✅ 有价值注释
var chunkSize = 5; // 为什么是5：大于5会明显卡顿，小于3会降低效率
```

### JSDoc 模板

```javascript
/**
 * 函数的简要说明
 *
 * 为什么这样设计: (关键决策说明)
 *
 * @param {Type} paramName — 参数说明
 * @returns {Object} { success: Boolean, data: Any, error: String }
 */
function myFunction(paramName) { ... }
```
