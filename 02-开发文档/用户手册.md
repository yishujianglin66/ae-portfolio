# AE StudioKit — 用户手册

> **版本**: v3.0 | **更新**: 2026-06-10
>
> 本手册面向 **After Effects 用户**，介绍扩展的安装、功能使用和常见问题。

---

## 1. 简介

AE StudioKit 是一个企业级 After Effects 扩展，集成四大核心功能：

| 功能 | 说明 |
|------|------|
| 🎨 **文字特效** | 108+ 动画预设、15 分类、一键应用 |
| 🎬 **视频增强** | 开源 AI 超分辨率 (2x/4x) + 帧插值慢动作 |
| 🎵 **人声分离** | AI 分离人声和伴奏，自动导入 AE 项目 |
| ⚙️ **环境诊断** | 一键检测 Python/FFmpeg/模型等依赖 |

---

## 2. 安装

### 2.1 前提条件

- After Effects 2023+ (v23.0+)
- Windows 10/11 (macOS 部分支持)
- Python 3.9+ (仅人声分离和视频增强需要)
- FFmpeg (项目已内置 8.1.1 版本)

### 2.2 安装步骤

```
1. 将 AE_StudioKit 文件夹复制到:
   %APPDATA%\Adobe\CEP\extensions\

2. 启用 CEP 调试模式 (如未启用):
   按 Win+R，输入 regedit，定位到:
   HKEY_CURRENT_USER\Software\Adobe\CSXS.12
   新建 DWORD 值 PlayerDebugMode = 1

3. 重启 After Effects

4. 在 AE 菜单栏: 窗口 → 扩展 → AE StudioKit
```

### 2.3 首次运行设置

1. 打开面板后，切换到 **⚙️ 设置** 标签
2. 检查依赖状态: Python、FFmpeg、模型
3. 点击 **🔄 重新检测** 确认环境就绪
4. 如有红色缺失项，按提示安装对应依赖

## 3. 文字特效标签

### 3.1 浏览预设

- 左侧分类筛选器点击切换分类
- 搜索框输入关键词实时过滤
- 悬停卡片查看预设描述

### 3.2 应用预设

1. 在 AE 中选中一个**文字图层**
2. **双击**预设卡片
3. 观察时间轴出现关键帧动画
4. 面板显示绿色 toast "✅ 预设已应用"

### 3.3 获取更多预设

- 点击 **🌐 在线获取** 从 newcger.com 抓取社区预设
- 点击 **🔄 刷新** 重新扫描本地 .ffx 文件

## 4. 视频增强标签

### 4.1 基本操作

1. 在输入框中粘贴视频文件路径 (或点击 **📁 浏览**)
2. 选择超分倍率: 2x (推荐)、4x (高精度)
3. 可选: 帧率倍增 (慢动作)、去噪、色彩增强
4. 点击 **🚀 开始增强**
5. 等待进度条完成 (大视频可能需要几分钟到几十分钟)

### 4.2 参数说明

| 参数 | 说明 | 建议 |
|------|------|------|
| 超分 2x | 分辨率翻倍 | 适合 1080p→4K |
| 超分 4x | 分辨率 4 倍 | 仅适合小视频 (<720p) |
| 帧率 2x | 慢动作 50% 速度 | 适合运动镜头 |
| 帧率 4x | 极慢动作 25% 速度 | CPU 密集，慎用 |
| 去噪 | 减少视频噪点 | 低光素材推荐开启 |
| 色彩增强 | CLAHE 对比度增强 | 灰暗素材推荐开启 |

### 4.3 引擎说明

视频增强使用自研开源引擎，不依赖 Topaz Video AI：
- **Real-ESRGAN**: 超分辨率 (ONNX 模型，~67MB)
- **RIFE**: 帧插值 (ONNX 模型，~48MB)
- 首次使用会自动下载模型文件

## 5. 人声分离标签

### 5.1 操作流程

1. 在 AE 中选中一个**包含音频的图层**
2. 验证面板显示 "图层名 (含音频)"
3. 选择分离引擎: Demucs (推荐)
4. 点击 **🎵 分离选中图层人声**
5. 等待处理完成
6. 检查 **AE 项目面板** — 应出现两个新素材:
   - `{图层名}_人声`
   - `{图层名}_伴奏`

### 5.2 引擎对比

| 引擎 | 质量 | 速度 | 显存需求 |
|------|------|------|----------|
| Demucs | ⭐⭐⭐⭐⭐ | GPU 加速快, CPU 慢 | 4GB+ |
| Spleeter | ⭐⭐⭐ | CPU 稳定 | 2GB RAM |

## 7. 常见问题

### Q: 面板显示 "AE 未连接"
**A**: 确保在 AE 中打开面板 (窗口 → 扩展 → AE StudioKit)，而非在浏览器中打开。

### Q: 文字预设双击没反应
**A**: 检查:
1. 是否选中了文字图层 (不是形状图层或空图层)
2. 面板状态栏是否显示 "AE: 已连接"
3. 切换到设置标签查看日志中的错误信息

### Q: 视频增强显示 "模型未找到"
**A**: 首次使用需要下载模型 (~115MB)。确保网络畅通，然后重试。

### Q: 人声分离显示 "FFmpeg 不可用"
**A**: 项目内置了 FFmpeg 8.1.1，确保 `ffmpeg-8.1.1-essentials_build/bin/` 目录存在。

### Q: 处理后找不到输出文件
**A**: 检查 `_storage/output/` 目录。
