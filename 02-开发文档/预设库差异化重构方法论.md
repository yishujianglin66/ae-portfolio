# 文字动画预设库差异化重构方法论

> 版本: v1.0 | 日期: 2026-07-27 | 状态: 已验证(65/65通过)

## 一、五阶段工作流

### Phase 1: 资产探针先行 (Asset Probing)

**原则**: 在动手设计之前，先用 ExtendScript 探针脚本枚举本地所有可用资产。

| 探针 | 文件 | 产出 |
|------|------|------|
| 字体探针 | `temp/probe30_font_registry.jsx` | 2500个AE注册字体 + 141个验证OK |
| 插件探针 | `temp/probe31_plugin_registry.jsx` | 133个候选测试 → 68个可用 |

**关键方法**:
- 字体验证: 创建临时TextLayer → 设置 `TextDocument.font` → 读回比对 → 确认无静默替换
- 插件验证: `layer.Effects.addProperty(matchName)` → 成功则枚举前25个参数的name/matchName/type
- 结果写入纯文本文件供后续脚本消费

### Phase 2: 多方案设计策略 (Design Strategy)

**核心思想**: 不是"给每个预设换个字体"，而是为每个品类定义完全不同的**设计语言**。

6大设计语言:
1. **插件特效驱动型** - Sapphire/VC插件作为核心视觉引擎
2. **能量光效驱动型** - Saber/Shine/Optical Flares 光束描绘
3. **版式叙事驱动型** - 多层ghost、字距呼吸、基线跳跃
4. **弹性节奏驱动型** - Scale3D弹性级联、卡点冲击
5. **手绘趣味驱动型** - 遮罩笔刷揭示、Turbulent Displace手抖
6. **数据空间驱动型** - RGB分离、扫描线、像素化故障

### Phase 3: 小样本试点验证 (Pilot Validation)

- 从4个品类各选2个 = 8个试点预设
- 每个试点完全重写jsx_template（不是在旧模板上patch）
- 验证管线: `gen_verify.js` → 生成JSX → AE `-r` 执行 → 结果写入txt
- 验收标准: 0 execution error, 字体读回正确, 插件addProperty成功

### Phase 4: 批量推广 (Batch Rollout)

- `gen_batch_v2.js` 一次性更新全部65个预设
- 三维度同步更新: fontFamily + easing + 插件注入代码
- 插件注入采用 `try/catch` 包裹 → graceful降级
- 批量后执行字体去重检查（发现3对重复 → fix_font_dupes.js修复）

### Phase 5: 渲染验收 (Render Verification)

- `gen_showcase.js` 构建65个独立预合成 + 主合成序列
- aerender渲染采样帧 → 人工/自动审查
- 最终指标: 65/65唯一字体、24种插件效果、8种缓动、0执行错误

## 二、缓动DNA体系

| DNA名称 | 特征 | 典型参数 | 适用品类 |
|---------|------|---------|---------|
| snap | 快速到位+微过冲 | easeOut + overshoot 5% | Kinetic/卡点 |
| bounce | 弹性回弹2-3次 | 阻尼弹簧公式 | 抖音/活力 |
| cinematicSlow | 慢入慢出+长尾 | cubic-bezier(0.16,1,0.3,1) | 电影/史诗 |
| mechanical | 匀速+硬切 | linear + step | 赛博/机械 |
| flicker | 随机闪烁 | wiggle(8,0.3) + threshold | 故障/霓虹 |
| wave | 正弦级联 | sin(time*freq + index*offset) | 波浪/流动 |
| elastic | 弹性拉伸 | elasticOut(amplitude, period) | 卡通/趣味 |
| impact | 冲击+震动 | 0→120→95→100 + S_Shake | 打击/爆发 |

## 六、关键设计原则

1. **每个预设必须有独立的"设计故事"** - 不是参数微调，而是架构级差异
2. **字体即设计** - 字体选择本身传达风格（书法→古风、等宽→科技、衬线→电影）
3. **插件是加速器不是拐杖** - try/catch降级确保无插件也能运行
4. **缓动DNA决定"手感"** - 同样的位移，snap和cinematicSlow是完全不同的体验
5. **验证驱动开发** - 每一步都有量化验收标准，不靠"看起来差不多"
