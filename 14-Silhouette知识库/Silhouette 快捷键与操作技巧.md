## 7. 自定义快捷键

### 7.1 自定义方法

```python
class ShortcutManager:
    """快捷键管理器"""
    
    def __init__(self):
        self.shortcuts = {}
        self.load_default()
    
    def load_default(self):
        """加载默认快捷键"""
        self.shortcuts = {
            "new_project": "Ctrl+N",
            "open_project": "Ctrl+O",
            "save_project": "Ctrl+S",
            "undo": "Ctrl+Z",
            "redo": "Ctrl+Shift+Z",
            "play_pause": "Space",
            "next_frame": "Right",
            "prev_frame": "Left",
            "bezier_tool": "B",
            "select_tool": "S",
            "pan_tool": "P",
            "zoom_tool": "Z"
        }
    
    def set_shortcut(self, action, shortcut):
        """设置快捷键"""
        # 检查冲突
        for act, key in self.shortcuts.items():
            if key == shortcut and act != action:
                print(f"警告:快捷键 {shortcut} 已绑定到 {act}")
                return False
        
        self.shortcuts[action] = shortcut
        return True
    
    def get_shortcut(self, action):
        """获取快捷键"""
        return self.shortcuts.get(action)
    
    def save_to_file(self, filepath):
        """保存到文件"""
        import json
        with open(filepath, "w") as f:
            json.dump(self.shortcuts, f, indent=2)
    
    def load_from_file(self, filepath):
        """从文件加载"""
        import json
        with open(filepath, "r") as f:
            self.shortcuts = json.load(f)
```

```python
SHORTCUT_SCHEMES = {
    "default": {
        "bezier_tool": "B",
        "select_tool": "S",
        "pan_tool": "P",
        "zoom_tool": "Z"
    },
    "after_effects": {
        "bezier_tool": "G",  # AE 钢笔工具
        "select_tool": "V",
        "pan_tool": "H",
        "zoom_tool": "Z"
    },
    "nuke": {
        "bezier_tool": "B",
        "select_tool": "S",
        "pan_tool": "Space",
        "zoom_tool": "Ctrl+Space"
    },
    "photoshop": {
        "bezier_tool": "P",
        "select_tool": "V",
        "pan_tool": "H",
        "zoom_tool": "Z"
    }
}

def apply_scheme(manager, scheme_name):
    """应用快捷键方案"""
    scheme = SHORTCUT_SCHEMES.get(scheme_name)
    if scheme:
        for action, shortcut in scheme.items():
            manager.set_shortcut(action, shortcut)
        print(f"已应用快捷键方案: {scheme_name}")
```

## 8. 操作技巧

### 8.1 Roto 效率技巧

```
1. 从大到小:先画大致形状,再细化
2. 使用快捷键切换工具:减少鼠标移动
3. 批量选择:Shift+Click 或框选
4. 复制形状:Ctrl+D 比重新画快
5. 使用对称:镜像功能节省一半工作
6. 关键帧间隔:先画首尾帧,再补中间
7. 形状命名:便于管理和查找
8. 使用图层:将不同对象分到不同图层
```

### 8.2 跟踪效率技巧

```
1. 选择好特征点:高对比度、稳定区域
2. 调整搜索区域:太小会丢失,太大慢
3. 分段跟踪:复杂运动分段处理
4. 正反向结合:正向+反向提高覆盖率
5. 定期检查:跟踪后逐帧检查质量
6. 手动修正:对失败帧手动调整
7. 多点平均:多点跟踪取平均更稳定
```

### 8.3 Paint 效率技巧

```
1. 调整画笔大小:[ ] 快速调整
2. 使用克隆源:Alt+Click 设置
3. 分层绘制:不同修复在不同帧
4. 撤销重做:Ctrl+Z/Y 快速修正
5. 使用遮罩:限制 Paint 范围
6. 保存笔触:便于复用
7. 实时预览:边画边看效果
```

### 8.4 时间轴技巧

```
1. 快速跳转:使用 Home/End
2. 关键帧导航:Ctrl+Left/Right
3. 框选关键帧:拖动选择多个
4. 批量删除:选中后 Delete
5. 复制关键帧:Ctrl+C/V
6. 时间标记:I/O 设置入出点
7. 循环预览:设置入出点后循环播放
```

### 8.5 节点图技巧

```
1. 命名规范:给节点有意义的名字
2. 颜色编码:不同类型用不同颜色
3. 合理布局:节点排列整齐
4. 减少冗余:合并相似节点
5. 使用注释:复杂节点图添加注释
6. 模板复用:保存常用结构为模板
7. 定期清理:删除无用节点
```

### 8.6 性能技巧

```
1. 降低预览质量:工作时用低质量
2. 关闭运动模糊:编辑时关闭
3. 使用代理:高分辨率用代理
4. 分段工作:大项目分段处理
5. 及时保存:避免意外丢失
6. 清理缓存:定期清理内存
7. 关闭其他软件:释放系统资源
```
