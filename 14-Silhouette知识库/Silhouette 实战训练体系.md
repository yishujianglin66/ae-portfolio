## 一、训练体系概览

### 1.1 五级能力模型

```
Level 5: 专家级（Expert）
    │   └─ 复杂项目全流程、团队管理、技术创新
    ▲
Level 4: 高级（Senior）
    │   └─ 复杂 Roto/Paint、脚本自动化、性能优化
    ▲
Level 3: 中级（Mid）
    │   └─ 独立完成中等复杂度镜头、跟踪、基础脚本
    ▲
Level 2: 基础（Junior）
    │   └─ 基础 Roto/Paint、简单跟踪、节点连接
    ▲
Level 1: 入门（Beginner）
    └─ 软件界面、基本操作、简单形状
```

### 1.2 训练周期建议

| 等级 | 周期 | 训练时长 | 项目数 |
|------|------|---------|--------|
| Level 1 | 1-2 周 | 20 小时 | 3 个 |
| Level 2 | 1-2 月 | 60 小时 | 8 个 |
| Level 3 | 3-6 月 | 200 小时 | 20 个 |
| Level 4 | 6-12 月 | 500 小时 | 50 个 |
| Level 5 | 2+ 年 | 1000+ 小时 | 100+ 个 |

### 1.3 训练原则

1. **循序渐进**：每级掌握后再进入下一级
2. **实战为主**：80% 时间动手实践
3. **反馈闭环**：定期评估与调整
4. **项目驱动**：以真实项目为训练目标
5. **持续学习**：跟随版本更新学习新功能

## 二、Level 1 - 入门级

**模块 2：项目管理（2 小时）**
- 创建新项目

**模块 3：基本形状（4 小时）**
- X-Spline 基础

**模块 4：输出（2 小时）**
- Output 节点设置

**项目 2：简单运动物体**

- 评估：帧间一致性

**项目 3：多形状管理**
- 任务：为画面中多个物体创建遮罩
- 时长：5 秒视频

- 评估：形状组织清晰度

| 项目 | 标准 | 通过 |

## 七、技能评估体系

### 7.1 评估维度

| 维度 | 权重 | 评估方式 |
|------|------|---------|
| 技术能力 | 40% | 实操测试 |
| 项目经验 | 30% | 项目案例 |
| 问题解决 | 20% | 情景测试 |
| 沟通协作 | 10% | 360 度评估 |

### 7.2 评估流程

```python
class SkillAssessment:
    """技能评估系统"""

    def __init__(self, artist_name):
        self.artist = artist_name
        self.scores = {
            "technical": 0,
            "project": 0,
            "problem_solving": 0,
            "communication": 0
        }
        self.projects = []

    def add_project(self, project_name, complexity, quality_score, time_score):
        """添加项目记录"""
        self.projects.append({
            "name": project_name,
            "complexity": complexity,
            "quality": quality_score,
            "time": time_score,
            "date": "2026-07-11"
        })

    def calculate_level(self):
        """计算能力等级"""
        total_score = (
            self.scores["technical"] * 0.4 +
            self.scores["project"] * 0.3 +
            self.scores["problem_solving"] * 0.2 +
            self.scores["communication"] * 0.1
        )

        if total_score >= 90:
            return "Level 5 (Expert)"
        elif total_score >= 75:
            return "Level 4 (Senior)"
        elif total_score >= 60:
            return "Level 3 (Mid)"
        elif total_score >= 40:
            return "Level 2 (Junior)"
        else:
            return "Level 1 (Beginner)"

    def generate_report(self):
        """生成评估报告"""
        level = self.calculate_level()
        report = f"""
=== 技能评估报告 ===
艺术家: {self.artist}
等级: {level}

详细得分:
  技术能力: {self.scores['technical']}/100
  项目经验: {self.scores['project']}/100
  问题解决: {self.scores['problem_solving']}/100
  沟通协作: {self.scores['communication']}/100

项目记录: {len(self.projects)} 个
"""
        return report

# 使用
assessment = SkillAssessment("张三")
assessment.scores = {
    "technical": 85,
    "project": 80,
    "problem_solving": 75,
    "communication": 70
}
print(assessment.generate_report())
```

## 九、总结

### 9.1 训练成功要素

1. **持续实践**：每天至少 2 小时
2. **项目驱动**：以真实项目为目标
3. **反馈循环**：定期评估与调整
4. **社区参与**：加入社区学习交流
5. **版本跟进**：跟随软件更新学习

### 9.2 常见误区

1. **跳级学习**：基础不牢就学高级
2. **只看不做**：只看教程不实践
3. **追求完美**：过度纠结细节
4. **闭门造车**：不与他人交流
5. **忽视理论**：只学操作不懂原理

```

    ↓
Level 3 (2-4年): Roto Artist
    ↓
```
