## 二、本轮现场实验记录（可复现）

### 实验 E-A：环境重建能力（灾备韧性实测）

- **背景**：.venv 于 8/29 事故丢失。requirements.txt 头部注明需 3.11/3.12（系统默认 3.13 超出 requires-python）。
- **操作**：`uv venv --python <系统3.11.9> .venv` + `uv pip install -r requirements.txt`。
- **结果**：6 分 10 秒完成 49 项核心依赖安装，一次成功。
- **结论**：核心依赖灾备韧性达标（重建 <10 分钟）；但 requirements-ml.txt（重型 ML）未在本轮安装，VLM 专家 4bit 推理等依赖其完整环境的路径未验证。

### 实验 E-B：测试收集健康

- **命令**：`.venv/Scripts/python.exe -m pytest --collect-only -q`
- **结果**：**5,384 tests collected / 0 errors**（15.65s）。
- **对照**：9/6 交接文档记录 5,354 → 本轮 5,384（+30），与 9/7 新增测试（run53v43 特效系列）吻合。
- **结论**：收集健康声明属实且有增长。

### 实验 E-C：核心契约单测

- **命令**：`pytest tests/test_rule_registry.py tests/test_cache_manager.py tests/test_effect_registry.py -q`

### 实验 E-D：ruff 质量闸门

## 三、行业顶尖水平对标

> 对标基准选取三层：① 人类顶尖（参照集 = B 站头部 AMV，13 部）；② 工业开源标杆（OpenMontage，44.8k★ agentic 视频生产系统；HyperFrames；ComfyUI 生态）；③ 学术前沿（AutoMV、MV-Crafter、MVAA、audeosynth）。

### 3.1 对人类顶尖（参照集量化对比，reports/reference_gap_run61.json）

| 指标 | MasterCut run61 | 参照集均值 | 参照前三分位线 | 判定 |
|------|----------------|-----------|---------------|------|
| beat_hit_rate（踩拍率） | **0.8455** | 0.7559 | 0.8193 | **反超 +2.6pp** ✅ |
| cut_visibility（切点可见性） | 0.8698 | 0.9549 | — | **落后 8.5pp** ❌（已实验证明非闪白频率问题，属结构性） |
| score_dynamism | 8.02 | 7.84 | — | 领先 |
| score_pacing | 7.76 | 7.54 | — | 领先 |
| score_text_read | 8.32 | 8.32 | — | 持平 |
| score_composition | 7.22 | 7.27 | — | 持平（-0.05） |
| score_color_harmony | 6.72 | 6.71 | — | 持平 |
| score_texture | 5.32 | 5.35 | — | 持平（-0.03） |
| score_overall | 7.28 | 7.24 | — | 持平偏正 |
| peak（削波） | 1.0 | 0.914 | — | ❌ 削波（修复点已定位：upstream limiter 0.95→0.88） |

**解读**：在"燃向 30s AMV"这个细分任务上，MasterCut 的节奏维度已**超过参照集前三分位**，语义综合分与人类顶尖均值持平。这是量化意义上的"接近顶尖"。剩余硬差距集中在：① 切点可见性（视觉冲击结构）8.5pp；② 削波（音频工程）；③ composition/texture 的最后一档质感。

**必须诚实的三条边界**：
1. 参照集仅 13 部、单风格域（燃向踩点混剪），统计功效有限；
2. 语义分来自 CNN 评分器而非人类盲评（评分器与管线同源，存在自证风险）；
3. 成功母版集中在 1 个场景（洛天依燃向）——**泛化性未经第二母版验证**。

### 3.2 对工业开源标杆（OpenMontage，当前 GitHub 增速第一的视频生产系统）

| 维度 | OpenMontage | MasterCut | 判定 |
|------|-------------|-----------|------|
| 定位 | 通用 agentic 视频工厂：12 条管线、100+ 工具、700+ skills，覆盖解说/纪录片/播客切片等 | 单点纵深：AMV 燃向母版精修 + 规则蒸馏闭环 | 路线不同：广度 vs 纵深 |
| 质量机制 | YAML 管线 + 渲染前质量门（防"PPT 式视频"） | **量化评分参照集 + A/B 证伪 + 规则生-死-退场生命周期** | **MasterCut 独有优势**——OpenMontage 无规则证伪与自动回退机制 |
| 音乐理解 | 节拍驱动剪辑 | stem 级鼓型分型 + 16 分音符网格量化锚 + 旋律锚 | **MasterCut 领先**（切点精度有 0.8455 量化背书，OpenMontage 无公开同类指标） |
| 素材来源 | 15 家视频/11 家图像/5 家配音供应商选型 | 自有素材库 + BGE-M3 检索（recall 0.400） | OpenMontage 领先 |
| 生态/社区 | 44.8k★、多 agent 客户端接入 | 单人单机 | OpenMountage 数量级领先 |
| 工程卫生 | 开源社区标准 | 5,384 测试 + CI 三闸门 + DVC + ruff + SHA 登记 | 单机项目罕见水平，但无覆盖率采集 |

**判定**：MasterCut 不应与 OpenMontage 拼广度（资源差数量级），应把"规则蒸馏 + 量化验收"做成 OpenMontage 没有的纵深壁垒——事实上这是本项目当前最接近实验室水准的资产。

### 3.3 对学术前沿（beat-sync 视频编辑，2025-2026）

- **MV-Crafter / MVAA**：用扩散模型做 beat-aligned 生成/补帧——MasterCut 的 E2 波（生成）尚为空白，此为与学术前沿的最大能力缺口。
- **AutoMV**：提出 12 维评估基准（Music Content / Technical / Post-production / Art 四大类）+ 人类专家盲评——MasterCut 当前评估仅 2 类（信号层 9 指标 + 语义层 7 维），**评估体系广度落后学术前沿一档**。
- **audeosynth（SIGGRAPH 2015）**：MCMC 优化做音画对齐——MasterCut 的网格量化锚 + 评分反馈迭代在工程上已超越其方法，但缺少其严谨的用户实验设计。

## 四、差距总评（实验室评级）

> 评级口径：S = 行业顶尖/反超；A = 接近顶尖；B = 可用但明显落后；C = 短板/空白。

| 能力域 | 评级 | 量化依据 |
|--------|------|---------|
| 音乐节拍理解与切点精度 | **S** | beat_hit_rate 0.8455 > 前三分位 0.8193；stem 分型 + 网格量化为开源界稀缺能力 |
| 规则蒸馏与自进化 | **S-**（机制 S，数据量待积累） | 规则生命周期完整跑通（证伪→退场→自动回退）；但规则库仅 2 条、验收日志刚起步 |
| 工程卫生与灾备 | **A** | 5,384 测试 0 错误、CI 三闸门、DVC 验证过端到端、6 分钟环境重建；缺覆盖率采集与 output/ 治理 |
| 视觉冲击与镜头质感 | **B+** | cut_visibility 落后 8.5pp（结构性）；composition/texture 与顶尖持平但未超越 |
| 端到端自动化 | **B+** | 一条命令出片（unified_edit 527 行入口），但 aerender 步骤仍需手动/分离启动，全链无人值守未达成 |
| 素材检索 | **C+** | recall 0.400 / 目标 0.800（完成度 50%） |
| 泛化能力 | **C** | 1 个验收场景；规则 applicability 域设计正确但未经跨片验证 |
| 生成能力（文生视频/补帧） | **C（空白）** | E2 未启动；8GB 显存约束是真实物理边界，非执行不力 |
| 评估体系 | **B** | 量化 16 指标 + 参照集对比超过多数开源项目；但无人类盲评、参照集小、评分器同源自证风险 |

**一句话总判**：在"燃向踩点 AMV"细分赛道，MasterCut 的节奏引擎已达人类顶尖前三分位之上、规则蒸馏机制为开源界独有；整体距离"行业顶尖综合系统"还差四块硬骨头——视觉冲击结构性差距、素材检索、泛化验证、生成能力。

## 五、后续开发路线（实验室级方案，沿用四条铁律：先评测后接入 / 8GB 硬约束 / 许可证一票否决 / 接入即蒸馏）

### R1 · 主攻 cut_visibility 结构性差距（第一优先，2 周）

- **假设**：8.5pp 差距源于切点帧内容（参照集为硬内容跳变，本项目为效果叠加）。
- **实验设计**：AEKV_IMPACT_SHIFT=1 重评（定格内容移至动作顶点帧，曾因"变糊"禁用——需先修 tmp/post_freeze.py 滤镜图拼接 bug）；A/B 双臂各 3 次渲染，切点可见性以参照集同口径评分器盲测。
- **验收线**：cut_visibility 0.870 → ≥0.92（每提升 1pp 需留 evidence 目录）。
- **回滚**：配置开关化（沿用 MASTER_* 环境变量惯例）。

### R2 · 评估体系升级到学术基准（与 R1 并行，2 周）

- 参照集扩容 13 → 50+（分层抽样：燃向/叙事向/MAD 三层，B 站 + YouTube 各半）；
- 引入人类盲评协议（验收 UI 已具备 A/B 并排能力，补随机化与评分者间一致性 Kappa 统计）；
- 语义评分器交叉验证：抽 20 个样本请 VLM 异源评分（非管线同源模型），量化自证风险。
- **验收线**：发布《评估基准 v2》文档 + 50 部参照集分布落盘。

### R3 · 素材检索补课（3 周）

- BGE-M3 召回 0.400 的根因排查（分块策略/负采样/索引构建），加 bge-reranker 二阶段重排；
- **验收线**：gold set recall@10 ≥0.70（阶段一）→ 0.80（阶段二）；每次改进留检索评测 evidence。

### R4 · 第二母版泛化验证（3-4 周，与 R3 并行）

- 选异风格 BGM（叙事向/慢节奏）跑全链，验证 R-2026-0002 的 applicability 域是否成立；
- **预期结果二选一**：规则跨片有效（→ 规则库扩容路径打开）；或触发适用域收窄（→ 这本身就是规则库机制的正常运作，记录 standby 理由）。
- **验收线**：第二母版 beat_hit_rate ≥ 该曲风参照分布中位数。

### R5 · 生成能力最小闭环（R1-R4 之后，4 周）

- 8GB 约束下唯一现实路线：LTX-2 / Wan2.2-1.3B 级小模型 + ComfyUI Block Sparse Attention（09-06 已合入 core，正好适配）生成 2-4s 空镜/转场素材；
- 接入即蒸馏：生成素材的使用率、被评分器惩罚率当轮沉淀为规则。
- **验收线**：生成镜头混入母版后整体语义分不低于纯素材版（非劣检验）。

## 六、结论

1. **磁盘与文档零漂移**：本轮 5 项现场实验（环境重建 / 收集 / 单测 / ruff / 资产核验）与交接文档全量一致，仅工作区存在 1 处未提交回归（F821）。
2. **细分赛道已达顶尖水平线之上**：踩拍率 0.8455 超参照前三分位（+2.6pp），节奏引擎具备开源界稀缺的 stem 级分型 + 网格量化能力。
3. **独有壁垒在规则蒸馏**：A/B 证伪 → 投票退场 → 自动回退的规则生命周期，OpenMontage 等工业标杆均无此机制——这是本项目最应加注的资产。
4. **距离"行业顶尖综合系统"的四块硬骨头**：视觉冲击结构性差距（8.5pp）、素材检索（50% 完成度）、泛化验证（0/1 场景）、生成能力（空白）。
5. **实验室纪律已内化**：先评测后接入、无证据即 PLAN、SHA 登记、证伪文化——四条铁律与 R1-R6 路线构成下一阶段的完整实验计划。
