## 二、产物价值判定

### 2.1 有作用——且是木偶动画线的关键配套（核心结论）

**`finetuned_anime_mixed.pth`（动漫域 IoU 0.9756，base 0.9544；COCO person +1.12%，双向最优）**：

1. **v17 生产链路角色不可替代**：MatAnyone 分段视频抠像 + BiRefNet 补缺失帧（v14/v17 FATE 验收定案，MOV 已交付 AE 真机验证）。`birefnet_fill.py` 权重优先级链第一指向它。
2. **WA2 木偶线的标准出口**（新增用途）：P1 实测已坐实 WA2 在 8G 卡可行（480p/48帧/1221s）。WA2 输出是含驱动视频背景的完整视频——要作为"角色动画素材"叠进 MasterCut 合成层，必须抠像。BiRefNet 动漫混合微调版正好是这一步的最优模型：**WA2 输出 → BiRefNet(mixed) 逐帧/分段抠像 → alpha 序列 → master_polish 合成层**。没有抠像模块，木偶线产物无法进入剪辑主链。
3. **素材池前处理**（可选）：角色 alpha 预生成，服务 IP 检索增强与素材复用。

### 2.2 保险资产——保留不动

- `matting_dataset.tar`：CelebA 伪 mask 3973 张由 BiRefNet base 自标注，**不可再生**；后续任何再微调（如针对 WA2 输出域的适配训练）都依赖它。
- DVC 三件套（`dvc-cache` 3.97G / `dvc-remote` 3.66G）：8-29 事故后唯一资产保险，绝对不动。

### 2.3 可精简——非紧急

- 15 ckpt 中的 `ep0-7`/`cont_ep0-3`/`v2`（约 10G）：训练中间快照，best/mixed/fp16 已覆盖生产与评估需求。已入 DVC、D 盘余量 95G，**不急着清**；若执行 AE-Data 精简（B2/B5 同批），可一并清。
- `AE-Work/models/matting/`（rmbg14/modnet ONNX 193M）：零引用、已被微调版全面替代，归入 AE-Work 209G 清理批次处理。
- `_Trash_2026-09-08` 两个 alpha 调试目录：随回收站清空即可。

## 三、系统管线中该模块的走向

**定位：素材前处理/生成后处理服务，与主链零耦合。**

```
MasterCut 主链（unified_edit：素材检索 → 切割 → 节奏合成 → EDL）
    ↑ alpha 素材注入（仅消费产物，不依赖抠像代码运行）
    
抠像模块（服务化，按需调用）
    ├─ 入口A（素材侧，可选）: 素材池角色提纯 → alpha 预生成 → IP检索/复用增强
    ├─ 入口B（木偶线，关键）: WA2 输出 → BiRefNet(mixed) 抠像 → alpha 序列
    │                        → master_polish/EDL 合成层叠加  ← 木偶线并入主链的标准出口
    └─ 入口C（独立交付）: v17 链路 alpha MOV → AE/Silhouette 人工精修
```

**决策与理由**：

1. **不进主链**：unified_edit 全代码 grep 零抠像引用——现状正确。主链是确定性 FFmpeg 合成，抠像是重 GPU 推理任务，耦合只会拖垮主链稳定性（今天 P1 的事故再次证明本机 GPU 任务必须互斥）。EDL/production_report 已具备记录 alpha 轨道的能力（inputs 数组天然支持）。
2. **木偶线出口用 BiRefNet(mixed) 单帧链**，不上 MatAnyone：WA2 输出无时域跟丢问题（生成视频主体稳定），单帧 BiRefNet 足够且免去 external/matanyone 依赖；v17 的 MatAnyone+锚定链保留给实拍素材抠像场景。
3. **`external/matanyone/` 恢复降级为"按需"**：v17 独立交付线已收官，仅当重新接到实拍抠像需求时再重下权重。
4. **训练线挂起但保留再启动能力**：数据集 tar + 训练脚本（finetune/train_v3）+ 云端流程（AutoDL 实例已关）俱全。再训练的触发条件：WA2 输出域与现有微调分布差异实测超标（IoU 掉档）时，做 WA2-domain 增量微调。
5. ~~**遗留修复项**（来自交接文档 P2-9）：`build_matting_dataset.py` 的 VOC 调色板 PIL 读法 bug 未修~~ **已修（2026-09-10）**：PIL 分支仅在 `im.mode == "P"` 时取索引，非调色板（RGB 衍生）PNG 走 cv2 兜底/自然过滤，另加 `mask.ndim != 2 → continue` 双保险与 `save_pair` 2D 断言（旧路径会写出三通道 mask 污染训练集）。合成测试验证：P 模式正确提取（2D {0,255}），RGB 衍生安全跳过。

## 四、一句话结论

D 盘抠像产物**有作用且不可裁撤核心**：混合微调权重（0.9756）是 WA2 木偶线并入 MasterCut 主链的标准出口配套，数据集 tar 是不可再生的再训练保险；可精简的只有训练中间快照（~10G，不急）与 AE-Work 孤儿 ONNX（193M）。模块走向 = **服务化定位、三个入口、与主链零耦合**，木偶线 alpha 出口优先级最高（等 P1 边界测试收官后可直接验证 WA2→BiRefNet→合成 这条链）。72.92G 的 batch_auto_frame 见第五节，建议清。
