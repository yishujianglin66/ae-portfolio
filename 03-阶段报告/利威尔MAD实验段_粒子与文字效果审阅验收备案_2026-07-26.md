## 二、已确认的问题清单（含根因定位）

| # | 问题 | 根因 | 严重度 |
|---|------|------|--------|
| P1 | 字体单调 | 7 句歌词共用单一回退链，未按风格分发字体 | 中 |
| P2 | 粒子单一 | 仅 1 个橙色 Particular 爆发实例，无颜色/类型/运动差异 | 高 |
| P3 | neon 歌词缺失 | 原 path text arc（路径文字弧形）实现脆弱，路径未正确生成导致文字不可见 | 高 |
| P4 | 自动化能力闲置 | 手写 JSX 未复用 TextEffectService 的 GLOW/RGB 层架构与预设动画 | 中 |

**衍生技术约束（执行中确认）**：
- AE2025 属性内省失效：`numProperties`/`value` 对 Trapcode/Font 对象返回 undefined，无法靠枚举 dump 属性树，必须用「设置-读回」法验证 matchName。
- Particular 改粒子类型/发射器类型会**重构属性树**，导致后续颜色（0070）设置失败 → 颜色必须最后设置或用独立 try/catch 包裹。
- 文本 Position 动画器必须用 `"ADBE Text Position 3D"`（不存在 `"ADBE Text Position"`），表达式需 3 元素 `[x,y,z]`。
- Wiggly 选择器 matchName 为 `"ADBE Text Wiggly Selector"`，频率属性 `"ADBE Text Temporal Freq"`。
- CC Light Sweep 属性顺序：1=Center / 2=Direction / 3=Shape(下拉1-3) / 4=Width / 5=Sweep Intensity。
- GLOW 层 duplicate 会继承原文字层 opacity 关键帧，直接 setValue 报错 → 用表达式 `value*(opac/100)` 缩放。

## 六、当前仍然不足的视觉效果（重点·未达理想水平）

> ⚠️ **明确记录：当前粒子效果与文字动画效果虽已通过本轮基础验收，但仍未达到理想水平。** 二者是接下来需要重点持续开发与深化的两个方向。

### 6.1 粒子效果不足

1. **节拍同步是近似而非帧锁定**：5 个爆发挂在固定关键帧时间点，未做音频瞬态（transient）检测驱动的真正 beat-reactive 发射。
2. **缺乏 3D 纵深**：粒子全部在 2D comp 平面，无前景/中景/背景三层粒子视差，无摄像机 parallax。
3. **物理维度单薄**：仅用了速度/散布/重力/空气阻力；未用 Trapcode Particular 的 turbulence 场、wind、vortex/swirl、Aux 辅助粒子系统。
4. **粒子密度偏低**：12s 内仅 5 爆发 + 3 氛围，高潮段（5–6s）之外的能量分布稀疏。
5. **无速度关联拖尾**：粒子无 motion-blur 速度拖尾/光轨（streak trail）。
6. **调色未体系化**：粒子颜色各自为政，未统一进一个连贯的调色板/LUT 系统。
7. **自定义 Sprite 未用**：Particular 粒子类型 5=Text / 6=Sprite 需外部图层，尚未利用利威尔关键帧做自定义粒子贴图。

### 6.2 文字动画效果不足

1. **动画行为复用率高**：7 句歌词仅约 6 种独立动画行为，部分风格共用底层逻辑，签名感不足。
2. **缺逐字 3D 深度级联**：无 z-space 逐字纵深 cascading（仅 Rotation Y 翻转，无真正的 3D 空间位移）。
3. **二级特效覆盖不全**：Light Sweep 仅用于 epic；cyber/cine/neon 缺少各自的签名二级特效。
4. **渐变蒙版未充分调用**：TextEffectService 的 GRAD_ 渐变蒙版架构已定义但未充分用于文字 reveal/wipe。
5. **霓虹真实感不足**：neon 闪烁是简单 opacity 抖动，无真实霓虹管点燃的色温渐变（冷→暖）与电压不稳抖动。
6. **打字机过于基础**：cine 打字机无光标/caret、无变速、无逐字模糊渐显。
7. **RGB 分离是静态偏移**：无动画化 glitch（抖动偏移、切片位移、scanline 撕裂）。
8. **中文歌词缺书法/笔刷 reveal**：中文衬线歌词无毛笔书写式逐笔揭示。
9. **字体可用性风险**：FZYaoTi / NotoSerifSC-Bold 在非本机环境可能缺失，回退链需进一步加固。

## 七、后续开发与深化计划（路线图）

> 总方针：以**粒子效果**与**文字动画效果**为两条主线持续深化，优先复用项目已有自动化能力（TextEffectService / 预设库 / 知识库），减少手写 JSX。

### 阶段 A · 节拍驱动粒子系统（粒子主线）
- 音频瞬态检测（已有 `analyze_bgm.json` / `audio/` 资源）→ 生成 beat 时间戳 → 驱动 Particular 发射关键帧
- 目标：粒子爆发与鼓点/重音帧锁定

### 阶段 B · 3D 粒子纵深与摄像机视差（粒子主线）
- 前景/中景/背景三层粒子 + comp 摄像机 parallax
- 目标：空间纵深感

### 阶段 C · 高级 Particular（粒子主线）
- Aux 辅助粒子、turbulence/wind/vortex 物理场、自定义 Sprite（利威尔关键帧贴图）、速度拖尾
- 目标：物理丰富度与电影级粒子质感

### 阶段 D · 动态字体排印引擎（文字主线）
- 音节级 choreography（scale/rotation/position 逐字编排）、逐字 3D z-space 级联
- 目标：kinetic typography

### 阶段 E · TextEffectService 全集成（文字主线）
- 由 Python 服务（`puppet-automation/src/services/text_effect_service.py`）直接生成 JSX，而非手写
- 补全 GRAD_ 渐变蒙版 reveal、真实霓虹点燃、动画化 RGB glitch、书法笔刷 reveal、打字机光标
- 目标：文字特效工业化、可配置化

### 阶段 F · 统一调色板 + LUT 体系（共性）
- 粒子与文字颜色纳入统一 palette，叠加 LUT
- 目标：视觉连贯性

### 阶段 G · 参考驱动风格匹配（共性）
- 调用 `10-风格化剪辑知识库`（256 文件）、`12-漫剪拉镜大师`、`11-大师知识库` 的参考分析方案
- 目标：向成熟风格对标
