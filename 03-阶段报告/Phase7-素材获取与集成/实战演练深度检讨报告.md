## 三、新功能详细设计

### 3.1 Phase7.1 - 新增 FFmpeg 工具集

| 工具 | 用途 | 技术 |
|------|------|------|
| `clip-media` | 按时间/帧裁剪视频 | FFmpeg |
| `extract-audio` | 从视频提取音频 | FFmpeg / yt-dlp |
| `get-media-info` | 获取媒体信息 | FFprobe |
| `search-media` | 搜索素材（本地/网络） | yt-dlp + API |

### 3.2 详细工具设计

#### `clip-media`
```typescript
server.tool("clip-media", "裁剪视频/音频", {
  filePath: z.string().describe("源文件路径"),
  startTime: z.string().describe("起始时间 (00:00:00)"),
  duration: z.string().describe("时长"),
  outputPath: z.string().optional()
})
```

#### `extract-audio`
```typescript
server.tool("extract-audio", "从视频提取音频", {
  filePath: z.string().describe("视频文件路径"),
  format: z.enum(["mp3", "wav", "m4a", "aac"]).optional().default("mp3"),
  outputPath: z.string().optional()
})
```

## 四、完整工作流示例

### 工作流 1: 从抖音下载视频 → 剪辑 → 导入AE
```
1. 抖音URL → download-media
2. clip-media (裁剪需要的片段
3. import-media-to-ae (导入)
```

### 工作流 2: 从视频提取BGM
```
1. 视频 → extract-audio
2. import-media-to-ae (导入为音频)
```
