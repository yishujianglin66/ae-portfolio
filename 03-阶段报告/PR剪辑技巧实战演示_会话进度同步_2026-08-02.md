## 三、失败分析与经验

### 3.1 PR 2025 ExtendScript API 关键踩点

#### 踩点 1：QE DOM API 名称错误
- **错误**：`qvt.numClips`
- **正确**：`qvt.numItems`
- **教训**：QE DOM（QE DOM API）和标准 DOM API 的属性名不同，需查阅 PR SDK 文档

#### 踩点 2：Lumetri Color 组件访问
- **错误**：`clip.addComponent("Lumetri Color")` 不存在
- **正确**：每个视频 clip 默认带 Lumetri Color 组件，通过 `clip.components` 遍历查找
- **正确代码**：
  ```javascript
  function findComponent(clip, namePattern) {
      var comps = clip.components;
      for (var i = 0; i < comps.length; i++) {
          var c = comps[i];
          if ((c.displayName.indexOf(namePattern) >= 0) ||
              (c.matchName.indexOf(namePattern) >= 0)) {
              return c;
          }
      }
      return null;
  }
  // 查找 Lumetri
  var lumetri = findComponent(clip, "Lumetri");
  // 中文 fallback
  if (!lumetri) lumetri = findComponent(clip, "颜色");
  ```

#### 踩点 3：关键帧 API
- **错误**：直接调用 `property.addKeyframe()` 不存在
- **正确**：`property.addKey(ticks)` + `property.setKeyValueAtKey(ticks, value)`
- **启用关键帧**：`property.setValue(value, true)` 第二参数 true 启用关键帧

#### 踩点 4：调整图层创建
- **问题**：PR 2025 DOM API 无 `createColorMatte`、`createAdjustmentLayer`
- **可行方案**：
  - QE DOM `qe.project.createColorMatte(r, g, b, name)` 可能可用（待验证）
  - 或导入 .prfpset 调整图层预设文件
  - 或标记为"需手动添加"

#### 踩点 5：嵌套序列
- **错误**：`qe.project.nestItems` 不存在
- **待验证**：
  - `qe.project.nestProjectItems(name)` 可能可用
  - `sequence.nest(name)` 可能可用
  - 实在不行用 `app.project.createNestedSequence()`

#### 踩点 6：文字标题
- **错误**：`qseq.addText`、`createTitleText` 均不存在
- **待验证方案**：
  - 导入 .mogrt（Motion Graphics Template）文件
  - 或用 QE DOM `qe.project.getActiveSequence().addText()` （需确认 API 存在）
  - PR 2025 可能需要通过 Essential Graphics 面板操作

#### 踩点 7：转场 API
- **错误**：`track.addTransition(name, time, duration)` 标准不存在
- **正确（QE DOM）**：`qvt.addVideoTransition(name, clip, side, alignment, duration, reverse)`
  - side: 0=whole, 1=start, 2=end
  - alignment: 0=center, 1=start, 2=end
- **教训**：必须使用 QE DOM API 添加转场，标准 DOM 无此能力

#### 踩点 8：音频淡入淡出
- **错误**：`qat.addTransition` 失败
- **正确**：通过 Channel Volume 组件的 Level 属性添加关键帧
- **正确代码**：
  ```javascript
  var levelComp = findComponent(audioClip, "Channel Volume");
  var levelProp = findProperty(levelComp, "Level");
  levelProp.setValue(-60, true); // 启用关键帧
  levelProp.addKey(start.ticks);
  levelProp.setKeyValueAtKey(start.ticks, -60);
  levelProp.addKey(start.ticks + 1*TICKS_PER_SEC);
  levelProp.setKeyValueAtKey(start.ticks + 1*TICKS_PER_SEC, 0);
  ```

## 六、PR 2025 ExtendScript API 速查表

### 6.1 项目与序列
```javascript
// 项目
app.project.rootItem              // 项目根 bin
app.project.sequences             // 所有序列
app.project.sequences.length      // 序列数量
app.project.activeSequence        // 当前活动序列
app.project.newSequence(name, presetPath)  // 创建序列（标准 DOM）
app.project.importFiles([paths])  // 导入素材
app.project.rootItem.createBin(name)       // 创建 bin

// QE DOM
app.enableQE()
qe.project.newSequence(name, presetPath)   // QE 创建序列
qe.project.getActiveSequence()
```

### 6.2 序列与轨道
```javascript
var seq = app.project.activeSequence;
seq.videoTracks                    // 视频轨道数组
seq.audioTracks                    // 音频轨道数组
seq.videoTracks[0].clips           // 第一视频轨的 clips
seq.videoTracks[0].insertClip(clipItem, ticks)  // 插入 clip
seq.videoTracks[0].addVideoTrack() // 添加视频轨
```

### 6.3 Clip 与组件
```javascript
var clip = seq.videoTracks[0].clips[0];
clip.start.ticks                   // 起始时间（ticks）
clip.end.ticks                     // 结束时间
clip.duration                      // 时长
clip.inPoint                        // 入点
clip.outPoint                       // 出点
clip.components                     // 组件数组
clip.components[i].displayName      // 组件显示名
clip.components[i].matchName        // 组件匹配名
clip.components[i].properties       // 组件属性数组
```

### 6.4 属性与关键帧
```javascript
var prop = component.properties[i];
prop.displayName                   // 属性名
prop.getValue()                    // 获取值
prop.setValue(value, keyframeEnabled)  // 设置值（true=启用关键帧）

prop.setKeyValueAtKey(ticks, value) // 设置关键帧值
prop.isKeyframable()               // 是否可关键帧
```
