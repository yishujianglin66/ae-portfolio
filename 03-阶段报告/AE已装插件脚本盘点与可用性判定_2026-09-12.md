# AE 已装脚本/插件盘点与可用性判定（2026-09-12 实机探针）

> 目的：回答"描点判断能否借助已装脚本/插件、能否被本管线调用"。
> 方法：文件系统盘点 + AE 内 `addProperty` 探针 + 授权文件/注册表排查 + 单帧渲染水印测试。
> 铁律沿用：**先探针后结论**；不确定的一律标"待验证"，不把"能加载"当成"能用"。

## 二、可用性判定（探针实测）

### 2.1 可脚本加载且可渲染（`已实证`）

| 插件/效果 | 探针结果 | 对本管线价值 |
|---|---|---|
| **Sapphire**：S_Glow(53 参数)、S_BlurMotion(52)、S_BlurDirectional(46)、**S_WarpChroma(55)**、S_FilmEffect(73)、**S_Grain(36)**、S_LensFlare(130)、S_Rays(68)、**S_Shake(83)**、S_LightLeak(104)、S_Feedback(50)、S_EdgeRays(67)、S_Kaleido(43)、S_Distort(41)、S_DissolveLuma(13)、S_WipeClock(34) | 全部 `addProperty` 成功、无弹窗；机器级授权记录存在（HKLM\SOFTWARE\GenArts + ProgramData\GenArts） | 补上调研报告的**后处理族缺口**：颗粒/胶片/漏光/色散/抖动/射线；S_Shake 可做**节拍驱动抖动** |
| Sapphire 不可用项 | S_GlowDistort / S_Chroma / S_TextFadeOn / S_TextScramble = 不存在于本机安装 | — |
| **Aescripts DeepGlow** | `addProperty` 成功（90 参数），单帧渲染出正常强光晕、**无水印**；ProgramData\aescripts 有 DeepGlow 授权目录 | 可作主发光替代（比 AE Glo2 控制更细） |

### 2.2 存在但**当前不可被脚本驱动**（`已实证` 负结果）

| 插件 | 实测现象 | 判定 |
|---|---|---|
| **Boris FX Continuum**（含 BCCExtrudedText / BCCBeatReactor） | `addProperty("BCC Extruded Text")` → 弹出 **"Boris FX - Continuum Error"** 模态框，阻塞 AE 脚本引擎（本次导致 2 次卡死、需重启 AE） | **不可用**；HKCU\SOFTWARE\Boris FX 有记录但 Continuum 本身报错（可能需重新激活/修复安装） |
| **Red Giant**（Cool Text / Text Anarchy / Trapcode） | 添加 Red Giant 效果 → 弹出 **"Red Giant" 授权对话框**并阻塞（窗口枚举实证） | **未激活**（注册表无 Red Giant 授权键）；需在 AE 界面登录/激活 |

### 2.3 对"描点判断"的具体结论

- 已装的**节拍/音频类第三方工具**（BCC Beat Reactor 等）**当前都不可脚本调用**（见 2.2）；而本项目自有的 Python 侧节拍链（`true_onsets` + `music_envelope` + `shot_scenes`）**已实证可用**
  （onset 对齐 ≤2 帧、节拍脉冲、发光随包络呼吸），且**确定性可复现**——这是第三方插件给不了的。
- 因此**描点判断不建议改依赖第三方**：收益边际（我们已在 AE 内做音频反应），成本高（授权 + 模态框会打断自动化）。
- 第三方真正能补的两个**独有能力**：
  1. **真 3D 挤压文字** = BCC Extruded Text（AE 原生该 API 被脚本锁死，见 2026-09-11 探针）→ 但 Continuum 当前报错，需先修好
  2. **逐字文字引擎**（Red Giant Cool Text / TypeMonkey）→ 可绕开"AE 范围选择器 × 脚本字体静默替换"的限制；需先激活 Red Giant

## 三、可落地建议（按性价比）

1. **立即可做（零授权风险）**：把 **Sapphire S_Shake / S_Grain / S_WarpChroma / S_FilmEffect** 与
   **Aescripts AEPixelSorter2（故障风）/ LongShadow（文字长阴影）/ RealGlow** 接入文字线，
   补上"后处理族"缺口（调研报告 W5 的试点项）。每项先探针参数名，再单效果 A/B 帧验证。
2. **需您一次性操作**：
   - 在 AE 界面**激活 Red Giant**（登录/输入序列号）→ 之后我探针并接入 Cool Text（逐字动画）
   - **修复/激活 Boris FX Continuum**（当前直接报错）→ 之后接入 BCC Extruded Text（真 3D 挤压）
3. **不建议**：为描点判断引入第三方节拍插件（自有链路已足够且更可控）。

## 附录 A：插件渲染阻塞（2026-09-12 追加，负结果）

**背景**：按 §三-1 建议接入 `S_Shake`（节拍抖动）+ `LongShadow`（文字长阴影）后做端到端验证。

| 环节 | 结果 |
|---|---|
| 参数探针 | `S_Shake-0050 Amplitude / 0051 Frequency / 0054 Motion Blur / 0056 Seed`；`ADBE LongShadow-0005 方向 / 0006 长度 / 0014 Fade Out / 0017 颜色 / 0018 Tint` 全部可写（`已实证`） |
| 注入 | **成功**：`layers=32 texts=22`，零报错标记（|SHAKE / |LSHADOW 均未出现），aep 8.96MB（较无插件版 +240KB） |
| **aerender 渲染** | **卡死**：输出临时 `.m4v` 停在 2,158,592 字节不动（>2 分钟无增长），必需强杀；进程常驻 5MB（启动器阶段即受阻） |
| **交互实例 renderQueue 渲染** | **失败**：420s 超时无返回、无输出文件；AE 内存回落（695MB）后需强杀重启 |

**判定**：插件效果**可注入但当前无法渲染**。最可能原因是**渲染期授权**（Red Giant 未激活；Sapphire 的
渲染期许可未验证——探针/注入阶段不报错，但渲染时会挂）。**已实证**的是"注入成功"与"两种渲染路径都阻塞"，
授权归因属**推断**，标 `待确认`。

**处置**：
1. 交付走 `TEXT_OVERLAY_PLUGINS=0`（新增环境开关，已实测生效：事件表中 px_shake/lshadow 全为 False）；
2. 插件路径**保留在代码内**（可用即开），待 Boss 激活 Red Giant / 修复 Boris Continuum 后重评；
3. 复现命令：`TEXT_OVERLAY_PLUGINS=1 TEXT_OVERLAY_VER=v29 ...`（勿在未激活状态反复尝试，每次需重启 AE）。

## 附录 B：附录 A 结论的**修正**（同日 A/B 单一变量实证）

附录 A 判定"插件可注入但无法渲染"，经**单一变量 A/B 隔离**后修正为：

| 测试 | 结果 | 结论 |
|---|---|---|
| LongShadow 单独（2D 文字，1 帧） | ✅ 0 秒完成 | 单插件可用 |
| S_Shake 单独（2D / **3D** / +运动模糊 +幅度KF，1-3 帧） | ✅ 1-2 秒完成 | 单插件可用，**3D 亦无问题** |
| S_Shake 在**完整 22 事件工程**（Sapphire） | ✅ **720 帧 60MB 全片完成** | **可用**（实测层：12 个爆点层，每层 7 个幅度KF 按节拍起峰） |
| **LongShadow 在完整工程** | ❌ 卡在 ~2.6MB（约 26-30 帧）不动，需强杀 | **元凶** |
| LongShadow + 遮罩揭示 + 发光/投影/模糊（**构建阶段**） | ❌ 脚本执行即卡死（JSX 无返回，aep 未生成） | **元凶确认**：LongShadow 与遮罩/效果组合时在构建期即挂 |
| 关闭 LongShadow 后同一工程 | ✅ 100 秒内输出 27.8MB，最终 720 帧完成 | **A/B 单一变量确认** |

**修正后的结论**：
1. **S_Shake（Sapphire）可用**——含 3D 图层、运动模糊、幅度关键帧；已接入交付版 `v29b`。
2. **LongShadow（Aescripts）排除**——单独可用，但与遮罩/多效果组合时在**构建期**卡死 AE；
   已改为显式开关（`TEXT_OVERLAY_LONGSHADOW=1` 才启用，默认关闭）。
3. 附录 A 中"Red Giant/Boris 不可用"的结论**不变**（那两个是授权/报错阻塞，已实证）。

**方法教训（重要）**：判定"插件不可用"必须做**单一变量 A/B**；本次若停在附录 A 的结论，
就会误杀可用的 S_Shake。同时：**构建期卡死**与**渲染期卡死**要分开测（本次两种情况都出现了）。
