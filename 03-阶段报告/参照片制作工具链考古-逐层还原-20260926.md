## 三、效果差距根因（回答"我缺哪一环"——不是缺滤镜）

当前管线的本质：**对已合成视频做整段后处理**（FFmpeg 滤镜链作用于扁平像素流）。
参照片的本质：**分层资产 → 各层独立变换 → 摄像机统一驱动 → 合成 → 后期**。
缺的不是效果，是**"层"这个抽象本身**。具体缺口（按依赖序）：

1. **素材分层能力**（最上游缺口）：前景角色/背景/特效分离 → 已有半成品：`puppet/` mediapipe 骨骼驱动、Silhouette 知识库（Roto/Paint/Matte 导出）、ComfyUI（D 盘 48GB，可生成补层）。缺：把"动画截图抠角色"的自动 Roto 管线接通（SAM2 引擎已在 puppet-automation！）
2. **逐层变换通道**：每层独立 position/scale/rotation + 摄像机 null 统一驱动（2.5D 视差、camera projection）→ AE 通道已通（executeAtomScript），缺"层参数包"的编排数据格式
3. **层间约束**：遮罩跟随（手书线条约束在角色轮廓=mask track）、阴影投射（222.aep 的 Casts Shadows 实证）→ AE 原生能力，缺编排表达
4. **骨骼驱动动画**（木偶层）：关节驱动+惯性 → puppet/puppet_auto_processor.py 已有，未接入主管线
5. **逐帧手绘层**（手书冲击波等）：当前完全缺失 → 需 ComfyUI 生成或 PS 绘制 + 序列导入（Silhouette Paint 文档给出修复/动画路径）
6. **3D 摄像机/物体**：鱼眼推拉可用 AE 摄像机+变焦近似；真三维碎片需 Blender（blender_run_script 通道已通）

## 四、素材→成片最小工具集（顺序链，含格式接口）

```
[1] 源获取     动画截图/素材库            → mp4/png序列
[2] 分层       SAM2自动Roto / Silhouette  → 带alpha的png序列或.exr多层（Matte导出指南格式）
[3] 层内加工   PS修图/ComfyUI重绘/补帧    → PSD分层 / png序列（保留alpha）
[4] 骨骼/逐帧  puppet(mediapipe) / 手书   → 部件序列或线稿序列
[5] AE合成     摄像机null+层视差+遮罩约束  → 预合成分段（.aep 工程，LUT/粒子/辉光/色散在此层）
   +粒子Saber  +三层调色级联 + 节拍表达式（分级视觉提前补偿表照抄 v15 实证值）
[6] 时间线     达芬奇(Resolve API) 或 AE   → 段落编排+速度坡道（setpts/Twixtor）
[7] 调色交付   DaVinci CDL/LUT 或 AE Lumetri → ProRes4444(中间) → H264(交付)
[8] 音画同步   librosa onset 表驱动 [5][6] 的 keyframe 时刻
```
并行关系：[2][3][4] 可按层并行；[5] 依赖 [2-4] 全部交付物；[6][7] 串行。**格式铁律：跨软件接口一律带 alpha 的序列（png16/exr），杜绝扁平 mp4 中转**（当前管线用扁平 mp4 中转正是"无层"的根源）。

## 六、全量 5 片层考古完成（2026-09-26 增补，rigid 公式修正后重跑）

执行中按六项质量准则补做了三件事：①`tests/test_layer_prober.py` 6 项合成帧方向性测试（静止/平移刚体/手书抖动/平涂/纯色/短镜降级，**6/6 passed 0.76s**）——首跑 3 失败暴露两个真缺陷：旧 rigid 公式（std/mean）可出负值→改为"运动块方向与全局主方向 ±30° 一致率"；纯噪声不是手书的合成真值（噪声边缘密度统计稳定）→改用抖动线稿。②公式修正后 **5 片全部重跑**（旧值作废）。③驱动脚本中文路径入 bat 被 cmd GBK 打乱→改 Python 驱动（bat 纯 ASCII）。

**跨片结论（三态：成立/受限/待定）**：
1. **抠像前景层 5/5 片全存在**（合计 58/205=28% 镜）——成立：Roto/键控分离是该类片子常规工序，但只作用于部分镜头（非全片）
2. **2.5D 视差层 5/5 全存在**（合计 50/205=24%，单片峰值蜘蛛侠 28%）——成立：静图拆层投影是普遍手法
3. **banding 可量化分离 2D/实拍源**（0.0089→0.0379 单调排序全对）——成立，可作源类型自动判别
4. **rigid 语义受限**：动画快切（72-82%）vs 史诗长镜（10%）方向合理，但"高 rigid"不能区分"木偶驱动"与"运镜带全局一致运流"——需 VLM 复核后才能升级到"骨骼驱动证据"级（待定，不包装）
5. 闪帧/标点集中在快切片（饿狼11/打戏10/日月8），叙事片≈0（张之维 0）——与 Stage A 踩拍/段落结论互证
