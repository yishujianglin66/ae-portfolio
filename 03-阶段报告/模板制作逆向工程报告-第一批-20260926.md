## 第一层：创作逻辑与叙事建构

### 美人鱼（较难）17.63s / 10镜 / BPM95.7 —— "呼吸式三段，黑场做标点"

**叙事弧线**（段落能量实测）：
- `0-1.6s` 长镜开场：辉光氛围镜（glow=0.337[硬证据]）+ 镜内加速坡道（ramp_up mag 0.771）——先给"这个世界很美"，再给运动感
- `1.57-2.27s` **三连击标点**：2 帧闪帧（1.57-1.60，粒子状高亮 n=13、dup=0.5[硬证据]）→ 0.65s **纯黑场**（sat=0.0、hue_c=1.0、黑场入场[硬证据]）——开场高潮后立刻"视觉重置"，这是刻意的静默战术
- `2.27-7.15s` 蓄力段：1.85s 辉光+粒子+色差镜（glow=0.416、n=15、aberr=-2px[硬证据]）→ 0.05s 极速闪过镜（flow mag=5.468，全片最大[硬证据]）→ 0.87s **第二次黑场定格**（flow=0.0、dup=0.981[硬证据]）→ 2.12s 叙事镜
- `7.15-17.63s` **双长镜爆发**：3.6s + 2.83s + 4.05s 三个长镜承载情绪——爆发段靠的是**镜内坡道与色差，不是快切**。镜 8（10.75-13.58）aberr=**-6px** 强色散 + ramp_down（1.372→减速）[硬证据]——情绪顶点用"画面开始散架"表达；镜 9 收尾 ramp_down 至 0.487 + dof=0.04 强虚化[硬证据]——"沉入水底"式落幕

**反常识手法清单（战术目的）**：
| 手法 | 位置 | 战术目的 |
|---|---|---|
| 2 帧闪帧 | 1.57s | 重音标点，制造"咔"的生理感 |
| 0.65s 纯黑场 ×2 | 1.62s / 4.17s | 视觉重置+蓄力，让下一镜更亮 |
| 0.05s 极速镜 | 4.12s | "来不及看清"的速度暗示 |
| 爆发段用长镜 | 7-17.6s | 情绪靠镜内速度曲线，不靠切 |

### 独自升级（一般）11.17s / 23镜 / BPM129.2 —— "坡道落拍开场，辉光递进爆发，长镜落幕"

- `0-1.6s` 开场四连抓：每镜 0.15-0.18s 且**全部 ramp_down**（mag 1.30-1.58[硬证据]）——从高速"砸落"到拍点上。注意：切点本身踩拍率只有 0.375，**但减速落点踩拍**——"身体跟乐句，切点跟画面流"[推断，由 ramp_down×前四镜+中位偏移 94ms 联合支撑]
- `2.25-6.7s` 爆发段：**辉光强度随能量递进**——glow 0.955(2.25s)→1.95(2.67s)→2.612(2.83s)→**3.524**(5.07s)[硬证据]，粒子数同步爬升 n=10→28。辉光不是全片铺的，是**叙事函数**
- `4.1-4.75s` 定格双标点：dup=0.53/1.0 静帧帧（镜14 全镜 dup=1.0[硬证据]）——快切段中的"急停"，为后段再加速腾出动态空间
- `6.7-11.17s` 落幕长镜：4.47s=**全片 40% 时长给最后一个镜头**，ramp_down + 粒子峰值 n=37 + 胶片颗粒 grain=12.64/corr=0.05[硬证据]——情绪着陆
- 全片色调 hue_c 0.4-0.76 高集中[硬证据]：蓝紫单色调偏移（影系 IP 色彩识别），与《AE效果视觉特征库》的冷色单色偏移配方吻合[推断]

### 两模板共同的创作语法（对系统最颠覆的部分）

1. **爆发≠快切**：高潮段由 2.8-4.5s 长镜+镜内速度曲线承载；快切（0.05-0.35s）集中在开场抓注意力和段落衔接
2. **时长双峰分布**[硬证据]：p10-p90 跨两个数量级（独自升级 0.12-0.72 + 尾部 4.47），系统当前输出是单峰均匀分布
3. **效果按叙事分配**：辉光只在爆发段且递进、颗粒只在首尾质感镜、黑场/静帧做标点——系统的 LUT/SFX 是全程均匀的
4. **镜内坡道是基本语法**：美人鱼 6/10、独自升级 17/23 镜有镜内 ramp_up/ramp_down[硬证据]——**每一镜内部都有速度表情**，不是整镜恒定倍率

## 第二层：剪辑技巧与时间线工程

| 维度 | 美人鱼 | 独自升级 | 系统 proof0926 | 判定 |
|---|---|---|---|---|
| 切点踩拍率(±80ms) | **0.18** | **0.38** | 0.96 | 系统自造规则，模板从不追求踩满 |
| 中位偏移 | 140ms | 94ms | ~0 | 模板偏移大=跟旋律不跟鼓点 |
| 镜内速度坡道占比 | 60% | 74% | **0%（整镜恒速）** | 系统缺失最大维度 |
| 闪帧剂量 | 1处(0.03s) | 2处(0.05s) | 按配方铺 | 模板极克制 |
| 黑场 | 2次(0.65/0.87s) | 0 | 0 | 战术黑场系统不会用 |
| 静帧定格 | 2镜 | 3镜 | 0 | 同上 |
| 转场主体 | 硬切+黑场标点 | 硬切+定格标点 | 硬切+闪帧 | 方向一致但缺标点层 |
| 镜头时长 | 中位1.70s 双峰 | 中位0.30s 双峰 | 中位~0.4s 单峰 | 双峰=节奏语法核心 |

**变速曲线形态**（Stage B flow_seq 实测）：不是"有变速"，是**逐镜微坡道**——典型形态：开场镜 0.18s 内 flow 从 1.9 降到 1.1（ramp_down 落拍）；爆发镜 5.07s 处 flow 0.4→2.9 爬升（ramp_up 冲刺）[硬证据]。缓动类型近似线性偏 ease-out（前段变化快）[推断，样本为 320px 光流均值，需人眼复核曲线尾部]。

**叠加层次结构推断**（按渲染顺序）：源素材 → 时间重映射(Twixtor) → 运动模糊(RSMB) → 粒子层 → 辉光层 → 色差层 → 调色 LUT → 颗粒顶层。依据：颗粒只在质感镜（顶层独立开关）、辉光随能量 keyframe（中间层可调）、色差只出现在峰值镜（后期风格层）[推断]。

## 第四层：能力边界与最小可复现参数集

### 现有管线能力对照（诚实清单）

| 模板语法 | FFmpeg 可达？ | 归属 |
|---|---|---|
| 镜内速度坡道 | ✅ setpts 分段表达式（resolve_engine 已有 dynamic_speed_ramp） | **只差编排器敢不敢逐镜生成坡道** |

| 真运动模糊 | ⚠️ minterpolate 伪；RSMB 质感需 AE | AE CC Force Motion Blur 原生 |
| 颗粒顶层 | ✅ noise=alls=20:allf=t | 一行滤镜 |
| 单色调 LUT | ✅ curves/colorbalance | 已有 LUT 链 |
| 时长双峰分布 | ✅ 编排层参数 | **纯策略问题，最先修** |

### 与系统输出的对账结论（时间线级，像素级抽样待做）

proof0926 七关 7/7 但**与模板语法存在四个结构性差异**：整镜恒速（模板 60-74% 镜内坡道）、单峰时长（模板双峰）、零标点（模板黑场/静帧/闪帧克制使用）、效果均匀铺（模板按叙事分配）。闸门的"踩拍≥65%"阈值本身与模板事实（0.18-0.38）相悖——**这是自造规则的最直接案例**，需改为"减速落点踩拍率"新口径。
