## 二、核心发现：applicability 是纸面声明

### 2.1 问题

`scripts/rule_registry.active_rules()` 原实现**只按 `inject_point` + `status` 过滤**：

```python
def active_rules(inject_point=None):        # 无 style/duration 入参
    for r in load_ruleset():
        if r.get("status") != "active": continue
        if validate_schema(r): continue
        if inject_point and r.get("inject_point") != inject_point: continue
        out.append(r)
```

而 R-2026-0002 声明了完整的适用域：

```json
"applicability": {"duration_range": [15, 45],
                  "bgm_structure": ["intro","build","drop"],
                  "style": ["amv_highenergy","燃向"]}
```

**即：把规则跑在抒情风格或 60s 时长上，它照样会被注入**——"适用域"从未约束任何行为。

### 2.2 诊断证据

`scripts/r4_applicability_probe.py`（新增）实测：

```
active_rules 形参: ['inject_point']
是否接收适用域上下文: False
active_rules('cut_anchor') 返回 1 条: R-2026-0002 (style 声明=['amv_highenergy','燃向'])
判定: applicability 未被校验（纸面声明）
```

证据落盘：`output/evidence/r4_applicability_20260909/probe.json`

## 三、修复：applicability 校验

### 3.1 实现

新增 `rule_applies(rule, context)`（`scripts/rule_registry.py`）：

| 维度 | 校验规则 |
|------|---------|
| `style` | context style 须在声明列表内（大小写不敏感） |
| `duration_range` | context duration 须落在 [lo, hi]（含边界） |
| `bgm_structure` | context structure 须与声明列表有交集 |

- **`context=None` 一律放行** —— 保持向后兼容，不误伤旧调用
- **声明不可解析时不约束** —— 畸形 duration_range 不抛异常
- `active_rules` / `cut_anchor_allowed` 均新增可选 `context` 参数

### 3.2 接入消费点

`ai/production_director.py`：

1. `__init__` 记录 `self._style_id`（从 taste_profile 的 `style_id`）
2. 锚点裁决处透传上下文：

```python
_rule_ctx = {"style": self._style_id, "duration": target_duration}
_rule_gate = _caa(_rule_ctx)
```

3. 退场日志显式标注原因（style + duration），便于诊断

### 3.3 修复前后对比

| context | 修复前 | 修复后 |
|---------|--------|--------|
| `amv_highenergy` + 30s（原适用域） | 1 条 | **1 条**（correct） |
| `emotional_lyric` + 30s | 1 条 ❌ | **0 条**（correct） |
| `ambient_calm` + 30s | 1 条 ❌ | **0 条**（correct） |
| `amv_highenergy` + 60s（超时长） | 1 条 ❌ | **0 条**（correct） |

## 五、规则退场的正确性论证

R4 场景下 `active_rules` 返回 **0 条**（style 不匹配），管线回退启发式；run61 场景返回 **1 条**（R-2026-0002 生效）。

**这正是"适用域收窄"的正常运作**：
- R-2026-0002 的证据来自洛天依燃向片（`run57→60`），其 `style` 声明为 `amv_highenergy/燃向`
- 抒情风格下规则**本就不该生效**（它的"16 分音符网格量化 + 0.55 dip"是燃向语法）
- 退场后管线用启发式，R4 仍达 narrative 中位数之上 → **说明退场决策正确，不是能力退化**

> 若不做此修复，R-2026-0002 会在抒情片上误注入燃向语法，属**跨风格污染**。
