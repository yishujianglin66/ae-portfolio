## 2. 已落地的能力（按层）

### 2.1 段落边界融合转场（ai/production_director.py）
- **SECTION_FUSION_MAP**：弧切换点融合词典（蓄力→爆发=flash 白闪 / 铺垫→蓄力=zoom / →尾声=fade / 未列出=cross_dissolve / **进入喘息一律硬切**）
- **_section_fusion()**：预算决策（融合 ≥3s 间隔；段落白闪独立 8s 预算，撞预算降级叠化不丢边界感）
- 段对象带 `transition_params["section_fusion"]=True` 标记 → beat_lock（渲染前全局降级柔转场的闸，4397 行区）**凭标记豁免**；豁免后 `chain_last_extra` **按存活转场重算**（避免 r1_fixed_v1 的"补偿无人消耗→时间线拉长→frozen_cut"回归）
- **变速+xfade 禁令已解除**（2026-08-12 的"98% 切点滞后"被受控实验推翻：tmp/xfade_drift_exp2.py，真实渲染链上漂移 ≤2 帧、帧守恒精确）；防线=转场安全化钳制 `t ≤ min(d前,d后)-0.1`（0.25s 镜头容 0.15s 微融合，容不下自动降级 cut）

### 2.2 小提琴重拍精确卡点
- 数据源：`cache/stems/9e00915a2a31/anchors.json`（`melody_onsets` 小提琴攻击音+音变点带强度、kick/snare_onsets 鼓点相位；BGM=1_from10s.mp3 的哈希目录）
- **_pick_anchor_hit()/_anchor_on_grid()**：取"最强且**在鼓点相位上**（±65ms 内有 kick/snare）"的锚；**离格装饰音不跟**（R-2026-0001 教训：跟离格事件走会被判"完全不在点上"）
- **融合边界吸附**：弧循环前预计算位移表（最强强锚 ±0.5s → 任意在相位锚 ±0.12s 帧级校准）；flash 对齐**白闪峰值**（边界=锚+t/2），zoom/叠化对齐**新镜头落定点**（边界=锚）；头/尾同步位移保持弧接缝连续
- **强锚补切**：漏覆盖的在相位强锚（±1.5 帧内无边界），把最近中间边界移过去（≤0.25s、移后段长 ≥0.18s 才动）
- 效果：强锚 ≤1帧覆盖 71%→**78%**（天花板≈78%，其余被离格/碎段/窗口守卫挡住）；融合边界全部 ≤1 帧贴锚（16-18ms）

### 2.3 踩点推进+震动（ffmpeg 侧，已被 AE 版取代但保留）
- `PUNCH_PEAK` 0.15→**0.22**（env `AEKV_PUNCH_PEAK`）；包络期逐帧交替抖动 `PUNCH_SHAKE_AMP`=0.008×宽（env `AEKV_PUNCH_SHAKE`，0=关）
- 单段探针 tmp/shake_probe.py：推近 +22.5%（期望 22%）、抖动 7.5px ✅

### 2.4 AE 专业特效通道（ai/ae_render_channel.py）★本轮核心成果
- **桥复活 + AE 通道端到端跑通（三轮 12/12 撞击镜头）**：桥构建合成（JSX executeAtomScript）→ 关 GUI 内工程 → `aerender -project`（与 GUI 共存 OK，56s/12镜）→ 并行规范化 MP4
- **pulse 分支新增 Position 抖动表达式**：Scale 最近撞击关键帧触发，7 帧内 36px×二次衰减，`posterizeTime(24)`+`seedRandom` 按帧确定性；comp/layer motionBlur=16 samples 让抖动带**真实运动模糊**
- **⚠️ 关键前提：AE 必须用 `os.startfile` 启动**——`subprocess.Popen` 起的 AE **不执行 Startup 脚本**（加载器一行日志不写、ping 无结果，但进程/窗口完全正常，极易误判为桥坏）。启动后看 `.ae-mcp-bridge/startup.log` 出现 "Polling started OK" 再发命令
- **坑**：ffmpeg 表达式求值器**不支持 `%` 运算符**（zoompan 交替方向必须写 `mod(on,2)`）

### 2.5 音效

1. **【根因级·已定位】用户观感不达标 = 整体风格方向不对**（2026-09-26 用户四选一确认，

2. **【缺陷】内容层"冻结切点"**：切点两侧画面近同（素材亮场/爆炸白帧相邻，像素差 0.6-3.8），purity9 有 3 处（6.83/13.63/13.92s）。**修复器(repair_cutpoints)只动切点时间表，治不了内容层**——根治方向：规划器选素材窗口时做"边界帧相似度"检查，或修复轮增加"换源窗口重渲"手段。注意 8.958s 类的融合叠化边界被自检判 frozen 是**预期误报**（渐变本就帧间相似）
