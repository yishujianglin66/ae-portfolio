## 四、下一步待开发任务优先级排序

### P1 — 立即执行（预计 4h）
1. **4+ 转场混用**：扩展 SECTION_TRANSITION_MAP，确保每次运行至少触发 3-4 种不同转场
   - 复用：`style_copy/ffmpeg_generator.py` STYLE_TO_FILTER_MAP.transitions
   - 关键：确保所有转场名在 FFmpeg xfade 有效范围内
   
2. **逐 beat 对齐**：将片段边界对齐到 `BeatOrchestrator.beat_times[]`
   - 复用：`audio/beat_orchestrator.py` 的 beat_times 列表
   - 关键：片段时长 = beat[i+1] - beat[i]，而非固定等分

### P2 — 短期扩展（预计 8h）
3. **VRS 内容分析集成**：接入 `vrs/vrs_orchestrator.py` 的 CV+LLM 混合分析
   - 复用：`vrs/video_effect_analyzer_v2.py` 识别 AE 特效/插件/混合模式
   - 目标：素材评分增加运动/构图/色彩维度

4. **逐段精细调色**：从全局 6 参数 → 每段独立调色参数
   - 复用：`ae/style_template_library.py` 模板效果参数
   - 关键：每段 FFmpeg eq/curves 参数独立计算

5. **多维素材评分**：扩展 cv2 评分维度
   - 新增：运动强度（光流）、构图评分（三分法）、色彩丰富度

### P3 — 中期目标（预计 6h）
6. **AE 工程打包**：生成 .aep 工程文件
   - 复用：`ae/style_template_library.py` 效果模板
   - 目标：可在 AE 中打开并二次编辑

7. **音乐感知变速**：变速随音乐能量曲线动态变化
   - 复用：`BeatOrchestrator` 的 energy_curve 列表
   - 关键：高能量段加速，低能量段减速

## 七、已知踩坑经验（必读）

### 1. FFmpeg xfade 转场名必须用具体方向名
- **错误**：`transition=slide` / `transition=zoom` / `transition=whip`
- **报错**：`const_values array too small for transition` 或 `Not yet implemented in FFmpeg`
- **正确**：`slideleft` / `circlecrop` / `smoothleft` 等具体方向名
- **别名映射**：`{"slide": "slideleft", "zoom": "circlecrop", "whip": "smoothleft", "wipe": "wipeleft"}`

### 2. fontfile 路径冒号需双层转义
- **错误**：`fontfile='C:/Windows/Fonts/arial.ttf'`
- **正确**：`fontfile='C\:/Windows/Fonts/arial.ttf'`
- **原理**：外层单引号保护 graph 级解析，`\:` 保护 option 级解析
- **建议**：使用 `-filter_complex_script` 传入脚本文件，避免 Windows 命令行引号剥离

### 3. 风格指纹结构是嵌套的
- **错误**：`fp.get("brightness")` — 返回 None
- **正确**：`fp.get("color", {}).get("avg_brightness")` — 返回实际值
- **结构**：`fingerprint["color"]["avg_brightness"]`，不是 `fingerprint["brightness"]`

### 4. style_copy 导入链断裂
- **错误**：`from scene_detector import SceneDetector` — ModuleNotFoundError
- **正确**：多路径降级导入（integrations/analysis/ae 子目录依次尝试）
- **修复位置**：`style_copy/input_parser.py` 第 39-54 行

### 5. fail-open 缺陷
- **错误**：FFmpeg 失败时 `self.state["success"] = True`
- **正确**：FFmpeg 失败必须标记 `success = False`（fail-closed 原则）
- **修复位置**：`style_copy/workflow.py` 第 114-119 行
