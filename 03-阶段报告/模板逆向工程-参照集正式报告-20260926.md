## 四层核心结论（234 镜实测，全部可在 forensics.json 复查）

### ① 创作逻辑：三种片型三种语法，不存在单一"好剪辑"模板
- **叙事史诗型**（一人之下张之维 122s/10镜）：中位镜长 8.75s、最长 42s，坡道率 0.60，辉光 60%——靠长镜内部运动叙事，切是稀有事件
- **节奏混剪型**（蜘蛛侠 38s/33镜、日月同错 39s/23镜）：中位 0.93-1.57s，色差 58-61%、辉光 64-78%——效果密度最高的形态
- **打戏型**（托尔芬VS蛇 87s/141镜）：中位 0.40s、切率 1.6/s、**粒子 82%、强色差 31 镜、定格 6 处**——快切+尘埃粒子+急停标点
- 共同语法：**末镜占比 13-35%（落幕长镜）**、段落 burst/mid 交替（每片 25-66 个能量段——段落切换远比我们系统的五段式细碎）

### ② 时间线工程：踩拍 0.27-0.44 区间再实锤
有音轨 4 片踩拍实测：一人之下 0.444 / 蜘蛛侠 0.406 / 日月 0.318 / 饿狼 0.269，中位偏移 89-169ms。**系统闸门现行"踩拍≥65%"与参照集事实相悖**，正式改口径：目标区间 0.25-0.45 + 落点(ramp_down 终点)对齐优先。镜内坡道率 0.39-0.64（5/5 片全部 ≥0.39）——**这是跨片型稳定的第一语法**，系统当前为 0。

### ③ 效果工程：覆盖度比教程样本高一档（正式数据）
| 效果 | 参照集实测覆盖 | 归因与最小参数 |
|---|---|---|
| 镜内速度坡道 | 39-64% 镜 | setpts 分段，起点×1.3→终点×0.8 |
| RGB 色差 ≥2px | **32-61% 镜**（打戏强色差 31 镜） | rgbashift 2-3px 常规 / 5-6px 峰值 |
| 辉光 | **41-78% 镜**，曲线收于情绪落点（日月 0.41→4.17） | AE 双栈 Glow，I 随能量 keyframe |
| 粒子 | 40-82% 镜 | Particular 灰尘配方（连通域 n=10-37） |
| 胶片颗粒 | 每片 3-9 镜 | noise=alls=18:allf=t+u 顶层 |
| 景深虚化 | 7-30% 镜 | 镜头模糊(iris) |
| 定格标点 | 每片 1-6 镜 | tpad clone |
| **饱和度对切（新发现）** | 同片 sat 0-219 双极（饿狼 0-200/蜘蛛侠 32-219） | 黑白镜与高饱和镜交替=重音工具；教程批未见此手法 |

### ④ 可复现性：FFmpeg 可覆盖 6/9 项，AE 通道补 3 项
坡道/色差/颗粒/定格/饱和对切/闪黑标点 = FFmpeg 全部可达（管线已有或一行滤镜）；辉光真阈值模式/粒子/景深遮罩 = AE 执行（particleFXMaster.jsx、双栈 Glow JSX 通道已通）。**无一项需要新插件采购**。
