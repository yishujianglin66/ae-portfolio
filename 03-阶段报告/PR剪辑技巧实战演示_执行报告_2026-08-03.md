| `app.project.importFiles()` | 导入素材 |

## 五、经验总结

1. **PR 2025 API 严重受限**：与 AE 不同，PR 的 ExtendScript API 几乎不允许创建/修改效果、文字、变速。唯一可靠的自动化路径是 `track.insertClip()` + Motion 关键帧。

2. **QE DOM 在 PR 2025 几乎不可用**：`app.enableQE(true)` 返回 true，但序列/轨道/clip 对象不可访问。`qe.project` 只有元数据属性。

3. **DroverLord 框架拦截 GUI 自动化**：PR 使用 CEF 渲染面板，标准 UI 自动化工具（UIA/Win32 鼠标事件）无法操作时间线。ComputerUse 需要特殊技术（keybd_event P/Invoke + UIA InvokePattern）才能部分绕过。

4. **Bridge eval 是最可靠的自动化路径**：通过 `pr_command.json` 文件投递命令，Bridge 在事件触发时执行。Ctrl+S 触发 `onProjectChanged` 是最稳定的触发方式。

5. **keepDirty 导致序列名不稳定**：序列名在每次事件后可能被改写（`VinlandEdit_d361` → `VinlandBeatSync_d698`），代码中必须按索引取序列。
