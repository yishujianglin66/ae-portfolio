## 三、本轮修复：reranker 缓存缺 snapshots

### 3.1 症状

端到端复跑时反复出现：

```
[WinError 10051] 向一个无法连接的网络尝试了一个套接字操作。
thrown while requesting HEAD https://huggingface.co/BAAI/bge-reranker-v2-m3/resolve/main/preprocessor_config.json
Retrying in 8s [Retry 5/5].
```

### 3.2 根因

`D:/hf_cache/hub/models--BAAI--bge-reranker-v2-m3/` 的 **`blobs/` 完整（2.4GB，含 2.27GB 主权重）
但缺 `snapshots/<rev>/` 目录**——HuggingFace 缓存靠 snapshots 里的软链暴露文件，
缺失时 `transformers` 会尝试联网补全，离线环境下即报 WinError 10051。

对照：同类已正常工作的 `models--BAAI--bge-m3` 有完整 snapshots。

### 3.3 修复

按 blob 内容识别用途后重建 snapshots（**用硬链接，不占额外空间**）：

| snapshots 文件 | ← blob（大小） |
|----------------|---------------|
| `pytorch_model.bin` | `d9e3e081…`（2.27GB，主权重） |
| `sentencepiece.bpe.model` | `cfc8146a…`（5.1MB，SentencePiece） |
| `tokenizer.json` | `69564b69…`（17MB） |
| `tokenizer_config.json` | `328a00a9…`（1.2KB） |
| `config.json` | `9f62673c…`（795B，XLMRobertaForSequenceClassification） |
| `special_tokens_map.json` | `b1879d70…`（964B） |
| `README.md` / `.gitattributes` | `55354087…` / `52373fe2…` |

### 3.4 验证

```
加载成功 13s（无联网重试）
重排分数: [0.162, 0.001]   ← 正确文档 0.162 vs 干扰项 0.001，分辨力正常
```

## 四、生产启用方式

```
# 开启归一化过滤路由（默认关）
AEKV_NORM_API=1

# 离线运行（推荐，避免联网重试拖慢）
HF_HUB_CACHE=D:/hf_cache/hub
HF_HUB_OFFLINE=1
```

分流设计（`ai/t11_hybrid_search.decide_route`）：

| 查询类型 | 路由 | 依据 |
|---------|------|------|
| 别名/IP 命中 | `hybrid`（原链路） | legacy 集 1.000，**保护不动** |
| 自然语言 + 归一化开 | `norm_filter` | 本轮验证 36/36 |
| 自然语言 + 仅重排开 | `semantic_rerank` | 基准 v2 D 臂 0.400 |

归一化依赖 API（百炼 qwen3.8-flash 5 票多数制），缓存 `cache/bge_m3_index/query_norm_mv_cache.jsonl`；
无 key/全部失败时回落 `NO_IP` → D 臂兜底，不阻断。

## 五、遗留与建议

1. **归一化成本**：5 次 API 调用/查询（并行 ~3s）。缓存命中则零成本。建议按调用量观察额度。
2. **legacy 集回归保护**：任何检索改动不得让 legacy A 臂掉下 1.000（基准 v2 已含该断言）。
3. **场景级检索基准**（VLM caption 实验的反弹方向）：caption 资产（1061 条）对"找雨夜悲伤镜头"
   这类**场景查询**是唯一有效文档形态，但当前基准无场景级 gold 标签，价值测不出。
   若后续有场景检索需求，应先补建场景级查询集。
4. **`frame_captions.jsonl`（225KB）与 reranker 缓存（2.4GB）**：资产已在盘，后者未纳入 DVC。

复现：

```bash
export AEKV_NORM_API=1 HF_HUB_CACHE=D:/hf_cache/hub HF_HUB_OFFLINE=1
python -c "
import sys; sys.path.insert(0,'.')
from ai.t11_hybrid_search import (load_intel_cache, enrich_with_pseudolabels,
                                  build_semantic_index, hybrid_search)
from ai.r3_benchmark_v2 import HELD_OUT_QUERIES

entries = enrich_with_pseudolabels(load_intel_cache(), max_per_ip=50)

hits = sum(any(exp in (e.get('ip_names') or []) or exp == (e.get('primary_ip') or '')
               for e in hybrid_search(entries, emb, model, q, top_k=10))
           for q, exp in HELD_OUT_QUERIES)
print(f'R@10 = {hits}/{len(HELD_OUT_QUERIES)}')
"
```
