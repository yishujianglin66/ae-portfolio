# F3: 文件导入功能测试
- tags: [测试, 测试用例, importFootage

## 测试目标
验证 After Effects MCP 项目中的文件导入功能（importFootage.jsx）的正确性

## 测试用例
### 测试用例 1: 基础素材导入
- **描述: 导入单个图片素材到项目面板
- **预期**: 素材成功导入到项目面板
- **参数**: {
  "filePath": "[测试素材路径]",
  "asSequence": false
}

### 测试用例 2: 导入素材到合成
- **描述: 导入素材并添加到指定合成
- **预期**: 素材导入到项目并添加到合成作为新图层
- **参数**: {
  "filePath": "[测试素材路径]",
  "compName": "测试合成",
  "asSequence": false
}

### 测试用例 3: 序列素材导入
- **描述: 导入素材并设置为序列导入
- **预期**: 序列素材正确导入
- **参数**: {
  "filePath": "[序列素材首帧路径]",
  "compName": "测试合成",
  "asSequence": true
}

### 测试用例 4: 错误处理 - 文件不存在
- **描述: 测试文件不存在的情况
- **预期: 返回错误信息，提示文件不存在
- **参数**: {
  "filePath": "不存在的文件路径"
}

### 测试用例 5: 错误处理 - 缺少必填参数
- **描述: 测试缺少 filePath 参数
- **预期: 返回错误信息，提示 filePath 缺少
- **参数**: {}

## 测试步骤
1. 准备测试素材
2. 创建测试合成
3. 使用 MCP 工具调用 import-footage
4. 检查结果
