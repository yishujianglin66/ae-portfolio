# F1 — 图层类型自动识别: 测试用例说明书

> 日期: 2026-06-05 | 配套脚本: `F1_layer_type.jsx`

---

## 测试环境准备

1. **启动 Adobe After Effects 2025** (或 2023/2024)
2. **新建项目**: 文件 → 新建 → 新建项目
3. **新建合成**:
   - 合成名称: `F1_Test_Comp`
   - 预设: HDTV 1080 29.97
   - 时长: 10 秒

### 创建测试图层

| 序号 | 菜单操作 | 图层默认名 | 预期分类 |
|------|---------|-----------|---------|
| 1 | 图层 → 新建 → 文本 (输入 "Hello 测试") | "Hello 测试" | 文字图层 |
| 2 | 图层 → 新建 → 纯色 → 选红色 → 确定 | "Red Solid" | 固态/纯色 |
| 3 | 图层 → 新建 → 空对象 | "Null 1" | 空对象 |
| 4 | 图层 → 新建 → 形状图层 (选矩形工具画一个矩形) | "Shape Layer 1" | 形状图层 |
| 5 | 图层 → 新建 → 摄像机 → 确定 (默认50mm) | "Camera 1" | 摄像机 |
| 6 | 图层 → 新建 → 灯光 → 确定 (默认平行光) | "Light 1" | 灯光 |
| 7 | 图层 → 新建 → 调整图层 | "Adjustment Layer 1" | 调整图层 |

---

## 测试 T1: 无合成打开

**操作**:
1. 关闭所有合成的时间轴面板（或确保无合成处于激活状态）
2. 运行: 文件 → 脚本 → 运行脚本文件 → 选择 `F1_layer_type.jsx`

**预期现象**:
- 弹出 alert 对话框
- 文字内容: "错误: 未选中任何项。请在项目面板中双击打开一个合成，或确认时间轴面板有焦点。"

---

## 测试 T2: 无图层选中

**操作**:
1. 激活 F1_Test_Comp 时间轴面板
2. 取消所有选择 (Ctrl+Shift+A 或在空白处点击)
3. 运行 `F1_layer_type.jsx`

**预期现象**:
- 弹出 alert 对话框
- 文字: "提示: 未选中任何图层。请在时间轴面板中选中至少一个图层后重新运行此脚本。"

---

## 测试 T3: 逐个图层单独测试

**操作** (每个图层重复一次):
1. 仅选中该图层
2. 运行 `F1_layer_type.jsx`
3. 记录 alert 中显示的分类

| 选中图层 | 预期 alert 摘要 |
|----------|----------------|
| Hello 测试 | 文字×1 |
| Red Solid | 固态/纯色×1 |
| Null 1 | 空对象×1 |
| Shape Layer 1 | 形状×1 |
| Camera 1 | 摄像机×1 |
| Light 1 | 灯光×1 |
| Adjustment Layer 1 | 调整层×1 |

---

## 测试 T4: 全选混合类型

**操作**:
1. 在时间轴中全选所有图层 (Ctrl+A)
2. 运行 `F1_layer_type.jsx`

**预期现象**:
- alert 显示选中 7 个图层
- 类型汇总包含: 文字、固态/纯色、空对象、形状、摄像机、灯光、调整层

---

## 测试 T5: 锁定/隐藏图层不影响识别

**操作**:
1. 锁定 "Red Solid" (点击该图层左侧的锁图标)
2. 将 "Shape Layer 1" 设为 Shy 隐藏 (点击 Shy 开关然后用时间轴面板的隐藏开关)
3. 全选所有可见图层
4. 运行脚本

**预期现象**:
- 锁定和 Shy 图层仍可被选中和识别
- 分类结果不受锁定/Shy 状态影响

---

## 测试 T6: 断链素材

**可选测试**:
1. 导入一个 WAV 文件到项目面板
2. 从项目面板拖入时间轴
3. 在项目面板中删除该 WAV 素材（使图层引用断裂）
4. 选中该图层运行脚本

**预期现象**:
- 不崩溃
- 分类为"空对象"或"AVLayer (source=...)"带描述
