## 🔥 标志性技法

### 1. 空对象绑定拉镜（核心思路）

DxshNova 的方法论极度清晰——**一个空对象控制一切**：

```
工作流：
① 新建 Null Object（空对象）
② 将所有画面图层设为空对象的子级
   ├── 图层 → Parent 下拉 → 选择 Null
   └── 或使用 Pick Whip 拖拽链接
③ 只在空对象上做关键帧动画
   ├── Scale：控制远近推拉
   ├── Position：控制左右上下滑镜
   └── Rotation：控制旋转甩镜
④ 单个画面图层仍可独立微调
```

### 2. 对角滑镜

他的招牌动作——不是水平/垂直移动，而是对角线方向：

```
Position 关键帧示例（对角移动）：
帧 0:  [960, 540]          ← 画面中央（1080p画布）
帧 6:  [1200, 700]         ← 右下角滑出
帧 8:  [700, 350]          ← 新画面从左上角滑入
帧 14: [960, 540]          ← 回到中央

配合 Scale：
帧 0:  100%
帧 6:  115%               ← 滑出时微微放大
帧 8:  85%                ← 新画面缩小进入
帧 14: 100%               ← 回归正常
```

### 3. 标准运动模糊参数

```
合成设置：
├── 高级 → 快门角度：180°（默认）
└── 快门相位：-90°

图层：
└── 运动模糊开关：开启

每层可额外加「变换」效果：
├── 快门角度：360°（更强模糊）
└── 用于特定高速镜头
```

## 🎬 典型拉镜模板

### 对角滑镜（可复刻模板）

```
准备工作：
├── 画面A → 预合成 → 动态拼贴(200%)
├── 画面B → 预合成 → 动态拼贴(200%)
└── 新建 Null → 画面A和B设为子级

空对象关键帧：
0帧:  Scale=100, Position=[960,540], Rotation=0
6帧:  Scale=115, Position=[1250,700], Rotation=5   ← A滑出
7帧:  Scale=85,  Position=[650,380],  Rotation=-5  ← B从对角滑入
14帧: Scale=100, Position=[960,540], Rotation=0    ← 归位

曲线：全选 Easy Ease (F9) → 调整峰值在切换点
```
