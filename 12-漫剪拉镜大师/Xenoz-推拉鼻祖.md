## 🔥 标志性技法

### 1. 鱼眼形变推拉

Xenoz 最具辨识度的技法——不是简单的 Scale 缩放，而是**带形变的推拉**：

```
核心思路：
├── Scale 放大 + 同时 Corner Pin 四角外扩
├── 或使用 Optics Compensation（镜头畸变）
│   └── 效果 → 扭曲 → 光学补偿
│       ├── 视野（FOV）：50-80
│       └── 反转镜头畸变：勾选
└── 效果：画面中心推近 + 边缘向外弯曲 = 鱼眼推拉
```

### 2. 动态拼贴过渡

```
① 所有画面图层添加「动态拼贴」
   ├── 输出宽度：250%
   ├── 输出高度：250%
   └── 镜像边缘：开启

② 在变换属性上做推拉
   ├── Scale 100% → 130% → 100%
   ├── Position 做微小偏移（5-15px）
   └── Rotation ±3-8°

③ 关键帧间距：3-8 帧之间切换
```

### 3. Shake 震动（他的标志性 shake）

来自 B站教程拆解：
```
wiggle(频率, 振幅) 表达式应用于 Position
├── 重拍：wiggle(15, 20)
├── 轻晃：wiggle(8, 5)
└── 仅水平抖：x = wiggle(10,15)[0]; [x, value[1]]
```

## 📐 曲线风格

Xenoz 的曲线特点：
- **极陡的缓入缓出** — 画面切换瞬间速度最大
- **几乎无匀速段** — 全程在加速或减速
- **关键帧间距** — 3-6 帧（极快）

```
速度曲线示意：
         /\
        /  \
       /    \    ← 峰值尖锐，切换瞬间达到最高速
      /      \
─────┘        └─────
  缓入         缓出
(2-3帧)      (2-3帧)
```

## 🎬 典型拉镜模板

### 基础推拉（新手可复刻）

```
第 1 步：画面A → 预合成 → 添加动态拼贴
第 2 步：画面B → 预合成 → 添加动态拼贴
第 3 步：画面A 在 0-4 帧：
         Scale: 100 → 125
         Rotation: 0 → -4°
第 4 步：画面B 在 4-8 帧：
         Scale: 80 → 100（从缩小弹回正常）
         Rotation: 3° → 0
第 5 步：两层都开运动模糊
第 6 步：曲线编辑器 → 调整峰值在切换点
```
