## 🔥 标志性技法

### 1. 旋转拉镜 + 挤压形变

```
核心组合：
├── Rotation Z：±5-15°（比 Xenoz 更大胆）
├── Scale X/Y 不等比缩放：
│   ├── Scale X: 120%, Scale Y: 85% → 横向挤压
│   └── Scale X: 80%, Scale Y: 120% → 纵向拉伸
└── 取消等比缩放锁 → 分别调 X 和 Y
```

### 2. 遮罩 + 运动路径跨画面衔接

Floby 的独门技巧——不是简单的 A→B 切换，而是**部分画面先行过渡**：

```
工作流：
① 画面A 在上层，画面B 在下层
② 在 A 上画 Pen Tool 遮罩（Mask Path）
③ 遮罩沿运动方向推进：
   ├── 从左到右滑 → 遮罩从左向右展开
   ├── 旋转过渡 → 遮罩从中心旋转展开
   └── 对角穿越 → 遮罩沿对角线扫过
④ 遮罩羽化：10-30px（柔边过渡）
⑤ 画面B 同时在遮罩露出区域做 Scale 微动
```

### 3. Glitch 故障过渡

```
效果叠加顺序：
① 画面A → CC Block Load（方块化故障）
   ├── Scans: 10-20
   └── Start/Completion 动画：0→100
② 画面B → RGB Split
   ├── 红通道偏移：±3px
   └── 蓝通道偏移：∓3px
③ Glitch 持续：4-8 帧
④ 搭配：画面抖动 wiggle(10, 15)
```

## 🎬 典型动作番拉镜模板

### 进击巨人式高燃拉镜

```
准备：画面A(动作高潮帧) + 画面B(下一镜头)

空对象动画（总控）：
帧0:  Scale=[100,100],  Rotation=0
帧4:  Scale=[120,85],   Rotation=12°   ← 挤压+旋转推向A
帧6:  Scale=[80,120],   Rotation=-8°   ← B缩入+反向旋转
帧12: Scale=[100,100],  Rotation=0

叠加效果（画面A上层）：
├── 帧0-4：CC Block Load (0→100)
├── 帧4-6：遮罩从右向左扫过
└── 帧6-12：Opacity 100→0

画面B下层：
└── 帧4-12：Opacity 0→100 + Scale 85→100
```

## 🎨 遮罩路径动画技巧

```
① 画矩形遮罩（覆盖全画面）
② 在 Mask Path 首帧：矩形在画面外（左侧）
③ 在 Mask Path 末帧：矩形覆盖全画面
④ 关键帧差值 → 中间帧自动填补路径
⑤ 调 Mask Feather：15-25px
⑥ 效果：画面被"扫"入，而不是"跳"入
```

## 💡 韩式快剪 vs 普通快剪

| 维度 | 普通快剪 | Floby 韩式快剪 |
|------|---------|--------------|
| 缩放 | 等比 Scale | XY 不等比挤压 |
| 旋转 | ±3-5° | ±10-15° |
| 过渡 | 硬切或淡入淡出 | 遮罩扫入 + Glitch |
| 节奏 | 平均分布 | 极度压缩（3-4帧一切） |
| 适合 | 所有类型 | 动作番 / 战斗场景 |
