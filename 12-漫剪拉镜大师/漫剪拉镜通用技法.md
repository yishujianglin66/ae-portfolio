# 漫剪拉镜通用技法

> 8 位大师的共同技术底座——理解了这些底层原理，再看任何拉镜都是一样的骨架。

---

## 🏗️ 核心概念：拉镜到底是什么

**拉镜（Push-Pull / Zoom Transition）** = 对图层做缩放+位移+旋转的关键帧动画，在两个画面之间制造**连续的运动错觉**。

```
画面A（当前帧）
    │
    ├── 放大/缩小（Scale）
    ├── 平移/推入（Position）
    ├── 旋转/甩动（Rotation）
    └── 形变（Corner Pin / Mesh Warp）
            │
            ↓ 运动模糊衔接
            │
画面B（下一帧）
```

---

## 🔧 五大核心属性（纯AE，无需插件）

### 1. Scale（缩放）

```
最常见：100% → 120% → 100%（拉近再推回）
关键帧曲线：先快后慢（Ease Out），进入新画面时加速（Ease In）
```

### 2. Position（位移 / 推拉）

```
X轴：左右滑镜
Y轴：上下甩镜
Z轴：推近拉远（需3D图层）
```

### 3. Rotation（旋转）

```
Z旋转：平面旋转甩镜
搭配缩放：边转边推 → 强烈的动态感
角度范围：通常 2°-15°，不超过 20°
```

### 4. Opacity（透明度）

```
交叉淡入淡出：画面A淡出 + 画面B淡入
时长：3-8 帧
常与缩放/位移叠加
```

### 5. Motion Blur（运动模糊）

```
必须开启！
图层开关 → 运动模糊（框框图标）
合成设置 → 高级 → 快门角度 180°（默认）
快门角度越大 = 模糊越强 = 速度感越强
```

## 📐 曲线编辑器（Graph Editor）— 拉镜的灵魂

所有大师的核心秘密在曲线编辑器里：

### 速度曲线模板

```
         ┌── 峰值速度（画面切换瞬间）
        /│\
       / │ \
      /  │  \──── 缓出（进入新画面后减速）
     /   │
────┘    │
缓入（接近切换时加速）
```

### 常用预设曲线

| 效果 | 曲线形状 | 场景 |
|------|---------|------|
| **丝滑推入** | Easy Ease (F9) | 慢节奏 |
| **快速甩镜** | 先平后陡再平 | 高燃 |
| **弹性回弹** | 过冲回弹 | 卡点 |
| **匀速拉镜** | 直线 | 长推 |

> 💡 Master 技巧：进入曲线编辑器 → 选中关键帧 → 右键 → Keyframe Velocity → 调整 incoming/outgoing 速度百分比

## 🧩 三大核心预设/效果组合

### 1. 动态拼贴（Dynamic Tile）

```
效果 → 风格化 → 动态拼贴
├── 输出宽度/高度：通常 200-300%
├── 镜像边缘：开启（消除黑边）
└── 配合缩放使用：放大时不会出现黑边
```

→ 这是 Xenoz 的标志性技法的底层

### 2. 变换（Transform）+ 运动模糊

```
效果 → 扭曲 → 变换
├── 缩放/位置/旋转 → 在这里做拉镜
├── 快门角度：360°（比合成默认更强）
└── 优势：在效果层面控制模糊，不影响图层原生属性
```

### 3. 空对象绑定（Null Object Parent）

```
新建空对象 → 做拉镜动画
所有画面图层 → 父子链接到空对象
→ 修改空对象 = 全局拉镜
→ 单个图层仍可独立微调

这是 DxshNova 的核心思路
```

## 🎬 拉镜流程标准化

### Molob 式全流程

```
① 预合成（Pre-comp）
   把每个画面的动画做好 → 分别预合成

② 动态拼贴
   每个预合成加动态拼贴 → 防止缩放黑边

③ 空对象绑定
   所有画面图层链接到 Null → 统一运镜

④ 拉镜关键帧
   在空对象上做 Scale + Position + Rotation

⑤ 运动模糊
   快门角度 180°-360°

⑥ 色彩统一
   调整层 → Lumetri Color / LUT → 所有画面色调统一

⑦ 微调曲线
   进入 Graph Editor → 逐帧调整速度
```

## 🎯 拉镜与音乐同步（Beat Sync）

### 节拍标记法

```
① 展开音频波形
② 按 "*" 键（小键盘）在节拍上加标记
③ 关键帧对齐标记点
④ 重音 = 快速拉镜 | 弱拍 = 慢推
```

### 时间参考

| 音乐类型 | BPM | 每拍帧数（24fps） |
|---------|-----|-----------------|
| 慢速 | 60-80 | 18-24 帧 |
| 中速 | 90-120 | 12-16 帧 |
| 快速 | 130-160 | 9-11 帧 |
| 极速 | 170+ | 6-8 帧 |

## ⚠️ 新手常犯错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 不开运动模糊 | 画面割裂感 | 图层+合成双重开 MB |
| 忘记动态拼贴 | 缩放时出现黑边 | 每个预合成都加 |
| 曲线用线性 | 机械感 | 至少用 Easy Ease (F9) |
| 缩放过大(>200%) | 画质糊掉 | 控制在 100-150% |
| 拉镜时长不统一 | 节奏混乱 | 同类型拉镜统一帧数 |
