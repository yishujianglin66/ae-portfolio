## 🔥 标志性技法

### 1. 院线级缓动曲线

Molob 的推拉不追求速度，追求**"看不见的丝滑"**：

```
曲线特征：
├── 极长的缓入缓出（8-15帧过渡）
├── 峰值速度远低于 Xenoz
├── 加速段和减速段几乎对称
└── 关键帧使用 Easy Ease + 手动微调手柄

对比：
Xenoz:  /\        （极端尖锐，3-6帧切换）
Molob:  ╱‾‾╲       （平滑圆弧，8-15帧过渡）
```

### 2. 预合成优先（Pre-comp First）

Molob 最强调的结构化工作流：

```
层级结构：
Main Comp
├── [调整层] ← 全局调色 LUT
├── [Null Object] ← 总控拉镜
│   ├── [预合成: 画面A]
│   │   ├── 动态拼贴 250%
│   │   ├── 画面A原始图层
│   │   └── 局部动画（独立关键帧）
│   ├── [预合成: 画面B]
│   │   ├── 动态拼贴 250%
│   │   └── ...
│   └── [预合成: 画面C]
└── [调整层] ← 全局颗粒/暗角
```

> 关键原则：**每个画面先在自己预合成里做好动画，再拉到主合成做整体拉镜。**

### 3. 色彩统一

Molob 极其重视色调一致性：

```
方法：
① 所有画面顶部加调整层
② 调整层添加 Lumetri Color
   ├── 基本校正 → 色温/色调统一
   ├── 创意 → Look: 选择统一风格 LUT
   └── 曲线 → 微调 RGB 通道
③ 可选：用 Color Balance 分别调阴影/中间调/高光
```
