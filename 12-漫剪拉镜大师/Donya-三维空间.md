## 🔥 标志性技法

### 1. 2D 画面分层 → 3D 空间

Donya 最核心的思维——把一张平面图拆成多个深度层：

```
原始画面（一张静态插画）
        │
        ↓ 用 Photoshop 或 AE 蒙版分层
        │
    ┌───┼───┐
  前景   中景   背景
  (人物) (建筑) (天空)
    │    │    │
    ↓    ↓    ↓
  AE 中转为 3D 图层，分配不同 Z 轴位置
    │    │    │
    └────┼────┘
         ↓
   3D 摄像机推动 → 产生真实视差（Parallax）
```

### 2. AE 摄像机图层 + 景深

```
① 图层 → 新建 → 摄像机
   类型：双节点摄像机（方便控制焦点）
   
② 景深设置：
   摄像机选项 → 景深：开启
   ├── 焦距：根据画面调（800-2000px）
   ├── 光圈：F/2.8-F/5.6（大光圈=浅景深）
   └── 模糊层次：200%（增强模糊量）

③ 摄像机动画：
   ├── Position Z：0 → -300（推进）
   ├── Point of Interest：锁定主体
   └── 可选 Rotation：轻微环绕
```

### 3. 镜头环绕运镜（Orbit）

```
设置：
① 新建 Null → 放在画面中央 → 3D 图层
② 摄像机 Parent → 空对象
③ 空对象做 Y Rotation：0° → 15°
④ 效果：摄像机绕画面中心环绕

配合景深：
├── 前景：大模糊（距摄像机近）
├── 中景（主体）：清晰（焦点在此）
└── 背景：轻微模糊（距摄像机远）
```

## 🎬 原神风插画拉镜模板

### 从静态插画到动态 AMV

```
第1步：素材准备
├── 用PS把插画分层（前景人物/中景建筑/背景天空）
├── 每层导出 PNG（透明背景）
└── 缺失的背景部分用内容识别填充补全

第2步：AE 3D空间搭建
├── 所有图层开启 3D 开关
├── 前景层 Z: -200, Scale: 120%
├── 中景层 Z: 0, Scale: 100%
├── 背景层 Z: 300, Scale: 85%
└── 新建 3D 摄像机

第3步：摄像机动画
├── 0秒: Position Z=0, Focus Distance=中景层
├── 5秒: Position Z=-180, 轻微 Y Rotation=8°
└── 曲线: 极致缓入缓出

第4步：粒子/光效
├── CC Particle World: 飘浮粒子
└── 调整层: 柔焦 + 暖色LUT
```

## 📐 Donya 式 3D 参数

| 图层 | Z轴位置 | Scale补偿 | 景深模糊 |
|------|--------|----------|---------|
| 超前景 | -400 | 140% | 高 |
| 前景 | -150 | 115% | 中 |
| 中景(主体) | 0 | 100% | 无 |
| 背景 | +200 | 85% | 低 |
| 远背景 | +500 | 70% | 中 |

> Scale 补偿公式：`补偿Scale = 100 × (1 + Z/摄像机距中景距离)`
> —— 保证各层在摄像机静止时看起来和原始画面一样大。
