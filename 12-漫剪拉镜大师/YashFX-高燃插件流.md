## 🔥 标志性技法

### 1. 径向模糊穿梭拉镜

YashFX 的代表性视觉——镜头进出时带径向模糊拖影：

```
效果叠加：
├── 效果 → 模糊和锐化 → 径向模糊
│   ├── 类型：缩放
│   ├── 数量：10-50（关键帧：0→50→0）
│   ├── 中心点：画面中心
│   └── 品质：最佳
│
├── Sapphire S_BlurMoCurves（更高级替代）
│   ├── 可以沿曲线方向模糊
│   └── 模糊+光效叠加
│
└── 配合 Scale 推拉：
    100% → 130%（同时径向模糊量增大）
    130% → 100%（模糊量归零）
```

### 2. Sapphire 光效拖影

```
Sapphire 插件组合：
├── S_Glow（辉光）
│   ├── Threshold: 0.3-0.5
│   ├── Glow Width: 20-40
│   └── Brightness: 1.5-3.0
│
├── S_LightLeak（漏光）
│   ├── 位置动画：从边缘扫入
│   └── 混合模式：滤色/叠加
│
└── S_Rays（放射光线）
    ├── 从画面亮点发射光线
    └── 推拉时增强
```

### 3. BCC 模糊穿梭

```
BCC (Boris Continuum Complete) 搭配：
├── BCC Lens Blur（镜头模糊）
│   └── 模拟真实镜头失焦
├── BCC Optical Dissolve（光学溶解过渡）
│   └── 比 AE 默认转场更自然
└── BCC Motion Blur（专业运动模糊）
    └── 比 AE 内置更强、更可控
```

## 🎬 高燃拉镜模板

### 径向模糊穿梭

```
准备：
├── 画面A → 预合成 → 动态拼贴
├── 画面B → 预合成 → 动态拼贴
└── Null 总控

空对象推拉：
帧0:  Scale=100
帧5:  Scale=135    ← 快速推进
帧6:  Scale=80     ← 切换到B
帧12: Scale=100    ← 弹回

效果叠加（画面A上层，帧0-6）：
├── 径向模糊: 数量 0→40→0
├── S_Glow: Brightness 1.0→2.5→1.0
└── S_LightLeak: Opacity 0→80→0

画面B下层 帧5-12：
├── 径向模糊: 数量 30→0
└── S_Glow: Brightness 2.0→1.0
```

## 🆚 纯AE vs YashFX 插件流

| 维度 | Xenoz 纯AE | YashFX 插件流 |
|------|-----------|-------------|
| 学习门槛 | 低（不需要插件） | 中（需安装 Sapphire/BCC） |
| 渲染速度 | 快 | 较慢（插件计算） |
| 视觉效果 | 干净、技术感 | 丰富、炸裂 |
| 可控性 | 精确到每一帧 | 部分依赖插件算法 |
| 适合平台 | B站 / YouTube | 短视频平台（更抓眼球） |

## 💡 核心启示

> YashFX 证明了一个道理：**同样的推拉关键帧，加了径向模糊+光效拖影，视觉冲击力翻倍。** 先掌握纯AE拉镜逻辑（Xenoz流），再用插件做增强层——而不是反过来。
