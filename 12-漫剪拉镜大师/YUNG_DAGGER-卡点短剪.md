## 🔥 标志性技法

### 1. Beat Sync 三段式卡点

```
每个节拍 = 三个动作：
① 预备（1-2帧）：Scale 微缩 100→95（蓄力）
② 爆发（1帧）：Scale 95→115 + Rotation ±3°（瞬间释放）
③ 回弹（3-5帧）：Scale 115→100（弹性归位）

关键帧密集度：
├── 蓄力段：Easy Ease In
├── 爆发段：线性（最快的切换）
└── 回弹段：Easy Ease Out
```

### 2. 音频波形可视化标记法

```
YUNG_DAGGER 工作流：
① 导入音频 → 展开音频波形
② 按 LL 展开波形视图（越大越好）
③ 按小键盘 * 在鼓点波峰处打标记
④ 标记序列 = 拉镜头序列

鼓点类型 → 拉镜策略：
├── Kick（低音鼓）：Scale 缩放主卡
├── Snare（军鼓）：Rotation 旋转辅卡
├── Hi-hat（镲）：Position 微移（轻量）
└── 重拍（Kick+Snare叠加）：缩放+旋转+位移 同时触发
```

### 3. 短平快拉镜节奏

```
时长公式：
15秒 ≈ 4-8 个节拍 ≈ 4-8 次拉镜
30秒 ≈ 8-16 个节拍 ≈ 8-16 次拉镜
60秒 ≈ 16-30 个节拍 ≈ 16-30 次拉镜

每次拉镜时长：
├── 极速：2-3帧（Snap风格）
├── 快速：4-6帧（主流）
└── 中速：7-10帧（间隔用）
```

## 🎬 模板：30秒 Beat Sync 拉镜序列

```
音轨结构（以 Trap Beat 为例）：
Intro(4拍) → Verse(8拍) → Hook/高潮(8拍) → Outro(4拍)

Intro (0-4秒)：慢推，建立氛围
├── 帧0-24:  Scale 100→108
├── 帧24-48: Scale 108→100
└── 曲线：平缓的 Ease In-Out

Verse (4-12秒)：卡点开始
├── 每个 Kick 鼓点 → 切换一次
├── Scale 100→120, Rotation ±5°
└── 每次拉镜 4-6 帧

Hook/高潮 (12-20秒)：密集卡点
├── 每个 Snare + Kick → 双倍卡点
├── Scale 100→130, Rotation ±8°
├── 加 Position 位移（对角线）
├── 运动模糊拉到 360° 快门
└── 每次拉镜 2-4 帧（极速）

Outro (20-30秒)：收束
├── 拉镜间距拉大
├── 最后一次大拉镜后 → 慢推到黑
└── Scale 100→85, Opacity 100→0
```
