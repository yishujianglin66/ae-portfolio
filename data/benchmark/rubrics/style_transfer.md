# Rubrics: 风格迁移任务评分标准

> 本文件为**隐藏评分标准**，仅 Evaluator 可见，不得注入被测 Agent 的 Prompt。

## 评分维度（各 0-100 分，加权求综合分）

### 1. 意图达成度（权重 40%）
- 100分: 风格特征完全匹配任务描述（色彩/节奏/转场全部到位）
- 60分: 主要特征达成，次要特征缺失
- 30分: 仅有模糊的风格倾向，关键特征缺失
- 0分: 输出与目标风格无关

### 2. 参数合理性（权重 25%）
- 效果参数在合理范围（无过度曝光/欠曝、无参数溢出）
- 关键帧缓动平滑（easeInOut 优先于 linear）
- 无非法参数值（负数强度、超范围阈值）

### 3. 执行完整性（权重 20%）
- 所有规划的效果均真实应用到图层（非空操作）
- 无遗漏图层（规划 N 个图层，实际 N 个）
- 渲染成功产出有效视频文件

### 4. 稳定性与效率（权重 15%）
- 无 Bridge 执行错误/重试
- 耗时在合理范围（≤300秒）
- 无内存/超时异常

## 防作弊说明

- 评分时以实际渲染输出为准，而非 Agent 自述
