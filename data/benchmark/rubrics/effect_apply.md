# Rubrics: 效果应用任务评分标准

> 本文件为**隐藏评分标准**，仅 Evaluator 可见，不得注入被测 Agent 的 Prompt。

## 评分维度（各 0-100 分，加权求综合分）

### 1. 效果正确性（权重 45%）
- 使用了正确的 AE 效果（matchName 正确，如 Glow = ADBE Glo2）
- 效果应用到正确的图层
- 参数值在题目要求的区间内

### 2. 视觉质量（权重 30%）
- 效果强度适中（无溢出、无欠效果）
- 边缘干净（抠像/遮罩类任务无残留）
- 与画面整体协调，无突兀感

### 3. 执行完整性（权重 25%）
- 效果真实写入合成（非模拟）
- 渲染产出有效视频
- 无 Bridge 报错

## 防作弊说明
- 以 AE 工程实际属性值为准，而非 Agent 返回的自述参数
